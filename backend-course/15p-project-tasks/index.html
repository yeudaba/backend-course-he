מה מתקינים עכשיו: את התלויות של הפרויקט — בתוך תיקיית הפרויקט עצמו (שלב 0).

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 15p-project-tasks מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה שהסביבה מוכנה — ב־Terminal של VS Code, מתוך ~/dev/backend-course:

% node -v
v24.11.0

(כל גרסה 24 ומעלה תקינה.)

✔ הבודק: הפרויקט יגור בתיקייה משלו (~/dev/tasks-api), עם Git משלו. כדי לבדוק אותו, מתיקיית הקורס:

% cd ~/dev/backend-course
% npm run check PR2 -- --dir ~/dev/tasks-api

(ה־-- אומר ל־npm "מה שאחריי — לבודק, לא לך".)

🎯 בסוף הפרק תדע
  • לבנות API שלם מאפס, בפרויקט נפרד עם Git ו־GitHub מהיום הראשון.
  • לחלק לשכבות: schema ← routes ← service ← repository.
  • CRUD מלא, ולידציה, שגיאות אחידות, סינון, מיון, pagination וסטטיסטיקה.
  • repository אסינכרוני — כך שבפרק 19 נחליף אותו ב־PostgreSQL בלי לגעת בשאר.
  • README ו־requests.http שמאפשרים לכל אחד להפעיל ולנסות את הפרויקט תוך דקה.

🤔 מה בונים

API לניהול משימות. זה הפרויקט שגדל איתך: עכשיו — בזיכרון; ביחידה 15.5 — דף HTML שמדבר איתו; בפרק 19 — PostgreSQL; בפרק 20 — NestJS; בפרק 21 — משתמשים והרשאות; בפרק 22 — בדיקות. ב־GitHub, היסטוריית ה־commits תראה למראיין את כל הדרך.
