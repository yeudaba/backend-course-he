1. README.md

מראיין פותח את ה־repo, וקורא את ה־README לפני (ולפעמים במקום) הקוד. תבנית:

README.md 
# tasks-api

API לניהול משימות: יצירה, עדכון, סינון, מיון ו־pagination.
Node.js 24 · TypeScript · Express 5 · Zod

## הפעלה
npm install
npm run dev        # http://localhost:3000

## Endpoints
| Method | Path           | תיאור |
|--------|----------------|-------|
| GET    | /health        | בדיקת חיים |
| GET    | /tasks         | רשימה: status, priority, q, sort, page, limit |
| ...    | ...            | ... |

דוגמאות מוכנות: `requests.http` (תוסף REST Client ל־VS Code).

## שגיאות
כל שגיאה: `{ "error": { "code", "message", "details"? } }` — טבלת קודים: ...

## מבנה
src/tasks — schema (Zod) ← routes ← service (חוקים) ← repository (כרגע בזיכרון)

## מה הלאה
- [ ] PostgreSQL + Prisma
- [ ] משתמשים והרשאות
- [ ] בדיקות אוטומטיות

הסעיף "מה הלאה" לא חולשה — הוא מראה שאתה יודע מה חסר. ותעדכן אותו בכל שלב של הפרויקט.

2. בדיקה עצמית

  • npm run check PR2 -- --dir ~/dev/tasks-api — הכול עובר חוץ מ־PR2-WEB (יחידה 15.5).
  • npm run typecheck (בתיקיית הפרויקט) — אין שגיאות.
  • אין try/catch ב־routes, ואין res.status(4xx) ב־service.
  • ה־service לא מייבא כלום מ־express.
  • שום מקום לא קורא ל־req.body לפני ש־validate עבר עליו.
  • שגיאה פנימית לא חושפת err.message ללקוח.
  • node_modules לא ב־Git (git ls-files | grep node_modules ריק).
  • כל בקשה ב־requests.http עובדת, כולל לפחות שתי בקשות שגיאה.
  • היסטוריית ה־commits מספרת סיפור (git log --oneline).
