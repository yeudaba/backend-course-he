3. הקמה

  1. ב־Finder: העתק את 15p-project-tasks/starter/tasks-api אל ~/dev/tasks-api (לצד backend-course, לא בתוכו).
  2. ב־Terminal:
% cd ~/dev/tasks-api
% npm install
added 78 packages, and audited 79 packages in 6s
% code .
  1. צור .gitignore עם השורה node_modules/ — לפני ה־commit הראשון.
  2. Git ו־GitHub (כמו בפרק 9, שיעור 4):
% git init
% git add .
% git commit -m "Initial skeleton for tasks API"
% git remote add origin https://github.com/YOUR-USER/tasks-api.git
% git push -u origin main
  1. הפעל: npm run dev. השרת עולה (tasks-api רץ: http://localhost:3000) — אבל כל בקשה תחזיר 404 של Express, כי createApp עוד ריקה.
  2. הרץ את הבודק (בחלון Terminal שני, מתיקיית הקורס): npm run check PR2 -- --dir ~/dev/tasks-api. הכול נכשל — מצוין, זו נקודת ההתחלה.

4. איך עובדים

  • commit לכל צעד שעובד: "Add task schemas", "Implement in-memory repository"... מראיין שפותח את ה־repo רואה איך אתה עובד, לא רק את התוצאה.
  • npm run typecheck (בתיקיית הפרויקט) מדי פעם — הבודק לא בודק טיפוסים, אבל TypeScript ימצא באגים לפני שהם קורים.
  • אפשר (ומומלץ) להעתיק מהפתרונות שלך לתרגילי פרק 15: E10 (שגיאות), E13 (pagination), E15 (validate), E16 (שכבות). זה לא רמאות — זו הסיבה שתרגלת אותם.
  • תקוע? רמזים בכל שלב. הפתרון המלא — רק בסוף (reference.html).
