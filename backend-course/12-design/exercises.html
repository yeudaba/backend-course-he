P12-E01 · מה ידפיס? (מחלקות)

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

נבא את הפלט:

class Counter {
  #count = 0;
  readonly name: string;
  constructor(name: string) {
    this.name = name;
  }
  get value(): number {
    return this.#count;
  }
  inc(): this {
    this.#count++;
    return this;
  }
}
const a = new Counter("a");
const b = new Counter("b");
a.inc().inc();
b.inc();
const c = a;
c.inc();
console.log(a.value, b.value, c.value, a === c, a.name);

P12-E02 · מחלקות ו־JSON

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

מה ידפיס, ולמה זה חשוב כשנתונים נשמרים במסד או נשלחים ברשת?

class Product {
  #cost = 40;
  name: string;
  price: number;
  constructor(name: string, price: number) {
    this.name = name;
    this.price = price;
  }
  get margin(): number {
    return this.price - this.#cost;
  }
}
const p = new Product("עט", 50);
const text = JSON.stringify(p);
const back = JSON.parse(text);
console.log(text);
console.log(p.margin, back.margin, back instanceof Product);

P12-E03 · מי תופס?

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

עם ההיררכיה AppError ← NotFoundError, AppError ← ValidationError — מה יחזיר handle לכל שגיאה? מה הבאג בסדר הבדיקות?

function handle(err: unknown): number {
  if (err instanceof AppError) return 400;
  if (err instanceof NotFoundError) return 404;
  if (err instanceof ValidationError) return 422;
  return 500;
}
handle(new NotFoundError("x", 1));
handle(new ValidationError("f", "m"));
handle(new Error("boom"));
handle("string error");

P12-E25 · אתגר: מיכל DI זעיר 🤖
