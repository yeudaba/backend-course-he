P12-E26 · מחסן כמחלקה 🤖 ✍️ מאפס רמה 3

💡 רמז 1

שדה פרטי אחד: #items = new Map<string, number>();. מתודה פרטית לבדיקת כמות (#checkQty(qty)) חוסכת לכתוב את אותה בדיקה פעמיים.

💡 רמז 2

ב־remove: קודם כל הבדיקות (כמות, ואז have < qty), ורק אחר כך שינוי. אם have - qty === 0 — this.#items.delete(sku). ‏totalItems: ‏[...this.#items.values()].reduce(...). ‏skus: ‏[...this.#items.keys()].sort().

✅ פתרון
// P12-E26: מחסן כמחלקה
export class Inventory {
  #items = new Map<string, number>();

  #checkQty(qty: number): void {
    if (!Number.isInteger(qty) || qty <= 0) {
      throw new RangeError("כמות חייבת להיות מספר שלם חיובי");
    }
  }

  add(sku: string, qty: number): void {
    this.#checkQty(qty);
    this.#items.set(sku, this.count(sku) + qty);
  }

  remove(sku: string, qty: number): void {
    this.#checkQty(qty);
    const have = this.count(sku);
    if (have < qty) {
      throw new Error(`אין מספיק ${sku}: יש ${have}, ביקשו ${qty}`);
    }
    if (have === qty) {
      this.#items.delete(sku);
    } else {
      this.#items.set(sku, have - qty);
    }
  }

  count(sku: string): number {
    return this.#items.get(sku) ?? 0;
  }

  totalItems(): number {
    return [...this.#items.values()].reduce((sum, n) => sum + n, 0);
  }

  skus(): string[] {
    return [...this.#items.keys()].sort();
  }
}

const inv = new Inventory();
inv.add("pen", 5);
inv.add("cup", 2);
inv.remove("cup", 2);
try {
  inv.remove("pen", 9);
} catch (err) {
  console.log((err as Error).message);
}
console.log(inv.count("pen"), inv.totalItems(), inv.skus());
אין מספיק pen: יש 5, ביקשו 9
5 5 [ 'pen' ]

השווה ל־P07-E27: שם המשתנה items היה "פרטי" כי הוא חי בתוך הפונקציה. כאן הוא פרטי בזכות #. בשני המקרים מבחוץ אפשר רק לקרוא למתודות. ההבדל העיקרי הוא בנוחות: במחלקה יש instanceof, ‏getters, ירושה, ומקום טבעי למתודות פרטיות כמו #checkQty.

הסדר ב־remove הוא העיקרון של שיעור 1: קודם בודקים, אחר כך משנים. כך שגיאה אף פעם לא משאירה את האובייקט "באמצע". ואם תשתמש ב־count בתוך add ו־remove, ה־?? 0 נכתב פעם אחת בלבד.

(err as Error): ב־TypeScript, מה שנתפס ב־catch הוא מטיפוס unknown (פרק 11, שיעור 4). כאן אנחנו יודעים מה נזרק. בקוד שמקבל שגיאות מבחוץ, עדיף err instanceof Error.

⚠️ טעויות נפוצות
  • לשנות את הכמות ורק אחר כך לבדוק — אחרי שגיאה המלאי כבר שלילי.
  • להשאיר פריטים עם 0 ב־Map — ‏skus() מחזירה פריטים שאזלו.
  • items = new Map() בלי # — הבודק מגלה ש־Object.keys(inv) לא ריק, כלומר אפשר לגשת לנתונים מבחוץ.
  • sort() ישירות על this.#items.keys() — ל־iterator אין sort. קודם [...].

P12-E27 · Money: אובייקט ערך 🤖 🔁 חזרה רמה 3

💡 רמז 1

שדה אחד: readonly #agorot: number;. ‏fromShekels מחשבת Math.round(shekels * 100) וקוראת ל־fromAgorot, כך שהבדיקה כתובה פעם אחת. (Number.isInteger(NaN) הוא false, ולכן גם NaN נתפס שם.)

💡 רמז 2

toString: מפרקים את הערך המוחלט לשקלים (Math.floor(abs / 100)) ולאגורות (abs % 100). את הפסיקים מוסיפים לשקלים כמו ב־P05-E25 — לולאה מהסוף, שלוש ספרות בכל פעם. האגורות: String(cents).padStart(2, "0").

✅ פתרון
// P12-E27: Money — אובייקט ערך
function withCommas(n: number): string {
  const digits = String(n);
  let out = "";
  for (let i = digits.length; i > 0; i -= 3) {
    const part = digits.slice(Math.max(0, i - 3), i);
    out = out === "" ? part : `${part},${out}`;
  }
  return out;
}

export class Money {
  readonly #agorot: number;

  private constructor(agorot: number) {
    this.#agorot = agorot;
  }

  static fromAgorot(agorot: number): Money {
    if (!Number.isInteger(agorot)) {
      throw new RangeError("סכום באגורות חייב להיות מספר שלם");
    }
    return new Money(agorot);
  }

  static fromShekels(shekels: number): Money {
    return Money.fromAgorot(Math.round(shekels * 100));
  }

  get agorot(): number {
    return this.#agorot;
  }

  plus(other: Money): Money {
    return new Money(this.#agorot + other.#agorot);
  }

  times(factor: number): Money {
    return Money.fromAgorot(Math.round(this.#agorot * factor));
  }

  equals(other: Money): boolean {
    return this.#agorot === other.#agorot;
  }

  toString(): string {
    const abs = Math.abs(this.#agorot);
    const shekels = withCommas(Math.floor(abs / 100));
    const cents = String(abs % 100).padStart(2, "0");
    return `${this.#agorot < 0 ? "-" : ""}₪${shekels}.${cents}`;
  }
}

const price = Money.fromShekels(1234.5);
console.log(String(price), String(price.times(3)), String(Money.fromAgorot(-500)));
console.log(Money.fromShekels(0.1).plus(Money.fromShekels(0.2)).equals(Money.fromAgorot(30)));
₪1,234.50 ₪3,703.50 -₪5.00
true

אובייקט ערך (value object) הוא אובייקט שמוגדר רק על ידי הערך שלו, כמו מספר. לכן הוא immutable: plus לא משנה את price, אלא מחזירה Money חדש. אם שני חלקים בקוד מחזיקים את אותו מופע, אף אחד מהם לא יכול "להזיז" לשני את הסכום (פרק 7, הפניות).

ה־constructor הפרטי מבטיח שכל מופע עבר דרך fromAgorot, כלומר דרך הבדיקה. שים לב ש־other.#agorot מותר: שדה פרטי נגיש לכל קוד בתוך המחלקה, גם במופע אחר שלה.

ב־toString עובדים עם הערך המוחלט ומוסיפים את המינוס בסוף. אחרת, עם ‎-550 אגורות, ‏Math.floor(-5.5) הוא ‎-6 (ולא ‎-5), ו־-550 % 100 הוא ‎-50.

⚠️ טעויות נפוצות
  • לשמור שקלים (this.amount = 19.9) — 0.1 + 0.2 חוזר, ו־equals נכשל.
  • times בלי Math.round — fromAgorot זורקת על 1990 * 1.17.
  • להוסיף פסיקים למחרוזת שכבר יש בה מינוס — "-123456" הופך ל־"-,123,456", בדיוק הטעות מ־P05-E25.

P12-E28 · דוח הלקוחות הגדולים 🤖 🔁 חזרה רמה 3

💡 רמז 1

שלושה שלבים בתוך topCustomers: (1) await this.#orders.findAll() ← filter ← קיבוץ ל־Map<number, number> של userId ← סכום. (2) [...totals] (מערך של זוגות) ← sort ← slice(0, n). (3) findByIds על ה־ids שנבחרו, ו־Map מ־id לשם.

(כמו שראית בשיעור 1: את השדות כותבים במפורש — #orders: OrderRepository; ובתוך ה־constructor ‏this.#orders = orders;.)

💡 רמז 2

מיון זוגות: .sort(([idA, a], [idB, b]) => b - a || idA - idB) — אם ההפרש 0, ה־|| עובר להשוואה השנייה. בסוף: top.map(([id, total]) => ({ name: names.get(id) ?? "לא ידוע", total })).

✅ פתרון
// P12-E28: דוח הלקוחות הגדולים
export type Order = { id: number; userId: number; total: number; status: "paid" | "cancelled" };
export type User = { id: number; name: string };

export interface OrderRepository {
  findAll(): Promise<Order[]>;
}
export interface UserRepository {
  findByIds(ids: number[]): Promise<User[]>;
}

export class ReportService {
  #orders: OrderRepository;
  #users: UserRepository;

  constructor(orders: OrderRepository, users: UserRepository) {
    this.#orders = orders;
    this.#users = users;
  }

  async topCustomers(n: number): Promise<{ name: string; total: number }[]> {
    const orders = await this.#orders.findAll();

    const totals = new Map<number, number>();
    for (const o of orders.filter((o) => o.status === "paid")) {
      totals.set(o.userId, (totals.get(o.userId) ?? 0) + o.total);
    }

    const top = [...totals].sort(([idA, a], [idB, b]) => b - a || idA - idB).slice(0, n);

    const users = await this.#users.findByIds(top.map(([id]) => id));
    const names = new Map(users.map((u) => [u.id, u.name]));

    return top.map(([id, total]) => ({ name: names.get(id) ?? "לא ידוע", total }));
  }
}

const orders: OrderRepository = {
  findAll: async () => [
    { id: 1, userId: 7, total: 100, status: "paid" },
    { id: 2, userId: 8, total: 300, status: "paid" },
    { id: 3, userId: 7, total: 250, status: "paid" },
    { id: 4, userId: 9, total: 999, status: "cancelled" },
  ],
};
const users: UserRepository = {
  findByIds: async (ids) => [{ id: 7, name: "דנה" }, { id: 8, name: "עומר" }].filter((u) => ids.includes(u.id)),
};

console.log(await new ReportService(orders, users).topCustomers(5));
[ { name: 'דנה', total: 350 }, { name: 'עומר', total: 300 } ]

ה־service לא יודע מאיפה מגיעים הנתונים: ממסד, מקובץ או מאובייקט מזויף בבדיקה. הוא יודע רק את ה־interface. בזכות זה הבודק יכול להזריק repository שסופר קריאות, ולוודא שלא נוצרה בעיית N+1: קריאה למסד לכל לקוח בנפרד, במקום קריאה אחת לכולם (תפגוש אותה שוב בפרקים 17 ו־19).

[...totals] הופך Map למערך של זוגות [userId, total], ומשם זה מיון רגיל (פרק 6). ‏new Map(users.map(...)) הוא הדרך הקצרה לבנות מילון מ־id לשם, כדי שהחיפוש בסוף לא יסרוק את המערך כל פעם מחדש.

⚠️ טעויות נפוצות
  • for (const [id] of top) { await this.#users.findByIds([id]); } — ‏N קריאות במקום אחת. הבודק סופר.
  • לשלוף שמות לכל הלקוחות לפני ה־slice — עובד, אבל מבקש מהמסד אלפי שמות כדי להציג חמישה.
  • .sort((a, b) => b[1] - a[1]) בלי שובר שוויון — הסדר בין לקוחות עם אותו סכום תלוי בסדר ההזמנות.
  • constructor(private orders: OrderRepository) — Node לא מריץ את הכתיב המקוצר הזה ישירות מקובץ .ts (שיעור 1).

// P12-E06
export class Counter {
  #count: number;
  #start: number;
  #max: number;

  constructor(start = 0, max = Infinity) {
    this.#start = start;
    this.#max = max;
    this.#count = start;
  }

  get value(): number {
    return this.#count;
  }

  increment(): this {
    this.#count = Math.min(this.#count + 1, this.#max);
    return this;
  }

  reset(): void {
    this.#count = this.#start;
  }
}

// P12-E07
export class Temperature {
  static readonly ABSOLUTE_ZERO = -273.15;
  readonly celsius: number;

  constructor(celsius: number) {
    if (celsius < Temperature.ABSOLUTE_ZERO) {
      throw new RangeError("מתחת לאפס המוחלט");
    }
    this.celsius = celsius;
  }

  static fromFahrenheit(f: number): Temperature {
    return new Temperature(((f - 32) * 5) / 9);
  }

  get fahrenheit(): number {
    return (this.celsius * 9) / 5 + 32;
  }

  isFreezing(): boolean {
    return this.celsius <= 0;
  }

  toString(): string {
    return `${this.celsius}°C`;
  }
}

// P12-E08
export type CartLine = { sku: string; price: number; qty: number };

export class ShoppingCart {
  #lines = new Map<string, CartLine>();

  add(sku: string, price: number, qty = 1): void {
    if (qty <= 0 || price <= 0) {
      throw new Error("כמות ומחיר חייבים להיות חיוביים");
    }
    const existing = this.#lines.get(sku);
    this.#lines.set(sku, { sku, price, qty: (existing?.qty ?? 0) + qty });
  }

  remove(sku: string): boolean {
    return this.#lines.delete(sku);
  }

  get total(): number {
    let sum = 0;
    for (const l of this.#lines.values()) {
      sum += l.price * l.qty;
    }
    return Math.round(sum * 100) / 100;
  }

  get itemCount(): number {
    let n = 0;
    for (const l of this.#lines.values()) {
      n += l.qty;
    }
    return n;
  }

  items(): CartLine[] {

// P12-E13
export class Inventory {
  #stock = new Map<string, number>();
  #reserved = new Map<string, number>();

  #assertQty(qty: number): void {
    if (!Number.isInteger(qty) || qty <= 0) {
      throw new Error("כמות לא תקינה");
    }
  }

  addStock(sku: string, qty: number): void {
    this.#assertQty(qty);
    this.#stock.set(sku, (this.#stock.get(sku) ?? 0) + qty);
  }

  available(sku: string): number {
    return (this.#stock.get(sku) ?? 0) - (this.#reserved.get(sku) ?? 0);
  }

  reserve(sku: string, qty: number): void {
    this.#assertQty(qty);
    if (this.available(sku) < qty) {
      throw new Error(`אין מספיק מלאי של ${sku}`);
    }
    this.#reserved.set(sku, (this.#reserved.get(sku) ?? 0) + qty);
  }

  release(sku: string, qty: number): void {
    this.#assertQty(qty);
    const reserved = this.#reserved.get(sku) ?? 0;
    if (qty > reserved) {
      throw new Error("שחרור גדול מהשריון");
    }
    this.#reserved.set(sku, reserved - qty);
  }

  commit(sku: string, qty: number): void {
    this.release(sku, qty);
    this.#stock.set(sku, (this.#stock.get(sku) ?? 0) - qty);
  }
}

export class RateLimiter {
  #limit: number;
  #windowMs: number;
  #now: () => number;
  #hits = new Map<string, number[]>();

  constructor({ limit, windowMs, now = Date.now }: { limit: number; windowMs: number; now?: () => number }) {
    this.#limit = limit;
    this.#windowMs = windowMs;
    this.#now = now;
  }

  #recent(key: string): number[] {
    const cutoff = this.#now() - this.#windowMs;
    const recent = (this.#hits.get(key) ?? []).filter((t) => t > cutoff);
    this.#hits.set(key, recent);
    return recent;
  }

  allow(key: string): boolean {
    const recent = this.#recent(key);
    if (recent.length >= this.#limit) {
      return false;
    }
    recent.push(this.#now());
    return true;
  }

  remaining(key: string): number {
    return Math.max(0, this.#limit - this.#recent(key).length);
  }
}

// P12-E17
export interface Repo<T extends { id: number }> {
  findById(id: number): Promise<T | null>;
  save(item: T): Promise<void>;
}

export class CachedRepository<T extends { id: number }> implements Repo<T> {
  #inner: Repo<T>;
  #cache = new Map<number, T | null>();
  #hits = 0;
  #misses = 0;

  constructor(inner: Repo<T>) {
    this.#inner = inner;
  }

  get hits(): number {
    return this.#hits;
  }
  get misses(): number {
    return this.#misses;
  }

  async findById(id: number): Promise<T | null> {
    if (this.#cache.has(id)) {
      this.#hits++;
      const cached = this.#cache.get(id) ?? null;
      return cached ? { ...cached } : null;
    }
    this.#misses++;
    const item = await this.#inner.findById(id);
    this.#cache.set(id, item ? { ...item } : null);
    return item;
  }

  async save(item: T): Promise<void> {
    await this.#inner.save(item);
    this.#cache.set(item.id, { ...item });
  }
}

✅ פתרון
// P12-E19
export class ValidationError extends Error {
  readonly field: string;
  constructor(field: string, message: string) {
    super(message);
    this.field = field;
  }
}

function parseIntStrict(text: string): number | null {
  return /^\d+$/.test(text.trim()) ? Number(text.trim()) : null;
}

export function parsePagination(query: Record<string, string | undefined>): { page: number; pageSize: number; offset: number } {
  let page = 1;
  if (query.page !== undefined) {
    const p = parseIntStrict(query.page);
    if (p === null || p < 1) {
      throw new ValidationError("page", "page חייב להיות מספר שלם חיובי");
    }
    page = p;
  }
  let pageSize = 20;
  if (query.pageSize !== undefined) {
    const s = parseIntStrict(query.pageSize);
    if (s === null || s < 1 || s > 100) {
      throw new ValidationError("pageSize", "pageSize חייב להיות בין 1 ל־100");
    }
    pageSize = s;
  }
  return { page, pageSize, offset: (page - 1) * pageSize };
}

console.log(parsePagination({ page: "3", pageSize: "10" }), parsePagination({}));
{ page: 3, pageSize: 10, offset: 20 } { page: 1, pageSize: 20, offset: 0 }

P12-E24 · אתגר: ארנק והעברות idempotent 🤖 רמה 5

💡 רמז 1

💡 רמז 2

שקלים ← אגורות: Math.round(amount * 100), ובדוק ש־Math.abs(amount * 100 - agorot) < 1e-9 (אחרת יש יותר מ־2 ספרות).

✅ פתרון
// P12-E24
export type Wallet = { id: string; balanceAgorot: number };
export interface WalletRepo {
  find(id: string): Promise<Wallet | null>;
  save(w: Wallet): Promise<void>;
}
export class NotFoundError extends Error {}
export class ValidationError extends Error {}
export class InsufficientFundsError extends Error {}

type TransferResult = { transferId: number; fromBalance: number; toBalance: number };

export class TransferService {
  #wallets: WalletRepo;
  #done = new Map<string, TransferResult>();
  #nextId = 1;

  constructor(wallets: WalletRepo) {
    this.#wallets = wallets;
  }

  async transfer(req: { from: string; to: string; amount: number; idempotencyKey: string }): Promise<TransferResult> {
    const previous = this.#done.get(req.idempotencyKey);
    if (previous) {
      return previous;
    }
    const agorot = Math.round(req.amount * 100);
    if (!(req.amount > 0) || Math.abs(req.amount * 100 - agorot) > 1e-9) {
      throw new ValidationError("סכום לא תקין");
    }
    if (req.from === req.to) {
      throw new ValidationError("לא ניתן להעביר לאותו ארנק");
    }
    const from = await this.#wallets.find(req.from);
    const to = await this.#wallets.find(req.to);
    if (!from || !to) {
      throw new NotFoundError("ארנק לא נמצא");
    }
    if (from.balanceAgorot < agorot) {
      throw new InsufficientFundsError("אין מספיק יתרה");
    }
    const newFrom = { ...from, balanceAgorot: from.balanceAgorot - agorot };
    const newTo = { ...to, balanceAgorot: to.balanceAgorot + agorot };
    await this.#wallets.save(newFrom);
    await this.#wallets.save(newTo);
    const result = { transferId: this.#nextId++, fromBalance: newFrom.balanceAgorot / 100, toBalance: newTo.balanceAgorot / 100 };
    this.#done.set(req.idempotencyKey, result);
    return result;
  }
}

const store = new Map<string, Wallet>([["a", { id: "a", balanceAgorot: 10000 }], ["b", { id: "b", balanceAgorot: 0 }]]);
const repo: WalletRepo = { find: async (id) => (store.has(id) ? { ...store.get(id)! } : null), save: async (w) => void store.set(w.id, { ...w }) };
const svc = new TransferService(repo);
const r1 = await svc.transfer({ from: "a", to: "b", amount: 19.9, idempotencyKey: "k1" });
const r2 = await svc.transfer({ from: "a", to: "b", amount: 19.9, idempotencyKey: "k1" });

idempotency היא דרישה בכל מערכת תשלומים, ותופיע בפרויקט הדגל (מפתח בכותרת הבקשה). כאן ה־Map בזיכרון — בייצור היא נשמרת במסד, ונבדקת בתוך אותה transaction.

⚠️ טעויות נפוצות
  • לבדוק את ה־idempotencyKey אחרי הבדיקות — ניסיון חוזר אחרי שהיתרה ירדה ייכשל ב"אין מספיק יתרה" במקום להחזיר את התוצאה המקורית.

P12-E25 · אתגר: מיכל DI זעיר 🤖 רמה 5

💡 רמז 1

💡 רמז 2

ב־resolve: אם name כבר ב־stack — מעגל: [...stack.slice(stack.indexOf(name)), name].join(" -> ").

✅ פתרון
// P12-E25: מיכל DI מינימלי
export class Container {
  #factories = new Map<string, (c: Container) => unknown>();
  #instances = new Map<string, unknown>();
  #resolving: string[] = [];

  register(name: string, factory: (c: Container) => unknown): void {
    if (this.#factories.has(name)) {
      throw new Error(`השירות ${name} כבר רשום`);
    }
    this.#factories.set(name, factory);
  }

  resolve<T = unknown>(name: string): T {
    if (this.#instances.has(name)) {
      return this.#instances.get(name) as T;
    }
    const factory = this.#factories.get(name);
    if (!factory) {
      throw new Error(`השירות ${name} לא רשום`);
    }
    if (this.#resolving.includes(name)) {
      const cycle = [...this.#resolving.slice(this.#resolving.indexOf(name)), name];
      throw new Error(`תלות מעגלית: ${cycle.join(" -> ")}`);
    }
    this.#resolving.push(name);
    try {
      const instance = factory(this);
      this.#instances.set(name, instance);
      return instance as T;
    } finally {
      this.#resolving.pop();
    }
  }
}

class Repo {}
class Service {
  repo: Repo;
  constructor(repo: Repo) {
    this.repo = repo;
  }
}
const c = new Container();
c.register("repo", () => new Repo());
c.register("service", (ct) => new Service(ct.resolve<Repo>("repo")));
const s = c.resolve<Service>("service");
console.log(s === c.resolve("service"), s.repo === c.resolve("repo"));

c.register("A", (ct) => ct.resolve("B"));
c.register("B", (ct) => ct.resolve("A"));
try {
  c.resolve("A");
} catch (err) {
  console.log((err as Error).message);
}
