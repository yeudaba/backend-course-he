P12-E43 · מתודה שנדרסת 🧠 הבנה רמה 2

💡 רמז 2

✅ פתרון
class Notifier {
  send(to: string): string {
    return `הודעה ל־${to}`;
  }
  sendAll(list: string[]): string[] {
    return list.map((to) => this.send(to));
  }
}

class LoudNotifier extends Notifier {
  send(to: string): string {
    return super.send(to).toUpperCase() + "!";
  }
}

P12-E09 · היררכיית שגיאות 🤖 💻 כתיבת קוד 🤖 רמה 2

✅ פתרון
// P12-E09
export class AppError extends Error {
  readonly status: number;
  readonly code: string;
  constructor(message: string, status: number, code: string) {
    super(message);
    this.name = new.target.name;
    this.status = status;
    this.code = code;
  }
}

export class NotFoundError extends AppError {
  constructor(entity: string, id: string | number) {
    super(`${entity} ${id} לא נמצא`, 404, "NOT_FOUND");
  }
}

export class ValidationError extends AppError {
  readonly field: string;
  constructor(field: string, message: string) {
    super(message, 400, "VALIDATION");
    this.field = field;
  }
}

export class ConflictError extends AppError {
  constructor(message: string) {
    super(message, 409, "CONFLICT");
  }
}

export function toHttp(err: unknown): { status: number; body: { code: string; message: string; field?: string } } {
  if (err instanceof AppError) {
    return {
      status: err.status,
      body: { code: err.code, message: err.message, ...(err instanceof ValidationError ? { field: err.field } : {}) },
    };
  }
  return { status: 500, body: { code: "INTERNAL", message: "שגיאה פנימית" } };
}

P12-E10 · חוזה Logger 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

PrefixLogger הוא הרכבה: "יש לו" Logger.

💡 רמז 2

processOrders מקבל Logger — לא MemoryLogger. כך עובד עם כל מימוש.

✅ פתרון
// P12-E10
export interface Logger {
  info(msg: string): void;
  error(msg: string): void;
}

export class MemoryLogger implements Logger {
  #lines: string[] = [];
  info(msg: string): void {
    this.#lines.push(`INFO: ${msg}`);
  }
  error(msg: string): void {
    this.#lines.push(`ERROR: ${msg}`);
  }
  get lines(): string[] {
    return [...this.#lines];
  }
}

export class PrefixLogger implements Logger {
  #inner: Logger;
  #prefix: string;
  constructor(inner: Logger, prefix: string) {
    this.#inner = inner;
    this.#prefix = prefix;
  }
  info(msg: string): void {
    this.#inner.info(`${this.#prefix} ${msg}`);
  }
  error(msg: string): void {
    this.#inner.error(`${this.#prefix} ${msg}`);
  }
}

export function processOrders(ids: number[], logger: Logger): number {
  let ok = 0;
  for (const id of ids) {
    if (id > 0) {
      logger.info(`order ${id} ok`);
      ok++;
    } else {
      logger.error(`order ${id} invalid`);
    }
  }
  return ok;
}

const mem = new MemoryLogger();
console.log(processOrders([1, -2], new PrefixLogger(mem, "[orders]")), mem.lines);
1 [ 'INFO: [orders] order 1 ok', 'ERROR: [orders] order -2 invalid' ]
⚠️ טעויות נפוצות
  • PrefixLogger extends MemoryLogger — ירושה במקום הרכבה; אז הוא עובד רק עם MemoryLogger.

// P12-E14
export class RateLimiter {
  #limit: number;
  #windowMs: number;
  #now: () => number;
  #hits = new Map<string, number[]>();

  constructor({ limit, windowMs, now = Date.now }: { limit: number; windowMs: number; now?: () => number }) {
    this.#limit = limit;
    this.#windowMs = windowMs;
    this.#now = now;
  }

  #recent(key: string): number[] {
    const cutoff = this.#now() - this.#windowMs;
    const recent = (this.#hits.get(key) ?? []).filter((t) => t > cutoff);
    this.#hits.set(key, recent);
    return recent;
  }

  allow(key: string): boolean {
    const recent = this.#recent(key);
    if (recent.length >= this.#limit) {
      return false;
    }
    recent.push(this.#now());
    return true;
  }

  remaining(key: string): number {
    return Math.max(0, this.#limit - this.#recent(key).length);
  }
}

export class HttpError extends Error {

    this.status = status;

P12-E26 · מחסן כמחלקה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

💡 רמז 2

ב־remove: קודם כל הבדיקות (כמות, ואז have < qty), ורק אחר כך שינוי. אם have - qty === 0 — this.#items.delete(sku). ‏totalItems: ‏[...this.#items.values()].reduce(...). ‏skus: ‏[...this.#items.keys()].sort().

✅ פתרון
// P12-E26: מחסן כמחלקה
export class Inventory {
  #items = new Map<string, number>();

  #checkQty(qty: number): void {
    if (!Number.isInteger(qty) || qty <= 0) {
      throw new RangeError("כמות חייבת להיות מספר שלם חיובי");
    }
  }

  add(sku: string, qty: number): void {
    this.#checkQty(qty);
    this.#items.set(sku, this.count(sku) + qty);
  }

  remove(sku: string, qty: number): void {
    this.#checkQty(qty);
    const have = this.count(sku);
    if (have < qty) {
      throw new Error(`אין מספיק ${sku}: יש ${have}, ביקשו ${qty}`);
    }
    if (have === qty) {
      this.#items.delete(sku);
    } else {
      this.#items.set(sku, have - qty);
    }
  }

  count(sku: string): number {
    return this.#items.get(sku) ?? 0;
  }

  totalItems(): number {
    return [...this.#items.values()].reduce((sum, n) => sum + n, 0);
  }

  skus(): string[] {
    return [...this.#items.keys()].sort();
  }
}

const inv = new Inventory();
inv.add("pen", 5);
inv.add("cup", 2);
inv.remove("cup", 2);
try {
  inv.remove("pen", 9);
} catch (err) {
  console.log((err as Error).message);
}
console.log(inv.count("pen"), inv.totalItems(), inv.skus());
אין מספיק pen: יש 5, ביקשו 9
5 5 [ 'pen' ]

השווה ל־P07-E27: שם המשתנה items היה "פרטי" כי הוא חי בתוך הפונקציה. כאן הוא פרטי בזכות #. בשני המקרים מבחוץ אפשר רק לקרוא למתודות. ההבדל העיקרי הוא בנוחות: במחלקה יש instanceof, ‏getters, ירושה, ומקום טבעי למתודות פרטיות כמו #checkQty.

הסדר ב־remove הוא העיקרון של שיעור 1: קודם בודקים, אחר כך משנים. כך שגיאה אף פעם לא משאירה את האובייקט "באמצע". ואם תשתמש ב־count בתוך add ו־remove, ה־?? 0 נכתב פעם אחת בלבד.

(err as Error): ב־TypeScript, מה שנתפס ב־catch הוא מטיפוס unknown (פרק 11, שיעור 4). כאן אנחנו יודעים מה נזרק. בקוד שמקבל שגיאות מבחוץ, עדיף err instanceof Error.

⚠️ טעויות נפוצות
  • לשנות את הכמות ורק אחר כך לבדוק — אחרי שגיאה המלאי כבר שלילי.
  • להשאיר פריטים עם 0 ב־Map — ‏skus() מחזירה פריטים שאזלו.
  • items = new Map() בלי # — הבודק מגלה ש־Object.keys(inv) לא ריק, כלומר אפשר לגשת לנתונים מבחוץ.
  • sort() ישירות על this.#items.keys() — ל־iterator אין sort. קודם [...].

export class LineError extends Error {
  readonly line: number;
  constructor(line: number, reason: string) {
    super(`שורה ${line}: ${reason}`);
    this.name = new.target.name;
    this.line = line;
  }
}

export class ImportError extends Error {
  readonly errors: LineError[];
  constructor(errors: LineError[]) {
    super(`${errors.length} שורות לא תקינות`);
    this.name = new.target.name;
    this.errors = errors;
  }
}

export function parseExpenses(text: string): { title: string; amount: number }[] {
  const rows: { title: string; amount: number }[] = [];
  const errors: LineError[] = [];
  const lines = text.split("\n");
  for (let i = 0; i < lines.length; i++) {
    if (lines[i].trim() === "") continue;
    const parts = lines[i].split(",").map((p) => p.trim());
    if (parts.length !== 2) {
      errors.push(new LineError(i + 1, "צריך שני שדות"));
      continue;
    }
    const [title, rawAmount] = parts;
    const amount = Number(rawAmount);
    if (title === "") {
      errors.push(new LineError(i + 1, "כותרת ריקה"));
    } else if (rawAmount === "" || !Number.isFinite(amount) || amount <= 0) {
      errors.push(new LineError(i + 1, "סכום לא תקין"));
    } else {
      rows.push({ title, amount });
    }
  }
  if (errors.length > 0) throw new ImportError(errors);
  return rows;
}

// P12-E54: בטל ובצע שוב
export class NothingToUndoError extends Error {
  constructor() {
    super("אין מה לבטל");
    this.name = new.target.name;
  }
}

export class NothingToRedoError extends Error {
  constructor() {
    super("אין מה לבצע שוב");
    this.name = new.target.name;
  }
}

export class History {
  #done: string[] = [];
  #undone: string[] = [];

  push(action: string): void {
    this.#done.push(action);
    this.#undone = [];
  }

  undo(): string {
    const action = this.#done.pop();
    if (action === undefined) throw new NothingToUndoError();
    this.#undone.push(action);
    return action;
  }

  redo(): string {
    const action = this.#undone.pop();
    if (action === undefined) throw new NothingToRedoError();
    this.#done.push(action);
    return action;
  }

  get done(): string[] {
    return [...this.#done];
  }
}

  h.redo();
