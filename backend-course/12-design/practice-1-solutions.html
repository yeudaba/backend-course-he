P12-E01 · מה ידפיס? (מחלקות) 🧠 הבנה רמה 1

💡 רמז 1

כל new יוצר מופע נפרד עם #count משלו.

💡 רמז 2

c = a — עוד הפניה לאותו מופע (פרק 7).

✅ פתרון
class Counter {
  #count = 0;
  readonly name: string;
  constructor(name: string) {
    this.name = name;
  }
  get value(): number {
    return this.#count;
  }
  inc(): this {
    this.#count++;
    return this;
  }
}
const a = new Counter("a");
const b = new Counter("b");
a.inc().inc();
b.inc();
const c = a;
c.inc();
console.log(a.value, b.value, c.value, a === c, a.name);
3 1 3 true a

return this מאפשר שרשור (a.inc().inc()).

⚠️ טעויות נפוצות
  • לחשוב ש־#count משותף לכל המופעים — הוא שייך לכל מופע בנפרד (משותף היה רק static).

P12-E02 · מחלקות ו־JSON 🧠 הבנה רמה 1

💡 רמז 1

JSON.stringify כולל רק שדות ציבוריים "רגילים".

💡 רמז 2

JSON.parse מחזיר אובייקט פשוט — בלי getters ובלי מתודות.

class Product {
  #cost = 40;
  name: string;
  price: number;
  constructor(name: string, price: number) {

    this.price = price;

const text = JSON.stringify(p);

מה שחוזר מהרשת או מהמסד הוא אובייקט פשוט. לכן: נתונים (DTOs, רשומות) — type ואובייקטים פשוטים; לוגיקה — במחלקות service שמקבלות את הנתונים.

P12-E29 · מופעים, שדות ו־static 🧠 הבנה רמה 1

💡 רמז 1

לכל מופע יש #used ו־id משלו. ‏static issued — אחד, משותף לכל המחלקה.

💡 רמז 2

ה־constructor רץ פעם אחת לכל new.

✅ פתרון
class Ticket {
  static issued = 0;
  readonly id: number;
  #used = false;

  constructor() {
    Ticket.issued++;
    this.id = Ticket.issued;
  }

  use(): string {
    if (this.#used) return `כרטיס ${this.id} כבר נוצל`;
    this.#used = true;
    return `כרטיס ${this.id} נוצל`;
  }
}

const b = new Ticket();

console.log(a.use());
console.log(b.use());
console.log(a.id, b.id, Ticket.issued);

כרטיס 2 נוצל

מה שכתוב עם static שייך למחלקה (מונה אחד), וכל השאר — למופע (כל כרטיס זוכר אם הוא נוצל). ניצול של a לא משפיע על b.

⚠️ טעויות נפוצות

P12-E30 · getter — מה מותר? 🧠 הבנה רמה 2

💡 רמז 1

P12-E31 · מחלקה או type? 🧠 הבנה רמה 1

💡 רמז 1

שתי שאלות: יש מצב פנימי שצריך להגן עליו? הנתונים עוברים ברשת / נשמרים?

💡 רמז 2

שגיאה — סעיף "סוגי שגיאות" בטבלה, ושיעור 2.

✅ פתרון

P12-E06 · Counter 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

שמור גם את start וגם את max בשדות פרטיים.

💡 רמז 2

this.#count = Math.min(this.#count + 1, this.#max); return this;

✅ פתרון
// P12-E06
export class Counter {
  #count: number;
  #start: number;
  #max: number;

  constructor(start = 0, max = Infinity) {
    this.#start = start;
    this.#max = max;
    this.#count = start;
  }

  get value(): number {
    return this.#count;
  }

  increment(): this {
    this.#count = Math.min(this.#count + 1, this.#max);
    return this;
  }

  reset(): void {
    this.#count = this.#start;
  }
}

const c = new Counter(0, 2);
console.log(c.increment().increment().increment().value);
2
⚠️ טעויות נפוצות
  • להחזיר void מ־increment — שרשור לא יעבוד.

P12-E07 · Temperature עם static 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

static fromFahrenheit(f: number): Temperature { return new Temperature(((f - 32) * 5) / 9); }

💡 רמז 2

RangeError היא מחלקת שגיאה מובנית, כמו TypeError.

✅ פתרון
// P12-E07
export class Temperature {
  static readonly ABSOLUTE_ZERO = -273.15;
  readonly celsius: number;

  constructor(celsius: number) {
    if (celsius < Temperature.ABSOLUTE_ZERO) {
      throw new RangeError("מתחת לאפס המוחלט");
    }
    this.celsius = celsius;
  }

  static fromFahrenheit(f: number): Temperature {
    return new Temperature(((f - 32) * 5) / 9);
  }

  get fahrenheit(): number {
    return (this.celsius * 9) / 5 + 32;
  }

  isFreezing(): boolean {
    return this.celsius <= 0;
  }

  toString(): string {
    return `${this.celsius}°C`;
  }
}

console.log(String(Temperature.fromFahrenheit(212)), new Temperature(21.5).fahrenheit);
100°C 70.7
⚠️ טעויות נפוצות
  • לבדוק את הטווח רק ב־fromFahrenheit — new Temperature(-500) יעבור.

P12-E08 · ShoppingCart 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

#lines = new Map<string, CartLine>()

💡 רמז 2

items: [...this.#lines.values()].map((l) => ({ ...l }))

✅ פתרון
// P12-E08
export type CartLine = { sku: string; price: number; qty: number };

export class ShoppingCart {
  #lines = new Map<string, CartLine>();

  add(sku: string, price: number, qty = 1): void {
    if (qty <= 0 || price <= 0) {
      throw new Error("כמות ומחיר חייבים להיות חיוביים");
    }
    const existing = this.#lines.get(sku);
    this.#lines.set(sku, { sku, price, qty: (existing?.qty ?? 0) + qty });
  }

  remove(sku: string): boolean {
    return this.#lines.delete(sku);
  }

  get total(): number {
    let sum = 0;
    for (const l of this.#lines.values()) {
      sum += l.price * l.qty;
    }
    return Math.round(sum * 100) / 100;
  }

  get itemCount(): number {
    let n = 0;
    for (const l of this.#lines.values()) {
      n += l.qty;
    }
    return n;
  }

  items(): CartLine[] {
    return [...this.#lines.values()].map((l) => ({ ...l }));
  }
}

const cart = new ShoppingCart();
cart.add("A", 2.5, 2);
cart.add("A", 2.5);
cart.add("B", 10);
console.log(cart.total, cart.itemCount, cart.items().length);
17.5 4 2
⚠️ טעויות נפוצות
  • items() שמחזיר את האובייקטים הפנימיים — cart.items()[0].qty = 999 משנה את העגלה.

P12-E13 · מלאי עם שמירה על חוקים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שני Map פרטיים: #stock ו־#reserved.

💡 רמז 2

פונקציה פרטית #assertQty(qty) — מתודות פרטיות נכתבות גם הן עם #.

✅ פתרון
// P12-E13
export class Inventory {
  #stock = new Map<string, number>();
  #reserved = new Map<string, number>();

  #assertQty(qty: number): void {
    if (!Number.isInteger(qty) || qty <= 0) {
      throw new Error("כמות לא תקינה");
    }
  }

  addStock(sku: string, qty: number): void {
    this.#assertQty(qty);
    this.#stock.set(sku, (this.#stock.get(sku) ?? 0) + qty);
  }

  available(sku: string): number {
    return (this.#stock.get(sku) ?? 0) - (this.#reserved.get(sku) ?? 0);
  }

  reserve(sku: string, qty: number): void {
    this.#assertQty(qty);
    if (this.available(sku) < qty) {
      throw new Error(`אין מספיק מלאי של ${sku}`);
    }
    this.#reserved.set(sku, (this.#reserved.get(sku) ?? 0) + qty);
  }

  release(sku: string, qty: number): void {
    this.#assertQty(qty);
    const reserved = this.#reserved.get(sku) ?? 0;
    if (qty > reserved) {
      throw new Error("שחרור גדול מהשריון");
    }
    this.#reserved.set(sku, reserved - qty);
  }

  commit(sku: string, qty: number): void {
    this.release(sku, qty);
    this.#stock.set(sku, (this.#stock.get(sku) ?? 0) - qty);
  }
}

const inv = new Inventory();
inv.addStock("A", 5);
inv.reserve("A", 3);
inv.commit("A", 2);
console.log(inv.available("A"));
2

(5 במלאי, 3 משוריינים ← commit של 2: מלאי 3, משוריין 1 ← זמין 2.) זה בדיוק הדפוס של "שריון בעגלה, הורדה בתשלום" שתממש בפרויקט הדגל — שם עם transaction במסד.

⚠️ טעויות נפוצות
  • commit בלי לבדוק שריון — אפשר למכור מה ששוריין למישהו אחר.

// P12-E33: ניקוד במשחק
export class Score {
  #points = 0;

  get points(): number {

P12-E34 · טווח מספרים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

ב־parse: const parts = text.split("-").map((p) => p.trim()); — צריך בדיוק שני חלקים, ושניהם מספרים (לא ריקים).

💡 רמז 2

חפיפה: this.start <= other.end && other.start <= this.end.

✅ פתרון
// P12-E34: טווח מספרים
export class Range {
  readonly start: number;
  readonly end: number;

  constructor(start: number, end: number) {
    if (end < start) throw new RangeError("end קטן מ־start");
    this.start = start;
    this.end = end;
  }

  static parse(text: string): Range {
    const parts = text.split("-").map((p) => p.trim());
    if (parts.length !== 2 || parts[0] === "" || parts[1] === "") throw new RangeError("טווח לא תקין");
    const start = Number(parts[0]);
    const end = Number(parts[1]);
    if (Number.isNaN(start) || Number.isNaN(end)) throw new RangeError("טווח לא תקין");
    return new Range(start, end);
  }

  get length(): number {
    return this.end - this.start;
  }

  includes(n: number): boolean {
    return n >= this.start && n <= this.end;
  }

  overlaps(other: Range): boolean {
    return this.start <= other.end && other.start <= this.end;
  }

  toString(): string {
    return `[${this.start}, ${this.end}]`;
  }
}

const r = Range.parse(" 3 - 7 ");
console.log(String(r), r.length, r.includes(7), r.overlaps(new Range(7, 10)), r.overlaps(new Range(8, 9)));
[3, 7] 4 true true false

static parse הוא "מפעל" — דרך נוספת ליצור מופע, כמו Money.fromAgorot בשיעור. שים לב שהוא קורא ל־new Range, ולכן גם טווח שנוצר מטקסט עובר את הבדיקה של ה־constructor ("7-3" זורק "end קטן מ־start").

⚠️ טעויות נפוצות
  • לבדוק ב־parse שוב ש־end ≥ start — כפילות; ה־constructor הוא המקום היחיד שאוכף את החוק.
  • מספרים שליליים ("-3-5") לא נתמכים כאן — split("-") שובר אותם. זה בסדר לתרגיל, אבל שווה לשים לב.

// P12-E35: רשימת משימות
export type Todo = { id: number; title: string; done: boolean };

export class TodoList {
  #items: Todo[] = [];
  #nextId = 1;

  add(title: string): number {
    const t = title.trim();
    if (t === "") throw new Error("כותרת ריקה");
    const id = this.#nextId++;
    this.#items.push({ id, title: t, done: false });
    return id;
  }

  complete(id: number): void {
    const item = this.#items.find((t) => t.id === id);
    if (!item) throw new Error(`משימה ${id} לא קיימת`);
    item.done = true;
  }

  remove(id: number): boolean {
    const before = this.#items.length;
    this.#items = this.#items.filter((t) => t.id !== id);
    return this.#items.length < before;
  }

  get pending(): string[] {
    return this.#items.filter((t) => !t.done).map((t) => t.title);
  }

  all(): Todo[] {
    return this.#items.map((t) => ({ ...t }));
  }
}

P12-E27 · Money: אובייקט ערך 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שדה אחד: readonly #agorot: number;. ‏fromShekels מחשבת Math.round(shekels * 100) וקוראת ל־fromAgorot, כך שהבדיקה כתובה פעם אחת. (Number.isInteger(NaN) הוא false, ולכן גם NaN נתפס שם.)

💡 רמז 2

toString: מפרקים את הערך המוחלט לשקלים (Math.floor(abs / 100)) ולאגורות (abs % 100). את הפסיקים מוסיפים לשקלים כמו ב־P05-E25 — לולאה מהסוף, שלוש ספרות בכל פעם. האגורות: String(cents).padStart(2, "0").

// P12-E27: Money — אובייקט ערך
function withCommas(n: number): string {
  const digits = String(n);
  let out = "";
  for (let i = digits.length; i > 0; i -= 3) {
    const part = digits.slice(Math.max(0, i - 3), i);
    out = out === "" ? part : `${part},${out}`;
  }
  return out;
}

export class Money {
  readonly #agorot: number;

  private constructor(agorot: number) {
    this.#agorot = agorot;
  }

  static fromAgorot(agorot: number): Money {
    if (!Number.isInteger(agorot)) {
      throw new RangeError("סכום באגורות חייב להיות מספר שלם");
    }
    return new Money(agorot);
  }

  static fromShekels(shekels: number): Money {
    return Money.fromAgorot(Math.round(shekels * 100));
  }

  get agorot(): number {
    return this.#agorot;
  }

  plus(other: Money): Money {
    return new Money(this.#agorot + other.#agorot);
  }

  times(factor: number): Money {
    return Money.fromAgorot(Math.round(this.#agorot * factor));
  }

  equals(other: Money): boolean {
    return this.#agorot === other.#agorot;
  }

  toString(): string {
    const abs = Math.abs(this.#agorot);
    const shekels = withCommas(Math.floor(abs / 100));
    const cents = String(abs % 100).padStart(2, "0");
    return `${this.#agorot < 0 ? "-" : ""}₪${shekels}.${cents}`;
  }
}

אובייקט ערך (value object) הוא אובייקט שמוגדר רק על ידי הערך שלו, כמו מספר. לכן הוא immutable: plus לא משנה את price, אלא מחזירה Money חדש. אם שני חלקים בקוד מחזיקים את אותו מופע, אף אחד מהם לא יכול "להזיז" לשני את הסכום (פרק 7, הפניות).

ה־constructor הפרטי מבטיח שכל מופע עבר דרך fromAgorot, כלומר דרך הבדיקה. שים לב ש־other.#agorot מותר: שדה פרטי נגיש לכל קוד בתוך המחלקה, גם במופע אחר שלה.

ב־toString עובדים עם הערך המוחלט ומוסיפים את המינוס בסוף. אחרת, עם ‎-550 אגורות, ‏Math.floor(-5.5) הוא ‎-6 (ולא ‎-5), ו־-550 % 100 הוא ‎-50.

⚠️ טעויות נפוצות
  • לשמור שקלים (this.amount = 19.9) — 0.1 + 0.2 חוזר, ו־equals נכשל.
  • times בלי Math.round — fromAgorot זורקת על 1990 * 1.17.
  • להוסיף פסיקים למחרוזת שכבר יש בה מינוס — "-123456" הופך ל־"-,123,456", בדיוק הטעות מ־P05-E25.

// P12-E39: יומן ציונים
export class Gradebook {
  #grades = new Map<string, number[]>();

  add(student: string, grade: number): void {
    const name = student.trim();
    if (name === "") throw new Error("שם ריק");
    if (!Number.isInteger(grade) || grade < 0 || grade > 100) throw new RangeError(`ציון לא תקין: ${grade}`);
    const list = this.#grades.get(name) ?? [];
    list.push(grade);
    this.#grades.set(name, list);
  }

  average(student: string): number {
    const list = this.#grades.get(student.trim());
    if (!list || list.length === 0) throw new Error(`אין ציונים ל־${student}`);
    const avg = list.reduce((s, g) => s + g, 0) / list.length;
    return Math.round(avg * 10) / 10;
  }

  top(n: number): { student: string; average: number }[] {
    return [...this.#grades.keys()]
      .map((student) => ({ student, average: this.average(student) }))
      .sort((a, b) => b.average - a.average || a.student.localeCompare(b.student))
      .slice(0, n);
  }

  get students(): number {
    return this.#grades.size;
  }
}

💡 רמז 1

שדה פרטי #tail: Promise<unknown> = Promise.resolve() — "המשימה האחרונה בתור". משימה חדשה: const run = this.#tail.then(() => task());

💡 רמז 2

הסוף החדש של התור צריך להצליח גם אם המשימה נכשלה: this.#tail = run.catch(() => {});. ואת #pending מורידים ב־finally.

✅ פתרון
// P12-E40: תור משימות אסינכרוני
export class TaskQueue {
  #tail: Promise<unknown> = Promise.resolve();
  #pending = 0;

  add<T>(task: () => Promise<T>): Promise<T> {
    this.#pending++;
    const run = this.#tail.then(() => task()).finally(() => {
      this.#pending--;
    });
    this.#tail = run.catch(() => {});
    return run;
  }

  get pending(): number {
    return this.#pending;
  }
}

const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));
async function demo() {
  const q = new TaskQueue();
  const log: string[] = [];
  const a = q.add(async () => { log.push("א התחיל"); await sleep(30); log.push("א הסתיים"); return "א"; });
  const bad = q.add(async () => { throw new Error("ב נכשל"); });
  const c = q.add(async () => { log.push("ג התחיל"); return "ג"; });
  console.log(q.pending);
  console.log(await a, await bad.catch((e: Error) => e.message), await c, q.pending);
  console.log(log);
}

התור הוא בעצם שרשרת Promises: כל משימה "נתלית" על סוף השרשרת. ה־catch(() => {}) על #tail חשוב: בלעדיו, משימה שנכשלה הייתה גורמת לכל המשימות שאחריה להיכשל בלי לרוץ. אבל מי שהוסיף את המשימה הכושלת עדיין מקבל את השגיאה — כי מחזירים לו את run, לא את #tail.

  • this.#tail = run בלי catch — כישלון אחד "תוקע" את התור לתמיד.
