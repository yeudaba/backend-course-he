P12-E01 · מה ידפיס? (מחלקות)

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

נבא את הפלט:

class Counter {
  #count = 0;
  readonly name: string;
  constructor(name: string) {
    this.name = name;
  }
  get value(): number {
    return this.#count;
  }
  inc(): this {
    this.#count++;
    return this;
  }
}
const a = new Counter("a");
const b = new Counter("b");
a.inc().inc();
b.inc();
const c = a;
c.inc();
console.log(a.value, b.value, c.value, a === c, a.name);

P12-E02 · מחלקות ו־JSON

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

מה ידפיס, ולמה זה חשוב כשנתונים נשמרים במסד או נשלחים ברשת?

class Product {
  #cost = 40;
  name: string;
  price: number;
  constructor(name: string, price: number) {
    this.name = name;
    this.price = price;
  }
  get margin(): number {
    return this.price - this.#cost;
  }
}
const p = new Product("עט", 50);
const text = JSON.stringify(p);
const back = JSON.parse(text);
console.log(text);
console.log(p.margin, back.margin, back instanceof Product);

P12-E27 · Money: אובייקט ערך 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

🔁 חזרה על אגורות (פרק 2, ‏P08-E26) ועל פסיקים במספרים (P05-E25), הפעם כמחלקה. בשיעור 1 ראית Money קטנה. כתוב גרסה מלאה, ששומרת אגורות שלמות ואי אפשר לשנות אותה (immutable):

  • private constructor(agorot: number) — פרטי: יוצרים מופע רק דרך שני ה"מפעלים":
  • static fromAgorot(agorot: number): Money — אם agorot אינו מספר שלם, זורקת RangeError("סכום באגורות חייב להיות מספר שלם").
  • static fromShekels(shekels: number): Money — מעגלת לאגורה הקרובה (19.9 ← 1990). ‏NaN או Infinity — אותה RangeError.
  • getter agorot (קריאה בלבד).
  • plus(other: Money): Money ו־times(factor: number): Money — מחזירות מופע חדש. ‏times מעגלת לאגורה.
  • equals(other: Money): boolean.
  • toString() — "₪1,234.50": פסיק כל שלוש ספרות, 2 ספרות אחרי הנקודה. סכום שלילי: "-₪5.00".
const price = Money.fromShekels(1234.5);
String(price);                         // "₪1,234.50"
String(price.times(3));                // "₪3,703.50"
Money.fromShekels(0.1).plus(Money.fromShekels(0.2)).equals(Money.fromAgorot(30)); // true
