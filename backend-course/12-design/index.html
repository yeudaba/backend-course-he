🎯 בסוף הפרק תדע
  • לכתוב מחלקות (class): שדות, constructor, מתודות, שדות פרטיים, getters ו־static.
  • ליצור סוגי שגיאות משלך עם extends Error.
  • להגדיר חוזה עם interface ולממש אותו בכמה מחלקות.
  • להפריד אחריות: מודל, repository ו־service — ולהזריק תלויות מבחוץ.
  • להבין את הגבול בין טיפוסים לבין validation בזמן ריצה.

🤔 למה צריך את זה?

בפרויקט 1 חילקת את הקוד לשלוש שכבות. בשרת אמיתי יש עשרות "ישויות" (משתמש, מוצר, הזמנה) ומאות פונקציות. בלי מבנה ברור — כל שינוי שובר משהו במקום אחר. הפרק הזה מלמד את אבני הבניין של המבנה הזה: מחלקות, חוזים (interfaces), ו"מי אחראי על מה". זה בדיוק המבנה של NestJS (פרק 20) — אחרי הפרק הזה הוא ייראה מוכר.

🏁 מבחן מעבר

  • לכתוב מחלקה עם שדה פרטי, מתודות ו־getter, ולהסביר מתי מחלקה ומתי פונקציות ואובייקטים פשוטים.
  • להגדיר NotFoundError ו־ValidationError ולתפוס כל אחת לחוד עם instanceof.
  • לכתוב interface ל־repository, שני מימושים (זיכרון ו"מזויף לבדיקות"), ו־service שעובד עם שניהם בלי שינוי.
  • להסביר למה body: CreateOrderDto לא מגן מקלט זדוני, ומה כן.
  • npm run check P12: 80% מ־E06–E19, ולפחות תרגיל תיקון אחד.
