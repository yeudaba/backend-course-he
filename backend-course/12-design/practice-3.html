P12-E56 · למה repository מחזיר עותק?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

שני repositories בזיכרון. בלי להריץ — מה יודפס?

type Product = { id: number; name: string; price: number };

class LeakyRepo {
  #items = new Map<number, Product>();
  async save(p: Product): Promise<void> {
    this.#items.set(p.id, p);
  }
  async findById(id: number): Promise<Product | null> {
    return this.#items.get(id) ?? null;
  }
}

class SafeRepo {
  #items = new Map<number, Product>();
  async save(p: Product): Promise<void> {
    this.#items.set(p.id, { ...p });
  }
  async findById(id: number): Promise<Product | null> {
    const p = this.#items.get(id);
    return p ? { ...p } : null;
  }
}

async function demo(repo: LeakyRepo | SafeRepo, label: string) {
  const pen = { id: 1, name: "עט", price: 5 };
  await repo.save(pen);
  pen.price = 999;
  const found = await repo.findById(1);
  if (found) found.name = "שונה בטעות";
  console.log(label, await repo.findById(1));
}

demo(new LeakyRepo(), "leaky:").then(() => demo(new SafeRepo(), "safe:"));

P12-E59 · service ששכח await

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 10, שיעור 3

בלי להריץ — מה tsc יגיד?

type Product = { id: number; price: number; stock: number };
interface ProductRepository {
  findById(id: number): Promise<Product | null>;
  save(p: Product): Promise<void>;
}

class OrderService {
  #products: ProductRepository;
  constructor(products: ProductRepository) {
    this.#products = products;
  }

  async placeOrder(id: number, qty: number): Promise<number> {
    const product = this.#products.findById(id);
    if (product === null) throw new Error("לא נמצא");
    if (product.stock < qty) throw new Error("אין מספיק");
    this.#products.save({ ...product, stock: product.stock - qty });
    return product.price * qty;
  }
}

P12-E63 · service ברצף או במקביל

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 10, שיעור 3

repository "איטי" (כל שליפה 30ms). בלי להריץ — מה יודפס? (זמנים מעוגלים לכפולות של 30.)

type User = { id: number; name: string };
const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));
const repo = {
  async findById(id: number): Promise<User | null> {
    await sleep(30);
    return id <= 3 ? { id, name: `user-${id}` } : null;
  },
};
const round = (t: number) => Math.round((Date.now() - t) / 30) * 30;

async function namesA(ids: number[]): Promise<string[]> {
  const names: string[] = [];
  for (const id of ids) {
    const u = await repo.findById(id);
    if (u) names.push(u.name);
  }
  return names;
}

async function namesB(ids: number[]): Promise<string[]> {
  const users = await Promise.all(ids.map((id) => repo.findById(id)));
  return users.filter((u) => u !== null).map((u) => u.name);
}

async function main() {
  let t = Date.now();
  console.log(await namesA([1, 2, 3, 4]), round(t));
  t = Date.now();
  console.log(await namesB([1, 2, 3, 4]), round(t));
}
main();

🔗 איך זה מתחבר: פרק 10: await בתוך לולאה מול Promise.all (P10-E80). השיעור: ב־service אמיתי ה־repository מדבר עם מסד — וכל שליפה היא נסיעה ברשת. ההבדל בין A ל־B הוא ההבדל בין דף שנטען מהר לדף איטי.
