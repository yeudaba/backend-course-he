P12-E03 · מי תופס?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

עם ההיררכיה AppError ← NotFoundError, AppError ← ValidationError — מה יחזיר handle לכל שגיאה? מה הבאג בסדר הבדיקות?

function handle(err: unknown): number {
  if (err instanceof AppError) return 400;
  if (err instanceof NotFoundError) return 404;
  if (err instanceof ValidationError) return 422;
  return 500;
}
handle(new NotFoundError("x", 1));
handle(new ValidationError("f", "m"));
handle(new Error("boom"));
handle("string error");

P12-E09 · היררכיית שגיאות 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ 12-design/starter/P12-E09.ts השלם:

  • AppError extends Error עם status ו־code, ו־name = שם המחלקה בפועל.
  • NotFoundError(entity, id) ← ${entity} ${id} לא נמצא, 404, "NOT_FOUND".
  • ValidationError(field, message) ← 400, "VALIDATION", ושדה field.
  • ConflictError(message) ← 409, "CONFLICT".
  • toHttp(err: unknown) ← { status, body: { code, message, field? } }; כל שגיאה שאינה AppError ← 500, { code: "INTERNAL", message: "שגיאה פנימית" }.

P12-E10 · חוזה Logger 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ 12-design/starter/P12-E10.ts מוגדר interface Logger { info(msg: string): void; error(msg: string): void }. השלם:

  • MemoryLogger implements Logger — שומר שורות ("INFO: ...", "ERROR: ..."), עם getter lines שמחזיר עותק.
  • PrefixLogger implements Logger — עוטף Logger אחר (מקבל ב־constructor) ומוסיף קידומת: new PrefixLogger(inner, "[orders]") ← info("x") קורא ל־inner.info("[orders] x").
  • processOrders(ids, logger) — לכל id: id חיובי ← info(order ${id} ok); אחרת ← error(order ${id} invalid). מחזירה מספר ההצלחות.

P12-E14 · הגבלת קצב עם שעון מוזרק 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

הגבלת קצב (rate limiting) מגינה על שרת מהצפה. בקובץ 12-design/starter/P12-E14.ts השלם RateLimiter: constructor מקבל { limit, windowMs, now = Date.now }. allow(key) מחזירה true אם ל־key היו פחות מ־limit בקשות מותרות ב־windowMs האחרונים (חלון "זז"), ואז רושמת את הבקשה; אחרת false (ולא רושמת). remaining(key) — כמה עוד מותר עכשיו.

למה מזריקים now? כדי שהבדיקה תוכל "להזיז את הזמן" בלי לחכות באמת.

P12-E26 · מחסן כמחלקה 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

ב־P07-E27 כתבת מלאי עם closure. עכשיו תכתוב אותו כמחלקה, עם שדה פרטי ועם שגיאות ברורות. הקובץ ריק, ואת הכול כותבים מאפס.

כתוב וייצא class Inventory:

  • add(sku: string, qty: number): void — מוסיפה.
  • remove(sku: string, qty: number): void — מורידה. אם אין מספיק: זורקת Error עם ההודעה אין מספיק ${sku}: יש ${have}, ביקשו ${qty}, והמלאי לא משתנה. פריט שהגיע ל־0 נעלם מהרשימה.
  • count(sku: string): number — כמה יש (0 לפריט שלא קיים).
  • totalItems(): number — סך כל היחידות בכל הפריטים.
  • skus(): string[] — הפריטים שיש מהם לפחות יחידה, ממוינים לפי א״ב.
  • ב־add וב־remove: כמות שאינה מספר שלם חיובי — RangeError("כמות חייבת להיות מספר שלם חיובי").

אי אפשר לשנות את המלאי מבחוץ, אלא רק דרך המתודות. הבודק בודק התנהגות בלבד, ולא איך שמרת את הנתונים בפנים.
