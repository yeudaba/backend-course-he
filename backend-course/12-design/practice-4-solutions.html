P12-E69 · validate או parse? 🧠 הבנה רמה 1

💡 רמז 1

"parse, don't validate": התוצאה של parse היא ערך חדש עם הטיפוס הנכון — לא true.

💡 רמז 2

בגרסה הראשונה, אותו body בדיוק (עם כל מה שיש בו) ממשיך הלאה.

✅ פתרון
  1. ה־as מבטיח ש"אם הבדיקה עברה — זה CreateOrderDto". אבל אין שום קשר בין הבדיקה לטיפוס: אם isValidOrder תשכח שדה, TypeScript לא ידע. ב־parse, הטיפוס של הערך שחוזר נבנה מתוך הבדיקות עצמן (return { productId, qty }) — אי אפשר "לשכוח".

⚠️ טעויות נפוצות

P12-E12 · parse ל־DTO 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

החזר אובייקט חדש; את age רק אם הוא לא undefined.

✅ פתרון
// P12-E12
export class ValidationError extends Error {
  readonly field: string;
  constructor(field: string, message: string) {
    super(message);
    this.name = "ValidationError";
    this.field = field;
  }
}

export type CreateUserDto = { email: string; name: string; age?: number };

export function parseCreateUser(input: unknown): CreateUserDto {
  if (typeof input !== "object" || input === null || Array.isArray(input)) {
    throw new ValidationError("body", "חייב להיות אובייקט");
  }
  const { email, name, age } = input as Record<string, unknown>;
  if (typeof email !== "string" || !email.includes("@")) {
    throw new ValidationError("email", "אימייל לא תקין");
  }
  if (typeof name !== "string" || name.trim() === "") {
    throw new ValidationError("name", "שם חובה");
  }
  if (age !== undefined && (typeof age !== "number" || !Number.isInteger(age) || age < 13 || age > 120)) {
    throw new ValidationError("age", "גיל לא תקין");
  }
  const dto: CreateUserDto = { email: email.trim().toLowerCase(), name: name.trim() };
  if (age !== undefined) {
    dto.age = age;
  }
  return dto;
}

console.log(parseCreateUser({ email: " Dana@X.com ", name: " דנה ", role: "admin" }));

P12-E19 · פרמטרי עמוד מה־URL 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

פונקציית עזר: parseIntStrict(text) — רק ספרות (/^\d+$/ — ביטוי רגולרי: "רק ספרות מההתחלה עד הסוף"), אחרת null.

💡 רמז 2

/^\d+$/.test(text) ? Number(text) : null

✅ פתרון
// P12-E19
export class ValidationError extends Error {
  readonly field: string;
  constructor(field: string, message: string) {
    super(message);
    this.field = field;
  }
}

function parseIntStrict(text: string): number | null {
  return /^\d+$/.test(text.trim()) ? Number(text.trim()) : null;
}

export function parsePagination(query: Record<string, string | undefined>): { page: number; pageSize: number; offset: number } {
  let page = 1;
  if (query.page !== undefined) {
    const p = parseIntStrict(query.page);
    if (p === null || p < 1) {
      throw new ValidationError("page", "page חייב להיות מספר שלם חיובי");
    }
    page = p;
  }
  let pageSize = 20;
  if (query.pageSize !== undefined) {
    const s = parseIntStrict(query.pageSize);
    if (s === null || s < 1 || s > 100) {
      throw new ValidationError("pageSize", "pageSize חייב להיות בין 1 ל־100");
    }
    pageSize = s;
  }
  return { page, pageSize, offset: (page - 1) * pageSize };
}

console.log(parsePagination({ page: "3", pageSize: "10" }), parsePagination({}));
{ page: 3, pageSize: 10, offset: 20 } { page: 1, pageSize: 20, offset: 0 }

(Number("1e2") הוא 100 ו־Number("0x10") הוא 16 — לכן בדיקה קפדנית של "רק ספרות".)

  • Number(query.page) || 1 — "abc" הופך בשקט לעמוד 1 במקום שגיאה.

P12-E23 · העלאת הרשאות דרך as 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

בנה אובייקט עדכון חדש רק עם השדות המותרים.

💡 רמז 2

אחרי הבדיקה: return { ...user, ...update } כש־update בנוי ממך.

✅ פתרון
// P12-E23: מתוקן — רשימת שדות מותרים
export type User = { id: number; name: string; bio: string; role: "user" | "admin" };
export type ProfileUpdate = { name?: string; bio?: string };

export function updateProfile(user: User, body: unknown): User {
  if (typeof body !== "object" || body === null) {
    throw new Error("שדה לא תקין: body");
  }
  const { name, bio } = body as Record<string, unknown>;
  const update: ProfileUpdate = {};
  if (name !== undefined) {
    if (typeof name !== "string" || name.trim() === "" || name.length > 50) {
      throw new Error("שדה לא תקין: name");
    }
    update.name = name.trim();
  }
  if (bio !== undefined) {
    if (typeof bio !== "string" || bio.length > 200) {
      throw new Error("שדה לא תקין: bio");
    }
    update.bio = bio;
  }
  return { ...user, ...update };
}

{ id: 1, name: 'דנה', bio: '', role: 'user' }

P12-E73 · מזהה מהבקשה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

שני מקרים: typeof input === "number" ← Number.isInteger(input) && input > 0. ‏typeof input === "string" ← /^\d+$/.test(input.trim()) ואז Number(...) ו־> 0.

💡 רמז 2

"0" ו־"000" עוברים את ה־regex, אבל הם לא חיוביים — לכן בודקים גם את המספר אחרי ההמרה.

✅ פתרון
// P12-E73: מזהה מהבקשה
export class ValidationError extends Error {
  readonly field: string;
  constructor(field: string, message: string) {
    super(message);
    this.name = new.target.name;
    this.field = field;
  }
}

export function parseId(input: unknown, field = "id"): number {
  let n = NaN;
  if (typeof input === "number") n = input;
  else if (typeof input === "string" && /^\d+$/.test(input.trim())) n = Number(input.trim());
  if (!Number.isSafeInteger(n) || n <= 0) {
    throw new ValidationError(field, `${field} חייב להיות מספר שלם חיובי`);
  }
  return n;
}

P12-E74 · עדכון חלקי (PATCH) 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

קודם: for (const key of Object.keys(input)) if (!["name", "price", "tags"].includes(key)) throw .... אחר כך — כל שדה בנפרד, רק if ("price" in input).

💡 רמז 2

שתי ספרות אחרי הנקודה: price * 100 צריך להיות (כמעט) שלם. זהירות: 19.9 * 100 הוא 1989.9999999999998 (פרק 2) — לכן משווים עם סובלנות: Math.abs(Math.round(p * 100) - p * 100) <= 1e-9. כפילויות ב־tags: new Set(normalized).size !== normalized.length.

✅ פתרון
// P12-E74: עדכון חלקי (PATCH)
export class ValidationError extends Error {
  readonly field: string;
  constructor(field: string, message: string) {
    super(message);
    this.name = new.target.name;
    this.field = field;
  }
}

export type ProductPatch = { name?: string; price?: number; tags?: string[] };

const ALLOWED = ["name", "price", "tags"];

export function parseProductPatch(input: unknown): ProductPatch {
  if (typeof input !== "object" || input === null || Array.isArray(input)) {
    throw new ValidationError("body", "גוף הבקשה חייב להיות אובייקט");
  }
  const keys = Object.keys(input);
  for (const key of keys) {
    if (!ALLOWED.includes(key)) throw new ValidationError(key, `שדה לא מוכר: ${key}`);
  }
  if (keys.length === 0) throw new ValidationError("body", "אין מה לעדכן");

  const patch: ProductPatch = {};
  if ("name" in input) {
    if (typeof input.name !== "string" || input.name.trim() === "") throw new ValidationError("name", "name לא תקין");
    patch.name = input.name.trim();
  }
  if ("price" in input) {
    const p = input.price;
    if (typeof p !== "number" || !Number.isFinite(p) || p <= 0 || Math.abs(Math.round(p * 100) - p * 100) > 1e-9) {
      throw new ValidationError("price", "price לא תקין");
    }
    patch.price = p;
  }
  if ("tags" in input) {
    const t = input.tags;
    if (!Array.isArray(t) || !t.every((x) => typeof x === "string" && x.trim() !== "")) {
      throw new ValidationError("tags", "tags לא תקין");
    }
    const tags = t.map((x: string) => x.trim().toLowerCase());
    if (new Set(tags).size !== tags.length) throw new ValidationError("tags", "tags לא תקין");

export function parseFilters(query: Record<string, string | undefined>): Filters {
  const price = (field: string): number | undefined => {
    const raw = (query[field] ?? "").trim();
    if (raw === "") return undefined;

// P12-E24
export type Wallet = { id: string; balanceAgorot: number };
export interface WalletRepo {
  find(id: string): Promise<Wallet | null>;
  save(w: Wallet): Promise<void>;
}
export class NotFoundError extends Error {}
export class ValidationError extends Error {}
export class InsufficientFundsError extends Error {}

type TransferResult = { transferId: number; fromBalance: number; toBalance: number };

export class TransferService {
  #wallets: WalletRepo;
  #done = new Map<string, TransferResult>();
  #nextId = 1;

  constructor(wallets: WalletRepo) {
    this.#wallets = wallets;
  }

  async transfer(req: { from: string; to: string; amount: number; idempotencyKey: string }): Promise<TransferResult> {
    const previous = this.#done.get(req.idempotencyKey);
    if (previous) {
      return previous;
    }
    const agorot = Math.round(req.amount * 100);
    if (!(req.amount > 0) || Math.abs(req.amount * 100 - agorot) > 1e-9) {
      throw new ValidationError("סכום לא תקין");
    }
    if (req.from === req.to) {
      throw new ValidationError("לא ניתן להעביר לאותו ארנק");
    }
    const from = await this.#wallets.find(req.from);
    const to = await this.#wallets.find(req.to);
    if (!from || !to) {
      throw new NotFoundError("ארנק לא נמצא");
    }
    if (from.balanceAgorot < agorot) {
      throw new InsufficientFundsError("אין מספיק יתרה");
    }
    const newFrom = { ...from, balanceAgorot: from.balanceAgorot - agorot };
    const newTo = { ...to, balanceAgorot: to.balanceAgorot + agorot };
    await this.#wallets.save(newFrom);
    await this.#wallets.save(newTo);
    const result = { transferId: this.#nextId++, fromBalance: newFrom.balanceAgorot / 100, toBalance: newTo.balanceAgorot / 100 };
    this.#done.set(req.idempotencyKey, result);
    return result;
  }
}

// P12-E25: מיכל DI מינימלי
export class Container {
  #factories = new Map<string, (c: Container) => unknown>();
  #instances = new Map<string, unknown>();
  #resolving: string[] = [];

  register(name: string, factory: (c: Container) => unknown): void {
    if (this.#factories.has(name)) {
      throw new Error(`השירות ${name} כבר רשום`);
    }
    this.#factories.set(name, factory);
  }

  resolve<T = unknown>(name: string): T {
    if (this.#instances.has(name)) {
      return this.#instances.get(name) as T;
    }
    const factory = this.#factories.get(name);
    if (!factory) {
      throw new Error(`השירות ${name} לא רשום`);
    }
    if (this.#resolving.includes(name)) {
      const cycle = [...this.#resolving.slice(this.#resolving.indexOf(name)), name];
      throw new Error(`תלות מעגלית: ${cycle.join(" -> ")}`);
    }
    this.#resolving.push(name);
    try {
      const instance = factory(this);
      this.#instances.set(name, instance);
      return instance as T;
    } finally {
      this.#resolving.pop();
    }
  }
}

  repo: Repo;

  }

export class SignupService {
  #users: UserRepository;
  #hash: (password: string) => string;

  constructor(users: UserRepository, hash: (password: string) => string) {
    this.#users = users;
    this.#hash = hash;
  }

  async signup(input: unknown): Promise<{ id: number; email: string; name: string }> {
    const dto = parseSignup(input);
    if (await this.#users.findByEmail(dto.email)) throw new ConflictError("האימייל כבר רשום");
    const u = await this.#users.insert({ email: dto.email, name: dto.name, passwordHash: this.#hash(dto.password) });
    return { id: u.id, email: u.email, name: u.name };
  }
}

const rows: User[] = [];
const repo: UserRepository = {
  async findByEmail(email) {
    return rows.find((u) => u.email === email) ?? null;
  },
  async insert(u) {
    const user = { ...u, id: rows.length + 1 };
    rows.push(user);
    return { ...user };
  },
};
const service = new SignupService(repo, (p) => `hash(${p.length})`);

      console.log(String(err));
    }
  }

}

שלוש שכבות, וכל אחת עושה דבר אחד: parseSignup מסננת את העולם (ה־isAdmin לא עבר), ה־service אוכף חוק עסקי ("אימייל ייחודי") ומחליט מה נשמר, וה־repository רק שומר. ה־hash מוזרק — בבדיקה הוא פונקציה פשוטה, בפרק 21 — bcrypt. והתשובה לא מכילה passwordHash — לעולם לא מחזירים אותו ללקוח.
