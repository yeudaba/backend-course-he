שיעור 6 — שלב 5 (רשות): עוזר אנליטיקה

⏱ ~120 דקות · 🤖 PR4-AGENT

🎯 בשלב הזה (רשות)
  • "כמה רכישות היו השבוע, ומה שיעור ההמרה מצפייה?" — בעברית, מעל ה־API שלך.
  • שני כלים, תאריך של היום בשעון ישראל, ותשובה עם מספרים מהכלים בלבד.

1. הדרישות

  • createAnalyticsAssistant({ client, query, now, maxSteps = 6 }) ← { ask(question) } ← { text, toolCalls, steps }.
  • כלים: daily_stats({ from, to, name? }) ו־funnel({ steps, from, to }), שקוראים ל־query.daily/query.funnel (בפרודקשן — אותן פונקציות שה־API משתמש בהן, או fetch ל־API עם ה־key של הלקוח).
  • system prompt עם התאריך של היום בשעון ישראל (אחרת "השבוע" של המודל הוא ניחוש), ובקשה לענות רק מהכלים.
  • כלים במקביל, תוצאות בהודעה אחת, שגיאה ← is_error, ותקרת צעדים — יחידה 29.5.

2. החלטות

  • הרשאות: העוזר מקבל query שכבר "נעול" על ה־tenant של המשתמש — המודל לא בוחר tenant, כמו customerId בשרת ה־MCP (29.5, E08).
  • קריאה בלבד: אין כלים שכותבים — אין צורך באישורים, וה־prompt injection שיכול להגיע מ־props של אירועים לא יכול לגרום לנזק.
  • עלות: trace לכל שאלה (29.5, E12), ותקרה ללקוח ליום (פרק 29).
