P20-E01 · מ־Express ל־Nest רמה 1

💡 רמז 1

חזור לטבלה בשיעור 1 ולשיעור 2 (טבלת ה־decorators).

💡 רמז 2

חלק מהדברים Nest עושה לבד — למשל 201 ל־POST.

✅ פתרון
  1. @Get(":id") על מתודה בתוך מחלקה עם @Controller("tasks") — ב־controller.
  2. @Param("id"), @Query("page"), @Body() — פרמטרים של מתודת ה־controller.
  3. מחזירים את האובייקט (return task). POST מחזיר 201 כברירת מחדל; לשינוי — @HttpCode().
  4. providers ב־module + constructor ב־service/controller. Nest יוצר ומעביר. החלפה בבדיקה: overrideProvider.
  5. pipe: ValidationPipe + DTO (או pipe משלך עם Zod, כמו בפרויקט 2).
  6. exception filter (@Catch()), נרשם ב־main.ts או עם APP_FILTER ב־module.
  7. NestFactory.create(AppModule) ואז app.listen(3000) — ב־main.ts.

המסקנה: אותם רעיונות בדיוק. Nest רק קובע לכל אחד מקום קבוע.

⚠️ טעויות נפוצות
  • לחשוב שב־Nest כותבים res.json() כמו ב־Express — אפשר (@Res()), אבל אז Nest מפסיק לטפל בתשובה בשבילך. כמעט תמיד פשוט מחזירים ערך.

P20-E02 · לקרוא controller רמה 1

💡 רמז 1

Nest רושם את ה־routes ב־Express לפי סדר המתודות במחלקה — ו־Express בודק לפי הסדר.

💡 רמז 2

"featured" מתאים לתבנית :id. מה ParseIntPipe יעשה איתו?

✅ פתרון

כל התשובות נבדקו בהרצה אמיתית:

  1. 200 {"route":"one","id":7} — id הוא מספר (ParseIntPipe).
  2. 400 {"message":"Validation failed (numeric string is expected)","error":"Bad Request","statusCode":400} — הבקשה נתפסה ב־:id, שרשום קודם, ו־ParseIntPipe נכשל על "featured".
  3. 201 — ברירת המחדל של @Post().
  4. 204 בלי גוף.
  5. 404 {"message":"Cannot PUT /products/3","error":"Not Found","statusCode":404}.

התיקון ל־(2): להזיז את @Get("featured") מעל @Get(":id"). אותו כלל כמו ב־Express (P15-E01): כתובות קבועות לפני כתובות עם פרמטרים. בפרויקט 2 זה @Get("stats") לפני :id.

⚠️ טעויות נפוצות
  • לחשוב ש־Nest "חכם" ובוחר את ה־route המדויק יותר — הוא לא. הסדר קובע.
  • לצפות ל־200 ב־POST — ב־Nest זה 201.

P20-E03 · לקרוא שגיאת DI רמה 1

💡 רמז 1

provider "פרטי" ל־module שלו עד שמייצאים אותו.

💡 רמז 2

שני צדדים: מי שנותן (exports) ומי שמקבל (imports).

✅ פתרון

(א) Nest ניסה ליצור את OrdersService; הרשימה בסוגריים היא הפרמטרים של ה־constructor, וה־? מסמן את זה שלא נמצא — הראשון (index [0]), מסוג UsersService. הוא חיפש אותו בהקשר של OrdersModule.

(ב)

@Module({ providers: [UsersService], exports: [UsersService] })
export class UsersModule {}

@Module({ imports: [UsersModule], providers: [OrdersService] })
export class OrdersModule {}

(ג) זה "עובד", אבל יוצר מופע שני של UsersService — עם state נפרד (משתמשים בזיכרון, חיבור למסד, cache). ב־Nest כל provider הוא singleton בתוך ה־module שרשם אותו. מייבאים — לא משכפלים.

⚠️ טעויות נפוצות
  • להוסיף רק imports בלי exports (או להפך) — אותה שגיאה בדיוק.
  • לייבא את ה־service (imports: [UsersService]) במקום את ה־module.

P20-E04 · מי רץ ומתי רמה 1

💡 רמז 1

האיור בשיעור 3: middleware ← guards ← interceptors (לפני) ← pipes ← handler ← interceptors (אחרי). שגיאה — ישר ל־filters.

💡 רמז 2

חלק ה"אחרי" של interceptor עם tap רץ רק כשה־handler הצליח.

✅ פתרון
  1. middleware ← guard (מאשר) ← interceptor (לפני) ← ParseIntPipe ← handler ← interceptor (אחרי) ← תשובה. ה־filter לא רץ.
  2. middleware ← guard זורק UnauthorizedException ← filter ← 401. interceptor, pipe ו־handler לא רצים.
  3. middleware ← guard ← interceptor (לפני) ← ParseIntPipe זורק 400 ← filter. ה־handler לא רץ, וגם ה־tap של ה־interceptor לא (אין ערך מוצלח).
  4. הכול עד ה־handler ← הוא זורק ← filter ← 404.

למה זה חשוב: guard הוא המקום לבדיקת הרשאה — כי שום קוד שלך (ואפילו לא ולידציה) לא רץ לפני שהוא אישר.

⚠️ טעויות נפוצות
  • לשים בדיקת הרשאה בתוך ה־handler — היא רצה מאוחר מדי, אחרי pipes שיכולים לגשת למסד.
  • לחשוב ש־middleware רץ אחרי guards — הפוך.

P20-E05 · למה צריך build רמה 1

💡 רמז 1

Node "מוחק" טיפוסים. decorator הוא לא טיפוס — הוא קוד שרץ.

💡 רמז 2

אחרי קומפילציה, מה נשאר מ־UsersService ומה נשאר מ־TasksRepository?

✅ פתרון

(א) מצב ה־strip-types של Node רק מוחק תחביר של טיפוסים. decorators (בגרסה ש־Nest משתמש בה, experimentalDecorators) הם קוד שצריך לתרגם לקריאות פונקציה — ואת זה רק קומפיילר (tsc, או ה־CLI של Nest שמפעיל אותו) עושה. לכן ב־Nest יש תמיד build: npm run start:dev מקמפל ל־dist/ ומריץ משם, והבודק מקמפל ל־.build/.

(ב) עם emitDecoratorMetadata הקומפיילר שומר, לכל מחלקה שיש עליה decorator, את רשימת הטיפוסים של פרמטרי ה־constructor (design:paramtypes → [UsersService]). Nest קורא את הרשימה, ומחפש provider לכל אחד. בלי decorator על המחלקה — אין רשימה. זה התפקיד האמיתי של @Injectable() (ותראה מה קורה בלעדיו ב־E20).

(ג) UsersService הוא class — הוא קיים בזמן ריצה, ואפשר לשמור הפניה אליו. interface נמחק לגמרי בקומפילציה; ב־metadata נשאר רק Object. לכן נותנים לו שם — token — ומבקשים לפי השם: @Inject(TASKS_REPOSITORY).

⚠️ טעויות נפוצות
  • לחשוב ש־@Injectable() "רושם" את ה־service — לא. הרישום הוא ב־providers של ה־module. ה־decorator רק גורם לקומפיילר לשמור את הטיפוסים.

P20-E06 · שלום Nest 🤖 רמה 2

💡 רמז 1

@Controller("hello") על המחלקה, @Get() על המתודה, @Query("name") name?: string בפרמטר.

💡 רמז 2

controller שלא מופיע ב־controllers: [...] של module — לא קיים מבחינת Nest (404).

✅ פתרון
// P20-E06
import { Controller, Get, Module, Query } from "@nestjs/common";

@Controller("hello")
export class HelloController {
  @Get()
  hello(@Query("name") name?: string) {
    return { message: `שלום ${name ? name : "אורח"}` };
  }
}

@Module({ controllers: [HelloController] })
export class HelloModule {}

שים לב כמה מעט קוד: אין res.json — מחזירים אובייקט, ו־Nest הופך אותו ל־JSON עם 200.

⚠️ טעויות נפוצות
  • לשכוח את controllers: [HelloController] ← 404 על הכול.
  • @Query() name (בלי שם) ← מקבלים את כל אובייקט ה־query, לא את המחרוזת.

P20-E07 · קריאת מוצרים 🤖 רמה 2

💡 רמז 1

ה־controller מקבל את ה־service ב־constructor: constructor(private readonly products: ProductsService) {}.

💡 רמז 2

throw new NotFoundException("...") מתוך ה־service. @Param("id", ParseIntPipe) id: number.

✅ פתרון
// P20-E07
import { Controller, Get, Injectable, Module, NotFoundException, Param, ParseIntPipe } from "@nestjs/common";

export interface Product {
  id: number;
  name: string;
  price: number;
}

@Injectable()
export class ProductsService {
  private readonly products: Product[] = [
    { id: 1, name: "Espresso cup", price: 24.9 },
    { id: 2, name: "Hand grinder", price: 189 },
    { id: 3, name: "Milk jug", price: 59.5 },
  ];

  list(): Product[] {
    return this.products;
  }

  findOne(id: number): Product {
    const product = this.products.find((p) => p.id === id);
    if (!product) throw new NotFoundException(`מוצר ${id} לא נמצא`);
    return product;
  }
}

@Controller("products")
export class ProductsController {
  constructor(private readonly products: ProductsService) {}

  @Get()
  list() {
    return this.products.list();
  }

  @Get(":id")
  findOne(@Param("id", ParseIntPipe) id: number) {
    return this.products.findOne(id);
  }
}

@Module({ controllers: [ProductsController], providers: [ProductsService] })
export class ProductsModule {}

ה־404 נזרק מה־service, לא מה־controller: כל מי שקורא ל־findOne (גם controller אחר, גם job) יקבל את אותה התנהגות. ה־controller נשאר דק — בדיוק כמו בפרויקט 2.

⚠️ טעויות נפוצות
  • בלי ParseIntPipe: id הוא "2", ו־p.id === "2" אף פעם לא נכון ← 404 על הכול. (טיפוס number בפרמטר לא ממיר כלום — זה רק TypeScript.)
  • להחזיר undefined במקום לזרוק ← 200 עם גוף ריק.

P20-E08 · DTO וולידציה 🤖 רמה 2

💡 רמז 1

העתק את ה־DTO מהשיעור — ובדוק כל decorator מול הדרישה.

💡 רמז 2

ה־service מקבל dto: CreateProductDto, ובונה אובייקט חדש (לא שומר את ה־dto עצמו).

✅ פתרון
// P20-E08
import { Body, Controller, Get, Injectable, Module, Post } from "@nestjs/common";
import { IsBoolean, IsInt, IsNumber, IsOptional, IsString, Length, Max, Min } from "class-validator";

export class CreateProductDto {
  @IsString()
  @Length(2, 80)
  name: string;

  @IsNumber({ maxDecimalPlaces: 2 })
  @Min(0.01)
  @Max(100_000)
  price: number;

  @IsInt()
  @Min(0)
  stock: number;

  @IsOptional()
  @IsBoolean()
  isActive?: boolean;
}

export interface Product extends CreateProductDto {
  id: number;
  isActive: boolean;
}

@Injectable()
export class ProductsService {
  private readonly products: Product[] = [];
  private nextId = 1;

  list(): Product[] {
    return this.products;
  }

  create(dto: CreateProductDto): Product {
    const product: Product = { id: this.nextId++, name: dto.name, price: dto.price, stock: dto.stock, isActive: dto.isActive ?? true };
    this.products.push(product);
    return product;
  }
}

@Controller("products")
export class ProductsController {
  constructor(private readonly products: ProductsService) {}

  @Get()
  list() {
    return this.products.list();
  }

  @Post()
  create(@Body() dto: CreateProductDto) {
    return this.products.create(dto);
  }
}

@Module({ controllers: [ProductsController], providers: [ProductsService] })
export class ProductsModule {}

ה־DTO הוא גם הטיפוס של dto וגם הסכמה של הבדיקה. כמו z.infer ב־Zod, רק הפוך: שם כותבים סכמה ומקבלים טיפוס, כאן כותבים class ומקבלים בדיקה.

למה לבנות אובייקט חדש ב־create? whitelist כבר מחק שדות זרים, אבל המופע הוא עדיין CreateProductDto — ומה שנשמר צריך להיות הטיפוס Product, עם id וברירות מחדל.

⚠️ טעויות נפוצות
  • @IsNumber() על stock ← 2.5 עובר. ל"שלם" — @IsInt().
  • @IsBoolean() בלי @IsOptional() ← שדה אופציונלי הופך לחובה.
  • לוותר על @IsString() כי "יש כבר @Length": על "name": 12345 ההודעה תהיה name must be longer than or equal to 2 and shorter than or equal to 80 characters — על אורך, לא על סוג. מבלבל. כותבים את שניהם.

P20-E09 · PATCH ו־DELETE 🤖 רמה 2

💡 רמז 1

export class UpdateProductDto extends PartialType(CreateProductDto) {} — מ־@nestjs/swagger.

💡 רמז 2

ב־update וב־remove קרא קודם ל־findOne — הוא כבר זורק 404.

✅ פתרון
// P20-E09
import { Body, Controller, Delete, Get, HttpCode, Injectable, Module, NotFoundException, Param, ParseIntPipe, Patch, Post } from "@nestjs/common";
import { PartialType } from "@nestjs/swagger";
import { IsInt, IsNumber, IsString, Length, Min } from "class-validator";

export class CreateProductDto {
  @IsString()
  @Length(2, 80)
  name: string;

  @IsNumber({ maxDecimalPlaces: 2 })
  @Min(0.01)
  price: number;

  @IsInt()
  @Min(0)
  stock: number;
}

export class UpdateProductDto extends PartialType(CreateProductDto) {}

export interface Product extends CreateProductDto {
  id: number;
}

@Injectable()
export class ProductsService {
  private readonly products: Product[] = [];
  private nextId = 1;

  create(dto: CreateProductDto): Product {
    const product = { id: this.nextId++, ...dto };
    this.products.push(product);
    return product;
  }

  findOne(id: number): Product {
    const product = this.products.find((p) => p.id === id);
    if (!product) throw new NotFoundException(`מוצר ${id} לא נמצא`);
    return product;
  }

  update(id: number, dto: UpdateProductDto): Product {
    const product = this.findOne(id);
    Object.assign(product, dto);
    return product;
  }

  remove(id: number): void {
    this.findOne(id);
    this.products.splice(this.products.findIndex((p) => p.id === id), 1);
  }
}

@Controller("products")
export class ProductsController {
  constructor(private readonly products: ProductsService) {}

  @Post()
  create(@Body() dto: CreateProductDto) {
    return this.products.create(dto);
  }

  @Get(":id")
  findOne(@Param("id", ParseIntPipe) id: number) {
    return this.products.findOne(id);
  }

  @Patch(":id")
  update(@Param("id", ParseIntPipe) id: number, @Body() dto: UpdateProductDto) {
    return this.products.update(id, dto);
  }

  @Delete(":id")
  @HttpCode(204)
  remove(@Param("id", ParseIntPipe) id: number) {
    this.products.remove(id);
  }
}

@Module({ controllers: [ProductsController], providers: [ProductsService] })
export class ProductsModule {}

PartialType יוצר מחלקה חדשה עם אותם שדות ואותם decorators, ומוסיף לכל אחד @IsOptional(). לכן { "stock": -1 } עדיין נכשל, ו־{ "color": "red" } נכשל על whitelist. למה מ־@nestjs/swagger ולא מ־@nestjs/mapped-types? שתיהן עובדות; הגרסה של swagger מעבירה גם את התיעוד (שיעור 4).

⚠️ טעויות נפוצות
  • לשכוח את @HttpCode(204) ← 200 עם גוף ריק.
  • Object.assign(product, dto) כש־dto מכיל id? כאן אי אפשר — whitelist מוחק שדות שאין ב־DTO. זה בדיוק למה whitelist חשוב.

P20-E10 · pagination עם Query DTO 🤖 רמה 2

💡 רמז 1

query מגיע כמחרוזת. @Type(() => Number) מ־class-transformer ממיר לפני הבדיקה (עם transform: true).

💡 רמז 2

ברירת מחדל: page: number = 1; — מאתחלים את השדה במחלקה.

✅ פתרון
// P20-E10
import { Controller, Get, Injectable, Module, Query } from "@nestjs/common";
import { Type } from "class-transformer";
import { IsInt, IsOptional, IsString, Max, Min } from "class-validator";

export class ListProductsQuery {
  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  page: number = 1;

  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  @Max(50)
  limit: number = 10;

  @IsOptional()
  @IsString()
  q?: string;
}

export interface Product {
  id: number;
  name: string;
}

@Injectable()
export class ProductsService {
  private readonly products: Product[] = Array.from({ length: 25 }, (_, i) => ({ id: i + 1, name: `Product ${i + 1}` }));

  list({ page, limit, q }: ListProductsQuery) {
    const filtered = q ? this.products.filter((p) => p.name.toLowerCase().includes(q.toLowerCase())) : this.products;
    const data = filtered.slice((page - 1) * limit, page * limit);
    return { data, meta: { page, limit, total: filtered.length, pages: Math.ceil(filtered.length / limit) } };
  }
}

@Controller("products")
export class ProductsController {
  constructor(private readonly products: ProductsService) {}

  @Get()
  list(@Query() query: ListProductsQuery) {
    return this.products.list(query);
  }
}

@Module({ controllers: [ProductsController], providers: [ProductsService] })
export class ProductsModule {}

הסדר של ה־decorators לא משנה לבדיקה, אבל קל לקרוא אותו מלמעלה: אופציונלי ← המרה ← שלם ← טווח. ומה עם ?q=product 2? 7 תוצאות: Product 2 ו־20–25.

⚠️ טעויות נפוצות
  • בלי @Type ← כל ?page=2 נכשל ב־"page must be an integer number" (תראה את זה שוב ב־E21).
  • לחשב pages עם Math.floor ← 25/10 נותן 2 ומאבדים את הדף האחרון.

P20-E11 · שעון כ־provider 🤖 רמה 2

💡 רמז 1

getUTCHours(), לא getHours() — אחרת התוצאה תלויה באזור הזמן של המחשב.

💡 רמז 2

אם לא כתבת @Inject(CLOCK): Clock הוא interface, ו־Nest לא יודע מה להזריק.

✅ פתרון
// P20-E11
import { Controller, Get, Inject, Injectable, Module } from "@nestjs/common";

export const CLOCK = "CLOCK";
export interface Clock {
  now(): Date;
}

@Injectable()
export class GreetingService {
  constructor(@Inject(CLOCK) private readonly clock: Clock) {}

  greeting(): string {
    const hour = this.clock.now().getUTCHours();
    if (hour >= 5 && hour < 12) return "בוקר טוב";
    if (hour >= 12 && hour < 17) return "צהריים טובים";
    if (hour >= 17 && hour < 21) return "ערב טוב";
    return "לילה טוב";
  }
}

@Controller("greeting")
export class GreetingController {
  constructor(private readonly greetings: GreetingService) {}

  @Get()
  get() {
    return { greeting: this.greetings.greeting() };
  }
}

@Module({
  controllers: [GreetingController],
  providers: [GreetingService, { provide: CLOCK, useValue: { now: () => new Date() } }],
})
export class GreetingModule {}

זה אותו רעיון כמו now ב־createApp({ now }) של פרויקט 2 — רק ש־Nest מנהל את ההחלפה. קוד שתלוי בזמן אף פעם לא קורא ל־new Date() ישירות: בבדיקה אי אפשר לקבוע מה השעה.

⚠️ טעויות נפוצות
  • hour <= 12 במקום < 12 ← 12:00 יוצא "בוקר טוב".

// P20-E12
import {
  ArgumentsHost, BadRequestException, Body, Catch, Controller, ExceptionFilter, Get, HttpException,
  Module, NotFoundException, Param, ParseIntPipe, Post, ValidationPipe, type ValidationError,
} from "@nestjs/common";
import { IsString, Length } from "class-validator";
import type { Response } from "express";

const CODES: Record<number, string> = { 400: "BAD_REQUEST", 401: "UNAUTHORIZED", 403: "FORBIDDEN", 404: "NOT_FOUND", 409: "CONFLICT" };

@Catch(HttpException)
export class ApiExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse<Response>();
    const status = exception.getStatus();
    const body = exception.getResponse();
    // אם מי שזרק כבר נתן code (למשל ה־exceptionFactory למטה) — משתמשים בו
    if (typeof body === "object" && body !== null && "code" in body) {
      res.status(status).json({ error: body });
      return;
    }
    res.status(status).json({ error: { code: CODES[status] ?? "ERROR", message: exception.message } });
  }
}

export function validationPipe() {
  return new ValidationPipe({
    whitelist: true,
    forbidNonWhitelisted: true,
    transform: true,
    exceptionFactory: (errors: ValidationError[]) =>
      new BadRequestException({
        code: "VALIDATION_ERROR",
        message: "קלט לא תקין",
        details: errors.map((e) => ({ field: e.property, messages: Object.values(e.constraints ?? {}) })),
      }),
  });
}

export class CreateItemDto {
  @IsString()
  @Length(1, 50)
  name: string;
}

@Controller("items")

  private readonly items: { id: number; name: string }[] = [];

    const item = { id: this.items.length + 1, name: dto.name };
    this.items.push(item);

  @Get(":id")

    const item = this.items.find((i) => i.id === id);
    if (!item) throw new NotFoundException(`פריט ${id} לא נמצא`);
    return item;
  }

// P20-E15
import { CallHandler, Controller, ExecutionContext, Get, Inject, Injectable, Module, NestInterceptor } from "@nestjs/common";
import { APP_INTERCEPTOR } from "@nestjs/core";
import type { Request, Response } from "express";
import { Observable, tap } from "rxjs";

export const LOGGER = "LOGGER";
export interface Logger {
  log(line: string): void;
}

@Injectable()
export class TimingInterceptor implements NestInterceptor {
  constructor(@Inject(LOGGER) private readonly logger: Logger) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<unknown> {
    const start = Date.now();
    const http = context.switchToHttp();
    const req = http.getRequest<Request>();
    const res = http.getResponse<Response>();
    return next.handle().pipe(
      tap(() => {
        // רץ אחרי ה־handler, לפני ש־Nest שולח את התשובה — לכן עוד אפשר להוסיף header
        const ms = Date.now() - start;
        res.setHeader("X-Response-Time", `${ms}ms`);
        this.logger.log(`${req.method} ${req.originalUrl} ${res.statusCode} ${ms}ms`);
      }),
    );
  }
}

@Controller()
export class PingController {
  @Get("ping")
  ping() {
    return { pong: true };
  }

  @Get("slow")
  async slow() {
    await new Promise((resolve) => setTimeout(resolve, 60));
    return { done: true };
  }
}

@Module({
  controllers: [PingController],
  providers: [
    { provide: LOGGER, useValue: console },
    { provide: APP_INTERCEPTOR, useClass: TimingInterceptor },
  ],
})
export class PingModule {}

const CODES: Record<number, string> = { 400: "BAD_REQUEST", 404: "NOT_FOUND", 409: "CONFLICT" };

@Catch(HttpException)
export class ApiExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse<Response>();
    const status = exception.getStatus();
    const body = exception.getResponse();
    const error = typeof body === "object" && body !== null && "code" in body ? body : apiError(CODES[status] ?? "ERROR", exception.message);

    forbidNonWhitelisted: true,

const LOAN_DAYS = 14;

@Injectable()
export class LibraryService {
  private readonly books: Book[] = [];
  private readonly loans: Loan[] = [];

  constructor(@Inject(CLOCK) private readonly clock: Clock) {}

  createBook(dto: CreateBookDto): Book {
    const book = { id: this.books.length + 1, title: dto.title, author: dto.author, copies: dto.copies, available: dto.copies };
    this.books.push(book);
    return book;
  }

  listBooks({ author, available, page, limit }: ListBooksQuery) {
    let books = this.books;
    if (author) books = books.filter((b) => b.author.toLowerCase().includes(author.toLowerCase()));
    if (available === "true") books = books.filter((b) => b.available > 0);
    return { data: books.slice((page - 1) * limit, page * limit), meta: { page, limit, total: books.length, totalPages: Math.ceil(books.length / limit) } };
  }

  getBook(id: number): Book {
    const book = this.books.find((b) => b.id === id);
    if (!book) throw new NotFoundException(apiError("BOOK_NOT_FOUND", `ספר ${id} לא נמצא`));
    return book;
  }

  lend(bookId: number, member: string): Loan {
    const book = this.getBook(bookId);
    if (this.loans.some((l) => l.bookId === bookId && l.member === member && l.returnedAt === null)) {
      throw new ConflictException(apiError("ALREADY_BORROWED", `${member} כבר מחזיק/ה את הספר`));
    }
    if (book.available === 0) throw new ConflictException(apiError("NO_COPIES", "אין עותק פנוי"));
    const now = this.clock.now();
    const loan = {
      id: this.loans.length + 1,
      bookId,
      member,
      loanedAt: now.toISOString(),
      dueAt: new Date(now.getTime() + LOAN_DAYS * 24 * 60 * 60 * 1000).toISOString(),
      returnedAt: null,
    };
    this.loans.push(loan);
    book.available--;
    return loan;
  }

  returnLoan(id: number): Loan {
    const loan = this.loans.find((l) => l.id === id);
    if (!loan) throw new NotFoundException(apiError("LOAN_NOT_FOUND", `השאלה ${id} לא נמצאה`));
    if (loan.returnedAt) throw new ConflictException(apiError("ALREADY_RETURNED", "ההשאלה כבר הוחזרה"));
    loan.returnedAt = this.clock.now().toISOString();
    this.getBook(loan.bookId).available++;
    return loan;
  }

  overdue(): Loan[] {
    const now = this.clock.now().getTime();
    return this.loans.filter((l) => l.returnedAt === null && new Date(l.dueAt).getTime() < now);
  }
}

// P20-E25
import {
  CanActivate, Controller, ExecutionContext, Get, HttpException, HttpStatus, Inject, Injectable, Module, UseGuards,
} from "@nestjs/common";
import type { Request, Response } from "express";

export const CLOCK = "CLOCK";
export const RATE_LIMIT = "RATE_LIMIT";
export interface Clock {
  now(): Date;
}
export interface RateLimitOptions {
  limit: number; // כמה בקשות מותר בחלון
  windowMs: number; // אורך החלון
}

@Injectable()
export class RateLimitGuard implements CanActivate {
  // לכל לקוח: מתי התחיל החלון שלו, וכמה בקשות היו בו
  private readonly windows = new Map<string, { start: number; count: number }>();

  constructor(
    @Inject(RATE_LIMIT) private readonly options: RateLimitOptions,
    @Inject(CLOCK) private readonly clock: Clock,
  ) {}

  canActivate(context: ExecutionContext): boolean {
    const http = context.switchToHttp();
    const req = http.getRequest<Request>();
    const res = http.getResponse<Response>();
    const key = req.get("x-client-id") ?? req.ip ?? "unknown";
    const now = this.clock.now().getTime();

    let w = this.windows.get(key);
    if (!w || now >= w.start + this.options.windowMs) {
      w = { start: now, count: 0 };
      this.windows.set(key, w);
    }
    if (w.count >= this.options.limit) {
      const seconds = Math.ceil((w.start + this.options.windowMs - now) / 1000);
      res.setHeader("Retry-After", String(seconds)); // לפני ה־throw: ה־header נשאר על ה־response
      throw new HttpException({ error: { code: "RATE_LIMITED", message: "יותר מדי בקשות — נסה שוב מאוחר יותר" } }, HttpStatus.TOO_MANY_REQUESTS);
    }
    w.count++;
    res.setHeader("X-RateLimit-Remaining", String(this.options.limit - w.count));
    return true;
  }
}

@Controller("data")
@UseGuards(RateLimitGuard)
export class DataController {
  @Get()
  get() {
    return { data: [1, 2, 3] };
  }
}

@Module({
  controllers: [DataController],
  providers: [
    RateLimitGuard,
    { provide: RATE_LIMIT, useValue: { limit: 5, windowMs: 60_000 } },
    { provide: CLOCK, useValue: { now: () => new Date() } },
  ],
})
export class DataModule {}
