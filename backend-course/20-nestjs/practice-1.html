P20-E29 · מי נוצר קודם, וכמה פעמים?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

כל constructor מדפיס שורה. מה יודפס כשהאפליקציה עולה? ואחרי 3 בקשות ל־GET /a ו־2 ל־GET /b — מה יחזירו הבקשות האחרונות, וכמה פעמים נוצר CounterService?

@Injectable()
export class CounterService {
  private count = 0;
  constructor() { console.log("CounterService"); }
  next() { return ++this.count; }
}

@Controller("a")
export class AController {
  constructor(private readonly counter: CounterService) { console.log("AController"); }
  @Get() hit() { return { a: this.counter.next() }; }
}

@Controller("b")
export class BController {
  constructor(private readonly counter: CounterService) { console.log("BController"); }
  @Get() hit() { return { b: this.counter.next() }; }
}

@Module({ controllers: [AController, BController], providers: [CounterService] })
export class AppModule {}

P20-E42 · ‏DI container קטן משלך 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 30 דק׳ידע נדרש: פרק 7, פרק 12, שיעור 1

מה Nest עושה בעלייה, בקטן. בקובץ 20-nestjs/starter/P20-E42.ts כתוב וייצא class Container:

register(token: string, deps: string[], factory: (...args: any[]) => unknown): void
get<T>(token: string): T
  • get יוצר את מה שנרשם תחת token: קודם את כל התלויות (deps, לפי הסדר — ברקורסיה), ואז קורא ל־factory(...depsValues).
  • singleton: כל token נוצר פעם אחת; get נוסף מחזיר את אותו מופע.
  • token שלא נרשם ← throw new Error(Cannot resolve ${token}); תלות חסרה — Cannot resolve ${token}: missing ${dep}.
  • מעגל (A צריך B, B צריך A) ← throw new Error(Circular dependency: A -&gt; B -&gt; A) (השרשרת מה־token הראשון).

P20-E43 · ‏decorators משלך: @Route ו־routesOf 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 5, פרק 7, פרק 12, שיעור 1

מה @Controller ו־@Get עושים? פונקציות שרצות על ה־class ושומרות מידע. בקובץ 20-nestjs/starter/P20-E43.ts כתוב וייצא (עם decorators בסגנון של Nest — experimentalDecorators):

export function Prefix(path: string): ClassDecorator
export function Route(method: "GET" | "POST" | "DELETE", path?: string): MethodDecorator
export function routesOf(cls: Function): string[]
  • @Prefix("products") על class שומר את ה־prefix. @Route("GET", ":id") על מתודה שומר method, נתיב ושם המתודה.
  • routesOf(cls) ← שורה לכל route, לפי סדר ההגדרה במחלקה: "GET /products/:id -> findOne". בלי path ← "GET /products -> list". בלי @Prefix ← "GET /:id -> ...".
  • שמור את המידע ב־Map (פרק 7) שהמפתח שלו הוא ה־class — לא כשדה על ה־class.
