1. Routes ופרמטרים

@Controller("products")
export class ProductsController {
  constructor(private readonly products: ProductsService) {}

  @Get()                                    // GET /products?page=2
  list(@Query() query: ListProductsQuery) { return this.products.list(query); }

  @Get(":id")                               // GET /products/7
  findOne(@Param("id", ParseIntPipe) id: number) { return this.products.findOne(id); }

  @Post()                                   // POST /products — 201 אוטומטית
  create(@Body() dto: CreateProductDto) { return this.products.create(dto); }

  @Patch(":id")
  update(@Param("id", ParseIntPipe) id: number, @Body() dto: UpdateProductDto) { return this.products.update(id, dto); }

  @Delete(":id")
  @HttpCode(204)                            // בלי זה — 200
  remove(@Param("id", ParseIntPipe) id: number) { this.products.remove(id); }
}
Decoratorמקביל ב־Express
@Param("id")req.params.id
@Query() · @Query("page")req.query · req.query.page
@Body()req.body
@Headers("x-api-key")req.get("x-api-key")
@HttpCode(204) · @Header("Cache-Control", "...")res.status(204) · res.set(...)

ParseIntPipe — pipe שממיר את "7" ל־7, ואם זה לא מספר — 400 עוד לפני שה־handler רץ. אפשר גם async: מתודה שמחזירה Promise — Nest מחכה, ושגיאה נתפסת.

2. DTO + ValidationPipe

src/products/dto/create-product.dto.ts 
import { IsBoolean, IsInt, IsNumber, IsOptional, IsString, Length, Max, Min } from "class-validator";

export class CreateProductDto {
  @IsString() @Length(2, 80)
  name: string;

  @IsNumber({ maxDecimalPlaces: 2 }) @Min(0.01) @Max(100_000)
  price: number;

  @IsInt() @Min(0)
  stock: number;

  @IsOptional() @IsBoolean()
  isActive?: boolean;
}
src/main.ts 
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,              // שדות בלי decorators — נמחקים
  forbidNonWhitelisted: true,   // ...או, עם זה, 400
  transform: true,              // הגוף הופך למופע של ה־DTO, ו־query/params מומרים לטיפוסים
}));
% curl -s -X POST localhost:3000/products -H "Content-Type: application/json" -d '{"name":"X","price":0,"extra":1}'
{"message":["property extra should not exist","name must be longer than or equal to 2 characters","price must not be less than 0.01","stock must not be less than 0","stock must be an integer number"],"error":"Bad Request","statusCode":400}

(פלט אמיתי. שים לב: על stock שחסר לגמרי יש שתי הודעות — כל decorator בודק בנפרד.) הרעיון זהה ל־Zod בפרק 15: מתארים קלט תקין פעם אחת. ההבדל: ב־Nest הסכמה היא class עם decorators, וה־class משמש גם כטיפוס TypeScript (וגם ל־Swagger, בשיעור 4).

💡 query מגיע כמחרוזת — גם כאן

?page=2 הוא "2". עם transform: true ו־@Type(() => Number) (מ־class-transformer) על השדה ב־DTO של ה־query — הוא הופך למספר לפני הבדיקה. זה ה־z.coerce של Nest.

ול־PATCH: export class UpdateProductDto extends PartialType(CreateProductDto) {} (מ־@nestjs/swagger) — כל השדות הופכים לאופציונליים, עם אותם חוקים.
