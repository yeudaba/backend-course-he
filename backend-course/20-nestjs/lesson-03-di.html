1. Custom providers

לא כל תלות היא class. שעון, הגדרות, repository לפי interface — לאלה נותנים token (מחרוזת או Symbol):

export const CLOCK = "CLOCK";
export interface Clock { now(): Date }

@Module({
  providers: [
    TasksService,
    { provide: CLOCK, useValue: { now: () => new Date() } },                 // ערך מוכן
    { provide: TASKS_REPOSITORY, useClass: PrismaTasksRepository },          // class לפי בחירה
    { provide: CONFIG, useFactory: () => loadConfig(process.env) },         // פונקציה (גם async)
  ],
})
export class TasksModule {}

@Injectable()
export class TasksService {
  constructor(
    @Inject(TASKS_REPOSITORY) private readonly repo: TasksRepository,     // interface — אין לו טיפוס בזמן ריצה, לכן token
    @Inject(CLOCK) private readonly clock: Clock,
  ) {}
}

למה @Inject(TOKEN)? TasksRepository הוא interface — הוא נמחק בקומפילציה, ו־Nest לא יכול "לראות" אותו. ה־token הוא השם שבו מבקשים. וזה בדיוק מה שמאפשר בבדיקה:

const moduleRef = await Test.createTestingModule({ imports: [TasksModule] })
  .overrideProvider(TASKS_REPOSITORY).useValue(new InMemoryTasksRepository())
  .overrideProvider(CLOCK).useValue({ now: () => new Date("2026-11-04T10:00:00Z") })
  .compile();

אותו רעיון כמו createApp({ repository, now }) של פרויקט 2 — רק ש־Nest מנהל את זה.

2. Modules: imports / exports

@Module({ providers: [UsersService], exports: [UsersService] })   // ← מאפשר לאחרים להשתמש
export class UsersModule {}

@Module({ imports: [UsersModule], providers: [OrdersService], controllers: [OrdersController] })
export class OrdersModule {}   // OrdersService יכול לקבל UsersService ב־constructor

provider "פרטי" ל־module שלו, עד שמייצאים אותו. שכחת exports או imports? Nest לא יעלה, עם הודעה כמו: Nest can't resolve dependencies of the OrdersService (?). Please make sure that the argument UsersService at index [0] is available in the OrdersModule module. (ואחריה רשימת "Potential solutions") — קרא אותה לאט, היא אומרת בדיוק מה חסר.

3. מחזור החיים של בקשה

src/common/api-key.guard.ts 
@Injectable()
export class ApiKeyGuard implements CanActivate {
  constructor(@Inject(API_KEYS) private readonly keys: Set<string>) {}

  canActivate(context: ExecutionContext): boolean {
    const req = context.switchToHttp().getRequest<Request>();
    const key = req.get("x-api-key");
    if (!key) throw new UnauthorizedException("חסר X-Api-Key");
    if (!this.keys.has(key)) throw new ForbiddenException("מפתח לא מוכר");
    return true;
  }
}
// שימוש: @UseGuards(ApiKeyGuard) מעל controller או מתודה
src/common/http-exception.filter.ts 
@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse<Response>();
    const status = exception.getStatus();
    res.status(status).json({ error: { code: CODES[status] ?? "ERROR", message: exception.message } });
  }
}
// שימוש: app.useGlobalFilters(new HttpExceptionFilter())

ExecutionContext / ArgumentsHost — עטיפה כללית (Nest תומך גם ב־GraphQL ו־WebSockets); switchToHttp() נותן את req/res הרגילים של Express.

4. Interceptors

interceptor עוטף את ה־handler: קוד לפני שהוא רץ, וקוד אחרי — על התשובה שהוא החזיר. זה המקום למדידת זמן, לוג, עטיפת תשובה או cache.

src/common/timing.interceptor.ts 
import { CallHandler, ExecutionContext, Injectable, NestInterceptor } from "@nestjs/common";
import type { Response } from "express";
import { Observable, map, tap } from "rxjs";

@Injectable()
export class TimingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<unknown> {
    const started = performance.now();                       // לפני ה־handler
    const res = context.switchToHttp().getResponse<Response>();
    return next.handle().pipe(                               // next.handle() — מריץ את ה־handler
      tap(() => res.setHeader("X-Response-Time", `${Math.round(performance.now() - started)}ms`)), // אחרי — רק מסתכל
      map((data) => ({ data })),                             // אחרי — מחליף את התשובה
    );
  }
}
  • next.handle() מריץ את ה־handler ומחזיר Observable (מספריית rxjs, שמגיעה עם Nest) — "Promise שיכול להחזיר כמה ערכים". כאן הוא מחזיר ערך אחד: מה שה־handler החזיר.
  • .pipe(...) מרכיב פעולות על הערך: tap(fn) — מריץ את fn ולא משנה כלום (לוג, header); map(fn) — מחליף את הערך במה ש־fn מחזירה (כמו map של מערך, פרק 6).
  • לא קוראים ל־next.handle()? ה־handler לא רץ בכלל. return of(value) (גם מ־rxjs) מחזיר תשובה מוכנה — כך בונים cache:
src/common/cache.interceptor.ts 
import { CallHandler, ExecutionContext, Injectable, NestInterceptor } from "@nestjs/common";
import { Observable, of, tap } from "rxjs";

@Injectable()
export class CacheInterceptor implements NestInterceptor {
  #cache = new Map<string, unknown>();
  intercept(context: ExecutionContext, next: CallHandler): Observable<unknown> {
    const url = context.switchToHttp().getRequest<{ url: string }>().url;
    if (this.#cache.has(url)) return of(this.#cache.get(url));   // בלי next.handle() — ה־handler לא רץ
    return next.handle().pipe(tap((data) => this.#cache.set(url, data)));
  }
}
// שימוש: @UseInterceptors(CacheInterceptor) מעל controller או מתודה

5. גלובלי מתוך module: ‏APP_INTERCEPTOR, ‏APP_FILTER, ‏APP_PIPE

app.useGlobalFilters(new X()) ב־main.ts עובד, אבל ה־filter נוצר ב־new — בלי DI, ובלי שהבדיקות (שבונות את ה־module, לא את main.ts) יראו אותו. הדרך של Nest: providers עם tokens מיוחדים מ־@nestjs/core:

src/app.module.ts 
import { BadRequestException, Module, ValidationPipe } from "@nestjs/common";
import { APP_FILTER, APP_INTERCEPTOR, APP_PIPE } from "@nestjs/core";
import { OrdersController } from "./orders/orders.controller";
import { TimingInterceptor } from "./common/timing.interceptor";
import { ErrorFilter } from "./common/error.filter";
import { CONFIG, GREETING, type Config } from "./config";

@Module({
  controllers: [OrdersController],
  providers: [
    { provide: CONFIG, useValue: { shopName: "Beans & Co" } },
    // useFactory עם inject: Nest מזריק את CONFIG כפרמטר הראשון של הפונקציה
    { provide: GREETING, useFactory: (config: Config) => `ברוכים הבאים ל־${config.shopName}`, inject: [CONFIG] },
    // גלובליים, אבל מתוך module — כך גם להם יש DI (ו־Test.createTestingModule מקבל אותם)
    { provide: APP_INTERCEPTOR, useClass: TimingInterceptor },
    { provide: APP_FILTER, useClass: ErrorFilter },
    {
      provide: APP_PIPE,
      useFactory: () =>
        new ValidationPipe({
          whitelist: true,
          transform: true,
          // exceptionFactory: מה לזרוק כשהבדיקה נכשלה. errors — מערך ValidationError (שדה + constraints)
          exceptionFactory: (errors) => new BadRequestException(errors.map((e) => `${e.property}: ${Object.values(e.constraints ?? {}).join(", ")}`)),
        }),
    },
  ],
})
export class AppModule {}
src/common/error.filter.ts 
@Catch(HttpException)
export class ErrorFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse<Response>();
    const body = exception.getResponse();                    // מה שנזרק: מחרוזת, או אובייקט כמו { message: [...] }
    const details = typeof body === "object" && Array.isArray((body as { message?: unknown }).message) ? (body as { message: string[] }).message : undefined;
    res.status(exception.getStatus()).json({ error: { code: exception.getStatus() === 400 ? "VALIDATION_ERROR" : "ERROR", message: exception.message, details } });
  }
}
src/main.ts 
const app = await NestFactory.create(AppModule);
app.setGlobalPrefix("api");                                  // כל ה־routes תחת /api
await app.listen(process.env.PORT ?? 3000);

{"data":{"calls":1}}

(פלט אמיתי; מ־curl -si הוצגו רק ה־status, ה־header והגוף.) מה רואים:

  • useFactory + inject — ה־GREETING נבנה מ־CONFIG. הסדר ב־inject הוא סדר הפרמטרים של הפונקציה.
  • exceptionFactory קבע את ההודעות (email: ...), ו־exception.getResponse() ב־filter החזיר את האובייקט שנזרק — עם המערך ב־message. ‏exception.message הוא רק הכותרת ("Bad Request Exception").
  • בקריאה השנייה ל־/slow ה־handler לא רץ (calls נשאר 1): ה־CacheInterceptor החזיר of(...). וה־{ data }? ה־TimingInterceptor הגלובלי עוטף מבחוץ — גם תשובה מה־cache.
  • setGlobalPrefix("api") — ה־controller כתוב עם "orders", והכתובת היא /api/orders.

וגם guard גלובלי: { provide: APP_GUARD, useClass: ApiKeyGuard } — אותו רעיון.
