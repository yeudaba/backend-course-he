1. Custom providers

לא כל תלות היא class. שעון, הגדרות, repository לפי interface — לאלה נותנים token (מחרוזת או Symbol):

export const CLOCK = "CLOCK";
export interface Clock { now(): Date }

@Module({
  providers: [
    TasksService,
    { provide: CLOCK, useValue: { now: () => new Date() } },                 // ערך מוכן
    { provide: TASKS_REPOSITORY, useClass: PrismaTasksRepository },          // class לפי בחירה
    { provide: CONFIG, useFactory: () => loadConfig(process.env) },         // פונקציה (גם async)
  ],
})
export class TasksModule {}

@Injectable()
export class TasksService {
  constructor(
    @Inject(TASKS_REPOSITORY) private readonly repo: TasksRepository,     // interface — אין לו טיפוס בזמן ריצה, לכן token
    @Inject(CLOCK) private readonly clock: Clock,
  ) {}
}

למה @Inject(TOKEN)? TasksRepository הוא interface — הוא נמחק בקומפילציה, ו־Nest לא יכול "לראות" אותו. ה־token הוא השם שבו מבקשים. וזה בדיוק מה שמאפשר בבדיקה:

const moduleRef = await Test.createTestingModule({ imports: [TasksModule] })
  .overrideProvider(TASKS_REPOSITORY).useValue(new InMemoryTasksRepository())
  .overrideProvider(CLOCK).useValue({ now: () => new Date("2026-11-04T10:00:00Z") })
  .compile();

אותו רעיון כמו createApp({ repository, now }) של פרויקט 2 — רק ש־Nest מנהל את זה.

2. Modules: imports / exports

@Module({ providers: [UsersService], exports: [UsersService] })   // ← מאפשר לאחרים להשתמש
export class UsersModule {}

@Module({ imports: [UsersModule], providers: [OrdersService], controllers: [OrdersController] })
export class OrdersModule {}   // OrdersService יכול לקבל UsersService ב־constructor

provider "פרטי" ל־module שלו, עד שמייצאים אותו. שכחת exports או imports? Nest לא יעלה, עם הודעה כמו: Nest can't resolve dependencies of the OrdersService (?). Please make sure that the argument UsersService at index [0] is available in the OrdersModule module. (ואחריה רשימת "Potential solutions") — קרא אותה לאט, היא אומרת בדיוק מה חסר.

3. מחזור החיים של בקשה

src/common/api-key.guard.ts 
@Injectable()
export class ApiKeyGuard implements CanActivate {
  constructor(@Inject(API_KEYS) private readonly keys: Set<string>) {}

  canActivate(context: ExecutionContext): boolean {
    const req = context.switchToHttp().getRequest<Request>();
    const key = req.get("x-api-key");
    if (!key) throw new UnauthorizedException("חסר X-Api-Key");
    if (!this.keys.has(key)) throw new ForbiddenException("מפתח לא מוכר");
    return true;
  }
}
// שימוש: @UseGuards(ApiKeyGuard) מעל controller או מתודה
src/common/http-exception.filter.ts 
@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse<Response>();
    const status = exception.getStatus();
    res.status(status).json({ error: { code: CODES[status] ?? "ERROR", message: exception.message } });
  }
}
// שימוש: app.useGlobalFilters(new HttpExceptionFilter())

ExecutionContext / ArgumentsHost — עטיפה כללית (Nest תומך גם ב־GraphQL ו־WebSockets); switchToHttp() נותן את req/res הרגילים של Express.
