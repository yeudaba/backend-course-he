P20-E02 · לקרוא controller

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

נתון:

@Controller("products")
export class ProductsController {
  @Get(":id")
  findOne(@Param("id", ParseIntPipe) id: number) { return { route: "one", id }; }

  @Get("featured")
  featured() { return { route: "featured" }; }

  @Post()
  create(@Body() dto: CreateProductDto) { return dto; }

  @Delete(":id")
  @HttpCode(204)
  remove() {}
}

מה ה־status ומה התשובה (בערך) עבור: (1) GET /products/7 (2) GET /products/featured (3) POST /products עם גוף תקין (4) DELETE /products/3 (5) PUT /products/3? ומה מתקנים ב־(2)?

P20-E08 · DTO וולידציה 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 20-nestjs/starter/P20-E08.ts:

  • השלם את CreateProductDto עם decorators של class-validator: name 2–80 תווים; price עד 2 ספרות אחרי הנקודה, בין 0.01 ל־100,000; stock שלם ≥ 0; isActive בוליאני אופציונלי.
  • POST /products ← 201 { id, name, price, stock, isActive } (isActive ברירת מחדל true, ids מ־1). GET /products ← כל המוצרים.

הבודק מפעיל את ה־ValidationPipe מהשיעור (whitelist, forbidNonWhitelisted, transform) — אתה רק כותב את ה־DTO. בדוק ש־{"name":"X","price":0,"extra":1} נותן את 4 ההודעות מהשיעור.

P20-E10 · pagination עם Query DTO 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 20-nestjs/starter/P20-E10.ts יש 25 מוצרים (Product 1 … Product 25). כתוב ListProductsQuery ו־GET /products?page=&limit=&q=:

P20-E16 · pipe משלך 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ 20-nestjs/starter/P20-E16.ts כתוב ParsePositiveIntPipe:

  • "7" ← 7. "0", "-3", "abc", "1.5", "", "7x", " 7" ← BadRequestException עם "id חייב להיות מספר שלם חיובי" — כש־id הוא שם הפרמטר (metadata.data).
  • השתמש בו ב־GET /items/:id.

P20-E26 · מודול סימניות — מקובץ ריק 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 35 דק׳ידע נדרש: שיעור 2

עד עכשיו השלמת קבצים שה־imports, ה־decorators וה־module בהם כבר היו כתובים. הפעם כותבים את כל המודול מהשורה הראשונה: interface, ‏DTO, ‏service, ‏controller ו־module. כתוב וייצא BookmarksModule עם סימניות בזיכרון: { id, url, title, tags }, ‏ids מ־1.

  • POST /bookmarks ← 201 והסימנייה. ‏CreateBookmarkDto: ‏url כתובת תקינה (@IsUrl()), ‏title מחרוזת באורך 1–100 (נשמרת אחרי trim), ‏tags לא חובה: מערך של עד 5 מחרוזות. בלי tags ← [].
  • GET /bookmarks ← כולן. עם ?tag=nest — רק אלה שיש להן את התגית.
  • GET /bookmarks/:id ← הסימנייה, או 404 עם ההודעה סימנייה ${id} לא נמצאה. ‏id שאינו מספר ← 400.
  • DELETE /bookmarks/:id ← 204 (בלי גוף), או 404.

הבודק מפעיל את המודול עם ValidationPipe גלובלי (whitelist, ‏forbidNonWhitelisted, ‏transform), כמו ב־main.ts של שיעור 2. שדה שלא ב־DTO ← 400.
