P20-E25 · אתגר: הגבלת קצב 🤖

רמה 5⏱ 45 דק׳ידע נדרש: שיעור 3

בקובץ 20-nestjs/starter/P20-E25.ts כתוב RateLimitGuard ("חלון קבוע") והפעל אותו על DataController:

  • האופציות מ־token RATE_LIMIT ({ limit, windowMs }), והזמן מ־CLOCK.
  • מזהה לקוח: header X-Client-Id, ואם אין — req.ip. לכל לקוח מונה משלו.
  • החלון מתחיל בבקשה הראשונה של הלקוח ונמשך windowMs. בכל בקשה מאושרת: header X-RateLimit-Remaining.
  • מעבר למכסה ← 429 { error: { code: "RATE_LIMITED", message } }, עם header Retry-After — שניות עד סוף החלון, מעוגל למעלה.

דוגמה (limit 3, חלון 10 שניות): 3 בקשות ב־10:00:00 ← remaining 2, 1, 0. בקשה ב־10:00:02.5 ← 429, Retry-After: 8. ב־10:00:10 ← חלון חדש.

🏁 מבחן מעבר

  • להסביר מה Nest עושה כשהוא רואה constructor(private readonly tasks: TasksService), ולמה צריך @Injectable().
  • לכתוב resource מלא (controller, service, DTOs, module) עם ולידציה ו־status נכונים.
  • להחליף provider בבדיקה (repository או שעון) עם overrideProvider.
  • לכתוב guard ו־exception filter, ולהסביר את סדר הריצה: middleware ← guards ← interceptors ← pipes ← handler ← filters.
  • פרויקט 2 ב־Nest, עם Swagger ב־/docs, ו־PR2-NEST עובר.
