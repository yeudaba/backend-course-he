זה P15-E24, ב־Nest. בקובץ 20-nestjs/starter/P20-E24.ts בנה LibraryModule — בזיכרון, עם DTOs, service, שני controllers, filter ושעון (CLOCK).

בקשההתנהגות
POST /books { title, author, copies }title ו־author 1–200 תווים, copies שלם 1–100 ← 201 { id, title, author, copies, available }
GET /books?author=&available=true&page=&limit=author — חלק מהשם, בלי תלות באותיות; available=true — רק עם עותק פנוי. limit עד 50 (ברירת מחדל 10) ← { data, meta: { page, limit, total, totalPages } }
GET /books/:id200 / 404 BOOK_NOT_FOUND
POST /books/:id/loans { member }member 1–100 תווים. אותו member כבר מחזיק ← 409 ALREADY_BORROWED; אין עותק ← 409 NO_COPIES ← 201 { id, bookId, member, loanedAt, dueAt, returnedAt: null } (dueAt = 14 יום, ISO)
POST /loans/:id/return200 עם returnedAt; כבר הוחזר ← 409 ALREADY_RETURNED; לא קיים ← 404 LOAN_NOT_FOUND
GET /loans/overdueלא הוחזרו, ו־dueAt עבר (לפי CLOCK)

כל שגיאה: { error: { code, message, details? } }; ולידציה ← 400 VALIDATION_ERROR עם details: [{ field, messages }]; כתובת לא קיימת ← 404 NOT_FOUND. ה־filter וה־ValidationPipe נרשמים בתוך המודול (APP_FILTER, APP_PIPE).
