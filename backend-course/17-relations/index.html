🧰 לפני שמתחילים — פרק 17

מה צריך שכבר יהיה מותקן: PostgreSQL, מסד course, קובץ .env והתוסף של VS Code (פרק 16).

מה מתקינים עכשיו: כלום. רק טוענים את נתוני הפרק:

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 17-relations מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

% cd ~/dev/backend-course
% psql -d course -f 17-relations/files/store.sql

(הקובץ יוצר טבלאות חדשות לצד אלה של פרק 16; products ו־customers נבנות מחדש במבנה של הפרק הזה. רוצה לחזור לנתונים של פרק 16? טען שוב את 16-sql/files/shop.sql.)

✔ בדיקה: psql -d course -c "select count(*) from orders" ← 12.

🎯 בסוף הפרק תדע
  • לתכנן טבלאות קשורות: מפתח ראשי, foreign key, יחס של אחד־לרבים ורבים־לרבים.
  • לשלב טבלאות עם JOIN (INNER ו־LEFT) — ולהבין מתי נעלמות שורות.
  • לקבץ ולסכם עם GROUP BY ו־HAVING.
  • לכתוב תת־שאילתות, CTE (WITH) ו־EXISTS.
  • פונקציות חלון בסיסיות: "הכי טוב בכל קבוצה" וסכום מצטבר.

🤔 למה צריך את זה?

בפרק 16 כל טבלה עמדה לבד. בעולם האמיתי: לקוח ← הזמנות ← פריטים ← מוצרים ← קטגוריות. כמעט כל endpoint שתכתוב ("ההזמנות שלי עם הסכום", "המוצרים הנמכרים החודש") הוא JOIN עם GROUP BY. וזה גם לב שאלות ה־SQL בראיונות: "לקוחות שלא הזמינו אף פעם", "המוצר הנמכר בכל קטגוריה", "ההכנסה לפי חודש".
