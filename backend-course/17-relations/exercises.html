P17-E28 · JOIN ו־GROUP BY בקוד 🤖

🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

🔁 חזרה על Map (פרק 7), ‏type (פרק 11) ואגורות (פרק 2). לפעמים הנתונים כבר אצלך בזיכרון (מ־API, מקובץ, ממטמון), וצריך לחבר ולקבץ אותם בקוד. כתוב ב־TypeScript את P17-E12 (הכנסה לפי עיר) — בלי SQL. בקובץ 17-relations/starter/P17-E28.ts כתוב וייצא:

  • את הטיפוסים Customer (‏id, ‏full_name, ‏city: string | null), ‏Order (‏id, ‏customer_id, ‏status), ‏OrderItem (‏order_id, ‏quantity, ‏unit_price), ו־CityRevenue (‏city, ‏revenue).

P17-E02 · כמה שורות?

SELECT * FROM customers c LEFT JOIN orders o ON o.customer_id = c.id;       -- 2
SELECT * FROM orders o LEFT JOIN customers c ON c.id = o.customer_id;       -- 3

P17-E03 · למה הסכום כפול?

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

נניח שיש גם טבלת payments(order_id, amount), ולהזמנה אחת יכולים להיות כמה תשלומים (חלוקה לכרטיסים). מישהו כתב:

SELECT o.id, SUM(oi.quantity * oi.unit_price) AS total, SUM(p.amount) AS paid
FROM orders o
JOIN order_items oi ON oi.order_id = o.id
JOIN payments p     ON p.order_id = o.id
GROUP BY o.id;

להזמנה עם 3 פריטים ו־2 תשלומים — מה יקרה ל־total ול־paid? למה? ואיך מתקנים?

P17-E04 · WHERE או HAVING?

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 3

אילו שאילתות תקינות? לתקינות — מה הן מחזירות במילים.

SELECT status, COUNT(*) FROM orders WHERE COUNT(*) > 2 GROUP BY status;                    -- 1
SELECT status, COUNT(*) FROM orders GROUP BY status HAVING COUNT(*) > 2;                   -- 2
SELECT status, COUNT(*) FROM orders WHERE created_at >= '2026-03-01' GROUP BY status;      -- 3
SELECT status, customer_id, COUNT(*) FROM orders GROUP BY status;                          -- 4
SELECT customer_id, COUNT(*) FROM orders GROUP BY customer_id HAVING status = 'paid';      -- 5
