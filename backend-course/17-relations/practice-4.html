P17-E69 · ‏ROW_NUMBER מול RANK בתיקו

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

לכל לקוח — כמה הזמנות שלא בוטלו יש לו, ושני דירוגים. כמה לקוחות יקבלו rn = 1? ו־rnk = 1? ומה rnk של מי שבא אחרי קבוצת השוויון?

WITH counts AS (
  SELECT c.full_name, COUNT(o.id) AS orders
  FROM customers c
  LEFT JOIN orders o ON o.customer_id = c.id AND o.status <> 'cancelled'
  GROUP BY c.id
)
SELECT full_name, orders,
       ROW_NUMBER() OVER (ORDER BY orders DESC, full_name) AS rn,
       RANK()       OVER (ORDER BY orders DESC) AS rnk
FROM counts
ORDER BY rn;

P17-E70 · ‏EXISTS מול JOIN — כמה פעמים כל לקוח?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

"הלקוחות שקנו פולי קפה (קטגוריה 1)". כמה שורות תחזיר כל שאילתה? למה?

SELECT c.full_name
FROM customers c
JOIN orders o       ON o.customer_id = c.id
JOIN order_items oi ON oi.order_id = o.id
JOIN products p     ON p.id = oi.product_id
WHERE p.category_id = 1
ORDER BY c.full_name;

SELECT c.full_name
FROM customers c
WHERE EXISTS (
  SELECT 1 FROM orders o
  JOIN order_items oi ON oi.order_id = o.id
  JOIN products p     ON p.id = oi.product_id
  WHERE o.customer_id = c.id AND p.category_id = 1
)
ORDER BY c.full_name;

P17-E71 · ‏OVER — עם PARTITION, עם ORDER BY, ובלי כלום

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: שיעור 4

ההזמנות של דנה ושל יוסי, עם סכום כל הזמנה (total), ושלושה חלונות על אותו סכום. מה כל עמודה מחשבת? נחש את הערכים בשורה הראשונה של יוסי.

WITH t AS (
  SELECT o.id, c.full_name, o.created_at, SUM(oi.quantity * oi.unit_price) AS total
  FROM orders o
  JOIN customers c    ON c.id = o.customer_id
  JOIN order_items oi ON oi.order_id = o.id
  WHERE c.id IN (1, 2)
  GROUP BY o.id, c.full_name
)
SELECT full_name, id, total,
       SUM(total) OVER () AS all_total,
       SUM(total) OVER (PARTITION BY full_name) AS customer_total,
       SUM(total) OVER (PARTITION BY full_name ORDER BY created_at) AS running
FROM t
ORDER BY full_name, created_at;

P17-E72 · ‏WITH או תת־שאילתה ב־FROM?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

שתי השאילתות מחזירות אותו דבר. מה כל חלק עושה? כתוב במילים את שלבי החישוב. ואם צריך את order_totals פעמיים באותה שאילתה (למשל גם ממוצע וגם מקסימום, משני JOIN שונים) — איזו צורה עדיפה?

SELECT ROUND(AVG(total), 2) AS avg_order, MAX(total) AS max_order
FROM (
  SELECT o.id, SUM(oi.quantity * oi.unit_price) AS total
  FROM orders o JOIN order_items oi ON oi.order_id = o.id
  WHERE o.status <> 'cancelled'
  GROUP BY o.id
) AS order_totals;

WITH order_totals AS (
  SELECT o.id, SUM(oi.quantity * oi.unit_price) AS total
  FROM orders o JOIN order_items oi ON oi.order_id = o.id
  WHERE o.status <> 'cancelled'
  GROUP BY o.id
)
SELECT ROUND(AVG(total), 2) AS avg_order, MAX(total) AS max_order
FROM order_totals;

P17-E78 · ‏WITH ושמות של שלבים ב־JavaScript

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 4

זה החישוב של "הלקוחות עם ממוצע ההזמנה הגבוה" (כאן — שניים) (הדוגמה עם WITH order_totals מהשיעור) — על מערכים בזיכרון. מה יודפס? איזו שורה ב־JS מקבילה לכל חלק ב־SQL (ה־CTE, ה־JOIN, ה־GROUP BY, ה־ORDER BY וה־LIMIT)?

const orders = [{ id: 1, customer: "Dana", status: "shipped" }, { id: 2, customer: "Yossi", status: "shipped" },
  { id: 3, customer: "Dana", status: "paid" }, { id: 4, customer: "Noa", status: "cancelled" }, { id: 5, customer: "Noa", status: "paid" }];
const items = [{ order: 1, total: 194.7 }, { order: 2, total: 278.7 }, { order: 3, total: 197 }, { order: 4, total: 649 }, { order: 5, total: 189 }];

const orderTotals = orders
  .filter((o) => o.status !== "cancelled")
  .map((o) => ({ customer: o.customer, total: items.filter((i) => i.order === o.id).reduce((s, i) => s + i.total, 0) }));

const byCustomer = new Map();
for (const t of orderTotals) {
  const g = byCustomer.get(t.customer) ?? { customer: t.customer, orders: 0, sum: 0 };
  g.orders += 1;
  g.sum += t.total;
  byCustomer.set(t.customer, g);
}
const result = [...byCustomer.values()]
  .map((g) => ({ customer: g.customer, orders: g.orders, avg: Math.round((g.sum / g.orders) * 100) / 100 }))
  .sort((a, b) => b.avg - a.avg)
  .slice(0, 2);
console.log(result);

🔗 איך זה מתחבר: filter/map/reduce/sort/slice מפרק 6 ו־Map מפרק 7 — והשיעור: WITH הוא "משתנה עם שם" לשלב בחישוב, בדיוק כמו const orderTotals.

P17-E27 · ההזמנה הכמה של הלקוח 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

🔁 חזרה על JOIN ו־GROUP BY (שיעורים 2–3) ועל פונקציות חלון (שיעור 4), יחד בשאילתה אחת. מחלקת השירות רוצה לראות, לכל לקוח, את ההזמנות שלו לפי הסדר, וכמה הוא הוציא עד כל הזמנה. בקובץ 17-relations/starter/P17-E27.sql כתוב שאילתה (רק הזמנות שלא בוטלו) עם העמודות:

  • total — סכום ההזמנה (כמות × מחיר יחידה, על כל הפריטים).
  • running_total — כמה הלקוח הוציא עד ההזמנה הזו, כולל.

מיון: לפי full_name, ואחר כך order_no.
