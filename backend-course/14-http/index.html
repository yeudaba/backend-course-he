פרק 14 — HTTP ורשת בסיסית

⏱ 4 מפגשים

🧰 לפני שמתחילים — פרק 14

מה צריך שכבר יהיה מותקן: Node.js 24+, VS Code, Google Chrome (פרק 0).

מה מתקינים עכשיו:

  • curl — כבר מותקן ב־Mac. בדיקה: curl --version.
  • תוסף REST Client ל־VS Code (מזהה humao.rest-client) — שליחת בקשות מתוך קובץ .http, עם תוצאה בחלון צד.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 14-http מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה שהסביבה מוכנה — ב־Terminal של VS Code, מתוך ~/dev/backend-course:

% node -v
v24.11.0

(כל גרסה 24 ומעלה תקינה.)

✔ שרת ההדגמה: node 14-http/files/demo-server.mjs ← אמור להופיע שרת ההדגמה רץ: http://localhost:4000. פתח את הכתובת ב־Chrome — תראה JSON. עצירה: Ctrl+C.

🎯 בסוף הפרק תדע
  • להסביר מה קורה מרגע שמקלידים כתובת ועד שמגיעה תשובה: URL, DNS, בקשה, תשובה.
  • לקרוא ולבנות בקשת HTTP: method, path, query, headers, body — ותשובה: status, headers, body.
  • לבחור status code נכון, ולהבין את ההבדל בין GET, POST, PUT, PATCH ו־DELETE.
  • לשלוח בקשות עם curl, REST Client ו־DevTools של Chrome.
  • לכתוב שרת HTTP בסיסי עם node:http, וללקוח עם fetch — כולל timeout.

🤔 למה צריך את זה?

זה הפרק שבו "Backend" מקבל משמעות: שרת הוא תוכנה שמקבלת בקשות HTTP ומחזירה תשובות HTTP. כל מה שבנית עד עכשיו — לוגיקה, validation, שגיאות — יישב מאחורי השכבה הזו. מראיינים שואלים על HTTP כמעט תמיד ("מה ההבדל בין PUT ל־PATCH?", "מתי 401 ומתי 403?"), ובלי להבין אותו קשה מאוד לדבג שרת.
