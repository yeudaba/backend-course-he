P14-E10 · מבקשה לפקודת curl 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 3

כלים כמו DevTools יודעים "Copy as cURL". בקובץ 14-http/starter/P14-E10.mjs השלם toCurl({ method, url, headers, body }):

  • method ברירת מחדל "GET"; רק אם אינו GET ← -X METHOD.
  • הכתובת, כל header (-H 'Name: value') והגוף (-d '...') — בתוך מירכאות בודדות.
  • גוף שהוא אובייקט ← JSON.stringify, ואם אין header בשם content-type (בלי תלות באותיות) ← מוסיפים Content-Type: application/json אחרי ה־headers הקיימים.
  • גרש בתוך ערך ← '\'' (סוגרים, גרש מוגן, פותחים).

סדר: curl [-X M] 'url' [-H ...] [-d ...], מופרד ברווח אחד.

P14-E15 · לקרוא קובץ .http 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 3

בקובץ 14-http/starter/P14-E15.mjs השלם parseHttpFile(text) — "מנוע" מוקטן של REST Client. מחזירה מערך { name, method, url, headers, body }:

  • שורות @name = value (לפני ה־### הראשון) מגדירות משתנים.
  • כל שורה שמתחילה ב־### פותחת בקשה חדשה; מה שאחריה (בלי רווחים) הוא name.
  • בתוך בקשה: מדלגים על שורות ריקות ועל הערות (# או //) עד שורת METHOD URL; אחריה headers (אובייקט, שמות כמו שנכתבו) עד שורה ריקה; כל השאר — body (אחרי trim; ריק ← undefined).
  • {{name}} בכתובת, ב־headers ובגוף ← ערך המשתנה. משתנה לא מוגדר ← Error(משתנה לא מוגדר: ${name}).
  • בקשה בלי שורת METHOD URL — לא נכנסת לתוצאה.
