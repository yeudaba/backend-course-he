3. Methods

Methodמשמעותדוגמהגוף?בטוח לחזור?
GETהבאGET /products/7לא✔ (לא משנה כלום)
POSTצור / פעולהPOST /productsכן✘ — שתי בקשות = שני מוצרים

DELETEמחקDELETE /products/7לא✔ (מחוק נשאר מחוק)

"בטוח לחזור" = idempotent. זה חשוב כי רשתות נופלות: אם בקשה לא קיבלה תשובה, לקוח ינסה שוב. ב־GET, PUT ו־DELETE זה בסדר. ב־POST — עלולה להיווצר הזמנה כפולה; את זה נפתור ב"מפתח idempotency" (פרק 24 ופרויקט הדגל).

4. Status codes

טווחמשמעותהנפוצים
2xxהצליח200 OK · 201 Created (נוצר משהו) · 204 No Content (הצליח, אין גוף — למשל אחרי מחיקה)
3xxהפניה301 (עבר לצמיתות) · 304 Not Modified (cache)
4xxהלקוח טעה400 Bad Request (קלט לא תקין) · 401 Unauthorized (לא מחובר) · 403 Forbidden (מחובר, אבל אסור) · 404 Not Found · 409 Conflict (התנגשות — למשל אימייל תפוס) · 422 (תקין מבנית, לא עובר חוקים) · 429 Too Many Requests
5xxהשרת נכשל500 Internal Server Error (באג) · 502/503/504 (שירות לא זמין / timeout)
💡 401 מול 403

401 = "מי אתה? תתחבר" (אין זהות או שהיא לא תקפה). 403 = "אני יודע מי אתה — ואסור לך" (אין הרשאה). שאלת ראיון קלאסית; נממש את שניהם בפרק 21.

⚠️ 4xx או 5xx — חשוב

קלט לא תקין שגרם לקריסה ← השרת מחזיר 500 ← הלקוח חושב שהשרת שבור (ולפעמים ינסה שוב ושוב). בדיקת קלט (פרקים 11–12) הופכת את זה ל־400 עם הודעה ברורה. כלל: 5xx = באג או תקלה אצלנו, שצריך לטפל בה; 4xx = הלקוח צריך לשנות משהו.
