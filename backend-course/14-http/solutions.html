P14-E01 · לפרק כתובות רמה 1

💡 רמז 1

port לא כתוב ← url.port הוא מחרוזת ריקה, והדפדפן משתמש ב־80 (http) או 443 (https).

💡 רמז 2

for (const text of [
  "http://localhost:4000/products?maxPrice=100",
  "https://api.shop.co.il/v2/orders/17/items?page=2&sort=-date",

בשתיים האחרונות ה־port הוא 443 (ברירת המחדל של https). ב־2: המשאב הוא "הפריטים של הזמנה 17", בגרסה 2 של ה־API; sort=-date היא מוסכמה נפוצה ל"מיון יורד לפי תאריך".

  • לחשוב שה־query הוא חלק מה־path. השרת מקבל אותם בנפרד — routing לפי path, סינון לפי query.

P14-E02 · method ו־status רמה 1

💡 רמז 1

4xx — הלקוח צריך לשנות משהו. 5xx — הבעיה אצלנו.

💡 רמז 2

לא מחובר ← 401. מחובר אבל אסור ← 403.

✅ פתרון
  1. GET /orders ← 200
  2. POST /orders ← 201, עם header Location: /orders/42 והאובייקט החדש בגוף
  3. GET /orders/999 ← 404
  4. DELETE /orders/7 ← 204 (או 200 עם גוף)
  5. PATCH /orders/7 עם {"address": "..."} ← 200
  6. POST /users ← 409 Conflict
  7. GET /orders ← 401
  8. DELETE /orders/8 ← 403 (יש מערכות שמחזירות 404 כדי לא לחשוף שההזמנה קיימת — גם זה לגיטימי)
  9. POST /products ← 400 (או 422)
  10. כל בקשה ← 503 (או 500)
⚠️ טעויות נפוצות
  • להחזיר 200 עם {"error": ...} בגוף. הלקוח, הדפדפן, כלי הניטור ו־retry — כולם מסתכלים על ה־status.
  • 500 על קלט לא תקין — זו לא תקלה שלנו.

P14-E03 · לקרוא בקשה גולמית רמה 1

💡 רמז 1

שורה ריקה מפרידה בין headers לגוף.

💡 רמז 2

idempotent: האם שליחה כפולה משנה את התוצאה?

✅ פתרון
  1. עדכון חלקי (PATCH) של הזמנה 17: הסטטוס יהיה "shipped".
  2. אפשרות שמשנה איך לבצע (בלי לשלוח הודעה ללקוח), לא מה לשנות. מוסכמה, לא חוק — אפשר היה גם בגוף.
  3. מהטוקן ב־Authorization — השרת stateless, אז כל בקשה מביאה את ההוכחה איתה.
  4. השרת לא יודע שהגוף הוא JSON; שרת זהיר יחזיר 415 (כמו שרת ההדגמה), שרת אחר אולי יתעלם מהגוף.
  5. הטוקן תקין והשרת יודע מי אתה — אבל אין לך הרשאה לעדכן את ההזמנה הזו. 401 היה אומר שהטוקן חסר, פג או לא תקין.
  6. כן — לקבוע סטטוס "shipped" פעמיים נותן אותה תוצאה. ({"addItem": 5} כבר לא היה בטוח.)
⚠️ טעויות נפוצות
  • לחשוב ש־PATCH תמיד idempotent — תלוי מה הוא עושה. "קבע ל־X" כן; "הוסף 1" לא.

P14-E05 · מה fetch עושה עם 404? רמה 1

💡 רמז 1

מבחינת fetch — הבקשה הצליחה: נשלחה, וחזרה תשובה.

💡 רמז 2

res.ok הוא true רק ל־200–299.

✅ פתרון
import http from "node:http";
import { once } from "node:events";

const server = http.createServer((req, res) => {
  res.writeHead(404, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ error: "לא נמצא" }));
});
server.listen(0);
await once(server, "listening");

try {
  const res = await fetch(`http://localhost:${server.address().port}/x`);
  console.log("הגיעה תשובה:", res.ok, res.status);
  const data = await res.json();
  console.log(data.error);
} catch (err) {
  console.log("נזרקה שגיאה:", err.message);
} finally {
  server.close();
}
הגיעה תשובה: false 404
לא נמצא

ה־catch לא רץ. אם הקוד היה מניח שהגוף הוא "ההזמנה" — היה ממשיך עם { error: ... } כאילו זו הזמנה. לכן תמיד: if (!res.ok) ....

⚠️ טעויות נפוצות
  • להסתמך על try/catch סביב fetch כדי "לתפוס 404".

P14-E06 · פירוק URL 🤖 רמה 2

💡 רמז 1

new URL(text) זורק על כתובת לא תקינה — תפוס וזרוק שגיאה משלך.

💡 רמז 2

Object.fromEntries(url.searchParams)

✅ פתרון
// P14-E06
const DEFAULT_PORTS = { "http:": 80, "https:": 443 };

export function parseUrl(text) {
  let url;
  try {
    url = new URL(text);
  } catch {
    throw new Error(`כתובת לא תקינה: ${text}`);
  }
  return {
    protocol: url.protocol.slice(0, -1),
    host: url.hostname,
    port: url.port ? Number(url.port) : (DEFAULT_PORTS[url.protocol] ?? null),
    path: url.pathname,
    query: Object.fromEntries(url.searchParams),
  };
}

console.log(JSON.stringify(parseUrl("http://localhost:4000/products?maxPrice=100&sort=price")));
console.log(JSON.stringify(parseUrl("https://shop.co.il")));
{"protocol":"http","host":"localhost","port":4000,"path":"/products","query":{"maxPrice":"100","sort":"price"}}
{"protocol":"https","host":"shop.co.il","port":443,"path":"/","query":{}}
⚠️ טעויות נפוצות
  • לפרק עם split(":") ו־split("/") — נשבר על פורטים, query, תווים מקודדים. יש URL מובנה.
  • Number(url.port) כש־port ריק ← 0, לא ברירת המחדל.

P14-E07 · קטגוריות status 🤖 רמה 2

💡 רמז 1

Math.floor(code / 100) נותן את הספרה הראשונה.

💡 רמז 2

new Set([...]).has(code)

✅ פתרון
// P14-E07
const CATEGORIES = { 2: "success", 3: "redirect", 4: "client-error", 5: "server-error" };
const RETRYABLE = new Set([408, 429, 500, 502, 503, 504]);

export function statusCategory(code) {
  if (!Number.isInteger(code)) return "unknown";
  return CATEGORIES[Math.floor(code / 100)] ?? "unknown";
}

export function shouldRetry(code) {
  return RETRYABLE.has(code);
}

console.log([200, 204, 301, 404, 429, 503, 99].map(statusCategory).join(" "));
console.log([400, 404, 429, 500, 503].map(shouldRetry).join(" "));
success success redirect client-error client-error server-error unknown
false false true true true

למה לא לנסות שוב 400 או 404? כי אותה בקשה תקבל אותה תשובה. ניסיון חוזר עוזר רק כשהבעיה זמנית. (501 Not Implemented הוא 5xx שגם לא כדאי לנסות שוב.)

⚠️ טעויות נפוצות
  • code >= 500 בלבד — מפספס את 429 ו־408, ותופס את 501.

P14-E08 · פירוק headers 🤖 רמה 2

💡 רמז 1

line.indexOf(":"), ואז slice לשני הצדדים.

💡 רמז 2

result[name] = name in result ? ${result[name]}, ${value} : value

✅ פתרון
// P14-E08
export function parseHeaders(lines) {
  const result = {};
  for (const line of lines) {
    const i = line.indexOf(":");
    if (i <= 0) throw new Error(`header לא תקין: ${line}`);
    const name = line.slice(0, i).trim().toLowerCase();
    const value = line.slice(i + 1).trim();
    result[name] = name in result ? `${result[name]}, ${value}` : value;
  }
  return result;
}

console.log(JSON.stringify(parseHeaders(["Content-Type: application/json", "Accept: text/html", "accept: application/json", "Authorization: Basic a:b"])));
{"content-type":"application/json","accept":"text/html, application/json","authorization":"Basic a:b"}
⚠️ טעויות נפוצות
  • line.split(":") — חותך את "Basic a:b" ומאבד חלק מהערך. אותו דבר בכל header עם כתובת (http://).

P14-E09 · בניית query string 🤖 רמה 2

💡 רמז 1

new URLSearchParams() ו־append(key, value) מקודדים בשבילך.

💡 רמז 2

const s = sp.toString(); return s ? "?" + s : "";

✅ פתרון
// P14-E09
export function buildQuery(params) {
  const sp = new URLSearchParams();
  for (const [key, value] of Object.entries(params)) {
    if (value === undefined || value === null) continue;
    for (const v of Array.isArray(value) ? value : [value]) sp.append(key, String(v));
  }
  const s = sp.toString();
  return s ? `?${s}` : "";
}

console.log(buildQuery({ page: 2, tag: ["a", "b"], q: "red & blue", skip: undefined }));
console.log(JSON.stringify(buildQuery({ skip: null })));
?page=2&tag=a&tag=b&q=red+%26+blue
""

שים לב ל־%26: בלי קידוד, q=red & blue היה נקרא כפרמטר q=red ועוד פרמטר בשם blue.

⚠️ טעויות נפוצות
  • לחבר מחרוזות ידנית (?q=${q}) — שובר ערכים עם &, = או #.

P14-E10 · מבקשה לפקודת curl 🤖 רמה 2

💡 רמז 1

const q = (s) => '${s.replaceAll("'", '\\'')}';

💡 רמז 2

בנה מערך חלקים ובסוף join(" ").

✅ פתרון
// P14-E10
const quote = (s) => `'${String(s).replaceAll("'", `'\\''`)}'`;

export function toCurl({ method = "GET", url, headers = {}, body }) {
  const parts = ["curl"];
  if (method !== "GET") parts.push("-X", method);
  parts.push(quote(url));
  const allHeaders = { ...headers };
  let data = body;
  if (body !== undefined && typeof body !== "string") {
    data = JSON.stringify(body);
    const hasType = Object.keys(headers).some((h) => h.toLowerCase() === "content-type");
    if (!hasType) allHeaders["Content-Type"] = "application/json";
  }
  for (const [name, value] of Object.entries(allHeaders)) parts.push("-H", quote(`${name}: ${value}`));
  if (data !== undefined) parts.push("-d", quote(data));
  return parts.join(" ");
}

console.log(toCurl({ url: "http://localhost:4000/products" }));
console.log(toCurl({ method: "POST", url: "http://localhost:4000/products", body: { name: "it's", price: 5 } }));
curl 'http://localhost:4000/products'
curl -X POST 'http://localhost:4000/products' -H 'Content-Type: application/json' -d '{"name":"it'\''s","price":5}'

נסה להריץ את השורה השנייה מול שרת ההדגמה — היא עובדת, גם עם הגרש.

⚠️ טעויות נפוצות
  • מירכאות כפולות סביב ה־JSON — ה־shell "אוכל" את המירכאות שבתוכו.

P14-E11 · השרת הראשון שלך 🤖 רמה 2

💡 רמז 1

פונקציית עזר send(res, status, body, headers) חוסכת חזרות.

💡 רמז 2

new URL(req.url, "http://localhost").pathname

✅ פתרון
// P14-E11
import http from "node:http";

function send(res, status, body, headers = {}) {
  res.writeHead(status, { "Content-Type": "application/json; charset=utf-8", ...headers });
  res.end(JSON.stringify(body));
}

const routes = {
  "/": () => ({ message: "שלום" }),
  "/time": () => ({ now: new Date().toISOString() }),
};

export function createHelloServer() {
  return http.createServer((req, res) => {
    const { pathname } = new URL(req.url, "http://localhost");
    const route = routes[pathname];
    if (!route) return send(res, 404, { error: "לא נמצא" });
    if (req.method !== "GET") return send(res, 405, { error: "Method Not Allowed" }, { Allow: "GET" });
    send(res, 200, route());
  });
}

מבנה "טבלת routes" (אובייקט של path ← פונקציה) קורא הרבה יותר טוב משרשרת if־ים, וזה בדיוק מה ש־Express עושה בשבילך.

⚠️ טעויות נפוצות
  • להשוות req.url === "/" — /?x=1 יחזיר 404.
  • לשכוח return אחרי send ← שתי תשובות לאותה בקשה, ושגיאה ERR_HTTP_HEADERS_SENT.

export async function getJson(url, { timeoutMs = 3000 } = {}) {

P14-E13 · לפרק בקשה גולמית 🤖 רמה 3

💡 רמז 1

קודם raw.replaceAll("\r\n", "\n"), ואז indexOf("\n\n") מפריד head מגוף.

💡 רמז 2

ה־path וה־query: new URL(target, "http://x").

✅ פתרון
// P14-E13
export function parseRequest(raw) {
  const text = raw.replaceAll("\r\n", "\n");
  const split = text.indexOf("\n\n");
  const head = split === -1 ? text : text.slice(0, split);
  const rawBody = split === -1 ? "" : text.slice(split + 2);
  const [requestLine, ...headerLines] = head.split("\n");

  const parts = requestLine.split(" ");
  if (parts.length !== 3) throw new Error("שורת בקשה לא תקינה");
  const [method, target] = parts;
  const url = new URL(target, "http://x");

  const headers = {};
  for (const line of headerLines) {
    const i = line.indexOf(":");
    headers[line.slice(0, i).trim().toLowerCase()] = line.slice(i + 1).trim();
  }

  let body;
  if (rawBody !== "") {
    body = headers["content-type"]?.includes("json") ? JSON.parse(rawBody) : rawBody;
  }
  return { method, path: url.pathname, query: Object.fromEntries(url.searchParams), headers, body };
}

const raw = "PATCH /orders/17?notify=false HTTP/1.1\r\nHost: api.shop.co.il\r\nContent-Type: application/json\r\n\r\n{\"status\":\"shipped\"}";
console.log(JSON.stringify(parseRequest(raw)));
{"method":"PATCH","path":"/orders/17","query":{"notify":"false"},"headers":{"host":"api.shop.co.il","content-type":"application/json"},"body":{"status":"shipped"}}

זה (בגרסה פשוטה מאוד) מה ש־node:http עושה לפני שהוא קורא ל־handler שלך — ומה ש־Express מוסיף מעליו (req.query, req.body).

⚠️ טעויות נפוצות
  • לפצל את כל הטקסט לפי \n ולחפש שורה ריקה — גוף JSON מרובה שורות יישבר.

P14-E14 · לבנות תשובה גולמית 🤖 רמה 3

💡 רמז 1

Buffer.byteLength("שלום") הוא 8, לא 4 — כל אות עברית היא 2 בתים ב־UTF-8.

💡 רמז 2

בנה מערך שורות ו־join("\r\n").

✅ פתרון
// P14-E14
export const STATUS_TEXT = {
  200: "OK", 201: "Created", 204: "No Content", 400: "Bad Request", 401: "Unauthorized",
  403: "Forbidden", 404: "Not Found", 409: "Conflict", 500: "Internal Server Error",
};

export function buildResponse(status, body, headers = {}) {
  const text = STATUS_TEXT[status];
  if (!text) throw new Error(`status לא מוכר: ${status}`);
  if (status === 204 && body !== undefined) throw new Error("204 לא יכול להכיל גוף");

  const all = { ...headers };
  let payload = "";
  if (body !== undefined) {
    payload = typeof body === "string" ? body : JSON.stringify(body);
    const hasType = Object.keys(headers).some((h) => h.toLowerCase() === "content-type");
    if (typeof body !== "string" && !hasType) all["Content-Type"] = "application/json; charset=utf-8";
    all["Content-Length"] = Buffer.byteLength(payload);
  }
  const lines = [`HTTP/1.1 ${status} ${text}`, ...Object.entries(all).map(([k, v]) => `${k}: ${v}`)];
  return lines.join("\r\n") + "\r\n\r\n" + payload;
}

console.log(buildResponse(201, { id: 3, name: "מסך" }, { Location: "/products/3" }));
HTTP/1.1 201 Created
Location: /products/3
Content-Type: application/json; charset=utf-8
Content-Length: 24

{"id":3,"name":"מסך"}
⚠️ טעויות נפוצות
  • payload.length — סופר תווים, לא בתים. עם עברית הלקוח יחתוך את הגוף באמצע.

// P14-E15
function substitute(s, vars) {
  return s.replace(/\{\{(\w+)\}\}/g, (_, name) => {
    if (!(name in vars)) throw new Error(`משתנה לא מוגדר: ${name}`);
    return vars[name];
  });
}

export function parseHttpFile(text) {
  const vars = {};
  const blocks = [];
  let current = null;
  for (const line of text.replaceAll("\r\n", "\n").split("\n")) {
    if (line.startsWith("###")) {
      current = { name: line.slice(3).trim(), lines: [] };
      blocks.push(current);
    } else if (current) {
      current.lines.push(line);
    } else {
      const m = line.match(/^@(\w+)\s*=\s*(.*)$/);
      if (m) vars[m[1]] = m[2].trim();
    }
  }

  const requests = [];
  for (const { name, lines } of blocks) {
    let i = 0;
    const isSkippable = (l) => l.trim() === "" || l.startsWith("#") || l.startsWith("//");
    while (i < lines.length && isSkippable(lines[i])) i++;
    if (i === lines.length) continue;
    const [method, url] = lines[i].trim().split(/\s+/);
    i++;
    const headers = {};
    for (; i < lines.length && lines[i].trim() !== ""; i++) {
      const c = lines[i].indexOf(":");
      headers[lines[i].slice(0, c).trim()] = substitute(lines[i].slice(c + 1).trim(), vars);
    }
    const body = lines.slice(i).join("\n").trim();
    requests.push({ name, method, url: substitute(url, vars), headers, body: body === "" ? undefined : substitute(body, vars) });
  }
  return requests;
}

const segments = (p) => p.split("/").filter(Boolean);

function matchParts(pattern, parts) {
  if (pattern.length !== parts.length) return null;
  const params = {};
  for (let i = 0; i < pattern.length; i++) {
    if (pattern[i].startsWith(":")) params[pattern[i].slice(1)] = decodeURIComponent(parts[i]);
    else if (pattern[i] !== parts[i]) return null;
  }
  return params;

export function createRouter() {
  const routes = [];
  return {
    add(method, pattern, handler) {
      routes.push({ method, pattern: segments(pattern), handler });
    },
    match(method, path) {
      const parts = segments(path);
      const allow = [];
      for (const route of routes) {
        const params = matchParts(route.pattern, parts);
        if (!params) continue;
        if (route.method === method) return { status: 200, handler: route.handler, params };
        allow.push(route.method);
      }
      return allow.length > 0 ? { status: 405, allow } : { status: 404 };
    },
  };
}

export async function readJsonBody(req, { limit = 1_000_000 } = {}) {
  if (!req.headers["content-type"]?.includes("application/json")) {
    throw new HttpError(415, "Content-Type חייב להיות application/json");
  }
  const chunks = [];
  let size = 0;
  for await (const chunk of req) {
    const buf = Buffer.from(chunk);
    size += buf.length;
    if (size > limit) throw new HttpError(413, "הגוף גדול מדי");
    chunks.push(buf);
  }
  const text = Buffer.concat(chunks).toString("utf8");
  if (text.trim() === "") throw new HttpError(400, "גוף ריק");
  try {
    return JSON.parse(text);
  } catch {
    throw new HttpError(400, "JSON לא תקין");
  }
}

function validateNote(body, { partial }) {
  if (typeof body !== "object" || body === null || Array.isArray(body)) return "הגוף חייב להיות אובייקט";
  if (partial && body.text === undefined && body.done === undefined) return "צריך text או done";
  if ((!partial || body.text !== undefined) && (typeof body.text !== "string" || body.text.trim().length < 1 || body.text.trim().length > 200)) {
    return "text: מחרוזת של 1–200 תווים";
  }
  if (body.done !== undefined && typeof body.done !== "boolean") return "done: true או false";
  return null;
}

  let nextId = 1;

    const parts = new URL(req.url, "http://localhost").pathname.split("/").filter(Boolean);
    try {
      if (parts[0] !== "notes" || parts.length > 2) return send(res, 404, { error: "לא נמצא" });

      if (parts.length === 1) {
        if (req.method === "GET") return send(res, 200, notes);
        if (req.method === "POST") {
          const body = await readJson(req);
          const error = validateNote(body, { partial: false });
          if (error) return send(res, 400, { error });
          const note = { id: nextId++, text: body.text.trim(), done: false };
          notes.push(note);
          return send(res, 201, note, { Location: `/notes/${note.id}` });
        }
        return send(res, 405, { error: "Method Not Allowed" }, { Allow: "GET, POST" });

      if (!["GET", "PATCH", "DELETE"].includes(req.method)) {

      if (req.method === "GET") return send(res, 200, note);

const RETRYABLE = new Set([408, 429, 500, 502, 503, 504]);
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

export async function fetchWithRetry(url, init = {}, { retries = 2, delayMs = 200 } = {}) {
  let lastError;
  let lastResponse;
  for (let attempt = 0; attempt <= retries; attempt++) {
    if (attempt > 0) await sleep(delayMs * 2 ** (attempt - 1));
    try {
      lastResponse = await fetch(url, init);
      lastError = undefined;
      if (!RETRYABLE.has(lastResponse.status)) return lastResponse;
    } catch (err) {
      lastError = err;
      lastResponse = undefined;
    }
  }
  if (lastError) throw lastError;
  return lastResponse;
}

// P14-E24
import fs from "node:fs";
import http from "node:http";

const segments = (p) => p.split("/").filter(Boolean);

function matchParts(pattern, parts) {
  if (pattern.length !== parts.length) return null;
  const params = {};
  for (let i = 0; i < pattern.length; i++) {
    if (pattern[i].startsWith(":")) params[pattern[i].slice(1)] = decodeURIComponent(parts[i]);
    else if (pattern[i] !== parts[i]) return null;
  }
  return params;
}

async function readBody(req) {
  if (!req.headers["content-type"]?.includes("application/json")) return undefined;
  const chunks = [];
  for await (const chunk of req) chunks.push(Buffer.from(chunk));
  const text = Buffer.concat(chunks).toString("utf8");
  if (text === "") return undefined;
  try {
    return JSON.parse(text);
  } catch {
    throw Object.assign(new Error("JSON לא תקין"), { status: 400 });
  }
}

function enhance(res) {
  res.status = (code) => {
    res.statusCode = code;
    return res;
  };
  res.json = (body) => {
    if (res.statusCode === 204) return res.end();
    res.setHeader("Content-Type", "application/json; charset=utf-8");
    res.end(JSON.stringify(body));
  };
}

export function createApp() {
  const middleware = [];
  const routes = [];

  async function route(req, res) {
    const parts = segments(req.path);
    const allow = [];
    for (const r of routes) {
      const params = matchParts(r.pattern, parts);
      if (!params) continue;
      if (r.method !== req.method) {
        allow.push(r.method);
        continue;
      }
      req.params = params;
      return r.handler(req, res);
    }
    if (allow.length > 0) {
      res.setHeader("Allow", allow.join(", "));
      return res.status(405).json({ error: "Method Not Allowed" });
    }
    res.status(404).json({ error: "לא נמצא" });
  }

  async function handle(req, res) {
    enhance(res);
    try {
      const url = new URL(req.url, "http://localhost");
      req.path = url.pathname;
      req.query = Object.fromEntries(url.searchParams);
      req.params = {};
      req.body = await readBody(req);
      let i = 0;
      const next = async () => {
        const fn = middleware[i++];
        if (fn) await fn(req, res, next);
        else await route(req, res);
      };
      await next();
    } catch (err) {
      if (res.headersSent) return res.end();
      if (err.status) return res.status(err.status).json({ error: err.message });
      console.error(err);
      res.status(500).json({ error: "שגיאה פנימית" });
    }
  }

  const app = {
    use(fn) {
      middleware.push(fn);
    },
    listen(port, cb) {
      return http.createServer(handle).listen(port, cb);
    },
  };
  for (const method of ["get", "post", "put", "patch", "delete"]) {
    app[method] = (pattern, handler) => routes.push({ method: method.toUpperCase(), pattern: segments(pattern), handler });
  }
  return app;
}

P14-E25 · אתגר: הגבלת קצב (rate limit) 🤖 רמה 5

💡 רמז 1

Map מלקוח ל־{ start, count }.

💡 רמז 2

חלון נגמר כש־now() - start >= windowMs. Retry-After: Math.ceil((start + windowMs - now()) / 1000).

✅ פתרון
// P14-E25
import http from "node:http";

export function createLimitedServer({ limit, windowMs, now = Date.now }) {
  const windows = new Map();

  return http.createServer((req, res) => {
    const client = req.headers["x-client-id"] ?? "anonymous";
    const t = now();
    let w = windows.get(client);
    if (!w || t - w.start >= windowMs) {
      w = { start: t, count: 0 };
      windows.set(client, w);
    }
    w.count++;

    const headers = { "Content-Type": "application/json; charset=utf-8" };
    if (w.count > limit) {
      headers["Retry-After"] = String(Math.ceil((w.start + windowMs - t) / 1000));
      headers["X-RateLimit-Remaining"] = "0";
      res.writeHead(429, headers);
      return res.end(JSON.stringify({ error: "יותר מדי בקשות" }));
    }
    headers["X-RateLimit-Remaining"] = String(limit - w.count);
    res.writeHead(200, headers);
    res.end(JSON.stringify({ ok: true }));
  });
}

שתי חולשות לחשוב עליהן: (1) ה־Map גדל לנצח — לקוחות ישנים לא נמחקים (פתרון: ניקוי תקופתי, או Redis עם תפוגה — פרק 26); (2) עם שני עותקים של השרת, לכל אחד מונה משלו, והלקוח מקבל פי 2. גם את זה פותר Redis. ומזהה שהלקוח שולח בעצמו אפשר לזייף — בפועל מגבילים לפי IP או לפי משתמש מחובר.

⚠️ טעויות נפוצות
  • Retry-After במילישניות — התקן מגדיר שניות.
