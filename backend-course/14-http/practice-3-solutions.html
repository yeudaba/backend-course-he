P14-E58 · איזה דגל של curl? 🧠 הבנה רמה 1

💡 רמז 1

הטבלה בסעיף 1 של השיעור. ‏-v מסמן את הבקשה ב־>.

💡 רמז 2

חפש בשורות > header שלא כתבת בעצמך.

✅ פתרון
  1. -i
  2. -v
  3. -X DELETE
  4. -H "Authorization: Bearer ..."
  5. -d '{"...":...}' יחד עם -H "Content-Type: application/json"
  6. -s

עם -d ובלי -X, ‏curl שולח POST — וזה נראה בשורה > POST. הוא גם מוסיף לבד Content-Type: application/x-www-form-urlencoded (הפורמט של טופס HTML). השרת מצפה ל־JSON ולכן עונה 415. עוד פרט: Content-Length: 29 — בתים, לא תווים (P14-E48).

⚠️ טעויות נפוצות
  • לחשוב שבלי -H לא נשלח Content-Type בכלל — curl שולח ברירת מחדל, והיא לא JSON.

P14-E59 · לקרוא פלט של curl -v 🧠 הבנה רמה 1

💡 רמז 1

חץ ימינה — יוצא מ־curl; חץ שמאלה — נכנס.

💡 רמז 2

השורה הריקה — זו שבטבלת "חלק / בבקשה / בתשובה" כתוב עליה "חובה".

✅ פתרון
  1. * — הודעות של curl עצמו (חיבור, DNS). ‏> — מה שנשלח. ‏< — מה שהתקבל.
  2. Host (חובה ב־HTTP/1.1 — אותו שרת יכול לארח כמה אתרים), ‏User-Agent (מי הלקוח) ו־Accept: */* — "אני מקבל כל פורמט".
  3. השורה הריקה שמפרידה בין ה־headers לגוף. לבקשה אין גוף, ולכן אחריה אין כלום.
  4. DNS — תרגום השם לכתובת (כאן 127.0.0.1, המחשב שלך).
  5. curl מדפיס את הגוף כמו שהוא, בלי סימון — זו השורה האחרונה.
⚠️ טעויות נפוצות
  • לחפש את ה־headers שהשרת קיבל בשורות < — אלה headers של התשובה.

P14-E60 · מירכאות ב־Terminal 🧠 הבנה רמה 2

ה־shell (Terminal) קורא את השורה לפני curl. מירכאה כפולה פותחת קטע, והמירכאה הכפולה הבאה — סוגרת אותו.

💡 רמז 2

P14-E61 · מה לא יעבוד בקובץ ה־.http? 🧠 הבנה רמה 1

💡 רמז 1

שמות משתנים, שורה ריקה, ו"מה מפריד בין בקשות".

💡 רמז 2

בקובץ השיעור — מה בא אחרי המילה Authorization:?

✅ פתרון
  1. {{baseUrl}} — המשתנה נקרא base. REST Client לא ימצא אותו, והכתובת לא תהיה תקינה.
  2. אין שורה ריקה בין Content-Type לגוף — ה־JSON ייקרא כעוד headers, והבקשה תצא בלי גוף (או לא תצא בכלל).
  3. אין ### לפני GET {{base}}/products/1 — היא נחשבת חלק מהגוף של ה־POST, ולא בקשה משלה.
  4. Authorization: let-me-in — חסר Bearer. השרת מצפה ל־Bearer let-me-in ויחזיר 401.
⚠️ טעויות נפוצות
  • לחשוב שה־### הוא "רק הערה" — הוא המפריד בין בקשות.

P14-E62 · איפה ב־DevTools? 🧠 הבנה רמה 1

💡 רמז 1

ב־Headers יש שלושה חלקים: General (כתובת, method, status), Response Headers, Request Headers.

💡 רמז 2

ב־Timing, השלב "Waiting for server response" הוא הזמן שהשרת עבד.

✅ פתרון
  1. רשימת הבקשות — אם לא הופיעה שורה חדשה בלחיצה, הבאג בצד הלקוח (הקוד לא שלח).
  2. Headers ← General: Request URL, Request Method.
  3. Headers ← General: Status Code (מופיע גם ברשימה).
  4. Headers ← Request Headers.
  5. Response (או Preview — JSON מעוצב).
  6. Timing: אם רוב הזמן ב־"Waiting for server response" — השרת איטי (אולי שאילתה איטית, פרק 18).

ההחלטה: אם הבקשה יצאה נכון (כתובת, method, headers, גוף) והשרת החזיר שגיאה או גוף שגוי — הבאג אצלך. אם הבקשה עצמה שגויה, או לא נשלחה — אצלו. אם הכול נכון ובכל זאת "לא עובד" — הלקוח לא קורא נכון את התשובה.

⚠️ טעויות נפוצות
  • להתחיל לחפש בקוד של השרת לפני שבדקת אם הבקשה בכלל הגיעה ומה היה בה.

// P14-E10
const quote = (s) => `'${String(s).replaceAll("'", `'\\''`)}'`;

export function toCurl({ method = "GET", url, headers = {}, body }) {
  const parts = ["curl"];
  if (method !== "GET") parts.push("-X", method);
  parts.push(quote(url));
  const allHeaders = { ...headers };
  let data = body;
  if (body !== undefined && typeof body !== "string") {
    data = JSON.stringify(body);
    const hasType = Object.keys(headers).some((h) => h.toLowerCase() === "content-type");
    if (!hasType) allHeaders["Content-Type"] = "application/json";
  }
  for (const [name, value] of Object.entries(allHeaders)) parts.push("-H", quote(`${name}: ${value}`));
  if (data !== undefined) parts.push("-d", quote(data));
  return parts.join(" ");
}

// P14-E15
function substitute(s, vars) {
  return s.replace(/\{\{(\w+)\}\}/g, (_, name) => {
    if (!(name in vars)) throw new Error(`משתנה לא מוגדר: ${name}`);
    return vars[name];
  });
}

export function parseHttpFile(text) {
  const vars = {};
  const blocks = [];
  let current = null;
  for (const line of text.replaceAll("\r\n", "\n").split("\n")) {
    if (line.startsWith("###")) {
      current = { name: line.slice(3).trim(), lines: [] };
      blocks.push(current);
    } else if (current) {
      current.lines.push(line);
    } else {
      const m = line.match(/^@(\w+)\s*=\s*(.*)$/);
      if (m) vars[m[1]] = m[2].trim();
    }
  }

  const requests = [];
  for (const { name, lines } of blocks) {
    let i = 0;
    const isSkippable = (l) => l.trim() === "" || l.startsWith("#") || l.startsWith("//");
    while (i < lines.length && isSkippable(lines[i])) i++;
    if (i === lines.length) continue;
    const [method, url] = lines[i].trim().split(/\s+/);
    i++;
    const headers = {};
    for (; i < lines.length && lines[i].trim() !== ""; i++) {
      const c = lines[i].indexOf(":");
      headers[lines[i].slice(0, c).trim()] = substitute(lines[i].slice(c + 1).trim(), vars);
    }
    const body = lines.slice(i).join("\n").trim();
    requests.push({ name, method, url: substitute(url, vars), headers, body: body === "" ? undefined : substitute(body, vars) });
  }
  return requests;
}

P14-E63 · מפקודת curl לבקשה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

לולאה עם אינדקס: for (let i = 0; i < args.length; i++). דגל עם ערך לוקח את args[++i].

💡 רמז 2

switch (arg) עם case "-X": case "--request": — שני שמות לאותו דגל.

✅ פתרון
// P14-E63: מפקודת curl לבקשה
export function parseCurlArgs(args) {
  let method;
  let url;
  let body;
  const headers = {};
  for (let i = 0; i < args.length; i++) {
    const arg = args[i];
    switch (arg) {
      case "-X":
      case "--request":
        method = args[++i].toUpperCase();
        break;
      case "-H":
      case "--header": {
        const h = args[++i];
        const colon = h.indexOf(":");
        headers[h.slice(0, colon).trim()] = h.slice(colon + 1).trim();
        break;
      }
      case "-d":
      case "--data":
        body = args[++i];
        break;
      case "-i":
      case "-v":
      case "-s":
        break;
      default:
        if (arg.startsWith("-")) throw new Error(`דגל לא מוכר: ${arg}`);
        url = arg;
    }
  }
  if (url === undefined) throw new Error("חסרה כתובת");
  return { method: method ?? (body === undefined ? "GET" : "POST"), url, headers, body };
}

P14-E64 · לפרק שורת פקודה עם מירכאות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

עוברים תו־תו עם מצב: let quote = null (או "'", או '"'), ‏let current = "", ו־let started = false — כדי ש־'' ייצור ארגומנט ריק.

בסוף כל מילה: if (started) { args.push(current); current = ""; started = false; }

💡 רמז 2

בתוך ": אם התו הוא \ והבא הוא " או \ — מוסיפים את הבא ומדלגים (i++).

✅ פתרון
// P14-E64: לפרק שורת פקודה עם מירכאות
export function splitArgs(cmd) {
  const args = [];
  let current = "";
  let started = false;
  let quote = null;
  const finish = () => {
    if (started) args.push(current);
    current = "";
    started = false;
  };
  for (let i = 0; i < cmd.length; i++) {
    const ch = cmd[i];
    if (quote === "'") {
      if (ch === "'") quote = null;
      else current += ch;
    } else if (quote === '"') {
      if (ch === "\\" && (cmd[i + 1] === '"' || cmd[i + 1] === "\\")) current += cmd[++i];
      else if (ch === '"') quote = null;
      else current += ch;
    } else if (ch === "'" || ch === '"') {
      quote = ch;
      started = true;
    } else if (ch === "\\" && cmd[i + 1] === "\n") {
      i++;
      finish();
    } else if (ch === " " || ch === "\n" || ch === "\t") {
      finish();
    } else {
      current += ch;
      started = true;
    }
  }
  if (quote) throw new Error("מירכאה לא נסגרה");
  finish();
  return args;
}

P14-E65 · לפרק פלט של curl -v 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שלב 1: text.split(/\r?\n/), ושני מערכים — שורות שמתחילות ב־"> " ושורות שמתחילות ב־"< ", בלי שני התווים הראשונים.

💡 רמז 2

פונקציית עזר אחת לשני הצדדים: headersOf(lines) שמדלגת על השורה הראשונה ועל שורות ריקות.

✅ פתרון
// P14-E65: לפרק פלט של curl -v
function headersOf(lines) {
  const headers = {};
  for (const line of lines.slice(1)) {
    const i = line.indexOf(":");
    if (line.trim() === "" || i === -1) continue;
    headers[line.slice(0, i).trim().toLowerCase()] = line.slice(i + 1).trim();
  }
  return headers;
}

export function parseVerbose(text) {
  const lines = text.split(/\r?\n/);
  const sent = lines.filter((l) => l.startsWith("> ") || l === ">").map((l) => l.slice(2));
  const got = lines.filter((l) => l.startsWith("< ") || l === "<").map((l) => l.slice(2));
  let request = null;
  let response = null;
  if (sent.length) {
    const [method, path] = sent[0].split(" ");
    request = { method, path, headers: headersOf(sent) };
  }
  if (got.length) {
    response = { status: Number(got[0].split(" ")[1]), headers: headersOf(got) };
  }
  return { request, response };
}

💡 רמז 2

// P14-E66: מבקשות לקובץ .http
export function toHttpFile(requests) {
  const origins = new Set(requests.map((r) => new URL(r.url).origin));
  const base = requests.length >= 2 && origins.size === 1 ? [...origins][0] : null;
  const lines = [];
  if (base) lines.push(`@base = ${base}`, "");
  requests.forEach((r, i) => {
    if (i > 0) lines.push("");
    const url = base && r.url.startsWith(base) ? "{{base}}" + r.url.slice(base.length) : r.url;
    lines.push(`### ${r.name}`, `${r.method} ${url}`);
    for (const [name, value] of Object.entries(r.headers ?? {})) lines.push(`${name}: ${value}`);
    if (r.body !== undefined) {
      lines.push("", typeof r.body === "string" ? r.body : JSON.stringify(r.body, null, 2));
    }
  });
  return lines.join("\n") + "\n";
}

export function networkSummary(entries) {
  let best = null;
  const byHost = {};
  for (const e of entries) {
    if (!best || e.ms > best.ms) best = e;
    const host = new URL(e.url).host;
    byHost[host] = (byHost[host] ?? 0) + 1;
  }
  return {
    count: entries.length,
    bytes: entries.reduce((sum, e) => sum + e.size, 0),
    failed: entries.filter((e) => e.status === 0 || e.status >= 400).length,
    json: entries.filter((e) => (e.contentType ?? "").toLowerCase().includes("json")).length,
    slowest: best ? best.url : null,
    byHost,
  };
}

P14-E68 · בודק לקובצי .http 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שני מעברים: הראשון אוסף את שמות המשתנים (/^@(\w+)\s*=/). השני עובר שורה־שורה עם "מצב": "before" (מחכים לשורת בקשה), "headers", "body".

💡 רמז 2

אזהרת "גוף בלי Content-Type" נכתבת כשהבקשה נגמרת (ב־### הבא או בסוף הקובץ) — אבל צריכה להופיע במקום של שורת הבקשה. אסוף אזהרות כ־{ line, text }, ובסוף מיין לפי line.

✅ פתרון
// P14-E68: בודק לקובצי .http
export function lintHttpFile(text) {
  const lines = text.split(/\r?\n/);
  const defined = new Set();
  for (const line of lines) {
    const m = line.match(/^@(\w+)\s*=/);
    if (m) defined.add(m[1]);
  }
  const warnings = [];
  const warn = (line, text) => warnings.push({ line, text });
  let state = "before";
  let req = null;
  const endRequest = () => {
    if (req && req.hasBody && !req.hasType) warn(req.line, "יש גוף בלי Content-Type");
    req = null;
  };
  lines.forEach((line, i) => {
    const n = i + 1;
    for (const m of line.matchAll(/\{\{(\w+)\}\}/g)) {
      if (!defined.has(m[1])) warn(n, `המשתנה ${m[1]} לא הוגדר`);
    }
    if (line.startsWith("###")) {
      endRequest();
      state = "before";
      return;
    }
    const isComment = line.startsWith("#") || line.startsWith("//");
    if (state === "before") {
      if (line.trim() === "" || isComment || line.startsWith("@")) return;
      req = { line: n, hasBody: false, hasType: false };
      state = "headers";
    } else if (state === "headers") {
      if (line.trim() === "") state = "body";
      else if (isComment) return;
      else if (!/^[^\s:]+:\s*\S/.test(line)) warn(n, "header לא תקין");
      else if (line.split(":")[0].toLowerCase() === "content-type") req.hasType = true;
    } else if (line.trim() !== "") {
      req.hasBody = true;
    }
  });
  endRequest();
  return warnings.sort((a, b) => a.line - b.line).map((w) => `שורה ${w.line}: ${w.text}`);
}

// P14-E72: להסתיר סודות בפקודת curl
const SECRET_PARAMS = new Set(["token", "key", "apikey", "password", "secret"]);

function redactHeader(header) {
  const colon = header.indexOf(":");
  if (colon === -1) return header;
  const name = header.slice(0, colon);
  const value = header.slice(colon + 1).trim();
  switch (name.trim().toLowerCase()) {
    case "authorization": {
      const space = value.indexOf(" ");
      return `${name}: ${space === -1 ? "***" : value.slice(0, space) + " ***"}`;
    }
    case "cookie":
      return `${name}: ${value
        .split(";")
        .filter((pair) => pair.trim() !== "")
        .map((pair) => pair.trim().split("=")[0] + "=***")
        .join("; ")}`;
    default:
      return header;
  }
}

function redactUrl(text) {
  const u = new URL(text);
  for (const key of [...u.searchParams.keys()]) {
    if (SECRET_PARAMS.has(key.toLowerCase())) u.searchParams.set(key, "***");
  }
  return u.href;
}

export function redactCurl(args) {
  return args.map((arg, i) => {
    if (args[i - 1] === "-H" || args[i - 1] === "--header") return redactHeader(arg);
    if (arg.startsWith("http://") || arg.startsWith("https://")) return redactUrl(arg);
    return arg;
  });
}

// P14-E73: סיכום קובצי .http בתיקייה
import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";

export async function summarizeHttpDir(dir) {
  let names;
  try {
    names = await fs.readdir(dir);
  } catch (err) {
    if (err.code === "ENOENT") throw new Error(`התיקייה לא קיימת: ${dir}`);
    throw err;
  }
  const files = names.filter((n) => n.endsWith(".http")).sort();
  return Promise.all(
    files.map(async (file) => {
      const text = await fs.readFile(path.join(dir, file), "utf8");
      const methods = {};
      let requests = 0;
      for (const line of text.split(/\r?\n/)) {
        const m = line.match(/^(GET|POST|PUT|PATCH|DELETE) /);
        if (!m) continue;
        requests++;
        methods[m[1]] = (methods[m[1]] ?? 0) + 1;
      }
      return { file, requests, methods };
    }),
  );
}

קודם filter ו־sort (על [...entries]), ואז מעבר אחד עם Set של מפתחות ${method} ${url} — הראשון שנראה הוא המוקדם.

💡 רמז 2

אפשר להניח שאין ' בכתובות וב־headers (ראית ב־P14-E69 מה עושים אם יש).

✅ פתרון
// P14-E74: ממה שנכשל ב־Network — לפקודות curl
export function failedAsCurl(entries) {
  const failed = entries.filter((e) => e.status === 0 || e.status >= 400).sort((a, b) => a.startedAt - b.startedAt);
  const seen = new Set();
  const out = [];
  for (const e of failed) {
    const key = `${e.method} ${e.url}`;
    if (seen.has(key)) continue;
    seen.add(key);
    const parts = ["curl"];
    if (e.method !== "GET") parts.push("-X", e.method);
    parts.push(`'${e.url}'`);
    for (const [name, value] of Object.entries(e.headers ?? {})) {
      if (name.toLowerCase() !== "cookie") parts.push("-H", `'${name}: ${value}'`);
    }
    out.push(parts.join(" "));
  }
  return out;
}

הסדר בקוד חשוב: ממיינים לפני שמסננים כפילויות, ואז "הראשון שנראה" הוא המוקדם ביותר. ה־/api/me שנשמר הוא זה מ־startedAt: 20, בלי headers. ו־filter יוצר מערך חדש, כך ש־sort אחריו לא משנה את הקלט.

⚠️ טעויות נפוצות
  • entries.sort(...) ישירות — משנה את המערך של מי שקרא לפונקציה.
  • להעתיק את ה־Cookie — פקודה שמודבקת בצ'אט עם עוגיית session היא בעצם סיסמה (P14-E72).
