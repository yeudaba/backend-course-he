P28.5-E26 · הנפוצים ביותר בזרם, בזיכרון קבוע 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 30 דק׳ידע נדרש: שיעור 3

"אילו עשרה נתיבים הכי נפוצים היום?" על מיליארד בקשות, ‏Map של כל הנתיבים לא נכנס לזיכרון: יש מיליוני /products/<id> שונים. האלגוריתם Space-Saving עונה עם k מונים בלבד, ובערבות: כל פריט שמופיע יותר מ־N/k פעמים נמצא ברשימה. זה אותו רעיון כמו HyperLogLog (‏E18) ו־reservoir sampling (‏E19): לוותר על דיוק מלא תמורת זיכרון קבוע. כתוב מקובץ ריק וייצא class TopK<T>:

  • constructor(k) — ‏k שאינו שלם חיובי ← RangeError.
  • add(item):
    • יש לו מונה ← count++.
    • אין, ויש פחות מ־k מונים ← מונה חדש: count: 1, error: 0.
    • אין, והזיכרון מלא ← מוחקים את המונה עם ה־count הקטן ביותר (נקרא לו min). החדש מקבל count: min + 1 ו־error: min: אולי הוא הופיע קודם, ונספר אצל מי שנמחק.
  • getter seen — כמה פריטים נכנסו בסך הכול.
  • top(n = k) ← [{ item, count, error }], מה־count הגבוה לנמוך, ובתיקו לפי String(item).
  • שדות פרטיים.

הבודק מריץ זרם של 60,000 פריטים ובודק את הערבויות: הכבדים נמצאים, ולכל פריט ברשימה count - error <= אמיתי <= count.
