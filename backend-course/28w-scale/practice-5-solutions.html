P28.5-E83 · ‏ETL או ELT? 🧠 הבנה רמה 1

💡 רמז 1

הסדר באותיות הוא הסדר בצינור.

💡 רמז 2

מה אם הגדרת "הזמנה פעילה" משתנה?

✅ פתרון
  1. ETL — מעבדים בדרך (מסננים, מחברים, מסכמים) וטוענים את התוצאה. ELT — טוענים את הגולמי כמו שהוא, ומעבדים בתוך המחסן עם SQL.
  2. ELT (בדרך כלל עם dbt לטבלאות המסוכמות).
  3. אפשר לחשב מחדש: "כמה הזמנות בוטלו תוך שעה מהיצירה" — אם שמרנו רק סיכום יומי, המידע אבד. עם הגולמי — שאילתה חדשה.
  4. כשאסור שמשהו יגיע למחסן: מידע אישי (מחיקה/hash של מייל — E80), סודות, או נפח שאין טעם לשמור (לוגים של debug).
⚠️ טעויות נפוצות
  • לסכם "כדי לחסוך מקום" — אחסון זול; החלטה שאי אפשר לשחזר — יקרה.

P28.5-E84 · ה־watermark שדילג 🧠 הבנה רמה 1

💡 רמז 1

‏now() ב־PostgreSQL הוא זמן תחילת הטרנזקציה.

💡 רמז 2

העמוד הראשון נחתך באמצע קבוצה עם אותו ערך.

✅ פתרון
  1. זהה לכולן — אותה טרנזקציה.
  2. הראשון מקבל 1,000 מתוכן; ה־watermark = ‏10:00:00.000. השני מבקש > 10:00:00.000 — ומדלג על כל 500 הנותרות.
  3. 500 — לתמיד (הן לא ישתנו שוב).
  4. מפתח מורכב: ‏WHERE (updated_at, id) > ($1, $2) ORDER BY updated_at, id, וה־watermark הוא הזוג. בתוך אותו זמן, ‏id קובע סדר מלא — אפשר להמשיך בדיוק מאיפה שנעצרנו.
⚠️ טעויות נפוצות
  • ‏>= במקום > — לא מדלג, אבל לולאה אינסופית אם יש יותר מ־1,000 שורות עם אותו זמן.

P28.5-E85 · מתי שומרים את ה־watermark? 🧠 הבנה רמה 1

💡 רמז 1

ה־watermark אומר "עד כאן כבר אצלי".

💡 רמז 2

"הגרסה האחרונה" בקריאה (‏QUALIFY).

✅ פתרון
  1. ה־watermark כבר מתקדם, אבל הנתונים לא נכתבו — העמוד הזה לא יגיע לעולם. אובדן שקט.
  2. קורא ← כותב ← ורק אז שומר. נפילה לפני השמירה ← הריצה הבאה קוראת שוב את אותו עמוד וכותבת אותו שוב.
  3. אובדן לא מורגש ולא ניתן לתיקון; כפילות — מתקנים בקריאה עם ה־QUALIFY מהשיעור (או E90). כמו at-least-once בתורים (יחידה 26.5).
  4. כתיבה ישירה שנקטעת משאירה קובץ חצי כתוב — וה־watermark לא קריא. ‏rename הוא אטומי: הקובץ הוא הישן או החדש, אף פעם לא חצי (‏E92).
⚠️ טעויות נפוצות
  • לשמור watermark "בסוף כל הריצה" אחרי 50 עמודים — נפילה באמצע מכפילה את כל הריצה; עדיף אחרי כל עמוד.

P28.5-E86 · הזמנה שנמחקה ממשיכה לחיות 🧠 הבנה רמה 1

💡 רמז 1

שורה שלא קיימת לא יכולה להופיע ב־SELECT.

💡 רמז 2

soft delete, ‏CDC, השוואה מלאה מדי פעם.

✅ פתרון
  1. הסנכרון רואה רק שורות שקיימות ושהשתנו. שורה מחוקה פשוט נעלמת מהמקור.
  2. את ההזמנה כאילו היא עדיין קיימת — לתמיד.
  3. (א) soft delete: ‏status = 'deleted' / ‏deleted_at, שמעדכן את updated_at — פשוט, אבל כל שאילתה באפליקציה צריכה לסנן. (ב) CDC (‏Debezium על ה־WAL) — רואה גם מחיקות, אבל עוד מערכת לתפעל. (ג) השוואה מלאה של מזהים פעם ביום — פשוט, ויקר כשהטבלה ענקית.
  4. soft delete — הזמנות ממילא לא אמורות להימחק (חשבונאות); "בוטלה" עדיף על "נעלמה".
⚠️ טעויות נפוצות
  • טבלת "audit" שה־trigger כותב אליה, בלי לבדוק שגם המחיקות עוברות — אותו פער במקום אחר.

P28.5-E88 · ‏cache לדשבורד: כמה זמן? 🧠 הבנה רמה 1

💡 רמז 1

הנתונים עצמם מתעדכנים רק כל 15 דקות.

💡 רמז 2

יום שעבר — "סגור" (כמעט).

✅ פתרון
  1. כמה דקות (‏1–5). TTL קצר מהסנכרון רק מוסיף שאילתות שמחזירות את אותה תשובה. (ואפשר לנקות את ה־cache כשסנכרון מסתיים.)
  2. ארוך — שעות או יום. הוא כמעט לא משתנה (חוץ מביטולים מאוחרים).
  3. מספר אחד מעותק אחד ומספר אחר מעותק אחר — "קופץ" בין ריענונים. פתרון: cache משותף ב־Redis (פרק 26), או להציג את זמן הנתונים.
  4. ‏asOf — זמן ה־watermark של הנתונים (לא זמן הבקשה), ו־X-Cache. בדשבורד: "מעודכן ל־10:45".
⚠️ טעויות נפוצות
  • להציג "עכשיו" כזמן העדכון — הנתונים הם של לפני 15 דקות, ולפעמים של לפני שעה אם הסנכרון נכשל.

P28.5-E24 · אתגר: API אנליטיקה תחת עומס 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

DuckDB בתוך התהליך: בעלייה — CREATE TABLE orders AS SELECT *, <day בישראל> AS day FROM read_parquet($1). מחשבים את היום פעם אחת, לא בכל שאילתה.

💡 רמז 2

פרמטרים ($1, $2) — לא שרשור של ה־query string ל־SQL. LRU פשוט: Map שומר סדר הכנסה; מחיקה והכנסה מחדש = "הכי חדש".

✅ פתרון
// P28.5-E24: API אנליטיקה מעל Parquet — DuckDB בתוך התהליך, cache, ו־p95 נמוך תחת עומס
import http from "node:http";
import { DuckDBInstance } from "@duckdb/node-api";

const DAY = /^\d{4}-\d{2}-\d{2}$/;
const isDay = (s: string | null): s is string => !!s && DAY.test(s) && !Number.isNaN(Date.parse(`${s}T00:00:00Z`)) && new Date(`${s}T00:00:00Z`).toISOString().startsWith(s);
const daysBetween = (a: string, b: string) => (Date.parse(`${b}T00:00:00Z`) - Date.parse(`${a}T00:00:00Z`)) / 86_400_000;

class TtlLru<V> {
  private map = new Map<string, { value: V; expires: number }>();
  private max: number;
  private ttlMs: number;
  private now: () => number;
  constructor(max: number, ttlMs: number, now: () => number) {
    this.max = max;
    this.ttlMs = ttlMs;
    this.now = now;
  }
  get(k: string): V | undefined {
    const e = this.map.get(k);
    if (!e) return undefined;
    if (e.expires <= this.now()) {
      this.map.delete(k);
      return undefined;
    }
    this.map.delete(k); // LRU: הכי חדש בסוף
    this.map.set(k, e);
    return e.value;
  }
  set(k: string, value: V) {
    this.map.delete(k);
    this.map.set(k, { value, expires: this.now() + this.ttlMs });
    if (this.map.size > this.max) this.map.delete(this.map.keys().next().value!);
  }
}

export async function createAnalyticsServer({ parquetPath, cacheTtlMs = 60_000, cacheSize = 100, now = Date.now }: { parquetPath: string; cacheTtlMs?: number; cacheSize?: number; now?: () => number }): Promise<http.Server> {
  const db = await DuckDBInstance.create(":memory:");
  const conn = await db.connect();
  // טוענים פעם אחת לזיכרון, עם עמודת יום מחושבת (שעון ישראל) — כל שאילתה אחר כך מהירה
  await conn.run(
    `CREATE TABLE orders AS SELECT *, strftime(timezone('Asia/Jerusalem', created_at), '%Y-%m-%d') AS day FROM read_parquet($1)`,
    [parquetPath],
  );
  const cache = new TtlLru<string>(cacheSize, cacheTtlMs, now);

  async function revenue(from: string, to: string) {
    const r = await conn.runAndReadAll(
      `SELECT day, count(*)::INTEGER AS orders, round(sum(quantity * price_cents) / 100.0, 2)::DOUBLE AS revenue
       FROM orders WHERE day BETWEEN $1 AND $2 GROUP BY day ORDER BY day`,
      [from, to],
    );
    const days = r.getRowObjects().map((x) => ({ day: String(x.day), orders: Number(x.orders), revenue: Number(x.revenue) }));
    const total = { orders: days.reduce((s, d) => s + d.orders, 0), revenue: Math.round(days.reduce((s, d) => s + d.revenue * 100, 0)) / 100 };
    return { from, to, days, total };
  }
  async function topProducts(day: string, limit: number) {
    const r = await conn.runAndReadAll(
      `SELECT product, sum(quantity)::INTEGER AS units, round(sum(quantity * price_cents) / 100.0, 2)::DOUBLE AS revenue
       FROM orders WHERE day = $1 GROUP BY product ORDER BY revenue DESC, product LIMIT $2`,
      [day, limit],
    );
    return r.getRowObjects().map((x) => ({ product: String(x.product), units: Number(x.units), revenue: Number(x.revenue) }));
  }

  const send = (res: http.ServerResponse, status: number, body: unknown, cacheState?: string) => {
    res.statusCode = status;
    res.setHeader("content-type", "application/json");
    if (cacheState) res.setHeader("x-cache", cacheState);
    res.end(typeof body === "string" ? body : JSON.stringify(body));
  };

  const server = http.createServer(async (req, res) => {
    const url = new URL(req.url ?? "/", "http://x");
    try {
      if (url.pathname === "/health") return send(res, 200, { ok: true });
      let key: string;
      let compute: () => Promise<unknown>;
      if (url.pathname === "/revenue") {
        const from = url.searchParams.get("from");
        const to = url.searchParams.get("to");
        if (!isDay(from) || !isDay(to)) return send(res, 400, { error: "from ו־to בפורמט YYYY-MM-DD" });
        if (daysBetween(from, to) < 0) return send(res, 400, { error: "from אחרי to" });
        if (daysBetween(from, to) > 92) return send(res, 400, { error: "עד 92 ימים" });
        key = `revenue:${from}:${to}`;
        compute = () => revenue(from, to);
      } else if (url.pathname === "/top-products") {
        const day = url.searchParams.get("day");
        const limit = Number(url.searchParams.get("limit") ?? 5);
        if (!isDay(day)) return send(res, 400, { error: "day בפורמט YYYY-MM-DD" });
        if (!Number.isInteger(limit) || limit < 1 || limit > 20) return send(res, 400, { error: "limit בין 1 ל־20" });
        key = `top:${day}:${limit}`;
        compute = () => topProducts(day, limit);
      } else return send(res, 404, { error: "not found" });

      const hit = cache.get(key);
      if (hit !== undefined) return send(res, 200, hit, "HIT");
      const body = JSON.stringify(await compute());
      cache.set(key, body);
      send(res, 200, body, "MISS");
    } catch {
      send(res, 500, { error: "internal" });
    }
  });
  server.on("close", () => {
    conn.closeSync();
    db.closeSync();
  });
  return server;
}

הארכיטקטורה הזו — Parquet (על S3) + DuckDB בתוך שירות — נפוצה יותר ויותר לדשבורדים פנימיים: בלי cluster של מחסן נתונים, ושאילתות של מילי־שניות על מיליוני שורות. כשהנתונים גדלים לטרה־בייטים — אותן שאילתות עוברות ל־BigQuery/Snowflake כמעט בלי שינוי.

⚠️ טעויות נפוצות
  • לשרשר את from ו־to לתוך ה־SQL. זה SQL injection; משתמשים בפרמטרים.
  • לחשב את היום בישראל בכל שאילתה. זה מאט מאוד; מחשבים אותו פעם אחת בעלייה, בטבלה.
  • cache לפי req.url כמו שהוא. ?to=…&from=… ו־?from=…&to=… הם אותה בקשה, ולכן המפתח בנוי מהפרמטרים אחרי אימות.
  • TTL לפי Date.now() במקום ה־now המוזרק. הבודק מזיז את השעון, וה־cache לא פג.

P28.5-E25 · אתגר: data lake מצטבר 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

watermark על (updated_at, id) ולא רק updated_at: עשרים שורות עם אותו updated_at בעמודים של 3 — WHERE (updated_at, id) > ($1, $2) ORDER BY updated_at, id. ו־updated_at::text שומר מיקרו־שניות, שה־Date של JavaScript מאבד.

כתיבה: טבלה זמנית ב־DuckDB, conn.createAppender, ו־COPY batch TO 'file' (FORMAT parquet).

💡 רמז 2

הגרסה האחרונה: QUALIFY row_number() OVER (PARTITION BY id ORDER BY updated_at DESC) = 1.

✅ פתרון
// P28.5-E25: סנכרון מצטבר מ־PostgreSQL ל־data lake (קובצי Parquet), ודוח שמתעלם מגרסאות ישנות
import fs from "node:fs/promises";
import path from "node:path";
import type { Pool } from "pg";
import type { DuckDBConnection } from "@duckdb/node-api";

interface State {
  seq: number;
  updatedAt: string | null; // ה־watermark: (updated_at, id) של השורה האחרונה שיוצאה
  id: number;
}

const q = (s: string) => `'${s.replaceAll("'", "''")}'`;

async function readState(dir: string): Promise<State> {
  try {
    return JSON.parse(await fs.readFile(path.join(dir, "_state.json"), "utf8"));
  } catch {
    return { seq: 0, updatedAt: null, id: 0 };
  }
}

export async function syncOrders({ pool, conn, lakeDir, pageSize = 1000 }: { pool: Pool; conn: DuckDBConnection; lakeDir: string; pageSize?: number }): Promise<{ exported: number; file: string | null }> {
  await fs.mkdir(lakeDir, { recursive: true });
  const state = await readState(lakeDir);
  const rows: any[] = [];
  let cursor = { updatedAt: state.updatedAt, id: state.id };
  for (;;) {
    // keyset על (updated_at, id): שורות עם אותו updated_at לא הולכות לאיבוד בין עמודים
    const { rows: page } = await pool.query(
      `SELECT id, customer_id, total_cents, status, created_at, updated_at, updated_at::text AS updated_at_text
       FROM orders
       WHERE $1::timestamptz IS NULL OR (updated_at, id) > ($1::timestamptz, $2::int)
       ORDER BY updated_at, id LIMIT $3`,
      [cursor.updatedAt, cursor.id, pageSize],
    );
    rows.push(...page);
    if (page.length < pageSize) break;
    const last = page.at(-1);
    cursor = { updatedAt: last.updated_at_text, id: last.id };
  }
  if (rows.length === 0) return { exported: 0, file: null }; // אין חדש ← אין קובץ ריק

  await conn.run(`CREATE OR REPLACE TEMP TABLE batch (id INTEGER, customer_id INTEGER, total_cents INTEGER, status VARCHAR, created_at TIMESTAMPTZ, updated_at TIMESTAMPTZ)`);
  const app = await conn.createAppender("batch");
  for (const r of rows) {
    app.appendInteger(r.id);
    app.appendInteger(r.customer_id);
    app.appendInteger(r.total_cents);
    app.appendVarchar(r.status);
    app.appendVarchar(r.created_at.toISOString());
    app.appendVarchar(r.updated_at_text);
    app.endRow();
  }
  app.closeSync();
  const seq = state.seq + 1;
  const file = path.join(lakeDir, `part-${String(seq).padStart(5, "0")}.parquet`);
  await conn.run(`COPY batch TO ${q(file)} (FORMAT parquet)`);
  // ה־state נכתב רק אחרי שהקובץ קיים; ובכתיבה אטומית (קובץ זמני ← rename)
  const last = rows.at(-1);
  const tmp = path.join(lakeDir, "_state.json.tmp");
  await fs.writeFile(tmp, JSON.stringify({ seq, updatedAt: last.updated_at_text, id: last.id }));
  await fs.rename(tmp, path.join(lakeDir, "_state.json"));
  return { exported: rows.length, file };
}

export async function lakeReport(conn: DuckDBConnection, lakeDir: string) {
  const r = await conn.runAndReadAll(`
    WITH latest AS (
      SELECT * FROM read_parquet(${q(path.join(lakeDir, "part-*.parquet"))})
      QUALIFY row_number() OVER (PARTITION BY id ORDER BY updated_at DESC) = 1 -- הגרסה האחרונה של כל הזמנה
    )
    SELECT strftime(timezone('Asia/Jerusalem', created_at), '%Y-%m-%d') AS day,
           count(*)::INTEGER AS orders, (sum(total_cents) / 100.0)::DOUBLE AS revenue
    FROM latest WHERE status <> 'cancelled'
    GROUP BY day ORDER BY day`);
  return r.getRowObjects().map((x) => ({ day: String(x.day), orders: Number(x.orders), revenue: Number(x.revenue) }));
}

זה ETL מצטבר "אמיתי" בקטן: Fivetran, Airbyte ו־Debezium עושים את אותו דבר (Debezium — מה־WAL, בלי לשאול את הטבלה). ו־"append-only + גרסה אחרונה בקריאה" הוא הבסיס של פורמטים כמו Delta Lake (Databricks) ו־Apache Iceberg — שמוסיפים מעל Parquet טרנזקציות ו־time travel.

⚠️ טעויות נפוצות

export type Watermark = { updatedAt: string; id: number };

export function compareWm(a: Watermark, b: Watermark): number {
  return Date.parse(a.updatedAt) - Date.parse(b.updatedAt) || a.id - b.id;
}

export function changesAfter<T extends Watermark>(rows: T[], wm: Watermark | null, limit: number) {
  const page = rows
    .filter((r) => wm === null || compareWm(r, wm) > 0)
    .sort(compareWm)
    .slice(0, limit);
  const last = page.at(-1);
  return { page, next: last ? { updatedAt: last.updatedAt, id: last.id } : wm };
}

// P28.5-E90: הגרסה האחרונה של כל רשומה
export function latestVersions<T extends { id: number; updatedAt: string }>(records: T[], asOf?: string): T[] {
  const limit = asOf === undefined ? Infinity : Date.parse(asOf);
  const best = new Map<number, T>();
  for (const r of records) {
    const t = Date.parse(r.updatedAt);
    if (t > limit) continue;
    const cur = best.get(r.id);
    if (!cur || Date.parse(cur.updatedAt) <= t) best.set(r.id, r);
  }
  return [...best.values()].sort((a, b) => a.id - b.id);
}

export function partitionPath(table: string, at: string | Date, part: number): string {
  if (!/^[a-z_]+$/.test(table)) throw new Error(`שם טבלה לא תקין: ${table}`);

// P28.5-E93: כמה הנתונים ישנים?
function label(lagMs: number): string {
  const s = Math.floor(lagMs / 1000);
  if (s < 60) return `${s}s`;
  if (s < 3600) return `${Math.floor(s / 60)}m ${s % 60}s`;
  return `${Math.floor(s / 3600)}h ${Math.floor((s % 3600) / 60)}m`;
}

export function freshness(lastSyncAt: string | null, now: number, intervalMs: number) {
  if (lastSyncAt === null) return { status: "broken" as const, lagMs: null, label: "never" };
  const lagMs = now - Date.parse(lastSyncAt);
  const status = lagMs <= intervalMs * 1.5 ? "fresh" : lagMs <= intervalMs * 4 ? "late" : "broken";
  return { status: status as "fresh" | "late" | "broken", lagMs, label: label(lagMs) };
}

// P28.5-E94: לולאת הסנכרון
type Wm = { updatedAt: string; id: number };

export async function runSync<T extends Wm>(
  deps: {
    loadWm(): Promise<Wm | null>;
    fetchAfter(wm: Wm | null, limit: number): Promise<T[]>;
    writeBatch(rows: T[], n: number): Promise<void>;
    saveWm(wm: Wm): Promise<void>;
  },
  limit = 1000,
) {
  let wm = await deps.loadWm();
  let pages = 0;
  let total = 0;
  while (true) {
    const rows = await deps.fetchAfter(wm, limit);
    if (rows.length === 0) break;
    await deps.writeBatch(rows, pages + 1);
    pages++;
    total += rows.length;
    const last = rows.at(-1)!;
    wm = { updatedAt: last.updatedAt, id: last.id };
    await deps.saveWm(wm);
    if (rows.length < limit) break;
  }
  return { pages, rows: total, wm };
}

  const app = express();
  app.get("/revenue", async (req, res) => {
    const r = Query.safeParse(req.query);
    if (!r.success) return res.status(400).json({ error: r.error.issues[0]?.message ?? "invalid" });
    const p = { from: r.data.from, to: r.data.to, country: r.data.country ?? null };

// P28.5-E100: בדיקות איכות לאצווה
export type Rule =
  | { kind: "unique"; field: string }
  | { kind: "notNull"; field: string }
  | { kind: "accepted"; field: string; values: unknown[] }
  | { kind: "range"; field: string; min: number; max: number };

function violations(rows: Record<string, unknown>[], rule: Rule): { count: number; examples: unknown[] } {
  const values = rows.map((r) => r[rule.field]);
  switch (rule.kind) {
    case "unique": {
      const seen = new Set<unknown>();
      const dup = new Set<unknown>();
      let count = 0;
      for (const v of values) {
        if (seen.has(v)) {
          count++;
          dup.add(v);
        } else seen.add(v);
      }
      return { count, examples: [...dup].slice(0, 3) };
    }
    case "notNull": {
      const bad = values.filter((v) => v === null || v === undefined);
      return { count: bad.length, examples: bad.slice(0, 3) };
    }
    case "accepted": {
      const bad = values.filter((v) => !rule.values.includes(v));
      return { count: bad.length, examples: bad.slice(0, 3) };
    }
    case "range": {
      const bad = values.filter((v) => typeof v !== "number" || Number.isNaN(v) || v < rule.min || v > rule.max);
      return { count: bad.length, examples: bad.slice(0, 3) };
    }
  }
}

export function checkBatch(rows: Record<string, unknown>[], rules: Rule[]) {
  const failures: { rule: string; count: number; examples: unknown[] }[] = [];
  for (const rule of rules) {
    const v = violations(rows, rule);
    if (v.count > 0) failures.push({ rule: `${rule.kind}:${rule.field}`, ...v });
  }
  return { ok: failures.length === 0, failures };
