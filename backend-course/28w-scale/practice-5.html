P28.5-E24 · אתגר: API אנליטיקה תחת עומס 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 60 דק׳ידע נדרש: שיעור 5

  • GET /revenue?from=YYYY-MM-DD&to=YYYY-MM-DD ← { from, to, days: [{ day, orders, revenue }], total: { orders, revenue } } — ימים בשעון ישראל, כולל שני הקצוות; revenue בשקלים (2 ספרות). תאריך לא תקין, from אחרי to, או טווח של יותר מ־92 ימים ← 400.

  • תחת עומס (300 בקשות, 10 במקביל) — p95 מתחת ל־50ms.

export function checkBatch(rows: Record<string, unknown>[], rules: Rule[]): { ok: boolean; failures: { rule: string; count: number; examples: unknown[] }[] }

כש־Rule הוא אחד מ:

type Rule =
  | { kind: "unique"; field: string }
  | { kind: "notNull"; field: string }
  | { kind: "accepted"; field: string; values: unknown[] }
  | { kind: "range"; field: string; min: number; max: number };
  • לכל כלל שנכשל — פריט ב־failures, לפי סדר הכללים: rule — ‏${kind}:${field}; ‏count — כמה שורות הפרו; ‏examples — עד 3 ערכים מפרים (לפי הסדר).
  • unique — כל הופעה שנייה ואילך של ערך היא הפרה (‏examples — הערכים הכפולים, בלי חזרות). ‏notNull — ‏null או undefined. ‏accepted — ערך שלא ברשימה (‏null נחשב הפרה). ‏range — לא מספר, או מחוץ ל־[min, max].
