P11-E26 · טיפוסים מטיפוסים: Omit, ‏Pick, ‏Partial, ‏Record 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

לעיתים קרובות צריך טיפוס שהוא "כמעט" טיפוס קיים: משתמש בלי הסיסמה, או עדכון שבו כל השדות אופציונליים. אפשר להעתיק את השדות ידנית, אבל אז כל שינוי ב־User מחייב לעדכן כמה מקומות. ב־TypeScript יש utility types שבונים טיפוס חדש מטיפוס קיים:

כותביםמקבלים
Omit<User, "passwordHash">כל השדות של User, חוץ מ־passwordHash
Pick<User, "name" | "email">רק name ו־email
Partial<T>כל השדות של T, כאופציונליים
Record<"a" | "b", number>{ a: number; b: number }

כתוב קובץ שמייצא (export):

  • type User — id (מספר), name, email, passwordHash (מחרוזות), role ("admin" או "member").
  • type PublicUser — User בלי passwordHash (מה שמותר לשלוח ללקוח). השתמש ב־Omit.
  • type UserPatch — עדכון: רק name ו־email, ושניהם אופציונליים. השתמש ב־Partial וב־Pick.
  • type RoleCounts — מספר לכל role. השתמש ב־Record וב־User["role"].
  • toPublic(u: User): PublicUser — עותק בלי passwordHash.
  • applyPatch(u: User, patch: UserPatch): User — עותק מעודכן.
  • countRoles(users: User[]): RoleCounts — כמה מכל role (גם 0).

הבודק מריץ את הפונקציות, וגם בודק את הטיפוסים: למשל ש־{ role: "admin" } לא מתקבל כ־UserPatch.

P11-E51 · חתימה לפונקציה מפרק 6

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: פרק 5, פרק 6, שיעור 2

את הפונקציות האלה כתבת (בערך) ב־JavaScript בפרקים 5–6. כתוב לכל אחת חתימה מלאה ב־TypeScript — טיפוסים לפרמטרים ולערך ההחזרה. בלי לגעת בגוף.

function sumBy(items, getValue) {
  return items.reduce((s, item) => s + getValue(item), 0);
}

function countIf(words, predicate) {
  let n = 0;
  for (const w of words) if (predicate(w)) n++;
  return n;
}

function makeCounter(start = 0) {
  let count = start;
  return () => ++count;
}

🔗 איך זה מתחבר: פרק 5 (callbacks ופונקציה שמחזירה פונקציה) ופרק 6 (reduce). השיעור: טיפוס של פונקציה — (x: T) => R — גם לפרמטר וגם לערך ההחזרה.

P11-E52 · טיפוס ל־callback של error-first

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 10, שיעור 2

type Callback = (err: Error | null, data?: string) => void;

function readName(id: number, done: Callback): void {
  if (id < 0) {
    done("מזהה שלילי");
    return;
  }
  if (id === 0) {
    done(new Error("לא נמצא"));

P11-E55 · sortBy גנרי 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: פרק 6, שיעור 2

כתוב וייצא sortBy<T>(items: T[], key: (item: T) => number): T[] — מערך חדש, ממוין מהקטן לגדול לפי המספר ש־key מחזירה. המקור לא משתנה, ובשוויון נשמר הסדר המקורי. וגם topN<T>(items: T[], key: (item: T) => number, n: number): T[] — n הפריטים עם המספר הגבוה ביותר, מהגבוה לנמוך.

sortBy([{ n: "b", age: 30 }, { n: "a", age: 20 }], (p) => p.age); // a, b
topN(["ccc", "a", "bb"], (s) => s.length, 2);                    // ["ccc", "bb"]
