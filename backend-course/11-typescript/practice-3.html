P11-E03 · מה הטיפוס כאן?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 3

לכל הערה (A–E) — מה הטיפוס של value באותה נקודה, לפי TypeScript?

function show(value: string | number | null | string[]) {
  // A
  if (value === null) {
    return "ריק";
  }
  // B
  if (Array.isArray(value)) {
    // C
    return value.join(",");
  }
  if (typeof value === "number") {
    // D
    return value.toFixed(2);
  }
  // E
  return value.trim();
}

P11-E27 · משך זמן: מטקסט למספר ובחזרה 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

🔁 חזרה על split, ‏endsWith, ‏slice ו־Number.isInteger (פרקים 2 ו־6), על לולאה עם return מוקדם (פרקים 4–5), ועל Math.floor ו־% (פרק 2) — עם טיפוסים. כתוב וייצא שתי פונקציות:

  • parseDuration(text: string): number | null — מחזירה דקות. הטקסט הוא מילים מופרדות ברווחים (אחד או יותר). כל מילה היא מספר שלם ואחריו h (שעות) או m (דקות). אם יש מילה לא תקינה, או שאין אף מילה — null.
  • formatDuration(minutes: number): string — הכיוון ההפוך: 90 ← "1h 30m", ‏120 ← "2h", ‏45 ← "45m", ‏0 ← "0m".
parseDuration("1h 30m");  // 90
parseDuration(" 2h ");    // 120
parseDuration("15m 1h");  // 75 — הסדר לא משנה
parseDuration("1.5h");    // null — רק מספרים שלמים
parseDuration("abc");     // null
parseDuration("");        // null

הבודק בודק גם את הטיפוסים: מי שקורא ל־parseDuration חייב לבדוק null לפני שהוא משתמש בתוצאה כמספר.
