P11-E71 · type guard שמשקר

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

הקוד עובר tsc. בלי להריץ — מה יודפס, ומה הבאג ב־isProduct?

type Product = { name: string; price: number };

function isProduct(value: unknown): value is Product {
  return typeof value === "object" && value !== null && "name" in value;
}

const raw: unknown = JSON.parse('[{"name":"עט","price":5},{"name":"דף"}]');
if (Array.isArray(raw)) {
  for (const item of raw.filter(isProduct)) {
    console.log(item.name, item.price * 2);
  }
}

P11-E74 · מערך של מחרוזות? 🤖

P11-E78 · JSON.parse בתוך async

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 10, שיעור 4

בשתי הפונקציות text הוא תוכן של קובץ הגדרות שנקרא מהדיסק. בלי להריץ — מה tsc יגיד על כל אחת? איזו מהן תחזיר "8080" (מחרוזת!) בזמן ריצה בלי שאף אחד ישים לב?

async function portA(read: () => Promise<string>): Promise<number> {
  const data = JSON.parse(await read());
  return data.port;
}

async function portB(read: () => Promise<string>): Promise<number> {
  const data: unknown = JSON.parse(await read());
  return data.port;
}

async function portC(read: () => Promise<string>): Promise<number> {
  const data: unknown = JSON.parse(await read());
  if (typeof data === "object" && data !== null && "port" in data && typeof data.port === "number") {
    return data.port;
  }
  throw new Error("port חסר או לא מספר");
}

🔗 איך זה מתחבר: פרק 10: await על קריאת קובץ, ו־async שמחזירה Promise<number>. השיעור: JSON.parse מחזיר any — וה־Promise<number> בחתימה לא עוזר, כי any "מתאים" לכל טיפוס.

P11-E79 · instanceof על מחלקות שגיאה

class NotFoundError extends Error {
  constructor(public resource: string) {
    super(`${resource} לא נמצא`);
  }
}

function handle(err: unknown): number {
  if (err instanceof NotFoundError) {
    console.log("חסר:", err.resource);

P11-E24 · אתגר: אירועים מוקלדים 🤖

P11-E25 · אתגר: mini-Zod 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 40 דק׳ידע נדרש: כל הפרק

בנה ספריית validation זעירה. בקובץ 11-typescript/starter/P11-E25.ts (הטיפוס Result ו־Validator<T> = (value: unknown, path?: string) => Result<T> מוגדרים) השלם:

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 4

🔁 חזרה על Promise.all (פרק 10) ועל Set (פרק 7), עם טיפוסים. כתוב קובץ שמייצא:

  • type User = { id: number; name: string }.
  • async function findUsers(ids: number[], getUser: (id: number) => Promise<User | undefined>): Promise<{ found: User[]; missing: number[] }>

הפונקציה מבקשת את כל המשתמשים במקביל. ‏getUser מחזירה undefined כשאין משתמש כזה. מחזירים את מי שנמצא ב־found ואת ה־ids שלא נמצאו ב־missing. שניהם לפי הסדר שב־ids. id שמופיע כמה פעמים — מבקשים ומחזירים פעם אחת.

// במסד: 1 → דנה, 3 → עומר

// { found: [{ id: 3, name: "עומר" }, { id: 1, name: "דנה" }], missing: [2] }
