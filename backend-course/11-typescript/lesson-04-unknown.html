שיעור 4 — unknown, any ו־type guards

⏱ ~30 דקות

🎯 בשיעור הזה
  • any — הכפתור שמכבה את TypeScript, ולמה לא ללחוץ עליו.
  • unknown — הדרך הבטוחה לנתונים שלא ידוע מה הם.
  • type guards (x is T) ו־as.

1. any

const data: any = JSON.parse('{"price": "12"}');
const total: number = data.price * 2 + data.prise;
data.foo.bar.baz();

  
אין אף שגיאה — אבל יש שלושה באגים (מחרוזת, שגיאת כתיב, וקריסה בזמן ריצה). any אומר ל־TypeScript "אל תבדוק כלום כאן", והוא "מדבק": כל מה שנגזר ממנו הוא any גם כן. ו־JSON.parse מחזיר any — לכן נתונים מבחוץ הם המקום המסוכן ביותר.


  
2. unknown


const data: unknown = JSON.parse('{"price": 12}');
console.log(data.price);
if (typeof data === "object" && data !== null && "price" in data && typeof data.price === "number") {
  console.log(data.price * 2);
}


snippet.ts(2,13): error TS18046: 'data' is of type 'unknown'.

  
unknown אומר "לא יודע מה זה" — ולכן אוסר כל שימוש עד שבודקים. בתוך ה־if, אחרי הבדיקות, מותר. כלל בקורס: נתונים שמגיעים מבחוץ (JSON, קבצים, בקשות HTTP) — unknown, ובודקים.


  
3. Type guards — בדיקה שאפשר להשתמש בה שוב


type Product = { name: string; price: number };

function isProduct(value: unknown): value is Product {
  return (
    typeof value === "object" &&
    value !== null &&
    "name" in value &&
    typeof value.name === "string" &&
    "price" in value &&
    typeof value.price === "number"
  );
}

const raw: unknown = JSON.parse('[{"name":"עט","price":5},{"name":"דף"}]');
if (Array.isArray(raw)) {
  const products = raw.filter(isProduct);
  console.log(products.map((p) => p.name));
}


[ 'עט' ]

  
value is Product (במקום boolean) מלמד את TypeScript: "אם הפונקציה החזירה true — זה Product". ואז filter(isProduct) מחזיר Product[]. בפרק 15 נשתמש בספרייה (Zod) שכותבת את הבדיקות האלה בשבילנו — אבל הרעיון זהה.


  
4. as — "תאמין לי"


const product = JSON.parse(text) as Product;

  
as לא בודק כלום — הוא מבטיח ל־TypeScript, ואם ההבטחה שקרית, הבאג יופיע בזמן ריצה. מקומות לגיטימיים: כשאתה באמת יודע יותר מהבודק (נדיר). מקום לא לגיטימי: נתונים מהמשתמש.


  

    ⚡ הנקודה החשובה ביותר בפרק
    
טיפוסים נמחקים לפני הרצה (שיעור 1, איור 1). אם השרת שלך מגדיר body: CreateOrder, ומישהו שולח {"quantity": "abc"} — TypeScript לא יעצור את זה. רק בדיקה בזמן ריצה (כמו isProduct) עוצרת. טיפוסים מגינים עליך מעצמך; validation מגן עליך מהעולם. בפרק 12 נעמיק בזה.
