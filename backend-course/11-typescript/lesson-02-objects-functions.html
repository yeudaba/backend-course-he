1. type — שם לצורה של אובייקט

type Product = {
  id: number;
  name: string;
  price: number;
  tags: string[];
};

const keyboard: Product = { id: 1, name: "מקלדת", price: 249, tags: ["מחשב"] };

function describe(p: Product): string {
  return `${p.name} — ₪${p.price}`;
}
console.log(describe(keyboard));
מקלדת — ₪249

מעכשיו, כל מקום שמקבל Product מקבל גם השלמה אוטומטית ב־VS Code: הקלד p. ותראה את השדות. וטעות כתיב (p.prise) — קו אדום מיד.

2. אופציונלי ו־readonly

type User = {
  readonly id: number;
  email: string;
  phone?: string;
};

const u: User = { id: 1, email: "dana@mail.com" };
u.id = 2;
const digits = u.phone.length;
const safe = u.phone?.length ?? 0;
snippet.ts(8,3): error TS2540: Cannot assign to 'id' because it is a read-only property.
snippet.ts(9,16): error TS18048: 'u.phone' is possibly 'undefined'.

phone? — "אולי קיים". TypeScript מכריח לטפל במקרה שהוא חסר — בדיוק השגיאה Cannot read properties of undefined מפרק 7, שנתפסת עכשיו לפני הרצה. ?. ו־?? פותרים (שורה 10 עוברת). readonly — מזהה לא משתנים אחרי יצירה.

3. interface — כמעט אותו דבר

interface Customer {
  id: number;
  name: string;
}
interface VipCustomer extends Customer {
  discountPercent: number;
}

interface ו־type חופפים ברוב המקרים. ההבדלים: interface אפשר להרחיב עם extends (וגם type יכול, עם &); type יכול גם להיות union (שיעור 3) — interface לא. בקורס: type כברירת מחדל, interface כשזה מתאים לצורה של "מחלקה" (פרק 12). בקוד של אחרים תראה את שניהם — וזה בסדר.

4. פונקציות

type Item = { price: number; qty?: number };

function lineTotal(item: Item, vatRate = 0.18): number {
  return Math.round(item.price * (item.qty ?? 1) * (1 + vatRate) * 100) / 100;
}

const applyAll = (items: Item[], fn: (item: Item) => number): number[] => items.map(fn);

console.log(applyAll([{ price: 100 }, { price: 10, qty: 2 }], (i) => lineTotal(i)));

5. Generics בקצרה

ראית number[], Promise<User>, Map<string, number>. ה־< > הוא "טיפוס כפרמטר" — מערך של מספרים, Promise של משתמש. אפשר לכתוב פונקציה כזו בעצמך:

function first<T>(items: T[]): T | undefined {
  return items[0];
}
const n = first([10, 20]);
const s = first(["a", "b"]);
console.log(n, s);
10 a

T הוא "הטיפוס שיתברר בקריאה": עבור [10, 20] הוא number, ולכן n הוא number | undefined. נעמיק בפרק 12.
