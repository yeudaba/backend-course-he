💡 רמז 2

chunk<T>(arr: T[], size: number): T[][] — אפשר גם בלי generic (number[]), אבל עם generic זה עובד לכל מערך.

✅ פתרון
// P11-E07: אותה לוגיקה מפרק 6, עם טיפוסים
export function cleanTags(input: string, max = 5): string[] {
  return input
    .split(",")
    .map((tag) => tag.trim().toLowerCase())
    .filter((tag) => tag !== "")
    .filter((tag, i, all) => all.indexOf(tag) === i)
    .slice(0, max);
}

export function chunk<T>(arr: T[], size: number): T[][] {
  const result: T[][] = [];
  for (let i = 0; i < arr.length; i += size) {
    result.push(arr.slice(i, i + size));
  }
  return result;
}

export function median(nums: number[]): number | null {
  if (nums.length === 0) {
    return null;
  }
  const sorted = [...nums].sort((a, b) => a - b);
  const mid = Math.floor(sorted.length / 2);
  return sorted.length % 2 === 1 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
}

console.log(cleanTags(" A, b ,a"), chunk([1, 2, 3], 2), median([3, 1, 2]));
[ 'a', 'b' ] [ [ 1, 2 ], [ 3 ] ] 2

⚠️ טעויות נפוצות

export function initials(fullName: string): string {
  return fullName
    .split(" ")
    .filter((w) => w !== "")
    .map((w) => w[0].toUpperCase() + ".")

}

✅ פתרון
// P11-E36: ממוצע עם טיפוסים
export function average(nums: number[]): number {
  if (nums.length === 0) return 0;
  const sum = nums.reduce((s, n) => s + n, 0);
  return Math.round((sum / nums.length) * 100) / 100;
}

export function above(nums: number[], limit: number): number[] {
  return nums.filter((n) => n > limit);
}

P11-E37 · ספירת מילים ב־Map מוקלד 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

💡 רמז 2

✅ פתרון
// P11-E37: ספירת מילים ב־Map מוקלד
export function countWords(text: string): Map<string, number> {
  const counts = new Map<string, number>();
  for (const raw of text.split(" ")) {
    if (raw === "") continue;
    const w = raw.toLowerCase();
    counts.set(w, (counts.get(w) ?? 0) + 1);
  }
  return counts;
}

console.log(countWords("the cat and The dog"));
console.log(countWords("   "));

⚠️ טעויות נפוצות
  • new Map() בלי <string, number> — הטיפוס הוא Map<any, any>, ואז הבדיקה לא שווה הרבה.

const DAY_MS = 24 * 60 * 60 * 1000;

export function daysBetween(from: Date, to: Date): number {
  return Math.trunc((to.getTime() - from.getTime()) / DAY_MS);
}

export function isWeekend(d: Date): boolean {
  const day = d.getDay();
  return day === 5 || day === 6;
}

P11-E42 · מספרים משורת CSV 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

line.split(",").map((s) => s.trim()).filter((s) => s !== "").map(Number) — ואחר כך סינון של NaN.

💡 רמז 2

Number("") הוא 0 ולא NaN — לכן מסננים ריקים לפני ההמרה. ב־sumLine: parseNumbers(line).reduce((s, n) => s + n, 0).

✅ פתרון
// P11-E42: מספרים משורת CSV
export function parseNumbers(line: string): number[] {
  return line
    .split(",")
    .map((s) => s.trim())
    .filter((s) => s !== "")
    .map(Number)
    .filter((n) => !Number.isNaN(n));
}

export function sumLine(line: string): number {
  return parseNumbers(line).reduce((s, n) => s + n, 0);
}

console.log(parseNumbers("10, 2.5,abc,, -3 "));
console.log(sumLine("10, 2.5,abc,, -3 "), sumLine(""));
[ 10, 2.5, -3 ]
9.5 0

בכל שלב בשרשרת TypeScript יודע את הטיפוס: string[] ← string[] ← number[]. נסה להחליף את .map(Number) ב־.map((s) => s) — ה־: number[] שבחתימה יתפוס מיד שמחזירים מחרוזות.

⚠️ טעויות נפוצות
  • לשכוח את הסינון של מחרוזות ריקות — ",," הופך ל־[0, 0, 0].

P11-E43 · קבוצות לפי אורך 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

קודם מקבצים לתוך new Map<number, string[]>(). אם אין עדיין רשימה לאורך — יוצרים [].

💡 רמז 2

בסוף בונים Map חדש לפי מפתחות ממוינים: for (const k of [...groups.keys()].sort((a, b) => a - b)) sorted.set(k, groups.get(k) ?? []);

✅ פתרון
// P11-E43: קבוצות לפי אורך
export function byLength(words: string[]): Map<number, string[]> {
  const groups = new Map<number, string[]>();
  for (const w of words) {
    const list = groups.get(w.length) ?? [];
    list.push(w);
    groups.set(w.length, list);
  }
  const sorted = new Map<number, string[]>();
  for (const k of [...groups.keys()].sort((a, b) => a - b)) {
    sorted.set(k, groups.get(k) ?? []);
  }
  return sorted;
}

console.log(byLength(["cat", "a", "dog", "bird", "be"]));

P11-E44 · קבלה מיושרת 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

פונקציית עזר פנימית: const line = (label: string, n: number): string => label.padEnd(12) + n.toFixed(2).padStart(8);

💡 רמז 2

לולאה על i מ־0 עד names.length, שמוסיפה שורות למערך ומסכמת total. בסוף: lines.join("\n").

✅ פתרון
// P11-E44: קבלה מיושרת
export function receipt(names: string[], prices: number[]): string {
  if (names.length !== prices.length) throw new Error("names ו־prices באורך שונה");
  const line = (label: string, n: number): string => label.padEnd(12) + n.toFixed(2).padStart(8);
  const lines: string[] = [];
  let total = 0;
  for (let i = 0; i < names.length; i++) {
    lines.push(line(names[i], prices[i]));
    total += prices[i];
  }
  lines.push(line("סה״כ", total));
  return lines.join("\n");
}

console.log(receipt(["קפה", "עוגה"], [12, 18.5]));
קפה            12.00
עוגה           18.50
סה״כ           30.50

const lines: string[] = [] — מערך ריק הוא אחד המקומות שבהם כדאי לכתוב טיפוס (אין ממה להסיק). ‏total מסוכם כמספר, ו־toFixed מופעל רק בהדפסה — אותו כלל מפרק 2: עיגול רק בתצוגה.

⚠️ טעויות נפוצות
  • total += prices[i].toFixed(2) — ב־JavaScript זה היה הופך את הסכום למחרוזת; כאן זו שגיאת טיפוסים.
