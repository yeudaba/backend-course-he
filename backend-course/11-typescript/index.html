פרק 11 — TypeScript בסיסי

⏱ 4 מפגשים

🧰 לפני שמתחילים — פרק 11

מה צריך שכבר יהיה מותקן: VS Code, Node.js 24+, הבודק האוטומטי.

מה מתקינים עכשיו: TypeScript — בתוך תיקיית הקורס, לא כתוכנה במחשב.

  1. העתק מחדש מ־~/Desktop/Backend/backend-course אל ~/dev/backend-course את package.json (Replace) ואת הקובץ החדש tsconfig.json.
  2. מתוך ~/dev/backend-course: 
    % npm install
  3. בדיקה: 
    % npx tsc -v
Version 5.9.3
    (כל גרסה 5.x תקינה.)
  4. תוסף ל־VS Code: לא צריך. VS Code כתוב ב־TypeScript ותומך בו מובנה — שגיאות טיפוסים יסומנו בקו אדום ישר בעורך, לפי ה־tsconfig.json שהעתקת.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 11-typescript מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ הרצת קובץ TypeScript: ב־Node 24, node file.ts עובד ישירות. אם מופיעה שגיאה Unknown file extension ".ts" — גרסת ה־Node ישנה; חזור לפרק 0, שיעור 2, ועדכן.

🎯 בסוף הפרק תדע
  • להבין מה TypeScript מוסיף, ומה ההבדל בין הרצת קוד לבין בדיקת טיפוסים.
  • לתת טיפוסים למשתנים, פרמטרים, ערכי החזרה, מערכים ואובייקטים.
  • להגדיר טיפוסים עם type ו־interface, כולל שדות אופציונליים ו־readonly.
  • להשתמש ב־union ו־literal types, ולצמצם טיפוסים (narrowing).
  • לעבוד נכון עם unknown במקום any, ולכתוב type guards.

🤔 למה צריך את זה?

בפרקים הקודמים ראית באגים שנולדו מ"סוג לא נכון": "5" + 3, שדה בשם שגוי שהחזיר undefined, פונקציה שקיבלה מחרוזת במקום מספר. JavaScript מגלה אותם רק כשהקוד רץ — ולפעמים אצל משתמש. TypeScript מגלה אותם בזמן שאתה מקליד. כמעט כל משרת Backend חדשה ב־Node דורשת TypeScript, וגם NestJS (פרק 20) כתוב בו.

🏁 מבחן מעבר

  • להמיר קובץ JavaScript מפרק 7 ל־TypeScript עם טיפוסים מלאים ובלי any, כך ש־npx tsc --noEmit עובר.
