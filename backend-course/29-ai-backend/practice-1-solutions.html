"שילוב" — המודל מציע או מסווג, והקוד (או בן אדם) מחליט.

✅ פתרון

  7. מודל, עם בדיקה של אדם לפני פרסום. תרגום הוא חוזקה, אבל זה טקסט שיווקי שעולה לאוויר.

P29-E02 · כמה זה יעלה? 🧠 הבנה רמה 1

💡 רמז 2

cache read של Opus 5.5: $0.20 למיליון, במקום $4.

✅ פתרון
  1. קלט: 8,000 × 3,500 = 28 מיליון טוקנים × $4 = $112. פלט: 8,000 × 300 = 2.4 מיליון × $20 = $48. סה״כ כ־$160 ביום — כ־$4,800 בחודש.

  3. להגביל max_tokens ואורך תשובה; לקצר היסטוריה (E07, E18); cache לתשובות לשאלות שחוזרות (E16); תקציב למשתמש (E17); ולבדוק עם eval (E19) אם מודל זול יותר מחזיק את האיכות בנתיב הזה — החלטה שמבוססת על מדידה, לא על ניחוש.
⚠️ טעויות נפוצות
  • לחשב רק לפי הפלט ("התשובות קצרות") — ברוב האפליקציות הקלט, שנשלח מחדש בכל הודעה, הוא רוב החשבון.

"איטי" — מה המשתמש רואה בזמן הזה? "עולה" — מי יכול להפעיל אותו כמה פעמים?

P29-E06 · שאלה ותשובה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

ב־Opus 5.5 החשיבה תמיד פועלת, ובתשובה יכול להופיע בלוק thinking לפני הטקסט.

✅ פתרון
// P29-E06
import type Anthropic from "@anthropic-ai/sdk";

export const MODEL = "claude-opus-5-5";

export type AskResult = { ok: true; text: string } | { ok: false; reason: "refusal" | "max_tokens" | "empty" };

// שאלה אחת ← תשובה. שלושה דברים שכל קריאה צריכה: לבדוק stop_reason לפני שקוראים את התוכן,
// לאסוף רק בלוקים מסוג text (יש גם thinking, tool_use…), ולא להניח ש־content[0] הוא הטקסט
export async function ask(client: Anthropic, question: string, { system }: { system?: string } = {}): Promise<AskResult> {
  const response = await client.messages.create({
    model: MODEL,
    max_tokens: 4096,
    ...(system ? { system } : {}),
    messages: [{ role: "user", content: question }],
  });
  if (response.stop_reason === "refusal") return { ok: false, reason: "refusal" };
  if (response.stop_reason === "max_tokens") return { ok: false, reason: "max_tokens" }; // תשובה חתוכה באמצע — לא מציגים כאילו שלמה
  const text = response.content
    .filter((b): b is Anthropic.TextBlock => b.type === "text")
    .map((b) => b.text)
    .join("")
    .trim();
  return text ? { ok: true, text } : { ok: false, reason: "empty" };
}
⚠️ טעויות נפוצות
  • response.content[0].text — TypeScript צועק (content הוא union), ובצדק: הבלוק הראשון לא בהכרח טקסט.

P29-E07 · היסטוריית שיחה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

✅ פתרון
// P29-E07
import type Anthropic from "@anthropic-ai/sdk";

export interface Turn {
  role: "user" | "assistant";
  text: string;
}

// ה־API לא זוכר כלום: כל בקשה שולחת את כל השיחה. כדי לא לשלם על שיחה אינסופית — שומרים רק את maxTurns
// הזוגות האחרונים. ההודעה הראשונה חייבת להיות user, וההיסטוריה לא נגמרת בשאלה פתוחה
export function buildMessages(history: readonly Turn[], question: string, maxTurns = 5): Anthropic.MessageParam[] {
  const clean = history.filter((t) => t.text.trim() !== "");
  let recent = clean.slice(-maxTurns * 2);
  while (recent.length > 0 && recent[0].role !== "user") recent = recent.slice(1);
  if (recent.length > 0 && recent[recent.length - 1].role === "user") recent = recent.slice(0, -1); // שאלה בלי תשובה (נכשלה) — לא שולחים שוב
  return [...recent.map((t) => ({ role: t.role, content: t.text })), { role: "user", content: question }];
}

זה החיסכון הפשוט ביותר: כל הודעה ישנה שנשלחת שוב עולה בכל בקשה מחדש. ובשיחות ארוכות באמת — גם compaction בצד השרת, או סיכום של ההתחלה.

⚠️ טעויות נפוצות
  • לשמור את ההיסטוריה ב־Map בזיכרון השרת — שרת שני לא מכיר אותה, ואחרי restart היא נעלמת (פרק 28: stateless). במסד או ב־Redis.

P29-E08 · כמה עלתה הבקשה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

המחירים "למיליון טוקנים": tokens × price / 1,000,000.

💡 רמז 2

input_tokens לא כולל את מה שנקרא מה־cache או נכתב אליו — אלה מונים נוספים.

✅ פתרון
// P29-E08
// עלות של בקשה מתוך usage. מחירים בדולר למיליון טוקנים — מהטבלה בשיעור 1 (לבדוק בדף התמחור לפני שמסתמכים)
export interface Prices {
  input: number;
  output: number;
  cacheWrite: number;
  cacheRead: number;
}

export interface Usage {
  input_tokens: number;
  output_tokens: number;
  cache_creation_input_tokens?: number | null;
  cache_read_input_tokens?: number | null;
}

export const PRICES: Record<string, Prices> = {
  "claude-opus-5-5": { input: 4, output: 20, cacheWrite: 5, cacheRead: 0.2 },
  "claude-sonnet-5-5": { input: 2, output: 10, cacheWrite: 2.5, cacheRead: 0.2 },
  "claude-haiku-5-5": { input: 0.1, output: 0.5, cacheWrite: 0.125, cacheRead: 0.01 },
};

export function costUsd(model: string, usage: Usage): number {
  const p = PRICES[model];
  if (!p) throw new Error(`אין מחיר למודל ${model}`);
  // input_tokens לא כולל את מה שנכתב ל־cache או נקרא ממנו — שלושה מונים נפרדים
  const usd =
    (usage.input_tokens * p.input +
      usage.output_tokens * p.output +
      (usage.cache_creation_input_tokens ?? 0) * p.cacheWrite +
      (usage.cache_read_input_tokens ?? 0) * p.cacheRead) /
    1_000_000;
  return Math.round(usd * 1_000_000) / 1_000_000; // דיוק של מיליונית דולר — בלי זנבות של 0.1+0.2
}

רושמים את זה בלוג של כל קריאה (עם request ID ומשתמש) — וזה הבסיס לתקציב (E17) ולדוח "כמה עולה לנו הפיצ׳ר".

⚠️ טעויות נפוצות
  • מחירים בקוד בלי תאריך ובלי מקור — הם משתנים. הערה עם תאריך וקישור לדף התמחור, ובדיקה מדי פעם.

// P29-E20
import type Anthropic from "@anthropic-ai/sdk";

export function replyText(message: Anthropic.Message): string {
  // תקלה 2: סירוב לא נבדק ← הלקוח קיבל תשובה ריקה בלי הסבר (או מה שהספיק להיכתב לפני הסירוב)
  if (message.stop_reason === "refusal") throw new Error("המודל סירב לענות");
  // תקלה 3: max_tokens לא נבדק ← חצי תשובה הוצגה כאילו היא שלמה
  if (message.stop_reason === "max_tokens") throw new Error("התשובה נחתכה (max_tokens)");
  return message.content
    .filter((b): b is Anthropic.TextBlock => b.type === "text") // תקלה 1: בלי filter, `${b.text}` של thinking או tool_use הוא המחרוזת "undefined"
    .map((b) => b.text)
    .join("");
}

💡 רמז 2

// P29-E32: סיכום שלא נחתך
import type Anthropic from "@anthropic-ai/sdk";

const SYSTEM = "Summarize the user's text in Hebrew, in at most three short sentences.";

export async function summarize(client: Anthropic, text: string, opts: { maxTokens?: number } = {}) {
  const first = opts.maxTokens ?? 1024;
  const call = (maxTokens: number) =>
    client.messages.create({ model: "claude-opus-5-5", max_tokens: maxTokens, system: SYSTEM, messages: [{ role: "user", content: text }] });

  let r = await call(first);
  let attempts = 1;
  if (r.stop_reason === "max_tokens") {
    r = await call(first * 2);
    attempts = 2;
  }
  if (r.stop_reason === "refusal") return { ok: false as const, reason: "refusal" as const };
  if (r.stop_reason === "max_tokens") return { ok: false as const, reason: "too_long" as const };
  const out = r.content
    .filter((b): b is Anthropic.TextBlock => b.type === "text")
    .map((b) => b.text)
    .join("")
    .trim();
  return { ok: true as const, text: out, attempts };
}

// P29-E33: כמה יעלה בחודש, בכל מודל
const PRICES: Record<string, [number, number]> = {
  "claude-opus-5-5": [4, 20],
  "claude-sonnet-5-5": [2, 10],
  "claude-haiku-5-5": [0.1, 0.5],
};

export function compareModels(load: { requestsPerDay: number; inputTokens: number; outputTokens: number; days?: number }) {
  const { requestsPerDay, inputTokens, outputTokens, days = 30 } = load;
  for (const n of [requestsPerDay, inputTokens, outputTokens, days]) {
    if (!Number.isFinite(n) || n < 0) throw new RangeError(`מספר לא תקין: ${n}`);
  }
  const requests = requestsPerDay * days;
  return Object.entries(PRICES)
    .map(([model, [inPrice, outPrice]]) => ({ model, exact: (requests * inputTokens * inPrice + requests * outputTokens * outPrice) / 1_000_000 }))
    .sort((a, b) => a.exact - b.exact)
    .map(({ model, exact }) => ({ model, usd: Math.round(exact * 100) / 100 }));
}

המחירים "קפואים" מאוקטובר 2026, כמו בשיעור. בקוד אמיתי הם בהגדרות (או בטבלה), לא בקוד — ובודקים אותם מול דף המחירים לפני שמתחייבים לתקציב.

// P29-E35: ההגדרות של הלקוח
const MODELS = ["claude-opus-5-5", "claude-sonnet-5-5", "claude-haiku-5-5"];

export function aiConfig(env: Record<string, string | undefined>) {
  const apiKey = env.ANTHROPIC_API_KEY ?? "";
  if (!apiKey.startsWith("sk-ant-")) throw new Error("ANTHROPIC_API_KEY חסר או לא בפורמט הנכון (sk-ant-...)");
  const model = env.AI_MODEL || "claude-opus-5-5";
  if (!MODELS.includes(model)) throw new Error(`AI_MODEL לא מוכר: ${model}`);
  const intIn = (name: string, def: number, min: number, max: number) => {
    const raw = env[name];
    if (raw === undefined || raw === "") return def;
    if (!/^\d+$/.test(raw) || Number(raw) < min || Number(raw) > max) throw new Error(`${name} חייב להיות שלם בין ${min} ל־${max}`);
    return Number(raw);
  };
  return { apiKey, model, maxRetries: intIn("AI_MAX_RETRIES", 2, 0, 5), timeoutMs: intIn("AI_TIMEOUT_MS", 30_000, 1_000, 600_000) };
}

// P29-E39: POST /ask ב־Express
import express from "express";
import Anthropic from "@anthropic-ai/sdk";
import { z } from "zod";

const Body = z.object({ question: z.string().trim().min(1).max(2000) });

export function askApp(client: Anthropic) {
  const app = express();
  app.use(express.json());
  app.post("/ask", async (req, res) => {
    const parsed = Body.safeParse(req.body);
    if (!parsed.success) return res.status(400).json({ error: "question: 1–2000 תווים" });
    try {
      const r = await client.messages.create({
        model: "claude-opus-5-5",
        max_tokens: 2048,
        system: "You are the assistant of a coffee-equipment shop. Answer briefly, in Hebrew.",
        messages: [{ role: "user", content: parsed.data.question }],
      });
      if (r.stop_reason === "refusal") return res.json({ answer: null, reason: "refusal" });
      if (r.stop_reason === "max_tokens") return res.status(502).json({ error: "truncated" });
      const answer = r.content
        .filter((b): b is Anthropic.TextBlock => b.type === "text")
        .map((b) => b.text)
        .join("")
        .trim();
      res.json({ answer });
    } catch (err) {
      if (err instanceof Anthropic.APIError) return res.status(503).json({ error: "ai_unavailable" });
      throw err;
    }
  });
  return app;
}

// P29-E40: מפתחות שלא דולפים ללוג
const SECRET = new Set(["apikey", "authorization", "x-api-key"]);

export function redactSecrets(value: unknown): unknown {
  if (typeof value === "string") return value.replace(/sk-ant-[\w-]+/g, "sk-ant-***");
  if (Array.isArray(value)) return value.map(redactSecrets);
  if (value !== null && typeof value === "object") {
    const out: Record<string, unknown> = {};
    for (const [k, v] of Object.entries(value)) out[k] = SECRET.has(k.toLowerCase()) ? "***" : redactSecrets(v);
    return out;
  }
  return value;
}

// P29-E41: מדדי טוקנים ב־/metrics
export function createAiMetrics() {
  const counts = new Map<string, number>();
  const add = (labels: string, n: number) => counts.set(labels, (counts.get(labels) ?? 0) + n);
  return {
    record(model: string, route: string, usage: { input_tokens: number; output_tokens: number; cache_read_input_tokens?: number | null }) {
      const base = `model="${model}",route="${route}"`;
      add(`${base},kind="input"`, usage.input_tokens);
      add(`${base},kind="output"`, usage.output_tokens);
      add(`${base},kind="cache_read"`, usage.cache_read_input_tokens ?? 0);
    },
    render() {
      const lines = [...counts]
        .filter(([, v]) => v > 0)
        .map(([labels, v]) => `ai_tokens_total{${labels}} ${v}`)
        .sort();
      return ["# HELP ai_tokens_total Tokens used by AI calls", "# TYPE ai_tokens_total counter", ...lines].join("\n") + "\n";
    },
  };
}
