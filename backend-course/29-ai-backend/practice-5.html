  1. סיווג עם messages.parse (סכמה: category, refund_amount_ils מספר או null, confidence low/medium/high). נכשל ← { action: "human", reason: "classification_failed" }.

  3. טיוטת תשובה (קריאה שנייה, הקטגוריה בהודעה). נכשלה ← draft_failed; אחרת ← { action: "draft", category, draft }.
