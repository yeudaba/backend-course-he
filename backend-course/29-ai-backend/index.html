פרק 29 — AI ב־Backend: לשלב מודל שפה בשרת

⏱ 4 מפגשים

🧰 לפני שמתחילים — פרק 29

מה צריך שכבר יהיה מותקן: Node.js 24. npm install בתיקיית הקורס מוסיף את @anthropic-ai/sdk (ה־SDK הרשמי של Claude ל־TypeScript).

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 29-ai-backend מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה: cd ~/dev/backend-course && npm install && npm run check P29-E06 ← הבודק רץ ונכשל על קובץ ההתחלה.

לא צריך מפתח API ולא עולה כסף. כל הבודקים משתמשים ב־SDK האמיתי עם fetch מדומה — שום בקשה לא יוצאת לרשת. כדי לנסות מול ה־API האמיתי (לא חובה): חשבון ב־platform.claude.com, מפתח, ו־ANTHROPIC_API_KEY ב־.env של פרויקט שלך — עם מגבלת הוצאה חודשית בקונסולה, לפני הקריאה הראשונה.

פרק חובה. יחידה 29.5 ופרויקט 4 נשענים עליו, ו־"שילבתי מודל שפה בשרת, עם בדיקות, הגבלת עלות והרשאות" הוא משפט שמראיינים שואלים עליו יותר ויותר.

🎯 בסוף הפרק תדע
  • לקרוא ל־Claude מ־Node.js עם ה־SDK הרשמי, ולהבין מה חוזר: בלוקים, stop_reason, usage.
  • לקבל פלט מובנה ומאומת (structured outputs + Zod), ולהתייחס לפלט של מודל כקלט לא אמין.
  • tool use: לתת למודל כלים — בלולאה נכונה, ועם ההרשאות של המשתמש בלבד.
  • פרודקשן: streaming, שגיאות ו־fallback, עלות (prompt caching, תקציב), cache לתשובות, prompt injection ופרטיות.
  • לבדוק פיצ׳רים של AI: לקוח מדומה, evals, וזרימות שבהן הקוד מחליט והמודל עושה צעדים מוגדרים.

🤔 למה צריך את זה?

הרבה מאוד פיצ׳רים חדשים בשנים האחרונות הם "שלב מודל שפה": לסכם ביקורות, לסווג פניות, לענות על שאלות מתוך מסמכי החברה, לתת למשתמש לחפש במילים שלו. בצד ה־Backend זה לא קסם — זו קריאת HTTP לשירות חיצוני: איטית, עולה כסף לפי שימוש, ומחזירה טקסט שאי אפשר לסמוך עליו בעיניים עצומות. כל מה שלמדת בקורס חל כאן: ולידציה (פרק 15), הרשאות (21), בדיקות (22), סודות (25), cache ותורים (26), retry ו־circuit breaker (28). הפרק מראה איך להפעיל אותם על הקופסה החדשה.
