// לפני שה־repo הופך לציבורי (ומראיינים פותחים אותו): סריקה לסודות. סוד שעלה ל־GitHub — נחשב דלוף,
// גם אם מחקת אותו ב־commit הבא (הוא בהיסטוריה). מבטלים אותו ומייצרים חדש
export interface Finding {
  path: string;
  line: number;
  kind: "env-file" | "anthropic-key" | "aws-key" | "private-key" | "db-password" | "jwt-secret";
}

const PLACEHOLDER = /^(\$\{.*\}|<.*>|your[_-]?\w*|password|changeme|secret|xxx+|\*+|)$/i;

export function findSecrets(files: readonly { path: string; content: string }[]): Finding[] {
  const out: Finding[] = [];
  for (const f of files) {
    if (/(^|\/)node_modules\//.test(f.path)) continue;
    const base = f.path.split("/").pop()!;
    const isExample = /\.example$|\.sample$|\.template$/.test(base);
    if (/^\.env(\..+)?$/.test(base) && !isExample) out.push({ path: f.path, line: 0, kind: "env-file" });
    f.content.split("\n").forEach((text, i) => {
      const line = i + 1;
      if (/sk-ant-[A-Za-z0-9_-]{10,}/.test(text)) out.push({ path: f.path, line, kind: "anthropic-key" });
      if (/\bAKIA[0-9A-Z]{16}\b/.test(text)) out.push({ path: f.path, line, kind: "aws-key" });
      if (/-----BEGIN [A-Z ]*PRIVATE KEY-----/.test(text)) out.push({ path: f.path, line, kind: "private-key" });
      const db = /postgres(?:ql)?:\/\/[^:\s/@]+:([^@\s]+)@/.exec(text);
      if (db && !PLACEHOLDER.test(db[1])) out.push({ path: f.path, line, kind: "db-password" });
      const jwt = /^\s*JWT_SECRET\s*=\s*["']?([^"'\s#]*)/.exec(text);
      if (jwt && !isExample && !PLACEHOLDER.test(jwt[1])) out.push({ path: f.path, line, kind: "jwt-secret" });
    });
  }
  return out;
}

💡 רמז 2

// P30-E09
// היסטוריית commits היא חלק מתיק העבודות: מראיין שפותח את ה־repo רואה "fix", "wip", "asdf" — או סיפור.
// הכללים המקובלים: שורת נושא קצרה שאומרת מה השתנה, בלי נקודה בסוף; שורה ריקה; גוף שמסביר למה
const VAGUE = /^(wip|fix(es|ed)?|update[sd]?|changes?|stuff|misc|asdf+|test|tmp|temp|\.+|commit|final|done|more)$/i;

export function lintCommit(message: string): string[] {
  const problems: string[] = [];
  const lines = message.replace(/\r\n/g, "\n").replace(/\n+$/, "").split("\n");
  const subject = (lines[0] ?? "").trim();
  if (!subject) return ["שורת נושא ריקה"];
  if (subject.length > 72) problems.push(`שורת נושא ארוכה (${subject.length} תווים, עד 72)`);
  if (/[.。]$/.test(subject)) problems.push("נקודה בסוף שורת הנושא");
  if (VAGUE.test(subject) || subject.split(/\s+/).length < 2) problems.push("שורת נושא לא אומרת מה השתנה");
  if (lines.length > 1 && lines[1].trim() !== "") problems.push("חסרה שורה ריקה בין הנושא לגוף");
  lines.slice(2).forEach((l, i) => {
    if (l.length > 100) problems.push(`שורה ${i + 3} בגוף ארוכה מ־100 תווים`);
  });
  return problems;
}

⚠️ טעויות נפוצות
  • להיתקע על "מושלם" — commits קטנים עם הודעות סבירות עדיפים על commit ענק אחד עם הודעה מושלמת.

// P30-E20
export interface Finding {
  path: string;
  line: number;
  kind: "env-file" | "anthropic-key" | "db-password";
}

export function findSecrets(files: readonly { path: string; content: string }[]): Finding[] {
  const out: Finding[] = [];
  for (const f of files) {
    const base = f.path.split("/").pop()!;
    // תקלה 1: היה base === ".env" ← .env.production ו־.env.local עברו בלי התראה

    f.content.split("\n").forEach((text, i) => {

      if (/sk-ant-[A-Za-z0-9_-]{10,}/.test(text)) out.push({ path: f.path, line: i + 1, kind: "anthropic-key" });
      const db = /postgres(?:ql)?:\/\/[^:\s/@]+:([^@\s]+)@/.exec(text);
      // תקלה 3: כל כתובת עם סיסמה דווחה — גם YOUR_PASSWORD ב־.env.example ← אלף התראות שווא, ואף אחד לא קורא אותן

    });
  }
  return out;
}

// P30-E39: שם ל־repo
export function repoName(title: string): string {
  let s = title
    .toLowerCase()
    .replace(/[\s_.]+/g, "-")
    .replace(/[^a-z0-9-]/g, "")
    .replace(/-+/g, "-")
    .replace(/^-|-$/g, "");
  s = s.slice(0, 40).replace(/-+$/, "");
  if (!s) throw new Error(`אי אפשר לבנות שם מ־"${title}"`);
  return s;
}

// P30-E40: README של פרויקט — מה חסר?
export function readmeMissing(md: string): string[] {
  const missing: string[] = [];
  const headings = md.match(/^#{2,}\s.*$/gm) ?? [];
  const blocks = md.match(/```[\s\S]*?```/g) ?? [];
  if (!/^# /m.test(md)) missing.push("title");
  if (!/https:\/\//.test(md)) missing.push("live-link");
  if (!blocks.some((b) => /^\s*(npm|docker|pnpm|node)\b/m.test(b))) missing.push("run-commands");
  if (!headings.some((h) => /decisions|החלטות/i.test(h))) missing.push("decisions");

}

// P30-E41: מה צריך להיות ב־.gitignore
const RISKY_DIRS = new Set(["node_modules", "dist", "coverage"]);

function risky(p: string): boolean {
  const parts = p.split("/");
  const name = parts.at(-1)!;
  if (parts.some((s) => RISKY_DIRS.has(s))) return true;
  if ((name === ".env" || name.startsWith(".env.")) && name !== ".env.example") return true;
  return name.endsWith(".pem") || name.endsWith(".key");
}

function matches(pattern: string, p: string): boolean {
  const parts = p.split("/");
  const name = parts.at(-1)!;
  if (pattern.endsWith("/")) return parts.slice(0, -1).includes(pattern.slice(0, -1));
  if (pattern.startsWith("/")) return p === pattern.slice(1) || p.startsWith(pattern.slice(1) + "/");
  if (pattern.startsWith("*.")) return name.endsWith(pattern.slice(1));
  if (pattern === ".env*") return name.startsWith(".env");
  return parts.includes(pattern);
}

export function unignoredRisks(gitignore: string, paths: string[]): string[] {
  const patterns = gitignore
    .split("\n")
    .map((l) => l.trim())
    .filter((l) => l && !l.startsWith("#"));
  return paths.filter((p) => risky(p) && !patterns.some((pat) => matches(pat, p)));
}

‏git עצמו תומך בהרבה יותר (‏**, ‏! לשלילה). לבדיקה אמיתית: ‏git check-ignore -v <path>.

⚠️ טעויות נפוצות
  • ‏.env* ב־.gitignore תופס גם את .env.example — שאמור כן להיות ב־repo. מוסיפים !.env.example.

  license?: string;

  dependencies?: Record<string, string>;
  devDependencies?: Record<string, string>;

const DEV = new Set(["typescript", "jest", "vitest", "eslint", "prettier"]);

export function packageIssues(pkg: Pkg): string[] {
  const issues: string[] = [];
  if (!pkg.engines?.node) issues.push("no-engines");
  if (!pkg.license) issues.push("no-license");
  const test = pkg.scripts?.test;
  if (!test || test.includes("no test specified")) issues.push("no-test-script");
  if (!pkg.scripts?.start) issues.push("no-start-script");
  const deps = Object.entries(pkg.dependencies ?? {});
  for (const [name, v] of [...deps, ...Object.entries(pkg.devDependencies ?? {})]) {
    if (v.trim() === "" || v === "*" || v === "latest") issues.push(`loose:${name}`);
  }
  for (const [name] of deps) {
    if (DEV.has(name) || name.startsWith("@types/")) issues.push(`dev-in-deps:${name}`);
  }
  return issues;
}

// P30-E46: מה ההיסטוריה אומרת
const VAGUE = new Set(["wip", "fix", "update", "stuff", "changes", "asdf"]);

export function historyStats(log: string) {
  const days = new Set<string>();
  const vague: string[] = [];
  let commits = 0;
  for (const line of log.split("\n")) {
    if (!line.trim()) continue;
    const [sha, date, ...rest] = line.split("|");
    if (rest.length === 0) throw new Error(`שורה לא תקינה: ${line}`);
    const subject = rest.join("|").trim();
    commits++;
    days.add(date);
    if (VAGUE.has(subject.toLowerCase()) || subject.split(/\s+/).filter(Boolean).length < 2) vague.push(sha);
  }
  const sorted = [...days].sort();
  let longestGapDays = 0;
  for (let i = 1; i < sorted.length; i++) {
    longestGapDays = Math.max(longestGapDays, Math.round((Date.parse(sorted[i]) - Date.parse(sorted[i - 1])) / 86_400_000));
  }
  return { commits, activeDays: days.size, longestGapDays, vague };
}

// P30-E47: סוד שנמחק — עדיין בהיסטוריה
type Commit = { sha: string; files: Record<string, string> };
type Finding = { kind: string; value: string; firstSha: string; stillPresent: boolean };

const RULES: [string, RegExp][] = [
  ["stripe", /sk_live_[A-Za-z0-9]{16,}/g],
  ["aws", /AKIA[A-Z0-9]{16}/g],
  ["github", /ghp_[A-Za-z0-9]{30,}/g],
];

function findAll(files: Record<string, string>): { kind: string; full: string }[] {
  const out: { kind: string; full: string; file: string; index: number }[] = [];
  for (const file of Object.keys(files).sort()) {
    for (const [kind, re] of RULES) {
      for (const m of files[file].matchAll(re)) out.push({ kind, full: m[0], file, index: m.index ?? 0 });
    }
  }
  return out.sort((a, b) => (a.file === b.file ? a.index - b.index : a.file < b.file ? -1 : 1));
}

export function secretsInHistory(commits: Commit[]): Finding[] {
  const seen = new Map<string, { kind: string; firstSha: string }>();
  for (const c of commits) {
    for (const f of findAll(c.files)) if (!seen.has(f.full)) seen.set(f.full, { kind: f.kind, firstSha: c.sha });
  }
  const last = new Set(commits.length ? findAll(commits.at(-1)!.files).map((f) => f.full) : []);
  return [...seen].map(([full, s]) => ({ kind: s.kind, value: full.slice(0, 8) + "…", firstSha: s.firstSha, stillPresent: last.has(full) }));
}

ממצא עם stillPresent: false הוא עדיין דליפה: הוא ב־git log -p של כל מי שעשה clone. לכן — מבטלים את הסוד (E36).
