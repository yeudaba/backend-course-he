# Noa Cohen

Backend developer (Node.js, TypeScript, PostgreSQL). I like systems that stay correct when two people click "buy" at the same time.

## What I built

- **[coffee-shop](https://github.com/noacohen-dev/coffee-shop)** — an online store API: NestJS, PostgreSQL, Prisma, JWT roles, idempotent payments, and a transaction that never sells stock it doesn't have (tested with 20 concurrent orders). Redis cache and a BullMQ queue for confirmation emails. Docker, GitHub Actions, live demo.
- **[tasks-api](https://github.com/noacohen-dev/tasks-api)** — one API that grew from an in-memory Express server into NestJS with auth, tests and CI. The commit history shows every step.
