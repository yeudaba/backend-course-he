P30-E75 · לחלק שתי דקות בין החלקים 🤖

export function allocateSeconds(weights: Record<string, number>, total: number): Record<string, number>

P30-E80 · ‏"12 מתוך 3" — לשחזר בקוד 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 18, שיעור 3

הסיפור הכי טוב ב־pitch הוא בדיוק זה שאפשר להדגים. בקובץ 30-career/starter/P30-E80.ts (יש בו רק הערה) כתוב וייצא — בלי מסד, עם "מלאי" בזיכרון שכל פעולה בו לוקחת זמן:

type Store = { read(): Promise<number>; write(v: number): Promise<void>; decrementIfAvailable(): Promise<boolean> };
export function createStore(stock: number, delayMs: number): Store
export function naiveBuy(store: Store): Promise<boolean>
export function safeBuy(store: Store): Promise<boolean>
export function simulate(buy: (s: Store) => Promise<boolean>, stock: number, buyers: number, delayMs: number): Promise<{ sold: number; finalStock: number }>
  • ‏createStore — כל פעולה מחכה delayMs ואז מבצעת. ‏read מחזיר את המלאי; ‏write קובע אותו; ‏decrementIfAvailable — אחרי ההמתנה, באותו צעד סינכרוני: אם המלאי ≥ 1 מוריד 1 ומחזיר true, אחרת false (כמו UPDATE … WHERE stock >= 1).
  • ‏naiveBuy — ‏read; אם יש — write(stock - 1) ו־true; אחרת false.
  • ‏safeBuy — ‏decrementIfAvailable.
  • ‏simulate — חנות חדשה, buyers קניות במקביל; ‏sold — כמה החזירו true; ‏finalStock — read בסוף.

🔗 איך זה מתחבר: race condition ו־UPDATE מותנה מפרק 18, ו־Promise.all מפרק 10 — והשיעור: הסיפור שאתה מספר, כקוד שאפשר להריץ.
