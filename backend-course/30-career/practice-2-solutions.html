## About
I build backend systems with Node.js, TypeScript and PostgreSQL.

My main project is coffee-shop, an online store API with roles, a cart, idempotent payments and an order flow that never sells stock it does not have. I proved that with a test that sends 20 concurrent orders for the last 3 units. It runs in Docker, deploys from GitHub Actions, and has a live demo.

Before that I built tasks-api in 8 stages, from a simple Express server to NestJS with authentication, 50+ tests and CI. The commit history shows how and why each step changed.

What I enjoy most: data modeling, transactions, and making failure cases explicit instead of hoping they won't happen.

I am looking for a junior backend role. Happy to walk through any of the code: noa.cohen.dev@gmail.com
