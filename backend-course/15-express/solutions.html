P15-E26 · API משימות — מקובץ ריק 🤖 ✍️ מאפס רמה 3

💡 רמז 1

הסדר בקובץ: imports (express, ‏z מ־zod) ← type Task ← schema ← createApp. בתוך createApp: ‏express.json(), המערך ו־nextId, ארבעת ה־routes, ובסוף error handler עם 4 פרמטרים.

💡 רמז 2

schema: z.object({ title: z.string().trim().min(1).max(100), done: z.boolean().default(false) }). אחרי safeParse: ‏result.error.issues.map((i) => i.path.join(".")), ו־new Set כדי שכל שם יופיע פעם אחת.

✅ פתרון
// P15-E26: API משימות מאפס
import express, { type Request, type Response, type NextFunction } from "express";
import { z } from "zod";

type Task = { id: number; title: string; done: boolean };

const newTaskSchema = z.object({
  title: z.string().trim().min(1).max(100),
  done: z.boolean().default(false),
});

export function createApp() {
  const app = express();
  app.use(express.json());
  const tasks: Task[] = [];
  let nextId = 1;

  const findTask = (id: string) => tasks.find((t) => t.id === Number(id));

  app.get("/tasks", (req, res) => {
    const { done } = req.query;
    if (done === "true" || done === "false") {
      res.json(tasks.filter((t) => t.done === (done === "true")));
      return;
    }
    res.json(tasks);
  });

  app.get("/tasks/:id", (req, res) => {
    const task = findTask(req.params.id);
    if (!task) {
      res.status(404).json({ error: "המשימה לא נמצאה" });
      return;
    }
    res.json(task);
  });

  app.post("/tasks", (req, res) => {
    const result = newTaskSchema.safeParse(req.body);
    if (!result.success) {
      const fields = [...new Set(result.error.issues.map((i) => i.path.join(".")))];
      res.status(400).json({ error: "קלט לא תקין", fields });
      return;
    }
    const task = { id: nextId++, ...result.data };
    tasks.push(task);
    res.status(201).location(`/tasks/${task.id}`).json(task);
  });

  app.delete("/tasks/:id", (req, res) => {
    const task = findTask(req.params.id);
    if (!task) {
      res.status(404).json({ error: "המשימה לא נמצאה" });
      return;
    }
    tasks.splice(tasks.indexOf(task), 1);
    res.sendStatus(204);
  });

  app.use((err: { type?: string }, req: Request, res: Response, next: NextFunction) => {
    if (err.type === "entity.parse.failed") {
      res.status(400).json({ error: "JSON לא תקין" });
      return;
    }
    next(err);
  });

  return app;
}

שים לב איפה כל דבר נמצא. ה־schema מחוץ ל־createApp: הוא קבוע, ואין סיבה לבנות אותו מחדש. הנתונים (tasks, ‏nextId) בפנים, כדי שכל אפליקציה תתחיל נקייה, כמו ב־P15-E08.

findTask משרתת שני routes. ‏Number("abc") הוא NaN, ו־NaN לא שווה לאף id — אז גם id שאינו מספר מקבל 404, בלי בדיקה נפרדת.

...result.data ולא ...req.body: אחרי Zod יש לנו את הערכים אחרי trim ועם ברירת המחדל של done. ושדה מיותר שהלקוח שלח (למשל id: 999) לא נכנס, כי z.object מסיר שדות שלא הוגדרו.

ההדגמה בסוף הקובץ מפעילה את השרת על פורט 0 (מערכת ההפעלה בוחרת פורט פנוי), שולחת שלוש בקשות, וסוגרת אותו.

⚠️ טעויות נפוצות
  • const task = { id: nextId++, ...req.body } — עוקף את Zod: הכותרת לא עוברת trim, והלקוח יכול לקבוע לעצמו id.
  • מערך המשימות ברמת הקובץ — בדיקה אחת "מלכלכת" את הבאה.
  • req.query.done === true — ב־query הכול מחרוזות, ובמקרה הזה זה "true".
  • לשכוח return אחרי res.status(404).json(...) — הקוד ממשיך, ומגיעים ל־Cannot set headers after they are sent (P15-E21).
  • error handler עם 3 פרמטרים — Express לא מזהה אותו כ־error handler.

P15-E27 · סכמת הרשמה עם regex 🤖 🔁 חזרה רמה 3

💡 רמז 1

username: z.string().trim().toLowerCase().regex(/^[a-z][a-z0-9_]{2,15}$/, "..."). האות הראשונה היא [a-z], ואחריה עוד 2–15 תווים — כלומר 3–16 בסך הכול.

password: אפשר לשרשר כמה .regex(), כל אחד עם הודעה משלו: .regex(/[A-Z]/, "...") ו־.regex(/\d/, "..."). כאן אין ^ ו־$: מספיק שהתו מופיע איפשהו.

💡 רמז 2

phone בשלושה שלבים: .transform((s) => s.replace(/[\s-]/g, "")) (מנקים) ← .pipe(z.string().regex(/^(\+972|0)5\d{8}$/, "...")) (בודקים את המחרוזת הנקייה) ← .transform((s) => s.replace(/^\+972/, "0")) (מאחדים צורה). ‏pipe מעביר את התוצאה של ה־transform לסכמה נוספת.

✅ פתרון

שני סוגים של regex כאן. ב־username ובטלפון יש ^...$: כל המחרוזת חייבת להתאים. בסיסמה אין: שואלים רק אם יש לפחות תו אחד כזה. ‏/[A-Z]/ בלי עוגנים הוא "יש אות גדולה איפשהו".

בטלפון הסדר חשוב: קודם מנקים, אחר כך בודקים, ובסוף מאחדים לצורה אחת. כך במסד נשמר רק 0501234567, ולא ארבע כתיבות שונות של אותו מספר. אחרת חיפוש לפי טלפון לא ימצא את המשתמש.

בסיסמה Zod ממשיך לבדוק גם אחרי שבדיקה נכשלה, ולכן "secret" מקבל שלוש הודעות. המשתמש רואה את כל מה שחסר בבת אחת.

⚠️ טעויות נפוצות
  • .regex(/[a-z0-9_]{3,16}/) בלי ^ ו־$ — ‏"dana!!!" עובר, כי "dana" נמצא בתוכה.
  • .toLowerCase() אחרי .regex() — ‏"Dana" נכשל לפני שהומר.
  • /^(+972|0)5\d{8}$/ — ‏+ הוא תו מיוחד ב־regex ("פעם אחת או יותר"). צריך \+.
  • s.replace("-", "") עם מחרוזת — מחליף רק את המקף הראשון. ב־regex עם g מוחלפים כולם.

P15-E28 · סכום עגלה 🤖 🔁 חזרה רמה 3

💡 רמז 1

קיבוץ: const qtyBySku = new Map<string, number>(), ובלולאה על items: ‏qtyBySku.set(sku, (qtyBySku.get(sku) ?? 0) + qty). ‏Map שומרת את סדר ההכנסה, ולכן הסדר נשמר מעצמו.

💡 רמז 2

לולאה שנייה, for (const [sku, qty] of qtyBySku): מוצר חסר ← 404 ו־return. אחרת lines.push(...). ובסוף: lines.reduce((sum, line) => sum + line.subtotal, 0).

✅ פתרון
// P15-E28: סכום עגלה
import express from "express";
import { z } from "zod";

export type Product = { name: string; price: number };

const cartSchema = z.object({
  items: z
    .array(z.object({ sku: z.string().min(1), qty: z.number().int().min(1).max(99) }))
    .min(1),
});

export function createApp(catalog: Map<string, Product>) {
  const app = express();
  app.use(express.json());

  app.post("/cart/total", (req, res) => {
    const result = cartSchema.safeParse(req.body);
    if (!result.success) {
      res.status(400).json({ error: "קלט לא תקין" });
      return;
    }

    // אותו sku פעמיים — מאחדים (Map שומרת על סדר ההופעה הראשונה)
    const qtyBySku = new Map<string, number>();
    for (const { sku, qty } of result.data.items) {
      qtyBySku.set(sku, (qtyBySku.get(sku) ?? 0) + qty);
    }

    const lines = [];
    for (const [sku, qty] of qtyBySku) {
      const product = catalog.get(sku);
      if (!product) {
        res.status(404).json({ error: `מוצר לא קיים: ${sku}` });
        return;
      }
      lines.push({ sku, name: product.name, qty, subtotal: product.price * qty });
    }

    const total = lines.reduce((sum, line) => sum + line.subtotal, 0);
    res.json({ lines, total });
  });

  return app;
}

]);

P15-E03 · מה הלקוח מקבל? רמה 1

💡 רמז 1

אחת מהן לא מסיימת את התשובה.

💡 רמז 2

res.send עם מחרוזת שולח HTML.

✅ פתרון
  1. 200, application/json, {"ok":true}
  2. 201, JSON, {"id":5}
  3. 204, בלי Content-Type, בלי גוף

  • (5) הוא באג נפוץ מאוד אחרי שינויים בקוד: מישהו מחק את ה־.json(...).

P15-E06 · שלום Express 🤖 רמה 2

// P15-E06
import express from "express";

export function createApp() {
  const app = express();

  app.get("/hello", (req, res) => {
    const name = typeof req.query.name === "string" && req.query.name !== "" ? req.query.name : "אורח";
    res.json({ message: `שלום ${name}` });
  });

  app.get("/add/:a/:b", (req, res) => {
    const a = Number(req.params.a);
    const b = Number(req.params.b);
    if (!Number.isFinite(a) || !Number.isFinite(b)) {
      res.status(400).json({ error: "a ו־b חייבים להיות מספרים" });
      return;
    }
    res.json({ sum: a + b });
  });

  return app;
}

✅ פתרון
// P15-E07
import express from "express";

export interface Product {
  id: number;
  name: string;
  price: number;
}

export function createApp(products: Product[]) {
  const app = express();

  app.get("/products", (req, res) => {
    const max = req.query.maxPrice;
    res.json(typeof max === "string" ? products.filter((p) => p.price <= Number(max)) : products);
  });

  app.get("/products/:id", (req, res) => {

import type { Request, Response, NextFunction } from "express";
import type { ZodType } from "zod";

type Part = "body" | "query" | "params";

export function validate(schemas: Partial<Record<Part, ZodType>>) {
  return (req: Request, res: Response, next: NextFunction) => {
    const details: { path: string; message: string }[] = [];
    const clean: Partial<Record<Part, unknown>> = {};
    for (const part of ["body", "query", "params"] as const) {
      const schema = schemas[part];
      if (!schema) continue;
      const result = schema.safeParse(req[part]);
      if (result.success) clean[part] = result.data;
      else for (const i of result.error.issues) details.push({ path: [part, ...i.path].join("."), message: i.message });
    }
    if (details.length > 0) {
      res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "קלט לא תקין", details } });
      return;
    }
    if ("body" in clean) req.body = clean.body;
    if ("query" in clean) res.locals.query = clean.query;
    if ("params" in clean) res.locals.params = clean.params;
    next();
  };
}

  email: string;

export class InMemoryUsersRepository {
  #users: User[] = [];
  #nextId = 1;
  findAll(): User[] {
    return [...this.#users];
  }
  findById(id: number): User | undefined {
    return this.#users.find((u) => u.id === id);
  }
  findByEmail(email: string): User | undefined {
    return this.#users.find((u) => u.email.toLowerCase() === email.toLowerCase());
  }
  insert(data: Omit<User, "id">): User {
    const user = { id: this.#nextId++, ...data };
    this.#users.push(user);
    return user;
  }
  delete(id: number): boolean {

export function requireApiKey(keys: Map<string, string>) {
  return (req: Request, res: Response, next: NextFunction) => {
    const key = req.get("x-api-key");
    if (!key) {

    next();
  };
}

// P15-E19
import express from "express";

type Forecast = { tempC: number; summary: string };

class TimeoutError extends Error {}

function withTimeout<T>(promise: Promise<T>, ms: number): Promise<T> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timeout = new Promise<never>((_, reject) => {
    timer = setTimeout(() => reject(new TimeoutError()), ms);
  });
  return Promise.race([promise, timeout]).finally(() => clearTimeout(timer));
}

export function createApp({ getForecast }: { getForecast: (city: string) => Promise<Forecast | null> }) {
  const app = express();

    let forecast: Forecast | null;
    try {
      forecast = await withTimeout(getForecast(city), 1000);
    } catch (err) {
      if (err instanceof TimeoutError) {
        res.status(504).json({ error: { code: "UPSTREAM_TIMEOUT", message: "שירות מזג האוויר לא ענה בזמן" } });
        return;
      }
      console.error(err);
      res.status(502).json({ error: { code: "UPSTREAM_ERROR", message: "שירות מזג האוויר לא זמין" } });
      return;
    }
    if (!forecast) {
      res.status(404).json({ error: { code: "CITY_NOT_FOUND", message: "עיר לא מוכרת" } });
      return;
    }
    res.json({ city, ...forecast });
  });
  return app;
}

✅ פתרון
// P15-E24
import express, { Router, type Request, type Response, type NextFunction } from "express";
import { z, type ZodType } from "zod";

class HttpError extends Error {
  status: number;
  code: string;
  constructor(status: number, code: string, message: string) {
    super(message);
    this.status = status;
    this.code = code;
  }
}

interface Book { id: number; title: string; author: string; copies: number; available: number }
interface Loan { id: number; bookId: number; member: string; loanedAt: string; dueAt: string; returnedAt: string | null }

const DAY = 24 * 60 * 60 * 1000;

class LibraryService {
  books: Book[] = [];
  loans: Loan[] = [];
  now: () => Date;
  constructor(now: () => Date) {
    this.now = now;
  }
  createBook(data: { title: string; author: string; copies: number }) {
    const book = { id: this.books.length + 1, ...data, available: data.copies };
    this.books.push(book);
    return book;
  }
  listBooks({ author, available }: { author?: string; available?: boolean }) {
    return this.books.filter(
      (b) => (!author || b.author.toLowerCase().includes(author.toLowerCase())) && (!available || b.available > 0)
    );
  }
  getBook(id: number) {
    const book = this.books.find((b) => b.id === id);
    if (!book) throw new HttpError(404, "BOOK_NOT_FOUND", "הספר לא נמצא");
    return book;
  }
  lend(bookId: number, member: string) {
    const book = this.getBook(bookId);
    if (this.loans.some((l) => l.bookId === bookId && l.member === member && !l.returnedAt)) {
      throw new HttpError(409, "ALREADY_BORROWED", "החבר כבר מחזיק את הספר");
    }
    if (book.available === 0) throw new HttpError(409, "NO_COPIES", "אין עותק פנוי");
    book.available--;
    const at = this.now();
    const loan = {
      id: this.loans.length + 1,
      bookId,
      member,
      loanedAt: at.toISOString(),
      dueAt: new Date(at.getTime() + 14 * DAY).toISOString(),
      returnedAt: null,
    };
    this.loans.push(loan);
    return loan;
  }
  returnLoan(id: number) {
    const loan = this.loans.find((l) => l.id === id);
    if (!loan) throw new HttpError(404, "LOAN_NOT_FOUND", "ההשאלה לא נמצאה");
    if (loan.returnedAt) throw new HttpError(409, "ALREADY_RETURNED", "הספר כבר הוחזר");
    loan.returnedAt = this.now().toISOString();
    this.getBook(loan.bookId).available++;
    return loan;
  }
  overdue() {
    const t = this.now().getTime();
    return this.loans.filter((l) => !l.returnedAt && Date.parse(l.dueAt) < t);
  }
}

function parse<T>(schema: ZodType<T>, value: unknown): T {
  const r = schema.safeParse(value);
  if (!r.success) {
    const err = new HttpError(400, "VALIDATION_ERROR", "קלט לא תקין");
    Object.assign(err, { details: r.error.issues.map((i) => ({ path: i.path.join("."), message: i.message })) });
    throw err;
  }
  return r.data;
}

const idSchema = z.coerce.number().int().positive();
const bookSchema = z.object({
  title: z.string().trim().min(1).max(200),
  author: z.string().trim().min(1).max(200),
  copies: z.number().int().min(1).max(100),
});
const listSchema = z.object({
  author: z.string().optional(),
  available: z.enum(["true", "false"]).transform((v) => v === "true").optional(),
  page: z.coerce.number().int().min(1).default(1),
  limit: z.coerce.number().int().min(1).max(50).default(10),
});
const loanSchema = z.object({ member: z.string().trim().min(1).max(100) });

export function createApp({ now = () => new Date() }: { now?: () => Date } = {}) {
  const service = new LibraryService(now);
  const app = express();
  app.use(express.json());

  const books = Router();
  books.post("/", (req, res) => {
    const book = service.createBook(parse(bookSchema, req.body));
    res.status(201).location(`/books/${book.id}`).json(book);
  });
  books.get("/", (req, res) => {
    const { page, limit, ...filters } = parse(listSchema, req.query);
    const all = service.listBooks(filters);
    const data = all.slice((page - 1) * limit, page * limit);
    res.json({ data, meta: { page, limit, total: all.length, totalPages: Math.ceil(all.length / limit) } });
  });
  books.get("/:id", (req, res) => {
    res.json(service.getBook(parse(idSchema, req.params.id)));
  });
  books.post("/:id/loans", (req, res) => {
    const { member } = parse(loanSchema, req.body);
    res.status(201).json(service.lend(parse(idSchema, req.params.id), member));
  });

  const loans = Router();
  loans.get("/overdue", (req, res) => {
    res.json(service.overdue());
  });
  loans.post("/:id/return", (req, res) => {
    res.json(service.returnLoan(parse(idSchema, req.params.id)));
  });

  app.use("/books", books);
  app.use("/loans", loans);
  app.use((req, res) => {
    res.status(404).json({ error: { code: "NOT_FOUND", message: "לא נמצא" } });
  });
  app.use((err: unknown, req: Request, res: Response, next: NextFunction) => {
    if (err instanceof HttpError) {
      const { details } = err as HttpError & { details?: unknown };
      res.status(err.status).json({ error: { code: err.code, message: err.message, ...(details ? { details } : {}) } });
      return;
    }
    if (typeof err === "object" && err !== null && "type" in err && err.type === "entity.parse.failed") {
      res.status(400).json({ error: { code: "INVALID_JSON", message: "JSON לא תקין" } });
      return;
    }
    console.error(err);
    res.status(500).json({ error: { code: "INTERNAL", message: "שגיאה פנימית" } });
  });
  return app;
}

P15-E25 · אתגר: Idempotency-Key 🤖 רמה 5

💡 רמז 1

💡 רמז 2

✅ פתרון
// P15-E25
import express, { type Request, type Response, type NextFunction } from "express";

type Entry = { requestBody: string; state: "running" | "done"; status?: number; body?: unknown };

export function idempotency() {
  const store = new Map<string, Entry>();

  return (req: Request, res: Response, next: NextFunction) => {
    const key = req.get("idempotency-key");
    if (!key) {
      res.status(400).json({ error: { code: "MISSING_IDEMPOTENCY_KEY", message: "חסר Idempotency-Key" } });
      return;
    }
    const requestBody = JSON.stringify(req.body ?? null);
    const existing = store.get(key);
    if (existing) {
      if (existing.requestBody !== requestBody) {
        res.status(422).json({ error: { code: "IDEMPOTENCY_KEY_REUSED", message: "המפתח שומש לבקשה אחרת" } });
        return;
      }
      if (existing.state === "running") {
        res.status(409).json({ error: { code: "REQUEST_IN_PROGRESS", message: "הבקשה המקורית עדיין מעובדת" } });
        return;
      }
      res.status(existing.status!).set("Idempotent-Replayed", "true").json(existing.body);
      return;
    }

    const entry: Entry = { requestBody, state: "running" };
    store.set(key, entry);
    const originalJson = res.json.bind(res);
    res.json = (body) => {
      if (res.statusCode >= 500) store.delete(key); // תקלה זמנית — מותר לנסות שוב
      else Object.assign(entry, { state: "done", status: res.statusCode, body });
      return originalJson(body);
    };
    next();
  };
}

export function createApp() {
  const app = express();
  app.use(express.json());
  const orders: Record<string, unknown>[] = [];

  app.get("/orders", (req, res) => {
    res.json(orders);
  });
  app.post("/orders", idempotency(), async (req, res) => {
    await new Promise((r) => setTimeout(r, 50));
    const order = { id: orders.length + 1, ...req.body };
    orders.push(order);
    res.status(201).json(order);
  });
  return app;
}
