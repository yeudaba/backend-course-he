P15-E57 · תכנון API למרפאה 🧠 הבנה רמה 1

💡 רמז 1

שמות עצם ברבים, פרמטרים לסינון ב־query, פעולה שאינה CRUD — פועל בסוף (/cancel).

💡 רמז 2

"ביטול" שלא מוחק את התור הוא לא DELETE.

✅ פתרון
  1. GET /doctors?specialty=cardiology ← 200.
  2. GET /doctors/4/slots?date=2026-11-20 ← 200 (תורים פנויים "שייכים" לרופא).
  3. POST /appointments עם { doctorId, patientId, startsAt } ← 201 + Location; תפוס ← 409.
  4. GET /patients/17/appointments?sort=-startsAt&page=1&limit=10 ← 200 עם { data, meta }.
  5. PATCH /appointments/88 עם { startsAt } ← 200.
  6. POST /appointments/88/cancel ← 200 (התור עם status: "cancelled"). פעולה עם משמעות עסקית — לא DELETE.
  7. DELETE /patients/17 ← 204.

התור הוא משאב בפני עצמו (/appointments) — שם יוצרים ומשנים אותו. הכתובות המקוננות הן "תצוגות" נוחות לרשימות: התורים של רופא, התורים של מטופל. עד שתי רמות; לא /doctors/4/patients/17/appointments.

⚠️ טעויות נפוצות
  • DELETE /appointments/88 לביטול — המידע נעלם, ואין דרך לדעת שהמטופל ביטל (חשוב לדוחות, לחיוב על אי־הגעה).

💡 רמז 1

P15-E59 · מה ה־Router רואה? 🧠 הבנה רמה 2

💡 רמז 1

בתוך ה־router, הכתובות יחסיות לקידומת — req.baseUrl הוא הקידומת, ו־req.path מה שאחריה.

P15-E60 · איזו שכבה אחראית? 🧠 הבנה רמה 1

💡 רמז 1

routes — כל מה שקשור ל־HTTP. service — חוקים של התחום. repository — איך שומרים ושולפים.

💡 רמז 2

שאל: אם מחר יהיה גם כלי שורת פקודה שמשתמש באותה לוגיקה — מה הוא צריך, ומה לא?

✅ פתרון
  1. routes — פרמטר של כתובת הוא עניין של HTTP.
  2. service — חוק עסקי ("אימייל ייחודי"); הוא שואל את ה־repository.
  3. repository — רק הוא יודע איך הנתונים שמורים.
  4. service מחליט "לא קיים" וזורק — בשיעור זה HttpError; בגרסה נקייה יותר (P15-E54) השגיאה היא של התחום, וה־error handler מתרגם ל־404.
  5. routes.
  6. service — חוק של התחום.
  7. service (או פונקציית עזר שהוא קורא לה): ה־repository מחזיר נתונים ו־total, וה־route רק שולח.
  8. repository.

המבחן: כלי שורת פקודה ישתמש ב־service וב־repository כמו שהם — ולא יצטרך שום דבר מ־routes.

⚠️ טעויות נפוצות
  • לשים חוקים עסקיים ב־route "כי שם מגיע הקלט" — אז כל ממשק חדש (תור, CLI, cron) צריך להעתיק אותם.

P15-E61 · code מול message 🧠 הבנה רמה 1

💡 רמז 1

בשיעור: "code — קבוע, באנגלית, בשביל קוד. message — לבני אדם, ואפשר לשנות אותו".

💡 רמז 2

details — כשצריך לומר איזה שדה לא תקין.

✅ פתרון
  1. הבדיקה תיכשל בשקט: במקום מסך "לא נמצא", המשתמש יראה שגיאה כללית. אף בדיקה בשרת לא תתפוס את זה — השרת "רק שינה טקסט".
  2. if (err.code === "TASK_NOT_FOUND") — ואת message רק מציגים.
  3. TASK_NOT_FOUND (404), ‏VALIDATION_ERROR (400), ‏EMAIL_TAKEN (409), ‏TASK_COMPLETED (409), ‏VALIDATION_ERROR (400).
  4. בשתי שגיאות הקלט: details: [{ "path": "title", "message": "חובה" }], ‏[{ "path": "page", ... }] — כדי שהטופס יסמן את השדה הנכון.
⚠️ טעויות נפוצות
  • להמציא code לכל שדה (TITLE_EMPTY, ‏PAGE_INVALID...) — עשרות קודים. קוד אחד לשגיאות קלט, והפירוט ב־details.

P15-E13 · רשימה עם pagination 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

Math.ceil(total / limit)

💡 רמז 2

schema.safeParse(req.query)

✅ פתרון
// P15-E13
import express from "express";
import { z } from "zod";

export function paginate<T>(items: T[], page: number, limit: number) {
  const start = (page - 1) * limit;
  return {
    data: items.slice(start, start + limit),
    meta: { page, limit, total: items.length, totalPages: Math.ceil(items.length / limit) },
  };
}

const querySchema = z.object({
  page: z.coerce.number().int().min(1).default(1),
  limit: z.coerce.number().int().min(1).max(50).default(10),
});

export function createApp(products: unknown[]) {
  const app = express();
  app.get("/products", (req, res) => {
    const q = querySchema.safeParse(req.query);
    if (!q.success) {
      res.status(400).json({
        error: {
          code: "VALIDATION_ERROR",
          message: "קלט לא תקין",
          details: q.error.issues.map((i) => ({ path: i.path.join("."), message: i.message })),
        },
      });
      return;
    }
    res.json(paginate(products, q.data.page, q.data.limit));
  });
  return app;
}
⚠️ טעויות נפוצות
  • להחזיר 404 לעמוד ריק — העמוד "קיים", פשוט אין בו פריטים. הלקוח רואה totalPages ויודע לעצור.

P15-E16 · Router ושכבות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

ה־service לא מכיר את req/res — רק זורק HttpError. ה־router לא מכיר את המערך — רק קורא ל־service.

💡 רמז 2

constructor(repo: InMemoryUsersRepository) { this.repo = repo; } — בלי private repo בפרמטר (Node לא תומך ב־TypeScript הזה בלי קומפילציה).

✅ פתרון
// P15-E16
import express, { Router, type Request, type Response, type NextFunction } from "express";
import { z } from "zod";

export class HttpError extends Error {
  status: number;
  code: string;
  constructor(status: number, code: string, message: string) {
    super(message);
    this.status = status;
    this.code = code;
  }
}

export interface User {
  id: number;
  name: string;
  email: string;
}

export class InMemoryUsersRepository {
  #users: User[] = [];
  #nextId = 1;
  findAll(): User[] {
    return [...this.#users];
  }
  findById(id: number): User | undefined {
    return this.#users.find((u) => u.id === id);
  }
  findByEmail(email: string): User | undefined {
    return this.#users.find((u) => u.email.toLowerCase() === email.toLowerCase());
  }
  insert(data: Omit<User, "id">): User {
    const user = { id: this.#nextId++, ...data };
    this.#users.push(user);
    return user;
  }
  delete(id: number): boolean {
    const before = this.#users.length;
    this.#users = this.#users.filter((u) => u.id !== id);
    return this.#users.length < before;
  }
}

export class UsersService {
  repo: InMemoryUsersRepository;
  constructor(repo: InMemoryUsersRepository) {
    this.repo = repo;
  }
  list() {
    return this.repo.findAll();
  }
  get(id: number) {
    const user = this.repo.findById(id);
    if (!user) throw new HttpError(404, "USER_NOT_FOUND", "המשתמש לא נמצא");
    return user;
  }
  create(data: { name: string; email: string }) {
    if (this.repo.findByEmail(data.email)) throw new HttpError(409, "EMAIL_TAKEN", "האימייל כבר רשום");
    return this.repo.insert(data);
  }
  remove(id: number) {
    if (!this.repo.delete(id)) throw new HttpError(404, "USER_NOT_FOUND", "המשתמש לא נמצא");
  }
}

const createUserSchema = z.object({ name: z.string().trim().min(1).max(50), email: z.email() });

export function createUsersRouter(service: UsersService) {
  const router = Router();
  router.get("/", (req, res) => {
    res.json(service.list());
  });
  router.get("/:id", (req, res) => {
    res.json(service.get(Number(req.params.id)));
  });
  router.post("/", (req, res) => {
    const parsed = createUserSchema.safeParse(req.body);
    if (!parsed.success) {
      const details = parsed.error.issues.map((i) => ({ path: i.path.join("."), message: i.message }));
      res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "קלט לא תקין", details } });
      return;
    }
    const user = service.create(parsed.data);
    res.status(201).location(`/users/${user.id}`).json(user);
  });
  router.delete("/:id", (req, res) => {
    service.remove(Number(req.params.id));
    res.sendStatus(204);
  });
  return router;
}

export function createApp(service = new UsersService(new InMemoryUsersRepository())) {
  const app = express();
  app.use(express.json());
  app.use("/users", createUsersRouter(service));
  app.use((err: unknown, req: Request, res: Response, next: NextFunction) => {
    if (err instanceof HttpError) {
      res.status(err.status).json({ error: { code: err.code, message: err.message } });
      return;
    }
    next(err);
  });
  return app;
}

שים לב: service.get זורק, וה־route לא תופס — השגיאה "עולה" ל־error handler. בגלל זה ה־routes קצרים כל כך.

⚠️ טעויות נפוצות
  • לבדוק אימייל כפול ב־router במקום ב־service — אז כל ממשק אחר (CLI, תור) ידלג על החוק.

P15-E19 · שירות חיצוני 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

handler יכול להיות async. timeout: Promise.race עם Promise שנדחה אחרי זמן (פרק 10).

💡 רמז 2

סמן את שגיאת ה־timeout (למשל מחלקה משלה) כדי להבדיל אותה משגיאת השירות.

✅ פתרון
// P15-E19
import express from "express";

type Forecast = { tempC: number; summary: string };

class TimeoutError extends Error {}

function withTimeout<T>(promise: Promise<T>, ms: number): Promise<T> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timeout = new Promise<never>((_, reject) => {
    timer = setTimeout(() => reject(new TimeoutError()), ms);
  });
  return Promise.race([promise, timeout]).finally(() => clearTimeout(timer));
}

export function createApp({ getForecast }: { getForecast: (city: string) => Promise<Forecast | null> }) {
  const app = express();
  app.get("/weather/:city", async (req, res) => {
    const city = req.params.city;
    let forecast: Forecast | null;
    try {
      forecast = await withTimeout(getForecast(city), 1000);
    } catch (err) {
      if (err instanceof TimeoutError) {
        res.status(504).json({ error: { code: "UPSTREAM_TIMEOUT", message: "שירות מזג האוויר לא ענה בזמן" } });
        return;
      }
      console.error(err);
      res.status(502).json({ error: { code: "UPSTREAM_ERROR", message: "שירות מזג האוויר לא זמין" } });
      return;
    }
    if (!forecast) {
      res.status(404).json({ error: { code: "CITY_NOT_FOUND", message: "עיר לא מוכרת" } });
      return;
    }
    res.json({ city, ...forecast });
  });
  return app;
}

clearTimeout ב־finally חשוב: בלעדיו, כל בקשה משאירה טיימר פתוח לשנייה, וגם מונעת מבדיקות להסתיים מהר.

⚠️ טעויות נפוצות
  • להחזיר 500 על כל שגיאה של שירות חיצוני — הניטור יצביע על הקוד שלך, כשהבעיה אצל הספק.

P15-E23 · ה־Promise שהפך ל־{} 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

JSON.stringify(Promise.resolve(5)) הוא "{}".

💡 רמז 2

forEach לא מחכה ל־callback async. ושגיאה בתוך .then שאף אחד לא מחזיר — אף אחד לא תופס.

✅ פתרון
// P15-E23: מתוקן
import express, { type Request, type Response, type NextFunction } from "express";

class NotFoundError extends Error {}

const orders = new Map([[1, { id: 1, itemIds: [10, 11, 10] }]]);
const prices = new Map([[10, 30], [11, 25]]);
const delay = () => new Promise((r) => setTimeout(r, 5));

export const repo = {
  async findOrder(id: number) {
    await delay();
    const order = orders.get(id);
    if (!order) throw new NotFoundError(`הזמנה ${id} לא נמצאה`);
    return order;
  },
  async priceOf(itemId: number) {
    await delay();
    return prices.get(itemId) ?? 0;
  },
};

export function createApp() {
  const app = express();

  app.get("/orders/:id", async (req, res) => {
    const order = await repo.findOrder(Number(req.params.id));
    res.json(order);
  });

  app.get("/orders/:id/total", async (req, res) => {
    const order = await repo.findOrder(Number(req.params.id));
    const itemPrices = await Promise.all(order.itemIds.map((id) => repo.priceOf(id)));
    res.json({ total: itemPrices.reduce((a, b) => a + b, 0) });
  });

  app.use((err: unknown, req: Request, res: Response, next: NextFunction) => {
    if (err instanceof NotFoundError) {
      res.status(404).json({ error: { code: "NOT_FOUND", message: err.message } });
      return;
    }
    next(err);
  });

  return app;
}

Express 5 מעביר ל־error handler רק Promise שה־handler מחזיר. repo.findOrder(...).then(...) בלי return (או בלי async/await) — השגיאה "יתומה", והבקשה נשארת בלי תשובה.

⚠️ טעויות נפוצות
  • להוסיף await לפני order.itemIds.forEach(async ...) — forEach מחזיר undefined, אין למה לחכות. צריך Promise.all + map.

P15-E26 · API משימות — מקובץ ריק 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

הסדר בקובץ: imports (express, ‏z מ־zod) ← type Task ← schema ← createApp. בתוך createApp: ‏express.json(), המערך ו־nextId, ארבעת ה־routes, ובסוף error handler עם 4 פרמטרים.

💡 רמז 2

schema: z.object({ title: z.string().trim().min(1).max(100), done: z.boolean().default(false) }). אחרי safeParse: ‏result.error.issues.map((i) => i.path.join(".")), ו־new Set כדי שכל שם יופיע פעם אחת.

✅ פתרון
// P15-E26: API משימות מאפס
import express, { type Request, type Response, type NextFunction } from "express";
import { z } from "zod";

type Task = { id: number; title: string; done: boolean };

const newTaskSchema = z.object({
  title: z.string().trim().min(1).max(100),
  done: z.boolean().default(false),
});

export function createApp() {
  const app = express();
  app.use(express.json());
  const tasks: Task[] = [];
  let nextId = 1;

// P15-E62: מיון לפי כמה שדות
function compare(a: unknown, b: unknown): number {
  if (typeof a === "number" && typeof b === "number") return a - b;
  return String(a).localeCompare(String(b));
}

export function sortBy<T>(items: T[], sort: string, allowed: string[]): T[] {
  const keys = sort
    .split(",")
    .map((s) => s.trim())
    .filter(Boolean)
    .map((s) => (s.startsWith("-") ? { field: s.slice(1), dir: -1 } : { field: s, dir: 1 }));
  for (const { field } of keys) {
    if (!allowed.includes(field)) throw new Error(`אי אפשר למיין לפי ${field}`);
  }
  return [...items].sort((a, b) => {
    for (const { field, dir } of keys) {
      const c = compare((a as Record<string, unknown>)[field], (b as Record<string, unknown>)[field]);
      if (c !== 0) return c * dir;
    }
    return 0;
  });
}

import express from "express";

export type Order = { id: number; status: "pending" | "paid" | "shipped" | "cancelled"; cancelledAt?: string; cancelReason?: string | null };

export function createApp(orders: Order[]) {
  const app = express();
  app.use(express.json());

  const find = (id: string) => orders.find((o) => o.id === Number(id));
  const notFound = { error: { code: "ORDER_NOT_FOUND", message: "ההזמנה לא נמצאה" } };

  app.get("/orders/:id", (req, res) => {
    const order = find(req.params.id);
    if (!order) {
      res.status(404).json(notFound);
      return;
    }
    res.json(order);
  });

  app.post("/orders/:id/cancel", (req, res) => {
    const order = find(req.params.id);
    if (!order) {
      res.status(404).json(notFound);
      return;
    }
    switch (order.status) {
      case "pending":
      case "paid":
        order.status = "cancelled";
        order.cancelledAt = new Date().toISOString();
        order.cancelReason = typeof req.body?.reason === "string" ? req.body.reason : null;
        break;
      case "cancelled":
        break;
      case "shipped":
        res.status(409).json({ error: { code: "ORDER_SHIPPED", message: "אי אפשר לבטל הזמנה שנשלחה" } });
        return;
    }
    res.json(order);
  });

  return app;
}

// P15-E28: סכום עגלה
import express from "express";
import { z } from "zod";

export type Product = { name: string; price: number };

const cartSchema = z.object({
  items: z
    .array(z.object({ sku: z.string().min(1), qty: z.number().int().min(1).max(99) }))
    .min(1),
});

export function createApp(catalog: Map<string, Product>) {
  const app = express();
  app.use(express.json());

  app.post("/cart/total", (req, res) => {
    const result = cartSchema.safeParse(req.body);
    if (!result.success) {
      res.status(400).json({ error: "קלט לא תקין" });
      return;
    }

    // אותו sku פעמיים — מאחדים (Map שומרת על סדר ההופעה הראשונה)
    const qtyBySku = new Map<string, number>();
    for (const { sku, qty } of result.data.items) {
      qtyBySku.set(sku, (qtyBySku.get(sku) ?? 0) + qty);
    }

    const lines = [];
    for (const [sku, qty] of qtyBySku) {
      const product = catalog.get(sku);
      if (!product) {
        res.status(404).json({ error: `מוצר לא קיים: ${sku}` });
        return;
      }
      lines.push({ sku, name: product.name, qty, subtotal: product.price * qty });
    }

    const total = lines.reduce((sum, line) => sum + line.subtotal, 0);
    res.json({ lines, total });
  });

  return app;
}

// P15-E68: רשימה עם meta וקישורים
import express from "express";

export type Product = { id: number; name: string; price: number };

const int = (v: unknown, def: number) => (v === undefined ? def : typeof v === "string" && /^\d+$/.test(v) ? Number(v) : NaN);

export function createApp(products: Product[]) {
  const app = express();
  app.get("/products", (req, res) => {
    const page = int(req.query.page, 1);
    const limit = int(req.query.limit, 10);
    if (!(page >= 1) || !(limit >= 1 && limit <= 50)) {
      res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "page או limit לא תקינים" } });
      return;
    }
    const q = typeof req.query.q === "string" ? req.query.q : undefined;
    const list = q === undefined ? products : products.filter((p) => p.name.toLowerCase().includes(q.toLowerCase()));
    const total = list.length;
    const totalPages = Math.ceil(total / limit);
    const link = (p: number) => {
      const params = new URLSearchParams();
      if (q !== undefined) params.set("q", q);
      params.set("page", String(p));
      params.set("limit", String(limit));
      return `/products?${params}`;
    };
    res.json({
      data: list.slice((page - 1) * limit, page * limit),
      meta: { page, limit, total, totalPages },
      links: { self: link(page), next: page < totalPages ? link(page + 1) : null, prev: page > 1 ? link(page - 1) : null },
    });
  });
  return app;
}

// P15-E69: יצירה מרובה — הכול או כלום
import express from "express";

export type Product = { id: number; name: string; price: number };

export function createApp() {
  const app = express();
  app.use(express.json());
  const products: Product[] = [];
  let nextId = 1;

  app.get("/products", (req, res) => {
    res.json(products);
  });

  app.post("/products/bulk", (req, res) => {
    const items: unknown = req.body;
    if (!Array.isArray(items) || items.length < 1 || items.length > 100) {
      res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "שלח מערך של 1–100 מוצרים" } });
      return;
    }
    const details: { index: number; message: string }[] = [];
    const seen = new Set<string>();
    items.forEach((item, index) => {
      const name = item?.name;
      if (typeof name !== "string" || name.trim() === "") return void details.push({ index, message: "name לא תקין" });
      if (!Number.isInteger(item.price) || item.price <= 0) return void details.push({ index, message: "price לא תקין" });
      const key = name.trim().toLowerCase();
      if (seen.has(key)) return void details.push({ index, message: "שם כפול" });
      seen.add(key);
    });
    if (details.length > 0) {
      res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "חלק מהמוצרים לא תקינים", details } });
      return;
    }
    const created = items.map((item) => ({ id: nextId++, name: item.name.trim(), price: item.price }));
    products.push(...created);
    res.status(201).json({ created });
  });

  return app;
}
