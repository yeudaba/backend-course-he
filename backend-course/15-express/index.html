פרק 15 — Express ו־REST

⏱ 5 מפגשים

🧰 לפני שמתחילים — פרק 15

מה צריך שכבר יהיה מותקן: Node.js 24+, VS Code, תוסף REST Client (פרק 14).

מה מתקינים עכשיו:

  • Express 5 — ספריית השרת הנפוצה ביותר ב־Node. Zod 4 — בדיקת קלט. בתיקיית הקורס הן כבר רשומות ב־package.json, אז מספיק:
% cd ~/dev/backend-course
% npm install

(בפרויקט חדש משלך — npm install express zod ו־npm install -D @types/express. נעשה את זה בפרויקט 2.)

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 15-express מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה שהסביבה מוכנה — ב־Terminal של VS Code, מתוך ~/dev/backend-course:

% node -v
v24.11.0

(כל גרסה 24 ומעלה תקינה.)

✔ בדיקה: node -e "import('express').then(m => console.log('express', typeof m.default))" ← express function.

שפה: מהפרק הזה והלאה כל הקוד ב־TypeScript (קבצי .ts). Node 24 מריץ אותם ישירות: node src/server.ts.

🎯 בסוף הפרק תדע
  • לבנות שרת Express: routes, params, query, גוף JSON ותשובות עם status נכון.
  • להבין middleware: שרשרת, סדר, next(), טיפול בשגיאות ו־404.
  • לתכנן REST API: כתובות, methods, סינון, מיון, pagination ומבנה שגיאות אחיד.
  • לבדוק כל קלט בגבול המערכת עם Zod — ולקבל טיפוסי TypeScript בחינם.
  • לפרק שרת לשכבות: routes ← service ← repository (פרק 12).

🤔 למה צריך את זה?

בפרק 14 כתבת שרת עם node:http וראית כמה "צנרת" זה דורש: פירוק כתובות, קריאת גוף, if־ים. Express עושה את הצנרת, ומשאיר לך את הלוגיקה. הוא הספרייה הנפוצה ביותר לשרתי Node, והבסיס שעליו בנוי NestJS (פרק 20). כמעט כל משרת Junior Node תבקש "ניסיון ב־Express / REST API". בסוף הפרק מתחיל פרויקט 2 — API משימות שיגדל איתך עד סוף הקורס.

🏁 מבחן מעבר

  • לבנות מאפס API של משאב אחד (CRUD) ב־Express, עם status נכון לכל מקרה.
  • להסביר מה קורה כשמחליפים סדר של שני app.use — ולתקן שרת שבו הסדר שגוי.
  • לכתוב error handler אחד שמטפל ב־JSON שבור, בשגיאת ולידציה, ב"לא נמצא" ובבאג.
  • לכתוב סכמת Zod ל־body ול־query (עם coerce), ולהחזיר 400 עם פירוט השדות.
  • להוסיף pagination וסינון לרשימה, עם meta בתשובה.
  • npm run check P15: 80% מ־E06–E19, ולפחות תרגיל תיקון אחד.
