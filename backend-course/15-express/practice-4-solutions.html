P15-E70 · מה safeParse יחזיר? 🧠 הבנה רמה 2

💡 רמז 1

z.number() לא ממיר מחרוזת (רק z.coerce.number()). ‏.trim() רץ לפני .min(2).

💡 רמז 2

שדה שלא בסכמה — נמחק. שדה עם undefined — כמו שדה חסר: ‏default נכנס לפעולה.

for (const input of inputs) {
  const r = userSchema.safeParse(input);
  console.log(r.success ? `✔ ${JSON.stringify(r.data)}` : `✘ ${r.error.issues[0].path.join(".") || "(השורש)"}: ${r.error.issues[0].message}`);

שלושה דברים שכדאי לזכור: data הוא הקלט אחרי ניקוי (trim, ‏default, בלי שדות זרים) — ממשיכים איתו, לא עם req.body; ‏age: "31" נכשל — בגוף JSON, מחרוזת היא לא מספר (בניגוד ל־query, שבו צריך coerce); ומחרוזת במקום אובייקט נכשלת "בשורש" — path ריק.

⚠️ טעויות נפוצות
  • לבדוק עם safeParse ולהמשיך עם req.body — מאבדים את ה־trim וה־default, ו־isAdmin עובר הלאה.

P15-E71 · object, strictObject ו־partial 🧠 הבנה רמה 2

💡 רמז 1

z.object מוחק שדות זרים; ‏z.strictObject נכשל עליהם.

💡 רמז 2

partial() הופך כל שדה לאופציונלי — כולל המצב שבו אף שדה לא נשלח.

console.log(JSON.stringify(patch.parse({ ownerId: 5 })));

השורה הרביעית היא הבעיה: PATCH עם {"ownerId": 5} עובר את הבדיקה ונותן {} — "עדכון" שלא מעדכן כלום, ומחזיר 200. לכן ב־P15-E17 דורשים "לפחות שדה אחד" (ושם גם strictObject — כדי שהלקוח יידע ש־ownerId לא נתמך). ובשורה האחרונה: partial לא מבטל את הבדיקות של שדה שנשלח.

⚠️ טעויות נפוצות
  • לחשוב ש־partial() "מוותר" על הבדיקות — הוא רק הופך שדות לאופציונליים.

P15-E73 · default, optional ו־nullable 🧠 הבנה רמה 2

💡 רמז 1

P15-E74 · coerce.boolean ו־"false" 🧠 הבנה רמה 2

P15-E75 · parse שזורק בתוך route 🧠 הבנה רמה 2

💡 רמז 1

parse זורק ZodError על קלט לא תקין. ב־route סינכרוני, Express תופס את השגיאה ומעביר ל־error handler.

💡 רמז 2

בלי error handler משלך — ה־handler המובנה של Express, שמחזיר 500 ו־HTML (P15-E45).

✅ פתרון
import express from "express";
import { z } from "zod";

const schema = z.object({ qty: z.number().int().min(1) });

function build(withHandler: boolean) {
  const app = express();
  app.use(express.json());
  app.post("/cart", (req, res) => {
    const { qty } = schema.parse(req.body);
    res.json({ qty });
  });
  if (withHandler) {
    app.use((err: unknown, req: express.Request, res: express.Response, next: express.NextFunction) => {
      if (err instanceof z.ZodError) {
        res.status(400).json({ error: { code: "VALIDATION_ERROR", details: err.issues.map((i) => i.path.join(".")) } });
        return;
      }
      res.status(500).json({ error: { code: "INTERNAL" } });
    });
  }
  return app;
}

const a = build(false).listen(0);
const b = build(true).listen(0);
const post = (s: typeof a, body: unknown) =>
  fetch(`http://localhost:${(s.address() as { port: number }).port}/cart`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body) });
setTimeout(async () => {
  for (const [name, server] of [["a", a], ["b", b]] as const) {
    const ok = await post(server, { qty: 2 });
    const bad = await post(server, { qty: 0 });
    const text = await bad.text();
    console.log(name, ok.status, bad.status, bad.headers.get("content-type"), text.startsWith("{") ? text : "(דף HTML)");
  }
  a.close();
  b.close();
}, 50);
a 200 500 text/html; charset=utf-8 (דף HTML)
b 200 400 application/json; charset=utf-8 {"error":{"code":"VALIDATION_ERROR","details":["qty"]}}

ב־a, קלט לא תקין של הלקוח הפך ל־500 — "השרת שבור" — ועוד בדף HTML. ב־b, אותו parse עובד יפה, כי error handler אחד מתרגם כל ZodError ל־400. שתי הדרכים לגיטימיות: safeParse ותשובה ב־route (כמו בשיעור), או parse + תרגום מרכזי (כמו P15-E54). מה שלא בסדר — parse בלי תרגום.

⚠️ טעויות נפוצות
  • לבדוק רק עם קלט תקין — ההבדל בין a ל־b נראה רק כשהקלט שבור.

P15-E11 · סכמת מוצר 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

z.array(z.string()).max(5).default([])

💡 רמז 2

issue.path.join(".")

✅ פתרון
// P15-E11
import { z } from "zod";

export const productSchema = z.object({
  name: z.string().trim().min(2, "לפחות 2 תווים").max(80, "עד 80 תווים"),
  price: z.number().positive("חייב להיות חיובי").max(100_000, "יקר מדי"),
  tags: z.array(z.string()).max(5, "עד 5 תגיות").default([]),
  inStock: z.boolean().default(true),
});

export type Product = z.infer<typeof productSchema>;

export function parseProduct(input: unknown) {
  const result = productSchema.safeParse(input);
  if (result.success) return { ok: true as const, data: result.data };
  return {
    ok: false as const,
    errors: result.error.issues.map((i) => ({ path: i.path.join("."), message: i.message })),
  };
}

console.log(JSON.stringify(parseProduct({ name: " מסך ", price: 899 })));
console.log(JSON.stringify(parseProduct({ name: "x", price: -1, tags: ["a", "b", 3] })));

{"ok":false,"errors":[{"path":"name","message":"לפחות 2 תווים"},{"path":"price","message":"חייב להיות חיובי"},{"path":"tags.2","message":"Invalid input: expected string, received number"}]}

P15-E14 · סינון ומיון 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

.refine((q) => ..., { message: "...", path: ["minPrice"] }) על כל האובייקט.

💡 רמז 2

מיון: [...list].sort(...). לשמות: a.name.localeCompare(b.name).

✅ פתרון
// P15-E14
import express from "express";
import { z } from "zod";

interface Product {
  id: number;
  name: string;
  price: number;
}

const querySchema = z
  .object({
    q: z.string().trim().optional(),
    minPrice: z.coerce.number().min(0).optional(),
    maxPrice: z.coerce.number().min(0).optional(),
    sort: z.enum(["price", "-price", "name", "-name"]).optional(),
  })
  .refine((q) => q.minPrice === undefined || q.maxPrice === undefined || q.minPrice <= q.maxPrice, {
    message: "minPrice גדול מ־maxPrice",
    path: ["minPrice"],
  });

const comparators = {
  price: (a: Product, b: Product) => a.price - b.price,
  name: (a: Product, b: Product) => a.name.localeCompare(b.name),
};

export function createApp(products: Product[]) {
  const app = express();
  app.get("/products", (req, res) => {
    const parsed = querySchema.safeParse(req.query);
    if (!parsed.success) {
      res.status(400).json({
        error: {
          code: "VALIDATION_ERROR",
          message: "קלט לא תקין",
          details: parsed.error.issues.map((i) => ({ path: i.path.join("."), message: i.message })),
        },
      });
      return;
    }
    const { q, minPrice, maxPrice, sort } = parsed.data;
    let list = products.filter(
      (p) =>
        (!q || p.name.toLowerCase().includes(q.toLowerCase())) &&
        (minPrice === undefined || p.price >= minPrice) &&
        (maxPrice === undefined || p.price <= maxPrice)
    );
    if (sort) {
      const desc = sort.startsWith("-");
      const compare = comparators[desc ? (sort.slice(1) as "price" | "name") : (sort as "price" | "name")];
      list = [...list].sort((a, b) => (desc ? -compare(a, b) : compare(a, b)));
    } else {
      list = [...list].sort((a, b) => a.id - b.id);
    }
    res.json(list);
  });
  return app;
}

מיון רק מרשימה סגורה (enum) הוא גם עניין של אבטחה: כשנעבור ל־SQL (פרק 16), שם עמודה שמגיע מהלקוח ישר לשאילתה הוא פרצה.

⚠️ טעויות נפוצות
  • products.sort(...) — ממיין את המערך המקורי, והבקשה הבאה בלי sort תקבל אותו ממוין.

P15-E15 · middleware בדיקה כללי 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

לולאה על ["body", "query", "params"], ולכל אחד safeParse(req[part]).

💡 רמז 2

[part, ...issue.path].join(".")

✅ פתרון
// P15-E15
import type { Request, Response, NextFunction } from "express";
import type { ZodType } from "zod";

type Part = "body" | "query" | "params";

export function validate(schemas: Partial<Record<Part, ZodType>>) {
  return (req: Request, res: Response, next: NextFunction) => {
    const details: { path: string; message: string }[] = [];
    const clean: Partial<Record<Part, unknown>> = {};
    for (const part of ["body", "query", "params"] as const) {
      const schema = schemas[part];
      if (!schema) continue;
      const result = schema.safeParse(req[part]);
      if (result.success) clean[part] = result.data;
      else for (const i of result.error.issues) details.push({ path: [part, ...i.path].join("."), message: i.message });
    }
    if (details.length > 0) {
      res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "קלט לא תקין", details } });
      return;
    }
    if ("body" in clean) req.body = clean.body;
    if ("query" in clean) res.locals.query = clean.query;
    if ("params" in clean) res.locals.params = clean.params;
    next();
  };
}

שימוש: router.patch("/:id", validate({ params: idSchema, body: updateSchema }), handler). זה הדפוס שתראה בכל פרויקט Express רציני (ו־NestJS עושה את זה עם "pipes" — פרק 20).

⚠️ טעויות נפוצות
  • לעצור בשגיאה הראשונה — הלקוח מתקן שדה, שולח שוב, ומגלה עוד שגיאה. החזר הכול בבת אחת.

P15-E17 · PATCH נכון 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

💡 רמז 2

"לפחות אחד": .refine((o) => Object.keys(o).length > 0, "צריך לפחות שדה אחד").

✅ פתרון
// P15-E17
import express, { type Response } from "express";
import { z } from "zod";

const updateSchema = z
  .strictObject({
    title: z.string().trim().min(1).max(100),
    done: z.boolean(),
    priority: z.enum(["low", "medium", "high"]),
  })
  .partial()
  .refine((o) => Object.keys(o).length > 0, "צריך לפחות שדה אחד");

const idSchema = z.coerce.number().int().positive();

function badRequest(res: Response, issues: z.core.$ZodIssue[]) {
  const details = issues.map((i) => ({ path: i.path.join("."), message: i.message }));
  res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "קלט לא תקין", details } });
}

export function createApp() {
  const app = express();
  app.use(express.json());
  const tasks = [
    { id: 1, title: "לקנות חלב", done: false, priority: "medium" },
    { id: 2, title: "לסיים את פרק 15", done: false, priority: "high" },
  ];

  app.patch("/tasks/:id", (req, res) => {
    const id = idSchema.safeParse(req.params.id);
    if (!id.success) return badRequest(res, id.error.issues);
    const body = updateSchema.safeParse(req.body);
    if (!body.success) return badRequest(res, body.error.issues);
    const task = tasks.find((t) => t.id === id.data);
    if (!task) {

// P15-E24
import express, { Router, type Request, type Response, type NextFunction } from "express";
import { z, type ZodType } from "zod";

class HttpError extends Error {
  status: number;
  code: string;
  constructor(status: number, code: string, message: string) {
    super(message);
    this.status = status;
    this.code = code;
  }
}

interface Book { id: number; title: string; author: string; copies: number; available: number }
interface Loan { id: number; bookId: number; member: string; loanedAt: string; dueAt: string; returnedAt: string | null }

const DAY = 24 * 60 * 60 * 1000;

class LibraryService {
  books: Book[] = [];
  loans: Loan[] = [];
  now: () => Date;
  constructor(now: () => Date) {
    this.now = now;
  }
  createBook(data: { title: string; author: string; copies: number }) {
    const book = { id: this.books.length + 1, ...data, available: data.copies };
    this.books.push(book);
    return book;
  }
  listBooks({ author, available }: { author?: string; available?: boolean }) {
    return this.books.filter(
      (b) => (!author || b.author.toLowerCase().includes(author.toLowerCase())) && (!available || b.available > 0)
    );
  }
  getBook(id: number) {
    const book = this.books.find((b) => b.id === id);
    if (!book) throw new HttpError(404, "BOOK_NOT_FOUND", "הספר לא נמצא");
    return book;
  }
  lend(bookId: number, member: string) {
    const book = this.getBook(bookId);
    if (this.loans.some((l) => l.bookId === bookId && l.member === member && !l.returnedAt)) {
      throw new HttpError(409, "ALREADY_BORROWED", "החבר כבר מחזיק את הספר");
    }
    if (book.available === 0) throw new HttpError(409, "NO_COPIES", "אין עותק פנוי");
    book.available--;
    const at = this.now();
    const loan = {
      id: this.loans.length + 1,
      bookId,
      member,
      loanedAt: at.toISOString(),
      dueAt: new Date(at.getTime() + 14 * DAY).toISOString(),
      returnedAt: null,
    };
    this.loans.push(loan);
    return loan;
  }
  returnLoan(id: number) {
    const loan = this.loans.find((l) => l.id === id);
    if (!loan) throw new HttpError(404, "LOAN_NOT_FOUND", "ההשאלה לא נמצאה");
    if (loan.returnedAt) throw new HttpError(409, "ALREADY_RETURNED", "הספר כבר הוחזר");
    loan.returnedAt = this.now().toISOString();
    this.getBook(loan.bookId).available++;
    return loan;
  }
  overdue() {
    const t = this.now().getTime();
    return this.loans.filter((l) => !l.returnedAt && Date.parse(l.dueAt) < t);
  }
}

function parse<T>(schema: ZodType<T>, value: unknown): T {
  const r = schema.safeParse(value);
  if (!r.success) {
    const err = new HttpError(400, "VALIDATION_ERROR", "קלט לא תקין");
    Object.assign(err, { details: r.error.issues.map((i) => ({ path: i.path.join("."), message: i.message })) });
    throw err;
  }
  return r.data;
}

// P15-E25
import express, { type Request, type Response, type NextFunction } from "express";

type Entry = { requestBody: string; state: "running" | "done"; status?: number; body?: unknown };

export function idempotency() {
  const store = new Map<string, Entry>();

  return (req: Request, res: Response, next: NextFunction) => {
    const key = req.get("idempotency-key");
    if (!key) {
      res.status(400).json({ error: { code: "MISSING_IDEMPOTENCY_KEY", message: "חסר Idempotency-Key" } });
      return;
    }
    const requestBody = JSON.stringify(req.body ?? null);
    const existing = store.get(key);
    if (existing) {
      if (existing.requestBody !== requestBody) {
        res.status(422).json({ error: { code: "IDEMPOTENCY_KEY_REUSED", message: "המפתח שומש לבקשה אחרת" } });
        return;
      }
      if (existing.state === "running") {
        res.status(409).json({ error: { code: "REQUEST_IN_PROGRESS", message: "הבקשה המקורית עדיין מעובדת" } });
        return;
      }
      res.status(existing.status!).set("Idempotent-Replayed", "true").json(existing.body);
      return;
    }

    const entry: Entry = { requestBody, state: "running" };
    store.set(key, entry);
    const originalJson = res.json.bind(res);
    res.json = (body) => {
      if (res.statusCode >= 500) store.delete(key); // תקלה זמנית — מותר לנסות שוב
      else Object.assign(entry, { state: "done", status: res.statusCode, body });
      return originalJson(body);
    };
    next();
  };
}

export function createApp() {
  const app = express();
  app.use(express.json());
  const orders: Record<string, unknown>[] = [];

  app.get("/orders", (req, res) => {
    res.json(orders);
  });
  app.post("/orders", idempotency(), async (req, res) => {
    await new Promise((r) => setTimeout(r, 50));
    const order = { id: orders.length + 1, ...req.body };
    orders.push(order);
    res.status(201).json(order);
  });
  return app;
}

P15-E27 · סכמת הרשמה עם regex 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

username: z.string().trim().toLowerCase().regex(/^[a-z][a-z0-9_]{2,15}$/, "..."). האות הראשונה היא [a-z], ואחריה עוד 2–15 תווים — כלומר 3–16 בסך הכול.

password: אפשר לשרשר כמה .regex(), כל אחד עם הודעה משלו: .regex(/[A-Z]/, "...") ו־.regex(/\d/, "..."). כאן אין ^ ו־$: מספיק שהתו מופיע איפשהו.

💡 רמז 2

phone בשלושה שלבים: .transform((s) => s.replace(/[\s-]/g, "")) (מנקים) ← .pipe(z.string().regex(/^(\+972|0)5\d{8}$/, "...")) (בודקים את המחרוזת הנקייה) ← .transform((s) => s.replace(/^\+972/, "0")) (מאחדים צורה). ‏pipe מעביר את התוצאה של ה־transform לסכמה נוספת.

✅ פתרון
// P15-E27: סכמת הרשמה עם regex
import { z } from "zod";

export const signupSchema = z.object({
  username: z
    .string()
    .trim()
    .toLowerCase()
    .regex(/^[a-z][a-z0-9_]{2,15}$/, "שם משתמש: 3–16 תווים — אותיות באנגלית, ספרות ו־_, ומתחיל באות"),
  phone: z
    .string()
    .transform((s) => s.replace(/[\s-]/g, ""))
    .pipe(z.string().regex(/^(\+972|0)5\d{8}$/, "טלפון נייד ישראלי: 05XXXXXXXX"))
    .transform((s) => s.replace(/^\+972/, "0")),
  password: z
    .string()
    .min(8, "סיסמה: לפחות 8 תווים")
    .regex(/[A-Z]/, "סיסמה: לפחות אות גדולה אחת")
    .regex(/\d/, "סיסמה: לפחות ספרה אחת"),
});

export type Signup = z.infer<typeof signupSchema>;

console.log(signupSchema.parse({ username: " Dana_88 ", phone: "+972 50-123-4567", password: "Secret123" }));
const bad = signupSchema.safeParse({ username: "8dana", phone: "03-1234567", password: "secret" });
if (!bad.success) {
  for (const issue of bad.error.issues) console.log(issue.path.join("."), "—", issue.message);
}
{ username: 'dana_88', phone: '0501234567', password: 'Secret123' }
username — שם משתמש: 3–16 תווים — אותיות באנגלית, ספרות ו־_, ומתחיל באות
phone — טלפון נייד ישראלי: 05XXXXXXXX
password — סיסמה: לפחות 8 תווים
password — סיסמה: לפחות אות גדולה אחת
password — סיסמה: לפחות ספרה אחת

שני סוגים של regex כאן. ב־username ובטלפון יש ^...$: כל המחרוזת חייבת להתאים. בסיסמה אין: שואלים רק אם יש לפחות תו אחד כזה. ‏/[A-Z]/ בלי עוגנים הוא "יש אות גדולה איפשהו".

בטלפון הסדר חשוב: קודם מנקים, אחר כך בודקים, ובסוף מאחדים לצורה אחת. כך במסד נשמר רק 0501234567, ולא ארבע כתיבות שונות של אותו מספר. אחרת חיפוש לפי טלפון לא ימצא את המשתמש.

בסיסמה Zod ממשיך לבדוק גם אחרי שבדיקה נכשלה, ולכן "secret" מקבל שלוש הודעות. המשתמש רואה את כל מה שחסר בבת אחת.

⚠️ טעויות נפוצות
  • .regex(/[a-z0-9_]{3,16}/) בלי ^ ו־$ — ‏"dana!!!" עובר, כי "dana" נמצא בתוכה.
  • .toLowerCase() אחרי .regex() — ‏"Dana" נכשל לפני שהומר.
  • /^(+972|0)5\d{8}$/ — ‏+ הוא תו מיוחד ב־regex ("פעם אחת או יותר"). צריך \+.
  • s.replace("-", "") עם מחרוזת — מחליף רק את המקף הראשון. ב־regex עם g מוחלפים כולם.
