P15-E01 · איזה route יענה? 🧠 הבנה רמה 1

P15-E02 · מאפיון ל־routes 🧠 הבנה רמה 1

💡 רמז 1

בתוך router, ה־path יחסי לקידומת.

💡 רמז 2

סינון — ב־query, לא בכתובת.

✅ פתרון
router.get("/", list);                 // GET /books?author=עגנון
router.get("/:id", getOne);            // GET /books/7
router.post("/", create);              // POST /books
router.patch("/:id", update);          // PATCH /books/7  { "copies": 3 }
router.delete("/:id", remove);         // DELETE /books/7
router.post("/:id/loans", lend);       // POST /books/7/loans  — יוצר השאלה
router.get("/:id/loans", listLoans);   // GET /books/7/loans

השאלה כ־POST /books/7/loans: "יוצרים משאב השאלה תחת הספר". גם POST /books/7/lend מקובל.

⚠️ טעויות נפוצות

P15-E03 · מה הלקוח מקבל? 🧠 הבנה רמה 1

✅ פתרון
  1. 200, application/json, {"ok":true}
  2. 201, JSON, {"id":5}
  3. 204, בלי Content-Type, בלי גוף

P15-E29 · מתי req.body ריק? 🧠 הבנה רמה 2

💡 רמז 1

הטבלה בסעיף 2: ‏req.body — "יש ערך רק אם נשלח JSON וגם express.json() רץ".

💡 רמז 2

express.json() מפרש רק בקשות שה־Content-Type שלהן JSON. את השאר הוא משאיר בשקט.

✅ פתרון
import express from "express";

function build(withJson: boolean) {
  const app = express();
  if (withJson) app.use(express.json());
  app.post("/echo", (req, res) => {
    res.json({ type: typeof req.body, body: req.body ?? null });
  });
  return app;
}

const a = build(false).listen(0);
const b = build(true).listen(0);
const url = (s: typeof a) => `http://localhost:${(s.address() as { port: number }).port}/echo`;
const json = { "Content-Type": "application/json" };
setTimeout(async () => {
  for (const [name, server] of [["a", a], ["b", b]] as const) {
    const r1 = await fetch(url(server), { method: "POST", headers: json, body: '{"x":1}' });
    const r2 = await fetch(url(server), { method: "POST", headers: { "Content-Type": "text/plain" }, body: '{"x":1}' });
    const r3 = await fetch(url(server), { method: "POST" });
    console.log(name, JSON.stringify(await r1.json()), JSON.stringify(await r2.json()), JSON.stringify(await r3.json()));
  }
  a.close();
  b.close();
}, 50);
a {"type":"undefined","body":null} {"type":"undefined","body":null} {"type":"undefined","body":null}
b {"type":"object","body":{"x":1}} {"type":"undefined","body":null} {"type":"undefined","body":null}

בלי express.json() — req.body תמיד undefined, גם כשנשלח JSON תקין. ועם express.json() — רק בקשה עם Content-Type: application/json מקבלת גוף. ולכן קוד כמו req.body.name ב־route קורס ב־TypeError (= 500) על כל לקוח ששכח header. בשיעור 4, Zod יהפוך את זה ל־400.

⚠️ טעויות נפוצות
  • לבדוק עם REST Client (שבו כתבת Content-Type) ולהסיק "עובד" — לקוח אחר ששולח בלי header יקבל 500.

P15-E30 · איזו כתובת מתאימה ל־:id? 🧠 הבנה רמה 2

💡 רמז 1

:id תופס חלק אחד של הנתיב — בין שני /. לא ריק, ולא כמה חלקים.

💡 רמז 2

ב־Express ברירת המחדל סלחנית לאותיות גדולות ול־/ בסוף. ו־404 של Express (בלי notFound משלך) הוא דף HTML.

✅ פתרון
import express from "express";

const app = express();
app.get("/users/:id", (req, res) => {
  res.json(req.params);
});

const server = app.listen(0, async () => {
  const base = `http://localhost:${(server.address() as { port: number }).port}`;
  for (const path of ["/users/7", "/users/7/", "/USERS/7", "/users/a%20b", "/users/", "/users/7/orders"]) {
    const res = await fetch(base + path);
    const type = res.headers.get("content-type") ?? "";
    console.log(path.padEnd(16), res.status, type.includes("json") ? await res.text() : "(דף HTML)");
  }
  server.close();
});
/users/7         200 {"id":"7"}
/users/7/        200 {"id":"7"}
/USERS/7         200 {"id":"7"}
/users/a%20b     200 {"id":"a b"}
/users/          404 (דף HTML)
/users/7/orders  404 (דף HTML)

Express מפענח את הפרמטר בשבילך (a%20b ← "a b"), סלחן ל־/ בסוף ולאותיות גדולות, ולא מתאים כשהחלק ריק או כשיש עוד חלקים אחריו (/users/7/orders הוא route אחר). וה־404 שחזר הוא HTML — זה מה שהלקוח מקבל עד שתוסיף notFound ב־JSON (שיעור 2).

⚠️ טעויות נפוצות
  • לצפות ש־/users/7/orders "ייפול" ל־/users/:id עם id = "7/orders".

P15-E31 · מה יש ב־req.query? 🧠 הבנה רמה 2

💡 רמז 1

פרמטר שחוזר פעמיים — ב־URLSearchParams.get (פרק 14) קיבלת רק את הראשון. Express אוסף את כולם.

💡 רמז 2

ב־Express 5 ה־query מפורש "פשוט": סוגריים מרובעים הם חלק מהשם, ופסיקים — חלק מהערך.

✅ פתרון
import express from "express";

const app = express();
app.get("/search", (req, res) => {
  res.json(req.query);
});

const server = app.listen(0, async () => {
  const base = `http://localhost:${(server.address() as { port: number }).port}/search`;
  for (const q of ["?tag=a&tag=b", "?inStock", "?ids=1,2,3", "?filter[price]=5", "?q=red+shoes&page=2"]) {
    console.log(q.padEnd(20), await (await fetch(base + q)).text());
  }
  server.close();
});
?tag=a&tag=b         {"tag":["a","b"]}
?inStock             {"inStock":""}
?ids=1,2,3           {"ids":"1,2,3"}
?filter[price]=5     {"filter[price]":"5"}
?q=red+shoes&page=2  {"q":"red shoes","page":"2"}

שלוש מסקנות: ערך יכול להיות מערך (tag) — ולכן הטיפוס של req.query.tag ב־TypeScript אינו סתם string (ראה P15-E39); פרמטר בלי ערך הוא ""; ו־ids=1,2,3 היא מחרוזת אחת — אם רוצים רשימה, מפרקים בעצמך (split(",")). ‏filter[price] הוא שם רגיל — ב־Express 4 הוא היה הופך לאובייקט מקונן.

⚠️ טעויות נפוצות
  • req.query.tag.toLowerCase() — קורס כשהלקוח שולח את tag פעמיים (מערך).

P15-E06 · שלום Express 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

req.query.name יכול להיות undefined (או מערך, אם נשלח פעמיים). typeof req.query.name === "string".

💡 רמז 2

Number.isFinite(Number(x)) — ושים לב ש־Number("") הוא 0.

✅ פתרון
// P15-E06
import express from "express";

export function createApp() {
  const app = express();

  app.get("/hello", (req, res) => {
    const name = typeof req.query.name === "string" && req.query.name !== "" ? req.query.name : "אורח";
    res.json({ message: `שלום ${name}` });
  });

  app.get("/add/:a/:b", (req, res) => {
    const a = Number(req.params.a);
    const b = Number(req.params.b);
    if (!Number.isFinite(a) || !Number.isFinite(b)) {
      res.status(400).json({ error: "a ו־b חייבים להיות מספרים" });
      return;
    }
    res.json({ sum: a + b });
  });

  return app;
}

להרצה ידנית: node -e "import('./15-express/solutions/P15-E06.ts').then(m => m.createApp().listen(3000))", או קובץ server.ts קטן כמו בשיעור 1.

⚠️ טעויות נפוצות
  • req.params.a + req.params.b ← "23" במקום 5.

P15-E07 · קריאת מוצרים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

products.find((p) => p.id === Number(req.params.id))

💡 רמז 2

maxPrice לא נשלח ← req.query.maxPrice === undefined.

✅ פתרון
// P15-E07
import express from "express";

export interface Product {
  id: number;
  name: string;
  price: number;
}

export function createApp(products: Product[]) {
  const app = express();

  app.get("/products", (req, res) => {
    const max = req.query.maxPrice;
    res.json(typeof max === "string" ? products.filter((p) => p.price <= Number(max)) : products);
  });

  app.get("/products/:id", (req, res) => {
    const product = products.find((p) => p.id === Number(req.params.id));
    if (!product) {
      res.status(404).json({ error: { code: "NOT_FOUND", message: "המוצר לא נמצא" } });
      return;
    }
    res.json(product);
  });

  return app;
}

(?maxPrice=abc כאן יחזיר רשימה ריקה — בתרגיל E14 נבדוק את ה־query כמו שצריך.)

⚠️ טעויות נפוצות
  • p.id === req.params.id — מספר מול מחרוזת, תמיד 404.

P15-E08 · יצירה ומחיקה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

אל תשכח app.use(express.json()). ואם הגוף לא נשלח בכלל — req.body הוא undefined.

💡 רמז 2

JSON שבור: app.use((err, req, res, next) => ...) בסוף, עם err.type === "entity.parse.failed".

✅ פתרון
// P15-E08
import express, { type Request, type Response, type NextFunction } from "express";

export function createApp() {
  const app = express();
  app.use(express.json());
  const products: { id: number; name: string; price: number }[] = [];
  let nextId = 1;

  app.get("/products", (req, res) => {
    res.json(products);
  });

  app.post("/products", (req, res) => {
    const { name, price } = req.body ?? {};
    if (typeof name !== "string" || name.trim() === "" || typeof price !== "number" || !(price > 0)) {
      res.status(400).json({ error: "name (מחרוזת) ו־price (מספר חיובי) חובה" });
      return;
    }
    const product = { id: nextId++, name: name.trim(), price };
    products.push(product);
    res.status(201).location(`/products/${product.id}`).json(product);
  });

  app.delete("/products/:id", (req, res) => {
    const index = products.findIndex((p) => p.id === Number(req.params.id));
    if (index === -1) {
      res.status(404).json({ error: "המוצר לא נמצא" });
      return;
    }
    products.splice(index, 1);
    res.sendStatus(204);
  });

  app.use((err: { type?: string }, req: Request, res: Response, next: NextFunction) => {
    if (err.type === "entity.parse.failed") {
      res.status(400).json({ error: "JSON לא תקין" });
      return;
    }
    next(err);
  });

  return app;
}

שים לב: ה־products וה־nextId נוצרים בתוך createApp, כך שכל אפליקציה (וכל בדיקה) מתחילה נקייה. משתנה ברמת הקובץ היה משותף לכולם.

⚠️ טעויות נפוצות
  • !price כבדיקה — מחרוזת "5" עוברת, ו־0 נדחה מסיבה לא ברורה. בדוק טיפוס במפורש.

P15-E32 · ברכה לפי שפה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

const lang = req.query.lang ?? "he"; — ואז שתי השוואות (===) למחרוזות. מערך לא שווה לאף אחת מהן.

💡 רמז 2

אחרי res.status(400).json(...) — return; בשורה נפרדת.

✅ פתרון
// P15-E32: ברכה לפי שפה
import express from "express";

export function createApp() {

P15-E33 · PUT שיוצר או מחליף 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

const settings = new Map<string, unknown>(); בתוך createApp. ‏const isNew = !settings.has(key); — לפני ה־set.

💡 רמז 2

req.body?.value === undefined תופס גם גוף חסר וגם שדה חסר. ל־GET /settings: Object.fromEntries(settings).

✅ פתרון
// P15-E33: PUT שיוצר או מחליף
import express from "express";

export function createApp() {
  const app = express();
  app.use(express.json());
  const settings = new Map<string, unknown>();

  app.get("/settings", (req, res) => {
    res.json(Object.fromEntries(settings));
  });

  app.get("/settings/:key", (req, res) => {
    const { key } = req.params;
    if (!settings.has(key)) {
      res.status(404).json({ error: "אין הגדרה כזו" });
      return;
    }
    res.json({ key, value: settings.get(key) });
  });

  app.put("/settings/:key", (req, res) => {
    const { key } = req.params;
    const value = req.body?.value;
    if (value === undefined) {
      res.status(400).json({ error: "חסר value" });
      return;
    }
    const isNew = !settings.has(key);
    settings.set(key, value);
    if (isNew) res.status(201).location(`/settings/${key}`);
    res.json({ key, value });
  });

  return app;
}

const server = createApp().listen(0, async () => {
  const address = server.address();
  const base = `http://localhost:${typeof address === "object" && address ? address.port : 0}`;
  const put = (key: string, body: unknown) =>
    fetch(`${base}/settings/${key}`, { method: "PUT", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body) });
  for (const res of [await put("theme", { value: "dark" }), await put("theme", { value: "light" }), await put("x", {})]) {
    console.log(res.status, res.headers.get("location"), await res.text());
  }
  console.log(await (await fetch(`${base}/settings`)).text());
  server.close();
});
201 /settings/theme {"key":"theme","value":"dark"}
200 null {"key":"theme","value":"light"}
400 null {"error":"חסר value"}
{"theme":"light"}

זה ההבדל בין PUT ל־POST: ב־PUT הלקוח בוחר את הכתובת (/settings/theme), ולכן אותה בקשה יכולה ליצור (201) או להחליף (200) — ושליחה חוזרת לא יוצרת כפילות (idempotent, פרק 14). ‏value: false או 0 הם ערכים תקינים, ולכן הבדיקה היא על undefined ולא על "falsy".

⚠️ טעויות נפוצות
  • if (!req.body.value) — דוחה את false, ‏0 ו־"", וקורס כשאין גוף בכלל.
  • לבדוק אם המפתח קיים אחרי ה־set — תמיד "קיים", ותמיד 200.

P15-E34 · X-Total-Count ובחירת שדות 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

res.set("X-Total-Count", String(products.length)) — ערך של header הוא מחרוזת.

💡 רמז 2

const fields = String(req.query.fields).split(",").map((f) => f.trim()).filter(Boolean); ואז Object.fromEntries([["id", p.id], ...fields.filter((f) => f !== "id").map((f) => [f, p[f]])]).

✅ פתרון
// P15-E34: X-Total-Count ובחירת שדות
import express from "express";

export type Product = { id: number; name: string; price: number; stock: number };
const KNOWN = ["id", "name", "price", "stock"];

export function createApp(products: Product[]) {
  const app = express();
  app.get("/products", (req, res) => {
    res.set("X-Total-Count", String(products.length));
    if (req.query.fields === undefined) {
      res.json(products);
      return;
    }
    const fields = String(req.query.fields)
      .split(",")
      .map((f) => f.trim())
      .filter(Boolean);
    const unknown = fields.find((f) => !KNOWN.includes(f));
    if (unknown) {
      res.status(400).json({ error: `שדה לא מוכר: ${unknown}` });
      return;
    }
    const picked = ["id", ...fields.filter((f) => f !== "id")];
    res.json(products.map((p) => Object.fromEntries(picked.map((f) => [f, p[f as keyof Product]]))));
  });
  return app;
}

const products = [
  { id: 1, name: "מקלדת", price: 249, stock: 3 },
  { id: 2, name: "עכבר", price: 89, stock: 0 },
];
const server = createApp(products).listen(0, async () => {
  const address = server.address();
  const base = `http://localhost:${typeof address === "object" && address ? address.port : 0}`;
  for (const q of ["", "?fields=price, name", "?fields=name,password"]) {
    const res = await fetch(`${base}/products${q}`);
    console.log(res.status, res.headers.get("x-total-count"), await res.text());
  }

// P15-E36: קישורים מקוצרים
import express from "express";

function isHttpUrl(value: unknown): value is string {
  if (typeof value !== "string" || !/^https?:\/\//.test(value)) return false;
  try {
    new URL(value);
    return true;
  } catch {
    return false;
  }
}

export function createApp() {
  const app = express();
  app.use(express.json());
  const codeToUrl = new Map<string, string>();
  const urlToCode = new Map<string, string>();
  let next = 1;

  app.post("/links", (req, res) => {
    const url = req.body?.url;
    if (!isHttpUrl(url)) {
      res.status(400).json({ error: "כתובת לא תקינה" });
      return;
    }
    const existing = urlToCode.get(url);
    if (existing) {
      res.json({ code: existing, url });
      return;
    }
    const code = String(next++);
    codeToUrl.set(code, url);
    urlToCode.set(url, code);
    res.status(201).location(`/links/${code}`).json({ code, url });
  });

  app.get("/links/:code", (req, res) => {
    const url = codeToUrl.get(req.params.code);
    if (!url) {
      res.status(404).json({ error: "קישור לא קיים" });
      return;
    }
    res.status(302).location(url).end();
  });

  return app;
}

import express from "express";

export type Order = { id: number; customer: string; status: "paid" | "shipped" | "cancelled"; totalAgorot: number; createdAt: string };
const DAY = /^\d{4}-\d{2}-\d{2}$/;

export function createApp(orders: Order[]) {
  const app = express();
  app.get("/stats", (req, res) => {
    const { from, to } = req.query;
    for (const value of [from, to]) {
      if (value !== undefined && (typeof value !== "string" || !DAY.test(value))) {
        res.status(400).json({ error: "תאריך לא תקין" });
        return;
      }
    }
    const list = orders.filter((o) => {
      const day = o.createdAt.slice(0, 10);
      return (from === undefined || day >= String(from)) && (to === undefined || day <= String(to));
    });

    const byStatus = { paid: 0, shipped: 0, cancelled: 0 };
    const byCustomer = new Map<string, number>();
    for (const o of list) {
      byStatus[o.status]++;
      if (o.status !== "cancelled") byCustomer.set(o.customer, (byCustomer.get(o.customer) ?? 0) + o.totalAgorot);
    }
    let topCustomer: string | null = null;
    let best = -1;
    for (const [customer, sum] of byCustomer) {
      if (sum > best) {
        best = sum;
        topCustomer = customer;
      }
    }
    const revenueAgorot = list.filter((o) => o.status !== "cancelled").reduce((sum, o) => sum + o.totalAgorot, 0);
    res.json({ count: list.length, byStatus, revenueAgorot, topCustomer });
  });
  return app;
}

import express from "express";

export type Note = { id: number; text: string; createdAt: string };

export class NotesStore {
  #notes = new Map<number, Note>();
  #nextId = 1;

  add(text: string): Note {
    const note = { id: this.#nextId++, text, createdAt: new Date().toISOString() };
    this.#notes.set(note.id, note);
    return note;
  }
  get(id: number): Note | undefined {
    return this.#notes.get(id);
  }
  list(): Note[] {
    return [...this.#notes.values()].sort((a, b) => a.id - b.id);
  }
  remove(id: number): boolean {
    return this.#notes.delete(id);
  }
}

export function createApp(store = new NotesStore()) {
  const app = express();
  app.use(express.json());

  app.get("/notes", (req, res) => {
    res.json(store.list());
  });

  app.post("/notes", (req, res) => {
    const text = req.body?.text;
    if (typeof text !== "string" || text.trim().length < 1 || text.trim().length > 200) {
      res.status(400).json({ error: "text לא תקין" });
      return;
    }
    const note = store.add(text.trim());
    res.status(201).location(`/notes/${note.id}`).json(note);
  });

  app.get("/notes/:id", (req, res) => {
    const note = store.get(Number(req.params.id));
    if (!note) {
      res.status(404).json({ error: "לא נמצא" });
      return;
    }
    res.json(note);
  });

  app.delete("/notes/:id", (req, res) => {
    if (!store.remove(Number(req.params.id))) {
      res.status(404).json({ error: "לא נמצא" });
      return;
    }
    res.sendStatus(204);
  });

  return app;
}

const store = new NotesStore();
store.add("פתק מוכן");
const server = createApp(store).listen(0, async () => {
  const address = server.address();
  const base = `http://localhost:${typeof address === "object" && address ? address.port : 0}/notes`;
  const created = await fetch(base, { method: "POST", headers: { "Content-Type": "application/json" }, body: '{"text":"  לקנות חלב  "}' });
  console.log(created.status, created.headers.get("location"));
  console.log(store.list().map((n) => n.text));
  console.log((await fetch(`${base}/1`, { method: "DELETE" })).status, (await fetch(`${base}/1`)).status);
  server.close();
});

הקוד שמחוץ לאפליקציה רואה בדיוק את מה שנשמר (store.list()) — כי שניהם עובדים עם אותו אובייקט. כך בדיוק בודקים שרת: נותנים לו store עם נתונים ידועים, שולחים בקשות, ובודקים את ה־store. בשיעור 3 ה־store יהפוך ל־repository, ובפרק 19 — למסד נתונים, בלי לגעת ב־routes.

⚠️ טעויות נפוצות

  • this.notes ציבורי — כל קוד יכול לשנות את ה־Map בלי לעבור דרך add (ובלי id תקין).
