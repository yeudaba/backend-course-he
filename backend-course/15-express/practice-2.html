P15-E04 · סדר middleware

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

מה יודפס, ומה יקבל הלקוח, לבקשה GET /admin/stats? ואחר כך ל־GET /public?

app.use((req, res, next) => { console.log("A"); next(); });
app.get("/public", (req, res) => { console.log("B"); res.json("public"); });
app.use("/admin", (req, res, next) => {
  console.log("C");
  if (req.get("x-admin") !== "yes") { res.status(403).json("אסור"); return; }
  next();
});
app.get("/admin/stats", (req, res) => { console.log("D"); res.json("stats"); });
app.use((req, res) => { console.log("E"); res.status(404).json("לא נמצא"); });

P15-E09 · middleware לוג 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ 15-express/starter/P15-E09.ts השלם createLogger(write) שמחזירה middleware. אחרי שכל תשובה נשלחה, הוא קורא ל־write עם שורה:

GET /products?page=2 200 3ms

method, הכתובת המלאה (כולל query — req.originalUrl), status, ומשך במילישניות שלמות. (הבדיקה מעבירה write משלה במקום console.log — זו הזרקת תלות.)

P15-E10 · שגיאות במקום אחד 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 15-express/starter/P15-E10.ts (המחלקה HttpError כתובה) השלם:

  • notFound ← 404 { error: { code: "NOT_FOUND", message: אין כתובת ${method} ${path} } }.
  • errorHandler: HttpError ← ה־status שלה עם { error: { code, message } }; JSON שבור ← 400 INVALID_JSON / "JSON לא תקין"; כל השאר ← 500 INTERNAL / "שגיאה פנימית", וקריאה ל־console.error(err).

הבדיקה בונה אפליקציה עם routes שזורקים (גם async), ומחברת את שתי הפונקציות שלך בסוף.

P15-E18 · מפתח API 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 15-express/starter/P15-E18.ts השלם requireApiKey(keys) — keys הוא Map ממפתח לשם לקוח. ה־middleware:

  • אין header X-Api-Key ← 401 { error: { code: "MISSING_API_KEY", ... } }, ו־header WWW-Authenticate: ApiKey.
  • מפתח לא מוכר ← 403 INVALID_API_KEY.
  • תקין ← res.locals.client = <שם הלקוח> וממשיך.

והשלם createApp(keys): GET /public פתוח לכולם ({ "ok": true }); כל מה שתחת /api מוגן; GET /api/me ← { "client": ... }.

P15-E20 · הסדר הפוך 🤖

💻 כתיבת קוד 🤖רמה 4⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ 15-express/starter/P15-E20.ts שלוש תקלות: (1) כל בקשה — גם GET /tasks — מקבלת 404; (2) אחרי שמזיזים את ה־404, POST /tasks נכשל כי req.body הוא undefined; (3) GET /tasks/boom מחזיר דף HTML של Express עם stack trace, במקום JSON 500. תקן רק את הסדר (אל תשנה את תוכן הפונקציות).

P15-E21 · Cannot set headers 🤖

💻 כתיבת קוד 🤖רמה 4⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ 15-express/starter/P15-E21.ts: (1) GET /products/abc כותב ביומן Cannot set headers after they are sent; (2) GET /products/1 מחזיר 404 למרות שהמוצר קיים; (3) ה־middleware של זמן התגובה מוסיף header — אבל לפעמים זה זורק את אותה שגיאה ולפעמים ה־header חסר. תקן את שלושתם; ה־header X-Response-Time צריך להופיע בכל תשובה (ערך כמו "3ms").
