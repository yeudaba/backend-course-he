P15-E29 · מתי req.body ריק?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

לשני השרתים אותו route. ב־a אין express.json(), וב־b יש. מה יודפס לכל בקשה?

import express from "express";

function build(withJson: boolean) {
  const app = express();
  if (withJson) app.use(express.json());
  app.post("/echo", (req, res) => {
    res.json({ type: typeof req.body, body: req.body ?? null });
  });
  return app;
}

const a = build(false).listen(0);
const b = build(true).listen(0);
const url = (s: typeof a) => `http://localhost:${(s.address() as { port: number }).port}/echo`;
const json = { "Content-Type": "application/json" };
setTimeout(async () => {
  for (const [name, server] of [["a", a], ["b", b]] as const) {
    const r1 = await fetch(url(server), { method: "POST", headers: json, body: '{"x":1}' });
    const r2 = await fetch(url(server), { method: "POST", headers: { "Content-Type": "text/plain" }, body: '{"x":1}' });
    const r3 = await fetch(url(server), { method: "POST" });
    console.log(name, JSON.stringify(await r1.json()), JSON.stringify(await r2.json()), JSON.stringify(await r3.json()));
  }
  a.close();
  b.close();
}, 50);

P15-E38 · המערך שהועבר ל־createApp

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, פרק 7, שיעור 1

createApp(products) מקבל מערך מבחוץ, ו־POST מוסיף אליו. מה יודפס?

import express from "express";

type Product = { id: number; name: string };

function createApp(products: Product[]) {
  const app = express();
  app.use(express.json());
  app.post("/products", (req, res) => {
    const product = { id: products.length + 1, name: req.body.name };
    products.push(product);
    res.status(201).json(product);
  });
  return app;
}

const seed: Product[] = [{ id: 1, name: "מקלדת" }];
const copy = [...seed];
const server = createApp(seed).listen(0, async () => {
  const base = `http://localhost:${(server.address() as { port: number }).port}`;
  await fetch(`${base}/products`, { method: "POST", headers: { "Content-Type": "application/json" }, body: '{"name":"עכבר"}' });
  console.log(seed.length, copy.length);
  seed.length = 0;
  const r = await fetch(`${base}/products`, { method: "POST", headers: { "Content-Type": "application/json" }, body: '{"name":"מסך"}' });
  console.log(JSON.stringify(await r.json()), seed.length);
  server.close();
});

🔗 איך זה מתחבר: מערכים ואובייקטים עוברים לפי הפניה (פרקים 6–7) — ‏[...seed] הוא עותק, ‏seed הוא אותו מערך. השיעור: createApp שמקבל נתונים מבחוץ (כמו ב־P15-E07).

P15-E39 · למה TypeScript לא מרשה toLowerCase?

type QueryValue = undefined | string | string[] | { [key: string]: unknown };

function search(query: { [key: string]: QueryValue }) {

  const q3 = String(query.q ?? "").toLowerCase();
  const page = Number(query.page ?? 1);
  if (typeof query.q === "string") {

}

  • האפליקציה: GET /notes ← store.list(); ‏POST /notes { text } (מחרוזת, אחרי trim 1–200; נשמר אחרי trim) ← 201 + Location, אחרת 400 { "error": "text לא תקין" }; ‏GET /notes/:id ← 200 / 404 { "error": "לא נמצא" }; ‏DELETE /notes/:id ← 204 / 404.
  • האפליקציה עובדת רק דרך ה־store שקיבלה (הבדיקה מעבירה store משלה עם פתקים מוכנים).
