P15-E01 · איזה route יענה?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

האפליקציה:

app.get("/products", A);
app.get("/products/new", B);
app.get("/products/:id", C);
app.post("/products", D);
app.get("/products/:id/reviews", E);

מי יטפל בכל בקשה, ומה יהיו req.params ו־req.query? (1) GET /products?sort=price (2) GET /products/new (3) GET /products/42 (4) POST /products/42 (5) GET /products/42/reviews?page=2 (6) GET /products/42/reviews/7. ומה ישתנה ב־(2) אם נחליף את הסדר של B ו־C?

P15-E02 · מאפיון ל־routes

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

כתוב את שורות ה־route (רק router.METHOD("path", ...)) ל־API של ספרייה, כש־router מחובר ב־app.use("/books", router):

  1. רשימת ספרים, עם סינון לפי מחבר.
  2. ספר אחד.
  3. הוספת ספר.
  4. שינוי רק של מספר העותקים.
  5. מחיקת ספר.
  6. השאלת ספר (פעולה, לא CRUD).
  7. כל ההשאלות של ספר.

P15-E03 · מה הלקוח מקבל?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

לכל handler — איזה status, איזה Content-Type ואיזה גוף יקבל הלקוח?

(req, res) => { res.json({ ok: true }); }                         // 1
(req, res) => { res.status(201).json({ id: 5 }); }                // 2
(req, res) => { res.sendStatus(204); }                            // 3
(req, res) => { res.send("שלום"); }                               // 4
(req, res) => { res.status(404); }                                // 5
(req, res) => { res.json(null); }                                 // 6

P15-E06 · שלום Express 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

בקובץ 15-express/starter/P15-E06.ts השלם createApp() שמחזירה אפליקציית Express:

  • GET /hello ← { "message": "שלום אורח" }; עם ?name=דנה ← "שלום דנה".
  • GET /add/:a/:b ← { "sum": a + b } (כמספרים). אם אחד מהם לא מספר ← 400 { "error": "a ו־b חייבים להיות מספרים" }.

P15-E07 · קריאת מוצרים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

בקובץ 15-express/starter/P15-E07.ts השלם createApp(products) (המוצרים מועברים מבחוץ):

  • GET /products ← כל המוצרים; עם ?maxPrice=100 ← רק עד המחיר.
  • GET /products/:id ← המוצר, או 404 { "error": { "code": "NOT_FOUND", "message": "המוצר לא נמצא" } }.

P15-E08 · יצירה ומחיקה 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 1

בקובץ 15-express/starter/P15-E08.ts השלם createApp() עם רשימת מוצרים בזיכרון (מתחילה ריקה, ids מ־1):

  • GET /products ← הרשימה.
  • POST /products { name, price } ← 201, המוצר עם id, ו־Location: /products/<id>. name חייב להיות מחרוזת לא ריקה (אחרי trim) ו־price מספר חיובי, אחרת 400 { "error": "..." }. JSON שבור ← 400 (רמז: error handler קטן).
  • DELETE /products/:id ← 204, או 404.
