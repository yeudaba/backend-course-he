P15-E58 · pagination כשהרשימה זזה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

הלקוח טוען עמוד 1 (3 פריטים, מהחדש לישן). בינתיים נוספות שתי משימות חדשות. אז הוא טוען עמוד 2. מה יודפס?

function paginate<T>(items: T[], page: number, limit: number) {
  const start = (page - 1) * limit;
  return items.slice(start, start + limit);
}

let tasks = [7, 6, 5, 4, 3, 2, 1]; // מזהים, מהחדש לישן
console.log("עמוד 1:", paginate(tasks, 1, 3));
tasks = [9, 8, ...tasks]; // נוספו שתי משימות
console.log("עמוד 2:", paginate(tasks, 2, 3));
tasks = tasks.filter((id) => id !== 8 && id !== 9 && id !== 7);
console.log("עמוד 3 אחרי מחיקות:", paginate(tasks, 3, 3));

P15-E59 · מה ה־Router רואה?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

import express, { Router } from "express";

const router = Router();
router.get("/", (req, res) => {
  res.json({ route: "list", baseUrl: req.baseUrl, path: req.path, originalUrl: req.originalUrl });
});
router.get("/:id", (req, res) => {
  res.json({ route: "one", id: req.params.id, path: req.path });
});

const app = express();
app.use("/api/tasks", router);

const server = app.listen(0, async () => {
  const base = `http://localhost:${(server.address() as { port: number }).port}`;
  for (const path of ["/api/tasks?page=2", "/api/tasks/", "/api/tasks/7", "/api/tasks/7/comments", "/tasks/7"]) {
    const res = await fetch(base + path);
    console.log(path.padEnd(22), res.status, res.headers.get("content-type")?.includes("json") ? await res.text() : "");
  }
  server.close();
});

P15-E26 · API משימות — מקובץ ריק 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 30 דק׳ידע נדרש: שיעור 3

P15-E65 · service ששולף במקביל

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: פרק 10, שיעור 3

service של "דף לקוח" שולף משתמש, הזמנות ונקודות — כל שליפה לוקחת 100ms (כמו מסד). שתי גרסאות. כמה זמן לוקחת כל אחת (בערך)?

const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));
const repo = {
  user: async (id: number) => (await sleep(100), { id, name: "דנה" }),
  orders: async (id: number) => (await sleep(100), [{ id: 1 }, { id: 2 }]),
  points: async (id: number) => (await sleep(100), 340),
};

async function sequential(id: number) {
  const user = await repo.user(id);
  const orders = await repo.orders(id);
  const points = await repo.points(id);
  return { user, orders: orders.length, points };
}
async function parallel(id: number) {
  const [user, orders, points] = await Promise.all([repo.user(id), repo.orders(id), repo.points(id)]);
  return { user, orders: orders.length, points };
}

for (const fn of [sequential, parallel]) {
  const start = Date.now();
  const result = await fn(7);
  const ms = Date.now() - start;
  console.log(fn.name, JSON.stringify(result), ms >= 290 ? "~300ms" : ms < 150 ? "~100ms" : "?");
}

P15-E67 · קצוות של slice

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 3

פונקציית ה־paginate מהשיעור, עם ערכים שלא בדקו. מה יודפס?

function paginate<T>(items: T[], page: number, limit: number) {
  const start = (page - 1) * limit;
  return {
    data: items.slice(start, start + limit),
    meta: { page, limit, total: items.length, totalPages: Math.ceil(items.length / limit) },
  };
}

const items = [1, 2, 3, 4, 5];
console.log(JSON.stringify(paginate(items, 3, 2)));
console.log(JSON.stringify(paginate(items, 9, 2)));
console.log(JSON.stringify(paginate(items, 0, 2)));
console.log(JSON.stringify(paginate(items, -1, 2)));
console.log(JSON.stringify(paginate(items, 1, 0)));
console.log(JSON.stringify(paginate([], 1, 10)));

🔗 איך זה מתחבר: slice עם אינדקסים שליליים מפרק 6, וחילוק באפס מפרק 1. השיעור: למה page ו־limit חייבים בדיקה (ובשיעור 4 — Zod עם min(1)).

  • אותו sku כמה פעמים ← שורה אחת, עם סכום הכמויות. השורות לפי סדר ההופעה הראשונה.
  • sku שאינו בקטלוג ← 404 { "error": "מוצר לא קיים: BOOK" }.
  • תשובה 200: { lines: [{ sku, name, qty, subtotal }], total }. ‏subtotal = מחיר × כמות. ‏total — סכום ה־subtotal, עם reduce.

P15-E68 · רשימה עם meta וקישורים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 14, שיעור 3

כתוב וייצא createApp(products) (מערך { id, name, price }) עם GET /products:

  • query: page (שלם ≥ 1, ברירת מחדל 1), ‏limit (שלם 1–50, ברירת מחדל 10), ‏q (אופציונלי — חיפוש בשם, בלי תלות באותיות). ‏page או limit לא תקינים (לא בדיוק ספרות, או מחוץ לטווח) ← 400 { error: { code: "VALIDATION_ERROR", message: "page או limit לא תקינים" } }.
  • תשובה: { data, meta: { page, limit, total, totalPages }, links: { self, next, prev } }. ‏total — אחרי הסינון; ‏totalPages — Math.ceil(total / limit).
  • הקישורים הם נתיב + query (בלי host), למשל /products?q=a&page=2&limit=5: ‏self — העמוד הנוכחי; ‏next — אם page < totalPages, אחרת null; ‏prev — אם page > 1, אחרת null. בכל קישור: q (רק אם נשלח), ‏page, ‏limit — בסדר הזה.

P15-E69 · יצירה מרובה — הכול או כלום 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 6, פרק 8, שיעור 3

כתוב וייצא createApp() עם מוצרים בזיכרון ו־:

  • POST /products/bulk — הגוף הוא מערך של { name, price } (1–100 פריטים; אחרת 400 { error: { code: "VALIDATION_ERROR", message: "שלח מערך של 1–100 מוצרים" } }).
  • כל פריט: name — מחרוזת לא ריקה אחרי trim; ‏price — מספר שלם חיובי (אגורות). שמות כפולים בתוך הבקשה (בלי תלות באותיות, אחרי trim) — שגיאה בפריט השני.
  • אם יש שגיאות ← 400 { error: { code: "VALIDATION_ERROR", message: "חלק מהמוצרים לא תקינים", details: [{ index, message }] } } — לכל פריט שגוי, לפי הסדר (הודעה אחת לפריט: "name לא תקין", "price לא תקין" או "שם כפול"; אם גם name וגם price שגויים — של name). ושום מוצר לא נשמר.
  • הכול תקין ← 201 { created: [...] } עם ids רצים (מ־1, ממשיכים בין בקשות; name נשמר אחרי trim).
  • GET /products ← כל המוצרים.
