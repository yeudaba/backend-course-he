בקובץ 15-express/starter/P15-E13.ts השלם:

  • paginate(items, page, limit) ← { data, meta: { page, limit, total, totalPages } }. רשימה ריקה ← totalPages: 0.

P15-E19 · שירות חיצוני 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

בקובץ 15-express/starter/P15-E19.ts השלם createApp({ getForecast }). getForecast(city) היא פונקציה async (שירות מזג אוויר חיצוני, שהבדיקה מזריקה): מחזירה { tempC, summary }, או null אם העיר לא מוכרת, או זורקת כשהשירות נופל.

GET /weather/:city:

  • הצליח ← 200 { city, tempC, summary }.
  • null ← 404 CITY_NOT_FOUND.
  • זרק ← 502 { error: { code: "UPSTREAM_ERROR", message: "שירות מזג האוויר לא זמין" } } — לא 500: הבעיה לא בקוד שלנו.
  • לקח יותר מ־1000ms ← 504 UPSTREAM_TIMEOUT.

P15-E26 · API משימות — מקובץ ריק 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 30 דק׳ידע נדרש: שיעור 3

עד עכשיו השלמת אפליקציות שהשלד שלהן כבר היה כתוב. הפעם הקובץ ריק: את ה־imports, ה־schema, ה־routes וה־error handler כותבים לבד, מהשורה הראשונה.

כתוב וייצא createApp() שמחזירה אפליקציית Express (בלי listen — הבודק מפעיל אותה). המשימות נשמרות בזיכרון: { id, title, done }, ‏ids מ־1.

  • GET /tasks ← כל המשימות. עם ?done=true או ?done=false — רק המתאימות. ערך אחר של done — כאילו לא נשלח.
  • GET /tasks/:id ← המשימה, או 404 { "error": "המשימה לא נמצאה" } (גם ל־id שאינו מספר).
  • POST /tasks עם { title, done? } ← 201, המשימה, ו־Location: /tasks/<id>. בודקים עם Zod: title מחרוזת, אחרי trim באורך 1–100 (ונשמרת אחרי trim). ‏done בוליאני, ברירת מחדל false.
  • קלט לא תקין ← 400 { "error": "קלט לא תקין", "fields": [...] }. ב־fields: שמות השדות שנכשלו, כל שם פעם אחת (["title", "done"]).
  • DELETE /tasks/:id ← 204, או 404 כמו למעלה.
  • JSON שבור ← 400 { "error": "JSON לא תקין" }.
  • כל אפליקציה מתחילה עם רשימה ריקה משלה.

📄 כותבים בקובץ 15-express/starter/P15-E26.ts (יש בו רק הערה), ובודקים:

% npm run check P15-E26

רוצה לנסות ביד? הוסף בסוף הקובץ createApp().listen(3000), ושלח בקשות עם curl או עם REST Client (פרק 14). לפני הבדיקה — מחק את השורה.

P15-E28 · סכום עגלה 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

🔁 חזרה על Map לקיבוץ (פרק 7) ועל reduce (פרק 6), בתוך route של Express. כתוב וייצא createApp(catalog). ‏catalog הוא Map<string, Product>, ו־type Product = { name: string; price: number } (מחיר באגורות). ייצא גם את Product.

route אחד: POST /cart/total עם גוף { items: [{ sku, qty }] }:

  • בדיקה עם Zod: ‏items מערך עם פריט אחד לפחות, ‏sku מחרוזת לא ריקה, ‏qty מספר שלם 1–99. אחרת 400 { "error": "קלט לא תקין" }.
  • אותו sku כמה פעמים ← שורה אחת, עם סכום הכמויות. השורות לפי סדר ההופעה הראשונה.
  • sku שאינו בקטלוג ← 404 { "error": "מוצר לא קיים: BOOK" }.
  • תשובה 200: { lines: [{ sku, name, qty, subtotal }], total }. ‏subtotal = מחיר × כמות. ‏total — סכום ה־subtotal, עם reduce.

📄 כותבים בקובץ 15-express/starter/P15-E28.ts (יש בו רק הערה), ובודקים:

% npm run check P15-E28
