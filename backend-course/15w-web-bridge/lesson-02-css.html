שיעור 2 — CSS: מספיק כדי שלא ייראה שבור

⏱ ~30 דקות

🎯 בשיעור הזה
  • איך מחברים CSS, ואיך כלל נראה.
  • selectors: תגית, class, id.
  • box model: padding, border, margin.
  • flexbox — סידור בשורה, ו־RTL.

1. כלל CSS

playground/style.css 
body {
  font-family: system-ui, sans-serif;
  background: #f4f5f7;
  margin: 0;
}

.card {
  background: white;
  border: 1px solid #d8dbe0;
  border-radius: 12px;
  padding: 16px;
}

#title {
  font-size: 1.5rem;
}

מחברים מה־head של הדף: <link rel="stylesheet" href="style.css">. כל כלל: selector (על מי) + הצהרות תכונה: ערך; (מה).

Selectorבוחר
body, liכל התגיות מהסוג
.cardכל מי שיש לו class="card" (אפשר הרבה)
#titleהאלמנט עם id="title" (אחד)
.card h2h2 שנמצא בתוך .card
li.doneli שיש לו גם class done
button:hoverכפתור כשהעכבר מעליו

כשכמה כללים מתנגשים — המפורט יותר מנצח (#id > .class > תגית), ובשוויון — האחרון בקובץ. אם משהו "לא מתעדכן", ב־DevTools ← Elements ← Styles רואים איזה כלל ניצח ואיזה נמחק בקו.

2. Box model

מלכודת קלאסית: width: 300px עם padding: 20px ו־border: 1px — הקופסה תופסת בפועל 342px. הפתרון שכולם שמים בראש כל קובץ CSS:

* {
  box-sizing: border-box; /* width כולל את ה־padding וה־border */
}

יחידות: px (פיקסלים), rem (יחסית לגודל הגופן הבסיסי — 1.5rem = פי 1.5), % (מההורה).

3. Flexbox — סידור בשורה

.row {
  display: flex;
  gap: 12px;                       /* רווח בין הילדים */
  align-items: center;             /* יישור אנכי */
  justify-content: space-between;  /* פיזור לרוחב */
}
.row .title {
  flex: 1;                         /* "קח את כל המקום שנשאר" */
}
<li class="row">
  <input type="checkbox">
  <span class="title">ללמוד flexbox</span>
  <button>מחיקה</button>
</li>

בלי flex — li מסדר את הילדים בשורה רק אם הם "inline", ויישור אנכי הוא סבל. עם flex: שלוש שורות CSS, והכפתור נדחף לקצה. ו־RTL? בזכות dir="rtl" על html, flex מתחיל מימין — הצ'קבוקס מימין, הכפתור משמאל. בלי לשנות כלום ב־CSS.

תכונהערכים נפוצים
flex-directionrow (ברירת מחדל) · column
justify-contentflex-start · center · space-between — לאורך הכיוון
align-itemsstretch · center · flex-start — לרוחב הכיוון
flex-wrap: wrapלרדת שורה כשאין מקום (טוב לטלפון)
💡 מספיק

עם מה שבשיעור הזה אפשר לבנות דף הדגמה מסודר. Grid, אנימציות, media queries וספריות כמו Tailwind — קיימים, ולא נחוצים למפתח Backend. אם תרצה בהמשך — MDN ו־Flexbox Froggy (משחק, יש עברית).
