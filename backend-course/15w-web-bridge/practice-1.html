P15.5-E13 · טבלת HTML מנתונים 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

דף ניהול מציג כמעט תמיד טבלה: מוצרים, הזמנות, משתמשים. כתוב פונקציה אחת שבונה טבלה לכל רשימה. כתוב וייצא renderTable(columns, rows), שמחזירה מחרוזת HTML:

  • columns — מערך של { key, label, numeric? }. ‏rows — מערך של אובייקטים.
  • המבנה, בשורה אחת ובלי רווחים בין התגיות: <table><thead><tr><th>label</th>...</tr></thead><tbody><tr><td>...</td>...</tr>...</tbody></table>.
  • בכל שורה, תא לכל עמודה לפי הסדר של columns: הערך row[key]. ערך null או undefined ← — (קו מפריד ארוך).
  • עמודה עם numeric: true ← <td class="num"> (ב־CSS היא תיושר לשמאל, כמו מספרים).
  • כל טקסט — גם הכותרות — מקודד כמו ב־P15.5-E06 (& < > " '). את הקידוד כותבים שוב, בתוך הקובץ הזה.
  • אין שורות ← <p class="empty">אין נתונים להצגה</p> במקום הטבלה.

P15.5-E28 · &lt; על המסך

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 2, שיעור 1

מה המשתמש יראה בדפדפן לכל שורה ב־HTML? ובאילו מהן ייווצר אלמנט אמיתי?

<p>1 &lt; 2 &amp;&amp; 3 &gt; 2</p>
<p>1 < 2 && 3 > 2</p>
<p>&lt;b&gt;מודגש?&lt;/b&gt;</p>
<p><b>מודגש!</b></p>
<p>&amp;lt;b&amp;gt;</p>

ואחר כך — מה תחזיר הפונקציה escapeHtml מ־P15.5-E06 על המחרוזת <b>, ועל התוצאה שלה פעם נוספת?

🔗 איך זה מתחבר: replaceAll ומחרוזות מפרק 2, ו־escapeHtml מ־P15.5-E06. השיעור: HTML הוא טקסט שהדפדפן מפרש — ו־&...; הוא הדרך לכתוב תו "כמו שהוא".

P15.5-E29 · טופס HTML מול express.json

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 15, שיעור 1

טופס רגיל (method="post", בלי JavaScript) שולח את השדות כ־application/x-www-form-urlencoded — לא JSON. הקוד מדמה שליחה כזו לשרת Express. מה יודפס?

import express from "express";

const app = express();
app.use(express.json());
app.post("/signup", (req, res) => res.json({ body: req.body ?? null }));
const app2 = express();
app2.use(express.urlencoded());
app2.post("/signup", (req, res) => res.json({ body: req.body ?? null }));

const form = new URLSearchParams({ email: "dana@x.co", terms: "on" });
for (const a of [app, app2]) {
  const server = a.listen(0);
  await new Promise((r) => server.once("listening", r));
  const res = await fetch(`http://localhost:${server.address().port}/signup`, { method: "POST", body: form });
  console.log(res.headers.get("content-type").split(";")[0], await res.text());
  server.close();
}

🔗 איך זה מתחבר: express.json() ו־req.body מפרק 15 (P15-E29), ו־Content-Type מפרק 14. השיעור: מה טופס HTML שולח כשאין JavaScript.

P15.5-E30 · אפשרויות של select מקוד 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: פרק 6, שיעור 1

רשימת הקטגוריות מגיעה מה־API, וצריך לבנות ממנה <option>־ים. כתוב וייצא renderOptions(options, selected) שמחזירה מחרוזת HTML:

  • options — מערך של { value, label }. לכל אחד: <option value="...">label</option>, בלי רווחים בין האפשרויות.
  • האפשרות שה־value שלה שווה ל־selected מקבלת selected (‏<option value="b" selected>). ‏value מספרי — משווים כמחרוזות (selected מה־query הוא מחרוזת).
  • גם ה־value וגם ה־label מקודדים (& < > " ' — כמו ב־P15.5-E06; כתוב את הקידוד בקובץ הזה).
  • אם placeholder (פרמטר שלישי, לא חובה) נשלח ← בהתחלה <option value="">placeholder</option>, ו־selected עליה כשאף אפשרות אחרת לא נבחרה.

P15.5-E31 · בודק תוויות לטופס 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 7, פרק 13, שיעור 1

כתוב וייצא checkForm(html) — מקבלת HTML של טופס (מחרוזת) ומחזירה מערך בעיות (מחרוזות), לפי הסדר הזה:

  1. לכל id שמופיע יותר מפעם אחת (בכל תגית): id כפול: X — פעם אחת לכל id, לפי הופעה ראשונה.
  2. לכל שדה (input, ‏select, ‏textarea) — לפי הסדר: בלי name ← שדה בלי name: <id או "?">; ושדה בלי id, או שאין label עם for שלו ← שדה בלי label: <name או "?">. שדות עם type="submit", "hidden" או "button" — לא נבדקים.
  3. לכל label שה־for שלו לא מצביע על שום id: label יתום: X.

מאפיינים יכולים להיות במירכאות כפולות, בודדות או בלי מירכאות; שמות תגיות ומאפיינים — בלי תלות באותיות.
