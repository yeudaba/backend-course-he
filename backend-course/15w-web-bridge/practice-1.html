P15.5-E13 · טבלת HTML מנתונים 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

דף ניהול מציג כמעט תמיד טבלה: מוצרים, הזמנות, משתמשים. כתוב פונקציה אחת שבונה טבלה לכל רשימה. כתוב וייצא renderTable(columns, rows), שמחזירה מחרוזת HTML:

  • columns — מערך של { key, label, numeric? }. ‏rows — מערך של אובייקטים.
  • המבנה, בשורה אחת ובלי רווחים בין התגיות: <table><thead><tr><th>label</th>...</tr></thead><tbody><tr><td>...</td>...</tr>...</tbody></table>.
  • בכל שורה, תא לכל עמודה לפי הסדר של columns: הערך row[key]. ערך null או undefined ← — (קו מפריד ארוך).
  • עמודה עם numeric: true ← <td class="num"> (ב־CSS היא תיושר לשמאל, כמו מספרים).
  • כל טקסט — גם הכותרות — מקודד כמו ב־P15.5-E06 (& < > " '). את הקידוד כותבים שוב, בתוך הקובץ הזה.
  • אין שורות ← <p class="empty">אין נתונים להצגה</p> במקום הטבלה.

📄 כותבים בקובץ 15w-web-bridge/starter/P15.5-E13.mjs (יש בו רק הערה), מריצים ובודקים:

% node 15w-web-bridge/starter/P15.5-E13.mjs
% npm run check P15.5-E13
