יחידה 15.5 — גישור: HTML, CSS ו־fetch

⏱ 2–3 מפגשים

🧰 לפני שמתחילים — יחידה 15.5

מה צריך שכבר יהיה מותקן: VS Code עם התוסף Live Preview (פרק 0), Google Chrome, ופרויקט 2 בשלב א׳.

מה מתקינים עכשיו: כלום לשיעורים 1–2. בשיעור 4 — חבילת cors בפרויקט 2 (שם יש הוראות).

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 15w-web-bridge מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה שהסביבה מוכנה — ב־Terminal של VS Code, מתוך ~/dev/backend-course:

% node -v
v24.11.0

(כל גרסה 24 ומעלה תקינה.)

✔ Live Preview: צור playground/hello.html עם השורה <h1>שלום</h1>, לחץ עליו לחיצה ימנית ← Show Preview. אמור להיפתח חלון עם "שלום".

🎯 בסוף הפרק תדע
  • לקרוא ולכתוב דף HTML בסיסי: מבנה, כותרות, רשימות, קישורים, טופס.
  • לעצב מספיק עם CSS: צבעים, ריווח, box model, flexbox ו־RTL.
  • לכתוב JavaScript בדפדפן: לבחור אלמנטים, להגיב לאירועים, ולהציג נתונים מ־API עם fetch.
  • להבין CORS: למה הדפדפן חוסם, ואיך פותרים בשרת — נכון, בלי *.
  • לחבר דף הדגמה לפרויקט 2.

🤔 למה בכלל, אם זה קורס Backend?

שלוש סיבות: (1) בראיונות שואלים "מה קורה מהלחיצה על כפתור ועד שהנתונים מופיעים" — צריך להכיר את שני הצדדים; (2) שגיאות CORS הן בעיה של ה־Backend, ואי אפשר להבין אותן בלי דפדפן; (3) פרויקט עם דף שאפשר ללחוץ עליו מרשים יותר מ־curl. היחידה קצרה בכוונה — לא React, לא עיצוב מתקדם. רק מה שצריך.
