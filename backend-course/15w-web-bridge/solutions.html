P15.5-E13 · טבלת HTML מנתונים 🤖 ✍️ מאפס רמה 3

💡 רמז 1

שלוש פונקציות קטנות: escapeHtml(value), ‏renderCell(column, row), ‏renderTable. כל חלק של הטבלה הוא map ואחריו join("").

💡 רמז 2

rows.map((row) => &lt;tr&gt;${columns.map((c) =&gt; renderCell(c, row)).join("")}&lt;/tr&gt;).join("") — map בתוך map: שורות בחוץ, עמודות בפנים.

✅ פתרון
// P15.5-E13: טבלת HTML מנתונים
const ENTITIES = { "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" };
const escapeHtml = (value) => String(value).replace(/[&<>"']/g, (ch) => ENTITIES[ch]);

function renderCell(column, row) {
  const value = row[column.key];
  const text = value === null || value === undefined ? "—" : escapeHtml(value);
  return column.numeric ? `<td class="num">${text}</td>` : `<td>${text}</td>`;
}

export function renderTable(columns, rows) {
  if (rows.length === 0) {
    return '<p class="empty">אין נתונים להצגה</p>';
  }
  const head = columns.map((c) => `<th>${escapeHtml(c.label)}</th>`).join("");
  const body = rows.map((row) => `<tr>${columns.map((c) => renderCell(c, row)).join("")}</tr>`).join("");
  return `<table><thead><tr>${head}</tr></thead><tbody>${body}</tbody></table>`;
}

const columns = [
  { key: "name", label: "מוצר" },
  { key: "price", label: "מחיר", numeric: true },
];
console.log(renderTable(columns, [{ name: "כוס <קרמיקה>", price: 19.9 }, { name: "עט" }]));
console.log(renderTable(columns, []));
<table><thead><tr><th>מוצר</th><th>מחיר</th></tr></thead><tbody><tr><td>כוס &lt;קרמיקה&gt;</td><td class="num">19.9</td></tr><tr><td>עט</td><td class="num">—</td></tr></tbody></table>
<p class="empty">אין נתונים להצגה</p>

הטבלה בנויה כמו הנתונים: map על השורות, ובתוך כל שורה map על העמודות. ה־join("") חשוב: בלעדיו מערך הופך למחרוזת עם פסיקים, ובדף מופיעים פסיקים בין התאים.

renderCell מטפלת בשלושה דברים: ערך חסר, קידוד, ו־class למספרים. כשהלוגיקה של תא אחד נמצאת בפונקציה משלה, הטבלה עצמה נשארת שורה קריאה אחת.

למה לבדוק null ו־undefined במפורש ולא value || "—"? כי מחיר 0 או מלאי 0 הם ערכים אמיתיים. עם || הם היו הופכים ל־—.

⚠️ טעויות נפוצות
  • לשכוח join("") — בין התאים מופיעים פסיקים.
  • value || "—" — ‏0 נעלם מהטבלה.
  • לקודד רק את התאים ולא את הכותרות. גם כותרת יכולה להגיע מהמשתמש (למשל שם של שדה מותאם אישית).
  • לעבור על Object.keys(row) במקום על columns — הסדר משתנה משורה לשורה, ושדות שלא ביקשו (כמו passwordHash) מופיעים בדף.

P15.5-E14 · debounce לשדה חיפוש 🤖 🔁 חזרה רמה 3

💡 רמז 1

משתנה אחד let timer מחוץ לפונקציה המוחזרת, אבל בתוך debounce. זה ה־closure: הוא "זוכר" את הטיימר בין קריאה לקריאה. בכל קריאה: clearTimeout(timer) ואז timer = setTimeout(...).

💡 רמז 2

ארגומנטים: function debounced(...args) { ... setTimeout(() => fn(...args), ms) }. מתודה על פונקציה: debounced.cancel = () => clearTimeout(timer); — פונקציה היא גם אובייקט.

✅ פתרון
// P15.5-E14: debounce לשדה חיפוש
export function debounce(fn, ms) {
  let timer = null;
  function debounced(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      timer = null;
      fn(...args);
    }, ms);
  }
  debounced.cancel = () => {
    clearTimeout(timer);
    timer = null;
  };
  return debounced;
}

// המשתמש מקליד "c", "co", "cor", "cors" — 30ms בין הקשות. החיפוש רץ פעם אחת, 100ms אחרי ההקשה האחרונה
const search = debounce((q) => console.log("מחפשים:", q), 100);
const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
for (const q of ["c", "co", "cor", "cors"]) {
  search(q);
  await sleep(30);
}
await sleep(150);
search("x");
search.cancel();
await sleep(150);
console.log("סוף");
מחפשים: cors
סוף

ה־closure הוא timer: כל קריאה ל־debounce יוצרת משתנה חדש, וכל פונקציה מוחזרת רואה רק את שלה. זה אותו מנגנון כמו המונה ב־P05-E26. שם הזיכרון היה מספר, וכאן הוא טיימר.

clearTimeout(null) לא עושה כלום, ולכן אין צורך לבדוק אם יש טיימר לפני שמבטלים.

בהדגמה, ארבע הקשות במרווח 30ms. כל אחת "מאפסת את השעון", ורק 100ms אחרי ההקשה האחרונה החיפוש רץ — פעם אחת, עם "cors". הקריאה עם "x" בוטלה עם cancel, ולכן לא הודפסה.

⚠️ טעויות נפוצות
  • let timer מחוץ ל־debounce (ברמת הקובץ) — כל השדות חולקים טיימר אחד, ושדה אחד מבטל את החיפוש של השני.
  • לשמור את הארגומנטים של הקריאה הראשונה — מחפשים "c" במקום "cors".
  • להפעיל את fn מיד ולחסום קריאות בהמשך — זה throttle, לא debounce.

P15.5-E15 · טעינת לוח בקרה במקביל 🤖 🔁 חזרה רמה 3

💡 רמז 1

Promise.all נכשל כולו אם בקשה אחת נכשלה, ולכן כאן משתמשים ב־Promise.allSettled: לכל בקשה מקבלים { status: "fulfilled", value } או { status: "rejected", reason }. ‏const [me, tasks, stats] = await Promise.allSettled([...]).

💡 רמז 2

if (me.status === "rejected") throw me.reason;. לשתי האחרות — פונקציית עזר valueOf(result, name) שמחזירה result.value, או מוסיפה ל־errors ומחזירה null.

✅ פתרון
// P15.5-E15: טעינת לוח בקרה במקביל
export async function loadDashboard(getJson) {
  const [me, tasks, stats] = await Promise.allSettled([getJson("/me"), getJson("/tasks"), getJson("/stats")]);
  if (me.status === "rejected") {
    throw me.reason;
  }
  const errors = [];
  const valueOf = (result, name) => {
    if (result.status === "fulfilled") {
      return result.value;
    }
    errors.push(`${name}: ${result.reason.message}`);
    return null;
  };
  return { me: me.value, tasks: valueOf(tasks, "tasks"), stats: valueOf(stats, "stats"), errors };
}

const data = { "/me": { name: "דנה" }, "/tasks": [{ id: 1, title: "ללמוד CORS" }] };
const getJson = async (path) => {
  await new Promise((resolve) => setTimeout(resolve, 50));
  if (!(path in data)) throw new Error("503 Service Unavailable");
  return data[path];
};

const start = Date.now();
const dashboard = await loadDashboard(getJson);
console.log(dashboard);
console.log(Date.now() - start < 100 ? "במקביל" : "אחד אחרי השני");
{
  me: { name: 'דנה' },
  tasks: [ { id: 1, title: 'ללמוד CORS' } ],
  stats: null,
  errors: [ 'stats: 503 Service Unavailable' ]
}
במקביל

שלוש בקשות של 50ms לקחו פחות מ־100ms, כי הן יצאו יחד. אחת אחרי השנייה זה היה לוקח 150ms.

ההחלטה מה "חובה" ומה "רשות" היא החלטה של הדף, לא של הרשת. בלי /me אי אפשר להציג כלום, ולכן זורקים, ומי שקרא ל־loadDashboard יעביר לדף ההתחברות. בלי סטטיסטיקה עדיין אפשר לעבוד, ולכן מציגים את הדף עם הודעה קטנה.

throw me.reason זורק את השגיאה המקורית ולא שגיאה חדשה. כך נשמרים ה־status וכל השדות ש־ApiError (P15.5-E08) הוסיפה.

⚠️ טעויות נפוצות
  • await getJson("/me"), אחר כך await getJson("/tasks")... — עובד, אבל לאט פי שלושה. הבודק מודד.
  • Promise.all — תקלה ב־/stats מפילה את כל הדף.
  • throw new Error("לא מחובר") במקום throw me.reason — מאבדים את סוג השגיאה ואת ההודעה מהשרת.

P15.5-E01 · מה לא תקין בדף? רמה 1

חסרים שלושה דברים בראש הקובץ.

💡 רמז 2

לכל שדה: label מחובר, name, type מתאים.

✅ פתרון
  1. אין <!doctype html> — מצב תאימות ישן.
  2. אין lang="he" dir="rtl" — הכיוון שגוי, וקורא מסך לא יודע שזו עברית.

P15.5-E03 · אותו origin? preflight? רמה 1

💡 רמז 1

origin = פרוטוקול + host + port. כל הבדל — origin אחר.

💡 רמז 2

"פשוטה" = GET/HEAD/POST, בלי headers מיוחדים, ו־Content-Type רק מסוגי טפסים.

✅ פתרון
  1. אותו origin — אין CORS בכלל.
  2. origin אחר (port). בקשה פשוטה ← בלי preflight, אבל התשובה תיחסם בלי Access-Control-Allow-Origin.
  3. origin אחר! 127.0.0.1 ו־localhost הם אותו מחשב, אבל שמות שונים.
  4. אחר; preflight — application/json הופך אותה ל"לא פשוטה".
  5. אחר; preflight — DELETE.
  6. אחר (פרוטוקול).
  7. אחר; preflight — header Authorization.
⚠️ טעויות נפוצות
  • לחשוב ש־localhost ו־127.0.0.1 "זה אותו דבר" — לדפדפן לא. זו סיבה נפוצה ל"זה עבד אתמול".

P15.5-E06 · קידוד HTML 🤖 רמה 2

💡 רמז 1

& קודם — אחרת < הופך ל־&lt; ואז ל־&amp;lt;.

💡 רמז 2

replaceAll חמש פעמים, או replace(/[&<>"']/g, (ch) => map[ch]).

✅ פתרון
// P15.5-E06
const ENTITIES = { "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" };

export function escapeHtml(value) {
  if (value === null || value === undefined) return "";
  return String(value).replace(/[&<>"']/g, (ch) => ENTITIES[ch]);
}

export function renderTaskItem(task) {
  return `<li class="task ${escapeHtml(task.priority)}">${escapeHtml(task.title)}</li>`;
}

⚠️ טעויות נפוצות

P15.5-E08 · לקוח API 🤖 רמה 3

💡 רמז 1

פונקציה פנימית אחת request(method, path, body), וכל המתודות קוראות לה.

💡 רמז 2

גוף שגיאה לא JSON: await res.json().catch(() => null).

✅ פתרון
// P15.5-E08
export class ApiError extends Error {
  constructor(status, code, message, details = []) {
    super(message);
    this.name = "ApiError";
    this.status = status;
    this.code = code;
    this.details = details;
  }
}

export function createApiClient(baseUrl) {
  async function request(method, path, body) {
    const res = await fetch(baseUrl + path, {
      method,
      headers: body === undefined ? {} : { "Content-Type": "application/json" },
      body: body === undefined ? undefined : JSON.stringify(body),
    });
    if (res.status === 204) return undefined;
    const data = await res.json().catch(() => null);
    if (!res.ok) {
      const e = data?.error;
      throw new ApiError(res.status, e?.code ?? "UNKNOWN", e?.message ?? `HTTP ${res.status}`, e?.details ?? []);
    }
    return data;
  }

  return {
    listTasks(params = {}) {
      const sp = new URLSearchParams();
      for (const [k, v] of Object.entries(params)) if (v !== "" && v !== undefined && v !== null) sp.append(k, String(v));
      const qs = sp.toString();
      return request("GET", `/tasks${qs ? `?${qs}` : ""}`);
    },
    createTask: (body) => request("POST", "/tasks", body),
    updateTask: (id, changes) => request("PATCH", `/tasks/${id}`, changes),
    deleteTask: (id) => request("DELETE", `/tasks/${id}`),
  };
}

בדף: const api = createApiClient("http://localhost:3000"), ואז try { await api.createTask(...) } catch (err) { if (err instanceof ApiError) showError(err.message) }. כל הידע על HTTP במקום אחד; שאר הקוד מדבר במונחים של "משימות". זה דפוס שתמצא בכל Frontend רציני — וגם ב־Backend, כשאתה קורא לשירות אחר.

⚠️ טעויות נפוצות
  • לקרוא res.json() על 204 — זורק, כי אין גוף.

למה Vary? כי התשובה שונה לפי origin — cache (פרק 26) חייב לדעת לא להגיש תשובה של origin אחד לאחר.

✅ פתרון
// P15.5-E09
import type { Request, Response, NextFunction } from "express";

export function corsMiddleware(origins: string[]) {
  const allowed = new Set(origins);
  return (req: Request, res: Response, next: NextFunction) => {
    const origin = req.get("origin");
    const ok = origin !== undefined && allowed.has(origin);
    res.vary("Origin");
    if (ok) res.set("Access-Control-Allow-Origin", origin);

    if (req.method === "OPTIONS") {
      if (ok) {
        res.set({
          "Access-Control-Allow-Methods": "GET,POST,PUT,PATCH,DELETE",
          "Access-Control-Allow-Headers": req.get("access-control-request-headers") ?? "Content-Type",
          "Access-Control-Max-Age": "600",
        });
      }
      res.sendStatus(204);
      return;
    }
    next();
  };
}

Max-Age אומר לדפדפן "אל תשאל שוב 10 דקות" — בלי זה, כל PATCH הוא שתי בקשות.

⚠️ טעויות נפוצות
  • להחזיר 403 לבקשה רגילה מ־origin לא מורשה — שובר לקוחות שאינם דפדפן (שרתים, אפליקציות), שבכלל לא שולחים Origin או ש־CORS לא רלוונטי להם.

P15.5-E12 · אתגר: CORS לייצור 🤖 רמה 5

💡 רמז 1

💡 רמז 2

תבנית ל־RegExp: לקודד נקודות (\.), להחליף את * ב־[a-z0-9-]+, ולעגן ^...$.

✅ פתרון
// P15.5-E12
import type { Request, Response, NextFunction } from "express";

function matcher(pattern: string): (origin: string) => boolean {
  if (!pattern.includes("*")) return (origin) => origin === pattern;
  const source = pattern
    .split("*")
    .map((part) => part.replace(/[.*+?^${}()|[\]\\/]/g, "\\$&"))
    .join("[a-z0-9-]+");
  const re = new RegExp(`^${source}$`);
  return (origin) => re.test(origin);
}

export function createCors({ allow, credentials = false, maxAge = 600 }: { allow: string[]; credentials?: boolean; maxAge?: number }) {
  const matchers = allow.map(matcher);
  return (req: Request, res: Response, next: NextFunction) => {
    const origin = req.get("origin");
    if (origin === undefined) return next();
    res.vary("Origin");
    const ok = matchers.some((m) => m(origin));
    const isPreflight = req.method === "OPTIONS" && req.get("access-control-request-method") !== undefined;

    if (!ok) {
      if (isPreflight) {
        res.status(403).json({ error: { code: "CORS_ORIGIN_NOT_ALLOWED", message: `origin לא מורשה: ${origin}` } });
        return;
      }
      return next();
    }

    res.set("Access-Control-Allow-Origin", origin);
    if (credentials) res.set("Access-Control-Allow-Credentials", "true");
    if (isPreflight) {
      res.set({
        "Access-Control-Allow-Methods": "GET,POST,PUT,PATCH,DELETE",
        "Access-Control-Allow-Headers": req.get("access-control-request-headers") ?? "Content-Type",
        "Access-Control-Max-Age": String(maxAge),
      });
      res.sendStatus(204);
      return;
    }
    next();
  };
}

למה לא * עם credentials? הדפדפן עצמו אוסר את השילוב — ובצדק: "כל אתר רשאי לקרוא, כולל עם העוגיות של המשתמש" זה בדיוק מה שה־Same-Origin Policy נועד למנוע. ותבניות preview (Vercel, Netlify) הן המקרה הנפוץ ביותר ל־wildcard — וגם המקום שבו regex רשלני (בלי ^...$, בלי קידוד נקודות) פותח פרצה.

⚠️ טעויות נפוצות
  • origin.endsWith(".preview.example.com") — מתיר גם http:// וגם תת־דומיינים מקוננים. ו־includes גרוע עוד יותר: https://preview.example.com.evil.io.
