4. טפסים

playground/form.html 
<form id="new-task">
  <label for="title">כותרת</label>
  <input id="title" name="title" required maxlength="120">

  <label for="priority">עדיפות</label>
  <select id="priority" name="priority">
    <option value="low">נמוכה</option>
    <option value="medium" selected>בינונית</option>
    <option value="high">גבוהה</option>
  </select>

  <label for="dueDate">תאריך יעד</label>
  <input id="dueDate" name="dueDate" type="date">

  <label for="notes">הערות</label>
  <textarea id="notes" name="notes" rows="3"></textarea>

  <button type="submit">הוספה</button>
</form>
  • label for ↔ input id — מחברים תווית לשדה: לחיצה על התווית ממקדת את השדה, וקורא מסך מקריא אותה.
  • name — השם שבו הערך יישלח (או ייקרא ב־JavaScript). בלי name — השדה לא נכלל.
  • type — text (ברירת מחדל), email, number, date, password, checkbox... הדפדפן נותן מקלדת ובוחר מתאימים.
  • required, maxlength, min — בדיקה בדפדפן, לפני שליחה. נוח למשתמש — אבל לא תחליף לבדיקה בשרת: כל אחד יכול לשלוח בקשה עם curl ולעקוף אותה.
