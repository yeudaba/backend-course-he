טבלה

<table>
  <caption>הזמנות אחרונות</caption>
  <thead>
    <tr><th>מספר</th><th>לקוח</th><th>סכום</th></tr>
  </thead>
  <tbody>
    <tr><td>1001</td><td>דנה</td><td>₪120.00</td></tr>
    <tr><td>1002</td><td>עומר</td><td>₪45.50</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="2">סה״כ</td><td>₪165.50</td></tr>
  </tfoot>
</table>

table — הטבלה. caption — כותרת לטבלה. tr — שורה; בתוכה th (תא כותרת) או td (תא רגיל). thead / tbody / tfoot מחלקים לשורות כותרת, גוף וסיכום. colspan="2" — התא תופס שתי עמודות. טבלה — רק לנתונים טבלאיים, לא כדי לסדר את הדף (בשביל זה יש CSS, שיעור 2).

ועוד שני מאפיינים שמופיעים על כל תגית: id (שם ייחודי בדף — id="tasks") ו־class (קבוצה לעיצוב, אפשר כמה — class="card done"). שניהם ישמשו את ה־CSS וה־JavaScript.

4. טפסים

playground/form.html 
<form id="new-task">
  <label for="title">כותרת</label>
  <input id="title" name="title" required maxlength="120">

  <label for="priority">עדיפות</label>
  <select id="priority" name="priority">
    <option value="low">נמוכה</option>
    <option value="medium" selected>בינונית</option>
    <option value="high">גבוהה</option>
  </select>

  <label for="dueDate">תאריך יעד</label>
  <input id="dueDate" name="dueDate" type="date">

  <label for="notes">הערות</label>
  <textarea id="notes" name="notes" rows="3"></textarea>

  <button type="submit">הוספה</button>
</form>
  • label for ↔ input id — מחברים תווית לשדה: לחיצה על התווית ממקדת את השדה, וקורא מסך מקריא אותה.
  • name — השם שבו הערך יישלח (או ייקרא ב־JavaScript). בלי name — השדה לא נכלל.
  • type — text (ברירת מחדל), email, number, date, password, checkbox... הדפדפן נותן מקלדת ובוחר מתאימים.
  • required, minlength, maxlength, min — בדיקה בדפדפן, לפני שליחה. נוח למשתמש — אבל לא תחליף לבדיקה בשרת: כל אחד יכול לשלוח בקשה עם curl ולעקוף אותה.
  • autocomplete — רמז לדפדפן מה להשלים: autocomplete="email", ‏"username", ‏"current-password" (סיסמה קיימת) או "new-password" (הרשמה). ‏autocomplete="off" — בלי השלמה.

לאן הטופס נשלח: action ו־method

<form action="/search" method="get">
  <label for="q">חיפוש</label>
  <input id="q" name="q" type="search">
  <button type="submit">חפש</button>
</form>

בלי JavaScript, הדפדפן שולח את הטופס בעצמו: action — לאיזו כתובת (בלי action — לכתובת של הדף עצמו), ו־method — get (ברירת מחדל) או post. ב־get השדות הופכים ל־query: הקלדת "קפה שחור" ← /search?q=%D7%A7%D7%A4%D7%94+%D7%A9%D7%97%D7%95%D7%A8 — אותו קידוד כמו ב־URLSearchParams (פרק 14). ב־post הם נשלחים בגוף, בפורמט של טופס ולא JSON. ‏type="search" הוא שדה טקסט שהדפדפן מציג כשדה חיפוש (עם כפתור ניקוי). בשיעור 3 נעצור את השליחה האוטומטית (preventDefault) ונשלח בעצמנו עם fetch.

5. תווים מיוחדים: < ו־&

< פותח תגית, ו־& פותח "ישות" (entity). כדי שיופיעו בדף כטקסט, כותבים אותם בקוד:

תוכותבים ב־HTMLמתי חובה
&&amp;תמיד (וקודם לכול — ראה למטה)
<&lt;בטקסט
>&gt;בטקסט (ליתר ביטחון)
"&quot;בתוך ערך של תכונה במירכאות כפולות
'&#39;בתוך ערך של תכונה במירכאות בודדות

<p>Tom &amp; Jerry: 1 &lt; 2</p> מוצג כ־"Tom & Jerry: 1 < 2". כשבונים HTML ממחרוזות בקוד (שרת שמחזיר דף, תבנית מייל) — כל ערך שמגיע מבחוץ מקודד כך לפני שמכניסים אותו, אחרת שם מוצר כמו <script>… הופך לקוד שרץ אצל כל מי שפותח את הדף. בקוד: replaceAll (פרק 2) לכל אחד מחמשת התווים — ו־& ראשון, אחרת &lt; שכבר יצרת הופך ל־&amp;lt;. (בשיעור 3 תראה את הדרך הבטוחה בדפדפן: textContent.)
