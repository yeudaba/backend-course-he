P15.5-E01 · מה לא תקין בדף? 🧠 הבנה רמה 1

💡 רמז 1

חסרים שלושה דברים בראש הקובץ.

💡 רמז 2

לכל שדה: label מחובר, name, type מתאים.

✅ פתרון
  1. אין <!doctype html> — מצב תאימות ישן.
  2. אין lang="he" dir="rtl" — הכיוון שגוי, וקורא מסך לא יודע שזו עברית.
  3. אין <meta charset="utf-8"> — העברית עלולה להופיע כג'יבריש.
  4. שדה האימייל: בלי label, בלי name (הערך לא יישלח!), ו־type="text" במקום email (אין בדיקת פורמט ומקלדת מתאימה בטלפון).
  5. <label>שם</label> בלי for="name" — לא מחובר לשדה.
  6. <img> בלי alt.

(ובונוס: <button> בתוך form הוא type="submit" כברירת מחדל — כאן זה מה שרוצים, אבל כפתור "ביטול" באותו טופס צריך type="button", אחרת גם הוא ישלח.)

⚠️ טעויות נפוצות
  • לחשוב שזה "רק קוסמטיקה" — שדה בלי name פשוט לא נשלח, וזה באג אמיתי.

P15.5-E16 · איזו תגית? 🧠 הבנה רמה 1

💡 רמז 1

שאל: מה המשמעות של התוכן — כותרת, רשימה, קוד, הדגשה? לכל משמעות יש תגית.

💡 רמז 2

בין ul ל־ol — האם הסדר חשוב?

✅ פתרון
  1. <h1> (בתוך <header>).
  2. <ol> + <li> — הדפדפן ממספר לבד.
  3. <ul> + <li>.
  4. <img src="logo.svg" alt="שם החברה"> — ה־alt הוא מה שקורא מסך יקריא.
  5. <code>.
  6. <strong>.
  7. <main>.
  8. <button>.

עם div לכולם הדף ייראה אותו דבר אחרי CSS, אבל קורא מסך לא יודע שזו רשימה של 3 שלבים, מנוע חיפוש לא יודע מה הכותרת, ו־div שמתחזה לכפתור לא מגיב ל־Enter במקלדת. המשמעות היא חלק מהממשק.

⚠️ טעויות נפוצות
  • לבחור תגית לפי איך שהיא נראית (h3 "כי הוא בגודל הנכון") — את הגודל קובע CSS.

P15.5-E17 · אילו שדות יישלחו? 🧠 הבנה רמה 2

💡 רמז 1

for של התווית חייב להיות שווה ל־id של השדה. ומה שנשלח הוא לפי name.

💡 רמז 2

option בלי value — מה נשלח? ו־checkbox שלא סומן — האם נשלח בכלל?

✅ פתרון
  1. אימייל — נשלח (יש name), אבל התווית לא מחוברת: for="email" ו־id="mail". לחיצה על "אימייל" לא תמקד את השדה, וקורא מסך לא יקריא אותה.
  2. טלפון — לא נשלח בכלל: אין name.
  3. עיר — נשלח. אם נבחרה "תל אביב", הערך הוא הטקסט "תל אביב" (אין value); אם "חיפה" — "hfa".
  4. תנאים — נשלח terms=on רק אם סומן. לא סומן ← השדה לא קיים בבקשה (לא false). בשרת: terms === "on".
⚠️ טעויות נפוצות
  • לבדוק בשרת body.terms === false — הוא אף פעם לא יגיע כ־false; הוא פשוט חסר.

P15.5-E18 · מה שייך ל־head? 🧠 הבנה רמה 1

💡 רמז 1

head — מידע על הדף. body — מה שמוצג.

💡 רמז 2

את הסקריפט שמים בסוף ה־body (שיעור 3) — למה דווקא שם?

✅ פתרון
  1. head. בלעדיו העברית עלולה להופיע כג'יבריש (הדפדפן מנחש קידוד).
  2. head. מוצג בלשונית, בהיסטוריה ובתוצאות חיפוש. בלעדיו — הלשונית מציגה את שם הקובץ.
  3. body. הכותרת שבתוך הדף.
  4. head. בלעדיו, בטלפון הדף מוצג כאילו הוא ברוחב מחשב — זעיר.
  5. head. בלעדיו — אין עיצוב.
  6. סוף ה־body (שיעור 3) — כך כשהקוד רץ, האלמנטים כבר קיימים ו־querySelector מוצא אותם.

title הוא שם הדף מחוץ לדף (לשונית, סימניה, גוגל); h1 הוא הכותרת בתוכו. לרוב דומים, לא תמיד: "המשימות שלי · TaskApp" מול "המשימות שלי".

⚠️ טעויות נפוצות
  • לשים את <h1> ב־head — הוא לא יוצג כמו שצריך (הדפדפן "מתקן" ומעביר אותו, אבל זה כבר לא הדף שכתבת).

P15.5-E19 · תגיות שנסגרו לא נכון 🧠 הבנה רמה 2

💡 רמז 1

תגיות נסגרות בסדר הפוך לפתיחה — כמו סוגריים בקוד.

💡 רמז 2

בתוך ul מותר רק li. ו־img בלי מה?

✅ פתרון
  1. סדר סגירה: em נפתח אחרון, ולכן נסגר ראשון — <strong>חשוב <em>מאוד</em></strong>. הדפדפן יבנה עץ אחר ממה שהתכוונת (ב־Elements תראה em כפול).
  2. p ישירות בתוך ul — לא תקין. הכותרת צריכה להיות לפני הרשימה.
  3. חסר alt. התמונה תוצג, אבל קורא מסך יקריא "logo.png" (או כלום), וכשהתמונה לא נטענת — לא יופיע כלום.
  4. <a> לא נסגר — כל מה שאחריו (עד סוף הבלוק) הופך לחלק מהקישור.

הלקח: "זה נראה בסדר" לא אומר שהעץ נכון. ב־DevTools ← Elements רואים את העץ אחרי התיקון של הדפדפן — ושם הבאגים נראים. כשבשיעור 3 תכתוב querySelector("ul li"), הקוד עובד מול העץ הזה.

⚠️ טעויות נפוצות
  • להסתמך על התצוגה בלבד. בדיקה אוטומטית (כמו ב־P15.5-E21) עובדת על העץ, לא על הצבעים.

P15.5-E20 · בדיקה בדפדפן מול בדיקה בשרת 🧠 הבנה רמה 1

💡 רמז 1

"כל אחד יכול לשלוח בקשה עם curl ולעקוף אותה" — מהשיעור.

💡 רמז 2

הבדיקה בדפדפן היא נוחות למשתמש — הודעה מיידית, בלי לחכות לשרת.

✅ פתרון
  1. הדפדפן לא שולח, ומציג הודעה ליד השדה ("הערך חייב להיות 18 או יותר").
  2. הבקשה מגיעה לשרת כמו שהיא — בלי אימייל ועם גיל 15. ה־HTML לא קיים בכלל בתמונה.

⚠️ טעויות נפוצות
  • להוריד את הבדיקה מהשרת "כי ה־HTML כבר בודק".

P15.5-E13 · טבלת HTML מנתונים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שלוש פונקציות קטנות: escapeHtml(value), ‏renderCell(column, row), ‏renderTable. כל חלק של הטבלה הוא map ואחריו join("").

💡 רמז 2

rows.map((row) => &lt;tr&gt;${columns.map((c) =&gt; renderCell(c, row)).join("")}&lt;/tr&gt;).join("") — map בתוך map: שורות בחוץ, עמודות בפנים.

✅ פתרון
// P15.5-E13: טבלת HTML מנתונים
const ENTITIES = { "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" };
const escapeHtml = (value) => String(value).replace(/[&<>"']/g, (ch) => ENTITIES[ch]);

function renderCell(column, row) {
  const value = row[column.key];
  const text = value === null || value === undefined ? "—" : escapeHtml(value);
  return column.numeric ? `<td class="num">${text}</td>` : `<td>${text}</td>`;
}

export function renderTable(columns, rows) {
  if (rows.length === 0) {
    return '<p class="empty">אין נתונים להצגה</p>';
  }
  const head = columns.map((c) => `<th>${escapeHtml(c.label)}</th>`).join("");
  const body = rows.map((row) => `<tr>${columns.map((c) => renderCell(c, row)).join("")}</tr>`).join("");
  return `<table><thead><tr>${head}</tr></thead><tbody>${body}</tbody></table>`;
}

const columns = [
  { key: "name", label: "מוצר" },
  { key: "price", label: "מחיר", numeric: true },
];
console.log(renderTable(columns, [{ name: "כוס <קרמיקה>", price: 19.9 }, { name: "עט" }]));
console.log(renderTable(columns, []));
<table><thead><tr><th>מוצר</th><th>מחיר</th></tr></thead><tbody><tr><td>כוס &lt;קרמיקה&gt;</td><td class="num">19.9</td></tr><tr><td>עט</td><td class="num">—</td></tr></tbody></table>
<p class="empty">אין נתונים להצגה</p>

הטבלה בנויה כמו הנתונים: map על השורות, ובתוך כל שורה map על העמודות. ה־join("") חשוב: בלעדיו מערך הופך למחרוזת עם פסיקים, ובדף מופיעים פסיקים בין התאים.

renderCell מטפלת בשלושה דברים: ערך חסר, קידוד, ו־class למספרים. כשהלוגיקה של תא אחד נמצאת בפונקציה משלה, הטבלה עצמה נשארת שורה קריאה אחת.

למה לבדוק null ו־undefined במפורש ולא value || "—"? כי מחיר 0 או מלאי 0 הם ערכים אמיתיים. עם || הם היו הופכים ל־—.

⚠️ טעויות נפוצות
  • לשכוח join("") — בין התאים מופיעים פסיקים.
  • value || "—" — ‏0 נעלם מהטבלה.
  • לקודד רק את התאים ולא את הכותרות. גם כותרת יכולה להגיע מהמשתמש (למשל שם של שדה מותאם אישית).
  • לעבור על Object.keys(row) במקום על columns — הסדר משתנה משורה לשורה, ושדות שלא ביקשו (כמו passwordHash) מופיעים בדף.

P15.5-E21 · שלד של דף 🤖 💻 כתיבת קוד 🤖 רמה 1

💡 רמז 1

הסדר: doctype ← html ← head (מידע) ← body (תוכן).

💡 רמז 2

קישור למייל: <a href="mailto:me@example.com">כתבו לי</a> — לחיצה פותחת את תוכנת המייל.

<!doctype html>

שישה דברים שכמעט כל דף צריך — ולכן כדאי שהיד תכתוב אותם בלי לחשוב. (ב־VS Code אפשר לכתוב ! ו־Tab ולקבל שלד מוכן — אבל אז בדוק ש־lang ו־dir נכונים: ברירת המחדל היא en.)

⚠️ טעויות נפוצות
  • לשכוח את dir="rtl" — הטקסט העברי מיושר לשמאל, וסימני פיסוק "קופצים" לצד הלא נכון.

P15.5-E22 · דף מתכון 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

💡 רמז 2

footer הוא אח של main, לא בתוכו: <body><main>...</main><footer>...</footer></body>.

שים לב ל־alt: הוא מתאר את התמונה ("מחבת עם ביצים") — לא "תמונה" ולא שם הקובץ. אם התמונה לא נטענת, או שהמשתמש לא רואה, זה מה שיקבל.

⚠️ טעויות נפוצות
  • alt="" — מותר רק לתמונה קישוטית בלבד. תמונה של המנה היא תוכן.

P15.5-E23 · טופס כניסה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

לכל שדה זוג: <label for="x">...</label> ו־<input id="x" ...>.

💡 רמז 2

צ'קבוקס: <input id="remember" name="remember" type="checkbox"> — בדרך כלל התווית באה אחריו.

✅ פתרון
<form id="login">
  <label for="email">אימייל</label>
  <input id="email" name="email" type="email" required autocomplete="email">

  <label for="password">סיסמה</label>
  <input id="password" name="password" type="password" required minlength="8">

  <input id="remember" name="remember" type="checkbox">
  <label for="remember">זכור אותי</label>

  <button type="submit">כניסה</button>
</form>

type="password" מסתיר את התווים, ו־autocomplete="email" נותן למנהל הסיסמאות לזהות את השדה. ה־minlength הוא נוחות — את אורך הסיסמה בודקים שוב בשרת (P15.5-E20, ופרק 21).

⚠️ טעויות נפוצות
  • להשתמש ב־placeholder במקום label — הטקסט נעלם כשמתחילים להקליד, וקוראי מסך לא תמיד מקריאים אותו.

const esc = (s) => String(s).replaceAll("&", "&amp;").replaceAll("<", "&lt;").replaceAll(">", "&gt;").replaceAll('"', "&quot;").replaceAll("'", "&#39;");

export function renderOptions(options, selected, placeholder) {
  const isSel = (v) => selected !== undefined && selected !== null && String(v) === String(selected);
  const option = (value, label, sel) => `<option value="${esc(value)}"${sel ? " selected" : ""}>${esc(label)}</option>`;
  const items = options.map((o) => option(o.value, o.label, isSel(o.value)));
  if (placeholder !== undefined) items.unshift(option("", placeholder, !options.some((o) => isSel(o.value))));
  return items.join("");
}

P15.5-E31 · בודק תוויות לטופס 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

תגיות: /<(\w+)([^>]*)>/g. מאפיינים מתוך החלק השני: /([\w-]+)(?:\s*=\s*("[^"]*"|'[^']*'|[^\s>]+))?/g, ואחר כך מסירים מירכאות.

💡 רמז 2

✅ פתרון
// P15.5-E31: בודק תוויות לטופס
function tags(html) {
  return [...html.matchAll(/<(\w+)([^>]*)>/g)].map((m) => {
    const attrs = {};
    for (const a of m[2].matchAll(/([\w-]+)(?:\s*=\s*("[^"]*"|'[^']*'|[^\s>]+))?/g)) {
      attrs[a[1].toLowerCase()] = (a[2] ?? "").replace(/^["']|["']$/g, "");
    }
    return { tag: m[1].toLowerCase(), attrs };
  });
}

export function checkForm(html) {
  const list = tags(html);
  const problems = [];
  const counts = new Map();
  for (const t of list) if (t.attrs.id) counts.set(t.attrs.id, (counts.get(t.attrs.id) ?? 0) + 1);
  for (const [id, n] of counts) if (n > 1) problems.push(`id כפול: ${id}`);

  const labelsFor = new Set(list.filter((t) => t.tag === "label" && t.attrs.for).map((t) => t.attrs.for));
  for (const t of list) {
    if (!["input", "select", "textarea"].includes(t.tag)) continue;
    if (["submit", "hidden", "button"].includes((t.attrs.type ?? "").toLowerCase())) continue;
    if (!t.attrs.name) problems.push(`שדה בלי name: ${t.attrs.id || "?"}`);
    if (!t.attrs.id || !labelsFor.has(t.attrs.id)) problems.push(`שדה בלי label: ${t.attrs.name || "?"}`);
  }
  for (const t of list) {
    if (t.tag === "label" && t.attrs.for && !counts.has(t.attrs.for)) problems.push(`label יתום: ${t.attrs.for}`);
  }
  return problems;
}

✅ פתרון
// P15.5-E32: HTML או JSON מאותו route
import express from "express";

const esc = (s) => String(s).replaceAll("&", "&amp;").replaceAll("<", "&lt;").replaceAll(">", "&gt;").replaceAll('"', "&quot;").replaceAll("'", "&#39;");

export function createApp(products) {
  const app = express();
  app.get("/products", (req, res) => {
    if (!(req.get("accept") ?? "").includes("text/html")) {
      res.json(products);
      return;
    }
    const list = products.length
      ? `<ul>${products.map((p) => `<li>${esc(p.name)} — ₪${p.price.toFixed(2)}</li>`).join("")}</ul>`
      : "<p>אין מוצרים</p>";
    res.type("html").send(`<!doctype html>
<html lang="he" dir="rtl">
<head><meta charset="utf-8"><title>מוצרים</title></head>
<body><h1>מוצרים</h1>${list}</body>
</html>`);
  });
  return app;
}
