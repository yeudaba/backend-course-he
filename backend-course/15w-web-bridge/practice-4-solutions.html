P15.5-E62 · למה cors() ראשון? 🧠 הבנה רמה 2

💡 רמז 1

preflight הוא בקשת OPTIONS שהדפדפן שולח בלי ה־headers שלך — גם בלי x-api-key.

💡 רמז 2

middleware שעונה (401) עוצר את השרשרת — מה שאחריו לא רץ.

✅ פתרון
import express from "express";
import cors from "cors";

const requireKey = (req, res, next) => (req.get("x-api-key") === "secret" ? next() : res.status(401).json({ error: "חסר מפתח" }));

function build(corsFirst) {
  const app = express();
  if (corsFirst) app.use(cors({ origin: ["http://localhost:5500"] }));
  app.use(requireKey);
  if (!corsFirst) app.use(cors({ origin: ["http://localhost:5500"] }));
  app.post("/tasks", (req, res) => res.status(201).json({ id: 1 }));
  return app;
}

for (const corsFirst of [false, true]) {
  const server = build(corsFirst).listen(0);
  await new Promise((r) => server.once("listening", r));
  const res = await fetch(`http://localhost:${server.address().port}/tasks`, {
    method: "OPTIONS",
    headers: { Origin: "http://localhost:5500", "Access-Control-Request-Method": "POST", "Access-Control-Request-Headers": "content-type,x-api-key" },
  });
  console.log(corsFirst ? "cors ראשון:" : "cors אחרי המפתח:", res.status, res.headers.get("access-control-allow-origin"));
  server.close();
}
cors אחרי המפתח: 401 null
cors ראשון: 204 http://localhost:5500

כש־cors אחרי בדיקת המפתח, ה־preflight נעצר ב־401 בלי header — והדפדפן מדווח "CORS error", למרות שהבעיה היא סדר. כש־cors ראשון, הוא עונה ל־OPTIONS בעצמו (204) ולא ממשיך הלאה; הבקשה האמיתית תגיע אחר כך — עם המפתח — ותעבור את requireKey.

⚠️ טעויות נפוצות
  • "לתקן" את שגיאת ה־CORS עם origin: "*" — הבעיה נשארת (401), ועכשיו גם כל אתר יכול לקרוא.

P15.5-E67 · איך הדף מתעדכן אחרי פעולה? 🧠 הבנה רמה 1

💡 רמז 1

חשוב על: מספר בקשות, מה קורה עם סינון/מיון/pagination, ומה המשתמש מרגיש ברשת איטית.

💡 רמז 2

אם השרת משנה משהו בעצמו (id, ‏createdAt, trim לכותרת) — מי יודע את הערך הנכון?

✅ פתרון
  1. טעינה מחדש — הכי פשוט ותמיד נכון (מה שבשרת = מה שעל המסך, כולל סינון ומיון). חיסרון: עוד בקשה, והרשימה "מהבהבת".
  2. עדכון מקומי — מהיר, בקשה אחת. חיסרון: צריך לחקות בדף את חוקי השרת — איפה המשימה נכנסת לפי המיון? האם היא בכלל עומדת בסינון?

(א) אופטימי — פעולה קטנה, כמעט תמיד מצליחה. (ב) טעינה מחדש — הסינון והמיון בשרת. (ג) עדכון מקומי (מוחקים את ה־li אחרי 204), או טעינה מחדש אם יש pagination (עמוד "מתמלא" מהעמוד הבא). בפרויקט: מתחילים עם טעינה מחדש, ומשפרים רק איפה שמרגישים איטיות.

⚠️ טעויות נפוצות

// P15.5-E68: כתובת לרשימה המסוננת
export function tasksPath({ status, q, page } = {}) {
  const params = new URLSearchParams();
  if (status && status !== "all") params.set("status", status);
  if (q && q.trim()) params.set("q", q.trim());
  if (page > 1) params.set("page", String(page));
  return `/tasks${params.size ? "?" + params : ""}`;
}

// P15.5-E69: שורת משימה עם אירועים
export function renderTask(doc, task, { onToggle, onDelete }) {
  const el = (tag, cls, text) => {
    const e = doc.createElement(tag);
    if (cls) e.className = cls;
    if (text !== undefined) e.textContent = text;
    return e;
  };
  const done = task.status === "done";
  const li = el("li", done ? "row done" : "row");
  li.dataset.id = task.id;

  const box = el("input");
  box.type = "checkbox";
  box.checked = done;
  box.addEventListener("change", () => onToggle(task.id, box.checked));

  let due = "בלי תאריך";
  if (task.dueDate) {
    const [y, m, d] = task.dueDate.split("-");
    due = `${d}.${m}.${y}`;
  }

  const del = el("button", "danger", "מחיקה");
  del.addEventListener("click", () => onDelete(task.id));

  li.append(box, el("span", "title", task.title), el("span", "meta", `${task.priority} · ${due}`), del);
  return li;
}

export function formatDue(dueDate, today) {
  if (dueDate === null || dueDate === undefined) return "בלי תאריך";
  const n = day(dueDate) - day(today);

export function showError(doc, box, error) {
  const p = doc.createElement("p");
  p.textContent = error.message;
  const parts = [p];
  if (error.details?.length) {
    const ul = doc.createElement("ul");
    for (const d of error.details) {
      const li = doc.createElement("li");
      li.textContent = `${d.path}: ${d.message}`;
      ul.append(li);
    }
    parts.push(ul);
  }
  box.replaceChildren(...parts);
  box.hidden = false;
}

export function clearError(box) {
  box.replaceChildren();
  box.hidden = true;
}

// P15.5-E72: לפרק CORS_ORIGINS
function isOrigin(x) {
  try {
    const u = new URL(x);
    return /^https?:$/.test(u.protocol) && u.pathname === "/" && !u.search && !u.hash && !x.endsWith("?") && !x.endsWith("#");
  } catch {
    return false;
  }
}

export function parseCorsOrigins(value, fallback = ["http://localhost:5500"]) {
  if (value === undefined || value.trim() === "") return [...fallback];
  if (value.trim() === "*") throw new Error("CORS_ORIGINS=* אסור — כתוב רשימה מפורשת");
  const items = value.split(",").map((s) => s.trim()).filter(Boolean);
  const bad = items.filter((x) => !isOrigin(x));
  if (bad.length) throw new Error(`CORS_ORIGINS לא תקין: ${bad.join(", ")}`);
  return [...new Set(items.map((x) => new URL(x).origin))];
}

    parseCorsOrigins(v);
  } catch (err) {
    console.log(err.message);
  }
}

export function latestOnly(fn) {
  let latest = 0;
  return async (...args) => {
    const my = ++latest;
    try {
      const value = await fn(...args);
      return my === latest ? { stale: false, value } : { stale: true };

    }
  };

// P15.5-E12
import type { Request, Response, NextFunction } from "express";

function matcher(pattern: string): (origin: string) => boolean {
  if (!pattern.includes("*")) return (origin) => origin === pattern;
  const source = pattern
    .split("*")
    .map((part) => part.replace(/[.*+?^${}()|[\]\\/]/g, "\\$&"))
    .join("[a-z0-9-]+");
  const re = new RegExp(`^${source}$`);
  return (origin) => re.test(origin);
}

export function createCors({ allow, credentials = false, maxAge = 600 }: { allow: string[]; credentials?: boolean; maxAge?: number }) {
  const matchers = allow.map(matcher);
  return (req: Request, res: Response, next: NextFunction) => {
    const origin = req.get("origin");
    if (origin === undefined) return next();
    res.vary("Origin");
    const ok = matchers.some((m) => m(origin));
    const isPreflight = req.method === "OPTIONS" && req.get("access-control-request-method") !== undefined;

    if (!ok) {
      if (isPreflight) {
        res.status(403).json({ error: { code: "CORS_ORIGIN_NOT_ALLOWED", message: `origin לא מורשה: ${origin}` } });
        return;
      }
      return next();
    }

    res.set("Access-Control-Allow-Origin", origin);
    if (credentials) res.set("Access-Control-Allow-Credentials", "true");
    if (isPreflight) {
      res.set({
        "Access-Control-Allow-Methods": "GET,POST,PUT,PATCH,DELETE",
        "Access-Control-Allow-Headers": req.get("access-control-request-headers") ?? "Content-Type",
        "Access-Control-Max-Age": String(maxAge),
      });
      res.sendStatus(204);
      return;
    }
    next();
  };
}

למה לא * עם credentials? הדפדפן עצמו אוסר את השילוב — ובצדק: "כל אתר רשאי לקרוא, כולל עם העוגיות של המשתמש" זה בדיוק מה שה־Same-Origin Policy נועד למנוע. ותבניות preview (Vercel, Netlify) הן המקרה הנפוץ ביותר ל־wildcard — וגם המקום שבו regex רשלני (בלי ^...$, בלי קידוד נקודות) פותח פרצה.

⚠️ טעויות נפוצות

function compare(a, b) {

export function groupByPriority(tasks) {
  const groups = new Map(ORDER.map((p) => [p, []]));
  for (const t of tasks) groups.get(ORDER.includes(t.priority) && t.priority !== "other" ? t.priority : "other").push(t);

  return groups;
}
