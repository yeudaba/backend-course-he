שיעור 4 — דף הדגמה לפרויקט 2

⏱ ~45 דקות · 🤖 PR2-WEB

🎯 בשיעור הזה

פרויקט 2 מקבל דף הדגמה: רשימת משימות עם סינון, טופס הוספה, סימון "בוצע" ומחיקה — ו־CORS בשרת. בסוף: npm run check PR2-WEB -- --dir ~/dev/tasks-api עובר, והדף עובד מול השרת שלך.

1. CORS בשרת

% cd ~/dev/tasks-api
% npm install cors
% npm install -D @types/cors
  1. ב־AppOptions הוסף corsOrigins?: string[], עם ברירת מחדל ["http://localhost:5500"].
  2. ב־createApp, ראשון: app.use(cors({ origin: corsOrigins })). (לפני express.json ולפני ה־routes — preflight צריך תשובה גם אם הוא היה נופל בהמשך.)
  3. ב־server.ts: corsOrigins: process.env.CORS_ORIGINS?.split(",") — בייצור (פרק 25) תגדיר את הדומיין האמיתי בלי לשנות קוד.
  4. npm run check PR2-WEB -- --dir ~/dev/tasks-api (מתיקיית הקורס).

2. שרת לדף

הדף צריך לרוץ מ־origin משלו (כמו אתר אמיתי, שה־Frontend וה־API שלו בכתובות נפרדות). העתק את 15w-web-bridge/files/serve-web.mjs אל ~/dev/tasks-api/scripts/serve-web.mjs, והוסף ל־package.json:

"scripts": {
  "dev": "node --watch src/server.ts",
  "start": "node src/server.ts",
  "web": "node scripts/serve-web.mjs",
  "typecheck": "tsc --noEmit"
}

הסקריפט מגיש את התיקייה web/ בפורט 5500. (קרא אותו — 25 שורות, ובהן ההגנה מ־../ של פרק 13.)

3. הדף

צור web/index.html, web/style.css ו־web/app.js. דרישות:

  • טופס: כותרת (חובה), עדיפות (select), תאריך יעד (date, לא חובה). שליחה ← POST, ניקוי הטופס, רענון הרשימה.
  • רשימה: כל משימה בשורה — צ'קבוקס "בוצע" (PATCH status), כותרת, עדיפות ותאריך, כפתור מחיקה (DELETE).
  • סינון לפי סטטוס (select) ← טעינה מחדש עם ?status=....
  • "טוען..." בזמן בקשה; "אין משימות" כשהרשימה ריקה.
  • שגיאה מה־API (למשל כותרת של 200 תווים) — מוצגת בתיבה, כולל ה־details.
  • שום innerHTML עם נתונים מהשרת.

<input type="date"> ריק נותן "", וה־API מצפה ל־null או "YYYY-MM-DD". fields.get("dueDate") || null. (זו בדיוק הפונקציה של תרגיל E07.)

4. להריץ

% npm run dev
% npm run web
הדף זמין ב־http://localhost:5500

(שני חלונות Terminal.) פתח http://localhost:5500 ב־Chrome, עם DevTools ← Network. הוסף משימה: תראה OPTIONS /tasks ואחריה POST /tasks. נסה גם: עצור את ה־API (Ctrl+C) ורענן — הדף צריך להציג שגיאה, לא להיתקע. ונסה ליצור משימה בשם <b>בדיקה</b> — היא צריכה להופיע עם התגיות כטקסט.

כשהכול עובד: commit ("Add demo web page and CORS"), עדכן ב־README את "הפעלה" (npm run web) ואת "מה הלאה" — ו־push. אחר כך השווה ל־15p-project-tasks/solutions/tasks-api/web/.

💼 בעולם העבודה

"ה־Frontend אומר שיש שגיאת CORS" — תשמע את זה בשבוע הראשון בעבודה. עכשיו תדע: (1) לבקש את ה־origin המדויק מהקונסול; (2) לבדוק בצד השרת את רשימת ה־origins ואת סדר ה־middleware; (3) לבדוק ב־Network אם ה־preflight חזר עם ה־headers הנכונים. ולא "לשים * שיעבוד".
