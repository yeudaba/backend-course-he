P15.5-E44 · לחשב specificity 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

כתוב וייצא שתי פונקציות:

  • specificity(selector) ← מערך [ids, classes, tags]: ‏#x ← id; ‏.x, ‏[attr], ‏[attr=v] ו־:hover (כל מצב עם : אחד) ← class; שם תגית ← tag. ‏* לא נספר. רווחים בין חלקים (צאצא) לא משנים.
  • winner(element, rules) — ‏rules: מערך { selector, value } (כולם כבר "מתאימים" לאלמנט); מחזירה את ה־value של הכלל שמנצח: הגבוה ב־specificity (משווים ids, אחר כך classes, אחר כך tags); בשוויון — האחרון. (הפרמטר element לא בשימוש — הוא שם כדי שהחתימה תזכיר את מה שהדפדפן עושה.) רשימה ריקה ← undefined.
specificity("#main .card h2:hover"); // [1, 2, 1]
specificity("ul li.done");           // [0, 1, 2]

P15.5-E45 · למה ה־CSS לא נטען?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 14, שיעור 2

הדף http://localhost:5500/tasks/index.html כולל <link rel="stylesheet" href="style.css">, והעיצוב לא מופיע. ב־DevTools ← Network רואים אחד מהמקרים. לכל אחד — מה הבעיה ואיך מתקנים?

  1. הבקשה היא ל־/tasks/style.css ומחזירה 404. הקובץ נמצא ב־/style.css.
  2. 200, אבל ה־header הוא Content-Type: text/plain. בקונסול: "Refused to apply style ... because its MIME type ('text/plain') is not a supported stylesheet MIME type".
  3. 200 עם text/css, ובכל זאת שינוי שעשית בקובץ לא מופיע — עד שעושים ⌘⇧R.
  4. אין שום בקשה ל־CSS ב־Network.

🔗 איך זה מתחבר: כתובות יחסיות ו־URL מפרק 14 (שיעור 1), ‏Content-Type ו־Cache-Control (שיעור 2), ו־DevTools (שיעור 3). השיעור: <link rel="stylesheet">.

P15.5-E46 · צבע hex לשלושה מספרים

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 2, שיעור 2

צבע כמו #d8dbe0 הוא שלושה מספרים בבסיס 16 (אדום, ירוק, כחול), כל אחד 00–ff. מה יודפס?

const hex = "#d8dbe0";
console.log(hex.slice(1, 3), parseInt(hex.slice(1, 3), 16));
console.log(parseInt("ff", 16), parseInt("0a", 16), parseInt("zz", 16));
console.log((255).toString(16), (10).toString(16), (10).toString(16).padStart(2, "0"));
const short = "#fa0";
console.log([...short.slice(1)].map((c) => c + c).join(""));

🔗 איך זה מתחבר: slice, ‏padStart ופירוק מחרוזת לתווים מפרק 2, ‏parseInt עם בסיס מפרק 1. השיעור: צבעים ב־CSS. זה ההכנה ל־P15.5-E48.

P15.5-E47 · regex לצבע

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 13, שיעור 2

איזה מהצבעים יעבור כל אחד מה־regexים? מה יודפס?

const a = /#[0-9a-f]{3}/;
const b = /^#[0-9a-f]{3}$|^#[0-9a-f]{6}$/;
const c = /^#([0-9a-f]{3}){1,2}$/i;
for (const color of ["#fff", "#FFF", "#d8dbe0", "#d8db", "d8dbe0", "#fffz", "red"]) {
  console.log(color.padEnd(8), a.test(color), b.test(color), c.test(color));
}

P15.5-E48 · hex ל־rgb ובחזרה 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: פרק 2, שיעור 2

כתוב וייצא:

  • hexToRgb(hex) ← { r, g, b } (מספרים 0–255). מקבלת #rgb או #rrggbb, בלי תלות באותיות. אחרת ← throw new Error(צבע לא תקין: ${hex}).
  • rgbToHex({ r, g, b }) ← #rrggbb באותיות קטנות. כל ערך חייב להיות מספר שלם 0–255, אחרת ← throw new Error("ערך rgb לא תקין").

P15.5-E49 · יחס ניגודיות 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 1, שיעור 2

טקסט אפור בהיר על רקע לבן קשה לקריאה. תקן הנגישות (WCAG) מודד את זה ב"יחס ניגודיות" — 4.5 לפחות לטקסט רגיל. כתוב וייצא:

  • luminance(hex) — "בהירות יחסית" (0 עד 1): לכל רכיב c (0–255): ‏s = c / 255, ואז s <= 0.03928 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4. התוצאה: 0.2126 * R + 0.7152 * G + 0.0722 * B (על הערכים אחרי ההמרה).
  • contrast(hex1, hex2) ← (L1 + 0.05) / (L2 + 0.05), כש־L1 הבהיר מבין השניים — מעוגל ל־2 ספרות אחרי הנקודה (מספר, לא מחרוזת).
  • readable(fg, bg) ← true אם הניגודיות 4.5 לפחות.

אפשר להניח שהצבעים תקינים (#rrggbb או #rgb). כתוב את המרת ה־hex בקובץ הזה.

P15.5-E50 · לכווץ CSS 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 2, פרק 13, שיעור 2

לפני שמעלים לאתר, מכווצים את ה־CSS (minify) — פחות בתים להוריד. כתוב וייצא minifyCss(css):

  • מוחקת הערות /* ... */ (גם על כמה שורות).
  • כל רצף של רווחים, טאבים ושורות חדשות ← רווח אחד.
  • מוחקת רווחים לפני ואחרי {, ‏}, ‏:, ‏; ו־,.
  • מוחקת ; שמופיע ממש לפני }.
  • מוחקת רווחים בהתחלה ובסוף.

(הנח שאין מחרוזות במירכאות בקובץ. ‏:hover שבתוך selector נשאר — אין בו רווח ממילא.)

minifyCss(".card {\n  padding: 16px;\n  /* רקע */\n  background: white;\n}\n");
// ".card{padding:16px;background:white}"
