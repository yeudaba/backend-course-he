P15.5-E62 · למה cors() ראשון?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

בשלב 2 בשיעור כתוב: "ב־createApp, ראשון: app.use(cors(...))". בקוד כאן הוא נרשם אחרי middleware שדורש מפתח API. הקוד שולח preflight כמו דפדפן. מה יודפס בכל אחד משני השרתים?

import express from "express";
import cors from "cors";

const requireKey = (req, res, next) => (req.get("x-api-key") === "secret" ? next() : res.status(401).json({ error: "חסר מפתח" }));

function build(corsFirst) {
  const app = express();
  if (corsFirst) app.use(cors({ origin: ["http://localhost:5500"] }));
  app.use(requireKey);
  if (!corsFirst) app.use(cors({ origin: ["http://localhost:5500"] }));
  app.post("/tasks", (req, res) => res.status(201).json({ id: 1 }));
  return app;
}

for (const corsFirst of [false, true]) {
  const server = build(corsFirst).listen(0);
  await new Promise((r) => server.once("listening", r));
  const res = await fetch(`http://localhost:${server.address().port}/tasks`, {
    method: "OPTIONS",
    headers: { Origin: "http://localhost:5500", "Access-Control-Request-Method": "POST", "Access-Control-Request-Headers": "content-type,x-api-key" },
  });
  console.log(corsFirst ? "cors ראשון:" : "cors אחרי המפתח:", res.status, res.headers.get("access-control-allow-origin"));
  server.close();
}

P15.5-E66 · תשובה ישנה שדורסת חדשה

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: שיעור 4

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
const server = { open: [["חלב", 300]], done: [["לחם", 50]] };

async function loadTasks(status) {
  const [[title, ms]] = server[status];
  await sleep(ms);
  shown = `${status}: ${title}`;
  console.log("הוצג:", shown);
}

loadTasks("open");
await sleep(10);
loadTasks("done");
await sleep(400);
console.log("הסינון שנבחר: done · מה שעל המסך:", shown);

  • allow: origins מדויקים, וגם תבנית עם * לתת־דומיין אחד: "https://*.preview.example.com" מתיר את https://pr-42.preview.example.com, אבל לא את https://a.b.preview.example.com, לא את http://pr-42.preview.example.com, ולא את https://preview.example.com.evil.io. תת־דומיין: אותיות קטנות, ספרות ומקפים.
  • מורשה ← Access-Control-Allow-Origin: <origin> (לעולם לא *); עם credentials ← גם Access-Control-Allow-Credentials: true. תמיד Vary: Origin.
  • preflight (OPTIONS עם Access-Control-Request-Method) ממורשה ← 204 עם methods (GET,POST,PUT,PATCH,DELETE), headers (מה שביקשו), Access-Control-Max-Age. preflight מלא מורשה ← 403 { error: { code: "CORS_ORIGIN_NOT_ALLOWED", message } } — עדיף לדבג מ־204 ריק.
  • בלי Origin (curl, שרת) ← next() בלי שום header. בקשה רגילה מלא־מורשה ← next() בלי ACAO.

🔗 איך זה מתחבר: כל היחידה — preflight ו־origins (שיעור 3), ‏CORS_ORIGINS ו־cors ראשון (שיעור 4, P15.5-E62/E72) — יחד עם middleware של Express (פרק 15) ו־headers מפרק 14.
