יחידה 25.7 — MongoDB: מסד של מסמכים

⏱ 3 מפגשים

🧰 לפני שמתחילים — יחידה 25.7

מה צריך שכבר יהיה מותקן: Docker Desktop (פרק 23), ו־PostgreSQL מפרק 16 (לתרגיל E25).

מה מתקינים / מריצים עכשיו:

  • MongoDB 8 בקונטיינר, כ־replica set של שרת אחד — זה מה שמאפשר טרנזקציות (שיעור 5). פעם אחת: 
    docker run -d --name mongo -p 27017:27017 mongo:8 --replSet rs0
docker exec mongo mongosh --quiet --eval "rs.initiate()"
    אחר כך רק docker start mongo.
  • בדיקה: docker exec -it mongo mongosh --quiet --eval "db.version()" ← 8.x. ו־docker exec -it mongo mongosh פותח shell אינטראקטיבי (exit ליציאה).
  • ב־~/dev/backend-course/.env: COURSE_MONGO_URL=mongodb://localhost:27017/?directConnection=true. הבודקים יוצרים database זמני לכל בדיקה ומוחקים אותו בסוף.
  • npm install בתיקיית הקורס — מוסיף את mongodb, ה־driver הרשמי ל־Node.js.
  • נתוני הדוגמה (חנות הקפה, כמסמכים) ל־database בשם shop: node 25w-mongodb/files/load-seed.mjs.
  • תוסף VS Code (לא חובה): MongoDB for VS Code — לראות collections ולהריץ שאילתות מתוך העורך. או MongoDB Compass.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 25w-mongodb מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה: cd ~/dev/backend-course && npm install && npm run check P25.7-E06 ← הבודק מתחבר ל־MongoDB ונכשל על קובץ ההתחלה. ECONNREFUSED 127.0.0.1:27017 — הקונטיינר לא רץ. This MongoDB deployment does not support retryable writes — הקונטיינר רץ בלי --replSet rs0 או בלי rs.initiate().

🎯 בסוף הפרק תדע
  • להבין את מודל המסמכים: collection, מסמך, _id ו־ObjectId, BSON — ומה שונה מטבלה.
  • לשאול ולעדכן: אופרטורים, מערכים ומסמכים מקוננים, $set/$inc/$push/$addToSet, upsert — ועדכון אטומי עם תנאי.
  • לתכנן מבנה לפי דפוסי הגישה: embed מול reference, שכפול מכוון, ומתי מערך גדל לנצח.
  • aggregation pipeline ($match, $unwind, $group, $lookup, $facet) ואינדקסים (ESR, unique, TTL, explain).
  • MongoDB מ־Node.js: driver, ObjectId ב־API, collections עם טיפוסים, טרנזקציות — ומתי לבחור Mongo ומתי PostgreSQL.

🤔 למה צריך את זה?

בפרקים 16–19 וביחידה 25.5 עבדת עם מסדים רלציוניים: טבלאות, שורות, JOIN. הרבה צוותים בארץ — במיוחד עם Node.js — עובדים עם MongoDB: מסד של מסמכים, שבו הזמנה עם כל הפריטים שלה היא אובייקט JSON אחד, בלי טבלת order_items. ב־stack של Node הוא נפוץ במיוחד, ובמודעות הוא מופיע לצד PostgreSQL ו־MySQL.

היחידה לא מנסה לשכנע אותך ש־Mongo "טוב יותר" — אלא שתדע לעבוד איתו, להבין מתי הוא מתאים, ולענות בראיון על השאלה "Mongo או Postgres?" בלי סיסמאות. הכול על חנות הקפה המוכרת, כמסמכים, ומול MongoDB 8 אמיתי בקונטיינר.

🏁 מבחן מעבר

  • להסביר מה ההבדל בין מסמך לשורה, ולמה _id הוא בדרך כלל ObjectId.
  • לכתוב find עם אופרטורים על מערכים ושדות מקוננים, ועדכון אטומי עם תנאי (stock: { $gte: qty }).
  • להחליט embed או reference לפי דפוסי גישה — ולהסביר למה בהזמנה שומרים עותק של המחיר.
  • לכתוב aggregation עם $unwind, $group ו־$lookup, ולבנות אינדקס מורכב לפי ESR ולבדוק אותו עם explain.
  • להשתמש בטרנזקציה עם session, ולהסביר מתי בכלל צריך אותה ב־Mongo.
  • לענות על "Mongo או Postgres?" עם שיקולים ולא עם סיסמאות.
  • npm run check P25.7: 80% מ־E06–E19, ולפחות שני תרגילי תיקון.
