P25.7-E02 · embed או reference?

🧠 הבנהרמה 1⏱ 15 דק׳ידע נדרש: שיעור 3

לכל זוג — embed (בתוך המסמך) או reference (מזהה)? למה?

  1. כתובות משלוח של לקוח (בדרך כלל 1–3).
  2. הזמנות של לקוח.
  3. המוצר בתוך פריט הזמנה.
  4. תגובות לפוסט בבלוג — פוסט רגיל מקבל 5, פוסט ויראלי 40,000.
  5. הקטגוריה של מוצר (שם, תיאור, תמונה), כשיש 12 קטגוריות ואלפי מוצרים.

  • addReview(db, productId, { by, rating }) — מוסיף { by, rating } ל־reviews ומעדכן את ratingCount ו־ratingSum. לקוח שכבר דירג — false בלי שינוי; מוצר לא קיים — false. דירוג — שלם 1–5, אחרת RangeError.
