P25.7-E04 · לקרוא explain 🧠 הבנה רמה 1

💡 רמז 1

12 חזרו, 3,800 נבדקו. ו־SORT בתוכנית = מיון בזיכרון.

💡 רמז 2

ESR: שני שדות של שוויון, ואחריהם שדה המיון.

✅ פתרון
  1. האינדקס מצא את 3,800 ההזמנות של c42; את הסינון לפי status ואת המיון Mongo עשה אחר כך — קרא 3,800 מסמכים כדי להחזיר 12, ומיין בזיכרון.
  2. { customerId: 1, status: 1, createdAt: -1 }. שני שדות השוויון קודם (הסדר ביניהם פחות חשוב), ואחריהם שדה המיון — כך הרשומות באינדקס כבר ממוינות בתוך כל צירוף.
  3. אין SORT בתוכנית, ו־totalKeysExamined / totalDocsExamined ≈ 12.
⚠️ טעויות נפוצות
  • { createdAt: -1, customerId: 1 } — שדה המיון ראשון: Mongo עובר על כל ההזמנות לפי זמן ומסנן תוך כדי.

P25.7-E12 · אינדקסים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

ESR: equality קודם, sort אחריו. createIndex(keys, { name }).

💡 רמז 2

TTL: { expiresAt: 1 }, { expireAfterSeconds: 0 } — "0 שניות אחרי הזמן שבשדה".

✅ פתרון
// P25.7-E12
import type { Db } from "mongodb";

export async function createIndexes(db: Db) {
  // ESR: Equality (customerId) ← Sort (createdAt) — מתאים ל"ההזמנות של לקוח, מהחדשה"
  await db.collection("orders").createIndex({ customerId: 1, createdAt: -1 }, { name: "customer_recent" });
  await db.collection("products").createIndex({ category: 1, price: 1 }, { name: "category_price" });
  // TTL: Mongo מוחק לבד מסמכים שה־expiresAt שלהם עבר (תהליך רקע, בערך פעם בדקה)
  await db.collection("sessions").createIndex({ expiresAt: 1 }, { name: "sessions_ttl", expireAfterSeconds: 0 });
}
⚠️ טעויות נפוצות
  • { createdAt: -1, customerId: 1 } — עדיין IXSCAN, אבל על כל ההזמנות.
  • TTL על שדה שהוא מחרוזת — Mongo לא מוחק כלום (רק Date).

P25.7-E14 · מכירות לפי מוצר 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

$match ← $unwind ← $group ← $sort ← $project.

💡 רמז 2

revenue: { $sum: { $multiply: ["$items.price", "$items.qty"] } }, ו־name: { $first: "$items.name" }.

✅ פתרון
// P25.7-E14
import type { Db } from "mongodb";

export async function salesByProduct(db: Db) {
  return db
    .collection("orders")
    .aggregate([
      { $match: { status: { $in: ["paid", "delivered"] } } }, // קודם מסננים — פחות מסמכים לשלבים הבאים
      { $unwind: "$items" }, // מסמך לכל פריט
      { $group: { _id: "$items.productId", name: { $first: "$items.name" }, units: { $sum: "$items.qty" }, revenue: { $sum: { $multiply: ["$items.price", "$items.qty"] } } } },
      { $sort: { revenue: -1, _id: 1 } },
      { $project: { _id: 0, productId: "$_id", name: 1, units: 1, revenue: 1 } },
    ])
    .toArray();
}
⚠️ טעויות נפוצות
  • $match אחרי $group — כבר אין status.
  • $lookup ל־products כדי לקחת מחיר — המחיר של היום, לא של ההזמנה.

P25.7-E15 · הלקוחות המובילים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

קיבוץ לפי customerId, ואז $lookup ל־customers.

💡 רמז 2

$limit לפני ה־$lookup. ותוצאת $lookup היא מערך — $unwind.

✅ פתרון
// P25.7-E15
import type { Db } from "mongodb";

export async function topCustomers(db: Db, n = 3) {
  return db
    .collection("orders")
    .aggregate([
      { $match: { status: { $ne: "cancelled" } } },
      { $group: { _id: "$customerId", spent: { $sum: "$total" }, orders: { $sum: 1 } } },
      { $sort: { spent: -1, _id: 1 } },
      { $limit: n }, // לפני ה־$lookup: מצטרפים רק ל־n לקוחות, לא לכולם
      { $lookup: { from: "customers", localField: "_id", foreignField: "_id", as: "customer" } },
      { $unwind: "$customer" },
      { $project: { _id: 0, customerId: "$_id", name: "$customer.name", spent: 1, orders: 1 } },
    ])
    .toArray();
}
⚠️ טעויות נפוצות
  • $lookup לפני ה־$group — מצרפים את הלקוח לכל הזמנה, ואז מקבצים.
  • name: "$customer.name" בלי $unwind — מקבלים מערך של שם אחד.

P25.7-E22 · aggregation עם שלוש תקלות 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

הרץ את ה־pipeline שלב אחרי שלב (מחק את השלבים מהסוף) ותסתכל על המסמכים.

💡 רמז 2

אחרי $group יש רק _id והשדות שהגדרת. ו־{ $sum: 1 } סופר מסמכים, לא יחידות.

✅ פתרון
// P25.7-E22
import type { Db } from "mongodb";

// כמה יחידות נמכרו מכל קטגוריה (הזמנות ששולמו או נמסרו)
export async function unitsByCategory(db: Db) {
  return db
    .collection("orders")
    .aggregate([
      { $match: { status: { $in: ["paid", "delivered"] } } }, // תקלה 1: לסנן לפני ה־$group — אחריו כבר אין status
      { $unwind: "$items" }, // תקלה 2: בלי $unwind, "$items.qty" הוא מערך, ו־$sum של מערך הוא 0
      { $lookup: { from: "products", localField: "items.productId", foreignField: "_id", as: "product" } },
      { $unwind: "$product" },
      { $group: { _id: "$product.category", units: { $sum: "$items.qty" } } }, // תקלה 3: qty, לא 1 (1 סופר שורות)
      { $sort: { units: -1, _id: 1 } },
      { $project: { _id: 0, category: "$_id", units: 1 } },
    ])
    .toArray();
}
⚠️ טעויות נפוצות
  • להוסיף status: { $first: "$status" } ל־$group ולסנן אחריו — מסנן לפי הסטטוס של הזמנה אחת בכל קבוצה.

P25.7-E24 · אתגר: דשבורד בבקשה אחת 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

$facet: { byDay: [...], byStatus: [...], topProducts: [...] } — שלושה pipelines על אותם מסמכים.

💡 רמז 2

$dateToString: { date: "$createdAt", format: "%Y-%m-%d", timezone: "Asia/Jerusalem" }. ו־byStatus — המרה לאובייקט ב־JS אחרי השאילתה.

✅ פתרון
// P25.7-E24
import type { Db } from "mongodb";

// דשבורד של טווח תאריכים — בבקשה אחת: הכנסות לפי יום (בשעון ישראל), ספירה לפי סטטוס, ו־3 המוצרים המובילים
export async function dashboard(db: Db, from: Date, to: Date) {
  const [result] = await db
    .collection("orders")
    .aggregate([
      { $match: { createdAt: { $gte: from, $lt: to } } },
      {
        $facet: {
          byDay: [
            { $match: { status: { $ne: "cancelled" } } },
            // היום לפי ישראל, לא לפי UTC: הזמנה ב־22:10Z ב־1.11 היא 2.11 בישראל (פרק 24)
            { $group: { _id: { $dateToString: { date: "$createdAt", format: "%Y-%m-%d", timezone: "Asia/Jerusalem" } }, revenue: { $sum: "$total" }, orders: { $sum: 1 } } },
            { $sort: { _id: 1 } },
            { $project: { _id: 0, day: "$_id", revenue: 1, orders: 1 } },
          ],
          byStatus: [{ $group: { _id: "$status", n: { $sum: 1 } } }, { $sort: { _id: 1 } }],
          topProducts: [
            { $match: { status: { $ne: "cancelled" } } },
            { $unwind: "$items" },
            { $group: { _id: "$items.productId", units: { $sum: "$items.qty" } } },
            { $sort: { units: -1, _id: 1 } },
            { $limit: 3 },
            { $project: { _id: 0, productId: "$_id", units: 1 } },
          ],
        },
      },
    ])
    .toArray();
  return {
    byDay: result.byDay,
    byStatus: Object.fromEntries(result.byStatus.map((s: { _id: string; n: number }) => [s._id, s.n])),
    topProducts: result.topProducts,
  };
}
⚠️ טעויות נפוצות
  • קיבוץ לפי יום ב־UTC — o6 (21:55Z ב־21.10) נספרת ב־21.10, אבל בישראל זה כבר 22.10.
  • שלוש שאילתות נפרדות — עובד, אבל שלוש סריקות של אותו טווח.
