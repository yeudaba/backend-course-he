P25.7-E72 · ‏$match — לפני או אחרי?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

שני pipelines שמחזירים את אותה תוצאה — "הכנסות לפי מוצר, רק הזמנות delivered":

// א
[{ $unwind: "$items" }, { $group: { _id: { p: "$items.productId", s: "$status" }, revenue: { $sum: { $multiply: ["$items.price", "$items.qty"] } } } }, { $match: { "_id.s": "delivered" } }]
// ב
[{ $match: { status: "delivered" } }, { $unwind: "$items" }, { $group: { _id: "$items.productId", revenue: { $sum: { $multiply: ["$items.price", "$items.qty"] } } } }]

(1) על מיליון הזמנות (10% delivered, 3 פריטים בממוצע) — כמה מסמכים עוברים ב־$unwind בכל אחד? (2) איזה מהם יכול להשתמש באינדקס על status, ולמה? (3) מתי $match חייב לבוא אחרי $group?

P25.7-E73 · ‏$unwind ומערך ריק

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

"כמה דירוגים יש לכל מוצר" —

[{ $unwind: "$reviews" }, { $group: { _id: "$_id", n: { $sum: 1 } } }]

(1) מה קורה למוצרים p4 ו־p7 (‏reviews: [])? (2) ולמוצר בלי שדה reviews בכלל? (3) איך משאירים אותם, ומה יהיה ה־n שלהם? (4) מה הדרך הקצרה יותר לספור, בלי $unwind בכלל?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 17, שיעור 4

-- א
