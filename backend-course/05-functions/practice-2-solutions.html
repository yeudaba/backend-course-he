P05-E46 · מקינון ל־guard clauses 🧠 הבנה רמה 2

💡 רמז 1

שלושה "מקרים רעים": סכום לא חיובי (null), אין קופון (0), קופון לא מוכר (0).

💡 רמז 2

אחרי שכל ה־guards עברו — נשאר רק המקרה הטוב: return total * 0.1;.

✅ פתרון
function discountFor(total, couponCode) {
  if (total <= 0) {
    return null;
  }
  if (couponCode !== "SAVE10") {
    return 0;
  }
  return total * 0.1;
}

20 0 0 null

"אין קופון" ו"קופון לא מוכר" התמזגו לבדיקה אחת (!== "SAVE10") — בגרסה המקוננת הם היו שני ענפים נפרדים עם אותה תוצאה. 17 שורות הפכו ל־9, ואין צורך במשתנה result. להוסיף קופון חדש? עוד if אחד לפני השורה האחרונה.

⚠️ טעויות נפוצות

P05-E47 · מי קורא למי? 🧠 הבנה רמה 2

💡 רמז 1

כש־a קוראת ל־b, היא "מחכה" עד ש־b מחזירה — ורק אז ממשיכה.

💡 רמז 2

השורה האחרונה: קודם מחושב a(1) (עם כל ההדפסות שבתוכה), ורק אז מודפס "תוצאה:".

✅ פתרון
function a(x) {
  console.log("a התחילה עם", x);
  const r = b(x + 1) * 2;
  console.log("a מחזירה", r);
  return r;
}
function b(y) {
  console.log("b התחילה עם", y);
  return y + 10;
}
console.log("תוצאה:", a(1));
a התחילה עם 1
b התחילה עם 2
a מחזירה 24
תוצאה: 24

"תוצאה:" מודפס אחרון, למרות שהוא כתוב ראשון בשורה — הארגומנטים של console.log מחושבים לפני ש־console.log עצמו רץ.

⚠️ טעויות נפוצות
  • להדפיס "תוצאה:" ראשון. זה הסדר שבו קוראים את השורה — לא הסדר שבו היא רצה.

P05-E13 · בדיקת אימייל 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

מיקום ה־@: const at = clean.indexOf("@"); — בהתחלה זה 0, בסוף זה clean.length - 1, חסר זה ‎-1.

💡 רמז 2

"נקודה אחרי ה־@": clean.slice(at + 1).includes(".").

✅ פתרון
// P05-E13: בדיקת אימייל עם guard clauses
function validateEmail(email) {
  const clean = email.trim();
  if (clean === "") {
    return "חובה להזין אימייל";
  }
  if (clean.includes(" ")) {
    return "אימייל לא יכול להכיל רווחים";
  }
  const at = clean.indexOf("@");
  if (at <= 0 || at === clean.length - 1) {
    return "חסר @ במקום הנכון";
  }
  if (!clean.slice(at + 1).includes(".")) {
    return "חסר דומיין תקין";
  }
  return null;
}

console.log(validateEmail("  dana@mail.com "));
console.log(validateEmail("dana@mail"));

module.exports = { validateEmail };
null
חסר דומיין תקין

זו בדיקה "בסיסית" — אימיילים אמיתיים מורכבים הרבה יותר. בשרת נשתמש בספריית validation (פרק 15), ובסוף שולחים מייל אימות כדי לדעת בוודאות.

⚠️ טעויות נפוצות
  • at < 0 בלבד — "@mail.com" יעבור.

// P05-E15: שנה מעוברת וימים בחודש
function isLeapYear(year) {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

function daysInMonth(month, year) {
  if (!Number.isInteger(month) || month < 1 || month > 12) {
    return null;
  }
  if (month === 2) {
    return isLeapYear(year) ? 29 : 28;
  }
  if (month === 4 || month === 6 || month === 9 || month === 11) {
    return 30;
  }
  return 31;
}

P05-E49 · משך עם ברירת מחדל 🤖 💻 כתיבת קוד 🤖 רמה 2

function formatDuration(seconds, showSeconds = true) {
  const hours = Math.floor(seconds / 3600);
  const minutes = `${Math.floor((seconds % 3600) / 60)}`.padStart(2, "0");
  const secs = `${seconds % 60}`.padStart(2, "0");
  if (!showSeconds) {
    return `${hours}:${minutes}`;
  }
  return `${hours}:${minutes}:${secs}`;
}

P05-E52 · הסדר של ה־guards 🧠 הבנה רמה 3

💡 רמז 1

✅ פתרון

P05-E53 · return בתוך לולאה 🧠 הבנה רמה 2

P05-E28 · מספר ראשוני 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

קודם guard: if (!Number.isInteger(n) || n < 2) return false;. אחר כך לולאה שמחפשת מחלק, ו־return false ברגע שמצאה.

💡 רמז 2

לא צריך לבדוק את כל המספרים עד n: אם יש מחלק, אחד מהם קטן או שווה לשורש. for (let d = 2; d * d <= n; d++). אם הלולאה הסתיימה בלי למצוא — return true.

✅ פתרון
// P05-E28: מספר ראשוני
function isPrime(n) {
  if (!Number.isInteger(n) || n < 2) return false;
  for (let d = 2; d * d <= n; d++) {
    if (n % d === 0) return false;
  }
  return true;
}

const primes = [];
for (let i = 1; i <= 30; i++) {
  if (isPrime(i)) primes.push(i);
}
console.log(primes.join(" "));

module.exports = { isPrime };

שני הדפוסים מפרק 4 ומשיעור 2 נפגשים כאן. ה־guard מטפל במקרים הרעים ויוצא. הלולאה מחפשת "עד שמוצאים", ו־return בתוך הלולאה עוצר אותה מוקדם — כמו break, אבל יוצא מהפונקציה כולה. ה־return true בסוף קורה רק אם אף מחלק לא נמצא.

למה d * d <= n? ל־1,000,000,007 לולאה עד n היא מיליארד סיבובים (כמה שניות). עד השורש — כ־31,600 סיבובים, וזה מיידי. בפרק 27 נקרא לזה O(√n).

⚠️ טעויות נפוצות
  • return true בתוך הלולאה (ב־else) — הפונקציה עונה אחרי מחלק אחד בלבד, ו־9 יוצא ראשוני.
  • לשכוח את ה־guard — 1 יוצא ראשוני (הלולאה לא רצה בכלל, ומגיעים ל־return true).
  • d < n / 2 — נכון, אבל עם 1,000,000,007 זה איטי מאוד.

    }

}
