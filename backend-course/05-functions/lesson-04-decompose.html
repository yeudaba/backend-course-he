שיעור 4 — גישור: פירוק בעיה לפונקציות + הבודק האוטומטי

⏱ ~30 דקות · יחידת גישור

🎯 יחידת גישור — מחיקוי לפתרון עצמאי

עד עכשיו רוב התרגילים היו "קוד שדומה לדוגמה". מכאן והלאה הבעיות גדלות, ואין דוגמה שאפשר להעתיק. בשיעור הזה נלמד שיטה לפתור בעיה חדשה, וגם איך לעבוד עם הבודק האוטומטי.

1. השיטה: ארבעה שלבים

  1. קרא ופרק למילים. סמן שמות עצם (← ערכים/משתנים/פרמטרים) ופעלים (← פונקציות). מה הקלט? מה הפלט?
  2. פתור ביד, לדוגמה אחת. בלי מחשב. כתוב את הצעדים שעשית בעברית.
  3. כל צעד ← פונקציה קטנה עם שם ברור. כתוב קודם רק את השם, הפרמטרים ומה היא מחזירה (בהערה).
  4. ממש ובדוק אחת־אחת, מהקטנה לגדולה. אחרי כל פונקציה — הרצה.

2. 👣 דוגמה מלאה

הבעיה: "כתוב פונקציה שמקבלת שם של מוצר ומחיר, ומחזירה שורת קבלה: שם המוצר באותיות גדולות, מרופד בנקודות עד 20 תווים, ואחריו המחיר עם שתי ספרות. מוצר עם שם ריק — 'מוצר ללא שם'."

שלב 1 — מילים

  • קלט: שם (מחרוזת), מחיר (מספר). פלט: מחרוזת אחת.
  • פעלים: "באותיות גדולות", "מרופד", "עם שתי ספרות", "שם ריק ← ברירת מחדל".

שלב 2 — ביד, לדוגמה "mouse", 89.9

"mouse" ← "MOUSE" ← "MOUSE..............." (20 תווים) ← 89.9 ← "89.90" ← מחברים: "MOUSE...............89.90".

שלב 4 — מימוש ובדיקה אחת־אחת

function cleanName(name) {
  const trimmed = name.trim();
  if (trimmed === "") {
    return "מוצר ללא שם";
  }
  return trimmed.toUpperCase();
}
console.log(cleanName("  mouse "), "|", cleanName("   "));

function formatAmount(price) {
  return price.toFixed(2);
}
console.log(formatAmount(89.9));

function receiptLine(name, price, width = 20) {
  return cleanName(name).padEnd(width, ".") + formatAmount(price);
}
console.log(receiptLine("mouse", 89.9));

כל שורת console.log היא "בדיקה ידנית" קטנה. בעולם המקצועי — וגם בקורס מעכשיו — הבדיקות האלה נכתבות בקובץ נפרד ורצות אוטומטית.

3. הבודק האוטומטי

בתרגילים עם 🤖, קובץ ההתחלה נראה כך:

05-functions/starter/P05-E06.js 
// P05-E06: ...תיאור התרגיל...
function toCelsius(fahrenheit) {
  // כתוב כאן
}

// הרצה ידנית (אפשר לשנות):
console.log(toCelsius(212));

// השורה הזו מאפשרת לבודק להשתמש בפונקציה. אל תמחק אותה (נסביר בפרק 8).
module.exports = { toCelsius };
  1. כתוב את הפונקציה בתוך קובץ ההתחלה. אל תשנה את שם הפונקציה ואת הפרמטרים.
  2. הרץ ידנית: node 05-functions/starter/P05-E06.js — ותראה את ה־console.log שלך.
  3. הרץ את הבודק: npm run check P05-E06.

כך נראית תשובה של הבודק:

✘ יש בדיקות שנכשלו. קרא את ההודעה מעל: מה ציפינו ומה קיבלנו.

איך קוראים: כל ✔ — בדיקה שעברה; ✖ — נכשלה, ומתחתיה מה הפונקציה שלך החזירה ומה היה צריך. השורה "(פלט מהקוד שלך)" היא ה־console.log שבקובץ. כאן כל התוצאות גדולות מדי — מכאן חוזרים לשיטה: מה הפונקציה עושה עם 212, ביד? (רמז: סדר פעולות...) ואם הקובץ שלך בכלל לא נטען (למשל SyntaxError), הבודק יציג ⚠️ עם השגיאה.

💡 הבודק הוא עוזר, לא שופט

הבדיקות בודקות מקרים נבחרים — כולל מקרי קצה שאולי לא חשבת עליהם. אם כולן עוברות — מצוין, אבל קרא גם את הפתרון המוסבר: לפעמים יש דרך פשוטה יותר. ואם נכשלת בדיקה ואתה בטוח שהקוד נכון — קרא את שם הבדיקה; הוא מסביר מה נדרש.

💼 בעולם העבודה

בראיון קוד, השיטה הזו היא מה שמראיינים רוצים לשמוע בקול: "אני רוצה לוודא שהבנתי — הקלט הוא..., הפלט הוא.... בוא נעבור על דוגמה ביד. אני אפרק לשלוש פונקציות..." — גם אם לא תסיים, הם ראו איך אתה חושב.
