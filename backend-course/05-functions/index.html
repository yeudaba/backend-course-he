⚡ מבחן כניסה — אולי אפשר לדלג?
  1. מה ההבדל בין פרמטר לארגומנט?
  2. מה ידפיס: function f(x) { x * 2; } console.log(f(5));
  3. כתוב פונקציה isEven(n) שמחזירה בוליאני.
  4. כתוב את אותה פונקציה כ־arrow function בשורה אחת.
  5. מה ידפיס: function greet(name = "אורח") { return "שלום " + name; } console.log(greet());
  6. מה ההבדל בין return ל־console.log בתוך פונקציה?
  7. מה יקרה: function f() { const a = 1; } f(); console.log(a);
  8. מה ידפיס: const apply = (fn, v) => fn(v); console.log(apply((x) => x + 1, 9));
  9. מה זה "פונקציה טהורה" (pure function)?
  10. למה return מוקדם (guard clause) עדיף על if מקונן?
תשובות
  1. פרמטר — השם בהגדרה; ארגומנט — הערך שמעבירים בקריאה.
  2. undefined — אין return.
  3. function isEven(n) { return n % 2 === 0; }
  4. const isEven = (n) => n % 2 === 0;
  5. שלום אורח
  6. return מחזיר ערך למי שקרא (אפשר להשתמש בו); console.log רק מדפיס.
  7. ReferenceError: a is not defined
  8. 10
  9. תלויה רק בפרמטרים שלה, מחזירה תמיד אותה תוצאה לאותו קלט, ולא משנה שום דבר מחוצה לה.
  10. משאיר את הקוד "שטוח": המקרים הרעים מטופלים ויוצאים, והמקרה הטוב בסוף בלי קינון.

🎯 בסוף הפרק תדע
  • להגדיר פונקציה, לקרוא לה, ולהעביר לה ארגומנטים.
  • להחזיר ערך עם return — ולהבין למה זה שונה מהדפסה.
  • לכתוב guard clauses ופרמטרים עם ברירת מחדל.
  • לכתוב arrow functions ולהעביר פונקציה כערך לפונקציה אחרת.
  • להבין scope: איפה משתנה "חי".
  • לפרק בעיה לפונקציות קטנות, ולבדוק אותן עם הבודק האוטומטי.
