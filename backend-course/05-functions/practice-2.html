function classify(temp) {

  }

P05-E46 · מקינון ל־guard clauses

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

כתוב על דף את הפונקציה מחדש עם guard clauses — בלי else בכלל, וכל מקרה רע מחזיר מיד:

function discountFor(total, couponCode) {
  let result;
  if (total > 0) {
    if (couponCode !== "") {
      if (couponCode === "SAVE10") {
        result = total * 0.1;
      } else {
        result = 0;
      }
    } else {
      result = 0;
    }
  } else {
    result = null;
  }
  return result;
}

P05-E52 · הסדר של ה־guards

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: פרק 2, פרק 3, שיעור 2

הפונקציה בודקת גיל מטופס. בלי להריץ — מה תחזיר לכל קלט?

function checkAge(input) {
  const age = Number(input);
  if (age < 0) {
    return "גיל לא יכול להיות שלילי";
  }
  if (age > 120) {
    return "גיל לא סביר";
  }
  if (Number.isNaN(age)) {
    return "חייב להיות מספר";
  }
  return `גיל ${age} — תקין`;
}

קלטים: "30" · "-5" · "abc" · "" · " 7 ". אילו תשובות שגויות? איך תסדר את ה־guards מחדש, ואיזה guard חסר?

🔗 איך זה מתחבר: בפרק 3 (P03-E74) ראית שהסדר בשרשרת בדיקות קלט חשוב — NaN < 0 הוא false, וגם NaN > 120. עם guard clauses זה אותו עיקרון בדיוק: כל guard מניח שהקודמים עברו.

P05-E53 · return בתוך לולאה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 2

שתי גרסאות של "המספר הזוגי הראשון בטווח". בלי להריץ — מה תחזיר כל אחת?

function firstEvenA(from, to) {
  for (let i = from; i <= to; i++) {
    if (i % 2 === 0) {
      return i;
    }
  }
  return null;
}
function firstEvenB(from, to) {
  for (let i = from; i <= to; i++) {
    if (i % 2 === 0) {
      return i;
    } else {
      return null;
    }
  }
}
console.log(firstEvenA(3, 9), firstEvenB(3, 9));
console.log(firstEvenA(4, 9), firstEvenB(4, 9));
console.log(firstEvenA(5, 5), firstEvenB(5, 5));
console.log(firstEvenA(9, 3), firstEvenB(9, 3));

🔗 איך זה מתחבר: בפרק 4 עצרת חיפוש עם דגל ו־break. בפונקציה, return בתוך הלולאה עושה את שניהם: עוצר את הלולאה וגם מחזיר תשובה. ה־return null אחרי הלולאה הוא "לא נמצא" — הוא רץ רק אם הלולאה נגמרה בלי למצוא.
