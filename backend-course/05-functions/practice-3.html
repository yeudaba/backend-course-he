P05-E58 · callback עם סוגריים

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

בלי להריץ — מה יקרה בכל קריאה?

function applyToRange(from, to, fn) {
  let result = "";
  for (let i = from; i <= to; i++) {
    result += fn(i) + " ";
  }
  return result.trim();
}
const triple = (n) => n * 3;
console.log(applyToRange(1, 4, triple));
console.log(applyToRange(1, 4, (n) => `#${n}`));
console.log(applyToRange(3, 1, triple));
console.log(applyToRange(1, 4, triple(2)));

P05-E12 · הפעל פעמיים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

בקובץ 05-functions/starter/P05-E12.js השלם:

  • applyTwice(fn, value) — מפעילה את fn על הערך, ואז שוב על התוצאה, ומחזירה.
  • applyN(fn, value, times) — אותו דבר, times פעמים (לולאה). עם times = 0 מחזירה את הערך כמו שהוא.

דוגמאות: applyTwice((x) => x + 3, 10) ← 16; applyN((s) => s + "!", "היי", 3) ← "היי!!!".

P05-E26 · מונה עם זיכרון (closure) 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

בשיעור 3 ראינו שלכל פונקציה יש scope משלה. יש לזה תוצאה מעניינת: פונקציה שנוצרה בתוך פונקציה אחרת ממשיכה לראות את המשתנים שלה, גם אחרי שהפונקציה החיצונית סיימה. זה נקרא closure, וככה שומרים "זיכרון" בלי משתנה גלובלי.

השלם את makeCounter(start = 0). היא מחזירה פונקציה. בכל קריאה לפונקציה שחזרה, המונה גדל ב־1 והערך החדש חוזר:

const visits = makeCounter();
visits(); // 1
visits(); // 2
const tickets = makeCounter(100);
tickets(); // 101
visits(); // 3 — לכל מונה זיכרון משלו

% node 05-functions/starter/P05-E26.js

P05-E59 · טקסט לפי callback 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

כתוב שתי פונקציות כ־arrow functions:

  • transformText(text, fn) — מפעילה את fn על כל תו, ומחזירה את המחרוזת שנבנתה מהתוצאות.
  • shout(text) — מחזירה את הטקסט באותיות גדולות עם ! בסוף (בשורה אחת, בלי { }).
transformText("abc", (ch) => ch.toUpperCase()); // "ABC"
transformText("abc", (ch) => ch + ch);          // "aabbcc"
transformText("a-b", (ch) => (ch === "-" ? "" : ch)); // "ab"
shout("hi");                                     // "HI!"

let runningTotal = 0;
const addImpure = (n) => {
  runningTotal += n;
  return runningTotal;
};
const sumRange = (from, to) => {
  let total = 0;
  for (let i = from; i <= to; i++) {

  }

console.log(sumRange(1, 3), sumRange(1, 3), sumRange(1, 3));

P05-E63 · ספירה לפי תנאי 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 3

כתוב countIf(from, to, predicate) שמחזירה כמה מספרים בטווח (כולל הקצוות) מקיימים את predicate — פונקציה שמקבלת מספר ומחזירה true/false:

countIf(1, 10, (n) => n % 2 === 0);   // 5
countIf(1, 100, (n) => n % 7 === 0);  // 14
countIf(5, 4, (n) => true);           // 0

🔗 איך זה מתחבר: דפוס הספירה מפרק 4 ("כמה מתחלקים ב־7?") כתבת שם עם תנאי קבוע. עכשיו התנאי הוא פרמטר: אותה לולאה סופרת כל דבר שתבקש. זה בדיוק filter של פרק 6.

P05-E64 · החיפוש הראשון 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 3

כתוב findFirst(from, to, predicate) שמחזירה את המספר הראשון בטווח שמקיים את predicate, או null אם אין כזה:

findFirst(1000, 2000, (n) => n % 7 === 0 && n % 13 === 0); // 1001
findFirst(1, 10, (n) => n > 20);                            // null

הבודק מוודא שהפונקציה עוצרת ברגע שמצאה — לא ממשיכה לבדוק.

🔗 איך זה מתחבר: P04-E17 ("החיפוש הראשון") השתמש ב־break ובדגל. בפונקציה, return בתוך הלולאה עושה את שניהם (P05-E53), והתנאי מגיע מבחוץ כ־callback. זה find של פרק 6.

P05-E65 · מפעל לפורמטים 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 15 דק׳ידע נדרש: פרק 2, שיעור 2, שיעור 3

כתוב makeFormatter(currency = "₪", decimals = 2) שמחזירה פונקציה: היא מקבלת סכום ומחזירה אותו מעוצב.

const shekels = makeFormatter();
const dollars = makeFormatter("$");
const rounded = makeFormatter("€", 0);
shekels(19.9);  // "₪19.90"
dollars(5);     // "$5.00"
rounded(19.9);  // "€20"

🔗 איך זה מתחבר: toFixed מפרק 2, ברירות מחדל משיעור 2, ומשיעור 3 — פונקציה היא ערך, ולכן אפשר גם להחזיר אותה (כמו makeCounter ב־P05-E26). הפונקציה שחוזרת "זוכרת" את currency ו־decimals.
