P05-E01 · מה יחזור?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

מה ידפיס הקוד? לכל שורת console.log — הסבר.

function a(x) {
  return x + 1;
}
function b(x) {
  console.log(x + 1);
}
function c(x) {
  x + 1;
}
console.log(a(1));
console.log(b(1));
console.log(c(1));
console.log(a(a(1)));

P05-E02 · פרמטרים וארגומנטים

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

בקוד הבא: מה הם הפרמטרים, מה הם הארגומנטים, ומה יודפס?

function describe(item, price, currency) {
  return `${item}: ${price} ${currency}`;
}
console.log(describe("עט", 5, "₪"));
console.log(describe(5, "עט", "₪"));
console.log(describe("מחברת", 12));
console.log(describe("תיק", 99, "₪", "מיותר"));
