P05-E37 · פונקציה בתוך לולאה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 1

בלי להריץ — מה יודפס? וכמה פעמים בסך הכול רצה הלולאה שבתוך stars?

function stars(n) {
  let s = "";
  for (let i = 0; i < n; i++) {
    s += "*";
  }
  return s;
}
for (let row = 1; row <= 3; row++) {
  console.log(`${row}: ${stars(row)}`);
}
console.log(stars(0) === "", stars(4).length);

🔗 איך זה מתחבר: בפרק 4 (P04-E12) בנית משולש עם לולאה מקוננת. כאן הלולאה הפנימית "התחבאה" בתוך פונקציה עם שם — הקוד קצר וקריא יותר, אבל מספר הצעדים לא השתנה: זו עדיין לולאה בתוך לולאה.
