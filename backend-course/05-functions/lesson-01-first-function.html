שיעור 1 — פונקציה ראשונה: פרמטרים ו־return

⏱ ~35 דקות

🎯 בשיעור הזה
  • להגדיר פונקציה ולקרוא לה.
  • פרמטרים וארגומנטים — "חורים" שממלאים בכל קריאה.
  • return — הפונקציה מחזירה תשובה.

1. הגדרה וקריאה

פונקציה היא כמו מתכון: כותבים אותו פעם אחת (הגדרה), ומבשלים לפיו כמה פעמים שרוצים (קריאה).

function printLine() {
  console.log("--------------------");
}

printLine();
console.log("קבלה");
printLine();
--------------------
קבלה
--------------------
חלקמה זה
function"אני מגדיר פונקציה"
printLineשם הפונקציה. camelCase, ועדיף פועל: printLine, calculateTotal, isValid
()רשימת הפרמטרים (כאן ריקה)
{ ... }גוף הפונקציה — מה שקורה בכל קריאה
printLine();קריאה: השם + סוגריים. בלי הסוגריים — שום דבר לא קורה

הגדרה לבד לא מריצה כלום. רק קריאה מריצה את הגוף.

2. פרמטרים: לתת לפונקציה ערכים

function greet(name, city) {
  console.log(`שלום ${name} מ${city}!`);
}

greet("דנה", "חיפה");
greet("עומר", "אילת");
שלום דנה מחיפה!
שלום עומר מאילת!

name ו־city הם פרמטרים — משתנים שקיימים רק בתוך הפונקציה. "דנה" ו־"חיפה" הם ארגומנטים — הערכים שנכנסים לפרמטרים בקריאה, לפי הסדר: הראשון לראשון, השני לשני.

מה אם מעבירים פחות ארגומנטים? הפרמטר החסר מקבל undefined. יותר? העודפים פשוט נזרקים. JavaScript לא מתלוננת — וזו סיבה טובה ל־TypeScript (פרק 11).

3. return — הפונקציה עונה

עד עכשיו הפונקציות הדפיסו. אבל רוב הפונקציות בשרת לא מדפיסות כלום — הן מחשבות ומחזירות תשובה, ומי שקרא להן מחליט מה לעשות איתה:

function calculateTotal(price, quantity) {
  return price * quantity;
}

const total = calculateTotal(40, 3);
console.log(total);
console.log(calculateTotal(10, 2) + calculateTotal(5, 4));
120
40

הקריאה calculateTotal(40, 3) היא ביטוי — היא "מתחלפת" בערך שהוחזר (120), בדיוק כמו 40 * 3. לכן אפשר לשמור אותה במשתנה, לחבר שתי קריאות, או לשבץ ב־template literal.

⚡ חשוב גם במסלול המהיר — הדפסה ≠ החזרה 
function printDouble(n) {
  console.log(n * 2);
}
function getDouble(n) {
  return n * 2;
}

const a = printDouble(5);
const b = getDouble(5);
console.log("a =", a);
console.log("b =", b);
10
a = undefined
b = 10

printDouble הדפיסה 10 — אבל לא החזירה כלום, ולכן a הוא undefined. פונקציה בלי return מחזירה undefined. כלל בקורס: פונקציות מחזירות; ההדפסה קורית בחוץ, אצל מי שקרא. כך אפשר להשתמש בתוצאה, לבדוק אותה (הבודק האוטומטי עושה בדיוק את זה), ובשרת — לשלוח אותה ללקוח.

return גם מסיים את הפונקציה

function check(n) {
  return "הראשון";
  console.log("לעולם לא ירוץ");
}
console.log(check(1));
הראשון

שורות אחרי return לא רצות. VS Code אפילו יציג אותן באפור. בשיעור הבא ננצל את זה.
