P05-E01 · מה יחזור? 🧠 הבנה רמה 1

💡 רמז 1

פונקציה בלי return מחזירה undefined. אבל b גם מדפיסה בעצמה.

💡 רמז 2

console.log(b(1)): קודם רצה b (מדפיסה 2), ואז מודפס מה שהיא החזירה.

✅ פתרון
function a(x) {
  return x + 1;
}
function b(x) {
  console.log(x + 1);
}
function c(x) {
  x + 1;
}
console.log(a(1));
console.log(b(1));
console.log(c(1));
console.log(a(a(1)));
2
2
undefined
undefined
3

השורה השנייה מייצרת שתי שורות פלט: "2" מתוך b, ואז "undefined" — הערך המוחזר. a(a(1)): הפנימית קודם ← 2 ← a(2) ← 3.

⚠️ טעויות נפוצות
  • לחשוב ש־c מחזירה 2 כי "היא מחשבת" — חישוב בלי return הולך לאיבוד.

P05-E02 · פרמטרים וארגומנטים 🧠 הבנה רמה 1

💡 רמז 1

ארגומנטים נכנסים לפי מיקום. ארגומנט חסר ← undefined.

💡 רמז 2

ארגומנט מיותר פשוט מתעלמים ממנו.

✅ פתרון

פרמטרים: item, price, currency. ארגומנטים: הערכים בכל קריאה.

function describe(item, price, currency) {
  return `${item}: ${price} ${currency}`;
}
console.log(describe("עט", 5, "₪"));
console.log(describe(5, "עט", "₪"));
console.log(describe("מחברת", 12));
console.log(describe("תיק", 99, "₪", "מיותר"));
עט: 5 ₪
5: עט ₪
מחברת: 12 undefined
תיק: 99 ₪

  • לצפות שגיאה בקריאה 3 או 4 — JavaScript לא בודקת מספר ארגומנטים (TypeScript כן — פרק 11).

P05-E07 · שטח והיקף 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

היקף = 2 × (רוחב + גובה).

💡 רמז 2

return מלבן ${width}×${height}: שטח ${area(width, height)}, היקף ${perimeter(width, height)};

✅ פתרון
// P05-E07: שטח והיקף של מלבן
function area(width, height) {
  return width * height;
}

function perimeter(width, height) {
  return 2 * (width + height);
}

function describeRect(width, height) {
  return `מלבן ${width}×${height}: שטח ${area(width, height)}, היקף ${perimeter(width, height)}`;
}

console.log(describeRect(3, 4));

module.exports = { area, perimeter, describeRect };
מלבן 3×4: שטח 12, היקף 14
⚠️ טעויות נפוצות
  • לחשב שוב את השטח בתוך describeRect במקום לקרוא ל־area — עובד, אבל מפספס את המטרה: אם הנוסחה תשתנה, יהיו שני מקומות לתקן.

P05-E08 · מחיר כולל מע״מ 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

חשב: ביניים = מחיר × כמות; סה״כ = ביניים × (1 + מע״מ).

💡 רמז 2

עיגול שמחזיר מספר: Math.round(x * 100) / 100 (toFixed מחזיר מחרוזת).

✅ פתרון
// P05-E08: מחיר כולל מע״מ
function totalWithVat(unitPrice, quantity, vatRate) {
  const subtotal = unitPrice * quantity;
  const total = subtotal * (1 + vatRate);
  return Math.round(total * 100) / 100;
}

console.log(totalWithVat(49.9, 3, 0.18));

module.exports = { totalWithVat };
176.65
⚠️ טעויות נפוצות
  • return total.toFixed(2) — הבודק יגיד '176.65' !== 176.65: מחרוזת מול מספר.

P05-E20 · פונקציות שלא מחזירות 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

הבודק בודק מה הפונקציה מחזירה. ההדפסה שאתה רואה — מאיפה היא מגיעה?

💡 רמז 2

שלושה באגים: הדפסה במקום החזרה; arrow function עם { } בלי return; return לבד בשורה.

✅ פתרון
// P05-E20: שלוש פונקציות — מתוקנות
function discountPrice(price, percent) {
  return price - (price * percent) / 100;
}

const addShipping = (total) => {
  return total + 25;
};

function finalPrice(price, percent) {
  return addShipping(discountPrice(price, percent));
}

console.log(finalPrice(200, 10));

module.exports = { discountPrice, addShipping, finalPrice };
205

(1) discountPrice הדפיסה במקום להחזיר. (2) addShipping חישבה בתוך { } בלי return. (3) ב־finalPrice, return עמד לבד בשורה — JavaScript מוסיפה ; אוטומטית, והפונקציה החזירה undefined.

⚠️ טעויות נפוצות
  • לתקן רק את מה שהבודק מראה ראשון ולא להריץ שוב.
חזרהתרגול שיעור 1הבאשיעור 2 — return לעומק, ברירות מחדל ו־guard clauses
