פונקציה בלי return מחזירה undefined. אבל b גם מדפיסה בעצמה.

P05-E31 · return שנשאר לבד בשורה 🧠 הבנה רמה 2

💡 רמז 1

JavaScript מוסיפה ; בסוף שורה שמסתיימת ב־return.

💡 רמז 2

שורות אחרי return לעולם לא רצות.

✅ פתרון
function total(price, qty) {
  return
    price * qty;
}
function discount(price) {
  return price * 0.9;
  console.log("הנחה חושבה");
}
console.log(total(10, 3));
console.log(discount(100));
undefined
90

total מחזירה undefined — ה־return "נסגר" בסוף השורה, והחישוב הוא שורה נפרדת שלא רצה. ב־discount, ההדפסה אחרי return לא רצה. VS Code מציג את שתי השורות שלא ירוצו באפור, ו־Prettier מזיז את price * qty; לעמודה של return — שני רמזים שמשהו לא בסדר.

⚠️ טעויות נפוצות
  • לשבור שורה אחרי return "כדי שיהיה קריא". הביטוי חייב להתחיל באותה שורה.

P05-E08 · מחיר כולל מע״מ 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

חשב: ביניים = מחיר × כמות; סה״כ = ביניים × (1 + מע״מ).

💡 רמז 2

עיגול שמחזיר מספר: Math.round(x * 100) / 100 (toFixed מחזיר מחרוזת).

✅ פתרון
// P05-E08: מחיר כולל מע״מ
function totalWithVat(unitPrice, quantity, vatRate) {
  const subtotal = unitPrice * quantity;
  const total = subtotal * (1 + vatRate);
  return Math.round(total * 100) / 100;
}

console.log(totalWithVat(49.9, 3, 0.18));

module.exports = { totalWithVat };
176.65
⚠️ טעויות נפוצות
  • return total.toFixed(2) — הבודק יגיד '176.65' !== 176.65: מחרוזת מול מספר.

P05-E20 · פונקציות שלא מחזירות 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

הבודק בודק מה הפונקציה מחזירה. ההדפסה שאתה רואה — מאיפה היא מגיעה?

💡 רמז 2

שלושה באגים: הדפסה במקום החזרה; arrow function עם { } בלי return; return לבד בשורה.

✅ פתרון
// P05-E20: שלוש פונקציות — מתוקנות
function discountPrice(price, percent) {
  return price - (price * percent) / 100;
}

const addShipping = (total) => {
  return total + 25;
};

function finalPrice(price, percent) {
  return addShipping(discountPrice(price, percent));
}

console.log(finalPrice(200, 10));

module.exports = { discountPrice, addShipping, finalPrice };
205

(1) discountPrice הדפיסה במקום להחזיר. (2) addShipping חישבה בתוך { } בלי return. (3) ב־finalPrice, return עמד לבד בשורה — JavaScript מוסיפה ; אוטומטית, והפונקציה החזירה undefined.

⚠️ טעויות נפוצות
  • לתקן רק את מה שהבודק מראה ראשון ולא להריץ שוב.

function minutesToText(totalMinutes) {

P05-E36 · אגורות ושקלים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

toAgorot: כפל ב־100, ואז עיגול לשלם הקרוב. agorotToText: שקלים עם Math.floor, אגורות עם % ו־padStart (כמו P02-E26).

💡 רמז 2

return Math.round(shekels * 100);

✅ פתרון
05-functions/starter/P05-E36.js 
function toAgorot(shekels) {
  return Math.round(shekels * 100);
}

function agorotToText(agorot) {
  const shekels = Math.floor(agorot / 100);
  const rest = `${agorot % 100}`.padStart(2, "0");
  return `${shekels}.${rest} ₪`;
}

console.log(toAgorot(0.29), agorotToText(toAgorot(19.99)));

module.exports = { toAgorot, agorotToText };
29 19.99 ₪

שים לב לשורת ההדגמה: agorotToText(toAgorot(19.99)) — התוצאה של פונקציה אחת נכנסת ישר כארגומנט לשנייה.

⚠️ טעויות נפוצות
  • Math.floor(shekels * 100) — 0.29 הופך ל־28 אגורות.
  • `${agorot / 100} ₪` — 5 הופך ל־"0.05 ₪" במקרה, אבל 1230 הופך ל־"12.3 ₪".

P05-E37 · פונקציה בתוך לולאה 🧠 הבנה רמה 2

    s += "*";

console.log(stars(0) === "", stars(4).length);

true 4

הלולאה הפנימית רצה 1 + 2 + 3 + 0 + 4 = 10 פעמים. כל קריאה ל־stars מתחילה עם s ריק משלה — כי הוא נוצר בתוך הפונקציה.

function gradeText(score) {
  if (score < 0 || score > 100) {
    return "ציון לא חוקי";
  }
  if (score >= 90) {
    return "מצוין";
  }
  if (score >= 80) {
    return "טוב מאוד";
  }
  if (score >= 65) {
    return "טוב";
  }
  if (score >= 55) {
    return "עובר";
  }
  return "נכשל";
}

console.log(gradeText(82), gradeText(101));

module.exports = { gradeText };

function repeatText(text, times, separator) {
  let result = "";
  for (let i = 0; i < times; i++) {
    if (i > 0) {
      result += separator;
    }
    result += text;
  }
  return result;
}

console.log(`[${repeatText("ab", 3, "-")}]`, `[${repeatText("x", 0, ",")}]`);

module.exports = { repeatText };
