שיעור 2 — return לעומק, ברירות מחדל ו־guard clauses

⏱ ~30 דקות

🎯 בשיעור הזה
  • פונקציות שמחזירות בוליאני — "שאלות".
  • פרמטרים עם ערך ברירת מחדל.
  • guard clauses: לטפל במקרים הרעים קודם, ולצאת מוקדם.
  • פונקציה שקוראת לפונקציה.

1. פונקציות־שאלה

פונקציה שמחזירה true/false נקראת כמו שאלה (isX, hasX, canX), ואז הקוד שמשתמש בה נקרא כמו אנגלית:

function isValidEmail(email) {
  return email.includes("@") && email.includes(".");
}

function canCheckout(itemsCount, isLoggedIn) {
  return itemsCount > 0 && isLoggedIn;
}

console.log(isValidEmail("dana@mail.com"));
console.log(isValidEmail("dana-mail.com"));
if (canCheckout(3, true)) {
  console.log("מעבר לתשלום");
}
true
false
מעבר לתשלום

שים לב: לא כתבנו if (...) { return true; } else { return false; }. ההשוואה עצמה כבר מחזירה בוליאני — מחזירים אותה ישר.

2. ערך ברירת מחדל

function formatPrice(amount, currency = "₪", decimals = 2) {
  return `${currency}${amount.toFixed(decimals)}`;
}

console.log(formatPrice(19.9));
console.log(formatPrice(19.9, "$"));
console.log(formatPrice(19.9, "€", 0));
₪19.90
$19.90
€20

אם הארגומנט לא הועבר (או הועבר undefined) — הפרמטר מקבל את ברירת המחדל. מקובל לשים פרמטרים עם ברירת מחדל בסוף הרשימה.

3. Guard clauses — יציאה מוקדמת

זוכר את בדיקת הכמות מפרק 3? שרשרת if / else if ארוכה. בתוך פונקציה יש דרך נקייה יותר: כל מקרה רע מחזיר מיד, וכשמגיעים לסוף — הכול תקין.

function validateQuantity(input) {
  if (input.trim() === "") {
    return "חובה להזין כמות";
  }
  const quantity = Number(input);
  if (Number.isNaN(quantity)) {
    return "הכמות חייבת להיות מספר";
  }
  if (!Number.isInteger(quantity) || quantity < 1) {
    return "הכמות חייבת להיות מספר שלם חיובי";
  }
  if (quantity > 10) {
    return "אפשר להזמין עד 10 יחידות";
  }
  return null;
}

console.log(validateQuantity(""));
console.log(validateQuantity("abc"));
console.log(validateQuantity("2.5"));
console.log(validateQuantity("3"));
חובה להזין כמות
הכמות חייבת להיות מספר
הכמות חייבת להיות מספר שלם חיובי
null

שים לב לבחירה: הפונקציה מחזירה הודעת שגיאה אם יש בעיה, ו־null אם הכול תקין. כך מי שקורא יכול לכתוב const error = validateQuantity(x); if (error !== null) {...}. בפרק 8 נלמד דרך מקובלת יותר לדווח על שגיאות (throw).

4. פונקציה שקוראת לפונקציה

פונקציות קטנות מתחברות לגדולות. כל אחת עושה דבר אחד:

function capitalize(word) {
  return word[0].toUpperCase() + word.slice(1).toLowerCase();
}

function formatFullName(first, last) {
  return `${capitalize(first)} ${capitalize(last)}`;
}

function initials(first, last) {
  return `${capitalize(first)[0]}.${capitalize(last)[0]}.`;
}

console.log(formatFullName("dANA", "levi"));
console.log(initials("dana", "levi"));
Dana Levi
D.L.

זה התרגיל מפרק 2 (P02-E09) — עכשיו בלי שום שכפול. ואם נגלה באג ב־capitalize (למשל, מה קורה עם מחרוזת ריקה?) — מתקנים במקום אחד, וכל מי שמשתמש בה מתוקן.

💼 בעולם העבודה

ב־code review תשמע "תעשה early return" כמעט בכל PR של מתחילים. ו"פונקציה עושה דבר אחד" היא העיקרון הראשון של קוד נקי — אם קשה לתת לפונקציה שם בלי המילה "ו" (validateAndSaveAndEmail), כנראה שהיא צריכה להתפצל.
