P24-E06 · logger של JSON 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 1

בקובץ 24-production/starter/P24-E06.ts כתוב createLogger({ level, sink, clock, base }):

  • מחזיר אובייקט עם debug, info, warn, error — כל אחת (msg, fields?).
  • כל קריאה ← קריאה אחת ל־sink עם מחרוזת JSON בשורה אחת: { ...base, ...fields, time, level, msg }. time — clock().toISOString().
  • שדות בשם time/level/msg ב־fields לא דורסים את האמיתיים.
  • רמה: ברירת מחדל info. מתחת לרמה — לא נכתב.
  • child(fields) ← logger חדש עם אותן הגדרות, ו־base מורחב.
  • ברירות מחדל: sink ← process.stdout.write(line + "\n"), clock ← new Date().

P24-E44 · ‏error handler עם requestId 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 15, שיעור 1

בקובץ 24-production/starter/P24-E44.ts (יש בו רק הערה) כתוב וייצא error middleware של Express:

export type Log = (level: "warn" | "error", msg: string, fields: Record<string, unknown>) => void;
export function errorHandler(log: Log): (err: unknown, req: Request, res: Response, next: NextFunction) => void
  • requestId — מ־res.locals.requestId (או null אם אין).
  • שגיאה עם status מספרי בין 400 ל־499 (למשל JSON שבור — ‏express.json() זורק שגיאה עם status: 400) ← התשובה באותו status, עם הגוף והלוג שלמטה (‏message בלוג — של השגיאה).
  • כל שגיאה אחרת ← 500, עם הגוף והלוג שלמטה. ההודעה המקורית לא נשלחת ללקוח.
  • אם התשובה כבר התחילה (res.headersSent) ← next(err) ולא נוגעים בה.
// 4xx
{ error: { code: "BAD_REQUEST", message: "בקשה לא תקינה", requestId } }
log("warn", "client error", { requestId, status, message })
// כל השאר — 500
{ error: { code: "INTERNAL", message: "שגיאה בשרת", requestId } }
log("error", "unhandled error", { requestId, err: { name, message, stack } })

  • url הוא req.originalUrl — נתיב עם query אופציונלי: "/reset?token=abc&lang=he".
  • מחזיר נתיב + query, שבו הערך של כל פרמטר ששמו ב־secretParams (בלי תלות באותיות גדולות) הוא ***. ברירת מחדל: ["token", "password", "code", "key", "secret"].
  • שאר הפרמטרים — כמו שהם, באותו סדר. בלי query ← הנתיב בלבד (בלי ?). ‏# ומה שאחריו — נעלם.
  • הקידוד — כמו של URLSearchParams: ‏/search?q=a b ← /search?q=a+b.
