P24-E06 · logger של JSON 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 1

בקובץ 24-production/starter/P24-E06.ts כתוב createLogger({ level, sink, clock, base }):

  • מחזיר אובייקט עם debug, info, warn, error — כל אחת (msg, fields?).
  • כל קריאה ← קריאה אחת ל־sink עם מחרוזת JSON בשורה אחת: { ...base, ...fields, time, level, msg }. time — clock().toISOString().
  • שדות בשם time/level/msg ב־fields לא דורסים את האמיתיים.
  • רמה: ברירת מחדל info. מתחת לרמה — לא נכתב.
  • child(fields) ← logger חדש עם אותן הגדרות, ו־base מורחב.
  • ברירות מחדל: sink ← process.stdout.write(line + "\n"), clock ← new Date().

P24-E07 · redact 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

בקובץ P24-E07.ts כתוב redact(value, keys?) שמחזיר עותק בלי סודות:

  • כל מפתח שנמצא ב־keys (בלי תלות באותיות גדולות/קטנות), בכל עומק — כולל בתוך מערכים — ← "[REDACTED]".
  • מחרוזת שהיא כולה Bearer <משהו> ← "Bearer [REDACTED]", בכל מפתח.
  • Date ← toISOString(). מעגל (אובייקט שמכיל את עצמו) ← "[Circular]". אותו אובייקט פעמיים בלי מעגל — מופיע פעמיים כרגיל.
  • המקור לא משתנה.

P24-E08 · X-Request-Id 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

בקובץ P24-E08.ts כתוב middleware של Express, requestId({ generate }):

  • אם הגיע header X-Request-Id תקין (/^[A-Za-z0-9._-]{1,64}$/) — משתמשים בו. אחרת — generate() (ברירת מחדל: randomUUID).
  • שומר ב־res.locals.requestId, ומחזיר ב־header X-Request-Id של התשובה — גם כשהבקשה נגמרת בשגיאה.

P24-E09 · שורת לוג לכל בקשה 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 1

בקובץ P24-E09.ts כתוב requestLogger({ log, now, skip }): כשבקשה מסתיימת, קריאה אחת ל־log(level, "request", fields):

  • fields: method, path (בלי query), status, durationMs (מעוגל), ו־requestId — רק אם יש ב־res.locals.requestId.
  • רמה: 5xx ← error, 4xx ← warn, השאר ← info.
  • now — שעון (מילישניות), ברירת מחדל performance.now(). נקרא בתחילת הבקשה ובסופה.
  • skip — רשימת נתיבים שלא כותבים כשהם מצליחים (< 400).

P24-E10 · הקשר של בקשה עם AsyncLocalStorage 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 1

בקובץ P24-E10.ts, עם AsyncLocalStorage:

  • runWithContext(ctx, fn) — מריץ את fn עם עותק של ctx כהקשר; מחזיר את מה שהיא מחזירה.
  • getContext() — ההקשר הנוכחי, או undefined.
  • setUser(userId) — מוסיף userId להקשר הנוכחי. מחוץ להקשר ← Error("אין הקשר של בקשה").
  • logLine(msg, fields) ← JSON.stringify({ msg, ...context, ...fields }).

הבודק מריץ שלוש "בקשות" במקביל עם await ו־setTimeout — ובודק שהן לא מתערבבות.
