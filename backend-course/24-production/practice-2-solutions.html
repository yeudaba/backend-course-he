P24-E47 · ‏+02:00 או Asia/Jerusalem? 🧠 הבנה רמה 2

💡 רמז 1

‏+02:00 הוא תשובה לשאלה "מה ההפרש עכשיו". הוא לא יודע מה יהיה ההפרש בעוד חצי שנה.

💡 רמז 2

מאיפה Node יודע את חוקי שעון הקיץ של ישראל?

✅ פתרון
  1. ביולי ההפרש האמיתי הוא +03:00. השרת מחשב 08:00 לפי +02:00 = ‏06:00Z — ובישראל זה 09:00. התזכורת מאחרת בשעה, כל הקיץ.
  2. הפוך: 08:00 לפי +03:00 = ‏05:00Z — ובדצמבר זה 07:00. שעה מוקדם.
  3. כלום בקוד. החוקים נמצאים במסד הנתונים של IANA, שמגיע עם Node (ועם מערכת ההפעלה). מעדכנים Node (או את ה־image) — והחישוב של "08:00 ב־Asia/Jerusalem" משתנה לבד. בגלל זה שומרים את שם האזור.

(שים לב: ב־Node 24, ‏"+02:00" הוא timeZone חוקי ל־Intl — אזור עם הפרש קבוע. לכן "הוא עבר בדיקת תקינות" לא אומר שהוא מה שרצית.)

⚠️ טעויות נפוצות
  • לשמור את ה־offset "בשביל ביצועים" — החישוב עם שם אזור זול, והבאג עולה כל חצי שנה.

// P24-E11
export function isValidTimeZone(tz: string): boolean {
  if (typeof tz !== "string" || tz === "") return false;
  try {
    new Intl.DateTimeFormat("en", { timeZone: tz }); // אזור לא קיים ← RangeError
    return true;
  } catch {
    return false;
  }
}

// en-CA כותב תאריכים כ־YYYY-MM-DD; hourCycle h23 — 00–23 (בלי "24:00" בחצות)
export function localDate(instant: Date, tz: string): string {
  return new Intl.DateTimeFormat("en-CA", { timeZone: tz, year: "numeric", month: "2-digit", day: "2-digit" }).format(instant);
}

export function localTime(instant: Date, tz: string): string {
  return new Intl.DateTimeFormat("en-GB", { timeZone: tz, hour: "2-digit", minute: "2-digit", hourCycle: "h23" }).format(instant);
}

P24-E12 · חצות בישראל — באיזו שעה ב־UTC? 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

offsetMinutes: מפרקים את הרגע לחלקים באזור (formatToParts), בונים מהם Date.UTC(...) "כאילו" הם UTC, ומחסרים את הרגע האמיתי.

💡 רמז 2

zonedTimeToUtc: יש רק שני offsets אפשריים סביב היום הזה — זה של אתמול וזה של מחר. לכל אחד: מועמד = wall − offset. מועמד "נכון" אם השעה המקומית שלו היא באמת השעה המבוקשת. אף אחד לא נכון ← השעה לא קיימת.

✅ פתרון
// P24-E12
const MIN = 60_000;

// ההפרש (בדקות) בין השעה המקומית ל־UTC ברגע מסוים: ישראל בחורף 120, בקיץ 180
export function offsetMinutes(instant: Date, tz: string): number {
  const p = Object.fromEntries(
    new Intl.DateTimeFormat("en-US", { timeZone: tz, hourCycle: "h23", year: "numeric", month: "numeric", day: "numeric", hour: "numeric", minute: "numeric" })
      .formatToParts(instant)
      .map((x) => [x.type, Number(x.value)]),
  );
  const asIfUtc = Date.UTC(p.year, p.month - 1, p.day, p.hour, p.minute);
  return Math.round((asIfUtc - Math.floor(instant.getTime() / MIN) * MIN) / MIN);
}

// "2026-03-27" + "09:00" בישראל ← הרגע ב־UTC
export function zonedTimeToUtc(date: string, time: string, tz: string): Date {
  const [y, mo, d] = date.split("-").map(Number);
  const [h, mi] = time.split(":").map(Number);
  const wall = Date.UTC(y, mo - 1, d, h, mi); // השעה על השעון, "כאילו" ב־UTC
  // שני ה־offsets האפשריים סביב אותו יום (לפני ואחרי מעבר שעון)
  const before = offsetMinutes(new Date(wall - 86_400_000), tz);
  const after = offsetMinutes(new Date(wall + 86_400_000), tz);
  const matches = [before, after]
    .map((o) => wall - o * MIN)
    .filter((t) => offsetMinutes(new Date(t), tz) * MIN + t === wall)
    .sort((a, b) => a - b);
  if (matches.length > 0) return new Date(matches[0]); // שעה כפולה (חזרה לשעון חורף) ← המופע הראשון
  return new Date(wall - before * MIN); // שעה שלא קיימת (מעבר לשעון קיץ) ← "קופצים" קדימה, כמו השעון
}

export function startOfDayInZone(date: string, tz: string): Date {
  return zonedTimeToUtc(date, "00:00", tz);
}

// טווח של יום מקומי, לשאילתה: start <= created_at < end
export function dayRangeInZone(date: string, tz: string): { start: Date; end: Date } {
  const [y, m, d] = date.split("-").map(Number);
  const next = new Date(Date.UTC(y, m - 1, d + 1)).toISOString().slice(0, 10);
  return { start: startOfDayInZone(date, tz), end: startOfDayInZone(next, tz) };
}

בשביל מה dayRangeInZone? "כמה משימות נוצרו היום" במסד: WHERE created_at >= $start AND created_at < $end. ב־DATE(created_at) של PostgreSQL — היום לפי UTC (או לפי ה־timezone של החיבור), לא של המשתמש.

⚠️ טעויות נפוצות
  • end = start + 24 שעות — ביום המעבר תפספס שעה, או תספור שעה מהיום הבא.
  • לחשב offset פעם אחת ("ישראל = +2") ולשמור. בקיץ הוא +3.
💡 Temporal

החישובים האלה הם בדיוק מה ש־Temporal — ה־API החדש של JavaScript לתאריכים — עושה מובנה: Temporal.PlainDate.from("2026-03-27").toZonedDateTime("Asia/Jerusalem"). הוא נכנס לדפדפנים ול־Node בשלבים; עד שתוכל להסתמך עליו בכל מקום — זה המנגנון, וכדאי להבין אותו.

P24-E13 · חשבון ימים לפי לוח השנה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

Date.UTC(y, m - 1, d + days, h, mi) — Date.UTC יודע לגלגל ימים לחודש הבא ולשנה הבאה.

💡 רמז 2

daysUntil: הפרש בין Date.UTC של שני התאריכים (בלי שעות), חלקי 86,400,000. ב־UTC אין שעון קיץ — לכן זה תמיד מספר שלם.

✅ פתרון
// P24-E13
const MIN = 60_000;
const DAY = 86_400_000;

function parts(instant: Date, tz: string) {
  const p = Object.fromEntries(
    new Intl.DateTimeFormat("en-US", { timeZone: tz, hourCycle: "h23", year: "numeric", month: "numeric", day: "numeric", hour: "numeric", minute: "numeric" })
      .formatToParts(instant)
      .map((x) => [x.type, Number(x.value)]),
  );
  return { y: p.year, m: p.month, d: p.day, h: p.hour, mi: p.minute };
}

const offset = (t: number, tz: string) => {
  const p = parts(new Date(t), tz);
  return (Date.UTC(p.y, p.m - 1, p.d, p.h, p.mi) - Math.floor(t / MIN) * MIN) / MIN;
};

// מ־E12: שעה על השעון באזור ← רגע (שעה שלא קיימת ← קדימה; כפולה ← הראשונה)
function wallToUtc(wall: number, tz: string): number {
  const before = offset(wall - DAY, tz);
  const after = offset(wall + DAY, tz);
  const ok = [before, after].map((o) => wall - o * MIN).filter((t) => offset(t, tz) * MIN + t === wall).sort((a, b) => a - b);
  return ok.length ? ok[0] : wall - before * MIN;
}

// "אותה שעה, בעוד N ימים" — לא N*24 שעות: ביום מעבר שעון זה לא אותו דבר
export function addLocalDays(instant: Date, days: number, tz: string): Date {
  const p = parts(instant, tz);
  return new Date(wallToUtc(Date.UTC(p.y, p.m - 1, p.d + days, p.h, p.mi), tz));
}

export function isSameLocalDay(a: Date, b: Date, tz: string): boolean {
  const x = parts(a, tz);
  const y = parts(b, tz);
  return x.y === y.y && x.m === y.m && x.d === y.d;
}

// כמה ימים (בלוח השנה של המשתמש) עד dueDate: 0 = היום, 1 = מחר, שלילי = עבר
export function daysUntil(dueDate: string, now: Date, tz: string): number {
  const [y, m, d] = dueDate.split("-").map(Number);
  const p = parts(now, tz);
  return Math.round((Date.UTC(y, m - 1, d) - Date.UTC(p.y, p.m - 1, p.d)) / DAY);
}
⚠️ טעויות נפוצות
  • Math.floor((due - now) / DAY) על רגעים — ב־23:59 "מחר" הוא 0 ימים.

✅ פתרון

  return new Intl.DateTimeFormat("en-CA", { timeZone: tz, year: "numeric", month: "2-digit", day: "2-digit" }).format(now);
}

// תקלה 2: יום ≠ 24 שעות. ביום המעבר לשעון קיץ +24 שעות נותן 10:00 במקום 09:00
export function tomorrowSameTime(instant: Date, tz: string): Date {
  const p = parts(instant, tz);
  const wall = Date.UTC(p.y, p.m - 1, p.d + 1, p.h, p.mi);
  const before = offset(wall - DAY, tz);
  const after = offset(wall + DAY, tz);
  const ok = [before, after].map((o) => wall - o * MIN).filter((t) => offset(t, tz) * MIN + t === wall).sort((a, b) => a - b);
  return new Date(ok.length ? ok[0] : wall - before * MIN);
}

// P24-E25
const MIN = 60_000;
const DAY = 86_400_000;

export interface Schedule {
  hour: number;
  minute: number;
  days?: number[]; // 0 = ראשון … 6 = שבת. בלי — כל יום
}

function parts(instant: Date, tz: string) {
  const p = Object.fromEntries(
    new Intl.DateTimeFormat("en-US", { timeZone: tz, hourCycle: "h23", year: "numeric", month: "numeric", day: "numeric", hour: "numeric", minute: "numeric" })
      .formatToParts(instant)
      .map((x) => [x.type, Number(x.value)]),
  );
  return { y: p.year, m: p.month, d: p.day, h: p.hour, mi: p.minute };
}
const offset = (t: number, tz: string) => {
  const p = parts(new Date(t), tz);
  return (Date.UTC(p.y, p.m - 1, p.d, p.h, p.mi) - Math.floor(t / MIN) * MIN) / MIN;
};
function wallToUtc(wall: number, tz: string): number {
  const before = offset(wall - DAY, tz);
  const after = offset(wall + DAY, tz);
  const ok = [before, after].map((o) => wall - o * MIN).filter((t) => offset(t, tz) * MIN + t === wall).sort((a, b) => a - b);
  return ok.length ? ok[0] : wall - before * MIN;
}

function validate({ hour, minute, days }: Schedule) {
  if (!Number.isInteger(hour) || hour < 0 || hour > 23) throw new RangeError("hour: 0–23");
  if (!Number.isInteger(minute) || minute < 0 || minute > 59) throw new RangeError("minute: 0–59");
  if (days && (days.length === 0 || days.some((d) => !Number.isInteger(d) || d < 0 || d > 6))) throw new RangeError("days: 0–6, לפחות יום אחד");
}

// הריצה הבאה — אחרי after (לא כולל). עוברים על ימים בלוח השנה *המקומי*, לא על 24 שעות
export function nextRun(schedule: Schedule, after: Date, tz: string): Date {
  validate(schedule);
  const start = parts(after, tz);
  for (let i = 0; i <= 7; i++) {
    const wall = Date.UTC(start.y, start.m - 1, start.d + i, schedule.hour, schedule.minute);
    const weekday = new Date(Date.UTC(start.y, start.m - 1, start.d + i)).getUTCDay();
    if (schedule.days && !schedule.days.includes(weekday)) continue;
    // שעה שלא קיימת (שעון קיץ) ← קדימה; שעה כפולה (חורף) ← רק המופע הראשון, פעם אחת
    const t = wallToUtc(wall, tz);
    if (t > after.getTime()) return new Date(t);
  }
  throw new Error("לא אמור לקרות"); // תוך 8 ימים תמיד יש התאמה
}

export function upcoming(schedule: Schedule, after: Date, tz: string, count: number): Date[] {
  const out: Date[] = [];
  let cursor = after;
  while (out.length < count) {
    cursor = nextRun(schedule, cursor, tz);
    out.push(cursor);
  }
  return out;
}

⚠️ טעויות נפוצות
  • next = last + 24h — זז בשעה פעמיים בשנה.
  • לבדוק "יום שישי" עם getUTCDay() על הרגע — ב־00:15 בישראל ביום חמישי, ב־UTC עדיין רביעי.

// P24-E52: גיל לפי תאריך לידה
function parse(s: string): [number, number, number] {
  const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(s);
  if (!m) throw new RangeError(`תאריך לא תקין: ${s}`);
  const [y, mo, d] = [+m[1], +m[2], +m[3]];
  const check = new Date(Date.UTC(y, mo - 1, d));
  if (check.getUTCFullYear() !== y || check.getUTCMonth() !== mo - 1 || check.getUTCDate() !== d) throw new RangeError(`תאריך לא קיים: ${s}`);
  return [y, mo, d];
}

export function ageOn(birthDate: string, today: string): number {
  const [by, bm, bd] = parse(birthDate);
  const [ty, tm, td] = parse(today);
  if (birthDate > today) throw new RangeError("תאריך הלידה אחרי היום");
  const beforeBirthday = tm < bm || (tm === bm && td < bd); // 28.2 < 29.2, ו־1.3 כבר אחרי
  return ty - by - (beforeBirthday ? 1 : 0);
}

export function ageAt(birthDate: string, instant: Date, tz: string): number {
  const today = new Intl.DateTimeFormat("en-CA", { timeZone: tz, year: "numeric", month: "2-digit", day: "2-digit" }).format(instant);
  return ageOn(birthDate, today);
}

    if (!weekend.includes(d.getUTCDay())) count++;
  }
  return count;
}

import { z } from "zod";

function isValidTimeZone(tz: string): boolean {
  if (tz === "") return false;
  try {
    new Intl.DateTimeFormat("en", { timeZone: tz });

  } catch {
    return false;
  }
}

// P24-E59: GET /today ב־Express
import { Router } from "express";

export function todayRouter({ now = () => new Date() }: { now?: () => Date } = {}) {
  const router = Router();
  router.get("/today", (req, res) => {
    const raw = req.query.tz === undefined ? "UTC" : req.query.tz;
    let tz: string;
    try {
      if (typeof raw !== "string" || raw === "") throw new RangeError("empty");
      tz = new Intl.DateTimeFormat("en", { timeZone: raw }).resolvedOptions().timeZone;
    } catch {
      res.status(400).json({ error: { code: "INVALID_TIME_ZONE", message: `אזור זמן לא מוכר: ${String(raw)}` } });
      return;
    }
    const at = now();
    const date = new Intl.DateTimeFormat("en-CA", { timeZone: tz, year: "numeric", month: "2-digit", day: "2-digit" }).format(at);
    const time = new Intl.DateTimeFormat("en-GB", { timeZone: tz, hour: "2-digit", minute: "2-digit", hourCycle: "h23" }).format(at);
    res.json({ tz, date, time });
  });
  return router;
}
⚠️ טעויות נפוצות
  • להחזיר את req.query.tz כמו שהוא — ואז "asia/jerusalem" ו־"Asia/Jerusalem" הם שני ערכים שונים בכל מקום שמשווה אותם.
