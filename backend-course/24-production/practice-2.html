P24-E03 · חידון אזורי זמן

מה ידפיס כל קטע? נסה לענות לפני שמריצים.

const at = new Date("2026-11-04T22:30:00Z");
const day = (tz) => new Intl.DateTimeFormat("en-CA", { timeZone: tz, dateStyle: "short" }).format(at);
console.log(day("UTC"), day("Asia/Jerusalem"), day("America/Los_Angeles"));

console.log(new Date("2026-11-05").toISOString());

const tz = (s, zone) => new Intl.DateTimeFormat("en-GB", { timeZone: zone, timeStyle: "short" }).format(new Date(s));
console.log(tz("2026-03-27T00:30:00Z", "Asia/Jerusalem"), tz("2026-03-26T23:30:00Z", "Asia/Jerusalem"));

console.log((new Date("2026-03-28T00:00:00+03:00") - new Date("2026-03-27T00:00:00+02:00")) / 3600000);

P24-E11 · תאריך מקומי 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ P24-E11.ts:

  • isValidTimeZone(tz) — true לאזור IANA קיים ("Asia/Jerusalem", "UTC"), false לכל דבר אחר, כולל מחרוזת ריקה.
  • localDate(instant, tz) ← "YYYY-MM-DD" באזור.
  • localTime(instant, tz) ← "HH:mm" (00–23).
  • isPastInZone(date, now, tz) — האם התאריך "YYYY-MM-DD" לפני "היום" באזור.

P24-E12 · חצות בישראל — באיזו שעה ב־UTC? 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 25 דק׳ידע נדרש: שיעור 2

הכיוון ההפוך: מתאריך ושעה מקומיים לרגע. בקובץ P24-E12.ts:

  • offsetMinutes(instant, tz) — ההפרש בדקות בין השעון באזור ל־UTC באותו רגע (ישראל: 120 בחורף, 180 בקיץ; ניו יורק בקיץ: −240).
  • zonedTimeToUtc(date, time, tz) — ("2026-11-05", "09:00", "Asia/Jerusalem") ← 2026-11-05T07:00:00.000Z. שעה שלא קיימת (קפיצה לשעון קיץ) ← קדימה, כמו השעון (02:30 ← 03:30). שעה כפולה (חזרה לחורף) ← המופע הראשון.
  • startOfDayInZone(date, tz) ו־dayRangeInZone(date, tz) ← { start, end }, כש־end הוא תחילת היום הבא (ביום מעבר — 23 או 25 שעות).

P24-E13 · חשבון ימים לפי לוח השנה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 2

בקובץ P24-E13.ts (הקובץ עצמאי — מותר להעתיק את הפונקציות מ־E12):

  • addLocalDays(instant, days, tz) — אותה שעה על השעון, בעוד days ימים (גם שלילי). 09:00 ב־26.3 ← 09:00 ב־27.3, למרות שעברו רק 23 שעות.
  • isSameLocalDay(a, b, tz).
  • daysUntil(dueDate, now, tz) — כמה ימים בלוח השנה עד התאריך: 0 = היום, 1 = מחר, שלילי = עבר.

P24-E25 · אתגר: מתי התזכורת הבאה? 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 60 דק׳ידע נדרש: שיעור 2

בקובץ P24-E25.ts: nextRun({ hour, minute, days }, after, tz) ← הרגע הבא (אחרי after, לא כולל) שבו השעון באזור מראה hour:minute, ביום מותר (days: 0 = ראשון … 6 = שבת; בלי — כל יום). ו־upcoming(schedule, after, tz, count) ← מערך של הריצות הבאות.

  • "היום" ו"יום בשבוע" — לפי האזור, לא לפי UTC.
  • שעה שלא קיימת ← קדימה (02:30 ב־27.3 בישראל ← 03:30). שעה כפולה ← פעם אחת, במופע הראשון.
  • hour 0–23, minute 0–59, שלמים; days לא ריק, 0–6 ← אחרת RangeError.
