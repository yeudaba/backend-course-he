P24-E31 · דוח latency מלוגים של JSON 🤖 ✍️ מאפס רמה 3

💡 רמז 1

path.split("?")[0].replace(/\/\d+(?=\/|$)/g, "/:id"). ‏(?=\/|$) אומר "ואחרי הספרות בא / או סוף" — בלי זה, /v2beta או /123abc היו נפגעים. ב־routeReport: ‏try { entry = JSON.parse(line) } catch { skipped++; continue; }.

💡 רמז 2

Map<string, { ms: number[]; errors: number }>, ואחר כך [...map].map(([route, s]) => ...). לאחוזון: const sorted = [...s.ms].sort((a, b) => a - b); sorted[Math.ceil(sorted.length * 0.95) - 1]. ‏sort() בלי פונקציה ממיין מספרים כטקסט (‏100 לפני 9).

✅ פתרון
// P24-E31 — דוח latency מלוגים של JSON
export type RouteStats = { route: string; count: number; errorPct: number; p95: number };

export function routeOf(method: string, path: string): string {
  const clean = path.split("?")[0].replace(/\/\d+(?=\/|$)/g, "/:id");
  return `${method.toUpperCase()} ${clean}`;
}

function p95(sorted: number[]): number {
  return sorted[Math.ceil(sorted.length * 0.95) - 1];
}

export function routeReport(lines: string[]): { routes: RouteStats[]; skipped: number } {
  const byRoute = new Map<string, { ms: number[]; errors: number }>();
  let skipped = 0;
  for (const line of lines) {
    let entry;
    try {
      entry = JSON.parse(line);
    } catch {
      skipped++;
      continue;
    }
    if (entry?.msg !== "request" || typeof entry.ms !== "number") {
      skipped++;
      continue;
    }
    const route = routeOf(entry.method, entry.path);
    const stats = byRoute.get(route) ?? { ms: [], errors: 0 };
    stats.ms.push(entry.ms);
    if (entry.status >= 500) stats.errors++;
    byRoute.set(route, stats);
  }

  const routes = [...byRoute].map(([route, { ms, errors }]) => ({
    route,
    count: ms.length,
    errorPct: Math.round((errors / ms.length) * 1000) / 10,
    p95: p95([...ms].sort((a, b) => a - b)),
  }));
  routes.sort((a, b) => b.p95 - a.p95 || a.route.localeCompare(b.route));
  return { routes, skipped };
}

⚠️ טעויות נפוצות

  • Math.round(0.95 * n) במקום Math.ceil(...) - 1 — עם 2 ערכים זה האינדקס 2, שלא קיים, וה־p95 יוצא undefined.
  • /\d+/g בלי עוגנים — /v2/users הופך ל־/v:id/users.

P24-E32 · בדיקות ל־Retry-After 🤖 🔁 חזרה רמה 3

💡 רמז 1

קבע "עכשיו" קבוע אחד: const NOW = new Date("2026-10-21T07:27:00Z"). אז דקה אחרי זה, "Wed, 21 Oct 2026 07:28:00 GMT", צריך לתת בדיוק 60_000. בדיקה שקוראת לפונקציה בלי now תלויה בשעה שבה היא רצה — אל תעשה את זה.

💡 רמז 2

לקלט לא תקין: טבלה ולולאה (‏P22-E17), ובהודעה JSON.stringify(bad) כדי לראות מה נכשל. חשוב על מה ש־Number() ו־Date.parse() "מקבלים בטעות": ‏Number("") הוא 0, ו־Date.parse("1.5") הוא תאריך בשנת 2001.

✅ פתרון

כל בדיקה כאן סוגרת באג אחד או יותר. ‏"0" תופס regex שדורש ספרה ראשונה שאינה 0. ‏" 30 " תופס מימוש בלי trim. התאריך שעבר תופס מימוש בלי Math.max. ו־NOW קבוע תופס מימוש שמתעלם מ־now וקורא ל־Date.now(): אצלו התשובה היא 0, כי 21 באוקטובר כבר עבר.

הקלטים הכי חשובים הם אלה שנראים "כמעט תקינים": ‏"", ‏"1.5", ‏"2026-10-21". מימוש עם Number(v) מחזיר על "" אפס, כלומר "נסה מיד". מימוש עם Date.parse בלבד מקבל את "1.5" כתאריך. בשני המקרים לקוח שמכבד את ה־header היה מציף את השרת שביקש ממנו לחכות.

⚠️ טעויות נפוצות
  • לבדוק רק את הדוגמה מהמשימה ("120") — רוב הבאגים כאן הם בקלט הלא תקין ובגבולות.
  • assert.ok(parseRetryAfter("abc") == null) — עובר גם על undefined. ‏assert.equal(..., null) מדויק.
  • להשוות תאריכים בלי now קבוע — הבדיקה עוברת היום ונכשלת מחר.

P24-E33 · התראה על שיעור שגיאות 🤖 🔁 חזרה רמה 2

💡 רמז 1

שדה #events: { at: number; error: boolean }[]. הבקשות נכנסות לפי סדר הזמן, ולכן הישנות תמיד בהתחלה: while (this.#events.length > 0 && this.#events[0].at <= from) this.#events.shift();.

💡 רמז 2

קרא ל־#prune() בתחילת שני ה־getters. ‏shouldAlert משתמש בהם: this.count >= ... && this.errorRate >= .... לבדיקת threshold: ‏!(t > 0 && t <= 1) תופס גם NaN, ו־t <= 0 || t > 1 לא.

✅ פתרון
// P24-E33 — התראה על שיעור שגיאות בחלון זמן
type Options = { windowMs: number; threshold: number; minRequests: number };

export class ErrorRateAlarm {
  #events: { at: number; error: boolean }[] = [];
  #options: Options;
  #now: () => number;

  constructor(options: Options, now: () => number = () => Date.now()) {
    if (!(options.threshold > 0 && options.threshold <= 1)) throw new RangeError("threshold חייב להיות בין 0 ל־1");
    this.#options = options;
    this.#now = now;
  }

  #prune(): void {
    const from = this.#now() - this.#options.windowMs;
    while (this.#events.length > 0 && this.#events[0].at <= from) this.#events.shift();
  }

  record(status: number): void {
    this.#events.push({ at: this.#now(), error: status >= 500 });
  }

  get count(): number {
    this.#prune();
    return this.#events.length;
  }

  get errorRate(): number {
    this.#prune();
    if (this.#events.length === 0) return 0;
    const errors = this.#events.filter((e) => e.error).length;
    return errors / this.#events.length;
  }

  shouldAlert(): boolean {
    return this.count >= this.#options.minRequests && this.errorRate >= this.#options.threshold;
  }
}

זה מה ש־Prometheus עושה בכלל של התראה: ‏rate(errors[1m]) / rate(requests[1m]) > 0.1, עם תנאי על הנפח. ההבדל: שם החלון מחושב ממונים (שיעור 6), וכאן שומרים כל בקשה. כך אפשר לראות את הלוגיקה, אבל בשרת עמוס מערך כזה גדל מהר. לכן ‏#prune מוחק, ולא רק מסנן.

⚠️ טעויות נפוצות
  • filter על כל המערך בכל קריאה במקום מחיקה — נכון בתוצאה, אבל הזיכרון גדל עם כל בקשה לנצח.
  • at < from במקום <= — בקשה בדיוק לפני דקה עדיין נספרת.
  • חלוקה באפס כשאין בקשות — errorRate יוצא NaN, ו־NaN >= 0.1 הוא false בשקט.
  • count() כמתודה במקום get count().

P24-E01 · מה כותבים ללוג, ובאיזו רמה? רמה 1

💡 רמז 1

שאלה לכל שורה: מי יקרא אותה, ומה הוא יעשה איתה? ושורה שמכילה סוד — כבר דלף, גם אם אף אחד לא קורא.

💡 רמז 2

error = מישהו צריך לקום ולטפל. warn = משהו לא תקין, אבל צפוי (לקוח שלח שטויות). info = אירועים רגילים שרוצים לספור ולחפש. debug = פרטים שמדליקים רק כשמחפשים באג.

✅ פתרון
  1. info, עם port וגרסה. פעם אחת — ומאוד שימושי כשבודקים "מתי עלה ה־deploy".
  2. info, עם userId — לא עם האימייל והסיסמה. (כבר יש שורת request עם הנתיב והסטטוס — לרוב לא צריך שורה נוספת.)
  3. warn (זו שורת ה־request עם 401). בלי הסיסמה שהוקלדה — סיסמה "כמעט נכונה" היא כמעט הסיסמה. הרבה 401 מאותו IP — סימן להתקפה (ולכן הגבלת קצב, שיעור 4).
  4. error, עם requestId, ההודעה וה־stack. זה מה ש־alert מחפש.
  5. לא. בגוף יש סיסמה. ולוגים נשמרים בשירותים חיצוניים, מגובים, ונגישים להרבה אנשים. אם חייבים — עם redact.
  6. debug — כבוי בפרודקשן. מספר עצום של שורות, ולפעמים ערכים רגישים בפרמטרים.
  7. debug (או בכלל לא) כשהוא מצליח. 17,280 שורות ביום שאומרות "הכול בסדר". כשהוא נכשל — כן (warn/error).
  8. warn — שורת ה־request עם 429. אם יש הרבה — מישהו מנסה משהו, או שהמגבלה נמוכה מדי ללקוחות אמיתיים.
⚠️ טעויות נפוצות
  • console.log(req.body) "רק לרגע" — ונשכח ב־commit.
  • הכול ב־error, "כדי שלא נפספס". אחרי שבוע אף אחד לא מסתכל על ה־alerts, וגם השגיאה האמיתית נבלעת.

  • לשמור offset (+02:00) במקום אזור (Asia/Jerusalem). ה־offset משתנה פעמיים בשנה; האזור יודע מתי.

💡 רמז 2

✅ פתרון
// P24-E06
type Level = "debug" | "info" | "warn" | "error";
const ORDER: Record<Level, number> = { debug: 10, info: 20, warn: 30, error: 40 };

export interface LoggerOptions {
  level?: Level;
  sink?: (line: string) => void;
  clock?: () => Date;
  base?: Record<string, unknown>;
}

export function createLogger({ level = "info", sink = (l) => process.stdout.write(l + "\n"), clock = () => new Date(), base = {} }: LoggerOptions = {}) {
  const write = (lvl: Level, msg: string, fields: Record<string, unknown> = {}) => {
    if (ORDER[lvl] < ORDER[level]) return; // מתחת לרמה — לא כותבים בכלל
    // time, level ו־msg קודם — ואחריהם השדות. שדה בשם level ב־fields לא ידרוס את הרמה האמיתית
    sink(JSON.stringify({ ...base, ...fields, time: clock().toISOString(), level: lvl, msg }));
  };
  return {
    debug: (msg: string, fields?: Record<string, unknown>) => write("debug", msg, fields),
    info: (msg: string, fields?: Record<string, unknown>) => write("info", msg, fields),
    warn: (msg: string, fields?: Record<string, unknown>) => write("warn", msg, fields),
    error: (msg: string, fields?: Record<string, unknown>) => write("error", msg, fields),
    // logger "ילד": אותן הגדרות, ועוד שדות קבועים (למשל requestId) בכל שורה
    child: (fields: Record<string, unknown>) => createLogger({ level, sink, clock, base: { ...base, ...fields } }),
  };
}

child הוא הדפוס שספריות כמו pino משתמשות בו: בתחילת בקשה req.log = logger.child({ requestId }), ומשם כל שורה כוללת אותו בלי לחשוב.

⚠️ טעויות נפוצות
  • JSON.stringify(entry, null, 2) — יפה בעין, שובר את "שורה = אירוע", ואיסוף הלוגים מקבל כל שורה כאירוע נפרד.
  • if (lvl < level) על מחרוזות — "error" < "info" (E20).

P24-E07 · redact 🤖 רמה 2

💡 רמז 1

פונקציה רקורסיבית walk(v): לא אובייקט ← כמו שהוא; מערך ← map(walk); אובייקט ← Object.fromEntries(Object.entries(v).map(...)).

💡 רמז 2

מעגל: שומרים Set של האובייקטים שבדרך אל הערך הנוכחי. מוסיפים לפני הירידה, מוחקים אחריה.

✅ פתרון
// P24-E07
const DEFAULT_KEYS = ["password", "passwordHash", "token", "accessToken", "refreshToken", "authorization", "cookie", "secret"];

export function redact(value: unknown, keys: string[] = DEFAULT_KEYS): unknown {
  const secret = new Set(keys.map((k) => k.toLowerCase()));
  const parents = new Set<object>(); // האובייקטים שבדרך אל הערך הנוכחי
  const walk = (v: unknown): unknown => {
    if (typeof v === "string") return v.replace(/^Bearer\s+\S+$/i, "Bearer [REDACTED]");
    if (v === null || typeof v !== "object") return v;
    if (v instanceof Date) return v.toISOString();
    if (parents.has(v)) return "[Circular]"; // אובייקט שמצביע על עצמו — אחרת רקורסיה אינסופית
    parents.add(v);
    const out = Array.isArray(v)
      ? v.map(walk)
      : Object.fromEntries(Object.entries(v).map(([k, x]) => [k, secret.has(k.toLowerCase()) ? "[REDACTED]" : walk(x)]));
    parents.delete(v);
    return out;
  };
  return walk(value); // מחזירים עותק — את המקור לא משנים
}
⚠️ טעויות נפוצות
  • delete obj.password — משנה את האובייקט של הקוד שקרא ללוג. אחרי שורת לוג, המשתמש "איבד" את הסיסמה שלו בדרך ל־bcrypt.
  • WeakSet של "כל מה שראיתי" — אז אובייקט משותף (לא מעגל) מסומן בטעות כ־Circular.

P24-E09 · שורת לוג לכל בקשה 🤖 רמה 2

💡 רמז 1

💡 רמז 2

✅ פתרון
// P24-E09
import { performance } from "node:perf_hooks";
import type { NextFunction, Request, Response } from "express";

type Level = "debug" | "info" | "warn" | "error";
export type Log = (level: Level, msg: string, fields: Record<string, unknown>) => void;

export function requestLogger({ log, now = () => performance.now(), skip = [] }: { log: Log; now?: () => number; skip?: string[] }) {
  return (req: Request, res: Response, next: NextFunction) => {
    const started = now(); // שעון מונוטוני: Date.now() יכול "לקפוץ" כששעון המחשב מתעדכן
    res.on("finish", () => {
      const path = req.originalUrl.split("?")[0]; // query יכול להכיל טוקנים ומידע אישי
      const status = res.statusCode;
      if (status < 400 && skip.includes(path)) return;
      const level: Level = status >= 500 ? "error" : status >= 400 ? "warn" : "info";
      log(level, "request", {
        method: req.method,
        path,
        status,
        durationMs: Math.round(now() - started),
        ...(res.locals.requestId ? { requestId: res.locals.requestId } : {}),
      });
    });
    next();
  };
}

למה performance.now() ולא Date.now()? Date.now() הוא שעון הקיר — כשהמחשב מסנכרן שעון (NTP), הוא יכול לקפוץ אחורה, ותקבל משך שלילי. performance.now() רק עולה.

P24-E12 · חצות בישראל — באיזו שעה ב־UTC? 🤖 רמה 2

💡 רמז 1

offsetMinutes: מפרקים את הרגע לחלקים באזור (formatToParts), בונים מהם Date.UTC(...) "כאילו" הם UTC, ומחסרים את הרגע האמיתי.

💡 רמז 2

zonedTimeToUtc: יש רק שני offsets אפשריים סביב היום הזה — זה של אתמול וזה של מחר. לכל אחד: מועמד = wall − offset. מועמד "נכון" אם השעה המקומית שלו היא באמת השעה המבוקשת. אף אחד לא נכון ← השעה לא קיימת.

✅ פתרון
// P24-E12
const MIN = 60_000;

// ההפרש (בדקות) בין השעה המקומית ל־UTC ברגע מסוים: ישראל בחורף 120, בקיץ 180
export function offsetMinutes(instant: Date, tz: string): number {
  const p = Object.fromEntries(
    new Intl.DateTimeFormat("en-US", { timeZone: tz, hourCycle: "h23", year: "numeric", month: "numeric", day: "numeric", hour: "numeric", minute: "numeric" })
      .formatToParts(instant)
      .map((x) => [x.type, Number(x.value)]),
  );
  const asIfUtc = Date.UTC(p.year, p.month - 1, p.day, p.hour, p.minute);
  return Math.round((asIfUtc - Math.floor(instant.getTime() / MIN) * MIN) / MIN);
}

// "2026-03-27" + "09:00" בישראל ← הרגע ב־UTC
export function zonedTimeToUtc(date: string, time: string, tz: string): Date {
  const [y, mo, d] = date.split("-").map(Number);
  const [h, mi] = time.split(":").map(Number);
  const wall = Date.UTC(y, mo - 1, d, h, mi); // השעה על השעון, "כאילו" ב־UTC
  // שני ה־offsets האפשריים סביב אותו יום (לפני ואחרי מעבר שעון)
  const before = offsetMinutes(new Date(wall - 86_400_000), tz);
  const after = offsetMinutes(new Date(wall + 86_400_000), tz);
  const matches = [before, after]
    .map((o) => wall - o * MIN)
    .filter((t) => offsetMinutes(new Date(t), tz) * MIN + t === wall)
    .sort((a, b) => a - b);
  if (matches.length > 0) return new Date(matches[0]); // שעה כפולה (חזרה לשעון חורף) ← המופע הראשון
  return new Date(wall - before * MIN); // שעה שלא קיימת (מעבר לשעון קיץ) ← "קופצים" קדימה, כמו השעון
}

export function startOfDayInZone(date: string, tz: string): Date {
  return zonedTimeToUtc(date, "00:00", tz);
}

// טווח של יום מקומי, לשאילתה: start <= created_at < end
export function dayRangeInZone(date: string, tz: string): { start: Date; end: Date } {
  const [y, m, d] = date.split("-").map(Number);
  const next = new Date(Date.UTC(y, m - 1, d + 1)).toISOString().slice(0, 10);
  return { start: startOfDayInZone(date, tz), end: startOfDayInZone(next, tz) };
}

בשביל מה dayRangeInZone? "כמה משימות נוצרו היום" במסד: WHERE created_at >= $start AND created_at < $end. ב־DATE(created_at) של PostgreSQL — היום לפי UTC (או לפי ה־timezone של החיבור), לא של המשתמש.

⚠️ טעויות נפוצות
  • end = start + 24 שעות — ביום המעבר תפספס שעה, או תספור שעה מהיום הבא.
  • לחשב offset פעם אחת ("ישראל = +2") ולשמור. בקיץ הוא +3.
💡 Temporal

החישובים האלה הם בדיוק מה ש־Temporal — ה־API החדש של JavaScript לתאריכים — עושה מובנה: Temporal.PlainDate.from("2026-03-27").toZonedDateTime("Asia/Jerusalem"). הוא נכנס לדפדפנים ול־Node בשלבים; עד שתוכל להסתמך עליו בכל מקום — זה המנגנון, וכדאי להבין אותו.

function parts(instant: Date, tz: string) {
  const p = Object.fromEntries(
    new Intl.DateTimeFormat("en-US", { timeZone: tz, hourCycle: "h23", year: "numeric", month: "numeric", day: "numeric", hour: "numeric", minute: "numeric" })
      .formatToParts(instant)
      .map((x) => [x.type, Number(x.value)]),
  );
  return { y: p.year, m: p.month, d: p.day, h: p.hour, mi: p.minute };
}

const offset = (t: number, tz: string) => {
  const p = parts(new Date(t), tz);
  return (Date.UTC(p.y, p.m - 1, p.d, p.h, p.mi) - Math.floor(t / MIN) * MIN) / MIN;
};

// מ־E12: שעה על השעון באזור ← רגע (שעה שלא קיימת ← קדימה; כפולה ← הראשונה)
function wallToUtc(wall: number, tz: string): number {
  const before = offset(wall - DAY, tz);
  const after = offset(wall + DAY, tz);
  const ok = [before, after].map((o) => wall - o * MIN).filter((t) => offset(t, tz) * MIN + t === wall).sort((a, b) => a - b);
  return ok.length ? ok[0] : wall - before * MIN;
}

// "אותה שעה, בעוד N ימים" — לא N*24 שעות: ביום מעבר שעון זה לא אותו דבר
export function addLocalDays(instant: Date, days: number, tz: string): Date {
  const p = parts(instant, tz);
  return new Date(wallToUtc(Date.UTC(p.y, p.m - 1, p.d + days, p.h, p.mi), tz));
}

export function isSameLocalDay(a: Date, b: Date, tz: string): boolean {
  const x = parts(a, tz);
  const y = parts(b, tz);
  return x.y === y.y && x.m === y.m && x.d === y.d;
}

// כמה ימים (בלוח השנה של המשתמש) עד dueDate: 0 = היום, 1 = מחר, שלילי = עבר
export function daysUntil(dueDate: string, now: Date, tz: string): number {
  const [y, m, d] = dueDate.split("-").map(Number);
  const p = parts(now, tz);
  return Math.round((Date.UTC(y, m - 1, d) - Date.UTC(p.y, p.m - 1, p.d)) / DAY);
}

// P24-E14
export interface StoredResponse {
  status: number;
  body: unknown;
}
export type Begin =
  | { kind: "new" }
  | { kind: "replay"; response: StoredResponse }
  | { kind: "mismatch" }
  | { kind: "in_progress" };

interface Entry {
  fingerprint: string;
  response: StoredResponse | null; // null = עדיין בטיפול
  createdAt: number;
}

export class IdempotencyStore {
  #entries = new Map<string, Entry>();
  #ttlMs: number;
  #now: () => number;

  constructor({ ttlMs = 24 * 3600_000, now = () => Date.now() }: { ttlMs?: number; now?: () => number } = {}) {
    this.#ttlMs = ttlMs;
    this.#now = now;
  }

  // scope = מי (בדרך כלל userId). אותו key של שני משתמשים — שתי רשומות נפרדות
  #id(scope: string, key: string) {
    return JSON.stringify([scope, key]); // לא `${scope}:${key}` — "a:b"+"c" ו־"a"+"b:c" היו מתנגשים
  }

  #live(id: string): Entry | undefined {
    const e = this.#entries.get(id);
    if (e && this.#now() - e.createdAt >= this.#ttlMs) {
      this.#entries.delete(id);
      return undefined;
    }
    return e;
  }

  begin(scope: string, key: string, fingerprint: string): Begin {
    const id = this.#id(scope, key);
    const e = this.#live(id);
    if (!e) {
      this.#entries.set(id, { fingerprint, response: null, createdAt: this.#now() });
      return { kind: "new" };
    }
    if (e.fingerprint !== fingerprint) return { kind: "mismatch" };
    if (e.response === null) return { kind: "in_progress" };
    return { kind: "replay", response: e.response };
  }

  complete(scope: string, key: string, response: StoredResponse) {
    const e = this.#entries.get(this.#id(scope, key));
    if (!e) throw new Error("אין בקשה כזו בטיפול");
    e.response = response;
  }

  release(scope: string, key: string) {
    const id = this.#id(scope, key);
    if (this.#entries.get(id)?.response === null) this.#entries.delete(id); // רק מה שלא הושלם
  }

  // מוחק רשומות שפג תוקפן; מחזיר כמה נמחקו. בשרת — כל כמה דקות
  sweep(): number {
    let removed = 0;
    for (const id of [...this.#entries.keys()]) if (!this.#live(id)) removed++;
    return removed;
  }

  get size() {
    return this.#entries.size;
  }
}

// P24-E15
import { createHash } from "node:crypto";
import type { NextFunction, Request, Response } from "express";

export interface StoredResponse {
  status: number;
  body: unknown;
}
export interface Store {
  begin(scope: string, key: string, fingerprint: string): { kind: "new" } | { kind: "replay"; response: StoredResponse } | { kind: "mismatch" } | { kind: "in_progress" };
  complete(scope: string, key: string, response: StoredResponse): void;
  release(scope: string, key: string): void;
}

const VALID_KEY = /^[A-Za-z0-9_-]{8,100}$/;

export function idempotency({ store, scope = (req) => req.get("x-user-id") ?? "anonymous" }: { store: Store; scope?: (req: Request) => string }) {
  return (req: Request, res: Response, next: NextFunction) => {
    const key = req.get("idempotency-key");
    if (req.method !== "POST" || key === undefined) return next(); // GET/PUT/DELETE כבר idempotent; בלי מפתח — רגיל
    if (!VALID_KEY.test(key)) return res.status(400).json({ error: "Idempotency-Key לא תקין" });

    const who = scope(req);
    // אותו מפתח לבקשה אחרת (נתיב או גוף אחר) — זו טעות של הלקוח, לא "ניסיון חוזר"
    const fingerprint = createHash("sha256").update(JSON.stringify([req.method, req.path, req.body ?? null])).digest("hex");
    const r = store.begin(who, key, fingerprint);
    if (r.kind === "mismatch") return res.status(422).json({ error: "המפתח כבר שימש לבקשה אחרת" });
    if (r.kind === "in_progress") return res.status(409).json({ error: "בקשה עם המפתח הזה עדיין בטיפול" });
    if (r.kind === "replay") return res.status(r.response.status).set("Idempotent-Replayed", "true").json(r.response.body);

    let done = false;
    const json = res.json.bind(res);
    res.json = (body: unknown) => {
      done = true;
      // 5xx — תקלה אצלנו, לא תשובה: משחררים, כדי שניסיון חוזר באמת ינסה שוב
      if (res.statusCode >= 500) store.release(who, key);
      else store.complete(who, key, { status: res.statusCode, body });
      return json(body);
    };
    // נגמר בלי res.json (חריגה ← טיפול השגיאות של Express, או החיבור נסגר) — משחררים
    res.on("close", () => {
      if (!done) store.release(who, key);
    });
    next();
  };
}

למה 4xx כן נשמר? כי זו תשובה סופית ונכונה — שליחה חוזרת של אותה בקשה לא תקינה תקבל את אותה תשובה בכל מקרה. 5xx — "לא הצלחנו", וניסיון חוזר הוא בדיוק מה שאנחנו רוצים שיקרה.

⚠️ טעויות נפוצות

import type pg from "pg";

export interface Payment {
  id: number;
  userId: number;
  amountCents: number;
}

export async function createPayment(pool: pg.Pool, userId: number, key: string, amountCents: number): Promise<{ replayed: boolean; payment: Payment }> {
  const fingerprint = JSON.stringify({ amountCents });
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    // שתי טרנזקציות עם אותו (user_id, key): השנייה *מחכה* כאן עד שהראשונה מסתיימת (נעילה על ה־PRIMARY KEY),
    // ואז — אם הראשונה עשתה COMMIT — DO NOTHING ולא מחזירה שורה
    const claimed = await client.query(
      "INSERT INTO idempotency_keys (user_id, key, fingerprint) VALUES ($1, $2, $3) ON CONFLICT (user_id, key) DO NOTHING RETURNING key",
      [userId, key, fingerprint],
    );
    if (claimed.rowCount === 1) {
      const { rows } = await client.query("INSERT INTO payments (user_id, amount_cents) VALUES ($1, $2) RETURNING id", [userId, amountCents]);
      await client.query("UPDATE idempotency_keys SET payment_id = $1 WHERE user_id = $2 AND key = $3", [rows[0].id, userId, key]);
      await client.query("COMMIT");
      return { replayed: false, payment: { id: rows[0].id, userId, amountCents } };
    }
    // המפתח כבר קיים (ו־committed — אחרת היינו עדיין מחכים): מחזירים את מה שנוצר אז
    const { rows } = await client.query(
      `SELECT k.fingerprint, p.id, p.amount_cents FROM idempotency_keys k JOIN payments p ON p.id = k.payment_id
       WHERE k.user_id = $1 AND k.key = $2`,
      [userId, key],
    );
    await client.query("COMMIT");
    if (rows[0].fingerprint !== fingerprint) throw new Error("IDEMPOTENCY_KEY_REUSED");
    return { replayed: true, payment: { id: rows[0].id, userId, amountCents: rows[0].amount_cents } };
  } catch (err) {
    await client.query("ROLLBACK").catch(() => {});
    throw err;
  } finally {
    client.release();
  }
}

הקסם הוא ב־PRIMARY KEY: כשטרנזקציה א׳ הכניסה מפתח ועדיין לא עשתה COMMIT, טרנזקציה ב׳ שמנסה להכניס את אותו מפתח מחכה. אם א׳ עושה COMMIT — ב׳ מקבלת DO NOTHING ורואה את השורה. אם א׳ עושה ROLLBACK — ב׳ מכניסה ו"זוכה". המסד עושה את התיאום, לא הקוד.

ומה עושה הגרסה הנאיבית (SELECT ואז INSERT, בלי טרנזקציה) עם 20 קריאות במקביל? הרצנו (פלט אמיתי): בקשה אחת הצליחה, 19 נכשלו עם duplicate key value violates unique constraint "idempotency_keys_pkey" — ו־20 שורות ב־payments. הלקוח קיבל שגיאות, וחויב 20 פעמים.

✅ פתרון
// P24-E17
export interface TakeResult {
  allowed: boolean;
  remaining: number;
  retryAfterSeconds: number;
}

// דלי עם capacity אסימונים, שמתמלא בקצב קבוע. כל בקשה לוקחת אסימון.
// מאפשר "פרץ" של עד capacity בקשות, ובממוצע — refillPerSecond בשנייה
export class TokenBucket {
  #capacity: number;
  #rate: number;
  #now: () => number;
  #tokens: number;
  #last: number;

  constructor({ capacity, refillPerSecond, now = () => Date.now() }: { capacity: number; refillPerSecond: number; now?: () => number }) {
    if (capacity <= 0 || refillPerSecond <= 0) throw new RangeError("capacity ו־refillPerSecond חייבים להיות חיוביים");
    this.#capacity = capacity;
    this.#rate = refillPerSecond;
    this.#now = now;
    this.#tokens = capacity; // מתחיל מלא
    this.#last = now();
  }

  #refill() {
    const t = this.#now();
    // לא שומרים טיימר — מחשבים כמה התמלא מאז הפעם הקודמת
    this.#tokens = Math.min(this.#capacity, this.#tokens + ((t - this.#last) / 1000) * this.#rate);
    this.#last = t;
  }

  take(cost = 1): TakeResult {
    if (cost > this.#capacity) throw new RangeError("cost גדול מהקיבולת — הבקשה לעולם לא תעבור");
    this.#refill();
    if (this.#tokens >= cost) {
      this.#tokens -= cost;
      return { allowed: true, remaining: Math.floor(this.#tokens), retryAfterSeconds: 0 };
    }
    // לא מורידים כלום כשנדחה — אחרת לקוח שמנסה שוב ושוב לא יעבור לעולם
    const missing = cost - this.#tokens;
    return { allowed: false, remaining: Math.floor(this.#tokens), retryAfterSeconds: Math.ceil(missing / this.#rate) };
  }
}

// P24-E18
import type { NextFunction, Request, Response } from "express";

export function rateLimit({ limit, windowMs, now = () => Date.now(), key = (req) => req.ip ?? "unknown" }: {
  limit: number;
  windowMs: number;
  now?: () => number;
  key?: (req: Request) => string;
}) {
  const hits = new Map<string, number[]>(); // לכל לקוח — הזמנים של הבקשות שעברו, בחלון האחרון
  let lastSweep = now();

  return (req: Request, res: Response, next: NextFunction) => {
    const t = now();
    // ניקוי מדי פעם: לקוח שהלך — לא נשאר בזיכרון לנצח
    if (t - lastSweep >= windowMs) {
      for (const [k, times] of hits) if (times.at(-1)! <= t - windowMs) hits.delete(k);
      lastSweep = t;
    }
    const id = key(req);
    const recent = (hits.get(id) ?? []).filter((x) => x > t - windowMs);
    const resetSeconds = (oldest: number) => Math.max(1, Math.ceil((oldest + windowMs - t) / 1000));
    res.setHeader("RateLimit-Limit", String(limit));

    if (recent.length >= limit) {
      hits.set(id, recent); // הבקשה שנדחתה לא נספרת
      const retry = resetSeconds(recent[0]);
      res.setHeader("RateLimit-Remaining", "0");
      res.setHeader("RateLimit-Reset", String(retry));
      res.setHeader("Retry-After", String(retry)); // בשניות, לפי התקן — לא מילישניות
      return res.status(429).json({ error: "יותר מדי בקשות" });
    }
    recent.push(t);
    hits.set(id, recent);
    res.setHeader("RateLimit-Remaining", String(limit - recent.length));
    res.setHeader("RateLimit-Reset", String(resetSeconds(recent[0])));
    next();
  };
}

ה־headers האלה (RateLimit-*) הם טיוטת תקן של IETF; GitHub ו־Cloudflare שולחים גרסאות שלהם (X-RateLimit-*). לקוח טוב קורא אותם ומאט לפני שהוא נחסם.

⚠️ טעויות נפוצות
  • זה עובד בשרת אחד. עם שלושה שרתים מאחורי load balancer, כל אחד סופר לבד — והמגבלה האמיתית פי 3. לשם צריך מונה משותף (Redis, פרק 26).

// P24-E19
import type { Server } from "node:http";

export function gracefulShutdown(server: Server, { timeoutMs = 10_000, onClose = async () => {} }: { timeoutMs?: number; onClose?: () => Promise<void> } = {}) {
  let running: Promise<{ forced: boolean }> | undefined;
  let shuttingDown = false;

  async function shutdown() {
    shuttingDown = true;
    // 1. לא מקבלים חיבורים חדשים. close() מחכה שכל החיבורים הקיימים ייסגרו
    const closed = new Promise<void>((resolve) => server.close(() => resolve()));
    // 2. חיבורי keep-alive שלא באמצע בקשה — סוגרים עכשיו (מ־Node 19 close עושה את זה בעצמו; מפורש — ברור יותר)
    server.closeIdleConnections();
    // 3. בקשות שבאמצע — מקבלות עד timeoutMs לסיים. אחר כך — בכוח
    let timer: NodeJS.Timeout | undefined;
    const timedOut = new Promise<boolean>((resolve) => {
      timer = setTimeout(() => resolve(true), timeoutMs);
    });
    const forced = await Promise.race([closed.then(() => false), timedOut]);
    clearTimeout(timer);
    if (forced) {
      server.closeAllConnections();
      await closed;
    }
    // 4. רק אחרי שאין בקשות — סוגרים את מה שהן משתמשות בו (מסד, תורים)
    await onClose();
    return { forced };
  }

  return {
    // אפשר לקרוא כמה פעמים (SIGTERM ואז SIGINT) — מתבצע פעם אחת
    shutdown: () => (running ??= shutdown()),
    isShuttingDown: () => shuttingDown,
  };
}

  if (Array.isArray(v)) return v.map(redact);
  if (v === null || typeof v !== "object") return v;
  return Object.fromEntries(Object.entries(v).map(([k, x]) => [k, SECRET.test(k) ? "[REDACTED]" : redact(x)]));
}

export function createLogger({ level = "info", sink }: { level?: Level; sink: (line: string) => void }) {
  const write = (lvl: Level, msg: string, fields: Record<string, unknown> = {}) => {
    // תקלה 1: "error" < "info" כמחרוזות (e לפני i) — שגיאות נזרקו! משווים מספרים
    if (ORDER[lvl] < ORDER[level]) return;
    // תקלה 2: רק password בשורש. { user: { password } } עבר כמו שהוא — עכשיו בכל עומק
    sink(JSON.stringify({ level: lvl, msg, ...(redact(fields) as Record<string, unknown>) }));
  };
  return {
    debug: (msg: string, f?: Record<string, unknown>) => write("debug", msg, f),
    info: (msg: string, f?: Record<string, unknown>) => write("info", msg, f),
    warn: (msg: string, f?: Record<string, unknown>) => write("warn", msg, f),
    error: (msg: string, f?: Record<string, unknown>) => write("error", msg, f),
  };
}

// תקלה 2: יום ≠ 24 שעות. ביום המעבר לשעון קיץ +24 שעות נותן 10:00 במקום 09:00
export function tomorrowSameTime(instant: Date, tz: string): Date {
  const p = parts(instant, tz);
  const wall = Date.UTC(p.y, p.m - 1, p.d + 1, p.h, p.mi);
  const before = offset(wall - DAY, tz);
  const after = offset(wall + DAY, tz);
  const ok = [before, after].map((o) => wall - o * MIN).filter((t) => offset(t, tz) * MIN + t === wall).sort((a, b) => a - b);
  return new Date(ok.length ? ok[0] : wall - before * MIN);
}

import { createHash } from "node:crypto";
import type { NextFunction, Request, Response } from "express";

export function idempotency() {
  const saved = new Map<string, { fingerprint: string; status: number; body: unknown }>();

  return (req: Request, res: Response, next: NextFunction) => {
    const key = req.get("idempotency-key");
    if (req.method !== "POST" || !key) return next();
    const userId = req.get("x-user-id") ?? "anonymous";
    // תקלה 1: המפתח היה גלובלי — יוסי עם אותו מפתח כמו דנה קיבל את ההזמנה של דנה (דליפת מידע!)
    const id = JSON.stringify([userId, key]);
    // תקלה 2: בלי טביעת אצבע — אותו מפתח עם גוף אחר החזיר בשקט את התשובה הישנה
    const fingerprint = createHash("sha256").update(JSON.stringify([req.path, req.body ?? null])).digest("hex");

    const hit = saved.get(id);
    if (hit && hit.fingerprint !== fingerprint) return res.status(422).json({ error: "המפתח כבר שימש לבקשה אחרת" });
    if (hit) return res.status(hit.status).set("Idempotent-Replayed", "true").json(hit.body);

    const json = res.json.bind(res);
    res.json = (body: unknown) => {
      // תקלה 3: גם 500 נשמר — וכל ניסיון חוזר קיבל את אותה שגיאה לנצח, בלי לנסות באמת
      if (res.statusCode < 500) saved.set(id, { fingerprint, status: res.statusCode, body });
      return json(body);
    };
    next();
  };
}

// P24-E23
import type { NextFunction, Request, Response } from "express";

export function rateLimit({ limit, windowMs, now = () => Date.now() }: { limit: number; windowMs: number; now?: () => number }) {
  const hits = new Map<string, number[]>();
  return (req: Request, res: Response, next: NextFunction) => {
    // תקלה 1: X-Forwarded-For הוא header שהלקוח שולח כרצונו — כל בקשה עם ערך אחר "עוקפת" את המגבלה.
    // req.ip בלבד; מאחורי proxy מוכר — app.set("trust proxy", 1), ו־Express מחשב את req.ip נכון
    const client = req.ip ?? "unknown";
    const t = now();
    const recent = (hits.get(client) ?? []).filter((x) => x > t - windowMs);
    if (recent.length >= limit) {
      hits.set(client, recent);
      // תקלה 3: Retry-After הוא בשניות (RFC 9110). 60000 = "חכה 16 שעות"
      res.setHeader("Retry-After", String(Math.ceil((recent[0] + windowMs - t) / 1000)));
      return res.status(429).json({ error: "יותר מדי בקשות" });
    }
    // תקלה 2: הבקשה נספרה לפני הבדיקה — גם הנדחות. לקוח שממשיך לנסות היה חסום לתמיד
    recent.push(t);
    hits.set(client, recent);
    next();
  };
}

ומתי כן X-Forwarded-For? כשהשרת מאחורי proxy שאתה שולט בו (load balancer בפרק 25). אז app.set("trust proxy", 1) — "סמוך על hop אחד" — ו־Express לוקח מה־header את הכתובת שה־proxy הוסיף, לא את מה שהלקוח כתב לפניה.

⚠️ טעויות נפוצות
  • trust proxy: true (הכול) כשאין proxy — אותה פרצה בדיוק, רק במקום אחר.

  const app = express();
  app.locals.draining = false;
  const orders: Order[] = [];
  const keys = new Map<string, { fingerprint: string; status: number; body: unknown } | null>();
  const hits = new Map<string, number[]>();

    logSink(JSON.stringify({ time: clock().toISOString(), level, msg, ...fields }));

        path,
        status,
        durationMs: Math.round(performance.now() - started),
      });
    });
    next();
  });

  app.get("/health", (req, res) => res.json({ status: "ok" }));

    res.locals.userId = userId;
    next();
  };

    hits.set(res.locals.userId, recent);

    if (prev === null) return fail(res, 409, "IDEMPOTENCY_IN_PROGRESS", "בקשה עם המפתח הזה בטיפול");

    if (prev) return res.status(prev.status).set("Idempotent-Replayed", "true").json(prev.body);

    if (typeof item !== "string" || item.trim() === "" || !Number.isInteger(quantity) || quantity < 1 || quantity > 100) {

    }

    orders.push(order);
    keys.set(id, { fingerprint, status: 201, body: order });
    res.status(201).location(`/orders/${order.id}`).json(order);
  });

  app.use((req, res) => fail(res, 404, "NOT_FOUND", "אין נתיב כזה"));

    if (err.type === "entity.parse.failed") return fail(res, 400, "INVALID_JSON", "JSON לא תקין");
    log("error", err.message, { requestId: res.locals.requestId, stack: err.stack });

  });
  return app;
}

יום בשבוע של תאריך מקומי: new Date(Date.UTC(y, m − 1, d)).getUTCDay(). שעה כפולה לא דורשת טיפול מיוחד: zonedTimeToUtc תמיד מחזיר את המופע הראשון, אז אחריו פשוט עוברים ליום הבא.

✅ פתרון
// P24-E25
const MIN = 60_000;
const DAY = 86_400_000;

export interface Schedule {
  hour: number;
  minute: number;
  days?: number[]; // 0 = ראשון … 6 = שבת. בלי — כל יום
}

function parts(instant: Date, tz: string) {
  const p = Object.fromEntries(
    new Intl.DateTimeFormat("en-US", { timeZone: tz, hourCycle: "h23", year: "numeric", month: "numeric", day: "numeric", hour: "numeric", minute: "numeric" })
      .formatToParts(instant)
      .map((x) => [x.type, Number(x.value)]),
  );
  return { y: p.year, m: p.month, d: p.day, h: p.hour, mi: p.minute };
}
const offset = (t: number, tz: string) => {
  const p = parts(new Date(t), tz);
  return (Date.UTC(p.y, p.m - 1, p.d, p.h, p.mi) - Math.floor(t / MIN) * MIN) / MIN;
};
function wallToUtc(wall: number, tz: string): number {
  const before = offset(wall - DAY, tz);
  const after = offset(wall + DAY, tz);
  const ok = [before, after].map((o) => wall - o * MIN).filter((t) => offset(t, tz) * MIN + t === wall).sort((a, b) => a - b);
  return ok.length ? ok[0] : wall - before * MIN;
}

function validate({ hour, minute, days }: Schedule) {
  if (!Number.isInteger(hour) || hour < 0 || hour > 23) throw new RangeError("hour: 0–23");
  if (!Number.isInteger(minute) || minute < 0 || minute > 59) throw new RangeError("minute: 0–59");
  if (days && (days.length === 0 || days.some((d) => !Number.isInteger(d) || d < 0 || d > 6))) throw new RangeError("days: 0–6, לפחות יום אחד");
}

// הריצה הבאה — אחרי after (לא כולל). עוברים על ימים בלוח השנה *המקומי*, לא על 24 שעות
export function nextRun(schedule: Schedule, after: Date, tz: string): Date {
  validate(schedule);
  const start = parts(after, tz);
  for (let i = 0; i <= 7; i++) {
    const wall = Date.UTC(start.y, start.m - 1, start.d + i, schedule.hour, schedule.minute);
    const weekday = new Date(Date.UTC(start.y, start.m - 1, start.d + i)).getUTCDay();
    if (schedule.days && !schedule.days.includes(weekday)) continue;
    // שעה שלא קיימת (שעון קיץ) ← קדימה; שעה כפולה (חורף) ← רק המופע הראשון, פעם אחת
    const t = wallToUtc(wall, tz);
    if (t > after.getTime()) return new Date(t);
  }
  throw new Error("לא אמור לקרות"); // תוך 8 ימים תמיד יש התאמה
}

export function upcoming(schedule: Schedule, after: Date, tz: string, count: number): Date[] {
  const out: Date[] = [];
  let cursor = after;
  while (out.length < count) {
    cursor = nextRun(schedule, cursor, tz);
    out.push(cursor);
  }
  return out;
}

⚠️ טעויות נפוצות
  • next = last + 24h — זז בשעה פעמיים בשנה.
  • לבדוק "יום שישי" עם getUTCDay() על הרגע — ב־00:15 בישראל ביום חמישי, ב־UTC עדיין רביעי.

P24-E26 · איזה מדד, ואילו labels? רמה 1

💡 רמז 1

counter — רק עולה (סופרים אירועים). gauge — עולה ויורד (מצב עכשיו). histogram — התפלגות של ערכים (זמנים, גדלים).

💡 רמז 2

כל צירוף שונה של ערכי labels הוא סדרה נפרדת בזיכרון של Prometheus. כמה משתמשים יש לך?

✅ פתרון
  1. counter orders_created_total{payment_method}. "בדקה האחרונה" — לא שומרים בקוד; Prometheus מחשב: increase(orders_created_total[1m]). ל־payment_method יש 3–4 ערכים — בסדר.
  2. histogram http_request_duration_seconds{method,route}, ומחשבים ב־Prometheus: histogram_quantile(0.95, …). ממוצע לא עונה על השאלה (סעיף 3 בשיעור).
  3. gauge queue_waiting_jobs{queue} — ערך שעולה ויורד. מודדים אותו בזמן ה־scrape (שואלים את BullMQ כמה מחכות), לא מעדכנים בכל עבודה.
  4. המלכודת. userId כ־label = סדרה לכל משתמש: מאה אלף משתמשים × routes × statuses = מיליוני סדרות, ו־Prometheus נופל (high cardinality). "כמה כל משתמש שלח" — שאלה ללוגים או למסד, לא למדדים. ל־labels — רק ערכים מקבוצה קטנה וסגורה.
  5. שני counters שכבר יש: http_requests_total עם status. היחס: rate(...{status=~"5.."}[5m]) / rate(...[5m]). לא סופרים אחוזים בקוד.
⚠️ טעויות נפוצות
  • gauge לספירת בקשות ("מספר הבקשות עד עכשיו") — אחרי restart הוא מתאפס, ו־Prometheus לא יודע שזה איפוס. counter יודע: rate מזהה ירידה כאיפוס.
  • route עם המזהה (/tasks/42) — אותה מלכודת כמו userId, רק מוסתרת.

// P24-E27
// רישום מדדים קטן בפורמט הטקסט של Prometheus: counter ו־histogram, עם labels
type Labels = Record<string, string>;

const escapeValue = (v: string) => v.replace(/\\/g, "\\\\").replace(/"/g, '\\"').replace(/\n/g, "\\n");
const formatLabels = (names: string[], values: string[], extra = "") => {
  const parts = names.map((n, i) => `${n}="${escapeValue(values[i])}"`);
  if (extra) parts.push(extra);
  return parts.length ? `{${parts.join(",")}}` : "";
};

function labelValues(names: string[], labels: Labels): string[] {
  const keys = Object.keys(labels);
  for (const k of keys) if (!names.includes(k)) throw new Error(`label לא מוכר: ${k}`);
  // כל label חובה — אחרת אותו מדד יופיע פעם עם label ופעם בלי, ואי אפשר לסכם
  return names.map((n) => {
    if (labels[n] === undefined) throw new Error(`חסר label: ${n}`);
    return String(labels[n]);
  });
}

export function createRegistry() {
  const metrics: { render: () => string }[] = [];
  const names = new Set<string>();
  const register = (name: string) => {
    if (names.has(name)) throw new Error(`מדד בשם ${name} כבר רשום`);
    names.add(name);
  };

  function counter({ name, help, labelNames = [] }: { name: string; help: string; labelNames?: string[] }) {
    register(name);
    const series = new Map<string, { values: string[]; value: number }>(); // מפתח: הערכים של ה־labels
    metrics.push({
      render: () =>
        [`# HELP ${name} ${help}`, `# TYPE ${name} counter`, ...[...series.values()].map((s) => `${name}${formatLabels(labelNames, s.values)} ${s.value}`)].join("\n"),
    });
    return {
      inc(labels: Labels = {}, by = 1) {
        if (by < 0) throw new RangeError("counter רק עולה");
        const values = labelValues(labelNames, labels);
        const key = JSON.stringify(values);
        const s = series.get(key) ?? { values, value: 0 };
        s.value += by;
        series.set(key, s);
      },
    };
  }

  function histogram({ name, help, labelNames = [], buckets }: { name: string; help: string; labelNames?: string[]; buckets: number[] }) {
    register(name);
    const sorted = [...buckets].sort((a, b) => a - b);
    const series = new Map<string, { values: string[]; counts: number[]; sum: number; count: number }>();
    metrics.push({
      render: () => {
        const lines = [`# HELP ${name} ${help}`, `# TYPE ${name} histogram`];
        for (const s of series.values()) {
          // הדליים מצטברים: le="0.1" סופר את כל מה שקטן או שווה ל־0.1 — כולל מה שב־le="0.05"
          sorted.forEach((le, i) => lines.push(`${name}_bucket${formatLabels(labelNames, s.values, `le="${le}"`)} ${s.counts[i]}`));
          lines.push(`${name}_bucket${formatLabels(labelNames, s.values, 'le="+Inf"')} ${s.count}`);
          lines.push(`${name}_sum${formatLabels(labelNames, s.values)} ${s.sum}`);
          lines.push(`${name}_count${formatLabels(labelNames, s.values)} ${s.count}`);
        }
        return lines.join("\n");
      },
    });
    return {
      observe(labels: Labels, value: number) {
        const values = labelValues(labelNames, labels);
        const key = JSON.stringify(values);
        const s = series.get(key) ?? { values, counts: sorted.map(() => 0), sum: 0, count: 0 };
        sorted.forEach((le, i) => { if (value <= le) s.counts[i]++; });
        s.sum += value;
        s.count++;
        series.set(key, s);
      },
    };
  }

  return { counter, histogram, metrics: () => metrics.map((m) => m.render()).join("\n") + "\n" };
}

בעבודה: prom-client עושה את זה, ועוד — gauge, summary, מדדי ברירת מחדל של Node (זיכרון, event loop lag, GC) בשורה אחת: collectDefaultMetrics().

⚠️ טעויות נפוצות
  • דליים לא מצטברים (כל ערך רק בדלי הראשון שמתאים) — histogram_quantile של Prometheus יחשב אחוזונים שגויים, בלי שום שגיאה.
  • לשכוח את le="+Inf" — בלעדיו Prometheus לא יודע כמה ערכים היו מעל הדלי האחרון.
  • ערכי labels בלי escaping — route עם " שובר את כל ה־scrape, לא רק שורה אחת.

// P24-E28
// middleware שמודד כל בקשה (RED: כמה, כמה נכשלו, כמה זמן) ו־handler ל־GET /metrics.
// מקבל registry מבחוץ (כמו E27, או prom-client) — כך אפשר להחליף אותו ולבדוק
import type { NextFunction, Request, Response } from "express";

type Labels = Record<string, string>;
export interface Registry {
  counter(opts: { name: string; help: string; labelNames: string[] }): { inc(labels: Labels, by?: number): void };
  histogram(opts: { name: string; help: string; labelNames: string[]; buckets: number[] }): { observe(labels: Labels, value: number): void };
  metrics(): string;
}

export const BUCKETS = [0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5];

export function httpMetrics(registry: Registry, { now = () => performance.now() }: { now?: () => number } = {}) {
  const requests = registry.counter({ name: "http_requests_total", help: "HTTP requests", labelNames: ["method", "route", "status"] });
  const duration = registry.histogram({ name: "http_request_duration_seconds", help: "HTTP request duration in seconds", labelNames: ["method", "route"], buckets: BUCKETS });

  const middleware = (req: Request, res: Response, next: NextFunction) => {
    if (req.path === "/metrics") return next(); // Prometheus קורא כל 15 שניות — לא רוצים שזה ימלא את הגרפים
    const start = now();
    // מודדים בסוף — רק אז ידועים ה־status והזמן
    res.on("finish", () => {
      // התבנית של ה־route, לא הכתובת: /tasks/:id ולא /tasks/42 — אחרת סדרה חדשה לכל מזהה
      // router על "/tasks" עם route "/" ← "/tasks" (בלי / בסוף). בלי route בכלל (404) ← "unmatched"
      const route = req.route ? (req.baseUrl && req.route.path === "/" ? req.baseUrl : req.baseUrl + req.route.path) : "unmatched";
      const method = req.method;
      requests.inc({ method, route, status: String(res.statusCode) });
      duration.observe({ method, route }, (now() - start) / 1000); // Prometheus: תמיד שניות
    });
    next();
  };

  const handler = (req: Request, res: Response) => {
    res.type("text/plain; version=0.0.4; charset=utf-8").send(registry.metrics());
  };

  return { middleware, handler };
}
⚠️ טעויות נפוצות
  • req.originalUrl או req.path כ־route — כל מזהה וכל query הם סדרה חדשה. אחרי שבוע: מיליון סדרות.
  • למדוד לפני next() — ה־status עוד 200 תמיד, והמשך כמעט 0.
  • מילישניות במקום שניות — הגרפים עובדים, אבל כל dashboard ו־alert מוכן (שמניח שניות) יהיה מוטה פי 1000.

// P24-E29
// tracing מינימלי לפי W3C Trace Context: traceparent נכנס ← span לבקשה ← traceparent יוצא
import { AsyncLocalStorage } from "node:async_hooks";
import { randomBytes } from "node:crypto";
import type { NextFunction, Request, Response } from "express";

export interface Span {
  traceId: string;
  spanId: string;
  parentSpanId: string | null;
  name: string;
  status: number;
  durationMs: number;
}

const TRACEPARENT = /^00-([0-9a-f]{32})-([0-9a-f]{16})-([0-9a-f]{2})$/;

export function parseTraceparent(header: string | undefined) {
  const m = header ? TRACEPARENT.exec(header.trim()) : null;
  if (!m) return null;
  const [, traceId, parentId, flags] = m;
  // מזהה של אפסים בלבד — לא תקין לפי התקן
  if (/^0+$/.test(traceId) || /^0+$/.test(parentId)) return null;
  return { traceId, parentId, sampled: (parseInt(flags, 16) & 1) === 1 };
}

const als = new AsyncLocalStorage<{ traceId: string; spanId: string }>();

// headers לבקשה יוצאת: השירות הבא יראה את ה־span שלנו כ"הורה"
export function outgoingHeaders(): Record<string, string> {
  const ctx = als.getStore();
  return ctx ? { traceparent: `00-${ctx.traceId}-${ctx.spanId}-01` } : {};
}

export function tracing({
  onSpan,
  now = () => performance.now(),
  randomHex = (bytes: number) => randomBytes(bytes).toString("hex"),
}: {
  onSpan: (span: Span) => void;
  now?: () => number;
  randomHex?: (bytes: number) => string;
}) {
  return (req: Request, res: Response, next: NextFunction) => {
    const parent = parseTraceparent(req.get("traceparent"));
    const traceId = parent?.traceId ?? randomHex(16); // אין הורה תקין ← אנחנו תחילת ה־trace
    const spanId = randomHex(8);
    const start = now();
    res.set("X-Trace-Id", traceId);
    res.on("finish", () => {
      const route = req.route ? req.baseUrl + req.route.path : "unmatched";
      onSpan({ traceId, spanId, parentSpanId: parent?.parentId ?? null, name: `${req.method} ${route}`, status: res.statusCode, durationMs: now() - start });
    });
    als.run({ traceId, spanId }, next);
  };
}
⚠️ טעויות נפוצות
  • לשלוח הלאה את ה־parentId שהגיע במקום ה־spanId שלנו — ב־Jaeger השירות הבא יופיע כ"אח" שלנו ולא כ"ילד", והעץ שקר.
  • trace חדש לכל בקשה גם כשהגיע traceparent — כל שירות מקבל trace משלו, ואי אפשר לראות בקשה אחת מקצה לקצה.
  • משתנה גלובלי במקום AsyncLocalStorage — בשתי בקשות במקביל, הבקשה היוצאת של אחת נושאת את ה־trace של השנייה (הבדיקה האחרונה).

// P24-E30
// הופך histogram לשורות בפורמט של Prometheus
export function renderHistogram({ name, labels, buckets, values }: { name: string; labels: Record<string, string>; buckets: number[]; values: number[] }): string[] {
  const esc = (v: string) => v.replace(/\\/g, "\\\\").replace(/"/g, '\\"').replace(/\n/g, "\\n");
  const base = Object.entries(labels).map(([k, v]) => `${k}="${esc(v)}"`); // תקלה 2: ערך עם " שבר את השורה
  const fmt = (extra?: string) => `{${[...base, ...(extra ? [extra] : [])].join(",")}}`;
  const sorted = [...buckets].sort((a, b) => a - b);
  const lines = sorted.map((le) => `${name}_bucket${fmt(`le="${le}"`)} ${values.filter((v) => v <= le).length}`); // תקלה 1: מצטבר — כל מה שקטן או שווה
  lines.push(`${name}_bucket${fmt('le="+Inf"')} ${values.length}`); // תקלה 3: +Inf חובה, ושווה ל־count
  const sum = values.reduce((a, b) => a + b, 0);
  lines.push(`${name}_sum${fmt()} ${sum}`, `${name}_count${fmt()} ${values.length}`);
  return lines;
}
  1. דליים לא מצטברים — כל ערך נספר רק בדלי הראשון שמתאים. histogram_quantile מניח מצטבר, ולכן מחשב אחוזונים שגויים — בלי שום שגיאה.
  2. אין escaping — route="a"b" הוא שורה לא חוקית, ו־Prometheus דוחה את כל ה־scrape (כל המדדים, לא רק זה).
  3. חסר le="+Inf" — בלעדיו אין דלי ש"תופס הכול", וערכים מעל הדלי האחרון נעלמים מהחישוב.
⚠️ טעויות נפוצות
  • לתקן את המצטבר רק ל־+Inf — כל הדליים צריכים להיות מצטברים.
