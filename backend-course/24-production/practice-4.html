P24-E17 · Token Bucket 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

בקובץ P24-E17.ts כתוב new TokenBucket({ capacity, refillPerSecond, now }) עם take(cost = 1) ← { allowed, remaining, retryAfterSeconds }:

  • מתחיל מלא. מתמלא ברציפות (גם חלקי אסימון) — עד capacity, לא מעבר.
  • יש מספיק ← מוריד, allowed: true, retryAfterSeconds: 0. remaining — מעוגל למטה.
  • אין ← לא מוריד כלום, ו־retryAfterSeconds = הזמן עד שיהיה מספיק, מעוגל למעלה.
  • cost > capacity, או capacity/קצב לא חיוביים ← RangeError.

P24-E18 · middleware של הגבלת קצב 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 4

בקובץ P24-E18.ts כתוב rateLimit({ limit, windowMs, now, key }) — חלון נע:

  • key(req) מזהה לקוח (ברירת מחדל req.ip). לכל לקוח — עד limit בקשות ב־windowMs האחרונות.
  • בכל תשובה: RateLimit-Limit, RateLimit-Remaining (אחרי הבקשה הזו), RateLimit-Reset (שניות עד שהבקשה הוותיקה בחלון יוצאת; לפחות 1).
  • מעל ← 429 עם { error } ו־Retry-After בשניות (מעוגל למעלה). בקשה שנדחתה לא נספרת.
  • לקוחות שנעלמו — לא נשארים בזיכרון לנצח.

P24-E19 · כיבוי מסודר 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 4

בקובץ P24-E19.ts כתוב gracefulShutdown(server, { timeoutMs, onClose }) ← { shutdown, isShuttingDown }. shutdown():

  1. מפסיק לקבל חיבורים חדשים, ו־isShuttingDown() ← true מיד.
  2. סוגר מיד חיבורי keep-alive שלא באמצע בקשה.
  3. מחכה שהבקשות שבאמצע יסתיימו — עד timeoutMs. אחר כך — סוגר בכוח את כל החיבורים.
  4. רק אז await onClose() (סגירת המסד).
  5. מחזיר { forced }. קריאה שנייה — אותה Promise, onClose פעם אחת.

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 25 דק׳ידע נדרש: שיעור 4
