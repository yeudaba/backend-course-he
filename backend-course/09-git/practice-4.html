P09-E05 · Git, GitHub, ומה איפה

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

נכון או לא נכון — ותקן את הלא־נכונים:

  1. בלי אינטרנט אי אפשר לעשות commit.
  2. git push שולח ל־GitHub את כל הקבצים שבתיקייה.
  3. git clone מוריד רק את הגרסה האחרונה של הקבצים.
  4. אחרי שמחקתי סיסמה מהקוד ועשיתי commit ו־push — היא כבר לא ב־GitHub.
  5. git pull מושך commits שאחרים דחפו ומשלב אותם בענף הנוכחי.

P09-E71 · מה מקבלים ב־clone?

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 4

הרצת git clone https://github.com/YOUR-USER/expenses-cli.git. לכל טענה — נכון או לא, ולמה?

  1. קיבלתי רק את הגרסה האחרונה של הקבצים, בלי היסטוריה.
  2. git log יראה את כל ה־commits, כולל של אנשים אחרים.
  3. צריך להריץ git remote add origin ... לפני ה־push הראשון.
  4. הקובץ .env של מי שיצר את המאגר הגיע אליי.
  5. node_modules הגיע אליי.

P09-E76 · סורק סודות 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

לפני push, בודקים שאין סודות בקוד. כתוב findSecrets(text) שעוברת על שורות הקובץ ומחזירה מערך של { line, kind } (שורות ממוספרות מ־1), לפי הכללים — לכל שורה לכל היותר ממצא אחד, הראשון שמתאים:

  1. "stripe" — השורה מכילה sk_live_.
  2. "private-key" — השורה מכילה PRIVATE KEY-----.
  3. "assignment" — יש בשורה =; המילה האחרונה לפני ה־= (באותיות גדולות) מכילה PASSWORD, ‏SECRET, ‏TOKEN או API_KEY; והערך שאחרי ה־= (בלי רווחים, ; בסוף ומירכאות) לא ריק ולא מתחיל ב־process.env.
findSecrets([
  'const stripe = "sk_live_51Hx9QzA";',
  "const apiKey = process.env.API_KEY;",
  'const DB_PASSWORD = "hunter2";',
  "JWT_SECRET=",
  "const token = getToken();",
].join("\n"));
// [{ line: 1, kind: "stripe" }, { line: 3, kind: "assignment" }, { line: 5, kind: "assignment" }]

📄 כותבים בקובץ 09-git/starter/P09-E76.js (יש בו רק הערה). בסוף הקובץ: module.exports = { findSecrets };

% node 09-git/starter/P09-E76.js

P09-E25 · אתגר: git bisect

💻 כתיבת קודרמה 5⏱ 30 דק׳ידע נדרש: כל הפרק

כשבאג נכנס "מתישהו" ויש מאות commits, git bisect מוצא את ה־commit האשם בחיפוש בינארי. בנה בעצמך מאגר playground/bisect-lab עם 12 commits, שבכל אחד שינוי קטן ב־calc.js (פונקציה total(items)), ובאחד מהם (נגיד השביעי) — באג. אחר כך כתוב סקריפט בדיקה קטן check.js שיוצא עם קוד 0 כשהתוצאה נכונה ו־1 כשלא, והרץ:

% git bisect start
% git bisect bad HEAD
% git bisect good <hash-of-first-commit>
% git bisect run node check.js

כמה צעדים לקח ל־Git? כמה היו לוקחים עם 1,000 commits?

🔗 איך זה מתחבר: החיפוש הבינארי של P08-E76 (פרק 8, שלב "בודד") — הפעם על היסטוריה של commits. ‏check.js הוא בודק קטן כמו P08-E19, ו־git bisect run מריץ אותו על כל commit שהוא בוחר.

P09-E80 · זרימת PR מקצה לקצה 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 25 דק׳ידע נדרש: שיעור 3, שיעור 4

סקריפט שמדמה את זרימת העבודה עם Pull Request, עם שרת מקומי (P09-E74):

  1. server.git (bare) ו־git clone server.git app. ב־app: commit Add README (README.md: # App) ו־git push -u origin main.
  2. ענף feature/usage: הוסף ל־README.md שורה Run: node index.js (בסוף), commit Add usage to README, ו־git push -u origin feature/usage.
  3. "מיזוג ה־PR": חזרה ל־main, ו־git merge --no-ff --no-edit feature/usage — --no-ff מכריח merge commit גם כשאפשר fast-forward, בדיוק כמו כפתור Merge pull request ב־GitHub. ‏git push.
  4. מחיקת הענף המקומי.
