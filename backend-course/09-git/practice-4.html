P09-E05 · Git, GitHub, ומה איפה

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

נכון או לא נכון — ותקן את הלא־נכונים:

  1. בלי אינטרנט אי אפשר לעשות commit.
  2. git push שולח ל־GitHub את כל הקבצים שבתיקייה.
  3. git clone מוריד רק את הגרסה האחרונה של הקבצים.
  4. אחרי שמחקתי סיסמה מהקוד ועשיתי commit ו־push — היא כבר לא ב־GitHub.
  5. git pull מושך commits שאחרים דחפו ומשלב אותם בענף הנוכחי.

P09-E23 · מפתח API ב־commit

P09-E25 · אתגר: git bisect

💻 כתיבת קודרמה 5⏱ 30 דק׳ידע נדרש: כל הפרק

כשבאג נכנס "מתישהו" ויש מאות commits, git bisect מוצא את ה־commit האשם בחיפוש בינארי. בנה בעצמך מאגר playground/bisect-lab עם 12 commits, שבכל אחד שינוי קטן ב־calc.js (פונקציה total(items)), ובאחד מהם (נגיד השביעי) — באג. אחר כך כתוב סקריפט בדיקה קטן check.js שיוצא עם קוד 0 כשהתוצאה נכונה ו־1 כשלא, והרץ:

% git bisect start
% git bisect bad HEAD
% git bisect good <hash-of-first-commit>
% git bisect run node check.js

כמה צעדים לקח ל־Git? כמה היו לוקחים עם 1,000 commits?
