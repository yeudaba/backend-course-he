אתה ב־main והרצת git merge feature/discount. בקובץ מופיע:

function finalPrice(price) {
<<<<<<< HEAD
  return withVat(price);
=======
  return withVat(price) - 10;
>>>>>>> feature/discount
}

(1) מה הגיע מאיזה ענף? (2) מה ייצא אם תלחץ Accept Current? Accept Incoming? (3) איך מסמנים ל־Git שפתרת?
