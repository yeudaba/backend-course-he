  4. כמו 2, אבל שני ה־commits שינו שורות שונות ורחוקות ב־a.js.

P09-E62 · לפתור התנגשויות בקוד 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

כתוב resolve(text, choice) שמקבלת תוכן של קובץ עם סימני התנגשות, ומחזירה אותו פתור. choice הוא "ours" (הצד של HEAD), "theirs" (הצד השני), או "both" (קודם ours ואז theirs). כל ההתנגשויות בקובץ נפתרות באותה בחירה; שורות מחוץ להתנגשויות נשארות כמו שהן.

const text = [
  "<<<<<<< HEAD",
  'const greeting = "שלום וברכה";',
  "=======",
  'const greeting = "Hello";',
  ">>>>>>> feature/english",
  "module.exports = { greeting };",
].join("\n");
resolve(text, "theirs");
// 'const greeting = "Hello";\nmodule.exports = { greeting };'

שורת סימון מזוהה לפי ההתחלה שלה: "<<<<<<<", "=======" (כל השורה), ">>>>>>>".

📄 כותבים בקובץ 09-git/starter/P09-E62.js (יש בו רק הערה). בסוף הקובץ: module.exports = { resolve };

% node 09-git/starter/P09-E62.js
% npm run check P09-E62

P09-E63 · התנגשות שנפתרה — ו־JSON שבור

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 7, פרק 8, שיעור 3

ב־package.json הייתה התנגשות: כל ענף הוסיף סקריפט. מישהו "פתר" ב־Accept Both. בלי להריץ — מה יודפס?

const resolved = `{
  "scripts": {
    "start": "node index.js",
    "test": "node --test"
    "lint": "eslint ."
  }
}`;
try {
  const pkg = JSON.parse(resolved);
  console.log(Object.keys(pkg.scripts));
} catch (err) {
  console.log(err.name);
  console.log(err.message);
}

🔗 איך זה מתחבר: JSON.parse מפרק 7 ו־try/catch מפרק 8. "Accept Both" מחבר שורות — הוא לא יודע JSON. בקבצים עם תחביר (JSON, קוד) — אחרי כל פתרון מריצים את הקוד או את הבדיקות (שלב 4 בפתרון התנגשות בשיעור).

P09-E65 · ענף הוא הפניה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 7, שיעור 3

בפרק 7 למדת שמשתנה של אובייקט הוא "חץ". ענף ב־Git הוא בדיוק כזה. הקוד הבא מדמה את זה. בלי להריץ — מה יודפס?

const c1 = { message: "Add app", parent: null };
const c2 = { message: "Add README", parent: c1 };
const branches = { main: c2 };
branches["feature/x"] = branches.main;
const c3 = { message: "Add x", parent: branches["feature/x"] };
branches["feature/x"] = c3;
console.log(branches.main.message, branches["feature/x"].message);
console.log(branches["feature/x"].parent === branches.main);
delete branches["feature/x"];
console.log(Object.keys(branches), c3.message);

🔗 איך זה מתחבר: הפניות מפרק 7: branches["feature/x"] = branches.main מעתיק חץ, לא commits — ולכן יצירת ענף היא מיידית. ומחיקת ענף (delete) מוחקת רק את החץ; ה־commit עצמו (c3) עדיין קיים — כמו ב־Git, שבו commit "נעלם" מהתצוגה, אבל אפשר עדיין להגיע אליו לפי ה־hash שלו.

P09-E66 · שם ענף מכותרת משימה 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: פרק 2, פרק 6, שיעור 3

כתוב branchName(title) שהופכת כותרת של משימה לשם ענף:

  • אם הכותרת מתחילה ב־fix: (בלי תלות באותיות) — קידומת fix/, והמילה עצמה מוסרת. אחרת — קידומת feature/.
  • שאר הכותרת: אותיות קטנות, כל מה שאינו אות אנגלית או ספרה הופך לרווח, ואז המילים מחוברות ב־- (בלי מקפים כפולים או בקצוות).
  • החלק שאחרי הקידומת — לכל היותר 30 תווים, ובלי - בסוף אחרי החיתוך.
branchName("Add monthly summary command");    // "feature/add-monthly-summary-command"
branchName("FIX: crash when file is empty!"); // "fix/crash-when-file-is-empty"

% npm run check P09-E66

🔗 איך זה מתחבר: ה־slug מ־P06-E16 (toLowerCase, ‏split, ‏filter, ‏join) והשוואת תווים מפרק 3, עם קידומת לפי סוג — המוסכמה של feature/... מהשיעור.

P09-E67 · לפרק את git branch 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 3

כתוב parseBranches(text) שמקבלת את הפלט של git branch ומחזירה { current, others }: הענף המסומן ב־*, ומערך כל השאר — ממוינים (localeCompare).

parseBranches("  feature/summary\n* main\n  fix/typo\n");
// { current: "main", others: ["feature/summary", "fix/typo"] }

אם אין ענף מסומן — current הוא null.

📄 כותבים בקובץ 09-git/starter/P09-E67.js (יש בו רק הערה). בסוף הקובץ: module.exports = { parseBranches };

% node 09-git/starter/P09-E67.js
% npm run check P09-E67

🔗 איך זה מתחבר: split, ‏filter, ‏map ו־sort מפרק 6 (על עותק!), ו־startsWith מפרק 2. הפורמט: שני תווים ("* " או רווחיים) ואז השם.

P09-E68 · מיזוג של שורות שונות באותו קובץ 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 2, שיעור 3

סקריפט שמראה ש־Git ממזג לבד שינויים באותו קובץ, כשהם בשורות רחוקות:

  1. commit Add config — config.txt עם 5 שורות: port=3000, ‏host=localhost, ‏mode=dev, ‏log=info, ‏cache=off.
  2. ענף feature/prod: commit Use prod mode שמשנה רק את השורה הראשונה ל־port=80.
  3. חזרה ל־main: commit Enable cache שמשנה רק את השורה האחרונה ל־cache=on.
  4. git merge --no-edit feature/prod — בלי התנגשות.

בסוף: config.txt מכיל את שני השינויים.
