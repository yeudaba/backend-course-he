שיעור 3 — branches, merge והתנגשויות

⏱ ~40 דקות

🎯 בשיעור הזה
  • מה זה branch, ולמה עובדים על ענף נפרד לכל משימה.
  • switch, merge, ומחיקת ענף.
  • התנגשות (conflict) — למה קורית ואיך פותרים בלי פאניקה.

1. ענף = מצביע עם שם

למה? כדי שהענף הראשי (main) יהיה תמיד במצב עובד. כל משימה — תכונה, תיקון באג — מקבלת ענף משלה. אם המשימה נכשלה, זורקים את הענף ו־main לא נפגע. וכשכמה אנשים עובדים, כל אחד בענף שלו.

2. הפקודות

% git switch -c feature/summary
Switched to a new branch 'feature/summary'
% git branch
* feature/summary
  main
% git commit -am "Add summary command"
% git switch main
Switched to branch 'main'
% git merge feature/summary
Updating 3d36ee3..a91c2e0
Fast-forward
 src/cli.js | 12 ++++++++++++
 1 file changed, 12 insertions(+)
% git branch -d feature/summary
Deleted branch feature/summary (was a91c2e0).
פקודהמה עושה
git switch -c nameיוצר ענף חדש מהמקום הנוכחי ועובר אליו
git switch nameעובר לענף קיים — הקבצים בתיקייה משתנים לגרסה של הענף
git branchרשימת ענפים; * = הנוכחי
git merge nameממזג את name לתוך הענף הנוכחי
git commit -am "..."קיצור: add לכל הקבצים שכבר במעקב + commit (לא קבצים חדשים!)
git branch -d nameמחיקת ענף שכבר מוזג

"Fast-forward" — אם ב־main לא קרה כלום מאז שהענף נוצר, Git פשוט מזיז את main קדימה. אם שני הצדדים התקדמו (כמו באיור), נוצר merge commit שמאחד את שני הקווים, ונפתח עורך לאשר את ההודעה (סגור את הלשונית ב־VS Code כדי לאשר).

⚠️ לפני switch — status

אם יש שינויים שלא נשמרו ב־commit, Git לפעמים יסרב לעבור ענף ("Your local changes would be overwritten") — וזה טוב, הוא מגן עליך. עשה commit (או git stash — "שים בצד", ו־git stash pop להחזיר) לפני המעבר.

3. התנגשות

כששני ענפים שינו את אותה שורה באותו קובץ, Git לא יכול לנחש מי צודק. הוא עוצר ושואל אותך. בתרגיל conflict (ראה דף התרגילים) תיצור בדיוק מצב כזה:

% git merge feature/english
Auto-merging greeting.js
CONFLICT (content): Merge conflict in greeting.js
Automatic merge failed; fix conflicts and then commit the result.

ובקובץ עצמו:

greeting.js 
<<<<<<< HEAD
const greeting = "שלום וברכה";
=======
const greeting = "Hello";
>>>>>>> feature/english
module.exports = { greeting };
סימוןפירוש
<<<<<<< HEADמכאן — הגרסה של הענף שאתה נמצא בו (main)
=======קו הפרדה
>>>>>>> feature/englishעד כאן — הגרסה של הענף שממזגים
  1. אל תיבהל. שום דבר לא אבד. git status מראה אילו קבצים בהתנגשות. (ואם רוצים לברוח: git merge --abort מחזיר הכול למצב שלפני ה־merge.)
  2. פתח את הקובץ ב־VS Code. מעל ההתנגשות יופיעו כפתורים: Accept Current / Accept Incoming / Accept Both — או ערוך ידנית לתוצאה הנכונה.
  3. מחק את כל שורות הסימון (<<<<<<<, =======, >>>>>>>). הקובץ צריך להיות קוד תקין.
  4. הרץ את הקוד/הבדיקות — לוודא שהתוצאה עובדת.
  5. git add greeting.js ואז git commit (ההודעה כבר מוכנה).

הפתרון הוא החלטה, לא טכניקה: לפעמים אחד הצדדים נכון, לפעמים צריך לשלב (למשל "Hello / שלום וברכה"). אם לא ברור — שואלים את מי שכתב את הצד השני.
