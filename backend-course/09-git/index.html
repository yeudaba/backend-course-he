🎯 בסוף הפרק תדע
  • להבין מה Git שומר, ואת שלושת האזורים: תיקיית עבודה, staging ו־repository.
  • לעבוד במחזור יומי: status ← add ← commit ← log, עם הודעות commit טובות.
  • לראות שינויים (diff), לבטל שינויים, ולהתעלם מקבצים (.gitignore).
  • לעבוד עם branches, למזג, ולפתור התנגשות.
  • להעלות פרויקט ל־GitHub, לעבוד עם Pull Request, ולשמור סודות מחוץ לקוד.

🤔 למה צריך את זה?

אין חברה בעולם שבה מפתחים לא עובדים עם Git. זו מכונת זמן לקוד: כל גרסה שמורה, אפשר לחזור אחורה, לראות מי שינה מה ולמה, ולעבוד כמה אנשים על אותו קוד בלי לדרוס זה את זה. ו־GitHub הוא גם תיק העבודות שלך: מראיינים פותחים את הפרופיל שלך עוד לפני הראיון.

🏁 מבחן מעבר

  • ליצור מאגר לפרויקט 1, עם .gitignore נכון ולפחות 3 commits עם הודעות ברורות — ולהעלות ל־GitHub עם README.
  • להסביר את שלושת האזורים ומה כל אחת מהפקודות add, commit, restore מזיזה ביניהם.
  • ליצור ענף, לעבוד עליו, לפתוח Pull Request ולמזג.
  • לפתור התנגשות בתרגיל conflict בלי לאבד אף אחד מהשינויים.
  • לדעת מה לעשות אם סוד נדחף ל־GitHub (ולמה מחיקה מה־commit הבא לא מספיקה).
  • לענות נכון על 80% מ־P09-E01–E19 ולפתור לפחות תרחיש תקלה אחד (E20–E23).
