⚠️ פקודות מסוכנות

באינטרנט תמצא git reset --hard ו־git push --force. הן משכתבות היסטוריה ומוחקות עבודה, ואין להן "בטל". בקורס לא נשתמש בהן. אם נתקעת — git status ושאל לפני שמריצים משהו שאתה לא מבין.

3. .gitignore

יש קבצים שאסור ש־Git יעקוב אחריהם:

מהלמה
node_modules/ספריות שמותקנות מחדש עם npm install (פרק 13). מאות מגה, אלפי קבצים
.envסודות: סיסמאות למסד, מפתחות API (פרק 13)
.DS_Storeקובץ זבל שה־Mac יוצר בכל תיקייה
קובצי נתונים מקומיים, logs, dist/נוצרים בהרצה; לא חלק מהקוד
.gitignore 
node_modules/
.env
.DS_Store
*.log
dist/

שורה = תבנית. / בסוף = תיקייה. * = "כל דבר". הקובץ .gitignore עצמו כן נכנס ל־Git (כדי שכל הצוות ישתמש בו).

⚠️ .gitignore לא עוזר בדיעבד

אם קובץ כבר נכנס ל־commit, הוספה ל־.gitignore לא מוציאה אותו. צריך git rm --cached file (מסיר מהמעקב, משאיר בדיסק) ואז commit. ואם זה סוד — הוא כבר בהיסטוריה; ראה שיעור 4.
