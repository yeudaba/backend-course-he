3. החוזה מתרחב

ב־tasks.repository.ts, ה־interface מקבל שתי מתודות, ו־InMemoryTasksRepository מקבל את הלוגיקה שהייתה ב־service:

export interface TasksRepository {
  list(query: ListQuery): Promise<TaskPage>;   // { data, meta }
  stats(today: string): Promise<TaskStats>;    // { total, byStatus, overdue }
  findById(id: number): Promise<Task | undefined>;
  insert(data: Omit<Task, "id">): Promise<Task>;
  update(id: number, changes: Partial<Omit<Task, "id">>): Promise<Task | undefined>;
  delete(id: number): Promise<boolean>;
}

וה־service: list(query) { return this.repo.list(query); }, stats() { return this.repo.stats(today(this.now())); }. הרץ את PR2-SERVICE, PR2-API ו־PR2-LIST — הם צריכים לעבור כמו קודם. זה refactor: מבנה חדש, התנהגות זהה, והבדיקות מוכיחות את זה.

4. PrismaTasksRepository

src/tasks/tasks.prisma-repository.ts — מחלקה שמקבלת PrismaClient ב־constructor ומממשת את ה־interface. שלושה דברים שצריך לשים לב אליהם:

  1. המרות: במסד dueDate הוא Date (בחצות UTC) ו־createdAt הוא Date; ב־API הם מחרוזות ("2026-12-31", ISO). פונקציה אחת toTask(row) לקריאה, ואחת toData(task) לכתיבה — לא לפזר המרות בכל מתודה.
  2. list במסד: where (status, priority, ו־OR של title/description עם contains + mode: "insensitive"), orderBy (כולל { dueDate: { sort, nulls: "last" } }, ו־{ id: "asc" } כשובר שוויון), skip/take, ו־count עם אותו where. שתי השאילתות — במקביל עם Promise.all.
  3. "לא נמצא": update/delete של id שלא קיים זורקים P2025 — תרגם ל־undefined/false, כמו בחוזה. ה־service כבר יודע להפוך את זה ל־404.
💡 רמז: stats במסד

prisma.task.groupBy({ by: ["status"], _count: { _all: true } }) לספירה לפי סטטוס, ו־count עם { status: { not: "done" }, dueDate: { lt: new Date(today + "T00:00:00Z") } } לאיחורים.

💡 רמז: מיון לפי עדיפות

ב־enum של PostgreSQL הסדר הוא סדר ההגדרה בסכמה — לכן low, medium, high (ולא לפי א״ב). orderBy: { priority: "desc" } עובד בלי טבלת דרגות.

5. server.ts ו־seed

src/server.ts 
import "dotenv/config";
import { createApp } from "./app.ts";
import { createPrisma } from "./db.ts";
import { PrismaTasksRepository } from "./tasks/tasks.prisma-repository.ts";

const port = Number(process.env.PORT ?? 3000);
if (!process.env.DATABASE_URL) throw new Error("חסר DATABASE_URL (ראה README)");
const prisma = createPrisma(process.env.DATABASE_URL);

createApp({
  repository: new PrismaTasksRepository(prisma),
  log: console.log,
  corsOrigins: process.env.CORS_ORIGINS?.split(","),
}).listen(port, () => console.log(`tasks-api רץ: http://localhost:${port}`));

createApp נשאר עם ברירת מחדל של InMemory — כך הבדיקות הישנות לא צריכות מסד. ו־prisma/seed.ts (עם createMany של כמה משימות לדוגמה) + npm run db:seed.

הרץ npm run dev, צור משימות מהדף של יחידה 15.5 — ועצור והפעל את השרת. המשימות נשארו. 🎉
