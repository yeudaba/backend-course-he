✅ פתרון
  1. order_items; מפתח משותף (order_id, product_id) — @@id([orderId, productId]).
  2. string | null (בגלל String?). Decimal — אובייקט, לא number.
  3. הזמנה: הפריטים שלה נמחקים איתה (onDelete: Cascade על OrderItem.order). קטגוריה עם מוצרים: שגיאה (ברירת המחדל — RESTRICT), קוד P2003.
  4. customerId הוא העמודה (FK). customer הוא שדה קשר — מאפשר include: { customer: true } ו־where: { customer: { city: "Haifa" } }.
  5. המפתח הראשי (id), ו־(customer_id, created_at) — @@index([customerId, createdAt]), בדיוק ה־index של "ההזמנות שלי" מפרק 18.
