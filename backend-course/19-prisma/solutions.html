P19-E01 · לקרוא schema רמה 1

💡 רמז 1

@@map, @@id, ?, onDelete.

💡 רמז 2

שדה קשר (עם @relation) קיים רק ב־client.

✅ פתרון
  1. order_items; מפתח משותף (order_id, product_id) — @@id([orderId, productId]).
  2. string | null (בגלל String?). Decimal — אובייקט, לא number.
  3. הזמנה: הפריטים שלה נמחקים איתה (onDelete: Cascade על OrderItem.order). קטגוריה עם מוצרים: שגיאה (ברירת המחדל — RESTRICT), קוד P2003.
  4. customerId הוא העמודה (FK). customer הוא שדה קשר — מאפשר include: { customer: true } ו־where: { customer: { city: "Haifa" } }.
  5. המפתח הראשי (id), ו־(customer_id, created_at) — @@index([customerId, createdAt]), בדיוק ה־index של "ההזמנות שלי" מפרק 18.
⚠️ טעויות נפוצות
  • לחשוב ש־orders Order[] ב־Customer הוא עמודה — אין שום דבר כזה בטבלה customers.

P19-E04 · N+1 ב־Prisma רמה 1

💡 רמז 1

ב־א' — שאילתה לכל איטרציה.

💡 רמז 2

ב־ב' — Prisma מביא את כל הלקוחות הדרושים בשאילתה אחת נוספת.

✅ פתרון

א: 1 + 12 = 13 שאילתות (N+1). ב: 2 שאילתות (ההזמנות, ואז כל הלקוחות שלהן עם WHERE id IN (...)) — וזה לא משתנה גם עם 10,000 הזמנות. ב' עדיף. ORM לא מונע N+1 לבד: לולאה עם await בפנים היא עדיין N+1.

⚠️ טעויות נפוצות
  • להוסיף include של הכול "ליתר ביטחון" — מביא נתונים שלא צריך. select רק את השדות שמשתמשים בהם.

P19-E05 · מקוד שגיאה ל־HTTP רמה 1

💡 רמז 1

P2002, P2025, P2003.

💡 רמז 2

אחד מהם לא זורק בכלל.

✅ פתרון
  1. P2002 (unique) ← 409 EMAIL_TAKEN.
  2. P2025 (לא נמצא) ← 404.
  3. P2003 (foreign key) ← 409 CATEGORY_NOT_EMPTY.
  4. P2003 (הלקוח לא קיים) ← 400 או 404 (הלקוח שנשלח לא קיים). עדיף לבדוק לפני ולהחזיר הודעה ברורה.
  5. לא שגיאה — מחזיר null. הקוד שלך מחליט: 404.
  6. שגיאת חיבור (לא P20xx של "נתונים") ← לא לתרגם; ה־errorHandler מחזיר 500, ובמערכת אמיתית — 503 וניטור.
⚠️ טעויות נפוצות
  • לתפוס כל שגיאה של Prisma ולהחזיר 404 — מסד שנפל ייראה כמו "לא נמצא", ואף אחד לא יקבל התראה.

💡 רמז 2

import { Prisma } from "../files/generated/prisma/client.ts"

✅ פתרון
// P19-E08
import { Prisma, type PrismaClient } from "../files/generated/prisma/client.ts";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function createCustomer(prisma: PrismaClient, data: { fullName: string; email: string; city?: string | null }) {
  try {
    return await prisma.customer.create({
      data: { fullName: data.fullName, email: data.email, city: data.city ?? null, joinedOn: new Date() },

P19-E09 · עדכון מלאי 🤖 רמה 2

💡 רמז 1

💡 רמז 2

✅ פתרון
// P19-E09
import { Prisma, type PrismaClient } from "../files/generated/prisma/client.ts";

export async function adjustStock(prisma: PrismaClient, productId: number, delta: number) {
  try {
    const p = await prisma.product.update({ where: { id: productId }, data: { stock: { increment: delta } }, select: { stock: true } });

P19-E10 · חיפוש מוצרים 🤖 רמה 2

💡 רמז 1

price: { gte: minPrice, lte: maxPrice } — Prisma מתעלם משדות undefined.

💡 רמז 2

אותו where ל־findMany ול־count; skip: (page - 1) * limit, take: limit.

✅ פתרון
// P19-E10
import type { Prisma, PrismaClient } from "../files/generated/prisma/client.ts";

export async function searchProducts(
  prisma: PrismaClient,
  { q, minPrice, maxPrice, page = 1, limit = 10 }: { q?: string; minPrice?: number; maxPrice?: number; page?: number; limit?: number } = {}
) {
  const where: Prisma.ProductWhereInput = {
    isActive: true,
    ...(q ? { name: { contains: q, mode: "insensitive" } } : {}),
    price: { gte: minPrice, lte: maxPrice },
  };
  const [rows, total] = await Promise.all([
    prisma.product.findMany({
      where,
      select: { id: true, name: true, price: true },
      orderBy: [{ price: "asc" }, { id: "asc" }],
      skip: (page - 1) * limit,
      take: limit,
    }),
    prisma.product.count({ where }),
  ]);
  return { data: rows.map((p) => ({ ...p, price: Number(p.price) })), total };
}
⚠️ טעויות נפוצות
  • q ריק ← contains: "" — עובד (מתאים להכול), אבל undefined נקי יותר.

P19-E11 · לקוח עם הזמנות 🤖 רמה 2

💡 רמז 1

include מקונן: orders ← items ← product.

💡 רמז 2

אפשר orderBy בתוך include, גם לפי שדה של קשר: orderBy: { product: { name: "asc" } }.

✅ פתרון
// P19-E11
import type { PrismaClient } from "../files/generated/prisma/client.ts";

export async function customerOrders(prisma: PrismaClient, customerId: number) {
  const c = await prisma.customer.findUnique({
    where: { id: customerId },
    select: {
      fullName: true,
      orders: {
        orderBy: { id: "asc" },
        select: {
          id: true,
          status: true,
          items: {
            orderBy: { product: { name: "asc" } },
            select: { quantity: true, unitPrice: true, product: { select: { name: true } } },
          },
        },
      },
    },
  });
  if (!c) return null;
  return {
    fullName: c.fullName,
    orders: c.orders.map((o) => ({
      id: o.id,
      status: o.status,
      items: o.items.map((i) => ({ product: i.product.name, quantity: i.quantity, unitPrice: Number(i.unitPrice) })),
    })),
  };
}

select מקונן (במקום include) — מביא רק את השדות שבאמת מחזירים.

⚠️ טעויות נפוצות
  • לולאה על ההזמנות עם findMany לפריטים — N+1.

P19-E12 · מחיקת קטגוריה 🤖 רמה 2

💡 רמז 1

P2025 ו־P2003.

💡 רמז 2

פונקציית עזר קטנה: prismaCode(err) שמחזירה את הקוד או undefined.

✅ פתרון
// P19-E12
import { Prisma, type PrismaClient } from "../files/generated/prisma/client.ts";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

const prismaCode = (err: unknown) => (err instanceof Prisma.PrismaClientKnownRequestError ? err.code : undefined);

export async function deleteCategory(prisma: PrismaClient, id: number) {
  try {
    await prisma.category.delete({ where: { id } });
  } catch (err) {
    if (prismaCode(err) === "P2025") throw new AppError("CATEGORY_NOT_FOUND");
    if (prismaCode(err) === "P2003") throw new AppError("CATEGORY_NOT_EMPTY");
    throw err;
  }
}

  • לבדוק count של מוצרים לפני המחיקה — מוצר שנוסף בין הבדיקה למחיקה. וה־FK עדיין יתפוס — אבל אז השגיאה לא מתורגמת.

P19-E13 · דוח הכנסות ב־SQL 🤖 רמה 3

💡 רמז 1

ה־SQL כמו ב־P17-E23; WHERE o.created_at >= ${since}.

💡 רמז 2

SUM(...)::float AS revenue — אחרת חוזר Decimal.

✅ פתרון
// P19-E13
import type { PrismaClient } from "../files/generated/prisma/client.ts";

export async function revenueByCategory(prisma: PrismaClient, { since }: { since: Date }) {
  return prisma.$queryRaw<{ category: string; revenue: number }[]>`
    SELECT c.name AS category, SUM(oi.quantity * oi.unit_price)::float AS revenue
    FROM order_items oi
    JOIN orders o     ON o.id = oi.order_id
    JOIN products p   ON p.id = oi.product_id
    JOIN categories c ON c.id = p.category_id
    WHERE o.status <> 'cancelled' AND o.created_at >= ${since}
    GROUP BY c.name
    ORDER BY revenue DESC`;
}

ה־${since} הופך לפרמטר ($1) — Prisma לא מדביק אותו כטקסט. בשאילתות האלה עדיין צריך לכתוב שמות טבלאות (snake_case), לא שמות מודלים.

⚠️ טעויות נפוצות
  • $queryRawUnsafe(... &gt;= '${since.toISOString()}') — עובד, עד שמישהו מעביר ערך מהמשתמש.

P19-E14 · הזמנה ב־transaction 🤖 רמה 3

💡 רמז 1

prisma.$transaction(async (tx) => { ... }) — וכל הפעולות דרך tx.

💡 רמז 2

אחרי ה־updateMany, tx.product.findUniqueOrThrow למחיר.

✅ פתרון
// P19-E14
import type { PrismaClient } from "../files/generated/prisma/client.ts";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function placeOrder(prisma: PrismaClient, customerId: number, items: { productId: number; quantity: number }[]) {
  return prisma.$transaction(async (tx) => {
    const lines = [];
    for (const { productId, quantity } of items) {
      const { count } = await tx.product.updateMany({
        where: { id: productId, stock: { gte: quantity } },
        data: { stock: { decrement: quantity } },
      });
      if (count === 0) throw new AppError("OUT_OF_STOCK");
      const { price } = await tx.product.findUniqueOrThrow({ where: { id: productId }, select: { price: true } });
      lines.push({ productId, quantity, unitPrice: price });
    }
    const order = await tx.order.create({ data: { customerId, status: "pending", items: { create: lines } } });
    const total = lines.reduce((sum, l) => sum + Number(l.unitPrice) * l.quantity, 0);
    return { orderId: order.id, total: Math.round(total * 100) / 100 };
  });
}
⚠️ טעויות נפוצות
  • await prisma.product.updateMany(...) בתוך ה־callback — רץ מחוץ ל־transaction, והמלאי לא חוזר כשפריט אחר חסר.

P19-E15 · ביטול הזמנה 🤖 רמה 3

💡 רמז 1

שני ביטולים במקביל: שניהם קוראים "paid", שניהם מחזירים מלאי. איך הופכים את המעבר "לא מבוטל ← מבוטל" לאטומי?

💡 רמז 2

tx.order.updateMany({ where: { id, status: { in: ["pending", "paid"] } }, data: { status: "cancelled" } }) — count 0 אומר שמישהו אחר (או הסטטוס) מנע. ואז לברר למה.

✅ פתרון
// P19-E15
import type { PrismaClient } from "../files/generated/prisma/client.ts";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function cancelOrder(prisma: PrismaClient, orderId: number) {
  return prisma.$transaction(async (tx) => {
    // המעבר לסטטוס cancelled — אטומי: רק אחד מכמה ביטולים במקביל "ינצח"
    const { count } = await tx.order.updateMany({
      where: { id: orderId, status: { in: ["pending", "paid"] } },
      data: { status: "cancelled" },
    });
    if (count === 0) {
      const order = await tx.order.findUnique({ where: { id: orderId }, select: { status: true } });
      if (!order) throw new AppError("ORDER_NOT_FOUND");
      throw new AppError(order.status === "cancelled" ? "ALREADY_CANCELLED" : "CANNOT_CANCEL");
    }
    const items = await tx.orderItem.findMany({ where: { orderId } });
    for (const i of items) {
      await tx.product.update({ where: { id: i.productId }, data: { stock: { increment: i.quantity } } });
    }
    return items.reduce((sum, i) => sum + i.quantity, 0);
  });
}
⚠️ טעויות נפוצות
  • findUnique לסטטוס ואז update — שני ביטולים במקביל מחזירים מלאי פעמיים.

P19-E16 · נתוני דשבורד 🤖 רמה 3

💡 רמז 1

count, aggregate({ _avg: { price: true } }), ו־_count של קשר: category.findMany({ select: { name: true, _count: { select: { products: true } } } }).

💡 רמז 2

כל השאילתות במקביל: Promise.all.

✅ פתרון
// P19-E16
import type { PrismaClient } from "../files/generated/prisma/client.ts";

export async function catalogStats(prisma: PrismaClient) {
  const [products, active, outOfStock, avg, categories] = await Promise.all([
    prisma.product.count(),
    prisma.product.count({ where: { isActive: true } }),
    prisma.product.count({ where: { isActive: true, stock: 0 } }),
    prisma.product.aggregate({ where: { isActive: true }, _avg: { price: true } }),
    prisma.category.findMany({ select: { name: true, _count: { select: { products: true } } } }),
  ]);
  return {
    products,
    active,
    outOfStock,
    avgActivePrice: Math.round(Number(avg._avg.price ?? 0) * 100) / 100,
    byCategory: Object.fromEntries(categories.map((c) => [c.name, c._count.products])),
  };
}
⚠️ טעויות נפוצות
  • (await prisma.product.findMany()).filter(...).length — מביא את כל הטבלה כדי לספור.

P19-E17 · pagination עם cursor 🤖 רמה 3

💡 רמז 1

take: limit + 1 כדי לדעת אם יש עוד.

💡 רמז 2

עם cursor: cursor: { id: after }, skip: 1 (לדלג על השורה של ה־cursor עצמו). עם where — פשוט id: { gt: after ?? 0 }.

✅ פתרון
// P19-E17
import type { PrismaClient } from "../files/generated/prisma/client.ts";

export async function listOrders(prisma: PrismaClient, { after, limit = 5 }: { after?: number; limit?: number } = {}) {
  const rows = await prisma.order.findMany({
    where: { id: { gt: after ?? 0 } },
    orderBy: { id: "asc" },
    take: limit + 1,
    select: { id: true, status: true },
  });
  const hasMore = rows.length > limit;
  const data = rows.slice(0, limit);
  return { data, nextCursor: hasMore ? data[data.length - 1].id : null };
}

(ה־cursor של Prisma נכשל אם הרשומה של ה־cursor נמחקה בינתיים. gt עמיד יותר.)

⚠️ טעויות נפוצות
  • skip: page * limit — חזרנו ל־OFFSET.

P19-E18 · תגיות למוצר 🤖 רמה 3

export async function setProductTags(prisma: PrismaClient, productId: number, names: string[]) {
  const clean = [...new Set(names.map((n) => n.trim().toLowerCase()).filter(Boolean))];
  return prisma.$transaction(async (tx) => {
    const product = await tx.product.findUnique({ where: { id: productId }, select: { id: true } });
    if (!product) throw new AppError("PRODUCT_NOT_FOUND");
    const tags = [];
    for (const name of clean) tags.push(await tx.tag.upsert({ where: { name }, create: { name }, update: {} }));
    await tx.productTag.deleteMany({ where: { productId } });
    await tx.productTag.createMany({ data: tags.map((t) => ({ productId, tagId: t.id })) });
    return tags.map((t) => t.name).sort();
  });
}

const PRODUCTS = [

  { name: "Cold Brew Filter Bags", price: 34.9, stock: 100 },
];

export async function seedDemoData(prisma: PrismaClient) {
  const category = await prisma.category.upsert({ where: { name: "cold brew" }, create: { name: "cold brew" }, update: {} });
  for (const p of PRODUCTS) {
    const existing = await prisma.product.findFirst({ where: { name: p.name, categoryId: category.id } });
    if (!existing) await prisma.product.create({ data: { ...p, categoryId: category.id } });
  }
  const customer = await prisma.customer.upsert({
    where: { email: "demo@example.com" },
    create: { email: "demo@example.com", fullName: "Demo User", city: "Tel Aviv", joinedOn: new Date("2026-01-01") },
    update: {},
  });
  return { categoryId: category.id, customerId: customer.id };
}

export async function buy(prisma: PrismaClient, productId: number, qty: number) {
  const { count } = await prisma.product.updateMany({
    where: { id: productId, stock: { gte: qty } },
    data: { stock: { decrement: qty } },
  });
  const product = await prisma.product.findUnique({ where: { id: productId }, select: { stock: true } });
  if (!product) throw new AppError("PRODUCT_NOT_FOUND");
  if (count === 0) throw new AppError("OUT_OF_STOCK");
  return product.stock;
}

export async function transferStock(prisma: PrismaClient, fromProductId: number, toProductId: number, qty: number) {
  await prisma.$transaction(async (tx) => {
    await tx.product.update({ where: { id: toProductId }, data: { stock: { increment: qty } } });
    const { count } = await tx.product.updateMany({
      where: { id: fromProductId, stock: { gte: qty } },

    });
    if (count === 0) throw new AppError("OUT_OF_STOCK");
  });

P19-E24 · אתגר: repository למוצרים 🤖 רמה 5

💡 רמז 1

💡 רמז 2

קטגוריה לפי שם בכתיבה: category: { connect: { name } } — ואם לא קיימת, Prisma זורק P2025.

✅ פתרון
// P19-E24
import { Prisma, type PrismaClient } from "../files/generated/prisma/client.ts";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export interface Product { id: number; name: string; category: string; price: number; stock: number; isActive: boolean }
export interface ListOptions { category?: string; q?: string; inStock?: boolean; sort?: "price" | "-price" | "name"; page?: number; limit?: number }

export interface ProductsRepository {
  list(options: ListOptions): Promise<{ data: Product[]; total: number }>;
  get(id: number): Promise<Product | undefined>;
  create(data: { name: string; category: string; price: number; stock: number }): Promise<Product>;
  update(id: number, changes: Partial<Omit<Product, "id">>): Promise<Product | undefined>;
  remove(id: number): Promise<boolean>;
}

const withCategory = { category: { select: { name: true } } } as const;
type Row = Prisma.ProductGetPayload<{ include: typeof withCategory }>;

const toProduct = (r: Row): Product => ({
  id: r.id,
  name: r.name,
  category: r.category.name,
  price: Number(r.price),
  stock: r.stock,
  isActive: r.isActive,
});

const code = (err: unknown) => (err instanceof Prisma.PrismaClientKnownRequestError ? err.code : undefined);

export class PrismaProductsRepository implements ProductsRepository {
  prisma: PrismaClient;
  constructor(prisma: PrismaClient) {
    this.prisma = prisma;
  }

  async list({ category, q, inStock, sort = "name", page = 1, limit = 10 }: ListOptions) {
    const where: Prisma.ProductWhereInput = {
      ...(category ? { category: { name: category } } : {}),
      ...(q ? { name: { contains: q, mode: "insensitive" } } : {}),
      ...(inStock ? { stock: { gt: 0 } } : {}),
    };
    const orderBy: Prisma.ProductOrderByWithRelationInput[] = [
      sort === "name" ? { name: "asc" } : { price: sort === "price" ? "asc" : "desc" },
      { id: "asc" },
    ];
    const [rows, total] = await Promise.all([
      this.prisma.product.findMany({ where, orderBy, include: withCategory, skip: (page - 1) * limit, take: limit }),
      this.prisma.product.count({ where }),
    ]);
    return { data: rows.map(toProduct), total };
  }

  async get(id: number) {
    const row = await this.prisma.product.findUnique({ where: { id }, include: withCategory });
    return row ? toProduct(row) : undefined;
  }

  async create({ name, category, price, stock }: { name: string; category: string; price: number; stock: number }) {
    try {
      const row = await this.prisma.product.create({
        data: { name, price, stock, category: { connect: { name: category } } },
        include: withCategory,
      });
      return toProduct(row);
    } catch (err) {
      if (code(err) === "P2025") throw new AppError("CATEGORY_NOT_FOUND");
      throw err;
    }
  }

  async update(id: number, { category, ...rest }: Partial<Omit<Product, "id">>) {
    const exists = await this.prisma.product.findUnique({ where: { id }, select: { id: true } });
    if (!exists) return undefined;
    try {
      const row = await this.prisma.product.update({
        where: { id },
        data: { ...rest, ...(category ? { category: { connect: { name: category } } } : {}) },
        include: withCategory,
      });
      return toProduct(row);
    } catch (err) {
      if (code(err) === "P2025") throw new AppError("CATEGORY_NOT_FOUND");
      throw err;
    }
  }

  async remove(id: number) {
    try {
      await this.prisma.product.delete({ where: { id } });
      return true;
    } catch (err) {
      if (code(err) === "P2025") return false;
      if (code(err) === "P2003") throw new AppError("PRODUCT_HAS_ORDERS");
      throw err;
    }
  }
}

ב־update, P2025 יכול לבוא משני מקומות (המוצר או הקטגוריה) — לכן בודקים קודם שהמוצר קיים. (יש בזה מרוץ קטן: מוצר שנמחק בין הבדיקה לעדכון ידווח כ"קטגוריה לא נמצאה". זה מקרה נדיר, ובשביל להבדיל באמת צריך לבדוק את שניהם באותו transaction.)

⚠️ טעויות נפוצות
  • להחזיר את ה־row של Prisma כמו שהוא — categoryId במקום שם, ו־Decimal במקום מספר. ה־repository הוא המקום שמתרגם.

P19-E25 · אתגר: דוח חודשי עם $queryRaw 🤖 רמה 5

💡 רמז 1

💡 רמז 2

SUM(revenue) OVER (ORDER BY m) לסכום מצטבר; to_char(make_date(${year}, m, 1), 'YYYY-MM'). ו־::int/::float כדי לקבל מספרים.

✅ פתרון
// P19-E25
import type { PrismaClient } from "../files/generated/prisma/client.ts";

export async function monthlyReport(prisma: PrismaClient, year: number) {
  return prisma.$queryRaw<{ month: string; orders: number; revenue: number; runningTotal: number }[]>`
    WITH sales AS (
      SELECT EXTRACT(MONTH FROM o.created_at AT TIME ZONE 'UTC')::int AS m,
             COUNT(DISTINCT o.id) AS orders,
             SUM(oi.quantity * oi.unit_price) AS revenue
      FROM orders o
      JOIN order_items oi ON oi.order_id = o.id
      WHERE o.status <> 'cancelled'
        AND o.created_at >= make_timestamptz(${year}::int, 1, 1, 0, 0, 0, 'UTC')
        AND o.created_at <  make_timestamptz(${year}::int + 1, 1, 1, 0, 0, 0, 'UTC')
      GROUP BY 1
    )
    SELECT to_char(make_date(${year}::int, g.m, 1), 'YYYY-MM') AS month,
           COALESCE(s.orders, 0)::int AS orders,
           COALESCE(s.revenue, 0)::float AS revenue,
           (SUM(COALESCE(s.revenue, 0)) OVER (ORDER BY g.m))::float AS "runningTotal"
    FROM generate_series(1, 12) AS g(m)
    LEFT JOIN sales s ON s.m = g.m
    ORDER BY g.m`;
}

שלושה כלים מהפרקים הקודמים בשאילתה אחת: CTE, LEFT JOIN מ"רשימת כל הערכים" (כדי שחודש ריק יופיע עם 0), ופונקציית חלון. ה־${year}::int — פרמטר עם המרה מפורשת, כי PostgreSQL לא תמיד מנחש את הטיפוס של פרמטר.

⚠️ טעויות נפוצות
  • GROUP BY ישר על orders — חודשים בלי מכירות פשוט לא יופיעו, והגרף בדשבורד "יקפוץ" מפברואר לאפריל.
