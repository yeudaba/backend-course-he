פרק 19 — Prisma ו־migrations

⏱ 5 מפגשים

🧰 לפני שמתחילים — פרק 19

מה צריך שכבר יהיה מותקן: PostgreSQL, מסד course, .env (פרק 16).

מה מתקינים עכשיו:

  • Prisma 7 — כבר רשום ב־package.json של תיקיית הקורס: npm install.
  • תוסף Prisma ל־VS Code (מזהה Prisma.prisma) — צבעים, השלמה ועיצוב לקובצי .prisma.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 19-prisma מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

מסד נפרד לפרק (כדי ש־Prisma לא יתנגש בטבלאות של פרקים 16–18):

% createdb shop                    # ב־EDB: createdb -U postgres shop

והוסף ל־.env של תיקיית הקורס שורה:

SHOP_DATABASE_URL=postgresql://localhost:5432/shop

(ב־EDB: postgresql://postgres:הסיסמה@localhost:5432/shop.) ואז, מתוך תיקיית הפרק:

% cd ~/dev/backend-course/19-prisma/files
% npx prisma migrate dev           # יוצר את הטבלאות לפי prisma/migrations
% npx prisma db seed               # טוען נתוני דוגמה
% npx prisma generate              # מייצר את Prisma Client ל־generated/prisma

✔ בדיקה: npx prisma studio — נפתח דפדפן עם הטבלאות והנתונים. ו־npm run check P19-E06 (מתיקיית הקורס) צריך להיכשל על הקוד שלך — לא על "לא נמצא Prisma Client".

🎯 בסוף הפרק תדע
  • להבין מה ORM עושה, מה הוא חוסך ומה הוא מסתיר.
  • לכתוב schema של Prisma: מודלים, טיפוסים, קשרים, enums ו־indexes.
  • לנהל שינויים במבנה עם migrations — בפיתוח ובייצור.
  • לשלוף ולשנות נתונים עם Prisma Client: סינון, include, pagination, transactions ושגיאות.
  • להעביר את פרויקט 2 ל־PostgreSQL — בלי לגעת ב־routes וב־service.

🤔 למה צריך את זה?

בפרק 18 כתבת SQL כמחרוזות בתוך TypeScript. זה עובד, אבל TypeScript לא יודע מה חוזר מהשאילתה, שגיאת כתיב בשם עמודה מתגלה רק בזמן ריצה, ושינויי מבנה מנוהלים ביד. ORM כמו Prisma נותן טיפוסים מלאים מהסכמה, שאילתות כקוד, ו־migrations שנכנסים ל־Git. Prisma הוא ה־ORM הנפוץ ביותר ב־TypeScript, ומופיע בהרבה משרות. בסוף הפרק פרויקט 2 שומר משימות ב־PostgreSQL — ונשאר עם בדיוק אותו API.
