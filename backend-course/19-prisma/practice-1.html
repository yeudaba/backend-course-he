P19-E43 · איזה SQL Prisma ישלח?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 16, שיעור 1

כתוב את ה־SQL (פרק 16) ששקול לשאילתה מהשיעור. ואז: אם maxPrice מגיע מה־query string ומשתמש שולח "50 OR 1=1" — מה יקרה ב־Prisma? ומה היה קורה עם pool.query(... price &lt; ${maxPrice})?

const products = await prisma.product.findMany({
  where: { isActive: true, price: { lt: maxPrice } },
  select: { id: true, name: true, price: true },
  orderBy: { price: "asc" },
});

🔗 איך זה מתחבר: SELECT, ‏WHERE ו־ORDER BY מפרק 16, ו־SQL injection — והשיעור: "הגנה מ־SQL injection כברירת מחדל".

P19-E44 · ‏ORM לא מונע מרוץ

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 18, שיעור 1

"עברנו ל־Prisma, אז הבאגים של פרק 18 נעלמו". האם זה נכון לקוד הזה? מה יקרה כששני לקוחות קונים את המטחנה האחרונה באותו רגע?

const p = await prisma.product.findUnique({ where: { id: 4 } });
if (!p || p.stock < 1) throw new AppError("OUT_OF_STOCK");
await prisma.product.update({ where: { id: 4 }, data: { stock: p.stock - 1 } });

🔗 איך זה מתחבר: race condition ועדכון אטומי מפרק 18 — והשיעור: ORM משנה את התחביר, לא את מה שקורה במסד.

P19-E45 · ‏snake_case ל־camelCase 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: פרק 2, פרק 7, שיעור 1

עם pg השורות מגיעות עם שמות העמודות של המסד (full_name), ו־Prisma נותן fullName בזכות @map. בקובץ 19-prisma/starter/P19-E45.ts כתוב וייצא:

export function toCamel(name: string): string
export function camelize(row: Record<string, unknown>): Record<string, unknown>
  • toCamel: ‏"full_name" ← "fullName", ‏"is_active" ← "isActive", ‏"created_at_utc" ← "createdAtUtc", ‏"id" ← "id". ‏_ בהתחלה או בסוף, או כמה ברצף — נשארים כמו שהם ("_private", ‏"a__b").
  • camelize: אובייקט חדש עם אותם ערכים (לא נוגעת בערכים — גם Date נשאר אותו אובייקט), ומפתחות לפי toCamel, באותו סדר.
% npm run check P19-E45

🔗 איך זה מתחבר: מחרוזות (replace עם פונקציה, או split/map) מפרק 2, ‏Object.entries/fromEntries מפרק 7 — והשיעור: מה @map חוסך לך.

P19-E46 · מה יש בכתובת המסד? 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: פרק 13, פרק 14, שיעור 1

כשהשרת עולה, טוב להדפיס לאן הוא מתחבר — בלי הסיסמה. בקובץ 19-prisma/starter/P19-E46.ts כתוב וייצא:

export function describeDbUrl(url: string): { host: string; port: number; database: string; user: string; password: string | null }
  • עם המחלקה URL (פרק 14). הפרוטוקול חייב להיות postgresql: או postgres:, ושם מסד (אחרי ה־/) — חובה; אחרת (גם כתובת שלא מתפרקת) ← throw new Error("כתובת מסד לא תקינה").
  • port — מספר; בלי פורט ← 5432. ‏user — מפוענח (%40 ← @), ‏"" אם אין.
  • password — "***" אם יש סיסמה, ו־null אם אין. אף פעם לא הסיסמה עצמה.
% npm run check P19-E46

🔗 איך זה מתחבר: URL מפרק 14 ומשתני סביבה מפרק 13 — והשיעור: DATABASE_URL הוא המחרוזת שכל החלקים של Prisma מקבלים.
