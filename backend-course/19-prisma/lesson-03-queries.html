1. קריאה

    isActive: true,

  },

  orderBy: [{ price: "desc" }, { id: "asc" }],

  take: 10,

findUnique — רק לפי שדה ייחודי (id, email), ומחזיר null אם אין. findFirst — לפי כל תנאי, את הראשון.

2. include: קשרים בלי N+1

const orders = await prisma.order.findMany({
  where: { customerId: 1 },
  orderBy: { createdAt: "desc" },
  include: {
    items: { include: { product: { select: { name: true } } } },
  },
});
// orders[0].items[0].product.name  ← מוקלד

Prisma מריץ שאילתה לכל "רמה" (הזמנות; כל הפריטים שלהן בבת אחת; כל המוצרים בבת אחת) ומחבר בזיכרון — בדיוק "אפשרות 2" משיעור N+1 בפרק 18. אבל לולאה עם findUnique לכל פריט — זה עדיין N+1, גם ב־Prisma.

ולראות מה Prisma שולח: new PrismaClient({ adapter, log: ["query"] }) — כל שאילתה מודפסת. שווה להפעיל מדי פעם בפיתוח.

5. עדכון אטומי ו־transactions

// הורדת מלאי בלי מרוץ — updateMany עם תנאי (כמו P18-E10)
const { count } = await prisma.product.updateMany({
  where: { id: productId, stock: { gte: qty } },
  data: { stock: { decrement: qty } },
});
if (count === 0) throw new AppError("OUT_OF_STOCK");

// interactive transaction — כמה פעולות, הכול או כלום
const order = await prisma.$transaction(async (tx) => {
  const p = await tx.product.updateMany({ where: { id: 1, stock: { gte: 1 } }, data: { stock: { decrement: 1 } } });
  if (p.count === 0) throw new AppError("OUT_OF_STOCK");  // זריקה ← ROLLBACK
  return tx.order.create({ data: { customerId: 1, items: { create: [{ productId: 1, quantity: 1, unitPrice: 89.9 }] } } });
});
⚠️ tx, לא prisma

בתוך ה־callback — כל הפעולות דרך tx. שאילתה דרך prisma רצה מחוץ ל־transaction (חיבור אחר!), ולא תתבטל בכישלון — אותו באג כמו pool.query("BEGIN") בפרק 18.

6. SQL ישיר

const rows = await prisma.$queryRaw<{ category: string; revenue: number }[]>`
  SELECT c.name AS category, SUM(oi.quantity * oi.unit_price)::float AS revenue
  FROM order_items oi
  JOIN products p ON p.id = oi.product_id
  JOIN categories c ON c.id = p.category_id
  WHERE p.price > ${minPrice}
  GROUP BY c.name`;

דוחות עם GROUP BY על כמה טבלאות, חלונות, CTE — ב־SQL זה פשוט יותר. $queryRaw עם template literal (הגרש ההפוך) הופך כל ${...} לפרמטר — בטוח מ־injection. $queryRawUnsafe("..." + x) — לא בטוח, ולא צריך כמעט אף פעם.
