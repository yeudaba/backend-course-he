P19-E68 · ‏$queryRaw מול $queryRawUnsafe

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 16, שיעור 3

לכל אחת — האם בטוחה מ־SQL injection כש־q ו־sort מגיעים מה־URL? אם לא — איך מתקנים?

await prisma.$queryRaw`SELECT id, name FROM products WHERE name ILIKE ${"%" + q + "%"}`;          // 1
await prisma.$queryRawUnsafe(`SELECT id, name FROM products WHERE name ILIKE '%${q}%'`);           // 2
await prisma.$queryRaw`SELECT id, name FROM products ORDER BY ${sort}`;                            // 3
await prisma.$queryRawUnsafe(`SELECT id, name FROM products ORDER BY ${sort}`);                    // 4

🔗 איך זה מתחבר: פרמטרים ו־SQL injection מפרק 16, ורשימה סגורה לשמות עמודות (P17-E67) — והשיעור: "template literal הופך כל ${...} לפרמטר".

P19-E69 · ‏skip: 10000 — מה המסד עושה?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 18, שיעור 3

מסך "כל ההזמנות" עם עמודים של 20, ו־200,000 הזמנות. שתי גרסאות:

await prisma.order.findMany({ orderBy: { id: "asc" }, skip: (page - 1) * 20, take: 20 });   // א
await prisma.order.findMany({ orderBy: { id: "asc" }, where: { id: { gt: after } }, take: 20 }); // ב
  1. איזה SQL כל אחת שולחת (בערך)?
  2. מה קורה בעמוד 5,000?
  3. מתי א׳ בסדר גמור?

🔗 איך זה מתחבר: OFFSET מול keyset ו־EXPLAIN מפרק 18 — והשיעור: skip/take של Prisma הם OFFSET/LIMIT.

P19-E70 · מה רואים ב־log: ["query"]?

P19-E27 · עמוד מוצרים: רשימה וספירה במקביל 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

🔁 חזרה על Promise.all ו־destructuring של מערך (פרקים 7 ו־10) ועל pagination עם OFFSET (‏P16-E14), הפעם ב־Prisma. מסך רשימה צריך שני דברים: המוצרים של העמוד, ו"כמה יש בסך הכול" (בשביל "עמוד 2 מתוך 3"). אלה שתי שאילתות שלא תלויות זו בזו, ולכן שולחים אותן יחד. בקובץ 19-prisma/starter/P19-E27.ts כתוב וייצא:

getProductPage(prisma, { page = 1, pageSize = 5, categoryId } = {}), שמחזירה { items, page, total, pages }:

  • רק מוצרים פעילים. עם categoryId — רק מהקטגוריה הזו.
  • items: ‏{ id, name, price } לפי id, כש־price הוא number. ‏total: כמה מוצרים מתאימים בסך הכול. ‏pages: כמה עמודים (‏Math.ceil). עמוד אחרי הסוף ← items: [], לא שגיאה.
  • findMany ו־count נשלחות במקביל, עם אותו where.
  • page שאינו מספר שלם חיובי ← RangeError("page חייב להיות מספר שלם חיובי"). ‏pageSize שאינו שלם בין 1 ל־50 ← RangeError("pageSize חייב להיות 1–50").
