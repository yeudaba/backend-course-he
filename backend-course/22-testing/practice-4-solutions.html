P22-E65 · ‏toBe, toEqual, toMatchObject — מה עובר? 🧠 הבנה רמה 2

💡 רמז 1

toBe הוא Object.is. ‏toEqual הוא "deep", אבל סלחן ל־undefined.

💡 רמז 2

✅ פתרון
import { expect } from "expect";

  ["toEqual מתעלם מ־undefined", () => expect({ id: 1, note: undefined }).toEqual({ id: 1 })],
  ["toStrictEqual לא מתעלם", () => expect({ id: 1, note: undefined }).toStrictEqual({ id: 1 })],

✔ toEqual מתעלם מ־undefined

P22-E69 · ‏expect משלך 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

פונקציה רקורסיבית equal(a, b, partial): אם אחד מהם לא אובייקט ← Object.is. מערך מול לא־מערך ← false. מערכים ← אורך + כל איבר. אובייקטים ← מפתחות.

💡 רמז 2

"מתעלמים מ־undefined":

const keys = (o) => Object.keys(o).filter((k) => o[k] !== undefined)

ב־partial בודקים רק את המפתחות של b, וכל אחד חייב להיות קיים ב־a (k in a).

✅ פתרון
// P22-E69: expect משלך — toBe, toEqual, toMatchObject, toThrow
type Ctor = new (...args: any[]) => Error;

const isObj = (v: unknown): v is Record<string, unknown> => typeof v === "object" && v !== null;
const keys = (o: Record<string, unknown>) => Object.keys(o).filter((k) => o[k] !== undefined);

function equal(a: unknown, b: unknown, partial: boolean): boolean {
  if (!isObj(a) || !isObj(b)) return Object.is(a, b);
  if (Array.isArray(a) !== Array.isArray(b)) return false;
  if (Array.isArray(a) && Array.isArray(b)) {
    return a.length === b.length && a.every((x, i) => equal(x, b[i], partial));
  }
  if (a instanceof Date || b instanceof Date) {
    return a instanceof Date && b instanceof Date && a.getTime() === b.getTime();
  }
  if (partial) return Object.keys(b).every((k) => k in a && equal(a[k], b[k], true));
  const kb = keys(b);
  return keys(a).length === kb.length && kb.every((k) => equal(a[k], b[k], false));
}

export function expect(actual: unknown) {
  const fail = (what: string) => {
    throw new Error(`expect(${JSON.stringify(actual)}) ${what}`);
  };
  return {
    toBe(expected: unknown) {
      if (!Object.is(actual, expected)) fail(`toBe(${JSON.stringify(expected)})`);
    },
    toEqual(expected: unknown) {
      if (!equal(actual, expected, false)) fail(`toEqual(${JSON.stringify(expected)})`);
    },
    toMatchObject(expected: object) {
      if (!equal(actual, expected, true)) fail(`toMatchObject(${JSON.stringify(expected)})`);
    },
    toThrow(expected?: string | RegExp | Ctor) {
      if (typeof actual !== "function") return fail("toThrow — צריך פונקציה");
      let thrown: unknown;
      let didThrow = false;
      try {
        (actual as () => unknown)();
      } catch (err) {
        didThrow = true;
        thrown = err;
      }
      if (!didThrow) return fail("toThrow — לא נזרקה שגיאה");
      const message = thrown instanceof Error ? thrown.message : String(thrown);
      if (typeof expected === "string" && !message.includes(expected)) fail(`toThrow("${expected}")`);
      if (expected instanceof RegExp && !expected.test(message)) fail(`toThrow(${expected})`);
      if (typeof expected === "function" && !(thrown instanceof expected)) fail(`toThrow(${expected.name})`);
    },
  };
}

עכשיו ההבדלים מ־E65 ברורים מתוך הקוד: toEqual ו־toMatchObject הם אותה רקורסיה, ורק דגל אחד (partial) קובע אם בודקים את כל המפתחות. ו־"מתעלם מ־undefined" הוא סינון אחד של מפתחות.

⚠️ טעויות נפוצות
  • JSON.stringify(a) === JSON.stringify(b) — תלוי בסדר המפתחות, ולא מבחין בין NaN ל־null.
  • typeof null === "object" — בלי הבדיקה, Object.keys(null) זורק.

💡 רמז 2

✅ פתרון
// P22-E70: it.each — טבלה של מקרים ← רשימה של בדיקות עם שמות
export function each<Row>(table: Row[]) {
  return (title: string, fn: (...args: any[]) => void) =>
    table.map((row) => {
      const args: unknown[] = Array.isArray(row) ? row : [row];
      let i = 0;
      const name = title.replace(/%[sd%]/g, (m) => {
        if (m === "%%") return "%";
        const value = args[i++];
        return m === "%d" ? String(Number(value)) : String(value);
      });
      return { name, run: () => fn(...args) };
    });
}

  • replace("%s", ...) עם מחרוזת — מחליף רק את המופע הראשון.

P22-E71 · מריץ מוטנטים משלך 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1
let code = source; for (const [from, to] of m.replace) { if (!code.includes(from)) throw ...; code = code.replace(from, to); }
💡 רמז 2

replace עם מחרוזת מחליף מופע אחד. אבל אם to מכיל $& או $1, יש להם משמעות מיוחדת. כדי להחליף "כמו שזה", העבר פונקציה: code.replace(from, () => to).

✅ פתרון
// P22-E71: mutation testing — הלב של הבודק
export type Mutant = { desc: string; replace: [from: string, to: string][] };
export type Result = { killed: string[]; survived: string[]; score: number };

export async function runMutants(
  source: string,
  mutants: Mutant[],
  runTests: (code: string) => boolean | Promise<boolean>,
): Promise<Result> {
  if (!(await runTests(source))) throw new Error("הבדיקות נכשלות על הקוד התקין");
  const killed: string[] = [];
  const survived: string[] = [];
  for (const m of mutants) {
    let code = source;
    for (const [from, to] of m.replace) {
      if (!code.includes(from)) throw new Error(`"${from}" לא נמצא (${m.desc})`);
      code = code.replace(from, () => to);
    }
    if (await runTests(code)) survived.push(m.desc);
    else killed.push(m.desc);
  }
  const score = mutants.length === 0 ? 100 : Math.round((100 * killed.length) / mutants.length);
  return { killed, survived, score };
}

שלושה פרטים שעושים את ההבדל: בדיקה על הקוד התקין קודם (אחרת "כל המוטנטים נהרגו" כי הבדיקות פשוט שבורות), שגיאה כשההחלפה לא נמצאה (אחרת "מוטנט" זהה למקור תמיד "שורד" ומבלבל), ו־() => to שמונע מ־$ בקוד להתפרש.

⚠️ טעויות נפוצות
  • replaceAll — מוטנט אמור להיות שינוי אחד.
  • לא לחכות ל־runTests (Promise) — כל Promise הוא truthy, וכל המוטנטים "שורדים".

P22-E72 · ‏jest.fn משלך 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

פונקציה פנימית const spy = (...args) => { ... }, ואז Object.assign(spy, { calls: [], ... }). ל־callCount —

Object.defineProperty(spy, "callCount", { get: () => spy.calls.length })
💡 רמז 2

תור: const once: any[] = []; ‏— once.length ? once.shift() : current?.(...args).

✅ פתרון
// P22-E72: createSpy — jest.fn בקטן
export type Spy = ((...args: any[]) => any) & {
  calls: any[][];
  results: any[];
  readonly callCount: number;
  mockReturnValueOnce(value: any): Spy;
  mockImplementation(fn: (...args: any[]) => any): Spy;
  reset(): void;
};

export function createSpy(impl?: (...args: any[]) => any): Spy {
  let current = impl;
  const once: any[] = [];
  const spy = ((...args: any[]) => {
    spy.calls.push(args);
    const value = once.length > 0 ? once.shift() : current?.(...args);
    spy.results.push(value);
    return value;
  }) as Spy;
  spy.calls = [];
  spy.results = [];
  Object.defineProperty(spy, "callCount", { get: () => spy.calls.length });
  spy.mockReturnValueOnce = (value) => {
    once.push(value);
    return spy;
  };
  spy.mockImplementation = (fn) => {
    current = fn;
    return spy;
  };
  spy.reset = () => {
    spy.calls = [];
    spy.results = [];
    once.length = 0;
  };
  return spy;
}

עכשיו ברור למה expect(send).toHaveBeenCalledWith(...) עובד: ה־spy הוא פונקציה רגילה עם מערך calls, ו־toHaveBeenCalledWith פשוט מחפש בו.

⚠️ טעויות נפוצות
  • לרשום ב־calls רק אחרי שה־implementation הצליח — קריאה שזרקה "נעלמת".
  • once.pop() — מחזיר מהסוף, לא לפי הסדר.

// P22-E75: קריאת lcov.info
function parse(lcov: string) {
  const rows: { file: string; line: number; hits: number }[] = [];
  let file = "";
  for (const raw of lcov.split("\n")) {
    const line = raw.trim();
    if (line.startsWith("SF:")) file = line.slice(3);
    else if (line.startsWith("DA:")) {
      const [n, hits] = line.slice(3).split(",");
      rows.push({ file, line: Number(n), hits: Number(hits) });
    }
  }
  return rows;
}

export function uncoveredLines(lcov: string): Record<string, number[]> {
  const out: Record<string, number[]> = {};
  for (const r of parse(lcov)) {
    if (r.hits === 0) (out[r.file] ??= []).push(r.line);
  }
  for (const lines of Object.values(out)) lines.sort((a, b) => a - b);
  return out;
}

export function linePercent(lcov: string): number {
  const rows = parse(lcov);
  if (rows.length === 0) return 100;
  const hit = rows.filter((r) => r.hits > 0).length;
  return Math.round((hit / rows.length) * 1000) / 10;
}

    for (const m of METRICS) {
      const min = limits[m];
      if (min !== undefined && data[m].pct < min) failures.push(`${name} ${m}: ${data[m].pct}% < ${min}%`);
    }
  };
  check("total", summary.total, thresholds);
  if (perFile) {
    for (const [file, data] of Object.entries(summary)) if (file !== "total") check(file, data, perFile);
  }
  return failures;
}

ב־Jest עצמו יש coverageThreshold שעושה את זה. הנקודה כאן: זה רק השוואת מספרים מקובץ JSON. מה שחשוב הוא איזה סף בוחרים, ועל מה (E78).
