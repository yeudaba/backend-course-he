P22-E69 · ‏expect משלך 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 30 דק׳ידע נדרש: שיעור 4

מה בדיוק toEqual בודק? כתוב בעצמך. בקובץ 22-testing/starter/P22-E69.ts כתוב וייצא:

export function expect(actual: unknown): {
  toBe(expected: unknown): void;
  toEqual(expected: unknown): void;
  toMatchObject(expected: object): void;
  toThrow(expected?: string | RegExp | (new (...args: any[]) => Error)): void;
}
  • כשל ← throw new Error(...) (כל הודעה). הצלחה ← כלום.
  • toBe — Object.is.
  • toEqual — השוואה לעומק: אובייקטים לפי מפתחות, מערכים לפי סדר ואורך, ומתעלמת ממפתחות שערכם undefined (כמו Jest). פרימיטיבים — Object.is.
  • toMatchObject — כל מפתח ב־expected חייב להיות קיים ב־actual ולהתאים (לעומק, וגם שם חלקי); מפתחות נוספים ב־actual מותרים. מערכים — האורך חייב להיות שווה.
  • toThrow — actual הוא פונקציה שחייבת לזרוק. מחרוזת ← ההודעה מכילה אותה; ‏RegExp ← מתאים להודעה; class ← instanceof.

הבודק משווה את התוצאות שלך ל־expect האמיתי של Jest על עשרות מקרים.

P22-E72 · ‏jest.fn משלך 🤖
