P00-E01 · תעודת זהות לסביבת העבודה

רמה 1⏱ 5 דק׳ידע נדרש: שיעורים 2–3

המשימה: הרץ ב־Terminal שלוש פקודות שבודקות גרסאות: של Node, של npm ושל VS Code. רשום לעצמך (במחברת או בקובץ) את שלושת המספרים.

ואז ענה במילים: אחת מהשלוש מציגה יותר משורה אחת. איזו, ומה לדעתך השורות הנוספות?

✅ נחשב הצלחה אם: קיבלת שלושה מספרי גרסה, וה־Node הוא 24 ומעלה.

P00-E02 · ניווט בעיניים עצומות

רמה 2⏱ 10 דק׳ידע נדרש: שיעורים 1, 4

המשימה: בלי להשתמש ב־Explorer או ב־Finder, רק בפקודות:

  1. עבור לתיקיית הבית.
  2. משם, עבור לתיקייה starter של פרק 0 — בכמה פקודות cd נפרדות, תיקייה אחת בכל פעם, ותוך שימוש ב־Tab.
  3. הצג את הקבצים שבה.
  4. חזור לתיקיית הקורס (backend-course) — בפקודה אחת.
  5. ודא שהגעת.

פלט צפוי בשלב 3:

P00-E05-predict.js	P00-E06-broken.js	P00-E07-where.js

✅ נחשב הצלחה אם: בשלב 5 pwd מציג /Users/yeuda/dev/backend-course.

P00-E05 · נבא את הפלט

רמה 3⏱ 10 דק׳ידע נדרש: שיעור 5, סעיפים 2 ו־4

המשימה: פתח ב־VS Code את 00-setup/starter/P00-E05-predict.js. לפני שאתה מריץ, כתוב על דף את הפלט המדויק — שורה אחר שורה. רק אחר כך הרץ והשווה.

לכל שורה שטעית בה — כתוב במשפט אחד למה.

✅ נחשב הצלחה אם: הניבוי שלך נכון לפחות ב־5 מתוך 6 שורות הפלט, ואתה יודע להסביר את כל השורות.

P00-E06 · שלושה באגים בחנות

רמה 4⏱ 15 דק׳ידע נדרש: שיעור 5, סעיפים 4–5

המשימה: הקובץ 00-setup/starter/P00-E06-broken.js אמור להדפיס ארבע שורות, אבל יש בו שלוש שגיאות.

  1. העתק אותו קודם ל־playground, כדי שהמקור יישאר: 
    % cp 00-setup/starter/P00-E06-broken.js playground/shop-fix.js
    (cp = copy. מקבלת "מאיפה" ו"לאן".)
  2. הרץ את playground/shop-fix.js.
  3. תקן רק את השגיאה שההודעה מצביעה עליה. שמור והרץ שוב.
  4. חזור על זה עד שהקובץ רץ בלי שגיאות.

P00-E07 · הבלש של Cannot find module

רמה 4⏱ 10 דק׳ידע נדרש: שיעורים 4–5

המצב: אתה נמצא ב־backend-course ומריץ:

% node P00-E07-where.js
Error: Cannot find module '/Users/yeuda/dev/backend-course/P00-E07-where.js'

המשימה:

  1. הסבר במילים: מה Node ניסה לעשות, ולמה זה נכשל?
  2. הרץ את הקובץ בהצלחה בלי לזוז מ־backend-course (בלי cd).
  3. הרץ אותו בהצלחה בדרך שנייה: עם cd.

פלט צפוי: מצאת אותי! הקובץ רץ בהצלחה.

✅ נחשב הצלחה אם: שתי הדרכים עבדו, וההסבר שלך מזכיר את התיקייה הנוכחית.

P00-E08 · אתגר: קבלה של בית קפה

רמה 5 · רשות⏱ 20 דק׳ידע נדרש: כל הפרק

🏁 מבחן מעבר לפרק 1

אתה מוכן לפרק 1 אם — בלי להסתכל בשיעורים — אתה יכול:

  • לפתוח את backend-course ב־VS Code מתוך Terminal רגיל, עם פקודה אחת.
  • ליצור קובץ .js חדש בתיקייה כלשהי, לכתוב בו שתי שורות הדפסה, ולהריץ אותו.
  • להסביר למישהו אחר (או בקול לעצמך) את ההבדל בין פקודת Terminal לשורת קוד.
  • לקבל ReferenceError, לומר באיזו שורה הבעיה ולתקן.
  • לפתור את P00-E06 ו־P00-E07 (תיקון תקלות).
