שיעור 2 — התקנת VS Code ו־Node.js

⏱ ~30 דקות (רובן המתנה להורדות)

🧰 מה מתקינים בשיעור הזה
  • VS Code — code.visualstudio.com/Download
  • Node.js LTS — nodejs.org/en/download
  • Google Chrome — google.com/chrome (אם כבר מותקן — דלג)

הכול חינמי, בלי הרשמה. צריך את סיסמת הכניסה למק (זו שאתה מקליד כשהמחשב נדלק) — ההתקנה תבקש אותה.

🤔 מה כל כלי עושה?

שאלה טבעית: "אבל JavaScript רץ בדפדפן, לא?" — נכון, במקור. Node.js לקח את המנוע שמריץ JavaScript בתוך Chrome, והוציא אותו החוצה, כך שאפשר להריץ JavaScript גם במחשב ובשרתים. זה מה שהופך את JavaScript לשפת Backend.

שלב א׳ — איזה מק יש לי?

  1. לחץ על תפוח בפינה השמאלית העליונה ← About This Mac.
  2. חפש את השורה Chip (או Processor):
    • כתוב Apple M1 / M2 / M3 / M4 ← יש לך Apple Silicon.
    • כתוב Intel ← יש לך Intel.
  3. רשום לעצמך את התשובה. תצטרך אותה עכשיו, ושוב בפרק 23 (Docker).

שלב ב׳ — התקנת VS Code

  1. היכנס ל־code.visualstudio.com/Download.
  2. מתחת לאייקון של Apple לחץ על הכפתור הגדול Mac — הוא מוריד גרסה שמתאימה גם ל־Apple Silicon וגם ל־Intel (Universal). יירד קובץ .zip לתיקייה Downloads.
  3. פתח את Downloads ולחץ פעמיים על ה־.zip. ייווצר האפליקציה Visual Studio Code (אייקון כחול).
  4. חשוב: גרור את Visual Studio Code לתיקייה Applications (בסרגל הצד של Finder). אם תשאיר אותה ב־Downloads — דברים ייכשלו בשיעור 3.
  5. פתח את VS Code מתוך Applications. אם מופיעה הודעה "Visual Studio Code is an app downloaded from the Internet. Are you sure you want to open it?" — לחץ Open. זה תקין: זו הורדה מהאתר הרשמי של Microsoft.
  6. נפתח מסך Welcome. מעולה — אפשר לסגור אותו. נכיר את התוכנה בשיעור 3.
💡 טיפ

כדי לא לחפש את VS Code כל פעם: כשהוא פתוח, לחיצה ימנית על האייקון שלו ב־Dock ← Options ← Keep in Dock.

שלב ג׳ — האם Node.js כבר מותקן?

ייתכן שהוא הותקן בעבר (למשל בתואר). נבדוק לפני שמתקינים. לשם כך נפתח לראשונה את ה־Terminal — חלון שבו כותבים פקודות למחשב. (בשיעור 4 נלמד אותו כמו שצריך; כרגע רק מקלידים פקודה אחת.)

  1. הקש ⌘ + רווח (נפתח Spotlight, החיפוש של המק), הקלד Terminal ולחץ Enter.
  2. ייפתח חלון עם שורה שנראית בערך כך: yeuda@MacBook ~ %. זו "שורת הפקודה" — המחשב מחכה לפקודה.
  3. ודא שהמקלדת באנגלית, הקלד node -v ולחץ Enter.
למה לא להסתפק בגרסה 22?

גרסה 22 עדיין נתמכת ותעבוד ברוב הקורס. אבל עדיף שהגרסה שלך תהיה זהה לגרסה שבה נבדקו הדוגמאות, כדי שהודעות השגיאה ייראו בדיוק כמו בשיעורים. העדכון לוקח 3 דקות.

שלב ד׳ — התקנת Node.js

  1. היכנס ל־nodejs.org/en/download.
  2. בחר את הגרסה שמסומנת LTS (קיצור של Long Term Support — "נתמכת לאורך זמן"). לא את Current.
  3. הורד את macOS Installer (.pkg). האתר מזהה בדרך כלל לבד את סוג המק.
  4. פתח את הקובץ .pkg מ־Downloads ולחץ Continue עד הסוף, אשר את הרישיון והקלד את סיסמת המק כשמתבקש.
  5. בסיום מופיע "The installation was completed successfully". לחץ Close. אם נשאל אם להעביר את קובץ ההתקנה לפח — כן.

שלב ה׳ — בדיקה שהכול עובד

⚠️ קודם לסגור את ה־Terminal ולפתוח חדש

חלון Terminal שהיה פתוח לפני ההתקנה לא "יודע" עליה. סגור אותו (⌘ + Q) ופתח מחדש דרך Spotlight.

הקלד את שתי הפקודות, אחת אחרי השנייה, ו־Enter אחרי כל אחת:

% node -v
v24.11.0
% npm -v
11.6.1

המספרים אצלך יהיו כנראה שונים — זה בסדר. מה שחשוב: אחרי node -v מופיע מספר שמתחיל ב־v והמספר הראשון הוא 24 ומעלה, ואחרי npm -v מופיע מספר כלשהו.

npm הותקן אוטומטית יחד עם Node. זה הכלי להתקנת ספריות קוד — נלמד אותו בפרק 13.

שלב ו׳ — Chrome

אם Chrome עוד לא מותקן: google.com/chrome ← Download ← פתח את הקובץ וגרור ל־Applications. נשתמש בו מפרק 14 כדי "לראות" בקשות שהדפדפן שולח לשרת.

🔍 פירוק הפקודה node -v

חלקמה זה
nodeשם התוכנה שרוצים להפעיל
רווחמפריד בין שם התוכנה לבין מה שנותנים לה. חובה — node-v בלי רווח לא יעבוד
-vדגל (flag) — אפשרות שמשנה את התנהגות התוכנה. v = version. מקף אחד

הרבה כלים מקבלים את אותו הדגל: npm -v, git --version. דגלים עם שני מקפים (--version) הם בדרך כלל הצורה המלאה, ועם מקף אחד — הקיצור.

✍️ תרגול קצר

1. הרץ node --version (שני מקפים, המילה המלאה). האם התוצאה שונה מ־node -v?

תשובה
זהה. -v הוא קיצור של --version.

2. מה ההבדל בין VS Code ל־Node.js, במשפט אחד?

תשובה
ב־VS Code כותבים את הקוד; Node.js מריץ אותו.

3. התקנת Node עם Terminal פתוח, ומיד הקלדת node -v וקיבלת command not found. מה הצעד הראשון?

תשובה
לסגור את ה־Terminal לגמרי ולפתוח חדש. חלון שנפתח לפני ההתקנה לא מכיר אותה.
💼 בעולם העבודה

בחברה תפגוש בדרך כלל כלי בשם nvm שמאפשר להחזיק כמה גרסאות Node במקביל, כי פרויקטים שונים דורשים גרסאות שונות. נכיר אותו בפרק 13 — לעכשיו, גרסה אחת מספיקה. שאלת ראיון נפוצה: "מה זה Node.js?" — תשובה טובה: "סביבת ריצה ל־JavaScript מחוץ לדפדפן, שמבוססת על מנוע V8 של Chrome, ומשמשת בעיקר לבניית שרתים."
