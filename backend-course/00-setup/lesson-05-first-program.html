שיעור 5 — תוכנית ראשונה וקריאת שגיאות

⏱ ~30 דקות · אין התקנות חדשות

🧰 לפני שמתחילים

צריך: VS Code פתוח על ~/dev/backend-course, Terminal פתוח בפאנל התחתון, והתיקייה playground משיעור 4. בדיקה: node -v מחזיר גרסה.

1. 👣 התוכנית הראשונה

  1. ב־Explorer, לחיצה ימנית על התיקייה playground ← New File… ← הקלד hello.js ← Enter. הקובץ נפתח בעורך.
  2. העבר את המקלדת לאנגלית, והקלד בדיוק את זה (עדיף להקליד ולא להעתיק — כך הידיים לומדות את הסימנים): playground/hello.js 
    console.log("שלום עולם");
console.log("זו התוכנית הראשונה שלי");
  3. שמור: ⌘ + S (גם אם הפעלת Auto Save — הרגל טוב). ה־● בלשונית הופך ל־✕.
  4. ב־Terminal, מתוך backend-course, הקלד:
% node playground/hello.js
שלום עולם
זו התוכנית הראשונה שלי

🎉 זהו. כתבת קוד, Node הריץ אותו, והפלט הופיע. כל Backend — גם של חברות ענק — מתחיל בדיוק כך: קובץ .js ופקודה node.

3. ⚠️ הכלל החשוב בשיעור: פקודה ≠ קוד

יש עכשיו שני "מקומות כתיבה", ולכל אחד שפה משלו. הבלבול ביניהם הוא הטעות הנפוצה ביותר בשבועות הראשונים.

מה קורה אם מתבלבלים?

playground/hello.js (שגוי!) 
node hello.js
% node playground/hello.js
/Users/yeuda/dev/backend-course/playground/hello.js:1
node hello.js
     ^^^^^

SyntaxError: Unexpected identifier 'hello'

Node ניסה לקרוא node hello.js כאילו זה JavaScript, ולא הבין. ובכיוון ההפוך — console.log("שלום") שהוקלד ב־Terminal ייתן שגיאה מוזרה של zsh (כמו zsh: unknown file attribute), כי ה־Terminal לא מבין JavaScript.

4. איך קוראים הודעת שגיאה

שגיאות הן לא כישלון — הן המחשב שמספר לך בדיוק מה הבעיה ואיפה. מתכנתים מנוסים לא עושים פחות שגיאות; הם פשוט קוראים אותן מהר. נשבור את הקוד בכוונה:

שים לב לשני דברים:

  • השורה הראשונה כן הודפסה (שלום). Node מבצע שורה אחר שורה ונעצר בשגיאה הראשונה — מה שלפניה כבר קרה.
  • אם התקנת Error Lens, השגיאה מופיעה גם בעורך עצמו, באדום, ליד השורה — לפעמים עוד לפני שהרצת.

"לא מוצא את הקובץ". תסתכל על הנתיב בהודעה: Node חיפש את hello.js ישירות ב־backend-course, אבל הקובץ נמצא ב־playground. שני פתרונות: node playground/hello.js, או cd playground ואז node hello.js. כלל אצבע: כשמופיע Cannot find module — הרץ pwd ו־ls.

5. שיטת עבודה מול שגיאה

  1. קרא את שורת סוג השגיאה (③). תרגם לעצמך לעברית.
  2. מצא את הקובץ והשורה (①). ב־VS Code: ⌘ + P, הקלד :2 ו־Enter — קופץ לשורה 2. (או ⌘ + לחיצה על הנתיב בתוך ה־Terminal.)
  3. הסתכל איפה החץ ^ (②), ובדוק גם את השורה שלפני — לפעמים הבעיה האמיתית שם.
  4. שנה דבר אחד, שמור, הרץ שוב. לא חמישה שינויים בבת אחת — אחרת לא תדע מה תיקן.
  5. נתקעת יותר מ־10 דקות? העתק את כל הודעת השגיאה ואת הקוד, ושלח לי.

בשורה הראשונה יש מירכאות — זה טקסט, ומודפס כמו שהוא. בשורה השנייה אין מירכאות — זה חישוב, ומודפסת התוצאה. נלמד את זה לעומק בפרקים 1–2.

3. מה הבעיה, ואיזו שגיאה תתקבל? console.log("שלום") כשהמירכאות השנייה היא ” (מירכאות מעוגלות שהועתקו ממסמך Word).

תשובה
SyntaxError: Invalid or unexpected token. ל־JavaScript, ” הוא לא סוגר מחרוזת — רק " ישר. לכן לא מעתיקים קוד מ־Word או מ־WhatsApp.
