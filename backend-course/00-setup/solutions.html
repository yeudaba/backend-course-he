P00-E01 · תעודת זהות לסביבת העבודה

💡 רמז 1
כל שלוש הפקודות בנויות אותו דבר: שם הכלי, רווח, ודגל שמבקש גרסה.
💡 רמז 2
ל־Node ול־npm השתמשנו ב־-v. ל־VS Code — --version (שיעור 3, סעיף 4).
✅ פתרון
% node -v
v24.11.0
% npm -v
11.6.1
% code --version
1.105.1
7d842fb85a0275a4a8e4d7e040d2625abbf7f084
arm64

(המספרים אצלך יהיו שונים.) code --version מציג שלוש שורות: הגרסה, מזהה ה־commit — "טביעת אצבע" של הגרסה המדויקת שנבנתה (נכיר commit בפרק 9), וסוג המעבד — arm64 ב־Apple Silicon או x64 ב־Intel.

⚠️ טעויות נפוצות
  • להריץ את code --version ולחשוב שהשורה השנייה (המחרוזת הארוכה) היא שגיאה — היא לא. -v עובד כאן כקיצור.
  • command not found: code — לא התקנת את פקודת code, או לא פתחת Terminal חדש אחר כך (שיעור 3, סעיף 4).

P00-E02 · ניווט בעיניים עצומות

💡 רמז 1
הנתיב המלא שאליו צריך להגיע: ~/dev/backend-course/00-setup/starter. כל / הוא פקודת cd אחת.
💡 רמז 2
מ־starter צריך לעלות שתי רמות כדי להגיע ל־backend-course. .. עולה אחת — ואפשר לשרשר: ../...
✅ פתרון
% cd ~

הסבר: ../.. פירושו "עלה תיקייה אחת, ומשם עוד אחת": starter ← 00-setup ← backend-course.

פתרון חלופי לשלב 4: cd ~/dev/backend-course — נתיב מלא. עובד מכל מקום, אבל ארוך יותר.

⚠️ טעויות נפוצות
  • cd .. פעם אחת בלבד — מגיעים ל־00-setup ולא ל־backend-course. pwd חושף את זה מיד.
  • הקלדת cd 00-Setup עם S גדולה — ב־Mac לפעמים עובד, אבל בתיקייה יופיע שם לא מדויק. התרגל ל־Tab.

P00-E03 · בונים חנות (של תיקיות)

💡 רמז 1
קודם תיקיות (mkdir), אחר כך קבצים (touch). אי אפשר ליצור קובץ בתוך תיקייה שעוד לא קיימת.
💡 רמז 2
קודם צריך את shop, ורק אחריה את products ו־orders שבתוכה.
✅ פתרון
% cd playground
% mkdir shop
% mkdir shop/products
% mkdir shop/orders
% touch shop/readme.txt
% touch shop/products/list.txt
% touch shop/orders/today.txt
% ls shop
orders		products	readme.txt
% ls shop/products
list.txt

הרחבה (לא חובה): אפשר לתת ל־mkdir ול־touch כמה שמות באותה פקודה, מופרדים ברווח: mkdir shop/products shop/orders. והדגל -p יוצר את כל התיקיות בדרך: mkdir -p shop/products עובד גם אם shop עוד לא קיימת.

⚠️ טעויות נפוצות
  • mkdir shop/products לפני ש־shop קיימת → mkdir: shop: No such file or directory.
  • touch shop/products/list.txt כשאתה לא ב־playground → הקובץ ייווצר במקום אחר, או שתקבל No such file or directory. בדוק עם pwd.

P00-E06 · שלושה באגים בחנות

💡 רמז 1
אל תחפש את שלושת הבאגים בבת אחת. הרץ, קרא רק את שורת סוג השגיאה ואת מספר השורה, ותקן רק שם.
💡 רמז 2
שלושת הבאגים הם בדיוק שלושת סוגי השגיאות מהטבלה בשיעור 5, סעיף 4 — אחד מכל סוג.
✅ פתרון

סבב 1:

…/playground/shop-fix.js:2
console.log("המוצר: מחברת";
            ^^^^^^^^^^^^^^

SyntaxError: missing ) after argument list

שורה 2: חסר ) לפני ה־;. תיקון: console.log("המוצר: מחברת");. שום דבר לא הודפס — בשגיאת תחביר Node לא מריץ אף שורה.

סבב 2:

…/playground/shop-fix.js:4
console.log("תודה ולהתראות”);
            ^^^^^^^^^^^^^^^^^

SyntaxError: Invalid or unexpected token

שורה 4: המירכאות הסוגרות הן ” (מעוגלות) במקום " (ישרות). Node לא רואה סוף למחרוזת. תיקון: למחוק את ” ולהקליד " במקלדת אנגלית. שוב שום דבר לא הודפס.

שים לב: בסבב 1 Node דיווח רק על השגיאה הראשונה שמצא. השגיאה בשורה 4 הייתה שם כל הזמן — היא פשוט לא דווחה עד שתוקנה הקודמת.

סבב 3:

ברוכים הבאים לחנות
המוצר: מחברת
…/playground/shop-fix.js:3
Console.log("מחיר: 12 ש״ח");
^

ReferenceError: Console is not defined

שורה 3: Console עם C גדולה. ל־JavaScript, Console ו־console הם שני שמות שונים לגמרי, ורק השני קיים. תיקון: console. הפעם שתי שורות כן הודפסו — כי זו שגיאה בזמן ריצה, והשורות שלפניה כבר רצו.

הטבלה המלאה:

סבבסוגשורההבעיההודפס משהו לפני?
1SyntaxError2חסר )לא
2SyntaxError4מירכאות מעוגלות ”לא
3ReferenceError3Console עם אות גדולהכן — שתי שורות

קובץ מתוקן: 00-setup/solutions/P00-E06-fixed.js

מה כדאי לקחת מזה: שגיאות התחביר (SyntaxError) מגיעות קודם, גם כשהן בשורה מאוחרת יותר, כי Node בודק את כל הקובץ לפני שהוא מתחיל להריץ.

⚠️ טעויות נפוצות
  • לתקן את Console ראשון כי "רואים אותו" — זה עובד, אבל מפספס את מטרת התרגיל: לעבוד לפי ההודעה.
  • להחליף את ” ב־“ — גם היא מעוגלת. רק " ישרה.
  • לשנות את ש״ח — הגרשיים העבריים ״ בתוך המחרוזת תקינים לגמרי. הם חלק מהטקסט, לא סוגרים אותו.

P00-E07 · הבלש של Cannot find module

💡 רמז 1
קרא את הנתיב בהודעה. היכן Node חיפש את הקובץ? היכן הוא באמת נמצא?
💡 רמז 2
Node מחפש את שם הקובץ יחסית לתיקייה שבה אתה נמצא. אפשר לתת לו נתיב שכולל את התיקיות בדרך.
✅ פתרון

א. ההסבר: Node חיפש את P00-E07-where.js בתיקייה הנוכחית (backend-course), כי לא נתנו לו נתיב אחר. אבל הקובץ נמצא שתי תיקיות פנימה: 00-setup/starter.

ב. בלי לזוז:

% node 00-setup/starter/P00-E07-where.js
מצאת אותי! הקובץ רץ בהצלחה.

ג. עם cd:

% cd 00-setup/starter
% node P00-E07-where.js
מצאת אותי! הקובץ רץ בהצלחה.
% cd ../..

(cd ../.. בסוף — כדי לחזור לנקודת המוצא. הרגל טוב.)

⚠️ טעויות נפוצות
  • node starter/P00-E07-where.js — חסרה תיקייה בדרך (00-setup).
  • node /00-setup/starter/... — / בהתחלה פירושו "משורש המחשב", לא מהתיקייה הנוכחית.

אין פתרון אחד נכון. העיצוב, הפריטים והמחירים — לבחירתך. מה שנבדק: הסכום מחושב ב־Node, והקובץ במקום הנכון.

חולשה בפתרון הזה, שנתקן בפרק 1: המחירים כתובים פעמיים — פעם בטקסט ופעם בחישוב. אם המחיר של הקרואסון ישתנה, צריך לזכור לעדכן בשני מקומות. משתנים (פרק 1) פותרים בדיוק את זה.

תשובה לשאלה למחשבה: בפרק 2 נלמד לחבר טקסט ומספר באותה שורה. הצצה: console.log("סה״כ:", 12 + 14 + 8); — פסיק בין שני דברים מדפיס אותם יחד, עם רווח ביניהם.
