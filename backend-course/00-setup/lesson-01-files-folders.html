🤔 למה צריך את זה בכלל?

כשמתכנתים, כל הזמן אומרים למחשב "תריץ את הקובץ הזה" או "תפתח את התיקייה הזאת". המחשב לא מנחש — הוא צריך כתובת מדויקת. רוב התקלות הראשונות של מתחילים הן לא בקוד, אלא ב"המחשב לא מוצא את הקובץ". השיעור הזה מונע את זה.

1. קובץ ותיקייה

קובץ (File) הוא מסמך אחד: תמונה, מסמך Word, או קובץ קוד. תיקייה (Folder) היא מגירה שמחזיקה קבצים ותיקיות נוספות. תיקייה בתוך תיקייה בתוך תיקייה — כך נוצר עץ.

2. סיומת — מה בא אחרי הנקודה

לשם של קובץ יש בדרך כלל סיומת (Extension): photo.jpg, cv.pdf, hello.js. הסיומת אומרת למחשב (ולך) איזה סוג קובץ זה:

סיומתסוגמתי נפגוש
.jsקוד JavaScriptכבר בשיעור 5
.tsקוד TypeScriptפרק 11
.jsonנתונים בפורמט JSONפרקים 7, 13
.htmlדף אינטרנט (כמו הדף הזה)עכשיו, ובפרק 15.5
.mdמסמך טקסט מעוצב (README)פרק 9
⚠️ ה־Mac מסתיר סיומות כברירת מחדל

זה גורם לבלבול: קובץ שנראה כמו hello הוא בעצם hello.js (או גרוע — hello.js.txt). נבקש מה־Finder להציג תמיד סיומות:

  1. פתח Finder (הפרצוף הכחול־לבן ב־Dock, למטה).
  2. בתפריט העליון: Finder ← Settings (או הקש ⌘ + ,).
  3. לשונית Advanced ← סמן ✔ את Show all filename extensions.

3. נתיב — הכתובת של קובץ

נתיב (Path) הוא רשימת התיקיות שעוברים בהן מלמעלה עד הקובץ, עם / ביניהן. כמו כתובת: עיר / רחוב / בית / דירה.

קיצור חשוב: הסימן ~

הסימן ~ (טילדה) הוא קיצור של תיקיית הבית שלך. אצלך ~ שווה ל־/Users/yeuda. לכן שני הנתיבים האלה זהים:

/Users/yeuda/dev/backend-course
~/dev/backend-course

איך מקלידים אותו: עובר למקלדת אנגלית, ומקיש ⇧ Shift + המקש שמשמאל ל־1 (המקש `, מעל Tab).

למה בלי עברית ובלי רווחים?

שם כמו הקורס שלי עובד מצוין ב־Finder, אבל ב־Terminal הרווח נחשב "סוף המילה". הפקודה cd הקורס שלי תיקרא כאילו כתבת שתי מילים נפרדות — ותיכשל. לכן תיקיות קוד נקרא תמיד באנגלית, באותיות קטנות, עם מקף במקום רווח: backend-course, tasks-api.

4. 👣 עושים: יוצרים את תיקיית העבודה

חומרי הקורס (כולל הדף שאתה קורא) נמצאים כרגע כאן:

~/Desktop/Backend/backend-course

נעביר אותם למקום הקבוע: ~/dev/backend-course.

  1. פתח Finder. בתפריט העליון: Go ← Home (או ⌘ + ⇧ + H). אתה בתיקיית הבית — בכותרת החלון כתוב yeuda.
  2. צור תיקייה חדשה: File ← New Folder (או ⌘ + ⇧ + N). קרא לה dev — באותיות קטנות — ולחץ Enter.
  3. פתח חלון Finder נוסף (⌘ + N), ועבור ל־Desktop ← Backend.
  4. גרור את התיקייה backend-course לתוך התיקייה dev תוך כדי החזקת ⌥ Option. ההחזקה גורמת להעתקה במקום העברה (יופיע + ירוק ליד הסמן) — כך נשאר עותק גיבוי על שולחן העבודה.
  5. פתח את dev ← backend-course ← README.html בלחיצה כפולה. הדף נפתח בדפדפן. מעכשיו עובדים רק מהעותק הזה.
✅ איך יודעים שהצליח?

בשורת הכתובת של הדפדפן מופיע נתיב שמסתיים ב־/Users/yeuda/dev/backend-course/README.html. אם מופיע Desktop בנתיב — אתה עדיין בעותק הישן.

⚠️ טעויות נפוצות
  • קראתי לתיקייה Dev עם D גדולה. ב־Mac זה בדרך כלל יעבוד, אבל בשרתים (Linux) Dev ו־dev הם שני שמות שונים. נתרגל מעכשיו לאותיות קטנות. לתיקון: לחיצה על השם ← Enter ← שינוי.
  • יצרתי את dev בתוך Desktop. הנתיב יהיה ~/Desktop/dev ולא ~/dev. גרור אותה לתיקיית הבית.
  • הגרירה העבירה במקום להעתיק. לא נורא — התיקייה במקום הנכון. פשוט לא נשאר גיבוי.
