שיעור 3 — סיור ב־VS Code

⏱ ~25 דקות

🧰 לפני שמתחילים

צריך שכבר יהיה מותקן: VS Code (שיעור 2), והתיקייה ~/dev/backend-course (שיעור 1).

מה מתקינים בשיעור: פקודת code, ושני תוספים:

  • Error Lens — מזהה: usernamehw.errorlens
  • Live Preview — מזהה: ms-vscode.live-server (של Microsoft)

1. פותחים תיקייה — לא קובץ

ב־VS Code עובדים תמיד על תיקייה שלמה (פרויקט), לא על קובץ בודד. כך התוכנה רואה את כל הקבצים, וה־Terminal שבתוכה יודע איפה הוא נמצא.

  1. ב־VS Code: File ← Open Folder…
  2. בחלון שנפתח: בסרגל הצד לחץ על תיקיית הבית (yeuda, עם אייקון בית). אם היא לא מופיעה — ⌘ + ⇧ + H.
  3. היכנס ל־dev, סמן את backend-course (לחיצה אחת, לא להיכנס) ולחץ Open.
  4. תופיע שאלה "Do you trust the authors of the files in this folder?" — לחץ Yes, I trust the authors. (את הקבצים האלה כתבנו אנחנו. בעתיד, על קוד שהורדת ממקור לא מוכר — לחשוב פעמיים.)

שים לב: ממשק VS Code מסודר משמאל לימין, הפוך מהדף הזה. הסרגלים בצד שמאל.

הנקודה הלבנה בלשונית

באיור, ליד hello.js יש ●. פירושו: יש שינויים שלא נשמרו. כשתשמור (⌘ + S) הנקודה תהפוך ל־✕. Node מריץ את מה ששמור בדיסק, לא את מה שמוצג על המסך — זו הסיבה מספר אחת ל"שיניתי את הקוד ושום דבר לא השתנה".

3. פתיחת ה־Terminal המובנה

במקום לעבור בין VS Code לאפליקציית Terminal נפרדת, נשתמש ב־Terminal שבתוך VS Code:

  1. בתפריט העליון: Terminal ← New Terminal. (קיצור: Ctrl + ` — עם מקלדת באנגלית.)
  2. בתחתית נפתח פאנל עם שורה שנגמרת ב־backend-course %. ה־Terminal כבר נמצא בתוך תיקיית הפרויקט — זה היתרון הגדול.
  3. הקלד node -v ו־Enter כדי לוודא שהוא עובד גם כאן.

4. התקנת פקודת code

הפקודה code מאפשרת לפתוח תיקייה ב־VS Code ישירות מה־Terminal. היא לא מותקנת כברירת מחדל ב־Mac.

  1. הקש ⌘ + ⇧ + P. נפתח בראש המסך שדה חיפוש — זו לוח הפקודות (Command Palette). דרכו אפשר להפעיל כל פעולה ב־VS Code בהקלדת שמה.
  2. הקלד shell command. תופיע האפשרות Shell Command: Install 'code' command in PATH. לחץ עליה.
  3. ייתכן שתתבקש סיסמת מק. בסיום מופיעה הודעה קטנה בפינה: Shell command 'code' successfully installed in PATH.
  4. בדיקה: סגור את ה־Terminal שבפאנל (אייקון הפח 🗑 בפינת הפאנל), פתח חדש (Terminal ← New Terminal), והקלד:
% code --version
1.105.1
...

מופיע מספר גרסה (ועוד שתי שורות)? הצלחת. המספר אצלך יהיה שונה.

✘ אם מופיע command not found: code
  • ודא ש־VS Code נמצא ב־Applications ולא ב־Downloads (שיעור 2, שלב ב׳, צעד 4). אם לא — סגור את VS Code, גרור אותו ל־Applications, פתח מחדש וחזור על ההתקנה.
  • ודא שפתחת Terminal חדש אחרי ההתקנה.

5. התקנת תוספים

  1. לחץ על אייקון Extensions בסרגל הפעולות (ארבעה ריבועים, אחד מהם נפרד) או ⌘ + ⇧ + X.
  2. בשדה החיפוש הקלד Error Lens. ודא שהיוצר הוא Alexander (מזהה usernamehw.errorlens) ולחץ Install.
  3. חפש Live Preview. ודא שהיוצר הוא Microsoft ולחץ Install.

דרך חלופית — מה־Terminal, עכשיו כשיש לך את code:

% code --install-extension usernamehw.errorlens
% code --install-extension ms-vscode.live-server
⚠️ זהירות מתוספים מזויפים

בחנות התוספים יש לפעמים תוספים עם שם דומה מיוצרים לא מוכרים. התקן רק לפי המזהה שבקורס, ובדוק את שם היוצר ומספר ההורדות (במיליונים).

לנסות את Live Preview

ב־Explorer, לחיצה ימנית על README.html ← Show Preview. דף הבית של הקורס ייפתח בתוך VS Code, בצד. כך אפשר לקרוא שיעור ולכתוב קוד באותו חלון.

6. שתי הגדרות שיחסכו לך תסכול

  1. שמירה אוטומטית: בתפריט File לחץ על Auto Save (יופיע ✓ לידו). מעכשיו הקובץ נשמר לבד שנייה אחרי שהפסקת להקליד.
  2. גודל טקסט: ⌘ + = מגדיל, ⌘ + - מקטין. בחר גודל שנוח לקרוא בלי להתאמץ.
