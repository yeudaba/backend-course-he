שיעור 4 — ה־Terminal: שש פקודות שצריך

⏱ ~25 דקות · אין התקנות חדשות

🧰 לפני שמתחילים

פתח את VS Code על ~/dev/backend-course, ופתח Terminal: Terminal ← New Terminal. כל הפקודות בשיעור נכתבות שם.

🤔 למה לא פשוט ללחוץ עם העכבר?

כי כמעט כל כלי של מפתחים — Node, npm, Git, Docker — עובד דרך פקודות. ובשרתים אין בכלל עכבר ומסך. ה־Terminal הוא לא "עולם של האקרים"; הוא פשוט עוד דרך לעשות את מה שאתה כבר עושה ב־Finder: לראות מה יש בתיקייה, לעבור לתיקייה אחרת וליצור קבצים.

1. מבנה של פקודה

⚠️ על הסימן %

בקורס, כל שורה שמתחילה ב־% היא פקודה. ה־% הוא ה־prompt — הסימן שה־Terminal מציג כשהוא מחכה לך. מקלידים רק את מה שאחריו. שורות בלי % הן פלט — מה שהמחשב עונה.

2. שש הפקודות

📍 pwd — איפה אני?

print working directory: מדפיס את הנתיב של התיקייה שאתה "נמצא" בה עכשיו.

% pwd
/Users/yeuda/dev/backend-course

👀 ls — מה יש כאן?

list: מציג את הקבצים והתיקיות בתיקייה הנוכחית. כמו להסתכל בחלון ה־Finder.

% ls
00-setup	README.html	assets		glossary.html

🚶 cd — לעבור לתיקייה

change directory. זו הפקודה שתשתמש בה הכי הרבה.

פקודהמה קורה
cd 00-setupנכנס לתיקייה 00-setup שנמצאת בתוך התיקייה הנוכחית
cd ..עולה תיקייה אחת למעלה (לתיקיית "האבא"). שתי נקודות = "אחת למעלה"
cd ~ או סתם cdחוזר לתיקיית הבית
cd ~/dev/backend-courseקופץ ישר לתיקייה לפי נתיב מלא, מכל מקום

📁 mkdir — יצירת תיקייה

make directory. בדיוק כמו New Folder ב־Finder.

% mkdir playground
% ls
00-setup	README.html	assets		glossary.html	playground

שים לב: כש־mkdir מצליחה, היא לא כותבת כלום. בעולם ה־Terminal, שקט = הצלחה. רק כשיש בעיה מופיעה הודעה.

📄 touch — יצירת קובץ ריק

% touch playground/test.js

יוצר קובץ ריק בשם test.js בתוך playground. הוא יופיע מיד גם ב־Explorer של VS Code — זה אותו קובץ, רק נראה משני מקומות.

🧹 clear — ניקוי המסך

מנקה את כל מה שכתוב בחלון. לא מוחק שום קובץ — רק את התצוגה. (קיצור: ⌘ + K.)

3. ארבעה טריקים שחוסכים הקלדה

מקשמה עושה
Tabהשלמה אוטומטית. הקלד cd 00 ולחץ Tab — ה־Terminal ישלים ל־cd 00-setup/. גם חוסך זמן, גם מונע שגיאות כתיב. השתמש בו כל הזמן.
↑מחזיר את הפקודה הקודמת. לחיצה נוספת — את זו שלפניה.
Ctrl + Cעוצר פקודה שרצה ולא נגמרת (למשל שרת — מפרק 15). גם יוצא ממצבים "תקועים". שים לב: Ctrl, לא ⌘.
גרירהגרירת קובץ או תיקייה מ־Finder לתוך ה־Terminal כותבת את הנתיב המלא שלהם.

4. ומה עם שמות עם רווחים?

לפעמים אין ברירה: גם ב־Mac עצמו יש תיקיות עם רווח בשם, למשל Application Support (שם תוכנות שומרות הגדרות). כדי להגיע לתיקייה כזו, עוטפים את הנתיב במירכאות:

% cd ~/Library/Application Support
cd: string not in pwd: /Users/yeuda/Library/Application
% cd "$HOME/Library/Application Support"
% pwd
/Users/yeuda/Library/Application Support

בלי מירכאות, ה־Terminal חושב שהרווח מפריד בין שני חלקים שונים — ונכשל. עם מירכאות זה עובד, אבל מסורבל. בגלל זה התיקיות שלנו בלי רווחים. (בתוך מירכאות כותבים $HOME במקום ~, כי ~ בתוך מירכאות לא מתורגם.)

⚠️ טעויות נפוצות

מה כתבתמה הופיעמה קרה ואיך מתקנים

CD ..לא מופיעה שגיאה, אבל pwd מראה שלא זזתפקודות נכתבות באותיות קטנות. תמיד. (ב־Mac CD מפעיל משהו אחר שלא עושה כלום; בשרת Linux תקבל שגיאה.)
cd..zsh: command not found: cd..חסר רווח בין cd ל־...
הקלדת % ls כולל ה־%fg: no current job (הודעה מבלבלת)את ה־% לא מקלידים — הוא רק מסמן שזו פקודה.
כתבת פקודה בעברית בטעות: ךדzsh: command not found: ךדהמקלדת הייתה בעברית. החלף לאנגלית (Ctrl + רווח או 🌐).

✍️ תרגול קצר

התחל מ־~/dev/backend-course (הרץ pwd כדי לוודא).

1. היכנס ל־00-setup והצג את מה שיש בה. כמה קבצי .html יש שם?

פתרון
% cd 00-setup
% ls
ספור את הקבצים שנגמרים ב־.html בפלט.

2. מתוך 00-setup, חזור לתיקיית הקורס בפקודה אחת, ובדוק שהגעת.

פתרון
% cd ..
% pwd
/Users/yeuda/dev/backend-course

3. בתוך playground (שיצרת בשיעור), צור תיקייה בשם notes, ובתוכה קובץ בשם day1.txt. השתמש רק ב־Terminal.

פתרון
% cd playground
% mkdir notes
% touch notes/day1.txt
% ls notes
day1.txt
אפשר גם cd notes ואז touch day1.txt — שתי הדרכים נכונות.
