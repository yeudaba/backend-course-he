שיעור 1 — אובייקט: שדות, גישה ושינוי

⏱ ~30 דקות

🎯 בשיעור הזה
  • ליצור אובייקט, לקרוא ולשנות שדות.
  • גישה עם נקודה ועם סוגריים מרובעים.
  • אובייקט בתוך אובייקט, וגישה בטוחה עם ?..
  • מתודות — פונקציות שהן שדה.

console.log(product.price * 2);
console.log(product.tags[0]);
console.log(product.color);

השוואה למערך: במערך מגיעים לערך לפי מיקום ([0]); באובייקט — לפי שם. כשהנתונים הם "רשימה של דברים מאותו סוג" — מערך. כשהם "תכונות של דבר אחד" — אובייקט.

2. שינוי, הוספה ומחיקה

const user = { name: "דנה", age: 31 };
user.age = 32;
user.email = "dana@mail.com";
delete user.name;
console.log(user);
{ age: 32, email: 'dana@mail.com' }

כמו במערך: const מונע להחליף את האובייקט כולו, אבל לא לשנות שדות בתוכו.

3. סוגריים מרובעים — כשהשם במשתנה

const prices = { coffee: 12, tea: 9 };
const item = "tea";
console.log(prices[item]);
console.log(prices.item);
prices["hot chocolate"] = 15;
console.log(prices);
9
undefined
{ coffee: 12, tea: 9, 'hot chocolate': 15 }

prices.item מחפש שדה ששמו המילה "item". prices[item] מחפש שדה ששמו מה שבתוך המשתנה — "tea". כלל: נקודה כשאתה יודע את השם בזמן כתיבת הקוד; סוגריים כשהשם מגיע ממשתנה (או כשיש בו רווח).

💡 מחירון במקום switch

זוכר את ה־switch הארוך של המחירון ב־P05-E24? עכשיו: const catalog = { "KB-101": 199, "KB-102": 249 }; const price = catalog[code] ?? null; — שורה אחת, וקל להוסיף מוצר.

4. אובייקטים מקוננים וגישה בטוחה

const order = {
  id: 1042,
  customer: { name: "עומר", address: { city: "אילת" } },
  coupon: null,
};
console.log(order.customer.address.city);
console.log(order.coupon?.code);
console.log(order.customer?.phone?.mobile);
console.log(order.coupon?.code ?? "ללא קופון");
אילת
undefined
undefined
ללא קופון
⚡ חשוב גם במסלול המהיר — השגיאה הנפוצה ביותר ב־JavaScript

בלי ?., order.coupon.code קורס: TypeError: Cannot read properties of null (reading 'code'). זו כנראה השגיאה שתראה הכי הרבה בקריירה. היא אומרת: "ניסית לקרוא שדה (code) מתוך משהו שהוא null (או undefined)". הדרך לקרוא אותה: מה שמשמאל לנקודה היה ריק. a?.b עוצר בשקט ומחזיר undefined אם a ריק — ובשילוב עם ?? נותן ברירת מחדל.

אבל זהירות: אל תפזר ?. בכל מקום "ליתר ביטחון". אם שדה חייב להיות קיים, עדיף שגיאה מיידית מאשר undefined שזולג הלאה. ?. — רק לשדות שבאמת אופציונליים.

5. מתודות — פונקציה בתוך אובייקט

const cart = {
  items: [12, 14, 8],
  total() {
    return this.items.reduce((s, p) => s + p, 0);
  },
};
console.log(cart.total());
console.log("שלום".toUpperCase());
34
שלום

שדה שהערך שלו פונקציה נקרא מתודה. this בתוך מתודה הוא "האובייקט שלפני הנקודה" (כאן cart). עכשיו מובן גם "x".toUpperCase() — מחרוזות הן "כמו אובייקטים" עם מתודות מובנות. נעמיק במתודות וב־this בפרק 12 (classes). כרגע — בקורס נעדיף פונקציות רגילות שמקבלות אובייקט כפרמטר.
