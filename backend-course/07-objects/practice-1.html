P07-E36 · עדכון מלאי 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

כתוב updateStock(product, delta) שמשנה את האובייקט שקיבלה:

  • אם product.stock + delta יוצא שלילי ← לא משנה כלום, ומחזירה false.
  • אחרת ← מעדכנת את stock, מעדכנת את השדה inStock (האם המלאי גדול מ־0), ומחזירה true.
const p = { name: "עכבר", stock: 2, inStock: true };
updateStock(p, -2); // true  — p: { name: "עכבר", stock: 0, inStock: false }
updateStock(p, -1); // false — p לא השתנה
updateStock(p, 5);  // true  — stock: 5, inStock: true

P07-E44 · פירוק "key=value" 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 15 דק׳ידע נדרש: פרק 6, שיעור 1

שורת הגדרות מגיעה כטקסט: "name=Dana; age=31 ;city=Haifa". כתוב parseSettings(text) שמחזירה אובייקט:

  • זוגות מופרדים ב־;, ובכל זוג — = בין השם לערך.
  • רווחים בקצוות של שם וערך — מוסרים.
  • זוג ריק, או בלי =, או עם שם ריק — מדלגים עליו.
  • הערכים נשארים מחרוזות. שם שמופיע פעמיים — האחרון קובע.
  • הערך יכול להכיל = (למשל "q=a=b" ← השם q, הערך "a=b").
parseSettings("name=Dana; age=31 ;city=Haifa");
// { name: "Dana", age: "31", city: "Haifa" }
parseSettings("a=1;;broken; =x; a=2; q=a=b");
// { a: "2", q: "a=b" }

🔗 איך זה מתחבר: split ו־for...of מפרק 6, ‏indexOf ו־slice על מחרוזת מפרק 2 (כדי לחתוך רק ב־= הראשון), ו־continue מפרק 4 לדלג על זוגות שבורים. ההצבה עם סוגריים מהשיעור בונה את האובייקט. ככה בדיוק נראה header של Cookie (פרק 14).
