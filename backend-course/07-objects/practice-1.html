P07-E01 · גישה לשדות

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

מה ידפיס הקוד? איזו שורה הייתה קורסת בלי ?.?

const user = {
  name: "נועה",
  roles: ["editor"],
  address: { city: "חיפה" },
  manager: null,
};
const field = "name";
console.log(user[field], user.field);
console.log(user.roles.length, user.roles[1]);
console.log(user.address.city, user.address.zip);
console.log(user.manager?.name);
console.log(user.manager?.name ?? "אין מנהל");
console.log(user["address"]["city"].length);

P07-E06 · יצירת מוצר 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

בקובץ 07-objects/starter/P07-E06.js השלם:

  • createProduct(name, price, stock = 0) — מחזירה { name, price, stock, inStock }, כש־inStock מחושב (stock > 0) והשם מנוקה מרווחים.
  • describeProduct(product) — "מקלדת — ₪249.00 (במלאי: 4)", או "(אזל)" כשהמלאי 0.

P07-E07 · מחירון כאובייקט 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

בקובץ 07-objects/starter/P07-E07.js השלם:

  • priceOf(catalog, code) — המחיר לפי קוד (catalog הוא אובייקט קוד ← מחיר), בלי תלות ברווחים ואותיות קטנות בקוד; לא קיים ← null.
  • withProduct(catalog, code, price) — מחזירה מחירון חדש עם המוצר (חדש או מעודכן). את המקור לא משנים.

P07-E08 · גישה בטוחה לנתונים חסרים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

משתמשים מגיעים מ־API עם שדות חסרים. בקובץ 07-objects/starter/P07-E08.js השלם:

  • getCity(user) — user.address.city, או "לא ידוע" אם משהו בדרך חסר (גם אם user עצמו null).
  • getFirstPhone(user) — הטלפון הראשון במערך user.phones, או null.
  • displayName(user) — nickname אם קיים ולא ריק, אחרת firstName, אחרת "אורח".
