שיעור 2 — מערך של אובייקטים

⏱ ~35 דקות

🎯 בשיעור הזה

המבנה הכי נפוץ ב־Backend: מערך של אובייקטים. כל מה שלמדת בפרק 6 עובד עליו — רק שה־callback מקבל אובייקט.

1. במקום מערכים מקבילים

const products = [
  { id: 1, name: "מקלדת", price: 249, stock: 4 },
  { id: 2, name: "עכבר", price: 89, stock: 0 },
  { id: 3, name: "מסך", price: 899, stock: 2 },
];

for (const p of products) {
  console.log(`${p.id}. ${p.name} — ₪${p.price}`);
}
1. מקלדת — ₪249
2. עכבר — ₪89
3. מסך — ₪899

כל המידע על מוצר יושב יחד. אי אפשר "לשכוח לעדכן את המערך השני". וכך בדיוק ייראו נתונים שמגיעים ממסד נתונים (פרק 16) או מ־API.

2. find, filter, map — על אובייקטים

const products = [
  { id: 1, name: "מקלדת", price: 249, stock: 4 },
  { id: 2, name: "עכבר", price: 89, stock: 0 },
  { id: 3, name: "מסך", price: 899, stock: 2 },
];

const byId = products.find((p) => p.id === 3);
console.log(byId.name);

const available = products.filter((p) => p.stock > 0);
console.log(available.map((p) => p.name));

const totalStockValue = products.reduce((sum, p) => sum + p.price * p.stock, 0);
console.log(totalStockValue);
מסך
[ 'מקלדת', 'מסך' ]
2794

"מצא מוצר לפי מזהה" — find לפי id. זו השורה הראשונה של כמעט כל route בשרת: GET /products/3 ← products.find((p) => p.id === 3). ואם לא נמצא — undefined, והשרת מחזיר "404 לא נמצא" (פרק 15).

map שיוצר אובייקטים חדשים

const products = [
  { id: 1, name: "מקלדת", price: 249, stock: 4 },
  { id: 2, name: "עכבר", price: 89, stock: 0 },
];

const forClient = products.map((p) => ({
  id: p.id,
  title: p.name,
  priceWithVat: Math.round(p.price * 1.18 * 100) / 100,
  available: p.stock > 0,
}));
console.log(forClient);
[
  { id: 1, title: 'מקלדת', priceWithVat: 293.82, available: true },
  { id: 2, title: 'עכבר', priceWithVat: 105.02, available: false }
]
⚠️ הסוגריים העגולים סביב { }

arrow function שמחזירה אובייקט צריכה סוגריים: (p) => ({ ... }). בלעדיהם, JavaScript חושבת ש־{ פותח בלוק של קוד — והתוצאה undefined.

💼 זה בדיוק מה ששרת עושה לפני שהוא שולח נתונים: לא מחזירים את האובייקט "כמו שהוא במסד" (עם שדות פנימיים, ולפעמים סודיים — כמו סיסמה מוצפנת!), אלא ממפים לאובייקט שמיועד ללקוח.

3. מיון לפי שדה

const users = [
  { name: "נועה", age: 29 },
  { name: "אבי", age: 41 },
  { name: "גיל", age: 35 },
];
const byAge = [...users].sort((a, b) => a.age - b.age);
const byName = [...users].sort((a, b) => a.name.localeCompare(b.name));
console.log(byAge.map((u) => u.name).join(", "));
console.log(byName.map((u) => u.name).join(", "));
נועה, גיל, אבי
אבי, גיל, נועה

4. קיבוץ: מערך ← אובייקט של סכומים

"כמה הכנסות לכל קטגוריה?" — אובייקט כצובר, כשהמפתחות נוצרים תוך כדי:

const sales = [
  { category: "מחשבים", amount: 1200 },
  { category: "ספרים", amount: 80 },
  { category: "מחשבים", amount: 300 },
  { category: "ספרים", amount: 45 },
];
const byCategory = {};
for (const s of sales) {
  byCategory[s.category] = (byCategory[s.category] ?? 0) + s.amount;
}
console.log(byCategory);
{ 'מחשבים': 1500, 'ספרים': 125 }

הטריק: byCategory[key] ?? 0 — "הערך הקיים, או 0 אם עוד אין". זה דפוס "group by" — ונראה אותו שוב ב־SQL בפרק 17 (GROUP BY).
