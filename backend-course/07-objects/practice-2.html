P07-E53 · map ששינה את המקור

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 2

בפרק 6 למדת ש־map "לא משנה את המקור". בלי להריץ — מה יודפס?

const products = [
  { name: "עט", price: 10 },
  { name: "תיק", price: 100 },
];
const withVat = products.map((p) => {
  p.price = p.price * 1.18;
  return p;
});
console.log(withVat[0].price, products[0].price);
console.log(withVat === products, withVat[0] === products[0]);

const safe = products.map((p) => ({ name: p.name, price: Math.round(p.price * 1.18) }));
console.log(safe[1].price, products[1].price);

🔗 איך זה מתחבר: בפרק 6, ‏map על מספרים באמת לא נגע במקור — כי p * 2 יוצר מספר חדש. אבל על אובייקטים, ה־callback מקבל את האובייקט עצמו (כמו find ב־P07-E46), ו־p.price = ... משנה אותו. map יצר מערך חדש — עם אותם אובייקטים בפנים.

P07-E54 · טבלה מיושרת

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: פרק 2, פרק 4, שיעור 2

בלי להריץ — איך ייראה הפלט? (כמה תווים בכל עמודה?)

const products = [
  { name: "Keyboard", price: 249 },
  { name: "Mouse", price: 89.5 },
  { name: "Monitor", price: 1299 },
];
for (const p of products) {
  console.log(p.name.padEnd(10, ".") + p.price.toFixed(2).padStart(8));

P07-E28 · יתרה מאירועים 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 2

🔁 חזרה על switch (פרק 3) ועל reduce (פרק 6), על מערך של אובייקטים. חשבון בנק שומר לא את היתרה, אלא רשימה של אירועים. כתוב balanceOf(events), שמחשבת את היתרה (מתחילים מ־0):

  • { type: "deposit", amount } — מוסיפים.
  • { type: "withdraw", amount } — מורידים, רק אם יש מספיק. אם אין — מתעלמים מהאירוע.
  • { type: "fee" } — עמלה קבועה של 5. מורידים אותה תמיד, גם אם היתרה יוצאת שלילית.
  • כל type אחר — מתעלמים.
balanceOf([
  { type: "deposit", amount: 100 },
  { type: "withdraw", amount: 30 },
  { type: "withdraw", amount: 500 }, // אין מספיק — מתעלמים
  { type: "fee" },
  { type: "bonus", amount: 1000 },   // לא מוכר — מתעלמים
]); // 65

השתמש ב־reduce, ובתוכו ב־switch.

P07-E56 · בדיקת מוצרים לפני ייבוא 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: פרק 3, פרק 5, שיעור 2

לפני שמייבאים קובץ מוצרים, בודקים אותו. כתוב:

  • productErrors(p) — מערך של הבעיות במוצר אחד (מערך ריק אם הוא תקין), בסדר הזה:
    1. "חסר שם" — אם name חסר, או ריק אחרי trim.
    2. "מחיר לא תקין" — אם price הוא לא מספר (typeof), או NaN, או לא חיובי.
    3. "מלאי לא תקין" — אם stock הוא לא מספר שלם (Number.isInteger) או שלילי.
  • validateAll(products) — מערך של הודעות לכל הקובץ, בפורמט "שורה 2: מחיר לא תקין" (השורות ממוספרות מ־1). מוצר עם כמה בעיות ← כמה הודעות.
validateAll([
  { name: "עט", price: 5, stock: 10 },
  { name: "  ", price: "5", stock: 1 },
  { name: "תיק", price: 120, stock: -2 },
]);
// ["שורה 2: חסר שם", "שורה 2: מחיר לא תקין", "שורה 3: מלאי לא תקין"]
