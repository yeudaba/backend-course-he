P07-E26 · mapValues עם Object.fromEntries 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

בשיעור 3 ראית את Object.entries(obj), שהופכת אובייקט למערך של זוגות [key, value]. יש לה פונקציה הפוכה: Object.fromEntries(pairs) בונה אובייקט ממערך של זוגות:

Object.fromEntries([["a", 1], ["b", 2]]); // { a: 1, b: 2 }

ביחד הן נותנות דפוס שימושי מאוד: אובייקט ← מערך ← map ← אובייקט. השלם את mapValues(obj, fn), שמחזירה אובייקט חדש עם אותם מפתחות, וכל ערך עובר דרך fn:

mapValues({ keyboard: 100, mouse: 50 }, (p) => p * 1.18); // { keyboard: 118, mouse: 59 }
mapValues({ a: " x ", b: "y " }, (s) => s.trim());       // { a: "x", b: "y" }

האובייקט המקורי לא משתנה. השתמש ב־Object.fromEntries.

P07-E63 · entries בשרשרת

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 3

בלי להריץ — מה יודפס?

const stock = { coffee: 12, tea: 0, cocoa: 5, milk: 0 };
const outOfStock = Object.entries(stock)
  .filter(([item, qty]) => qty === 0)
  .map(([item]) => item);
console.log(outOfStock);

const top = Object.entries(stock)
  .sort((a, b) => b[1] - a[1])
  .slice(0, 2)
  .map(([item, qty]) => `${item}: ${qty}`);
console.log(top.join(" | "));

console.log(Object.keys(stock).length, Object.values(stock).filter((q) => q > 0).length);

🔗 איך זה מתחבר: Object.entries הופך אובייקט למערך של זוגות [מפתח, ערך] — ומשם כל הכלים של פרק 6 עובדים: filter, ‏sort, ‏slice, ‏map. ו־destructuring של מערך בפרמטר של ה־callback (([item, qty]) => ...) נותן שמות לזוג.

P07-E64 · ברירות מחדל ל־null מהמסד

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 3, פרק 5, שיעור 3

שורה מהמסד מגיעה עם null בשדות ריקים. בלי להריץ — מה יודפס?

const row = { name: "דנה", nickname: null, city: undefined, score: 0 };

const { nickname = "אין", city = "לא ידוע", score = 100 } = row;
console.log(nickname, city, score);

function display({ name, nickname = name }) {
  return nickname;
}

P07-E65 · עדכון מקונן בלי לשנות 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 3

כתוב שתי פונקציות שמחזירות משתמש חדש, בלי לשנות את המקורי (ולא אף אובייקט או מערך שבתוכו):

addTag(user, "new");     // { ..., tags: ["vip", "new"] }
user;                    // לא השתנה

P07-E66 · countBy והנפוצים ביותר 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: פרק 5, פרק 6, שיעור 3

כתוב שתי פונקציות:

  • countBy(list, keyFn) — אובייקט: לכל ערך ש־keyFn(item) מחזירה ← כמה פריטים קיבלו אותו.
  • topKeys(counts, n) — מקבלת אובייקט ספירה, ומחזירה מערך של n המפתחות עם הספירה הגבוהה ביותר. בתיקו — לפי סדר אלפביתי (localeCompare).
const orders = [{ city: "חיפה" }, { city: "אילת" }, { city: "חיפה" }, { city: "באר שבע" }];
const counts = countBy(orders, (o) => o.city); // { "חיפה": 2, "אילת": 1, "באר שבע": 1 }
topKeys(counts, 2);                            // ["חיפה", "אילת"]
countBy(["a", "bb", "cc"], (w) => w.length);   // { 1: 1, 2: 2 }

P07-E67 · מ־snake_case ל־camelCase 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: פרק 2, פרק 6, שיעור 3

המסד מחזיר שדות כמו first_name, אבל בקוד JavaScript נהוג firstName. כתוב:

  • toCamel(key) — "first_name" ← "firstName", ‏"created_at_utc" ← "createdAtUtc", ‏"id" ← "id".
  • camelizeKeys(row) — אובייקט חדש עם אותם ערכים, וכל מפתח עובר דרך toCamel. רק הרמה הראשונה.
  • camelizeRows(rows) — אותו דבר לכל שורה במערך.
camelizeKeys({ id: 7, first_name: "דנה", last_login_at: null });
// { id: 7, firstName: "דנה", lastLoginAt: null }
