⚡ מבחן כניסה — אולי אפשר לדלג?
  1. מה ידפיס: const p = { name: "עט", price: 5 }; console.log(p.price, p["name"], p.color);
  2. מה ידפיס: const a = { n: 1 }; const b = a; b.n = 2; console.log(a.n);
  3. מה ידפיס: console.log({ n: 1 } === { n: 1 });
  4. כתוב: מערך products של אובייקטים עם price — סכום כל המחירים.
  5. מה עושה user?.address?.city?
  6. כתוב עם destructuring: הוצא name ו־age מ־user למשתנים.
  7. מה ההבדל בין { ...obj } ל־structuredClone(obj)?
  8. מה מחזיר JSON.stringify({ a: 1 }), ומה הסוג שלו?
  9. מתי עדיף Map על אובייקט רגיל לחיפוש?
  10. איך מסירים כפילויות ממערך בשורה אחת?
תשובות
  1. 5 עט undefined
  2. 2 — שני המשתנים מצביעים על אותו אובייקט.
  3. false — שני אובייקטים שונים, גם אם התוכן זהה.
  4. products.reduce((s, p) => s + p.price, 0)
  5. ניגש בבטחה: אם משהו בדרך הוא null/undefined — מחזיר undefined במקום לקרוס.
  6. const { name, age } = user;
  7. spread מעתיק רק את הרמה הראשונה (אובייקטים פנימיים משותפים); structuredClone — עותק עמוק מלא.
  8. '{"a":1}' — מחרוזת.
  9. כשהמפתחות דינמיים (מזהים, אימיילים), כשיש הרבה הוספות/מחיקות, או כשהמפתח לא מחרוזת.
  10. [...new Set(arr)]

  • להשתמש ב־Map ו־Set כדי לחבר נתונים מקושרים במהירות.

🤔 למה צריך את זה?

ב־P06-E24 החזקת שלושה מערכים מקבילים ליום: שם, הזמנות, הכנסה — ו־revenue[i] בכל מקום. אובייקט מאגד את כל המידע על "דבר אחד" יחד: { day: "ראשון", orders: 12, revenue: 1840 }. כל מה שעובר בין שרת ללקוח ב־API הוא אובייקטים (בפורמט JSON), וכל שורה במסד נתונים הופכת בקוד לאובייקט. זה הפרק שבו הקוד שלך מתחיל להיראות כמו קוד של שרת.
