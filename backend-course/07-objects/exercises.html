P07-E26 · mapValues עם Object.fromEntries 🤖

🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

בשיעור 3 ראית את Object.entries(obj), שהופכת אובייקט למערך של זוגות [key, value]. יש לה פונקציה הפוכה: Object.fromEntries(pairs) בונה אובייקט ממערך של זוגות:

Object.fromEntries([["a", 1], ["b", 2]]); // { a: 1, b: 2 }

ביחד הן נותנות דפוס שימושי מאוד: אובייקט ← מערך ← map ← אובייקט. השלם את mapValues(obj, fn), שמחזירה אובייקט חדש עם אותם מפתחות, וכל ערך עובר דרך fn:

mapValues({ keyboard: 100, mouse: 50 }, (p) => p * 1.18); // { keyboard: 118, mouse: 59 }
mapValues({ a: " x ", b: "y " }, (s) => s.trim());       // { a: "x", b: "y" }

האובייקט המקורי לא משתנה. השתמש ב־Object.fromEntries.

P07-E27 · מלאי פרטי (closure) 🤖

🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 4

🔁 חזרה על closure (פרק 5, ‏P05-E26), הפעם עם Map. כתוב createStock(), שמחזירה אובייקט עם שלוש פונקציות. המלאי עצמו שמור בתוך createStock, ואי אפשר לגשת אליו מבחוץ:

  • add(item, qty) — מוסיפה qty יחידות.
  • take(item, qty) — אם יש מספיק: מורידה ומחזירה true. אם אין: לא משנה כלום ומחזירה false.
  • count(item) — כמה יש (0 לפריט שלא קיים).
const stock = createStock();
stock.add("pen", 5);
stock.take("pen", 2);  // true
stock.take("pen", 10); // false
stock.count("pen");    // 3
stock.count("cup");    // 0

שני מלאים שנוצרו בשתי קריאות ל־createStock לא חולקים נתונים.

P07-E28 · יתרה מאירועים 🤖

🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 2

🔁 חזרה על switch (פרק 3) ועל reduce (פרק 6), על מערך של אובייקטים. חשבון בנק שומר לא את היתרה, אלא רשימה של אירועים. כתוב balanceOf(events), שמחשבת את היתרה (מתחילים מ־0):

  • { type: "deposit", amount } — מוסיפים.
  • { type: "withdraw", amount } — מורידים, רק אם יש מספיק. אם אין — מתעלמים מהאירוע.
  • { type: "fee" } — עמלה קבועה של 5. מורידים אותה תמיד, גם אם היתרה יוצאת שלילית.
  • כל type אחר — מתעלמים.
balanceOf([
  { type: "deposit", amount: 100 },
  { type: "withdraw", amount: 30 },
  { type: "withdraw", amount: 500 }, // אין מספיק — מתעלמים
  { type: "fee" },
  { type: "bonus", amount: 1000 },   // לא מוכר — מתעלמים
]); // 65

השתמש ב־reduce, ובתוכו ב־switch.
