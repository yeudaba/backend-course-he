P07-E01 · גישה לשדות 🧠 הבנה רמה 1

user.field מחפש שדה בשם "field".

💡 רמז 2

שדה שלא קיים ← undefined. ניסיון לקרוא שדה מתוך null ← שגיאה.

✅ פתרון
const user = {
  name: "נועה",
  roles: ["editor"],
  address: { city: "חיפה" },

const field = "name";
console.log(user[field], user.field);
console.log(user.roles.length, user.roles[1]);
console.log(user.address.city, user.address.zip);
console.log(user.manager?.name);
console.log(user.manager?.name ?? "אין מנהל");
console.log(user["address"]["city"].length);

P07-E06 · יצירת מוצר 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

shorthand: return { name: name.trim(), price, stock, inStock: stock > 0 };

💡 רמז 2

ternary בתוך template literal לחלק של המלאי.

✅ פתרון
// P07-E06: יצירת מוצר
function createProduct(name, price, stock = 0) {
  return { name: name.trim(), price, stock, inStock: stock > 0 };
}

function describeProduct(product) {
  const stockText = product.inStock ? `במלאי: ${product.stock}` : "אזל";
  return `${product.name} — ₪${product.price.toFixed(2)} (${stockText})`;
}

const kb = createProduct(" מקלדת ", 249, 4);
console.log(kb);
console.log(describeProduct(kb));

module.exports = { createProduct, describeProduct };
{ name: 'מקלדת', price: 249, stock: 4, inStock: true }
מקלדת — ₪249.00 (במלאי: 4)
⚠️ טעויות נפוצות
  • לשמור inStock: true קבוע במקום לחשב.

P07-E07 · מחירון כאובייקט 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

catalog[code.trim().toUpperCase()] ?? null

💡 רמז 2

מפתח מחושב באובייקט חדש: { ...catalog, [code]: price }.

✅ פתרון
// P07-E07: מחירון כאובייקט
function priceOf(catalog, code) {
  return catalog[code.trim().toUpperCase()] ?? null;
}

function withProduct(catalog, code, price) {
  return { ...catalog, [code.trim().toUpperCase()]: price };
}

const catalog = { "KB-101": 199, "MS-201": 89 };
console.log(priceOf(catalog, " kb-101 "), priceOf(catalog, "X"));
console.log(withProduct(catalog, "kb-102", 249), catalog);

module.exports = { priceOf, withProduct };
199 null
{ 'KB-101': 199, 'MS-201': 89, 'KB-102': 249 } { 'KB-101': 199, 'MS-201': 89 }

[expr]: value בתוך אובייקט — "מפתח מחושב": השם הוא תוצאת הביטוי. כך נראה switch המחירון מפרק 5 — בשתי שורות.

⚠️ טעויות נפוצות
  • { ...catalog, code: price } — יוצר שדה בשם "code".

P07-E08 · גישה בטוחה לנתונים חסרים 🤖 💻 כתיבת קוד 🤖 רמה 2

user?.address?.city ?? "לא ידוע"

💡 רמז 2

✅ פתרון
// P07-E08: גישה בטוחה
const getCity = (user) => user?.address?.city ?? "לא ידוע";
const getFirstPhone = (user) => user?.phones?.[0] ?? null;
const displayName = (user) => user?.nickname || user?.firstName || "אורח";

console.log(getCity({ address: {} }), getFirstPhone({ phones: [] }), displayName({ nickname: "", firstName: "דנה" }));

module.exports = { getCity, getFirstPhone, displayName };
לא ידוע null דנה

?.[0] — גישה בטוחה לאינדקס.

⚠️ טעויות נפוצות
  • user.address?.city — אם user הוא null זה עדיין קורס.
