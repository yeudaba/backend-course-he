P07-E29 · נקודה או סוגריים? 🧠 הבנה רמה 1

💡 רמז 1

נקודה: השם כמו שהוא כתוב בקוד. סוגריים: מה שבתוך הסוגריים מחושב קודם — משתנה, מחרוזת, מספר.

💡 רמז 2

מפתחות של אובייקט הם תמיד מחרוזות: המספר 2026 הופך ל־"2026".

✅ פתרון

product.field מחפש שדה ששמו המילה field — ואין כזה. product[field] מחפש את מה שבמשתנה — "price". השדה "in stock" (עם רווח) נגיש רק עם סוגריים: product.in stock הוא שגיאת תחביר. ו־product[2026] זהה ל־product["2026"], כי המפתח הומר למחרוזת.

⚠️ טעויות נפוצות
  • product.field כשהתכוונת למשתנה field — מקבלים undefined בשקט.

✅ פתרון
07-objects/starter/P07-E36.js 
function updateStock(product, delta) {
  const next = product.stock + delta;
  if (next < 0) {
    return false;
  }
  product.stock = next;
  product.inStock = next > 0;
  return true;
}

const p = { name: "עכבר", stock: 2, inStock: true };
console.log(updateStock(p, -2), p);
console.log(updateStock(p, -1), p);

module.exports = { updateStock };
true { name: 'עכבר', stock: 0, inStock: false }
false { name: 'עכבר', stock: 0, inStock: false }

P07-E38 · חשבון עם מתודות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

המבנה (בתוך מתודה — this.balance):

return {
  owner: owner,
  balance: 0,
  deposit(amount) {
    // ...
  },
};
💡 רמז 2

guards בכל מתודה, כמו בפרק 5. ו־summary: this.balance.toFixed(2).

✅ פתרון
07-objects/starter/P07-E38.js 
function createAccount(owner) {
  return {
    owner: owner,
    balance: 0,
    deposit(amount) {
      if (amount <= 0) {
        return false;
      }
      this.balance += amount;
      return true;
    },
    withdraw(amount) {
      if (amount <= 0 || amount > this.balance) {
        return false;
      }
      this.balance -= amount;
      return true;
    },
    summary() {
      return `${this.owner}: ₪${this.balance.toFixed(2)}`;
    },
  };
}

const acc = createAccount("דנה");
console.log(acc.deposit(200), acc.withdraw(79.5), acc.withdraw(500), acc.summary());

module.exports = { createAccount };
true true false דנה: ₪120.50

כל קריאה ל־createAccount יוצרת אובייקט חדש, עם יתרה משלו. בפרק 12 תכתוב את אותו דבר כ־class — והמבנה כמעט זהה.

⚠️ טעויות נפוצות
  • balance += amount בלי this. — ReferenceError, כי אין משתנה בשם balance.
  • arrow function כמתודה (deposit: (amount) => { this.balance... }) — ב־arrow, this הוא לא האובייקט. לכן מתודות כותבים בכתיב deposit(amount) { ... }.

💡 רמז 1

function applyCoupon(total, code, coupons) {
  const percent = coupons[code.trim().toUpperCase()];
  if (percent === undefined) {
    return total;
  }
  return Math.round(total * (1 - percent / 100) * 100) / 100;
}

function parseSettings(text) {
  const result = {};
  for (const part of text.split(";")) {
    const eq = part.indexOf("=");
    if (eq === -1) {
      continue;
    }
    const key = part.slice(0, eq).trim();
    const value = part.slice(eq + 1).trim();
    if (key === "") {
      continue;
    }
    result[key] = value;
  }
  return result;
}

console.log(parseSettings("name=Dana; age=31 ;city=Haifa"));
console.log(parseSettings("a=1;;broken; =x; a=2; q=a=b"));

module.exports = { parseSettings };
{ name: 'Dana', age: '31', city: 'Haifa' }
{ a: '2', q: 'a=b' }

למה לא part.split("=")? כי "q=a=b".split("=") נותן שלושה חלקים, והערך "a=b" נחתך. indexOf מוצא רק את ה־= הראשון.

⚠️ טעויות נפוצות

  • result.key = value — כל הערכים נכתבים לשדה אחד בשם "key".
