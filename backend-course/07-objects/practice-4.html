P07-E05 · Set ו־Map

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

מה ידפיס? ואחר כך: לכל מצב — מערך, אובייקט, Set או Map?

const s = new Set([3, 1, 3, 2]);
s.add(1);
console.log(s.size, [...s].join(","), s.has(2));
const m = new Map([["a", 1]]);
m.set("b", 2);
m.set("a", 10);
console.log(m.size, m.get("a"), m.get("c") ?? 0);
  1. רשימת המוצרים בעגלה, לפי סדר ההוספה.
  2. פרטי משתמש אחד (שם, אימייל, גיל).
  3. כל המשתמשים, כדי למצוא משתמש לפי id במהירות.
  4. אוסף כתובות IP שכבר ביקרו באתר היום.

P07-E70 · אובייקט, Map או Set?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

לכל מקרה — אובייקט רגיל, Map, ‏Set או מערך? ונמק במשפט.

  1. ההגדרות של האפליקציה: port, ‏dbUrl, ‏logLevel.
  2. רשימת כתובות IP שכבר נחסמו — שואלים "האם הכתובת הזו חסומה?" על כל בקשה.
  3. מזהה משתמש ← מספר הבקשות שלו בדקה האחרונה.
  4. ההזמנות של היום, לפי הסדר שבו הגיעו.
  5. תגיות של פוסט, בלי כפילויות.
  6. מטמון (cache): כתובת URL ← התשובה שחזרה ממנה.

P07-E71 · כמה השוואות?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

שתי דרכים לחבר הזמנות ללקוחות. הקוד סופר כמה פעולות כל דרך עושה. בלי להריץ — מה יודפס? ומה יקרה עם 1,000 הזמנות ו־1,000 לקוחות?

const customers = [{ id: 1 }, { id: 2 }, { id: 3 }, { id: 4 }];
const orders = [
  { customerId: 4 },
  { customerId: 2 },
  { customerId: 4 },
  { customerId: 9 },
  { customerId: 1 },
];

let compares = 0;
for (const o of orders) {
  customers.find((c) => {
    compares++;
    return c.id === o.customerId;
  });
}

let steps = 0;
const byId = new Map();
for (const c of customers) {
  byId.set(c.id, c);
  steps++;
}
for (const o of orders) {
  byId.get(o.customerId);
  steps++;
}
console.log(compares, steps);

P07-E77 · לקוחות בלי הזמנות 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

שני מערכים: customers ({ id, name }) ו־orders ({ id, customerId }). כתוב:

  • ordersByCustomer(orders) — Map: מזהה לקוח ← מערך של מזהי ההזמנות שלו, לפי הסדר.
  • customersWithoutOrders(customers, orders) — מערך של שמות הלקוחות שאין להם אף הזמנה, לפי הסדר ב־customers. בלי לולאה בתוך לולאה (השתמש ב־Set של מזהים).
  • orphanOrders(customers, orders) — מערך מזהי ההזמנות שה־customerId שלהן לא קיים.
const customers = [{ id: 1, name: "דנה" }, { id: 2, name: "עומר" }, { id: 3, name: "נועה" }];
const orders = [{ id: 10, customerId: 2 }, { id: 11, customerId: 9 }, { id: 12, customerId: 2 }];
ordersByCustomer(orders);                   // Map(2) { 2 => [10, 12], 9 => [11] }
customersWithoutOrders(customers, orders);  // ["דנה", "נועה"]
orphanOrders(customers, orders);            // [11]

P07-E78 · שני מלאים, זיכרון נפרד

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 5, שיעור 4

בלי להריץ — מה יודפס?

function createCounter() {
  const counts = new Map();
  return {
    hit(key) {
      counts.set(key, (counts.get(key) ?? 0) + 1);
      return counts.get(key);
    },
    size() {
      return counts.size;
    },
  };
}
const pages = createCounter();
const users = createCounter();
pages.hit("/home");
pages.hit("/home");
console.log(pages.hit("/cart"), pages.hit("/home"), users.hit("/home"));
console.log(pages.size(), users.size(), pages.counts);

🔗 איך זה מתחבר: closure מפרק 5 (P05-E26): כל קריאה ל־createCounter יוצרת Map חדש, והמתודות שחוזרות "זוכרות" אותו. מבחוץ אין דרך להגיע אליו — pages.counts לא קיים. זה המבנה של P07-E27.

P07-E79 · כפילויות של אובייקטים

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3, שיעור 4

רשימת משתמשים הגיעה משני מקורות, וחלקם כפולים. בלי להריץ — מה יודפס?

const users = [
  { id: 1, name: "דנה" },
  { id: 2, name: "עומר" },
  { id: 1, name: "דנה" },
];
console.log(new Set(users).size);
const byId = new Map(users.map((u) => [u.id, u]));
console.log(byId.size, [...byId.values()].map((u) => u.name));

const seen = new Set();
const unique = users.filter((u) => {
  if (seen.has(u.id)) {
    return false;
  }
  seen.add(u.id);
  return true;
});
console.log(unique.length, unique[1].name);

🔗 איך זה מתחבר: משיעור 3: שני אובייקטים עם אותו תוכן הם לא אותו אובייקט — ולכן Set לא מזהה אותם ככפולים. הפתרון: Set או Map של המזהה (מספר — ערך פשוט שמשווים לפי תוכן).

P07-E80 · includes בלולאה מול Set

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, כל הפרק

שתי גרסאות של unique (הסרת כפילויות, כמו P06-E13). הקוד סופר פעולות. בלי להריץ — מה יודפס? ומה יקרה עם 10,000 ערכים שונים?

const values = ["a", "b", "a", "c", "b", "d"];

let checks = 0;
const result1 = [];
for (const v of values) {
  checks += result1.length;
  if (!result1.includes(v)) {
    result1.push(v);
  }
}

let steps = 0;
const seen = new Set();
const result2 = [];
for (const v of values) {
  steps++;
  if (!seen.has(v)) {
    seen.add(v);
    result2.push(v);
  }
}
console.log(result1, result2);
console.log(checks, steps);

(checks סופר את המקרה הגרוע של includes: כמה איברים יש במערך שהוא עובר עליו.)

🔗 איך זה מתחבר: P06-E13 פתר את זה עם מערך ו־includes — נכון, אבל כל includes הוא לולאה נסתרת. Set.has הוא צעד אחד. ב־P06-E25 שאלת "כמה צעדים"; כאן אותה שאלה, עם הכלי שפותר אותה.

P07-E24 · אתגר: מלאי והזמנות 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 40 דק׳ידע נדרש: כל הפרק

מערכת מלאי קטנה, בלי לשנות אף קלט. בקובץ 07-objects/starter/P07-E24.js השלם:

  • applyOrder(inventory, order) — inventory הוא אובייקט קוד ← כמות; order הוא { id, items: [{ code, qty }] }. מחזירה { ok: true, inventory: מלאי חדש }, או — אם מוצר לא קיים או שאין מספיק לאחד הפריטים — { ok: false, inventory: המלאי המקורי, error: "..." }. הכול או כלום: אם פריט אחד נכשל, אף פריט לא מורד.
  • processOrders(inventory, orders) — מעבדת לפי הסדר, ומחזירה { inventory, accepted: [ids], rejected: [{ id, error }] }.

הודעות השגיאה — בקובץ ההתחלה. שים לב למקרה: אותו קוד מופיע פעמיים באותה הזמנה.

🔗 איך זה מתחבר: הכול ביחד: אובייקט כמילון (שיעור 1), מערך של אובייקטים (שיעור 2), עדכון בלי לשנות את הקלט עם spread (שיעור 3), ולולאה עם guard שעוצרת בשגיאה הראשונה (פרקים 4–5). "הכול או כלום" הוא בדיוק מה שטרנזקציה במסד נתונים עושה (פרק 18).

P07-E25 · אתגר: twoSum מהיר ואנגרמות 🤖

P07-E27 · מלאי פרטי (closure) 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 4

🔁 חזרה על closure (פרק 5, ‏P05-E26), הפעם עם Map. כתוב createStock(), שמחזירה אובייקט עם שלוש פונקציות. המלאי עצמו שמור בתוך createStock, ואי אפשר לגשת אליו מבחוץ:

  • add(item, qty) — מוסיפה qty יחידות.
  • take(item, qty) — אם יש מספיק: מורידה ומחזירה true. אם אין: לא משנה כלום ומחזירה false.
  • count(item) — כמה יש (0 לפריט שלא קיים).
const stock = createStock();
stock.add("pen", 5);
stock.take("pen", 2);  // true
stock.take("pen", 10); // false
stock.count("pen");    // 3
stock.count("cup");    // 0

שני מלאים שנוצרו בשתי קריאות ל־createStock לא חולקים נתונים.
