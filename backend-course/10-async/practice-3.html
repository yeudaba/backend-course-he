מה יודפס?

Promise.resolve(2)
  .then((x) => x * 10)
  .then((x) => {
    x + 1;
  })
  .then((x) => console.log("A", x))
  .then(() => {
    throw new Error("אופס");
  })
  .then(() => console.log("B"))
  .catch((e) => {
    console.log("C", e.message);
    return 7;
  })
  .then((x) => console.log("D", x));

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 3

P10-E13 · הקובץ הראשון שקיים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

שרתים מחפשים קובץ הגדרות בכמה מקומות. בקובץ 10-async/starter/P10-E13.js השלם readFirstExisting(files) (async) עם fs/promises: מנסה לקרוא כל קובץ לפי הסדר ומחזירה { file, text } של הראשון שהצליח. אם אף אחד לא קיים — זורקת Error("לא נמצא אף קובץ"). נסה את הבא רק אם הקודם נכשל.

P10-E14 · שורות בכל הקבצים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

בקובץ 10-async/starter/P10-E14.js השלם lineCounts(dir): קוראת את כל הקבצים שמסתיימים ב־.txt בתיקייה (fs.readdir), במקביל, ומחזירה אובייקט שם קובץ ← מספר שורות. קובץ ריק ← 0. (שורה = טקסט מופרד ב־\n; ירידת שורה בסוף הקובץ לא יוצרת שורה נוספת.)
