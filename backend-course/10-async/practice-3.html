P10-E64 · then שלא מחכה

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: שיעור 3

בלי להריץ — מה יודפס? מצא את הבאג, והסבר איך שורה אחת מתקנת אותו.

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

function save(item) {
  return sleep(20).then(() => {
    console.log("נשמר:", item);
    return item.length;
  });
}

Promise.resolve("מחברת")
  .then((item) => {
    save(item);
  })
  .then((len) => console.log("אורך:", len))
  .finally(() => console.log("סיימנו"));

P10-E66 · בדיקת גיל — כ־Promise 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

כתוב checkAge(age) שמחזירה new Promise, שמסתיים אחרי 10 מילישניות:

  • age אינו מספר, או שלילי ← נכשל עם RangeError("גיל לא תקין").
  • age >= 18 ← מצליח עם "מותר"; אחרת ← מצליח עם "אסור".
checkAge(20).then(console.log);                     // מותר
checkAge(12).then(console.log);                     // אסור
checkAge(-3).catch((e) => console.log(e.message));  // גיל לא תקין

P10-E69 · Promise, טיימר ו־executor

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1, שיעור 3

בלי להריץ — מה הסדר?

setTimeout(() => console.log("A"), 0);
const p = new Promise((resolve) => {
  console.log("B");
  resolve("C");
});
p.then((v) => {
  console.log(v);
  return "D";
}).then((v) => console.log(v));
Promise.resolve().then(() => console.log("E"));
console.log("F");

🔗 איך זה מתחבר: שיעור 1: קוד סינכרוני ← תור ה־Promises ← טיימרים. השיעור הזה מוסיף שני פרטים: ה־executor של new Promise סינכרוני, ו־then שמגיע אחרי then נכנס לתור רק כשהקודם הסתיים.

P10-E70 · אותה פעולה — callback מול Promise

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: שיעור 2, שיעור 3

הנה אותה פעולה פעמיים: קרא הגדרות, ואז משתמש.

// גרסת callbacks (שיעור 2)
readConfig((err, config) => {
  if (err) return console.log("נכשל:", err.message);
  readUser(config.userId, (err, user) => {
    if (err) return console.log("נכשל:", err.message);
    console.log(user.name);
  });
});

// גרסת Promises (השיעור)
readConfigP()
  .then((config) => readUserP(config.userId))
  .then((user) => console.log(user.name))
  .catch((err) => console.log("נכשל:", err.message));

ציין לפחות ארבעה הבדלים מעשיים בין הגרסאות (מה קל יותר, מה בטוח יותר, מה לא יכול לקרות באחת מהן).

🔗 איך זה מתחבר: שיעור 2 הראה את הבעיות של callbacks (פירמידה, שגיאות כפולות, callback כפול); כאן רואים איך כל אחת נפתרת.

P10-E71 · map שמחזיר Promises

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 3

בלי להריץ — מה יודפס?

const sleep = (ms, v) => new Promise((r) => setTimeout(() => r(v), ms));

const results = [1, 2, 3].map((n) => sleep(10, n * 2));
console.log(results.length, results[0] instanceof Promise);
console.log(results.map((r) => typeof r));
results[2].then((v) => console.log("השלישי:", v));
const sum = results.reduce((s, r) => s + r, 0);
console.log(typeof sum, sum.slice(0, 7));

🔗 איך זה מתחבר: פרק 6: map מחזיר את מה שה־callback מחזיר — כאן Promises, לא מספרים. ‏reduce עם + על אובייקטים ממיר אותם למחרוזות (פרק 2). בשיעור הבא Promise.all יהפוך מערך של Promises ל־Promise של מערך.

P10-E72 · promisify משלך 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: פרק 5, שיעור 2, שיעור 3

כתוב promisify(fn): מקבלת פונקציה בסגנון error-first — שה־callback הוא הארגומנט האחרון שלה — ומחזירה פונקציה חדשה שמקבלת את אותם ארגומנטים (בלי ה־callback) ומחזירה Promise.

const fs = require("node:fs");
const readFileP = promisify(fs.readFile);
readFileP("a.txt", "utf8").then(console.log);   // התוכן

function addLater(a, b, cb) { setTimeout(() => cb(null, a + b), 5); }
promisify(addLater)(2, 3).then(console.log);    // 5

📄 כותבים בקובץ 10-async/starter/P10-E72.js (יש בו רק הערה). בסוף הקובץ: module.exports = { promisify };

% node 10-async/starter/P10-E72.js
% npm run check P10-E72

🔗 איך זה מתחבר: פרק 5: פונקציה שמחזירה פונקציה, ופרמטר rest (...args) שאוסף "כמה ארגומנטים שיהיו". שיעור 2: error-first. השיעור: new Promise שעוטף callback — אבל הפעם לכל פונקציה, לא רק ל־readFile. (ל־Node יש כזו מוכנה: util.promisify.)

P10-E73 · סכום המספרים בקובץ 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: פרק 2, פרק 6, שיעור 3

כתוב sumFile(file) עם fs/promises ו־then (בלי await): הקובץ מכיל מספר בכל שורה. מצליחה עם הסכום.

  • מדלגים על שורות ריקות (גם כאלה שיש בהן רק רווחים). רווחים בקצוות מותרים.
  • שורה שאינה מספר ← נכשלת עם Error שההודעה שלו שורה N: "X" אינו מספר, כש־N מתחיל ב־1 ו־X הוא תוכן השורה בלי הרווחים.
  • קובץ שלא קיים ← השגיאה המקורית.
// prices.txt: "10\n 2.5\n\n7\n"
sumFile("prices.txt").then(console.log); // 19.5

% node 10-async/starter/P10-E73.js
% npm run check P10-E73

🔗 איך זה מתחבר: split, ‏trim, ‏Number ו־Number.isNaN מפרק 2, ולולאה על מערך עם אינדקס מפרק 6. השיעור: throw בתוך then הופך לכישלון של ה־Promise.

P10-E74 · הגדרות עם ברירות מחדל 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 7, פרק 8, שיעור 3

כתוב loadSettings(file, defaults) עם fs/promises ו־then/catch (בלי await). מצליחה עם אובייקט חדש:

  • הקובץ קיים ← כל השדות של defaults, ומעליהם השדות מהקובץ (שדה שקיים בשניהם — מהקובץ).
  • הקובץ לא קיים (ENOENT) ← עותק של defaults. זה לא כישלון.
  • כל שגיאה אחרת (למשל JSON לא תקין, או שהנתיב הוא תיקייה) ← נכשלת עם אותה שגיאה.
  • אסור לשנות את defaults.
loadSettings("missing.json", { port: 3000, debug: false }).then(console.log);
// { port: 3000, debug: false }

📄 כותבים בקובץ 10-async/starter/P10-E74.js (יש בו רק הערה). בסוף הקובץ: module.exports = { loadSettings };

% node 10-async/starter/P10-E74.js
% npm run check P10-E74

🔗 איך זה מתחבר: spread של אובייקטים מפרק 7 ({ ...defaults, ...fromFile } — האחרון מנצח), ו"לתפוס רק את מה שאתה יודע לטפל בו" מפרק 8 — בדיקת err.code, ו־throw err לכל השאר. בשיעור: catch שמחזיר ערך "מתקן" את השרשרת, ו־catch שזורק — ממשיך את הכישלון.
