1. "הבטחה" לתוצאה עתידית

כשמזמינים בפיצרייה, מקבלים מספר הזמנה. זה לא פיצה — זו הבטחה לפיצה. בינתיים אפשר לעשות דברים אחרים, וכשהמספר נקרא — או שמקבלים פיצה, או שאומרים "נגמר הבצק". Promise הוא מספר ההזמנה.

2. then, catch, finally

import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";

const file = path.join(os.tmpdir(), "promise-demo.json");
await fs.writeFile(file, '{"total": 42}');

fs.readFile(file, "utf8")
  .then((text) => JSON.parse(text))
  .then((data) => console.log("סה״כ:", data.total))
  .catch((err) => console.log("נכשל:", err.message))
  .finally(() => console.log("סיימנו לנסות"));
סה״כ: 42
סיימנו לנסות
מתודהמתי רצה
.then(fn)כשהקודם הצליח. מה ש־fn מחזירה עובר ל־then הבא (אם היא מחזירה Promise — מחכים לו)
.catch(fn)אם משהו בשרשרת שלפניה נכשל — כולל JSON.parse שזרק
.finally(fn)תמיד, בסוף

זה פותר את פירמידת האבדון: שרשרת שטוחה, ו־catch אחד לכל השלבים.

3. ליצור Promise: sleep

function sleep(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

function delayedValue(value, ms) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (value < 0) {
        reject(new Error("ערך שלילי"));
      } else {
        resolve(value * 2);
      }
    }, ms);
  });
}

sleep(50).then(() => console.log("עברו 50ms"));
delayedValue(5, 10).then((v) => console.log("קיבלתי", v));
delayedValue(-1, 20).catch((e) => console.log("נכשל:", e.message));
קיבלתי 10
נכשל: ערך שלילי
עברו 50ms

new Promise((resolve, reject) => { ... }) — הפונקציה שבפנים רצה מיד. קוראים ל־resolve(ערך) כשיש תוצאה, או ל־reject(שגיאה) כשנכשל. (את sleep נכתוב כמעט בכל פרק מעכשיו — לסימולציות ולניסיונות חוזרים.)
