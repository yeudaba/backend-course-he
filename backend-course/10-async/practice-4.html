P10-E78 · return או return await?

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: שיעור 4

בשיעור נכתב: "שים לב ל־return await בתוך try". בלי להריץ — מה יודפס?

const fail = async () => {
  throw new Error("נכשל");
};

async function withoutAwait() {
  try {
    return fail();
  } catch {
    return "נתפס בפנים";
  }
}

async function withAwait() {
  try {
    return await fail();
  } catch {
    return "נתפס בפנים";
  }
}

withoutAwait().then(console.log, (e) => console.log("ברח החוצה:", e.message));
withAwait().then(console.log, (e) => console.log("ברח החוצה:", e.message));

(then(a, b) עם שתי פונקציות: a להצלחה, b לכישלון — כמו then(a).catch(b).)

P10-E79 · לקרוא תוצאה של allSettled

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

בלי להריץ — מה יודפס?

const ok = (ms, v) => new Promise((r) => setTimeout(() => r(v), ms));
const fail = (ms, m) => new Promise((_, rej) => setTimeout(() => rej(new Error(m)), ms));

const results = await Promise.allSettled([ok(20, "משתמש"), fail(10, "אין חיבור"), ok(5, 3)]);
console.log(results.map((r) => r.status));
console.log(results.filter((r) => r.status === "fulfilled").map((r) => r.value));
console.log(results.filter((r) => r.status === "rejected").map((r) => r.reason.message));

(הקוד רץ כקובץ .mjs, ולכן מותר await ברמה העליונה.)

P10-E80 · await בלולאה מול map

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: פרק 4, פרק 6, שיעור 4

בלי להריץ — מה יודפס? (הזמנים מעוגלים לכפולות של 40.)

const sleep = (ms, v) => new Promise((r) => setTimeout(() => r(v), ms));
const price = (id) => sleep(40, id * 10);
const ids = [1, 2, 3];
const round = (t) => Math.round((Date.now() - t) / 40) * 40;

let t = Date.now();
let sum = 0;
for (const id of ids) {
  sum += await price(id);
}
console.log("for:", sum, round(t));

t = Date.now();
const prices = await Promise.all(ids.map((id) => price(id)));
console.log("map:", prices.reduce((s, p) => s + p, 0), round(t));

t = Date.now();
const all = await Promise.all(ids.map(async (id) => (await price(id)) + 1));
console.log("async map:", all, round(t));

🔗 איך זה מתחבר: for...of מפרק 4, ‏map ו־reduce מפרק 6. השיעור: await בתוך לולאה מחכה בכל סיבוב; map מתחיל את כל ה־Promises מיד, ו־Promise.all מחכה לכולם יחד.

P10-E81 · try/catch רגיל ופונקציית async

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 8, שיעור 4

בלי להריץ — מה יודפס?

async function boom() {
  throw new Error("בום");
}

try {
  const p = boom();
  console.log("לא נזרק כאן");
  p.catch((e) => console.log("ה־catch של ה־Promise:", e.message));
} catch (err) {
  console.log("try/catch רגיל:", err.message);
}

async function main() {
  try {
    await boom();
  } catch (err) {
    console.log("try/catch עם await:", err.message);
  }
}
main();

🔗 איך זה מתחבר: פרק 8: try/catch תופס שגיאות שנזרקות בזמן שהוא פתוח. השיעור: async לא זורקת — היא מחזירה Promise שנכשל. רק await "הופך" אותו בחזרה לזריקה, שה־try יכול לתפוס.

P10-E27 · סכום הזמנה במקביל 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 4

🔁 חזרה על map ו־reduce (פרק 6) ועל destructuring (פרק 7), הפעם עם Promise.all. כתוב async function orderTotal(items, getPrice):

  • items — מערך של { sku, qty }.
  • getPrice(sku) — מחזירה Promise עם המחיר (כמו שאילתה למסד או ל־API).
  • מחזירה את סכום price × qty של כל הפריטים. כל המחירים נשלפים במקביל, לא אחד אחרי השני.
  • אם אחד המחירים נכשל — orderTotal נכשלת עם אותה שגיאה.
const prices = { A: 10, B: 25 };
const getPrice = async (sku) => prices[sku];
await orderTotal([{ sku: "A", qty: 3 }, { sku: "B", qty: 2 }], getPrice); // 80

הבודק נותן getPrice שמחכה 50ms לכל מחיר. עם 5 פריטים, אם הם במקביל — זה לוקח כ־50ms ולא 250ms.

P10-E28 · כל העמודים 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 4

🔁 חזרה על while (פרק 4) ועל spread של מערכים (פרק 6), עם await. הרבה APIs מחזירים תוצאות בעמודים: כל תשובה כוללת חלק מהפריטים ואת מספר העמוד הבא. כתוב async function fetchAll(getPage, maxPages = 100):

  • getPage(n) מחזירה Promise עם { items, next }. ‏next הוא מספר העמוד הבא, או null אם זה העמוד האחרון.
  • מתחילים מעמוד 1, וממשיכים לפי next עד null. מחזירים מערך אחד עם כל הפריטים, לפי הסדר.
  • הגנה: אם קראנו כבר maxPages עמודים ועדיין יש next — זורקים Error("יותר מדי עמודים"). (API עם באג יכול להחזיר next לנצח.)
// עמוד 1: { items: ["a", "b"], next: 2 }
// עמוד 2: { items: ["c"], next: null }
await fetchAll(getPage); // ["a", "b", "c"]

📄 כותבים בקובץ 10-async/starter/P10-E28.js (יש בו רק הערה). בסוף הקובץ: module.exports = { fetchAll };

% node 10-async/starter/P10-E28.js
% npm run check P10-E28

🔗 איך זה מתחבר: while מפרק 4 עם תנאי עצירה ומונה, spread של מערכים מפרק 6, ו־throw מפרק 8 — עם await בתוך הלולאה. כאן הרצף הכרחי: את מספר העמוד הבא יודעים רק מהתשובה הקודמת (P10-E77).
