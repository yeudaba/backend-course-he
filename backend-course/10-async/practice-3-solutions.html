P10-E04 · ערכים בשרשרת 🧠 הבנה רמה 1

💡 רמז 1

then בלי return מעביר undefined.

💡 רמז 2

אחרי שגיאה — מדלגים על כל ה־then עד catch. catch שמחזיר ערך "מתקן" את השרשרת.

✅ פתרון
Promise.resolve(2)
  .then((x) => x * 10)
  .then((x) => {
    x + 1;
  })
  .then((x) => console.log("A", x))
  .then(() => {
    throw new Error("אופס");
  })
  .then(() => console.log("B"))
  .catch((e) => {
    console.log("C", e.message);
    return 7;
  })
  .then((x) => console.log("D", x));
A undefined
C אופס
D 7
⚠️ טעויות נפוצות
  • לחשוב ש־D לא ירוץ — אחרי catch השרשרת ממשיכה כרגיל.

P10-E09 · שרשרת then 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

findUser ← then: אם null, throw new Error(...); אחרת return findOrders(user.id).then(...).

💡 רמז 2

צריך את השם גם בשלב של ההזמנות — then פנימי שעדיין רואה את user.

✅ פתרון
// P10-E09
const users = [{ id: 1, name: "דנה" }, { id: 2, name: "עומר" }];
const orders = [{ userId: 1 }, { userId: 1 }, { userId: 2 }];
const wait = (v) => new Promise((r) => setTimeout(() => r(v), 5));
const findUser = (id) => wait(users.find((u) => u.id === id) ?? null);
const findOrders = (userId) => wait(orders.filter((o) => o.userId === userId));

function orderCountText(userId) {
  return findUser(userId).then((user) => {
    if (user === null) {
      throw new Error("משתמש לא נמצא");
    }
    return findOrders(user.id).then((list) => `${user.name}: ${list.length} הזמנות`);
  });
}

orderCountText(1)
  .then(console.log)
  .then(() => orderCountText(9))
  .catch((e) => console.log(e.message));

module.exports = { findUser, findOrders, orderCountText };

משתמש לא נמצא
⚠️ טעויות נפוצות
  • לשכוח return לפני findOrders(...) — הפונקציה תחזיר undefined במקום לחכות.

P10-E10 · Promise משלך 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

new Promise((resolve, reject) => setTimeout(() => { ... }, ms))

💡 רמז 2

בתוך ה־setTimeout: guard clauses עם reject ו־return.

✅ פתרון
// P10-E10
function slowSquareRoot(n, ms = 10) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (typeof n !== "number" || Number.isNaN(n)) {
        reject(new Error("לא מספר"));
        return;
      }
      if (n < 0) {
        reject(new Error("אין שורש למספר שלילי"));
        return;
      }
      resolve(Math.sqrt(n));
    }, ms);
  });
}

slowSquareRoot(81).then(console.log);

module.exports = { slowSquareRoot };
9
⚠️ טעויות נפוצות
  • throw בתוך setTimeout במקום reject — לא נתפס על ידי ה־Promise, ומפיל את התוכנית.

P10-E13 · הקובץ הראשון שקיים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

for (const file of files) { try { return { file, text: await fs.readFile(file, "utf8") }; } catch { /* ממשיכים */ } }

💡 רמז 2

כאן ההמתנה ברצף היא בכוונה — לא רוצים לקרוא את כולם.

✅ פתרון
// P10-E13
const fs = require("node:fs/promises");

async function readFirstExisting(files) {
  for (const file of files) {
    try {
      const text = await fs.readFile(file, "utf8");
      return { file, text };
    } catch {
      // הקובץ לא קיים או לא קריא — ננסה את הבא
    }
  }
  throw new Error("לא נמצא אף קובץ");
}

readFirstExisting(["/nope1", "/nope2"]).catch((e) => console.log(e.message));

module.exports = { readFirstExisting };
לא נמצא אף קובץ
⚠️ טעויות נפוצות
  • return fs.readFile(...) בלי await בתוך try — השגיאה לא נתפסת שם, והלולאה לא ממשיכה.

P10-E14 · שורות בכל הקבצים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

const names = (await fs.readdir(dir)).filter((n) => n.endsWith(".txt"));

💡 רמז 2

Promise.all(names.map(async (name) => [name, count(await fs.readFile(path.join(dir, name), "utf8"))])) ואז Object.fromEntries.

✅ פתרון
// P10-E14
const fs = require("node:fs/promises");
const path = require("node:path");

function countLines(text) {
  if (text === "") {
    return 0;
  }
  const trimmed = text.endsWith("\n") ? text.slice(0, -1) : text;
  return trimmed.split("\n").length;
}

async function lineCounts(dir) {
  const names = (await fs.readdir(dir)).filter((n) => n.endsWith(".txt"));
  const pairs = await Promise.all(
    names.map(async (name) => [name, countLines(await fs.readFile(path.join(dir, name), "utf8"))])
  );
  return Object.fromEntries(pairs);
}

module.exports = { lineCounts, countLines };
⚠️ טעויות נפוצות
  • fs.readFile(name) בלי path.join(dir, ...) — מחפש בתיקייה הנוכחית.

P10-E21 · שרשרת שאיבדה ערכים 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

then שלא מחזיר; Promise שנוצר בתוך then ולא הוחזר.

💡 רמז 2

כל then שעושה עבודה אסינכרונית חייב return ל־Promise.

✅ פתרון
// P10-E21: מתוקן
const wait = (v, ms = 5) => new Promise((r) => setTimeout(() => r(v), ms));
const getPrice = (code) => wait({ "KB-101": 199 }[code] ?? null);
const getShipping = (price) => wait(price >= 200 ? 0 : 25);

function priceWithShipping(code) {
  return getPrice(code)
    .then((price) => {
      if (price === null) {
        throw new Error("מוצר לא קיים");
      }
      return getShipping(price).then((shipping) => price + shipping);
    });
}

priceWithShipping("KB-101").then(console.log);

module.exports = { priceWithShipping };
