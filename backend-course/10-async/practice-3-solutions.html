P10-E04 · ערכים בשרשרת 🧠 הבנה רמה 1

💡 רמז 1

then בלי return מעביר undefined.

💡 רמז 2

אחרי שגיאה — מדלגים על כל ה־then עד catch. catch שמחזיר ערך "מתקן" את השרשרת.

✅ פתרון
Promise.resolve(2)
  .then((x) => x * 10)
  .then((x) => {
    x + 1;
  })
  .then((x) => console.log("A", x))
  .then(() => {
    throw new Error("אופס");
  })
  .then(() => console.log("B"))
  .catch((e) => {
    console.log("C", e.message);

P10-E61 · Promise מסתיים פעם אחת 🧠 הבנה רמה 1

💡 רמז 1

חזור לאיור 1 בשיעור: מ־pending עוברים פעם אחת, ואחרי זה Promise "קפוא".

💡 רמז 2

resolve ו־reject הם פונקציות רגילות — הן לא עוצרות את הקוד שאחריהן.

✅ פתרון
const p = new Promise((resolve, reject) => {
  resolve("ראשון");
  reject(new Error("מאוחר מדי"));
  resolve("שני");
  console.log("הקוד בפנים ממשיך לרוץ");
});

p.then((v) => console.log("then:", v)).catch((e) => console.log("catch:", e.message));
p.then((v) => console.log("then נוסף:", v));
הקוד בפנים ממשיך לרוץ
then: ראשון
then נוסף: ראשון

הקריאה הראשונה קובעת: ה־Promise הצליח עם "ראשון", וכל הקריאות שאחריה מתעלמות בשקט. אפשר לחבר כמה then לאותו Promise — כולם מקבלים את אותו ערך. וזה ההבדל הגדול מ־callback: Promise לא יכול "להיקרא פעמיים" (P10-E20).

⚠️ טעויות נפוצות
  • לחשוב ש־resolve עובד כמו return. הוא לא יוצא מהפונקציה.

P10-E62 · finally ומה עובר הלאה 🧠 הבנה רמה 2

💡 רמז 1

finally לא מקבל את הערך ולא משנה אותו — הערך (או השגיאה) עובר דרכו הלאה.

💡 רמז 2

אחרי שגיאה מדלגים על then, אבל לא על finally.

✅ פתרון
Promise.resolve(5)
  .finally(() => {
    console.log("finally 1");
    return 100;
  })
  .then((x) => {
    console.log("then 1:", x);
    throw new Error("שבר");
  })
  .finally(() => console.log("finally 2"))
  .then((x) => console.log("then 2:", x))
  .catch((e) => console.log("catch:", e.message))
  .finally(() => console.log("finally 3"));
finally 1
then 1: 5
finally 2
catch: שבר
finally 3

ה־return 100 ב־finally 1 לא שינה כלום — then 1 קיבל 5. השגיאה עברה דרך finally 2 (שרץ) ודרך then 2 (שדולג) עד ה־catch. ‏finally 3 רץ אחרי ש־catch "תיקן" את השרשרת. זה התפקיד של finally: ניקוי (לסגור חיבור, לכבות "טוען...") בלי להתערב בתוצאה.

⚠️ טעויות נפוצות
  • לחשוב ש־finally מקבל את הערך כפרמטר — הוא מקבל כלום.

P10-E64 · then שלא מחכה 🧠 הבנה רמה 2

💡 רמז 1

ה־then הראשון קורא ל־save — אבל מה הוא מחזיר?

💡 רמז 2

אם then מחזיר Promise, השרשרת מחכה לו. אם הוא מחזיר undefined — לא.

✅ פתרון
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

function save(item) {
  return sleep(20).then(() => {
    console.log("נשמר:", item);
    return item.length;
  });
}

Promise.resolve("מחברת")
  .then((item) => {
    save(item);
  })
  .then((len) => console.log("אורך:", len))
  .finally(() => console.log("סיימנו"));
אורך: undefined
סיימנו
נשמר: מחברת

"סיימנו" מודפס לפני "נשמר": השרשרת לא חיכתה לשמירה, ו־len הוא undefined. גרוע מזה — אם save הייתה נכשלת, אף catch לא היה תופס (unhandled rejection). התיקון: .then((item) => save(item)) — בלי סוגריים מסולסלים, או עם return save(item);.

⚠️ טעויות נפוצות
  • להוסיף sleep נוסף "כדי לחכות" — מסתיר את הבאג ולא מתקן אותו.

P10-E65 · איזה catch תופס? 🧠 הבנה רמה 2

💡 רמז 1

catch תופס רק שגיאות מלמעלה — מה שקרה לפניו בשרשרת.

💡 רמז 2

אחרי ש־catch החזיר ערך, השרשרת שוב "תקינה" — ה־then הבא רץ.

✅ פתרון
Promise.reject(new Error("א"))
  .then(() => console.log("1"))
  .catch((e) => {
    console.log("catch ראשון:", e.message);
    return "תוקן";
  })
  .then((v) => {
    console.log("2", v);
    throw new Error("ב");
  })
  .then(() => console.log("3"))
  .catch((e) => console.log("catch שני:", e.message))
  .then(() => console.log("4"));
catch ראשון: א
2 תוקן
catch שני: ב
4

כל catch אחראי על הקטע שמעליו, עד ה־catch הקודם. השגיאה "ב" נזרקה אחרי ה־catch הראשון, ולכן רק השני יכול לתפוס אותה. ‏"1" ו־"3" לא מודפסים — דילגו עליהם.

⚠️ טעויות נפוצות
  • לחשוב ש־catch אחד בתחילת השרשרת "מגן" על כולה. הוא מגן רק על מה שלפניו.

P10-E09 · שרשרת then 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

findUser ← then: אם null, throw new Error(...); אחרת return findOrders(user.id).then(...).

💡 רמז 2

צריך את השם גם בשלב של ההזמנות — then פנימי שעדיין רואה את user.

✅ פתרון
// P10-E09
const users = [{ id: 1, name: "דנה" }, { id: 2, name: "עומר" }];
const orders = [{ userId: 1 }, { userId: 1 }, { userId: 2 }];
const wait = (v) => new Promise((r) => setTimeout(() => r(v), 5));
const findUser = (id) => wait(users.find((u) => u.id === id) ?? null);
const findOrders = (userId) => wait(orders.filter((o) => o.userId === userId));

function orderCountText(userId) {
  return findUser(userId).then((user) => {
    if (user === null) {
      throw new Error("משתמש לא נמצא");
    }
    return findOrders(user.id).then((list) => `${user.name}: ${list.length} הזמנות`);
  });
}

orderCountText(1)
  .then(console.log)
  .then(() => orderCountText(9))
  .catch((e) => console.log(e.message));

module.exports = { findUser, findOrders, orderCountText };

משתמש לא נמצא
⚠️ טעויות נפוצות
  • לשכוח return לפני findOrders(...) — הפונקציה תחזיר undefined במקום לחכות.

P10-E10 · Promise משלך 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

💡 רמז 2

בתוך ה־setTimeout: guard clauses עם reject ו־return.

✅ פתרון
// P10-E10
function slowSquareRoot(n, ms = 10) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (typeof n !== "number" || Number.isNaN(n)) {
        reject(new Error("לא מספר"));
        return;
      }
      if (n < 0) {
        reject(new Error("אין שורש למספר שלילי"));
        return;
      }
      resolve(Math.sqrt(n));
    }, ms);
  });
}

slowSquareRoot(81).then(console.log);

module.exports = { slowSquareRoot };
9
⚠️ טעויות נפוצות
  • throw בתוך setTimeout במקום reject — לא נתפס על ידי ה־Promise, ומפיל את התוכנית.

P10-E13 · הקובץ הראשון שקיים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

for (const file of files) { try { return { file, text: await fs.readFile(file, "utf8") }; } catch { /* ממשיכים */ } }

💡 רמז 2

כאן ההמתנה ברצף היא בכוונה — לא רוצים לקרוא את כולם.

✅ פתרון
// P10-E13
const fs = require("node:fs/promises");

async function readFirstExisting(files) {
  for (const file of files) {
    try {
      const text = await fs.readFile(file, "utf8");
      return { file, text };
    } catch {
      // הקובץ לא קיים או לא קריא — ננסה את הבא
    }
  }
  throw new Error("לא נמצא אף קובץ");
}

readFirstExisting(["/nope1", "/nope2"]).catch((e) => console.log(e.message));

module.exports = { readFirstExisting };
לא נמצא אף קובץ
⚠️ טעויות נפוצות
  • return fs.readFile(...) בלי await בתוך try — השגיאה לא נתפסת שם, והלולאה לא ממשיכה.

P10-E14 · שורות בכל הקבצים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

const names = (await fs.readdir(dir)).filter((n) => n.endsWith(".txt"));

💡 רמז 2

Promise.all(names.map(async (name) => [name, count(await fs.readFile(path.join(dir, name), "utf8"))])) ואז Object.fromEntries.

✅ פתרון
// P10-E14
const fs = require("node:fs/promises");
const path = require("node:path");

function countLines(text) {
  if (text === "") {
    return 0;
  }
  const trimmed = text.endsWith("\n") ? text.slice(0, -1) : text;
  return trimmed.split("\n").length;
}

async function lineCounts(dir) {
  const names = (await fs.readdir(dir)).filter((n) => n.endsWith(".txt"));
  const pairs = await Promise.all(
    names.map(async (name) => [name, countLines(await fs.readFile(path.join(dir, name), "utf8"))])
  );
  return Object.fromEntries(pairs);
}

module.exports = { lineCounts, countLines };
⚠️ טעויות נפוצות
  • fs.readFile(name) בלי path.join(dir, ...) — מחפש בתיקייה הנוכחית.

P10-E66 · בדיקת גיל — כ־Promise 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

כמו delayedValue בשיעור: return new Promise((resolve, reject) => { setTimeout(() => { ... }, 10); });

💡 רמז 2

בתוך הטיימר: if (typeof age !== "number" || age < 0) { reject(new RangeError("גיל לא תקין")); return; }.

✅ פתרון
// P10-E66: בדיקת גיל — כ־Promise
function checkAge(age) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (typeof age !== "number" || Number.isNaN(age) || age < 0) {
        reject(new RangeError("גיל לא תקין"));
        return;
      }
      resolve(age >= 18 ? "מותר" : "אסור");
    }, 10);
  });
}

checkAge(20)
  .then(console.log)
  .then(() => checkAge(12))
  .then(console.log)
  .then(() => checkAge(-3))
  .catch((e) => console.log(e.name, e.message));

module.exports = { checkAge };
מותר
אסור
RangeError גיל לא תקין

שלושה מצבים, שתי דרכים לסיים: resolve לשתי התשובות הלגיטימיות, ‏reject לקלט שאי אפשר לענות עליו. "אסור" הוא לא שגיאה — זו תשובה. (Number.isNaN תופס את NaN, שהוא דווקא מסוג "number".)

⚠️ טעויות נפוצות
  • reject("גיל לא תקין") עם מחרוזת — אין message, ואין stack. תמיד Error.
  • להחליט מחוץ לטיימר ולקרוא ל־reject מיד — הבודק מצפה שגם הכישלון יגיע אחרי 10ms.

P10-E67 · קורא JSON עם then 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

const fs = require("node:fs/promises"); ו־return fs.readFile(file, "utf8").then((text) => ...).

💡 רמז 2

בתוך ה־then: try { return JSON.parse(text); } catch { throw new Error(JSON לא תקין ב־${file}); }. שגיאה שנזרקת בתוך then הופכת לכישלון של ה־Promise. כך שגיאת הקריאה לא עוברת דרך ה־try, ונשארת כמו שהיא.

✅ פתרון
// P10-E67: קורא JSON עם then
const fs = require("node:fs/promises");

function readJson(file) {
  return fs.readFile(file, "utf8").then((text) => {
    try {
      return JSON.parse(text);
    } catch {
      throw new Error(`JSON לא תקין ב־${file}`);
    }
  });
}

const os = require("node:os");
const path = require("node:path");
const good = path.join(os.tmpdir(), "p10-e67.json");
const bad = path.join(os.tmpdir(), "p10-e67-bad.json");
require("node:fs").writeFileSync(good, '{"port": 8080}');
require("node:fs").writeFileSync(bad, "{port: 8080}");
readJson(good)
  .then((cfg) => console.log(cfg.port))
  .then(() => readJson(bad))
  .catch((e) => console.log(e.message.replace(os.tmpdir(), "<tmp>")))
  .then(() => readJson("/no/such.json"))
  .catch((e) => console.log(e.code));

module.exports = { readJson };
8080
JSON לא תקין ב־<tmp>/p10-e67-bad.json
ENOENT

שים לב איפה ה־try: רק סביב JSON.parse, שהוא סינכרוני. שגיאת קריאה לא עוברת דרכו — היא דוחה את ה־Promise של readFile, וה־then שלנו פשוט לא רץ. ככה כל סוג שגיאה מגיע למי שקרא עם המידע הנכון.

⚠️ טעויות נפוצות
  • .catch(() => { throw new Error("JSON לא תקין...") }) בסוף השרשרת — גם "קובץ לא קיים" יקבל את ההודעה הזו, וה־code ילך לאיבוד.
  • לשכוח return לפני fs.readFile(...) — הפונקציה מחזירה undefined.

P10-E68 · העתק באותיות גדולות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שני then: הראשון מחזיר את ה־Promise של fs.writeFile (כדי שהשרשרת תחכה לו); השני מחזיר את האורך.

💡 רמז 2

האורך צריך לעבור מה־then הראשון לשני. אפשרות: .then((text) => fs.writeFile(dest, text.toUpperCase()).then(() => text.length)).

✅ פתרון
// P10-E68: העתק באותיות גדולות
const fs = require("node:fs/promises");

function copyUpper(src, dest) {
  return fs.readFile(src, "utf8").then((text) => {
    const upper = text.toUpperCase();
    return fs.writeFile(dest, upper).then(() => upper.length);
  });
}

const os = require("node:os");
const path = require("node:path");
const a = path.join(os.tmpdir(), "p10-e68-a.txt");
const b = path.join(os.tmpdir(), "p10-e68-b.txt");
require("node:fs").writeFileSync(a, "hello");
copyUpper(a, b)
  .then((n) => console.log(n, require("node:fs").readFileSync(b, "utf8")))
  .then(() => copyUpper("/no/such.txt", b))
  .catch((e) => console.log(e.code));

module.exports = { copyUpper };
5 HELLO
ENOENT

fs.writeFile מצליח עם undefined, ולכן ה־.then(() => upper.length) הפנימי "מחליף" את הערך באורך. ה־return לפניו גורם לשרשרת החיצונית לחכות לכתיבה — אחרת מי שקרא היה מקבל את האורך לפני שהקובץ נכתב (הבודק קורא את הקובץ ברגע שה־Promise מצליח).

⚠️ טעויות נפוצות
  • fs.writeFile(...) בלי return — ה־Promise מצליח לפני שהכתיבה הסתיימה, ושגיאת כתיבה הולכת לאיבוד.
  • fs.writeFileSync בתוך ה־then — עובד, אבל חוסם; המשימה היא שרשרת.

P10-E69 · Promise, טיימר ו־executor 🧠 הבנה רמה 2

💡 רמז 1

הקוד הסינכרוני: B ו־F. אחר כך — מי כבר מוכן בתור ה־Promises?

💡 רמז 2

כש־C רץ, הוא "משחרר" את ה־then של D — שנכנס לסוף התור, אחרי E.

✅ פתרון

P10-E70 · אותה פעולה — callback מול Promise 🧠 הבנה רמה 2

💡 רמז 1

ספור את בדיקות השגיאה בכל גרסה. ומה קורה בכל גרסה אם config הוא undefined ו־config.userId זורק?

💡 רמז 2

מה קורה בכל גרסה אם readConfig בטעות קוראת ל־callback פעמיים?

✅ פתרון
  1. שגיאות במקום אחד: ב־Promises יש catch אחד; ב־callbacks — בדיקה בכל רמה.
  2. שגיאה שנזרקת: אם config.userId זורק, בגרסת ה־Promises ה־catch תופס. בגרסת ה־callbacks — זריקה בתוך callback מפילה את התוכנית (P10-E56).
  3. "פעם אחת": Promise מסתיים פעם אחת (P10-E61). callback יכול בטעות להיקרא פעמיים, ואז readUser רץ פעמיים.
  4. שטוח מול מקונן: שלב נוסף ב־Promises = עוד שורת then; ב־callbacks = עוד רמת הזחה.
  5. ערך שאפשר להחזיר: פונקציה שמחזירה Promise אפשר להעביר הלאה ולחבר אליה עוד then או finally; את גרסת ה־callback אי אפשר "להחזיר".
⚠️ טעויות נפוצות
  • "ב־Promises אין שגיאות". יש — הן פשוט מגיעות למקום אחד, ובלי catch הן מפילות את Node (unhandled rejection).

P10-E72 · promisify משלך 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

✅ פתרון
// P10-E72: promisify משלך
function promisify(fn) {
  return (...args) =>
    new Promise((resolve, reject) => {
      fn(...args, (err, value) => {
        if (err) {
          reject(err);
        } else {
          resolve(value);
        }
      });
    });
}

function addLater(a, b, cb) {
  setTimeout(() => (typeof a === "number" ? cb(null, a + b) : cb(new TypeError("לא מספר"))), 5);
}
const add = promisify(addLater);
add(2, 3)
  .then(console.log)
  .then(() => add("x", 1))
  .catch((e) => console.log(e.message))
  .then(() => promisify(require("node:fs").readFile)("/no/such.txt", "utf8"))
  .catch((e) => console.log(e.code));

module.exports = { promisify };

// P10-E73: סכום המספרים בקובץ
const fs = require("node:fs/promises");

function sumFile(file) {
  return fs.readFile(file, "utf8").then((text) => {
    const lines = text.split("\n");
    let sum = 0;
    for (let i = 0; i < lines.length; i++) {
      const t = lines[i].trim();
      if (t === "") continue;
      const n = Number(t);
      if (Number.isNaN(n)) throw new Error(`שורה ${i + 1}: "${t}" אינו מספר`);
      sum += n;
    }
    return sum;
  });
}

const os = require("node:os");
const path = require("node:path");
const file = path.join(os.tmpdir(), "p10-e73.txt");
require("node:fs").writeFileSync(file, "10\n 2.5\n\n7\n");
sumFile(file)
  .then(console.log)
  .then(() => {
    require("node:fs").writeFileSync(file, "10\nעשרים\n");
    return sumFile(file);
  })
  .catch((e) => console.log(e.message));

// P10-E74: הגדרות עם ברירות מחדל
const fs = require("node:fs/promises");

function loadSettings(file, defaults) {
  return fs
    .readFile(file, "utf8")
    .then((text) => ({ ...defaults, ...JSON.parse(text) }))
    .catch((err) => {
      if (err.code === "ENOENT") return { ...defaults };
      throw err;
    });
}

const os = require("node:os");
const path = require("node:path");
const file = path.join(os.tmpdir(), "p10-e74.json");
require("node:fs").writeFileSync(file, '{"port": 8080, "name": "shop"}');
const defaults = { port: 3000, debug: false };
loadSettings(file, defaults)
  .then((s) => console.log(s))
  .then(() => loadSettings("/no/such.json", defaults))
  .then((s) => console.log(s, s === defaults))
  .then(() => loadSettings(os.tmpdir(), defaults))
  .catch((e) => console.log("נכשל:", e.code));
