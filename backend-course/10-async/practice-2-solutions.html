P10-E03 · error-first 🧠 הבנה רמה 1

💡 רמז 1

סדר הפרמטרים.

💡 רמז 2

מה קורה אם יש שגיאה — האם הקוד עוצר?

✅ פתרון
  1. הפרמטרים הפוכים: הראשון הוא err.
  2. JSON.parse רץ לפני בדיקת השגיאה — אם הקריאה נכשלה, text הוא undefined וה־parse זורק.

fs.readFile("data.json", "utf8", (err, text) => {
  if (err) {
    console.log("שגיאה:", err.message);
    return;
  }
  try {
    console.log(JSON.parse(text).total);
  } catch {
    console.log("JSON לא תקין");
  }
});
⚠️ טעויות נפוצות
  • לשכוח את ה־return — הבאג הכי נפוץ עם callbacks.

P10-E46 · קובץ שלא קיים, ומה קודם 🧠 הבנה רמה 1

💡 רמז 1

fs.readFile חוזרת מיד. ה־callback רץ רק כשמערכת ההפעלה ענתה — גם אם התשובה היא "אין קובץ".

💡 רמז 2

כשיש שגיאה, הפרמטר השני לא מקבל ערך.

console.log("1. מבקש");

גם כישלון מגיע "אחר כך": Node שולח את הבקשה למערכת ההפעלה וממשיך. כשיש שגיאה, ה־callback מקבל אותה בפרמטר הראשון, והשני נשאר undefined. ENOENT = "Error NO ENTry" — אין קובץ כזה.

⚠️ טעויות נפוצות
  • לחשוב שבשגיאה ה־callback לא נקרא בכלל. הוא תמיד נקרא — פעם אחת, עם שגיאה או עם תוצאה.

P10-E47 · למה השגיאה ראשונה? 🧠 הבנה רמה 1

💡 רמז 1

חשוב על מי שכותב את ה־callback: מה הדבר הראשון שהוא רואה?

💡 רמז 2

"אין שגיאה" נכתב ב־Node כ־null. ולגבי פעמיים: מה יקרה אם ה־callback שולח אימייל או מחייב כרטיס?

✅ פתרון
  1. כי אי אפשר לכתוב callback בלי לתת שם לפרמטר הראשון — הוא תמיד מול העיניים, ומזכיר לבדוק אותו. אילו השגיאה הייתה אחרונה, קל היה לכתוב (data) => ... ולשכוח שיש בכלל שגיאה.
  2. callback(null, data) — הצלחה, והתוצאה היא data. callback(err) — כישלון; אין תוצאה.
  3. הצלחה. "אין שגיאה, ואין גם מה להחזיר" — למשל אחרי כתיבת קובץ.
  4. מי שקורא לך מניח שה־callback הוא "סוף הפעולה". קריאה שנייה מריצה את ההמשך פעמיים: תשובה כפולה ללקוח, חיוב כפול, או קריסה ("כבר נשלחה תשובה"). זה הבאג שב־P10-E20.
⚠️ טעויות נפוצות
  • לבדוק if (data) במקום if (err) — קובץ ריק ("") הוא הצלחה עם ערך falsy.

P10-E48 · try סביב readFile 🧠 הבנה רמה 2

💡 רמז 1

האם fs.readFile זורקת? או שהיא מעבירה את השגיאה למקום אחר?

text?.length — אם text הוא undefined, התוצאה undefined (בלי קריסה).

✅ פתרון
const fs = require("node:fs");

try {
  fs.readFile("/no/such/file.txt", "utf8", (err, text) => {
    console.log("ב־callback, אורך:", text?.length);
  });
  console.log("סוף ה־try");
} catch (err) {
  console.log("נתפס:", err.code);
}
console.log("אחרי");
סוף ה־try
אחרי

ה־catch לא רץ אף פעם: readFile לא זורקת, והשגיאה מגיעה ל־callback בפרמטר err — שהקוד פשוט התעלם ממנו. התיקון: לוותר על ה־try, ובתחילת ה־callback:

if (err) {
  console.log("נכשל:", err.code);

}
⚠️ טעויות נפוצות
  • להוסיף try/catch נוסף סביב הקריאה "ליתר ביטחון". הוא לא תופס כלום; רק err נושא את השגיאה.

P10-E49 · לקרוא פירמידה 🧠 הבנה רמה 2

💡 רמז 1

ספור את הפונקציות שמקוננות זו בתוך זו — כל callback הוא רמה.

💡 רמז 2

סעיף 4: "בכל מקרה" = אחרי הצלחה וגם בכל אחת מנקודות הכישלון.

✅ פתרון
  1. ארבע רמות (readConfig ← readUser ← readOrders ← sendReport), וארבע בדיקות שגיאה זהות.

P10-E50 · Sync או callback? 🧠 הבנה רמה 1

💡 רמז 1

השאלה היא: האם יש בזמן הזה מישהו אחר שמחכה למלצר?

💡 רמז 2

לפני שהשרת התחיל לקבל בקשות — אין אף אחד שמחכה.

✅ פתרון
  1. Sync בסדר. אין שום דבר אחר לעשות עד שההגדרות נטענו; הקוד פשוט יותר.
  2. callback (או Promise). בזמן הקריאה שאר הבקשות צריכות לקבל שירות.
  3. Sync בסדר. כלי שורת פקודה של משתמש אחד, פעולה אחת.
  4. Sync בסדר. זה קורה פעם אחת, לפני שמישהו מחכה.
  5. לא זה ולא זה כמו שהוא: גם readFile יטען 2GB לזיכרון. קוראים בחתיכות (streams — בפרק 13); אבל בוודאי לא Sync.
⚠️ טעויות נפוצות
  • "Sync תמיד רע". הוא רע רק כשיש מישהו אחר שמחכה — כלומר בתוך שרת שכבר מקבל בקשות.

P10-E07 · callback בסגנון Node 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

בתוך ה־callback של readFile: אם יש err — return callback(err).

💡 רמז 2

JSON.parse בתוך try/catch. היזהר לא לקרוא ל־callback בתוך ה־try (אם הוא עצמו יזרוק — ייקרא שוב מה־catch).

✅ פתרון
// P10-E07: callback בסגנון error-first
const fs = require("node:fs");

function readJson(file, callback) {
  fs.readFile(file, "utf8", (err, text) => {
    if (err) {
      callback(err);
      return;
    }
    let data;
    try {
      data = JSON.parse(text);
    } catch (parseError) {
      callback(parseError);
      return;
    }
    callback(null, data);
  });
}

readJson("/no/such.json", (err) => console.log(err.code));

module.exports = { readJson };
ENOENT
⚠️ טעויות נפוצות
  • try { callback(null, JSON.parse(text)) } catch (e) { callback(e) } — אם ה־callback של מי שקרא זורק, הוא יקרא פעמיים.

// P10-E08
function legacyGetPrice(code, callback) {
  const prices = { "KB-101": 199, "MS-201": 89 };
  setTimeout(() => {
    if (code in prices) {
      callback(null, prices[code]);
    } else {
      callback(new Error(`אין מחיר ל־${code}`));
    }
  }, 5);
}

function getPrice(code) {
  return new Promise((resolve, reject) => {
    legacyGetPrice(code, (err, price) => {
      if (err) {
        reject(err);
      } else {
        resolve(price);
      }
    });
  });
}

getPrice("KB-101").then((p) => console.log(p));

module.exports = { legacyGetPrice, getPrice };

(ל־Node יש עוזר מובנה: require("node:util").promisify(legacyGetPrice) — עושה בדיוק את זה לכל פונקציה error-first.)

⚠️ טעויות נפוצות

P10-E20 · callback שנקרא פעמיים 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

חסר return אחרי טיפול בשגיאה; ה־parse לא בתוך try.

💡 רמז 2

מבנה נכון: אם err ← cb(err) ו־return; try parse; catch ← cb(e) ו־return; cb(null, data).

✅ פתרון
// P10-E20: מתוקן
const fs = require("node:fs");

function loadSettings(file, cb) {
  fs.readFile(file, "utf8", (err, text) => {
    if (err) {
      cb(err);
      return;
    }
    let settings;
    try {
      settings = JSON.parse(text);
    } catch (parseErr) {
      cb(parseErr);
      return;
    }
    cb(null, { theme: "light", ...settings });
  });
}

module.exports = { loadSettings };
⚠️ טעויות נפוצות
  • להוסיף try/catch סביב fs.readFile — לא תופס שום דבר אסינכרוני.

P10-E26 · חיבור אסינכרוני עם callback 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

כל הקוד של הפונקציה נכנס לתוך setTimeout(() => { ... }, 10). כך גם השגיאה וגם התוצאה מגיעות אחרי ההמתנה.

💡 רמז 2

בתוך ה־setTimeout: if (typeof a !== "number" || typeof b !== "number") { callback(new TypeError(...)); return; }, ואחריו callback(null, a + b);.

✅ פתרון
// P10-E26: חיבור אסינכרוני עם callback
function addLater(a, b, callback) {
  setTimeout(() => {
    if (typeof a !== "number" || typeof b !== "number") {
      callback(new TypeError("a ו־b חייבים להיות מספרים"));
      return;
    }
    callback(null, a + b);
  }, 10);
}

addLater(2, 3, (err, sum) => console.log(err, sum));
addLater(2, "3", (err) => console.log(err.message));
console.log("קודם אני");

module.exports = { addLater };

"קודם אני" מודפס ראשון, כי שתי הקריאות ל־addLater רק רושמות טיימר וחוזרות מיד (שיעור 1). ה־callbacks רצים אחר כך, מתוך ה־event loop.

למה גם השגיאה מחכה? כי פונקציה שלפעמים קוראת ל־callback מיד ולפעמים אחר כך מבלבלת את מי שמשתמש בה: הקוד שאחרי הקריאה רץ פעם לפני ה־callback ופעם אחריו. הכלל ב־Node: callback תמיד אסינכרוני.

⚠️ טעויות נפוצות
  • בדיקת הטיפוסים לפני ה־setTimeout, עם callback(err) מיד — השגיאה מגיעה בסנכרון. הבודק תופס את זה.
  • לשכוח return אחרי ה־callback של השגיאה — ה־callback נקרא פעמיים, פעם עם שגיאה ופעם עם "23".
  • return a + b מתוך ה־setTimeout — הערך הולך לאיבוד. מי שקרא ל־addLater כבר לא מחכה.

P10-E51 · שורות מקובץ 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

התבנית מהשיעור: fs.readFile(file, "utf8", (err, text) => { if (err) { callback(err); return; } ... }).

💡 רמז 2

text.split("\n"), ואם האיבר האחרון ריק — pop(). (קובץ ריק לגמרי ← מערך ריק.)

✅ פתרון
// P10-E51: שורות מקובץ
const fs = require("node:fs");

function readLines(file, callback) {
  fs.readFile(file, "utf8", (err, text) => {
    if (err) {
      callback(err);
      return;
    }
    const lines = text.split("\n");
    if (lines[lines.length - 1] === "") lines.pop();
    callback(null, lines);
  });
}

const os = require("node:os");
const path = require("node:path");
const file = path.join(os.tmpdir(), "p10-e51.txt");
fs.writeFileSync(file, "קפה\nחלב\nלחם\n");
readLines(file, (err, lines) => {
  console.log(err, lines);
  readLines("/no/such/file.txt", (err) => console.log(err.code));
});

module.exports = { readLines };

בהדגמה הקריאה השנייה מתחילה רק בתוך ה־callback של הראשונה. אילו שתיהן היו יוצאות "למטבח" יחד, הסדר בפלט היה יכול להשתנות — מי שעונה קודם מודפס קודם. זה בדיוק המצב בשרת: לא יודעים מי יחזור ראשון.

P10-E52 · שני קבצים, אחד אחרי השני 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

שתי רמות: ה־callback של הקריאה הראשונה קורא ל־fs.readFile(fileB, ...), ובתוך ה־callback השני — callback(null, a + b).

💡 רמז 2

בכל רמה: if (err) { callback(err); return; } לפני כל דבר אחר.

✅ פתרון
// P10-E52: שני קבצים, אחד אחרי השני
const fs = require("node:fs");

function joinFiles(fileA, fileB, callback) {
  fs.readFile(fileA, "utf8", (err, a) => {
    if (err) {
      callback(err);
      return;
    }
    fs.readFile(fileB, "utf8", (err, b) => {
      if (err) {
        callback(err);
        return;
      }
      callback(null, a + b);
    });
  });
}

const path = require("node:path");
const head = path.join(os.tmpdir(), "p10-e52-head.txt");
const body = path.join(os.tmpdir(), "p10-e52-body.txt");
fs.writeFileSync(head, "כותרת\n");
fs.writeFileSync(body, "גוף\n");
joinFiles(head, body, (err, text) => {
  console.log(err);
  console.log(text);
  joinFiles(head, "/no/such/file.txt", (err) => console.log("נכשל:", err.code));
});

P10-E53 · לשמור JSON 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

let text; try { text = JSON.stringify(data, null, 2); } catch (err) { ...; return; } — כאן try כן עובד, כי stringify סינכרוני.

💡 רמז 2

ב־fs.writeFile(file, text, (err) => ...) מעבירים את err כמו שהוא: אם אין שגיאה הוא null. אבל עדיף במפורש: if (err) ... else callback(null).

✅ פתרון
// P10-E53: לשמור JSON
const fs = require("node:fs");

function saveJson(file, data, callback) {
  let text;
  try {
    text = JSON.stringify(data, null, 2);
  } catch (err) {
    setTimeout(() => callback(err), 0);
    return;
  }
  fs.writeFile(file, text, (err) => {
    if (err) {
      callback(err);
      return;
    }
    callback(null);
  });
}

const os = require("node:os");
const path = require("node:path");
const file = path.join(os.tmpdir(), "p10-e53.json");
saveJson(file, { theme: "dark", fonts: [12, 14] }, (err) => {
  console.log("נשמר?", err === null);
  console.log(fs.readFileSync(file, "utf8"));
  saveJson(file, { n: 10n }, (err) => console.log(err.message));
});

module.exports = { saveJson };

P10-E54 · לעטוף readFile ב־Promise 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

בתוך ה־callback: if (err) reject(err); else resolve(text);. ול־readUpper: return readText(file).then((t) => t.toUpperCase());

✅ פתרון
// P10-E54: לעטוף readFile ב־Promise
const fs = require("node:fs");

function readText(file) {
  return new Promise((resolve, reject) => {
    fs.readFile(file, "utf8", (err, text) => {
      if (err) {
        reject(err);
      } else {
        resolve(text);
      }
    });
  });
}

function readUpper(file) {
  return readText(file).then((t) => t.toUpperCase());
}

  .then(() => readUpper(file))
  .then((t) => console.log(t))
  .then(() => readText("/no/such.txt"))
  .catch((e) => console.log(e.code));

module.exports = { readText, readUpper };

⚠️ טעויות נפוצות
  • return text מתוך ה־callback במקום resolve(text) — ה־Promise נשאר pending לנצח.
  • לכתוב גם reject(err) וגם resolve(text) בלי else — לא מזיק (Promise מסתיים פעם אחת), אבל מבלבל את מי שקורא.

P10-E56 · throw או callback? 🧠 הבנה רמה 2

💡 רמז 1

parsePrice זורקת בתוך ה־callback של setTimeout. מי מחכה שם עם catch?

💡 רמז 2

✅ פתרון
  1. ה־try/catch שבחוץ כבר הסתיים כשהטיימר רץ (P10-E41). parsePrice זורקת, אף אחד לא תופס, והתוכנית קורסת — ו־cb לא נקרא בכלל.
  2. תופסים בתוך ה־callback, ומעבירים הלאה:

  const n = Number(text);
  if (Number.isNaN(n)) throw new TypeError(`"${text}" אינו מחיר`);
  return n;
}

  setTimeout(() => {
    let price;
    try {
      price = parsePrice(text);
    } catch (err) {
      callback(err);
      return;
    }
    callback(null, price);
  }, 10);
}

⚠️ טעויות נפוצות
  • לשים את callback(null, ...) בתוך ה־try — callback כפול כשהוא זורק.

P10-E58 · לקרוא את כל הקבצים במקביל 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שלושה משתנים: texts = [], ‏left = files.length, ‏finished = false. בכל callback: אם כבר finished — יוצאים.

💡 רמז 2

בשגיאה: finished = true; callback(err);. בהצלחה: texts[i] = text; left--; if (left === 0) { finished = true; callback(null, texts); }.

✅ פתרון
// P10-E58: לקרוא את כל הקבצים במקביל
const fs = require("node:fs");

function readAll(files, callback) {
  if (files.length === 0) {
    setTimeout(() => callback(null, []), 0);
    return;
  }
  const texts = [];
  let left = files.length;
  let finished = false;
  files.forEach((file, i) => {
    fs.readFile(file, "utf8", (err, text) => {
      if (finished) return;
      if (err) {
        finished = true;
        callback(err);
        return;
      }
      texts[i] = text;
      left--;
      if (left === 0) {
        finished = true;
        callback(null, texts);
      }
    });
  });
}

const path = require("node:path");

  console.log(err, texts);
  readAll([a, "/no/such.txt", b], (err) => console.log("נכשל:", err.code));
});

  • בלי הדגל finished — שתי שגיאות ← callback פעמיים.

// P10-E59: משתמשים מקובץ CSV
const fs = require("node:fs");

function loadUsers(file, callback) {
  fs.readFile(file, "utf8", (err, text) => {
    if (err) {
      callback(err);
      return;
    }
    const lines = text.split("\n");
    const users = [];
    for (let i = 1; i < lines.length; i++) {
      if (lines[i].trim() === "") continue;
      const parts = lines[i].split(",").map((p) => p.trim());
      const age = Number(parts[1]);
      if (parts.length !== 3 || parts[1] === "" || Number.isNaN(age)) {
        callback(new Error(`שורה ${i + 1} לא תקינה`));
        return;
      }
      users.push({ name: parts[0], age, city: parts[2] });
    }
    callback(null, users);
  });
}

P10-E60 · משימות ברצף בלי פירמידה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

פונקציה פנימית next(i): אם i === tasks.length — callback(null, results). אחרת — tasks[i]((err, result) => { ... }).

💡 רמז 2

בתוך ה־done: בשגיאה — callback(err); return;. אחרת results.push(result); next(i + 1);.

✅ פתרון
// P10-E60: משימות ברצף בלי פירמידה
function series(tasks, callback) {
  const results = [];
  if (tasks.length === 0) {
    setTimeout(() => callback(null, results), 0);
    return;
  }
  function next(i) {
    if (i === tasks.length) {
      callback(null, results);
      return;
    }
    tasks[i]((err, result) => {
      if (err) {
        callback(err);
        return;
      }
      results.push(result);
      next(i + 1);
    });
  }
  next(0);
}

const log = [];
series([
  (done) => setTimeout(() => { log.push("config"); done(null, "config"); }, 10),
  (done) => setTimeout(() => { log.push("user"); done(null, "user"); }, 5),
], (err, results) => {
  console.log(err, results, log);
  series([
    (done) => done(new Error("אין הגדרות")),
    (done) => done(null, "לא אמור לרוץ"),
  ], (err) => console.log("נכשל:", err.message));
});

module.exports = { series };
