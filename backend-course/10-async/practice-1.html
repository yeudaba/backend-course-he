P10-E02 · event loop מעורב

🧠 הבנהרמה 1⏱ 15 דק׳ידע נדרש: שיעור 1

נבא את הסדר והסבר כל צעד לפי איור ה־event loop:

console.log(1);
setTimeout(() => console.log(2), 0);
Promise.resolve().then(() => console.log(3));
Promise.resolve().then(() => {
  console.log(4);
  setTimeout(() => console.log(5), 0);
});
console.log(6);

P10-E06 · delay 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

בקובץ 10-async/starter/P10-E06.js השלם:

  • delay(ms, value) — מחזירה Promise שמצליח עם value אחרי ms מילישניות.
  • countdown(from, ms, log) — אסינכרונית: קוראת ל־log(n) מ־from עד 1, עם המתנה של ms בין מספר למספר, ובסוף log("🚀").
