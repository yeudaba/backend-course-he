P10-E26 · חיבור אסינכרוני עם callback 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

כתוב addLater(a, b, callback) בסגנון error-first של Node (שיעור 2):

  • אחרי 10 מילישניות (setTimeout) — callback(null, a + b).
  • אם a או b אינם מספרים — callback(new TypeError("a ו־b חייבים להיות מספרים")). גם השגיאה מגיעה אחרי ההמתנה, לא מיד.
  • ה־callback נקרא בדיוק פעם אחת.
addLater(2, 3, (err, sum) => console.log(err, sum)); // (אחרי 10ms) null 5
console.log("קודם אני");                             // מודפס ראשון

הבודק בודק גם שה־callback לא נקרא לפני ש־addLater חזרה.

P10-E53 · לשמור JSON 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

כתוב saveJson(file, data, callback): כותבת את data לקובץ כ־JSON מעוצב (JSON.stringify(data, null, 2)) עם fs.writeFile, ובסוף callback(null). בשגיאת כתיבה — callback(err).

מלכודת: JSON.stringify יכול לזרוק (למשל על 10n — BigInt). במקרה כזה saveJson לא זורקת, אלא מעבירה את השגיאה ל־callback(err) — ולא מיד: עטוף את הקריאה ל־callback ב־setTimeout(..., 0), כי callback תמיד מגיע "אחר כך" (P10-E26).

saveJson("settings.json", { theme: "dark" }, (err) => console.log("נשמר?", err === null));
saveJson("big.json", { n: 10n }, (err) => console.log(err.message));

P10-E55 · תוצאות שמגיעות בסדר אחר

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: פרק 4, פרק 6, שיעור 2

בלי להריץ — מה יודפס? fakeRead מדמה קריאה שלוקחת זמן שונה לכל קובץ.

function fakeRead(name, ms, callback) {
  setTimeout(() => callback(null, name.toUpperCase()), ms);
}

const files = [["a", 30], ["b", 10], ["c", 20]];
const results = [];
const byIndex = [];
for (let i = 0; i < files.length; i++) {
  const [name, ms] = files[i];
  fakeRead(name, ms, (err, text) => {
    results.push(text);
    byIndex[i] = text;
    if (results.length === files.length) {
      console.log("push:", results);
      console.log("byIndex:", byIndex);
    }
  });
}
console.log("אחרי הלולאה:", results.length);

🔗 איך זה מתחבר: לולאת for עם let (פרק 4), destructuring של מערך ו־push מול השמה לאינדקס (פרק 6). השיעור: callbacks חוזרים בסדר שבו הפעולות הסתיימו, לא בסדר שבו הן התחילו.

P10-E59 · משתמשים מקובץ CSV 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 2, פרק 6, פרק 7, שיעור 2

כתוב loadUsers(file, callback): קוראת קובץ CSV, וקוראת ל־callback(null, users) עם מערך של אובייקטים.

  • השורה הראשונה היא כותרת (name,age,city) — מדלגים עליה. גם שורות ריקות (למשל בסוף הקובץ) — מדלגים.
  • כל שורה הופכת ל־{ name, age, city }: בלי רווחים בקצוות של כל שדה, ו־age כמספר.
  • שורה שאין בה בדיוק 3 שדות, או שהגיל בה אינו מספר — callback(new Error("שורה N לא תקינה")), כש־N הוא מספר השורה בקובץ (הכותרת היא שורה 1).
  • שגיאת קריאה — callback(err) המקורי. בכל מקרה — callback פעם אחת.
// users.csv:
// name,age,city
// דנה, 31 ,חיפה
// עומר,27,תל אביב
loadUsers("users.csv", (err, users) => console.log(users));
// [ { name: 'דנה', age: 31, city: 'חיפה' }, { name: 'עומר', age: 27, city: 'תל אביב' } ]

P10-E60 · משימות ברצף בלי פירמידה 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: פרק 5, שיעור 2

הפירמידה מהשיעור נבנית כי כל שלב מקונן בתוך הקודם. כתוב כלי שמריץ שלבים ברצף בלי קינון: series(tasks, callback).

  • tasks הוא מערך של פונקציות, כל אחת בצורה (done) => { ... }, ש"מסיימת" עם done(err, result).
  • מריצים את הראשונה; רק כשהיא קוראת ל־done — את השנייה, וכן הלאה.
  • בסוף — callback(null, results) עם כל התוצאות לפי הסדר. שגיאה באחת — callback(err) מיד, ולא מריצים את השאר. מערך ריק — callback(null, []) בטיימר של 0.
series([
  (done) => setTimeout(() => done(null, "config"), 10),
  (done) => setTimeout(() => done(null, "user"), 5),
], (err, results) => console.log(err, results)); // null [ 'config', 'user' ]

📄 כותבים בקובץ 10-async/starter/P10-E60.js (יש בו רק הערה). בסוף הקובץ: module.exports = { series };

% node 10-async/starter/P10-E60.js
