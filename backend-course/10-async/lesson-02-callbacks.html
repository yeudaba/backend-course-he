שיעור 2 — callbacks ו־error-first

⏱ ~25 דקות

🎯 בשיעור הזה
  • callbacks אסינכרוניים: "תתקשר אליי כשסיימת".
  • המוסכמה של Node: error-first.
  • למה callbacks מסתבכים ("callback hell") — והמוטיבציה ל־Promises.

1. קריאת קובץ — בגרסה האסינכרונית

בפרויקט 1 השתמשת ב־fs.readFileSync — התוכנית עוצרת עד שהקובץ נקרא. הגרסה האסינכרונית מקבלת callback:

const fs = require("node:fs");
const os = require("node:os");
const path = require("node:path");

const file = path.join(os.tmpdir(), "async-demo.txt");
fs.writeFileSync(file, "שלום מהקובץ");

console.log("מבקש לקרוא...");
fs.readFile(file, "utf8", (err, text) => {
  if (err) {
    console.log("שגיאה:", err.message);
    return;
  }
  console.log("קיבלתי:", text);
});
console.log("ממשיך בינתיים");
מבקש לקרוא...
ממשיך בינתיים
קיבלתי: שלום מהקובץ

2. error-first

המוסכמה של Node: ה־callback מקבל קודם את השגיאה (או null אם אין), ורק אחר כך את התוצאה. למה ראשונה? כדי שאי אפשר יהיה "לשכוח" לבדוק אותה.

const fs = require("node:fs");
fs.readFile("/no/such/file.txt", "utf8", (err, text) => {
  if (err) {
    console.log(err.code);
    return;
  }
  console.log(text);
});
ENOENT
⚠️ try/catch לא תופס שגיאות של callback

try { fs.readFile(..., cb) } catch {} — לא יעבוד: ה־try מסתיים מיד, הרבה לפני שהשגיאה מתרחשת. שגיאות אסינכרוניות מגיעות דרך הפרמטר err (או, בהמשך, דרך Promise).

3. callback hell

מה אם צריך כמה פעולות ברצף — כל אחת תלויה בקודמת? קרא הגדרות ← קרא משתמש ← קרא הזמנות של המשתמש:

readConfig((err, config) => {
  if (err) return handle(err);
  readUser(config.userId, (err, user) => {
    if (err) return handle(err);
    readOrders(user.id, (err, orders) => {
      if (err) return handle(err);
      sendReport(orders, (err) => {
        if (err) return handle(err);
        console.log("done");
      });
    });
  });
});

"פירמידת האבדון": כל שלב מוזח עוד, הטיפול בשגיאות חוזר בכל רמה, וקשה לקרוא מה קורה. כך נראה הרבה קוד Node ישן. ה־Promises (שיעור 3) ו־async/await (שיעור 4) נולדו כדי לפתור בדיוק את זה — אותה לוגיקה תיראה כמו ארבע שורות רגילות.

4. 👣 לעטוף callback ב־Promise

תצטרך את זה עם ספריות ישנות. הצצה לשיעור הבא:

const fs = require("node:fs");

function readText(file) {
  return new Promise((resolve, reject) => {
    fs.readFile(file, "utf8", (err, text) => {
      if (err) {
        reject(err);
      } else {
        resolve(text);
      }
    });
  });
}

readText("/no/such/file.txt").catch((err) => console.log("נתפס:", err.code));
נתפס: ENOENT

(ל־fs כבר יש גרסה מוכנה שמחזירה Promises: require("node:fs/promises") — נשתמש בה בשיעור הבא.)
