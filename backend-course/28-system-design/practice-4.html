P28-E25 · אתגר: Bloom filter 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 45 דק׳ידע נדרש: שיעור 4

"השם הזה תפוס?" על מיליון משתמשים, בלי לשאול את המסד על כל הקלדה. בקובץ P28-E25.ts: createBloom(expected, falsePositiveRate) ← { m, k, bytes, add(item), mightContain(item) }. m = ceil(−n·ln p / (ln 2)²) ביטים, k = round(m/n · ln 2) (לפחות 1), ומערך Uint8Array של ceil(m/8) בתים. k מיקומים לכל פריט: מ־sha256 של הפריט, h1 = 4 הבתים הראשונים, h2 = 4 הבאים (אי־זוגי), מיקום i = (h1 + i·h2) % m.

P28-E26 · quorum: כמה העתקים צריכים להסכים 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 25 דק׳ידע נדרש: שיעור 4

במסדים מבוזרים (Cassandra, ‏DynamoDB) יש N העתקים של כל רשומה. כתיבה מחכה ל־W אישורים, וקריאה שואלת R העתקים. אם R + W > N, כל קבוצת קריאה חופפת לכל קבוצת כתיבה בהעתק אחד לפחות, ולכן הקריאה תמיד רואה את הכתיבה האחרונה. כתוב מקובץ ריק סימולציה קטנה, וייצא:

  • type Replica = { up: boolean; version: number; value: string | null }.
  • isStrong(n, r, w): boolean — ‏r + w > n.
  • quorumWrite(replicas, w, value, version): boolean — כותבת value ו־version לכל העתק עם up: true, ומחזירה האם לפחות w אישרו. גם כשהכתיבה "נכשלה", העתקים שאישרו נשארים מעודכנים.
  • quorumRead(replicas, r) ← { value, version, repaired }. קוראת את r ההעתקים הזמינים הראשונים (לפי הסדר במערך), ומחזירה את הערך עם ה־version הגבוה מביניהם. ‏read repair: כל העתק שנקרא ויש לו גרסה ישנה מתעדכן לחדשה, ו־repaired הוא כמה עודכנו. פחות מ־r העתקים זמינים ← Error.

% node 28-system-design/starter/P28-E26.ts
% npm run check P28-E26

P28-E82 · מאיפה לקרוא? 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 26, שיעור 4

"מה מותר להיות ישן" — כקוד. בקובץ 28-system-design/starter/P28-E82.ts (יש בו רק הערה) כתוב וייצא:

export function readSource(policy: Policy, ctx: { lastWriteAt: number | null; now: number; inTransaction: boolean }): "cache" | "replica" | "primary"

כש־Policy הוא אחד מ:

type Policy = { kind: "strong" } | { kind: "stale-ok"; maxStaleMs: number; cacheable: boolean };
  • strong (מלאי, יתרה) ← תמיד "primary". וגם כל קריאה בתוך טרנזקציה (inTransaction) ← "primary".
  • ‏stale-ok: אם המשתמש כתב לפני פחות מ־maxStaleMs (‏now - lastWriteAt < maxStaleMs) ← "primary" (קריאה אחרי כתיבה, E14). אחרת: ‏cacheable ← "cache", אחרת "replica".
  • maxStaleMs שלילי ← RangeError.

🔗 איך זה מתחבר: cache מפרק 26 וטרנזקציות מפרק 18, יחד עם replicas משיעור 2 — והשיעור: עקביות לכל נתון.
