P28-E44 · שיא מתוך לוגים של JSON 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 24, שיעור 1

דף אחד צריך כמה קריאות; חלקן תלויות באחרות (צריך את המשתמש לפני ההזמנות שלו). אם מריצים כל מה שאפשר במקביל (Promise.all), הזמן הוא ה"מסלול הקריטי" — שרשרת התלויות הארוכה ביותר. בקובץ 28-system-design/starter/P28-E45.ts (יש בו רק הערה) כתוב וייצא:

export function pageTime(steps: { name: string; ms: number; after?: string[] }[]): { sequential: number; parallel: number; critical: string[] }
  • sequential — סכום כל הזמנים (הכול ב־await אחד אחרי השני).
  • parallel — הזמן שבו מסתיים הצעד האחרון, כשכל צעד מתחיל ברגע שכל ה־after שלו הסתיימו. ‏critical — שמות הצעדים בשרשרת הארוכה, מההתחלה לסוף (בתיקו בין תלויות — הראשונה ב־after; בתיקו בין צעדים אחרונים — הראשון ב־steps).
  • תלות בשם שלא קיים ← Error עם השם. מעגל תלויות ← Error שכולל "מעגל". רשימה ריקה ← { sequential: 0, parallel: 0, critical: [] }.
