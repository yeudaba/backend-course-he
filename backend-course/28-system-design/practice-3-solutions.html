P28-E06 · base62 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

כמו להמיר לבסיס 2: שארית החלוקה ב־62 היא הספרה האחרונה; מחלקים (שלם) וממשיכים.

💡 רמז 2

decode: n = n * 62 + ALPHABET.indexOf(ch), משמאל לימין.

✅ פתרון
// P28-E06
// base62: ספרות 0-9, a-z, A-Z. כמו בסיס 10 או 16 — רק עם 62 "ספרות". 7 תווים = 62⁷ ≈ 3.5 טריליון קודים
const ALPHABET = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";

export function encode(n: number): string {
  if (!Number.isSafeInteger(n) || n < 0) throw new Error("רק מספר שלם אי־שלילי");
  if (n === 0) return "0";
  let out = "";
  while (n > 0) {
    out = ALPHABET[n % 62] + out;
    n = Math.floor(n / 62);
  }
  return out;
}

export function decode(code: string): number {
  if (!/^[0-9a-zA-Z]+$/.test(code)) throw new Error("קוד לא תקין");
  let n = 0;
  for (const ch of code) n = n * 62 + ALPHABET.indexOf(ch);
  if (!Number.isSafeInteger(n)) throw new Error("קוד ארוך מדי");
  return n;
}
⚠️ טעויות נפוצות
  • לשכוח את 0 — הלולאה לא רצה, ומתקבלת מחרוזת ריקה (E20).

P28-E10 · קוד אקראי והתנגשויות 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

לולאת ניסיונות, ובתוכה לולאה שבונה את הקוד.

💡 רמז 2

random מוזרק — כך הבודק קובע מה יוגרל.

✅ פתרון
// P28-E10
// קוד קצר אקראי: אין צורך במונה משותף בין שרתים. התנגשות — נדירה, אבל קורית: בודקים ומנסים שוב
const ALPHABET = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";

export async function generateCode(
  exists: (code: string) => Promise<boolean>,
  { length = 7, maxAttempts = 5, random = Math.random }: { length?: number; maxAttempts?: number; random?: () => number } = {},
): Promise<string> {
  for (let attempt = 0; attempt < maxAttempts; attempt++) {
    let code = "";
    for (let i = 0; i < length; i++) code += ALPHABET[Math.floor(random() * 62)];
    if (!(await exists(code))) return code;
  }
  throw new Error(`לא נמצא קוד פנוי אחרי ${maxAttempts} ניסיונות`);
}

"בודקים ואז מכניסים" — יש פה מרוץ: שני שרתים מגרילים אותו קוד, שניהם רואים "פנוי". הסיכוי זעום, אבל הפתרון הנכון זהה לפרויקט 3: UNIQUE במסד, ו־INSERT שנכשל ← קוד חדש. כך עושה E17 (insert מחזיר false).

⚠️ טעויות נפוצות
  • לולאה בלי גבול — אם ה־store תמיד אומר "תפוס" (באג, או מסד מלא בקודים קצרים), השרת נתקע.

P28-E17 · שירות קיצור קישורים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

new URL(url) זורק על כתובת לא חוקית; .protocol כולל את הנקודתיים: "https:".

💡 רמז 2

תפוגה: expiresAt = now() + ttlSeconds * 1000, ו־now() >= expiresAt ← 410.

✅ פתרון
// P28-E17
// שירות קיצור קישורים — הלוגיקה, מעל store שאפשר להחליף (Map בבדיקות, PostgreSQL + Redis בפרודקשן)
export interface Link {
  code: string;
  url: string;
  createdAt: number;
  expiresAt: number | null;
  clicks: number;
}

export interface Store {
  get(code: string): Promise<Link | undefined>;
  insert(link: Link): Promise<boolean>; // false אם הקוד תפוס
  incrementClicks(code: string): Promise<void>;
}

export function memoryStore(): Store & { links: Map<string, Link> } {
  const links = new Map<string, Link>();
  return {
    links,
    get: async (code) => links.get(code),
    insert: async (link) => (links.has(link.code) ? false : (links.set(link.code, { ...link }), true)),
    incrementClicks: async (code) => {
      const l = links.get(code);
      if (l) l.clicks++;
    },
  };
}

const RESERVED = new Set(["api", "admin", "health", "login"]);

export function createShortener(store: Store, { newCode, now = () => Date.now() }: { newCode: () => string; now?: () => number }) {
  return {
    async create({ url, alias, ttlSeconds }: { url: string; alias?: string; ttlSeconds?: number }): Promise<Link> {
      let parsed: URL;
      try {
        parsed = new URL(url);
      } catch {
        throw new Error("כתובת לא תקינה");
      }
      if (parsed.protocol !== "https:" && parsed.protocol !== "http:") throw new Error("רק http/https"); // לא javascript: ולא data:
      if (alias !== undefined && (!/^[a-zA-Z0-9-]{3,30}$/.test(alias) || RESERVED.has(alias.toLowerCase()))) throw new Error("alias לא תקין");
      const base = { url: parsed.toString(), createdAt: now(), expiresAt: ttlSeconds ? now() + ttlSeconds * 1000 : null, clicks: 0 };
      if (alias !== undefined) {
        if (!(await store.insert({ ...base, code: alias }))) throw new Error("alias תפוס");
        return { ...base, code: alias };
      }
      for (let i = 0; i < 5; i++) {
        const code = newCode();
        if (await store.insert({ ...base, code })) return { ...base, code };
      }
      throw new Error("לא נמצא קוד פנוי");
    },
    // מה ה־redirect מחזיר: 302 (לא 301 — דפדפן שומר 301 לתמיד, ואז לא סופרים קליקים ואי אפשר לשנות יעד)
    async resolve(code: string): Promise<{ status: 302; location: string } | { status: 404 } | { status: 410 }> {
      const link = await store.get(code);
      if (!link) return { status: 404 };
      if (link.expiresAt !== null && now() >= link.expiresAt) return { status: 410 };
      await store.incrementClicks(code);
      return { status: 302, location: link.url };
    },
  };
}

מכאן לשירות אמיתי — הכול כבר בקורס: Nest controller עם @Redirect, store ב־PostgreSQL (code כ־PRIMARY KEY), cache של code ← url ב־Redis (רוב הקליקים על מעט קישורים), והקליקים — INCR ב־Redis או תור, שנכתבים למסד באצוות. הגבלת קצב על create. אולי פרויקט קטן לתיק העבודות?

⚠️ טעויות נפוצות
  • לקבל כל מחרוזת כ־URL — javascript: בקישור "קצר" שמופץ ברשת הוא מתקפה מוכנה.

P28-E20 · base62 עם שלוש תקלות 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

n / 62 ב־JavaScript — מה הוא מחזיר ל־63?

💡 רמז 2

out += ch מוסיף לסוף. איזו ספרה מחושבת ראשונה?

✅ פתרון
// P28-E20
const ALPHABET = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";

export function encode(n: number): string {
  if (!Number.isSafeInteger(n) || n < 0) throw new Error("רק מספר שלם אי־שלילי");
  if (n === 0) return "0"; // תקלה 1: בלי זה, 0 ← "" (הלולאה לא רצה), וקוד ריק לא מתפענח
  let out = "";
  while (n > 0) {
    out = ALPHABET[n % 62] + out; // תקלה 2: היה out += … ← הספרות יוצאות הפוך (הקטנה ראשונה)
    n = Math.floor(n / 62); // תקלה 3: היה n / 62 ← שבר, והלולאה ממשיכה עם 0.0something עד שמתקבל אפס
  }
  return out;
}

export function decode(code: string): number {
  if (!/^[0-9a-zA-Z]+$/.test(code)) throw new Error("קוד לא תקין");
  let n = 0;
  for (const ch of code) n = n * 62 + ALPHABET.indexOf(ch);
  return n;
}
⚠️ טעויות נפוצות
  • "לתקן" עם .split("").reverse().join("") בסוף — עובד, אבל הקוד הנכון פשוט יותר.
