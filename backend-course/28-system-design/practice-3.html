P28-E69 · ‏redirect עם cache ו־X-Cache 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 26, שיעור 3

עם הטיפוסים (כתוב וייצא גם אותם):

type Store = { get(code: string): Promise<Link | null> };
