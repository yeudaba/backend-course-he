P28-E99 · ‏fan-out בתור, בחבילות 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: פרק 26, שיעור 5

הכתיבה לפידים — בתור, לא בתוך הבקשה. ופוסט של מי שיש לו 50,000 עוקבים לא נכנס ל־job אחד. בקובץ 28-system-design/starter/P28-E99.ts (יש בו רק הערה) כתוב וייצא:

export function fanoutJobs(postId: number, followers: string[], batchSize?: number): { name: string; data: { postId: number; followers: string[] }; opts: { jobId: string } }[]
  • מחלקת את העוקבים לחבילות של batchSize (ברירת מחדל 1,000), לפי הסדר; job לכל חבילה, עם name: "fanout".
  • jobId קבוע: ‏fanout:<postId>:<index> (מ־0) — כדי שאם הבקשה רצה פעמיים, BullMQ לא יכניס אותם שוב.
  • עוקבים כפולים ברשימה — פעם אחת (המקום הראשון). אין עוקבים ← []. ‏batchSize שאינו שלם חיובי ← RangeError.

(בפרודקשן: await queue.addBulk(fanoutJobs(...)).)

  • אחוזון בשיטת nearest-rank: ממיינים את הזמנים, ו־pN הוא האיבר במקום Math.ceil(N / 100 × count) (מ־1).
