P26-E27 · הודעת SSE 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 6

בקובץ P26-E27.ts כתוב formatEvent({ data, event, id, retry }) שמחזירה הודעה אחת בפורמט של SSE:

  • שדות בסדר: id, event, retry (רק אם הוגדרו — גם id: 0), ואז data.
  • data שאינו מחרוזת ← JSON.
  • ירידת שורה בתוך data (\n, \r\n או \r) ← שורת data: נפרדת לכל שורה.
  • ההודעה מסתיימת בשורה ריקה.

P26-E28 · רכזת SSE עם Last-Event-ID 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 6

בקובץ P26-E28.ts כתוב eventHub({ bufferSize = 100 }) ← { handler, publish, size }:

  • handler — route של Express (GET /events): status 200, Content-Type: text/event-stream, Cache-Control: no-cache, והחיבור נשאר פתוח.
  • publish(event, data) — נותן id עולה (1, 2, 3…), שולח לכל המחוברים id, event ו־data (JSON), ומחזיר את ה־id.
  • שומר את bufferSize האירועים האחרונים. לקוח שמתחבר עם Last-Event-ID: n מקבל קודם את כל מה שבמאגר ואחרי n. בלי ה־header — רק אירועים חדשים.
  • לקוח שהתנתק — יוצא מהרשימה (size() יורד).

P26-E29 · חדרי צ'אט ב־WebSocket 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 30 דק׳ידע נדרש: שיעור 6

בקובץ P26-E29.ts כתוב createChatServer(server, { verifyToken }) שמחבר WebSocket (החבילה ws) לשרת HTTP קיים, בכתובת /chat?token=…:

  • אימות לפני שהחיבור נפתח: verifyToken(token) מחזיר שם משתמש או null. null (או נתיב אחר) ← 401 והחיבור נסגר.
  • {"type":"join","room":"orders"} ← {"type":"joined","room":"orders"}. join לחדר אחר ← יוצאים מהקודם.
  • {"type":"say","text":"…"} ← לכל מי שבחדר (כולל השולח): {"type":"message","room","from","text"}. from — המשתמש מה־token, לא מה שהלקוח כתב.
  • JSON שבור, say לפני join, סוג לא מוכר ← {"type":"error","error":"…"}, והחיבור נשאר פתוח.
  • מחזיר { close } שסוגר את כל החיבורים.

P26-E30 · fan-out בין שרתים עם Redis 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 6

שלושה שרתים מאחורי load balancer, ולכל אחד לקוחות SSE משלו. ההזמנה של דנה עודכנה בשרת A — אבל הדפדפן שלה מחובר ל־C. בקובץ P26-E30.ts כתוב createRelay({ pub, sub, channel }) (async) ← { publish, subscribe, close }:

  • publish(data) — שולח לכל השרתים (כולל זה) דרך Redis, כ־JSON.
  • subscribe(listener) — מאזין מקומי (למשל: לקוח SSE). מחזיר פונקציה שמסירה אותו.
  • כל מאזין, בכל שרת, מקבל כל הודעה פעם אחת.
  • מנוי אחד ב־Redis לכל relay — לא אחד לכל מאזין. הודעות מערוצים אחרים על אותו חיבור — לא נכנסות.
  • close() — מבטל את המנוי.
