P26-E16 · תור מיילים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 4

בקובץ P26-E16.ts, עם BullMQ:

  • createEmailQueue(connection, prefix) ← { queue, send(id, email), close }. send מוסיף עבודה עם jobId = id (הוספה כפולה = עבודה אחת), 4 ניסיונות, ו־backoff אקספוננציאלי.
  • startEmailWorker(connection, prefix, deliver) ← Worker שקורא ל־deliver(email). זריקה = כישלון ← BullMQ מנסה שוב.

P26-E17 · עבודה מתוזמנת וביטול 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

בקובץ P26-E17.ts: createReminders(connection, prefix) ← { schedule(orderId, delayMs), cancel(orderId), … }. schedule — עבודה עם delay ו־jobId = remind-<orderId>. cancel — אם העבודה עדיין ממתינה: מוחקים, true; אחרת false.

P26-E18 · צרכן idempotent 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

בקובץ P26-E18.ts: processOnce(redis, messageId, ttlSeconds, handler) — מריץ את handler רק אם ההודעה לא טופלה (SET processed:<id> … NX EX). כבר טופלה ← { processed: false }. נכשלה ← מוחקים את הסימון (אפשר לנסות שוב) וזורקים.
