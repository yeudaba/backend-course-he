P26-E33 · TypedEmitter: אירועים עם טיפוסים 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 25 דק׳ידע נדרש: שיעור 3

🔁 חזרה על generics ו־keyof (פרק 11), ‏class עם שדות פרטיים (פרק 12), ‏Map ו־Set (פרק 7) ו־closures (פרק 5). pub/sub (שיעור 3) מעביר אירועים בין שרתים, ובתוך שרת אחד מעבירים אותם עם emitter. ‏EventEmitter של Node מקבל כל שם וכל payload. אם טעית באות אחת בשם האירוע, אף אחד לא מאזין, ואף אחד לא יודע. כתוב וייצא class TypedEmitter<Events extends Record<string, unknown>>:

  • on(event, listener) — רושם, ומחזיר פונקציה שמבטלת את הרישום. אותה פונקציה פעמיים לאותו אירוע — נרשמת פעם אחת.
  • off(event, listener). ‏once(event, listener) — נקרא פעם אחת ואז מתבטל. גם הוא מחזיר פונקציית ביטול.
  • emit(event, payload): number — קורא לכל המאזינים לפי סדר הרישום, ומחזיר כמה נקראו. מאזין שמבטל את עצמו באמצע (once) לא גורם לדלג על אחרים.
  • listenerCount(event): number.
  • טיפוסים: ‏new TypedEmitter<{ "order.paid": { orderId: number } }>(). ‏emit("order.cancelled", ...), או payload שלא מתאים, הם שגיאת קומפילציה, ובמאזין e.orderId הוא number. הבודק בודק את זה.
