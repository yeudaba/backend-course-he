P26-E05 · מה יחזיר Redis?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

נסה לענות לפני שמריצים (חיבור ל־Redis מקומי, כמו בקופסת 🧰):

import { Redis } from "ioredis";
const r = new Redis(process.env.REDIS_URL ?? "redis://localhost:6379", { keyPrefix: "e05:" });
await r.del("n", "s", "l", "z");
console.log(await r.incr("n"), await r.incrby("n", 10), typeof (await r.get("n")));
console.log(await r.sadd("s", "a", "b", "a"), await r.sadd("s", "a"), await r.scard("s"));
await r.rpush("l", "1", "2", "3");
console.log(await r.lrange("l", 0, -1), await r.lpop("l"), await r.llen("l"));
await r.zadd("z", 30, "yossi", 50, "dana", 10, "noa");
console.log(await r.zrevrange("z", 0, 1), await r.zscore("z", "dana"));
console.log(await r.set("x", "1", "NX"), await r.set("x", "2", "NX"), await r.get("x"));
await r.del("n", "s", "l", "z", "x");
await r.quit();

P26-E31 · sessions ב־Redis 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 30 דק׳ידע נדרש: שיעור 1

JWT (פרק 21) הוא לא הדרך היחידה. הרבה אתרים שומרים session בשרת, ושולחים לדפדפן רק מזהה אקראי בעוגייה. היתרון: אפשר לבטל session מיד, ואפשר "לנתק מכל המכשירים" אחרי החלפת סיסמה. Redis הוא המקום הטבעי לזה: מהיר, משותף לכל השרתים, ו־TTL מובנה. כתוב מקובץ ריק וייצא (‏redis הוא Redis של ioredis):

  • createSession(redis, userId, data = {}, ttlSec = 1800): Promise<string> — מזהה מ־randomUUID(). בתוך MULTI: ‏hash ב־session:<id> עם השדות של data ועוד userId, תוקף של ttlSec, והוספה ל־set ב־user:<userId>:sessions. גם לרשימה יש תוקף, והוא כמו ה־session הארוך שבה: session קצר לא מקצר אותה.
  • getSession(redis, id, ttlSec = 1800) ← { userId: number, data } (בלי userId בתוך data), או null. כל קריאה מחזירה את התוקף ל־ttlSec (sliding expiration): משתמש פעיל לא מתנתק.
  • destroySession(redis, id): Promise<boolean> — מוחקת את ה־hash ומוציאה אותו מהרשימה. לא קיים ← false.
  • destroyAllForUser(redis, userId): Promise<number> — מוחקת את כל ה־sessions שברשימה ואת הרשימה עצמה. מחזירה כמה sessions באמת נמחקו (מי שכבר פג לא נספר).
