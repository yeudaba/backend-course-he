P26-E05 · מה יחזיר Redis?

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

נסה לענות לפני שמריצים (חיבור ל־Redis מקומי, כמו בקופסת 🧰):

import { Redis } from "ioredis";
const r = new Redis(process.env.REDIS_URL ?? "redis://localhost:6379", { keyPrefix: "e05:" });
await r.del("n", "s", "l", "z");
console.log(await r.incr("n"), await r.incrby("n", 10), typeof (await r.get("n")));
console.log(await r.sadd("s", "a", "b", "a"), await r.sadd("s", "a"), await r.scard("s"));
await r.rpush("l", "1", "2", "3");
console.log(await r.lrange("l", 0, -1), await r.lpop("l"), await r.llen("l"));
await r.zadd("z", 30, "yossi", 50, "dana", 10, "noa");
console.log(await r.zrevrange("z", 0, 1), await r.zscore("z", "dana"));
console.log(await r.set("x", "1", "NX"), await r.set("x", "2", "NX"), await r.get("x"));
await r.del("n", "s", "l", "z", "x");
await r.quit();

P26-E07 · cache-aside 🤖

רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ P26-E07.ts: createCacheAside(redis) ← { get(key, ttl, load), stats, invalidate(key) }. get: יש ב־Redis ← מחזיר (stats.hits++); אין ← load(), שומר עם TTL, מחזיר (stats.misses++). שגיאה מ־load ← עולה, ולא נשמר כלום. null/undefined ← לא נשמרים.

P26-E09 · הגבלת קצב משותפת 🤖

P26-E13 · cache שעומד בעומס 🤖

רמה 3⏱ 25 דק׳ידע נדרש: שיעור 2

בקובץ P26-E13.ts: createStampedeCache(redis, { lockMs, waitMs, pollMs }) ← { get(key, ttl, loader) }. כשאין ערך: בתוך תהליך — בקשות במקביל לאותו מפתח מחכות לאותו Promise; בין שרתים — רק מי שתפס מנעול (key:lock) טוען, והשאר מחכים שהערך יופיע, עד waitMs — ואז טוענים בעצמם.

P26-E14 · ביטול עם גרסה 🤖

רמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ P26-E14.ts: createVersionedCache(redis) ← { get(group, key, ttl, load) → { value, hit }, invalidate(group) }. המפתח בפועל: c:<group>:<version>:<key>; הגרסה ב־v:<group> (ברירת מחדל "0"); invalidate ← INCR לגרסה.

P26-E15 · חלון נע ב־sorted set 🤖

P26-E16 · תור מיילים 🤖

  • startEmailWorker(connection, prefix, deliver) ← Worker שקורא ל־deliver(email). זריקה = כישלון ← BullMQ מנסה שוב.

P26-E18 · צרכן idempotent 🤖
