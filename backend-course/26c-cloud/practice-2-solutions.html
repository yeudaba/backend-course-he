P26.3-E02 · מי רשאי? IAM 🧠 הבנה רמה 1

💡 רמז 1

סדר ההחלטה של AWS: Deny מפורש? ← אסור. Allow? ← מותר. אחרת ← אסור.

💡 רמז 2

ARN של bucket וה־ARN של האובייקטים בתוכו — שני דברים שונים.

✅ פתרון
  1. לא. מפתח קבוע של אדם, עם כל ההרשאות שלו, שלא פג. דולף מלוג, מגיבוי, ממחשב של מפתח. לשרת — role: הרשאות רק למה שהוא צריך, ו־credentials זמניים שמתחלפים לבד (STS).
  2. לא. arn:aws:s3:::coffee-uploads הוא ה־bucket עצמו (לפעולות כמו ListBucket). אובייקטים הם arn:aws:s3:::coffee-uploads/*. זה בדיוק הבאג של E21: "AccessDenied, אבל נתתי הרשאה!".
  3. נכון — implicit deny. ברירת המחדל היא "לא".
  4. לא. Deny מפורש מנצח תמיד, לא משנה כמה Allow יש. כך חוסמים פעולה מסוכנת לכולם (למשל מחיקה של גיבויים) בלי לבדוק כל policy (E13).
  5. נכון. IRSA או EKS Pod Identity: ה־ServiceAccount של ה־pod מקושר ל־IAM role, וה־SDK מקבל credentials זמניים אוטומטית. אין סוד לנהל.
  6. לא. s3:* כולל DeleteObject, PutBucketPolicy (להפוך את ה־bucket לציבורי!) ו־DeleteBucket. least privilege = רשימת פעולות מפורשת (E08).

P26.3-E03 · מה S3 מחזיר? 🧠 הבנה רמה 1

💡 רמז 1

ב־S3 אין "עדכון" — יש כתיבה של אובייקט שלם במקום הקודם.

💡 רמז 2

המפתחות ממוינים כמחרוזות (lexicographic), לא כמספרים.

✅ פתרון
import { S3Client, CreateBucketCommand, PutObjectCommand, GetObjectCommand, ListObjectsV2Command } from "@aws-sdk/client-s3";

const s3 = new S3Client({
  region: "us-east-1",
  endpoint: process.env.AWS_ENDPOINT_URL ?? "http://localhost:4566", // LocalStack
  credentials: { accessKeyId: "test", secretAccessKey: "test" },
  forcePathStyle: true,
});
const Bucket = `e03-${Date.now()}`;
await s3.send(new CreateBucketCommand({ Bucket }));
const put = (Key: string, Body: string) => s3.send(new PutObjectCommand({ Bucket, Key, Body }));

await put("img2.png", "v1");
await put("img10.png", "v1");
await put("img2.png", "v2");
await put("receipts/2026/a.pdf", "pdf");

const obj = await s3.send(new GetObjectCommand({ Bucket, Key: "img2.png" }));
console.log("1.", await obj.Body!.transformToString());
const all = await s3.send(new ListObjectsV2Command({ Bucket }));
console.log("2.", all.Contents!.map((o) => o.Key).join(", "));
const top = await s3.send(new ListObjectsV2Command({ Bucket, Delimiter: "/" }));
console.log("3.", top.Contents!.map((o) => o.Key), top.CommonPrefixes!.map((p) => p.Prefix));
1. v2
2. img10.png, img2.png, receipts/2026/a.pdf
3. [ 'img10.png', 'img2.png' ] [ 'receipts/' ]
  1. v2 — הכתיבה השנייה החליפה את האובייקט כולו. (מאז 2020 S3 עקבי מיידית: קריאה אחרי כתיבה מחזירה את הגרסה החדשה. אם צריך היסטוריה — Versioning על ה־bucket.)
  2. img10 לפני img2 — מיון של מחרוזות: "1" < "2". מי שרוצה סדר מספרי — מרפד באפסים (img002) או מפתח עם תאריך ISO (E19).
  3. אין תיקיות ב־S3: receipts/2026/a.pdf הוא מפתח אחד עם לוכסנים. Delimiter: "/" רק מקבץ מפתחות לפי ה־prefix עד הלוכסן הראשון — ומחזיר את receipts/ ב־CommonPrefixes, כאילו הייתה תיקייה.

P26.3-E06 · JSON ב־S3 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

res.Body הוא stream. ל־SDK יש transformToString().

💡 רמז 2

ה־SDK זורק NoSuchKey — מחלקה שאפשר לבדוק עם instanceof.

✅ פתרון
// P26.3-E06: לשמור ולקרוא JSON ב־S3
import { S3Client, PutObjectCommand, GetObjectCommand, NoSuchKey } from "@aws-sdk/client-s3";

export async function putJson(s3: S3Client, bucket: string, key: string, value: unknown): Promise<void> {
  await s3.send(
    new PutObjectCommand({
      Bucket: bucket,
      Key: key,
      Body: JSON.stringify(value),
      ContentType: "application/json; charset=utf-8",
    }),
  );
}

export async function getJson<T = unknown>(s3: S3Client, bucket: string, key: string): Promise<T | null> {
  try {
    const res = await s3.send(new GetObjectCommand({ Bucket: bucket, Key: key }));
    const text = await res.Body!.transformToString("utf-8");
    return JSON.parse(text) as T;
  } catch (err) {
    if (err instanceof NoSuchKey) return null; // רק "אין כזה" הוא null; כל שגיאה אחרת — למעלה
    throw err;
  }
}
⚠️ טעויות נפוצות
  • catch { return null } על הכול — bucket עם שם שגוי בפרודקשן נראה כמו "אין נתונים", ואף אחד לא יודע שמשהו שבור (E22).

P26.3-E07 · העלאה ישירה ל־S3 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

getSignedUrl(s3, new PutObjectCommand({…}), { expiresIn }) מ־@aws-sdk/s3-request-presigner. החתימה לא שולחת כלום ל־AWS — היא חישוב מקומי עם ה־credentials.

💡 רמז 2

ContentType ו־ContentLength בתוך ה־command נכנסים לחתימה: הלקוח חייב לשלוח בדיוק אותם.

✅ פתרון
// P26.3-E07: כתובת חתומה (presigned URL) להעלאת קובץ ישירות ל־S3
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";
import { randomUUID } from "node:crypto";

export const ALLOWED_TYPES = ["image/png", "image/jpeg", "application/pdf"];
export const MAX_BYTES = 5 * 1024 * 1024;
export const EXPIRES_IN = 300;

export interface UploadRequest {
  userId: number;
  filename: string;
  contentType: string;
  size: number;
}

export function safeName(filename: string): string {
  const base = filename.split(/[\\/]/).pop() ?? "";
  const clean = base.replace(/[^A-Za-z0-9._-]/g, "_").replace(/^\.+/, "").slice(-100);
  return clean || "file";
}

export async function createUploadUrl(s3: S3Client, bucket: string, req: UploadRequest) {
  if (!ALLOWED_TYPES.includes(req.contentType)) throw new Error(`סוג קובץ לא מותר: ${req.contentType}`);
  if (!Number.isInteger(req.size) || req.size <= 0 || req.size > MAX_BYTES) throw new Error("גודל קובץ לא תקין (עד 5MB)");
  if (!Number.isInteger(req.userId) || req.userId <= 0) throw new Error("userId לא תקין");
  const key = `uploads/${req.userId}/${randomUUID()}-${safeName(req.filename)}`;
  const url = await getSignedUrl(
    s3,
    new PutObjectCommand({ Bucket: bucket, Key: key, ContentType: req.contentType, ContentLength: req.size }),
    { expiresIn: EXPIRES_IN },
  );
  return { url, key, expiresIn: EXPIRES_IN, headers: { "content-type": req.contentType } };
}

למה זה טוב: קובץ של 5MB לא תופס זיכרון וחיבור בשרת שלנו, ו־S3 מתמודד עם אלף העלאות במקביל. השרת עדיין מחליט מי מעלה, מה ולאן. בפרודקשן מוסיפים: רשומה במסד עם ה־key (סטטוס "ממתין"), ואירוע מ־S3 כשההעלאה הסתיימה.

⚠️ טעויות נפוצות
  • להשתמש בשם הקובץ כמפתח — שני משתמשים מעלים receipt.pdf, והשני דורס את הראשון.
  • לבדוק סוג לפי סיומת השם — הלקוח שולט בה. כאן הסוג חתום בכתובת; בדיקה אמיתית של התוכן — אחרי ההעלאה.

P26.3-E13 · מעריך policies 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

הדרך הקצרה ל־wildcard: לבנות RegExp — אבל קודם לברוח (escape) מכל תו מיוחד, אחרת . ב־ARN מתאים לכל תו.

💡 רמז 2

Deny אפשר להחזיר מיד. Allow — רק לזכור, כי Deny מאוחר יותר עדיין מנצח.

✅ פתרון
// P26.3-E13: להעריך IAM policy — כמו ש־AWS מחליט
export interface Statement {
  Effect: "Allow" | "Deny";
  Action: string | string[];
  Resource: string | string[];
}
export interface Policy {
  Version: string;
  Statement: Statement[];
}
export type Decision = "allow" | "explicit-deny" | "implicit-deny";

const list = (x: string | string[]) => (Array.isArray(x) ? x : [x]);

export function wildcardMatch(pattern: string, value: string, ignoreCase = false): boolean {
  const escaped = pattern.replace(/[.+^${}()|[\]\\]/g, "\\$&").replace(/\*/g, ".*").replace(/\?/g, ".");
  return new RegExp(`^${escaped}$`, ignoreCase ? "i" : "").test(value);
}

export function evaluate(policies: Policy[], action: string, resource: string): Decision {
  let allowed = false;
  for (const p of policies) {
    for (const s of p.Statement) {
      const hit =
        list(s.Action).some((a) => wildcardMatch(a, action, true)) && // שמות פעולות לא רגישים לרישיות
        list(s.Resource).some((r) => wildcardMatch(r, resource)); // ARN רגיש
      if (!hit) continue;
      if (s.Effect === "Deny") return "explicit-deny"; // Deny מפורש מנצח תמיד
      allowed = true;
    }
  }
  return allowed ? "allow" : "implicit-deny";
}

באמת יש עוד שכבות: policies של ה־bucket עצמו (resource-based), Permission Boundaries, Service Control Policies של הארגון, ו־Conditions. העיקרון לא משתנה: Deny מפורש בכל שכבה מנצח.

P26.3-E19 · pagination ב־S3 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

IsTruncated ו־NextContinuationToken — ובקריאה הבאה ContinuationToken.

💡 רמז 2

DeleteObjects לא זורק כשחלק נכשל — הוא מחזיר Errors.

✅ פתרון
// P26.3-E19: לרשום ולמחוק לפי prefix — עם pagination
import { S3Client, ListObjectsV2Command, DeleteObjectsCommand } from "@aws-sdk/client-s3";

export async function listAllKeys(s3: S3Client, bucket: string, prefix: string, pageSize = 1000): Promise<string[]> {
  const keys: string[] = [];
  let token: string | undefined;
  do {
    const page = await s3.send(
      new ListObjectsV2Command({ Bucket: bucket, Prefix: prefix, MaxKeys: pageSize, ContinuationToken: token }),
    );
    for (const o of page.Contents ?? []) keys.push(o.Key!);
    token = page.IsTruncated ? page.NextContinuationToken : undefined;
  } while (token);
  return keys;
}

export async function deletePrefix(s3: S3Client, bucket: string, prefix: string): Promise<number> {
  if (!prefix || !prefix.endsWith("/")) throw new Error('prefix חייב להיות תיקייה שמסתיימת ב־"/" (ולא ריק — זה כל ה־bucket)');
  const keys = await listAllKeys(s3, bucket, prefix);
  for (let i = 0; i < keys.length; i += 1000) {
    const batch = keys.slice(i, i + 1000);
    const res = await s3.send(
      new DeleteObjectsCommand({ Bucket: bucket, Delete: { Objects: batch.map((Key) => ({ Key })), Quiet: true } }),
    );
    if (res.Errors?.length) throw new Error(`מחיקה נכשלה: ${res.Errors[0].Key} — ${res.Errors[0].Message}`);
  }
  return keys.length;
}
⚠️ טעויות נפוצות
  • קריאה אחת ל־ListObjectsV2 — עובד בפיתוח (30 קבצים), ומוחק "הכול" בפרודקשן חוץ מכל מה שאחרי האלף הראשון.
  • deletePrefix("uploads/42") מוחק גם את uploads/420/… — prefix הוא מחרוזת, לא תיקייה.

P26.3-E22 · הדשבורד מראה "אין מכירות" — שלוש תקלות 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

הוסף console.log ב־catch. מה הטיפוס של res.Body?

💡 רמז 2

למה הבאג הראשון היה בלתי נראה? בגלל השני.

✅ פתרון
// P26.3-E22: דוחות יומיים ב־S3 — אחרי התיקון
import { S3Client, PutObjectCommand, GetObjectCommand, NoSuchKey } from "@aws-sdk/client-s3";

export interface ReportRow {
  productId: number;
  sold: number;
}

const keyFor = (date: string) => `reports/daily/${date}.json`;

export async function saveReport(s3: S3Client, bucket: string, date: string, rows: ReportRow[]) {
  await s3.send(
    new PutObjectCommand({
      Bucket: bucket,
      Key: keyFor(date),
      Body: JSON.stringify(rows),
      ContentType: "application/json", // תיקון 3: בלי זה — binary/octet-stream
    }),
  );
}

export async function loadReport(s3: S3Client, bucket: string, date: string): Promise<ReportRow[] | null> {
  try {
    const res = await s3.send(new GetObjectCommand({ Bucket: bucket, Key: keyFor(date) }));
    return JSON.parse(await res.Body!.transformToString()); // תיקון 1: Body הוא stream
  } catch (err) {
    if (err instanceof NoSuchKey) return null; // תיקון 2: רק "אין דוח" הוא null
    throw err;
  }
}

הלקח הוא בשניים יחד: String(res.Body) נותן "[object IncomingMessage]", JSON.parse זורק — וה־catch הכללי הופך את זה ל"אין דוח". catch שבולע הכול לא רק מסתיר תקלות עתידיות; הוא הסתיר את הבאג שכבר היה.

P26.3-E27 · חשבון S3 לפי מדרגות 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

משתנה from, שמתחיל ב־0: איפה המדרגה הנוכחית מתחילה. בכל מדרגה: const to = tier.upTo === null ? amount : Math.min(amount, tier.upTo). המחיר של המדרגה הוא (to - from) * tier.price, ואחר כך from = to. כש־amount <= from — break.

💡 רמז 2

"תעבורה חינם עד 100GB" היא פשוט מדרגה עם price: 0. לעיגול: Math.round(n * 100) / 100. ‏!(amount >= 0) תופס גם NaN, כי כל השוואה עם NaN היא false.

✅ פתרון
// P26.3-E27 — חשבון S3 לפי מדרגות
export type Tier = { upTo: number | null; price: number };

// מחירים לדוגמה (דולר). כל מדרגה: עד כמה יחידות (מצטבר), ומה המחיר ליחידה בה. null — "וכל השאר"
export const STORAGE_PER_GB: Tier[] = [
  { upTo: 51_200, price: 0.023 },
  { upTo: 512_000, price: 0.022 },
  { upTo: null, price: 0.021 },
];
export const TRANSFER_OUT_PER_GB: Tier[] = [
  { upTo: 100, price: 0 },
  { upTo: 10_240, price: 0.09 },
  { upTo: null, price: 0.085 },
];

export function tieredCost(amount: number, tiers: Tier[]): number {
  if (!(amount >= 0)) throw new RangeError("amount חייב להיות מספר לא שלילי");
  let cost = 0;
  let from = 0;
  for (const tier of tiers) {
    if (amount <= from) break;
    const to = tier.upTo === null ? amount : Math.min(amount, tier.upTo);
    cost += (to - from) * tier.price;
    from = to;
  }
  return cost;
}

const cents = (n: number) => Math.round(n * 100) / 100;

export function s3Bill(usage: { storageGb: number; putRequests: number; getRequests: number; transferOutGb: number }) {
  const storage = cents(tieredCost(usage.storageGb, STORAGE_PER_GB));
  const requests = cents((usage.putRequests / 1000) * 0.005 + (usage.getRequests / 1000) * 0.0004);
  const transfer = cents(tieredCost(usage.transferOutGb, TRANSFER_OUT_PER_GB));
  return { storage, requests, transfer, total: cents(storage + requests + transfer) };
}
