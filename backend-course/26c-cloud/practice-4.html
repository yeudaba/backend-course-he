P26.3-E05 · Helm ו־GitOps: מה יוצא, ומי עושה מה

🧠 הבנהרמה 1⏱ 20 דק׳ידע נדרש: שיעור 4

א. מה helm template ידפיס לשורות האלה, עם values-prod.yaml?

# templates/deployment.yaml (קטע)
replicas: {{ .Values.replicas }}
image: "{{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }}"
{{- if .Values.resources }}
resources: {{- toYaml .Values.resources | nindent 2 }}
{{- end }}

# values.yaml                          # values-prod.yaml
replicas: 1                            replicas: 3

  repository: ghcr.io/noa-cohen/coffee-shop    tag: "1.5.0"
  tag: ""
resources: {}
# Chart.yaml: appVersion: "1.4.2"

ב. סדר את השלבים של שינוי קוד עד שהוא בפרודקשן, וכתוב ליד כל אחד מי עושה אותו — מפתח, Jenkins או Argo CD: (1) Argo CD רואה שינוי ב־repo התצורה; (2) push ל־main; (3) build ו־push של image עם tag של ה־commit; (4) בדיקות; (5) commit ל־repo התצורה שמשנה את ה־tag; (6) rolling update ב־cluster; (7) pull request ו־review.

P26.3-E15 · Application של Argo CD 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 4

ב־P26.3-E15.yaml: Application בשם coffee-api-prod (ב־namespace argocd) שמסנכרן את ה־Helm chart ב־charts/coffee-api מ־https://github.com/noa-cohen/coffee-deploy.git (ענף main), עם values-prod.yaml, אל namespace coffee ב־cluster שבו Argo CD רץ. סנכרון אוטומטי: למחוק משאבים שנמחקו מ־Git, ולהחזיר שינויים ידניים. ואם ה־namespace לא קיים — ליצור אותו.

P26.3-E25 · אתגר: עדכון tag ב־repo התצורה 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 45 דק׳ידע נדרש: שיעור 4

הצעד האחרון של ה־CI ב־GitOps: לשנות את ה־tag של ה־image בקובץ YAML ב־repo התצורה, ולעשות commit — ו־Argo CD עושה את השאר. ב־P26.3-E25.ts: bumpImageTag(text, repository, tag) ← { text, changed }:

  • מעדכנת כל image של אותו repository ב־containers וב־initContainers של Deployment, Job, CronJob (וכל מה שיש לו spec.template.spec) — גם אם היה עם tag אחר או digest (@sha256:…).
  • לא נוגעת ב־repository אחר — גם לא כזה שמתחיל באותו שם — ולא ב־ConfigMap.
  • שומרת על ההערות, הסדר והמרכאות: ה־diff הוא רק השורות של ה־image.
  • tag לא תקין (תווים מותרים: אותיות, ספרות, . _ -, עד 128) או repository שלא נמצא ← שגיאה. אותו tag פעמיים ← 0 שינויים, אותו טקסט.
