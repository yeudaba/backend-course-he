P26.3-E01 · איזה שירות של AWS?

🧠 הבנהרמה 1⏱ 15 דק׳ידע נדרש: שיעור 1

לכל צורך של חנות הקפה — איזה שירות של AWS, ולמה (שירות אחד או שניים לכל שורה):

  1. להריץ את ה־API (Docker image) — 3 עותקים, עם rolling update.
  2. PostgreSQL מנוהל, עם גיבוי יומי ו־failover.
  3. Redis ל־cache ול־BullMQ.
  4. לשמור תמונות של מוצרים וקבלות PDF שמשתמשים מעלים.
  5. להגיש את התמונות מהר לגולשים בכל העולם.
  6. תור הודעות בין ה־API ל־worker שמקטין תמונות.
  7. לשמור את סיסמת המסד ואת JWT_SECRET.
  8. לראות לוגים ומדדים, ולקבל התראה כש־5xx קופץ.
  9. פונקציה שרצה פעם ביום ב־03:00 ומייצרת דוח — 20 שניות בסך הכול.
  10. להחליט מי (אדם או שירות) רשאי לעשות מה.

P26.3-E30 · ‏EC2, קונטיינרים או Lambda?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

לכל משימה — EC2, קונטיינרים (ECS/EKS) או Lambda, ולמה:

  1. ה־API של חנות הקפה — מקבל בקשות כל הזמן, image של Docker כבר קיים.
  2. webhook מספק התשלומים — 200 קריאות ביום, כל אחת 50ms.
  3. ה־worker של BullMQ (פרק 26) — מחכה לעבודות כל הזמן.
  4. הקטנת תמונה כשמישהו מעלה קובץ ל־S3.
  5. מערכת ישנה שדורשת תוכנה מותקנת על Windows Server.
  6. חיבור WebSocket פתוח לשעה (שיעור 6 בפרק 26).

P26.3-E31 · של מי האחריות?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

לפי "Shared Responsibility" — AWS או אתה? ולמה?

  1. דיסק שהתקלקל בשרת של RDS.
  2. bucket של קבלות שמישהו הפך לציבורי.

P26.3-E34 · ‏AZ, ‏region ופיזור עותקים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

בקובץ 26c-cloud/starter/P26.3-E34.ts (יש בו רק הערה) כתוב וייצא:

export function regionOf(az: string): string | null
export function spreadAcrossAzs(replicas: number, azs: string[]): Record<string, number>
export function survivesAzLoss(spread: Record<string, number>, minHealthy: number): boolean
  • regionOf("eu-central-1a") ← "eu-central-1". שם AZ הוא region (אותיות קטנות ומקפים, ומספר בסוף) ועוד אות אחת. אחרת ← null.
  • spreadAcrossAzs — מחלק את העותקים בסבב, לפי סדר ה־AZs: ‏5 על ["a", "b", "c"] ← { a: 2, b: 2, c: 1 }. כל AZ מופיע בתוצאה (גם עם 0). בלי AZs ← RangeError.
  • survivesAzLoss ← true אם אחרי נפילה של כל AZ אחד, נשארים לפחות minHealthy עותקים.

P26.3-E35 · כמה תשיעיות?

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

P26.3-E36 · ‏EC2 או Lambda — מה יותר זול? 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

export function ec2Monthly(hourlyUsd: number, instances: number, hours?: number): number
export function lambdaMonthly(opts: { requests: number; avgMs: number; memoryMb: number; perMillionRequests?: number; perGbSecond?: number }): number

P26.3-E37 · ‏handler של Lambda מאחורי API Gateway 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 1

Lambda לא מקבלת req ו־res — היא מקבלת אובייקט אירוע, ומחזירה אובייקט. בקובץ 26c-cloud/starter/P26.3-E37.ts (יש בו רק הערה) כתוב וייצא:

export async function handler(event: { httpMethod: string; path: string; body: string | null; isBase64Encoded?: boolean }): Promise<{ statusCode: number; headers: Record<string, string>; body: string }>
  • תמיד headers: { "Content-Type": "application/json" }, ו־body — מחרוזת JSON.
  • GET /health ← ‏200 ‏{"ok":true}.
  • POST /orders — הגוף (אם isBase64Encoded — מפענחים קודם): ‏productId שלם חיובי, ‏qty שלם 1–10. תקין ← ‏202 ‏{"accepted":true,"productId":…,"qty":…}. JSON שבור או ריק ← ‏400 ‏{"error":"JSON לא תקין"}. ערכים לא תקינים ← ‏400 עם error אחר.
  • כל השאר ← ‏404 ‏{"error":"not found"}.
