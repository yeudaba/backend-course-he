P26.3-E94 · סימולציה של declarative pipeline 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 5

הכללים של E89, בקוד. בקובץ 26c-cloud/starter/P26.3-E94.ts (יש בו רק הערה) כתוב וייצא:

type Stage = { name: string; when?: boolean; fails?: boolean; unstable?: boolean };
export function pipelineResult(stages: Stage[], post: string[]): { ran: string[]; skipped: string[]; result: "SUCCESS" | "UNSTABLE" | "FAILURE"; post: string[] }
  • stages לפי הסדר. ‏when: false ← דולג (לא כישלון). ‏fails ← רץ, התוצאה FAILURE, וכל ה־stages שאחריו מדולגים. ‏unstable ← רץ, התוצאה UNSTABLE (אם עוד לא FAILURE), וממשיכים.
  • post — התנאים שהוגדרו. מחזירה את אלה שרצים, בסדר של Jenkins: always, ‏failure, ‏success, ‏unstable, ‏unsuccessful (כל מה שאינו SUCCESS), ‏cleanup (תמיד, אחרון). תנאי לא מוכר ← Error.
