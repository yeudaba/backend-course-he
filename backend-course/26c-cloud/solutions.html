P26.3-E26 · label selector של Kubernetes 🤖 ✍️ מאפס רמה 3

💡 רמז 1

שני שלבים: קודם לפרק את המחרוזת לרשימת דרישות, ואז לבדוק כל אחת. פירוק בפסיקים שלא בתוך סוגריים: selector.split(/,(?![^()]*\))/). כלומר "פסיק, שאחריו לא בא ) בלי ( באמצע". לכל חלק — שלושה regex, לפי הסדר: שוויון (/^([\w./-]+)\s*(==|=|!=)\s*([\w.-]*)$/), קבוצה (in/notin עם סוגריים), וקיום (/^(!?)\s*([\w./-]+)$/).

💡 רמז 2

שמור כל דרישה כאובייקט עם op (‏"=", ‏"!=", ‏"in", ‏"notin", ‏"exists", ‏"!exists"), ואז requirements.every(...) עם switch (r.op). "האם יש label": ‏Object.hasOwn(labels, key). ‏labels[key] !== undefined נכשל על מפתחות כמו constructor.

✅ פתרון
// P26.3-E26 — label selector של Kubernetes
export type Requirement =
  | { key: string; op: "=" | "!="; value: string }
  | { key: string; op: "in" | "notin"; values: string[] }
  | { key: string; op: "exists" | "!exists" };

const EQUALITY = /^([\w./-]+)\s*(==|=|!=)\s*([\w.-]*)$/;
const SET = /^([\w./-]+)\s+(in|notin)\s*\(([^()]*)\)$/;
const EXISTS = /^(!?)\s*([\w./-]+)$/;
const VALUE = /^[\w.-]+$/;

export function parseSelector(selector: string): Requirement[] {
  if (selector.trim() === "") return [];
  // פסיק מפריד בין דרישות — אבל לא פסיק בתוך סוגריים
  return selector.split(/,(?![^()]*\))/).map((raw) => {
    const part = raw.trim();
    let m = part.match(EQUALITY);
    if (m) return { key: m[1], op: m[2] === "!=" ? "!=" : "=", value: m[3] };
    m = part.match(SET);
    if (m) {
      const values = m[3].split(",").map((v) => v.trim());
      if (values.some((v) => !VALUE.test(v))) throw new SyntaxError(`ערך לא תקין ב־"${part}"`);
      return { key: m[1], op: m[2] as "in" | "notin", values };
    }
    m = part.match(EXISTS);
    if (m) return { key: m[2], op: m[1] ? "!exists" : "exists" };
    throw new SyntaxError(`דרישה לא תקינה: "${part}"`);
  });
}

export function matches(labels: Record<string, string>, selector: string): boolean {
  return parseSelector(selector).every((r) => {
    const has = Object.hasOwn(labels, r.key);
    const value = labels[r.key];
    switch (r.op) {
      case "=":
        return has && value === r.value;
      case "!=":
        return !has || value !== r.value;
      case "in":
        return has && r.values.includes(value);
      case "notin":
        return !has || !r.values.includes(value);
      case "exists":
        return has;
      case "!exists":
        return !has;
    }
  });
}

שורה 3: ‏tier!=db מחזיר את כל מי שאינו מסד. אם היה Pod בלי tier בכלל, גם הוא היה חוזר. זו הסמנטיקה של Kubernetes, והיא מפתיעה: ‏!= ו־notin אומרים "לא שווה", ולא "קיים ושונה". מי שרוצה "קיים ושונה" כותב tier,tier!=db.

פירוק לפני הערכה (parseSelector ואז every) הוא אותו מבנה כמו ב־parseAuthorization (‏P21-E27) וב־parseInfo (‏P26-E32): קודם הופכים טקסט למבנה עם טיפוס, ואז הלוגיקה פשוטה. ה־union של Requirement מבטיח שב־case "in" יש values, וב־case "=" יש value.

שגיאה על selector שבור, ולא false שקט, חשובה במיוחד כאן. ‏false אומר "אף Pod לא מתאים", כלומר Service שלא שולח תעבורה לאף אחד, בלי שום הודעה.

⚠️ טעויות נפוצות
  • selector.split(",") — ‏env in (prod,staging) נחתך לשני חלקים שבורים.
  • != שדורש שה־label קיים — Pods בלי ה־label נעלמים מהתוצאה, בניגוד ל־Kubernetes.
  • לבדוק קודם את regex הקיום — app ב־app=web לא מתאים לו (יש =), אבל בלי ^ ו־$ הוא היה מתאים לחלק מהמחרוזת.
  • להחזיר false על selector לא תקין — טעות הקלדה נראית כמו "אין Pods".

P26.3-E27 · חשבון S3 לפי מדרגות 🤖 🔁 חזרה רמה 2

💡 רמז 1

משתנה from, שמתחיל ב־0: איפה המדרגה הנוכחית מתחילה. בכל מדרגה: const to = tier.upTo === null ? amount : Math.min(amount, tier.upTo). המחיר של המדרגה הוא (to - from) * tier.price, ואחר כך from = to. כש־amount <= from — break.

💡 רמז 2

"תעבורה חינם עד 100GB" היא פשוט מדרגה עם price: 0. לעיגול: Math.round(n * 100) / 100. ‏!(amount >= 0) תופס גם NaN, כי כל השוואה עם NaN היא false.

✅ פתרון
// P26.3-E27 — חשבון S3 לפי מדרגות
export type Tier = { upTo: number | null; price: number };

// מחירים לדוגמה (דולר). כל מדרגה: עד כמה יחידות (מצטבר), ומה המחיר ליחידה בה. null — "וכל השאר"
export const STORAGE_PER_GB: Tier[] = [
  { upTo: 51_200, price: 0.023 },
  { upTo: 512_000, price: 0.022 },
  { upTo: null, price: 0.021 },
];
export const TRANSFER_OUT_PER_GB: Tier[] = [
  { upTo: 100, price: 0 },
  { upTo: 10_240, price: 0.09 },
  { upTo: null, price: 0.085 },
];

export function tieredCost(amount: number, tiers: Tier[]): number {
  if (!(amount >= 0)) throw new RangeError("amount חייב להיות מספר לא שלילי");
  let cost = 0;
  let from = 0;
  for (const tier of tiers) {
    if (amount <= from) break;
    const to = tier.upTo === null ? amount : Math.min(amount, tier.upTo);
    cost += (to - from) * tier.price;
    from = to;
  }
  return cost;
}

const cents = (n: number) => Math.round(n * 100) / 100;

export function s3Bill(usage: { storageGb: number; putRequests: number; getRequests: number; transferOutGb: number }) {
  const storage = cents(tieredCost(usage.storageGb, STORAGE_PER_GB));
  const requests = cents((usage.putRequests / 1000) * 0.005 + (usage.getRequests / 1000) * 0.0004);
  const transfer = cents(tieredCost(usage.transferOutGb, TRANSFER_OUT_PER_GB));
  return { storage, requests, transfer, total: cents(storage + requests + transfer) };
}

P26.3-E28 · סיכום של kubectl get pods 🤖 🔁 חזרה רמה 2

💡 רמז 1

const cols = header.trim().split(/\s{2,}/), ואז const [NAME, READY, ...] = ["NAME", "READY", ...].map((c) => cols.indexOf(c)). בכל שורה: const [ready, total] = cells[READY].split("/").map(Number). ‏parseInt("14 (63s ago)", 10) קורא ספרות עד התו הראשון שאינו ספרה, ומחזיר 14.

ב־parsePods השתמש ב־map ישירות (בלי לולאה), וסנן קודם שורות ריקות.

💡 רמז 2

ספירה: byStatus[p.status] = (byStatus[p.status] ?? 0) + 1. מיון: sort((a, b) => b.restarts - a.restarts || a.name.localeCompare(b.name)). כשההפרש הוא 0, ‏|| עובר לקריטריון השני.

✅ פתרון
// P26.3-E28 — סיכום של kubectl get pods
export type Pod = { name: string; ready: number; total: number; status: string; restarts: number; age: string };

export function parsePods(text: string): Pod[] {
  const [header, ...rows] = text.trim().split("\n");
  const cols = header.trim().split(/\s{2,}/);
  const at = (name: string) => {
    const i = cols.indexOf(name);
    if (i === -1) throw new Error(`חסרה עמודה ${name}`);
    return i;
  };
  const [NAME, READY, STATUS, RESTARTS, AGE] = ["NAME", "READY", "STATUS", "RESTARTS", "AGE"].map(at);
  return rows
    .filter((row) => row.trim() !== "")
    .map((row) => {
      const cells = row.trim().split(/\s{2,}/);
      const [ready, total] = cells[READY].split("/").map(Number);
      return {
        name: cells[NAME],
        ready,
        total,
        status: cells[STATUS],
        restarts: parseInt(cells[RESTARTS], 10),
        age: cells[AGE],
      };
    });
}

export function podSummary(pods: Pod[]) {
  const byStatus: Record<string, number> = {};
  for (const pod of pods) byStatus[pod.status] = (byStatus[pod.status] ?? 0) + 1;
  const notReady = pods.filter((p) => p.ready < p.total && p.status !== "Completed").map((p) => p.name);
  const restarting = pods
    .filter((p) => p.restarts >= 3)
    .sort((a, b) => b.restarts - a.restarts || a.name.localeCompare(b.name))
    .map((p) => `${p.name} (${p.restarts})`);
  return { byStatus, notReady, restarting };
}

P26.3-E02 · מי רשאי? IAM רמה 1

💡 רמז 1

💡 רמז 2

✅ פתרון

  3. נכון — implicit deny. ברירת המחדל היא "לא".
  4. לא. Deny מפורש מנצח תמיד, לא משנה כמה Allow יש. כך חוסמים פעולה מסוכנת לכולם (למשל מחיקה של גיבויים) בלי לבדוק כל policy (E13).

P26.3-E04 · מה Kubernetes יעשה? רמה 1

💡 רמז 1

💡 רמז 2

✅ פתרון
  1. ה־ReplicaSet רואה 2 במקום 3, ויוצר pod חדש תוך שניות. זה הרעיון של desired state: לא אומרים "תפעיל", אומרים "צריכים להיות 3".
  2. שום pod לא מופעל מחדש (liveness תקין). כולם יוצאים מה־endpoints של ה־Service (readiness נכשל) — הבקשות נכשלות מהר ב־Ingress במקום להיתקע, וכשהמסד חוזר, הם חוזרים לבד. אם liveness היה בודק את המסד — Kubernetes היה מפעיל מחדש את כל ה־pods בלולאה, בלי שזה עוזר בכלום (פרק 25).
  3. אחרי failureThreshold כישלונות של liveness — הקונטיינר מופעל מחדש (RESTARTS עולה ב־kubectl get pods).
  4. OOMKilled — הקונטיינר נהרג ומופעל מחדש. (חריגה מ־limit של CPU לא הורגת — היא מאטה: throttling.)
  5. ה־pods החדשים ב־CrashLoopBackOff, אף אחד לא Ready — וה־rolling update נעצר: הישנים לא מוסרים מעבר ל־maxUnavailable. האתר ממשיך לעבוד על הגרסה הישנה. kubectl rollout undo (או revert ב־Git, עם Argo CD — שיעור 4).
  6. ה־scheduler יוצר שני pods חדשים על nodes אחרים (אם יש מקום — אחרת הם Pending, E18). ו־PodDisruptionBudget מגן מכיבוי מתוכנן של nodes, לא מתקלה (E11).

export async function putJson(s3: S3Client, bucket: string, key: string, value: unknown): Promise<void> {
  await s3.send(

      Bucket: bucket,
      Key: key,
      Body: JSON.stringify(value),

export async function getJson<T = unknown>(s3: S3Client, bucket: string, key: string): Promise<T | null> {
  try {
    const res = await s3.send(new GetObjectCommand({ Bucket: bucket, Key: key }));
    const text = await res.Body!.transformToString("utf-8");
    return JSON.parse(text) as T;

    throw err;
  }
}

P26.3-E07 · העלאה ישירה ל־S3 🤖 רמה 2

💡 רמז 1

💡 רמז 2

✅ פתרון
// P26.3-E07: כתובת חתומה (presigned URL) להעלאת קובץ ישירות ל־S3
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";
import { randomUUID } from "node:crypto";

export const ALLOWED_TYPES = ["image/png", "image/jpeg", "application/pdf"];
export const MAX_BYTES = 5 * 1024 * 1024;
export const EXPIRES_IN = 300;

export interface UploadRequest {
  userId: number;
  filename: string;
  contentType: string;
  size: number;
}

export function safeName(filename: string): string {
  const base = filename.split(/[\\/]/).pop() ?? "";
  const clean = base.replace(/[^A-Za-z0-9._-]/g, "_").replace(/^\.+/, "").slice(-100);
  return clean || "file";
}

export async function createUploadUrl(s3: S3Client, bucket: string, req: UploadRequest) {
  if (!ALLOWED_TYPES.includes(req.contentType)) throw new Error(`סוג קובץ לא מותר: ${req.contentType}`);
  if (!Number.isInteger(req.size) || req.size <= 0 || req.size > MAX_BYTES) throw new Error("גודל קובץ לא תקין (עד 5MB)");
  if (!Number.isInteger(req.userId) || req.userId <= 0) throw new Error("userId לא תקין");
  const key = `uploads/${req.userId}/${randomUUID()}-${safeName(req.filename)}`;
  const url = await getSignedUrl(
    s3,
    new PutObjectCommand({ Bucket: bucket, Key: key, ContentType: req.contentType, ContentLength: req.size }),
    { expiresIn: EXPIRES_IN },
  );
  return { url, key, expiresIn: EXPIRES_IN, headers: { "content-type": req.contentType } };
}

למה זה טוב: קובץ של 5MB לא תופס זיכרון וחיבור בשרת שלנו, ו־S3 מתמודד עם אלף העלאות במקביל. השרת עדיין מחליט מי מעלה, מה ולאן. בפרודקשן מוסיפים: רשומה במסד עם ה־key (סטטוס "ממתין"), ואירוע מ־S3 כשההעלאה הסתיימה.

⚠️ טעויות נפוצות
  • להשתמש בשם הקובץ כמפתח — שני משתמשים מעלים receipt.pdf, והשני דורס את הראשון.
  • לבדוק סוג לפי סיומת השם — הלקוח שולט בה. כאן הסוג חתום בכתובת; בדיקה אמיתית של התוכן — אחרי ההעלאה.

// P26.3-E12: הגדרות מ־env, עם המוסכמה *_FILE לסודות (Kubernetes Secret שמורכב כקובץ)
export interface AppConfig {
  databaseUrl: string;
  jwtSecret: string;
  redisUrl: string;
  port: number;
}

type ReadFile = (path: string) => string;

const REQUIRED = { databaseUrl: "DATABASE_URL", jwtSecret: "JWT_SECRET", redisUrl: "REDIS_URL" } as const;

export function readSetting(env: Record<string, string | undefined>, name: string, readFile: ReadFile): string | undefined {
  const direct = env[name];
  const file = env[`${name}_FILE`];
  if (direct !== undefined && file !== undefined) throw new Error(`${name} ו־${name}_FILE מוגדרים שניהם — בחר אחד`);
  if (file !== undefined) {
    let text: string;
    try {
      text = readFile(file);
    } catch {
      throw new Error(`${name}_FILE: אי אפשר לקרוא את ${file}`);
    }
    const value = text.replace(/\r?\n$/, "");
    if (!value) throw new Error(`${name}_FILE: הקובץ ${file} ריק`);
    return value;
  }
  return direct === "" ? undefined : direct;
}

export function loadConfig(env: Record<string, string | undefined>, readFile: ReadFile): AppConfig {
  const missing: string[] = [];
  const out: Record<string, string> = {};
  for (const [key, name] of Object.entries(REQUIRED)) {
    const v = readSetting(env, name, readFile);
    if (v === undefined) missing.push(name);
    else out[key] = v;
  }
  if (missing.length) throw new Error(`חסרות הגדרות: ${missing.join(", ")}`);
  const port = Number(env.PORT ?? "3000");
  if (!Number.isInteger(port) || port < 1 || port > 65535) throw new Error(`PORT לא תקין: ${env.PORT}`);
  return { databaseUrl: out.databaseUrl, jwtSecret: out.jwtSecret, redisUrl: out.redisUrl, port };
}

💡 רמז 2

✅ פתרון
// P26.3-E13: להעריך IAM policy — כמו ש־AWS מחליט
export interface Statement {
  Effect: "Allow" | "Deny";
  Action: string | string[];
  Resource: string | string[];
}
export interface Policy {
  Version: string;
  Statement: Statement[];
}
export type Decision = "allow" | "explicit-deny" | "implicit-deny";

const list = (x: string | string[]) => (Array.isArray(x) ? x : [x]);

export function wildcardMatch(pattern: string, value: string, ignoreCase = false): boolean {
  const escaped = pattern.replace(/[.+^${}()|[\]\\]/g, "\\$&").replace(/\*/g, ".*").replace(/\?/g, ".");
  return new RegExp(`^${escaped}$`, ignoreCase ? "i" : "").test(value);
}

export function evaluate(policies: Policy[], action: string, resource: string): Decision {
  let allowed = false;
  for (const p of policies) {
    for (const s of p.Statement) {
      const hit =
        list(s.Action).some((a) => wildcardMatch(a, action, true)) && // שמות פעולות לא רגישים לרישיות
        list(s.Resource).some((r) => wildcardMatch(r, resource)); // ARN רגיש
      if (!hit) continue;
      if (s.Effect === "Deny") return "explicit-deny"; // Deny מפורש מנצח תמיד
      allowed = true;
    }
  }
  return allowed ? "allow" : "implicit-deny";
}

באמת יש עוד שכבות: policies של ה־bucket עצמו (resource-based), Permission Boundaries, Service Control Policies של הארגון, ו־Conditions. העיקרון לא משתנה: Deny מפורש בכל שכבה מנצח.

export function parseCpu(q: string | number): number {
  const s = String(q).trim();
  const m = /^(\d+(?:\.\d+)?)(m?)$/.exec(s);
  if (!m) throw new Error(`CPU לא תקין: ${q}`);
  const n = Number(m[1]);
  const milli = m[2] ? n : n * 1000;
  if (!Number.isInteger(milli)) throw new Error(`CPU לא תקין (פחות ממילי־ליבה): ${q}`);
  return milli;
}

// מחזיר בתים: "512Mi" ← 536870912, "1G" ← 1e9
export function parseMemory(q: string | number): number {
  const s = String(q).trim();
  const m = /^(\d+(?:\.\d+)?)(Ki|Mi|Gi|Ti|k|M|G|T)?$/.exec(s);
  if (!m) throw new Error(`memory לא תקין: ${q}`);
  const unit = m[2] ? (BINARY[m[2]] ?? DECIMAL[m[2]]) : 1;
  return Math.round(Number(m[1]) * unit);
}

export function formatMemory(bytes: number): string {
  for (const u of ["Gi", "Mi", "Ki"]) if (bytes >= BINARY[u] && bytes % BINARY[u] === 0) return `${bytes / BINARY[u]}${u}`;
  return String(bytes);
}

// P26.3-E17: rolling update — כמה pods מותר, ואיך ה־rollout מתקדם
export type Amount = number | `${number}%`;

function resolve(amount: Amount, replicas: number, round: (n: number) => number, name: string): number {
  if (typeof amount === "number") {
    if (!Number.isInteger(amount) || amount < 0) throw new Error(`${name} לא תקין: ${amount}`);
    return amount;
  }
  const m = /^(\d+)%$/.exec(amount);
  if (!m) throw new Error(`${name} לא תקין: ${amount}`);
  return round((replicas * Number(m[1])) / 100);
}

export function rolloutBounds(replicas: number, maxSurge: Amount, maxUnavailable: Amount) {
  if (!Number.isInteger(replicas) || replicas < 1) throw new Error("replicas חייב להיות לפחות 1");
  const surge = resolve(maxSurge, replicas, Math.ceil, "maxSurge"); // Kubernetes: surge מעגל למעלה
  const unavailable = resolve(maxUnavailable, replicas, Math.floor, "maxUnavailable"); // unavailable — למטה
  if (surge === 0 && unavailable === 0) throw new Error("maxSurge ו־maxUnavailable לא יכולים להיות שניהם 0 — ה־rollout לא יתקדם");
  return { maxPods: replicas + surge, minAvailable: replicas - unavailable };
}

export interface Snapshot {
  old: number;
  new: number;
}

// מודל פשוט: pods חדשים שנוצרו בצעד מוכנים (ready) בסוף הצעד
export function simulateRollout(replicas: number, maxSurge: Amount, maxUnavailable: Amount) {
  const { maxPods, minAvailable } = rolloutBounds(replicas, maxSurge, maxUnavailable);
  let oldPods = replicas;
  let newPods = 0;
  const steps: Snapshot[] = [{ old: oldPods, new: newPods }];
  while (oldPods > 0 || newPods < replicas) {
    const remove = Math.max(0, Math.min(oldPods, oldPods + newPods - minAvailable));
    oldPods -= remove;
    const add = Math.max(0, Math.min(replicas - newPods, maxPods - oldPods - newPods));
    newPods += add;
    if (remove === 0 && add === 0) throw new Error("ה־rollout תקוע");
    steps.push({ old: oldPods, new: newPods });
  }
  return { maxPods, minAvailable, steps };
}

הבחירה בפועל: maxUnavailable: 0 + maxSurge: 1 — אף פעם לא פחות קיבולת, אבל איטי ודורש מקום ל־pod נוסף. 25%/25% (ברירת המחדל של Kubernetes) — מהר יותר. maxSurge: 0 — כשאין מקום פנוי ב־cluster.

// P26.3-E18: scheduler קטן — לאיזה node כל pod הולך (לפי requests)
export interface NodeSpec {
  name: string;
  cpu: string;
  memory: string;
}
export interface PodSpec {
  name: string;
  cpu: string;
  memory: string;
}

// מוכנות (מ־E14)
export const parseCpu = (q: string) => (q.endsWith("m") ? Number(q.slice(0, -1)) : Number(q) * 1000);
const UNITS: Record<string, number> = { Ki: 2 ** 10, Mi: 2 ** 20, Gi: 2 ** 30, k: 1e3, M: 1e6, G: 1e9 };
export const parseMemory = (q: string) => {
  const m = /^(\d+(?:\.\d+)?)(Ki|Mi|Gi|k|M|G)?$/.exec(q)!;
  return Math.round(Number(m[1]) * (m[2] ? UNITS[m[2]] : 1));
};

export function schedule(nodes: NodeSpec[], pods: PodSpec[]) {
  const free = new Map(nodes.map((n) => [n.name, { cpu: parseCpu(n.cpu), memory: parseMemory(n.memory) }]));
  const order = pods
    .map((p) => ({ name: p.name, cpu: parseCpu(p.cpu), memory: parseMemory(p.memory) }))
    .sort((a, b) => b.cpu - a.cpu || b.memory - a.memory || a.name.localeCompare(b.name)); // הגדולים קודם
  const placements: Record<string, string> = {};
  const pending: string[] = [];
  for (const pod of order) {
    const node = nodes.find((n) => {
      const f = free.get(n.name)!;
      return f.cpu >= pod.cpu && f.memory >= pod.memory;
    });
    if (!node) {
      pending.push(pod.name);
      continue;
    }
    const f = free.get(node.name)!;
    f.cpu -= pod.cpu;
    f.memory -= pod.memory;
    placements[pod.name] = node.name;
  }
  return { placements, pending, free: Object.fromEntries(free) };
}

import { S3Client, ListObjectsV2Command, DeleteObjectsCommand } from "@aws-sdk/client-s3";

export async function listAllKeys(s3: S3Client, bucket: string, prefix: string, pageSize = 1000): Promise<string[]> {
  const keys: string[] = [];
  let token: string | undefined;
  do {
    const page = await s3.send(
      new ListObjectsV2Command({ Bucket: bucket, Prefix: prefix, MaxKeys: pageSize, ContinuationToken: token }),
    );
    for (const o of page.Contents ?? []) keys.push(o.Key!);
    token = page.IsTruncated ? page.NextContinuationToken : undefined;
  } while (token);
  return keys;
}

export async function deletePrefix(s3: S3Client, bucket: string, prefix: string): Promise<number> {
  if (!prefix || !prefix.endsWith("/")) throw new Error('prefix חייב להיות תיקייה שמסתיימת ב־"/" (ולא ריק — זה כל ה־bucket)');
  const keys = await listAllKeys(s3, bucket, prefix);
  for (let i = 0; i < keys.length; i += 1000) {
    const batch = keys.slice(i, i + 1000);
    const res = await s3.send(
      new DeleteObjectsCommand({ Bucket: bucket, Delete: { Objects: batch.map((Key) => ({ Key })), Quiet: true } }),
    );
    if (res.Errors?.length) throw new Error(`מחיקה נכשלה: ${res.Errors[0].Key} — ${res.Errors[0].Message}`);
  }
  return keys.length;
}

// P26.3-E25: GitOps — לעדכן את ה־tag של image ב־repo התצורה, בלי להרוס את הקובץ
import { parseAllDocuments, isMap, isSeq, YAMLMap } from "yaml";

const TAG_RE = /^[A-Za-z0-9_][A-Za-z0-9._-]{0,127}$/;

// "ghcr.io/x/app:1.2" ← "ghcr.io/x/app"; גם @sha256:…; ולא מתבלבל עם port של registry (localhost:5000/app)
export function repositoryOf(image: string): string {
  const at = image.indexOf("@");
  const noDigest = at >= 0 ? image.slice(0, at) : image;
  const slash = noDigest.lastIndexOf("/");
  const colon = noDigest.lastIndexOf(":");
  return colon > slash ? noDigest.slice(0, colon) : noDigest;
}

function podSpecs(doc: any): YAMLMap[] {
  const out: YAMLMap[] = [];
  const kind = doc.get("kind");
  const spec = doc.get("spec");
  if (!isMap(spec)) return out;
  const tpl = kind === "CronJob" ? (spec.getIn(["jobTemplate", "spec", "template", "spec"]) as unknown) : spec.getIn(["template", "spec"]);
  if (isMap(tpl)) out.push(tpl);
  return out;
}

export function bumpImageTag(text: string, repository: string, tag: string): { text: string; changed: number } {
  if (!TAG_RE.test(tag)) throw new Error(`tag לא תקין: ${tag}`);
  const docs = parseAllDocuments(text);
  let changed = 0;
  for (const doc of docs) {
    if ("errors" in doc && doc.errors.length) throw new Error(`YAML לא תקין: ${doc.errors[0].message}`);
    for (const pod of podSpecs(doc)) {
      for (const field of ["initContainers", "containers"]) {
        const list = pod.get(field);
        if (!isSeq(list)) continue;
        for (const c of list.items) {
          if (!isMap(c)) continue;
          const image = c.get("image");
          if (typeof image !== "string" || repositoryOf(image) !== repository) continue;
          const next = `${repository}:${tag}`;
          if (image !== next) {
            c.set("image", next);
            changed++;
          }
        }
      }
    }
  }
  if (changed === 0 && !text.includes(`${repository}:${tag}`)) throw new Error(`לא נמצא image של ${repository}`);
  return { text: docs.map((d) => d.toString()).join(""), changed };
}
