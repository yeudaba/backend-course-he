P26.3-E69 · ‏Synced, ‏Healthy — ומה ביניהם 🧠 הבנה רמה 1

💡 רמז 1

Sync = "האם ה־cluster כמו Git". Health = "האם מה שרץ עובד".

💡 רמז 2

שני הצירים עצמאיים.

✅ פתרון
  1. OutOfSync, ‏Healthy — הגרסה הקודמת עובדת, פשוט לא מה שב־Git.
  2. Synced, ‏Progressing.
  3. Synced, ‏Degraded (אחרי progressDeadlineSeconds, ברירת מחדל 10 דקות). ה־YAML הוא מה שביקשת; זה פשוט לא עובד. התיקון — ב־Git (revert).
  4. OutOfSync (‏5 ≠ 3), ‏Healthy. עם selfHeal — Argo היה מחזיר ל־3.
  5. Synced (עם prune — ה־Deployment נמחק גם מה־cluster), ‏Health: ה־Service בלי pods. ‏Argo עשה בדיוק מה שביקשו ממנו — מכאן חשיבות ה־review ב־repo התצורה.
⚠️ טעויות נפוצות
  • "Synced = הכול טוב" — Synced אומר רק שה־cluster תואם ל־Git.

P26.3-E70 · ‏prune ו־selfHeal 🧠 הבנה רמה 2

💡 רמז 1

selfHeal מחזיר כל שינוי במשאב שמנוהל. prune מוחק משאב מנוהל שנעלם מ־Git.

💡 רמז 2

איך Argo יודע שמשאב "שלו"?

✅ פתרון
  1. תוך דקות, selfHeal מחזיר את ה־image ל־מה שב־Git — ה־rollback הידני "נעלם". ב־GitOps גם תיקון בלילה הוא git revert.
  2. prune מוחק את ה־HPA מה־cluster, וה־Deployment חוזר ל־replicas מ־Git.
  3. כלום — הוא לא מנוהל על ידי ה־Application (אין עליו את הסימון של Argo), אז prune לא נוגע בו.
  4. מלחמה: Argo מחזיר ל־3, ה־HPA ל־8… הפתרון: כשיש HPA, לא כותבים replicas ב־Deployment (או אומרים ל־Argo להתעלם מהשדה).
⚠️ טעויות נפוצות
  • להשבית selfHeal "כי הוא מפריע" — זה בדיוק מה שמונע drift.

P26.3-E25 · אתגר: עדכון tag ב־repo התצורה 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

JSON.parse/stringify או js-yaml מאבדים את ההערות. החבילה yaml: parseAllDocuments ← עץ (Document), doc.get/getIn/set, ו־doc.toString() שומר על הכול.

💡 רמז 2

repository של image: הכול עד ה־: האחרון — אבל רק אם הוא אחרי ה־/ האחרון (localhost:5000/app).

✅ פתרון
// P26.3-E25: GitOps — לעדכן את ה־tag של image ב־repo התצורה, בלי להרוס את הקובץ
import { parseAllDocuments, isMap, isSeq, YAMLMap } from "yaml";

const TAG_RE = /^[A-Za-z0-9_][A-Za-z0-9._-]{0,127}$/;

// "ghcr.io/x/app:1.2" ← "ghcr.io/x/app"; גם @sha256:…; ולא מתבלבל עם port של registry (localhost:5000/app)
export function repositoryOf(image: string): string {
  const at = image.indexOf("@");
  const noDigest = at >= 0 ? image.slice(0, at) : image;
  const slash = noDigest.lastIndexOf("/");
  const colon = noDigest.lastIndexOf(":");
  return colon > slash ? noDigest.slice(0, colon) : noDigest;
}

function podSpecs(doc: any): YAMLMap[] {
  const out: YAMLMap[] = [];
  const kind = doc.get("kind");
  const spec = doc.get("spec");
  if (!isMap(spec)) return out;
  const tpl = kind === "CronJob" ? (spec.getIn(["jobTemplate", "spec", "template", "spec"]) as unknown) : spec.getIn(["template", "spec"]);
  if (isMap(tpl)) out.push(tpl);
  return out;
}

export function bumpImageTag(text: string, repository: string, tag: string): { text: string; changed: number } {
  if (!TAG_RE.test(tag)) throw new Error(`tag לא תקין: ${tag}`);
  const docs = parseAllDocuments(text);
  let changed = 0;
  for (const doc of docs) {
    if ("errors" in doc && doc.errors.length) throw new Error(`YAML לא תקין: ${doc.errors[0].message}`);
    for (const pod of podSpecs(doc)) {
      for (const field of ["initContainers", "containers"]) {
        const list = pod.get(field);
        if (!isSeq(list)) continue;
        for (const c of list.items) {
          if (!isMap(c)) continue;
          const image = c.get("image");
          if (typeof image !== "string" || repositoryOf(image) !== repository) continue;
          const next = `${repository}:${tag}`;
          if (image !== next) {
            c.set("image", next);
            changed++;
          }
        }
      }
    }
  }
  if (changed === 0 && !text.includes(`${repository}:${tag}`)) throw new Error(`לא נמצא image של ${repository}`);
  return { text: docs.map((d) => d.toString()).join(""), changed };
}

בפועל יש לזה כלים מוכנים — kustomize edit set image, yq, או Argo CD Image Updater — אבל כולם עושים בדיוק את זה. וה־commit עצמו (ב־Jenkins): git commit -am "coffee-api 1.5.0" && git push ל־repo התצורה, עם token שיש לו הרשאה רק ל־repo הזה.

P26.3-E73 · ‏mergeValues כמו של Helm 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

"אובייקט רגיל": v !== null && typeof v === "object" && !Array.isArray(v).

💡 רמז 2

פונקציה רקורסיבית mergeTwo(base, over), ו־layers.reduce(mergeTwo, {}). ‏structuredClone לערכים שמוחלפים.

✅ פתרון
// P26.3-E73: mergeValues כמו של Helm
type Obj = Record<string, unknown>;
const isObj = (v: unknown): v is Obj => v !== null && typeof v === "object" && !Array.isArray(v);

function mergeTwo(base: Obj, over: Obj): Obj {
  const out: Obj = structuredClone(base);
  for (const [k, v] of Object.entries(over)) {
    if (v === null) delete out[k];
    else if (isObj(v) && isObj(out[k])) out[k] = mergeTwo(out[k] as Obj, v);
    else out[k] = structuredClone(v);
  }
  return out;
}

export function mergeValues(...layers: Obj[]): Obj {
  return layers.reduce(mergeTwo, {});
}

זה כל הסוד של -f values-prod.yaml: קובץ קטן עם ההבדלים בלבד. ה־null הוא הדרך היחידה "להוריד" משהו שהבסיס הגדיר.

⚠️ טעויות נפוצות
  • ‏{ ...base, ...over } — מיזוג רדוד: image: { tag } מוחק את image.repository.
  • למזג מערכים איבר־איבר — Helm לא עושה את זה, והתוצאה תהיה שונה ממה שיוצא בפרודקשן.

P26.3-E74 · ‏helm template קטן 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

‏tpl.replace(/\{\{\s*(.*?)\s*\}\}/g, (_, expr) => …), ובפנים expr.split("|").map((s) => s.trim()).

💡 רמז 2

נתיב — מורידים את הנקודה הראשונה, ויורדים שלב־שלב:

".Values.image.tag".slice(1).split(".").reduce((o, k) => o?.[k], ctx)
✅ פתרון
// P26.3-E74: helm template קטן
type Ctx = { Values: Record<string, unknown>; Release: { Name: string }; Chart: { AppVersion: string } };

function lookup(path: string, ctx: Ctx): unknown {
  return path.slice(1).split(".").reduce<unknown>((o, k) => (o == null ? undefined : (o as Record<string, unknown>)[k]), ctx);
}

function literal(token: string, ctx: Ctx): unknown {
  if (token.startsWith('"')) return JSON.parse(token);
  if (token.startsWith(".")) return lookup(token, ctx);
  return Number(token);
}

const empty = (v: unknown) => v === undefined || v === null || v === "" || v === 0 || v === false;

export function renderTemplate(tpl: string, ctx: Ctx): string {
  return tpl.replace(/\{\{\s*(.*?)\s*\}\}/g, (_, expr: string) => {
    const [first, ...pipes] = expr.split("|").map((s) => s.trim());
    let v = lookup(first, ctx);
    let quote = false;
    for (const p of pipes) {
      if (p.startsWith("default ")) {
        if (empty(v)) v = literal(p.slice("default ".length).trim(), ctx);
      } else if (p === "quote") quote = true;
      else throw new Error(`פונקציה לא מוכרת: ${p}`);
    }
    if (v !== null && typeof v === "object") throw new Error(`${first} הוא אובייקט — צריך toYaml`);
    const s = v == null ? "" : String(v);
    return quote ? JSON.stringify(s) : s;
  });
}

‏Helm אמיתי הוא Go templates עם עשרות פונקציות (toYaml, ‏include, ‏if…), אבל הליבה היא זו: נתיב בתוך מבנה, וצינור של פונקציות. השורה מהשיעור — עכשיו אתה יודע בדיוק מה יוצא ממנה:

image: "{{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }}"
⚠️ טעויות נפוצות
  • v ?? Y במקום בדיקת "ריק" — ‏"" (כמו tag: "" בבסיס) לא נחשב חסר, וה־image יוצא coffee-shop:.
  • regex חמדן (.* בלי ?) — שני ביטויים באותה שורה נבלעים לאחד.

P26.3-E76 · הסטטוס של Application 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

השוואה בלי תלות בסדר מפתחות: פונקציה canon(v) שמחזירה JSON עם מפתחות ממוינים (רקורסיבית).

💡 רמז 2

ערכים חסרים ב־status (‏undefined) הם 0: ‏(s.updatedReplicas ?? 0) < replicas.

✅ פתרון
// P26.3-E76: הסטטוס של Application
type Res = { kind: string; name: string; spec: unknown; status?: any };

function canon(v: unknown): string {
  if (Array.isArray(v)) return `[${v.map(canon).join(",")}]`;
  if (v !== null && typeof v === "object") {
    return `{${Object.keys(v).sort().map((k) => `${JSON.stringify(k)}:${canon((v as Record<string, unknown>)[k])}`).join(",")}}`;
  }
  return JSON.stringify(v);
}
const id = (r: Res) => `${r.kind}/${r.name}`;

export function appStatus(desired: Res[], live: Res[]) {
  const liveById = new Map(live.map((r) => [id(r), r]));
  const wanted = new Set(desired.map(id));
  const outOfSync: string[] = [];
  let missing = false;
  for (const d of desired) {
    const l = liveById.get(id(d));
    if (!l) missing = true;
    if (!l || canon(l.spec) !== canon(d.spec)) outOfSync.push(id(d));
  }
  for (const l of live) if (!wanted.has(id(l))) outOfSync.push(id(l));

  let health: "Healthy" | "Progressing" | "Degraded" | "Missing" = "Healthy";
  if (missing) health = "Missing";
  else {
    for (const d of desired.filter((r) => r.kind === "Deployment")) {
      const l = liveById.get(id(d))!;
      const s = l.status ?? {};
      const replicas = (l.spec as { replicas?: number })?.replicas ?? 1;
      if ((s.conditions ?? []).some((c: { reason?: string }) => c.reason === "ProgressDeadlineExceeded")) {
        health = "Degraded";
        break;
      }
      if ((s.updatedReplicas ?? 0) < replicas || (s.availableReplicas ?? 0) < replicas) health = "Progressing";
    }
  }
  return { sync: outOfSync.length ? ("OutOfSync" as const) : ("Synced" as const), health, outOfSync: outOfSync.sort() };
}

שני צירים עצמאיים, בדיוק כמו בממשק של Argo CD: ‏sync משווה Git ל־cluster, ו־health מסתכל על ה־status שה־controllers כותבים. (Argo האמיתי יודע לחשב health לעשרות סוגי משאבים, ומשווה רק שדות שאתה כתבת — לא כאלה ש־Kubernetes מוסיף.)

⚠️ טעויות נפוצות
  • JSON.stringify(a) === JSON.stringify(b) — אותו spec בסדר מפתחות אחר נחשב שונה.
  • להחזיר Progressing לפני שבודקים Degraded בכל ה־Deployments — Degraded חשוב יותר.

P26.3-E77 · ‏checksum ל־ConfigMap: שינוי הגדרות ← rollout 🤖 💻 כתיבת קוד 🤖 רמה 2

// P26.3-E77: checksum ל־ConfigMap — שינוי הגדרות ← rollout
import { createHash } from "node:crypto";

export function configChecksum(data: Record<string, string>) {
  const text = Object.keys(data).sort().map((k) => `${k}=${data[k]}\n`).join("");
  return createHash("sha256").update(text).digest("hex");
}

export function withConfigChecksum<T extends object>(deployment: T, data: Record<string, string>): T {
  const copy = structuredClone(deployment) as any;
  copy.spec.template.metadata ??= {};
  copy.spec.template.metadata.annotations ??= {};
  copy.spec.template.metadata.annotations["checksum/config"] = configChecksum(data);
  return copy;
}

ההגדרות השתנו ← ה־hash השתנה ← ה־template השתנה ← ReplicaSet חדש ו־rolling update. ההגדרות לא השתנו ← אותו hash ← אין rollout מיותר. בגלל זה הסדר הממוין: אותן הגדרות חייבות לתת אותו hash.

⚠️ טעויות נפוצות
  • לשים את ה־annotation ב־metadata של ה־Deployment עצמו, לא של ה־template — שום pod לא מתחלף.
  • hash של JSON.stringify(data) — סדר מפתחות אחר נותן hash אחר, ו־rollout בלי סיבה.

// P26.3-E78: sync waves — מה קודם?
type Obj = { kind: string; metadata: { name: string; annotations?: Record<string, string> } };

const KINDS = ["Namespace", "ConfigMap", "Secret", "ServiceAccount", "Service", "Deployment", "Job", "CronJob", "Ingress"];
const rank = (k: string) => (KINDS.includes(k) ? KINDS.indexOf(k) : KINDS.length);

export function syncWaves(objs: Obj[]): string[][] {
  const waves = new Map<number, Obj[]>();
  for (const o of objs) {
    const raw = o.metadata.annotations?.["argocd.argoproj.io/sync-wave"] ?? "0";
    if (!/^-?\d+$/.test(raw.trim())) throw new Error(`sync-wave לא תקין ב־${o.kind}/${o.metadata.name}: ${raw}`);
    const w = Number(raw);
    waves.set(w, [...(waves.get(w) ?? []), o]);
  }
  return [...waves.keys()]
    .sort((a, b) => a - b)
    .map((w) =>
      waves
        .get(w)!
        .sort((a, b) => rank(a.kind) - rank(b.kind) || (a.metadata.name < b.metadata.name ? -1 : a.metadata.name > b.metadata.name ? 1 : 0))
        .map((o) => `${o.kind}/${o.metadata.name}`),
    );
}

השימוש הקלאסי: ה־Job של ה־migrations בגל -1, וה־Deployment בגל 0 — כך הקוד החדש לא עולה לפני שהמסד מוכן (‏E24). ‏Argo מחכה שכל גל יהיה Healthy לפני הבא — ו־Job "בריא" רק כשהוא הסתיים בהצלחה.

⚠️ טעויות נפוצות
  • מיון מפתחות ה־Map בלי פונקציית השוואה — ‏[-1, 10, 2] ממוינים כמחרוזות.

// P26.3-E82: tag ל־image מ־git
export function imageTag(ref: string, sha: string): string {
  if (!/^[0-9a-f]{40}$/.test(sha)) throw new Error("sha לא תקין");
  const tag = /^refs\/tags\/(.+)$/.exec(ref);
  if (tag) {
    const m = /^v(\d+\.\d+\.\d+(?:-[0-9A-Za-z.]+)?)$/.exec(tag[1]);
    if (!m) throw new Error(`tag לא בפורמט vX.Y.Z: ${tag[1]}`);
    return m[1];
  }
  const branch = /^refs\/heads\/(.+)$/.exec(ref);
  if (!branch) throw new Error(`ref לא נתמך: ${ref}`);
  const clean = branch[1]
    .toLowerCase()
    .replace(/[^a-z0-9.-]+/g, "-")
    .replace(/-+/g, "-")
    .replace(/^-|-$/g, "")
    .slice(0, 40)
    .replace(/-$/, "");
  return `${clean}-${sha.slice(0, 7)}`;
}

tag של image הוא מחרוזת עם חוקים (אותיות, ספרות, ‏_ . -, עד 128 תווים) — שם של ענף כמו feature/Login_Page לא עובר. וה־SHA בסוף הוא מה שהופך כל image לניתן לזיהוי: מהפרודקשן אפשר לחזור בדיוק ל־commit שנבנה.

⚠️ טעויות נפוצות

import { z } from "zod";

const nonEmpty = z.string().min(1);
const HOST = /^[a-z0-9-]+(\.[a-z0-9-]+)+$/;

const schema = z
  .object({
    replicas: z.number().int().min(1).max(20),
    image: z.object({ repository: nonEmpty, tag: nonEmpty.refine((t) => t !== "latest", "לא latest — גרסה קבועה") }),
    resources: z.object({
      requests: z.object({ cpu: nonEmpty, memory: nonEmpty }),
      limits: z.object({ memory: nonEmpty }),
    }),
    ingress: z.object({ enabled: z.boolean(), host: z.string().optional() }).optional(),
    autoscaling: z.object({ enabled: z.boolean(), minReplicas: z.number().int().optional(), maxReplicas: z.number().int().optional() }).optional(),
  })
  .superRefine((v, ctx) => {
    if (v.ingress?.enabled && !HOST.test(v.ingress.host ?? "")) {
      ctx.addIssue({ code: "custom", path: ["ingress", "host"], message: "שם מארח לא תקין" });
    }
    const a = v.autoscaling;
    if (a?.enabled) {
      if ((a.minReplicas ?? 0) < 2) ctx.addIssue({ code: "custom", path: ["autoscaling", "minReplicas"], message: "לפחות 2" });
      if ((a.minReplicas ?? 0) > (a.maxReplicas ?? 0)) ctx.addIssue({ code: "custom", path: ["autoscaling", "maxReplicas"], message: "קטן מ־minReplicas" });
    }
  });

export function validateValues(values: unknown) {
  const r = schema.safeParse(values);
  return r.success ? [] : r.error.issues.map((i) => ({ path: i.path.join("."), message: i.message }));
}

// P26.3-E84: לחכות ל־Synced ו־Healthy
type Status = { sync: string; health: string };
type Opts = { timeoutMs: number; intervalMs: number; sleep?: (ms: number) => Promise<void>; now?: () => number };

export async function waitForSync(getStatus: () => Promise<Status>, { timeoutMs, intervalMs, sleep = (ms) => new Promise((r) => setTimeout(r, ms)), now = Date.now }: Opts) {
  const start = now();
  for (;;) {
    let s: Status | null = null;
    try {
      s = await getStatus();
    } catch {
      // תקלה רגעית ב־API — ממשיכים לנסות
    }
    if (s?.health === "Degraded") throw new Error("DEGRADED");
    if (s?.sync === "Synced" && s.health === "Healthy") return s;
    if (now() - start >= timeoutMs) throw new Error("TIMEOUT");
    await sleep(intervalMs);
  }
}

⚠️ טעויות נפוצות
  • לבדוק timeout לפני הקריאה הראשונה — עם timeoutMs: 0 לא נבדק אפילו פעם אחת.
  • לזרוק על שגיאת רשת ראשונה — Argo מתעדכן, ה־API מגמגם שנייה, וה־pipeline נכשל בלי סיבה.
