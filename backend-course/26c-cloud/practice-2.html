P26.3-E13 · מעריך policies 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 2

ב־P26.3-E13.ts, הלוגיקה ש־AWS מריץ על כל קריאה (בגרסה מצומצמת):

  • wildcardMatch(pattern, value, ignoreCase?) — * = כל רצף (גם ריק), ? = תו אחד. כל תו אחר — כפשוטו.
  • evaluate(policies, action, resource) — "explicit-deny" אם statement כלשהו עם Deny מתאים; אחרת "allow" אם יש Allow מתאים; אחרת "implicit-deny". Action ו־Resource — מחרוזת או מערך; שם הפעולה לא רגיש לרישיות, ה־ARN כן.

P26.3-E27 · חשבון S3 לפי מדרגות 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 2⏱ 20 דק׳ידע נדרש: שיעור 2

🔁 חזרה על לולאת for...of עם משתנה מצטבר ו־break (פרק 4), ‏Math.min ועיגול לסנטים (פרק 2), ו־type עם null (פרק 11). ב־AWS רוב המחירים במדרגות: ה־GB הראשונים במחיר אחד, הבאים במחיר נמוך יותר. ‏500GB הם לא "500 × המחיר של המדרגה שבה נגמרת הכמות", אלא כל חלק במחיר של המדרגה שלו. כתוב וייצא:

  • type Tier = { upTo: number | null; price: number }. ‏upTo מצטבר (‏"עד 10, עד 30"), ו־null הוא "וכל השאר".
  • tieredCost(amount, tiers): number — עם לולאה על המדרגות. עם המדרגות [{ upTo: 10, price: 1 }, { upTo: 30, price: 0.5 }, { upTo: null, price: 0.25 }]: ‏11 ← 10.5, ‏130 ← 45. שלילי או NaN ← RangeError.
  • s3Bill({ storageGb, putRequests, getRequests, transferOutGb }) ← { storage, requests, transfer, total } בדולרים, כל אחד מעוגל לסנטים, ו־total הוא סכום שלושת המעוגלים (מעוגל שוב). מחירים לדוגמה:
    • אחסון: עד 51,200GB ‏— 0.023 ל־GB, עד 512,000GB ‏— 0.022, מעל — 0.021.
    • בקשות: ‏PUT ‏— 0.005 לכל 1,000. ‏GET ‏— 0.0004 לכל 1,000.
    • תעבורה החוצה: 100GB הראשונים בחינם, עד 10,240GB ‏— 0.09, מעל — 0.085.

🔗 איך זה מתחבר: לולאה עם משתנה מצטבר מפרק 4 ועיגול לסנטים מפרק 2 — והשיעור: כמה S3 באמת עולה.

P26.3-E57 · ייצוא CSV ל־S3 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 16, שיעור 2

מנהלת רוצה "קובץ של כל ההזמנות של החודש" — תוצאה של שאילתה (פרק 16), כ־CSV ב־S3. בקובץ 26c-cloud/starter/P26.3-E57.ts (יש בו רק הערה) כתוב וייצא:

export function toCsv(rows: Record<string, unknown>[]): string
export async function exportCsv(s3: S3Client, bucket: string, key: string, rows: Record<string, unknown>[]): Promise<{ rows: number; bytes: number }>
  • toCsv: שורת כותרת מהמפתחות של השורה הראשונה, ואז שורה לכל רשומה, לפי אותו סדר עמודות. שורות מופרדות ב־\r\n, וגם בסוף יש \r\n. בלי שורות ← "".
  • ערך: null/undefined ← ריק. ‏Date ← ‏toISOString(). ערך עם פסיק, מירכאות או ירידת שורה ← בתוך מירכאות, ומירכאות בפנים מוכפלות (" ← "").
  • exportCsv: שומר עם ContentType: text/csv; charset=utf-8, ועם BOM (‏﻿) בהתחלה — כדי ש־Excel יציג עברית. מחזיר כמה שורות וכמה בתים נשמרו.

🔗 איך זה מתחבר: שורות של שאילתה מפרק 16, ו־Date מפרק 24 — והשיעור: אובייקט ב־S3, ובתים ולא תווים.
