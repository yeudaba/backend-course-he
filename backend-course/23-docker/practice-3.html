P23-E55 · מה נבנה מחדש?

ה־Dockerfile:

FROM node:24-alpine
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci --omit=dev

אחרי build מלא אחד, לכל שינוי — אילו הוראות ירוצו שוב (ולא יגיעו מה־cache)?

  2. הוספת תלות (npm install zod).
  3. תיקנת טעות כתיב ב־README.md.
  4. שינית את CMD ל־["node", "--enable-source-maps", "src/server.mjs"].
  5. שום שינוי, אבל יצאה גרסה חדשה של node:24-alpine והרצת docker build --pull.

P23-E63 · ‏lint ל־Dockerfile משלך 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 30 דק׳ידע נדרש: פרק 6, פרק 13, שיעור 3

export function lintDockerfile(text: string): string[]

מפרקים לשורות (שורה שנגמרת ב־\ ממשיכה בבאה; שורות ריקות והערות — מדלגים; ההוראה — המילה הראשונה, בלי תלות באותיות). מחזירים הודעות, לפי הסדר הזה (כל אחת פעם אחת, רק אם רלוונטית):

  6. "CMD בצורת מחרוזת" — ה־CMD האחרון לא מתחיל ב־[.

P23-E64 · האם הקובץ ייכנס ל־image? 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 13, שיעור 3

בקובץ 23-docker/starter/P23-E64.ts כתוב וייצא מימוש פשוט של .dockerignore:

export function isIgnored(file: string, patterns: string[]): boolean
  • file — נתיב יחסי עם / (‏src/app.ts, ‏.env.production).
  • שורות ריקות והערות (#) — מדלגים. ‏/ בהתחלה או בסוף של תבנית — מורידים.
  • תבנית מתאימה לקובץ אם היא מתאימה לנתיב כולו או לתיקייה שמכילה אותו (‏node_modules מתאים ל־node_modules/x/y.js).
  • בתבנית: * — כל רצף בלי /; ‏? — תו אחד שאינו /; ‏** — כל רצף, גם עם / (‏**/*.log מתאים ל־a.log ול־x/y/a.log).
  • ! בהתחלה — "לא להתעלם". התבנית האחרונה שמתאימה קובעת.

P23-E65 · ‏Dockerfile שמריץ בדיקות לפני build 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 22, שיעור 3

image לא אמור להיבנות אם הבדיקות נכשלות. בתיקייה 23-docker/starter/P23-E65/ (פרויקט TypeScript עם npm test ו־npm run build שמייצר dist/) כתוב Dockerfile בשני שלבים:

  • שלב build (‏FROM node:24-alpine AS build): ‏WORKDIR /app, ‏COPY package.json package-lock.json ./, ‏RUN npm ci, ‏COPY . ., ‏RUN npm test, ‏RUN npm run build — בסדר הזה.
  • שלב אחרון (‏FROM node:24-alpine): ‏WORKDIR /app, ‏ENV NODE_ENV=production, ‏COPY package.json package-lock.json ./, ‏RUN npm ci --omit=dev, ‏COPY --from=build /app/dist ./dist, ‏USER node, ‏CMD ["node", "dist/main.js"].
  • בשלב האחרון: אין COPY . ., ואין npm test.
% npm run check P23-E65
