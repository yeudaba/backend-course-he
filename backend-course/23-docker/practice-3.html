P23-E05 · סקירת Dockerfile

🧠 הבנהרמה 1⏱ 15 דק׳ידע נדרש: שיעור 3

מצא לפחות שש בעיות, והסבר כל אחת:

FROM node:latest
COPY . .
RUN npm install
ENV DATABASE_URL=postgresql://postgres:supersecret@prod-db:5432/app
RUN npm run build
EXPOSE 3000
CMD npm start

P23-E12 · Dockerfile ראשון 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 3

בתיקייה 23-docker/starter/P23-E12/ יש שרת בלי תלויות (server.mjs, /health). כתוב Dockerfile: node:24-alpine, תיקיית עבודה /app, רק הקבצים שצריך, EXPOSE 3000, ו־CMD בצורת מערך.

לנסות: docker build -t p23-e12 23-docker/starter/P23-E12 ← docker run --rm -p 3000:3000 p23-e12 ← curl localhost:3000/health.

P23-E13 · .dockerignore 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

ב־P23-E13/ ה־Dockerfile עושה COPY . .. בתיקייה אמיתית יש גם .env (וגם .env.production), node_modules, coverage/, logs/, קובצי *.log ו־tmp/. כתוב .dockerignore כך שאף אחד מאלה לא ייכנס ל־image. (הבודק מוסיף אותם לעותק של התיקייה, בונה, ובודק מה יש בפנים.)

P23-E14 · cache של שכבות 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

ב־P23-E14/ שרת עם תלות (zod) ו־package-lock.json. כתוב Dockerfile כך ששינוי ב־server.mjs לא יריץ שוב את npm ci (הבודק בונה, משנה שורה בקוד, בונה שוב, ומחפש CACHED בשלב של npm ci). רק תלויות production, ולא root.

P23-E15 · multi-stage ל־TypeScript 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 3

ב־P23-E15/ שרת ב־TypeScript (src/server.ts, npm run build ← dist/). כתוב Dockerfile בשני שלבים: build — מתקין הכול ומקמפל; runtime — רק dist/ ותלויות production. ב־image הסופי לא יהיו src/ ו־typescript, והוא ירוץ כ־node.

P23-E16 · HEALTHCHECK ו־PORT 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

ב־P23-E16/Dockerfile: ברירת מחדל PORT=8080 (ENV), EXPOSE 8080, לא root, ו־HEALTHCHECK שבודק /health על ה־PORT בפועל — גם כשמריצים עם -e PORT=9000. (הבודק מחכה ש־docker inspect יראה healthy, פעמיים.)

P23-E20 · Dockerfile עם שלוש תקלות 🤖

💻 כתיבת קוד 🤖רמה 4⏱ 15 דק׳ידע נדרש: שיעור 3

P23-E20/Dockerfile נבנה ורץ. ובכל זאת, ב־code review הוא היה נדחה: (1) כל שינוי בקוד מריץ שוב את npm ci; (2) הוא רץ כ־root; (3) יש בו סוד — docker image inspect מראה אותו לכל מי שיש לו את ה־image. תקן. את הסוד האפליקציה תקבל בזמן ריצה (-e JWT_SECRET=...).

P23-E23 · עובד אצלי, לא ב־Docker 🤖

💻 כתיבת קוד 🤖רמה 4⏱ 15 דק׳ידע נדרש: שיעור 3

P23-E23/server.mjs עובד מצוין עם node server.mjs ב־Mac. ב־Docker: docker run -p 3000:3000 ← curl localhost:3000/health ← Connection reset by peer. שתי תקלות בקובץ. תקן אותו (את ה־Dockerfile לא צריך לשנות).
