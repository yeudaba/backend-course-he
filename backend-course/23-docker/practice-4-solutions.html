P23-E67 · ‏localhost בתוך קונטיינר 🧠 הבנה רמה 1

💡 רמז 1

שם של שירות הוא שם מחשב — רק בתוך הרשת של הפרויקט.

💡 רמז 2

localhost תמיד קיים. השאלה מי מאזין שם.

✅ פתרון
  1. מה־Mac (בזכות ports). מתוך app — גם, כי app עצמו מאזין שם.
  2. רק מתוך הרשת (‏app). מה־Mac — אין שם כזה, ואין port.
  3. משום מקום: מה־Mac אין port פתוח; בתוך app, ‏localhost הוא app, ושם אין PostgreSQL.
  4. מתוך הרשת (למשל מ־db, או מקונטיינר אחר). מה־Mac — לא.

‏localhost קיים בכל קונטיינר (127.0.0.1 שלו), אז השם נפתר — אבל אף אחד לא מאזין ב־5432 שם, ולכן "connection refused".

⚠️ טעויות נפוצות
  • לפתוח ports למסד "כדי שהאפליקציה תגיע אליו". היא מגיעה דרך הרשת הפנימית.

P23-E68 · ‏depends_on — מה הוא באמת מבטיח? 🧠 הבנה רמה 2

💡 רמז 1

"התחיל" ≠ "מוכן". PostgreSQL צריך כמה שניות.

💡 רמז 2

מה compose עושה כשמבקשים לחכות ל־healthy לשירות שאין לו healthcheck?

✅ פתרון
  • א — app עולה מיד כשהקונטיינר של db התחיל. לפעמים המסד עוד לא מקבל חיבורים, ו־app נופל (תלוי במזל).
  • ב — app מחכה ש־pg_isready יצליח. יציב.
  • ג — שגיאה של compose: אי אפשר לחכות ל־healthy בלי healthcheck (‏"has no healthcheck configured").

retry באפליקציה: כי המסד יכול ליפול גם אחרי העלייה (restart, עדכון), ו־compose לא עוזר שם. healthcheck פותר את העלייה; retry — את החיים.

⚠️ טעויות נפוצות
  • sleep 10 לפני הפעלת האפליקציה. איטי תמיד, ולא מספיק כשהמחשב עמוס.

P23-E69 · ‏down, down -v, stop 🧠 הבנה רמה 1

💡 רמז 1

‏stop — עוצר. ‏down — עוצר ומוחק קונטיינרים ורשת.

💡 רמז 2

volumes נמחקים רק כשמבקשים במפורש.

✅ פתרון
  1. הכול נשאר, הקונטיינרים עצורים. ‏start מחזיר אותם.
  2. קונטיינרים ורשת נמחקים; ה־volume והנתונים נשארים.
  3. הכול נמחק, כולל ה־volume — הנתונים אבדו.
  4. image חדש לשירותים שהשתנו, והקונטיינרים שלהם נוצרים מחדש. הנתונים ב־volume.
  5. קונטיינר חדש ל־db, אותו volume — הנתונים נשארים.
⚠️ טעויות נפוצות
  • להתרגל ל־down -v "כדי להתחיל נקי" בפרויקט עם נתונים שחשובים לך.

💡 רמז 2

P23-E17 · compose: app ו־PostgreSQL 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

בתוך compose, כל שירות נגיש לאחרים לפי השם שלו: @db:5432, לא localhost.

💡 רמז 2

depends_on: db: condition: service_healthy — רק עם healthcheck ב־db.

✅ פתרון
services:
  db:
    image: postgres:18-alpine
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: app
      POSTGRES_DB: visits
    volumes:
      - db-data:/var/lib/postgresql
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U app -d visits"]
      interval: 2s
      timeout: 3s
      retries: 30

  app:
    build: .
    environment:
      DATABASE_URL: postgresql://app:app@db:5432/visits # db = שם השירות, לא localhost
    ports:
      - "${APP_PORT:-3000}:3000"
    depends_on:
      db:
        condition: service_healthy

volumes:
  db-data:

שלושה דברים שכל compose של "אפליקציה + מסד" צריך: שם שירות כ־host, volume בשם (שורד down), וhealthcheck + condition (בלעדיהם האפליקציה עולה לפני שהמסד מוכן, ונופלת — E21).

⚠️ טעויות נפוצות
  • volume בלי שם (- /var/lib/postgresql) — volume אנונימי שקל לאבד.

P23-E71 · ‏lint ל־compose 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

for (const [name, s] of Object.entries(doc.services ?? {})) — סדר המפתחות של אובייקט שומר את סדר ההוספה.

💡 רמז 2

environment כמערך:

Object.fromEntries(env.map((x) => [x.slice(0, x.indexOf("=")), x.slice(x.indexOf("=") + 1)]))
✅ פתרון
// P23-E71: lint ל־compose
const DB = /^(postgres|mysql|mongo|redis)\b/;

function envOf(env: unknown): Record<string, string> {
  if (Array.isArray(env)) {
    return Object.fromEntries(env.map((x: string) => {
      const i = x.indexOf("=");
      return i === -1 ? [x, ""] : [x.slice(0, i), x.slice(i + 1)];
    }));
  }
  return (env ?? {}) as Record<string, string>;
}

export function lintCompose(doc: any): string[] {
  const out: string[] = [];
  for (const [name, s] of Object.entries<any>(doc.services ?? {})) {
    const image: string | undefined = s.image;
    if (image !== undefined && ((!image.includes(":") && !image.includes("@")) || image.endsWith(":latest"))) out.push(`${name}: image בלי tag`);
    if (image && DB.test(image) && s.ports?.length) out.push(`${name}: מסד עם ports`);
    if (image?.startsWith("postgres:18") && (s.volumes ?? []).some((v: unknown) => typeof v === "string" && v.endsWith(":/var/lib/postgresql/data"))) {
      out.push(`${name}: volume של PostgreSQL 18 בנתיב הישן`);
    }
    if (Array.isArray(s.depends_on)) out.push(`${name}: depends_on בלי condition`);
    for (const [k, v] of Object.entries(envOf(s.environment))) {
      if (/localhost|127\.0\.0\.1/.test(String(v))) out.push(`${name}: localhost ב־${k}`);
    }
  }
  return out;
}

כל כלל כאן הוא טעות מהשיעור (E67, ‏E68, ‏E74, ‏E75). ה־YAML הוא סתם מבנה נתונים — וכמו ה־Dockerfile ב־E63, אפשר לבדוק אותו בקוד, ב־CI, לפני שמישהו מריץ.

⚠️ טעויות נפוצות
  • לשכוח שירות עם build ובלי image — ‏image.includes על undefined זורק.

P23-E72 · ‏${VAR:-default} — כמו compose 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

‏regex אחד עם חלופות, ו־replace עם פונקציה:

/\$\$|\$\{([A-Za-z_]\w*)(?:(:?[-?])([^}]*))?\}|\$([A-Za-z_]\w*)/g
💡 רמז 2

בפונקציה: אם ההתאמה היא "$$" ← "$". אחרת השם הוא m1 ?? m4, והאופרטור (:-, ‏-, ‏:?, ‏?) קובע.

✅ פתרון
// P23-E72: interpolation בסגנון compose
const RE = /\$\$|\$\{([A-Za-z_]\w*)(?:(:?[-?])([^}]*))?\}|\$([A-Za-z_]\w*)/g;

export function interpolate(text: string, env: Record<string, string | undefined>): string {
  return text.replace(RE, (all, braced?: string, op?: string, arg?: string, bare?: string) => {
    if (all === "$$") return "$";
    const name = (braced ?? bare)!;
    const value = env[name];
    const empty = value === undefined || value === "";
    switch (op) {
      case ":-":
        return empty ? arg! : value!;
      case "-":
        return value === undefined ? arg! : value;
      case ":?":
        if (empty) throw new Error(`${name}: ${arg}`);
        return value!;
      case "?":
        if (value === undefined) throw new Error(`${name}: ${arg}`);
        return value;
      default:
        return value ?? "";
    }
  });
}

P23-E27 · קורא קובץ .env 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

לולאת for (let i = 0; i < lines.length; i++) ולא for...of, כי צריך את מספר השורה להודעה. ‏const eq = line.indexOf("="), ואז line.slice(0, eq) ו־line.slice(eq + 1). ‏split("=") היה חותך את הערך בכל =.

💡 רמז 2

שלושה מקרים לערך, לפי הסדר: מתחיל ונגמר ב־" ← value.slice(1, -1).replaceAll("\\n", "\n"). מתחיל ונגמר ב־' ← slice(1, -1). אחרת ← חותכים ב־indexOf(" #") אם יש. בדוק value.length >= 2, אחרת הערך " לבדו "מתחיל ונגמר" במירכאות.

✅ פתרון
// P23-E27 — קורא קובץ .env
export function parseEnv(text: string): Record<string, string> {
  const result: Record<string, string> = {};
  const lines = text.split("\n");
  for (let i = 0; i < lines.length; i++) {
    let line = lines[i].trim();
    if (line === "" || line.startsWith("#")) continue;
    if (line.startsWith("export ")) line = line.slice("export ".length).trim();

    const eq = line.indexOf("=");
    if (eq === -1) throw new SyntaxError(`שורה ${i + 1}: חסר =`);
    const key = line.slice(0, eq).trim();
    if (!/^[A-Za-z_][A-Za-z0-9_]*$/.test(key)) throw new SyntaxError(`שורה ${i + 1}: שם לא חוקי: ${key}`);

    let value = line.slice(eq + 1).trim();
    if (value.length >= 2 && value.startsWith('"') && value.endsWith('"')) {
      value = value.slice(1, -1).replaceAll("\\n", "\n");
    } else if (value.length >= 2 && value.startsWith("'") && value.endsWith("'")) {
      value = value.slice(1, -1);
    } else {
      const hash = value.indexOf(" #");
      if (hash !== -1) value = value.slice(0, hash).trim();
    }
    result[key] = value;
  }
  return result;
}

// P23-E77: DATABASE_URL — עם קידוד
export type DbConfig = { user: string; password: string; host: string; port: number; database: string };

export function toDatabaseUrl(c: DbConfig): string {
  const e = encodeURIComponent;
  return `postgresql://${e(c.user)}:${e(c.password)}@${c.host}:${c.port}/${e(c.database)}`;
}

export function parseDatabaseUrl(url: string): DbConfig {
  let u: URL;
  try {
    u = new URL(url);
  } catch {
    throw new Error("DATABASE_URL לא תקין");
  }
  const database = decodeURIComponent(u.pathname.slice(1));
  if (!["postgresql:", "postgres:"].includes(u.protocol) || !database) throw new Error("DATABASE_URL לא תקין");
  return {
    user: decodeURIComponent(u.username),
    password: decodeURIComponent(u.password),
    host: u.hostname,
    port: u.port ? Number(u.port) : 5432,
    database,
  };
}
