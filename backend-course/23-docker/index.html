פרק 23 — Linux ו־Docker

⏱ 5 מפגשים

🧰 לפני שמתחילים — פרק 23

מה צריך שכבר יהיה מותקן: Node.js 24, VS Code, ופרויקט 2 בשלב ה׳.

מה מתקינים עכשיו:

  • Docker Desktop ל־Mac — בחר את הגרסה למעבד שלך (Apple silicon או Intel: תפריט ← About This Mac). אחרי ההתקנה פתח את Docker Desktop פעם אחת ואשר את ההרשאות; הלווייתן בשורת התפריטים צריך להיות יציב (לא מהבהב).
  • תוסף VS Code: Container Tools — עזרה בכתיבת Dockerfile ו־compose, ורשימת קונטיינרים בצד.
  • (רשות) ShellCheck — מסמן טעויות בסקריפטים של bash בזמן הכתיבה.

Docker Desktop תופס זיכרון ודיסק. כשלא עובדים איתו — אפשר לסגור אותו (Quit). ו־docker system df מראה כמה מקום תופסים images ו־volumes.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 23-docker מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה: docker run --rm node:24-alpine node -e "console.log(process.version, process.platform)" ← v24.… linux. (בפעם הראשונה Docker מוריד את ה־image — זה לוקח רגע.) שים לב ל־linux: הקוד רץ בלינוקס, גם על ה־Mac.

🎯 בסוף הפרק תדע
  • להסתדר בשרת Linux: קבצים, הרשאות, תהליכים, ports, משתני סביבה ולוגים.
  • לכתוב סקריפטים קצרים ובטוחים ב־bash, ולעבד טקסט עם pipelines.
  • להבין image, container, volume ו־port — ולהריץ PostgreSQL בפקודה אחת.
  • לכתוב Dockerfile טוב: cache, .dockerignore, multi-stage, לא root, healthcheck.
  • Docker Compose: כמה שירותים, רשת, volumes, תלויות והגדרות.
  • פרויקט 2, שלב ו׳: כל המערכת עולה בפקודה אחת — docker compose up.

🤔 למה צריך את זה?

הפרויקט שלך רץ ב־Mac. הוא צריך Node 24, PostgreSQL 18, migrations, משתני סביבה, ושני טרמינלים. מפתח חדש בצוות צריך חצי יום כדי להריץ אותו; שרת בענן — עוד חצי. Docker אורז את כל זה: האפליקציה, עם הגרסה המדויקת של Node והתלויות, הופכת ל־image אחד שרץ אותו דבר בכל מקום — ו־Compose מעלה אותה יחד עם המסד בפקודה אחת. כמעט כל משרת Backend מבקשת Docker, וכמעט כל שרת שתפגוש הוא Linux. ובפרק 25 — ה־image הזה הוא בדיוק מה שנפרס.
