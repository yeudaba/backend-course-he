P23-E25 · אתגר: wait-for 🤖

P23-E26 · סבב גיבויים: לשמור רק את האחרונים 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 2⏱ 20 דק׳ידע נדרש: שיעור 1

בשרת קטן מגבים את PostgreSQL פעם ביום: ‏docker exec db pg_dump ... | gzip > backups/db-2026-11-05.sql.gz. בלי ניקוי, הדיסק מתמלא אחרי כמה חודשים. כתוב מקובץ ריק את rotate-backups.sh <dir> <keep>:

  • גיבוי הוא קובץ בתיקייה עצמה (לא בתתי־תיקיות) בשם db-YYYY-MM-DD.sql.gz. כל קובץ אחר (‏notes.txt, ‏db-latest.sql.gz) לא נוגעים בו.
  • משאירים את keep הגיבויים החדשים ביותר (לפי התאריך שבשם), ומוחקים את השאר. על כל קובץ שנמחק מדפיסים את השם שלו (בלי התיקייה), מהישן לחדש.
  • אם יש keep גיבויים או פחות — לא מוחקים ולא מדפיסים כלום, ויוצאים עם 0.
  • לא בדיוק שני ארגומנטים, או keep שאינו שלם חיובי ← הודעה ל־stderr ו־exit 2. התיקייה לא קיימת ← exit 1.

📄 כותבים בקובץ 23-docker/starter/P23-E26.sh (יש בו רק הערה), מריצים ובודקים:

% bash 23-docker/starter/P23-E26.sh backups 3
% npm run check P23-E26
