P23-E26 · סבב גיבויים: לשמור רק את האחרונים 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 2⏱ 20 דק׳ידע נדרש: שיעור 1

בשרת קטן מגבים את PostgreSQL פעם ביום: ‏docker exec db pg_dump ... | gzip > backups/db-2026-11-05.sql.gz. בלי ניקוי, הדיסק מתמלא אחרי כמה חודשים. כתוב מקובץ ריק את rotate-backups.sh <dir> <keep>:

  • גיבוי הוא קובץ בתיקייה עצמה (לא בתתי־תיקיות) בשם db-YYYY-MM-DD.sql.gz. כל קובץ אחר (‏notes.txt, ‏db-latest.sql.gz) לא נוגעים בו.
  • משאירים את keep הגיבויים החדשים ביותר (לפי התאריך שבשם), ומוחקים את השאר. על כל קובץ שנמחק מדפיסים את השם שלו (בלי התיקייה), מהישן לחדש.
  • אם יש keep גיבויים או פחות — לא מוחקים ולא מדפיסים כלום, ויוצאים עם 0.
  • לא בדיוק שני ארגומנטים, או keep שאינו שלם חיובי ← הודעה ל־stderr ו־exit 2. התיקייה לא קיימת ← exit 1.

📄 כותבים בקובץ 23-docker/starter/P23-E26.sh (יש בו רק הערה), מריצים ובודקים:

% bash 23-docker/starter/P23-E26.sh backups 3
% npm run check P23-E26

P23-E33 · משתנה סביבה — מי רואה אותו?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 13, שיעור 1

בכל מקרה — מה ידפיס node -e 'console.log(process.env.PORT)'?

  1. PORT=4000 node -e '...'
  2. PORT=4000 בשורה אחת, ואז node -e '...' בשורה הבאה.
  3. export PORT=4000, ואז node -e '...'.
  4. ב־.env כתוב PORT=4000, ו־node -e '...' רץ באותה תיקייה.
  5. export PORT=4000 בטרמינל אחד, ו־node בטרמינל אחר.

🔗 איך זה מתחבר: ‏process.env ו־dotenv מפרק 13 — והשיעור: ‏export ו־VAR=x command.

P23-E36 · הרשאות: אותיות ↔ מספרים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: פרק 4, שיעור 1

בקובץ 23-docker/starter/P23-E36.ts כתוב וייצא:

export function toOctal(perms: string): string     // "-rwxr-xr-x" ← "755"
export function fromOctal(octal: string): string   // "640" ← "rw-r-----"
  • toOctal מקבל 10 תווים (הראשון — סוג: -, ‏d או l), ובכל שלשה רק r/-, ‏w/-, ‏x/- במקומות שלהם. אחרת ← throw new Error(הרשאות לא תקינות: ${perms}).
  • fromOctal מקבל בדיוק 3 ספרות 0–7 ומחזיר 9 תווים. אחרת ← throw new Error(מספר לא תקין: ${octal}).
% npm run check P23-E36

🔗 איך זה מתחבר: לולאות ומחרוזות מפרקים 2 ו־4 — והשיעור: ‏r=4, ‏w=2, ‏x=1.
