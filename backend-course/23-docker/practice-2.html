P23-E43 · לפרק את עמודת PORTS 🤖

P23-E44 · לפרק שם של image 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 23-docker/starter/P23-E44.ts כתוב וייצא:

export type ImageRef = { registry: string; repository: string; tag: string | null; digest: string | null };
export function parseImageRef(ref: string): ImageRef
parseImageRef("postgres:18-alpine") // { registry: "docker.io", repository: "library/postgres", tag: "18-alpine", digest: null }
  • ‏node ← tag "latest". ‏ghcr.io/dana/tasks-api:1.2.0 ← registry ghcr.io, repository dana/tasks-api. ‏dana/tasks-api ← registry docker.io.
  • החלק הראשון הוא registry רק אם יש בו . או :, או שהוא localhost (‏localhost:5000/app:dev).
  • ‏@sha256:... בסוף ← digest. עם digest ובלי tag ← tag: null.
  • ריק, או רווח, או אותיות גדולות ב־repository ← throw new Error(שם לא תקין: ${ref}).

P23-E45 · לבנות את פקודת docker run 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 23-docker/starter/P23-E45.ts כתוב וייצא פונקציה שהופכת תיאור לארגומנטים של docker run (כמו שהטבלה בשיעור מסבירה):

export type RunSpec = {
  image: string; name?: string; detach?: boolean; rm?: boolean; restart?: "no" | "always" | "unless-stopped";
  env?: Record<string, string>; ports?: string[]; volumes?: string[]; command?: string[];
};
export function runArgs(spec: RunSpec): string[]
  • הסדר: "run", ‏-d (אם detach), ‏--rm, ‏--name X, ‏--restart X, לכל env ‏-e KEY=value (לפי סדר המפתחות), לכל port ‏-p X, לכל volume ‏-v X, ה־image, ואחריו ה־command.
  • image בלי tag ובלי digest (‏"postgres", ‏"dana/api") ← throw new Error(צריך tag מפורש: ${image}).
  • rm יחד עם restart שאינו "no" ← throw new Error("--rm ו־--restart לא הולכים יחד").
  • ערך של env עובר כמו שהוא (גם עם רווחים) — כל זוג הוא ארגומנט אחד.

P23-E28 · כמה מקום תופסים ה־images? 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 2⏱ 20 דק׳ידע נדרש: שיעור 2

🔁 חזרה על switch (פרק 4), ‏reduce (פרק 6), ‏toFixed (פרק 2) ו־while (פרק 4). ‏docker images מדפיס טבלה, והגדלים בה הם טקסט: 245MB, ‏1.21GB. Docker משתמש ביחידות עשרוניות: kB = 1,000 בתים, ‏MB = 1,000,000. כתוב וייצא:

  • parseSize(text): number — בתים. מספר (אפשר עם נקודה), ואחריו יחידה: B, ‏kB (גם KB), ‏MB, ‏GB, ‏TB. את היחידה בוחרים עם switch. כל דבר אחר ← Error.
  • formatSize(bytes): string — היחידה הגדולה ביותר שבה הערך הוא לפחות 1. בבתים — מספר שלם (999B). ביחידות אחרות — ספרה אחת אחרי הנקודה, בלי .0: ‏12.3kB, ‏245MB, ‏1.5GB.
  • totalSize(dockerImages): string — מקבלת את כל הפלט של docker images (שורת כותרת ושורות), ומחזירה את סכום עמודת SIZE, מעוצב. העמודות מופרדות בשני רווחים או יותר (בתוך CREATED יש רווח בודד). מצא את העמודה לפי הכותרת, לא לפי מספר קבוע.

🔗 איך זה מתחבר: Math.round ויחידות מפרק 2, ‏reduce מפרק 6 — והשיעור: כמה מקום תופסים images (‏docker image ls).

% npm run check P23-E28

P23-E51 · סיכום של docker inspect 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 7, פרק 21, שיעור 2

‏docker inspect <container> מחזיר JSON ענק. בקובץ 23-docker/starter/P23-E51.ts כתוב וייצא פונקציה שמוציאה ממנו את מה שחשוב, בלי לחשוף סודות:

export function summarize(inspect: any[]): {
  name: string; image: string; running: boolean; health: string | null;
  ports: string[]; mounts: string[]; env: Record<string, string>;
}
  • מהאיבר הראשון במערך. ‏name — Name בלי ה־/ בהתחלה. ‏image — Config.Image. ‏running — State.Running. ‏health — State.Health.Status, או null אם אין.
  • ports — מ־HostConfig.PortBindings: לכל port בקונטיינר ולכל binding ← ${HostIp || "0.0.0.0"}:${HostPort}-&gt;${port}, ממוין.
  • mounts — מ־Mounts: ‏volume ← volume ${Name} → ${Destination}; ‏bind ← bind ${Source} → ${Destination}.
  • env — מ־Config.Env (‏"KEY=value"; הערך יכול להכיל =). מפתח שמכיל PASSWORD, ‏SECRET, ‏TOKEN או KEY ← "***".
  • מערך ריק ← throw new Error("אין קונטיינר").
% npm run check P23-E51
