P23-E72 · ‏${VAR:-default} — כמו compose 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 4

בקובץ 23-docker/starter/P23-E72.ts כתוב וייצא את ההחלפה של משתנים ש־compose עושה:

export function interpolate(text: string, env: Record<string, string | undefined>): string
  • ${VAR} ו־$VAR ← הערך, או מחרוזת ריקה.
  • ${VAR:-default} ← הערך אם הוא מוגדר ולא ריק; אחרת default.
  • ${VAR-default} ← default רק אם לא מוגדר (ריק — נשאר ריק).
  • ${VAR:?message} ← לא מוגדר או ריק ← throw new Error(${VAR}: ${message}).
  • $$ ← $ (ולא מתחיל משתנה).
  • שם משתנה: אות או _, ואחריהן אותיות, ספרות, _.

P23-E27 · קורא קובץ .env 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 2⏱ 20 דק׳ידע נדרש: שיעור 4

🔁 חזרה על indexOf/slice (‏P14-E26), ביטויים רגולריים (‏P13-E26) ולולאת for עם אינדקס (פרק 4). ‏env_file ב־compose ו־node --env-file קוראים קובץ .env. כתוב וייצא parseEnv(text: string): Record<string, string>:

  • שורה ריקה, או שורה שמתחילה ב־# (אחרי trim) — מדלגים.
  • אפשר export בתחילת השורה, ואז מתעלמים ממנו.
  • השם הוא מה שלפני ה־= הראשון (אחרי trim), והוא חייב להתאים ל־[A-Za-z_][A-Za-z0-9_]*. אין =, או שם לא חוקי ← SyntaxError עם מספר השורה (מ־1): ‏"שורה 2: ...".
  • הערך הוא מה שאחרי ה־= הראשון, אחרי trim. ב־= נוספים בתוך הערך לא נוגעים (‏postgres://...?sslmode=disable).
  • ערך במירכאות כפולות: מורידים אותן, ו־\n (שני תווים) הופך לשורה חדשה. במירכאות בודדות: מורידים אותן ותו לא. בלי מירכאות: # (רווח ואחריו סולמית) מתחיל הערה עד סוף השורה.
  • שם שמופיע פעמיים — הערך האחרון קובע.

🔗 איך זה מתחבר: קריאת קבצים מפרק 13 ו־Map/אובייקטים מפרק 7 — והשיעור: קובץ .env שליד compose.yaml.
