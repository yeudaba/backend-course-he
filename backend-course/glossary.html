פרק 0 — הכנה: המחשב, VS Code והרצה ראשונה

File (פַייל)
קובץ — מסמך אחד שנשמר במחשב
Folder / Directory (פוֹלְדֶר / דַיירֶקטוֹרִי)
תיקייה
Path (פַּאת׳)
נתיב — הכתובת של קובץ או תיקייה, מופרדת ב־/
~ (Home directory) (הוֹם)
תיקיית הבית: /Users/yeuda
Working directory (וֶורְקִינְג)
התיקייה שה־Terminal נמצא בה עכשיו (pwd)

סיומת קובץ (.js), וגם: תוסף ל־VS Code
Terminal (טֶרְמִינָל)
חלון שבו נותנים למחשב פקודות בכתב
Prompt (פְּרוֹמְפְּט)
הסימן % שמראה שה־Terminal מחכה. לא מקלידים אותו
Flag (פְלֶאג)
תוספת לפקודה שמתחילה במקף: -v, --version
Node.js (נוֹד)
סביבת ריצה ל־JavaScript מחוץ לדפדפן
npm (אֶן־פִּי־אֶם)
מנהל החבילות של Node
Output (אַאוּטְפּוּט)
פלט — מה שהתוכנית מדפיסה
SyntaxError (סִינְטַקְס אֶרוֹר)
שגיאת תחביר: הקוד לא חוקי, שום שורה לא רצה
ReferenceError (רֶפֶרֶנְס אֶרוֹר)
שימוש בשם שלא קיים; השורות שלפניו כבר רצו

פרק 1 — ערכים ומשתנים

Value (וַולְיוּ)
ערך — פיסת מידע אחת: 5, "שלום", true
Type (טַייפּ)
סוג הערך: מחרוזת, מספר, בוליאני...
String (סְטְרִינְג)
מחרוזת — טקסט בתוך מירכאות
Number (נַאמְבֶּר)
מספר — שלם או עשרוני, סוג אחד לכולם
Boolean (בּוּלִיאַן)
ערך אמת: true (אמת) או false (שקר)
typeof (טַייפּ־אוֹף)
אופרטור שמחזיר את שם הסוג של ערך
Comment (קוֹמֶנְט)
הערה — טקסט בקוד ש־Node מדלג עליו: //
Variable (וֶרִיאַבֶּל)
משתנה — שם שמצביע על ערך
Declaration (דֶקְלַרֵיישֶן)
הכרזה — יצירת המשתנה (let x)
Assignment (אַסַיינְמֶנְט)
השמה — הצבת ערך במשתנה עם =
const (קוֹנְסְט)
משתנה שאי אפשר להציב בו ערך חדש
let (לֶט)
משתנה שאפשר להציב בו ערך חדש
camelCase (קֶמֶל קֵייס)
מוסכמת שמות: מילה ראשונה קטנה, כל מילה אחריה באות גדולה: totalPrice
undefined (אַנְדִיפַיינְד)
"עוד לא קיבל ערך"
null (נַאל)
"ריק בכוונה"
TypeError (טַייפּ אֶרוֹר)
שגיאה בזמן ריצה: פעולה לא מתאימה לסוג/למשתנה (למשל שינוי const)

פרק 2 — פעולות ומחרוזות

Operator (אוֹפֶּרֵייטוֹר)
סימן פעולה: +, -, *, /, %
Expression (אֶקְסְפְּרֶשֶׁן)
ביטוי — כל קטע קוד שמחושב לערך: price * 2
Precedence (פְּרֶסִידֶנְס)
קדימות — איזו פעולה מחושבת קודם
Remainder (%) (רִימֵיינְדֶר)
שארית חלוקה: 7 % 3 הוא 1
Increment (אִינְקְרֶמֶנְט)
הגדלה ב־1: count++
Concatenation (קוֹנְקָטֵנֵיישֶׁן)
שרשור — חיבור מחרוזות
Template literal (טֶמְפְּלֵייט לִיטֶרַל)
מחרוזת בגרש הפוך שאפשר לשבץ בה ערכים עם ${...}
Method (מֶתוֹד)
פעולה שמחוברת לערך, נקראת עם נקודה וסוגריים: name.trim()
Property (פְּרוֹפֶּרְטִי)
תכונה של ערך, בלי סוגריים: name.length
Index (אִינְדֶקְס)
מיקום של תו (או איבר), מתחיל מ־0
NaN (נָאן)
Not a Number — תוצאה של חישוב/המרה שנכשלו
Type coercion (קוֹאֶרְשֶׁן)
המרה אוטומטית של סוג, למשל "5" * 2

פרק 3 — תנאים

Condition (קוֹנְדִישֶׁן)
תנאי — ביטוי שמחושב ל־true או false
Comparison operator (קוֹמְפֶּרִיזֶן)
סימן השוואה: ===, !==, <, >=...
Strict equality (===) (סְטְרִיקְט)
שוויון מחמיר — אותו ערך ואותו סוג
if / else (אִיף / אֶלְס)
"אם / אחרת" — בחירה איזה קוד ירוץ
Block (בְּלוֹק)
קטע קוד בתוך { }
Logical operators (לוֹגִ'יקַל)
&& (וגם), || (או), ! (לא)
Truth table (טְרוּת׳ טֵייבְּל)
טבלת אמת — כל הצירופים של true/false והתוצאה
Truthy / Falsy (טְרוּתִ'י / פוֹלְסִי)
ערך שמתנהג כמו true/false בתוך תנאי
Nullish coalescing (??) (נַאלִיש)
ערך ברירת מחדל רק כשהערך null או undefined
Ternary (טֶרְנֶרִי)
תנאי מקוצר: cond ? a : b
switch (סְוִויץ')
בחירה בין הרבה ערכים אפשריים של משתנה אחד
Guard clause (גַארְד קְלוֹז)
בדיקה בתחילת הקוד שעוצרת מוקדם כשהקלט לא תקין
Edge case (אֶדְג' קֵייס)
מקרה קצה — קלט גבולי (0, ריק, שלילי, בדיוק על הגבול)

פרק 4 — לולאות

Loop (לוּפּ)
לולאה — קוד שחוזר על עצמו
Iteration (אִיטֶרֵיישֶׁן)
סיבוב אחד של הלולאה
while (וַוייל)
"כל עוד" — חוזר כל עוד התנאי true
for (פוֹר)
לולאה עם אתחול, תנאי וצעד בשורה אחת
Counter (קַאוּנְטֶר)
מונה — משתנה שסופר סיבובים (בדרך כלל i)
Infinite loop (אִינְפִינִיט לוּפּ)
לולאה אינסופית — התנאי לעולם לא נהיה false
Accumulator (אָקְיוּמְיוּלֵייטוֹר)
צובר — משתנה שאוסף תוצאה לאורך הלולאה (סכום, ספירה)
break (בְּרֵייק)
יציאה מיידית מהלולאה
continue (קוֹנְטִינְיוּ)
דילוג לסיבוב הבא
Off-by-one (אוֹף־בַּיי־וָואן)
טעות של סיבוב אחד מיותר או חסר (< במקום <=)
for...of (פוֹר אוֹף)
לולאה שעוברת על כל איבר (כאן: כל תו במחרוזת)
Nested loop (נֶסְטֶד לוּפּ)
לולאה בתוך לולאה
Flag (פְלֶאג)
דגל — בוליאני שזוכר "האם קרה משהו" (למשל found)

פרק 5 — פונקציות

Function (פַאנְקְשֶׁן)
פונקציה — קוד עם שם שאפשר להפעיל שוב ושוב
Call / Invoke (קוֹל / אִינְווֹק)
קריאה — הפעלת פונקציה: greet()
Parameter (פָּרָמֶטֶר)
השם שמקבל ערך בהגדרת הפונקציה: function f(name)
Argument (אַרְגְיוּמֶנְט)
הערך שמעבירים בקריאה: f("דנה")
return (רִיטֶרְן)
החזרת ערך למי שקרא לפונקציה — וסיום הפונקציה
Default parameter (דִיפוֹלְט)
ערך לפרמטר אם לא הועבר ארגומנט
Guard clause (גַארְד קְלוֹז)
בדיקה בתחילת פונקציה שמחזירה מוקדם במקרה לא תקין
Arrow function (אָרוֹ פַאנְקְשֶׁן)
כתיב מקוצר: (x) => x * 2
Scope (סְקוֹפּ)
התחום שבו משתנה מוכר
Side effect (סַייד אֶפֶקְט)
תופעת לוואי — שינוי של משהו מחוץ לפונקציה (הדפסה, שינוי משתנה חיצוני, כתיבה למסד)
Pure function (פְּיוּר)
פונקציה טהורה — אותו קלט ← אותה תוצאה, בלי תופעות לוואי
Callback (קוֹלְבֶּק)
פונקציה שמעבירים לפונקציה אחרת כדי שתקרא לה
module.exports (מוֹדְיוּל אֶקְסְפּוֹרְטְס)
השורה שמאפשרת לקבצים אחרים (ולבודק) להשתמש בפונקציה — נלמד בפרק 8

פרק 6 — מערכים

Array (אַרֵיי)
מערך — רשימה מסודרת של ערכים: [10, 20, 30]
Element / Item (אֶלֶמֶנְט / אַייטֶם)
איבר — ערך אחד במערך
Index (אִינְדֶקְס)
מיקום של איבר, מתחיל מ־0
push / pop (פּוּש / פּוֹפּ)
הוספה / הסרה בסוף המערך
unshift / shift (אַנְשִׁיפְט / שִׁיפְט)
הוספה / הסרה בהתחלה
map (מֶאפּ)
מערך חדש שבו כל איבר עבר פונקציה
filter (פִילְטֶר)
מערך חדש רק עם האיברים שעברו בדיקה
find (פַיינְד)
האיבר הראשון שעובר בדיקה (או undefined)
some / every (סָאם / אֶבְרִי)
האם לפחות אחד / כולם עוברים בדיקה
reduce (רִידְיוּס)
"מכווץ" מערך לערך אחד (סכום, מקסימום...)
Comparator (קוֹמְפֶּרֵייטוֹר)
פונקציה שאומרת ל־sort מי לפני מי: (a, b) => a - b
Mutate (מְיוּטֵייט)
לשנות את המקור. push, sort, splice משנים; map, filter, slice לא
split / join (סְפְּלִיט / ג'וֹיְן)
מחרוזת ← מערך / מערך ← מחרוזת
Spread (...) (סְפְּרֶד)
"פריסה" של איברים: [...arr] יוצר עותק

פרק 7 — אובייקטים

Object (אוֹבְּיֶקְט)
אובייקט — אוסף של שדות עם שמות: { name: "דנה", age: 31 }
Property / Key (פְּרוֹפֶּרְטִי / קִי)
שדה / מפתח — השם של ערך בתוך אובייקט
Value (וַולְיוּ)
הערך של השדה
Dot notation (דוֹט)
גישה עם נקודה: user.name
Bracket notation (בְּרָאקֶט)
גישה עם סוגריים מרובעים: user["name"] או user[key]
Optional chaining (?.) (אוֹפְּשֶׁנַל צֵ'יינִינְג)
גישה בטוחה: a?.b מחזיר undefined במקום לקרוס
Reference (רֶפֶרֶנְס)
הפניה — משתנה שמצביע על אובייקט, לא מכיל עותק שלו
Shallow copy (שָׁאלוֹ)
עותק רדוד — רק הרמה הראשונה ({ ...obj })
Deep copy (דִיפּ)
עותק עמוק — הכול, כולל אובייקטים פנימיים (structuredClone)
Destructuring (דִיסְטְרַקְצֶ'רִינְג)
פירוק: const { name } = user;
JSON (ג'ֵייסוֹן)
פורמט טקסט לאובייקטים — השפה שבה שרתים מדברים
Map (מֶאפּ)
מבנה של מפתח ← ערך, עם חיפוש מהיר
Set (סֶט)
אוסף ערכים ייחודיים (בלי כפילויות)

פרק 8 — ארגון קוד ואיתור תקלות

Module (מוֹדְיוּל)
קובץ קוד שמייצא דברים לקבצים אחרים
export / import (אֶקְסְפּוֹרְט / אִימְפּוֹרְט)
ייצוא/ייבוא בתחביר המודרני (ES Modules)
module.exports / require (רִיקְוַוייר)
ייצוא/ייבוא בתחביר הישן של Node (CommonJS)
Exception (אֶקְסֶפְּשֶׁן)
חריגה — שגיאה שנזרקה ועוצרת את הזרימה הרגילה
throw (ת'רוֹאוּ)
זריקת שגיאה: throw new Error("...")
try / catch / finally (טְרַיי / קֶאץ' / פַיינָלִי)
ניסיון / טיפול בשגיאה / קוד שרץ בכל מקרה
Stack trace (סְטֶאק טְרֵייס)
רשימת הפונקציות שנקראו עד לשגיאה
Debugger (דִיבָּאגֶר)
כלי שעוצר את התוכנית ומאפשר להסתכל פנימה
Breakpoint (בְּרֵייקְפּוֹיְנְט)
נקודת עצירה — שורה שבה הדיבאגר עוצר
Step over / into (סְטֶפּ אוֹבֶר / אִינְטוּ)
התקדמות שורה אחת / כניסה לתוך פונקציה
Linter (לִינְטֶר)
כלי שבודק את הקוד בלי להריץ (ESLint)
Reproduce (רִיפְּרוֹדְיוּס)
לשחזר באג — לגרום לו לקרות שוב בכוונה

פרויקט 1 — מנהל הוצאות בשורת הפקודה

CLI (סִי־אֶל־אַיי)
Command Line Interface — תוכנה שמפעילים מה־Terminal
process.argv (פְּרוֹסֶס אַרְג־וִוי)
המילים שהוקלדו בפקודה, כמערך
Exit code (אֶגְזִיט קוֹד)
המספר שתוכנית מחזירה בסיום: 0 = הצלחה, אחר = כישלון
fs (אֶף־אֶס)
File System — המודול של Node לקבצים
Persistence (פֶּרְסִיסְטֶנְס)
שמירת מידע כך שיישאר אחרי שהתוכנית נסגרת
Separation of concerns (סֶפָּרֵיישֶׁן)
הפרדה: כל חלק בקוד אחראי על דבר אחד
README (רִיד־מִי)
קובץ שמסביר מה הפרויקט ואיך מפעילים אותו

פרק 9 — Git ו־GitHub

Version control (וֶרְשֶׁן קוֹנְטְרוֹל)
ניהול גרסאות — שמירת היסטוריה של כל שינוי
Repository (repo) (רִיפּוֹזִיטוֹרִי)
מאגר — תיקיית פרויקט ש־Git עוקב אחריה
Commit (קוֹמִיט)
"תמונת מצב" שמורה של הפרויקט, עם הודעה
Staging area (סְטֵייגִ'ינְג)
אזור ההכנה — מה שייכנס ל־commit הבא
Working directory (וֶורְקִינְג)
הקבצים כפי שהם עכשיו בתיקייה
Diff (דִיף)
ההבדלים בין שתי גרסאות
Branch (בְּרַאנְץ')
ענף — קו פיתוח נפרד
Merge (מֶרְג')
מיזוג — איחוד שינויים מענף אחד לאחר
Conflict (קוֹנְפְלִיקְט)
התנגשות — שני ענפים שינו את אותה שורה
Remote (רִימוֹט)
עותק של המאגר בשרת (GitHub)
push / pull (פּוּש / פּוּל)
שליחה לשרת / משיכה מהשרת
Clone (קְלוֹן)
הורדה של מאגר שלם מהשרת
Pull Request (PR) (פּוּל רִיקְוֶוסְט)
בקשה למזג ענף, עם סקירת קוד
HEAD (הֶד)
"אתה נמצא כאן" — ה־commit הנוכחי
.gitignore (גִיט־אִיגְנוֹר)
רשימת קבצים ש־Git לא יעקוב אחריהם

פרק 10 — אסינכרוניות

Synchronous (סִינְכְּרוֹנִי)
פעולה שהתוכנית מחכה לסופה לפני שממשיכה
Asynchronous (אָסִינְכְּרוֹנִי)
פעולה שמתחילה עכשיו ומסתיימת אחר כך, בלי לעצור את התוכנית
Event loop (אִיוֶונְט לוּפּ)
המנגנון של Node שמריץ callbacks כשהפעולות שלהם מסתיימות
Callback (קוֹלְבֶּק)

ממשק דפדפן לצפייה ועריכה של הנתונים

פרק 20 — NestJS

NestJS (נֶסְט)
Framework לשרתי Node ב־TypeScript, עם מבנה קבוע ו־DI
Decorator (דֶקוֹרֵייטוֹר)
@Something() מעל class/מתודה/פרמטר — מוסיף מידע ש־Nest קורא
Module (מוֹדְיוּל)
יחידה שמקבצת controllers ו־providers של תחום אחד
Controller (קוֹנְטְרוֹלֶר)
מחלקה עם routes — שכבת ה־HTTP
Provider (פְּרוֹבַיידֶר)
כל דבר ש־Nest יכול להזריק: service, repository, ערך, factory
Dependency Injection (דִיפֶּנְדֶנְסִי אִינְג'קְשֶׁן)
Nest יוצר את התלויות ומעביר אותן ב־constructor
Injection token (טוֹקֶן)
מזהה לתלות שאינה class: @Inject("CLOCK")
DTO (דִי־טִי־אוֹ)
Data Transfer Object — מחלקה שמתארת את הקלט, עם decorators של ולידציה
Pipe (פַּייפּ)
ממיר/בודק קלט לפני ה־handler (ParseIntPipe, ValidationPipe)
Guard (גַארְד)
מחליט אם הבקשה מורשית להמשיך (401/403)
Interceptor (אִינְטֶרְסֶפְּטוֹר)
עוטף את ה־handler: לפני ואחרי (זמנים, לוגים, שינוי תשובה)
Exception filter (פִילְטֶר)
תופס שגיאות וקובע את התשובה
Swagger / OpenAPI (סְוָוגֶר)
תיעוד API אוטומטי, עם ממשק לניסוי בדפדפן

פרק 21 — כניסה והרשאות

Authentication (אוֹתֶנְטִיקֵיישֶׁן)
אימות זהות — "מי אתה?" (כניסה). שגיאה: 401
Authorization (אוֹתוֹרִיזֵיישֶׁן)
הרשאה — "מה מותר לך?". שגיאה: 403 (או 404)
Hash (הָאשׁ)
פונקציה חד־כיוונית: מהסיסמה מקבלים מחרוזת, ומהמחרוזת אי אפשר לחזור לסיסמה
Salt (סוֹלְט)
ערך אקראי שמתווסף לסיסמה לפני ה־hash — שתי סיסמאות זהות נותנות hash שונה
bcrypt (בִּי־קְרִיפְּט)
אלגוריתם hash איטי בכוונה, לסיסמאות. כולל salt ו־cost
Cost / rounds (קוֹסְט)
כמה איטי ה־hash: כל +1 מכפיל את הזמן
JWT (ג'וֹט / ג'יי־דַבְּלְיוּ־טִי)
JSON Web Token: header.payload.signature — מידע חתום שהשרת יכול לבדוק בלי מסד
Bearer token (בֵּירֶר)
טוקן שמי שמחזיק בו — נכנס. נשלח ב־Authorization: Bearer ...
Access token (אַקְסֶס טוֹקֶן)
טוקן קצר־מועד (דקות) שנשלח בכל בקשה
Refresh token (רִיפְרֶשׁ טוֹקֶן)
טוקן ארוך־מועד (ימים), רק לקבלת access token חדש
Rotation (רוֹטֵיישֶׁן)
כל refresh token עובד פעם אחת ומוחלף בחדש
Role (רוֹל)
תפקיד (user, admin) שקובע מה מותר
IDOR / BOLA (אַיְי־דוֹר / בּוֹלָה)
גישה לאובייקט של משתמש אחר רק משינוי id. הפרצה מספר 1 ב־API
Mass assignment (מַאס אַסַיְינְמֶנְט)
שדה שהלקוח לא אמור לקבוע (role, ownerId) נכנס דרך גוף הבקשה
User enumeration (אִינוּמֶרֵיישֶׁן)
לגלות אילו אימיילים רשומים לפי הבדל בתשובה או בזמן
OWASP (אוֹ־וַואסְפּ)
ארגון שמפרסם את רשימות הפרצות הנפוצות והמלצות הגנה

פרק 22 — בדיקות

Unit test (יוּנִיט טֶסְט)
בדיקה של יחידה אחת (פונקציה, מחלקה) לבד, בלי מסד ורשת
Integration test (אִינְטֶגְרֵיישֶׁן)
בדיקה של הקוד שלך מול מערכת אמיתית (מסד, HTTP)
E2E test (אִי־טוּ־אִי)
End-to-end: כל השרשרת, כמו שמשתמש או לקוח משתמשים בה
Test pyramid (פִּירָמִידָה)
הרבה בדיקות unit מהירות, פחות integration, מעט e2e
AAA (אֵיי־אֵיי־אֵיי)
Arrange, Act, Assert — הכנה, פעולה, בדיקה
Assertion (אַסֶרְשֶׁן)
טענה שהבדיקה בודקת: assert.equal(actual, expected)
Test double (טֶסְט דַאבֶּל)
"כפיל" — משהו שמחליף תלות אמיתית בבדיקה
Stub (סְטַאבּ)
כפיל שמחזיר תשובה קבועה
Fake (פֵייק)
מימוש אמיתי ופשוט (למשל repository בזיכרון)
Spy / Mock (סְפַּיי / מוֹק)
כפיל שמקליט קריאות (mock.fn / jest.fn), ובודקים מה נקרא
Fixture / Builder (פִיקְסְצֶ'ר / בִּילְדֶר)
נתוני בדיקה מוכנים, או פונקציה שיוצרת אותם
Flaky test (פְלֵייקִי)
בדיקה שלפעמים עוברת ולפעמים לא, בלי שהקוד השתנה
Coverage (קַאבְרֶג')
אילו שורות/ענפים רצו בזמן הבדיקות
Mutation testing (מְיוּטֵיישֶׁן)
מכניסים באגים קטנים לקוד ובודקים שהבדיקות נכשלות
Regression (רֶגְרֶשֶׁן)
באג שחוזר אחרי שתוקן — לכן כותבים בדיקה עם התיקון
