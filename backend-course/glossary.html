פרק 7 — אובייקטים

JSON (ג'ֵייסוֹן)
פורמט טקסט לאובייקטים — השפה שבה שרתים מדברים
Map (מֶאפּ)

Set (סֶט)

יחידה 19.5 — MySQL: מה שונה מ־PostgreSQL

MySQL (מַיי־אֶס־קְיוּ־אֶל)
מסד נתונים רלציוני פתוח, הנפוץ בעולם; היום של Oracle (ו־MariaDB — fork שלו)
InnoDB (אִינוֹ־דִי־בִּי)
מנוע האחסון של MySQL: טרנזקציות, נעילות שורה, מפתחות זרים
AUTO_INCREMENT (אוֹטוֹ־אִינְקְרֶמֶנְט)
מספור אוטומטי של מפתח ראשי (ב־PostgreSQL: IDENTITY)
Collation (קוֹלֵיישֶׁן)
כללי השוואה ומיון של טקסט — רגיש לרישיות? לניקוד? לרווחים?
utf8mb4 (יוּ־טִי־אֶף־8־אֶם־בִּי־4)
UTF-8 מלא (עד 4 בתים לתו, כולל אמוג׳י). utf8 של MySQL הוא רק עד 3
sql_mode (אֶס־קְיוּ־אֶל מוֹד)
הגדרות שקובעות כמה MySQL מחמיר: STRICT, ONLY_FULL_GROUP_BY…
REPEATABLE READ (רִיפִּיטַבְּל רִיד)
רמת הבידוד ברירת המחדל ב־InnoDB: קריאה רגילה רואה תמונה קבועה מתחילת הטרנזקציה
Locking read (לוֹקִינְג רִיד)
SELECT … FOR UPDATE / FOR SHARE — קורא את הגרסה האחרונה ונועל
SKIP LOCKED (סְקִיפּ לוֹקְד)
מדלג על שורות נעולות במקום לחכות — לתורי עבודות
Deadlock (דֶדְלוֹק)
שתי טרנזקציות שכל אחת מחכה לנעילה של השנייה; InnoDB מבטל אחת (errno 1213)
Clustered index (קְלַאסְטֶרְד אִינְדֶקְס)
ב־InnoDB הטבלה עצמה ממוינת לפי המפתח הראשי
ON DUPLICATE KEY UPDATE (אוֹן דוּפְּלִיקֵייט קִי אַפְּדֵייט)
ה־upsert של MySQL
affectedRows / changedRows (אֲפֶקְטֶד רוֹאוּז)
כמה שורות התאימו ל־WHERE / כמה באמת השתנו
Implicit commit (אִימְפְּלִיסִיט קוֹמִיט)
DDL (CREATE/ALTER) מסיים את הטרנזקציה הפתוחה — אין rollback ל־migration

פרק 20 — NestJS

NestJS (נֶסְט)
Framework לשרתי Node ב־TypeScript, עם מבנה קבוע ו־DI
Decorator (דֶקוֹרֵייטוֹר)
@Something() מעל class/מתודה/פרמטר — מוסיף מידע ש־Nest קורא
Module (מוֹדְיוּל)
יחידה שמקבצת controllers ו־providers של תחום אחד
Controller (קוֹנְטְרוֹלֶר)
מחלקה עם routes — שכבת ה־HTTP
Provider (פְּרוֹבַיידֶר)
כל דבר ש־Nest יכול להזריק: service, repository, ערך, factory
Dependency Injection (דִיפֶּנְדֶנְסִי אִינְג'קְשֶׁן)
Nest יוצר את התלויות ומעביר אותן ב־constructor
Injection token (טוֹקֶן)
מזהה לתלות שאינה class: @Inject("CLOCK")
DTO (דִי־טִי־אוֹ)
Data Transfer Object — מחלקה שמתארת את הקלט, עם decorators של ולידציה
Pipe (פַּייפּ)
ממיר/בודק קלט לפני ה־handler (ParseIntPipe, ValidationPipe)
Guard (גַארְד)
מחליט אם הבקשה מורשית להמשיך (401/403)
Interceptor (אִינְטֶרְסֶפְּטוֹר)
עוטף את ה־handler: לפני ואחרי (זמנים, לוגים, שינוי תשובה)
Exception filter (פִילְטֶר)
תופס שגיאות וקובע את התשובה
Swagger / OpenAPI (סְוָוגֶר)
תיעוד API אוטומטי, עם ממשק לניסוי בדפדפן

פרק 21 — כניסה והרשאות

Authentication (אוֹתֶנְטִיקֵיישֶׁן)
אימות זהות — "מי אתה?" (כניסה). שגיאה: 401
Authorization (אוֹתוֹרִיזֵיישֶׁן)
הרשאה — "מה מותר לך?". שגיאה: 403 (או 404)
Hash (הָאשׁ)
פונקציה חד־כיוונית: מהסיסמה מקבלים מחרוזת, ומהמחרוזת אי אפשר לחזור לסיסמה
Salt (סוֹלְט)
ערך אקראי שמתווסף לסיסמה לפני ה־hash — שתי סיסמאות זהות נותנות hash שונה
bcrypt (בִּי־קְרִיפְּט)
אלגוריתם hash איטי בכוונה, לסיסמאות. כולל salt ו־cost
Cost / rounds (קוֹסְט)
כמה איטי ה־hash: כל +1 מכפיל את הזמן
JWT (ג'וֹט / ג'יי־דַבְּלְיוּ־טִי)
JSON Web Token: header.payload.signature — מידע חתום שהשרת יכול לבדוק בלי מסד
Bearer token (בֵּירֶר)
טוקן שמי שמחזיק בו — נכנס. נשלח ב־Authorization: Bearer ...
Access token (אַקְסֶס טוֹקֶן)
טוקן קצר־מועד (דקות) שנשלח בכל בקשה
Refresh token (רִיפְרֶשׁ טוֹקֶן)
טוקן ארוך־מועד (ימים), רק לקבלת access token חדש
Rotation (רוֹטֵיישֶׁן)
כל refresh token עובד פעם אחת ומוחלף בחדש
Role (רוֹל)
תפקיד (user, admin) שקובע מה מותר
IDOR / BOLA (אַיְי־דוֹר / בּוֹלָה)
גישה לאובייקט של משתמש אחר רק משינוי id. הפרצה מספר 1 ב־API
Mass assignment (מַאס אַסַיְינְמֶנְט)
שדה שהלקוח לא אמור לקבוע (role, ownerId) נכנס דרך גוף הבקשה
User enumeration (אִינוּמֶרֵיישֶׁן)
לגלות אילו אימיילים רשומים לפי הבדל בתשובה או בזמן
OWASP (אוֹ־וַואסְפּ)
ארגון שמפרסם את רשימות הפרצות הנפוצות והמלצות הגנה

פרק 22 — בדיקות

Unit test (יוּנִיט טֶסְט)
בדיקה של יחידה אחת (פונקציה, מחלקה) לבד, בלי מסד ורשת
Integration test (אִינְטֶגְרֵיישֶׁן)
בדיקה של הקוד שלך מול מערכת אמיתית (מסד, HTTP)
E2E test (אִי־טוּ־אִי)
End-to-end: כל השרשרת, כמו שמשתמש או לקוח משתמשים בה
Test pyramid (פִּירָמִידָה)
הרבה בדיקות unit מהירות, פחות integration, מעט e2e
AAA (אֵיי־אֵיי־אֵיי)
Arrange, Act, Assert — הכנה, פעולה, בדיקה
Assertion (אַסֶרְשֶׁן)
טענה שהבדיקה בודקת: assert.equal(actual, expected)
Test double (טֶסְט דַאבֶּל)
"כפיל" — משהו שמחליף תלות אמיתית בבדיקה
Stub (סְטַאבּ)
כפיל שמחזיר תשובה קבועה
Fake (פֵייק)
מימוש אמיתי ופשוט (למשל repository בזיכרון)
Spy / Mock (סְפַּיי / מוֹק)
כפיל שמקליט קריאות (mock.fn / jest.fn), ובודקים מה נקרא
Fixture / Builder (פִיקְסְצֶ'ר / בִּילְדֶר)
נתוני בדיקה מוכנים, או פונקציה שיוצרת אותם
Flaky test (פְלֵייקִי)
בדיקה שלפעמים עוברת ולפעמים לא, בלי שהקוד השתנה
Coverage (קַאבְרֶג')
אילו שורות/ענפים רצו בזמן הבדיקות
Mutation testing (מְיוּטֵיישֶׁן)
מכניסים באגים קטנים לקוד ובודקים שהבדיקות נכשלות
Regression (רֶגְרֶשֶׁן)
באג שחוזר אחרי שתוקן — לכן כותבים בדיקה עם התיקון

פרק 23 — Linux ו־Docker

Shell / bash / zsh (שֶׁל)
התוכנה שמפרשת את מה שמקלידים בטרמינל. ב־Mac: zsh; בשרתים ובסקריפטים: bash
Pipe (פַּייפּ)
| — הפלט של פקודה אחת הוא הקלט של הבאה
stdout / stderr (סְטַנְדַּרְט אַאוּט / אֶרוֹר)
שני ערוצי פלט: תוצאות, והודעות שגיאה
Exit code (אֶגְזִיט קוֹד)
המספר שתהליך מחזיר: 0 = הצלחה, כל דבר אחר = כישלון
Permissions (פֶּרְמִישֶׁנְס)
rwx לבעלים, לקבוצה ולאחרים (chmod 644, 755, 600)
Process / PID (פְּרוֹסֶס)
תוכנה שרצה, ומספר הזיהוי שלה
Signal (SIGTERM) (סִיגְנַל)
הודעה לתהליך: SIGTERM — "תסגור יפה"; SIGKILL — מיד, בלי לשאול
Image (אִימָג')
תבנית קבועה: מערכת קבצים + הגדרות. נבנה מ־Dockerfile
Container (קוֹנְטֵיינֶר)
מופע רץ של image, מבודד מהמחשב
Layer (לֵייֶר)
שכבה ב־image — כל הוראה ב־Dockerfile; נשמרת ב־cache
Volume (ווֹלְיוּם)
אחסון ששורד מחיקה של קונטיינר — שם גרים הנתונים
Bind mount (בַּיינְד מַאוּנְט)
תיקייה מהמחשב שמחוברת לתוך קונטיינר
Registry (רֶגִ'יסְטְרִי)
שרת שמאחסן images (Docker Hub, GHCR)
Multi-stage build (מוּלְטִי־סְטֵייג')
Dockerfile עם כמה FROM: בונים באחד, מעתיקים רק את התוצאה לאחרון
Docker Compose (קוֹמְפּוֹז)
קובץ YAML שמתאר כמה שירותים יחד, ומעלה אותם בפקודה אחת
Healthcheck (הֶלְתְ'צֶ'ק)
בדיקה תקופתית שאומרת אם השירות באמת מוכן

פרק 24 — מוכן לפרודקשן: לוגים, זמן, Idempotency והגבלת קצב

Structured logging (סְטְרַקְצֶ'רְד לוֹגִינְג)
לוג שכל שורה בו היא אובייקט (JSON) עם שדות — לא משפט חופשי
Log level (לוֹג לֶבֶל)
debug / info / warn / error — כמה חשובה השורה, ומה נכתב בכל סביבה
Request ID / Correlation ID (רִיקְוֶוסְט אַיי־דִי)
מזהה ייחודי לבקשה, שמופיע ב־header ובכל שורת לוג שלה
Redaction (רִידַקְשֶׁן)
הסתרת ערכים רגישים (סיסמאות, טוקנים) לפני שהם נכתבים
AsyncLocalStorage (אֵסִינְק לוֹקָל סְטוֹרֶג')
"משתנה" ששייך לבקשה הנוכחית ועובר דרך await — מ־node:async_hooks
Instant (אִינְסְטַנְט)
רגע אחד בזמן, זהה בכל העולם (Date, timestamptz)
Time zone (IANA) (טַיים זוֹן)
אזור עם חוקי שעון: Asia/Jerusalem. לא offset קבוע
UTC offset (אוֹפְסֶט)
ההפרש מ־UTC ברגע מסוים: +02:00 בחורף בישראל, +03:00 בקיץ
DST (דִי־אֶס־טִי)
Daylight Saving Time — שעון קיץ: יום של 23 שעות ויום של 25
Idempotent (אִידֶמְפּוֹטֶנְט)
פעולה שביצוע שלה פעם אחת או כמה פעמים משאיר אותו מצב
Idempotency-Key (אִידֶמְפּוֹטֶנְסִי קִי)
header עם מזהה של פעולה — השרת מבצע אותה פעם אחת, ובניסיון חוזר מחזיר את אותה תשובה
Race condition (רֵייס קוֹנְדִישֶׁן)
באג שתלוי בסדר שבו שתי פעולות במקביל מתבצעות
Rate limiting (רֵייט לִימִיטִינְג)
הגבלת מספר הבקשות של לקוח בפרק זמן; מעבר — 429
Token bucket (טוֹקֶן בָּאקֶט)
אלגוריתם הגבלה שמאפשר פרץ קצר ושומר על קצב ממוצע
Graceful shutdown (גְרֵייסְפוּל שַׁאטְדָאוּן)
כיבוי שמסיים את הבקשות שבאמצע, ורק אז סוגר משאבים
Readiness / Liveness (רֵדִינֶס / לַייבְנֶס)
"מוכן לקבל תנועה" מול "התהליך חי" — שתי בדיקות שונות

פרק 25 — CI ופריסה: מהמחשב שלך לכתובת חיה

CI (Continuous Integration) (סִי־אַיי)
שרת שמריץ build ובדיקות על כל push ו־pull request, בסביבה נקייה
CD (Delivery / Deployment) (סִי־דִי)
Delivery: כל commit מוכן לעלות. Deployment: עולה לבד
Workflow (וֶורְקְפְלוֹ)
קובץ YAML ב־.github/workflows: מתי לרוץ, ואילו jobs
Job / Step / Runner (ג'וֹבּ / סְטֶפּ / רָאנֶר)
job = רצף צעדים על מכונה אחת (runner); jobs רצים במקביל אלא אם יש needs
Action (אַקְשֶׁן)
צעד מוכן לשימוש חוזר (actions/checkout@v5)
Service container (סֶרְוִויס קוֹנְטֵיינֶר)
קונטיינר שרץ ליד ה־job — למשל PostgreSQL לבדיקות
Secret / Variable (סִיקְרֶט / וֶרִיאַבְּל)
ערך מוצפן שלא מוצג בלוגים / הגדרה גלויה, שתיהן מחוץ לקוד
Deploy hook (דִיפְּלוֹי הוּק)
כתובת סודית שקריאה אליה מפעילה deploy בפלטפורמה
Smoke test (סְמוֹק טֶסְט)
בדיקה קצרה אחרי deploy: הגרסה הנכונה רצה ועונה
Rollback (רוֹלְבֶּק)
חזרה לגרסה הקודמת שעבדה
Blue/green (בְּלוּ/גְרִין)
שתי סביבות: מעלים את החדשה ליד הישנה, בודקים, ורק אז מעבירים תנועה
Expand/contract (אֶקְסְפֶּנְד/קוֹנְטְרַקְט)
שינוי סכמה בשלבים, כך ששתי הגרסאות עובדות מול המסד בזמן ה־deploy
TLS termination (טִי־אֶל־אֶס טֶרְמִינֵיישֶׁן)
ה־HTTPS "נגמר" ב־proxy, והוא מעביר HTTP לשרת
Reverse proxy (רִיוֶורְס פְּרוֹקְסִי)
שרת שמקבל בקשות מבחוץ ומעביר לאפליקציה (Caddy, nginx, load balancer)
HSTS (אֵייץ'־אֶס־טִי־אֶס)
header שאומר לדפדפן: לאתר הזה — רק HTTPS
Cold start (קוֹלְד סְטַארְט)
הבקשה הראשונה לשרת "ישן" — מחכה שהוא יעלה

פרויקט 3 — פרויקט הדגל: חנות ציוד קפה

Snapshot (price) (סְנַפְּשׁוֹט)
שמירת המחיר והשם בשורת ההזמנה — היסטוריה לא משתנה
Conditional update (קוֹנְדִישְׁנַל אַפְּדֵייט)
UPDATE ... WHERE stock >= n — בדיקה ושינוי בפעולה אטומית אחת
Lost update (לוֹסְט אַפְּדֵייט)
שתי פעולות קוראות אותו ערך, וכל אחת כותבת על השנייה
State machine (סְטֵייט מָשִׁין)
רשימת המצבים והמעברים המותרים ביניהם
Soft delete (סוֹפְט דִילִיט)
סימון "לא פעיל" במקום מחיקה — כדי שהיסטוריה לא תישבר
Black-box test (בְּלֶק בּוֹקְס)
בדיקה שמכירה רק את החוזה (HTTP), לא את הקוד

יחידה 25.5 — ענן ו־Kubernetes: AWS, Kubernetes, Helm, Jenkins ו־Argo CD

AWS (אֵיי־דַבְּלְיוּ־אֶס)
Amazon Web Services — ספק הענן הגדול בעולם
Region / AZ (רִיגְ׳ן / אֵיי־זִי)
אזור גאוגרפי (eu-central-1) / מרכז נתונים נפרד בתוכו
IAM (אַיי־אֶם)
ניהול זהויות והרשאות ב־AWS: users, roles, policies
Role (רוֹל)
זהות בלי סיסמה קבועה, ששירות "לובש" ומקבל credentials זמניים
ARN (אַרְן)
המזהה הייחודי של משאב ב־AWS: arn:aws:s3:::bucket/key

אחסון אובייקטים: bucket + key ← קובץ

פרק 27 — אלגוריתמים וראיונות

Time complexity (טַיְים קוֹמְפְּלֶקְסִיטִי)
כמה העבודה גדלה כשהקלט גדל
Big-O (בִּיג אוֹ)
סימון לקצב הגדילה במקרה הגרוע: O(1), O(log n), O(n), O(n log n), O(n²)
Space complexity (סְפֵּייס קוֹמְפְּלֶקְסִיטִי)
כמה זיכרון נוסף האלגוריתם צריך
Hash map / Hash set (הֶאשׁ מֶאפּ / הֶאשׁ סֶט)
Map / Set: חיפוש, הוספה ומחיקה ב־O(1) בממוצע
Two pointers / Sliding window (טוּ פּוֹיְנְטֶרְס / סְלַיְידִינְג וִינְדוֹאוּ)
שני אינדקסים שזזים באותו כיוון — O(n) במקום O(n²)
Stack / Queue (סְטֶאק / קְיוּ)
LIFO — האחרון יוצא ראשון / FIFO — הראשון יוצא ראשון
Binary search (בַּיְינֶרִי סֶרְץ')
חציית הטווח בכל צעד, על נתונים ממוינים — O(log n)
Graph / BFS / DFS (גְרָף / בִּי־אֶף־אֶס / דִי־אֶף־אֶס)
צמתים וקשתות; סריקה לרוחב (הקצר) / לעומק
Topological sort (טוֹפּוֹלוֹגִ'יקַל סוֹרְט)
סדר שבו כל צומת בא אחרי מה שהוא תלוי בו
Recursion (רִיקֶרְז'ְן)
פונקציה שקוראת לעצמה על בעיה קטנה יותר, עד מקרה בסיס
Dynamic programming (דַיְנָמִיק פְּרוֹגְרָמִינְג)
פתרון שבונה תשובה מתשובות לתתי־בעיות, כל אחת מחושבת פעם אחת
Heap / Priority queue (הִיפּ / פְּרָיוֹרִיטִי קְיוּ)
מבנה שמוציא תמיד את המינימום (או המקסימום) ב־O(log n)
Trie (טְרַיי)
עץ של אותיות — חיפוש לפי prefix
Edge case (אֶדְג' קֵייס)
מקרה קצה: ריק, אחד, הכול זהה, ענק, שלילי
Brute force (בְּרוּט פוֹרְס)
הפתרון הישיר שבודק הכול — נקודת התחלה טובה בראיון
Window function (וִינְדוֹאוּ פַאנְקְשֶׁן)
SQL: חישוב על "חלון" של שורות (ROW_NUMBER() OVER …)
