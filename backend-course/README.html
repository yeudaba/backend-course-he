🎯 איך משתמשים בקורס
  1. מתחילים תמיד בקופסת 🧰 "לפני שמתחילים" שבראש כל פרק — שם כתוב מה להתקין ומה להעתיק.
  2. קוראים שיעור, ופותרים את התרגילים הקצרים שבסופו לפני שממשיכים לשיעור הבא.
  3. בסוף הפרק פותרים את דף התרגילים. דף הפתרונות נפרד — פותחים אותו רק אחרי ניסיון אמיתי.
  4. נתקעת? רמז 1 ← רמז 2 ← פתרון. ואם עדיין לא — שלח לי את הקוד ואת הודעת השגיאה.
  5. פרקים עם ⚡ הם פרקי רענון: יש בהם מבחן כניסה שמאפשר לדלג על רוב ההסברים.
