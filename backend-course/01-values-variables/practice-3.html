P01-E05 · undefined או null?

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 3

לכל מצב, כתוב אם הערך המתאים הוא undefined או null, ולמה:

  1. יצרת let total; ועוד לא חישבת כלום.

  4. טעית בשם משתנה בתוך אובייקט (נלמד בפרק 7) ולכן לא נמצא ערך.

P01-E53 · var לעומת let — נבא

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 3

שתי תוכניות שנבדלות רק במילה אחת. מה ידפיס כל אחת?

// תוכנית א
console.log(x);
var x = 3;
console.log(x);
// תוכנית ב
console.log(y);
let y = 3;
console.log(y);

איזו התנהגות עדיפה לך כמתכנת, ולמה?

P01-E54 · באג שקט: NaN

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: שיעור 3

והפלט: לתשלום: NaN. (NaN = Not a Number, "לא מספר" — נכיר אותו בפרק 2.)

הסבר במילים: מה יש ב־discount ברגע החישוב, למה התוצאה היא לא מספר, ומה הערך הנכון ל־discount כשאין הנחה — 0, null, או להשאיר כמו שהוא?

P01-E61 · למה let בלי ערך מותר, ו־const לא?

🧠 הבנהרמה 3⏱ 5 דק׳ידע נדרש: שיעורים 2–3

השורה הראשונה תקינה, והשנייה נותנת שגיאה עוד לפני שמשהו רץ:

let total;
const tax;
SyntaxError: Missing initializer in const declaration

הסבר במילים שלך: למה JavaScript מתעקשת על ערך ב־const, ולא ב־let? (רמז: מה היה קורה ל־tax אחר כך, לו זה היה מותר?)

🔗 איך זה מתחבר: בשיעור 2 למדת ש־const אי אפשר להציב בו ערך חדש. בשיעור 3 למדת שמשתנה בלי ערך מקבל undefined. חבר את שני החוקים — והשגיאה הזו נהיית הגיונית לגמרי.

P01-E62 · טבלת מעקב על כל הפרק

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: שיעורים 1–3

מלא טבלת מעקב (status, userName, points, פלט) וכתוב את הפלט המלא — בלי להריץ:

let status;
const userName = "רון";
console.log(userName, status);
status = null;
console.log(typeof status, typeof userName);
let points = 0;
points = points + 10;
status = "פעיל";
console.log(status, points, typeof points);
console.log("points", typeof "points");

🔗 איך זה מתחבר: כל שורה כאן היא משיעור אחר: typeof ומירכאות (שיעור 1), let/const והצבה (שיעור 2), undefined ו־null (שיעור 3). טבלת מעקב היא הכלי שמחבר את כולם — וככה תקרא קוד גם בפרקים הבאים.

P01-E63 · ביקורת קוד: מה לא בסדר כאן?

🧠 הבנהרמה 4⏱ 10 דק׳ידע נדרש: כל הפרק

חבר לצוות ביקש שתעבור על הקוד שלו לפני שהוא נכנס למערכת. הקוד רץ — אבל יש בו לפחות שש בעיות של סגנון וכוונה. מצא אותן, הסבר כל אחת במשפט, והצע קוד מתוקן:

var shop_name = "פרחי הגליל";
let deliveryCity = "צפת";
const IsOpen = true;
let x = 0;          // x = מספר ההזמנות
x = x + 1;
let phone = "null"; // הלקוח לא נתן טלפון
let note = undefined;
console.log(shop_name, deliveryCity, IsOpen, x, phone, note);

🔗 איך זה מתחבר: זה סיכום של כל הפרק בעיניים של מתכנת אחר: שמות ו־const/let (שיעור 2), הערות טובות (שיעור 1), var, null ו־undefined (שיעור 3). ביקורת קוד (code review) היא חלק קבוע מהעבודה — וכאן אתה מתאמן עליה.

P01-E23 · שדרוג קוד ישן 🤖

💻 כתיבת קוד 🤖רמה 4⏱ 15 דק׳ידע נדרש: שיעורים 2–3

  • בלי var: const לכל מה שלא משתנה, let רק למה שמשתנה.

  • חישוב ההכנסות בלי לכתוב את bookPrice שלוש פעמים — אפשר להשתמש ב־bookPrice * booksSold (* = כפל; נלמד בפרק 2).
