על let: בתוך התוכנית הזו שום ערך לא משתנה — לכן const. במערכת אמיתית הנתונים משתנים (מספר ההזמנות עולה), אבל זה קורה במסד הנתונים, ובקוד בדרך כלל יוצרים משתנה חדש עם הערך המעודכן. נראה את זה בפרק 7.

⚠️ טעויות נפוצות
  • לסמן הכול let "ליתר ביטחון". let מספר לקורא "שים לב, זה ישתנה" — ואם לא, זה מטעה.

P01-E17 · const או let? 💻 כתיבת קוד רמה 3

💡 רמז 1

השאלה היחידה: האם יהיה צורך בשורה עם שם = ערך חדש?

💡 רמז 2

שים לב להבדל בין 4 ל־5.

✅ פתרון
  1. const — לא משתנה.
  2. let — גדל בכל הוספה.
  3. const — קבוע (אם המע״מ ישתנה בחוק, משנים את הקוד, לא בזמן ריצה).
  4. const — מחושב פעם אחת, בשורה אחת.
  5. let — מתעדכן שוב ושוב.
  6. let — מצב שמשתנה.
⚠️ טעויות נפוצות
  • לחשוב ש"סכום" תמיד let. מה שקובע הוא אם מציבים בו שוב — לא מה המשמעות שלו.

P01-E22 · באג בלי שגיאה 🤖 💻 כתיבת קוד 🤖 רמה 4

P01-E21 · שתי שגיאות, סדר נכון 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

חזור לפרק 0: מה ההבדל בין SyntaxError לבין שגיאה בזמן ריצה?

💡 רמז 2

הסבב השני: קוד רץ מלמעלה למטה — מתי נוצר customerName?

✅ פתרון

סבב 1: SyntaxError: Identifier 'deliveryFee' has already been declared בשורה 6. תיקון: deliveryFee = 0; (בלי let).

סבב 2: ReferenceError: Cannot access 'customerName' before initialization בשורה 2. תיקון: להזיז את ההגדרה מעל ההדפסה.

// P01-E21: יש כאן שתי שגיאות. תקן אחת בכל פעם, לפי ההודעה.
const customerName = "אורי";
console.log("משלוח ל:", customerName);

let deliveryFee = 25;
deliveryFee = 0;
console.log("דמי משלוח:", deliveryFee);
משלוח ל: אורי
דמי משלוח: 0

למה שורה 6 דווחה קודם: Node בודק את התחביר של כל הקובץ לפני שהוא מריץ שורה אחת. הכרזה כפולה היא שגיאת תחביר, ולכן נתפסה לפני ההרצה. השימוש ב־customerName לפני ההגדרה הוא שגיאה בזמן ריצה — נתפסת רק כשמגיעים אליה.

⚠️ טעויות נפוצות
  • למחוק את השורה let deliveryFee = 25; — עובד, אבל עדיף להבין שהבעיה היא ה־let השני.
חזרהתרגול שיעור 2הבאשיעור 3 — undefined, null, ומה עם var
