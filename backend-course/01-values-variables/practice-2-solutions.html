P01-E17 · const או let? 🧠 הבנה רמה 3

💡 רמז 1

השאלה היחידה: האם יהיה צורך בשורה עם שם = ערך חדש?

💡 רמז 2

שים לב להבדל בין 4 ל־5.

✅ פתרון
  1. const — לא משתנה.
  2. let — גדל בכל הוספה.
  3. const — קבוע (אם המע״מ ישתנה בחוק, משנים את הקוד, לא בזמן ריצה).
  4. const — מחושב פעם אחת, בשורה אחת.
  5. let — מתעדכן שוב ושוב.
  6. let — מצב שמשתנה.
⚠️ טעויות נפוצות
  • לחשוב ש"סכום" תמיד let. מה שקובע הוא אם מציבים בו שוב — לא מה המשמעות שלו.

P01-E45 · ארבע דרכים להגדיל מונה 🧠 הבנה רמה 2

💡 רמז 1

שתיים נותנות SyntaxError, אחת רצה בלי שגיאה אבל לא עושה כלום, ואחת נכונה.

💡 רמז 2

ב־ב: החשבון קורה — אבל לאן הולכת התוצאה? ב־ד: מה צריך להיות בצד שמאל של =?

✅ פתרון
  • א — SyntaxError: Identifier 'count' has already been declared. את let כותבים רק בפעם הראשונה; כאן יצרנו את count פעם שנייה.
  • ב — אין שגיאה, ומודפס 0. JavaScript חישבה 1 — ו"זרקה" אותו, כי לא אמרנו לשים אותו בשום קופסה.
  • ג — נכונה. מודפס 1.
  • ד — SyntaxError: Invalid left-hand side in assignment. בצד שמאל של = חייב להיות שם של קופסה, ו־count + 1 הוא חשבון, לא קופסה.
let count = 0;
count + 1;
console.log(count);
count = count + 1;
console.log(count);
0
1
⚠️ טעויות נפוצות
  • לחשוב ש־count + 1; מגדיל את count. בלי = שום קופסה לא משתנה.
  • לקרוא את = כמו "שווה" במתמטיקה, שבו אפשר להחליף צדדים. כאן הכיוון קבוע: הערך מימין נכנס לקופסה משמאל.
