P01-E05 · undefined או null? 🧠 הבנה רמה 1

💡 רמז 1

שאל: מי שם את הערך — JavaScript, או המתכנת בכוונה?

💡 רמז 2

"בכוונה" = null.

✅ פתרון
  1. undefined — JavaScript שמה אותו כי עוד לא נתת ערך.
  2. null — החלטה מפורשת: אין ערך.
  3. null — המתכנת מסמן במפורש "אין שליח כרגע".
  4. undefined — לא החלטת על כלום; זה סימן לבאג.
⚠️ טעויות נפוצות
  • להשתמש ב־undefined בכוונה כדי לסמן "ריק". מוסכמה: אנחנו כותבים null, ו־undefined משאירים לשפה.

P01-E12 · טלפון לא חובה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

"בחרה לא למסור" — החלטה מכוונת. איזה מהשניים?

💡 רמז 2

const phone = null;

✅ פתרון
01-values-variables/starter/P01-E12.js 
const userName = "תמר";
const phone = null;

console.log("שם:", userName);
console.log("טלפון:", phone);
console.log("יש טלפון?", false);
שם: תמר
טלפון: null
יש טלפון? false
⚠️ טעויות נפוצות
  • const phone = "null"; — זו מחרוזת עם המילה null, לא הערך null.
  • const phone = ""; — מחרוזת ריקה היא ערך (טלפון ריק), לא "אין ערך". במערכות אמיתיות מבדילים בין השניים.

P01-E19 · הבלש של undefined 💻 כתיבת קוד רמה 3

💡 רמז 1

ל־city אין ערך עד שורה 7 בקוד. zip קיבל ערך — איזה?

💡 רמז 2

זכור את "המוזרות הידועה" משיעור 3.

✅ פתרון
let city;
const zip = null;
console.log(city);
console.log(zip);
console.log(typeof city);
console.log(typeof zip);
city = "חיפה";
console.log(city, typeof city);
console.log("city");
undefined
null
undefined
object
חיפה string
city

שורה 4 של הפלט היא object — המוזרות של typeof null. ושורה אחרונה: במירכאות — המילה עצמה, לא הערך.

⚠️ טעויות נפוצות
  • לענות null ל־typeof zip.

P01-E27 · חיישן טמפרטורה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

משתנה שמשנים את הערך שלו — const או let? ומה יש במשתנה שהוגדר בלי =?

ואיזה מהשניים — undefined או null — אומר "אין ערך, בכוונה"?

💡 רמז 2

שורה ראשונה: let temperature;, ומיד אחריה הדפסה. אחר כך temperature = 24; והדפסה.

✅ פתרון
01-values-variables/starter/P01-E27.js 
let temperature;
console.log("טמפרטורה:", temperature);

temperature = 24;
console.log("טמפרטורה:", temperature);

temperature = null; // החיישן נותק — "אין ערך", בכוונה
console.log("טמפרטורה:", temperature);
טמפרטורה: undefined
טמפרטורה: 24
טמפרטורה: null

שלושת השלבים הם שלושת המצבים משיעור 3: undefined — JavaScript שמה כי עוד לא נתנו ערך; מספר — ערך רגיל; null — אנחנו מסמנים במפורש שאין ערך.

⚠️ טעויות נפוצות
  • let temperature = undefined; — עובד, אבל מיותר: זה בדיוק מה ש־JavaScript עושה לבד.
  • let temperature = 24; בשורה השלישית — SyntaxError: Identifier 'temperature' has already been declared. מגדירים פעם אחת, ואחר כך רק מציבים.

🔗 חלק 2

P01-E23 · שדרוג קוד ישן 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

אילו משתנים מקבלים ערך חדש אחרי השורה הראשונה שלהם?

💡 רמז 2

אם מחשבים את ההכנסות פעם אחת, בשורה אחת, אחרי שידוע כמה נמכרו — האם הן עדיין צריכות להיות let?

✅ פתרון
const storeName = "הספרייה של דני";
const bookPrice = 40;
let booksSold = 0;

booksSold = booksSold + 3;
const totalIncome = bookPrice * booksSold;

console.log(storeName);
console.log("נמכרו:", booksSold, "הכנסות:", totalIncome);
הספרייה של דני
נמכרו: 3 הכנסות: 120

totalIncome הפך ל־const: במקום "להתחיל מ־0 ולהוסיף", מחשבים אותו פעם אחת כשכל המידע ידוע. זה דפוס חשוב: כמה שפחות משתנים שמשתנים — פחות מקומות לבאגים.

⚠️ טעויות נפוצות
  • להשאיר Total_Income — עובד, אבל לא במוסכמה.
  • לחשב את ההכנסות לפני שמעדכנים את booksSold — תקבל 0.

P01-E24 · אתגר: עגלת קניות 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

שני משתנים מצטברים (let): מספר הפריטים והסכום. כל השאר const.

💡 רמז 2

"לתשלום" — משתנה חדש: const totalToPay = cartTotal + shippingFee;. כך cartTotal לא משתנה.

✅ פתרון
01-values-variables/starter/P01-E24.js 
const shippingFee = 30;
let itemsCount = 0;
let cartTotal = 0;

const item1Name = "מקלדת";
const item1Price = 250;
itemsCount = itemsCount + 1;
cartTotal = cartTotal + item1Price;
console.log("נוסף:", item1Name, "| פריטים:", itemsCount, "| סכום:", cartTotal);

const item2Name = "עכבר";
const item2Price = 90;
itemsCount = itemsCount + 1;
cartTotal = cartTotal + item2Price;
console.log("נוסף:", item2Name, "| פריטים:", itemsCount, "| סכום:", cartTotal);

const item3Name = "משטח לעכבר";
const item3Price = 35;
itemsCount = itemsCount + 1;
cartTotal = cartTotal + item3Price;
console.log("נוסף:", item3Name, "| פריטים:", itemsCount, "| סכום:", cartTotal);

const item4Name = "כבל USB";
const item4Price = 25;
itemsCount = itemsCount + 1;
cartTotal = cartTotal + item4Price;
console.log("נוסף:", item4Name, "| פריטים:", itemsCount, "| סכום:", cartTotal);

const totalToPay = cartTotal + shippingFee;
console.log("---");
console.log("סכום העגלה:", cartTotal);
console.log("דמי משלוח:", shippingFee);
console.log("לתשלום:", totalToPay);
נוסף: מקלדת | פריטים: 1 | סכום: 250
נוסף: עכבר | פריטים: 2 | סכום: 340
נוסף: משטח לעכבר | פריטים: 3 | סכום: 375
נוסף: כבל USB | פריטים: 4 | סכום: 400
---
סכום העגלה: 400
דמי משלוח: 30
לתשלום: 430

מה מרגיש לא נוח בפתרון הזה? אותם ארבעה בלוקים חוזרים, ושמות כמו item3Price. זה בדיוק מה שפונקציות (פרק 5), מערכים (פרק 6) ואובייקטים (פרק 7) פותרים. שמור את הקובץ — בפרק 7 נכתוב אותו מחדש בשליש מהאורך.

⚠️ טעויות נפוצות
  • cartTotal = cartTotal + shippingFee; — משנה את סכום העגלה, והשורה "סכום העגלה" תדפיס 430.

P01-E26 · תעודת זהות של ערך 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

console.log מקבל כמה ערכים מופרדים בפסיק. איזה אופרטור מחזיר את הסוג של ערך?

💡 רמז 2

יש ארבעה חלקים בשורה: הטקסט "ערך:", המשתנה, הטקסט "| סוג:", והסוג.

✅ פתרון
01-values-variables/starter/P01-E26.js 
const value = 42;
console.log("ערך:", value, "| סוג:", typeof value);
ערך: 42 | סוג: number

למה זה עובד עם כל ערך: השורה לא יודעת מה יש ב־value — היא שואלת אותו בזמן הריצה. כך גם הבודק יכול להחליף את הערך ולקבל תשובה נכונה. עם null תקבל object — זו המוזרות המפורסמת משיעור 3, לא טעות שלך.

⚠️ טעויות נפוצות
  • console.log("ערך:", value, "| סוג: number") — עובר עם 42 ונכשל ברגע שהערך משתנה. זה בדיוק מה שהבודק תופס.
  • "| סוג:" + typeof value — עובד, אבל עם + צריך לשים לב לרווחים (נלמד בפרק 2). עם פסיקים log מוסיף רווח לבד.

P01-E28 · משחק: חיים ונקודות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

אילו ערכים משתנים במהלך המשחק, ואילו לא? לפי זה תבחר בין const ל־let.

💡 רמז 2

שני משתנים מתעדכנים: let lives = startLives; ו־let points = 0;. כל אירוע הוא שורת עדכון ושורת הדפסה.

✅ פתרון
01-values-variables/starter/P01-E28.js 
const startLives = 3;
const coinPoints = 10;
const diamondPoints = 50;

let lives = startLives;
let points = 0;

points = points + coinPoints;
console.log("מטבע | חיים:", lives, "| נקודות:", points);

lives = lives - 1;
console.log("פגיעה | חיים:", lives, "| נקודות:", points);

points = points + coinPoints;
console.log("מטבע | חיים:", lives, "| נקודות:", points);

points = points + diamondPoints;
console.log("יהלום | חיים:", lives, "| נקודות:", points);

console.log("סיום:", lives, "חיים,", points, "נקודות");
מטבע | חיים: 3 | נקודות: 10
פגיעה | חיים: 2 | נקודות: 10
מטבע | חיים: 2 | נקודות: 20
יהלום | חיים: 2 | נקודות: 70
סיום: 2 חיים, 70 נקודות

למה let lives = startLives ולא פשוט let lives = 3: כך 3 כתוב פעם אחת. כשרוצים משחק "קשה" עם חיים אחדים, משנים שורה אחת. זה אותו עיקרון כמו בקבלה (P01-E13): מקור אמת אחד לכל ערך.

שים לב גם שאת coinPoints השתמשנו פעמיים — אבל כתבנו את 10 רק פעם אחת.

⚠️ טעויות נפוצות
  • points = 10; במקום points = points + coinPoints; — במטבע השני הנקודות "מתאפסות" ל־10 במקום לגדול ל־20.
  • const lives = startLives; — TypeError: Assignment to constant variable. בפגיעה הראשונה.
  • להדפיס "סיום: 2 חיים" כטקסט — עובר עם 3 חיים, ונכשל כשהבודק מתחיל מ־5.
