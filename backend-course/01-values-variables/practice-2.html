P01-E17 · const או let?

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: שיעור 2

לכל משתנה בתוכנית של חנות אונליין, בחר const או let ונמק במשפט:

  1. שם החנות.
  2. מספר הפריטים בעגלה בזמן שהמשתמש מוסיף פריטים.
  3. שיעור המע״מ (18).
  4. הסכום הכולל, שמחושב פעם אחת בסוף מהמחירים.
  5. הסכום המצטבר, שמתעדכן בכל פעם שנוסף פריט.
  6. האם המשתמש מחובר — כשהוא יכול להתחבר ולהתנתק בזמן שהתוכנית רצה.

P01-E44 · העתק או קישור?

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 2

בלי להריץ: מלא טבלת מעקב (score, copy, פלט) וכתוב מה יודפס.

P01-E45 · ארבע דרכים להגדיל מונה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

בכל אחת מארבע התוכניות, השורה הראשונה היא let count = 0; והאחרונה console.log(count);. רק השורה האמצעית שונה:

let count = count + 1;   // א
count + 1;               // ב
count = count + 1;       // ג
count + 1 = count;       // ד

לכל אחת: יש שגיאה? אם כן — איזו, ובמילים שלך למה. אם לא — מה יודפס? רק אחת עושה מה שרצינו (מדפיסה 1).

P01-E46 · אותו פלט, סוג אחר — עם משתנים

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: שיעורים 1–2

בלי להריץ — מה יודפס?

const a = "5";
const b = 5;
console.log(a, b);
console.log(typeof a, typeof b);
console.log("a", a);
console.log(typeof "b");

ואז ענה: אם בפלט של שרת אתה רואה 5 5, איך תדע מי מהם מספר?

🔗 איך זה מתחבר: בשיעור 1 למדת שהמירכאות קובעות את הסוג, ו־typeof חושף אותו. משתנים לא משנים את החוק הזה — הסוג שייך לערך שבקופסה. ומה שבמירכאות הוא תמיד טקסט, גם אם הוא נראה כמו שם של משתנה.

P01-E47 · שני ReferenceError, שתי סיבות

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: פרק 0, שיעור 2

שתי תוכניות קצרות, ושתיהן נותנות ReferenceError — אבל עם הודעות שונות:

// תוכנית 1
const price = 30;
console.log(Price);
ReferenceError: Price is not defined
// תוכנית 2
console.log(total);
let total = 5;
ReferenceError: Cannot access 'total' before initialization
  1. הסבר במילים שלך מה כל הודעה אומרת, ומה התיקון.
  2. בפרק 0 ראית ReferenceError: consol is not defined. לאיזו משתי ההודעות היא דומה, ולמה?
  3. באחת התוכניות המשתנה קיים בקובץ, ובשנייה — לא. איזו היא איזו?

🔗 איך זה מתחבר: את ReferenceError פגשת בפרק 0 כשטעית בכתיב של console. עכשיו, כשיש משתנים, יש לה שתי גרסאות: "אין דבר כזה" ו"יש — אבל עוד לא הגענו אליו". שתיהן נפתרות בקריאה זהירה של ההודעה.

P01-E48 · הערה טובה או שם טוב?

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: שיעורים 1–2

קרא את הקוד:

const x = 18; // x הוא אחוז המע״מ
let n = 0; // n סופר כמה פריטים יש בעגלה
n = n + 1; // מוסיף 1 ל־n
const p = 49.9; // המחיר של המוצר
// דמי משלוח קבועים: יש לנו הסכם עם חברת שליחויות אחת
const shippingFee = 25;
  1. הצע שמות טובים במקום x, n ו־p.
  2. אחרי שינוי השמות — אילו הערות כבר מיותרות, ואיזו כדאי להשאיר? למה?
  3. נסח כלל אחד במילים שלך: מתי שם טוב מחליף הערה, ומתי הערה עדיין חשובה?

🔗 איך זה מתחבר: בשיעור 1 למדת שהערה טובה מסבירה למה, לא מה. בשיעור 2 למדת לבחור שמות שמסבירים מה יש בקופסה. ביחד: את ה"מה" אומר השם, ואת ה"למה" — ההערה.
