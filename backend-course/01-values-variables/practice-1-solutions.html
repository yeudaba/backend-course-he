P01-E30 · true, "true" או True? 🧠 הבנה רמה 1

💡 רמז 1

בוליאני כותבים בלי מירכאות ובאותיות קטנות. מה קורה כשמשהו לא עומד באחד משני התנאים?

💡 רמז 2

שתי השורות הראשונות מדפיסות אותו דבר. ההבדל רואים רק עם typeof. השלישית — זוכר את טבלת הטעויות בסוף השיעור?

✅ פתרון
console.log(true, typeof true);
console.log("true", typeof "true");
true boolean
true string
  • true — בוליאני. מודפס true, הסוג boolean.
  • "true" — מחרוזת של ארבע אותיות. מודפס בדיוק אותו דבר (המירכאות לא מודפסות!), אבל הסוג string.
  • True — לא ערך בכלל. בלי מירכאות, JavaScript מחפשת משהו בשם הזה, לא מוצאת, ועוצרת: ReferenceError: True is not defined.

"המשתמש מחובר" — true, כי זו תשובת כן/לא. בפרק 3 נשאל עליה "אם מחובר — ...", ועם המחרוזת "true" זה לא יעבוד כמו שאתה מצפה.

⚠️ טעויות נפוצות
  • לחשוב ש־"true" ו־true זהים כי הפלט זהה. הפלט מטעה — הסוג קובע.

P01-E34 · לכבות שתי שורות במכה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

P01-E38 · קוראים הודעת שגיאה: True 🧠 הבנה רמה 2

💡 רמז 1

is not defined = "לא מוגדר". JavaScript חושבת ש־True הוא שם של משהו.

💡 רמז 2

ReferenceError היא שגיאה בזמן ריצה, לא שגיאת תחביר. מה זה אומר על השורות שלפניה?

✅ פתרון
  1. ReferenceError: True is not defined — "אין דבר שנקרא True". בלי מירכאות ועם אות גדולה, זה לא הבוליאני true; JavaScript מחפשת משהו בשם הזה ולא מוצאת.
  2. שורה 3 (types.js:3), והחץ מצביע בדיוק על True.
  3. זו שגיאה בזמן ריצה: Node הריץ שורה 1, שורה 2, ונעצר בשורה 3. מה שאחריה לא רץ.
  4. התיקון: true באותיות קטנות.
console.log("שם:", "דנה");
console.log("גיל:", 31);
console.log("מנוי:", true);
console.log("סוף");
שם: דנה
גיל: 31
מנוי: true
סוף
⚠️ טעויות נפוצות
  • לכתוב "True" במירכאות כדי "להשתיק" את השגיאה — הקוד ירוץ, אבל זה טקסט ולא בוליאני.
  • לחפש את הבעיה בשורה 1 כי "שם התחילה ההודעה" — קרא קודם את שורת הסוג, ואז את מספר השורה.

P01-E39 · שני קבצים, שתי שגיאות — פלט שונה 🧠 הבנה רמה 3
