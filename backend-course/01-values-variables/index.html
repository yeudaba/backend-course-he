⚡ מבחן כניסה — אולי אפשר לדלג?

זוכר את המושגים מהתואר? ענה על 10 השאלות בלי להריץ (~15 דקות), ואז פתח את התשובות.

  1. מה ידפיס console.log(typeof "5");?
  2. מה ידפיס console.log(typeof 5);?
  3. מה ההבדל בין let ל־const?
  4. מה יקרה: const a = 1; a = 2;
  5. מה ידפיס: let x; console.log(x);
  6. כתוב משתנה שמחזיק את המחיר 49.9, בשם לפי המוסכמה של JavaScript ל"מחיר מוצר".
  7. מה ידפיס console.log("סכום:", 3 + 4);?
  8. מה ההבדל בין null ל־undefined?
  9. מה ידפיס: let n = 5; n = n + 1; console.log(n);
  10. למה כמעט לא משתמשים היום ב־var?
תשובות
  1. string — המירכאות הופכות אותו לטקסט.
  2. number
  3. let אפשר להציב בו ערך חדש; const — לא.
  4. TypeError: Assignment to constant variable.
  5. undefined
  6. const productPrice = 49.9; (camelCase)
  7. סכום: 7
  8. undefined = "עוד לא קיבל ערך" (בדרך כלל JavaScript שמה אותו); null = "ריק בכוונה" (אנחנו שמים אותו).
  9. 6
  10. יש לו התנהגות מבלבלת (תחום הכרזה רחב, אפשר להכריז שוב) — let ו־const מחליפים אותו.

8 ומעלה נכונות? מסלול מהיר: קרא רק את הקופסאות שמסומנות ⚡ בשיעורים, ופתור את תרגילי רמות 3–5 (P01-E13 עד P01-E25). פחות מ־8? עבור על הפרק המלא — זה ישתלם.

🎯 בסוף הפרק תדע
  • להכיר את שלושת סוגי הערכים הבסיסיים: מחרוזת, מספר ובוליאני — ולבדוק סוג עם typeof.
  • ליצור משתנים עם const ו־let, ולדעת מתי כל אחד.
  • לעקוב אחרי ערכי משתנים שורה אחר שורה בטבלת מעקב.
  • להבין את undefined ואת null, ולמה לא משתמשים ב־var.
  • לקרוא את השגיאות הנפוצות של משתנים ולתקן אותן.

🤔 למה צריך משתנים?

בתרגיל הקבלה של פרק 0 כתבת את מחיר הקרואסון פעמיים: פעם בטקסט ופעם בחישוב. אם המחיר משתנה — צריך לזכור לעדכן בשני מקומות, ומספיק לשכוח אחד כדי שהקבלה תשקר. משתנה הוא שם שנותנים לערך, כך שכותבים אותו פעם אחת ומשתמשים בו בכל מקום. בשרת אמיתי כמעט כל שורה עובדת עם משתנים: שם המשתמש שהתחבר, סכום ההזמנה, מספר הפריטים במלאי.
