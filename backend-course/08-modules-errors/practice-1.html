P08-E01 · מה יוצא ומה נכנס

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

נתונים שני קבצים. מה ידפיס main.js?

// utils.js
const SECRET = 42;
function double(n) {
  return n * 2;
}
function triple(n) {
  return n * 3;
}
module.exports = { double, SECRET_PLUS_ONE: SECRET + 1 };
// main.js
const utils = require("./utils");
const { double, triple } = require("./utils");
console.log(double(5));
console.log(utils.SECRET_PLUS_ONE);
console.log(utils.SECRET);
console.log(typeof triple);

P08-E26 · מודול כסף ב־ES Modules 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

כסף בשרת שומרים באגורות שלמות (פרק 2), אבל משתמשים מקלידים שקלים. בתרגיל הזה תכתוב שני קבצים ב־ES Modules:

1. P08-E26-money.mjs (החתימות כבר כתובות) — מייצא שתי פונקציות:

  • toAgorot(shekels) — 19.9 ← 1990. שים לב: 19.9 * 100 הוא 1989.9999999999998, אז צריך לעגל.
  • formatILS(agorot) — 2500 ← "₪25.00", ‏5 ← "₪0.05".

2. P08-E26.mjs (יש בו רק הערה) — מייבא את שתי הפונקציות מהקובץ הראשון, ומייצא cartTotal(prices): מקבלת מערך מחירים בשקלים ומחזירה את הסכום כמחרוזת מעוצבת. החישוב — באגורות:

cartTotal([19.9, 0.1, 5]); // "₪25.00"
cartTotal([0.1, 0.2]);     // "₪0.30" (ולא 0.30000000000000004)
cartTotal([]);             // "₪0.00"

📄 כותבים בשני הקבצים בתיקייה 08-modules-errors/starter/, מריצים ובודקים:

% node 08-modules-errors/starter/P08-E26.mjs
% npm run check P08-E26
