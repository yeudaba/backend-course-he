  4. בקובץ main.js (בלי "type": "module"): import { sum } from "./math.mjs";
  5. בקובץ main.js: const { sum } = require("math");

P08-E42 · groupBy כמודול ES 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: פרק 7, שיעור 1

כתוב מודול ES בקובץ P08-E42.mjs:

  • ייצוא בשם: groupBy(list, keyFn) — מחזירה Map: מפתח ← מערך הפריטים שקיבלו אותו, לפי הסדר.
  • ייצוא default: countByStatus(orders) — אובייקט רגיל: סטטוס ← כמה הזמנות, בעזרת groupBy.
groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"));
// Map(2) { 'odd' => [ 1, 3 ], 'even' => [ 2, 4 ] }
countByStatus([{ status: "paid" }, { status: "new" }, { status: "paid" }]);
// { paid: 2, new: 1 }
