P08-E55 · איזה כפתור?

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 3

הדיבאגר עצר בשורה const total = calcTotal(items) + shipping(city);. לכל מצב — איזה כפתור (Continue, Step Over, Step Into, Step Out) או איזה כלי?

  1. אתה בטוח ש־calcTotal ו־shipping תקינות, ורוצה לראות את total בשורה הבאה.
  2. אתה חושד ב־calcTotal, ורוצה לראות מה קורה בתוכה.
  3. נכנסת ל־calcTotal בטעות, היא ארוכה, ואתה רוצה לחזור לשורה שממנה באת.
  4. יש לך breakpoint נוסף 200 שורות למטה, ורוצה להגיע אליו.
  5. הבאג קורה רק בהזמנה מספר 4,812 מתוך 10,000.
  6. רוצה לדעת מה הערך של items.length * 2 עכשיו, בלי לשנות את הקוד.

P08-E56 · תנאים ל־breakpoint

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

לכל מצב — כתוב את הביטוי שתשים ב־Edit Breakpoint, כך שהדיבאגר יעצור רק ברגע הבעייתי:

  const order = orders[i];

  1. אחרי כמה אלפי הזמנות, total נהיה NaN. רוצים לעצור בהזמנה שגרמה לזה.
  2. הלקוח מתלונן על ההזמנה שהמזהה שלה "A-77".
  3. חושדים שיש הזמנות בלי qty.
  4. רוצים לעצור רק בהזמנה האחרונה.
  5. חושדים שיש מחירים שהגיעו כמחרוזת.

P08-E63 · stack trace שעובר דרך map

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 3

בלי להריץ — מה יודפס? (שוב מדפיסים רק את שמות הפונקציות מה־stack.)

function parsePrice(text) {
  return JSON.parse(text).price;
}
function loadPrices(lines) {
  return lines.map(parsePrice);
}

try {
  loadPrices(['{"price": 5}', "{price: 7}"]);
} catch (err) {
  console.log(err.name);
  console.log(err.stack.split("\n").slice(1, 5).map((line) => line.trim().split(" ")[1]));
}

🔗 איך זה מתחבר: map מפרק 6 קורא ל־callback בשבילך — ולכן הוא מופיע בערימה בין הפונקציה שלך לבין מי שקרא לה, עם <anonymous> כי הוא קוד מובנה. ו־JSON.parse מפרק 7 זורק SyntaxError — גם הוא מובנה, ולכן הוא השורה העליונה.

P08-E64 · לזרוק מחדש — ומה קורה ל־stack?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2, שיעור 3

שתי דרכים "לעטוף" שגיאה. בלי להריץ — מה יודפס?

function readConfig(text) {
  return JSON.parse(text);
}
function loadA(text) {
  try {
    return readConfig(text);
  } catch (err) {
    throw err;
  }
}
function loadB(text) {
  try {
    return readConfig(text);
  } catch (err) {
    throw new Error(`הגדרות לא תקינות: ${err.name}`);
  }
}
const firstFrames = (err) => err.stack.split("\n").slice(1, 3).map((l) => l.trim().split(" ")[1]);

for (const load of [loadA, loadB]) {
  try {
    load("{bad");
  } catch (err) {
    console.log(err.name, firstFrames(err));
  }
}

🔗 איך זה מתחבר: מהשיעור הקודם: throw err; בתוך catch הוא "לא בולעים — זורקים הלאה". מהשיעור הזה: ה־stack נוצר ב־new Error. לכן זריקה מחדש שומרת את המקור, ושגיאה חדשה מתחילה ערימה חדשה — מהמקום שבו יצרת אותה.

P08-E67 · מעקב קריאות (דיבאגר של עניים) 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: פרק 5, שיעור 2, שיעור 3

כתוב trace(fn, name, log) שמחזירה פונקציה חדשה שמקבלת ארגומנט אחד, ועושה בדיוק מה ש־fn עושה — אבל רושמת למערך log:

  • לפני הקריאה: → ${name}(${JSON.stringify(arg)})
  • אחרי הצלחה: ← ${name} = ${JSON.stringify(result)}, ומחזירה את התוצאה.
  • אם fn זרקה: ✘ ${name}: ${err.message}, וזורקת מחדש את אותה שגיאה.
const log = [];
