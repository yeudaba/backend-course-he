P08-E26 · מודול כסף ב־ES Modules 🤖 ✍️ מאפס רמה 2

💡 רמז 1

ב־money.mjs: Math.round(shekels * 100), ו־(agorot / 100).toFixed(2). בראש P08-E26.mjs: import { toAgorot, formatILS } from "./P08-E26-money.mjs"; — עם ./ ועם הסיומת.

P08-E27 · כפילויות ברשימת הרשמה 🤖 🔁 חזרה רמה 2

💡 רמז 1

שתי קבוצות: seen (כל מה שכבר ראינו) ו־dups (מה שראינו פעמיים). עוברים בלולאה: אם הכתובת כבר ב־seen — מוסיפים ל־dups, אחרת — ל־seen.

הבדיקה הראשונה: Array.isArray(emails).

💡 רמז 2

Set שומר על סדר ההוספה, ומוסיף כל ערך רק פעם אחת. לכן בסוף מספיק return [...dups];.

✅ פתרון
// P08-E27: כפילויות ברשימת הרשמה
function findDuplicates(emails) {
  if (!Array.isArray(emails)) {
    throw new TypeError("emails חייב להיות מערך");
  }
  const seen = new Set();
  const dups = new Set();
  for (const raw of emails) {
    const email = raw.trim().toLowerCase();
    if (seen.has(email)) {
      dups.add(email);
    } else {
      seen.add(email);
    }
  }
  return [...dups];
}

console.log(findDuplicates(["a@x.com", "b@x.com", " A@x.com", "c@x.com", "b@x.com", "a@x.com"]));
try {
  findDuplicates("a@x.com");
} catch (err) {
  console.log(`${err.name}: ${err.message}`);
}

module.exports = { findDuplicates };
[ 'a@x.com', 'b@x.com' ]
TypeError: emails חייב להיות מערך

שתי תכונות של Set עושות כאן את כל העבודה: has מהיר (לא סורק את כל הרשימה כמו includes), ו־add של ערך שכבר קיים לא עושה כלום. לכן כתובת שמופיעה שלוש פעמים נכנסת ל־dups פעם אחת בלבד, בלי בדיקה נוספת.

למה TypeError ולא Error? כי זה סוג השגיאה המדויק — "קיבלתי ערך מהסוג הלא נכון". בלי ה־guard, מחרוזת הייתה עוברת בלולאה תו אחרי תו, ומחזירה תוצאה שגויה בשקט.

⚠️ טעויות נפוצות
  • dups כמערך עם push — כתובת שמופיעה שלוש פעמים נכנסת פעמיים.
  • לנרמל רק לפני has ולשמור את המקור — " A@x.com" נכנס לתוצאה עם הרווח.
  • typeof emails !== "object" — גם null ו־{} עוברים. Array.isArray מדויק.

P08-E28 · מפרש פקודות ל־CLI 🤖 🔁 חזרה רמה 3

💡 רמז 1

פירוק: const [word, ...rest] = line.trim().split(" ").filter((w) => w !== "");. ה־...rest אוסף את כל שאר המילים למערך.

💡 רמז 2

switch (word.toLowerCase()). ב־case "add": const amount = Number(rest[0]);, ‏guard עם Number.isFinite(amount) && amount > 0, ו־note: rest.slice(1).join(" "). את השורה הריקה בודקים לפני ה־switch (word === undefined).

✅ פתרון
// P08-E28: מפרש פקודות
function parseCommand(line) {
  const [word, ...rest] = line.trim().split(" ").filter((w) => w !== "");
  if (word === undefined) {
    throw new Error("לא הוקלדה פקודה");
  }

  switch (word.toLowerCase()) {
    case "add": {
      const amount = Number(rest[0]);
      if (rest.length === 0 || !Number.isFinite(amount) || amount <= 0) {
        throw new Error("סכום לא תקין");
      }
      return { cmd: "add", amount, note: rest.slice(1).join(" ") };
    }
    case "list":
      return { cmd: "list" };
    case "total":
      return { cmd: "total" };
    default:
      throw new Error(`פקודה לא מוכרת: "${word}"`);
  }
}

console.log(parseCommand("  add 25   קפה בבוקר "));
for (const line of ["add abc", "", "delete 3"]) {
  try {
    parseCommand(line);
  } catch (err) {
    console.log(err.message);
  }
}

module.exports = { parseCommand };

סכום לא תקין
לא הוקלדה פקודה
פקודה לא מוכרת: "delete"

שלוש שכבות של הגנה, כל אחת במקום שלה. שורה ריקה נבדקת לפני ה־switch. סכום לא תקין נבדק בתוך case "add", כי רק שם יש סכום. ופקודה לא מוכרת נתפסת ב־default. ה־default זורק במקום להחזיר, כי אין שום ערך "נכון" להחזיר במקרה הזה.

הסוגריים המסולסלים אחרי case "add": יוצרים בלוק, וכך ה־const amount שייך רק ל־case הזה. בלי הבלוק, כל ה־cases חולקים scope אחד, ושני const עם אותו שם ב־cases שונים זה שגיאת תחביר.

למה rest.length === 0? כי Number(undefined) הוא NaN, וזה כבר נתפס. אבל Number("") הוא 0, ולכן כדאי להיות מפורש.

⚠️ טעויות נפוצות
  • line.split(" ") בלי filter — רווח כפול יוצר מילה ריקה, ו־"add 25" נכשל.
  • parseFloat(rest[0]) — "25abc" נותן 25 ועובר. Number מחמירה יותר ומחזירה NaN.
  • rest.join(" ") בתור ה־note — הסכום נכנס להערה.

P08-E03 · null או throw? רמה 1

💡 רמז 1

שאל: האם זה מצב רגיל שהקוד הקורא צפוי לטפל בו כל יום? או מצב שאסור שיקרה / שאי אפשר להמשיך ממנו?

💡 רמז 2

"אין תוצאות" הוא לא שגיאה. "הקלט הוא זבל" — כן.

✅ פתרון
  1. null — "לא נמצא" הוא תוצאה רגילה; הקורא יחליט (404 או הודעה).
  2. throw — קלט לא תקין; אי אפשר להמשיך לחשב.

  5. throw — חילוק ב־0 הוא שגיאת תכנות/קלט (JavaScript מחזירה Infinity — ערך שישבש חישובים בשקט).
  6. [] — אין תוצאות זה מקרה רגיל.
⚠️ טעויות נפוצות
  • לזרוק שגיאה על "לא נמצא" בכל מקום — הקוד הקורא יתמלא ב־try/catch.

// P08-E08: זריקת שגיאות
function parsePositiveInt(input, fieldName = "ערך") {
  if (String(input).trim() === "") {
    throw new Error(`${fieldName}: שדה חובה`);
  }
  const n = Number(input);
  if (Number.isNaN(n)) {
    throw new Error(`${fieldName}: חייב להיות מספר`);
  }
  if (!Number.isInteger(n) || n < 1) {
    throw new Error(`${fieldName}: חייב להיות מספר שלם חיובי`);
  }
  return n;
}

  console.log(err.message);

P08-E09 · JSON בטוח 🤖 רמה 2

💡 רמז 1

try { return JSON.parse(text); } catch { return fallback; } — מותר catch בלי (err) כשלא צריך את השגיאה.

💡 רמז 2

parseOrThrow: ב־catch — throw new Error("JSON לא תקין");

✅ פתרון
// P08-E09: JSON.parse עם טיפול בשגיאות
function safeParse(text, fallback = null) {
  try {
    return JSON.parse(text);
  } catch {
    return fallback;
  }
}

function parseOrThrow(text) {
  try {
    return JSON.parse(text);
  } catch {
    throw new Error("JSON לא תקין");
  }
}

console.log(safeParse('{"a":1}'), safeParse("{oops", {}));

module.exports = { safeParse, parseOrThrow };
{ a: 1 } {}

"תרגום" שגיאה טכנית להודעה ברורה הוא דפוס נפוץ — רק אל תמחק לגמרי את המקור: בעבודה אמיתית שומרים אותו, new Error("JSON לא תקין", { cause: err }), כדי שביומן יהיה הפרט הטכני.

⚠️ טעויות נפוצות
  • safeParse("null") מחזיר null — זה JSON תקין! כאן זה זהה לברירת המחדל, אבל שים לב שהערכים האלה לא תמיד ניתנים להבחנה.

P08-E10 · עטיפה של ניסיון 🤖 רמה 2

💡 רמז 1

try { return { ok: true, value: fn() }; } catch (err) { return { ok: false, error: err.message }; }

💡 רמז 2

firstSuccessful: לולאה, ובכל סיבוב attempt; אם ok — return result.value.

✅ פתרון
// P08-E10: הפיכת שגיאות לערכים
function attempt(fn) {
  try {
    return { ok: true, value: fn() };
  } catch (err) {
    return { ok: false, error: err.message };
  }
}

function firstSuccessful(fns) {
  for (const fn of fns) {
    const result = attempt(fn);
    if (result.ok) {
      return result.value;
    }
  }
  throw new Error("כל הניסיונות נכשלו");
}

console.log(attempt(() => JSON.parse("[1]")), attempt(() => null.x).ok);

module.exports = { attempt, firstSuccessful };
{ ok: true, value: [ 1 ] } false

הצורה { ok, value, error } נפוצה מאוד (ב־API-ים, ובפרויקט הדגל) — היא הופכת "קריסה" ל"תוצאה" שאפשר לבדוק.

// P08-E15: ניסיונות חוזרים
function retry(fn, times) {
  let lastError;
  for (let attempt = 1; attempt <= times; attempt++) {
    try {
      return fn(attempt);
    } catch (err) {
      lastError = err;
    }
  }
  throw lastError;
}

  return { ...account, balance: account.balance + amount };
}

function withdraw(account, amount) {
  assertAmount(amount);
  if (account.balance < amount) {
    throw bankError("INSUFFICIENT_FUNDS", "אין מספיק יתרה");
  }
  return { ...account, balance: account.balance - amount };
}

function transfer(from, to, amount) {
  if (from.id === to.id) {
    throw bankError("SAME_ACCOUNT", "לא ניתן להעביר לאותו חשבון");
  }
  const newFrom = withdraw(from, amount);
  const newTo = deposit(to, amount);
  return [newFrom, newTo];
}

function safeTransfer(from, to, amount) {
  try {
    const [newFrom, newTo] = transfer(from, to, amount);
    return { ok: true, from: newFrom, to: newTo };
  } catch (err) {
    return { ok: false, code: err.code, message: err.message, from, to };
  }
}

const a = { id: 1, owner: "דנה", balance: 100 };
const b = { id: 2, owner: "עומר", balance: 20 };
console.log(safeTransfer(a, b, 30));
console.log(safeTransfer(a, b, 500).code);

💡 רמז 1

שלב 1 — tokenize: הפוך את הטקסט למערך כמו [2, "+", 3, "*", 4]. עבור תו־תו: ספרה או נקודה ← צבור למספר; אופרטור ← "סגור" את המספר והוסף את האופרטור; רווח ← דלג; אחר ← שגיאה.

שלב 2 — שני מעברים: קודם עבור על הטוקנים וחשב כל * ו־/ מיד (מחליף שלושה טוקנים בתוצאה), ואז חבר/חסר את מה שנשאר משמאל לימין. בדוק תקינות: טוקנים במקומות זוגיים — מספרים; במקומות אי־זוגיים — אופרטורים; האורך אי־זוגי.

// P08-E25: מחשבון בלי eval
const OPERATORS = ["+", "-", "*", "/"];

function tokenize(expression) {
  const tokens = [];
  let current = "";
  const flush = () => {
    if (current !== "") {
      const n = Number(current);
      if (Number.isNaN(n)) throw new Error("ביטוי לא תקין");
      tokens.push(n);
      current = "";
    }
  };
  for (const ch of expression) {
    if ("0123456789.".includes(ch)) {
      current += ch;
    } else if (OPERATORS.includes(ch)) {
      flush();
      tokens.push(ch);
    } else if (ch === " ") {
      flush();
    } else {
      throw new Error(`תו לא חוקי: ${ch}`);
    }
  }
  flush();
  return tokens;
}

function validate(tokens) {
  const ok =
    tokens.length % 2 === 1 &&
    tokens.every((t, i) => (i % 2 === 0 ? typeof t === "number" : OPERATORS.includes(t)));
  if (!ok) throw new Error("ביטוי לא תקין");
}

function calculate(expression) {
  const tokens = tokenize(expression);
  validate(tokens);

  const stack = [tokens[0]];
  for (let i = 1; i < tokens.length; i += 2) {
    const op = tokens[i];
    const n = tokens[i + 1];
    if (op === "*") {
      stack.push(stack.pop() * n);
    } else if (op === "/") {
      if (n === 0) throw new Error("חילוק באפס");
      stack.push(stack.pop() / n);
    } else {
      stack.push(op, n);
    }
  }

  let result = stack[0];
  for (let i = 1; i < stack.length; i += 2) {
    result = stack[i] === "+" ? result + stack[i + 1] : result - stack[i + 1];
  }
  return result;
}

console.log(calculate("2 + 3 * 4"), calculate("10 / 4 - 1"), calculate("7"));
for (const bad of ["2 + x", "3 +", "4 / 0"]) {
  try {
    calculate(bad);
  } catch (err) {
    console.log(err.message);
  }
}

module.exports = { calculate, tokenize };
