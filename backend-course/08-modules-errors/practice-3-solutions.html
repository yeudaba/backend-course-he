💡 רמז 2

האיבר הראשון לא נספר. וגם החלוקה — במה מחלקים?

✅ פתרון
// P08-E11: ממוצע — מתוקן
function averageScore(scores) {
  if (scores.length === 0) {
    return 0;
  }
  let sum = 0;
  for (let i = 0; i < scores.length; i++) {
    sum += scores[i];
  }
  return sum / scores.length;
}

console.log(averageScore([80, 90, 100]));

module.exports = { averageScore };
90

בדיבאגר רואים שהסיבוב הראשון מתחיל ב־i = 1 (המקורי: let i = 1), כך ש־80 לא נכנס לסכום, ובנוסף החלוקה הייתה ב־scores.length - 1 — שני באגים ש"כמעט" מבטלים זה את זה, ולכן התוצאה נראתה סבירה.

⚠️ טעויות נפוצות

item.qty ?? 1

✅ פתרון
// P08-E16: סכום הזמנה עם כמות ברירת מחדל
function orderTotal(items) {
  let total = 0;
  for (const item of items) {
    total += item.price * (item.qty ?? 1);
  }
  return total;
}

console.log(orderTotal([{ price: 10, qty: 2 }, { price: 5 }, { price: 3, qty: 0 }]));

module.exports = { orderTotal };
25

שים לב לפריט עם qty: 0 — עם || הוא היה נחשב כ־1. ?? משאיר אותו 0 (פרק 3!).

⚠️ טעויות נפוצות
  • item.qty || 1 — כמות 0 הופכת ל־1.

P08-E22 · עם הדיבאגר: הרצף הארוך 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

מתי best מתעדכן? רק כשהרצף נשבר...

💡 רמז 2

אחרי הלולאה, אם הרצף לא נשבר — best לא קיבל את הערך האחרון. או: לעדכן את best בכל סיבוב.

✅ פתרון
// P08-E22: הרצף הארוך ביותר — מתוקן
function longestStreak(days) {
  let best = 0;
  let current = 0;
  for (const visited of days) {
    current = visited ? current + 1 : 0;
    best = Math.max(best, current);
  }
  return best;
}

console.log(longestStreak([true, false, true, true, true]));

module.exports = { longestStreak };
3

המקורית עדכנה את best רק ב־else (כשיום ריק שובר את הרצף). רצף שנמשך עד הסוף לא "נשבר", ולכן לא נספר. התיקון — לעדכן בכל סיבוב — גם פשוט יותר. באג קלאסי של "הסיבוב האחרון" (חפש אותו בכל לולאה עם מצב!).

⚠️ טעויות נפוצות
  • להוסיף if מיוחד אחרי הלולאה — עובד, אבל עדכון בכל סיבוב פשוט יותר ומונע את הבאג מראש.
