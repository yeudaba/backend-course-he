P08-E02 · זרימה של try/catch/finally

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

מה ידפיס הקוד?

function check(n) {
  console.log("בודק", n);
  if (n < 0) throw new Error("שלילי");
  return n * 10;
}
for (const n of [1, -2, 3]) {
  try {
    const r = check(n);
    console.log("תוצאה", r);
  } catch (e) {
    console.log("שגיאה:", e.message);
  } finally {
    console.log("---");
  }
}

P08-E03 · null או throw?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

לכל פונקציה — האם במקרה הבעייתי עדיף להחזיר null/ערך ריק, או לזרוק שגיאה? נמק.

  1. findProductByCode(code) — הקוד לא קיים במחירון.
  2. parseAmount(text) — הטקסט הוא "abc".
  3. getUserCart(userId) — למשתמש אין עגלה עדיין.
  4. connectToDatabase(url) — המסד לא עונה.
  5. divide(a, b) — b הוא 0.
  6. search(query) — אין תוצאות.

P08-E10 · עטיפה של ניסיון 🤖

P08-E13 · שגיאות עם שדה וקוד 🤖

P08-E14 · שגיאה ← תשובת HTTP 🤖

P08-E27 · כפילויות ברשימת הרשמה 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

🔁 חזרה על Set (פרק 7), עם שגיאה ברורה משיעור 2. כתוב findDuplicates(emails), שמחזירה מערך של כתובות שמופיעות יותר מפעם אחת:

  • לפני ההשוואה: בלי רווחים בקצוות, ובאותיות קטנות. " Dana@x.com" ו־"dana@X.com " הן אותה כתובת.

findDuplicates(["a@x.com", "b@x.com", " A@x.com", "c@x.com", "b@x.com", "a@x.com"]);

P08-E28 · מפרש פקודות ל־CLI 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

🔁 חזרה על switch (פרק 3) ועל split (פרק 6), עם throw. בפרויקט 1 תכתוב כלי שורת פקודה להוצאות. החלק הראשון שלו הוא פונקציה שמפרשת שורה שהמשתמש הקליד. כתוב parseCommand(line):

שורהמחזירה
"add 25 קפה בבוקר"{ cmd: "add", amount: 25, note: "קפה בבוקר" }
"add 12.5"{ cmd: "add", amount: 12.5, note: "" }
"list"{ cmd: "list" }
"total"{ cmd: "total" }
  • רווחים מיותרים (בקצוות ובין המילים) לא משנים כלום. שם הפקודה — בלי תלות באותיות גדולות ("LIST" עובד).
  • add עם סכום חסר, לא מספר, או לא חיובי — throw new Error("סכום לא תקין").
  • שורה ריקה — Error("לא הוקלדה פקודה"). פקודה אחרת — Error('פקודה לא מוכרת: "xyz"') (עם המילה שהוקלדה, בגרשיים).

📄 כותבים בקובץ 08-modules-errors/starter/P08-E28.js (יש בו רק הערה). בסוף הקובץ: module.exports = { parseCommand };
