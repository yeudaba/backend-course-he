}

P08-E44 · הסדר של try/catch/finally

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

בלי להריץ — מה יודפס, ובאיזה סדר?

function step(name, fail) {
  console.log(`מתחיל ${name}`);
  if (fail) {
    throw new Error(`${name} נכשל`);
  }
  console.log(`סיים ${name}`);
}

try {
  step("א", false);
  step("ב", true);
  step("ג", false);
} catch (err) {
  console.log(`נתפס: ${err.message}`);
} finally {
  console.log("ניקוי");
}
console.log("ממשיכים");

P08-E49 · try בתוך הלולאה או מסביב לה?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 2

שתי גרסאות — אותו קלט. בלי להריץ — מה תדפיס כל אחת?

function parseQty(text) {
  const n = Number(text);
  if (!Number.isInteger(n) || n < 1) {
    throw new Error(`לא תקין: "${text}"`);
  }
  return n;
}
const inputs = ["2", "x", "5"];

let total1 = 0;
try {
  for (const t of inputs) {
    total1 += parseQty(t);
  }
} catch (err) {
  console.log(`גרסה 1: ${err.message}`);
}
console.log(`סה״כ 1: ${total1}`);

let total2 = 0;
for (const t of inputs) {
  try {
    total2 += parseQty(t);
  } catch (err) {
    console.log(`גרסה 2: ${err.message}`);
  }
}
console.log(`סה״כ 2: ${total2}`);

🔗 איך זה מתחבר: לולאה מפרק 4 ו־try מהשיעור: איפה שמים את ה־try קובע מה קורה אחרי שגיאה. מסביב ללולאה — שגיאה אחת עוצרת הכול (כמו break). בתוך הלולאה — מדלגים על הפריט הבעייתי וממשיכים (כמו continue).

P08-E51 · catch שהחזיר undefined

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 2

מישהו "תיקן" קריסה עם try/catch. בלי להריץ — מה יודפס? מה הבעיה בתיקון?

function parsePrice(text) {
  try {
    const n = Number(text);
    if (Number.isNaN(n)) {
      throw new Error(`מחיר לא תקין: ${text}`);
    }
    return n;
  } catch (err) {
    console.log("שגיאה");
  }
}

const prices = ["10", "abc", "5"].map(parsePrice);
console.log(prices);
const total = prices.reduce((sum, p) => sum + p, 0);
console.log(total);

🔗 איך זה מתחבר: map ו־reduce מפרק 6: מה שה־callback מחזיר נכנס למערך. catch בלי return הוא "בליעה" של שגיאה — הפונקציה מסתיימת ומחזירה undefined, וה־undefined ממשיך לזרום בשרשרת עד שהוא הורס חישוב רחוק.

P08-E52 · בדיקת מבנה של אובייקט 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 15 דק׳ידע נדרש: פרק 7, שיעור 2

כתוב assertShape(obj, shape). shape הוא אובייקט: שם שדה ← הסוג שצריך להיות לו (מה ש־typeof מחזיר):

const shape = { name: "string", price: "number", inStock: "boolean" };
assertShape({ name: "עט", price: 5, inStock: true }, shape); // מחזירה true
assertShape({ name: "עט", price: "5", inStock: true }, shape);
// זורקת Error: "price: ציפינו ל־number וקיבלנו string"
assertShape({ name: "עט", inStock: true }, shape);
// זורקת Error: "price: ציפינו ל־number וקיבלנו undefined"

בודקים את השדות לפי הסדר ב־shape, וזורקים על הבעיה הראשונה. לשגיאה יש גם שדה field (שם השדה הבעייתי) ו־status = 400. שדות נוספים ב־obj שלא מופיעים ב־shape — מותרים.
