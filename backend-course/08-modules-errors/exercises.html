P08-E28 · מפרש פקודות ל־CLI 🤖

🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

🔁 חזרה על switch (פרק 3) ועל split (פרק 6), עם throw. בפרויקט 1 תכתוב כלי שורת פקודה להוצאות. החלק הראשון שלו הוא פונקציה שמפרשת שורה שהמשתמש הקליד. כתוב parseCommand(line):

שורהמחזירה

  • רווחים מיותרים (בקצוות ובין המילים) לא משנים כלום. שם הפקודה — בלי תלות באותיות גדולות ("LIST" עובד).

  • שורה ריקה — Error("לא הוקלדה פקודה"). פקודה אחרת — Error('פקודה לא מוכרת: "xyz"') (עם המילה שהוקלדה, בגרשיים).

P08-E02 · זרימה של try/catch/finally

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

מה ידפיס הקוד?

function check(n) {
  console.log("בודק", n);
  if (n < 0) throw new Error("שלילי");
  return n * 10;
}
for (const n of [1, -2, 3]) {
  try {
    const r = check(n);
    console.log("תוצאה", r);
  } catch (e) {
    console.log("שגיאה:", e.message);
  } finally {
    console.log("---");
  }
}

P08-E24 · אתגר: חשבון בנק עם שגיאות מסודרות 🤖

רמה 5⏱ 35 דק׳ידע נדרש: כל הפרק

בקובץ 08-modules-errors/starter/P08-E24.js בנה "מודול בנק" קטן. חשבון הוא { id, owner, balance }. אף פונקציה לא משנה את הקלט — כולן מחזירות חשבונות חדשים.

  • bankError(code, message) — Error עם שדה code.
  • deposit(account, amount) — סכום חייב להיות מספר חיובי, אחרת INVALID_AMOUNT / "סכום לא תקין".
  • withdraw(account, amount) — כמו deposit, ואם אין מספיק: INSUFFICIENT_FUNDS / "אין מספיק יתרה".
  • transfer(from, to, amount) — מחזירה [newFrom, newTo]. העברה לאותו חשבון (id זהה) ← SAME_ACCOUNT / "לא ניתן להעביר לאותו חשבון". הכול או כלום.
  • safeTransfer(from, to, amount) — כמו transfer, אבל לא זורקת: מחזירה { ok: true, from, to } או { ok: false, code, message, from, to } (עם החשבונות המקוריים).

P08-E25 · אתגר: מחשבון בטוח 🤖

רמה 5⏱ 40 דק׳ידע נדרש: כל הפרק

בקובץ 08-modules-errors/starter/P08-E25.js השלם calculate(expression) שמחשבת ביטוי עם מספרים שלמים או עשרוניים, + - * /, ורווחים — בלי eval — ומכבדת סדר פעולות (כפל וחילוק לפני חיבור וחיסור). שגיאות (Error עם ההודעות):

  • תו לא מוכר ← "תו לא חוקי: x"
  • ביטוי לא שלם (מתחיל/נגמר באופרטור, שני אופרטורים ברצף, ריק) ← "ביטוי לא תקין"
  • חילוק ב־0 ← "חילוק באפס"

דוגמאות: "2 + 3 * 4" ← 14; "10 / 4 - 1" ← 1.5; "7" ← 7.
