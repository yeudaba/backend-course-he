פרק 8 — ארגון קוד ואיתור תקלות

⏱ 4 מפגשים

🧰 לפני שמתחילים — פרק 8

מה צריך שכבר יהיה מותקן: VS Code, Node.js 24+, הבודק האוטומטי.

מה מתקינים עכשיו: ESLint — כלי שקורא את הקוד ומסמן טעויות נפוצות (כמו == או משתנה שלא בשימוש) עוד לפני שמריצים.

  1. העתק מחדש מ־~/Desktop/Backend/backend-course אל ~/dev/backend-course את הקובץ package.json (בחר Replace — הוא התעדכן) ואת הקובץ החדש eslint.config.mjs.
  2. ב־Terminal, מתוך ~/dev/backend-course, הרץ פעם אחת: 
    % npm install
    הפקודה מורידה את ESLint לתיקייה חדשה בשם node_modules (כמה עשרות שניות, דורש אינטרנט). מה בדיוק קרה כאן — נלמד בפרק 13. אם מופיעות כמה שורות npm warn — זה תקין.
  3. תוסף ל־VS Code: ESLint (מזהה dbaeumer.vscode-eslint, של Microsoft). אחרי ההתקנה, בעיות יסומנו בקו גלי צהוב/אדום ישר בעורך.
  4. בדיקה: 
    % npx eslint 01-values-variables/starter/P01-E23-old-code.js
    אמורות להופיע שגיאות no-var — בדיוק מה שתיקנת בפרק 1.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 08-modules-errors מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה שהסביבה מוכנה — ב־Terminal של VS Code, מתוך ~/dev/backend-course:

% node -v
v24.11.0

(כל גרסה 24 ומעלה תקינה.)

🎯 בסוף הפרק תדע
  • לפצל קוד לכמה קבצים עם module.exports/require ועם export/import — ולהבין סוף־סוף את השורה בתחתית קובצי התרגילים.
  • לזרוק שגיאות עם throw ולתפוס אותן עם try/catch/finally.
  • לבחור מתי להחזיר null ומתי לזרוק שגיאה.
  • לקרוא stack trace עד הסוף ולהגיע לשורה שלך.
  • להשתמש ב־Debugger של VS Code: breakpoints, צעד־אחר־צעד ומעקב אחרי משתנים.
  • להשתמש ב־ESLint ובשיטת עבודה מסודרת לאיתור באגים.

🤔 למה צריך את זה?

הקוד שלך גדל. בפרויקט הראשון (מיד אחרי הפרק) יהיו כמה מאות שורות — בקובץ אחד זה בלתי אפשרי לתחזק. ושרת אמיתי לא "קורס" כשמשהו משתבש: הוא תופס את השגיאה ומחזיר הודעה מסודרת. והכי חשוב: מכאן ואילך רוב הזמן שלך כמפתח יעבור על הבנה למה משהו לא עובד. הפרק הזה נותן לך את הכלים לזה.

  • לפצל קובץ אחד לשניים — אחד מייצא פונקציות, השני משתמש בהן — בשני הסגנונות.
