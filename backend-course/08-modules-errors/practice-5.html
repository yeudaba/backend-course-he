P08-E81 · regex: מה יודפס?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 5

בלי להריץ — מה יודפס?

console.log(/^\d{3}$/.test("1234"), /\d{3}/.test("1234"));
console.log(/^[a-z]+$/i.test("Hello"), /^[a-z]+$/.test("Hello"));

const m = "order-0042".match(/^order-(\d+)$/);
console.log(m[1], Number(m[1]));

console.log("a1b22c333".match(/\d+/g));
console.log("abc".match(/\d/));

P08-E82 · שלושה בודקים, שלושה באגים

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 5

שלושה בודקי קלט מטופס הרשמה. בכל אחד יש באג.

const POSTAL = /\d{7}/;        // מיקוד: בדיוק 7 ספרות
const PRICE = /^\d+.\d{2}$/;   // מחיר: כמו "12.50"
const HAS_UPPER = /[A-Z]/g;    // סיסמה: לפחות אות גדולה אחת

לכל אחד: (1) תן קלט שבו הבודק טועה, ומה הוא מחזיר. (2) תקן אותו.

P08-E83 · בודקי קלט לטופס 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 5

השלם שלוש פונקציות שמחזירות true או false. כל אחת עם regex אחד ו־test:

  • isMobile(text) — נייד ישראלי: 05, עוד ספרה, מקף אופציונלי, ו־7 ספרות. ("052-1234567", "0541234567")
  • isPostalCode(text) — בדיוק 7 ספרות.
  • isUsername(text) — 3 עד 16 תווים. התו הראשון אות לטינית קטנה, ואחריו אותיות קטנות, ספרות או _.
isMobile("052-1234567");  // true
isMobile("052-123456");   // false
isPostalCode("6100000");  // true
isUsername("dana_2026");  // true
isUsername("2dana");      // false

P08-E84 · לפרק שורת לוג 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 5

כל שורה בלוג של השרת נראית כך:

2026-11-19T08:30:00Z GET /tasks/42 200 13ms

כתוב parseLogLine(line) שמחזירה { time, method, path, status, ms }. ‏status ו־ms מספרים, והשאר מחרוזות. ‏method הוא אחד מ־GET, ‏POST, ‏PUT, ‏PATCH, ‏DELETE. ‏path מתחיל ב־/ ואין בו רווחים. שורה שלא בפורמט (גם רווח מיותר) ← null.

parseLogLine("2026-11-19T08:30:00Z GET /tasks/42 200 13ms");
// { time: "2026-11-19T08:30:00Z", method: "GET", path: "/tasks/42", status: 200, ms: 13 }
parseLogLine("server started"); // null

📄 כותבים בקובץ 08-modules-errors/starter/P08-E84.js (יש בו רק הערה). בסוף הקובץ: module.exports = { parseLogLine };

% node 08-modules-errors/starter/P08-E84.js
% npm run check P08-E84

P08-E85 · camelCase ו־snake_case 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 5

במסד הנתונים השדות כתובים created_at (snake_case), ובקוד JavaScript ‏createdAt (camelCase). כתוב שתי פונקציות המרה, כל אחת עם replace אחד:

  • snakeToCamel(name) — כל _ ואחריו אות קטנה ← האות הגדולה, בלי ה־_.
  • camelToSnake(name) — כל אות גדולה ← _ והאות הקטנה.
snakeToCamel("created_at_utc");    // "createdAtUtc"
camelToSnake("orderItemsCount");   // "order_items_count"
snakeToCamel("id");                // "id"

📄 כותבים בקובץ 08-modules-errors/starter/P08-E85.js (יש בו רק הערה). בסוף הקובץ: module.exports = { snakeToCamel, camelToSnake };

% node 08-modules-errors/starter/P08-E85.js
% npm run check P08-E85

P08-E86 · מחיר מטקסט, באגורות 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 2, שיעור 2, שיעור 5

משתמשים מקלידים מחיר בטופס. כתוב parsePrice(text) שמחזירה את המחיר באגורות (מספר שלם). מותר:

  • רווחים בהתחלה ובסוף, ו־₪ אופציונלי בהתחלה (אולי עם רווח אחריו).
  • שקלים: ספרות רצופות (1234), או עם פסיק כל שלוש ספרות (1,234).
  • אגורות: אופציונלי, נקודה ואחריה ספרה אחת או שתיים.

כל דבר אחר ← זורקים שגיאה, עם הטקסט המקורי בהודעה:

throw new Error(`מחיר לא תקין: "${text}"`);
parsePrice("12");           // 1200
parsePrice("12.5");         // 1250
parsePrice(" ₪ 1,234.50 "); // 123450
parsePrice("12,50");        // Error: מחיר לא תקין: "12,50"

📄 כותבים בקובץ 08-modules-errors/starter/P08-E86.js (יש בו רק הערה). בסוף הקובץ: module.exports = { parsePrice };

% node 08-modules-errors/starter/P08-E86.js
% npm run check P08-E86

🔗 איך זה מתחבר: regex עם groups (שיעור 5) מפרק את הקלט, throw (שיעור 2) עוצר קלט לא תקין עם הודעה ברורה, ו־padEnd (פרק 2) משלים אגורות. ובאגורות, ולא Number("12.5") * 100, בגלל בעיית העשרוניים מפרק 2.
