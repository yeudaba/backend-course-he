P08-E96 · חיפוש של משתמש, try ו־finally

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2, שיעור 5

בלי להריץ — מה יודפס, ובאיזה סדר?

function search(lines, query) {
  try {
    const re = new RegExp(query, "i");
    return lines.filter((line) => re.test(line));
  } catch (err) {
    console.log(`✘ ${err.name}`);
    return [];
  } finally {
    console.log(`חיפוש: ${query}`);
  }
}

function orderId(text) {
  return text.match(/#(\d+)/)[1];
}

const lines = ["Order #12 paid", "order #7 new", "Refund (partial)"];
console.log(search(lines, "order"));
console.log(search(lines, "(partial"));
try {
  console.log(orderId("Order #12 paid"), orderId("Refund (partial)"));
} catch (err) {
  console.log(err instanceof TypeError, err.message);
}

🔗 איך זה מתחבר: שיעור 2: ‏try, ‏catch ו־finally, ושגיאות שיש להן name ו־message. שיעור 5: ‏new RegExp מטקסט של משתמש, ו־match שמחזיר null. שתי השגיאות כאן הן שתי הטעויות הנפוצות בתיבה של שיעור 5. השאלה היא מי תופס אותן.

P08-E99 · לקרוא קובץ .env 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 6, פרק 7, שיעור 2, שיעור 5

בקובץ .env שומרים הגדרות של שרת (נשתמש בו בפרק 13). כתוב parseEnv(text) שמקבלת את התוכן שלו ומחזירה אובייקט:

  • ירידת שורה: \n או \r\n.
  • שורה ריקה (או רק רווחים), ושורה שמתחילה ב־# (אחרי רווחים) — מדלגים.
  • אחרת: KEY=VALUE. ‏KEY הוא אות לטינית גדולה או _, ואחריה אותיות גדולות, ספרות או _. מותרים רווחים סביב ה־=.
  • VALUE בלי הרווחים שמסביב. אם הוא עטוף במירכאות כפולות, הן יורדות, והתוכן שבתוכן נשאר כמו שהוא. ‏= בתוך הערך הוא חלק מהערך.
  • מפתח שחוזר: הערך האחרון קובע.
  • כל שורה אחרת ← זורקים שגיאה עם מספר השורה (מ־1) והשורה עצמה:
throw new Error(`שורה ${n}: לא בפורמט KEY=VALUE: "${line}"`);
parseEnv('# שרת\nPORT = 3000\n\nAPP_NAME="My App"\nDB_URL=postgres://u:p@h/db?x=1');
// { PORT: "3000", APP_NAME: "My App", DB_URL: "postgres://u:p@h/db?x=1" }
parseEnv("PORT=3000\nport=4000");
// Error: שורה 2: לא בפורמט KEY=VALUE: "port=4000"

P08-E100 · סיכום של קובץ לוג 🤖

ב־P08-E84 פירקת שורת לוג אחת. עכשיו כל הקובץ. כתוב מודול ES (.mjs) שמייצא summarizeLog(text):
