P08-E30 · קובץ שנטען פעמיים 🧠 הבנה רמה 2

💡 רמז 2

"logger נטען" מודפס פעם אחת, ורק כשמגיעים לשורת ה־require — לא לפני "main התחיל". יש count אחד, שמשותף לכל מי שמייבא את הקובץ — לכן "שני" קיבל 2. משתנה ברמה העליונה של מודול הוא כמו משתנה פרטי של closure (פרק 5) שכל הקובץ חולק.

P08-E32 · ייצוא default מול ייצוא בשם 🧠 הבנה רמה 2

💡 רמז 1

את ייצוא ה־default מייבאים בלי סוגריים מסולסלים, ובכל שם שרוצים. ייצוא בשם — רק בשם המדויק, בתוך { }.

💡 רמז 2

האם יש ב־logger.mjs ייצוא בשם log? (השם של הפונקציה לא נחשב — היא יוצאה כ־default.)

✅ פתרון
% node playground/e32/a.mjs
LOG: info
% node playground/e32/b.mjs
SyntaxError: The requested module './logger.mjs' does not provide an export named 'log'

a.mjs עובד: write הוא שם חדש שבחרנו ל־default, ו־LEVEL מגיע בשם. b.mjs נכשל עוד לפני שהקוד רץ — ב־ESM, Node בודק את כל הייבואים מראש. זה היתרון של ייצוא בשם: שגיאת כתיב נתפסת מיד, ולא כ־undefined שמתגלה מאוחר (P08-E38).

⚠️ טעויות נפוצות
  • import { default } from ... — לא חוקי. default מייבאים בלי סוגריים.

P08-E33 · מה לייצא? 🧠 הבנה רמה 2

💡 רמז 1

שאל: מה מי שמשתמש בקובץ צריך? מה הוא פרט פנימי שאולי תשנה מחר?

💡 רמז 2

אם hasDigit מיוצא, ומישהו בקובץ אחר משתמש בו — מה קורה כשתרצה לשנות לו את השם?

✅ פתרון

module.exports = { validatePassword, passwordStrength }; — רק שתי הפונקציות שהאפליקציה צריכה. MIN_LENGTH, ‏COMMON, ‏hasDigit ו־isCommon הם פרטי מימוש: אם מחר תחליף את הרשימה בקובץ של 10,000 סיסמאות, או תמזג את hasDigit לתוך פונקציה אחרת — אף קובץ אחר לא יישבר.

ייצוא של הכול "ליתר ביטחון" הופך כל פרט פנימי להבטחה: ברגע שמישהו משתמש בו, אי אפשר לשנות אותו בלי לחפש בכל הפרויקט. הכלל: מייצאים כמה שפחות — את ה"ממשק", לא את המימוש. (בבודקים של הקורס לפעמים מייצאים גם פונקציות עזר — כדי שאפשר יהיה לבדוק כל אחת לבד.)

⚠️ טעויות נפוצות
  • לייצא את MIN_LENGTH כדי ש"הטופס ידע מה האורך" — ואז שני מקומות מחליטים מה החוק. עדיף שהטופס יציג את ההודעה ש־validatePassword מחזירה.

P08-E07 · אותו דבר ב־ES Modules 🤖 💻 כתיבת קוד 🤖 רמה 2

✅ פתרון
// P08-E07: ES Modules
const words = (text) => text.trim().split(" ").filter((w) => w !== "");

export function slugify(text) {
  return words(text.toLowerCase()).join("-");
}

export function wordCount(text) {
  return words(text).length;
}

export default function summary(text) {
  return `${wordCount(text)} מילים: ${slugify(text)}`;

⚠️ טעויות נפוצות

P08-E26 · מודול כסף ב־ES Modules 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

ב־money.mjs: Math.round(shekels * 100), ו־(agorot / 100).toFixed(2). בראש P08-E26.mjs: import { toAgorot, formatILS } from "./P08-E26-money.mjs"; — עם ./ ועם הסיומת.

💡 רמז 2

prices.map(toAgorot) נותן מערך של מספרים שלמים. מחברים עם reduce, ומעצבים את התוצאה עם formatILS.

✅ פתרון
// P08-E26: מודול כסף
export function toAgorot(shekels) {
  return Math.round(shekels * 100);
}

export function formatILS(agorot) {
  return `₪${(agorot / 100).toFixed(2)}`;
}
// P08-E26: סכום עגלה, באגורות
import { toAgorot, formatILS } from "./P08-E26-money.mjs";

export function cartTotal(prices) {
  const total = prices.map(toAgorot).reduce((sum, a) => sum + a, 0);
  return formatILS(total);
}

console.log(cartTotal([19.9, 0.1, 5]));
console.log(cartTotal([0.1, 0.2]));
% node 08-modules-errors/starter/P08-E26.mjs
₪25.00
₪0.30

החלוקה לשני קבצים היא לא רק סדר. money.mjs יודע על כסף ולא יודע על עגלות, ולכן אפשר להשתמש בו גם בדוח, בקבלה ובפרויקט 1. cartTotal לא יודעת איך מעגלים או מעצבים — היא רק מחברת.

prices.map(toAgorot): מעבירים את הפונקציה עצמה, בלי סוגריים, ו־map קוראת לה על כל מחיר (פרק 5, "פונקציה כערך"). החיבור קורה על מספרים שלמים, ולכן 0.1 + 0.2 לא מייצר שארית.

⚠️ טעויות נפוצות
  • from "./P08-E26-money" בלי .mjs — ב־ES Modules הסיומת חובה: ERR_MODULE_NOT_FOUND.
  • shekels * 100 בלי Math.round — ‏1989.9999999999998 אגורות.
  • לחבר בשקלים ולהמיר בסוף — עם [0.1, 0.2] זה עדיין עובד בזכות העיגול, אבל בסכומים גדולים השגיאה מצטברת. ההמרה קורה מיד, לכל מחיר.

P08-E37 · קובץ index שמאחד מודולים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

spread של אובייקטים (פרק 7):

⚠️ טעויות נפוצות
  • module.exports = { strings, numbers }; — מייצא שני אובייקטים, והמשתמש צריך strings.capitalize.
  • שתי שורות module.exports = ... — השנייה דורסת את הראשונה.

const { orderErrors } = require("./P08-E41-validate");

function splitOrders(orders) {
  const valid = [];
  const invalid = [];
  for (const o of orders) {
    const errors = orderErrors(o);
    if (errors.length === 0) {
      valid.push(o.id);
    } else {
      invalid.push({ id: o.id, errors });
    }
  }
  return { valid, invalid };
}

module.exports = { splitOrders };
08-modules-errors/starter/P08-E41-validate.js 
function orderErrors(order) {
  const errors = [];
  if (!order.email.includes("@")) {
    errors.push("אימייל לא תקין");
  }
  if (order.items.length === 0) {
    errors.push("הזמנה ריקה");
  }
  if (order.items.some((i) => !Number.isInteger(i.qty) || i.qty < 1)) {
    errors.push("כמות לא תקינה");
  }
  return errors;
}

module.exports = { orderErrors };

הזמנה ריקה לא מקבלת גם "כמות לא תקינה": some על מערך ריק מחזיר false (P06-E61).

export function groupBy(list, keyFn) {
  const groups = new Map();
  for (const item of list) {
    const key = keyFn(item);
    if (!groups.has(key)) {
      groups.set(key, []);
    }
    groups.get(key).push(item);
  }
  return groups;
}

export default function countByStatus(orders) {
  const groups = groupBy(orders, (o) => o.status);
  return Object.fromEntries([...groups].map(([status, list]) => [status, list.length]));
}

import rates from "./P08-E43-rates.mjs";

const SYMBOLS = { ILS: "₪", USD: "$", EUR: "€" };

export function convert(amount, from, to) {
  if (rates[from] === undefined || rates[to] === undefined) {
    return null;
  }
  return Math.round((amount * rates[from] / rates[to]) * 100) / 100;
}

export function formatMoney(amount, currency) {
  const symbol = SYMBOLS[currency];
  if (symbol === undefined) {
    return `${amount.toFixed(2)} ${currency}`;
  }
  return `${symbol}${amount.toFixed(2)}`;
}
