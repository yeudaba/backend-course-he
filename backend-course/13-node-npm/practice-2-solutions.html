P13-E47 · לסגור שרת בצורה מסודרת 🧠 הבנה רמה 1

💡 רמז 1

💡 רמז 2

סעיף 4: process.exit חותך באמצע (P13-E45).

✅ פתרון

  4. מגדירים זמן מקסימלי (למשל 10 שניות): אחריו — יוצאים בכל זאת, עם קוד יציאה שמסמן בעיה. גם Docker עצמו שולח SIGKILL (שאי אפשר לתפוס) אחרי זמן קצוב. נממש את זה בפרק 24.

P13-E08 · ארגומנטים עם דגלים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

לולאה עם אינדקס, כי לפעמים "צורכים" גם את האיבר הבא (i++).

💡 רמז 2

--a=b: const eq = arg.indexOf("=").

✅ פתרון
// P13-E08
export function parseArgs(argv) {
  const positional = [];
  const flags = {};
  for (let i = 0; i < argv.length; i++) {
    const arg = argv[i];
    if (!arg.startsWith("--")) {
      positional.push(arg);
      continue;
    }
    const body = arg.slice(2);
    const eq = body.indexOf("=");
    if (eq !== -1) {
      flags[body.slice(0, eq)] = body.slice(eq + 1);
    } else if (i + 1 < argv.length && !argv[i + 1].startsWith("--")) {
      flags[body] = argv[i + 1];
      i++;
    } else {
      flags[body] = true;
    }
  }
  return { positional, flags };
}

console.log(parseArgs(["add", "--amount", "5", "--note=hi there", "--dry", "--x"]));
{
  positional: [ 'add' ],
  flags: { amount: '5', note: 'hi there', dry: true, x: true }
}

שים לב לעמימות: --dry food — האם food הוא הערך של dry? לפי הכלל שלנו, כן. לכן כלים אמיתיים מגדירים מראש אילו דגלים בוליאניים. ל־Node יש util.parseArgs מובנה שעושה בדיוק את זה.

⚠️ טעויות נפוצות
  • לשכוח i++ אחרי שצרכת ערך — הוא יופיע גם כ־positional.

P13-E09 · משתני סביבה מוקלדים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

✅ פתרון
// P13-E09
export function envInt(env, name, fallback) {
  const raw = env[name]?.trim();
  if (raw === undefined || raw === "") return fallback;
  if (!/^-?\d+$/.test(raw)) throw new Error(`${name} חייב להיות מספר שלם`);
  return Number(raw);
}

export function envBool(env, name, fallback) {
  const raw = env[name]?.trim().toLowerCase();
  if (raw === undefined || raw === "") return fallback;
  if (["true", "1", "yes", "on"].includes(raw)) return true;
  if (["false", "0", "no", "off"].includes(raw)) return false;
  throw new Error(`${name} חייב להיות בוליאני`);
}

console.log(envInt({ PORT: "8080" }, "PORT", 3000), envBool({ DEBUG: "False" }, "DEBUG", true));
8080 false

הבאג שזה מונע: if (process.env.DEBUG) — המחרוזת "false" היא truthy, ולכן DEBUG=false מפעיל דיבוג.

⚠️ טעויות נפוצות
  • Boolean(env.DEBUG) — "false" ← true.

P13-E14 · CLI קטן עם קוד יציאה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

parseArgs({ args: argv, options: { name: { type: "string" }, times: { type: "string" }, shout: { type: "boolean" } }, strict: true }) — זורק על דגל לא מוכר.

💡 רמז 2

ההודעה של parseArgs באנגלית — תפוס ותחליף. שם הדגל מופיע בה; או בדוק בעצמך לפני הקריאה.

✅ פתרון
// P13-E14
import { parseArgs } from "node:util";

const KNOWN = ["name", "times", "shout"];

export function run(argv, { log = console.log, error = console.error } = {}) {
  const unknown = argv.find((a) => a.startsWith("--") && !KNOWN.includes(a.slice(2).split("=")[0]));
  if (unknown) {
    error(`דגל לא מוכר: ${unknown.split("=")[0]}`);
    return 2;
  }
  const { values } = parseArgs({
    args: argv,
    options: { name: { type: "string" }, times: { type: "string" }, shout: { type: "boolean" } },
    strict: true,
  });
  if (!values.name) {
    error("חסר --name");
    return 2;
  }
  const times = values.times === undefined ? 1 : Number(values.times);
  if (!Number.isInteger(times) || times < 1 || times > 10) {
    error("--times חייב להיות בין 1 ל־10");
    return 2;
  }
  const text = `שלום, ${values.name}!`;
  for (let i = 0; i < times; i++) {
    log(values.shout ? text.toUpperCase() : text);
  }
  return 0;
}

console.log(run(["--name", "Dana", "--times", "2", "--shout"]));
שלום, DANA!
שלום, DANA!
0

קוד 2 לשימוש שגוי — מוסכמה של כלים ב־Unix (1 = כישלון כללי).

⚠️ טעויות נפוצות
  • להחזיר 0 גם בשגיאה — סקריפט שמשתמש בכלי לא יידע שמשהו נכשל.

P13-E48 · אילו משתנים מוגדרים? 🤖 💻 כתיבת קוד 🤖 רמה 2

✅ פתרון
// P13-E48: אילו משתנים מוגדרים?
export function envStatus(env, names) {
  return names.map((name) => {
    const v = env[name];
    if (v === undefined) return `${name}: חסר`;
    if (v.trim() === "") return `${name}: ריק`;
    return `${name}: מוגדר`;
  });
}

P13-E49 · CLI שמסכם מספרים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

שלב 1: if (args.length === 0) { error(...); return 2; }. שלב 2: לולאה שממירה ובודקת — לפני שמדפיסים משהו.

💡 רמז 2

Number("") הוא 0 — בדוק גם arg.trim() === "". ו־import.meta.main (‏Node 24) הוא true רק בקובץ שהורץ ישירות.

✅ פתרון
// P13-E49: CLI שמסכם מספרים
export function runSum(args, { log, error }) {
  if (args.length === 0) {
    error("שימוש: sum <מספרים...>");
    return 2;
  }
  let sum = 0;
  for (const arg of args) {
    const n = Number(arg);
    if (arg.trim() === "" || Number.isNaN(n)) {
      error(`"${arg}" אינו מספר`);
      return 1;
    }
    sum += n;
  }
  log(sum);
  return 0;
}

if (import.meta.main) {
  process.exitCode = runSum(process.argv.slice(2), { log: console.log, error: console.error });
}

console.log(runSum(["1", "2", "3.5"], { log: console.log, error: console.error }));
console.log(runSum(["1", "abc"], { log: console.log, error: console.log }));

0
"abc" אינו מספר
1
שימוש: sum <מספרים...>

(ההדגמה רצה בלי ארגומנטים, ולכן גם הבלוק של import.meta.main רץ: הודעת השימוש — השורה האחרונה בפלט — נכתבה ל־stderr, וקוד היציאה של ההרצה הוא 2.) ההפרדה בין runSum (לוגיקה: מקבלת מערך, מחזירה מספר) לבין שתי השורות שבתחתית (חיבור לעולם: process.argv, console, exitCode) — היא מה שמאפשר לבדוק כלי CLI בלי להריץ תהליכים. אותו רעיון כמו DI מפרק 12.

  • להדפיס סכום חלקי לפני שגילית ארגומנט לא תקין.

P13-E50 · כיבוי מסודר 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

יוצרים מראש let finish; const done = new Promise((r) => (finish = r)); ומחזירים את done. ב־handler: if (started) return; started = true;

💡 רמז 2

for (const fn of [...cleanups].reverse()) { try { await fn(); } catch (err) { ...; failed = true; } } — בתוך handler שהוא async.

✅ פתרון
// P13-E50: כיבוי מסודר
export function onShutdown(proc, cleanups, log) {
  let started = false;
  let finish;
  const done = new Promise((resolve) => (finish = resolve));

  async function handler(signal) {
    if (started) return;
    started = true;
    log(`התקבל ${signal}, סוגר...`);
    let failed = false;
    for (const fn of [...cleanups].reverse()) {
      try {
        await fn();
      } catch (err) {
        log(`ניקוי נכשל: ${err.message}`);
        failed = true;
      }
    }
    proc.exitCode = failed ? 1 : 0;
    log("סיום");
    finish();
  }

  proc.on("SIGINT", () => handler("SIGINT"));
  proc.on("SIGTERM", () => handler("SIGTERM"));
  return done;
}

const handlers = {};
const fakeProc = { exitCode: undefined, on: (sig, fn) => (handlers[sig] = fn) };
const done = onShutdown(fakeProc, [
  async () => console.log("  סוגר מסד נתונים"),
  async () => { throw new Error("השרת כבר סגור"); },
  async () => console.log("  מפסיק לקבל בקשות"),
], console.log);
handlers.SIGTERM();
handlers.SIGINT();
await done;
console.log("exitCode:", fakeProc.exitCode);

הסדר ההפוך הוא הסדר הנכון: בעלייה פתחנו מסד ← שרת, ולכן בכיבוי — קודם מפסיקים לקבל בקשות ורק אחר כך סוגרים את המסד (P13-E47). ‏proc מוזרק, ולכן אפשר לבדוק את כל זה בלי לשלוח אותות אמיתיים לתהליך. בשרת: onShutdown(process, [closeDb, closeServer], console.log).

⚠️ טעויות נפוצות
  • להריץ את ה־cleanups במקביל — המסד נסגר בזמן שבקשות עוד משתמשות בו.
  • לעצור בכישלון הראשון — שאר המשאבים נשארים פתוחים.
  • process.exit בסוף — חותך כתיבה ללוג שעוד לא הסתיימה (P13-E45).

P13-E54 · הגדרות מדגלים וממשתני סביבה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

💡 רמז 2

// P13-E54: הגדרות מדגלים וממשתני סביבה
export function resolveSettings(args, env) {
  let portText;
  let verbose = env.VERBOSE === "1";
  let name;
  for (let i = 0; i < args.length; i++) {
    const a = args[i];
    if (a === "--port") {
      portText = args[i + 1];
      i++;
    } else if (a.startsWith("--port=")) {
      portText = a.slice("--port=".length);
    } else if (a === "--verbose") {
      verbose = true;
    } else if (a.startsWith("--")) {
      throw new Error(`דגל לא מוכר: ${a}`);
    } else if (name === undefined) {
      name = a;
    }
  }
  const text = portText ?? env.PORT ?? "3000";
  const port = Number(text);
  if (!/^\d+$/.test(text) || port < 1 || port > 65535) throw new Error(`port לא תקין: ${text}`);
  return { port, verbose, name: name ?? "app" };
}

console.log(resolveSettings(["shop", "--port", "9000"], { PORT: "8080" }));
console.log(resolveSettings(["--port=7000", "--verbose"], {}));
console.log(resolveSettings([], { PORT: "8080", VERBOSE: "1" }));
try {
  resolveSettings(["--prot", "1"], {});
} catch (err) {
  console.log(err.message);
}
{ port: 9000, verbose: false, name: 'shop' }
{ port: 7000, verbose: true, name: 'app' }
{ port: 8080, verbose: true, name: 'app' }
דגל לא מוכר: --prot

סדר העדיפויות (דגל ← סביבה ← ברירת מחדל) מתבטא בשורה אחת עם ??. והבדיקה נעשית אחרי הבחירה — כך גם ערך לא תקין ב־PORT נתפס, אבל רק אם באמת משתמשים בו.

⚠️ טעויות נפוצות
  • להתעלם מדגל לא מוכר — --prot 1 (שגיאת כתיב) עובר בשקט, והשרת עולה על פורט אחר ממה שחשבת.
  • portText || env.PORT — ‏--port= (ריק) נופל בשקט לערך הסביבה.

💡 רמז 1

💡 רמז 2

✅ פתרון
// P13-E55: כלי שסופר פריטים בקובץ JSON
export async function countItems(args, { log, error, readFile }) {
  if (args.length !== 1) {
    error("שימוש: count <file>");
    return 2;
  }
  const [file] = args;
  let text;
  try {
    text = await readFile(file, "utf8");
  } catch (err) {
    if (err.code === "ENOENT") {
      error(`הקובץ לא נמצא: ${file}`);
      return 1;
    }
    throw err;
  }
  let data;
  try {
    data = JSON.parse(text);
  } catch {
    data = null;
  }
  if (!Array.isArray(data)) {
    error(`${file}: צריך מערך JSON`);
    return 1;
  }
  log(`${file}: ${data.length} פריטים`);
  return 0;
}

import fs from "node:fs/promises";

console.log(await countItems([], io));

1
שימוש: count <file>
2

"שגיאה צפויה" (אין קובץ, תוכן שבור) הופכת להודעה ברורה וקוד יציאה. "לא צפויה" (אין הרשאה, דיסק מלא) נזרקת — ותיראה כ־stack trace, כי מי שמתחזק את הכלי צריך לדעת עליה. ‏readFile מוזרק — בדיוק כמו ה־repository בפרק 12.

⚠️ טעויות נפוצות
  • catch { error("הקובץ לא נמצא") } לכל שגיאה — "אין הרשאה" מדווח כ"לא נמצא", ומבזבזים שעה בחיפוש קובץ שקיים.

// P13-E56: מסך עזרה מיושר
export function formatHelp(tool, commands) {
  const left = commands.map((c) => (c.args ? `${c.name} ${c.args}` : c.name));
  const width = Math.max(0, ...left.map((s) => s.length));
  const lines = [`שימוש: ${tool} <פקודה> [ארגומנטים]`, "", "פקודות:"];
  commands.forEach((c, i) => lines.push("  " + left[i].padEnd(width + 3) + c.desc));
  return lines.join("\n");
}

  { name: "list", args: "", desc: "כל ההוצאות" },
  { name: "report", args: "<month>", desc: "סיכום חודשי" },
]));

  • ${c.name} ${c.args} גם כשאין args — רווח מיותר שמשפיע על היישור.
