P13-E04 · בטוח או לא?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 3

לכל פעולה — בטוחה? אם לא — מה לעשות במקום?

  1. להוסיף .env ל־Git כי "המאגר פרטי".
  2. להוסיף .env.example עם JWT_SECRET=.
  3. לכתוב ב־README את סיסמת המסד של סביבת הפיתוח המשותפת.
  4. console.log(process.env) בעליית השרת.
  5. לשים את אותו JWT_SECRET בפיתוח ובייצור.

P13-E15 · config עם הסתרת סודות 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

בקובץ 13-node-npm/starter/P13-E15.mjs השלם:

  • loadConfig(env) ← אובייקט קפוא (Object.freeze): { port (ברירת מחדל 3000), databaseUrl (חובה), jwtSecret (חובה, לפחות 32 תווים), logLevel ("info" ברירת מחדל; רק debug/info/warn/error) }. כל הבעיות יחד בשגיאה אחת: "הגדרות לא תקינות: DATABASE_URL חסר; JWT_SECRET קצר מדי" (בסדר: DATABASE_URL, JWT_SECRET, PORT, LOG_LEVEL).
  • redact(config) ← עותק שבו כל שדה ששמו מכיל secret, password או url (בלי תלות באותיות) מוחלף ב־"***".

P13-E16 · הגדרות לפי סביבה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

בקובץ 13-node-npm/starter/P13-E16.mjs השלם configFor(env) לפי NODE_ENV (ברירת מחדל "development"; ערך אחר שאינו development/test/production ← Error(NODE_ENV לא מוכר: ${v})):

  • development: databaseUrl ברירת מחדל "postgres://localhost:5432/app_dev", logLevel: "debug", cors: "*".
  • test: databaseUrl ברירת מחדל "postgres://localhost:5432/app_test", logLevel: "error", cors: "*".
  • production: DATABASE_URL ו־CORS_ORIGIN חובה (חסר ← Error(${name} חובה ב־production)), logLevel: "info", cors = CORS_ORIGIN.

משתנה סביבה מפורש תמיד גובר על ברירת מחדל. מחזירה { env, databaseUrl, logLevel, cors }.
