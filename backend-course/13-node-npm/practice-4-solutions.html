P13-E73 · readFile או stream? 🧠 הבנה רמה 1

💡 רמז 1

שאל: מה גודל הקובץ ביחס לזיכרון — וכמה פעמים במקביל זה קורה?

💡 רמז 2

גם קובץ "בינוני" × 1000 בקשות במקביל = הרבה זיכרון.

✅ פתרון
  1. readFile. קטן, פעם אחת — פשוט יותר.
  2. stream. 8GB לא ייכנס לזיכרון (ובכל מקרה — לא צריך את כולו בבת אחת).
  3. שניהם סבירים; stream עדיף בשרת, כי אם 100 משתמשים מעלים בבת אחת — 300MB בזיכרון. ‏createHash יודע לקבל חלקים (update לכל חלק).
  4. stream (readline). מעבדים שורה ושולחים, בלי להחזיק את כל הקובץ — וגם מתחילים לעבוד מיד.
  5. stream, בלי ספק: 1GB × אלף משתמשים = טרה־בייט זיכרון. עם stream, כל הורדה מחזיקה רק חלק קטן בכל רגע.
⚠️ טעויות נפוצות
  • "הקובץ קטן אצלי, אז readFile בסדר" — בייצור הקבצים גדלים, והבקשות מגיעות במקביל.

P13-E74 · כמה שורות ספר readline? 🧠 הבנה רמה 2

💡 רמז 1

השורה האחרונה בקובץ לא מסתיימת ב־\n — האם readline מדלג עליה?

💡 רמז 2

crlfDelay: Infinity מטפל ב־\r\n (סוף שורה של Windows) כשורה אחת שנגמרת. ומה עם split("\n")?

✅ פתרון
import fs from "node:fs";
import os from "node:os";
import path from "node:path";
import readline from "node:readline";

const file = path.join(os.tmpdir(), "p13-e74.log");
fs.writeFileSync(file, "GET /a 200\n\nPOST /b 500\r\nGET /c 404");

const rl = readline.createInterface({ input: fs.createReadStream(file), crlfDelay: Infinity });
let lines = 0;
let empty = 0;
const statuses = [];
for await (const line of rl) {
  lines++;
  if (line === "") {
    empty++;
    continue;
  }
  statuses.push(Number(line.split(" ")[2]));
}
console.log(lines, empty, statuses);
console.log(fs.readFileSync(file, "utf8").split("\n").length);

readline נותן את השורה האחרונה גם בלי \n בסופה, ומסיר את ה־\r של Windows — ולכן 500 יצא מספר נקי. שורה ריקה היא שורה (צריך לדלג בעצמך). ו־split("\n") נותן אותו מספר שורות — אבל משאיר את ה־\r בסוף השורה השלישית. Number אמנם סולח עליו (הוא מתעלם מרווחים לבנים בקצוות), אבל בדיקה כמו line.endsWith("500") או השוואה של מחרוזות — תיכשל בשקט.

⚠️ טעויות נפוצות
  • לשכוח את for await ולכתוב for רגיל — rl אינו מערך, והלולאה זורקת.

P13-E75 · randomUUID, randomBytes או Math.random? 🧠 הבנה רמה 1

💡 רמז 1

השאלה: האם מישהו ירוויח מלנחש את הערך? אם כן — Math.random לא בא בחשבון.

💡 רמז 2

hash הוא דטרמיניסטי (אותו קלט ← אותה תוצאה) — זה בדיוק מה שצריך לזיהוי כפילויות, ובדיוק הבעיה בסיסמאות.

✅ פתרון
  1. randomUUID() — ייחודי, ולא אפשר לנחש את ההזמנה הבאה (בניגוד ל־/orders/1, /orders/2...).
  2. randomBytes(32).toString("hex") — אקראי קריפטוגרפי. מי שמנחש טוקן — משתלט על חשבון.
  3. Math.random() מספיק — אין מה להרוויח מלנחש סדר שאלות.
  4. randomUUID() — ייחודי לכל בקשה.
  5. createHash("sha256") על התוכן — אותו קובץ ← אותו hash.
  6. אף אחד מהם! לסיסמאות — bcrypt/argon2, איטיים בכוונה ועם salt (פרק 21). ‏sha256 מהיר מדי — אפשר לנסות מיליארדי סיסמאות בשנייה.
⚠️ טעויות נפוצות
  • Math.random().toString(36) כטוקן אבטחה — הוא נראה אקראי, אבל אפשר לשחזר את הרצף.

P13-E76 · מה hash מבטיח? 🧠 הבנה רמה 2

💡 רמז 1

hash הוא דטרמיניסטי, ואורך התוצאה קבוע — לא משנה כמה גדול הקלט.

💡 רמז 2

update כמה פעמים = כאילו הכול נשלח ברצף אחד.

✅ פתרון

שלוש תכונות: אותו קלט ← אותה תוצאה; שינוי של אות אחת ← תוצאה אחרת לגמרי; ואורך קבוע (64 תווי hex = 256 ביט). השורה האחרונה היא מה שמאפשר hash על stream: מזינים חלק אחרי חלק (P13-E73, סעיף 3). ומה hash לא נותן: דרך לחזור מהתוצאה לקלט.

⚠️ טעויות נפוצות
  • להשתמש ב־hash כ"הצפנה" — אין מפתח, ואין "פענוח". זה טביעת אצבע.

P13-E11 · נתיב בטוח 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

✅ פתרון
// P13-E11
import path from "node:path";

export function safeJoin(baseDir, userPath) {
  const base = path.resolve(baseDir);
  const full = path.resolve(base, userPath);
  if (full !== base && !full.startsWith(base + path.sep)) {
    throw new Error("נתיב לא מורשה");
  }
  return full;
}

} catch (err) {
  console.log(err.message);

P13-E12 · סטטיסטיקת תיקייה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

fs.readdir(dir, { withFileTypes: true }) נותן אובייקטים עם isFile().

💡 רמז 2

גודל: (await fs.stat(full)).size. במקביל עם Promise.all.

✅ פתרון
// P13-E12
import fs from "node:fs/promises";
import path from "node:path";

export async function dirStats(dir) {
  const entries = await fs.readdir(dir, { withFileTypes: true });
  const files = entries.filter((e) => e.isFile()).map((e) => e.name);
  const sizes = await Promise.all(files.map(async (name) => (await fs.stat(path.join(dir, name))).size));
  const byExtension = {};
  for (const name of files) {
    const ext = path.extname(name).slice(1).toLowerCase() || "(none)";
    byExtension[ext] = (byExtension[ext] ?? 0) + 1;
  }
  return { files: files.length, totalBytes: sizes.reduce((s, n) => s + n, 0), byExtension };
}

const tmp = await fs.mkdtemp(path.join((await import("node:os")).tmpdir(), "stats-"));
await fs.writeFile(path.join(tmp, "a.TXT"), "12345");
await fs.writeFile(path.join(tmp, "Makefile"), "x");
await fs.mkdir(path.join(tmp, "sub"));
console.log(await dirStats(tmp));
{ files: 2, totalBytes: 6, byExtension: { '(none)': 1, txt: 1 } }
⚠️ טעויות נפוצות
  • לספור גם תיקיות — stat של תיקייה מחזיר גודל, וההכללה שגויה.

P13-E17 · שמירת קובץ שהועלה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

path.extname(originalName).toLowerCase()

💡 רמז 2

await fs.mkdir(baseDir, { recursive: true }) ואז writeFile ל־path.join(baseDir, storedName).

✅ פתרון
// P13-E17
import fs from "node:fs/promises";
import path from "node:path";
import { randomUUID } from "node:crypto";

const ALLOWED = [".png", ".jpg", ".jpeg", ".pdf"];

export async function storeUpload(baseDir, originalName, content) {
  const ext = path.extname(originalName).toLowerCase();
  if (!ALLOWED.includes(ext)) {
    throw new Error("סוג קובץ לא נתמך");
  }
  const storedName = `${randomUUID()}${ext}`;
  await fs.mkdir(baseDir, { recursive: true });
  await fs.writeFile(path.join(baseDir, storedName), content);
  return { storedName, originalName: path.basename(originalName), size: Buffer.byteLength(content) };
}

const dir = path.join((await import("node:os")).tmpdir(), "uploads-demo");
const r = await storeUpload(dir, "../../evil/Report.PDF", "hello");
console.log(r.storedName.endsWith(".pdf"), r.originalName, r.size);

שלושה עקרונות אבטחה: (1) אף פעם לא להשתמש בשם שהמשתמש שלח כנתיב; (2) allowlist של סוגים; (3) שומרים את השם המקורי רק כ"מידע" (במסד) להצגה. (בפועל בודקים גם את התוכן — לא רק את הסיומת — ומגבילים גודל.)

P13-E18 · ספירת סטטוסים מלוג 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

for await (const line of rl)

💡 רמז 2

קבוצה: ${Math.floor(status / 100)}xx.

✅ פתרון
// P13-E18
import fs from "node:fs";
import readline from "node:readline";

export async function countStatuses(file) {
  const result = { "2xx": 0, "3xx": 0, "4xx": 0, "5xx": 0, invalid: 0, slowest: null };
  const rl = readline.createInterface({ input: fs.createReadStream(file), crlfDelay: Infinity });
  for await (const raw of rl) {
    const line = raw.trim();
    if (line === "") continue;
    const parts = line.split(/\s+/);
    const status = Number(parts[2]);
    const ms = Number(parts[3]);
    const group = `${Math.floor(status / 100)}xx`;
    if (parts.length !== 4 || !Number.isInteger(status) || Number.isNaN(ms) || !(group in result) || group === "invalid") {
      result.invalid++;
      continue;
    }
    result[group]++;
    if (result.slowest === null || ms > result.slowest.ms) {
      result.slowest = { path: parts[1], ms };
    }
  }
  return result;
}

const path = await import("node:path");
const file = path.join(os.tmpdir(), "demo-access.log");
fs.writeFileSync(file, "GET /a 200 12\nGET /b 404 3\n\nPOST /c 500 900\nbroken line\nGET /d 301 5\n");

  '3xx': 1,

P13-E19 · קבצים כפולים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

💡 רמז 2

✅ פתרון
// P13-E19
import fs from "node:fs";
import fsp from "node:fs/promises";
import path from "node:path";
import { createHash } from "node:crypto";

export async function fileHash(file) {
  const hash = createHash("sha256");
  for await (const chunk of fs.createReadStream(file)) {
    hash.update(chunk);
  }
  return hash.digest("hex");
}

export async function findDuplicates(dir) {
  const entries = await fsp.readdir(dir, { withFileTypes: true });
  const names = entries.filter((e) => e.isFile()).map((e) => e.name);
  const hashes = await Promise.all(names.map((n) => fileHash(path.join(dir, n))));
  const groups = new Map();
  names.forEach((name, i) => {
    const list = groups.get(hashes[i]) ?? [];
    list.push(name);
    groups.set(hashes[i], list);
  });
  return [...groups.values()]
    .filter((g) => g.length > 1)
    .map((g) => g.sort())
    .sort((a, b) => a[0].localeCompare(b[0]));
}

const tmp = await fsp.mkdtemp(path.join((await import("node:os")).tmpdir(), "dups-"));
for (const [name, text] of [["a.txt", "x"], ["b.txt", "y"], ["c.txt", "x"], ["d.txt", "y"], ["e.txt", "z"]]) {
  await fsp.writeFile(path.join(tmp, name), text);
}
console.log(await findDuplicates(tmp));

// P13-E23: מתוקן
import fs from "node:fs";
import readline from "node:readline";

export async function countMatchingLines(file, word) {
  const w = word.toLowerCase();
  const rl = readline.createInterface({ input: fs.createReadStream(file), crlfDelay: Infinity });
  let count = 0;
  for await (const line of rl) {
    if (line.toLowerCase().includes(w)) {
      count++;

  }
  return count;
}

P13-E26 · פירוק שורת לוג עם regex 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

בונים את ה־regex חלק אחר חלק, משמאל לימין: \S+ ("רצף בלי רווחים") ל־ip ולשני המקפים, \[([^\]]+)\] לזמן ("כל מה שאינו ]"), ואז "([A-Z]+) (\S+) HTTP\/[\d.]+". מסיימים ב־(\d{3}) (\d+|-). ‏^ בהתחלה ו־$ בסוף — כדי שכל השורה תתאים, ולא רק חלק ממנה.

💡 רמז 2

קבוצה בשם: (?<ip>\S+). אחרי const m = line.trim().match(LINE) הערכים נמצאים ב־m.groups, ואפשר לפרק אותם: const { ip, time, ... } = m.groups. אם m הוא null — אין התאמה.

✅ פתרון
// P13-E26: פירוק שורת לוג עם regex
const LINE = /^(?<ip>\S+) \S+ \S+ \[(?<time>[^\]]+)\] "(?<method>[A-Z]+) (?<path>\S+) HTTP\/[\d.]+" (?<status>\d{3}) (?<bytes>\d+|-)$/;

export function parseAccessLine(line) {
  const m = line.trim().match(LINE);
  if (!m) {
    return null;
  }
  const { ip, time, method, path, status, bytes } = m.groups;
  return {
    ip,
    time,
    method,
    path,
    status: Number(status),
    bytes: bytes === "-" ? 0 : Number(bytes),
  };
}

console.log(parseAccessLine('203.0.113.7 - - [10/Nov/2026:13:05:01 +0000] "GET /api/users?page=2 HTTP/1.1" 200 512'));
console.log(parseAccessLine('10.0.0.1 - dana [10/Nov/2026:13:05:02 +0000] "DELETE /api/users/7 HTTP/1.1" 204 -'));
console.log(parseAccessLine("משהו אחר לגמרי"));
{
  ip: '203.0.113.7',
  time: '10/Nov/2026:13:05:01 +0000',

  • להחזיר status: "200" — מחרוזת ולא מספר.

import fs from "node:fs/promises";
import path from "node:path";

async function exists(p) {
  try {
    await fs.stat(p);
    return true;
  } catch (err) {
    if (err.code === "ENOENT") return false;
    throw err;
  }
}

export async function freeName(dir, name) {
  const safe = path.basename(name);
  if (!(await exists(path.join(dir, safe)))) return safe;
  const ext = path.extname(safe);
  const base = safe.slice(0, safe.length - ext.length);
  for (let i = 1; ; i++) {
    const candidate = `${base} (${i})${ext}`;
    if (!(await exists(path.join(dir, candidate)))) return candidate;
  }
}

const parse = (v) => v.split(".").map(Number);
function compare(a, b) {
  const x = parse(a);
  const y = parse(b);
  for (let i = 0; i < 3; i++) if (x[i] !== y[i]) return x[i] - y[i];
  return 0;
}
function satisfies(version, range) {
  if (!range.startsWith("^")) return compare(version, range) === 0;
  const min = range.slice(1);
  return compare(version, min) >= 0 && parse(version)[0] === parse(min)[0];
}

export function resolveDeps(rootDeps, registry) {
  const chosen = {};
  const queue = Object.entries(rootDeps);
  while (queue.length > 0) {
    const [name, range] = queue.shift();
    if (chosen[name]) {
      if (!satisfies(chosen[name], range)) {
        throw new Error(`התנגשות: ${name}`);
      }
      continue;
    }
    const versions = Object.keys(registry[name] ?? {}).filter((v) => satisfies(v, range)).sort(compare);
    const best = versions.at(-1);
    if (!best) {
      throw new Error(`אין גרסה של ${name} שמתאימה ל־${range}`);
    }
    chosen[name] = best;
    queue.push(...Object.entries(registry[name][best].deps ?? {}));
  }
  return Object.fromEntries(Object.entries(chosen).sort(([a], [b]) => a.localeCompare(b)));
}

export async function rotate(dir, name, maxFiles) {
  const actions = [];
  const file = (i) => path.join(dir, i === 0 ? name : `${name}.${i}`);
  const label = (i) => (i === 0 ? name : `${name}.${i}`);

  if (await exists(file(maxFiles))) {
    await fs.rm(file(maxFiles));
    actions.push(`delete ${label(maxFiles)}`);
  }
  for (let i = maxFiles - 1; i >= 0; i--) {
    if (await exists(file(i))) {
      await fs.rename(file(i), file(i + 1));
      actions.push(`${label(i)} -> ${label(i + 1)}`);
    }
  }
  await fs.writeFile(file(0), "");
  actions.push(`create ${name}`);
  return actions;
}

import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";

async function readJson(file) {
  const text = await fs.readFile(file, "utf8");
  try {
    return JSON.parse(text);
  } catch {
    throw new Error(`${path.basename(file)}: JSON לא תקין`);
  }
}

export async function loadConfigs(files) {
  const configs = await Promise.all(files.map(readJson));
  return configs.reduce((merged, config) => ({ ...merged, ...config }), {});
}

  • try סביב הכול עם catch שזורק "JSON לא תקין" — קובץ חסר מקבל הודעה שקרית.
