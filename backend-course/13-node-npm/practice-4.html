P13-E74 · כמה שורות ספר readline?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

בלי להריץ — מה יודפס?

import fs from "node:fs";
import os from "node:os";
import path from "node:path";
import readline from "node:readline";

const file = path.join(os.tmpdir(), "p13-e74.log");
fs.writeFileSync(file, "GET /a 200\n\nPOST /b 500\r\nGET /c 404");

const rl = readline.createInterface({ input: fs.createReadStream(file), crlfDelay: Infinity });
let lines = 0;
let empty = 0;
const statuses = [];
for await (const line of rl) {
  lines++;
  if (line === "") {
    empty++;
    continue;
  }
  statuses.push(Number(line.split(" ")[2]));
}
console.log(lines, empty, statuses);
console.log(fs.readFileSync(file, "utf8").split("\n").length);

P13-E77 · שם קובץ פנוי 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

  • מקבלת שם קובץ; לוקחת רק את path.basename(name) (הגנה מ־path traversal).

P13-E78 · readdir ו־stat במקביל

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: פרק 10, שיעור 4

בלי להריץ — מה יודפס? (התיקייה נוצרת בתחילת הקוד, כך שהתוכן ידוע.)

import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";

const dir = await fs.mkdtemp(path.join(os.tmpdir(), "p13-e78-"));
await fs.writeFile(path.join(dir, "b.txt"), "12345");
await fs.writeFile(path.join(dir, "a.log"), "1");
await fs.mkdir(path.join(dir, "sub"));

const names = await fs.readdir(dir);
console.log(names.sort());
const stats = await Promise.all(names.map((n) => fs.stat(path.join(dir, n))));
const files = names.filter((n, i) => stats[i].isFile());
const bytes = stats.reduce((s, st) => s + (st.isFile() ? st.size : 0), 0);
console.log(files, bytes);
const entries = await fs.readdir(dir, { withFileTypes: true });
console.log(entries.filter((e) => e.isDirectory()).map((e) => e.name));
await fs.rm(dir, { recursive: true });

🔗 איך זה מתחבר: פרק 10: Promise.all על map — כל ה־stat יחד, והתוצאות לפי אותו סדר (P10-E80). פרק 6: filter עם אינדקס ו־reduce. השיעור: readdir מחזיר שמות בלבד — את הסוג והגודל צריך לשאול בנפרד (או withFileTypes).

P13-E79 · startsWith — בדיקה שנראית בטוחה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 2, שיעור 4

בדיקה נפוצה ל"האם הנתיב בתוך התיקייה". בלי להריץ — מה יודפס?

import path from "node:path";
const base = "/srv/uploads";

function naive(userPath) {
  const full = path.resolve(base, userPath);
  return full.startsWith(base);
}
function better(userPath) {
  const full = path.resolve(base, userPath);
  const rel = path.relative(base, full);
  return rel !== "" && !rel.startsWith("..") && !path.isAbsolute(rel);
}

for (const p of ["a.png", "../etc/passwd", "../uploads-evil/x.sh", "/srv/uploads/b.png", "."]) {
  console.log(p.padEnd(22), naive(p), better(p));
}

🔗 איך זה מתחבר: פרק 2: startsWith משווה תווים — לא "תיקיות". השיעור: path traversal (הקופסה 🔐), ו־path.relative מ־P13-E72.
