P13-E26 · פירוק שורת לוג עם regex 🤖

✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

שרתי web (nginx, Apache) כותבים כל בקשה כשורה בפורמט קבוע, שנקרא Common Log Format:

203.0.113.7 - - [10/Nov/2026:13:05:01 +0000] "GET /api/users?page=2 HTTP/1.1" 200 512

ב־P13-E18 פירקת שורות פשוטות עם split(" "). כאן split לא מספיק: בתוך הסוגריים המרובעים ובתוך המירכאות יש רווחים. הכלי הנכון הוא ביטוי רגולרי (regex) עם קבוצות בשם.

כתוב וייצא parseAccessLine(line):

  • מחזירה { ip, time, method, path, status, bytes }. ‏time — מה שבין [ ל־]. ‏status ו־bytes — מספרים.
  • כשאין גוף בתשובה השרת כותב - במקום מספר הבתים. במקרה כזה bytes: 0.
  • רווחים בתחילת השורה ובסופה לא מפריעים.
  • שורה שלא בפורמט — null.

📄 כותבים בקובץ 13-node-npm/starter/P13-E26.mjs (יש בו רק הערה), מריצים ובודקים:

% node 13-node-npm/starter/P13-E26.mjs
% npm run check P13-E26

P13-E27 · העלאת גרסה (semver) 🤖

🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 1

🔁 חזרה על switch (פרק 4) ועל destructuring של מערך (פרק 7), על נושא משיעור 1. בגרסה MAJOR.MINOR.PATCH, הפקודה npm version patch (או minor, major) מעלה את אחד החלקים. כתוב וייצא bump(version, kind) שעושה את אותו דבר:

  • "patch": 1.4.2 ← 1.4.3. ‏"minor": ‏1.4.2 ← 1.5.0. ‏"major": ‏1.4.2 ← 2.0.0. שים לב: החלקים שאחרי זה שהועלה מתאפסים.
  • גרסה שאינה בדיוק שלושה מספרים עם נקודות ביניהם ("1.4", ‏"1.4.x", ‏"v1.4.2") ← Error(גרסה לא תקינה: ${version}).
  • סוג אחר ← Error(סוג לא מוכר: ${kind}).
  • כתוב את הבחירה בין הסוגים עם switch.

📄 כותבים בקובץ 13-node-npm/starter/P13-E27.mjs (יש בו רק הערה), מריצים ובודקים:

% node 13-node-npm/starter/P13-E27.mjs
% npm run check P13-E27

בקובץ 13-node-npm/starter/P13-E24.mjs השלם resolveDeps(rootDeps, registry): rootDeps הוא { name: range } (כמו ב־package.json, רק טווחי ^ או גרסה מדויקת), ו־registry הוא { name: { "1.2.0": { deps: { other: "^2.0.0" } }, ... } }. מחזירה { name: version } — לכל חבילה (ישירה ועקיפה) הגרסה הגבוהה שמקיימת את הטווח, ממוין לפי שם. שגיאות:

  • חבילה לא קיימת / אין גרסה מתאימה ← Error(אין גרסה של ${name} שמתאימה ל־${range}).
  • שתי חבילות דורשות טווחים שאין להם גרסה משותפת (כאן — "שטוח": גרסה אחת לכל חבילה) ← Error(התנגשות: ${name}).

אפשר לייבא את maxSatisfying ואת satisfies מ־P13-E13 (העתק את הקוד, או כתוב שוב).
