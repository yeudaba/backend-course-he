P13-E57 · מה Node קורא מ־.env? 🧠 הבנה רמה 2

💡 רמז 1

מירכאות מסביב לערך — לא חלק מהערך. רווחים בקצוות — מנוקים. מה קורה כשאותו מפתח מופיע פעמיים?

💡 רמז 2

בלי --env-file, אף אחד לא קורא את הקובץ.

✅ פתרון
% node --env-file=.env show-env.mjs
PORT = "9090"
APP_NAME = "Dana Shop"
EMPTY = ""
SPACED = "hello world"
GREETING = "שלום # לא הערה"
URL = "postgres://u:p@localhost:5432/shop?ssl=true"
MISSING = undefined
% node show-env.mjs
PORT = undefined
APP_NAME = undefined
...

ההגדרה האחרונה של PORT מנצחת. ‏EMPTY= הוא מחרוזת ריקה — לא undefined (ולכן required בשיעור בודק גם trim() === ""). # בתוך מירכאות הוא חלק מהערך, וה־= וה־? בתוך ה־URL לא מפריעים — רק ה־= הראשון מפריד. ובלי הדגל — הקובץ פשוט לא קיים מבחינת Node.

⚠️ טעויות נפוצות
  • לשכוח את --env-file ב־script של npm start — ואז "הקוד עובד ב־dev ולא ב־start".

P13-E58 · למה להיכשל מוקדם? 🧠 הבנה רמה 1

💡 רמז 1

"fail fast" — עדיף להיכשל במקום שבו הבעיה נוצרה, ומוקדם ככל האפשר.

💡 רמז 2

מערכת הפריסה (פרק 25) יודעת לזהות "השרת לא עלה" ולהשאיר את הגרסה הקודמת.

✅ פתרון
  1. כשהמשתמש הראשון מנסה להתחבר — כלומר לקוח מגלה, בייצור, אולי שעות אחרי העלייה.
  2. הגרוע מכל: חלק מהספריות יחתמו עם מפתח ריק או עם המחרוזת "undefined" — וכל אחד יוכל לזייף טוקן. שגיאה שקטה היא פרצה.
  3. גרסה א׳: השרת לא עולה, מערכת הפריסה רואה שהבדיקה נכשלה ומשאירה את הגרסה הקודמת רצה, וההודעה בלוג אומרת בדיוק מה חסר. בגרסה ב׳ השרת "עלה בהצלחה" — והתקלה מתגלה בבוקר, מלקוחות.
⚠️ טעויות נפוצות
  • ברירת מחדל ל־JWT_SECRET (?? "dev-secret") — "נוח" בפיתוח, וקטסטרופה אם שוכחים להגדיר בייצור (P13-E22).

P13-E59 · Object.freeze — כמה עמוק? 🧠 הבנה רמה 2

💡 רמז 1

ב־ES Modules (strict), השמה לשדה של אובייקט קפוא זורקת.

💡 רמז 2

Object.freeze מקפיא את השדות של האובייקט עצמו. האם config.db הוא אותו אובייקט?

✅ פתרון

  port: 3000,
  db: { url: "postgres://localhost/shop", poolSize: 5 },
  admins: ["dana"],

try {
  config.port = 9999;
} catch (err) {
  console.log(err.name);
}
config.db.poolSize = 50;
config.admins.push("hacker");

3000 50 [ 'dana', 'hacker' ]

freeze "רדוד" — כמו readonly ב־TypeScript (P11-E45): השדה db תמיד מצביע לאותו אובייקט, אבל את האובייקט עצמו מותר לשנות. config עם קבוצות מקוננות צריך הקפאה עמוקה (P13-E65).

⚠️ טעויות נפוצות
  • לחשוב שב־CommonJS (לא strict) זה עובד אותו דבר — שם ההשמה ל־config.port פשוט "נבלעת" בשקט, בלי שגיאה.

P13-E61 · מי מנצח: הטרמינל או .env? 🧠 הבנה רמה 2

💡 רמז 1

משתנה שכבר הוגדר בסביבה (בטרמינל, או ע״י מערכת הפריסה) — האם .env דורס אותו?

💡 רמז 2

ומה Node עושה כשהקובץ שביקשת לא קיים — מתעלם, או נכשל?

✅ פתרון
% node --env-file=.env show-env.mjs
PORT = "9090"
...
% PORT=1234 node --env-file=.env show-env.mjs
PORT = "1234"
...
% node --env-file=missing.env show-env.mjs
node: missing.env: not found
% echo $?
9

משתנה סביבה "אמיתי" גובר על .env — הקובץ רק משלים את מה שחסר. כך אפשר להשאיר --env-file=.env ב־script, ובשרת (או בבדיקה) לדרוס ערך אחד בלי לגעת בקובץ. וקובץ חסר — Node לא עולה בכלל (fail fast גם כאן). אם רוצים "אם קיים" — יש --env-file-if-exists.

⚠️ טעויות נפוצות
  • להניח ש־.env "הוא מקור האמת" — בשרת לרוב אין .env בכלל, והכול מגיע מהסביבה.

P13-E10 · קורא .env 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

indexOf("=") — רק הראשון מפריד.

💡 רמז 2

מירכאות: אם הערך מתחיל ונגמר באותה מירכאה — slice(1, -1).

✅ פתרון
// P13-E10
export function parseDotenv(text) {
  const result = {};
  const lines = text.split("\n");
  for (let i = 0; i < lines.length; i++) {
    const line = lines[i].trim();
    if (line === "" || line.startsWith("#")) continue;
    const eq = line.indexOf("=");
    if (eq === -1) throw new Error(`שורה ${i + 1} לא תקינה`);
    const key = line.slice(0, eq).trim();
    let value = line.slice(eq + 1).trim();
    const q = value[0];
    if ((q === '"' || q === "'") && value.length >= 2 && value.at(-1) === q) {
      value = value.slice(1, -1);
    }
    result[key] = value;
  }
  return result;
}

console.log(parseDotenv('# db\nDATABASE_URL = postgres://a:b@h/db?x=1\nAPP_NAME="Dana Shop"\n\nEMPTY='));
{
  DATABASE_URL: 'postgres://a:b@h/db?x=1',
  APP_NAME: 'Dana Shop',
  EMPTY: ''
}
⚠️ טעויות נפוצות
  • line.split("=") — ערך עם = נחתך.

P13-E15 · config עם הסתרת סודות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

אסוף מערך problems, ובסוף — אם לא ריק — זרוק.

💡 רמז 2

redact: Object.fromEntries(Object.entries(c).map(([k, v]) => [k, /secret|password|url/i.test(k) ? "***" : v])).

✅ פתרון
// P13-E15
const LEVELS = ["debug", "info", "warn", "error"];

export function loadConfig(env) {
  const problems = [];
  if (!env.DATABASE_URL) problems.push("DATABASE_URL חסר");
  if (!env.JWT_SECRET) problems.push("JWT_SECRET חסר");
  else if (env.JWT_SECRET.length < 32) problems.push("JWT_SECRET קצר מדי");
  const port = env.PORT === undefined ? 3000 : Number(env.PORT);
  if (!Number.isInteger(port) || port < 1 || port > 65535) problems.push("PORT לא תקין");
  const logLevel = env.LOG_LEVEL ?? "info";
  if (!LEVELS.includes(logLevel)) problems.push("LOG_LEVEL לא תקין");
  if (problems.length > 0) {
    throw new Error(`הגדרות לא תקינות: ${problems.join("; ")}`);
  }
  return Object.freeze({ port, databaseUrl: env.DATABASE_URL, jwtSecret: env.JWT_SECRET, logLevel });
}

export function redact(config) {
  return Object.fromEntries(
    Object.entries(config).map(([k, v]) => [k, /secret|password|url/i.test(k) ? "***" : v])
  );
}

try {
  loadConfig({ JWT_SECRET: "short" });
} catch (err) {
  console.log(err.message);
}
console.log(redact(loadConfig({ DATABASE_URL: "postgres://u:p@h/db", JWT_SECRET: "x".repeat(32) })));
הגדרות לא תקינות: DATABASE_URL חסר; JWT_SECRET קצר מדי
{ port: 3000, databaseUrl: '***', jwtSecret: '***', logLevel: 'info' }
⚠️ טעויות נפוצות
  • לזרוק על הבעיה הראשונה — מי שמגדיר ייאלץ לנסות שוב ושוב.

P13-E16 · הגדרות לפי סביבה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

אובייקט ברירות מחדל לפי סביבה, ואז env.X ?? defaults.x.

💡 רמז 2

ב־production: אין ברירות מחדל לשדות החובה — בדיוק כדי שלא "יעבוד בטעות" מול מסד לא נכון.

✅ פתרון
// P13-E16
const DEFAULTS = {
  development: { databaseUrl: "postgres://localhost:5432/app_dev", logLevel: "debug", cors: "*" },
  test: { databaseUrl: "postgres://localhost:5432/app_test", logLevel: "error", cors: "*" },
  production: { logLevel: "info" },
};

export function configFor(env) {
  const name = env.NODE_ENV ?? "development";
  const defaults = DEFAULTS[name];
  if (!defaults) {
    throw new Error(`NODE_ENV לא מוכר: ${name}`);
  }
  if (name === "production") {
    for (const key of ["DATABASE_URL", "CORS_ORIGIN"]) {
      if (!env[key]) throw new Error(`${key} חובה ב־production`);
    }
  }
  return {
    env: name,
    databaseUrl: env.DATABASE_URL ?? defaults.databaseUrl,
    logLevel: env.LOG_LEVEL ?? defaults.logLevel,
    cors: env.CORS_ORIGIN ?? defaults.cors,
  };
}

  databaseUrl: 'postgres://localhost:5432/app_dev',
  logLevel: 'debug',
  cors: '*'
}
{
  env: 'production',
  databaseUrl: 'postgres://prod/db',
  logLevel: 'info',
  cors: 'https://shop.example.com'

P13-E62 · required ו־optional 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

const value = env[name]?.trim(); — אם env[name] הוא undefined, התוצאה undefined בלי קריסה.

💡 רמז 2

if (value === undefined || value === "") ... — שני המקרים יחד.

✅ פתרון
// P13-E62: required ו־optional
export function required(env, name) {
  const value = env[name]?.trim();
  if (value === undefined || value === "") throw new Error(`חסר משתנה סביבה: ${name}`);
  return value;
}

export function optional(env, name, fallback) {
  const value = env[name]?.trim();
  return value === undefined || value === "" ? fallback : value;
}

const env = { DATABASE_URL: " postgres://localhost/shop ", LOG_LEVEL: "" };
console.log(required(env, "DATABASE_URL"), optional(env, "LOG_LEVEL", "info"));
try {
  required(env, "JWT_SECRET");
} catch (err) {
  console.log(err.message);
}
postgres://localhost/shop info
חסר משתנה סביבה: JWT_SECRET

שתי פונקציות קטנות שכל מודול config בנוי מהן. הן מקבלות env — ולכן הבודק נותן להן אובייקט רגיל, והשרת נותן process.env.

⚠️ טעויות נפוצות
  • env[name] || fallback בלי trim — " " (רווחים) נחשב ערך.

P13-E63 · בודק לקובץ .env 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

לולאה עם אינדקס על text.split("\n"), ו־Map משם לשורה הראשונה שבה הופיע. אחרי כל אזהרה — continue (אזהרה אחת לשורה).

💡 רמז 2

מירכאות: const q = value[0]; if (q === '"' || q === "'") { if (value.length < 2 || !value.endsWith(q)) ... }

✅ פתרון
// P13-E63: בודק לקובץ .env
export function lintEnv(text) {
  const warnings = [];
  const firstLine = new Map();
  const lines = text.split("\n");
  for (let i = 0; i < lines.length; i++) {
    const n = i + 1;
    const t = lines[i].trim();
    if (t === "" || t.startsWith("#")) continue;
    const eq = t.indexOf("=");
    if (eq === -1) {
      warnings.push(`שורה ${n}: חסר =`);
      continue;
    }
    const name = t.slice(0, eq).trim();
    const value = t.slice(eq + 1).trim();
    if (!/^[A-Z][A-Z0-9_]*$/.test(name)) {
      warnings.push(`שורה ${n}: שם לא תקין: ${name}`);
      continue;
    }
    if (firstLine.has(name)) {
      warnings.push(`שורה ${n}: ${name} מוגדר שוב (קודם בשורה ${firstLine.get(name)})`);
      continue;
    }
    firstLine.set(name, n);
    const q = value[0];
    if (q === '"' || q === "'") {
      if (value.length < 2 || !value.endsWith(q)) warnings.push(`שורה ${n}: מירכאות לא סגורות`);
    } else if (value.includes(" ")) {
      warnings.push(`שורה ${n}: ערך עם רווחים בלי מירכאות`);
    }
  }
  return warnings;
}

console.log(lintEnv('# הגדרות\nPORT=8080\nport=9\nAPP_NAME=Dana Shop\nPORT=1\nTITLE="Hi\nGOOD="a b"\nBROKEN\n'));
[
  'שורה 3: שם לא תקין: port',
  'שורה 4: ערך עם רווחים בלי מירכאות',
  'שורה 5: PORT מוגדר שוב (קודם בשורה 2)',
  'שורה 6: מירכאות לא סגורות',
  'שורה 8: חסר ='
]

כל אזהרה כאן היא באג שראית בפרק: PORT כפול (P13-E57 — האחרון מנצח בשקט), ערך עם רווחים (תלוי בכלי שקורא — חלק חותכים אותו), ושם באותיות קטנות (process.env.PORT לא ימצא את port). כלים כמו dotenv-linter עושים בדיוק את זה, ורצים ב־CI.

⚠️ טעויות נפוצות
  • לרשום שם ב־Map גם כשהשורה קיבלה אזהרה על השם — אז שם לא תקין "תופס" מקום.
  • value.endsWith('"') לבד — ערך שהוא רק " (תו אחד) נחשב סגור.

P13-E64 · מה חסר לי ב־.env? 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

// P13-E64: מה חסר לי ב־.env?
function parse(text) {
  const map = new Map();
  for (const line of text.split("\n")) {
    const t = line.trim();
    if (t === "" || t.startsWith("#")) continue;
    const i = t.indexOf("=");
    if (i === -1) continue;
    const key = t.slice(0, i).trim();
    let value = t.slice(i + 1).trim();
    const q = value.match(/^(["'])(.*)\1$/);
    if (q) value = q[2];
    if (!map.has(key)) map.set(key, value);
  }
  return map;
}

  const extra = [...env.keys()].filter((k) => !example.has(k));

}

    if (typeof value === "object" && value !== null) deepFreeze(value);
  }
  return Object.freeze(obj);

export function buildConfig(env) {
  const problems = [];
  const text = (name) => env[name]?.trim() ?? "";
  const int = (name, fallback, min, max) => {
    const raw = text(name);
    if (raw === "") return fallback;
    const n = Number(raw);
    if (!/^\d+$/.test(raw) || n < min || n > max) {
      problems.push(name);
      return fallback;
    }
    return n;
  };

  const hostRaw = env.HOST;
  if (hostRaw !== undefined && hostRaw.trim() === "") problems.push("HOST");

P13-E69 · הפניות בין משתנים ב־.env 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

פונקציה פנימית resolve(key, stack) שמחזירה את הערך המורחב של key. בתוכה: vars[key].replace(/\$\{(\w+)\}/g, (_, name) => ...).

💡 רמז 2

stack הוא Set של המפתחות שבאמצע הרחבה. אם key כבר בו — מעגל. אחרת: stack.add(key), מרחיבים, ובסוף stack.delete(key).

✅ פתרון
// P13-E69: הפניות בין משתנים ב־.env
export function expand(vars) {
  const done = new Map();
  function resolve(key, stack) {
    if (done.has(key)) return done.get(key);
    if (stack.has(key)) throw new Error(`הפניה מעגלית: ${key}`);
    stack.add(key);
    const value = vars[key].replace(/\$\{(\w+)\}/g, (_, name) => {
      if (!(name in vars)) throw new Error(`משתנה לא מוגדר: ${name} (ב־${key})`);
      return resolve(name, stack);
    });
    stack.delete(key);
    done.set(key, value);
    return value;
  }
  const result = {};
  for (const key of Object.keys(vars)) result[key] = resolve(key, new Set());
  return result;
}

💡 רמז 2

פונקציה convert(type, raw, rule) עם switch, שמחזירה ערך או undefined כשלא תקין. ה־default לא עובר המרה — הוא כבר בטיפוס הנכון.

✅ פתרון
// P13-E70: סכמה למשתני סביבה
const camel = (name) => name.toLowerCase().replace(/_([a-z0-9])/g, (_, c) => c.toUpperCase());

function convert(rule, raw) {
  switch (rule.type) {
    case "string":
      return raw;
    case "int":
      return /^-?\d+$/.test(raw) ? Number(raw) : undefined;
    case "bool": {
      const v = raw.toLowerCase();
      if (v === "true" || v === "1") return true;
      if (v === "false" || v === "0") return false;
      return undefined;
    }
    case "enum":
      return rule.values.includes(raw) ? raw : undefined;
    default:
      throw new Error(`סוג לא מוכר: ${rule.type}`);
  }
}

export function parseEnv(env, schema) {
  const result = {};
  const problems = [];
  for (const [name, rule] of Object.entries(schema)) {
    const raw = env[name]?.trim() ?? "";
    let value;
    if (raw === "") {
      convert(rule, "");
      if (!("default" in rule)) {
        problems.push(`${name}: חסר`);
        continue;
      }
      value = rule.default;
    } else {
      value = convert(rule, raw);
      if (value === undefined) {
        problems.push(`${name}: לא תקין`);
        continue;
      }
    }
    result[camel(name)] = value;
  }
  if (problems.length > 0) throw new Error("הגדרות לא תקינות:\n" + problems.join("\n"));
  return result;
}

export function redact(value) {
  if (Array.isArray(value)) return value.map(redact);
  if (typeof value === "object" && value !== null) {

  return value;
}
