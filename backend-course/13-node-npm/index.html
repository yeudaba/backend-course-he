פרק 13 — Node.js ו־npm

⏱ 3–4 מפגשים

🧰 לפני שמתחילים — פרק 13

מה צריך שכבר יהיה מותקן: Node.js 24+ (npm מגיע איתו), VS Code, הבודק.

מה מתקינים עכשיו: שום תוכנה. בפרק הזה תתקין ספריות לתוך פרויקטים עם npm install — וסוף־סוף תבין מה קרה כשהרצת את זה בפרקים 8 ו־11.

רשות — nvm (מנהל גרסאות Node): בעבודה תפגוש פרויקטים שדורשים גרסאות Node שונות. nvm מאפשר להחזיק כמה גרסאות. לא חובה בקורס — אם תתקין, עקוב אחרי ההוראות הרשמיות בלבד.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 13-node-npm מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה שהסביבה מוכנה — ב־Terminal של VS Code, מתוך ~/dev/backend-course:

% node -v
v24.11.0

(כל גרסה 24 ומעלה תקינה.)

בדיקה נוספת: npm -v מציג גרסה 10 ומעלה.

🎯 בסוף הפרק תדע
  • להבין מה זה package, package.json, node_modules ו־package-lock.json — ומה נכנס ל־Git.
  • להתקין ספריות (dependencies / devDependencies), להבין גרסאות (semver), ולהריץ scripts.
  • לעבוד עם process: ארגומנטים, משתני סביבה, קוד יציאה, אותות.
  • לנהל הגדרות וסודות עם .env ו־--env-file.
  • להשתמש במודולים המובנים: fs/promises, path, crypto, readline.

🤔 למה צריך את זה?

אף שרת לא נכתב מאפס: Express, Prisma, Zod, ספריית תאריכים — כולן חבילות npm. פרויקט Backend טיפוסי תלוי במאות חבילות (ישירות ועקיפות). להבין איך הן מותקנות, איך גרסאות עובדות, ואיך שומרים סודות מחוץ לקוד — זה בסיס לכל פרויקט מכאן והלאה, וחלק מהשאלות הראשונות בראיון.

🏁 מבחן מעבר

  • ליצור פרויקט חדש עם npm init, להתקין חבילה אחת כ־dependency ואחת כ־devDependency, ולהסביר כל שדה שנוסף.
  • להסביר מה אומרות הגרסאות ^4.18.2 ו־~4.18.2, ומה תפקיד ה־lockfile.
  • לכתוב מודול config שקורא מ־process.env, נכשל מוקדם על הגדרה חסרה, ועובד עם node --env-file=.env.
  • לקרוא קובץ גדול שורה־שורה בלי לטעון אותו לזיכרון.
  • npm run check P13: 80% מ־E06–E19, ולפחות תרגיל תיקון אחד.
