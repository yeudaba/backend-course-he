שיעור 2 — process: ארגומנטים, סביבה וקוד יציאה

⏱ ~30 דקות

🎯 בשיעור הזה

האובייקט process — הקשר של התוכנית שלך עם העולם: מה הקלידו, אילו הגדרות קיבלה, איפה היא רצה, ואיך היא מסתיימת.

1. מה יש ב־process

שדהמה זה
process.argvהמילים שבפקודה (פרויקט 1)
process.envמשתני הסביבה — אובייקט של מחרוזות (או undefined)
process.exitCode = 1קוד היציאה כשהתוכנית תסתיים
process.cwd()התיקייה שממנה הורצה הפקודה
import.meta.dirnameהתיקייה שבה נמצא הקובץ (ב־ES Modules)
process.on("SIGINT", fn)מה לעשות כשלוחצים Ctrl+C

2. משתני סביבה

% PORT=8080 NODE_ENV=production node -e 'console.log(process.env.PORT, typeof process.env.PORT, process.env.MISSING)'
8080 string undefined

משתני סביבה הם הדרך המקובלת להעביר לתוכנית הגדרות שמשתנות בין סביבות: פורט, כתובת מסד, מפתחות. אותו קוד רץ במחשב שלך, בבדיקות ובשרת — ורק משתני הסביבה שונים. שים לב: תמיד מחרוזת. process.env.PORT + 1 הוא "80801". (פרק 2 — המר במפורש.)

3. cwd מול dirname

tools/where.mjs 
console.log("הורץ מתוך:", process.cwd());
console.log("הקובץ נמצא ב:", import.meta.dirname);
% cd ~/dev/backend-course
% node tools/where.mjs

הקובץ נמצא ב: /Users/yeuda/dev/backend-course/tools
% cd tools && node where.mjs
הורץ מתוך: /Users/yeuda/dev/backend-course/tools
הקובץ נמצא ב: /Users/yeuda/dev/backend-course/tools

הבאג הקלאסי: fs.readFile("data.json") — נתיב יחסי נפתר לפי cwd, כך שהתוכנית עובדת רק כשמריצים אותה מהתיקייה "הנכונה". לקבצים שצמודים לקוד — path.join(import.meta.dirname, "data.json"). (ב־CommonJS: __dirname.)

4. קוד יציאה

מפרויקט 1 אתה מכיר את process.exitCode. יש גם process.exit(1) — יוצא מיד, גם אם יש פעולות אסינכרוניות באמצע (כתיבה לקובץ, לוג). עדיף process.exitCode ולתת לתוכנית להסתיים בעצמה.

5. Ctrl+C בצורה מסודרת

process.on("SIGINT", () => {
  console.log("\nסוגר חיבורים ויוצא...");
  // server.close(), db.disconnect() ...
  process.exit(0);
});

שרת שנעצר (בפריסה — SIGTERM) צריך לסיים בקשות פתוחות ולסגור חיבורים למסד לפני שהוא יוצא — "graceful shutdown". נממש בפרק 24.
