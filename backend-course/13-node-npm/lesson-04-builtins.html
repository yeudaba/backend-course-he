Node מגיע עם "ספרייה סטנדרטית" עשירה — לפני שמתקינים חבילה, כדאי לבדוק אם יש כבר משהו מובנה. נכיר את אלה שתשתמש בהם הכי הרבה.

1. path

import path from "node:path";
console.log(path.join("data", "..", "uploads", "a.png"));
console.log(path.basename("/srv/app/report.pdf"));
console.log(path.extname("photo.final.jpg"));
console.log(path.resolve("/srv/app", "logs", "today.log"));
uploads/a.png
report.pdf
.jpg
/srv/app/logs/today.log

תמיד path.join ולא חיבור מחרוזות עם "/" — הוא מטפל ב־.., בלוכסנים כפולים, ובהבדלים בין מערכות הפעלה.

🔐 Path traversal

אם משתמש שולח שם קובץ ("../../etc/passwd") ואתה עושה path.join("uploads", name) — יצאת מהתיקייה! שם קובץ מהמשתמש: path.basename(name) (רק השם, בלי תיקיות), ובדיקה שהנתיב הסופי עדיין בתוך התיקייה המותרת (תרגיל E17).

2. fs/promises

import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";

const dir = await fs.mkdtemp(path.join(os.tmpdir(), "demo-"));
await fs.mkdir(path.join(dir, "reports", "2026"), { recursive: true });
await fs.writeFile(path.join(dir, "reports", "2026", "oct.txt"), "שורה 1\n");
await fs.appendFile(path.join(dir, "reports", "2026", "oct.txt"), "שורה 2\n");
console.log(await fs.readdir(path.join(dir, "reports", "2026")));
const stat = await fs.stat(path.join(dir, "reports", "2026", "oct.txt"));
console.log(stat.size > 0, stat.isFile());
await fs.rm(dir, { recursive: true });
[ 'oct.txt' ]
true true

mkdir עם recursive: true יוצר את כל התיקיות בדרך (כמו mkdir -p). fs.rm(..., { recursive: true }) מוחק תיקייה עם כל התוכן — בלי פח. השתמש בזהירות, ותמיד עם נתיב שאתה בנית.

3. readline — קובץ גדול, שורה־שורה

readFile טוען את כל הקובץ לזיכרון. ללוג של 5GB — השרת יקרוס. הפתרון: stream — קריאה בחלקים:

import fs from "node:fs";
import os from "node:os";
import path from "node:path";
import readline from "node:readline";

const file = path.join(os.tmpdir(), "access.log");
fs.writeFileSync(file, "GET /a 200\nGET /b 404\nPOST /c 500\nGET /d 200\n");

const rl = readline.createInterface({ input: fs.createReadStream(file), crlfDelay: Infinity });
let errors = 0;
for await (const line of rl) {
  const status = Number(line.split(" ")[2]);
  if (status >= 400) errors++;
}
console.log(`שגיאות: ${errors}`);
שגיאות: 2

for await — לולאה על "רצף אסינכרוני": כל סיבוב מחכה לשורה הבאה. הזיכרון בשימוש — שורה אחת בכל רגע, לא משנה כמה גדול הקובץ.

4. crypto

import { randomUUID, randomBytes, createHash } from "node:crypto";
console.log(randomUUID().length);
console.log(randomBytes(16).toString("hex").length);
console.log(createHash("sha256").update("hello").digest("hex").slice(0, 16));
36
32
2cf24dba5fb0a30e

randomUUID — מזהים ייחודיים (נשתמש בהם ל־request ID ולמפתחות idempotency). randomBytes — טוקנים אקראיים בטוחים (איפוס סיסמה). createHash — "טביעת אצבע" של תוכן. ⚠️ לא לסיסמאות — לסיסמאות יש אלגוריתמים איטיים בכוונה (bcrypt/argon2, פרק 21). ולעולם לא Math.random() לשום דבר שקשור לאבטחה — הוא צפוי.
