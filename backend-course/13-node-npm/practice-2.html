P13-E48 · אילו משתנים מוגדרים? 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

בעליית השרת רוצים להדפיס אילו משתני סביבה קיימים — בלי להדפיס את הערכים (שיעור 3: לא מדפיסים סודות). כתוב וייצא envStatus(env, names):

  • מחזירה מערך של שורות, אחת לכל שם, לפי הסדר: "PORT: מוגדר", או "JWT_SECRET: חסר".

P13-E49 · CLI שמסכם מספרים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

כתוב וייצא runSum(args, { log, error }) — הלב של כלי sum (‏args הוא process.argv.slice(2)). מחזירה קוד יציאה:

  • בלי ארגומנטים ← error("שימוש: sum <מספרים...>"), מחזירה 2.
  • ארגומנט שאינו מספר ← error("&lt;arg&gt;" אינו מספר) (לראשון שנכשל), מחזירה 1, ולא מדפיסה סכום.
  • אחרת ← log עם הסכום (כמספר, למשל log(6)), מחזירה 0.

ובסוף הקובץ — הפעלה אמיתית, רק כשהקובץ מורץ ישירות (ולא כשהבודק מייבא אותו):

if (import.meta.main) {
  process.exitCode = runSum(process.argv.slice(2), { log: console.log, error: console.error });
}

P13-E50 · כיבוי מסודר 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

כתוב וייצא onShutdown(proc, cleanups, log) — מנגנון כיבוי מסודר (סעיף 5 בשיעור):

  • proc — אובייקט עם on(signal, handler) ושדה exitCode (בשרת — process; בבדיקה — מזויף).
  • רושמת handler ל־"SIGINT" ול־"SIGTERM". כשמגיע אחד מהם: log(התקבל ${signal}, סוגר...), ואז מריצה את cleanups (מערך של פונקציות אסינכרוניות) בסדר הפוך — אחת אחרי השנייה (מה שנפתח אחרון נסגר ראשון).
  • אם cleanup נכשל — log(ניקוי נכשל: ${err.message}), וממשיכים לבאים. בסוף: proc.exitCode = 0 אם הכול הצליח, אחרת 1, ו־log("סיום").
  • אות שני (בזמן שהכיבוי עדיין רץ או אחריו) — מתעלמים ממנו.
  • מחזירה Promise שמסתיים כשהכיבוי הסתיים (ונוצר בעת רישום — כדי שאפשר לחכות לו).

P13-E52 · destructuring של argv

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: פרק 7, שיעור 2

במקום process.argv נשתמש במערך קבוע (כדי שהפלט לא יהיה תלוי באיך מריצים). בלי להריץ — מה יודפס?

const argv = ["/usr/local/bin/node", "/home/dana/expenses.mjs", "add", "קפה", "12.5", "--card"];

const [, , command, ...rest] = argv;
console.log(command, rest);

const [, script] = argv;
console.log(script.split("/").at(-1));

const [, , cmd2 = "help", name2 = "?"] = ["node", "x.mjs"];

const flags = rest.filter((a) => a.startsWith("--")).map((a) => a.slice(2));

P13-E54 · הגדרות מדגלים וממשתני סביבה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 2, פרק 8, שיעור 2

הרבה כלים מקבלים הגדרה גם מדגל וגם ממשתנה סביבה — והדגל גובר. כתוב וייצא resolveSettings(args, env) שמחזירה { port, verbose, name }:

  • port: ‏--port 9000 או --port=9000 ← אחרת env.PORT ← אחרת 3000. מה שנבחר חייב להיות שלם 1–65535, אחרת throw new Error(port לא תקין: ${value}) (עם הטקסט המקורי).
  • verbose: ‏--verbose (בלי ערך) ← true; אחרת env.VERBOSE === "1".
  • name: הארגומנט הראשון שאינו דגל (ולא ערך של --port), או "app".
  • כל דגל אחר ← throw new Error(דגל לא מוכר: ${flag}).
resolveSettings(["shop", "--port", "9000"], { PORT: "8080" }); // { port: 9000, verbose: false, name: "shop" }
resolveSettings([], { PORT: "8080", VERBOSE: "1" });          // { port: 8080, verbose: true, name: "app" }

P13-E55 · כלי שסופר פריטים בקובץ JSON 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 8, פרק 10, שיעור 2

כתוב וייצא async function countItems(args, { log, error, readFile }) — כלי שורת פקודה: count <file> מדפיס כמה איברים יש במערך שבקובץ JSON. מחזירה קוד יציאה:

  • לא בדיוק ארגומנט אחד ← error("שימוש: count <file>"), ‏2.

readFile מוזרק (כמו fs.readFile מ־fs/promises: readFile(file, "utf8")), ולכן הבודק יכול לתת "קבצים" בלי דיסק.

P13-E56 · מסך עזרה מיושר 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: פרק 2, פרק 6, שיעור 2

כל כלי CLI צריך --help. כתוב וייצא formatHelp(tool, commands):

  • commands — מערך של { name, args, desc } (‏args יכול להיות ריק).
  • השורה הראשונה: שימוש: ${tool} &lt;פקודה&gt; [ארגומנטים], ואחריה שורה ריקה ו־"פקודות:".
  • לכל פקודה שורה: שני רווחים, ואז name ו־args (עם רווח ביניהם, או רק name אם אין args), מיושר עם padEnd לאורך של הארוך מביניהם ועוד 3 רווחים, ואז desc.
  • מחזירה מחרוזת אחת עם \n בין השורות.
console.log(formatHelp("expenses", [
  { name: "add", args: "<title> <amount>", desc: "הוספת הוצאה" },
  { name: "list", args: "", desc: "כל ההוצאות" },
]));
// שימוש: expenses <פקודה> [ארגומנטים]
//
// פקודות:
//   add <title> <amount>   הוספת הוצאה
//   list                   כל ההוצאות
