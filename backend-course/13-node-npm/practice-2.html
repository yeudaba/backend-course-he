P13-E08 · ארגומנטים עם דגלים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

בקובץ 13-node-npm/starter/P13-E08.mjs השלם parseArgs(argv) ← { positional: [...], flags: {} }, עם תמיכה ב־--name value, --name=value, ו־--verbose (דגל בלי ערך ← true, אם הבא אחריו גם מתחיל ב־-- או שאין בא). כל השאר — positional.

["add", "--amount", "5", "--note=hi there", "--dry", "food"] ← { positional: ["add", "food"], flags: { amount: "5", note: "hi there", dry: true } }

P13-E09 · משתני סביבה מוקלדים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

בקובץ 13-node-npm/starter/P13-E09.mjs השלם (env הוא אובייקט כמו process.env):

  • envInt(env, name, fallback) — חסר/ריק ← fallback; שלם ← המספר; אחרת ← Error(${name} חייב להיות מספר שלם).
  • envBool(env, name, fallback) — true/1/yes/on ← true; false/0/no/off ← false (בלי תלות באותיות); חסר ← fallback; אחר ← Error(${name} חייב להיות בוליאני).

P13-E14 · CLI קטן עם קוד יציאה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 13-node-npm/starter/P13-E14.mjs השלם run(argv, { log, error }) לכלי greet: greet --name דנה --times 2 [--shout] ← מדפיס (log) "שלום, דנה!" פעמיים (ב־shout — אותיות גדולות, למשל לשם באנגלית). מחזיר קוד יציאה:

  • 0 — הצלחה.
  • 2 — שימוש שגוי: --name חסר, --times לא שלם 1–10, או דגל לא מוכר. ההודעה ב־error(...): "חסר --name" / "--times חייב להיות בין 1 ל־10" / "דגל לא מוכר: --x".

מותר (ומומלץ) להשתמש ב־parseArgs המובנה של Node (import { parseArgs } from "node:util") עם strict: true.
