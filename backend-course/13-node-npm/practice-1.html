P13-E02 · מה מותר?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

לכל זוג — האם הגרסה מקיימת את הטווח?

  1. ^1.2.3 ← 1.2.3 · 1.9.0 · 2.0.0 · 1.2.2
  2. ~1.2.3 ← 1.2.9 · 1.3.0
  3. 1.2.3 ← 1.2.4

ולמה, אם יש lockfile, ייתכן שאצלך מותקנת 1.2.3 ואצל חבר שהוסיף את החבילה היום — 1.9.0?

בקובץ 13-node-npm/starter/P13-E06.mjs השלם:

  • parseVersion("1.2.3") ← [1, 2, 3]; פורמט לא תקין ← זריקת Error(גרסה לא תקינה: ${v}).

P13-E07 · דוח package.json 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

בקובץ 13-node-npm/starter/P13-E07.mjs השלם:

  • depsReport(pkg) ← { prod: [...], dev: [...], total } — שמות ממוינים; שדות חסרים ← רשימה ריקה.
  • scriptLines(pkg) ← מערך "npm run dev → node --watch src/server.js", אבל ל־start ו־test בלי run ("npm start → ...").
  • readPackage(dir) (async) ← קורא את package.json בתיקייה; אין קובץ ← Error("לא נמצא package.json").

P13-E13 · מיון ובחירת גרסאות 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

זה מה ש־npm עושה כשאתה מתקין. בקובץ 13-node-npm/starter/P13-E13.mjs השלם:

  • compareVersions(a, b) ← שלילי/0/חיובי (כמו comparator של sort).
  • satisfies(version, range) — range: "^x.y.z" (ללא המקרה המיוחד של 0), "~x.y.z", או גרסה מדויקת.
  • maxSatisfying(versions, range) ← הגרסה הגבוהה ביותר שמקיימת, או null.

P13-E27 · העלאת גרסה (semver) 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 1

🔁 חזרה על switch (פרק 4) ועל destructuring של מערך (פרק 7), על נושא משיעור 1. בגרסה MAJOR.MINOR.PATCH, הפקודה npm version patch (או minor, major) מעלה את אחד החלקים. כתוב וייצא bump(version, kind) שעושה את אותו דבר:

  • "patch": 1.4.2 ← 1.4.3. ‏"minor": ‏1.4.2 ← 1.5.0. ‏"major": ‏1.4.2 ← 2.0.0. שים לב: החלקים שאחרי זה שהועלה מתאפסים.
  • גרסה שאינה בדיוק שלושה מספרים עם נקודות ביניהם ("1.4", ‏"1.4.x", ‏"v1.4.2") ← Error(גרסה לא תקינה: ${version}).
  • סוג אחר ← Error(סוג לא מוכר: ${kind}).
  • כתוב את הבחירה בין הסוגים עם switch.
