P13-E33 · שם חבילה חוקי 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

ל־npm יש חוקים לשמות חבילות. כתוב וייצא isValidPackageName(name) שמחזירה true רק אם:

  • האורך 1 עד 214 תווים.
  • רק אותיות קטנות באנגלית, ספרות, ו־- . _
  • לא מתחיל ב־. או ב־_.
  • או: שם עם scope — @scope/name, כששני החלקים עומדים בחוקים שלמעלה (וגם ה־scope לא מתחיל ב־./_).
isValidPackageName("express");      // true
isValidPackageName("@types/node");  // true
isValidPackageName("My-Package");   // false — אות גדולה
isValidPackageName(".hidden");      // false

P13-E35 · להוסיף תלות 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

כתוב וייצא addDependency(pkg, name, version, { dev = false } = {}) — מה ש־npm install עושה ל־package.json:

  • מחזירה אובייקט חדש (אסור לשנות את pkg).
  • מוסיפה name: "^" + version ל־dependencies (או ל־devDependencies עם dev: true). אם החלק לא קיים — יוצרת אותו.
  • אם החבילה נמצאת בחלק השני — מעבירה אותה (מוחקת משם). אם אחרי זה החלק השני ריק — מוחקת אותו.
  • המפתחות בחלק שהשתנה ממוינים לפי ה־ABC (כמו ש־npm כותב).
addDependency({ name: "app", dependencies: { zod: "^4.1.5" } }, "express", "5.1.0");
// { name: "app", dependencies: { express: "^5.1.0", zod: "^4.1.5" } }

P13-E36 · מה ישן? (npm outdated) 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

npm outdated מראה אילו תלויות יש להן גרסה חדשה יותר. כתוב וייצא outdated(deps, latest):

  • deps — כמו ב־package.json: { name: "^1.2.3" } (עם ^, ~ או בלי). הגרסה הנוכחית היא המספר שבטווח.
  • latest — { name: "1.4.0" }: הגרסה האחרונה שפורסמה. חבילה שאין לה ערך ב־latest — מדלגים.
  • מחזירה מערך של { name, current, latest, type } רק לחבילות שבהן latest גדולה מהנוכחית, כש־type הוא "major", "minor" או "patch" — החלק הראשון שגדל. ממוין לפי שם.
outdated({ express: "^4.18.2", zod: "~4.1.5", pg: "8.16.0" }, { express: "5.1.0", zod: "4.1.12", pg: "8.16.0" });
// [ { name: "express", current: "4.18.2", latest: "5.1.0", type: "major" },
//   { name: "zod", current: "4.1.5", latest: "4.1.12", type: "patch" } ]

P13-E37 · מה יש ב־lockfile 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

ב־package-lock.json יש שדה packages: המפתח הוא נתיב בתוך node_modules, והערך כולל version (המפתח "" הוא הפרויקט עצמו — מדלגים עליו):

{
  "packages": {
    "": { "name": "app" },
    "node_modules/express": { "version": "5.1.0" },
    "node_modules/debug": { "version": "4.4.1" },
    "node_modules/send/node_modules/debug": { "version": "2.6.9" },
    "node_modules/@types/node": { "version": "24.3.0", "dev": true }
  }
}

כתוב וייצא lockSummary(lock) שמחזירה:

  • total — כמה רשומות (בלי "").
  • prod / dev — כמה מהן עם dev: true וכמה בלי.
  • versions — Map משם החבילה (מה שאחרי ה־node_modules/ האחרון בנתיב — כולל scope כמו @types/node) למערך הגרסאות שלה, ממוין, בלי כפילויות.
  • duplicates — שמות החבילות שמותקנות ביותר מגרסה אחת, ממוינים.

P13-E38 · למיין גרסאות כמו מחרוזות

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 1

בלי להריץ — מה יודפס?

const versions = ["1.10.0", "1.9.0", "1.2.0", "10.0.0", "2.0.0"];
console.log([...versions].sort());
console.log("1.10.0" > "1.9.0", "4.1.12" > "4.1.5");

const asNumbers = (v) => v.split(".").map(Number);
const byNumbers = [...versions].sort((a, b) => {
  const x = asNumbers(a);
  const y = asNumbers(b);
  return x[0] - y[0] || x[1] - y[1] || x[2] - y[2];
});
console.log(byNumbers);

P13-E27 · העלאת גרסה (semver) 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 1

🔁 חזרה על switch (פרק 4) ועל destructuring של מערך (פרק 7), על נושא משיעור 1. בגרסה MAJOR.MINOR.PATCH, הפקודה npm version patch (או minor, major) מעלה את אחד החלקים. כתוב וייצא bump(version, kind) שעושה את אותו דבר:

  • "patch": 1.4.2 ← 1.4.3. ‏"minor": ‏1.4.2 ← 1.5.0. ‏"major": ‏1.4.2 ← 2.0.0. שים לב: החלקים שאחרי זה שהועלה מתאפסים.
  • גרסה שאינה בדיוק שלושה מספרים עם נקודות ביניהם ("1.4", ‏"1.4.x", ‏"v1.4.2") ← Error(גרסה לא תקינה: ${version}).
  • סוג אחר ← Error(סוג לא מוכר: ${kind}).
  • כתוב את הבחירה בין הסוגים עם switch.

P13-E41 · פרטי פרויקט מ־package.json 🤖

P13-E42 · תלויות לפי scope 🤖

כתוב וייצא byScope(pkg) — מקבצת את כל התלויות (dependencies ו־devDependencies יחד) לפי scope:

  • מחזירה Map מ־scope (למשל "@types") למערך שמות מלאים ("@types/node"), ממוין.
  • חבילות בלי scope — תחת המפתח "(ללא)".
  • סדר המפתחות ב־Map: "(ללא)" ראשון (אם קיים), ואחריו ה־scopes לפי ה־ABC.
byScope({ dependencies: { express: "^5", "@prisma/client": "^6" }, devDependencies: { "@types/node": "^24", "@types/express": "^5", eslint: "^9" } });
// Map { "(ללא)" => ["eslint", "express"], "@prisma" => ["@prisma/client"], "@types" => ["@types/express", "@types/node"] }
