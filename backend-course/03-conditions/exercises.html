P03-E05 · truthy, falsy ו־??

P03-E11 · מ־if/else ל־ternary

רמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

כתוב מחדש כל קטע עם ternary ו־const (בלי let), כך שהפלט לא ישתנה:

let status;
if (isOnline) {
  status = "מחובר";
} else {
  status = "לא מחובר";
}

let fee;
if (isExpress) {
  fee = 40;
} else {
  fee = 20;
}

let word;
if (count === 1) {
  word = "הודעה";
} else {
  word = "הודעות";
}
console.log(`${status} | משלוח ${fee} | ${count} ${word}`);

הגדר בעצמך isOnline = true, isExpress = false, count = 3.

P03-E15 · מי רשאי לערוך?

רמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

כללי עריכה של מסמך במערכת:

  • מנהל (role === "admin") — תמיד.
  • עורך ("editor") — רק אם המסמך לא נעול.
  • כותב המסמך — רק אם המסמך לא נעול ולא פורסם.
  • כל השאר — לא.

משתנים: role, isAuthor, isLocked, isPublished. כתוב ביטוי אחד canEdit, והדפס אותו. בדוק לפחות 5 צירופים — כולל מנהל עם מסמך נעול, וכותב של מסמך שפורסם.

P03-E16 · ברירות מחדל לחיפוש

רמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

API לחיפוש מוצרים מקבל פרמטרים אופציונליים. כל אחד יכול להיות undefined (לא נשלח):

const pageParam = undefined;
const limitParam = 0;
const sortParam = "";
const minPriceParam = 0;

כללים: page ברירת מחדל 1; limit ברירת מחדל 20, ואם נשלח 0 או יותר מ־100 — השתמש ב־20; sort ברירת מחדל "newest" — גם אם נשלחה מחרוזת ריקה; minPrice ברירת מחדל 0 (ו־0 חוקי). הדפס:

page=1 limit=20 sort=newest minPrice=0
