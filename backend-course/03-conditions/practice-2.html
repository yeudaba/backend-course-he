P03-E54 · הקלט שלא נכנס ל־if

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 2, שיעורים 1–2

הכמות הגיעה מטופס כטקסט. בלי להריץ — מה יודפס?

const quantityInput = "5";
if (quantityInput === 5) {
  console.log("א: חמש בדיוק");
}
if (quantityInput > 3) {
  console.log("ב: יותר משלוש");
}
if (quantityInput > "10") {
  console.log("ג: יותר מעשר");

P03-E55 · const בלי ערך, let בלי else

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 1, שיעור 2

שתי תוכניות. בלי להריץ — מה יקרה בכל אחת?

// תוכנית א
const age = 20;
const label;
if (age >= 18) {
  label = "בגיר";
}
console.log(label);
// תוכנית ב
const age = 15;
let label;
if (age >= 18) {
  label = "בגיר";
}
console.log(`התווית: ${label}`);

ואז: מה חסר בתוכנית ב, ואיך היית מתקן?

🔗 איך זה מתחבר: בפרק 1 (P01-E61) ראית למה let בלי ערך מותר ו־const לא. הדפוס "let לפני ה־if" מהשיעור הזה בנוי בדיוק על זה — וגם על הסכנה: undefined כשאף בלוק לא הציב.

P03-E56 · toFixed בתוך תנאי

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 2, שיעורים 1–2

בלי להריץ — מה יודפס?

const total = 99.999;
if (total.toFixed(2) === 100) {
  console.log("א: בדיוק 100");
}
if (total.toFixed(2) === "100.00") {
  console.log("ב: מוצג כ־100.00");
}
if (total >= 100) {
  console.log("ג: משלוח חינם");
} else {
  console.log(`ג: חסרים ${(100 - total).toFixed(2)} למשלוח חינם`);
}

ואז: הלקוח רואה על המסך "סה״כ: 100.00" ואת ההודעה של ג. למה זה מבלבל, ומה היית עושה?

🔗 איך זה מתחבר: toFixed מפרק 2 מחזיר טקסט ומעגל; === משיעור 1 בודק סוג; if משיעור 2 מחליט על סמך זה. שלושה כללים — באג אחד.
