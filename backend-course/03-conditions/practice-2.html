P03-E03 · איזה בלוק ירוץ?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 2

לכל ערך של score: 95, 90, 75, 40, -3 — מה ידפיס הקוד? (בלי להריץ.) האם יש ערך שמקבל תוצאה לא הגיונית?

if (score >= 90) {
  console.log("מצוין");
} else if (score >= 70) {
  console.log("טוב");
} else if (score >= 0) {
  console.log("נכשל");
} else {
  console.log("ציון לא חוקי");
}

P03-E08 · ציון במילים 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

P03-E13 · תעריפי משלוח לפי משקל 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 2

חברת שליחויות: עד 1 ק״ג (כולל) — 25; עד 5 ק״ג — 40; עד 20 ק״ג — 70; מעל 20 — 70 ועוד 5 לכל ק״ג מעבר ל־20 (חלק של ק״ג נחשב כק״ג שלם). משקל 0 או פחות ← שגיאה: משקל חייב להיות חיובי. כתוב תוכנית שמתחילה ב־const weight = 23.4; ומדפיסה משקל 23.4 ק״ג: 90 ש״ח. בדוק: 1, 1.01, 5, 20, 20.1, 0.

P03-E14 · שנה מעוברת 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 2

שנה היא מעוברת (29 בפברואר) אם היא מתחלקת ב־4, חוץ משנים שמתחלקות ב־100 — אלא אם הן מתחלקות גם ב־400. כתוב תוכנית שמתחילה ב־const year = 1900; ומדפיסה 1900: רגילה (או 2024: מעוברת). בדוק: 2024, 2023, 1900, 2000, 2100.

כתוב שתי גרסאות באותו קובץ: אחת עם if / else if ואחת עם ביטוי בוליאני אחד (&&, ||). כל גרסה מדפיסה שורה — כלומר אותה שורה פעמיים.
