בלוק { } שעומד לבד, בלי if לפניו, פשוט רץ.

✅ פתרון

ה־; אחרי if (stock < 5) הוא "פקודה ריקה" — זה כל מה שה־if שולט בו. הבלוק שאחריו כבר לא שייך לו, ורץ תמיד. Prettier מזיז את הקוד כך שהבלוק נראה "יתום" — אות אזהרה.

⚠️ טעויות נפוצות

P03-E13 · תעריפי משלוח לפי משקל 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 2

מעל 20: 70 + Math.ceil(weight - 20) * 5.

✅ פתרון
03-conditions/starter/P03-E13.js

  price = null;
} else if (weight <= 1) {
  price = 25;

  price = 40;

  price = 70;

  console.log("שגיאה: משקל חייב להיות חיובי");

⚠️ טעויות נפוצות

💡 רמז 2

P03-E54 · הקלט שלא נכנס ל־if 🧠 הבנה רמה 2

💡 רמז 1

=== בודק סוג. > בין טקסט למספר ממיר את הטקסט. > בין שני טקסטים — השוואה מילונית.

💡 רמז 2

ג: "5" > "10" — משווים "5" ל־"1".

✅ פתרון
const quantityInput = "5";
if (quantityInput === 5) {
  console.log("א: חמש בדיוק");
}
if (quantityInput > 3) {
  console.log("ב: יותר משלוש");
}
if (quantityInput > "10") {
  console.log("ג: יותר מעשר");
}
if (Number(quantityInput) > 10) {
  console.log("ד: יותר מעשר (כמספר)");
}
ב: יותר משלוש
ג: יותר מעשר
  • א: לא נכנס — טקסט מול מספר.
  • ב: עובד במקרה — > המיר את "5" ל־5.
  • ג: באג מסוכן — 5 "גדול מ־10" בהשוואה מילונית. אם זו הייתה בדיקת "מקסימום 10 יחידות", לקוח שהזמין 5 היה נדחה — ולקוח שהזמין 1000 ("1000" > "10") נדחה רק במקרה.
  • ד: הדרך הנכונה. לא נכנס, כי 5 לא גדול מ־10.
⚠️ טעויות נפוצות
  • להסיק מ־ב שאין צורך להמיר. הקוד ב־ג נראה בדיוק אותו דבר — ושבור.

P03-E55 · const בלי ערך, let בלי else 🧠 הבנה רמה 2

💡 רמז 1

א: const חייב לקבל ערך באותה שורה. Node בודק את זה עוד לפני הריצה.

💡 רמז 2

ב: אם התנאי false ואין else — מה הערך של label?

✅ פתרון

א: SyntaxError: Missing initializer in const declaration — שום שורה לא רצה.

const age = 15;
let label;
if (age >= 18) {
  label = "בגיר";
}
console.log(`התווית: ${label}`);
התווית: undefined

ב: חסר else. כשמשתנה מקבל ערך בתוך if, ודא שכל מסלול מציב לו ערך — אחרת יגיע undefined למסך. תיקון: else { label = "קטין"; }.

⚠️ טעויות נפוצות
  • לפתור את א עם const label = undefined; — אז ההצבה בתוך ה־if תיכשל. צריך let.

P03-E56 · toFixed בתוך תנאי 🧠 הבנה רמה 2

💡 רמז 1

(99.999).toFixed(2) הוא "100.00" — טקסט.

💡 רמז 2

ג: ההשוואה על המספר האמיתי, שהוא קצת פחות מ־100.

✅ פתרון
const total = 99.999;
if (total.toFixed(2) === 100) {
  console.log("א: בדיוק 100");
}
if (total.toFixed(2) === "100.00") {
  console.log("ב: מוצג כ־100.00");
}
if (total >= 100) {
  console.log("ג: משלוח חינם");
} else {
  console.log(`ג: חסרים ${(100 - total).toFixed(2)} למשלוח חינם`);
}
ב: מוצג כ־100.00
ג: חסרים 0.00 למשלוח חינם

המבלבל: המסך מראה 100.00, אבל הקוד מחליט לפי 99.999 — ואומר "חסרים 0.00". הפתרון האמיתי: לא להגיע למצב כזה — לשמור כסף באגורות שלמות (P03-E40), כך שמה שמוצג ומה שמושווה הם אותו מספר.

P03-E59 · זמן נסיעה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

קודם const minutes = Math.round(distanceKm / speedKmh * 60);. אחר כך שעות ודקות כמו בפרק 2.

💡 רמז 2

שני if נפרדים: אחד בוחר את הפורמט, והשני (עצמאי!) מוסיף אזהרה.

✅ פתרון
03-conditions/starter/P03-E59.js 
const distanceKm = 130;
const speedKmh = 90;
const minutes = Math.round(distanceKm / speedKmh * 60);
if (minutes < 60) {
  console.log(`זמן נסיעה: ${minutes} דקות`);
} else {
  const hours = Math.floor(minutes / 60);
  const rest = `${minutes % 60}`.padStart(2, "0");
  console.log(`זמן נסיעה: ${hours}:${rest} שעות`);
}
if (minutes > 120) {
  console.log("מומלץ לעצור להפסקה");
}
זמן נסיעה: 1:27 שעות

שים לב: hours ו־rest נוצרו בתוך הבלוק — כי צריך אותם רק שם. 30 ק״מ ← 20 דקות. 250 ק״מ ← 2:47 והפסקה.

⚠️ טעויות נפוצות
  • לשים את האזהרה ב־else if — ואז היא "גונבת" את התור של הדפסת הזמן.
