P03-E03 · איזה בלוק ירוץ? 🧠 הבנה רמה 1

💡 רמז 1

בודקים מלמעלה למטה, ועוצרים בתנאי הראשון שמתקיים.

💡 רמז 2

90 — האם 90 >= 90?

✅ פתרון

95 ← מצוין · 90 ← מצוין (>= כולל) · 75 ← טוב · 40 ← נכשל · ‎-3 ← ציון לא חוקי.

ומה עם 150? "מצוין" — הקוד לא בודק גבול עליון. בבדיקת קלט אמיתית היינו מוסיפים score > 100 לתנאי ה"לא חוקי" ושמים אותו ראשון.

⚠️ טעויות נפוצות
  • לחשוב ש־95 ידפיס גם "טוב" — רק בלוק אחד רץ.

P03-E07 · זוגי או אי־זוגי 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

מספר זוגי — השארית בחלוקה ב־2 היא 0.

💡 רמז 2

if (n % 2 === 0)

✅ פתרון
03-conditions/starter/P03-E07.js 
const n = 17;
if (n % 2 === 0) {
  console.log(`${n} הוא זוגי`);
} else {
  console.log(`${n} הוא אי־זוגי`);
}
17 הוא אי־זוגי

0 זוגי ✔; ‎-4 זוגי ✔. שים לב: ‎-3 % 2 הוא ‎-1 ולא 1 — לכן בודקים === 0 ולא === 1 לאי־זוגי.

⚠️ טעויות נפוצות
  • if (n % 2 === 1) לאי־זוגי — נכשל במספרים שליליים.

P03-E08 · ציון במילים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

הבדיקה הלא חוקית — ראשונה. אחר כך מהגבוה לנמוך.

💡 רמז 2

אחרי שבדקת >= 90, אין צורך לכתוב < 90 בתנאי הבא — else if כבר מבטיח את זה.

✅ פתרון
03-conditions/starter/P03-E08.js 
const score = 82;
let label;

if (score < 0 || score > 100) {
  label = "ציון לא חוקי";
} else if (score >= 90) {
  label = "מצוין";
} else if (score >= 80) {
  label = "טוב מאוד";
} else if (score >= 65) {
  label = "טוב";
} else if (score >= 55) {
  label = "עובר";
} else {
  label = "נכשל";
}

console.log(`ציון ${score}: ${label}`);
ציון 82: טוב מאוד
⚠️ טעויות נפוצות
  • לכתוב score >= 80 && score < 90 בכל תנאי — לא שגוי, אבל מיותר ומגדיל סיכוי לטעות בגבול.

P03-E13 · תעריפי משלוח לפי משקל 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שגיאה ← ≤1 ← ≤5 ← ≤20 ← אחרת.

💡 רמז 2

מעל 20: 70 + Math.ceil(weight - 20) * 5.

✅ פתרון
03-conditions/starter/P03-E13.js 
const weight = 23.4;
let price;

if (weight <= 0) {
  price = null;
} else if (weight <= 1) {
  price = 25;
} else if (weight <= 5) {
  price = 40;
} else if (weight <= 20) {
  price = 70;
} else {
  price = 70 + Math.ceil(weight - 20) * 5;
}

if (price === null) {
  console.log("שגיאה: משקל חייב להיות חיובי");
} else {
  console.log(`משקל ${weight} ק״ג: ${price} ש״ח`);
}
משקל 23.4 ק״ג: 90 ש״ח

20.1 ← 70 + Math.ceil(0.1) * 5 = 75 ✔.

⚠️ טעויות נפוצות
  • < במקום <= — משקל של בדיוק 1 ק״ג ישלם 40.

P03-E14 · שנה מעוברת 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

גרסת if: בדוק ÷400 קודם, אחר כך ÷100, אחר כך ÷4.

💡 רמז 2

ביטוי אחד: (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0.

✅ פתרון
03-conditions/starter/P03-E14.js 
const year = 1900;

// גרסה 1: if / else if
let isLeap;
if (year % 400 === 0) {
  isLeap = true;
} else if (year % 100 === 0) {
  isLeap = false;
} else if (year % 4 === 0) {
  isLeap = true;
} else {
  isLeap = false;
}
console.log(`${year}: ${isLeap ? "מעוברת" : "רגילה"}`);

// גרסה 2: ביטוי אחד
const isLeap2 = (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
console.log(`${year}: ${isLeap2 ? "מעוברת" : "רגילה"}`);
1900: רגילה
1900: רגילה

2000 ← מעוברת (÷400). 2100 ← רגילה. בגרסה 1, הסדר הוא העיקר: אם בודקים ÷4 קודם — 1900 תצא מעוברת.

⚠️ טעויות נפוצות
  • לבדוק רק year % 4 === 0 — נכון ל־99% מהשנים, וזה בדיוק סוג הבאג שמתגלה שנים אחר כך.
