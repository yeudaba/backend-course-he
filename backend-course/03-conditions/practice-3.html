P03-E62 · ?? או ||?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

בלי להריץ — מה יודפס?

const a = 0;
const b = "";
const c = null;
const d = undefined;
const e = "שלום";
console.log(a ?? 5, a || 5);
console.log(b ?? "ברירת מחדל", b || "ברירת מחדל");
console.log(c ?? 5, c || 5);
console.log(d ?? 5, d || 5);
console.log(e ?? "x", e || "x");

ואז: לכל אחד מהשדות האלה בטופס — ?? או ||? (1) מספר פריטים בעמוד (0 לא הגיוני), (2) אחוז הנחה (0 חוקי), (3) כינוי (ריק = "לא בחר").

P03-E67 · ?? ו־Number

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 1, פרק 2, שיעור 3

בלי להריץ — מה יודפס?

console.log(Number(undefined ?? "5"));
console.log(Number(null) ?? 10);
console.log(Number("") || 20);
console.log(Number("") ?? 20);
console.log(Number("abc") || 1);
console.log(Number(undefined) ?? 1);

ואז: פרמטר page מגיע מהכתובת כטקסט, ולפעמים לא מגיע בכלל (undefined). כתוב שורה אחת שנותנת מספר, עם ברירת מחדל 1.

🔗 איך זה מתחבר: null ו־undefined מפרק 1, Number ו־NaN מפרק 2, ו־??/|| מהשיעור. השאלה החשובה בכל שורה: ?? בא לפני ההמרה או אחריה?

P03-E68 · "0" עובר, 0 לא

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 2, שיעור 3

בלי להריץ — מה יודפס?

const qtyInput = "0";
if (qtyInput) {
  console.log("א: הוזן משהו");
}
const qty = Number(qtyInput);
if (qty) {
  console.log("ב: יש כמות");
} else {
  console.log("ב: אין כמות");
}
if (qtyInput.trim() !== "" && qty > 0) {
  console.log("ג: כמות חיובית");
}

ואז: מה ההבדל בין שתי השאלות "המשתמש הזין משהו?" ו"הכמות חיובית?" — ולמה כדאי לכתוב כל אחת במפורש?

🔗 איך זה מתחבר: בפרק 2 ראית שהמרה הופכת "0" ל־0 ו־"" ל־0. truthy/falsy מהשיעור מתנהג שונה לגמרי לפני ואחרי ההמרה — לכן בודקים במפורש.
