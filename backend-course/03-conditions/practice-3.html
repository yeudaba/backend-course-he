P03-E09 · כניסה למערכת 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

משתמש יכול להיכנס רק אם שם המשתמש נכון וגם הסיסמה נכונה וגם החשבון לא חסום. הנתונים כבר כתובים בקובץ ההתחלה:

const savedUsername = "dana";
const savedPassword = "s3cret!Pass";
const isBlocked = false;

const typedPassword = "s3cret!Pass";

שם המשתמש לא רגיש לאותיות גדולות ולרווחים; הסיסמה כן. הדפס כניסה הצליחה או שם משתמש או סיסמה שגויים — ואם החשבון חסום: החשבון חסום.

P03-E15 · מי רשאי לערוך? 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

כללי עריכה של מסמך במערכת:

  • מנהל (role === "admin") — תמיד.
  • עורך ("editor") — רק אם המסמך לא נעול.
  • כותב המסמך — רק אם המסמך לא נעול ולא פורסם.
  • כל השאר — לא.

משתנים: role, isAuthor, isLocked, isPublished. כתוב ביטוי אחד canEdit, והדפס אותו בפורמט רשאי לערוך? false. בדוק לפחות 5 צירופים — כולל מנהל עם מסמך נעול, וכותב של מסמך שפורסם. (הבודק בודק שבעה.)

📄 כותבים בקובץ 03-conditions/starter/P03-E15.js (יש בו רק הערה עם המשימה), מריצים ובודקים:

P03-E16 · ברירות מחדל לחיפוש 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

API לחיפוש מוצרים מקבל פרמטרים אופציונליים. כל אחד יכול להיות undefined (לא נשלח). הערכים האלה כבר כתובים בקובץ ההתחלה, והבודק מחליף אותם בצירופים אחרים:

const pageParam = undefined;
const limitParam = 0;
const sortParam = "";
const minPriceParam = 0;

כללים: page ברירת מחדל 1; limit ברירת מחדל 20, ואם נשלח 0 או יותר מ־100 — השתמש ב־20; sort ברירת מחדל "newest" — גם אם נשלחה מחרוזת ריקה; minPrice ברירת מחדל 0 (ו־0 חוקי). הדפס:

page=1 limit=20 sort=newest minPrice=0

📄 כותבים בקובץ 03-conditions/starter/P03-E16.js (הפרמטרים כבר כתובים בו), מריצים ובודקים:

% node 03-conditions/starter/P03-E16.js
% npm run check P03-E16

P03-E26 · שעות פתיחה 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

החנות פתוחה מ־8:00 ועד 20:00 (ב־20:00 כבר סגור), ובשבת סגורה כל היום. בקובץ כבר כתובות שתי שורות:

const hour = 14;

הוסף קוד שמדפיס שורה אחת:

  • בשבת: שבת — סגור
  • בשעות הפתיחה: 14:00 — פתוח (נסגר בעוד 6 שעות), וכשנשארה שעה אחת: 19:00 — פתוח (נסגר בעוד שעה)

הבודק יחליף את hour ואת isSaturday ויבדוק את הגבולות (7, 8, 19, 20).
