P03-E31 · =, == או ===? 🧠 הבנה רמה 1

💡 רמז 1

סימן אחד — הצבה. שניים — השוואה "סלחנית" שממירה סוגים. שלושה — השוואה קפדנית.

💡 רמז 2

שורה 2: הצבה היא גם ביטוי — והערך שלה הוא מה שהוצב.

✅ פתרון
let x = 5;
console.log(x = 7);
console.log(x);
console.log(x == "7");

console.log(x === 7);

7
true
false
true
  • = מציב (ושורה 2 שינתה את x ל־7 — בתוך console.log!).
  • == ממיר את "7" למספר ואז משווה — true.
  • === בודק גם סוג — מספר מול טקסט ← false.
⚠️ טעויות נפוצות
  • לחשוב ששורה 2 "בודקת" אם x הוא 7. זה הבאג של תרגיל P03-E20 — = בתוך תנאי.

P03-E32 · 5 < x < 10 🧠 הבנה רמה 2

💡 רמז 1

השוואות מחושבות משמאל לימין, שתיים־שתיים. 5 < 50 הוא true. ואז?

💡 רמז 2

בהשוואה עם מספר, true הופך ל־1 ו־false ל־0.

✅ פתרון
const x = 50;
console.log(5 < x < 10);
console.log(10 > x > 5);
console.log(3 > 2 > 1);
true
false
false
  • שורה 2: 5 < 50 ← true ← true < 10 ← 1 < 10 ← true. "נכון", למרות ש־50 לא בין 5 ל־10.
  • שורה 3: 10 > 50 ← false ← 0 > 5 ← false.
  • שורה 4: 3 > 2 ← true ← 1 > 1 ← false!

JavaScript לא מתלוננת כי כל צעד הוא השוואה חוקית — רק שהיא לא מה שהתכוונת. הדרך הנכונה: x > 5 && x < 10 — שתי השוואות, ו"וגם" ביניהן.

⚠️ טעויות נפוצות
  • לסמוך על זה כי "במתמטיקה כותבים ככה". JavaScript היא לא מתמטיקה.

P03-E06 · יש מספיק במלאי? 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

המר את הקלט, ואז const hasEnough = stock >= requested;

console.log(`יש מספיק? ${hasEnough}`);
console.log(`חסרות: ${missing}`);

יש מספיק? false
חסרות: 3

עם "5": יש מספיק — true, חסרות 0.

⚠️ טעויות נפוצות
  • להשוות stock >= requestedInput בלי המרה. עם "12" זה עובד במקרה (השוואה מספרית ממירה), אבל זה הרגל רע.

P03-E38 · בתוך התקציב? 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

💡 רמז 1

"@ לא בהתחלה" — האינדקס של @ גדול מ־0 (ואם אין @ בכלל, indexOf מחזיר ‎-1).

💡 רמז 2

"או" בלי ||: מחרוזת לא יכולה להיגמר גם ב־.com וגם ב־.co.il. לכן כאן "לפחות אחד נכון" זהה ל"שני הבוליאנים שונים זה מזה": endsCom !== endsCoIl.

✅ פתרון
03-conditions/starter/P03-E44.js 
const emailInput = "  Dana@Mail.com ";
const email = emailInput.trim().toLowerCase();
const atIndex = email.indexOf("@");
const endsCom = email.endsWith(".com");
const endsCoIl = email.endsWith(".co.il");
console.log(`נקי: ${email}`);
console.log(`יש @? ${email.includes("@")}`);
console.log(`@ לא בהתחלה? ${atIndex > 0}`);
console.log(`נגמר ב־.com או .co.il? ${endsCom !== endsCoIl}`);
נקי: dana@mail.com
יש @? true
@ לא בהתחלה? true
נגמר ב־.com או .co.il? true

endsCom !== endsCoIl הוא "בדיוק אחד מהם נכון". כאן זה שווה ל"או", כי מחרוזת לא יכולה להיגמר גם ב־.com וגם ב־.co.il. זה טריק — ובשיעור 3 תחליף אותו ב־endsCom || endsCoIl, שאומר בדיוק מה שהתכוונת.

⚠️ טעויות נפוצות
  • atIndex !== -1 בשורה 3 — זה "יש @", לא "לא בהתחלה". "@mail.com" יעבור.
