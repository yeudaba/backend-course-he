P03-E02 · == מול === 🧠 הבנה רמה 1

💡 רמז 1

== ממיר סוגים לפני ההשוואה; === לא.

💡 רמז 2

רק זוג אחד שווה גם ב־===.

✅ פתרון
console.log(1 == "1", 1 === "1");
console.log(0 == "", 0 === "");
console.log(null == undefined, null === undefined);
console.log("abc" == "abc", "abc" === "abc");
console.log(0 == false, 0 === false);
true false
true false
true false
true true
true false

למה ===: כי == מחליט בשבילנו להמיר סוגים, וזה גורם ל"שוויונות" מפתיעים (0 שווה למחרוזת ריקה!) שמסתירים באגים.

⚠️ טעויות נפוצות
  • לחשוב ש־null === undefined — שני ערכים שונים, גם אם שניהם "ריקים".

P03-E06 · יש מספיק במלאי? 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

המר את הקלט, ואז const hasEnough = stock >= requested;

💡 רמז 2

Math.max(0, requested - stock) — הגדול מבין 0 לבין ההפרש.

✅ פתרון
03-conditions/starter/P03-E06.js 
const requestedInput = "12";
const stock = 9;

const requested = Number(requestedInput);
const hasEnough = stock >= requested;
const missing = Math.max(0, requested - stock);

console.log(`ביקשו: ${requested}, במלאי: ${stock}`);
console.log(`יש מספיק? ${hasEnough}`);
console.log(`חסרות: ${missing}`);
ביקשו: 12, במלאי: 9
יש מספיק? false
חסרות: 3

עם "5": יש מספיק — true, חסרות 0.

⚠️ טעויות נפוצות
  • להשוות stock >= requestedInput בלי המרה. עם "12" זה עובד במקרה (השוואה מספרית ממירה), אבל זה הרגל רע.

P03-E20 · הקופון שמשנה את עצמו 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

כמה סימני = יש בתנאי?

💡 רמז 2

הצבה היא גם ביטוי — הערך שלה הוא הערך שהוצב. האם "SUMMER10" truthy?

✅ פתרון

מה קרה: coupon = "SUMMER10" הציב את הערך במשתנה (ולכן coupon השתנה), והערך של ביטוי ההצבה הוא "SUMMER10" — מחרוזת לא ריקה, truthy — ולכן הבלוק רץ.

let coupon = "WINTER";
let discount = 0;

if (coupon === "SUMMER10") {
  discount = 10;
}

console.log("קוד:", coupon);
console.log("הנחה:", discount);
קוד: WINTER
הנחה: 0

שיפור נוסף: coupon לא אמור להשתנות — אם היה const, הבאג היה הופך ל־TypeError מיידי. עוד סיבה להעדיף const.

⚠️ טעויות נפוצות
  • == במקום = — עובד כאן, אבל בקורס: ===.
