⏱ ~35 דקות

זיכרון קל: && מחמיר (צריך שכולם יסכימו), || מקל (מספיק אחד).

👣 דוגמה: מי יכול למחוק הזמנה?

חוק עסקי: הזמנה אפשר למחוק אם המשתמש הוא מנהל, או שהוא הבעלים של ההזמנה וגם ההזמנה עוד לא נשלחה.

const isAdmin = false;
const isOwner = true;
const isShipped = false;

const canDelete = isAdmin || (isOwner && !isShipped);
console.log(canDelete);
true

הסוגריים לא חובה כאן (&& מחושב לפני ||), אבל הם מבהירים את הכוונה — השאר אותם. שימו לב גם ל־!isShipped: "לא נשלחה".

💡 טווח

"בין 18 ל־67" כותבים age >= 18 && age <= 67. לא 18 <= age <= 67 (ראינו בשיעור 1 למה זה תמיד true).

2. Short-circuit — עצירה מוקדמת

&& מפסיק לבדוק ברגע שהוא פוגש false (התוצאה כבר ידועה), ו|| — ברגע שהוא פוגש true. זה שימושי כדי לא לגשת למשהו שלא קיים:

const user = null;
if (user !== null && user.length > 0) {
  console.log("יש משתמש");
} else {
  console.log("אין משתמש");
}
אין משתמש

אם user הוא null, הצד השני (user.length) בכלל לא נבדק — ולכן אין שגיאה. בסדר הפוך היינו מקבלים TypeError: Cannot read properties of null.

3. ⚡ truthy ו־falsy

⚡ חשוב גם במסלול המהיר

בתוך if (...) אפשר לשים כל ערך, לא רק בוליאני. JavaScript תמיר אותו: יש שישה ערכים שנחשבים "falsy" (מתנהגים כמו false), וכל השאר "truthy":

falsy (כמו false)דוגמאות truthy (כמו true)
false, 0, "" (מחרוזת ריקה), null, undefined, NaN"0", " ", "false", -1, 42, וכל אובייקט/מערך (גם ריק!)
const name = "";
if (name) {
  console.log(`שלום ${name}`);
} else {
  console.log("לא הוזן שם");
}
לא הוזן שם

נוח. אבל מסוכן עם מספרים:

const discount = 0;
if (discount) {
  console.log(`הנחה: ${discount}`);
} else {
  console.log("לא הוגדרה הנחה");
}
לא הוגדרה הנחה

הנחה של 0 היא ערך חוקי — אבל if (discount) התייחס אליה כאילו לא קיימת. כלל: כש־0 (או מחרוזת ריקה) הוא ערך חוקי — בדוק במפורש: if (discount !== undefined) או if (discount !== null).

4. ברירת מחדל: ??

הרבה פעמים רוצים "קח את הערך, ואם אין — קח ברירת מחדל". למשל: מספר תוצאות בעמוד שהמשתמש ביקש, ואם לא ביקש — 20.

const requestedPageSize = undefined;
const pageSize = requestedPageSize ?? 20;
console.log(pageSize);

const requestedDiscount = 0;
console.log(requestedDiscount ?? 10);
console.log(requestedDiscount || 10);
20
0
10

a ?? b נותן את b רק אם a הוא null או undefined. לעומתו a || b נותן את b כש־a הוא כל ערך falsy — כולל 0. בשורה האחרונה || "דרס" הנחה חוקית של 0. בקוד חדש — השתמש ב־?? לברירות מחדל.
