P03-E02 · == מול === רמה 1

💡 רמז 1

⚠️ טעויות נפוצות
  • לחשוב ש־null === undefined — שני ערכים שונים, גם אם שניהם "ריקים".

P03-E06 · יש מספיק במלאי? רמה 2

💡 רמז 1

המר את הקלט, ואז const hasEnough = stock >= requested;

💡 רמז 2

✅ פתרון
playground/p03e06.js 
const requestedInput = "12";
const stock = 9;

const requested = Number(requestedInput);
const hasEnough = stock >= requested;
const missing = Math.max(0, requested - stock);

console.log(`ביקשו: ${requested}, במלאי: ${stock}`);
console.log(`יש מספיק? ${hasEnough}`);
console.log(`חסרות: ${missing}`);
ביקשו: 12, במלאי: 9
יש מספיק? false
חסרות: 3

עם "5": יש מספיק — true, חסרות 0.

⚠️ טעויות נפוצות
  • להשוות stock >= requestedInput בלי המרה. עם "12" זה עובד במקרה (השוואה מספרית ממירה), אבל זה הרגל רע.

P03-E07 · זוגי או אי־זוגי רמה 2

💡 רמז 2

✅ פתרון
playground/p03e07.js

P03-E08 · ציון במילים רמה 2

P03-E13 · תעריפי משלוח לפי משקל רמה 3

💡 רמז 1

שגיאה ← ≤1 ← ≤5 ← ≤20 ← אחרת.

💡 רמז 2

מעל 20: 70 + Math.ceil(weight - 20) * 5.

✅ פתרון
playground/p03e13.js 
const weight = 23.4;
let price;

if (weight <= 0) {
  price = null;
} else if (weight <= 1) {
  price = 25;
} else if (weight <= 5) {
  price = 40;
} else if (weight <= 20) {
  price = 70;
} else {
  price = 70 + Math.ceil(weight - 20) * 5;
}

if (price === null) {
  console.log("שגיאה: משקל חייב להיות חיובי");
} else {
  console.log(`משקל ${weight} ק״ג: ${price} ש״ח`);
}
משקל 23.4 ק״ג: 90 ש״ח

20.1 ← 70 + Math.ceil(0.1) * 5 = 75 ✔.

⚠️ טעויות נפוצות
  • < במקום <= — משקל של בדיוק 1 ק״ג ישלם 40.

P03-E14 · שנה מעוברת רמה 3

💡 רמז 1

גרסת if: בדוק ÷400 קודם, אחר כך ÷100, אחר כך ÷4.

💡 רמז 2

ביטוי אחד: (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0.

✅ פתרון
playground/p03e14.js 
const year = 1900;

// גרסה 1: if / else if
let isLeap;
if (year % 400 === 0) {
  isLeap = true;
} else if (year % 100 === 0) {
  isLeap = false;
} else if (year % 4 === 0) {
  isLeap = true;
} else {
  isLeap = false;
}
console.log(`${year}: ${isLeap ? "מעוברת" : "רגילה"}`);

// גרסה 2: ביטוי אחד
const isLeap2 = (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
console.log(`${year}: ${isLeap2 ? "מעוברת" : "רגילה"}`);
1900: רגילה
1900: רגילה

2000 ← מעוברת (÷400). 2100 ← רגילה. בגרסה 1, הסדר הוא העיקר: אם בודקים ÷4 קודם — 1900 תצא מעוברת.

⚠️ טעויות נפוצות
  • לבדוק רק year % 4 === 0 — נכון ל־99% מהשנים, וזה בדיוק סוג הבאג שמתגלה שנים אחר כך.

P03-E16 · ברירות מחדל לחיפוש רמה 3

💡 רמז 1

בחר לכל אחד ?? או || לפי השאלה: האם 0 / "" הם ערכים חוקיים?

💡 רמז 2

ל־limit צריך תנאי נוסף מעבר לברירת מחדל: (limit < 1 || limit > 100) ? 20 : limit.

✅ פתרון
playground/p03e16.js 
const pageParam = undefined;
const limitParam = 0;
const sortParam = "";
const minPriceParam = 0;

const page = pageParam ?? 1;
const rawLimit = limitParam ?? 20;
const limit = rawLimit < 1 || rawLimit > 100 ? 20 : rawLimit;
const sort = sortParam || "newest";
const minPrice = minPriceParam ?? 0;

console.log(`page=${page} limit=${limit} sort=${sort} minPrice=${minPrice}`);
page=1 limit=20 sort=newest minPrice=0

sort הוא המקום היחיד שבו || נכון: מחרוזת ריקה צריכה לקבל ברירת מחדל. ב־minPrice, || היה עובד במקרה (כי ברירת המחדל גם היא 0), אבל ?? מבטא את הכוונה.

⚠️ טעויות נפוצות
  • sortParam ?? "newest" — מחרוזת ריקה תעבור, וה־API ינסה למיין לפי "".

P03-E17 · חוזק סיסמה רמה 3

💡 רמז 1

💡 רמז 2

✅ פתרון
playground/p03e17.js 
const username = "dana1234";
const password = "long!password1";

const lower = password.toLowerCase();
const hasSpecial = password.includes("!") || password.includes("@") || password.includes("#");

if (password === "") {
  console.log("חובה להזין סיסמה");
} else if (password.length < 8) {
  console.log("לפחות 8 תווים");
} else if (lower === username.toLowerCase()) {
  console.log("הסיסמה לא יכולה להיות שם המשתמש");
} else if (lower === "12345678" || lower === "password" || lower === "qwertyui") {
  console.log("סיסמה נפוצה מדי");
} else if (!hasSpecial) {
  console.log("חייב תו מיוחד: ! @ #");
} else {
  console.log("סיסמה תקינה");
}
סיסמה תקינה

⚠️ טעויות נפוצות
  • להדפיס את כל הבעיות שנמצאו — זה לגיטימי בממשק, אבל התרגיל ביקש את הראשונה. שים לב לדרישות.

P03-E19 · מחיר כרטיס לקולנוע רמה 3

💡 רמז 1

שלב אחר שלב: מחיר בסיס (if/else if), תוספת (ternary עם &&), הנחה (ternary).

💡 רמז 2

const surcharge = isWeekend && age < 65 ? 10 : 0;

✅ פתרון
playground/p03e19.js 
const age = 70;
const isWeekend = true;
const isMember = true;

let base;
if (age <= 12) {
  base = 30;
} else if (age <= 64) {
  base = 45;
} else {
  base = 25;
}

const surcharge = isWeekend && age < 65 ? 10 : 0;
const beforeDiscount = base + surcharge;
