const a = 7;
const b = "7";
console.log(a === 7);
console.log(a === b);
console.log(a !== b);
console.log(a >= 7);
console.log(a > 7);

P03-E06 · יש מספיק במלאי? 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

הכמות שהלקוח ביקש הגיעה כטקסט: const requestedInput = "12";, והמלאי הוא const stock = 9;. כתוב תוכנית שמדפיסה:

ביקשו: 12, במלאי: 9
יש מספיק? false
חסרות: 3

השורה "חסרות" מחושבת. אחר כך בדוק עם בקשה של "9" ושל "5" — מה יודפס ב"חסרות"? תקן כך שלא יודפס מספר שלילי (רמז: Math.max מפרק 2). הבודק מריץ את הקוד שלך עם שלוש הבקשות.

📄 כותבים בקובץ 03-conditions/starter/P03-E06.js (יש בו רק הערה עם המשימה), מריצים ובודקים:

% node 03-conditions/starter/P03-E06.js
% npm run check P03-E06
