שיעור 4 — ternary, switch ובדיקת קלט

⏱ ~30 דקות

🎯 בשיעור הזה
  • ternary — if/else בשורה אחת שמחזיר ערך.
  • switch — בחירה לפי ערך מתוך רשימה.
  • דפוס לבדיקת קלט: הקלט הלא תקין נבדק קודם.

1. Ternary: תנאי ? אם־כן : אם־לא

כשכל מה ש־if/else עושה הוא לבחור ערך — יש קיצור:

const age = 16;
const label = age >= 18 ? "בגיר" : "קטין";
console.log(label);

const items = 1;
console.log(`יש לך ${items} ${items === 1 ? "פריט" : "פריטים"} בעגלה`);
קטין
יש לך 1 פריט בעגלה

קוראים: "האם age >= 18? אם כן — "בגיר", אחרת — "קטין"". היתרון: אפשר להשתמש ב־const ולשבץ בתוך template literal. כלל: ternary רק לבחירה פשוטה בין שני ערכים. אם יש בפנים עוד ternary — חזור ל־if/else.

2. switch — בחירה מתוך רשימה

כשבודקים משתנה אחד מול הרבה ערכים קבועים:

const status = "shipped";
let message;
switch (status) {
  case "pending":
    message = "ההזמנה התקבלה";
    break;
  case "shipped":
    message = "ההזמנה בדרך";
    break;
  case "delivered":
    message = "ההזמנה נמסרה";
    break;
  default:
    message = "סטטוס לא מוכר";
}
console.log(message);
ההזמנה בדרך

3. 👣 דפוס חשוב: בדיקת קלט

בשרת, לפני שעושים משהו עם קלט — בודקים אותו. הדפוס: מתחילים מהמקרים הרעים, כל אחד עם הודעה ברורה, ורק בסוף — המקרה הטוב.

const quantityInput = "abc";
const quantity = Number(quantityInput);

if (quantityInput.trim() === "") {
  console.log("שגיאה: חובה להזין כמות");
} else if (Number.isNaN(quantity)) {
  console.log("שגיאה: הכמות חייבת להיות מספר");
} else if (quantity <= 0) {
  console.log("שגיאה: הכמות חייבת להיות חיובית");
} else if (quantity > 10) {
  console.log("שגיאה: אפשר להזמין עד 10 יחידות");
} else {
  console.log(`הוזמנו ${quantity} יחידות`);
}
שגיאה: הכמות חייבת להיות מספר

הסדר חשוב: בודקים "ריק" לפני "לא מספר" (כי Number("") הוא 0 — זוכר?), ו"לא מספר" לפני "שלילי" (כי NaN <= 0 הוא false, והקלט היה עובר!). בפרק 5 נכתוב את זה כפונקציה שמחזירה מוקדם (guard clause) — זה יהיה עוד יותר נקי.

💡 מקרי קצה — הרגל של מפתח Backend

לכל בדיקה, שאל: מה קורה עם ריק? 0? שלילי? בדיוק על הגבול (10)? טקסט? רווחים? אלה בדיוק הקלטים שבודקים יכתבו לך בדיקות עליהם — ושתוקפים ינסו.
