P03-E11 · מ־if/else ל־ternary 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

כתוב מחדש כל קטע עם ternary ו־const (בלי let), כך שהפלט לא ישתנה:

let status;
if (isOnline) {
  status = "מחובר";
} else {
  status = "לא מחובר";
}

let fee;
if (isExpress) {
  fee = 40;
} else {
  fee = 20;
}

let word;
if (count === 1) {
  word = "הודעה";
} else {
  word = "הודעות";
}
console.log(`${status} | משלוח ${fee} | ${count} ${word}`);

בקובץ ההתחלה הקוד כבר כתוב, עם isOnline = true, isExpress = false, count = 3. בסוף לא יישארו בו let ו־if.

% npm run check P03-E11

P03-E17 · חוזק סיסמה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

כתוב תוכנית עם const username = "dana1234"; ו־const password = "..."; שבודקת סיסמה חדשה לפי הסדר ומדפיס את הבעיה הראשונה שנמצאה, או "סיסמה תקינה":

  1. ריקה ← "חובה להזין סיסמה"
  2. קצרה מ־8 ← "לפחות 8 תווים"
  3. זהה לשם המשתמש (בלי תלות באותיות גדולות) ← "הסיסמה לא יכולה להיות שם המשתמש"
  4. אחת מהסיסמאות הנפוצות "12345678", "password", "qwertyui" ← "סיסמה נפוצה מדי"
  5. לא מכילה אף אחד מהתווים !, @, # ← "חייב תו מיוחד: ! @ #"

בדוק עם: "", "abc", "Dana1234" (כששם המשתמש dana1234), "password", "longpassword1", "long!password1". הבודק מחליף את הסיסמה בכל אחת מהן.

P03-E18 · קודי סטטוס של HTTP 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 4

כל תשובה של שרת מגיעה עם קוד סטטוס (נלמד לעומק בפרק 14). עם switch, המר קוד (const status = 403;) להודעה בעברית. השתמש בכוונה ב"נפילה" בין case־ים כשכמה קודים מקבלים אותה הודעה:

  • 200, 201 ← "הצלחה"
  • 400 ← "בקשה שגויה"
  • 401, 403 ← "אין הרשאה"
  • 404 ← "לא נמצא"
  • 500, 502, 503 ← "תקלה בשרת"
  • כל השאר ← "קוד לא מוכר"
403: אין הרשאה

P03-E05 · truthy, falsy ו־??

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעורים 3–4

מה תדפיס כל שורה?

console.log(Boolean("0"));
console.log(Boolean(""));
console.log(Boolean(" "));
console.log(Boolean(-1));
console.log(0 || "ברירת מחדל");
console.log(0 ?? "ברירת מחדל");
console.log(null ?? "ברירת מחדל");
console.log("" || "אורח");
console.log("" ?? "אורח");
console.log(5 > 3 ? "כן" : "לא");
