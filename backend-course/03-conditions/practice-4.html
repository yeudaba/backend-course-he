P03-E11 · מ־if/else ל־ternary 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

כתוב מחדש כל קטע עם ternary ו־const (בלי let), כך שהפלט לא ישתנה:

let status;
if (isOnline) {
  status = "מחובר";
} else {
  status = "לא מחובר";
}

let fee;
if (isExpress) {
  fee = 40;
} else {
  fee = 20;
}

let word;
if (count === 1) {
  word = "הודעה";
} else {
  word = "הודעות";
}
console.log(`${status} | משלוח ${fee} | ${count} ${word}`);

בקובץ ההתחלה הקוד כבר כתוב, עם isOnline = true, isExpress = false, count = 3. בסוף לא יישארו בו let ו־if.

P03-E17 · חוזק סיסמה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

כתוב תוכנית עם const username = "dana1234"; ו־const password = "..."; שבודקת סיסמה חדשה לפי הסדר ומדפיס את הבעיה הראשונה שנמצאה, או "סיסמה תקינה":

P03-E05 · truthy, falsy ו־??

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעורים 3–4

מה תדפיס כל שורה?

console.log(Boolean("0"));
console.log(Boolean(""));
console.log(Boolean(" "));
console.log(Boolean(-1));
console.log(0 || "ברירת מחדל");
console.log(0 ?? "ברירת מחדל");
console.log(null ?? "ברירת מחדל");
console.log("" || "אורח");
console.log("" ?? "אורח");
console.log(5 > 3 ? "כן" : "לא");

🔗 איך זה מתחבר: Boolean ו־truthy/falsy (שיעור 3) הם מה ש־if ו־ternary (שיעור 4) "רואים" כשנותנים להם ערך שאינו בוליאני — ו־?? הוא הדרך לתת ברירת מחדל בלי ליפול במלכודת של 0 ו־"".

P03-E79 · ternary, toFixed וקלט מטופס

ואז: השורה של label עובדת. למה בכל זאת עדיף לכתוב אותה אחרת?

P03-E80 · ביקורת קוד: מקינון לשרשרת

🧠 הבנהרמה 4⏱ 15 דק׳ידע נדרש: כל הפרק

חבר צוות כתב בדיקת הרשמה עם קינון עמוק:

const emailInput = " Dana@Mail.com";
const passwordInput = "abc";
const email = emailInput.trim().toLowerCase();
if (email !== "") {
  if (email.includes("@")) {
    if (passwordInput.length >= 8) {
      console.log(`נרשמת: ${email}`);
    } else {
      console.log("סיסמה קצרה מדי");
    }
  } else {
    console.log("אימייל לא תקין");
  }
} else {
  console.log("חובה להזין אימייל");
}

(1) מה יודפס? (2) כתוב על דף גרסה "שטוחה": שרשרת if / else if / else אחת, שבה המקרים הרעים קודם. (3) הוסף לשרשרת בדיקה חדשה — "הסיסמה לא יכולה להכיל את האימייל". באיזו גרסה קל יותר להוסיף אותה, ולמה?

🔗 איך זה מתחבר: ניקוי מחרוזות מפרק 2, השוואות ותנאים מכל השיעורים, ודפוס בדיקת הקלט משיעור 4. בפרק 5 תכתוב את זה כפונקציה עם guard clauses — עוד צעד באותו כיוון.
