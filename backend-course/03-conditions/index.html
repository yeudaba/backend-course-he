⚡ מבחן כניסה — אולי אפשר לדלג?
  1. console.log(5 === "5", 5 == "5");
  2. console.log(10 > 3 && 2 > 5);
  3. console.log(!(3 < 1) || false);
  4. מה ידפיס: const t = 15; if (t > 25) { console.log("חם"); } else if (t > 10) { console.log("נעים"); } else { console.log("קר"); }
  5. אילו מהערכים "falsy": 0, "0", "", " ", null, NaN?
  6. console.log(0 || 50, 0 ?? 50);
  7. כתוב ב־ternary: אם age 18 ומעלה — "בגיר", אחרת "קטין".
  8. מה הבאג: if (role = "admin") { ... }
  9. console.log("apple" < "banana");
  10. מה ההבדל בין if (x) ... לבין if (x !== undefined) ... כש־x הוא 0?
תשובות
  1. false true
  2. false
  3. true
  4. נעים
  5. 0, "", null, NaN
  6. 50 0
  7. const label = age >= 18 ? "בגיר" : "קטין";
  8. = מציב במקום להשוות — התנאי תמיד מתקיים. צריך ===.
  9. true (השוואה לפי סדר מילוני)
  10. if (0) לא נכנס (0 falsy), ואילו 0 !== undefined הוא true ונכנס.

🎯 בסוף הפרק תדע
  • להשוות ערכים עם ===, !==, <, >, <=, >= — ולדעת למה לא ==.
  • לבנות החלטות עם if, else if, else.
  • לשלב תנאים עם &&, ||, !, ולמלא טבלת אמת.
  • להבין truthy/falsy, ולתת ערך ברירת מחדל עם ??.
  • לכתוב ternary ו־switch, ולבדוק קלט עם "guard clauses".

🤔 למה צריך את זה?

שרת מקבל החלטות כל הזמן: "האם הסיסמה נכונה?", "האם יש מספיק מלאי?", "האם המשתמש הוא מנהל?", "האם הקלט חוקי — ואם לא, איזו הודעת שגיאה להחזיר?". כל ההחלטות האלה הן תנאים. בסוף הפרק תכתוב את הבדיקות האלה בעצמך.
