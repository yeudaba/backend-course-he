P03-E73 · איזה כלי? 🧠 הבנה רמה 2

💡 רמז 1

ternary — בחירה בין שני ערכים. switch — משתנה אחד מול ערכים קבועים. כל השאר — if.

💡 רמז 2

טווחים (משקל) ותנאים מורכבים (&&, ||) לא מתאימים ל־switch, שבודק רק שוויון.

✅ פתרון
  1. ternary — שני ערכים, בתוך template literal.
  2. switch — משתנה אחד מול רשימה קבועה. (בפרק 7 — אובייקט "מפה" יהיה עוד יותר קצר.)
  3. if / else if — טווחים.
  4. if / else if — בדיקות שונות, כל אחת עם הודעה, לפי סדר — הדפוס של בדיקת קלט.
  5. ביטוי בוליאני (isAdmin || (isOwner && !isLocked)) — ואז if פשוט, או ternary אם בוחרים ערך.
  6. switch — ערכים קבועים.
⚠️ טעויות נפוצות
  • לדחוס בדיקת קלט ל־ternary מקונן. אפשר — ואי אפשר לקרוא את זה.

P03-E75 · switch על טקסט מה־URL 🧠 הבנה רמה 2

💡 רמז 1

switch משווה עם ===. מה הסוג של statusFromUrl?

💡 רמז 2

תיקון אחד משנה את מה שבסוגריים של switch. השני — את ה־case־ים.

✅ פתרון
const statusFromUrl = "404";
switch (statusFromUrl) {
  case 404:
    console.log("לא נמצא");
    break;
  case 500:
    console.log("תקלה בשרת");
    break;
  default:
    console.log("קוד לא מוכר");
}
קוד לא מוכר

"404" === 404 הוא false, אז אף case לא מתאים. תיקונים: (א) switch (Number(statusFromUrl)); (ב) case "404":. א עדיף — ממירים פעם אחת בכניסה, ומכאן עובדים עם מספר אמיתי (שאפשר גם להשוות עם >=).

⚠️ טעויות נפוצות
  • לחשוב ש־switch "סלחני" כמו ==. הוא קפדן כמו ===.

P03-E76 · מקרי קצה לשדה "גיל" 🧠 הבנה רמה 3

💡 רמז 2

"על הגבול" זה ארבעה קלטים: 5, 6, 18, 19.

P03-E23 · בדיקת גיל שבורה 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

שני קלטים נכשלים: " " ו־"10". מה זה Number(" ")?

💡 רמז 2

סדר נכון: ריק (אחרי trim) ← לא מספר ← טווח ← קבוצות מהצעירה למבוגרת (או מהמבוגרת לצעירה — אבל עקבי!).

✅ פתרון
const ageInput = "   ";
const age = Number(ageInput);

if (ageInput.trim() === "") {
  console.log("שגיאה: חובה להזין גיל");
} else if (Number.isNaN(age)) {
  console.log("שגיאה: גיל חייב להיות מספר");
} else if (age < 0 || age > 120) {
  console.log("שגיאה: גיל לא הגיוני");
} else if (age < 18) {
  console.log("קבוצה: קטין");
} else if (age < 65) {
  console.log("קבוצה: מבוגר");
} else {
  console.log("קבוצה: גמלאי");
}
שגיאה: חובה להזין גיל

הבאגים: (1) " " הופך ל־0, עובר את בדיקת הטווח, ולא נתפס כ"ריק" כי לא היה trim. (2) age < 65 נבדק לפני age < 18, אז קטינים נתפסו כמבוגרים.

למה "abc" עבר: NaN < 0 ו־NaN > 120 שניהם false — אז בדיקת הטווח "פספסה" אותו במקרה, והוא הגיע לבדיקת isNaN. תלות במזל כזה היא בדיוק מה שהסדר הנכון מבטל.

⚠️ טעויות נפוצות
  • לתקן רק את הסדר של הקבוצות ולא לבדוק את כל 8 הקלטים. אחרי תיקון — בודקים הכול שוב, לא רק את מה שתיקנו.

const day = 29;
const month = 2;
const year = 2024;

const isLeap = (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;

let daysInMonth;
switch (month) {
  case 4:
  case 6:
  case 9:
  case 11:
    daysInMonth = 30;
    break;

    break;

  console.log(`${date}: שנה מחוץ לטווח`);
} else if (month < 1 || month > 12) {
  console.log(`${date}: אין חודש ${month}`);
} else if (day < 1 || day > daysInMonth) {

P03-E28 · חניון 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שני חלקים נפרדים: התצוגה (Math.floor, %, padStart — כמו בשעון של P02-E25) והמחיר (if / else if).

"רבע שעה שהתחיל" — איזו פונקציה של Math מעגלת למעלה?

💡 רמז 2

מעל שעה: 12 + Math.ceil((minutesParked - 60) / 15) * 3.5, ואז Math.min(80, ...).

✅ פתרון
03-conditions/starter/P03-E28.js 
const minutesParked = 135;

const firstHour = 12;
const perQuarter = 3.5;
const dailyMax = 80;

let price;
if (minutesParked <= 15) {
  price = 0;
} else if (minutesParked <= 60) {
  price = firstHour;
} else {
  const quarters = Math.ceil((minutesParked - 60) / 15);
  price = Math.min(dailyMax, firstHour + quarters * perQuarter);
}

const hours = Math.floor(minutesParked / 60);
const minutes = String(minutesParked % 60).padStart(2, "0");
console.log(`${hours}:${minutes} שעות חניה — לתשלום: ${price.toFixed(2)} ₪`);
2:15 שעות חניה — לתשלום: 29.50 ₪

בדיקה ב־135 דקות: אחרי השעה הראשונה נשארו 75 דקות. 75 / 15 הוא 5 רבעים בדיוק, ולכן 12 + 5 × 3.5 = 29.5. ב־61 דקות: Math.ceil(1 / 15) הוא 1, ולכן 15.50.

Math.min(80, ...) הוא "תקרה": הערך הקטן מבין השניים. זה אותו טריק כמו Math.max(0, ...) ב־P03-E06, שהוא "רצפה". שניהם חוסכים if.

⚠️ טעויות נפוצות
  • Math.floor או Math.round במקום Math.ceil — ב־61 דקות החניון יפסיד את הרבע שהתחיל.
  • minutesParked / 15 * 3.5 בלי להוריד את השעה הראשונה — השעה נספרת פעמיים.
  • ${hours}:${minutesParked % 60} בלי padStart ← 1:0 במקום 1:00.
