P25-E24 · אתגר: linter ל־workflows 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 60 דק׳ידע נדרש: כל הפרק

בקובץ P25-E24.ts: lintWorkflow(yamlText) ← רשימת { job, rule } (job: null לממצא ברמת הקובץ). קוראים את ה־YAML עם js-yaml. כללים:

  • yaml — לא נקרא (ואז רק הממצא הזה).
  • permissions — אין permissions ברמת הקובץ.
  • timeout — job בלי timeout-minutes.
  • unpinned-action — uses בלי @, או עם @main/@master.
  • npm-install — run עם npm install / npm i.
  • secret-in-run — ${{ secrets.… }} בתוך טקסט ה־run עצמו (במקום דרך env).
  • unknown-needs — needs ל־job שלא קיים.
  • deploy-without-needs — job ששמו כולל "deploy" בלי needs.
  • pr-secrets — ה־workflow רץ גם ב־pull_request, ה־job משתמש ב־secrets., וה־if שלו לא מגביל ל־push.

ה־ci.yml של הפרויקט (שלב ח׳) חייב לצאת נקי.
