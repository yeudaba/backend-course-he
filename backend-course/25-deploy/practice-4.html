P25-E05 · HTTPS ו־proxy

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

הפרויקט רץ ב־Render: הלקוח ← (HTTPS) ← load balancer של Render ← (HTTP, ברשת הפנימית) ← הקונטיינר שלך.

  1. הקוד שלך מאזין ל־HTTP, לא ל־HTTPS. האם החיבור של המשתמש מוצפן?
  2. מה יהיה req.ip בלי trust proxy? ומה זה יעשה להגבלת הקצב מפרק 24?
  3. מה יהיה req.protocol בלי trust proxy?
  4. למה לא פשוט app.set("trust proxy", true)?
  5. מה עושה Strict-Transport-Security, ולמה לא שולחים אותו ב־localhost?

P25-E07 · security headers 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 4

בקובץ P25-E07.ts כתוב middleware securityHeaders({ hstsMaxAge }):

  • בכל תשובה: X-Content-Type-Options: nosniff, X-Frame-Options: DENY, Referrer-Policy: no-referrer, Cross-Origin-Resource-Policy: same-site.
  • בלי X-Powered-By.
  • Strict-Transport-Security: max-age=<hstsMaxAge>; includeSubDomains — רק כש־req.secure (ברירת מחדל: 180 יום = 15552000 שניות).

P25-E12 · /ready עם כמה בדיקות 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 4

בקובץ P25-E12.ts: readyHandler(checks, { timeoutMs }) — handler של Express. checks — אובייקט של פונקציות async (למשל { db: () => prisma.$queryRawSELECT 1 }).

  • מריץ את כולן במקביל, כל אחת מוגבלת ל־timeoutMs.
  • 200 { status: "ok", checks: { db: "up", … } }, או 503 { status: "unavailable", checks } עם "down" (נכשלה/זרקה) או "timeout".
  • Cache-Control: no-store.

P25-E18 · מי הלקוח? X-Forwarded-For 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 4

בקובץ P25-E18.ts: clientIp(remoteAddress, forwardedFor, hops) — מה Express עושה עם trust proxy: hops.

  • forwardedFor — הערך של X-Forwarded-For: רשימה מופרדת בפסיקים. כל proxy מוסיף בסוף את הכתובת שהתחברה אליו.
  • hops — כמה proxies שלנו יש לפני השרת. 0 ← remoteAddress.
  • סופרים מהסוף: remoteAddress הוא hop 0, הכתובת האחרונה ברשימה — hop 1, וכן הלאה. רשימה קצרה מ־hops — הכתובת הכי רחוקה שיש.

הבודק משווה גם ל־req.ip של Express האמיתי.

P25-E23 · proxy ו־headers עם שלוש תקלות 🤖

💻 כתיבת קוד 🤖רמה 4⏱ 20 דק׳ידע נדרש: שיעור 4

השרת ב־P25-E23.ts רץ מאחורי proxy אחד (Render). הגבלת הקצב נעקפת עם header אחד, דפדפנים "ננעלים" על HTTPS גם ב־localhost, והשרת מספר לכל אחד על איזו טכנולוגיה הוא רץ. מצא ותקן.
