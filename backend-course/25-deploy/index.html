פרק 25 — CI ופריסה: מהמחשב שלך לכתובת חיה

⏱ 4 מפגשים

🧰 לפני שמתחילים — פרק 25

מה צריך שכבר יהיה מותקן: Node.js 24, Docker Desktop, ופרויקט 2 בשלב ז׳ — ב־repo משלו ב־GitHub (tasks-api), עם push שעובד.

מה מתקינים / פותחים עכשיו:

  • תוסף VS Code: GitHub Actions — השלמה ובדיקה של קובצי workflow בזמן הכתיבה, ורשימת ריצות בצד.
  • חשבון ב־Neon — PostgreSQL מנוהל בענן. בתוכנית החינמית המסד לא פג (נכון לנובמבר 2026; תנאים של תוכניות חינמיות משתנים — בדוק בדף התמחור).
  • חשבון ב־Render — מריץ את ה־Docker image שלך. בתוכנית החינמית השרת "נרדם" אחרי 15 דקות בלי בקשות, ומתעורר תוך כדקה.

שניהם — כניסה עם חשבון ה־GitHub, בלי כרטיס אשראי. את החשבונות פותחים רק בשיעור 5; עד אז הכול רץ אצלך ובתרגילים.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 25-deploy מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה: cd ~/dev/backend-course && npm install && npm run check P25-E09 ← הבודק רץ ונכשל על קובץ ההתחלה הריק (עוד לא כתבת workflow). זה הסימן שהכול מותקן — כולל js-yaml, שהבודק של התרגילים האלה צריך.

🎯 בסוף הפרק תדע
  • להבין CI ו־CD, ולכתוב workflow של GitHub Actions: triggers, jobs, steps, services, cache, matrix.
  • לנהל הגדרות וסודות: env, GitHub Secrets ו־Variables, הרשאות, ולהיכשל מהר על הגדרה שגויה.
  • לפרוס: migrations בטוחים, deploy, בדיקת עשן ו־rollback — ולהבין blue/green ו־expand/contract.
  • HTTPS ו־reverse proxy: TLS termination, trust proxy, security headers, health מול readiness.
  • פרויקט 2, שלב ח׳: CI/CD מלא — וקישור חי ל־API בתיק העבודות.

🤔 למה צריך את זה?

הפרויקט שלך עובד, נבדק ועולה ב־Docker — אצלך. מראיין שפותח את ה־README רוצה לראות שני דברים: שהבדיקות רצות לבד על כל שינוי (ה־✓ הירוק ליד כל commit), ושיש כתובת חיה שאפשר ללחוץ עליה. ובעבודה, אף אחד לא מעלה קוד "ידנית מהמחשב": כל pull request עובר CI, וכל merge ל־main יוצא לאוויר בתהליך אוטומטי — עם בדיקה שהוא באמת עובד, ודרך חזרה אם לא. הפרק הזה סוגר את פרויקט 2: מ־git push ועד https://….
