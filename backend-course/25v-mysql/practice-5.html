P25.5-E93 · ‏UUID ל־BINARY(16), ו־UUIDv7 ממוין 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 5

בקובץ 25v-mysql/starter/P25.5-E93.ts (יש בו רק הערה) כתוב וייצא:

export function uuidToBin(uuid: string): Buffer
export function binToUuid(bin: Buffer): string
export function uuidv7(nowMs: number, random: Buffer): string
  • uuidToBin — 16 בתים, בדיוק כמו UUID_TO_BIN(uuid) של MySQL. UUID לא תקין (36 תווים, hex ומקפים במקומות שלהם; אותיות גדולות מותרות) ← RangeError. ‏binToUuid — ההפך, באותיות קטנות.
  • uuidv7 — 48 הביטים הראשונים: nowMs; אחריהם 4 ביטים של גרסה (7); ‏2 ביטים של variant (10); כל השאר — מ־random (‏16 בתים, משתמשים בביטים שלו במקומות שנשארו).

הבודק משווה ל־MySQL אמיתי, ומכניס UUIDv7 לעמודת BINARY(16) כדי לבדוק שהסדר במסד = סדר הזמן.

P25.5-E94 · העברה בקבוצות — עם המשך 🤖

export async function copyInBatches<R extends { id: number }>(opts: {
  readBatch: (afterId: number, size: number) => Promise<R[]>;

  startAfter?: number;
}): Promise<{ batches: number; rows: number; lastId: number }>
