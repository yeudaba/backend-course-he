P25.5-E43 · ‏LAST_INSERT_ID — של מי?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

שלושה קטעי קוד (mysql2, עם pool). לכל אחד — האם ה־id שמתקבל הוא בהכרח של השורה שהקוד הכניס?

// א
await pool.query("INSERT INTO customers (name, email, city) VALUES (?, ?, ?)", [n, e, c]);
const [[{ id }]] = await pool.query("SELECT LAST_INSERT_ID() AS id");

// ב
const [res] = await pool.execute("INSERT INTO customers (name, email, city) VALUES (?, ?, ?)", [n, e, c]);
const id = res.insertId;

// ג
const [[{ id }]] = await pool.query("SELECT MAX(id) AS id FROM customers");

ומה עם INSERT של שלוש שורות בפקודה אחת — מה insertId מחזיר, ואיך מקבלים את שלושת המזהים?

P25.5-E27 · INSERT מרובה שורות, עם upsert 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 2⏱ 20 דק׳ידע נדרש: שיעור 2

🔁 חזרה על Object.keys (פרק 7), ‏map/flatMap/join (פרק 6), ‏regex (‏P13-E26) ושאילתות עם פרמטרים (‏P16-E27). ‏ORM לא תמיד יודע לייצר INSERT אחד עם 500 שורות. לולאה של 500 INSERTים איטית פי כמה עשרות. כתוב וייצא:

buildBulkInsert(table, rows, { add?, set? } = {}): { sql, params }

  • INSERT INTO t (a, b) VALUES (?, ?), (?, ?). סדר העמודות לפי המפתחות של השורה הראשונה, ו־params לפי אותו סדר, שורה אחרי שורה, גם אם בשורה אחרת המפתחות כתובים בסדר אחר.
  • upsert, בתחביר של שיעור 2: אם יש add או set, מוסיפים AS new ON DUPLICATE KEY UPDATE , ואחריו קודם כל עמודה מ־add (c = t.c + new.c), ואחר כך כל עמודה מ־set (c = new.c), מופרדות ב־", ".
  • שם טבלה או עמודה (גם ב־add/set) חייב להתאים ל־^[a-z_][a-z0-9_]*$. אין שורות, או שורה עם עמודות אחרות מהראשונה ← Error.

הבודק מריץ את התוצאה על MySQL אמיתי.

🔗 איך זה מתחבר: ‏map/join מפרק 6, ‏Object.keys מפרק 7 ושאילתות עם פרמטרים מפרק 16 — והשיעור: ‏ON DUPLICATE KEY UPDATE.
