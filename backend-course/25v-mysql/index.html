יחידה 25.5 — MySQL: מה שונה מ־PostgreSQL

⏱ 3 מפגשים

🧰 לפני שמתחילים — יחידה 25.5

מה צריך שכבר יהיה מותקן: PostgreSQL מפרק 16 (לתרגיל E25), ו־Docker Desktop מפרק 23 — כאן מריצים בו את MySQL בפקודה אחת.

מה מתקינים / מריצים עכשיו:

  • MySQL 8.4 בקונטיינר (פעם אחת; אחר כך docker start mysql): 
    docker run -d --name mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=course -e MYSQL_DATABASE=course mysql:8.4
  • בדיקה: docker exec -it mysql mysql -uroot -pcourse course -e "SELECT VERSION()" ← 8.4.x.
  • ב־~/dev/backend-course/.env: COURSE_MYSQL_URL=mysql://root:course@localhost:3306. הבודקים יוצרים database זמני לכל בדיקה ומוחקים אותו בסוף.
  • npm install בתיקיית הקורס — מוסיף את mysql2, ה־driver של MySQL ל־Node.js.
  • תוסף VS Code (לא חובה): Database Client — לראות טבלאות ולהריץ שאילתות מתוך העורך.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 25v-mysql מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה: cd ~/dev/backend-course && npm install && npm run check P25.5-E06 ← הבודק מתחבר ל־MySQL ונכשל על הקובץ הריק. ECONNREFUSED 127.0.0.1:3306 — הקונטיינר לא רץ.

🎯 בסוף הפרק תדע
  • להכיר את ההבדלים שמפתיעים מי שמגיע מ־PostgreSQL: טיפוסים, קולציות, utf8mb4, ||, RETURNING, upsert.
  • לכתוב SQL של MySQL 8: window functions, JSON, FULLTEXT, ו־GROUP BY תחת ONLY_FULL_GROUP_BY.
  • טרנזקציות ב־InnoDB: REPEATABLE READ, קריאות נועלות, SKIP LOCKED, ו־deadlocks — ולראות אותם קורים.
  • Node.js מול MySQL עם mysql2: pool, execute עם ?, insertId, affectedRows, וטיפוסים שחוזרים כמחרוזות.
  • אינדקסים ו־EXPLAIN ב־InnoDB, migrations עם GET_LOCK — והעברת נתונים מ־PostgreSQL.

🤔 למה צריך את זה?

בפרקים 16–19 עבדת עם PostgreSQL. רוב המודעות לג׳וניור Backend מבקשות "SQL" — וחלק גדול מהן מבקשות במפורש MySQL: הוא מסד הנתונים הפתוח הנפוץ בעולם, ובחברות רבות בארץ הוא הבסיס של המערכת. החדשות הטובות: 90% ממה שלמדת עובר כמו שהוא — SELECT, JOIN, GROUP BY, אינדקסים, טרנזקציות. היחידה הזו היא על ה־10% הנותרים: הדברים ש"עבדו ב־PostgreSQL" ומחזירים ב־MySQL תוצאה אחרת בשקט, והדברים שמראיין שואל עליהם כשכתוב במודעה "2+ years with MySQL".

🏁 מבחן מעבר

  • לתרגם שאילתה מ־PostgreSQL ל־MySQL, ולזהות את ||, ILIKE, DISTINCT ON ו־RETURNING.
  • להסביר utf8 מול utf8mb4, וקולציה _ai_ci — ומה זה עושה ל־UNIQUE.
  • להסביר REPEATABLE READ ולמה SELECT רגיל בתוך טרנזקציה יכול להחזיר ערך ישן.
  • לכתוב טרנזקציה עם mysql2 (חיבור אחד מה־pool), ותור עבודות עם SKIP LOCKED.
  • לקרוא EXPLAIN ולבנות אינדקס מורכב בסדר הנכון.
  • npm run check P25.5: 80% מ־E06–E19, ולפחות שני תרגילי תיקון.
