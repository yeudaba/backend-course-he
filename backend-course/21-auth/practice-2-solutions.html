P21-E02 · לפרק JWT ביד 🧠 הבנה רמה 1

💡 רמז 1

שלושה חלקים, מופרדים בנקודה. שני הראשונים — JSON.

💡 רמז 2

exp הוא שניות מאז 1970 ב־UTC: new Date(exp * 1000). בנובמבר ישראל ב־UTC+2.

✅ פתרון

(א) כל אחד יכול לקרוא את ה־header ואת ה־payload:

const [h, p] = token.split(".");
console.log(Buffer.from(h, "base64url").toString()); // {"alg":"HS256","typ":"JWT"}
console.log(Buffer.from(p, "base64url").toString()); // {"sub":7,"role":"user","iat":1793872800,"exp":1793873700}

משתמש 7, תפקיד user, נוצר ב־1793872800. מה שאי אפשר בלי הסוד: לבדוק שהחתימה אמיתית, או ליצור חתימה חדשה.

(ב) new Date(1793873700 * 1000).toISOString() ← 2026-11-05T10:15:00.000Z, כלומר 12:15 בשעון ישראל. 900 שניות (15 דקות) אחרי iat.

(ג) השרת מחשב את החתימה מחדש על ה־header וה־payload ששונו, ומקבל משהו אחר ממה שכתוב בחלק השלישי ← invalid signature ← 401. (אלא אם השרת משתמש ב־decode במקום verify — ראה E20.)

(ד) לא. ה־payload קריא לכל מי שמחזיק את הטוקן — כולל תוספי דפדפן, לוגים של proxy, וכל מי שהטוקן דלף אליו. ובנוסף: אם המשתמש מחליף טלפון, הטוקן ממשיך "לטעון" את הישן עד שיפוג. ב־JWT שמים מזהים וזכויות (sub, role), לא פרטים אישיים.

⚠️ טעויות נפוצות
  • לחשוב שה־payload מוצפן כי "הוא נראה כמו ג'יבריש". זה Base64url.
  • לשכוח ש־exp בשניות, ו־new Date() מצפה למילישניות ← תאריך ב־1970.

P21-E45 · ‏session או JWT? 🧠 הבנה רמה 1

💡 רמז 1

הטבלה בסעיף 1 של השיעור: "יציאה / ביטול" ו"מה השרת בודק".

💡 רמז 2

JWT אי אפשר לבטל, אבל אפשר לקצר לו את החיים.

✅ פתרון
  1. session: מוחקים את הרשומה, והכרטיס מת מיד. ‏JWT: עובד עד ה־exp.
  2. session: מיד (מוחקים את ה־sessions שלו). ‏JWT: רק כשהטוקן יפוג.
  3. session: גישה לאותו מקום שבו שמורים ה־sessions (מסד או Redis משותף). ‏JWT: רק את הסוד.
  4. session: שאילתה אחת לפחות בכל בקשה. ‏JWT: אפס.

הפרויקט: access token קצר (15 דקות, JWT, בלי מסד) ו־refresh token ארוך שנשמר במסד (אפשר לבטל, כמו session). כך מקבלים "בלי מסד ברוב הבקשות", וחלון של 15 דקות לכל היותר אחרי ביטול (שיעור 3).

⚠️ טעויות נפוצות
  • "JWT יותר מאובטח מ־session". אף אחד לא מאובטח יותר. יש פשרות שונות: ביטול מיידי מול בדיקה בלי מסד.

P21-E46 · ‏decode או verify? 🧠 הבנה רמה 2

💡 רמז 1

decode רק מפענח Base64. מה הוא לא בודק?

💡 רמז 2

שאל בכל קטע: האם השרת מחליט משהו על סמך נתונים שלא נבדקו?

✅ פתרון
  • א — פרצה. כל אחד יכול לכתוב payload עם "role":"admin", ו־decode יקבל אותו (ראית את זה בשיעור).
  • ב — בטוח: verifyAsync בודק חתימה ותוקף, ורק אז משתמשים בתוכן.
  • ג — בסדר. זה הלקוח שקורא את הטוקן שלו בשביל תצוגה. אין כאן החלטת הרשאה, והשרת ממילא יבדוק.
  • ד — עובד, אבל מבולגן: בודקים תוקף לפני חתימה (טוקן מזויף מקבל תשובה של "פג"), ושני מקורות אמת. כאן זה לא פרצה כי verifyAsync נקרא לפני השימוש, אבל עדיף לקחת את ה־payload מ־verify (ש־exp כבר בתוכו).
⚠️ טעויות נפוצות
  • "decode זה בסדר, כי ה־guard ממילא דורש טוקן". הוא דורש מחרוזת, וכל אחד יכול לייצר אחת.

P21-E47 · מה מותר לשים ב־payload? 🧠 הבנה רמה 1

💡 רמז 1

כל מי שמחזיק את הטוקן קורא את ה־payload. וה־payload נשלח בכל בקשה.

💡 רמז 2

ומה קורה לערך בטוקן כשהערך במסד משתנה?

✅ פתרון
  • sub, ‏exp — כן, זה העיקר.
  • role, ‏permissions — מקובל: חוסך שאילתה. המחיר: שינוי הרשאה תופס רק כשהטוקן פג (סיבה לתוקף קצר).
  • email — עדיף לא: מידע אישי שנחשף לכל מי שרואה את הטוקן (לוגים, proxy), ומשתנה.
  • passwordHash, ‏creditCardLast4 — לא. סודות או מידע רגיש בטקסט גלוי (Base64).
  • isBlocked — חסר תועלת: אם הוא חסום, לא מנפיקים לו טוקן. וערך שהשתנה אחרי ההנפקה לא יתעדכן בטוקן.
  • רשימת משימות — לא. הטוקן נשלח בכל בקשה ויהיה ענק, והמידע מתיישן מיד.
⚠️ טעויות נפוצות
  • לחשוב שהחתימה "מסתירה" את התוכן. החתימה מונעת שינוי, לא קריאה.

P21-E48 · אילו headers עוברים? 🧠 הבנה רמה 2

💡 רמז 1

\s+ — רווח אחד או יותר. ‏\S+ — תווים שאינם רווח, לפחות אחד. ‏^/$ — כל המחרוזת.

💡 רמז 2

Express לא עושה trim לערכים של headers שאתה בונה בבדיקה.

✅ פתרון
const re = /^Bearer\s+(\S+)$/i;
for (const h of ["Bearer abc.def.ghi", "bearer abc", "Bearer  abc", "Bearer abc def", "Bearerabc", "Basic abc", " Bearer abc", "BEARER abc.def", ""]) {
  const m = re.exec(h);
  console.log(JSON.stringify(h).padEnd(22), m ? m[1] : null);
}
"Bearer abc.def.ghi"   abc.def.ghi
"bearer abc"           abc
"Bearer  abc"          abc
"Bearer abc def"       null
"Bearerabc"            null
"Basic abc"            null
" Bearer abc"          null
"BEARER abc.def"       abc.def
""                     null

הדגל i מקבל כל צורה של "Bearer" (התקן אומר שה־scheme לא תלוי באותיות). שני רווחים עוברים בזכות \s+. טוקן עם רווח בתוכו או רווח לפני "Bearer" נדחים בזכות ^ ו־$. ו־?? "": בלי header, req.get מחזיר undefined, ו־exec(undefined) היה בודק את המחרוזת "undefined". עם "" פשוט אין התאמה ← 401.

⚠️ טעויות נפוצות
  • header.split(" ")[1] — "עובד" על "Basic abc" ועל "Bearer abc def", ומעביר הלאה טוקן לא נכון.

P21-E49 · ‏"default deny" — מה קורה כשמישהו שוכח? 🧠 הבנה רמה 2

💡 רמז 1

"שכחה צריכה להיכשל לכיוון הבטוח" (סעיף 4).

💡 רמז 2

טעות שכולם רואים מיד מול טעות שאף אחד לא רואה.

✅ פתרון
  • (א) צוות א׳: ה־route פתוח לכולם, ואף אחד לא ישים לב (הוא עובד!) עד שמישהו מבחוץ ימצא אותו. צוות ב׳: הוא מוגן אוטומטית.
  • (ב) אף אחד לא יכול להתחבר (401 בכניסה). הבדיקה הראשונה, או המשתמש הראשון, יגלו את זה תוך דקות.
  • (ג) הטעות של צוות ב׳. היא "רועשת" ונתפסת מיד, ולא חושפת מידע. הטעות של צוות א׳ שקטה ומסוכנת. זה default deny: מה שלא הותר במפורש — אסור.
⚠️ טעויות נפוצות
  • לחשוב ש־code review יתפוס כל שכחה. הוא לא. ברירת מחדל בטוחה תופסת גם את מה שהעין פספסה.

P21-E09 · כניסה ו־JWT 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

ה־JwtService מוזרק (כי JwtModule ב־imports): this.jwt.signAsync(payload, { expiresIn: 900 }).

💡 רמז 2

POST מחזיר 201 כברירת מחדל — כניסה לא "יוצרת משאב", אז @HttpCode(200).

✅ פתרון
// P21-E09
import { Body, Controller, HttpCode, Injectable, Module, OnModuleInit, Post, UnauthorizedException } from "@nestjs/common";
import { JwtModule, JwtService } from "@nestjs/jwt";
import bcrypt from "bcryptjs";

export const JWT_SECRET = "e09-secret-for-exercises-only-0123456789";

interface User {
  id: number;
  email: string;
  passwordHash: string;
  role: "user" | "admin";
}

@Injectable()
export class UsersService implements OnModuleInit {
  private users: User[] = [];

  async onModuleInit() {
    this.users = [
      { id: 1, email: "dana@example.com", passwordHash: await bcrypt.hash("dana-password-1", 4), role: "user" },
      { id: 2, email: "admin@example.com", passwordHash: await bcrypt.hash("admin-password-1", 4), role: "admin" },
    ];
  }

  findByEmail(email: string) {
    return this.users.find((u) => u.email === email);
  }
}

@Injectable()
export class AuthService {
  constructor(
    private readonly users: UsersService,
    private readonly jwt: JwtService,
  ) {}

  async login(email: string, password: string) {
    const user = this.users.findByEmail(String(email).trim().toLowerCase());
    // אותה שגיאה לשני המקרים
    if (!user || !(await bcrypt.compare(String(password), user.passwordHash))) {
      throw new UnauthorizedException("אימייל או סיסמה שגויים");
    }
    const accessToken = await this.jwt.signAsync({ sub: user.id, role: user.role }, { expiresIn: 900 });
    return { accessToken, tokenType: "Bearer", expiresIn: 900 };
  }
}

@Controller("auth")
export class AuthController {
  constructor(private readonly auth: AuthService) {}

  @Post("login")
  @HttpCode(200)
  login(@Body() body: { email: string; password: string }) {
    return this.auth.login(body.email, body.password);
  }
}

@Module({
  imports: [JwtModule.register({ secret: JWT_SECRET })],
  controllers: [AuthController],
  providers: [UsersService, AuthService],
})
export class AuthModule {}

שים לב שהבודק מאמת את הטוקן עם new JwtService({ secret: JWT_SECRET }).verifyAsync(...) — כלומר כל שרת שמכיר את הסוד יכול לבדוק אותו, בלי לשאול את המסד. זה כל הרעיון של JWT. (בפרויקט גם משווים זמנים עם hash דמה — E18.)

⚠️ טעויות נפוצות
  • להכניס את האימייל ל־payload "בשביל הנוחות".
  • לשכוח expiresIn ← טוקן לנצח.

P21-E10 · guard של JWT 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

/^Bearer\s+(\S+)$/i.exec(req.get("authorization") ?? "").

💡 רמז 2

verifyAsync זורק על כל בעיה. תפוס, וזרוק UnauthorizedException משלך — אחרת השגיאה של הספרייה הופכת ל־500.

✅ פתרון
// P21-E10
import { CanActivate, Controller, ExecutionContext, Get, Injectable, Module, Req, UnauthorizedException, UseGuards } from "@nestjs/common";
import { JwtModule, JwtService } from "@nestjs/jwt";
import type { Request } from "express";

export const JWT_SECRET = "e10-secret-for-exercises-only-0123456789";

export interface AuthUser {
  id: number;
  role: string;
}

@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(private readonly jwt: JwtService) {}

  async canActivate(context: ExecutionContext) {
    const req = context.switchToHttp().getRequest<Request & { user?: AuthUser }>();
    const match = /^Bearer\s+(\S+)$/i.exec(req.get("authorization") ?? "");
    if (!match) throw new UnauthorizedException("נדרשת התחברות");
    try {
      const payload = await this.jwt.verifyAsync<{ sub: number; role: string }>(match[1], { algorithms: ["HS256"] });
      req.user = { id: payload.sub, role: payload.role };
      return true;
    } catch {
      throw new UnauthorizedException("טוקן לא תקין");
    }
  }
}

@Controller()
export class ProfileController {
  @Get("me")
  @UseGuards(JwtAuthGuard)
  me(@Req() req: { user: AuthUser }) {
    return req.user;
  }

  @Get("hello")
  hello() {
    return { hello: "world" };
  }
}

@Module({
  imports: [JwtModule.register({ secret: JWT_SECRET })],
  controllers: [ProfileController],
  providers: [JwtAuthGuard],
})
export class ProfileModule {}

algorithms: ["HS256"] — רשימה מפורשת של מה שמקבלים. טוקן שה־header שלו מצהיר על אלגוריתם אחר נדחה, גם אם מישהו ינסה טריקים.

⚠️ טעויות נפוצות
  • return false במקום לזרוק ← Nest מחזיר 403 "Forbidden resource" (E21).
  • authorization.split(" ")[1] — עם שני רווחים, או בלי רווח, מקבלים undefined או מחרוזת ריקה.

P21-E11 · guard גלובלי ו־@Public 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

this.reflector.getAllAndOverride(IS_PUBLIC, [context.getHandler(), context.getClass()]).

💡 רמז 2

ה־guard צריך Reflector ו־JwtService ב־constructor. עם APP_GUARD + useClass, Nest מזריק אותם.

✅ פתרון
// P21-E11
import {
  CanActivate, Controller, createParamDecorator, ExecutionContext, Get, Injectable, Module, SetMetadata, UnauthorizedException,
} from "@nestjs/common";
import { APP_GUARD, Reflector } from "@nestjs/core";
import { JwtModule, JwtService } from "@nestjs/jwt";
import type { Request } from "express";

export const JWT_SECRET = "e11-secret-for-exercises-only-0123456789";

export interface AuthUser {
  id: number;
  role: string;
}

export const IS_PUBLIC = "isPublic";
export const Public = () => SetMetadata(IS_PUBLIC, true);

export const CurrentUser = createParamDecorator((_data: unknown, ctx: ExecutionContext): AuthUser => {
  return ctx.switchToHttp().getRequest().user;
});

@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(
    private readonly jwt: JwtService,
    private readonly reflector: Reflector,
  ) {}

  async canActivate(context: ExecutionContext) {
    // getAllAndOverride: קודם המתודה, אחר כך ה־class
    if (this.reflector.getAllAndOverride<boolean>(IS_PUBLIC, [context.getHandler(), context.getClass()])) return true;
    const req = context.switchToHttp().getRequest<Request & { user?: AuthUser }>();
    const match = /^Bearer\s+(\S+)$/i.exec(req.get("authorization") ?? "");
    if (!match) throw new UnauthorizedException("נדרשת התחברות");
    try {
      const payload = await this.jwt.verifyAsync<{ sub: number; role: string }>(match[1]);
      req.user = { id: payload.sub, role: payload.role };
      return true;
    } catch {
      throw new UnauthorizedException("טוקן לא תקין");
    }
  }
}

@Controller("notes")
export class NotesController {
  @Get("mine")
  mine(@CurrentUser() user: AuthUser) {
    return { owner: user.id, notes: [`הפתק של משתמש ${user.id}`] };
  }

  @Public()
  @Get("public")
  publicNotes() {
    return { notes: ["פתק לכולם"] };
  }
}

@Public()
@Controller("info")
export class InfoController {
  @Get()
  info() {
    return { name: "notes-api", version: "1.0" };
  }
}

@Module({
  imports: [JwtModule.register({ secret: JWT_SECRET })],
  controllers: [NotesController, InfoController],
  providers: [{ provide: APP_GUARD, useClass: JwtAuthGuard }],
})
export class NotesModule {}

"default deny": controller חדש שמישהו יוסיף מחר מוגן אוטומטית. כדי לפתוח משהו — צריך לכתוב @Public() במפורש, וזה בולט ב־code review.

⚠️ טעויות נפוצות
  • reflector.get(IS_PUBLIC, context.getHandler()) בלבד ← @Public() על class לא עובד (E21).

P21-E12 · תוקף לפי שעון 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

ב־signAsync, iat שבתוך ה־payload קובע גם ממנו נספר expiresIn.

💡 רמז 2

verifyAsync(token, { clockTimestamp }), ו־err.name === "TokenExpiredError".

✅ פתרון
// P21-E12
import { Inject, Injectable, Module, UnauthorizedException } from "@nestjs/common";
import { JwtModule, JwtService } from "@nestjs/jwt";

export const CLOCK = "CLOCK";
export const ACCESS_TTL_SECONDS = 900;
export interface Clock {
  now(): Date;
}

@Injectable()
export class TokenService {
  constructor(
    private readonly jwt: JwtService,
    @Inject(CLOCK) private readonly clock: Clock,
  ) {}

  private nowSeconds() {
    return Math.floor(this.clock.now().getTime() / 1000);
  }

  issue(userId: number): Promise<string> {
    // iat מהשעון שלנו — ו־exp מחושב ממנו
    return this.jwt.signAsync({ sub: userId, iat: this.nowSeconds() }, { expiresIn: ACCESS_TTL_SECONDS });
  }

  async verify(token: string): Promise<{ userId: number }> {
    try {
      const payload = await this.jwt.verifyAsync<{ sub: number }>(token, { clockTimestamp: this.nowSeconds() });
      return { userId: payload.sub };
    } catch (err) {
      const expired = err instanceof Error && err.name === "TokenExpiredError";
      throw new UnauthorizedException(expired ? "פג תוקף הטוקן" : "טוקן לא תקין");
    }
  }
}

@Module({
  imports: [JwtModule.register({ secret: "e12-secret-for-exercises-only-0123456789" })],
  providers: [TokenService, { provide: CLOCK, useValue: { now: () => new Date() } }],
  exports: [TokenService],
})
export class TokensModule {}

למה זה חשוב? בלי שעון מוזרק, הבדיקה של "פג תוקף" צריכה לחכות 15 דקות, או ליצור טוקן עם תאריך בעבר ולקוות שהחישוב נכון. עם CLOCK — בודקים את הגבול בדיוק, בשנייה.

⚠️ טעויות נפוצות
  • Date.now() במקום Math.floor(... / 1000) ← iat במילישניות, וכל טוקן "נוצר בעתיד הרחוק".

P21-E20 · שלוש תקלות של כניסה 🤖 💻 כתיבת קוד 🤖 רמה 4

import { Body, Controller, Get, Headers, HttpCode, Injectable, Module, Post, UnauthorizedException } from "@nestjs/common";
import { JwtModule, JwtService } from "@nestjs/jwt";
import bcrypt from "bcryptjs";

export const JWT_SECRET = "e20-secret-for-exercises-only-0123456789";

interface User {
  id: number;
  email: string;
  passwordHash: string;
  role: "user" | "admin";
}

@Injectable()
export class AuthService {
  private readonly users: User[] = [];

  constructor(private readonly jwt: JwtService) {}

  async register(email: string, password: string) {
    const user: User = { id: this.users.length + 1, email, passwordHash: await bcrypt.hash(password, 4), role: "user" };
    this.users.push(user);
    const { passwordHash, ...publicUser } = user; // ← תקלה 3: ה־hash יצא בתשובה
    return publicUser;
  }

  async login(email: string, password: string) {
    const user = this.users.find((u) => u.email === email);
    // ← תקלה 2: היה password === user.passwordHash — סיסמה אף פעם לא שווה ל־hash שלה
    if (!user || !(await bcrypt.compare(password, user.passwordHash))) throw new UnauthorizedException("אימייל או סיסמה שגויים");
    return { accessToken: await this.jwt.signAsync({ sub: user.id, role: user.role }, { expiresIn: 900 }) };
  }

  async whoAmI(authorization: string | undefined) {
    const token = /^Bearer\s+(\S+)$/i.exec(authorization ?? "")?.[1];
    if (!token) throw new UnauthorizedException("נדרשת התחברות");
    try {
      // ← תקלה 1: היה jwt.decode — מפענח בלי לבדוק חתימה. כל אחד יכול "להיות" admin
      const payload = await this.jwt.verifyAsync<{ sub: number; role: string }>(token);
      return { id: payload.sub, role: payload.role };
    } catch {
      throw new UnauthorizedException("טוקן לא תקין");
    }
  }
}

@Controller("auth")
export class AuthController {
  constructor(private readonly auth: AuthService) {}

  @Post("register")
  register(@Body() body: { email: string; password: string }) {
    return this.auth.register(body.email, body.password);
  }

  @Post("login")
  @HttpCode(200)
  login(@Body() body: { email: string; password: string }) {
    return this.auth.login(body.email, body.password);
  }

  @Get("me")
  me(@Headers("authorization") authorization?: string) {
    return this.auth.whoAmI(authorization);
  }
}

@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(
    private readonly jwt: JwtService,
    private readonly reflector: Reflector,
  ) {}

  async canActivate(context: ExecutionContext) {
    // ← תקלה 2: היה reflector.get(IS_PUBLIC, context.getHandler()) — @Public() על ה־class לא נקרא
    if (this.reflector.getAllAndOverride<boolean>(IS_PUBLIC, [context.getHandler(), context.getClass()])) return true;

💡 רמז 1

// P21-E26: JWT ביד — HS256 עם node:crypto
import { createHmac, timingSafeEqual } from "node:crypto";

export type Claims = { sub: number; role: string; iat: number; exp: number };

const b64 = (value: unknown) => Buffer.from(JSON.stringify(value)).toString("base64url");
const sign = (data: string, secret: string) => createHmac("sha256", secret).update(data).digest("base64url");

export function signJwt(payload: { sub: number; role: string }, secret: string, expiresInSec: number, now = Math.floor(Date.now() / 1000)): string {
  const data = `${b64({ alg: "HS256", typ: "JWT" })}.${b64({ ...payload, iat: now, exp: now + expiresInSec })}`;
  return `${data}.${sign(data, secret)}`;
}

export function verifyJwt(token: string, secret: string, now = Math.floor(Date.now() / 1000)): Claims {
  const parts = token.split(".");
  if (parts.length !== 3) throw new Error("טוקן לא תקין");
  const [header, payload, signature] = parts;

  const expected = Buffer.from(sign(`${header}.${payload}`, secret));
  const actual = Buffer.from(signature);
  if (expected.length !== actual.length || !timingSafeEqual(expected, actual)) {
    throw new Error("חתימה לא תקינה");
  }

  let head: { alg?: string };
  let claims: Claims;
  try {
    head = JSON.parse(Buffer.from(header, "base64url").toString());
    claims = JSON.parse(Buffer.from(payload, "base64url").toString());
  } catch {
    throw new Error("טוקן לא תקין");
  }
  if (head.alg !== "HS256") throw new Error("טוקן לא תקין");
  if (typeof claims.exp !== "number" || now >= claims.exp) throw new Error("פג תוקף");
  return claims;
}

// P21-E50: jwtInfo — רק לתצוגה. לא להחלטות הרשאה!
export type JwtInfo = { alg: string; sub: number; role: string; secondsLeft: number; expired: boolean };

const fromB64 = (part: string) => JSON.parse(Buffer.from(part, "base64url").toString("utf8"));

export function jwtInfo(token: string, nowSec: number): JwtInfo {
  const parts = token.split(".");
  if (parts.length !== 3) throw new Error("טוקן לא תקין");
  let header: { alg: string };
  let payload: { sub: number; role: string; exp: number };
  try {
    header = fromB64(parts[0]);
    payload = fromB64(parts[1]);
  } catch {
    throw new Error("טוקן לא תקין");
  }
  return {
    alg: header.alg,
    sub: payload.sub,
    role: payload.role,
    secondsLeft: Math.max(0, payload.exp - nowSec),
    expired: nowSec >= payload.exp,
  };
}

// P21-E27: פירוק header של Authorization
export type Credentials =
  | { scheme: "bearer"; token: string }
  | { scheme: "basic"; username: string; password: string };

export function parseAuthorization(header: string | undefined): Credentials | null {
  const match = header?.trim().match(/^(\S+)\s+(\S+)$/);
  if (!match) return null;
  const [, scheme, value] = match;

  switch (scheme.toLowerCase()) {
    case "bearer":
      return /^[A-Za-z0-9._~+/-]+=*$/.test(value) ? { scheme: "bearer", token: value } : null;
    case "basic": {
      const decoded = Buffer.from(value, "base64").toString("utf8");
      const i = decoded.indexOf(":");
      if (i <= 0) return null;
      return { scheme: "basic", username: decoded.slice(0, i), password: decoded.slice(i + 1) };
    }
    default:
      return null;
  }
}

import { CanActivate, Controller, ExecutionContext, Get, Injectable, Module, Req, UnauthorizedException, UseGuards } from "@nestjs/common";
import { JwtModule, JwtService } from "@nestjs/jwt";

export const SECRET = "p21-e54-secret-at-least-32-chars!!";

function readCookie(header: string | undefined, name: string): string | undefined {
  for (const part of (header ?? "").split(";")) {
    const i = part.indexOf("=");
    if (i !== -1 && part.slice(0, i).trim() === name) return part.slice(i + 1).trim();
  }
  return undefined;
}

@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(private readonly jwt: JwtService) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const req = context.switchToHttp().getRequest();
    const header: string | undefined = req.get("authorization");
    let token: string | undefined;
    if (header !== undefined) {
      token = /^Bearer\s+(\S+)$/i.exec(header)?.[1];
    } else {
      token = readCookie(req.get("cookie"), "access_token");
    }
    if (!token) throw new UnauthorizedException("נדרשת התחברות");
    try {
      const payload = await this.jwt.verifyAsync(token);
      req.user = { id: payload.sub, role: payload.role };
      return true;
    } catch {
      throw new UnauthorizedException("טוקן לא תקין");
    }
  }
}

@Controller()
export class MeController {
  @Get("me")
  @UseGuards(JwtAuthGuard)
  me(@Req() req: any) {
    return req.user;
  }

  @Get("hello")
  hello() {
    return { hello: "world" };
  }
}

@Module({
  imports: [JwtModule.register({ secret: SECRET })],
  controllers: [MeController],
  providers: [JwtAuthGuard],
})
export class AppModule {}

למה לא "נופלים" ל־cookie כשה־header שבור? כי זה מסתיר באגים בלקוח, ובאבטחה כלל טוב הוא: מקור אחד ברור לכל בקשה. ו־cookie בדפדפן מביא איתו את CSRF (הדפדפן שולח אותו לבד), לכן במוצר אמיתי מוסיפים SameSite (שיעור 3).

⚠️ טעויות נפוצות
  • cookie.split("=") — טוקן שיש בו = (ריפוד של base64) נחתך.
  • לחפש includes("access_token") — גם my_access_token=... "מתאים".

// P21-E55: לקוח API שמוסיף Authorization לכל בקשה
export class ApiError extends Error {
  status: number;
  code: string | undefined;
  constructor(status: number, message: string, code: string | undefined) {
    super(message);
    this.status = status;
    this.code = code;
  }
}

export function createApiClient(baseUrl: string, getToken: () => string | null) {
  return {
    async request(method: string, path: string, body?: unknown): Promise<unknown> {
      const headers: Record<string, string> = {};
      const token = getToken();
      if (token !== null) headers.authorization = `Bearer ${token}`;
      if (body !== undefined) headers["content-type"] = "application/json";
      const res = await fetch(baseUrl + path, { method, headers, body: body === undefined ? undefined : JSON.stringify(body) });
      if (res.status === 204) return null;
      const text = await res.text();
      if (res.ok) return JSON.parse(text);
      let data: { code?: string; message?: string } = {};
      try {
        data = JSON.parse(text);
      } catch {}
      throw new ApiError(res.status, data.message ?? `HTTP ${res.status}`, data.code);
    },
  };
}

בזכות getToken (פונקציה, לא ערך), הלקוח תמיד שולח את הטוקן העדכני. זה הבסיס ל־E71 (שיעור 3), שבו הלקוח מרענן טוקן לבד כשמקבל 401.

⚠️ טעויות נפוצות
  • לקבל את הטוקן כמחרוזת ב־createApiClient. אחרי refresh הלקוח ממשיך לשלוח את הישן.
  • await res.json() על 204 — זורק (אין גוף).
