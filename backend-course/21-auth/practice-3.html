(א) למה לא לתת access token אחד ל־7 ימים? (ב) למה לא refresh token שהוא JWT (בלי מסד)? (ג) תוקף גנב את ה־refresh token של דנה ביום שני ב־09:00, והשתמש בו ב־09:05. דנה פתחה את הלפטופ ב־09:30. מה קורה, צעד אחר צעד? (ד) ומה אם התוקף גנב רק את ה־access token?

P21-E15 · refresh token אטום 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

בקובץ 21-auth/starter/P21-E15.ts השלם את RefreshTokenService:

  • issue(userId) ← 32 בתים אקראיים ב־base64url (43 תווים). באחסון (records) המפתח הוא ה־SHA-256 (hex) של הטוקן — לא הטוקן. תוקף: 7 ימים לפי CLOCK.
  • rotate(token) ← { userId, refreshToken } חדש, והישן לא עובד יותר. לא קיים / כבר נוצל / פג ← 401 "צריך להתחבר מחדש".

P21-E16 · משפחות של טוקנים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 3

בפרויקט, שימוש חוזר מבטל את כל הטוקנים של המשתמש — גם בטלפון, שלא קרה לו כלום. בקובץ 21-auth/starter/P21-E16.ts עשה את זה מדויק יותר:

  • login(userId) ← טוקן חדש ב"משפחה" חדשה (כניסה = מכשיר).
  • rotate(token) ← טוקן חדש באותה משפחה, והישן מבוטל.
  • שימוש בטוקן מבוטל ← מבטלים את כל המשפחה שלו (ורק אותה), ו־401.
  • activeCount(userId) ← כמה טוקנים פעילים יש למשתמש. תוקף: 7 ימים.

P21-E17 · יציאה והחלפת סיסמה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

בקובץ 21-auth/starter/P21-E17.ts השלם את AccountService:

  • logout(token) — מבטל את ה־refresh token הזה בלבד. טוקן לא מוכר — לא עושה כלום (בלי שגיאה).
  • changePassword(userId, oldPassword, newPassword):
    • הסיסמה הנוכחית שגויה ← 401 "הסיסמה הנוכחית שגויה".
    • חדשה קצרה מ־8 ← 400 "לפחות 8 תווים"; זהה לישנה ← 400 "הסיסמה החדשה זהה לישנה".
    • הצלחה ← hash חדש, וכל ה־refresh tokens של המשתמש מבוטלים.

P21-E28 · רשימת חסימה לטוקנים 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 20 דק׳ידע נדרש: שיעור 3

🔁 חזרה על class עם שדות פרטיים ו־getter (פרק 12), ‏Map ומחיקה תוך כדי מעבר (פרק 7), ושעון מוזרק (‏P21-E12). access token אי אפשר "לבטל": הוא תקף עד ה־exp שלו. כשחייבים לבטל אחד מיד (משתמש נחסם, טוקן דלף), שומרים את המזהה שלו (jti) ברשימת חסימה, עד שהוא פג ממילא. כתוב וייצא class TokenBlocklist:

  • constructor(now = () => Math.floor(Date.now() / 1000)) — שעון בשניות, שאפשר להחליף בבדיקות.
  • block(jti, exp) — חוסמת עד exp. טוקן שכבר פג (exp <= now()) — לא נשמר בכלל.
  • isBlocked(jti) — ‏true רק אם הוא ברשימה ועוד לא פג.
  • cleanup() — מוחקת את כל מה שפג, ומחזירה כמה נמחקו.
  • getter size. הנתונים בשדות פרטיים.
