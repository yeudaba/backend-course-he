P21-E26 · JWT ביד, עם node:crypto 🤖 ✍️ מאפס רמה 3

💡 רמז 1

שתי פונקציות עזר: b64 = (v) => Buffer.from(JSON.stringify(v)).toString("base64url") ו־sign = (data, secret) => createHmac("sha256", secret).update(data).digest("base64url"). אחר כך signJwt היא שתי שורות.

💡 רמז 2

ב־verifyJwt: מחשבים מחדש את החתימה מ־header.payload, ומשווים לזו שבטוקן. ‏timingSafeEqual מקבלת שני Buffer באותו אורך, אחרת היא זורקת. לכן קודם בודקים את האורך: expected.length !== actual.length || !timingSafeEqual(expected, actual). רק אחרי שהחתימה תקינה מפענחים JSON.

✅ פתרון
// P21-E26: JWT ביד — HS256 עם node:crypto
import { createHmac, timingSafeEqual } from "node:crypto";

export type Claims = { sub: number; role: string; iat: number; exp: number };

const b64 = (value: unknown) => Buffer.from(JSON.stringify(value)).toString("base64url");
const sign = (data: string, secret: string) => createHmac("sha256", secret).update(data).digest("base64url");

export function signJwt(payload: { sub: number; role: string }, secret: string, expiresInSec: number, now = Math.floor(Date.now() / 1000)): string {
  const data = `${b64({ alg: "HS256", typ: "JWT" })}.${b64({ ...payload, iat: now, exp: now + expiresInSec })}`;
  return `${data}.${sign(data, secret)}`;
}

export function verifyJwt(token: string, secret: string, now = Math.floor(Date.now() / 1000)): Claims {
  const parts = token.split(".");
  if (parts.length !== 3) throw new Error("טוקן לא תקין");
  const [header, payload, signature] = parts;

  const expected = Buffer.from(sign(`${header}.${payload}`, secret));
  const actual = Buffer.from(signature);
  if (expected.length !== actual.length || !timingSafeEqual(expected, actual)) {
    throw new Error("חתימה לא תקינה");
  }

  let head: { alg?: string };
  let claims: Claims;
  try {
    head = JSON.parse(Buffer.from(header, "base64url").toString());
    claims = JSON.parse(Buffer.from(payload, "base64url").toString());
  } catch {
    throw new Error("טוקן לא תקין");
  }
  if (head.alg !== "HS256") throw new Error("טוקן לא תקין");
  if (typeof claims.exp !== "number" || now >= claims.exp) throw new Error("פג תוקף");
  return claims;
}

}

P21-E27 · פירוק header של Authorization 🤖 🔁 חזרה רמה 2

💡 רמז 1

const match = header?.trim().match(/^(\S+)\s+(\S+)$/); — ‏?. מטפל ב־undefined. אחר כך const [, scheme, value] = match; ו־switch (scheme.toLowerCase()).

💡 רמז 2

טוקן: /^[A-Za-z0-9._~+/-]+=*$/ (המקף בסוף הסוגריים, כדי שלא ייקרא כטווח). ‏basic: ‏Buffer.from(value, "base64").toString("utf8"), ואז indexOf(":") ו־slice, כמו בעוגיות. בתוך case שמגדיר const צריך סוגריים מסולסלים: case "basic": { ... }.

✅ פתרון
// P21-E27: פירוק header של Authorization
export type Credentials =
  | { scheme: "bearer"; token: string }
  | { scheme: "basic"; username: string; password: string };

export function parseAuthorization(header: string | undefined): Credentials | null {
  const match = header?.trim().match(/^(\S+)\s+(\S+)$/);
  if (!match) return null;
  const [, scheme, value] = match;

  switch (scheme.toLowerCase()) {
    case "bearer":
      return /^[A-Za-z0-9._~+/-]+=*$/.test(value) ? { scheme: "bearer", token: value } : null;
    case "basic": {
      const decoded = Buffer.from(value, "base64").toString("utf8");
      const i = decoded.indexOf(":");
      if (i <= 0) return null;
      return { scheme: "basic", username: decoded.slice(0, i), password: decoded.slice(i + 1) };
    }
    default:
      return null;
  }
}

  • header.split(" ") — שני רווחים באמצע נותנים מילה ריקה, ו־undefined בלי ?. מפיל את השרת.
  • if (scheme === "Bearer") — לקוחות ששולחים bearer נדחים. לפי התקן ה־scheme לא תלוי באותיות.
  • const [user, pass] = decoded.split(":") — הסיסמה pa:ss נחתכת ל־pa.

P21-E28 · רשימת חסימה לטוקנים 🤖 🔁 חזרה רמה 3

💡 רמז 1

שני שדות: #blocked = new Map<string, number>() (‏jti ← exp) ו־#now: () => number. ‏isBlocked: ‏const exp = this.#blocked.get(jti); return exp !== undefined && exp > this.#now();.

💡 רמז 2

cleanup: ‏for (const [jti, exp] of this.#blocked) { if (exp <= now) { this.#blocked.delete(jti); removed++; } }. ב־Map מותר למחוק את הרשומה הנוכחית תוך כדי מעבר. קרא ל־this.#now() פעם אחת לפני הלולאה.

✅ פתרון
// P21-E28: רשימת חסימה לטוקנים (logout ל־access token)
export class TokenBlocklist {
  #blocked = new Map<string, number>();
  #now: () => number;

  constructor(now: () => number = () => Math.floor(Date.now() / 1000)) {
    this.#now = now;
  }

  block(jti: string, exp: number): void {
    if (exp <= this.#now()) return; // כבר פג תוקף — אין מה לחסום
    this.#blocked.set(jti, exp);
  }

  isBlocked(jti: string): boolean {
    const exp = this.#blocked.get(jti);
    return exp !== undefined && exp > this.#now();
  }

  cleanup(): number {
    const now = this.#now();
    let removed = 0;
    for (const [jti, exp] of this.#blocked) {
      if (exp <= now) {
        this.#blocked.delete(jti);
        removed++;
      }
    }
    return removed;
  }

  get size(): number {
    return this.#blocked.size;
  }
}

  • לשמור טוקנים שכבר פגו — הרשימה גדלה בלי סיבה.
  • size() כמתודה במקום get size().

P21-E01 · hash, הצפנה או encoding? רמה 1

💡 רמז 1

טבלת שלוש השורות בתחילת שיעור 1.

💡 רמז 2

חשוב מה יש לתוקף שמחזיק עותק של המסד וגם של קוד השרת וה־env.

✅ פתרון
  1. לא. הצפנה הפיכה — מי שמשיג את המפתח (שיושב באותו שרת, ב־env) מקבל את כל הסיסמאות. ומי שעובד בחברה עם גישה למפתח — גם.
  2. לא. Base64 הוא encoding: Buffer.from(x, "base64").toString() וזהו. זו לא הגנה בכלל.
  3. לא. הוא חד־כיווני, אבל מהיר ובלי salt: תוקף מנחש מיליארדי סיסמאות נפוצות בשנייה, וכל ניחוש נבדק מול כל המשתמשים בבת אחת.
  4. לא. ל־bcrypt יש salt אקראי חדש בכל hash — ראית בשיעור ש־a === b הוא false.
  5. לא. בגלל ה־salt, hash חדש לעולם לא יהיה שווה לישן. משתמשים ב־bcrypt.compare(password, hash), שקורא את ה־salt מתוך ה־hash.
  6. לא — ואם זה אפשרי, משהו שבור. השרת לא אמור להיות מסוגל לשחזר סיסמה. "שכחתי סיסמה" שולח קישור חד־פעמי עם טוקן אקראי לקביעת סיסמה חדשה.
⚠️ טעויות נפוצות
  • להשתמש ב"מוצפן" כמילה כללית ל"מוגן". בראיון — "שומרים hash איטי עם salt (bcrypt או Argon2)", לא "מצפינים".

P21-E02 · לפרק JWT ביד רמה 1

💡 רמז 1

שלושה חלקים, מופרדים בנקודה. שני הראשונים — JSON.

💡 רמז 2

exp הוא שניות מאז 1970 ב־UTC: new Date(exp * 1000). בנובמבר ישראל ב־UTC+2.

✅ פתרון

(א) כל אחד יכול לקרוא את ה־header ואת ה־payload:

const [h, p] = token.split(".");
console.log(Buffer.from(h, "base64url").toString()); // {"alg":"HS256","typ":"JWT"}
console.log(Buffer.from(p, "base64url").toString()); // {"sub":7,"role":"user","iat":1793872800,"exp":1793873700}

משתמש 7, תפקיד user, נוצר ב־1793872800. מה שאי אפשר בלי הסוד: לבדוק שהחתימה אמיתית, או ליצור חתימה חדשה.

(ב) new Date(1793873700 * 1000).toISOString() ← 2026-11-05T10:15:00.000Z, כלומר 12:15 בשעון ישראל. 900 שניות (15 דקות) אחרי iat.

(ג) השרת מחשב את החתימה מחדש על ה־header וה־payload ששונו, ומקבל משהו אחר ממה שכתוב בחלק השלישי ← invalid signature ← 401. (אלא אם השרת משתמש ב־decode במקום verify — ראה E20.)

(ד) לא. ה־payload קריא לכל מי שמחזיק את הטוקן — כולל תוספי דפדפן, לוגים של proxy, וכל מי שהטוקן דלף אליו. ובנוסף: אם המשתמש מחליף טלפון, הטוקן ממשיך "לטעון" את הישן עד שיפוג. ב־JWT שמים מזהים וזכויות (sub, role), לא פרטים אישיים.

⚠️ טעויות נפוצות
  • לחשוב שה־payload מוצפן כי "הוא נראה כמו ג'יבריש". זה Base64url.
  • לשכוח ש־exp בשניות, ו־new Date() מצפה למילישניות ← תאריך ב־1970.

P21-E03 · 401, 403 או 404? רמה 1

💡 רמז 1

401 — "לא יודע מי אתה". 403 — "יודע, ואסור". 404 — "אין (בשבילך)".

💡 רמז 2

מה יוסי יכול ללמוד אם (3) יחזיר 403?

✅ פתרון
  1. 401 UNAUTHORIZED — אין זהות בכלל.
  2. 401 INVALID_TOKEN ("פג תוקף הטוקן") — הטוקן כבר לא מוכיח זהות. הלקוח צריך לעשות refresh ולנסות שוב.
  3. 404 TASK_NOT_FOUND — מבחינת יוסי המשימה לא קיימת. 403 היה מגלה לו ש־5 קיים (ומאפשר לסרוק אילו מספרים קיימים).
  4. 403 FORBIDDEN — דנה מזוהה, אבל הפעולה עצמה אסורה לתפקיד שלה. כאן אין מה להסתיר: כולם יודעים שיש /users.
  5. 404 — בדיוק כמו (3). וזה העיקר: יוסי לא יכול להבדיל בין "לא קיים" ל"לא שלך".
  6. 401 INVALID_CREDENTIALS.
⚠️ טעויות נפוצות
  • 403 על משאב של משתמש אחר — "נכון" מבחינת השם, ודולף מבחינת אבטחה.
  • 403 כשאין טוקן — הלקוח לא יבין שצריך להתחבר. 401 אומר "תתחבר"; 403 אומר "גם אם תתחבר — לא".

P21-E04 · שני טוקנים — למה? רמה 1

💡 רמז 1

מה אפשר לבטל, ומה לא?

💡 רמז 2

(ג) — עקוב אחרי refresh() בשיעור 3: מה רואה השרת כשהדפדפן של דנה שולח טוקן שכבר הוחלף?

✅ פתרון

(א) JWT אי אפשר לבטל — הוא תקף עד exp. טוקן גנוב היה עובד שבוע, גם אחרי יציאה וגם אחרי החלפת סיסמה.

(ב) כל הערך של ה־refresh token הוא שאפשר לבטל אותו (יציאה, החלפת סיסמה, זיהוי גניבה) ולוודא שהוא חד־פעמי. לשם כך השרת צריך לזכור מה ניתן ומה כבר נוצל — כלומר מסד. ואם ממילא בודקים במסד, אין סיבה שהוא יהיה JWT: מחרוזת אקראית מספיקה.

(ג) 09:05: התוקף שולח את הטוקן ← השרת מבטל אותו ומחזיר לתוקף זוג חדש (A2, R2). 09:30: הדפדפן של דנה שולח את אותו טוקן ← השרת רואה טוקן שכבר בוטל ← מבטל את כל ה־refresh tokens של דנה (כולל R2 של התוקף) ← 401 לדנה, שמתחברת מחדש עם סיסמה. התוקף נשאר עם A2 בלבד — עד 15 דקות מ־09:05, כלומר כבר לא תקף. (במערכת אמיתית גם שולחים לדנה מייל: "זיהינו כניסה חשודה".)

(ד) הוא עובד עד שיפוג — לכל היותר 15 דקות. זה המחיר של JWT, ולכן התוקף קצר.

⚠️ טעויות נפוצות
  • לחשוב שיציאה "מבטלת" את ה־access token. היא מבטלת רק את ה־refresh.

  2. סיסמה נשמרת כמו שהיא (password: body.password) ← bcrypt.hash, ועמודה בשם passwordHash.
  3. mass assignment — ...body מאפשר לשלוח "role":"admin". ← schema מחמיר (strict), ושדות מפורשים.
  4. מחזירים את כל המשתמש מההרשמה — כולל הסיסמה. ← toPublicUser.
  5. סיסמה בלוג ← לעולם לא. לכל היותר האימייל, ובזהירות.
  6. user enumeration — 404 "אין משתמש" מול 401 "סיסמה שגויה". ← אותה תשובה (401) לשניהם, ו־compare מול hash דמה.
  7. השוואה ישירה (!==) — נובעת מבעיה 2. ← bcrypt.compare.
  8. הסיסמה והאימייל בתוך ה־JWT — כל אחד קורא את ה־payload. ← רק sub ו־role.
  9. JWT בלי expiresIn — תקף לנצח. ← 15 דקות + refresh.
  10. IDOR ב־orders/:id — אין התחברות ואין בדיקת בעלות: כל אחד עובר על כל ההזמנות. ← guard, ו־where: { id, userId: user.id } עם 404.
⚠️ טעויות נפוצות
  • למצוא את הבעיות ה"גדולות" ולפספס את הלוג — בפועל, לוגים הם אחד המקומות הנפוצים לדליפת סיסמאות.

P21-E06 · hash לסיסמאות 🤖 רמה 2

💡 רמז 1

bcrypt.hash, bcrypt.compare, bcrypt.getRounds — כולם בשיעור 1.

💡 רמז 2

hashPassword היא async, אז throw בתוכה הופך ל־Promise שנדחה — וזה מה שהבודק מצפה (assert.rejects).

✅ פתרון
// P21-E06
import bcrypt from "bcryptjs";

export async function hashPassword(password: string, rounds = 12): Promise<string> {
  if (password.length === 0) throw new Error("סיסמה ריקה");
  return bcrypt.hash(password, rounds);
}

export function verifyPassword(password: string, hash: string): Promise<boolean> {
  return bcrypt.compare(password, hash);
}

// hash ישן עם cost נמוך מהנוכחי? בכניסה הבאה (כשיש לנו את הסיסמה) — מחשבים מחדש
export function needsRehash(hash: string, rounds = 12): boolean {
  return bcrypt.getRounds(hash) < rounds;
}

למה needsRehash? כי cost טוב היום יהיה חלש בעוד כמה שנים (מחשבים מתחזקים). אי אפשר לחשב hash חדש בלי הסיסמה — אבל בכניסה מוצלחת הסיסמה בידיים: if (needsRehash(user.passwordHash)) save(await hashPassword(password)). כך המשתמשים "משתדרגים" בהדרגה, בלי שאף אחד יקליד סיסמה מחדש.

⚠️ טעויות נפוצות
  • hash === await hashPassword(password) במקום compare — תמיד false (salt).
  • לשכוח await לפני bcrypt.compare ← Promise הוא "truthy", וכל סיסמה עוברת!

P21-E07 · מדיניות סיסמאות 🤖 רמה 2

💡 רמז 2

export class RegisterDto {
  // רץ לפני הבדיקה (transform: true): "  Dana@Example.com " ← "dana@example.com"
  @Transform(({ value }) => (typeof value === "string" ? value.trim().toLowerCase() : value))
  @IsEmail()
  @MaxLength(254)
  email: string;

  @IsString()
  @MinLength(8)
  password: string;
}

  id: number;
  email: string;
  passwordHash: string;
  role: "user" | "admin";
}

    return this.users.find((u) => u.email === email);
  }

  }
}

✅ פתרון
// P21-E11
import {
  CanActivate, Controller, createParamDecorator, ExecutionContext, Get, Injectable, Module, SetMetadata, UnauthorizedException,
} from "@nestjs/common";
import { APP_GUARD, Reflector } from "@nestjs/core";
import { JwtModule, JwtService } from "@nestjs/jwt";
import type { Request } from "express";

export const JWT_SECRET = "e11-secret-for-exercises-only-0123456789";

export interface AuthUser {
  id: number;
  role: string;
}

export const IS_PUBLIC = "isPublic";
export const Public = () => SetMetadata(IS_PUBLIC, true);

export const CurrentUser = createParamDecorator((_data: unknown, ctx: ExecutionContext): AuthUser => {
  return ctx.switchToHttp().getRequest().user;
});

@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(
    private readonly jwt: JwtService,
    private readonly reflector: Reflector,
  ) {}

  async canActivate(context: ExecutionContext) {
    // getAllAndOverride: קודם המתודה, אחר כך ה־class
    if (this.reflector.getAllAndOverride<boolean>(IS_PUBLIC, [context.getHandler(), context.getClass()])) return true;
    const req = context.switchToHttp().getRequest<Request & { user?: AuthUser }>();
    const match = /^Bearer\s+(\S+)$/i.exec(req.get("authorization") ?? "");
    if (!match) throw new UnauthorizedException("נדרשת התחברות");
    try {
      const payload = await this.jwt.verifyAsync<{ sub: number; role: string }>(match[1]);
      req.user = { id: payload.sub, role: payload.role };
      return true;
    } catch {
      throw new UnauthorizedException("טוקן לא תקין");
    }
  }
}

💡 רמז 1

💡 רמז 2

✅ פתרון
// P21-E12
import { Inject, Injectable, Module, UnauthorizedException } from "@nestjs/common";
import { JwtModule, JwtService } from "@nestjs/jwt";

export const CLOCK = "CLOCK";
export const ACCESS_TTL_SECONDS = 900;
export interface Clock {
  now(): Date;
}

@Injectable()
export class TokenService {
  constructor(
    private readonly jwt: JwtService,
    @Inject(CLOCK) private readonly clock: Clock,
  ) {}

  private nowSeconds() {
    return Math.floor(this.clock.now().getTime() / 1000);
  }

  issue(userId: number): Promise<string> {
    // iat מהשעון שלנו — ו־exp מחושב ממנו
    return this.jwt.signAsync({ sub: userId, iat: this.nowSeconds() }, { expiresIn: ACCESS_TTL_SECONDS });
  }

  async verify(token: string): Promise<{ userId: number }> {
    try {
      const payload = await this.jwt.verifyAsync<{ sub: number }>(token, { clockTimestamp: this.nowSeconds() });
      return { userId: payload.sub };
    } catch (err) {
      const expired = err instanceof Error && err.name === "TokenExpiredError";
      throw new UnauthorizedException(expired ? "פג תוקף הטוקן" : "טוקן לא תקין");
    }
  }
}

@Module({
  imports: [JwtModule.register({ secret: "e12-secret-for-exercises-only-0123456789" })],
  providers: [TokenService, { provide: CLOCK, useValue: { now: () => new Date() } }],
  exports: [TokenService],
})
export class TokensModule {}

💡 רמז 1

// מדמה התחברות בשביל התרגיל (במקום JWT): x-user-id ו־x-user-role ב־headers
@Injectable()
export class FakeAuthGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const req = context.switchToHttp().getRequest();
    const id = Number(req.get("x-user-id"));
    if (!Number.isInteger(id) || id < 1) throw new UnauthorizedException("נדרשת התחברות");
    req.user = { id, role: req.get("x-user-role") ?? "user" };
    return true;
  }
}

export const ROLES = "roles";
export const Roles = (...roles: Role[]) => SetMetadata(ROLES, roles);

@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const roles = this.reflector.getAllAndOverride<Role[] | undefined>(ROLES, [context.getHandler(), context.getClass()]);
    if (!roles || roles.length === 0) return true;
    const user = context.switchToHttp().getRequest().user;
    if (!user || !roles.includes(user.role)) throw new ForbiddenException("אין הרשאה");
    return true;
  }
}

P21-E15 · refresh token אטום 🤖 רמה 3

💡 רמז 1

randomBytes(32).toString("base64url") ו־createHash("sha256").update(token).digest("hex").

💡 רמז 2

"פג" — כש־expiresAt <= now. בדיוק 7 ימים אחרי — כבר לא.

✅ פתרון
// P21-E15
import { createHash, randomBytes } from "node:crypto";
import { Inject, Injectable, UnauthorizedException } from "@nestjs/common";

export const CLOCK = "CLOCK";
export interface Clock {
  now(): Date;
}

export const REFRESH_TTL_MS = 7 * 24 * 60 * 60 * 1000;
const sha256 = (value: string) => createHash("sha256").update(value).digest("hex");

interface Record {
  userId: number;
  expiresAt: number;
  usedAt: number | null;
}

@Injectable()
export class RefreshTokenService {
  // המפתח הוא ה־hash של הטוקן — הטוקן עצמו לא נשמר בשום מקום
  private readonly records = new Map<string, Record>();

  constructor(@Inject(CLOCK) private readonly clock: Clock) {}

  issue(userId: number): string {
    const token = randomBytes(32).toString("base64url");
    this.records.set(sha256(token), { userId, expiresAt: this.clock.now().getTime() + REFRESH_TTL_MS, usedAt: null });
    return token;
  }

  rotate(token: string): { userId: number; refreshToken: string } {
    const record = this.records.get(sha256(token));
    const now = this.clock.now().getTime();
    if (!record || record.usedAt !== null || record.expiresAt <= now) throw new UnauthorizedException("צריך להתחבר מחדש");
    record.usedAt = now; // פעם אחת בלבד
    return { userId: record.userId, refreshToken: this.issue(record.userId) };
  }

  storedKeys(): string[] {
    return [...this.records.keys()];
  }
}

שים לב ש־storedKeys() מחזיר רק hashes: אם מישהו ישפוך את ה־Map (או את הטבלה) — אין לו אף טוקן שעובד. ולמה SHA-256 ולא bcrypt? כי הטוקן אקראי לגמרי (אין מה לנחש), וכי צריך לחפש לפיו — bcrypt נותן hash שונה בכל פעם.

⚠️ טעויות נפוצות
  • Math.random().toString(36) — לא מספיק אקראי לאבטחה. תמיד crypto.randomBytes.
  • למחוק את הרשומה הישנה במקום לסמן אותה — עובד כאן, אבל אז אי אפשר לזהות שימוש חוזר (E16).

P21-E16 · משפחות של טוקנים 🤖 רמה 3

💡 רמז 1

לכל רשומה: { userId, familyId, expiresAt, revoked }. familyId — מחרוזת אקראית שנוצרת ב־login.

💡 רמז 2

ב־rotate, הסדר: לא קיים ← 401; מבוטל ← בטל משפחה, 401; פג ← 401; אחרת — בטל וצור חדש עם אותו familyId.

✅ פתרון
// P21-E16
import { createHash, randomBytes } from "node:crypto";
import { Inject, Injectable, UnauthorizedException } from "@nestjs/common";

export const CLOCK = "CLOCK";
export interface Clock {
  now(): Date;
}

const TTL_MS = 7 * 24 * 60 * 60 * 1000;
const sha256 = (value: string) => createHash("sha256").update(value).digest("hex");

interface Record {
  userId: number;
  familyId: string; // כל הטוקנים שנולדו מאותה כניסה (אותו מכשיר)
  expiresAt: number;
  revoked: boolean;
}

@Injectable()
export class RefreshTokenService {
  private readonly records = new Map<string, Record>();

  constructor(@Inject(CLOCK) private readonly clock: Clock) {}

  private store(userId: number, familyId: string) {
    const token = randomBytes(32).toString("base64url");
    this.records.set(sha256(token), { userId, familyId, expiresAt: this.clock.now().getTime() + TTL_MS, revoked: false });
    return token;
  }

  // כניסה חדשה = משפחה חדשה
  login(userId: number): string {
    return this.store(userId, randomBytes(8).toString("hex"));
  }

  rotate(token: string): { userId: number; refreshToken: string } {
    const record = this.records.get(sha256(token));
    if (!record) throw new UnauthorizedException("צריך להתחבר מחדש");
    if (record.revoked) {
      // שימוש חוזר: מישהו מחזיק עותק. מבטלים את כל המשפחה — רק המכשיר הזה, לא את כל המכשירים
      for (const r of this.records.values()) if (r.familyId === record.familyId) r.revoked = true;
      throw new UnauthorizedException("צריך להתחבר מחדש");
    }
    if (record.expiresAt <= this.clock.now().getTime()) throw new UnauthorizedException("צריך להתחבר מחדש");
    record.revoked = true;
    return { userId: record.userId, refreshToken: this.store(record.userId, record.familyId) };
  }

  activeCount(userId: number): number {
    return [...this.records.values()].filter((r) => r.userId === userId && !r.revoked).length;
  }
}

rotation עם זיהוי שימוש חוזר מופיע בהמלצות האבטחה של OAuth, ו"משפחה" (token family) הוא המונח שספקי זהות כמו Auth0 משתמשים בו. התוקף שגנב מהלפטופ נחסם, הלפטופ מתחבר מחדש — והטלפון לא מרגיש כלום.

⚠️ טעויות נפוצות
  • לבטל את המשפחה רק כשהטוקן המבוטל חוזר, אבל לשכוח שהחדש (שבידי התוקף או המשתמש) באותה משפחה — אז הוא ממשיך לעבוד.

// P21-E17
import { createHash, randomBytes } from "node:crypto";
import { BadRequestException, Inject, Injectable, NotFoundException, UnauthorizedException } from "@nestjs/common";
import bcrypt from "bcryptjs";

export const BCRYPT_ROUNDS = "BCRYPT_ROUNDS";
const sha256 = (value: string) => createHash("sha256").update(value).digest("hex");

interface User {
  id: number;
  email: string;
  passwordHash: string;
}

@Injectable()
export class AccountService {
  private readonly users: User[] = [];
  private readonly refreshTokens = new Map<string, { userId: number; revoked: boolean }>();

  constructor(@Inject(BCRYPT_ROUNDS) private readonly rounds: number) {}

  async createUser(email: string, password: string) {
    const user = { id: this.users.length + 1, email, passwordHash: await bcrypt.hash(password, this.rounds) };
    this.users.push(user);
    return user.id;
  }

  async login(email: string, password: string): Promise<string> {
    const user = this.users.find((u) => u.email === email);
    if (!user || !(await bcrypt.compare(password, user.passwordHash))) throw new UnauthorizedException("אימייל או סיסמה שגויים");
    const token = randomBytes(32).toString("base64url");
    this.refreshTokens.set(sha256(token), { userId: user.id, revoked: false });
    return token;
  }

  isActive(token: string): boolean {
    const record = this.refreshTokens.get(sha256(token));
    return record !== undefined && !record.revoked;
  }

  logout(token: string): void {
    const record = this.refreshTokens.get(sha256(token));
    if (record) record.revoked = true; // טוקן לא מוכר — פשוט לא עושים כלום
  }

  async changePassword(userId: number, oldPassword: string, newPassword: string): Promise<void> {
    const user = this.users.find((u) => u.id === userId);
    if (!user) throw new NotFoundException("משתמש לא נמצא");
    // מי שמחזיק טוקן גנוב לא יכול להחליף סיסמה בלי לדעת את הישנה
    if (!(await bcrypt.compare(oldPassword, user.passwordHash))) throw new UnauthorizedException("הסיסמה הנוכחית שגויה");
    if (newPassword.length < 8) throw new BadRequestException("לפחות 8 תווים");
    if (newPassword === oldPassword) throw new BadRequestException("הסיסמה החדשה זהה לישנה");
    user.passwordHash = await bcrypt.hash(newPassword, this.rounds);
    // "צא מכל המכשירים": אם הסיסמה דלפה, גם הטוקנים שנוצרו איתה לא בטוחים
    for (const record of this.refreshTokens.values()) if (record.userId === userId) record.revoked = true;
  }
}

הסיסמה הישנה נדרשת כי "מחובר" לא אומר "זה באמת הוא": אולי מישהו גנב טוקן, או ישב ליד מחשב פתוח. בלי הישנה — הוא היה מחליף סיסמה ונועל את הבעלים בחוץ. וביטול כל הטוקנים — כי אם המשתמש מחליף סיסמה בגלל חשד, הוא מצפה שכל מי שהיה מחובר ייזרק החוצה.

⚠️ טעויות נפוצות
  • לבטל את הטוקנים לפני הבדיקות ← ניסיון כושל עם סיסמה שגויה מנתק את המשתמש מכל המכשירים (התקפת "ניתוק" פשוטה).

  compare(password: string, hash: string): Promise<boolean>;
}

interface User {
  id: number;
  email: string;
  passwordHash: string;
}

@Injectable()
export class LoginService {
  private readonly users: User[] = [];
  private dummyHash?: Promise<string>;

  async addUser(email: string, password: string) {
    this.users.push({ id: this.users.length + 1, email, passwordHash: await this.hasher.hash(password) });
  }

  async login(email: string, password: string): Promise<{ userId: number }> {

    // compare רץ בדיוק פעם אחת בכל מקרה — גם כשאין משתמש
    this.dummyHash ??= this.hasher.hash("dummy-password-nobody-knows");
    const ok = await this.hasher.compare(password, user ? user.passwordHash : await this.dummyHash);

export function safeEqual(a: string, b: string): boolean {
  // hash קודם — כך שני הצדדים באותו אורך, ו־timingSafeEqual לא זורק
  const ha = createHash("sha256").update(a).digest();
  const hb = createHash("sha256").update(b).digest();
  return timingSafeEqual(ha, hb);
}

למה זה חשוב: בלי hash דמה, "אין משתמש" חוזר תוך מילישנייה ו"סיסמה שגויה" אחרי עשירית שנייה — וזה מספיק כדי לבנות רשימת לקוחות. ו־=== על מחרוזות עוצר בתו הראשון שונה: מדידה זהירה מגלה כמה תווים מההתחלה נכונים, וכך אפשר לנחש מפתח תו אחר תו. (ב־E25 תשתמש ב־timingSafeEqual על מפתחות API.)

⚠️ טעויות נפוצות

// P21-E19
import { Body, Controller, HttpCode, HttpException, HttpStatus, Inject, Injectable, Module, Post, Res, UnauthorizedException } from "@nestjs/common";
import type { Response } from "express";

export const CLOCK = "CLOCK";
export interface Clock {
  now(): Date;
}

export const MAX_FAILURES = 5;
export const WINDOW_MS = 15 * 60 * 1000;

@Injectable()
export class LoginAttemptsService {
  // לכל אימייל: מתי היו הכישלונות האחרונים
  private readonly failures = new Map<string, number[]>();

  constructor(@Inject(CLOCK) private readonly clock: Clock) {}

  private recent(email: string) {
    const now = this.clock.now().getTime();
    const list = (this.failures.get(email) ?? []).filter((t) => now - t < WINDOW_MS);
    this.failures.set(email, list);
    return list;
  }

  // כמה שניות לחכות, או 0 אם מותר לנסות
  retryAfterSeconds(email: string): number {
    const list = this.recent(email);
    if (list.length < MAX_FAILURES) return 0;
    const unlockAt = list[list.length - MAX_FAILURES] + WINDOW_MS;
    return Math.ceil((unlockAt - this.clock.now().getTime()) / 1000);
  }

  recordFailure(email: string) {
    this.failures.set(email, [...this.recent(email), this.clock.now().getTime()]);
  }

  reset(email: string) {
    this.failures.delete(email);
  }
}

@Controller("auth")
export class AuthController {
  constructor(private readonly attempts: LoginAttemptsService) {}

  @Post("login")
  @HttpCode(200)
  login(@Body() body: { email: string; password: string }, @Res({ passthrough: true }) res: Response) {
    const email = String(body.email).trim().toLowerCase(); // אחרת Dana@ ו־dana@ — שני מונים
    const wait = this.attempts.retryAfterSeconds(email);
    if (wait > 0) {
      res.setHeader("Retry-After", String(wait));
      throw new HttpException("יותר מדי ניסיונות. נסה שוב מאוחר יותר", HttpStatus.TOO_MANY_REQUESTS);
    }
    // בתרגיל: סיסמה "נכונה" היא correct-password (בפרויקט — bcrypt)
    if (body.password !== "correct-password") {
      this.attempts.recordFailure(email);
      throw new UnauthorizedException("אימייל או סיסמה שגויים");
    }
    this.attempts.reset(email);
    return { ok: true };
  }
}

    this.records.set(sha256(token), { userId, expiresAt: this.clock.now().getTime() + 7 * DAY_MS, used: false });
    return token;
  }

  rotate(token: string) {
    const record = this.records.get(sha256(token));
    if (!record || record.used || record.expiresAt <= this.clock.now().getTime()) throw new UnauthorizedException("צריך להתחבר מחדש");

  }

const sha256 = (v: string) => createHash("sha256").update(v).digest("hex");

@Injectable()
export class AuthService {
  private readonly refresh = new Map<string, { userId: number; expiresAt: number; revoked: boolean }>();
  private readonly dummy: Promise<string>;

  constructor(
    private readonly users: UsersService,
    private readonly jwt: JwtService,
    @Inject(CONFIG) private readonly config: Config,
    @Inject(CLOCK) private readonly clock: Clock,
  ) {
    this.dummy = bcrypt.hash("dummy-password-nobody-knows", config.bcryptRounds);
  }

  private nowSeconds() {
    return Math.floor(this.clock.now().getTime() / 1000);
  }

  private async issue(user: User) {
    const accessToken = await this.jwt.signAsync({ sub: user.id, role: user.role, iat: this.nowSeconds() }, { expiresIn: this.config.accessTtlSeconds });
    const refreshToken = randomBytes(32).toString("base64url");
    this.refresh.set(sha256(refreshToken), { userId: user.id, expiresAt: this.clock.now().getTime() + this.config.refreshTtlDays * 86_400_000, revoked: false });
    return { accessToken, refreshToken };
  }

  async login(email: string, password: string) {
    const user = this.users.findByEmail(email);
    const ok = await bcrypt.compare(password, user ? user.passwordHash : await this.dummy);
    if (!user || !ok) throw new UnauthorizedException("אימייל או סיסמה שגויים");
    return this.issue(user);
  }

  async rotate(token: string) {
    const record = this.refresh.get(sha256(token));
    if (!record) throw relogin();
    if (record.revoked) {
      for (const r of this.refresh.values()) if (r.userId === record.userId) r.revoked = true;
      throw relogin();
    }
    if (record.expiresAt <= this.clock.now().getTime()) throw relogin();
    record.revoked = true;
    const user = this.users.findById(record.userId);
    if (!user) throw relogin();
    return this.issue(user);
  }

  logout(token: string) {
    const record = this.refresh.get(sha256(token));
    if (record) record.revoked = true;
  }

  async verify(token: string): Promise<AuthUser> {
    try {
      const p = await this.jwt.verifyAsync<{ sub: number; role: Role }>(token, { clockTimestamp: this.nowSeconds() });
      return { id: p.sub, role: p.role };
    } catch {
      throw new UnauthorizedException("טוקן לא תקין");
    }
  }
}

// מדמה התחברות של משתמש (במקום JWT): x-user-id ב־header — לניהול המפתחות
@Injectable()
export class FakeAuthGuard implements CanActivate {

    const req = context.switchToHttp().getRequest();

interface ApiKeyRecord {
  id: number;
  userId: number;
  name: string;
  prefix: string;
  hash: string;
  scopes: Scope[];
  createdAt: string;
  lastUsedAt: string | null;
  revokedAt: string | null;
}

const sha256 = (v: string) => createHash("sha256").update(v).digest();
const KEY_FORMAT = /^tk_([0-9a-f]{8})_[A-Za-z0-9_-]{32}$/;

@Injectable()
export class ApiKeysService {
  private readonly keys: ApiKeyRecord[] = [];

  constructor(@Inject(CLOCK) private readonly clock: Clock) {}

  // המפתח המלא מוחזר פעם אחת בלבד. נשמרים: prefix (לחיפוש ולתצוגה) ו־hash
  create(userId: number, name: string, scopes: Scope[]) {
    const prefix = randomBytes(4).toString("hex");
    const key = `tk_${prefix}_${randomBytes(24).toString("base64url")}`;
    const record: ApiKeyRecord = {
      id: this.keys.length + 1, userId, name, prefix, hash: sha256(key).toString("hex"), scopes,
      createdAt: this.clock.now().toISOString(), lastUsedAt: null, revokedAt: null,
    };
    this.keys.push(record);
    return { id: record.id, name, prefix, scopes, key };
  }

  list(userId: number) {
    return this.keys
      .filter((k) => k.userId === userId)
      .map(({ id, name, prefix, scopes, createdAt, lastUsedAt, revokedAt }) => ({ id, name, prefix, scopes, createdAt, lastUsedAt, revoked: revokedAt !== null }));
  }

  revoke(userId: number, id: number) {
    const record = this.keys.find((k) => k.id === id && k.userId === userId);
    if (!record) throw new NotFoundException(`מפתח ${id} לא נמצא`);
    record.revokedAt ??= this.clock.now().toISOString();
  }

  authenticate(key: string): { userId: number; scopes: Scope[] } | undefined {
    const prefix = KEY_FORMAT.exec(key)?.[1];
    if (!prefix) return undefined;
    const record = this.keys.find((k) => k.prefix === prefix && k.revokedAt === null);
    if (!record || !timingSafeEqual(sha256(key), Buffer.from(record.hash, "hex"))) return undefined;
    record.lastUsedAt = this.clock.now().toISOString();
    return { userId: record.userId, scopes: record.scopes };
  }
}

const SCOPE = "scope";
export const RequireScope = (scope: Scope) => SetMetadata(SCOPE, scope);

@Injectable()
export class ApiKeyGuard implements CanActivate {
  constructor(private readonly keys: ApiKeysService, private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const req = context.switchToHttp().getRequest();
    const key = req.get("x-api-key");
    if (!key) throw new UnauthorizedException("חסר X-Api-Key");
    const auth = this.keys.authenticate(key);
    if (!auth) throw new UnauthorizedException("מפתח לא תקין");
    const scope = this.reflector.get<Scope | undefined>(SCOPE, context.getHandler());
    if (scope && !auth.scopes.includes(scope)) throw new ForbiddenException(`למפתח אין הרשאת ${scope}`);
    req.apiKey = auth;
    return true;
  }
}

@Controller("keys")
@UseGuards(FakeAuthGuard)
export class KeysController {
  constructor(private readonly keys: ApiKeysService) {}

  @Post()
  create(@Req() req: { user: { id: number } }, @Body() body: { name: string; scopes: Scope[] }) {
    const scopes = (Array.isArray(body.scopes) ? body.scopes : []).filter((s): s is Scope => s === "read" || s === "write");
    return this.keys.create(req.user.id, String(body.name), scopes.length ? scopes : ["read"]);
  }

  @Get()
  list(@Req() req: { user: { id: number } }) {
    return this.keys.list(req.user.id);
  }

  @Delete(":id")
  @HttpCode(204)
  revoke(@Req() req: { user: { id: number } }, @Param("id", ParseIntPipe) id: number) {
    this.keys.revoke(req.user.id, id);
  }
}
