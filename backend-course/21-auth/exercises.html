P21-E05 · מצא את הפרצות

רמה 1⏱ 15 דק׳ידע נדרש: שיעור 4

קוד שנכתב בלחץ של דדליין. מצא לפחות שש בעיות אבטחה, וכתוב לכל אחת מה התוקף עושה ואיך מתקנים:

const JWT_SECRET = "secret";

@Post("register")
async register(@Body() body: any) {
  const user = await this.prisma.user.create({ data: { ...body, password: body.password } });
  return user;
}

@Post("login")
async login(@Body() { email, password }: any) {
  console.log("login attempt", email, password);
  const user = await this.prisma.user.findUnique({ where: { email } });
  if (!user) throw new NotFoundException("אין משתמש עם האימייל הזה");
  if (user.password !== password) throw new UnauthorizedException("סיסמה שגויה");
  return { token: jwt.sign({ sub: user.id, role: user.role, email, password }, JWT_SECRET) };
}

@Get("orders/:id")
async order(@Param("id") id: string) {
  return this.prisma.order.findUnique({ where: { id: Number(id) } });
}

P21-E06 · hash לסיסמאות 🤖

רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

בקובץ 21-auth/starter/P21-E06.ts כתוב שלוש פונקציות עם bcryptjs:

  • hashPassword(password, rounds = 12) ← hash. סיסמה ריקה ← Error("סיסמה ריקה").
  • verifyPassword(password, hash) ← true/false.
  • needsRehash(hash, rounds = 12) ← true אם ה־cost שב־hash נמוך מ־rounds.

  • POST /keys { name, scopes } (משתמש מחובר, דרך FakeAuthGuard) ← 201 { id, name, prefix, scopes, key }. המפתח: tk_<8 hex>_<32 תווי base64url>, ו־prefix הם 8 ה־hex. scopes: "read" / "write" (ברירת מחדל ["read"]). המפתח המלא מוחזר רק כאן — נשמרים רק prefix ו־SHA-256.
  • GET /keys ← המפתחות של המשתמש: { id, name, prefix, scopes, createdAt, lastUsedAt, revoked }. DELETE /keys/:id ← 204; של אחר ← 404.
  • GET /data (scope read) ו־POST /data (scope write) — עם header X-Api-Key ו־ApiKeyGuard: חסר ← 401 "חסר X-Api-Key"; לא תקין/מבוטל ← 401 "מפתח לא תקין"; בלי scope ← 403 "למפתח אין הרשאת write". מחזירים { data: [1, 2, 3], owner } / { saved: true, owner }, ומעדכנים lastUsedAt לפי CLOCK.

🏁 מבחן מעבר

  • להסביר למה sha256(password) לא מספיק, ומה bcrypt מוסיף (salt, cost).
  • לפרק JWT ביד, ולהסביר למה שינוי role ב־payload לא עובד — ומה כן אפשר לקרוא ממנו בלי הסוד.
  • לכתוב guard גלובלי עם @Public(), ו־@Roles() עם Reflector.
  • להסביר access + refresh, rotation, ומה קורה כשמישהו משתמש ב־refresh token ישן.
  • להסביר 401 / 403 / 404, ולמה משימה של משתמש אחר מחזירה 404.
