P21-E32 · למה אין "חיפוש לפי hash"?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

מפתח כתב את הכניסה כך, והיא אף פעם לא מצליחה:

async login(email: string, password: string) {
  const passwordHash = await bcrypt.hash(password, 12);
  const user = await this.users.findFirst({ where: { email, passwordHash } });
  if (!user) throw invalidCredentials();
  return this.issueTokens(user);
}

(א) למה היא תמיד נכשלת? (ב) הוא "תיקן" עם bcrypt.hash(password, "$2b$12$abcdefghijklmnopqrstuv") (salt קבוע לכולם). עכשיו זה עובד. מה הבעיה? (ג) כתוב את שלוש השורות הנכונות.

P21-E06 · hash לסיסמאות 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

בקובץ 21-auth/starter/P21-E06.ts כתוב שלוש פונקציות עם bcryptjs:

  • hashPassword(password, rounds = 12) ← hash. סיסמה ריקה ← Error("סיסמה ריקה").
  • verifyPassword(password, hash) ← true/false.
  • needsRehash(hash, rounds = 12) ← true אם ה־cost שב־hash נמוך מ־rounds.

P21-E37 · ‏PasswordService עם hash "דמה" 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

export class PasswordService {
  constructor(rounds: number)

P21-E41 · ‏bcrypt וה־event loop

🧠 הבנהרמה 2⏱ 15 דק׳ידע נדרש: פרק 10, שיעור 1

מפתח החליף את await bcrypt.hash(password, 12) ב־bcrypt.hashSync(password, 12), "כי זה פשוט יותר ואין צורך ב־await". (א) כמה זמן לוקח hash עם cost ‏12 (שאלה E30)? (ב) מה קורה לכל שאר הבקשות לשרת באותו זמן? (ג) נחש מה ידפיס הקוד, ואז הרץ:

import bcrypt from "bcryptjs";
let ticks = 0;
const timer = setInterval(() => ticks++, 10);
bcrypt.hashSync("x", 12);
console.log("sync — הטיימר רץ בזמן ה־hash?", ticks > 0);
ticks = 0;
await bcrypt.hash("x", 12);
console.log("async — הטיימר רץ בזמן ה־hash?", ticks > 0);
clearInterval(timer);

🔗 איך זה מתחבר: ה־event loop ו־setInterval מפרק 10 — והשיעור: hash איטי בכוונה.

P21-E43 · לעבור מ־SHA-256 ל־bcrypt בלי לאפס סיסמאות 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 13, שיעור 1

מערכת ישנה שמרה sha256(password) (64 תווי hex). אי אפשר להפוך אותו ל־bcrypt בלי הסיסמה, אבל בכניסה מוצלחת הסיסמה בידיים. בקובץ 21-auth/starter/P21-E43.ts כתוב וייצא:

  password: string,

  rounds: number,

  • hash של bcrypt (מתחיל ב־$2) ← bcrypt.compare. לא שומרים כלום.
