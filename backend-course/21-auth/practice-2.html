P21-E10 · guard של JWT 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 20 דק׳ידע נדרש: שיעור 2

בקובץ 21-auth/starter/P21-E10.ts השלם את JwtAuthGuard, והפעל אותו על GET /me בלבד (/hello נשאר פתוח):

  • header Authorization: Bearer <token> — "Bearer" בלי תלות באותיות.
  • אין header, או לא Bearer ← 401 "נדרשת התחברות".
  • טוקן לא תקין — לא JWT, חתום בסוד אחר, או שפג ← 401 "טוקן לא תקין".
  • תקין ← req.user = { id: sub, role }, ו־/me מחזיר אותו.

P21-E26 · JWT ביד, עם node:crypto 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 30 דק׳ידע נדרש: שיעור 2

בשיעור 2 פירקת JWT ביד וראית שהוא שלושה חלקים ב־base64url, והאחרון הוא חתימה. עכשיו תכתוב את sign ו־verify בעצמך, בלי ספרייה, רק עם node:crypto. כך תדע בדיוק מה jsonwebtoken עושה (ומה הוא בודק). כתוב וייצא:

  • type Claims = { sub: number; role: string; iat: number; exp: number }.
  • signJwt(payload, secret, expiresInSec, now = שניות מעכשיו): string. ‏header: ‏{"alg":"HS256","typ":"JWT"}. ‏payload: ‏{ sub, role, iat: now, exp: now + expiresInSec }, בסדר הזה. חתימה: ‏HMAC-SHA256 של ${header}.${payload} עם הסוד, ב־base64url. הבודק משווה לטוקן של jsonwebtoken, תו אחר תו.
  • verifyJwt(token, secret, now = שניות מעכשיו): Claims, שבודקת לפי הסדר:
    • לא בדיוק שלושה חלקים ← Error("טוקן לא תקין").
    • החתימה לא תואמת ← Error("חתימה לא תקינה"). משווים עם timingSafeEqual, ולא עם ===.
    • header שאינו JSON, או alg שאינו "HS256" ← Error("טוקן לא תקין").
    • now >= exp ← Error("פג תוקף").

% npm run check P21-E26

P21-E27 · פירוק header של Authorization 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 2⏱ 15 דק׳ידע נדרש: שיעור 2

🔁 חזרה על switch (פרק 4), ביטויים רגולריים (P13-E26) ו־indexOf/slice (‏P14-E26). ה־header ‏Authorization מגיע בכמה צורות: Bearer <token>, או Basic <base64 של user:password>. כתוב וייצא:

  • type Credentials = { scheme: "bearer"; token: string } | { scheme: "basic"; username: string; password: string }.
  • parseAuthorization(header: string | undefined): Credentials | null:
    • אחרי trim: בדיוק שתי מילים (scheme וערך), עם רווח אחד או יותר ביניהן. אחרת ← null.
    • ה־scheme בלי תלות באותיות (Bearer, ‏bearer, ‏BASIC). הבחירה — עם switch. scheme אחר ← null.
    • bearer: הטוקן רק מהתווים A–Z a–z 0–9 - . _ ~ + /, ואחריהם אפשר = אחד או יותר רק בסוף. אחרת ← null.
    • basic: מפענחים base64. הנקודתיים הראשונות מפרידות בין שם לסיסמה (בסיסמה מותר :). אין נקודתיים, או שם משתמש ריק ← null.
