1. למה לא קובץ JSON?

בפרויקט 1 שמרת הוצאות בקובץ JSON. זה עבד — לאדם אחד, עם מאות שורות. עכשיו דמיין חנות אמיתית:

בעיהקובץ JSONמסד נתונים
שני לקוחות קונים באותו רגעשניהם קוראים, שניהם כותבים — אחד דורס את השניtransactions ונעילות (פרק 18)
מיליון הזמנות, "תן לי את של לקוח 7"לקרוא את כל הקובץ לזיכרוןindex — מילישניות (פרק 18)
השרת נפל באמצע כתיבהקובץ חצי כתוב, הכול אבודאו שהכול נשמר או ששום דבר
מחיר שלילי, אימייל כפולרק אם הקוד שלך בדקהמסד עצמו מסרב (אילוצים)
"כמה הכנסות לפי חודש?"לכתוב לולאותשאילתה אחת

2. המודל: טבלאות

מסד אחד (course) מכיל טבלאות רבות. בפרק 17 נחבר ביניהן (לקוח ← הזמנות ← מוצרים) — משם השם "יחסי" (relational).

3. psql

% psql -d course
psql (18.0)
Type "help" for help.

course=# select name, price from products where category = 'grinders';
         name         | price
----------------------+--------
 Hand Grinder         | 189.00
 Electric Grinder Pro | 649.00
(2 rows)

course=# \q
פקודהמה עושה
\dtרשימת הטבלאות
\d productsהמבנה של טבלה: עמודות, טיפוסים, אילוצים
\xתצוגה אנכית (נוח לשורות רחבות)
\qיציאה

פקודות שמתחילות ב־\ הן של psql עצמו, לא SQL. כל שאר הפקודות — SQL, ומסתיימות ב־;. שכחת? psql יחכה (course-#) עד שתקליד ;.

מוסכמה: מילות SQL באותיות גדולות (SELECT, WHERE) ושמות באותיות קטנות. ל־PostgreSQL זה לא משנה — זה לבני אדם. בדוגמאות בפרק נכתוב כך:

SELECT name, price
FROM products
WHERE category = 'grinders';
         name         | price
----------------------+--------
 Hand Grinder         | 189.00
 Electric Grinder Pro | 649.00
(2 rows)

4. התוסף של VS Code

לתרגילים נוח יותר לעבוד מקובץ .sql ב־VS Code: כותבים את השאילתה, מסמנים, ⌘+⇧+E, והתוצאה מופיעה בטבלה מתחת. בתחתית החלון בוחרים לאיזה חיבור (connection) לשלוח. שמור את קובצי הניסוי שלך ב־playground/.

💡 למה הנתונים באנגלית?

הטרמינל של VS Code מציג עברית בסדר הפוך (אין לו תמיכה בכיוון ימין־לשמאל). PostgreSQL שומר עברית מצוין — זו רק בעיית תצוגה. כדי שהטבלאות בטרמינל יהיו קריאות, נתוני הדוגמה באנגלית; ההסברים — בעברית.
