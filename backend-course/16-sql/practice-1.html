P16-E39 · SELECT ב־JavaScript 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: שיעור 1

כדי להבין מה המסד עושה, כתוב את אותו דבר ב־JavaScript. כתוב וייצא select(rows, columns, where = {}):

  • rows — מערך של אובייקטים (כמו שורות בטבלה). ‏columns — מערך שמות עמודות.
  • where — אובייקט של "עמודה ← ערך"; שורה נכללת רק אם כל הזוגות שווים (===). ‏{} ← כל השורות.
  • מחזירה מערך חדש של אובייקטים חדשים, רק עם העמודות שב־columns, בסדר שלהן.
  • עמודה שלא קיימת בשורות (ב־columns או ב־where) ← throw new Error(column "${name}" does not exist) — בדיוק כמו PostgreSQL. (הנח שלכל השורות אותן עמודות; טבלה ריקה — בלי בדיקה.)

P16-E41 · אילוצים ב־JavaScript 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 1

בטבלה בסעיף 1: "מחיר שלילי, אימייל כפול — המסד עצמו מסרב". כתוב וייצא checkRows(rows, rules) — בודק "אילוצים" על מערך שורות, ומחזיר מערך הפרות (מחרוזות), לפי הסדר: קודם לפי שורה, ובתוך שורה — לפי סדר הכללים notNull ← unique ← check.

  • rules.notNull — שמות עמודות. ערך null או undefined ← row ${i}: ${col} is null.
  • rules.unique — שמות עמודות. ערך שכבר הופיע בעמודה בשורה קודמת ← row ${i}: duplicate ${col}: ${value}. (null לא נחשב כפילות — כמו ב־PostgreSQL.)
  • rules.check — אובייקט "שם ← פונקציה" ({ positive_price: (r) => r.price > 0 }). פונקציה שמחזירה false ← row ${i}: check ${name} failed.
  • i מתחיל ב־0. כל חלק ב־rules אופציונלי.

זו השורה הראשונה בטבלת "למה לא JSON": שתי הזמנות "באותו רגע". הקוד מדמה שתי בקשות במקביל, שכל אחת קוראת את הקובץ, מוסיפה הזמנה וכותבת. כמה הזמנות יהיו בקובץ בסוף?

import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";

const file = path.join(await fs.mkdtemp(path.join(os.tmpdir(), "orders-")), "orders.json");
await fs.writeFile(file, "[]");

async function addOrder(order) {
  const orders = JSON.parse(await fs.readFile(file, "utf8"));
  orders.push(order);
  await new Promise((r) => setTimeout(r, 20)); // "עבודה" — חישוב מחיר, בדיקת מלאי

}

await Promise.all([addOrder({ id: 1, who: "Dana" }), addOrder({ id: 2, who: "Yossi" })]);
console.log(JSON.parse(await fs.readFile(file, "utf8")));

for (let i = 3; i <= 5; i++) await addOrder({ id: i, who: "one by one" });
console.log(JSON.parse(await fs.readFile(file, "utf8")).map((o) => o.id));

P16-E45 · numeric מול float

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 2, שיעור 1

למחיר בטבלה יש טיפוס numeric(10, 2). ‏::float8 בשאילתה ממיר ל"מספר עשרוני" רגיל (כמו number ב־JavaScript). מה יחזיר?

SELECT 0.1 + 0.2 AS numeric_sum, 0.1::float8 + 0.2::float8 AS float_sum;
SELECT 19.90 * 3 AS numeric_total, 19.90::float8 * 3 AS float_total;
SELECT (0.1 + 0.2) = 0.3 AS numeric_equal, (0.1::float8 + 0.2::float8) = 0.3::float8 AS float_equal;

🔗 איך זה מתחבר: 0.1 + 0.2 ב־JavaScript (פרק 2) וכסף ב־JSON (P14-E54). השיעור: לכל עמודה יש טיפוס — והטיפוס קובע איך החשבון נעשה.

P16-E46 · מ־CSV לשורות עם טיפוסים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 2, פרק 6, שיעור 1

הלקוח שולח קובץ CSV של מוצרים, ולפני שמכניסים אותו לטבלה צריך להפוך כל שדה לטיפוס של העמודה. כתוב וייצא parseCsv(text, types):

  • השורה הראשונה — שמות העמודות (מופרדים בפסיק). כל שורה אחרת — ערכים. שורות ריקות (גם בסוף) — מדלגים. \r\n או \n.
  • types — אובייקט "עמודה ← טיפוס": "text" (כמו שהוא, אחרי trim), "integer" (מספר שלם — אחרת שגיאה), "numeric" (מספר — אחרת שגיאה), "boolean" (true/false בלבד), "date" (בדיוק YYYY-MM-DD; נשאר מחרוזת). עמודה בלי טיפוס ← text.
  • ערך ריק (אחרי trim) ← null, בכל טיפוס.
  • שגיאה ← throw new Error(line ${n}: invalid ${type} for ${column}: "${value}"), כש־n הוא מספר השורה בקובץ (הכותרת היא שורה 1). שורה עם מספר ערכים שונה מהכותרת ← line ${n}: expected ${k} values, got ${m}.

(אין צורך לטפל בפסיקים בתוך מירכאות.)

P16-E48 · לנחש טיפוס לכל עמודה 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 1, פרק 13, שיעור 1

כמו \d של psql — אבל על נתונים שהגיעו מ־JSON. כתוב וייצא describe(rows) שמחזירה מערך { column, type, nullable } — לפי סדר העמודות בשורה הראשונה (ועמודות שמופיעות רק בשורות מאוחרות — בסוף, לפי סדר ההופעה):

  • nullable — true אם באחת השורות הערך null או חסר.
  • type לפי הערכים שאינם null: כולם מספרים שלמים ← "integer"; כולם מספרים (חלקם לא שלמים) ← "numeric"; כולם boolean ← "boolean"; כולם מחרוזות בתבנית YYYY-MM-DD ← "date"; כולם מחרוזות ← "text"; אין אף ערך ← "unknown"; ערבוב של סוגים אחרים ← "mixed".
