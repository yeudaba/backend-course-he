P16-E29 · קובץ JSON או מסד? 🧠 הבנה רמה 1

💡 רמז 1

שאל: האם יש כתיבות במקביל? כמה נתונים? האם צריך "חוקים" שהנתונים חייבים לעמוד בהם? ושאלות מורכבות?

💡 רמז 2

שני עותקים של שרת לא חולקים קובץ בזיכרון — וגם לא בדיסק, אם הם על מכונות שונות.

✅ פתרון
  1. JSON — כותב אחד, נתונים קטנים, אין שאילתות.
  2. מסד — כתיבות במקביל: עם קובץ, שתי הזמנות "קוראות-משנות-כותבות" ואחת נמחקת (P16-E43 מדגים).
  3. JSON (או קובץ קוד) — נתונים קבועים לקריאה בלבד. (אם השרת כבר עובד מול מסד, נוח גם לשים אותם שם — אבל לא חובה.)
  4. מסד — "לפי חודש בשנתיים" היא שאילתה אחת עם צבירה (פרק 17); עם קובץ — לולאות ידניות על כל הנתונים.
  5. מסד — ייחודיות שנאכפת במקום אחד (UNIQUE), גם כששני שרתים כותבים במקביל.
⚠️ טעויות נפוצות
  • "מסד תמיד" — לפעמים קובץ הוא בדיוק הכלי הנכון. השאלה היא מקביליות, נפח וחוקים.

P16-E30 · המונחים על טבלה אמיתית 🧠 הבנה רמה 1

💡 רמז 1

💡 רמז 2

אימייל יכול להשתנות. מפתח ראשי — אף פעם לא.

✅ פתרון
  1. 6: id, ‏full_name, ‏email, ‏city, ‏phone, ‏joined_on.
  2. date — כך המסד מוודא שזה תאריך אמיתי (2026-02-30 נדחה), ואפשר להשוות ולמיין ("הצטרפו אחרי מרץ").
  3. id. משתמש יכול להחליף אימייל — ואז כל מי שמצביע עליו (הזמנות, פרק 17) צריך להשתנות. מזהה מספרי שהמסד נותן לא משתנה לעולם.
  4. city ו־phone — אין להם NOT NULL.
  5. לשורה יש בדיוק אותן עמודות כמו לכל שורה אחרת, עם טיפוסים שהמסד אוכף. במערך JavaScript כל אובייקט יכול להיות במבנה אחר (שדה חסר, מספר במקום מחרוזת).
⚠️ טעויות נפוצות
  • להשתמש בשם (full_name) כמזהה — יש שני "Dana Levi" בכל מערכת אמיתית.

P16-E31 · psql — מה קורה כאן? 🧠 הבנה רמה 1

💡 רמז 1

הטבלה בסעיף 3: פקודות עם \ שייכות ל־psql; SQL מסתיים ב־;.

💡 רמז 2

course-# (מקף במקום שווה) — psql מחכה להמשך הפקודה.

✅ פתרון
  1. psql -d course — מתחבר למסד course.
  2. \dt — רשימת הטבלאות (products, ‏customers).
  3. \d customers — העמודות, הטיפוסים והאילוצים של הטבלה.
  4. SQL בלי ; — psql לא שולח עדיין; ה־prompt הופך ל־course-#, ו־Enter על שורה ריקה לא משנה כלום. ה־; בשורה השלישית שולח את כל הפקודה, ומתקבלים 3 הלקוחות מחיפה.
  5. \x — תצוגה אנכית: כל עמודה בשורה משלה.
  6. השאילתה מציגה את מוצר 6 — באנכי (-[ RECORD 1 ]- ואז עמודה־עמודה).
  7. exit — בגרסאות חדשות של psql יוצא (כמו \q).
⚠️ טעויות נפוצות
  • לחשוב ש־psql "תקוע" כשמופיע course-# — הוא מחכה ל־;.

P16-E32 · SQL או psql? 🧠 הבנה רמה 1

💡 רמז 1

מה שמתחיל ב־\ — psql. כל השאר — SQL.

💡 רמז 2

מילות SQL ושמות טבלאות/עמודות לא רגישים לאותיות. ערכים בתוך '...' — רגישים (P16-E33).

✅ פתרון
  1. psql, בלי ;.
  2. SQL — צריך ; ב־psql (מקוד Node — לא חובה, כי כל קריאה היא פקודה אחת).
  3. psql.
  4. SQL — עובדת בדיוק כמו בכתיב הרגיל: PostgreSQL הופך שמות לאותיות קטנות. רק 'beans' חייב להיות בדיוק כמו בנתונים.
  5. psql.
⚠️ טעויות נפוצות
  • לנסות \d מתוך קוד — זו לא פקודת SQL. (מקוד שואלים את information_schema — פרק 19.)

P16-E34 · מה מפתח ראשי מבטיח? 🧠 הבנה רמה 1

💡 רמז 1

PRIMARY KEY = ‏UNIQUE + NOT NULL.

💡 רמז 2

IDENTITY הוא מונה שרק עולה — הוא לא "חוזר אחורה" למספרים שהתפנו.

✅ פתרון
  1. נכון — זה עיקר המפתח הראשי.
  2. לא נכון — PRIMARY KEY הוא גם NOT NULL. וממילא ה־IDENTITY נותן מספר בכל INSERT.
  3. לא נכון — אחרי מחיקות, או INSERT שנכשל (שיעור 4, P16-E74), יש "חורים".
  4. לא נכון — יקבל 15. מספר שהיה בשימוש לא חוזר (אחרת קישור ישן היה מצביע על מוצר אחר).
  5. נכון — בגלל הייחודיות.
⚠️ טעויות נפוצות
  • להשתמש ב־MAX(id) + 1 כדי "לנחש" את ה־id הבא — שני שרתים במקביל ינחשו את אותו מספר.

P16-E39 · SELECT ב־JavaScript 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

שלושה שלבים — כמו בשיעור 2 ("סדר הביצוע"): filter (WHERE) ← map (SELECT).

💡 רמז 2

בדיקת עמודות: const known = Object.keys(rows[0] ?? {}); — ואם rows.length > 0 ושם לא ב־known ← זורקים.

✅ פתרון
// P16-E39: SELECT ב־JavaScript
type Row = Record<string, unknown>;

export function select(rows: Row[], columns: string[], where: Row = {}): Row[] {
  if (rows.length > 0) {
    const known = Object.keys(rows[0]);
    for (const name of [...columns, ...Object.keys(where)]) {
      if (!known.includes(name)) throw new Error(`column "${name}" does not exist`);
    }
  }
  return rows
    .filter((row) => Object.entries(where).every(([col, value]) => row[col] === value))
    .map((row) => Object.fromEntries(columns.map((col) => [col, row[col]])));
}

];

P16-E40 · פלט כמו psql 🤖 💻 כתיבת קוד 🤖 רמה 2

✅ פתרון
// P16-E40: פלט כמו psql
type Row = Record<string, unknown>;

export function formatTable(rows: Row[]): string {
  const footer = `(${rows.length} ${rows.length === 1 ? "row" : "rows"})`;
  if (rows.length === 0) return footer;
  const cols = Object.keys(rows[0]);
  const text = (v: unknown) => (v === null || v === undefined ? "" : String(v));
  const widths = cols.map((c) => Math.max(c.length, ...rows.map((r) => text(r[c]).length)));
  const line = (cells: string[]) =>
    cells
      .map((c, i) => ` ${c.padEnd(widths[i])} `)
      .join("|")
      .trimEnd();
  return [line(cols), widths.map((w) => "-".repeat(w + 2)).join("+"), ...rows.map((r) => line(cols.map((c) => text(r[c])))), footer].join("\n");
}

P16-E41 · אילוצים ב־JavaScript 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

ל־unique: Map<string, Set<unknown>> — לכל עמודה, הערכים שכבר נראו.

💡 רמז 2

לולאה אחת על השורות (rows.forEach((row, i) => ...)), ובתוכה שלוש לולאות על הכללים — כך הסדר יוצא נכון.

✅ פתרון
// P16-E41: אילוצים ב־JavaScript
type Row = Record<string, unknown>;
export type Rules = { notNull?: string[]; unique?: string[]; check?: Record<string, (row: Row) => boolean> };

export function checkRows(rows: Row[], rules: Rules): string[] {
  const problems: string[] = [];
  const seen = new Map<string, Set<unknown>>();
  rows.forEach((row, i) => {
    for (const col of rules.notNull ?? []) {
      if (row[col] === null || row[col] === undefined) problems.push(`row ${i}: ${col} is null`);
    }
    for (const col of rules.unique ?? []) {
      const value = row[col];
      if (value === null || value === undefined) continue;
      if (!seen.has(col)) seen.set(col, new Set());
      if (seen.get(col)!.has(value)) problems.push(`row ${i}: duplicate ${col}: ${value}`);
      seen.get(col)!.add(value);
    }
    for (const [name, fn] of Object.entries(rules.check ?? {})) {
      if (!fn(row)) problems.push(`row ${i}: check ${name} failed`);
    }
  });
  return problems;
}

const customers = [
  { email: "dana@example.com", price: 10 },
  { email: "dana@example.com", price: -5 },
  { email: null, price: 3 },
  { email: null, price: 0 },
];
console.log(checkRows(customers, { notNull: ["email"], unique: ["email"], check: { positive_price: (r) => (r.price as number) > 0 } }));
[
  'row 1: duplicate email: dana@example.com',
  'row 1: check positive_price failed',
  'row 2: email is null',
  'row 3: email is null',

שלושה סוגי חוקים שבשיעור 4 תכתוב בתוך CREATE TABLE: ‏NOT NULL, ‏UNIQUE, ‏CHECK. ההבדל: כאן הבדיקה רצה רק כשמישהו זוכר לקרוא לה; במסד — על כל כתיבה, מכל קוד, גם משני שרתים במקביל.

⚠️ טעויות נפוצות
  • לספור שני null כ"כפילות" — ב־SQL, ‏NULL לא שווה לשום דבר, גם לא ל־NULL אחר (שיעור 3), ולכן UNIQUE מרשה כמה.

P16-E42 · לקוחות שהצטרפו ביום מסוים 🤖 💻 כתיבת קוד 🤖 רמה 1

💡 רמז 1

WHERE joined_on = '2026-03-05'.

💡 רמז 2

✅ פתרון

⚠️ טעויות נפוצות

P16-E46 · מ־CSV לשורות עם טיפוסים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 2

פונקציה convert(value, type, column, n) עם switch (type). ל־integer: /^-?\d+$/; ל־numeric: Number(v) ו־Number.isFinite.

✅ פתרון
// P16-E46: מ־CSV לשורות עם טיפוסים
export type ColumnType = "text" | "integer" | "numeric" | "boolean" | "date";

function convert(raw: string, type: ColumnType, column: string, n: number): unknown {
  const v = raw.trim();
  if (v === "") return null;
  const fail = () => {
    throw new Error(`line ${n}: invalid ${type} for ${column}: "${v}"`);
  };
  switch (type) {
    case "text":
      return v;
    case "integer":
      return /^-?\d+$/.test(v) ? Number(v) : fail();
    case "numeric":
      return Number.isFinite(Number(v)) ? Number(v) : fail();
    case "boolean":
      return v === "true" ? true : v === "false" ? false : fail();
    case "date":
      return /^\d{4}-\d{2}-\d{2}$/.test(v) ? v : fail();
  }
}

export function parseCsv(text: string, types: Record<string, ColumnType>): Record<string, unknown>[] {
  const lines = text.split(/\r?\n/).map((line, i) => ({ line, n: i + 1 }));
  const [header, ...rest] = lines.filter((l) => l.line.trim() !== "");
  if (!header) return [];
  const columns = header.line.split(",").map((c) => c.trim());
  return rest.map(({ line, n }) => {
    const values = line.split(",");
    if (values.length !== columns.length) throw new Error(`line ${n}: expected ${columns.length} values, got ${values.length}`);
    return Object.fromEntries(columns.map((c, i) => [c, convert(values[i], types[c] ?? "text", c, n)]));
  });
}

// P16-E47: route שעובד כמו WHERE
import express from "express";

export type Product = { id: number; name: string; category: string; price: number; stock: number; is_active: boolean };

export function createApp(products: Product[]) {
  const app = express();
  app.get("/products", (req, res) => {
    const known = Object.keys(products[0] ?? {});
    const where = Object.entries(req.query).map(([col, value]) => [col, String(value)] as const);
    const unknown = where.find(([col]) => !known.includes(col));
    if (unknown) {
      res.status(400).json({ error: `column "${unknown[0]}" does not exist` });
      return;
    }
    const rows = products
      .filter((p) => where.every(([col, value]) => String(p[col as keyof Product]) === value))
      .sort((a, b) => a.id - b.id)
      .map(({ id, name, price }) => ({ id, name, price }));
    res.json(rows);
  });
  return app;
}

P16-E48 · לנחש טיפוס לכל עמודה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

קודם אוספים את שמות העמודות (Set, לפי סדר), ואז לכל עמודה — מערך הערכים שאינם null.

💡 רמז 2

סדר הבדיקות: ריק ← every(Number.isInteger) ← every(typeof === "number") ← boolean ← date ← string ← mixed.

✅ פתרון
// P16-E48: לנחש טיפוס לכל עמודה
type Row = Record<string, unknown>;
export type Column = { column: string; type: string; nullable: boolean };
const DATE = /^\d{4}-\d{2}-\d{2}$/;

function typeOf(values: unknown[]): string {
  if (values.length === 0) return "unknown";
  if (values.every((v) => Number.isInteger(v))) return "integer";
  if (values.every((v) => typeof v === "number")) return "numeric";
  if (values.every((v) => typeof v === "boolean")) return "boolean";
  if (values.every((v) => typeof v === "string" && DATE.test(v))) return "date";
  if (values.every((v) => typeof v === "string")) return "text";
  return "mixed";
}

export function describe(rows: Row[]): Column[] {
  const columns = new Set<string>();
  for (const row of rows) for (const key of Object.keys(row)) columns.add(key);
  return [...columns].map((column) => {
    const values = rows.map((r) => r[column]);
    const present = values.filter((v) => v !== null && v !== undefined);
    return { column, type: typeOf(present), nullable: present.length < rows.length };
  });
}
