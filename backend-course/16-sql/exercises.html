P16-E04 · NULL בפועל

מה התוצאה של כל אחד? (בלי להריץ, ואז בדוק.)

SELECT NULL = NULL;                                   -- 1
SELECT NULL IS NULL;                                  -- 2
SELECT 10 + NULL;                                     -- 3
SELECT COALESCE(NULL, NULL, 'x', 'y');                -- 4
SELECT COUNT(city), COUNT(*) FROM customers;          -- 5
SELECT COUNT(*) FROM customers WHERE city <> 'Haifa'; -- 6

P16-E05 · מה הפקודה עושה?

UPDATE products SET stock = 0;                                       -- 1

DELETE FROM customers WHERE city = NULL;                             -- 3
DELETE FROM customers WHERE city IS NULL;                            -- 4
UPDATE products SET price = price * 0.9 WHERE category = 'beans' OR is_active; -- 5
DROP TABLE customers;                                                -- 6

P16-E24 · אתגר: טבלת קופונים 🤖

  • id — מפתח ראשי ממוספר. code — טקסט, ייחודי, 4–20 תווים, רק אותיות גדולות באנגלית וספרות.

🏁 מבחן מעבר

  • לכתוב שאילתה עם סינון על כמה תנאים, מיון בשני שדות ו־LIMIT — בלי לבדוק בתיעוד.
  • להסביר למה WHERE phone = NULL לא מחזיר כלום, ומה כותבים במקום.
  • ליצור טבלה עם מפתח ראשי, NOT NULL, DEFAULT, UNIQUE ו־CHECK — ולהראות שכל אילוץ עובד.
  • לעדכן ולמחוק שורות עם WHERE מדויק, ולבדוק עם SELECT לפני.
