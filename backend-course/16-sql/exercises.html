P16-E27 · בונה שאילתות עם פרמטרים 🤖

🔁 חזרהרמה 3⏱ 25 דק׳ידע נדרש: שיעור 2

🔁 חזרה על switch (פרק 4), ‏type עם שדות אופציונליים ו־union (פרק 11) ו־join (פרק 6), הפעם ב־TypeScript שמייצר SQL. מסך חיפוש מוצרים שולח לשרת מסננים, והשרת צריך לבנות מהם שאילתה. לעולם לא מדביקים ערכים מהמשתמש לתוך הטקסט של השאילתה. במקומם כותבים $1, ‏$2..., והערכים נשלחים בנפרד (זה יקרה בפרק 18 עם pg).

בקובץ 16-sql/starter/P16-E27.ts כתוב וייצא:

  • type ProductFilters — כל השדות לא חובה: category: string, ‏minPrice: number, ‏maxPrice: number, ‏search: string, ‏inStock: boolean, ‏sort: "price" | "-price" | "name", ‏limit: number.
  • buildProductQuery(filters: ProductFilters): { text: string; values: unknown[] }.

הטקסט: SELECT id, name, price FROM products WHERE is_active, ואחריו תנאים עם AND , ‏ ORDER BY ... ובסוף LIMIT $n (רק אם יש limit). התנאים, בסדר הזה, ורק למסננים שנשלחו:

  • category = $n, ‏price >= $n (‏minPrice), ‏price <= $n (‏maxPrice), ‏name ILIKE $n (הערך: %search%).
  • inStock: true ← stock > 0. ‏inStock: false ← stock = 0. (בלי פרמטר — אלה לא ערכים מהמשתמש.)
  • מיון, עם switch: ‏"price" ← price, id; ‏"-price" ← price DESC, id; ‏"name" ← name; בלי sort ← id. ערך אחר (מקוד JavaScript שלא עבר בדיקת טיפוסים) ← Error(מיון לא מוכר: ${sort}).
  • המספרים של הפרמטרים לפי הסדר שבו נוספו: $1, ‏$2... ‏values באותו סדר.
buildProductQuery({ category: "beans", maxPrice: 90, inStock: true, sort: "-price", limit: 2 });
// text:   "SELECT id, name, price FROM products WHERE is_active AND category = $1 AND price <= $2 AND stock > 0 ORDER BY price DESC, id LIMIT $3"
// values: ["beans", 90, 2]

📄 כותבים בקובץ 16-sql/starter/P16-E27.ts (יש בו רק הערה), מריצים ובודקים:

% node 16-sql/starter/P16-E27.ts
% npm run check P16-E27

הבודק בודק את הטקסט, ואז גם מריץ את השאילתה שלך על נתוני החנות, ומשווה את המוצרים שחזרו.

P16-E28 · אזור לכל לקוח (CASE כמו switch) 🤖

🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

🔁 חזרה על switch (פרק 4) ועל NULL (שיעור 3, ‏P16-E21), הפעם ב־SQL. ל־CASE יש צורה קצרה שעובדת בדיוק כמו switch: ‏CASE city WHEN 'Haifa' THEN 'north' ... ELSE ... END. בקובץ 16-sql/starter/P16-E28.sql כתוב רשימת לקוחות לצוות המכירות, עם העמודות:

  • full_name.
  • region: ‏'Tel Aviv' ו־'Ramat Gan' ← 'center', ‏'Haifa' ← 'north', ‏'Jerusalem' ← 'jerusalem', ‏'Beer Sheva' ← 'south'. עיר אחרת או חסרה ← 'unknown'.
  • contact: הטלפון, ואם אין — האימייל.

מיון: לפי האזור בסדר center, north, jerusalem, south, unknown (לא לפי א״ב!), ובתוך כל אזור לפי full_name.
