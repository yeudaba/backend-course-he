מה מתקינים עכשיו: שרת PostgreSQL, תוסף ל־VS Code, ומסד לקורס.

1. שרת PostgreSQL

קודם בדוק אם כבר יש לך: ב־Terminal, ls /Library/PostgreSQL /Applications | grep -i postgres. אם מופיע PostgreSQL 18 (או גרסה אחרת) — כבר הותקן בעבר (מהאתר של EDB, עם pgAdmin). אל תתקין Postgres.app בנוסף — שניהם ירצו את פורט 5432. דלג לסעיף "יש לי כבר PostgreSQL".

אין לך: הורד את Postgres.app (הגרסה האחרונה), גרור ל־Applications, פתח ← Initialize. בפינה יופיע פיל 🐘. ואז הוסף את כלי שורת הפקודה (פעם אחת):

% sudo mkdir -p /etc/paths.d && echo /Applications/Postgres.app/Contents/Versions/latest/bin | sudo tee /etc/paths.d/postgresapp

סגור ופתח מחדש את ה־Terminal. ב־Postgres.app המשתמש הוא שם המשתמש שלך ב־Mac, בלי סיסמה.

יש לי כבר PostgreSQL (EDB): המשתמש הוא postgres, והסיסמה — זו שבחרת בהתקנה. כלי שורת הפקודה נמצאים ב־/Library/PostgreSQL/18/bin; הוסף אותם ל־PATH: echo 'export PATH="/Library/PostgreSQL/18/bin:$PATH"' >> ~/.zshrc, ופתח Terminal חדש.

2. מסד לקורס ונתוני הדוגמה

% createdb course                 # ב־EDB: createdb -U postgres course
% cd ~/dev/backend-course
% psql -d course -f 16-sql/files/shop.sql      # ב־EDB: psql -U postgres -d course -f ...

(בטעינה הראשונה יופיעו שתי שורות NOTICE: table ... does not exist, skipping — זה תקין.)

3. חיבור לבודק

צור בתיקיית הקורס קובץ .env עם שורה אחת:

COURSE_DATABASE_URL=postgresql://localhost:5432/course

ב־EDB: COURSE_DATABASE_URL=postgresql://postgres:הסיסמה@localhost:5432/course. ואז npm install (מתקין את pg, הספרייה שהבודק משתמש בה).

4. תוסף ל־VS Code

PostgreSQL של Microsoft (מזהה ms-ossdata.vscode-pgsql). אחרי ההתקנה: אייקון הפיל בסרגל הצד ← Add Connection ← Server localhost, Database course, המשתמש (והסיסמה ב־EDB). מעכשיו: פותחים קובץ .sql, מסמנים שאילתה ← ⌘+⇧+E — והתוצאה מופיעה בטבלה.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 16-sql מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

✔ בדיקה: psql -d course -c "select count(*) from products" ← 14. ו־npm run check P16-E06 צריך להיכשל עם "הקובץ ריק" — לא עם "אין חיבור למסד".

🎯 בסוף הפרק תדע
  • להבין מה זה מסד נתונים יחסי, ולמה לא סתם קובץ JSON.
  • לשלוף נתונים: SELECT, WHERE, ORDER BY, LIMIT, DISTINCT, ביטויים וכינויים.
  • להבין NULL — ולא ליפול בו.
  • פונקציות צבירה בסיסיות: COUNT, SUM, AVG, MIN, MAX.
  • ליצור טבלה עם טיפוסים ואילוצים, ולשנות נתונים: INSERT, UPDATE, DELETE — בזהירות.

🤔 למה צריך את זה?

ב־API של פרויקט 2 המשימות נעלמות בכל הפעלה מחדש. בשרת אמיתי הנתונים חיים במסד נתונים — ו־SQL היא השפה שבה מדברים איתו. גם כשנשתמש ב־Prisma (פרק 19), מתחת יש SQL, ובראיונות ל־Backend כמעט תמיד יש שאלת SQL ("כתוב שאילתה שמחזירה..."). זה גם ידע שלא מתיישן: SQL קיים 50 שנה, ועובד כמעט אותו דבר ב־PostgreSQL, MySQL ו־SQL Server.

🏁 מבחן מעבר

  • לכתוב שאילתה עם סינון על כמה תנאים, מיון בשני שדות ו־LIMIT — בלי לבדוק בתיעוד.
  • להסביר למה WHERE phone = NULL לא מחזיר כלום, ומה כותבים במקום.
  • ליצור טבלה עם מפתח ראשי, NOT NULL, DEFAULT, UNIQUE ו־CHECK — ולהראות שכל אילוץ עובד.
  • לעדכן ולמחוק שורות עם WHERE מדויק, ולבדוק עם SELECT לפני.
