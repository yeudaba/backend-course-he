P16-E28 · אזור לכל לקוח (CASE כמו switch) 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 3

🔁 חזרה על switch (פרק 4) ועל NULL (שיעור 3, ‏P16-E21), הפעם ב־SQL. ל־CASE יש צורה קצרה שעובדת בדיוק כמו switch: ‏CASE city WHEN 'Haifa' THEN 'north' ... ELSE ... END. בקובץ 16-sql/starter/P16-E28.sql כתוב רשימת לקוחות לצוות המכירות, עם העמודות:

  • full_name.
  • region: ‏'Tel Aviv' ו־'Ramat Gan' ← 'center', ‏'Haifa' ← 'north', ‏'Jerusalem' ← 'jerusalem', ‏'Beer Sheva' ← 'south'. עיר אחרת או חסרה ← 'unknown'.
  • contact: הטלפון, ואם אין — האימייל.

מיון: לפי האזור בסדר center, north, jerusalem, south, unknown (לא לפי א״ב!), ובתוך כל אזור לפי full_name.
