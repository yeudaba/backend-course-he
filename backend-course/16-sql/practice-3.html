P16-E59 · ממוצע שמתעלם מ־NULL

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

שלוש ביקורות: 10, NULL (אין דירוג) ו־20. ‏(VALUES ...) AS t(x) בונה "טבלה" זמנית עם עמודה x. מה יחזיר?

SELECT COUNT(*) AS all_rows, COUNT(x) AS with_x, SUM(x) AS sum_x,
       AVG(x) AS avg_x, AVG(COALESCE(x, 0)) AS avg_zero, SUM(x) / COUNT(*) AS sum_div_all
FROM (VALUES (10), (NULL), (20)) AS t(x);

P16-E60 · צבירה על אפס שורות

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

SELECT COUNT(*) AS n, SUM(stock) AS units, MAX(price) AS max_price, AVG(price) AS avg_price,

P16-E67 · null ב־JavaScript מול NULL ב־SQL

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 1, שיעור 3

אותם ביטויים, בשני העולמות. מה ידפיס ה־JavaScript? ומה יחזיר ה־SQL?

console.log(null === null, null == undefined, null + 5, null > 0, null >= 0);
console.log([null, 5].includes(null), "a" + null, Math.max(3, null));
SELECT NULL = NULL AS eq, NULL + 5 AS plus, NULL > 0 AS gt, 'a' || NULL AS concat, GREATEST(3, NULL) AS greatest;

🔗 איך זה מתחבר: המרות של null מפרק 1 (וההשוואות המוזרות שלו). השיעור: NULL ב־SQL הוא "לא ידוע" — ולכן כמעט כל פעולה איתו נותנת NULL.

P16-E68 · מה pg מחזיר מ־COUNT ו־SUM?

השאילתה הייתה SELECT COUNT(*) AS n, SUM(stock) AS units, AVG(price) AS avg, MAX(price) AS max, 7 AS seven, 1.5::float8 AS f FROM ... (‏price הוא numeric). ענה:

P16-E69 · reduce מול SUM ו־AVG

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 6, שיעור 3

אותם דירוגים — [10, null, 20] — סוכמו פעם ב־JavaScript ופעם ב־SQL (P16-E59). מה ידפיס ה־JavaScript, ובמה זה שונה מהמסד?

const ratings = [10, null, 20];
const sum = ratings.reduce((s, x) => s + x, 0);
console.log(sum, sum / ratings.length);

const present = ratings.filter((x) => x !== null);
console.log(present.reduce((s, x) => s + x, 0) / present.length, present.length);

const empty = [];
console.log(empty.reduce((s, x) => s + x, 0), Math.max(...empty), empty.reduce((s, x) => s + x, 0) / empty.length);

🔗 איך זה מתחבר: reduce ו־filter מפרק 6, ו־null + 10 מפרק 1 (P16-E67). השיעור: צבירות ו־NULL — ומה קורה על אפס שורות (P16-E60).

P16-E71 · צבירות ב־JavaScript שמתנהגות כמו SQL 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: פרק 6, שיעור 3

כתוב וייצא aggregate(rows, column) שמחזירה { count, countAll, sum, avg, min, max } — בדיוק לפי חוקי SQL:

  • countAll = ‏COUNT(*) (כל השורות). ‏count = ‏COUNT(column) — רק ערכים שאינם null/undefined.
  • sum, ‏avg, ‏min, ‏max — רק על הערכים שאינם null; אין אף ערך ← null (לא 0, לא NaN, לא Infinity).
  • min/max עובדים גם על מחרוזות (השוואה עם </> — מתאים לתאריכי ISO). בעמודה של מחרוזות, sum ו־avg הם null.

📄 כותבים בקובץ 16-sql/starter/P16-E71.ts (יש בו רק הערה).

% npm run check P16-E71

🔗 איך זה מתחבר: filter/reduce מפרק 6 (P16-E69). השיעור: צבירות מתעלמות מ־NULL, ומחזירות NULL על אפס ערכים.
