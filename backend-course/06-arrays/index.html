⚡ מבחן כניסה — אולי אפשר לדלג?
  1. מה ידפיס: const a = [10, 20, 30]; console.log(a[1], a.length, a[3]);
  2. מה ההבדל בין push ל־unshift?
  3. כתוב בשורה אחת: מערך חדש שבו כל מחיר ב־prices כפול 1.18.
  4. כתוב בשורה אחת: רק המספרים הזוגיים מתוך nums.
  5. מה מחזיר [5, 8, 12].find((x) => x > 6)? ומה [5].find((x) => x > 6)?
  6. כתוב עם reduce: סכום של nums.
  7. מה ידפיס: console.log([10, 1, 5, 100].sort()); — ולמה?
  8. מה ההבדל בין slice ל־splice?
  9. מה ידפיס: "a,b,c".split(",").join(" | ")?
  10. מה המשמעות של const list = [1]; list.push(2); — זה חוקי? ו־list = [3]?
תשובות
  1. 20 3 undefined
  2. push מוסיף לסוף, unshift להתחלה.
  3. prices.map((p) => p * 1.18)
  4. nums.filter((n) => n % 2 === 0)
  5. 8; undefined
  6. nums.reduce((sum, n) => sum + n, 0)
  7. [1, 10, 100, 5] — sort בלי פונקציה ממיין כמחרוזות. צריך (a, b) => a - b.
  8. slice מחזיר עותק של חלק ולא משנה; splice משנה את המערך (מוחק/מכניס).
  9. a | b | c
  10. push חוקי — const מונע הצבה חדשה, לא שינוי תוכן. list = [3] ← TypeError.

  • להבחין בין מתודות שמשנות את המערך לבין כאלה שמחזירות מערך חדש.

🤔 למה צריך את זה?

ב־P01-E24 היו לך item1Price, item2Price... — ובפרק 4 פירקת ידנית טקסט כמו "10,20,30". כל רשימה בשרת היא מערך: המוצרים בעגלה, ההזמנות של היום, תוצאות חיפוש. API שמחזיר "רשימת משתמשים" מחזיר מערך. הפרק הזה הוא כנראה החשוב ביותר בחטיבה.
