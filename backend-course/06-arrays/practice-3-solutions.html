P06-E59 · מה ה־callback מחזיר? 🧠 הבנה רמה 1

💡 רמז 1

map שם במערך החדש את מה שה־callback מחזיר — מה שזה לא יהיה. filter משאיר איבר אם מה שחוזר הוא truthy.

💡 רמז 2

arrow function עם { } וללא return מחזירה undefined (פרק 5). ואיזה מספר הוא falsy?

✅ פתרון
const nums = [1, 2, 3];
console.log(nums.map((n) => n * 2));
console.log(nums.map((n) => { n * 2; }));
console.log(nums.map((n) => n > 1));
console.log(nums.filter((n) => n * 2));
console.log(nums.filter((n) => n - 2));
console.log(["1", "2", "x"].map(Number));
[ 2, 4, 6 ]
[ undefined, undefined, undefined ]
[ false, true, true ]
[ 1, 2, 3 ]
[ 1, 3 ]
[ 1, 2, NaN ]

שורה 2: הסוגריים המסולסלים הפכו את הגוף לבלוק בלי return — ושלושה undefined. שורה 3: map לא מסנן — הוא מחזיר בוליאני לכל איבר. שורה 4: כל n * 2 שונה מ־0, כלומר truthy — אף אחד לא נזרק. שורה 5: 2 - 2 הוא 0, falsy — רק ה־2 נזרק.

⚠️ טעויות נפוצות
  • להשתמש ב־map כדי "לסנן" — מקבלים מערך של true/false באותו אורך.
  • לכתוב ל־filter callback שמחזיר מספר "בטעות" — הוא יעבוד לפי truthy/falsy, לא לפי מה שהתכוונת.

P06-E60 · find, filter, some — מה חוזר? 🧠 הבנה רמה 1

השורה האחרונה היא המלכודת: find מצא את 0 — והחזיר אותו. if (0) הוא false, ולכן ה־if יחשוב "אין פריט שאזל" — בדיוק כשיש. לשאלת "האם יש?" — some. find — רק כשצריך את האיבר עצמו (ואז בודקים !== undefined). זה אותו באג כמו indexOf ב־P06-E32.

P06-E61 · every על עגלה ריקה 🧠 הבנה רמה 2

💡 רמז 1

every שואל "האם יש מישהו שנכשל?" — ואם אין אף אחד בכלל...

💡 רמז 2

some על מערך ריק — האם יש "לפחות אחד" באפס איברים?

✅ פתרון
function canCheckout(stock) {
  return stock.every((qty) => qty > 0);
}
function hasProblem(stock) {
  return stock.some((qty) => qty <= 0);
}
console.log(canCheckout([3, 1]), canCheckout([3, 0]), canCheckout([]));
console.log(hasProblem([3, 1]), hasProblem([3, 0]), hasProblem([]));
true false true
false true false

canCheckout([]) מחזיר true — מותר "לקנות" עגלה ריקה. every על מערך ריק הוא תמיד true, ו־some על ריק — תמיד false. זה עקבי מתמטית, אבל כמעט אף פעם לא מה שהעסק רוצה. התיקון: guard מפורש.

function canCheckout(stock) {
  return stock.length > 0 && stock.every((qty) => qty > 0);
}
⚠️ טעויות נפוצות
  • לסמוך על every בלי לחשוב על ריק — "כל המשתמשים אישרו?" על קבוצה בלי משתמשים תחזיר כן.

P06-E62 · forEach, map או for...of? 🧠 הבנה רמה 1

💡 רמז 1

forEach לא מחזיר כלום — גם אם ה־callback מחזיר.

💡 רמז 2

ב־c: מה ה־callback מחזיר? (יש בו רק console.log.)

✅ פתרון
const prices = [10, 20];
const a = prices.forEach((p) => p * 2);
const b = prices.map((p) => p * 2);
const c = prices.map((p) => {
  console.log(p);
});
console.log(a, b, c);
10
20
undefined [ 20, 40 ] [ undefined, undefined ]

a הוא undefined — forEach זורק את מה שה־callback מחזיר. c הוא מערך של undefined — "map שמדפיס" מייצר מערך זבל. ההדפסות 10 ו־20 קורות בזמן ה־map, לפני השורה האחרונה.

המשימות: (1) for...of — רק "לעשות משהו", בלי תוצאה. (2) map — אותו אורך, ערכים חדשים. (3) filter — פחות איברים, אותם ערכים.

⚠️ טעויות נפוצות
  • const result = arr.forEach(...) — תמיד undefined.

P06-E14 · ניקוי תגיות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שרשרת: split ← map(trim + lowercase) ← filter(לא ריק) ← unique ← slice(0, 5).

💡 רמז 2

unique עם filter: .filter((tag, i, all) => all.indexOf(tag) === i) — "שמור רק אם זו ההופעה הראשונה".

✅ פתרון
// P06-E14: ניקוי תגיות
function cleanTags(input, max = 5) {
  return input
    .split(",")
    .map((tag) => tag.trim().toLowerCase())
    .filter((tag) => tag !== "")
    .filter((tag, i, all) => all.indexOf(tag) === i)
    .slice(0, max);
}

console.log(cleanTags(" Node, , backend ,API, node ,  "));

module.exports = { cleanTags };
[ 'node', 'backend', 'api' ]

ה־callback של filter מקבל גם את המערך כולו כפרמטר שלישי. indexOf מחזיר את ההופעה הראשונה — אם היא לא באינדקס הנוכחי, זו כפילות.

⚠️ טעויות נפוצות
  • להסיר כפילויות לפני toLowerCase — "Node" ו־"node" שניהם יישארו.

P06-E16 · slug ו־Title Case 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

פונקציה פרטית אחת words(text) שמחזירה מערך מילים נקי — וכל השאר משתמשות בה.

💡 רמז 2

text.trim().split(" ").filter((w) => w !== "")

✅ פתרון
// P06-E16: טיפול במילים עם מערכים
function words(text) {
  return text.trim().split(" ").filter((w) => w !== "");
}

function toSlug(title) {
  return words(title.toLowerCase()).join("-");
}

function titleCase(text) {
  return words(text)
    .map((w) => w[0].toUpperCase() + w.slice(1).toLowerCase())
    .join(" ");
}

function wordCount(text) {
  return words(text).length;
}

console.log(toSlug("  Learn   Node JS  "), "|", titleCase("  learn   NODE js "), "|", wordCount("  a  b c "));

module.exports = { toSlug, titleCase, wordCount };
learn-node-js | Learn Node Js | 3

השווה ל־P04-E19 ו־P05-E17: אותן בעיות, שליש מהקוד. מעכשיו זו הדרך.

⚠️ טעויות נפוצות
  • wordCount("") — בלי ה־filter, "".split(" ") הוא [""] ← מילה אחת.

P06-E21 · map ו־filter שבורים 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

אחת מחזירה מערך של undefined, אחת לא מסננת כלום, ואחת מחזירה undefined בכלל.

💡 רמז 2

{ } בלי return; callback של filter שמחזיר ערך במקום בוליאני; forEach במקום map.

✅ פתרון
// P06-E21: callbacks — מתוקן
function doublePrices(prices) {
  return prices.map((p) => p * 2);
}

function activeUsers(statuses) {
  return statuses.filter((s) => s === "active");
}

function shout(words) {
  return words.map((w) => w.toUpperCase());
}

console.log(doublePrices([5, 10]), activeUsers(["active", "blocked", "active"]), shout(["hi"]));

module.exports = { doublePrices, activeUsers, shout };
[ 10, 20 ] [ 'active', 'active' ] [ 'HI' ]

(1) map((p) => { p * 2 }) ← [undefined, undefined]. (2) filter((s) => s) — כל מחרוזת לא ריקה truthy, אז כולן נשארו. (3) forEach לא מחזיר כלום.

⚠️ טעויות נפוצות
  • לתקן את (3) עם forEach ו־push למערך — עובד, אבל זה בדיוק מה ש־map עושה.

P06-E64 · חיפוש מוצרים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

נקה את השאילתה פעם אחת לפני ה־filter: const q = query.trim().toLowerCase();

💡 רמז 2

בתוך ה־filter: name.toLowerCase().includes(q). ושאילתה ריקה? "abc".includes("") הוא true — אז היא עובדת לבד.

✅ פתרון
06-arrays/starter/P06-E64.js 
function search(names, query) {
  const q = query.trim().toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(q));
}

function countMatches(names, query) {
  return search(names, query).length;
}

const products = ["Laptop Pro", "USB cable", "laptop stand", "Mouse"];
console.log(search(products, "laptop"), countMatches(products, ""));

module.exports = { search, countMatches };
[ 'Laptop Pro', 'laptop stand' ] 4

שאילתה ריקה לא צריכה טיפול מיוחד: כל מחרוזת "מכילה" את המחרוזת הריקה. ו־filter תמיד מחזיר מערך חדש — גם כשכל האיברים עברו, ולכן זה עותק ולא אותו מערך.

⚠️ טעויות נפוצות
  • להוריד אותיות רק בשאילתה ולא בשם (או להפך) — "Laptop Pro" לא יימצא.
  • return names; לשאילתה ריקה — מחזיר את המערך המקורי, ומי שישנה את התוצאה ישנה גם את הקטלוג.

P06-E65 · callback עם סוגריים — שוב 🧠 הבנה רמה 2

💡 רמז 1

isEven() קוראת לפונקציה עכשיו, בלי ארגומנט. מה היא מחזירה? ומה filter יעשה עם זה?

💡 רמז 2

map קורא ל־callback עם שלושה ארגומנטים: האיבר, האינדקס, והמערך. Number משתמשת רק בראשון. ו־parseInt (פרק 2)? הפרמטר השני שלה הוא הבסיס (10 לעשרוני, 2 לבינארי...).

✅ פתרון
function isEven(n) {
  return n % 2 === 0;
}
const nums = [1, 2, 3, 4];
console.log(nums.filter(isEven));
console.log(nums.filter((n) => isEven(n)));
console.log(nums.map(isEven));
console.log(["10", "10", "10"].map(Number));
console.log(["10", "10", "10"].map(parseInt));
[ 2, 4 ]
[ 2, 4 ]
[ false, true, false, true ]
[ 10, 10, 10 ]
[ 10, NaN, 2 ]

nums.filter(isEven()): קודם רצה isEven(undefined) ומחזירה false, ואז filter(false) זורק TypeError: false is not a function.

והשורה האחרונה היא מלכודת מפורסמת: map(parseInt) קורא ל־parseInt("10", 0), parseInt("10", 1), parseInt("10", 2) — האינדקס נכנס כבסיס. בבסיס 1 אין ספרות בכלל (NaN), ובבסיס 2 "10" הוא 2. הכלל: אם הפונקציה מקבלת יותר מפרמטר אחד — עטוף אותה: map((s) => parseInt(s)).

⚠️ טעויות נפוצות
  • filter(isEven()) — קריאה במקום העברה.
  • להעביר ישירות פונקציה שיש לה פרמטר שני "אופציונלי" — היא תקבל את האינדקס.

P06-E66 · מלולאה למתודה 🧠 הבנה רמה 2

💡 רמז 1

שאל: האם התוצאה באותו אורך כמו prices? פחות? איבר אחד? בוליאני?

💡 רמז 2

ה' עושה שני דברים — סינון ואז המרה. אפשר לשרשר.

✅ פתרון
const prices = [50, 120, 200, 0];
const a = prices.map((p) => p * 1.18);
const b = prices.filter((p) => p > 100);
const c = prices.find((p) => p > 100);
const d = prices.every((p) => p > 0);
const e = prices.filter((p) => p > 100).map((p) => p * 0.9);
console.log(a, b, c, d, e);
[ 59, 141.6, 236, 0 ] [ 120, 200 ] 120 false [ 108, 180 ]

ד' הוא every עם התנאי ההפוך מהלולאה: הלולאה מחפשת מישהו ש־p <= 0; every בודק שכולם p > 0. (אפשר גם !prices.some((p) => p <= 0).) בה', הסדר חשוב: קודם מסננים לפי המחיר המקורי, ואז מורידים 10%.

⚠️ טעויות נפוצות
  • ב־ה', להפוך את הסדר (map ואז filter) — מסננים לפי המחיר אחרי ההנחה: מחיר 110 הופך ל־99 ונזרק.

P06-E67 · truthy בתוך filter 🧠 הבנה רמה 1

💡 רמז 1

הערכים ה־falsy: false, 0, "", null, undefined, NaN. כל השאר — truthy, כולל "0" ו־" ".

💡 רמז 2

|| מחזיר את הצד הימני כשהשמאלי falsy (פרק 3).

✅ פתרון

console.log(values.filter((v) => v));

"0" ו־" " נשארים — הם מחרוזות לא ריקות. והתשובה לשאלה: ציון 0 הוא falsy — filter((s) => s) יזרוק גם את מי שקיבל 0, לא רק את החסרים. הדרך הבטוחה: לבדוק במפורש — filter((s) => s !== null && s !== undefined).

⚠️ טעויות נפוצות
  • filter(Boolean) על מספרים — זורק את כל האפסים.

function gradeLabel(score) {
  if (score >= 90) {
    return "מצוין";
  }
  if (score >= 55) {
    return "עובר";
  }

function isValidCoupon(code) {
  const clean = code.trim().toUpperCase();
  if (clean.length !== 8 || !clean.startsWith("IL")) {
    return false;
  }
  return clean
    .slice(2)
    .split("")
    .every((ch) => ch >= "0" && ch <= "9");
}

function validCoupons(codes) {
  return codes.map((c) => c.trim().toUpperCase()).filter(isValidCoupon);
}

console.log(validCoupons([" il123456", "IL12345", "IL12a456", "XX123456", "IL000001 "]));

module.exports = { isValidCoupon, validCoupons };
[ 'IL123456', 'IL000001' ]

קודם map שמנקה, ואז filter — כך התוצאה כבר מנוקה. isValidCoupon מנקה בעצמה גם כן, כדי שתעבוד נכון גם כשקוראים לה לבד.

⚠️ טעויות נפוצות
  • filter ואז map — עובד כאן, אבל אז הניקוי קורה פעמיים לכל קופון תקין. כשהסדר לא משנה את התוצאה — עדיף שהשלב שמצמצם יהיה ראשון. כשהוא כן משנה (P06-E66) — חושבים.
  • לבדוק ספרות עם !Number.isNaN(Number(rest)) — "1e3456" (מספר בכתיב מדעי) ו־" 12345" (רווח בהתחלה) עוברים את הבדיקה. הבודק בודק את שניהם.

P06-E70 · מפעל לתנאים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

between מחזירה arrow function: return (n) => ...;. היא "רואה" את min ו־max גם אחרי ש־between סיימה.

💡 רמז 2

not: return (x) => !predicate(x);

✅ פתרון
06-arrays/starter/P06-E70.js 
function between(min, max) {
  return (n) => n >= min && n <= max;
}

function not(predicate) {
  return (x) => !predicate(x);
}

const prices = [5, 12, 30, 18, 50];
console.log(prices.filter(between(10, 20)), prices.filter(not(between(10, 20))), prices.some(between(40, 60)));

module.exports = { between, not };
[ 12, 18 ] [ 5, 30, 50 ] true

prices.filter(not(between(10, 20))) נקרא כמעט כמו משפט באנגלית. כאן — בניגוד ל־P06-E65 — הסוגריים אחרי between נכונים: between(10, 20) מחזירה פונקציה, ואותה מעבירים ל־filter.

⚠️ טעויות נפוצות
  • return n >= min && n <= max; בתוך between — אין n, ו־between צריכה להחזיר פונקציה, לא בוליאני.
