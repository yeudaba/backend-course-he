P06-E45 · שינוי המשתנה של for...of 🧠 הבנה רמה 1

💡 רמז 1

בכל סיבוב של for...of, p מקבל עותק של הערך — כמו פרמטר של פונקציה (P05-E38).

💡 רמז 2

בלולאה השנייה יש הצבה לתוך תא של המערך: prices[i] = ....

✅ פתרון
const prices = [10, 20, 30];
for (let p of prices) {
  p = p * 2;
}
console.log(prices);

for (let i = 0; i < prices.length; i++) {
  prices[i] = prices[i] * 2;
}
console.log(prices);
[ 10, 20, 30 ]
[ 20, 40, 60 ]

הלולאה הראשונה שינתה רק את המשתנה p, שנוצר מחדש בכל סיבוב — המערך לא נגוע. כדי לשנות את המערך עצמו צריך לכתוב לתא שלו, ולשם כך צריך את האינדקס. עם const p הלולאה הראשונה הייתה זורקת TypeError: Assignment to constant variable. כבר בסיבוב הראשון — וזה דווקא טוב: השגיאה מגלה שהקוד לא עושה מה שחשבת. לכן בשיעור כותבים const.

(בשיעור 3 תראה דרך שלישית — map, שמחזירה מערך חדש בלי לגעת במקור.)

⚠️ טעויות נפוצות
  • לחשוב ש־p = p * 2 בתוך for...of "מעדכן את האיבר". הוא מעדכן עותק.

P06-E46 · split — מקרי קצה 🧠 הבנה רמה 1

💡 רמז 1

split חותך בכל מקום שבו מופיע המפריד. בין שני חיתוכים צמודים (או בין חיתוך לקצה) נוצרת מחרוזת ריקה.

💡 רמז 2

אם המפריד לא מופיע בכלל — מקבלים מערך עם איבר אחד: כל המחרוזת. גם כשהמחרוזת ריקה.

✅ פתרון
console.log("a,b,c".split(","), "a,b,c".split(",").length);
console.log("a,b,".split(","));
console.log("abc".split(","));
console.log("".split(","), "".split(",").length);
console.log("2026-11-11".split("-")[1]);
console.log("שלום עולם".split(""));
[ 'a', 'b', 'c' ] 3
[ 'a', 'b', '' ]
[ 'abc' ]
[ '' ] 1
11
[
  'ש', 'ל', 'ו',
  'ם', ' ', 'ע',
  'ו', 'ל', 'ם'
]

המלכודת: "".split(",") הוא [""] — מערך עם איבר אחד (מחרוזת ריקה), ולכן length הוא 1, לא 0. שדה ריק ייספר כ"פריט אחד". התיקון: guard לפני (if (text.trim() === "") { return 0; }), או לזרוק את הריקים — בשיעור 3 עם filter.

גם פסיק בסוף ("a,b,") מייצר מחרוזת ריקה בסוף המערך. ו־split("") מפרק לתווים — גם בעברית, וגם הרווח הוא תו.

⚠️ טעויות נפוצות
  • text.split(",").length בתור "מספר הפריטים" — לשדה ריק מחזיר 1.

P06-E47 · join — מה יוצא? 🧠 הבנה רמה 1

💡 רמז 1

join שם את המפריד בין האיברים — לא לפני הראשון ולא אחרי האחרון.

💡 רמז 2

בלי ארגומנט, המפריד הוא פסיק. ו־template literal הופך מערך למחרוזת בדיוק כמו join() בלי ארגומנט.

✅ פתרון

abc

מערך ריק ← מחרוזת ריקה; איבר אחד ← רק הוא, בלי מפריד. זה בדיוק מה שהיית צריך לכתוב ביד בפרק 4 (P04-E21: "בלי פסיק בסוף") — join עושה את זה בשבילך. השורה האחרונה מסבירה את הפלט בתור: עומר,נועה מהשיעור הקודם.

⚠️ טעויות נפוצות
  • לבנות מחרוזת בלולאה עם += ", " ואז לחתוך את הפסיק האחרון — join עושה את זה בלי טעויות.

P06-E48 · מקסימום שמתחיל מאפס 🧠 הבנה רמה 2

💡 רמז 1

מה קורה ב־maxTemp כשכל הטמפרטורות מתחת לאפס? איזה ערך אף פעם לא "מנצח" את 0?

💡 רמז 2

ב־printAll: מה האינדקס האחרון שהלולאה מבקרת בו? האם יש תא כזה?

✅ פתרון
function maxTemp(temps) {
  let max = 0;
  for (const t of temps) {
    if (t > max) {
      max = t;
    }
  }
  return max;
}

function printAll(names) {
  const lines = [];
  for (let i = 0; i <= names.length; i++) {
    lines.push(`${i + 1}. ${names[i]}`);
  }
  return lines;
}

console.log(maxTemp([12, 30, 25]), maxTemp([-5, -2, -9]));
console.log(printAll(["דנה", "עומר"]));
30 0
[ '1. דנה', '2. עומר', '3. undefined' ]

maxTemp([-5, -2, -9]) מחזיר 0 — טמפרטורה שלא הייתה בכלל. התיקון (כמו בשיעור): let max = temps[0]; — מתחילים מאיבר אמיתי.

printAll מוסיף שורה שלישית עם undefined: התנאי i <= names.length מבקר גם באינדקס 2, שלא קיים. התיקון: i < names.length. (וב־for...of הבאג הזה בכלל לא יכול לקרות.)

⚠️ טעויות נפוצות
  • לבדוק את maxTemp רק עם מספרים חיוביים — והבאג לא מתגלה. מקרי קצה: ריק, שליליים, איבר אחד.

P06-E09 · פירוק וחיבור טקסט 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

parseNumbers: split(","), ואז לולאה שמוסיפה Number(part.trim()) למערך תוצאה.

💡 רמז 2

humanList: כל האיברים חוץ מהאחרון (slice(0, -1)) מחוברים ב־", ", ואז " ו־" והאחרון.

✅ פתרון
// P06-E09: split ו־join
function parseNumbers(text) {
  if (text.trim() === "") {
    return [];
  }
  const result = [];
  for (const part of text.split(",")) {
    result.push(Number(part.trim()));
  }
  return result;
}

function humanList(items) {
  if (items.length === 0) {
    return "";
  }
  if (items.length === 1) {
    return items[0];
  }
  return `${items.slice(0, -1).join(", ")} ו־${items[items.length - 1]}`;
}

console.log(parseNumbers("10, 20,30"));
console.log(humanList(["קפה", "תה", "מים"]));

module.exports = { parseNumbers, humanList };
[ 10, 20, 30 ]
קפה, תה ו־מים
⚠️ טעויות נפוצות
  • "".split(",") מחזיר [""], ו־Number("") הוא 0 — לכן ה־guard clause.

P06-E13 · ספירה וייחודיים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

unique: מערך תוצאה, ולכל איבר — if (!result.includes(x)) result.push(x).

💡 רמז 2

mostFrequent: עבור על unique(arr), ולכל ערך חשב countOccurrences — מקסימום.

✅ פתרון
// P06-E13: ספירה וערכים ייחודיים
function countOccurrences(arr, value) {
  let count = 0;
  for (const x of arr) {
    if (x === value) {
      count++;
    }
  }
  return count;
}

function unique(arr) {
  const result = [];
  for (const x of arr) {
    if (!result.includes(x)) {
      result.push(x);
    }
  }
  return result;
}

function mostFrequent(arr) {
  let best;
  let bestCount = 0;
  for (const value of unique(arr)) {
    const count = countOccurrences(arr, value);
    if (count > bestCount) {
      best = value;
      bestCount = count;
    }
  }
  return best;
}

console.log(unique([3, 1, 3, 2, 1]), mostFrequent(["a", "b", "b", "a", "b"]));

module.exports = { countOccurrences, unique, mostFrequent };
[ 3, 1, 2 ] b

💡 mostFrequent כאן היא לולאה בתוך לולאה (O(n²)) — ראה פרק 4, שיעור 4. בפרק 7 נכתוב אותה עם Map במעבר אחד. ול־unique יש קיצור: [...new Set(arr)] — גם הוא בפרק 7.

⚠️ טעויות נפוצות
  • >= במקום > במקסימום — בתיקו ינצח האחרון.

P06-E20 · סיכום שגוי 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

בדוק: את גבולות הלולאה (האם האיבר האחרון נספר?), את ערך ההתחלה של המקסימום, ואת המקרה הריק.

💡 רמז 2

אפשר להחליף את כל הלולאה ב־for...of — וכך באג הגבולות נעלם מעצמו.

✅ פתרון
// P06-E20: סיכום מכירות — מתוקן
function summarize(sales) {
  if (sales.length === 0) {
    return "אין מכירות";
  }
  let total = 0;
  let best = sales[0];
  for (const s of sales) {
    total += s;
    if (s > best) {
      best = s;
    }
  }
  return `${sales.length} מכירות, סה״כ ${total}, הגדולה ביותר ${best}`;
}

console.log(summarize([100, 250, 40]));
console.log(summarize([-20, -5]));

module.exports = { summarize };
3 מכירות, סה״כ 390, הגדולה ביותר 250
2 מכירות, סה״כ -25, הגדולה ביותר -5

(1) i < sales.length - 1 דילג על האחרון. (2) best = 0 — עם החזרות בלבד התוצאה 0. (3) רשימה ריקה החזירה "0 מכירות, הגדולה ביותר 0" — הבודק דורש הודעה מפורשת.

⚠️ טעויות נפוצות
  • לתקן רק מה שרואים בדוגמה הראשונה. הבודק בודק גם קלטים "רעים".

function numberedList(items) {

P06-E52 · ראשי תיבות 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

split(" "), ואז for...of על המילים. מחרוזת ריקה ברשימה (מרווח כפול) — מדלגים עליה.

💡 רמז 2

if (word === "") { continue; } ואז result += word[0].toUpperCase();

✅ פתרון

function acronym(phrase) {
  let result = "";
  for (const word of phrase.split(" ")) {
    if (word === "") {
      continue;
    }
    result += word[0].toUpperCase();
  }
  return result;
}

console.log(acronym("Hyper Text Markup Language"), acronym("  as soon   as possible "));

module.exports = { acronym };
HTML ASAP
⚠️ טעויות נפוצות
  • לא לדלג על מילים ריקות — ""[0] הוא undefined, ו־undefined.toUpperCase() זורק TypeError.

P06-E53 · המילה הארוכה ביותר 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

דפוס "הכי גדול" מהשיעור — אבל משווים length, ושומרים את המילה. מתחילים מ־"" (אורך 0) — כאן זה בטוח, כי אין מילים באורך שלילי.

💡 רמז 2

if (word.length > best.length) { best = word; } — למה > ולא >=?

✅ פתרון
06-arrays/starter/P06-E53.js 
function longestWord(sentence) {
  let best = "";
  for (const word of sentence.split(" ")) {
    if (word.length > best.length) {
      best = word;
    }
  }
  return best;
}

console.log(longestWord("I love backend development"), longestWord("cat dog"));

module.exports = { longestWord };
development cat

מילים ריקות (מרווח כפול) לא מפריעות: האורך שלהן 0, והן אף פעם לא "מנצחות". ו־> (ולא >=) שומר את הראשונה בתיקו.

⚠️ טעויות נפוצות
  • >= — בתיקו מקבלים את האחרונה.
  • לשמור את האורך בלבד (best = word.length) — ואז אין מה להחזיר.

P06-E54 · return בתוך for...of 🧠 הבנה רמה 2

💡 רמז 1

ב־firstNegativeBroken: כמה סיבובים הלולאה רצה לכל היותר?

💡 רמז 2

ומה מחזירה פונקציה שהלולאה שלה לא רצה אף פעם, ואין אחריה return?

✅ פתרון
function firstNegative(nums) {
  for (const n of nums) {
    if (n < 0) {
      return n;
    }
  }
  return null;
}

function firstNegativeBroken(nums) {
  for (const n of nums) {
    if (n < 0) {
      return n;
    } else {
      return null;
    }
  }
}

console.log(firstNegative([4, -2, -7]), firstNegative([1, 2]), firstNegative([]));
console.log(firstNegativeBroken([4, -2, -7]), firstNegativeBroken([-1, 5]), firstNegativeBroken([]));

function collatz(n) {
  const steps = [n];
  while (n !== 1) {
    n = n % 2 === 0 ? n / 2 : n * 3 + 1;
    steps.push(n);
  }
  return steps;
}

ה־n הראשון נכנס למערך עוד לפני הלולאה, ולכן collatz(1) מחזירה [1] בלי להיכנס ללולאה בכלל. בתוך הלולאה, הסדר הוא קודם לחשב ואז push. כך ה־1 האחרון נכנס, והתנאי עוצר מיד אחריו.

אפשר לשנות את n, כי הוא פרמטר מקומי. מי שקרא לפונקציה לא מושפע, כי מספרים מועברים כעותק (בפרק 7 תראה שעם מערכים ואובייקטים זה שונה).

  • n % 2 === 0 ? n / 2 : n * 3 + 1 בלי n = — n לא משתנה, והלולאה אינסופית.

function capitalize(word) {
  return word[0].toUpperCase() + word.slice(1).toLowerCase();
}

function capitalizeWords(text) {
  const words = [];
  for (const word of text.split(" ")) {
    if (word !== "") {
      words.push(capitalize(word));
    }
  }
  return words.join(" ");
}

console.log(capitalizeWords("  learn   NODE js "));

module.exports = { capitalize, capitalizeWords };

function longestStreak(results, kind = "W") {
  let current = 0;
  let best = 0;
  for (const r of results) {
    if (r === kind) {
      current++;
      if (current > best) {
        best = current;
      }
    } else {
      current = 0;
    }
  }
  return best;
}

console.log(longestStreak(["W", "W", "L", "W", "W", "W", "D"]), longestStreak(["W", "L", "L", "L", "W"], "L"));

module.exports = { longestStreak };
