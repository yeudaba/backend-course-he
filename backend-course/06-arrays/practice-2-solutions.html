P06-E08 · סכום וממוצע 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

צובר שמתחיל ב־0.

💡 רמז 2

ב־average: guard clause למערך ריק, ואז sum(nums) / nums.length.

✅ פתרון
// P06-E08: סכום וממוצע
function sum(nums) {
  let total = 0;
  for (const n of nums) {
    total += n;
  }
  return total;
}

function average(nums) {
  if (nums.length === 0) {
    return 0;
  }
  return sum(nums) / nums.length;
}

console.log(sum([1, 2, 3]), average([90, 80, 70]), average([]));

module.exports = { sum, average };
6 80 0
⚠️ טעויות נפוצות
  • מערך ריק: 0 / 0 הוא NaN.

P06-E09 · פירוק וחיבור טקסט 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

parseNumbers: split(","), ואז לולאה שמוסיפה Number(part.trim()) למערך תוצאה.

💡 רמז 2

humanList: כל האיברים חוץ מהאחרון (slice(0, -1)) מחוברים ב־", ", ואז " ו־" והאחרון.

✅ פתרון
// P06-E09: split ו־join
function parseNumbers(text) {
  if (text.trim() === "") {
    return [];
  }
  const result = [];
  for (const part of text.split(",")) {
    result.push(Number(part.trim()));
  }
  return result;
}

function humanList(items) {
  if (items.length === 0) {
    return "";
  }
  if (items.length === 1) {
    return items[0];
  }
  return `${items.slice(0, -1).join(", ")} ו־${items[items.length - 1]}`;
}

console.log(parseNumbers("10, 20,30"));
console.log(humanList(["קפה", "תה", "מים"]));

module.exports = { parseNumbers, humanList };
[ 10, 20, 30 ]
קפה, תה ו־מים
⚠️ טעויות נפוצות
  • "".split(",") מחזיר [""], ו־Number("") הוא 0 — לכן ה־guard clause.

P06-E13 · ספירה וייחודיים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

unique: מערך תוצאה, ולכל איבר — if (!result.includes(x)) result.push(x).

💡 רמז 2

mostFrequent: עבור על unique(arr), ולכל ערך חשב countOccurrences — מקסימום.

✅ פתרון
// P06-E13: ספירה וערכים ייחודיים
function countOccurrences(arr, value) {
  let count = 0;
  for (const x of arr) {
    if (x === value) {
      count++;
    }
  }
  return count;
}

function unique(arr) {
  const result = [];
  for (const x of arr) {
    if (!result.includes(x)) {
      result.push(x);
    }
  }
  return result;
}

function mostFrequent(arr) {
  let best;
  let bestCount = 0;
  for (const value of unique(arr)) {
    const count = countOccurrences(arr, value);
    if (count > bestCount) {
      best = value;
      bestCount = count;
    }
  }
  return best;
}

console.log(unique([3, 1, 3, 2, 1]), mostFrequent(["a", "b", "b", "a", "b"]));

module.exports = { countOccurrences, unique, mostFrequent };
[ 3, 1, 2 ] b

💡 mostFrequent כאן היא לולאה בתוך לולאה (O(n²)) — ראה פרק 4, שיעור 4. בפרק 7 נכתוב אותה עם Map במעבר אחד. ול־unique יש קיצור: [...new Set(arr)] — גם הוא בפרק 7.

⚠️ טעויות נפוצות
  • >= במקום > במקסימום — בתיקו ינצח האחרון.

P06-E20 · סיכום שגוי 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

בדוק: את גבולות הלולאה (האם האיבר האחרון נספר?), את ערך ההתחלה של המקסימום, ואת המקרה הריק.

💡 רמז 2

אפשר להחליף את כל הלולאה ב־for...of — וכך באג הגבולות נעלם מעצמו.

✅ פתרון
// P06-E20: סיכום מכירות — מתוקן
function summarize(sales) {
  if (sales.length === 0) {
    return "אין מכירות";
  }
  let total = 0;
  let best = sales[0];
  for (const s of sales) {
    total += s;
    if (s > best) {
      best = s;
    }
  }
  return `${sales.length} מכירות, סה״כ ${total}, הגדולה ביותר ${best}`;
}

console.log(summarize([100, 250, 40]));
console.log(summarize([-20, -5]));

module.exports = { summarize };
3 מכירות, סה״כ 390, הגדולה ביותר 250
2 מכירות, סה״כ -25, הגדולה ביותר -5

(1) i < sales.length - 1 דילג על האחרון. (2) best = 0 — עם החזרות בלבד התוצאה 0. (3) רשימה ריקה החזירה "0 מכירות, הגדולה ביותר 0" — הבודק דורש הודעה מפורשת.

⚠️ טעויות נפוצות
  • לתקן רק מה שרואים בדוגמה הראשונה. הבודק בודק גם קלטים "רעים".

P06-E27 · סדרת קולץ 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

אתה לא יודע מראש כמה צעדים יהיו — רק מתי לעצור. זה while, לא for.

💡 רמז 2

const steps = [n]; while (n !== 1) { n = ...; steps.push(n); } return steps;

✅ פתרון
// P06-E27: סדרת קולץ
function collatz(n) {
  const steps = [n];
  while (n !== 1) {
    n = n % 2 === 0 ? n / 2 : n * 3 + 1;
    steps.push(n);
  }
  return steps;
}

console.log(collatz(6).join(" → "));
console.log(collatz(27).length);

module.exports = { collatz };
6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1
112

ה־n הראשון נכנס למערך עוד לפני הלולאה, ולכן collatz(1) מחזירה [1] בלי להיכנס ללולאה בכלל. בתוך הלולאה, הסדר הוא קודם לחשב ואז push. כך ה־1 האחרון נכנס, והתנאי עוצר מיד אחריו.

אפשר לשנות את n, כי הוא פרמטר מקומי. מי שקרא לפונקציה לא מושפע, כי מספרים מועברים כעותק (בפרק 7 תראה שעם מערכים ואובייקטים זה שונה).

⚠️ טעויות נפוצות
  • push לפני החישוב — ה־1 בסוף חסר, וה־n הראשון מופיע פעמיים.
  • n % 2 === 0 ? n / 2 : n * 3 + 1 בלי n = — n לא משתנה, והלולאה אינסופית.
