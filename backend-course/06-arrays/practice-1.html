P06-E38 · בטל ובצע שוב (undo/redo) 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 15 דק׳ידע נדרש: שיעור 1

עורך טקסט שומר שתי מחסניות: history (הפעולות שבוצעו) ו־redoStack (פעולות שבוטלו). כתוב שלוש פונקציות שמשנות את המערכים שקיבלו:

  • doAction(history, redoStack, action) — מוסיפה את הפעולה ל־history, ומרוקנת את redoStack (אחרי פעולה חדשה אי אפשר "לבצע שוב" דברים ישנים).
  • undo(history, redoStack) — מוציאה את הפעולה האחרונה מ־history, מעבירה אותה ל־redoStack ומחזירה אותה. אין מה לבטל ← null.
  • redo(history, redoStack) — ההפך: מ־redoStack חזרה ל־history, ומחזירה אותה. אין ← null.
const history = [];
const redoStack = [];
doAction(history, redoStack, "הקלד A");
doAction(history, redoStack, "הקלד B");
undo(history, redoStack);  // "הקלד B"
redo(history, redoStack);  // "הקלד B"
undo(history, redoStack);  // "הקלד B"
doAction(history, redoStack, "הקלד C"); // redoStack מתרוקן
redo(history, redoStack);  // null

📄 כותבים בקובץ 06-arrays/starter/P06-E38.js (יש בו רק הערה). בסוף הקובץ: module.exports = { doAction, undo, redo };

P06-E40 · while שמרוקן תור

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 1

בלי להריץ — מה יודפס, ובאיזה סדר?

const queue = ["דנה", "עומר", "נועה"];

  const next = queue.shift();
  served++;
  console.log(`${served}: ${next} (נשארו ${queue.length})`);
  if (next === "עומר") {
    queue.push("עומר שוב");
  }
}
console.log(served, queue);

ואז: מה היה קורה אם במקום "עומר שוב" היינו מכניסים בחזרה את next עצמו?

P06-E41 · פונקציה שמקבלת מערך

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 5, שיעור 1

function addOne(n) {
  n = n + 1;
  return n;
}

  list.push("חדש");
  return list.length;
}
function replaceList(list) {
  list = ["אחר"];
  return list.length;
}

P06-E43 · לשרת את התור 🤖

P06-E44 · היסטוריית גלישה מוגבלת 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 15 דק׳ידע נדרש: פרק 3, פרק 5, שיעור 1

כתוב visit(history, page, max = 5) שמעדכנת את היסטוריית הגלישה (מערך, הישן בהתחלה) ומחזירה אותה:

  1. דף ריק ("" או רק רווחים) ← לא משנים כלום.
  2. אם הדף הוא כבר האחרון בהיסטוריה (רענון) ← לא מוסיפים שוב.
  3. אחרת — מוסיפים לסוף (אחרי trim).
  4. אם עכשיו יש יותר מ־max דפים — מוחקים את הישן ביותר.
const h = ["/home", "/products"];
visit(h, "/products");        // ["/home", "/products"] — רענון
visit(h, " /cart ");          // ["/home", "/products", "/cart"]
visit(h, "/home", 3);         // ["/products", "/cart", "/home"] — ה־/home הישן נמחק
