P06-E01 · מה יש במערך?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

עקוב אחרי המערך שורה אחר שורה ונבא את הפלט:

const list = ["חלב", "לחם"];
list.push("ביצים");
list.unshift("קפה");
const a = list.pop();
const b = list.shift();
list[1] = "לחם מלא";
console.log(list, list.length, a, b);
console.log(list.includes("חלב"), list.indexOf("ביצים"));

P06-E26 · range — מערך של מספרים 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

השלם את range(start, end, step = 1), שמחזירה מערך חדש של מספרים מ־start עד end, בלי end עצמו, בקפיצות של step:

range(1, 5);      // [1, 2, 3, 4]
range(0, 10, 3);  // [0, 3, 6, 9]
range(5, 5);      // []
range(0, 5, 0);   // [] — צעד שאינו חיובי: מחזירים מערך ריק (אחרת — לולאה אינסופית)

📄 כותבים בקובץ 06-arrays/starter/P06-E26.js (החתימה כבר כתובה), מריצים ובודקים:

% node 06-arrays/starter/P06-E26.js
% npm run check P06-E26
