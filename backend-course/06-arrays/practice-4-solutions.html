P06-E05 · משנה או לא? 🧠 הבנה רמה 1

💡 רמז 1

slice, spread, map — לא משנים. sort, splice — משנים.

💡 רמז 2

אחרי ה־sort היורד: [3, 2, 1]; אחרי splice: האיבר הראשון יצא.

✅ פתרון

const a = data.slice(0, 2);
const b = [...data].sort((x, y) => x - y);
console.log(data);
const c = data.map((x) => x * 2);
const d = data.sort((x, y) => y - x);
console.log(data, d === data);
const e = data.splice(0, 1);

P06-E71 · מעקב אחרי reduce 🧠 הבנה רמה 1

💡 רמז 1

הסיבוב הראשון מקבל את ערך ההתחלה כצובר, ואת האיבר הראשון.

💡 רמז 2

ראשונה: (1, 3) ← 7, (7, 8) ← 23... במערך ריק — ה־callback לא רץ בכלל, ו־reduce מחזיר את ערך ההתחלה.

✅ פתרון

console.log(nums.reduce((acc, n) => acc + n * 2, 1));
console.log(nums.reduce((acc, n) => (n > acc ? n : acc), 0));
console.log(nums.reduce((acc, n) => acc + n + ",", ""));
console.log(nums.reduce((acc, n) => acc * n, 1), [].reduce((acc, n) => acc * n, 1));
27
8
3,8,2,
48 1

ראשונה: (1, 3) ← 7, (7, 8) ← 23, (23, 2) ← 27 — ערך ההתחלה 1 נספר פעם אחת. שלישית: הצובר הוא מחרוזת, ולכן כל + הוא שרשור, עם פסיק מיותר בסוף (join היה עדיף). רביעית: מכפלה מתחילה מ־1 (לא מ־0!), ובמערך ריק התוצאה היא ערך ההתחלה.

⚠️ טעויות נפוצות
  • ערך התחלה 0 למכפלה — התוצאה תמיד 0.
  • לשכוח שערך ההתחלה הוא חלק מהתוצאה — reduce(..., 1) לסכום מוסיף 1.

P06-E73 · comparator — מה יוצא? 🧠 הבנה רמה 2

💡 רמז 1

בלי פונקציה — השוואה של מחרוזות, תו אחר תו. ובמחרוזות, כל האותיות הגדולות באות לפני כל הקטנות.

💡 רמז 2

בשורה האחרונה יש שתי מילים באורך 2. sort של JavaScript יציב: איברים "שווים" שומרים על הסדר המקורי שלהם.

✅ פתרון

console.log(["banana", "apple", "Cherry"].sort());

console.log(["bb", "a", "ccc", "dd"].sort((a, b) => a.length - b.length));
[ 1, 10, 100, 25, 9 ]
[ 1, 9, 10, 25, 100 ]
[ 100, 25, 10, 9, 1 ]
[ 'Cherry', 'apple', 'banana' ]

מיון ברירת מחדל: "100" לפני "25" לפני "9" — כי משווים תו ראשון. במחרוזות: "Cherry" קפץ לראש הרשימה רק בגלל ה־C הגדולה; localeCompare ממיין כמו מילון. בשורה האחרונה, "bb" נשאר לפני "dd" — כמו במערך המקורי.

⚠️ טעויות נפוצות
  • (a, b) => a > b כ־comparator — מחזיר בוליאני ולא מספר שלילי/חיובי. התוצאה לא אמינה. תמיד a - b או localeCompare.

P06-E74 · slice או splice? 🧠 הבנה רמה 2

💡 רמז 1

slice(start, end) — עותק, בלי end, המקור לא משתנה. splice(start, count, ...items) — משנה את המקור, ומחזיר את מה שנמחק.

P06-E17 · סטטיסטיקה עם reduce 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

min: nums.reduce((m, n) => (n < m ? n : m), nums[0]).

💡 רמז 2

או: Math.min(...nums) — גם תקין, אבל התרגיל ביקש reduce.

✅ פתרון
// P06-E17: min, max, average עם reduce
function stats(nums) {
  if (nums.length === 0) {
    return null;
  }
  const min = nums.reduce((m, n) => (n < m ? n : m), nums[0]);
  const max = nums.reduce((m, n) => (n > m ? n : m), nums[0]);
  const total = nums.reduce((s, n) => s + n, 0);
  const average = Math.round((total / nums.length) * 100) / 100;
  return [min, max, average];
}

console.log(stats([4, -2, 9, 1]), stats([]));

module.exports = { stats };
[ -2, 9, 3 ] null
⚠️ טעויות נפוצות
  • ערך התחלה 0 ל־min/max — שגוי כשכל המספרים חיוביים (min) או שליליים (max).

P06-E18 · הכי גבוהים וחציון 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

topN: עותק ממוין יורד ← slice(0, n).

💡 רמז 2

median: const mid = Math.floor(sorted.length / 2); באורך זוגי — (sorted[mid - 1] + sorted[mid]) / 2.

✅ פתרון
// P06-E18: topN וחציון
function topN(nums, n) {
  return [...nums].sort((a, b) => b - a).slice(0, n);
}

function median(nums) {
  if (nums.length === 0) {
    return null;
  }
  const sorted = [...nums].sort((a, b) => a - b);
  const mid = Math.floor(sorted.length / 2);
  if (sorted.length % 2 === 1) {
    return sorted[mid];
  }
  return (sorted[mid - 1] + sorted[mid]) / 2;
}

console.log(topN([5, 100, 20, 7], 2), median([5, 1, 9]), median([4, 1, 3, 10]));

module.exports = { topN, median };
[ 100, 20 ] 5 3.5

💼 חציון חשוב יותר מממוצע במדידת זמני תגובה של שרת: בקשה אחת איטית מאוד "מושכת" את הממוצע, אבל לא את החציון (פרק 28 — p50, p95).

⚠️ טעויות נפוצות

P06-E19 · עמודים 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

chunk: לולאה עם i += size, ובכל סיבוב arr.slice(i, i + size).

💡 רמז 2

getPage: arr.slice((page - 1) * pageSize, page * pageSize) — ו־page < 1 ← [].

✅ פתרון
// P06-E19: חלוקה לעמודים
function chunk(arr, size) {
  const result = [];
  for (let i = 0; i < arr.length; i += size) {
    result.push(arr.slice(i, i + size));
  }
  return result;
}

function getPage(arr, page, pageSize) {
  if (page < 1) {
    return [];
  }
  return arr.slice((page - 1) * pageSize, page * pageSize);
}

function totalPages(count, pageSize) {
  return Math.max(1, Math.ceil(count / pageSize));
}

console.log(chunk([1, 2, 3, 4, 5], 2), getPage(["a", "b", "c", "d", "e"], 2, 2), totalPages(0, 10));

module.exports = { chunk, getPage, totalPages };
[ [ 1, 2 ], [ 3, 4 ], [ 5 ] ] [ 'c', 'd' ] 1

מערך של מערכים — chunk מחזיר אחד כזה. ב־getPage, עמוד אחרי הסוף "עובד לבד": slice מחוץ לגבולות מחזיר [].

⚠️ טעויות נפוצות
  • getPage עם page * pageSize כהתחלה — עמוד 1 יתחיל מהעמוד השני.

P06-E77 · להכניס ולהזיז בלי לשנות 🤖 💻 כתיבת קוד 🤖 רמה 3

function insertAt(arr, index, item) {
  return [...arr.slice(0, index), item, ...arr.slice(index)];
}

function moveItem(arr, from, to) {
  const item = arr[from];
  const without = [...arr.slice(0, from), ...arr.slice(from + 1)];
  return insertAt(without, to, item);
}

P06-E78 · reduce או לולאה? ביקורת קוד 🧠 הבנה רמה 2

💡 רמז 1

הצובר הוא מערך של שלושה מספרים. רק הזמנות חיוביות משנות אותו.

💡 רמז 2

a[0] — סכום, a[1] — ספירה, a[2] — מקסימום.

✅ פתרון
function summarizeOrders(orders) {
  let total = 0;
  let count = 0;
  let biggest = 0;
  for (const amount of orders) {
    if (amount <= 0) {
      continue;
    }
    total += amount;
    count++;
    if (amount > biggest) {
      biggest = amount;
    }
  }
  return [total, count, biggest];
}

const orders = [120, -5, 300, 0, 80];
const r = orders.reduce((a, o) => (o > 0 ? [a[0] + o, a[1] + 1, o > a[2] ? o : a[2]] : a), [0, 0, 0]);
console.log(r, summarizeOrders(orders));

P06-E79 · sort בתוך פונקציה 🧠 הבנה רמה 2

💡 רמז 1

מה עושה sort למערך שהוא נקרא עליו? ו־scores ו־exam — אותו מערך?

💡 רמז 2

slice מחזיר עותק — אבל רק אחרי שה־sort כבר שינה.

✅ פתרון
function topTwo(scores) {
  return scores.sort((a, b) => b - a).slice(0, 2);
}
function topTwoSafe(scores) {
  return [...scores].sort((a, b) => b - a).slice(0, 2);
}

P06-E24 · אתגר: דוח מכירות שבועי 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 2

function bestDay(days, revenue) {
  const index = revenue.indexOf(Math.max(...revenue));
  return days[index];
}

function averageOrderValue(orders, revenue) {
  const totalOrders = sum(orders);
  if (totalOrders === 0) {
    return 0;
  }
  return Math.round((sum(revenue) / totalOrders) * 100) / 100;
}

function daysAbove(days, revenue, threshold) {
  return days.filter((_, i) => revenue[i] > threshold);
}

function reportLines(days, orders, revenue) {
  const lines = days.map((d, i) => `${d}: ${orders[i]} הזמנות, ${money(revenue[i])}`);
  lines.push(`סה״כ: ${sum(orders)} הזמנות, ${money(sum(revenue))}`);
  return lines;
}

P06-E25 · אתגר: שאלות ראיון — two sum ומיזוג 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

twoSum: לולאה מקוננת, כש־j מתחיל מ־i + 1.

💡 רמז 2

mergeSorted: let i = 0, j = 0; ו־while (i < a.length && j < b.length); אחרי הלולאה — מוסיפים את מה שנשאר מאחד מהם.

✅ פתרון
// P06-E25: twoSum ו־mergeSorted
function twoSum(nums, target) {
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[i] + nums[j] === target) {
        return [i, j];
      }
    }
  }
  return null;
}

function mergeSorted(a, b) {
  const result = [];
  let i = 0;
  let j = 0;
  while (i < a.length && j < b.length) {
    if (a[i] <= b[j]) {
      result.push(a[i]);
      i++;
    } else {
      result.push(b[j]);
      j++;
    }
  }
  return [...result, ...a.slice(i), ...b.slice(j)];
}

console.log(twoSum([2, 7, 11, 15], 9), twoSum([1, 2], 10));
console.log(mergeSorted([1, 4, 9], [2, 3, 10, 12]).join(", "));

module.exports = { twoSum, mergeSorted };

צעדים: twoSum — עד כחצי מיליון השוואות (לולאה מקוננת, O(n²)). mergeSorted — לכל היותר 2,000 (כל איבר נלקח פעם אחת, O(n)). בפרק 7 נפתור את twoSum במעבר אחד עם Map — זה מה שהמראיין מחכה לו אחרי הפתרון הראשון.

⚠️ טעויות נפוצות
  • twoSum עם j שמתחיל מ־0 — עלול להחזיר [i, i] (אותו איבר פעמיים).

P06-E28 · מחירון עם נקודות 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

פונקציית עזר קטנה line(label, amount) שבונה שורה אחת. את המחירים עוברים עם names.map((name, i) => line(name, prices[i])) — הפרמטר השני של map הוא האינדקס.

💡 רמז 2

החיתוך: label.length > 16 ? label.slice(0, 15) + "…" : label. הסכום: prices.reduce((sum, p) => sum + p, 0). ובסוף: [...rows, line("TOTAL", total)].

✅ פתרון
// P06-E28: מחירון עם נקודות
function line(label, amount) {
  const name = label.length > 16 ? label.slice(0, 15) + "…" : label;
  return name.padEnd(16, ".") + amount.toFixed(2).padStart(8, ".");
}

function priceList(names, prices) {
  const rows = names.map((name, i) => line(name, prices[i]));
  const total = prices.reduce((sum, p) => sum + p, 0);
  return [...rows, line("TOTAL", total)];
}

const lines = priceList(["Keyboard", "Mouse", "Mechanical keyboard RGB"], [199, 89.9, 450]);
console.log(lines.join("\n"));
