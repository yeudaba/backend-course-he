🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

מה ידפיס הקוד? לכל שורה — האם data השתנה?

const data = [3, 1, 2];
const a = data.slice(0, 2);
const b = [...data].sort((x, y) => x - y);
console.log(data);
const c = data.map((x) => x * 2);
const d = data.sort((x, y) => y - x);
console.log(data, d === data);
const e = data.splice(0, 1);
console.log(data, e, a, b, c);

P06-E24 · אתגר: דוח מכירות שבועי 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 35 דק׳ידע נדרש: כל הפרק

בקובץ 06-arrays/starter/P06-E24.js מקבלים שלושה מערכים מקבילים של שבוע: days (שמות), orders (מספר הזמנות), revenue (הכנסה בש״ח). השלם:

  • bestDay(days, revenue) — שם היום עם ההכנסה הגבוהה ביותר.
  • averageOrderValue(orders, revenue) — סך ההכנסות חלקי סך ההזמנות, מעוגל ל־2 ספרות; בלי הזמנות ← 0.
  • daysAbove(days, revenue, threshold) — שמות הימים שבהם ההכנסה מעל הסף.
  • reportLines(days, orders, revenue) — מערך שורות טקסט, אחת לכל יום: "ראשון: 12 הזמנות, ₪1,840" (פסיקים באלפים — toLocaleString("en-US") מותר כאן), ובסוף שורת "סה״כ: 70 הזמנות, ₪9,330".

P06-E25 · אתגר: שאלות ראיון — two sum ומיזוג 🤖

💻 כתיבת קוד 🤖רמה 5⏱ 30 דק׳ידע נדרש: כל הפרק

שתי שאלות ראיון קלאסיות. בקובץ 06-arrays/starter/P06-E25.js השלם:

  • twoSum(nums, target) — מחזירה [i, j] (עם i < j) של שני איברים שסכומם target, הזוג הראשון שנמצא; אין ← null. twoSum([2, 7, 11, 15], 9) ← [0, 1].
  • mergeSorted(a, b) — שני מערכים ממוינים ← מערך ממוין אחד, בלי sort: שני מצביעים, כל פעם לוקחים את הקטן מבין השניים.
