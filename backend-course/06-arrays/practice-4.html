P06-E78 · reduce או לולאה? ביקורת קוד

חבר צוות כתב:

const r = orders.reduce(
  (a, o) => (o > 0 ? [a[0] + o, a[1] + 1, o > a[2] ? o : a[2]] : a),

(1) מה r עבור orders = [120, -5, 300, 0, 80]? (2) מה כל אחד משלושת התאים מייצג? (3) כתוב את אותו חישוב עם for...of ושלושה משתנים עם שמות טובים — ובפונקציה עם שם.

🔗 איך זה מתחבר: בפרק 4 כתבת כמה צוברים באותה לולאה; בפרק 5 למדת ששמות טובים ופונקציות קטנות הם מה שהופך קוד לקריא. ה־reduce כאן "חכם" — אבל קשה לקרוא אותו ולמצוא בו באג. כמו שאמר השיעור: כשהלוגיקה מתארכת — לולאה.

P06-E79 · sort בתוך פונקציה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 5, שיעור 4

בלי להריץ — מה יודפס?

function topTwo(scores) {
  return scores.sort((a, b) => b - a).slice(0, 2);
}
function topTwoSafe(scores) {
  return [...scores].sort((a, b) => b - a).slice(0, 2);
}

const exam = [70, 95, 60, 88];
console.log(topTwoSafe(exam), exam);
console.log(topTwo(exam), exam);
console.log(`הסטודנט הראשון ברשימה קיבל ${exam[0]}`);

🔗 איך זה מתחבר: בפרק 5 (P05-E57) הבחנת בין פונקציה טהורה לפונקציה עם תופעת לוואי. topTwo נראית טהורה — היא "רק מחזירה" — אבל sort משנה את המערך שהיא קיבלה, ומשנה את הנתונים של מי שקרא לה (P06-E41).

P06-E80 · שרשרת שלמה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 2, כל הפרק

בלי להריץ — עקוב אחרי המערך בכל שלב של השרשרת, ומה יודפס?

const raw = " 120, 45 ,abc, 300,,80 , 45";
const prices = raw
  .split(",")
  .map((s) => s.trim())
  .filter((s) => s !== "")
  .map(Number)
  .filter((n) => !Number.isNaN(n));
const top = [...prices].sort((a, b) => b - a).slice(0, 3);
const total = top.reduce((sum, p) => sum + p, 0);
console.log(prices);
console.log(top, total);
console.log(`ממוצע: ${(total / top.length).toFixed(2)}`);

🔗 איך זה מתחבר: כל הפרק בשרשרת אחת: split (שיעור 2), map/filter (שיעור 3), עותק + sort + slice + reduce (שיעור 4) — ו־Number, ‏Number.isNaN ו־toFixed מפרק 2. ככה נראה עיבוד קלט אמיתי בשרת.

P06-E24 · אתגר: דוח מכירות שבועי 🤖
