P06-E48 · מקסימום שמתחיל מאפס

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

שתי פונקציות "כמעט נכונות". לכל אחת — מה היא תחזיר על הקלטים, מה הבאג, ומה התיקון?

function maxTemp(temps) {
  let max = 0;
  for (const t of temps) {
    if (t > max) {
      max = t;
    }
  }
  return max;
}

function printAll(names) {
  const lines = [];
  for (let i = 0; i <= names.length; i++) {
    lines.push(`${i + 1}. ${names[i]}`);
  }
  return lines;
}

console.log(maxTemp([12, 30, 25]), maxTemp([-5, -2, -9]));
console.log(printAll(["דנה", "עומר"]));

P06-E54 · return בתוך for...of

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 5, שיעור 2

שתי גרסאות של "מצא את המספר השלילי הראשון". בלי להריץ — מה יודפס?

function firstNegative(nums) {
  for (const n of nums) {
    if (n < 0) {
      return n;
    }
  }
  return null;
}

function firstNegativeBroken(nums) {
  for (const n of nums) {
    if (n < 0) {
      return n;
    } else {
      return null;
    }
  }
}

console.log(firstNegative([4, -2, -7]), firstNegative([1, 2]), firstNegative([]));
console.log(firstNegativeBroken([4, -2, -7]), firstNegativeBroken([-1, 5]), firstNegativeBroken([]));

🔗 איך זה מתחבר: בפרק 5 (P05-E53) ראית ש־return בתוך לולאה עוצר גם את הלולאה וגם את הפונקציה. עם for...of זה אותו דבר — וזה בדיוק מה ש־find תעשה בשבילך בשיעור 3.

P06-E56 · continue ו־break על מערך

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 2

בלי להריץ — מה יודפס?

const orders = [120, 0, 45, -1, 300, 80];
let sum = 0;
let count = 0;
for (const amount of orders) {
  if (amount === 0) {
    continue;
  }
  if (amount < 0) {
    break;
  }
  sum += amount;
  count++;
}
console.log(sum, count);

ואז: נניח ש־-1 מסמן "סוף הנתונים" (כמו בקבצים ישנים). מה היה קורה אם היית מחליף את break ב־continue?

🔗 איך זה מתחבר: continue ו־break מפרק 4 עובדים בדיוק אותו דבר ב־for...of: continue מדלג לאיבר הבא, break יוצא מהלולאה. מתודות כמו map ו־filter (שיעור 3) לא יודעות לעצור באמצע — עוד סיבה שלולאה עדיין שימושית.
