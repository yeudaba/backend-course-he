P06-E04 · איזו מתודה?

לכל משימה, איזו מתודה מתאימה (map / filter / find / some / every / reduce / join)? אין צורך לכתוב קוד.

  1. להפוך מערך של מחירים בשקלים למחירים בדולרים.

  3. לקבל את המשתמש הראשון שהאימייל שלו הוא X.
  4. לחשב את סך כל ההכנסות.
  5. לקבל רק את המוצרים שבמלאי.
  6. לבדוק שכל השדות בטופס מולאו.
  7. להפוך רשימת תגיות לטקסט "node, api".

P06-E60 · find, filter, some — מה חוזר?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 3

שלוש מתודות, אותו תנאי. בלי להריץ — מה יודפס? שים לב לסוג של כל תוצאה.

const stock = [0, 5, 0, 12];
console.log(stock.find((s) => s > 3));
console.log(stock.filter((s) => s > 3));
console.log(stock.some((s) => s > 3));
console.log(stock.findIndex((s) => s > 3));
console.log(stock.find((s) => s > 100), stock.filter((s) => s > 100), stock.some((s) => s > 100));
console.log(stock.find((s) => s === 0), stock.findIndex((s) => s === 0));

ואז: מה הבעיה בקוד if (stock.find((s) => s === 0)) { ... }, שאמור לבדוק "האם יש פריט שאזל"?

P06-E61 · every על עגלה ריקה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 3

הפונקציה מחליטה אם אפשר לבצע הזמנה. בלי להריץ — מה יודפס? מה הבעיה, ואיך מתקנים?

function canCheckout(stock) {
  return stock.every((qty) => qty > 0);
}
function hasProblem(stock) {
  return stock.some((qty) => qty <= 0);
}
console.log(canCheckout([3, 1]), canCheckout([3, 0]), canCheckout([]));
console.log(hasProblem([3, 1]), hasProblem([3, 0]), hasProblem([]));

בלי להריץ — מה יודפס? (שורה אחת כאן זורקת שגיאה — איזו? ענה עליה במילים, והיא לא בהרצה.)

function isEven(n) {
  return n % 2 === 0;
}
const nums = [1, 2, 3, 4];
console.log(nums.filter(isEven));
console.log(nums.filter((n) => isEven(n)));
console.log(nums.map(isEven));
console.log(["10", "10", "10"].map(Number));
console.log(["10", "10", "10"].map(parseInt));

והשורה שלא בהרצה: nums.filter(isEven()).

🔗 איך זה מתחבר: בפרק 5 (P05-E58) ראית שמעבירים את הפונקציה (בלי סוגריים), ולא את התוצאה שלה. המתודות של השיעור מקבלות callback — ולכן כל פונקציה עם שם שכתבת בפרק 5 יכולה להיכנס אליהן ישירות.

P06-E66 · מלולאה למתודה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 4, שיעור 3

כל אחת מהלולאות האלה (מפרק 4) מחליפה מתודה אחת מהשיעור. לכל אחת: איזו מתודה, ואיך תיראה השורה?

// א
const result = [];
for (const p of prices) {
  result.push(p * 1.18);
}

// ב
const result = [];
for (const p of prices) {
  if (p > 100) {
    result.push(p);
  }
}

// ג
let found = undefined;
for (const p of prices) {
  if (p > 100) {
    found = p;
    break;
  }
}

// ד
let ok = true;
for (const p of prices) {
  if (p <= 0) {
    ok = false;
    break;
  }
}

// ה
const result = [];
for (const p of prices) {
  if (p > 100) {
    result.push(p * 0.9);
  }
}

P06-E70 · מפעל לתנאים 🤖

💻 כתיבת קוד 🤖✍️ מאפסרמה 3⏱ 15 דק׳ידע נדרש: פרק 5, שיעור 3

כתוב פונקציות שמחזירות פונקציה (כמו P05-E65), כדי שאפשר יהיה לכתוב filter קריא:

  • between(min, max) — מחזירה פונקציה שמקבלת n ומחזירה האם min <= n <= max.
  • not(predicate) — מחזירה פונקציה שמחזירה את ההפך מ־predicate.
const prices = [5, 12, 30, 18, 50];
prices.filter(between(10, 20));       // [12, 18]
prices.filter(not(between(10, 20)));  // [5, 30, 50]
prices.some(between(40, 60));         // true
