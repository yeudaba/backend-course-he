שיעור 2 — מעבר על מערך, split ו־join

⏱ ~30 דקות

🎯 בשיעור הזה
  • לעבור על מערך עם for...of ועם for רגיל.
  • דפוסי הצבירה מפרק 4 — על מערכים.
  • split ו־join: בין מחרוזת למערך.

1. for...of — הכלי הראשי

const prices = [12, 14, 8];
let total = 0;
for (const price of prices) {
  total += price;
}
console.log(`סה״כ: ${total}`);
סה״כ: 34

בדיוק כמו for...of על מחרוזת מפרק 4 — רק שכל סיבוב מקבל איבר במקום תו. ודפוס הצובר זהה: let total = 0 לפני, += בפנים.

2. for עם אינדקס — כשצריך מיקום

const names = ["אספרסו", "קרואסון", "מים"];
const prices = [12, 14, 8];
for (let i = 0; i < names.length; i++) {
  console.log(`${i + 1}. ${names[i]} — ${prices[i]}`);
}
1. אספרסו — 12
2. קרואסון — 14
3. מים — 8

כאן צריך את i כדי לחבר שני מערכים "מקבילים" ולמספר שורות. (שני מערכים מקבילים הם דפוס שביר — אם אחד מתעדכן והשני לא, הכול משתבש. בפרק 7 נחליף אותם במערך של אובייקטים.)

3. דפוסים מוכרים, על מערכים

const temps = [-2, 5, 11, -6, 3];

let max = temps[0];
let belowZero = 0;
let firstAboveTen = null;
for (const t of temps) {
  if (t > max) {
    max = t;
  }
  if (t < 0) {
    belowZero++;
  }
  if (firstAboveTen === null && t > 10) {
    firstAboveTen = t;
  }
}
console.log(max, belowZero, firstAboveTen);
11 2 11

מקסימום (מתחילים מהאיבר הראשון!), ספירה, וחיפוש ראשון. בשיעור 3 נראה מתודות מובנות שעושות כל אחד מאלה בשורה אחת — אבל חשוב להבין מה הן עושות מתחת.

4. split — מחרוזת למערך

בפרק 4 פירקנו ידנית את "10,20,30". עם split:

const csv = "10,20,30";
const parts = csv.split(",");
console.log(parts);
console.log(typeof parts[0]);

const words = "learn node js".split(" ");
console.log(words, words.length);

const letters = "abc".split("");
console.log(letters);
[ '10', '20', '30' ]
string
[ 'learn', 'node', 'js' ] 3
[ 'a', 'b', 'c' ]

שים לב: האיברים הם מחרוזות — "10" ולא 10. כדי לחשב — צריך להמיר כל אחד (בשיעור 3: map(Number)).

5. join — מערך למחרוזת

const tags = ["node", "backend", "api"];
console.log(tags.join(", "));
console.log(tags.join(" | "));
console.log(tags.join(""));
console.log(["2026", "10", "31"].join("-"));
node, backend, api
node | backend | api
nodebackendapi
2026-10-31
💡 split + join

הצמד הזה פותר המון בעיות טקסט. למשל slug מפרק 2, עכשיו כולל רווחים כפולים: title.trim().toLowerCase().split(" ").filter(...)... — את ה־filter נלמד בשיעור הבא.
