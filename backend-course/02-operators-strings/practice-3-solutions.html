P02-E53 · נבא: Number על טקסטים 🧠 הבנה רמה 1

הכי מסוכנת: Number("") ← 0. אם משתמש לא מילא כמות, השרת "חושב" שהוא הזמין 0, בלי שום שגיאה. NaN לפחות נראה חשוד; 0 נראה כמו ערך אמיתי. גם "1,000" מפתיע — פסיק של אלפים שובר את ההמרה.

⚠️ טעויות נפוצות
  • לצפות ש־Number("12px") ייתן 12. זה מה ש־parseInt עושה, לא Number.

P02-E56 · NaN שעבר את כל הקופה 🧠 הבנה רמה 2

💡 רמז 1

Number("12,90") — פסיק הוא תו "זר". ומה קורה לכל חישוב עם NaN?

💡 רמז 2

מה typeof NaN? זה בדיוק הסוג שציפית לו — ולכן הוא לא חושד.

✅ פתרון
const priceInput = "12,90";
const quantity = 3;
const price = Number(priceInput);
const subtotal = price * quantity;
const total = subtotal + 15;
console.log(`לתשלום: ${total}`);
console.log(typeof total, Number.isNaN(price));
לתשלום: NaN
number true
  1. כמו בפלט.
  2. שורה 3: Number("12,90") הוא NaN. NaN "מדבק" — כל חישוב איתו נותן NaN — אז הוא עבר בשקט דרך הכפל והחיבור.
  3. typeof NaN הוא "number". מבחינת הסוג הכול "תקין".
  4. Number.isNaN(price) מיד אחרי ההמרה. בפרק 3 נוסיף if שעוצר שם ומחזיר "נא להזין מספר".
⚠️ טעויות נפוצות
  • לחפש את הבאג בשורה שמדפיסה. השורה שמדפיסה רק מראה את הבעיה — היא נוצרה הרבה קודם.

P02-E57 · קפדן או סלחן? 🧠 הבנה רמה 2

💡 רמז 1

parseInt/parseFloat קוראים מההתחלה ועוצרים בתו הראשון שאינו חלק ממספר. parseInt גם עוצר בנקודה.

💡 רמז 2

שורה 4: parseInt("") — אין אף ספרה לקרוא.

✅ פתרון
console.log(Number("3.5kg"), parseFloat("3.5kg"));
console.log(Number("12abc"), parseInt("12abc"));
console.log(Number(" 42 "), parseInt(" 42 "));
console.log(Number(""), parseInt(""));
console.log(Number("7.9"), parseInt("7.9"));
NaN 3.5
NaN 12
42 42
0 NaN
7.9 7

לכמות בשרת — Number, כמו בקורס: (א) "12abc" הוא כנראה קלט שגוי, ו־NaN מאפשר לזהות ולדחות אותו; parseInt "מנחש" 12 ומסתיר את הבעיה. (ב) parseInt("7.9") חותך בשקט ל־7. הסכנה של Number היא דווקא "" ← 0, ואותה צריך לבדוק בנפרד (פרק 3).

⚠️ טעויות נפוצות
  • לחשוב ש"סלחני" זה טוב יותר. בשרת, ניחוש שקט גרוע משגיאה ברורה.

P02-E11 · קלט מטופס 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 2

P02-E18 · המרת יחידות מקלט 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

Number(weightInput), ואז !Number.isNaN(...) — או פשוט הדפס Number.isNaN ותחשוב הפוך. (הסימן ! הופך true ל־false — נלמד בפרק 3; כאן אפשר גם typeof.)

💡 רמז 2

בדיקה פשוטה בלי !: Number.isNaN(kg) === false.

✅ פתרון
02-operators-strings/starter/P02-E18.js 
const weightInput = "72.5";
const kgToLb = 2.20462;

const kg = Number(weightInput);
const lb = kg * kgToLb;

console.log(`${kg} ק״ג = ${lb.toFixed(2)} פאונד`);
console.log(`בדיקת קלט: ${weightInput} הוא מספר? ${Number.isNaN(kg) === false}`);
72.5 ק״ג = 159.83 פאונד
בדיקת קלט: 72.5 הוא מספר? true

עם "72,5": Number מחזיר NaN (פסיק אינו נקודה עשרונית), והפלט: NaN ק״ג = NaN פאונד ו־false. בישראל משתמשים לפעמים מקלידים פסיק — שרת טוב מחזיר הודעת שגיאה ברורה במקום להמשיך עם NaN (פרק 3).

⚠️ טעויות נפוצות
  • parseFloat("72,5") ← 72 בשקט — גרוע יותר מ־NaN, כי לא תשים לב.

P02-E20 · עגלה שמחשבת מוזר 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

הבאג הגלוי: מה מחברים בשורה האחרונה? הבאג הרדום: מה הסוג של quantityInput ו־unitPriceInput כשמשתמשים בהם?

💡 רמז 2

המר את שני הקלטים למספרים בתחילת הקובץ, והשתמש ב־withShipping בהדפסה.

const unitPriceInput = "125";

const unitPrice = Number(unitPriceInput);

console.log("כמות:", quantity);
console.log("מחיר ליחידה:", unitPrice);
console.log("סה״כ:", total);
console.log("כולל משלוח (30):", withShipping);
כמות: 2
מחיר ליחידה: 125
סה״כ: 250
כולל משלוח (30): 280

הבאג הגלוי: ההדפסה חישבה ביטוי חדש ("125" + 30 + "2") במקום להשתמש ב־withShipping. הבאג הרדום: הקלטים נשארו טקסט. הכפל עבד כי * ממיר; ביום שמישהו יכתוב quantityInput + 1 — יקבל "21".

⚠️ טעויות נפוצות
  • לתקן רק את השורה האחרונה ולהשאיר את הקלטים כטקסט.

P02-E22 · הנחה שמשתבשת 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

חפש כל מקום שבו toFixed נקרא לפני שהחישוב הסתיים, וכל קלט שלא הומר.

💡 רמז 2

שלוש בעיות: price נשאר טקסט; discount הפך לטקסט מוקדם מדי; withShipping משרשר.

✅ פתרון
const priceInput = "120";
const discountPercent = 15;
const shipping = 20;

const price = Number(priceInput);
const discount = (price * discountPercent) / 100;
const afterDiscount = price - discount;
const withShipping = afterDiscount + shipping;

console.log("מחיר מקורי:", price.toFixed(2));
console.log(`הנחה (${discountPercent}%):`, discount.toFixed(2));
console.log("אחרי הנחה:", afterDiscount.toFixed(2));
console.log("כולל משלוח:", withShipping.toFixed(2));
מחיר מקורי: 120.00
הנחה (15%): 18.00
אחרי הנחה: 102.00
כולל משלוח: 122.00
⚠️ טעויות נפוצות
  • להשאיר discount עם toFixed. היום price - discount "עובד" כי - ממיר — אבל מחר מישהו יחבר אותו.

P02-E63 · עמוד 21 🧠 הבנה רמה 3

💡 רמז 1

שורה 3: + עם טקסט. שורה 4: - ממיר למספר.

💡 רמז 2

שאלה 5: מה זה Number("")?

✅ פתרון
const page = "2";
const pageSize = 10;
console.log(page + 1);
console.log((page - 1) * pageSize);
21
10
  1. כמו בפלט.
  2. שורה 3: + עם טקסט מדביק ← "העמוד הבא" הוא 21. שורה 4: - ממיר את "2" ל־2.
  3. היא עובדת רק בגלל שבמקרה השתמשנו ב־-. שינוי קטן (למשל page * pageSize - pageSize עובד, אבל pageSize + page לא) — ונשבר. אי אפשר לסמוך על קוד ש"עובד במקרה".
  4. מיד כשהקלט מגיע: const page = Number(pageInput);. מאותה שורה, page הוא מספר, וכל הקוד שאחריו בטוח.
  5. Number("") הוא 0, ואז (0 - 1) * 10 = ‎-10 — "דלג על ‎-10 תוצאות". בפרק 3 נלמד לדחות קלט כזה.
⚠️ טעויות נפוצות
  • "לתקן" ל־page - -1 — טריק שעובד ואף אחד לא מבין. המר במפורש.

P02-E64 · מלאי מהטופס 🤖 💻 כתיבת קוד 🤖 רמה 3

קודם המר את שני הקלטים. אחר כך שני חישובים: stock - ordered ו־ordered - stock — כל אחד "לפחות 0".

P02-E66 · קבלה מהטופס, עם סכום מצטבר 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

המר כל קלט פעם אחת בהתחלה. סכום פריט 2 — משתנה משלו (line2).

💡 רמז 2

total += Number(price1); ו־total += line2;. באגורות: Math.round(total * 100) — כי כפל של שבר ב־100 לא תמיד יוצא שלם (נסה 19.99 * 100).

✅ פתרון
02-operators-strings/starter/P02-E66.js 
const price1 = "49.90";
const price2 = "15";
const quantity2 = "3";
const item1 = Number(price1);
const line2 = Number(price2) * Number(quantity2);
let total = 0;
total += item1;
total += line2;
console.log(`פריט 1: ${item1.toFixed(2)}`);
console.log(`פריט 2: ${quantity2} x ${price2} = ${line2.toFixed(2)}`);
console.log(`סה״כ: ${total.toFixed(2)}`);
console.log(`באגורות: ${Math.round(total * 100)}`);
פריט 1: 49.90
פריט 2: 3 x 15 = 45.00
סה״כ: 94.90
באגורות: 9490

עם "10": פריט 1 10.00, סה״כ 55.00, באגורות 5500.

⚠️ טעויות נפוצות
  • total += price1; בלי Number — 0 + "49.90" הוא הטקסט "049.90", ומכאן הכול הדבקה.
  • total * 100 בלי Math.round — כאן במקרה יוצא 9490, אבל עם מחיר "19.99" יוצא 1998.9999999999998.
