+ עם מחרוזת באחד הצדדים ← שרשור. שאר הפעולות ממירות למספר. ותמיד משמאל לימין.

console.log(Number("") + 5);

מחרוזות: שורות 1, 4, 5. כל השאר מספרים (כולל NaN, שהוא מסוג number). השורה האחרונה היא המלכודת: שדה ריק הפך ל־0 בשקט.

⚠️ טעויות נפוצות
  • לענות 15 לשורה 5 — "1" + 10 כבר יצר מחרוזת.

P02-E11 · קלט מטופס 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

המר כל קלט עם Number() לפני החישוב.

💡 רמז 2

הסימן × הוא רק טקסט בפלט — בקוד הכפל הוא *.

✅ פתרון
02-operators-strings/starter/P02-E11.js 
const ticketsInput = "4";
const ticketPriceInput = "62.5";

const tickets = Number(ticketsInput);
const ticketPrice = Number(ticketPriceInput);
const total = tickets * ticketPrice;

console.log(`${tickets} כרטיסים × ${ticketPrice} = ${total}`);
console.log(`סוג התוצאה: ${typeof total}`);
4 כרטיסים × 62.5 = 250
סוג התוצאה: number

"4" * "62.5" היה עובד גם בלי המרה (כפל ממיר לבד) — אבל ההמרה המפורשת מגינה עליך ביום שמישהו ישנה את זה ל־+.

⚠️ טעויות נפוצות
  • להמיר רק אחד מהשניים — עובד בכפל, נשבר בחיבור.

P02-E12 · תצוגת מחיר 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

let price, ואחרי כל הצבה: console.log(₪ ${price.toFixed(2)}).

💡 רמז 2

אפשר להעתיק את ₪ מהדף.

✅ פתרון
let price = 5;

price = 19.9;

₪ 0.33
⚠️ טעויות נפוצות

P02-E18 · המרת יחידות מקלט 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

Number(weightInput), ואז !Number.isNaN(...) — או פשוט הדפס Number.isNaN ותחשוב הפוך. (הסימן ! הופך true ל־false — נלמד בפרק 3; כאן אפשר גם typeof.)

💡 רמז 2

בדיקה פשוטה בלי !: Number.isNaN(kg) === false.

✅ פתרון
02-operators-strings/starter/P02-E18.js 
const weightInput = "72.5";
const kgToLb = 2.20462;

const kg = Number(weightInput);
const lb = kg * kgToLb;

console.log(`${kg} ק״ג = ${lb.toFixed(2)} פאונד`);
console.log(`בדיקת קלט: ${weightInput} הוא מספר? ${Number.isNaN(kg) === false}`);
72.5 ק״ג = 159.83 פאונד
בדיקת קלט: 72.5 הוא מספר? true

עם "72,5": Number מחזיר NaN (פסיק אינו נקודה עשרונית), והפלט: NaN ק״ג = NaN פאונד ו־false. בישראל משתמשים לפעמים מקלידים פסיק — שרת טוב מחזיר הודעת שגיאה ברורה במקום להמשיך עם NaN (פרק 3).

⚠️ טעויות נפוצות
  • parseFloat("72,5") ← 72 בשקט — גרוע יותר מ־NaN, כי לא תשים לב.

P02-E20 · עגלה שמחשבת מוזר 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

הבאג הגלוי: מה מחברים בשורה האחרונה? הבאג הרדום: מה הסוג של quantityInput ו־unitPriceInput כשמשתמשים בהם?

💡 רמז 2

המר את שני הקלטים למספרים בתחילת הקובץ, והשתמש ב־withShipping בהדפסה.

✅ פתרון
const quantityInput = "2";
const unitPriceInput = "125";
const shipping = 30;

const quantity = Number(quantityInput);
const unitPrice = Number(unitPriceInput);
const total = quantity * unitPrice;
const withShipping = total + shipping;

console.log("כמות:", quantity);
console.log("מחיר ליחידה:", unitPrice);
console.log("סה״כ:", total);
console.log("כולל משלוח (30):", withShipping);
כמות: 2
מחיר ליחידה: 125
סה״כ: 250
כולל משלוח (30): 280

הבאג הגלוי: ההדפסה חישבה ביטוי חדש ("125" + 30 + "2") במקום להשתמש ב־withShipping. הבאג הרדום: הקלטים נשארו טקסט. הכפל עבד כי * ממיר; ביום שמישהו יכתוב quantityInput + 1 — יקבל "21".

⚠️ טעויות נפוצות
  • לתקן רק את השורה האחרונה ולהשאיר את הקלטים כטקסט.

P02-E22 · הנחה שמשתבשת 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

חפש כל מקום שבו toFixed נקרא לפני שהחישוב הסתיים, וכל קלט שלא הומר.

💡 רמז 2

שלוש בעיות: price נשאר טקסט; discount הפך לטקסט מוקדם מדי; withShipping משרשר.

✅ פתרון
const priceInput = "120";
const discountPercent = 15;
const shipping = 20;

const price = Number(priceInput);
const discount = (price * discountPercent) / 100;
const afterDiscount = price - discount;
const withShipping = afterDiscount + shipping;

console.log("מחיר מקורי:", price.toFixed(2));
console.log(`הנחה (${discountPercent}%):`, discount.toFixed(2));
console.log("אחרי הנחה:", afterDiscount.toFixed(2));
console.log("כולל משלוח:", withShipping.toFixed(2));
מחיר מקורי: 120.00
הנחה (15%): 18.00
אחרי הנחה: 102.00
כולל משלוח: 122.00
⚠️ טעויות נפוצות
  • להשאיר discount עם toFixed. היום price - discount "עובד" כי - ממיר — אבל מחר מישהו יחבר אותו.
