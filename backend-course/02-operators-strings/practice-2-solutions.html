P02-E03 · תכונה או מתודה? 🧠 הבנה רמה 1

💡 רמז 1

length הוא מידע (בלי סוגריים). toUpperCase הוא פעולה (עם סוגריים).

💡 רמז 2

שורה אחת לא נכשלת אבל גם לא עושה מה שרוצים.

✅ פתרון
  • s.length ✔ ← 7
  • s.length() ✘ TypeError: s.length is not a function — בלי סוגריים.
  • s.toUpperCase ⚠️ לא נכשל, אבל מחזיר את המתודה עצמה ולא מפעיל אותה — חסרים ().
  • s.toUpperCase() ✔ ← "BACKEND"
  • s.touppercase() ✘ TypeError: s.touppercase is not a function — אותיות גדולות בשם המתודה.
  • s.trim().length ✔ ← 7
⚠️ טעויות נפוצות
  • לחשוב ש־s.toUpperCase בלי סוגריים "עובד" כי אין שגיאה.

P02-E08 · כרטיס ברכה 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

template literal יכול לכלול ירידות שורה כמו שהן.

💡 רמז 2

${age + 1}

✅ פתרון
02-operators-strings/starter/P02-E08.js 
const name = "עומר";
const age = 30;
const city = "אילת";

const card = `מזל טוב, ${name}!
היום אתה בן ${age}.
בשנה הבאה תהיה בן ${age + 1}.
ברכות חמות מכל החברים ב־${city}.`;

console.log(card);
מזל טוב, עומר!
היום אתה בן 30.
בשנה הבאה תהיה בן 31.
ברכות חמות מכל החברים ב־אילת.
⚠️ טעויות נפוצות
  • להזיח את השורות בתוך ה־template literal (רווחים בתחילת שורה) — הרווחים יודפסו.

P02-E09 · ראשי תיבות 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

האות הראשונה: firstName[0]. השאר: firstName.slice(1) (בלי פרמטר שני — עד הסוף).

💡 רמז 2

firstName[0].toUpperCase() + firstName.slice(1)

✅ פתרון
02-operators-strings/starter/P02-E09.js 
const firstName = "dana";
const lastName = "levi";

const initials = `${firstName[0].toUpperCase()}.${lastName[0].toUpperCase()}.`;
const first = firstName[0].toUpperCase() + firstName.slice(1);
const last = lastName[0].toUpperCase() + lastName.slice(1);

console.log(`ראשי תיבות: ${initials}`);
console.log(`שם מלא: ${first} ${last}`);
ראשי תיבות: D.L.
שם מלא: Dana Levi

הקוד ל"אות ראשונה גדולה" חוזר פעמיים — בפרק 5 נהפוך אותו לפונקציה.

⚠️ טעויות נפוצות
  • firstName.toUpperCase()[0] — עובד לאות הראשונה, אבל הופך את הכול לגדול בדרך.

P02-E10 · נרמול אימייל 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

שרשור מתודות: rawEmail.trim().toLowerCase().

💡 רמז 2

includes("@") ו־endsWith(".com") מחזירים בוליאני.

✅ פתרון
02-operators-strings/starter/P02-E10.js 
const rawEmail = "   Yossi.Cohen@Gmail.COM  ";
const email = rawEmail.trim().toLowerCase();

console.log(`אימייל: ${email}`);
console.log(`אורך: ${email.length}`);
console.log(`יש @? ${email.includes("@")}`);
console.log(`נגמר ב־.com? ${email.endsWith(".com")}`);
אימייל: yossi.cohen@gmail.com
אורך: 21
יש @? true
נגמר ב־.com? true
⚠️ טעויות נפוצות
  • לבדוק endsWith(".com") לפני toLowerCase — יחזיר false בגלל .COM.

P02-E15 · הסתרת מספר כרטיס 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

4 התווים האחרונים: cardNumber.slice(cardNumber.length - 4) — או בקיצור slice(-4).

💡 רמז 2

בונוס: last4.padStart(cardNumber.length, "*").

✅ פתרון
02-operators-strings/starter/P02-E15.js 
const cardNumber = "4580123412345678";
const last4 = cardNumber.slice(-4);

console.log(`**** **** **** ${last4}`);
console.log(`כרטיס שמסתיים ב־${last4} (${cardNumber.length} ספרות)`);

// בונוס: עובד לכל אורך
const masked = last4.padStart(cardNumber.length, "*");
console.log(masked);
**** **** **** 5678
כרטיס שמסתיים ב־5678 (16 ספרות)
************5678

💼 בעולם האמיתי, שרת שלך בכלל לא אמור לשמור מספרי כרטיס — חברת הסליקה שומרת אותם ומחזירה לך רק 4 ספרות ו"טוקן". בפרויקט הדגל התשלום יהיה מדומה מאותה סיבה.

⚠️ טעויות נפוצות
  • slice(12) — עובד רק לכרטיס של 16 ספרות בדיוק.

P02-E16 · שם קובץ וסיומת 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

מצא את מיקום הנקודה עם indexOf("."). השם — מההתחלה עד הנקודה; הסיומת — מאחרי הנקודה עד הסוף.

💡 רמז 2

fileName.slice(0, dotIndex) ו־fileName.slice(dotIndex + 1).

✅ פתרון
02-operators-strings/starter/P02-E16.js 
const fileName = "Invoice-March.PDF";
const dotIndex = fileName.indexOf(".");

const baseName = fileName.slice(0, dotIndex);
const extension = fileName.slice(dotIndex + 1).toLowerCase();

console.log(`שם: ${baseName}`);
console.log(`סיומת: ${extension}`);
console.log(`PDF? ${extension === "pdf"}`);
שם: Invoice-March
סיומת: pdf
PDF? true

(=== בודק שוויון — נלמד אותו בפרק 3. אפשר גם extension.includes("pdf").) מקרה קצה: לקובץ my.report.pdf יש שתי נקודות, ו־indexOf ימצא את הראשונה. הפתרון: lastIndexOf(".") — מחפשת מהסוף.

⚠️ טעויות נפוצות
  • slice(dotIndex) בלי + 1 — הסיומת תצא .pdf עם הנקודה.

P02-E17 · כתובת ידידותית (slug) 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

שלושה שלבים: ניקוי רווחים מסביב, אותיות קטנות, החלפת רווחים במקפים.

💡 רמז 2

title.trim().toLowerCase().replaceAll(" ", "-")

✅ פתרון
02-operators-strings/starter/P02-E17.js 
const title = "  Learn Node JS Fast  ";
const slug = title.trim().toLowerCase().replaceAll(" ", "-");

console.log(slug);
console.log(`https://blog.example.com/posts/${slug}`);
learn-node-js-fast
https://blog.example.com/posts/learn-node-js-fast

סדר השלבים חשוב: אם מחליפים רווחים לפני trim, הרווחים שבקצוות הופכים למקפים: --learn-node-js-fast--.

⚠️ טעויות נפוצות
  • replace(" ", "-") — מחליף רק את המופע הראשון.

P02-E21 · ארבעה באגים במחרוזות 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

שתי השגיאות הן TypeError: ... is not a function. קרא בדיוק את השם שבהודעה.

💡 רמז 2

השקטים: (1) תוצאה של מתודה שלא נשמרה; (2) בדיקה שמסתמכת על משהו שלא קשור ל"דומיין חוקי" — האם זה באג? הפלט הרצוי אומר true.

✅ פתרון
const rawName = " dana ";
const rawEmail = "  Dana@Mail.com  ";

const name = rawName.trim().toUpperCase();
console.log("משתמש:", name);
console.log("אורך השם:", name.length);

const email = rawEmail.trim().toLowerCase();
console.log("אימייל:", email);
console.log("דומיין חוקי?", email.endsWith(".com"));
משתמש: DANA
אורך השם: 4
אימייל: dana@mail.com
דומיין חוקי? true

(1) toUppercase ← toUpperCase. (2) length() ← length. (3) rawEmail.trim(); לא נשמר — האימייל יצא עם רווחים: " dana@mail.com ". (4) בגלל הרווחים בסוף, endsWith(".com") החזיר false. תיקון 3 פתר גם את 4 — דוגמה טובה לאיך באג אחד יוצר "באג" אחר.

⚠️ טעויות נפוצות
  • לתקן את 4 בעזרת includes(".com") — מסתיר את הבעיה האמיתית (הרווחים).

P02-E27 · פירוק אימייל 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

קודם מנקים (trim, toLowerCase), ואחר כך מחפשים איפה ה־@.

💡 רמז 2

const at = clean.indexOf("@"); — ואז שני slice: אחד עד at, ואחד מ־at + 1.

✅ פתרון
02-operators-strings/starter/P02-E27.js 
const email = "  Dana.Levi@Example.com ";

const clean = email.trim().toLowerCase();
const at = clean.indexOf("@");
const user = clean.slice(0, at);
const domain = clean.slice(at + 1);

console.log(`משתמש: ${user}`);
console.log(`דומיין: ${domain}`);
משתמש: dana.levi
דומיין: example.com

למה מנקים לפני שמחפשים: indexOf מחזיר מיקום. אם מחפשים במחרוזת עם הרווחים ואז חותכים מהמחרוזת הנקייה, המיקום זז בשני תווים, והחיתוך יוצא עקום. עובדים כל הזמן על אותה מחרוזת — הנקייה.

⚠️ טעויות נפוצות
  • slice(at) בלי + 1 — הדומיין יוצא @example.com.
  • slice(0, 9) — עובד רק לאימייל של דנה. הבודק מחליף את האימייל בדיוק בשביל זה.
