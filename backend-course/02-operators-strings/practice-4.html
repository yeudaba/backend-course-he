P02-E70 · אותה תוצאה?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

לכל זוג ביטויים — האם התוצאה תמיד זהה? אם לא, תן דוגמה לערכים שבהם הם שונים. נתונים:

const a = 1;
const b = 2;
const c = "3";
const name = " dana ";
const n = 2.3;
  1. a + b + c לעומת c + b + a
  2. price * qty + ship לעומת ship + qty * price (שלושתם מספרים)
  3. name.trim().toUpperCase() לעומת name.toUpperCase().trim()
  4. Math.round(n) * 2 לעומת Math.round(n * 2)
  5. `${a}${b}` לעומת a + b

P02-E80 · ביקורת קוד: שורה אחת ארוכה מדי
