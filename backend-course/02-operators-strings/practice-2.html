P02-E43 · נבא: אינדקסים ו־slice

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 2

בלי להריץ — מה תדפיס כל שורה?

const s = "backend";
console.log(s.length);
console.log(s[1]);
console.log(s[s.length - 1]);
console.log(s.slice(0, 4));
console.log(s.slice(4));
console.log(s.indexOf("k"));
console.log(s.indexOf("z"));
console.log(s[7]);

אחר כך הרץ והשווה. בשורה שטעית בה — צייר את המחרוזת עם האינדקסים מעליה, כמו באיור בשיעור.

P02-E44 · גרשיים, מירכאות או גרש הפוך?

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 2

בלי להריץ — מה יודפס?

const name = "נועה";
console.log("שלום ${name}");
console.log('שלום ' + name);
console.log(`שלום ${name}`);
console.log(`2 + 3 = ${2 + 3}`);
console.log("2 + 3 = " + 2 + 3);

ואז ענה: איך תזהה במבט אחד בקוד אם ${...} יעבוד?

P02-E45 · המחרוזת שלא השתנתה

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: שיעור 2

בלי להריץ — מה יודפס?

let word = "  Hi  ";
word.trim();
word.toUpperCase();
console.log(`[${word}]`);
const clean = word.trim().toUpperCase();
console.log(`[${clean}]`);
console.log(word.length, clean.length);

ואז ענה במשפט אחד: למה שורות 2–3 "לא עשו כלום"? ואיך היית משנה אותן כדי שכן ישפיעו על word?

P02-E46 · תכונה, מתודה, ושרשור

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

בלי להריץ — מה יודפס?

const raw = "  Hello World ";
console.log(raw.length);
console.log(raw.trim().length);
console.log(raw.includes("world"));
console.log(raw.toLowerCase().includes("world"));
console.log(raw.trim().slice(0, 5).toUpperCase());

ועכשיו: מה יקרה אם נוסיף את השורה console.log(raw.length.trim());? הסבר במשפט למה.

P02-E47 · למספר אין length

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 1, שיעור 2

בלי להריץ — מה יודפס?

const code = 4521;
console.log(code.length);
console.log(`${code}`.length);
const zip = "04521";
console.log(zip.length, zip[0]);
let missing;
console.log(`[${missing}]`);
console.log(`[${null}]`);

ואז: אם בדף של חנות כתוב "שלום undefined" — מה זה אומר לך על הקוד?

🔗 איך זה מתחבר: בפרק 1 ראית ש־undefined הוא "שם אין כלום", ושהסוג שייך לערך. כאן זה פוגש את המחרוזות: length קיים רק למחרוזות, ו־template literal הופך כל ערך — גם undefined — לטקסט.

P02-E48 · const ומתודות

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 1, שיעור 2

בלי להריץ:

const name = "dana";
name.toUpperCase();
console.log(name);

(1) מה יודפס? (2) מתכנת "מתקן" ל־name = name.toUpperCase(); — מה יקרה עכשיו? (3) תן שתי דרכים לתקן, ואמור איזו עדיפה ולמה.

🔗 איך זה מתחבר: בפרק 1 למדת ש־const אי אפשר להציב מחדש. בשיעור הזה למדת שמתודות מחזירות עותק. ביחד: כדי "לשנות" מחרוזת שב־const — שומרים את העותק במשתנה חדש.

P02-E49 · + מחבר או מדביק?

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: שיעורים 1–2

בלי להריץ — מה יודפס?

const a = 10;
const b = 5;
console.log("סה״כ: " + a + b);
console.log(a + b + " ש״ח");
console.log("סה״כ: " + a * b);
console.log(`סה״כ: ${a + b}`);
console.log(`${a}${b}`);

🔗 איך זה מתחבר: סדר הפעולות משיעור 1 (כפל לפני חיבור, ומשמאל לימין) פוגש את הכלל של שיעור 2: + עם טקסט מדביק. כל שורה כאן היא שילוב אחר של השניים.

P02-E50 · קבלה עם template literals 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 10 דק׳ידע נדרש: שיעורים 1–2

כתוב תוכנית עם ארבעה משתנים:

const item = "חולצה";
const price = 80;
const quantity = 3;
const discountPercent = 10;

שמדפיסה:

3 x חולצה = 240 ש״ח
הנחה (10%): 24 ש״ח
לתשלום: 216 ש״ח

כל שורה נבנית עם template literal (בלי + בין טקסטים). שום תוצאה לא כתובה בקוד. הבודק משנה את הכמות ואת אחוז ההנחה.

📄 כותבים בקובץ 02-operators-strings/starter/P02-E50.js (יש בו רק הערה עם המשימה), מריצים ובודקים:

% node 02-operators-strings/starter/P02-E50.js
% npm run check P02-E50

🔗 איך זה מתחבר: את החשבון (כפל, אחוזים) למדת בשיעור 1; template literal משיעור 2 מאפשר לשים אותו ישר בתוך הטקסט, בלי לדאוג ש־+ יהפוך להדבקה.

P02-E51 · כמה תווים נשארו? 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 10 דק׳ידע נדרש: שיעורים 1–2

הודעת SMS מוגבלת ל־70 תווים. כתוב תוכנית שמתחילה ב:

const maxLength = 70;
const message = "  נפגשים מחר ב־8 בבוקר ליד הכניסה  ";

ומדפיסה (ההודעה אחרי ניקוי רווחים מהצדדים):

הודעה: [נפגשים מחר ב־8 בבוקר ליד הכניסה]
אורך: 31
נשארו: 39
תצוגה מקדימה: נפגשים מחר...

"תצוגה מקדימה" = 10 התווים הראשונים ואחריהם שלוש נקודות. הבודק מחליף את ההודעה ואת maxLength.

📄 כותבים בקובץ 02-operators-strings/starter/P02-E51.js (יש בו רק הערה עם המשימה), מריצים ובודקים:

% node 02-operators-strings/starter/P02-E51.js
% npm run check P02-E51

🔗 איך זה מתחבר: trim, length ו־slice משיעור 2 נותנים את המספרים; החיסור משיעור 1 הופך אותם למידע שימושי. ככה נראית בדיקת אורך בטופס אמיתי.

P02-E52 · מספר הזמנה עם אפסים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 10 דק׳ידע נדרש: פרק 1, שיעורים 1–2

בקובץ כבר כתובה השורה let orderNumber = 42; (מספר). הוסף קוד שמדפיס את המזהה של ההזמנה הנוכחית ושל הבאה — עם 5 ספרות, ואפסים מובילים:

הזמנה נוכחית: ORD-00042
הזמנה הבאה: ORD-00043
סוג המזהה: string
אורך המזהה: 9

את "הזמנה הבאה" מחשבים עם orderNumber++ (בשורה משלו). הבודק מחליף את 42 ב־7 וב־12345.

📄 כותבים בקובץ 02-operators-strings/starter/P02-E52.js (השורה הראשונה כבר כתובה), מריצים ובודקים:

% node 02-operators-strings/starter/P02-E52.js
% npm run check P02-E52

🔗 איך זה מתחבר: let ו־typeof מפרק 1, ++ משיעור 1, ו־padStart משיעור 2. וגם תובנה: מזהה הוא טקסט, גם כשהוא בנוי ממספר.
