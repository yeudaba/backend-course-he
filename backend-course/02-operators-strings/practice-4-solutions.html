P02-E23 · הקבלה של 305 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

השורה של העט: אחרי שהצד השמאלי הפך למחרוזת, כל + הוא שרשור.

💡 רמז 2

בשורה האחרונה: "סה״כ לתשלום: " + 36 + 14 + 15.

✅ פתרון

שורת העט: 2 + " x עט = " + 2 + 7 ← "2 x עט = " + 2 + 7 ← "2 x עט = 2" + 7 ← "2 x עט = 27". (גם הכוונה הייתה שגויה: penQty + penPrice במקום כפל.)

סה״כ: "סה״כ לתשלום: " + 36 + 14 + 15 ← "...36" + 14 ← "...3614" + 15 ← "...361415".

const notebookPrice = 12;
const notebookQty = 3;
const penPrice = 7;
const penQty = 2;
const shipping = 15;

const notebooksTotal = notebookQty * notebookPrice;
const pensTotal = penQty * penPrice;
const total = notebooksTotal + pensTotal + shipping;

console.log(`${notebookQty} x מחברת = ${notebooksTotal}`);
console.log(`${penQty} x עט = ${pensTotal}`);
console.log(`משלוח: ${shipping}`);
console.log(`סה״כ לתשלום: ${total}`);
3 x מחברת = 36
2 x עט = 14
משלוח: 15
סה״כ לתשלום: 65

שים לב לשיפור: החישובים יצאו למשתנים עם שמות, וההדפסה רק משבצת אותם. קל יותר לקרוא, ואין סיכוי לשרשור בטעות.

⚠️ טעויות נפוצות
  • לתקן רק עם סוגריים ולהשאיר penQty + penPrice.

P02-E24 · אתגר: קבלה מעוצבת 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

שורה אחת: name.padEnd(20, ".") + price.toFixed(2).padStart(8) (ברירת המחדל של התו היא רווח).

💡 רמז 2

המר ונקה כל קלט פעם אחת בהתחלה. את הקופון — (-coupon).toFixed(2) כדי לקבל מינוס.

const item1 = "  mouse  ";
const price1 = "89.9";
const item2 = "keyboard";
const price2 = " 249 ";
const item3 = "USB cable";
const price3 = "19.5";
const couponPercent = "10";
const vatRate = 0.18;
const nameWidth = 20;
const priceWidth = 8;

const name1 = item1.trim().toUpperCase();
const name2 = item2.trim().toUpperCase();
const name3 = item3.trim().toUpperCase();
const p1 = Number(price1);

P02-E25 · אתגר: שעון דיגיטלי 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

שעות = Math.floor(totalSeconds / 3600). מה שנשאר אחרי השעות — totalSeconds % 3600 — מתחלק לדקות ושניות באותה שיטה.

💡 רמז 2

לאפס מוביל: String(hours).padStart(2, "0").

✅ פתרון
02-operators-strings/starter/P02-E25.js 
const totalSeconds = 3725;

const hours = Math.floor(totalSeconds / 3600);
const minutes = Math.floor((totalSeconds % 3600) / 60);
const seconds = totalSeconds % 60;

const hh = String(hours).padStart(2, "0");
const mm = String(minutes).padStart(2, "0");
const ss = String(seconds).padStart(2, "0");

console.log(`${totalSeconds} שניות = ${hh}:${mm}:${ss}`);
3725 שניות = 01:02:05

עם 90000: 25:00:00 — לא שגוי, אבל לא "שעה ביום". אפשרות: להוסיף ימים — Math.floor(totalSeconds / 86400) — ולהציג 1d 01:00:00. בעבודה אמיתית משתמשים בספרייה לתאריכים ושעות (פרק 24), כי יש אזורי זמן ושעון קיץ.

⚠️ טעויות נפוצות
  • Math.floor(totalSeconds / 60) לדקות — נותן את כל הדקות (62), לא את הדקות שאחרי השעות (2).

P02-E28 · חשבון חשמל 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

מה יוצא מ־" 10712 " - "10450"? ומ־" 10712 " + "10450"? אל תסמוך על המרה אוטומטית — המר בעצמך.

💡 רמז 2

שלושה חישובים: used = current - previous, ‏cost = used * pricePerKwh, ‏withVat = cost * (1 + vatPercent / 100). ‏toFixed(2) רק בהדפסה.

✅ פתרון
02-operators-strings/starter/P02-E28.js 
const previousReading = "10450";
const currentReading = " 10712 ";
const pricePerKwh = 0.6402;
const vatPercent = 18;

const used = Number(currentReading) - Number(previousReading);
const cost = used * pricePerKwh;
const withVat = cost * (1 + vatPercent / 100);

console.log(`צריכה: ${used} קוט״ש`);
console.log(`לפני מע״מ: ${cost.toFixed(2)} ₪`);
console.log(`כולל מע״מ (${vatPercent}%): ${withVat.toFixed(2)} ₪`);
צריכה: 262 קוט״ש
לפני מע״מ: 167.73 ₪
כולל מע״מ (18%): 197.92 ₪

Number(" 10712 ") מתעלם מרווחים בקצוות ומחזיר 10712, אז trim לא חובה כאן. ובכל זאת אנחנו ממירים במפורש: עם - JavaScript הייתה ממירה לבד, אבל ביום שמישהו יחבר שתי קריאות עם + הוא יקבל שרשור של טקסט.

toFixed רק בהדפסה: אם מעגלים את cost באמצע ואז מחשבים ממנו מע״מ, עיגול אחד נערם על השני. מחשבים עם הערך המלא, ומעגלים פעם אחת, בתצוגה.

⚠️ טעויות נפוצות
  • לכתוב (18%) כטקסט קבוע בשורה השלישית — עם מע״מ של 17% השורה תשקר. הבודק תופס את זה.
  • cost * 18 / 100 — זה רק המע״מ, בלי המחיר עצמו.
  • const cost = (used * pricePerKwh).toFixed(2); — עכשיו cost הוא מחרוזת, ו־cost * 1.18 עובד במקרה, אבל cost + vat ישרשר.
