P02-E32 · שגיאה, Infinity או NaN? 🧠 הבנה רמה 2

💡 רמז 1

שלוש שורות נעצרות, שתיים לא. שגיאות שונות: אחת כי הקוד לא כתוב נכון בכלל, אחת כי שם לא קיים, ואחת כי מנסים "לקרוא" למשהו שאינו פונקציה.

💡 רמז 2

JavaScript מבחינה בין אותיות גדולות לקטנות: Math קיים, math לא. ול־Math יש round, לא Round.

✅ פתרון
  1. SyntaxError — אין סימן x לכפל. Node לא מצליח אפילו לקרוא את הקובץ.
  2. ReferenceError: math is not defined — אין משתנה בשם math.
  3. יודפס Infinity — בלי שגיאה.
  4. יודפס NaN — בלי שגיאה.
  5. TypeError: Math.Round is not a function — Math.Round לא קיים (הוא undefined), ואי אפשר "לקרוא" לו עם סוגריים.
console.log(10 / 0);
console.log(0 / 0);
Infinity
NaN

הכי מסוכנים: 3 ו־4. שגיאה עוצרת את התוכנית ומראה לך בדיוק איפה הבעיה. Infinity ו־NaN ממשיכים בשקט לתוך החישובים הבאים — ומגיעים ללקוח כ"לתשלום: NaN". בפרק 3 נלמד לבדוק לפני שמחלקים.

⚠️ טעויות נפוצות
  • לחשוב ש־10 / 0 זורק שגיאה, כמו בהרבה שפות אחרות. ב־JavaScript — לא.

P02-E13 · עמודים בתוצאות חיפוש 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

מספר עמודים — עיגול כלפי מעלה. תוצאות בעמוד האחרון — שארית, אבל עם מקרה מיוחד.

💡 רמז 2

אם השארית היא 0, העמוד האחרון מלא: אפשר להשתמש ב־totalItems - (pages - 1) * pageSize במקום %, וזה עובד תמיד. עמוד n מתחיל ב־(n - 1) * pageSize + 1.

✅ פתרון
02-operators-strings/starter/P02-E13.js 
const totalItems = 47;
const pageSize = 10;
const page = 3;

const pages = Math.ceil(totalItems / pageSize);
const lastPageItems = totalItems - (pages - 1) * pageSize;
const from = (page - 1) * pageSize + 1;
const to = page * pageSize;

console.log(`סה״כ תוצאות: ${totalItems}`);
console.log(`עמודים: ${pages}`);
console.log(`תוצאות בעמוד האחרון: ${lastPageItems}`);
console.log(`עמוד ${page} מציג את תוצאות ${from} עד ${to}`);
סה״כ תוצאות: 47
עמודים: 5
תוצאות בעמוד האחרון: 7
עמוד 3 מציג את תוצאות 21 עד 30

עם 50: Math.ceil(5) = 5, ו־50 - 40 = 10 ✔ (50 % 10 היה נותן 0 ✘). עם 3: עמוד 1, 3 תוצאות. (בעמוד 3 כשאין 30 תוצאות — to יצא גדול מדי; נתקן עם Math.min או תנאי בפרק 3.)

⚠️ טעויות נפוצות
  • Math.round(47 / 10) ← 5 במקרה, אבל 41 / 10 ייתן 4 במקום 5.

P02-E14 · חלוקת חשבון במסעדה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

טיפ = חשבון × אחוז / 100. לכל סועד: Math.ceil(totalWithTip / diners).

💡 רמז 2

"נאסף בפועל" = מה שכל אחד משלם × מספר הסועדים. "עודף" = נאסף פחות הסה״כ. הצג עם toFixed(2).

✅ פתרון
02-operators-strings/starter/P02-E14.js 
const bill = 487;
const tipPercent = 12;
const diners = 6;

const tip = (bill * tipPercent) / 100;
const totalWithTip = bill + tip;
const perPerson = Math.ceil(totalWithTip / diners);
const collected = perPerson * diners;
const extra = collected - totalWithTip;

console.log(`חשבון: ${bill}`);
console.log(`טיפ (${tipPercent}%): ${tip.toFixed(2)}`);
console.log(`סה״כ עם טיפ: ${totalWithTip.toFixed(2)}`);
console.log(`כל אחד משלם: ${perPerson}`);
console.log(`נאסף בפועל: ${collected}`);
console.log(`עודף לטיפ: ${extra.toFixed(2)}`);
חשבון: 487
טיפ (12%): 58.44
סה״כ עם טיפ: 545.44
כל אחד משלם: 91
נאסף בפועל: 546
עודף לטיפ: 0.56
⚠️ טעויות נפוצות
  • Math.round במקום ceil: 545.44/6 = 90.9 ← 91 במקרה; עם סכום אחר יחסר כסף.
  • להדפיס extra בלי toFixed ← 0.5599999999999454.

P02-E26 · אגורות לשקלים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

כמה פעמים 100 נכנס ב־1234 (בשלמים)? ומה נשאר?

💡 רמז 2

const shekels = Math.floor(agorot / 100); — ואת השארית באותה צורה, עם %.

✅ פתרון
02-operators-strings/starter/P02-E26.js 
const agorot = 1234;
const shekels = Math.floor(agorot / 100);
const rest = agorot % 100;
console.log(`${agorot} אגורות = ${shekels} ₪ ו־${rest} אג׳`);
1234 אגורות = 12 ₪ ו־34 אג׳

זה אותו דפוס כמו "דקות לשעות" (P02-E06): Math.floor של החלוקה נותן את היחידה הגדולה, ו־% את מה שנשאר. נפגוש אותו שוב בשעון (E25) ובעמודים של תוצאות חיפוש (E13).

⚠️ טעויות נפוצות
  • agorot / 100 בלי Math.floor ← 12.34 ₪, ועם 5 אגורות ← 0.05 ₪ ו־5 אג׳.
  • Math.round במקום Math.floor — עם 99999 תקבל 1000 ₪ במקום 999.

P02-E34 · מע״מ על מחיר 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

שני משתנים חדשים: vat ו־total. ואז שלוש שורות console.log עם פסיק בין הכותרת לערך.

💡 רמז 2

const vat = price * 18 / 100; ו־const total = price + vat;

P02-E36 · כמה אוטובוסים? 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

"צריך" — Math.ceil. "מלאים" — Math.floor. "נשארו" — %.

💡 רמז 2

מקומות פנויים = (מספר האוטובוסים שצריך × busSize) פחות הנוסעים.

✅ פתרון
02-operators-strings/starter/P02-E36.js 
const passengers = 130;
const busSize = 50;
const busesNeeded = Math.ceil(passengers / busSize);
const fullBuses = Math.floor(passengers / busSize);
const leftOver = passengers % busSize;
const freeSeats = busesNeeded * busSize - passengers;
console.log("אוטובוסים צריך:", busesNeeded);
console.log("אוטובוסים מלאים:", fullBuses);
console.log("נשארו אחרי המלאים:", leftOver);
console.log("מקומות פנויים:", freeSeats);
אוטובוסים צריך: 3
אוטובוסים מלאים: 2
נשארו אחרי המלאים: 30
מקומות פנויים: 20

עם 150: 3, 3, 0, 0. עם 7: 1, 0, 7, 43. שים לב שכל מספר נשמר במשתנה עם שם — וכך freeSeats משתמש ב־busesNeeded במקום לחשב שוב.

⚠️ טעויות נפוצות
  • Math.round(passengers / busSize) — עם 130 יוצא 3 במקרה, אבל עם 110 יוצא 2, ועשרה ילדים נשארים בבית.

P02-E37 · let בלי ערך, const עם += 🧠 הבנה רמה 2

💡 רמז 1

תוכנית א: visits++ זה visits = visits + 1. כמה זה undefined + 1?

💡 רמז 2

תוכנית ב: total += 5 זה total = total + 5 — הצבה למשתנה const.

let visits;

NaN

P02-E38 · typeof של תוצאות חשבון 🧠 הבנה רמה 2

💡 רמז 1

שורה 4: typeof חל רק על הערך שמיד אחריו. מה זה typeof 7, ומה קורה כשעושים לזה % 2?

💡 רמז 2

שורה 6: בחשבון, null מתנהג כמו 0.

✅ פתרון
console.log(7 / 0, typeof (7 / 0));
console.log(0 / 0, typeof (0 / 0));
console.log(Math.round(2.5), typeof Math.round(2.5));
console.log(typeof 7 % 2);
let empty = null;
console.log(empty + 1);
Infinity number
NaN number
3 number
NaN
1
  • שורות 1–2: Infinity ו־NaN הם ערכים מסוג number — "מספרים מיוחדים".
  • שורה 3: Math.round מחזיר מספר. (2.5 מתעגל למעלה.)
  • שורה 4: typeof 7 הוא הטקסט "number", ו־"number" % 2 הוא NaN. רצית typeof (7 % 2).
  • שורה 6: null + 1 הוא 1 — בלי שגיאה. עוד סיבה להיזהר: null בחשבון נעלם בשקט.
⚠️ טעויות נפוצות
