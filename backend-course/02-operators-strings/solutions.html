P02-E26 · אגורות לשקלים 🤖 🔥 חימום רמה 2

💡 רמז 1

כמה פעמים 100 נכנס ב־1234 (בשלמים)? ומה נשאר?

💡 רמז 2

const shekels = Math.floor(agorot / 100); — ואת השארית באותה צורה, עם %.

✅ פתרון
02-operators-strings/starter/P02-E26.js 
const agorot = 1234;
const shekels = Math.floor(agorot / 100);
const rest = agorot % 100;
console.log(`${agorot} אגורות = ${shekels} ₪ ו־${rest} אג׳`);
1234 אגורות = 12 ₪ ו־34 אג׳

זה אותו דפוס כמו "דקות לשעות" (P02-E06): Math.floor של החלוקה נותן את היחידה הגדולה, ו־% את מה שנשאר. נפגוש אותו שוב בשעון (E25) ובעמודים של תוצאות חיפוש (E13).

⚠️ טעויות נפוצות
  • agorot / 100 בלי Math.floor ← 12.34 ₪, ועם 5 אגורות ← 0.05 ₪ ו־5 אג׳.
  • Math.round במקום Math.floor — עם 99999 תקבל 1000 ₪ במקום 999.

P02-E27 · פירוק אימייל 🤖 🔥 חימום רמה 2

💡 רמז 1

קודם מנקים (trim, toLowerCase), ואחר כך מחפשים איפה ה־@.

💡 רמז 2

const at = clean.indexOf("@"); — ואז שני slice: אחד עד at, ואחד מ־at + 1.

✅ פתרון
02-operators-strings/starter/P02-E27.js 
const email = "  Dana.Levi@Example.com ";

const clean = email.trim().toLowerCase();
const at = clean.indexOf("@");
const user = clean.slice(0, at);
const domain = clean.slice(at + 1);

console.log(`משתמש: ${user}`);
console.log(`דומיין: ${domain}`);
משתמש: dana.levi
דומיין: example.com

למה מנקים לפני שמחפשים: indexOf מחזיר מיקום. אם מחפשים במחרוזת עם הרווחים ואז חותכים מהמחרוזת הנקייה, המיקום זז בשני תווים, והחיתוך יוצא עקום. עובדים כל הזמן על אותה מחרוזת — הנקייה.

⚠️ טעויות נפוצות
  • slice(at) בלי + 1 — הדומיין יוצא @example.com.
  • slice(0, 9) — עובד רק לאימייל של דנה. הבודק מחליף את האימייל בדיוק בשביל זה.

P02-E28 · חשבון חשמל 🤖 ✍️ מאפס רמה 3

💡 רמז 1

מה יוצא מ־" 10712 " - "10450"? ומ־" 10712 " + "10450"? אל תסמוך על המרה אוטומטית — המר בעצמך.

💡 רמז 2

שלושה חישובים: used = current - previous, ‏cost = used * pricePerKwh, ‏withVat = cost * (1 + vatPercent / 100). ‏toFixed(2) רק בהדפסה.

✅ פתרון
02-operators-strings/starter/P02-E28.js 
const previousReading = "10450";
const currentReading = " 10712 ";
const pricePerKwh = 0.6402;
const vatPercent = 18;

const used = Number(currentReading) - Number(previousReading);
const cost = used * pricePerKwh;
const withVat = cost * (1 + vatPercent / 100);

console.log(`צריכה: ${used} קוט״ש`);
console.log(`לפני מע״מ: ${cost.toFixed(2)} ₪`);
console.log(`כולל מע״מ (${vatPercent}%): ${withVat.toFixed(2)} ₪`);
צריכה: 262 קוט״ש
לפני מע״מ: 167.73 ₪
כולל מע״מ (18%): 197.92 ₪

Number(" 10712 ") מתעלם מרווחים בקצוות ומחזיר 10712, אז trim לא חובה כאן. ובכל זאת אנחנו ממירים במפורש: עם - JavaScript הייתה ממירה לבד, אבל ביום שמישהו יחבר שתי קריאות עם + הוא יקבל שרשור של טקסט.

toFixed רק בהדפסה: אם מעגלים את cost באמצע ואז מחשבים ממנו מע״מ, עיגול אחד נערם על השני. מחשבים עם הערך המלא, ומעגלים פעם אחת, בתצוגה.

⚠️ טעויות נפוצות
  • לכתוב (18%) כטקסט קבוע בשורה השלישית — עם מע״מ של 17% השורה תשקר. הבודק תופס את זה.
  • cost * 18 / 100 — זה רק המע״מ, בלי המחיר עצמו.
  • const cost = (used * pricePerKwh).toFixed(2); — עכשיו cost הוא מחרוזת, ו־cost * 1.18 עובד במקרה, אבל cost + vat ישרשר.

P02-E03 · תכונה או מתודה? רמה 1

💡 רמז 1

length הוא מידע (בלי סוגריים). toUpperCase הוא פעולה (עם סוגריים).

💡 רמז 2

שורה אחת לא נכשלת אבל גם לא עושה מה שרוצים.

✅ פתרון
  • s.length ✔ ← 7
  • s.length() ✘ TypeError: s.length is not a function — בלי סוגריים.
  • s.toUpperCase ⚠️ לא נכשל, אבל מחזיר את המתודה עצמה ולא מפעיל אותה — חסרים ().

  • s.touppercase() ✘ TypeError: s.touppercase is not a function — אותיות גדולות בשם המתודה.
  • s.trim().length ✔ ← 7
⚠️ טעויות נפוצות
  • לחשוב ש־s.toUpperCase בלי סוגריים "עובד" כי אין שגיאה.

P02-E13 · עמודים בתוצאות חיפוש 🤖 רמה 3

💡 רמז 1

מספר עמודים — עיגול כלפי מעלה. תוצאות בעמוד האחרון — שארית, אבל עם מקרה מיוחד.

💡 רמז 2

אם השארית היא 0, העמוד האחרון מלא: אפשר להשתמש ב־totalItems - (pages - 1) * pageSize במקום %, וזה עובד תמיד. עמוד n מתחיל ב־(n - 1) * pageSize + 1.

✅ פתרון
02-operators-strings/starter/P02-E13.js 
const totalItems = 47;
const pageSize = 10;
const page = 3;

const pages = Math.ceil(totalItems / pageSize);
const lastPageItems = totalItems - (pages - 1) * pageSize;
const from = (page - 1) * pageSize + 1;
const to = page * pageSize;

console.log(`סה״כ תוצאות: ${totalItems}`);
console.log(`עמודים: ${pages}`);
console.log(`תוצאות בעמוד האחרון: ${lastPageItems}`);
console.log(`עמוד ${page} מציג את תוצאות ${from} עד ${to}`);
סה״כ תוצאות: 47
עמודים: 5
תוצאות בעמוד האחרון: 7
עמוד 3 מציג את תוצאות 21 עד 30

עם 50: Math.ceil(5) = 5, ו־50 - 40 = 10 ✔ (50 % 10 היה נותן 0 ✘). עם 3: עמוד 1, 3 תוצאות. (בעמוד 3 כשאין 30 תוצאות — to יצא גדול מדי; נתקן עם Math.min או תנאי בפרק 3.)

⚠️ טעויות נפוצות
  • Math.round(47 / 10) ← 5 במקרה, אבל 41 / 10 ייתן 4 במקום 5.

P02-E14 · חלוקת חשבון במסעדה 🤖 רמה 3

💡 רמז 1

טיפ = חשבון × אחוז / 100. לכל סועד: Math.ceil(totalWithTip / diners).

💡 רמז 2

"נאסף בפועל" = מה שכל אחד משלם × מספר הסועדים. "עודף" = נאסף פחות הסה״כ. הצג עם toFixed(2).

✅ פתרון
02-operators-strings/starter/P02-E14.js 
const bill = 487;
const tipPercent = 12;
const diners = 6;

const tip = (bill * tipPercent) / 100;
const totalWithTip = bill + tip;
const perPerson = Math.ceil(totalWithTip / diners);
const collected = perPerson * diners;
const extra = collected - totalWithTip;

console.log(`חשבון: ${bill}`);
console.log(`טיפ (${tipPercent}%): ${tip.toFixed(2)}`);
console.log(`סה״כ עם טיפ: ${totalWithTip.toFixed(2)}`);
console.log(`כל אחד משלם: ${perPerson}`);
console.log(`נאסף בפועל: ${collected}`);
console.log(`עודף לטיפ: ${extra.toFixed(2)}`);
חשבון: 487
טיפ (12%): 58.44
סה״כ עם טיפ: 545.44
כל אחד משלם: 91
נאסף בפועל: 546
עודף לטיפ: 0.56
⚠️ טעויות נפוצות
  • Math.round במקום ceil: 545.44/6 = 90.9 ← 91 במקרה; עם סכום אחר יחסר כסף.
  • להדפיס extra בלי toFixed ← 0.5599999999999454.

P02-E18 · המרת יחידות מקלט 🤖 רמה 3

💡 רמז 1

Number(weightInput), ואז !Number.isNaN(...) — או פשוט הדפס Number.isNaN ותחשוב הפוך. (הסימן ! הופך true ל־false — נלמד בפרק 3; כאן אפשר גם typeof.)

💡 רמז 2

בדיקה פשוטה בלי !: Number.isNaN(kg) === false.

✅ פתרון
02-operators-strings/starter/P02-E18.js 
const weightInput = "72.5";
const kgToLb = 2.20462;

const kg = Number(weightInput);
const lb = kg * kgToLb;

console.log(`${kg} ק״ג = ${lb.toFixed(2)} פאונד`);
console.log(`בדיקת קלט: ${weightInput} הוא מספר? ${Number.isNaN(kg) === false}`);
72.5 ק״ג = 159.83 פאונד
בדיקת קלט: 72.5 הוא מספר? true

עם "72,5": Number מחזיר NaN (פסיק אינו נקודה עשרונית), והפלט: NaN ק״ג = NaN פאונד ו־false. בישראל משתמשים לפעמים מקלידים פסיק — שרת טוב מחזיר הודעת שגיאה ברורה במקום להמשיך עם NaN (פרק 3).

⚠️ טעויות נפוצות
  • parseFloat("72,5") ← 72 בשקט — גרוע יותר מ־NaN, כי לא תשים לב.

P02-E21 · ארבעה באגים במחרוזות 🤖 רמה 4

💡 רמז 1

💡 רמז 2

השקטים: (1) תוצאה של מתודה שלא נשמרה; (2) בדיקה שמסתמכת על משהו שלא קשור ל"דומיין חוקי" — האם זה באג? הפלט הרצוי אומר true.

✅ פתרון

const priceInput = "120";

P02-E23 · הקבלה של 305 🤖 רמה 4

💡 רמז 1

השורה של העט: אחרי שהצד השמאלי הפך למחרוזת, כל + הוא שרשור.

💡 רמז 2

בשורה האחרונה: "סה״כ לתשלום: " + 36 + 14 + 15.

✅ פתרון

שורת העט: 2 + " x עט = " + 2 + 7 ← "2 x עט = " + 2 + 7 ← "2 x עט = 2" + 7 ← "2 x עט = 27". (גם הכוונה הייתה שגויה: penQty + penPrice במקום כפל.)

סה״כ: "סה״כ לתשלום: " + 36 + 14 + 15 ← "...36" + 14 ← "...3614" + 15 ← "...361415".

const notebookPrice = 12;
const notebookQty = 3;
const penPrice = 7;
const penQty = 2;
const shipping = 15;

const notebooksTotal = notebookQty * notebookPrice;
const pensTotal = penQty * penPrice;
const total = notebooksTotal + pensTotal + shipping;

console.log(`${notebookQty} x מחברת = ${notebooksTotal}`);
console.log(`${penQty} x עט = ${pensTotal}`);
console.log(`משלוח: ${shipping}`);

2 x עט = 14

סה״כ לתשלום: 65

שים לב לשיפור: החישובים יצאו למשתנים עם שמות, וההדפסה רק משבצת אותם. קל יותר לקרוא, ואין סיכוי לשרשור בטעות.

P02-E25 · אתגר: שעון דיגיטלי 🤖 רמה 5

💡 רמז 1

שעות = Math.floor(totalSeconds / 3600). מה שנשאר אחרי השעות — totalSeconds % 3600 — מתחלק לדקות ושניות באותה שיטה.

💡 רמז 2

לאפס מוביל: String(hours).padStart(2, "0").

✅ פתרון
02-operators-strings/starter/P02-E25.js 
const totalSeconds = 3725;

const hours = Math.floor(totalSeconds / 3600);
const minutes = Math.floor((totalSeconds % 3600) / 60);
const seconds = totalSeconds % 60;

const hh = String(hours).padStart(2, "0");
const mm = String(minutes).padStart(2, "0");
const ss = String(seconds).padStart(2, "0");

console.log(`${totalSeconds} שניות = ${hh}:${mm}:${ss}`);
3725 שניות = 01:02:05

עם 90000: 25:00:00 — לא שגוי, אבל לא "שעה ביום". אפשרות: להוסיף ימים — Math.floor(totalSeconds / 86400) — ולהציג 1d 01:00:00. בעבודה אמיתית משתמשים בספרייה לתאריכים ושעות (פרק 24), כי יש אזורי זמן ושעון קיץ.

⚠️ טעויות נפוצות
  • Math.floor(totalSeconds / 60) לדקות — נותן את כל הדקות (62), לא את הדקות שאחרי השעות (2).
