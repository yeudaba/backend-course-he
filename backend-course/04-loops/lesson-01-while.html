1. while — כמו if שחוזר

while נראה כמעט כמו if. ההבדל: אחרי שהבלוק רץ, JavaScript חוזרת לבדוק את התנאי שוב. כל עוד הוא true — עוד סיבוב.

let count = 1;
while (count <= 3) {
  console.log(`סיבוב ${count}`);
  count++;
}
console.log("סיימנו, count =", count);
סיבוב 1
סיבוב 2
סיבוב 3
סיימנו, count = 4

3. לולאה אינסופית

אם שוכחים את הצעד, התנאי לעולם לא נהיה false:

playground/forever.js 
let count = 1;
while (count <= 3) {
  console.log(`סיבוב ${count}`);
}

הרצה תמלא את המסך ב"סיבוב 1" בלי סוף. אל תיבהל: לחץ Ctrl + C ב־Terminal — Node ייעצר מיד. זה קורה לכל מתכנת; העיקר לדעת לעצור ולמצוא איזה מהחלקים חסר.

⚠️ גרסה ערמומית: צעד בכיוון הלא נכון

let n = 10; while (n > 0) { n++; } — יש צעד, אבל הוא מתרחק מהסוף. שאל תמיד: "האם הצעד מקרב אותי לכך שהתנאי יהיה false?"

4. מתי while?

כשלא יודעים מראש כמה סיבובים יהיו — רק מתי לעצור. דוגמה: כמה שנים ייקח לחיסכון של 10,000 לגדול ל־15,000 בריבית 5%?

let balance = 10000;
let years = 0;
while (balance < 15000) {
  balance *= 1.05;
  years++;
}
console.log(`אחרי ${years} שנים: ${balance.toFixed(2)}`);
אחרי 9 שנים: 15513.28

לא ידענו שיהיו 9 סיבובים — הלולאה גילתה את זה. בשרת: "נסה להתחבר למסד עד שתצליח, עד 5 ניסיונות" (פרק 26) — זה while.
