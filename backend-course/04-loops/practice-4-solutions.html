P04-E73 · for...of או אינדקס? 🧠 הבנה רמה 1

💡 רמז 1

אם צריך את המיקום, או תו שכן (לפני/אחרי) — אינדקס. אם רק את התו — for...of.

💡 רמז 2

בונוס: ב־for...of נוצר ch חדש בכל סיבוב. ב־for הרגיל, i++ משנה את אותו משתנה.

✅ פתרון
  1. for...of — רק התו.
  2. אינדקס — צריך את המיקום.
  3. אינדקס — משווים את text[i] ל־text[i + 1].
  4. for...of — reversed = ch + reversed.
  5. אינדקס — i += 2.

בונוס: const אוסר הצבה מחדש. ב־for...of אף אחד לא מציב ל־ch — בכל סיבוב יש ch חדש. ב־for, i++ הוא הצבה (P04-E47).

const text = "a1b22";
for (let i = 0; i < text.length - 1; i++) {
  if (text[i] === text[i + 1]) {
    console.log(`תווים זהים צמודים במקום ${i}: ${text[i]}`);
  }
}
תווים זהים צמודים במקום 3: 2
⚠️ טעויות נפוצות
  • סעיף 3 עם i < text.length — בסיבוב האחרון text[i + 1] הוא undefined. כאן זה לא מפיל כלום, אבל זה סיבוב מיותר.

P04-E18 · פלינדרום 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

נקה: text.toLowerCase().replaceAll(" ", "").

💡 רמז 2

פתרון 2: for (let i = 0; i < clean.length / 2; i++) ומשווים clean[i] ל־clean[clean.length - 1 - i].

✅ פתרון
04-loops/starter/P04-E18.js 
const text = "Was it a car or a cat I saw";
const clean = text.toLowerCase().replaceAll(" ", "");

// פתרון 1: היפוך
let reversed = "";
for (const ch of clean) {
  reversed = ch + reversed;
}
console.log(`פלינדרום? ${clean === reversed}`);

// פתרון 2: שני מצביעים
let isPalindrome = true;
for (let i = 0; i < clean.length / 2; i++) {
  if (clean[i] !== clean[clean.length - 1 - i]) {
    isPalindrome = false;
    break;
  }
}
console.log(`פלינדרום? ${isPalindrome}`);
פלינדרום? true
פלינדרום? true

פתרון 2 עושה חצי עבודה ועוצר מוקדם. מחרוזת ריקה — פלינדרום (אין מה שלא תואם). זו שאלת ראיון נפוצה מאוד, והטכניקה "שני מצביעים מהקצוות" חוזרת בהרבה שאלות.

⚠️ טעויות נפוצות
  • clean.length - i בלי - 1 — מחוץ לגבולות, undefined.

P04-E19 · אות גדולה בכל מילה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

trim קודם. דגל atWordStart = true; כל רווח מדליק אותו, כל אות מכבה.

💡 רמז 2

כדי לא להוסיף רווח כפול: הוסף רווח לתוצאה רק אם התו האחרון בתוצאה אינו רווח.

✅ פתרון
04-loops/starter/P04-E19.js 
const input = "  learn   node and express ";
const text = input.trim();
let result = "";
let atWordStart = true;

for (const ch of text) {
  if (ch === " ") {
    if (result[result.length - 1] !== " ") {
      result += " ";
    }
    atWordStart = true;
  } else if (atWordStart) {
    result += ch.toUpperCase();
    atWordStart = false;
  } else {
    result += ch.toLowerCase();
  }
}

console.log(`[${result}]`);
[Learn Node And Express]

בפרק 6 זה יהיה שורה אחת עם split ו־map — אבל כדאי להבין מה קורה מתחת.

⚠️ טעויות נפוצות
  • לשכוח לכבות את הדגל — כל המילה יוצאת באותיות גדולות.

P04-E80 · ביקורת קוד: הלולאה המקוננת המוסתרת 🧠 הבנה רמה 4

💡 רמז 1

שיפור 1: מתי אפשר לעצור? שיפור 2: האם צריך להשוות את i = 5 ל־j = 2, אם כבר השווינו את 2 ל־5?

💡 רמז 2

להתחיל את j מ־i + 1 — וגם i !== j כבר לא נחוץ.

✅ פתרון
const text = "express";
let hasRepeat = false;
let steps = 0;
for (let i = 0; i < text.length; i++) {
  for (let j = 0; j < text.length; j++) {
    steps++;
    if (i !== j && text[i] === text[j]) {
      hasRepeat = true;
    }
  }
}
console.log(hasRepeat, steps);

let found = false;
let fewerSteps = 0;
for (let i = 0; i < text.length && !found; i++) {
  for (let j = i + 1; j < text.length; j++) {
    fewerSteps++;
    if (text[i] === text[j]) {
      found = true;
      break;
    }
  }
}
console.log(found, fewerSteps);
true 49
true 4
  1. true 49 — יש שני e (ושני s), ו־7 × 7 = 49 צעדים. הגרסה המשופרת מוצאת את אותה תשובה אחרי 4 צעדים בלבד.
  2. 1000 × 1000 = מיליון.
  3. (א) j מתחיל מ־i + 1 — כל זוג נבדק פעם אחת (בערך חצי מהצעדים). (ב) לעצור ברגע שנמצאה חזרה — break בפנימית, ו־!found בתנאי של החיצונית (break יוצא רק מהפנימית — P04-E78).
  4. בלי i !== j, כל תו "שווה לעצמו" — והתשובה תמיד true. בגרסה המשופרת זה לא נחוץ, כי j תמיד אחרי i.

(בפרק 7 תכיר Set, שעושה את זה במעבר אחד — 1000 צעדים במקום מיליון.)

⚠️ טעויות נפוצות
  • לחשוב ש־break לבד בפנימית מספיק כדי לעצור הכול.

P04-E24 · אתגר: יהלום 🤖 💻 כתיבת קוד 🤖 רמה 5

P04-E25 · אתגר: לוח סילוקין של הלוואה 🤖 💻 כתיבת קוד 🤖 רמה 5

💡 רמז 1

while (balance > 0). בכל סיבוב: interest = balance * rate, balance += interest, payment = Math.min(monthlyPayment, balance), balance -= payment.

💡 רמז 2

צוברים: totalPaid ו־totalInterest. הבדיקה לפני הלולאה: monthlyPayment <= loan * rate.

✅ פתרון
04-loops/starter/P04-E25.js 
const loan = 10000;
const rate = 0.01;
const monthlyPayment = 1500;

if (monthlyPayment <= loan * rate) {
  console.log("התשלום החודשי לא מכסה את הריבית — ההלוואה לעולם לא תיגמר");
} else {
  let balance = loan;
  let month = 0;
  let totalPaid = 0;
  let totalInterest = 0;

  console.log("חודש  ריבית  תשלום   יתרה");
  while (balance > 0) {
    month++;
    const interest = balance * rate;
    balance += interest;
    const payment = Math.min(monthlyPayment, balance);
    balance -= payment;
    totalPaid += payment;
    totalInterest += interest;
    console.log(
      `${String(month).padEnd(6)}${interest.toFixed(2).padEnd(7)}${payment.toFixed(2).padEnd(8)}${balance.toFixed(2)}`
    );
  }
  console.log("---");
  console.log(`סה״כ שולם: ${totalPaid.toFixed(2)}`);
  console.log(`סה״כ ריבית: ${totalInterest.toFixed(2)}`);
}

P04-E27 · ספירת סטטוסים 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

ארבעה מונים שמתחילים ב־0, ו־for (const ch of statuses). בתוך הלולאה — switch (ch).

💡 רמז 2

כל case מגדיל מונה אחד ונגמר ב־break. "לא מוכר" — ב־default.

✅ פתרון
04-loops/starter/P04-E27.js 
const statuses = "PPDCPD";

let paid = 0;
let delivered = 0;
let cancelled = 0;
let unknown = 0;

for (const ch of statuses) {
  switch (ch) {
    case "P":
      paid++;
      break;
    case "D":
      delivered++;
      break;
    case "C":
      cancelled++;
      break;
    default:
      unknown++;
  }
}

console.log(`שולמו: ${paid} | נמסרו: ${delivered} | בוטלו: ${cancelled} | לא מוכר: ${unknown}`);
שולמו: 3 | נמסרו: 2 | בוטלו: 1 | לא מוכר: 0

זה דפוס הצבירה משיעור 3, עם ארבעה צוברים במקום אחד. ה־switch מחליט איזה צובר לקדם. default הוא רשת הביטחון: בלעדיו, תו לא צפוי פשוט היה נעלם מהדוח, ואף אחד לא היה שם לב.

switch משווה עם ===, ולכן "p" לא שווה ל־"P". אם רוצים לקבל גם אותיות קטנות, כותבים switch (ch.toUpperCase()). בפרק 7 נחליף את ארבעת המשתנים באובייקט אחד.

⚠️ טעויות נפוצות
  • לשכוח break — P "נופל" ל־case "D" וסופר גם הזמנה שנמסרה.
  • להדפיס בתוך הלולאה — יוצאות שש שורות במקום שורת סיכום אחת.
