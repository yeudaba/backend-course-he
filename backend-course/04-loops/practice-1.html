P04-E30 · כמה סיבובים, ואיפה עוצרים?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

לכל קטע — כמה פעמים ירוץ הבלוק, ומה הערך של i אחרי הלולאה?

// א
let i = 5;
while (i < 5) {
  i++;
}
// ב
let i = 0;
while (i < 5) {
  i += 2;
}
// ג
let i = 10;
while (i > 0) {
  i -= 3;
}
// ד
let i = 1;
while (i < 100) {
  i *= 3;
}

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

P04-E33 · if או while?

🧠 הבנהרמה 1⏱ 5 דק׳ידע נדרש: שיעור 1

בלי להריץ — מה ידפיס כל קטע?

let x = 0;
if (x < 3) {
  x++;
}
console.log("if:", x);

let y = 0;
while (y < 3) {
  y++;
}
console.log("while:", y);

ואז: הסבר במשפט אחד מה ההבדל בין if ל־while, במילים של "כמה פעמים".

P04-E38 · padStart בעבודת יד

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 2, שיעור 1

בלי להריץ — מה יודפס?

let code = "7";
while (code.length < 4) {
  code = "0" + code;
}
console.log(code);
console.log("7".padStart(4, "0"));

let tag = "abc";
while (tag.length < 4) {
  tag = "0" + tag;
}
console.log(tag);

ואז: מה יקרה אם נכתוב code = code + "0" במקום "0" + code?

🔗 איך זה מתחבר: בפרק 2 השתמשת ב־padStart כ"קופסה שחורה". עכשיו אתה יכול לכתוב אותה בעצמך: לולאה שחוזרת "כל עוד האורך קטן מהיעד". הרבה מתודות מוכנות הן בעצם לולאה כזו.

P04-E39 · עד 3 ניסיונות

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 3, שיעור 1

בלי להריץ — מלא טבלת מעקב (tries, connected, התנאי) ונבא את הפלט:

let tries = 0;
let connected = false;
while (!connected && tries < 3) {
  tries++;
  console.log(`ניסיון ${tries}`);
  if (tries === 2) {
    connected = true;
  }
}
console.log(connected ? `התחברנו אחרי ${tries}` : "נכשל");

ואז: מה יודפס אם נשנה את tries === 2 ל־tries === 5? ולמה הלולאה לא אינסופית במקרה הזה?

🔗 איך זה מתחבר: התנאי של while הוא ביטוי בוליאני כמו בפרק 3 — אפשר לשלב בו && ו־!. זה הדפוס "נסה עד שתצליח, אבל לא יותר מ־N פעמים", שתראה בשרת בכל התחברות למסד נתונים.

P04-E40 · NaN בתנאי של לולאה

🧠 הבנהרמה 3⏱ 10 דק׳ידע נדרש: פרק 2, פרק 3, שיעור 1

קלט לא תקין הגיע לשתי לולאות. בלי להריץ — מה יקרה בכל אחת?

// א
let n = Number("abc");
let rounds = 0;
while (n < 10) {
  n++;
  rounds++;
}
console.log("סיבובים:", rounds);
// ב
let m = Number("abc");
while (m !== 10) {
  m++;
}
console.log("סיימנו");

ואז: איזו בדיקה היית מוסיף לפני הלולאה?

🔗 איך זה מתחבר: בפרק 2 ראית ש־NaN "מדבק"; בפרק 3 — ש־NaN לא שווה לכלום, ושכל השוואה איתו היא false. בלולאה זה הופך לשני באגים הפוכים: לולאה שלא רצה בכלל, ולולאה שלא נגמרת.
