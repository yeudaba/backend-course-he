P04-E01 · מעקב אחרי while

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 1

מלא טבלת מעקב (n לפני כל בדיקה, תוצאת התנאי, מה הודפס) ונבא את הפלט:

let n = 1;
while (n < 40) {
  console.log(n);
  n = n * 3;
}
console.log("סוף:", n);

כמה פעמים נבדק התנאי? כמה פעמים רץ הבלוק?

P04-E06 · ספירה לאחור 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 5 דק׳ידע נדרש: שיעור 1

עם while, כתוב תוכנית שמתחילה ב־let n = 10; וסופרת לאחור מ־10 ל־1 בקפיצות של 3 ומדפיסה בסוף "המראה":

P04-E13 · השערת קולץ 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 15 דק׳ידע נדרש: שיעור 1

קח מספר חיובי. אם הוא זוגי — חלק ב־2; אם אי־זוגי — כפול 3 ועוד 1. חזור עד שמגיעים ל־1. כתוב תוכנית שמדפיסה את המסלול ואת מספר הצעדים, עבור const start = 6;:

6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1
צעדים: 8

נסה גם 27 (111 צעדים!). למה כאן while ולא for?

📄 כותבים בקובץ 04-loops/starter/P04-E13.js (יש בו רק הערה עם המשימה), מריצים ובודקים:

% node 04-loops/starter/P04-E13.js
% npm run check P04-E13

P04-E26 · סכום עד יעד 🤖

💻 כתיבת קוד 🤖🔥 חימוםרמה 2⏱ 10 דק׳ידע נדרש: שיעור 1

בקובץ כבר כתובה השורה const goal = 100;. חבר 1 + 2 + 3 + ... עד שהסכום מגיע ליעד או עובר אותו, והדפס:

הבודק יחליף את היעד ב־10 וב־1000. אתה לא יודע מראש כמה מספרים תצטרך — רק מתי לעצור.
