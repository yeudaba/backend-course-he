P04-E03 · break ו־continue

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 3

מה ידפיס הקוד? מלא טבלת מעקב של i ו־total.

let total = 0;
for (let i = 1; i <= 10; i++) {
  if (i % 3 === 0) {
    continue;
  }
  if (total > 12) {
    break;
  }
  total += i;
}
console.log(total);

P04-E60 · break מול continue

let a = "";
for (let i = 1; i <= 6; i++) {
  if (i === 4) {
    break;
  }
  a += i;
}
console.log(a);

  if (i === 4) {

P04-E61 · המקסימום שמתחיל מ־0

  const value = i * (i - 10);

P04-E65 · כמה בדיקות חסך ה־break?

בלי להריץ — מה יודפס?

const n = 221;
let checks = 0;
let divisor = null;
for (let d = 2; d < n; d++) {
  checks++;
  if (n % d === 0) {
    divisor = d;
    break;
  }
}
console.log(`${n} ${divisor === null ? "ראשוני" : `מתחלק ב־${divisor}`}`);
console.log(`בדיקות: ${checks}`);

ואז: כמה בדיקות היו בלי ה־break? ומה היה ערכו של divisor בסוף?

🔗 איך זה מתחבר: ternary ו־null כ"עוד לא נמצא" מפרקים 1 ו־3, עם הדגל וה־break מהשיעור. ה־ternary בשורת ההדפסה בוחר הודעה לפי אם הלולאה מצאה משהו.

P04-E66 · continue או if/else?

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: פרק 3, שיעור 3

שתי לולאות שאמורות לעשות אותו דבר: לסכום מחירים של מוצרים במלאי, ולדלג על אזלו. (המחיר של המוצר ה־i הוא i * 10, והמוצרים 2 ו־5 אזלו.)

let a = 0;
for (let i = 1; i <= 6; i++) {
  if (i === 2 || i === 5) {
    continue;
  }
  a += i * 10;
}
let b = 0;
for (let i = 1; i <= 6; i++) {
  if (i !== 2 && i !== 5) {
    b += i * 10;
  }
}
console.log(a, b);

(1) מה יודפס? (2) למה התנאי בגרסה ב הוא && ולא ||? (3) מתי continue עדיף?

🔗 איך זה מתחבר: בפרק 3 (P03-E64) ראית ש"לא (א או ב)" שווה ל"לא א וגם לא ב". כאן זה ההבדל בין שתי הלולאות: אחת אומרת "דלג אם", השנייה "עשה אם לא".

P04-E67 · צובר שהפך למחרוזת

  a += i * 2;
}
let b = 0;
for (let i = 1; i <= 3; i++) {
  b += i * 2;
}
