P04-E03 · break ו־continue

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 3

מה ידפיס הקוד? מלא טבלת מעקב של i ו־total.

let total = 0;
for (let i = 1; i <= 10; i++) {
  if (i % 3 === 0) {
    continue;
  }
  if (total > 12) {
    break;
  }
  total += i;
}
console.log(total);
