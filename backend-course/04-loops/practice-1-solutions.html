P04-E31 · איזה חלק חסר? 🧠 הבנה רמה 2

💡 רמז 1

א — מה ש־Node פוגש בשורה הראשונה. ב — לאן הצעד לוקח את n?

💡 רמז 2

ד — מה ערך התנאי כבר בבדיקה הראשונה?

✅ פתרון

  4. ד — תנאי הפוך: 0 > 3 הוא false — הלולאה לא רצה אפילו פעם אחת, בלי שום שגיאה. צריך tries < 3.
let tries = 0;
while (tries > 3) {
  console.log(`ניסיון ${tries}`);
  tries++;
}
console.log("אחרי הלולאה, tries =", tries);
אחרי הלולאה, tries = 0
⚠️ טעויות נפוצות
  • ד הוא הכי ערמומי: אין שגיאה ואין לולאה אינסופית — פשוט כלום. כשלולאה "לא עושה כלום", בדוק את התנאי בבדיקה הראשונה.

P04-E32 · אינסופית או לא? 🧠 הבנה רמה 2

💡 רמז 1

א: רשום את הערכים: 10, 7, 4, 1, ... האם 0 מופיע?

💡 רמז 2

ד: מספרים ב־JavaScript לא גדלים לנצח — בסוף מגיעים ל־Infinity. האם Infinity > 0?

✅ פתרון
  1. אינסופית. 10, 7, 4, 1, ‎-2, ‎-5... מדלגים מעל 0. תנאי עם !== מסוכן; n > 0 היה עוצר.
  2. נגמרת אחרי 20 סיבובים, ב־10. (0.5 נשמר בזיכרון בדיוק, אז אין כאן הפתעה.)
  3. נגמרת אחרי 2 סיבובים: "ab" (אורך 2), "abab" (אורך 4).
  4. אינסופית. m מגיע ל־Infinity, ו־Infinity * 2 הוא עדיין Infinity — תמיד גדול מ־0.
let x = 0;
let rounds = 0;
while (x < 10) {
  x += 0.5;
  rounds++;
}
let s = "";
while (s.length < 3) {
  s += "ab";
}
console.log(rounds, x, s);
20 10 abab
⚠️ טעויות נפוצות
  • א: "4 סיבובים" — מניחים ש־!== עוצר "מתישהו". רק אם הערך פוגע בדיוק ב־0.

P04-E33 · if או while? 🧠 הבנה רמה 1

💡 רמז 1

if בודק פעם אחת. while חוזר לבדוק אחרי כל סיבוב.

💡 רמז 2

ב־while: 0 ← 1 ← 2 ← 3, ואז 3 < 3?

✅ פתרון
let x = 0;
if (x < 3) {
  x++;
}
console.log("if:", x);

let y = 0;
while (y < 3) {
  y++;
}
console.log("while:", y);
if: 1
while: 3

if מריץ את הבלוק אפס או אחת פעמים. while — אפס או יותר, עד שהתנאי נשבר.

⚠️ טעויות נפוצות
  • לחשוב ש־while "עוצר ב־2" כי התנאי הוא < 3. הוא עוצר כשהבדיקה נכשלת — אחרי שהמונה כבר הגיע ל־3.

P04-E13 · השערת קולץ 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

while (n !== 1), ובתוכו if/else.

💡 רמז 2

בנה את המסלול כמחרוזת: מתחילים ב־String(start), ובכל צעד מוסיפים → ${n}.

✅ פתרון
04-loops/starter/P04-E13.js 
const start = 6;
let n = start;
let steps = 0;
let path = String(n);

while (n !== 1) {
  if (n % 2 === 0) {
    n = n / 2;
  } else {
    n = n * 3 + 1;
  }
  steps++;
  path += ` → ${n}`;
}

console.log(path);
console.log(`צעדים: ${steps}`);
6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1
צעדים: 8

למה while: אין דרך לדעת מראש כמה צעדים — רק מתי לעצור. (אגב, איש לא הוכיח שהלולאה הזו תמיד מסתיימת — זו שאלה פתוחה במתמטיקה!) עם 0 או מספר שלילי — לולאה אינסופית. בדיקת קלט לפני הלולאה הייתה מונעת את זה.

⚠️ טעויות נפוצות
  • להתחיל את path כ־"" ולהוסיף → בכל סיבוב — יוצא חץ מיותר בהתחלה.

P04-E20 · ההמראה שלא מגיעה 🤖 💻 כתיבת קוד 🤖 רמה 4

P04-E26 · סכום עד יעד 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

"כל עוד הסכום קטן מהיעד" — זה התנאי של ה־while. אילו משתנים משתנים בכל סיבוב?

💡 רמז 2

שני משתנים: let sum = 0; ו־let n = 0;. בכל סיבוב: n++ ואז sum += n.

✅ פתרון
04-loops/starter/P04-E26.js 
const goal = 100;

let sum = 0;
let n = 0;
while (sum < goal) {
  n++;
  sum += n;
}

console.log(`הגענו ל־${sum} אחרי ${n} מספרים`);
הגענו ל־105 אחרי 14 מספרים

מעקב קצר: אחרי 13 מספרים הסכום 91 (עדיין פחות מ־100), אחרי 14 הוא 105, והתנאי 105 < 100 נכשל. עם יעד 10 הלולאה עוצרת בדיוק ב־10, כי 10 < 10 הוא false.

הסדר בתוך הלולאה חשוב: קודם n++ ורק אחר כך sum += n. בסדר ההפוך הסיבוב הראשון מוסיף 0, וכל הספירה זזה באחד.

⚠️ טעויות נפוצות
  • while (sum <= goal) — עם יעד 10 הלולאה תמשיך ל־15, כי היא לא עוצרת כשמגיעים בדיוק ליעד.
  • sum += n; n++; — הסיבוב הראשון מוסיף 0, ומספר המספרים יוצא גדול באחד.

P04-E37 · חיידקים שמכפילים את עצמם 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

while (count <= target) — "יותר ממיליון" אומר שבדיוק מיליון עוד לא מספיק.

💡 רמז 2

דקות = הכפלות × 20. שעות: Math.floor(minutes / 60); דקות: `${minutes % 60}`.padStart(2, "0").

✅ פתרון
04-loops/starter/P04-E37.js 
const start = 100;
const target = 1000000;
let count = start;
let doublings = 0;
while (count <= target) {
  count *= 2;
  doublings++;
}
const minutes = doublings * 20;
const hours = Math.floor(minutes / 60);
const rest = `${minutes % 60}`.padStart(2, "0");
console.log(`אחרי ${doublings} הכפלות (${hours}:${rest} שעות): ${count} חיידקים`);
אחרי 14 הכפלות (4:40 שעות): 1638400 חיידקים

עם 1000: 4 הכפלות, 1:20, 1600 חיידקים.

⚠️ טעויות נפוצות
  • לחשב את הזמן בתוך הלולאה בכל סיבוב — עובד, אבל מיותר. את מה שתלוי רק בתוצאה הסופית מחשבים אחרי הלולאה.

P04-E39 · עד 3 ניסיונות 🧠 הבנה רמה 2

💡 רמז 1

הלולאה ממשיכה רק אם שני החלקים true: עוד לא התחברנו, וגם נשארו ניסיונות.

💡 רמז 2

עם tries === 5: connected לעולם לא יהיה true. מה עוצר את הלולאה?

✅ פתרון
let tries = 0;
let connected = false;
while (!connected && tries < 3) {
  tries++;
  console.log(`ניסיון ${tries}`);
  if (tries === 2) {
    connected = true;
  }
}
console.log(connected ? `התחברנו אחרי ${tries}` : "נכשל");
ניסיון 1
ניסיון 2
התחברנו אחרי 2

עם tries === 5: "ניסיון 1", "ניסיון 2", "ניסיון 3", "נכשל". החלק tries < 3 הוא "רשת ביטחון" — גם אם ההצלחה לא מגיעה, הלולאה נעצרת.

⚠️ טעויות נפוצות
  • !connected || tries < 3 — עם "או", מספיק שלא התחברנו כדי להמשיך — ואם לא מצליחים, זו לולאה אינסופית.

P04-E40 · NaN בתנאי של לולאה 🧠 הבנה רמה 3

💡 רמז 1

NaN < 10? ו־NaN !== 10?

💡 רמז 2

NaN + 1 הוא עדיין NaN.

✅ פתרון
let n = Number("abc");
let rounds = 0;
while (n < 10) {
  n++;
  rounds++;
}
console.log("סיבובים:", rounds);
סיבובים: 0

א: NaN < 10 הוא false — הלולאה לא רצה בכלל. אין שגיאה, פשוט "שום דבר לא קרה".

ב: NaN !== 10 הוא תמיד true, ו־m++ משאיר NaN — לולאה אינסופית (Ctrl + C).

הבדיקה: if (Number.isNaN(n)) { ... } לפני הלולאה — הדפוס של בדיקת קלט מפרק 3. ועוד לקח: תנאי לולאה עם < או > בטוח יותר מ־!==.

⚠️ טעויות נפוצות
  • לחשוב ש־Number("abc") זורק שגיאה. הוא מחזיר NaN בשקט — והשקט הזה הוא הבעיה.

P04-E42 · מעשרוני לבינארי 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

צריך עותק שמשתנה (let rest = n;) — כי בסוף רוצים להדפיס גם את n המקורי.

💡 רמז 2

bits = (rest % 2) + bits; — הספרה החדשה משמאל.

✅ פתרון
04-loops/starter/P04-E42.js 
const n = 13;
let rest = n;
let bits = "";
while (rest > 0) {
  bits = (rest % 2) + bits;
  rest = Math.floor(rest / 2);
}
if (bits === "") {
  bits = "0";
}
console.log(`${n} בבינארי: ${bits}`);
13 בבינארי: 1101

13 ← שארית 1, נשאר 6 ← שארית 0, נשאר 3 ← 1, נשאר 1 ← 1, נשאר 0. קוראים מהסוף להתחלה: 1101.

⚠️ טעויות נפוצות
  • bits += rest % 2 — הספרות יוצאות הפוך (1011).
  • let bits = 0; — אז 1 + 0 הוא חיבור, לא שרשור. מתחילים מ־"".

P04-E43 · מכונת קפה 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

קודם בדיקת קלט (trim() === "" או Number.isNaN). רק ב־else — הלולאה.

💡 רמז 2

while (money >= price) { money -= price; cups++; }

✅ פתרון
04-loops/starter/P04-E43.js 
const moneyInput = "20";
const price = 6.5;
const amount = Number(moneyInput);
if (moneyInput.trim() === "" || Number.isNaN(amount)) {
  console.log("שגיאה: סכום לא תקין");
} else {
  let money = amount;
  let cups = 0;
  while (money >= price) {
    money -= price;
    cups++;
  }
  console.log(`נקנו ${cups} ${cups === 1 ? "כוס" : "כוסות"}, נשאר ${money.toFixed(2)} ₪`);
}
נקנו 3 כוסות, נשאר 0.50 ₪
⚠️ טעויות נפוצות
  • לשכוח את הבדיקה של "" — Number("") הוא 0, ואז "נקנו 0 כוסות, נשאר 0.00" במקום שגיאה.
