P04-E01 · מעקב אחרי while 🧠 הבנה רמה 1

💡 רמז 1

n מוכפל פי 3 בכל סיבוב: 1, 3, ...

💡 רמז 2

27 < 40, אבל 81 לא.

✅ פתרון
let n = 1;
while (n < 40) {
  console.log(n);
  n = n * 3;
}
console.log("סוף:", n);
1
3
9
27
סוף: 81

התנאי נבדק 5 פעמים (1, 3, 9, 27, 81), הבלוק רץ 4. אחרי הלולאה n הוא 81 — גדול מהגבול, כי הבדיקה קורית רק בתחילת סיבוב.

⚠️ טעויות נפוצות
  • לחשוב שהלולאה עוצרת "ב־40" — היא עוצרת בבדיקה הראשונה שנכשלת.

P04-E06 · ספירה לאחור 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

אתחול 10, תנאי > 0, צעד -= 3.

💡 רמז 2

אחרי 1 מגיעים ל־‎-2, והתנאי נכשל.

✅ פתרון
04-loops/starter/P04-E06.js 
let n = 10;
while (n > 0) {
  console.log(n);
  n -= 3;
}
console.log("המראה!");
10
7
4
1
המראה!
⚠️ טעויות נפוצות
  • תנאי n !== 0 — n לעולם לא יהיה 0 (10, 7, 4, 1, ‎-2...) — לולאה אינסופית. השתמש ב־>, לא ב־!==, כשיש קפיצות.

P04-E13 · השערת קולץ 🤖 💻 כתיבת קוד 🤖 רמה 3

💡 רמז 1

while (n !== 1), ובתוכו if/else.

💡 רמז 2

בנה את המסלול כמחרוזת: מתחילים ב־String(start), ובכל צעד מוסיפים → ${n}.

✅ פתרון
04-loops/starter/P04-E13.js 
const start = 6;
let n = start;
let steps = 0;
let path = String(n);

while (n !== 1) {
  if (n % 2 === 0) {
    n = n / 2;
  } else {
    n = n * 3 + 1;
  }
  steps++;
  path += ` → ${n}`;
}

console.log(path);
console.log(`צעדים: ${steps}`);
6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1
צעדים: 8

למה while: אין דרך לדעת מראש כמה צעדים — רק מתי לעצור. (אגב, איש לא הוכיח שהלולאה הזו תמיד מסתיימת — זו שאלה פתוחה במתמטיקה!) עם 0 או מספר שלילי — לולאה אינסופית. בדיקת קלט לפני הלולאה הייתה מונעת את זה.

⚠️ טעויות נפוצות
  • להתחיל את path כ־"" ולהוסיף → בכל סיבוב — יוצא חץ מיותר בהתחלה.

P04-E20 · ההמראה שלא מגיעה 🤖 💻 כתיבת קוד 🤖 רמה 4

💡 רמז 1

האם seconds משתנה אי פעם?

💡 רמז 2

seconds + 1 מחשב ערך — אבל לא מציב אותו בשום מקום. וגם הכיוון שגוי.

✅ פתרון

הצעד שבור פעמיים: seconds + 1 הוא ביטוי שהתוצאה שלו נזרקת (אין =), וגם אם היה מוצב — הוא מגדיל במקום להקטין, כך שהתנאי seconds > 0 היה נשאר תמיד true.

let seconds = 5;
while (seconds > 0) {
  console.log(seconds);
  seconds--;
}
console.log("🚀 המראה!");
5
4
3
2
1
🚀 המראה!
⚠️ טעויות נפוצות
  • לתקן ל־seconds += 1 — עכשיו יש הצבה, ועדיין לולאה אינסופית.

P04-E26 · סכום עד יעד 🤖 💻 כתיבת קוד 🤖 רמה 2

💡 רמז 1

"כל עוד הסכום קטן מהיעד" — זה התנאי של ה־while. אילו משתנים משתנים בכל סיבוב?

💡 רמז 2

שני משתנים: let sum = 0; ו־let n = 0;. בכל סיבוב: n++ ואז sum += n.

✅ פתרון
04-loops/starter/P04-E26.js 
const goal = 100;

let sum = 0;
let n = 0;
while (sum < goal) {
  n++;
  sum += n;
}

console.log(`הגענו ל־${sum} אחרי ${n} מספרים`);
הגענו ל־105 אחרי 14 מספרים

מעקב קצר: אחרי 13 מספרים הסכום 91 (עדיין פחות מ־100), אחרי 14 הוא 105, והתנאי 105 < 100 נכשל. עם יעד 10 הלולאה עוצרת בדיוק ב־10, כי 10 < 10 הוא false.

הסדר בתוך הלולאה חשוב: קודם n++ ורק אחר כך sum += n. בסדר ההפוך הסיבוב הראשון מוסיף 0, וכל הספירה זזה באחד.

⚠️ טעויות נפוצות
  • while (sum <= goal) — עם יעד 10 הלולאה תמשיך ל־15, כי היא לא עוצרת כשמגיעים בדיוק ליעד.
  • sum += n; n++; — הסיבוב הראשון מוסיף 0, ומספר המספרים יוצא גדול באחד.
