P04-E45 · מ־for ל־while ובחזרה

🧠 הבנהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 2

כתוב על דף:

  1. את הלולאה הזו כ־while, עם אותו פלט:
for (let i = 2; i <= 8; i += 2) {
  console.log(i);
}
  1. את הלולאה הזו כ־for:
let n = 5;
while (n > 0) {
  console.log(n);
  n--;
}

P04-E54 · תנאי בתוך for

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 3, שיעור 2

בלי להריץ — מה יודפס?

let pattern = "";
for (let i = 1; i <= 7; i++) {
  pattern += i % 3 === 0 ? "#" : "-";
}
console.log(pattern);

let label = "";
for (let i = 1; i <= 4; i++) {
  if (i === 1) {
    label += "ראשון";
  } else if (i === 4) {
    label += " ואחרון";
  } else {
    label += ", אמצעי";
  }
}
console.log(label);

🔗 איך זה מתחבר: כל מה שלמדת בפרק 3 — ternary, if / else if — עובד בתוך הבלוק של הלולאה. הלולאה מחליטה כמה פעמים, והתנאי מחליט מה לעשות בכל פעם.

P04-E28 · טבלת המרת טמפרטורות 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 3⏱ 15 דק׳ידע נדרש: שיעור 2

🔁 חזרה על padStart ו־toFixed (פרק 2) ועל תנאים (פרק 3), בתוך לולאת for. כתוב תוכנית שמתחילה בשלוש השורות:

const from = -10;
const to = 40;
const step = 10;

ומדפיסה טבלה מ־from עד to (כולל) בקפיצות של step. בכל שורה: הצלזיוס מיושר לימין ברוחב 3, הפרנהייט (C × 9 / 5 + 32) עם ספרה אחת אחרי הנקודה ומיושר ברוחב 5, ובסוגריים: קר מתחת ל־10, נעים מ־10 עד 25 (כולל), חם מעל 25.

-10°C =  14.0°F (קר)
  0°C =  32.0°F (קר)
 10°C =  50.0°F (נעים)
 20°C =  68.0°F (נעים)
 30°C =  86.0°F (חם)
 40°C = 104.0°F (חם)

הבודק מריץ גם עם טווחים אחרים, ובודק את הגבול 25/26.
