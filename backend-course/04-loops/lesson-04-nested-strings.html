שיעור 4 — לולאות על מחרוזות ולולאות מקוננות

⏱ ~30 דקות

🎯 בשיעור הזה
  • מעבר על תווים של מחרוזת: עם אינדקס, ועם for...of.
  • לולאה בתוך לולאה — ומה זה עושה למספר הצעדים.

1. מעבר על מחרוזת עם אינדקס

מפרק 2 אתה יודע ש־text[i] הוא התו במקום i, ו־text.length הוא האורך. יחד עם for:

const code = "A7B2";
for (let i = 0; i < code.length; i++) {
  console.log(`מקום ${i}: ${code[i]}`);
}
מקום 0: A
מקום 1: 7
מקום 2: B
מקום 3: 2

הכותרת for (let i = 0; i < text.length; i++) היא אולי השורה הנפוצה ביותר בתכנות. שים לב ל־< (לא <=): האינדקס האחרון הוא length - 1.

2. for...of — בלי אינדקס

כשלא צריך את המיקום, רק את התו עצמו — יש קיצור:

const word = "banana";
let countA = 0;
for (const ch of word) {
  if (ch === "a") {
    countA++;
  }
}
console.log(`ב־${word} יש ${countA} פעמים a`);
ב־banana יש 3 פעמים a

קוראים: "לכל ch מתוך word". כאן const תקין — בכל סיבוב נוצר ch חדש. בפרק 6 נשתמש ב־for...of על מערכים — שם הוא יהיה הכלי הראשי.

3. לולאות מקוננות

לולאה בתוך לולאה: על כל סיבוב של החיצונית, הפנימית רצה מההתחלה ועד הסוף. כמו שעון: על כל שעה, המחוג של הדקות מסתובב 60 פעם.

for (let row = 1; row <= 3; row++) {
  let line = "";
  for (let col = 1; col <= 4; col++) {
    line += String(row * col).padStart(4);
  }
  console.log(line);
}
   1   2   3   4
   2   4   6   8
   3   6   9  12

הלולאה החיצונית רצה 3 פעמים, הפנימית 4 פעמים בכל אחת — סה״כ 12 חישובים. שימו לב ש־line מתאפס בתוך החיצונית: שורה חדשה לכל row.

💼 בעולם העבודה

הבאג הכי יקר שמפתחי Backend מתחילים כותבים: לולאה מקוננת מוסתרת — למשל, על כל הזמנה (לולאה) מחפשים את הלקוח ברשימת כל הלקוחות (עוד לולאה). עם 100 הזמנות זה מהיר; עם 100,000 השרת "נתקע". בפרק 7 נלמד Map שפותר את זה, ובפרק 19 את הגרסה שלו במסד נתונים (בעיית N+1).
