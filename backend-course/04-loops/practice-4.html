P04-E04 · for...of ולולאה מקוננת

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

מה ידפיס כל קטע?

let a = "";
for (const ch of "abc") {
  a = a + ch + ch;
}
console.log(a);

let count = 0;
for (let i = 0; i < 4; i++) {
  for (let j = 0; j < 3; j++) {
    count++;
  }
}
console.log(count);

let pairs = "";
for (let i = 1; i <= 2; i++) {
  for (let j = 1; j <= 2; j++) {
    pairs += `${i}${j} `;
  }
}
console.log(pairs);

P04-E05 · כמה צעדים?

🧠 הבנהרמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

לפונקציה (שעוד לא למדנו לכתוב) יש אחד משני קטעי הקוד הבאים. n הוא מספר ההזמנות במערכת. כמה פעמים תרוץ שורת ה־count++ בכל קטע כש־n = 10? כש־n = 1,000? איזה קטע יהיה בעייתי בשרת, ולמה?

// קטע א
for (let i = 0; i < n; i++) {
  count++;
}
// קטע ב
for (let i = 0; i < n; i++) {
  for (let j = 0; j < n; j++) {
    count++;
  }
}

P04-E27 · ספירת סטטוסים 🤖

💻 כתיבת קוד 🤖🔁 חזרהרמה 2⏱ 10 דק׳ידע נדרש: שיעור 4

🔁 חזרה על switch (פרק 3), הפעם בתוך לולאה. מערכת הזמנות שולחת דוח יומי כמחרוזת, תו לכל הזמנה: P — שולמה, D — נמסרה, C — בוטלה. כל תו אחר — "לא מוכר".

כתוב תוכנית שמתחילה ב־const statuses = "PPDCPD";, עוברת על התווים, וסופרת עם switch:

שולמו: 3 | נמסרו: 2 | בוטלו: 1 | לא מוכר: 0

הבודק מחליף את המחרוזת — גם במחרוזת ריקה ובאותיות קטנות (p הוא "לא מוכר").
