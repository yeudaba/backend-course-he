P04-E79 · for...of על מספר

🧠 הבנהרמה 2⏱ 5 דק׳ידע נדרש: פרק 2, שיעור 4

מישהו רוצה לסכום את הספרות של מספר עם for...of. בלי להריץ — מה יקרה בכל גרסה?

// א
const n = 1234;
let sumA = 0;
for (const d of n) {
  sumA += d;
}
// ב
const n = 1234;
let sumB = 0;
for (const d of `${n}`) {
  sumB += d;
}
console.log(sumB);
// ג
const n = 1234;
let sumC = 0;
for (const d of String(n)) {
  sumC += Number(d);
}
console.log(sumC);

🔗 איך זה מתחבר: for...of עובר על דברים שיש להם "תוכן לעבור עליו" — מחרוזת כן, מספר לא. ההמרות מפרק 2 (String, Number, template literal) הן מה שמחבר בין השניים. (ב־P04-E16 פתרת את אותה בעיה בלי מחרוזות בכלל — עם %.)

P04-E80 · ביקורת קוד: הלולאה המקוננת המוסתרת

🧠 הבנהרמה 4⏱ 15 דק׳ידע נדרש: כל הפרק

הקוד בודק אם יש תו שחוזר במחרוזת:

const text = "express";
let hasRepeat = false;
let steps = 0;
for (let i = 0; i < text.length; i++) {
  for (let j = 0; j < text.length; j++) {
    steps++;
    if (i !== j && text[i] === text[j]) {
      hasRepeat = true;
    }
  }
}
console.log(hasRepeat, steps);

(1) מה יודפס? (2) כמה צעדים היו למחרוזת של 1000 תווים? (3) הצע שני שיפורים שמקטינים את מספר הצעדים — בלי לשנות את התשובה. (4) למה בכלל צריך את i !== j?

🔗 איך זה מתחבר: לולאה מקוננת (שיעור 4), דגל ו־break (שיעור 3), ו־&& מפרק 3. זה הבאג מקופסת "בעולם העבודה" בשיעור — לולאה בתוך לולאה שנראית תמימה, ונהיית איטית מאוד כשהנתונים גדלים.
