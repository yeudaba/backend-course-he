⚡ מבחן כניסה — אולי אפשר לדלג?
  1. כמה פעמים תרוץ הלולאה: for (let i = 0; i < 5; i++)?
  2. מה ידפיס: let s = 0; for (let i = 1; i <= 4; i++) { s += i; } console.log(s);
  3. כתוב לולאה שמדפיסה 10, 8, 6, 4, 2.
  4. מה ההבדל בין break ל־continue?
  5. מה ידפיס: let n = 1; while (n < 50) { n *= 3; } console.log(n);
  6. כתוב לולאה שסופרת כמה פעמים האות "a" מופיעה ב־"banana".
  7. מה הבעיה: let i = 0; while (i < 3) { console.log(i); }
  8. כמה פעמים תודפס המילה: for (let r = 0; r < 3; r++) { for (let c = 0; c < 4; c++) { console.log("x"); } }
  9. מה יקרה: for (let i = 0; i < 3; i++) {} ואז console.log(i);
  10. איך מוצאים את המספר הגדול ביותר בלולאה (במילים)?

🎯 בסוף הפרק תדע
  • לחזור על קוד עם while ועם for, ולעצור בזמן.
  • לעקוב אחרי לולאה בטבלת מעקב — כולל הסיבוב האחרון.
  • להשתמש בדפוסי צבירה: סכום, ספירה, מקסימום, בניית מחרוזת, דגל "נמצא".
  • לשלוט בזרימה עם break ו־continue.
  • לעבור על תווים של מחרוזת עם for...of, ולכתוב לולאות מקוננות.

🤔 למה צריך את זה?

ב־P01-E24 (עגלת הקניות) כתבת אותו בלוק ארבע פעמים. ומה אם בעגלה 200 פריטים? או אם השרת צריך לעבור על 10,000 הזמנות כדי לחשב דוח יומי? לולאה כותבת את החזרה פעם אחת — ונותנת למחשב לחזור כמה שצריך.
