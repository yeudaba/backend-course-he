P04-E03 · break ו־continue

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 3

מה ידפיס הקוד? מלא טבלת מעקב של i ו־total.

let total = 0;
for (let i = 1; i <= 10; i++) {
  if (i % 3 === 0) {
    continue;
  }
  if (total > 12) {
    break;
  }
  total += i;
}
console.log(total);

P04-E05 · כמה צעדים?

רמה 1⏱ 10 דק׳ידע נדרש: שיעור 4

לפונקציה (שעוד לא למדנו לכתוב) יש אחד משני קטעי הקוד הבאים. n הוא מספר ההזמנות במערכת. כמה פעמים תרוץ שורת ה־count++ בכל קטע כש־n = 10? כש־n = 1,000? איזה קטע יהיה בעייתי בשרת, ולמה?

// קטע א
for (let i = 0; i < n; i++) {
  count++;
}
// קטע ב
for (let i = 0; i < n; i++) {
  for (let j = 0; j < n; j++) {
    count++;
  }
}
