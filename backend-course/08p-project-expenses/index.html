פרויקט 1 — מנהל הוצאות בשורת הפקודה

⏱ 4–6 מפגשים

🧰 לפני שמתחילים — פרויקט 1

מה צריך שכבר יהיה מותקן: VS Code, Node.js 24+, ESLint והבודק האוטומטי (פרקים 5, 8).

מה מתקינים עכשיו: כלום. כל מה שהפרויקט צריך מובנה ב־Node.

📂 העתקת חומרי הפרק: ב־Finder, העתק את התיקייה 08p-project-expenses מתוך ~/Desktop/Backend/backend-course אל ~/dev/backend-course (גרירה עם ⌥ Option). אם התיקייה כבר שם מהעתקה קודמת ואתה רוצה לשמור את מה שכתבת — בחר Keep Both / Stop ולא Replace.

הפרויקט שלך נמצא ב־08p-project-expenses/starter/expenses-cli. אפשר לפתוח רק אותו ב־VS Code (code 08p-project-expenses/starter/expenses-cli), אבל את הבודק מריצים מתיקיית הקורס (~/dev/backend-course).

✔ בדיקה שהסביבה מוכנה — ב־Terminal של VS Code, מתוך ~/dev/backend-course:

% node -v
v24.11.0

(כל גרסה 24 ומעלה תקינה.)

✔ הבודק: npm run check PR1 — יריץ את שלושת קובצי הבדיקה של הפרויקט (כרגע כולם נכשלים).

🎯 בסוף הפרק תדע
  • לבנות תוכנית שלמה מכמה מודולים, עם הפרדה בין לוגיקה, אחסון וממשק.
  • לשמור נתונים בקובץ JSON ולטעון אותם בהפעלה הבאה.
  • לקבל פקודות מה־Terminal (process.argv) ולהחזיר קוד יציאה.
  • לטפל בכל קלט לא תקין בהודעה ברורה, בלי שהתוכנית תקרוס.
  • להגיע לפרויקט ראשון שעולה לתיק העבודות (בפרק 9 — ל־GitHub).

🤔 מה בונים

כלי שורת פקודה לניהול הוצאות אישיות. אין כאן דפדפן ואין שרת — אבל המבנה הוא בדיוק המבנה של שרת: שכבת לוגיקה (חישובים וחוקים), שכבת אחסון (קובץ; בהמשך — מסד נתונים), ושכבת ממשק (כאן Terminal; בהמשך — HTTP). כשתגיע לפרק 15, תחליף רק את שכבת הממשק — והלוגיקה תישאר.

% node src/cli.js add 2026-10-01 food 54.5 lunch with team
נוספה הוצאה #1
% node src/cli.js add 2026-10-03 transport 12
נוספה הוצאה #2
% node src/cli.js summary 2026-10
סיכום 2026-10: 2 הוצאות, סה״כ 66.50
  food             54.50
  transport        12.00
% node src/cli.js add 2026-02-30 food 5
שגיאה: תאריך לא תקין: 2026-02-30 (פורמט: YYYY-MM-DD)
