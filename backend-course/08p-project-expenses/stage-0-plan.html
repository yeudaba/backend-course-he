3. כלי חדש 1: process.argv

כשמריצים node src/cli.js add 2026-10-01 food 54.5, Node שם את כל המילים במערך process.argv:

playground/args.js 
console.log(process.argv);
console.log(process.argv.slice(2));
% node playground/args.js add 2026-10-01 food 54.5
[
  '/usr/local/bin/node',
  '/Users/yeuda/dev/backend-course/playground/args.js',
  'add',
  '2026-10-01',
  'food',
  '54.5'
]
[ 'add', '2026-10-01', 'food', '54.5' ]

שני הראשונים הם נתיב ה־node ונתיב הקובץ — לכן slice(2). שים לב: הכול מחרוזות ("54.5"). ומילים מופרדות ברווחים — לכן הערה של כמה מילים מגיעה כמה איברים, ונחבר אותן עם join(" ").

4. כלי חדש 2: fs — קבצים

import fs from "node:fs";
import os from "node:os";
import path from "node:path";

const file = path.join(os.tmpdir(), "demo.json");
fs.writeFileSync(file, JSON.stringify([{ id: 1 }], null, 2));
console.log(fs.existsSync(file));
const text = fs.readFileSync(file, "utf8");
console.log(JSON.parse(text)[0].id);
true
1
פונקציהמה עושה
fs.existsSync(path)האם הקובץ קיים
fs.readFileSync(path, "utf8")קורא את כל הקובץ כמחרוזת. קובץ שלא קיים ← Error: ENOENT: no such file or directory
fs.writeFileSync(path, text)כותב (ודורס אם קיים)

ה־Sync בשם אומר "סינכרוני": התוכנית מחכה עד שהקובץ נקרא. לתוכנית שורת פקודה זה בסדר; בשרת — לא, ובפרק 10 נלמד את הגרסאות האסינכרוניות. path.join מחבר חלקי נתיב בצורה נכונה בכל מערכת הפעלה.
