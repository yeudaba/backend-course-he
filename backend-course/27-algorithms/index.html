🎯 בסוף הפרק תדע
  • לנתח סיבוכיות זמן וזיכרון (Big-O), ולזהות O(n²) שמתחבא בתוך פונקציה מובנית.
  • הדפוסים שחוזרים בראיונות: Map ו־Set, שני מצביעים וחלון נע, מחסנית ותור, מיון, חיפוש בינארי, BFS, מיון טופולוגי, תכנון דינמי.
  • לפתור שאלה בראיון בקול: הבהרות, דוגמאות, פתרון ראשון, שיפור, בדיקה.
  • שאלות SQL מראיונות: top-N לכל קבוצה, "השני בגובהו", ו־NULL שמפיל שאילתות.
  • לענות על שאלות Backend עם דוגמאות מהפרויקטים שלך.

🤔 למה צריך את זה?

ברוב תהליכי הגיוס ל־Junior Backend יש לפחות שלב אחד של "שאלת קוד": מראיין, עורך משותף, 30–45 דקות, ובעיה כמו "מצא כפילויות" או "הדרך הקצרה במפה". לא מחפשים שם גאונות — מחפשים שתבחר מבנה נתונים נכון, תדע להגיד מה הסיבוכיות, ותחשוב בקול. והחדשות הטובות: רוב הכלים כבר אצלך. Map ו־Set (פרק 7), אינדקסים (פרק 18), תורים (פרק 26) — אלה אותם רעיונות בדיוק, רק בשמות של ספרי אלגוריתמים. הפרק הזה מסדר אותם, מוסיף את מה שחסר, ומתרגל את הראיון עצמו.
