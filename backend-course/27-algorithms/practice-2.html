P27-E55 · ‏LRU עם TTL 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: פרק 26, שיעור 2

export function createTtlLru<V>(capacity: number, ttlMs: number, now?: () => number): { get(key: string): V | undefined; set(key: string, value: V): void; size(): number }
  • get — ערך שפג (‏now() >= expiresAt) ← נמחק ו־undefined. ערך תקף ← עובר לסוף ("שימוש").

  • size() — כמה ערכים תקפים (מנקה פגים בדרך).
  • ‏now — ברירת מחדל Date.now. כל פעולה O(1) בממוצע.
