P27-E89 · סיסמאות עם scrypt ו־salt 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 5

"איך שומרים סיסמאות?" — בלי ספרייה, עם node:crypto. בקובץ 27-algorithms/starter/P27-E89.ts (יש בו רק הערה) כתוב וייצא:

export function hashPassword(password: string): string

  • hashPassword — ‏salt אקראי של 16 בתים, ‏scryptSync(password, salt, 64), ומחרוזת בפורמט scrypt$<salt hex>$<hash hex>. אותה סיסמה פעמיים ← מחרוזות שונות.

P27-E90 · ‏ETag ו־304 ב־Express 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 5

cache בצד הדפדפן: השרת שולח ETag (טביעת אצבע של התשובה), והדפדפן שולח אותו בבקשה הבאה ב־If-None-Match. לא השתנה ← 304 בלי גוף. בקובץ 27-algorithms/starter/P27-E90.ts (יש בו רק הערה) כתוב וייצא:

  • GET /products — ה־JSON של getProducts(), עם ETag: "<sha1 hex של הגוף>" (כולל המירכאות) ו־Cache-Control: no-cache (‏= "לשאול כל פעם").
  • ‏If-None-Match זהה ל־ETag הנוכחי ← ‏304, בלי גוף.
  • ‏Express שולח ETag משלו כברירת מחדל — כבה אותו (app.set("etag", false)), כדי שהבודק יראה את שלך.

P27-E91 · ‏cursor לעימוד: לקודד, לפענח, להמשיך 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 5

export function encodeCursor(c: { createdAt: string; id: number }): string
export function decodeCursor(s: string): { createdAt: string; id: number } | null

P27-E93 · ‏Idempotency-Key בזיכרון 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 5

בקובץ 27-algorithms/starter/P27-E93.ts (יש בו רק הערה) כתוב וייצא:

export function createIdempotency(ttlMs: number, now?: () => number): { run<T>(key: string, body: unknown, fn: () => Promise<T>): Promise<{ status: "fresh" | "replayed"; result: T }> }
  • key חדש ← מריצים fn, שומרים את התוצאה ו־hash של body (‏sha256 של JSON.stringify), ומחזירים "fresh".
  • אותו key ואותו body (בתוך ttlMs) ← "replayed" עם התוצאה השמורה, בלי להריץ.
  • אותו key, body אחר ← Error("KEY_REUSED").
  • אותו key שמגיע בזמן שהראשון עוד רץ ← מחכה לו (לא מריץ פעמיים). ‏fn שזרק ← לא נשמר (ניסיון הבא ירוץ).
  • אחרי ttlMs — נשכח.

P27-E94 · ‏SQL injection: ‏tagged template שמייצר פרמטרים 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 20 דק׳ידע נדרש: שיעור 5

export function sql(strings: TemplateStringsArray, ...values: unknown[]): { text: string; values: unknown[] }
sql`SELECT * FROM users WHERE email = ${email} AND age > ${18}`
// ← { text: "SELECT * FROM users WHERE email = $1 AND age > $2", values: [email, 18] }
  • ערך שהוא מערך ← רשימת פרמטרים: WHERE id IN (${[1, 2, 3]}) ← ‏IN ($1, $2, $3). מערך ריק ← Error (‏IN () לא תקין ב־SQL).

P27-E95 · ‏heap: ‏k הגדולים מתוך זרם 🤖

💻 כתיבת קוד 🤖רמה 3⏱ 25 דק׳ידע נדרש: שיעור 5

export class MinHeap { push(x: number): void; pop(): number | undefined; peek(): number | undefined; get size(): number }

P27-E100 · האם האינדקס ישמש? — כלל הקידומת 🤖

P27-E102 · ‏p50, ‏p95, ‏p99 — לא ממוצע 🤖

💻 כתיבת קוד 🤖רמה 2⏱ 15 דק׳ידע נדרש: פרק 24, שיעור 5

בקובץ 27-algorithms/starter/P27-E102.ts (יש בו רק הערה) כתוב וייצא:

export function percentiles(latencies: number[], ps: number[]): Record<string, number | null>
  • לכל p (‏0 < p ≤ 100) — שיטת "nearest rank": ממיינים (עותק!), ולוקחים את האיבר במקום Math.ceil(p / 100 × n) (מ־1). המפתח בתוצאה: "p" + p (‏p50, ‏p99.9).
  • בלי נתונים ← null לכל p. ‏p מחוץ לטווח ← RangeError.
  • מיון אחד לכל הקריאה — O(n log n): ‏1,000,000 ערכים — מתחת ל־500ms.
