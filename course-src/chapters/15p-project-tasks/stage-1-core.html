🎯 בשלב הזה

הלב של הפרויקט — בלי HTTP בכלל: מה זו משימה תקינה (schema), איפה היא נשמרת (repository), ומה החוקים (service). בסוף: `npm run check PR2-SCHEMA -- --dir ~/dev/tasks-api` ו־`PR2-SERVICE` עוברים.

1. `tasks.schema.ts`

סכמהשדות
`createTaskSchema``title` — trim, 1–120 · `description` — trim, עד 2000, nullable, ברירת מחדל `null` · `status` — `STATUSES`, ברירת מחדל `"todo"` · `priority` — `PRIORITIES`, ברירת מחדל `"medium"` · `dueDate` — `z.iso.date()` (YYYY-MM-DD, כולל בדיקה שהתאריך קיים), nullable, ברירת מחדל `null`

💡 רמז: למה לא `createTaskSchema.partial()` לעדכון?

כי `partial()` משאיר את ה־`default`־ים: `{ "status": "done" }` היה הופך ל־`{ status: "done", priority: "medium", description: null, ... }` — ו־PATCH היה דורס שדות שהלקוח לא ביקש לשנות. לכן כותבים את הסכמה מחדש עם `z.strictObject({...}).partial()` (כמו P15-E17).

2. `tasks.repository.ts`

ה־interface `TasksRepository` כבר כתוב — זה החוזה. ממש את `InMemoryTasksRepository`:

  • מערך פרטי (`#tasks`) ומונה (`#nextId`, מתחיל ב־1). id לא חוזר לשימוש אחרי מחיקה.
  • `update` משנה רק את השדות שהתקבלו ומחזיר את המשימה המעודכנת, או `undefined` אם אין. `delete` מחזיר `true`/`false`.
  • מחזירים עותקים (`{ ...task }`). אחרת, קוד שמקבל משימה ומשנה אותה (למשל במיון או בבדיקה) משנה את המאגר בלי לעבור דרך `update`. מסד נתונים אמיתי מתנהג כמו עותק — אז גם הזיכרון צריך.
💡 למה async, כשהכול בזיכרון?

כי בפרק 19 תכתוב `PrismaTasksRepository` עם אותו interface — ושם כל קריאה היא async. אם ה־service כבר עושה `await this.repo.findById(...)`, ההחלפה תהיה שורה אחת ב־`createApp`. זה בדיוק "לתכנן לשינוי" מפרק 12.

3. `tasks.service.ts` — חלק א׳

מתודההתנהגות
`get(id)`המשימה, או `HttpError(404, "TASK_NOT_FOUND", ...)`
`create(input)``dueDate` לפני היום ← `HttpError(422, "DUE_DATE_IN_PAST", ...)`. אחרת — `createdAt` ו־`updatedAt` = `this.now().toISOString()`, ושמירה
`update(id, changes)`מעדכן ו־`updatedAt` = עכשיו; לא קיים ← 404
`remove(id)`לא קיים ← 404

("היום" — לפי UTC: `now.toISOString().slice(0, 10)`. ומשווים מחרוזות YYYY-MM-DD ישירות — בפורמט הזה, סדר מילוני = סדר כרונולוגי. אזורי זמן כמו שצריך — פרק 24.)

`now` מוזרק ב־constructor — כך הבדיקה קובעת "היום הוא 4 בנובמבר" ובודקת 422 בלי תלות בתאריך האמיתי.

💡 רמז: איך HttpError מגיע ל־service?

`errors.ts` כבר מכיל את המחלקה `HttpError` (מוכנה בשלד). ה־service מייבא אותה וזורק. (יש מי שמעדיף שה־service יזרוק שגיאות "עסקיות" כמו `TaskNotFoundError`, ושה־errorHandler יתרגם ל־HTTP. זה נקי יותר — וזה מה ש־NestJS עושה עם exception filters. כאן נשארים פשוטים.)
