1. Arrow functions

שתי דרכים לכתוב את אותה פונקציה:

```js run function doubleA(n) { return n * 2; } const doubleB = (n) => { return n * 2; }; const doubleC = (n) => n * 2; console.log(doubleA(5), doubleB(5), doubleC(5)); ``` ```out 10 10 10 ```
כתיבמתי
`function name(...) { ... }`פונקציות "ראשיות" עם שם, בראש הקובץ
`const name = (...) => { ... };`זהה כמעט לגמרי; נפוץ מאוד בקוד מודרני
`(n) => n * 2`גוף של ביטוי אחד בלי סוגריים מסולסלים — ה־`return` אוטומטי. מושלם לפונקציות קטנות שמעבירים לפונקציה אחרת
⚠️ שתי מלכודות
  • `(n) => { n * 2 }` — עם סוגריים מסולסלים חייבים `return`. בלעדיו: `undefined`.
  • arrow function שהוגדרה עם `const` לא קיימת לפני השורה שלה: קריאה מוקדמת ← `ReferenceError: Cannot access 'sayHi' before initialization`. (פונקציה שהוגדרה עם `function` — כן קיימת מתחילת הקובץ. אל תסתמך על זה; הגדר לפני שימוש.)

2. Scope — איפה משתנה חי

כל פונקציה היא "חדר". משתנה שנוצר בתוך החדר (כולל הפרמטרים) לא נראה מבחוץ. אבל מתוך החדר רואים החוצה:

```js run const vatRate = 0.18; function withVat(price) { const vat = price * vatRate; return price + vat; } console.log(withVat(100)); console.log(typeof vat); ``` ```out 118 undefined ```

למה זה טוב? כי שתי פונקציות יכולות להשתמש בשם `total` בלי להתנגש. ולמה להיזהר? כי פונקציה שמשתמשת במשתנה חיצוני תלויה בו — אם מישהו ישנה אותו, היא תתנהג אחרת. מכאן —

3. פונקציות טהורות ותופעות לוואי

```js run let cartTotal = 0; function addToCartImpure(price) { cartTotal += price; } function addToTotal(total, price) { return total + price; } addToCartImpure(50); addToCartImpure(50); console.log(cartTotal); console.log(addToTotal(addToTotal(0, 50), 50)); ``` ```out 100 100 ```

`addToCartImpure` משנה משתנה בחוץ (תופעת לוואי), ולכן התוצאה של קריאה תלויה בכל הקריאות הקודמות. `addToTotal` היא טהורה: תמיד אותה תשובה לאותם ארגומנטים — קל לבדוק אותה, קל להבין אותה. בשרת חייבות להיות תופעות לוואי (כתיבה למסד, שליחת מייל) — אבל המטרה היא לרכז אותן במקומות מעטים, ולשמור את החישובים טהורים.

4. פונקציה כערך: callbacks

`typeof doubleC` הוא `"function"` — פונקציה היא ערך, כמו מספר. לכן אפשר להעביר אותה כארגומנט:

```js run function applyToRange(from, to, fn) { let result = ""; for (let i = from; i <= to; i++) { result += fn(i) + " "; } return result.trim(); } console.log(applyToRange(1, 5, (n) => n * n)); console.log(applyToRange(1, 5, (n) => (n % 2 === 0 ? "זוגי" : "אי־זוגי"))); ``` ```out 1 4 9 16 25 אי־זוגי זוגי אי־זוגי זוגי אי־זוגי ```

`applyToRange` לא יודעת מה לעשות עם כל מספר — היא מקבלת את זה מבחוץ, בתור פונקציה (callback). זה הרעיון שמאחורי `map`, `filter` ו־`sort` בפרק 6, ומאחורי כל route בשרת Express (פרק 15): "כשתגיע בקשה לכתובת הזו — תפעיל את הפונקציה הזו".
