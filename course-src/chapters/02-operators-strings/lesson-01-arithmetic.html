1. סימני החשבון

סימןשםדוגמהתוצאה
`+`חיבור`7 + 3``10`
`-`חיסור`7 - 3``4`
`*`כפל (כוכבית, לא x)`7 * 3``21`
`/`חילוק`7 / 2``3.5`
`%`שארית חלוקה`7 % 3``1`
`**`חזקה`2 ** 3``8`
`( )`סוגריים — "חשב קודם"`(7 + 3) * 2``20`

`%` — שארית: הכלי שנראה מיותר ומשמש כל הזמן

`17 % 5` שואל: "אם מחלקים 17 ל־5 קבוצות שוות, כמה נשאר?" — 3 קבוצות של 5 = 15, ונשארו `2`.

```js run console.log(17 % 5); console.log(10 % 2); console.log(11 % 2); console.log(125 % 60); ``` ```out 2 0 1 5 ```

שימושים: זוגי או אי־זוגי (`n % 2` הוא 0 לזוגי), המרת זמן (125 דקות = 2 שעות ו־`125 % 60` = 5 דקות), כל פריט שלישי בלולאה (פרק 4), ועמודים בתוצאות חיפוש (פרק 15).

2. סדר פעולות

כמו בבית הספר: סוגריים ← חזקה ← כפל/חילוק/שארית ← חיבור/חיסור. כשיש כמה פעולות מאותה רמה — משמאל לימין.

```js run console.log(2 + 3 * 4); console.log((2 + 3) * 4); console.log(20 - 10 - 5); console.log(100 / 10 / 2); console.log(2 * 3 ** 2); ``` ```out 14 20 5 5 18 ```
💡 כלל זהב

כשאתה לא בטוח — שים סוגריים. `price + (price * vat)` ברור יותר מ־`price + price * vat`, גם אם התוצאה זהה. קוד נקרא הרבה יותר פעמים משהוא נכתב.

3. קיצורים לעדכון משתנה

בפרק 1 כתבת הרבה `count = count + 1`. יש קיצורים:

קיצורשווה ל־
`total += 5``total = total + 5`
`total -= 5``total = total - 5`
`total *= 2``total = total * 2`
`total /= 2``total = total / 2`
`count++``count = count + 1`
`count--``count = count - 1`
```js run let stock = 10; stock -= 3; stock += 5; stock++; stock *= 2; console.log(stock); ``` ```out 26 ```

(10 ← 7 ← 12 ← 13 ← 26.) הקיצורים עובדים רק עם `let` — הם הרי משנים את המשתנה.

⚠️ `++` בתוך ביטוי

יש גם `++count` (לפני) ו־`count++` (אחרי), והם נבדלים רק כשמשתמשים בהם בתוך ביטוי אחר. כדי לא להסתבך: כתוב `count++` תמיד בשורה משלו.

4. עיגול: `Math`

`Math` הוא "ארגז כלים" מובנה של חישובים. נשתמש בכמה:

```js run console.log(Math.round(4.5)); console.log(Math.round(4.4)); console.log(Math.floor(4.9)); console.log(Math.ceil(4.1)); console.log(Math.max(3, 17, 8)); console.log(Math.min(3, 17, 8)); console.log(Math.abs(-12)); ``` ```out 5 4 4 5 17 3 12 ```
כלימה עושהשימוש ב־Backend
`Math.round(x)`עיגול לשלם הקרובדירוג ממוצע של מוצר
`Math.floor(x)`עיגול למטה"כמה עמודים מלאים יש?"
`Math.ceil(x)`עיגול למעלה"כמה עמודים צריך בסך הכול?" — 23 תוצאות, 10 בעמוד ← `Math.ceil(23 / 10)` = 3
`Math.max` / `Math.min`הגדול / הקטן מבין כמה מספרים"לפחות 0": `Math.max(0, stock - ordered)`
