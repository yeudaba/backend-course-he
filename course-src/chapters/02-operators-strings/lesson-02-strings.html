🎯 בשיעור הזה
  • לחבר טקסטים עם `+`, ולמה זה מסורבל.
  • template literals — הדרך המודרנית לבנות טקסט.
  • אורך מחרוזת, אינדקסים, ומתודות שימושיות.

1. שרשור עם `+`

כשאחד הצדדים של `+` הוא מחרוזת — `+` הופך מ"חיבור" ל"הדבקה" (שרשור):

```js run const firstName = "דנה"; const lastName = "לוי"; const fullName = firstName + " " + lastName; console.log(fullName); console.log("שלום, " + fullName + "! יש לך " + 3 + " הודעות."); ``` ```out דנה לוי שלום, דנה לוי! יש לך 3 הודעות. ```

עובד, אבל השורה האחרונה קשה לקריאה, וקל לשכוח רווח ליד המירכאות. יש דרך טובה יותר.

2. Template literals

מחרוזת שנכתבת בין גרשיים הפוכים `...` (המקש משמאל ל־1, מעל Tab, במקלדת אנגלית). בתוכה אפשר לשבץ כל ערך או חישוב עם ${...}:

```js run const name = "דנה"; const messages = 3; const price = 40; console.log(`שלום, ${name}! יש לך ${messages} הודעות.`); console.log(`שני כרטיסים עולים ${price * 2} ש״ח`); ``` ```out שלום, דנה! יש לך 3 הודעות. שני כרטיסים עולים 80 ש״ח ```

חלקמה זה
`גרש הפוך — פותח וסוגר. לא ' ולא "
${...}"חור" בטקסט: מה שבפנים מחושב, והתוצאה נכנסת לטקסט
`${price * 2}`אפשר לשים בפנים כל ביטוי — חישוב, משתנה, קריאה למתודה

💡 כלל בקורס

מעכשיו, כל טקסט שמשלב משתנים — כותבים כ־template literal.

3. אורך ואינדקסים

`length` אומר כמה תווים יש במחרוזת (כולל רווחים). כל תו יושב במיקום (index) שמתחיל מ־0:

```js run const word = "Hello"; console.log(word.length); console.log(word[0]); console.log(word[4]); console.log(word[word.length - 1]); console.log(word[10]); ``` ```out 5 H o o undefined ```

אינדקס שלא קיים מחזיר `undefined` — בלי שגיאה. שים לב לדפוס `word[word.length - 1]` — "התו האחרון". (קיצור מודרני: `word.at(-1)`.)

4. מתודות מחרוזת

מתודה היא פעולה שמחוברת לערך. קוראים לה עם נקודה, שם, וסוגריים: `email.trim()`. ההבדל מ־`length`: ל־`length` אין סוגריים, כי הוא תכונה (property) — מידע, לא פעולה.

מתודהמה מחזירהדוגמה ← תוצאה
`toUpperCase()` / `toLowerCase()`עותק באותיות גדולות/קטנות`"Node".toLowerCase()` ← `"node"`
`trim()`עותק בלי רווחים בהתחלה ובסוף`" hi ".trim()` ← `"hi"`
`includes(x)``true`/`false`: האם `x` מופיע`"a@b.com".includes("@")` ← `true`
`startsWith(x)` / `endsWith(x)`האם מתחיל/נגמר ב־`x``"report.pdf".endsWith(".pdf")` ← `true`
`indexOf(x)`האינדקס של המופע הראשון, או `-1``"hello".indexOf("l")` ← `2`
`slice(start, end)`חתיכה מ־`start` עד לפני `end``"hello".slice(1, 3)` ← `"el"`
`replaceAll(a, b)`עותק שבו כל `a` הוחלף ב־`b``"050-123-4567".replaceAll("-", "")` ← `"0501234567"`
`padStart(n, c)`עותק שמרופד משמאל עד אורך `n``"7".padStart(3, "0")` ← `"007"`
⚡ חשוב גם במסלול המהיר — מחרוזות לא משתנות

אף מתודה לא משנה את המחרוזת המקורית — כולן מחזירות עותק חדש. אם לא שומרים את התוצאה, היא הולכת לאיבוד:

```js run let email = " Dana@Mail.com "; email.trim(); console.log(`[${email}]`); email = email.trim().toLowerCase(); console.log(`[${email}]`); ``` ```out [ Dana@Mail.com ] [dana@mail.com] ```

(הסוגריים המרובעים בפלט הם רק כדי לראות את הרווחים.) שים לב גם לשרשור מתודות: `email.trim().toLowerCase()` — כל מתודה פועלת על התוצאה של הקודמת, משמאל לימין.

👣 דוגמה מודרכת: ניקוי שם משתמש

משתמש נרשם עם `" @Yossi_Cohen "`. אנחנו רוצים לשמור `yossi_cohen` — בלי רווחים, בלי `@` בהתחלה, באותיות קטנות.

```js run const raw = " @Yossi_Cohen "; const trimmed = raw.trim(); console.log(`1: [${trimmed}]`); const withoutAt = trimmed.replaceAll("@", ""); console.log(`2: [${withoutAt}]`); const username = withoutAt.toLowerCase(); console.log(`3: [${username}]`); ``` ```out 1: [@Yossi_Cohen] 2: [Yossi_Cohen] 3: [yossi_cohen] ```

בשלבים עם הדפסה אחרי כל אחד — כך רואים איפה משהו משתבש. כשזה עובד, אפשר לכווץ לשורה אחת: `raw.trim().replaceAll("@", "").toLowerCase()`.
