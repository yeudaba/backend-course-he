🎯 יחידת גישור — למה היא כאן?

הרבה טעויות של מתחילים הן לא "לא יודע את הפקודה", אלא ניחוש של מה ביטוי יחזיר. בשיעור הקצר הזה נלמד שיטה לקרוא ביטוי כמו שהמחשב קורא אותו — בלי ניחושים. השיטה הזו תשמש אותך בכל פרק מעכשיו, ובכל שאלת "מה יודפס?" בראיון.

השיטה: לכווץ צעד אחר צעד

  1. החלף כל שם משתנה בערך שלו (מטבלת המעקב).
  2. מצא את הפעולה הבאה לפי הסדר: סוגריים ← קריאות למתודות ← `**` ← `* / %` ← `+ -`. בתיקו — משמאל לימין.
  3. חשב רק אותה, ורשום את הביטוי מחדש עם התוצאה במקומה. שים לב לסוג של התוצאה (מספר? טקסט?).
  4. חזור עד שנשאר ערך אחד.

👣 דוגמה 1

```js run const a = 10; const b = "4"; console.log(a + b * 2 - 1); ``` ```out 17 ```
צעדהביטוימה עשינו
0`a + b * 2 - 1`המקור
1`10 + "4" * 2 - 1`הצבנו ערכים. שים לב: `b` הוא טקסט
2`10 + 8 - 1`כפל קודם. `*` ממיר את `"4"` למספר ← `8` (מספר)
3`18 - 1`משמאל לימין: `10 + 8` — שני מספרים ← `18`
4`17`סיימנו

👣 דוגמה 2 — עם מחרוזות

```js run const qty = 2; const unit = 15; console.log("סה״כ: " + qty * unit + 5); ``` ```out סה״כ: 305 ```
צעדהביטוימה עשינו
1`"סה״כ: " + 2 * 15 + 5`הצבה
2`"סה״כ: " + 30 + 5`כפל קודם ← `30`
3`"סה״כ: 30" + 5`משמאל לימין: טקסט + מספר ← שרשור
4`"סה״כ: 305"`שוב טקסט + מספר ← שרשור. לא 35!

הכוונה הייתה כנראה להוסיף 5 ש״ח משלוח. התיקון: סוגריים — `"סה״כ: " + (qty * unit + 5)` — או, עדיף, template literal: `סה״כ: ${qty * unit + 5}`.

👣 דוגמה 3 — עם מתודות

```js run const input = " Tel Aviv "; console.log(input.trim().length * 2); ``` ```out 16 ```
צעדהביטוימה עשינו
1`" Tel Aviv ".trim().length * 2`הצבה
2`"Tel Aviv".length * 2`מתודות קודם, משמאל לימין: `trim()`
3`8 * 2``length` של `"Tel Aviv"` — 8 תווים כולל הרווח
4`16`
💡 איך מוודאים בלי לנחש?

מפרקים את הביטוי לכמה משתנים עם `console.log` אחרי כל אחד — כמו בדוגמת ניקוי שם המשתמש בשיעור 2. זו גם הדרך לדבג באמת: לא להסתכל על ביטוי ארוך ולקוות, אלא לפרק ולהדפיס.
