@@ P04-E05 | 1 | כמה צעדים? | 10 | שיעור 4
@task
<p>לפונקציה (שעוד לא למדנו לכתוב) יש אחד משני קטעי הקוד הבאים. <code>n</code> הוא מספר ההזמנות במערכת. כמה פעמים תרוץ שורת ה־<code>count++</code> בכל קטע כש־<code>n = 10</code>? כש־<code>n = 1,000</code>? איזה קטע יהיה בעייתי בשרת, ולמה?</p>
```js
// קטע א
for (let i = 0; i < n; i++) {
  count++;
}
// קטע ב
for (let i = 0; i < n; i++) {
  for (let j = 0; j < n; j++) {
    count++;
  }
}
```
@hint1
<p>קטע ב: על כל אחד מ־n הסיבובים החיצוניים — n פנימיים.</p>
@hint2
<p>1,000 × 1,000 = ?</p>
@solution
<p>קטע א: 10 ו־1,000. קטע ב: 100 ו־1,000,000. כשמספר ההזמנות גדל פי 100, קטע א עושה פי 100 עבודה, וקטע ב — פי 10,000. בשרת עם הרבה נתונים קטע ב יאט את כל הבקשות. זה מה שבפרק 27 נקרא O(n) לעומת O(n²).</p>
@mistakes
<ul><li>לענות 2,000 לקטע ב.</li></ul>

<p>📄 כותבים בקובץ <code>04-loops/starter/P04-E77.js</code> (יש בו רק הערה עם המשימה), מריצים ובודקים:</p>

@hint2
<p>כמו בלוח הכפל בשיעור: <code>let line = "";</code> <strong>בתוך</strong> החיצונית, ו־<code>console.log(line)</code> בסוף כל שורה.</p>
@solution
```js run file=04-loops/starter/P04-E77.js save=solutions/P04-E77.js
const size = 4;
for (let row = 0; row < size; row++) {
  let line = "";
  for (let col = 0; col < size; col++) {
    line += (row + col) % 2 === 0 ? "#" : ".";
  }
  console.log(line);
}
```

```out
.#.#
```

<p>(1) מה יודפס? (2) כמה צעדים היו למחרוזת של 1000 תווים? (3) הצע שני שיפורים שמקטינים את מספר הצעדים — <strong>בלי</strong> לשנות את התשובה. (4) למה בכלל צריך את <code>i !== j</code>?</p>
<p>🔗 <strong>איך זה מתחבר:</strong> לולאה מקוננת (שיעור 4), דגל ו־<code>break</code> (שיעור 3), ו־<code>&amp;&amp;</code> מפרק 3. זה הבאג מקופסת "בעולם העבודה" בשיעור — לולאה בתוך לולאה שנראית תמימה, ונהיית איטית מאוד כשהנתונים גדלים.</p>
@hint1
<p>שיפור 1: מתי אפשר לעצור? שיפור 2: האם צריך להשוות את <code>i = 5</code> ל־<code>j = 2</code>, אם כבר השווינו את 2 ל־5?</p>
@hint2
<p>להתחיל את <code>j</code> מ־<code>i + 1</code> — וגם <code>i !== j</code> כבר לא נחוץ.</p>
@solution
```js run
const text = "express";
let hasRepeat = false;
let steps = 0;
for (let i = 0; i < text.length; i++) {
  for (let j = 0; j < text.length; j++) {
    steps++;
    if (i !== j && text[i] === text[j]) {
      hasRepeat = true;
    }
  }
}
console.log(hasRepeat, steps);

let found = false;
let fewerSteps = 0;
for (let i = 0; i < text.length && !found; i++) {
  for (let j = i + 1; j < text.length; j++) {
    fewerSteps++;
    if (text[i] === text[j]) {
      found = true;
      break;
    }
  }
}
console.log(found, fewerSteps);
```

```out
true 49
true 4
```

(ב) לעצור ברגע שנמצאה חזרה — <code>break</code> בפנימית, ו־<code>!found</code> בתנאי של החיצונית (<code>break</code> יוצא רק מהפנימית — P04-E78).</li><li>בלי <code>i !== j</code>, כל תו "שווה לעצמו" — והתשובה תמיד <code>true</code>. בגרסה המשופרת זה לא נחוץ, כי <code>j</code> תמיד אחרי <code>i</code>.</li></ol>
<p>(בפרק 7 תכיר <code>Set</code>, שעושה את זה במעבר אחד — 1000 צעדים במקום מיליון.)</p>
