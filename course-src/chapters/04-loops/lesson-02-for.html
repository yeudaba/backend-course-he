1. אותם שלושה חלקים, בשורה אחת

רוב הלולאות הן "תעשה משהו N פעמים". בשביל זה יש `for`, שמרכז את האתחול, התנאי והצעד בכותרת אחת:

```js run for (let i = 1; i <= 3; i++) { console.log(`סיבוב ${i}`); } ``` ```out סיבוב 1 סיבוב 2 סיבוב 3 ```

הסדר המדויק: ① ← ② ← בלוק ← ③ ← ② ← בלוק ← ③ ← ② ... עד ש־② הוא `false`.

2. וריאציות

```js run let up = ""; for (let i = 0; i < 5; i++) { up += i + " "; } console.log(up); let down = ""; for (let i = 5; i >= 1; i--) { down += i + " "; } console.log(down); let evens = ""; for (let i = 0; i <= 10; i += 2) { evens += i + " "; } console.log(evens); ``` ```out 0 1 2 3 4 5 4 3 2 1 0 2 4 6 8 10 ```

(בנינו מחרוזת בתוך הלולאה והדפסנו פעם אחת בסוף, כדי שכל התוצאות יהיו בשורה אחת — דפוס שנחזור אליו בשיעור 3.)

💡 למה מתחילים מ־0?

`for (let i = 0; i < 5; i++)` רץ בדיוק 5 פעמים (0–4). זה הסגנון הנפוץ, כי אינדקסים של מחרוזות (ובהמשך מערכים) מתחילים מ־0. הצורה הזו — מתחילים ב־0, תנאי `<`, ומספר הסיבובים מימין — כדאי להפוך להרגל.

3. Off-by-one — הבאג הנפוץ בעולם

"סיבוב אחד יותר מדי או פחות מדי". נניח רוצים להדפיס 1 עד 5:

כותרתמדפיס
`for (let i = 1; i <= 5; i++)`1 2 3 4 5✔
`for (let i = 1; i < 5; i++)`1 2 3 4✘ חסר האחרון
`for (let i = 0; i <= 5; i++)`0 1 2 3 4 5✘ אחד מיותר
`for (let i = 0; i < 5; i++)` עם `i + 1`1 2 3 4 5✔

הדרך לתפוס את זה: בדוק את הסיבוב הראשון ואת האחרון בטבלת מעקב. אם שניהם נכונים — כל האמצע נכון.

4. המונה חי רק בתוך הלולאה

`i` שנוצר ב־`let` בכותרת קיים רק בתוך הלולאה. אחריה:

```term % node playground/after-loop.js !! ReferenceError: i is not defined ```

אם צריך את הערך אחרי הלולאה — שומרים אותו במשתנה שהוגדר לפני הלולאה. ועוד דבר: `for (const i = 0; ...)` ייכשל עם `TypeError: Assignment to constant variable.` — המונה משתנה, ולכן `let`.
