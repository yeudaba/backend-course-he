  • לולאה בתוך לולאה — ומה זה עושה למספר הצעדים.

1. מעבר על מחרוזת עם אינדקס

מפרק 2 אתה יודע ש־`text[i]` הוא התו במקום `i`, ו־`text.length` הוא האורך. יחד עם `for`:

```js run const code = "A7B2"; for (let i = 0; i < code.length; i++) { console.log(`מקום ${i}: ${code[i]}`); } ``` ```out מקום 0: A מקום 1: 7 מקום 2: B מקום 3: 2 ```

הכותרת `for (let i = 0; i < text.length; i++)` היא אולי השורה הנפוצה ביותר בתכנות. שים לב ל־`<` (לא `<=`): האינדקס האחרון הוא `length - 1`.

2. `for...of` — בלי אינדקס

כשלא צריך את המיקום, רק את התו עצמו — יש קיצור:

```js run const word = "banana"; let countA = 0; for (const ch of word) { if (ch === "a") { countA++; } } console.log(`ב־${word} יש ${countA} פעמים a`); ``` ```out ב־banana יש 3 פעמים a ```

קוראים: "לכל `ch` מתוך `word`". כאן `const` תקין — בכל סיבוב נוצר `ch` חדש. בפרק 6 נשתמש ב־`for...of` על מערכים — שם הוא יהיה הכלי הראשי.

👣 דוגמה מודרכת: היפוך מחרוזת

```js run const original = "Node"; let reversed = ""; for (const ch of original) { reversed = ch + reversed; } console.log(reversed); ``` ```out edoN ```

הטריק: מוסיפים כל תו לפני מה שנבנה עד עכשיו (`ch + reversed` ולא `reversed + ch`). שאלת ראיון קלאסית — עכשיו יש לך פתרון.

3. לולאות מקוננות

לולאה בתוך לולאה: על כל סיבוב של החיצונית, הפנימית רצה מההתחלה ועד הסוף. כמו שעון: על כל שעה, המחוג של הדקות מסתובב 60 פעם.

```js run for (let row = 1; row <= 3; row++) { let line = ""; for (let col = 1; col <= 4; col++) { line += String(row * col).padStart(4); } console.log(line); } ``` ```out 1 2 3 4 2 4 6 8 3 6 9 12 ```

הלולאה החיצונית רצה 3 פעמים, הפנימית 4 פעמים בכל אחת — סה״כ 12 חישובים. שימו לב ש־`line` מתאפס בתוך החיצונית: שורה חדשה לכל `row`.
