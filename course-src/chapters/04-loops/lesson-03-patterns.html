🎯 בשיעור הזה

חמישה "דפוסים" שחוזרים כמעט בכל לולאה שתכתוב — גם בשרת אמיתי. ועוד שני כלים לשליטה בזרימה: `break` ו־`continue`.

1. דפוס הצובר: סכום

משתנה מחוץ ללולאה, שמתחיל ב"ערך ריק" (0 לסכום), ובכל סיבוב מוסיפים לו:

```js run let sum = 0; for (let i = 1; i <= 4; i++) { sum += i; } console.log(sum); ``` ```out 10 ```

⚠️ הטעות: צובר בתוך הלולאה

אם כותבים `let sum = 0;` בתוך הבלוק — הוא מתאפס בכל סיבוב, וגם לא קיים אחרי הלולאה. הצובר תמיד לפני הלולאה.

2. ספירה — צובר עם תנאי

```js run let multiplesOf7 = 0; for (let i = 1; i <= 100; i++) { if (i % 7 === 0) { multiplesOf7++; } } console.log(`בין 1 ל־100 יש ${multiplesOf7} מספרים שמתחלקים ב־7`); ``` ```out בין 1 ל־100 יש 14 מספרים שמתחלקים ב־7 ```

3. מקסימום ומינימום

"הכי גדול עד עכשיו": מתחילים מהערך הראשון, ובכל סיבוב — אם הנוכחי גדול יותר, הוא המנצח החדש. כאן נחשב את הערך הגדול ביותר של הנוסחה i * (10 - i) עבור i בין 0 ל־10:

```js run let best = 0 * (10 - 0); let bestI = 0; for (let i = 1; i <= 10; i++) { const value = i * (10 - i); if (value > best) { best = value; bestI = i; } } console.log(`המקסימום ${best} מתקבל ב־i=${bestI}`); ``` ```out המקסימום 25 מתקבל ב־i=5 ```

בפרק 6, עם מערכים, זה יהיה "המוצר הכי יקר" או "ההזמנה הכי גדולה". שים לב: מתחילים מהערך הראשון ולא מ־0 — אם כל הערכים שליליים, התחלה מ־0 תחזיר תשובה שגויה.

4. בניית מחרוזת

צובר שהוא מחרוזת, מתחיל ב־`""`:

```js run let stars = ""; for (let i = 0; i < 5; i++) { stars += "★"; } console.log(stars); ``` ```out ★★★★★ ```

5. דגל: "האם נמצא?"

בוליאני שמתחיל ב־`false`, והופך ל־`true` אם משהו קרה:

```js run const n = 91; let hasDivisor = false; for (let d = 2; d < n; d++) { if (n % d === 0) { hasDivisor = true; } } console.log(`${n} ${hasDivisor ? "אינו ראשוני" : "ראשוני"}`); ``` ```out 91 אינו ראשוני ```

(91 = 7 × 13.) אבל ברגע שמצאנו מחלק אחד — אין טעם להמשיך עוד 80 סיבובים. לשם כך יש `break`.

6. `break` ו־`continue`

פקודהמה עושהמתי
`break`יוצאת מהלולאה לגמרימצאנו מה שחיפשנו; אין טעם להמשיך
`continue`מדלגת על שאר הבלוק, וממשיכה לסיבוב הבאהפריט הנוכחי לא רלוונטי
```js run const n = 91; let firstDivisor = null; for (let d = 2; d < n; d++) { if (n % d === 0) { firstDivisor = d; break; } } console.log(`המחלק הראשון: ${firstDivisor}`); let odds = ""; for (let i = 1; i <= 9; i++) { if (i % 2 === 0) { continue; } odds += i + " "; } console.log(odds); ``` ```out המחלק הראשון: 7 1 3 5 7 9 ```

הלולאה הראשונה רצה 6 סיבובים במקום 89. ב־Backend זה ההבדל בין שאילתה של מילישנייה לשאילתה של שנייה (פרק 27).
