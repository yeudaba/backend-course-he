1. משתנה = שם על קופסה

דמיין מחסן. כל ערך יושב בקופסה, ועל הקופסה מדבקה עם שם. כשהקוד אומר `price`, JavaScript הולכת לקופסה שהמדבקה שלה `price` ולוקחת מה שיש בה.

```js run file=playground/variables.js const productName = "מחברת"; const price = 12; console.log(productName, "עולה", price); ``` ```out מחברת עולה 12 ```

🔍 פירוק השורה

חלקמה זה
`const`"צור משתנה קבוע". מילה שמורה של השפה
`price`השם שבחרת — המדבקה
`=`הצבה: "שים את הערך שמימין בתוך הקופסה שמשמאל". זה לא "שווה" של מתמטיקה
`12`הערך שנכנס לקופסה
`;`סוף ההוראה

כשמשתמשים במשתנה — כותבים את השם בלי מירכאות. `console.log(price)` מדפיס `12`; `console.log("price")` מדפיס את המילה `price`.

2. `let` — משתנה שאפשר לעדכן

לפעמים הערך צריך להשתנות: מספר הפריטים בעגלה גדל, יתרה יורדת. בשביל זה יש `let`. את המילה `let` כותבים רק בפעם הראשונה; בעדכון — רק השם, `=` והערך החדש.

```js run file=playground/cart.js let itemsInCart = 0; console.log("בעגלה:", itemsInCart); itemsInCart = 1; console.log("בעגלה:", itemsInCart); itemsInCart = itemsInCart + 2; console.log("בעגלה:", itemsInCart); ``` ```out בעגלה: 0 בעגלה: 1 בעגלה: 3 ```

השורה `itemsInCart = itemsInCart + 2;` מבלבלת בהתחלה, כי במתמטיקה היא בלתי אפשרית. אבל זכור: `=` הוא הצבה. קוראים אותה מימין לשמאל: "קח את מה שיש עכשיו ב־`itemsInCart` (1), הוסף 2, ושים את התוצאה (3) בחזרה בקופסה".

```js run let balance = 100; const price = 30; balance = balance - price; balance = balance - price; const left = balance; console.log(left); ``` ```out 40 ```

3. `const` או `let`? הכלל

כלל אצבע

תמיד מתחילים ב־`const`. עוברים ל־`let` רק כשיודעים שהערך חייב להשתנות בהמשך (מונה, סכום מצטבר, מצב). ככה, מי שקורא את הקוד יודע: כל `const` — הערך שלו לא יזוז, אפשר לסמוך עליו.

ואם מנסים לשנות `const`? JavaScript עוצרת אותך:

```term % node playground/const-error.js .. /Users/yeuda/dev/backend-course/playground/const-error.js:2 price = 20; ^ !! TypeError: Assignment to constant variable. ```

(`TypeError` היא שגיאה בזמן ריצה: השורות שלפניה כבר רצו.) התיקון: אם הערך באמת צריך להשתנות — `let`. אם לא — כנראה התכוונת ליצור משתנה חדש עם שם אחר.

4. שמות טובים

כלל✔ תקין✘ לא תקין / לא מומלץ
אותיות באנגלית, ספרות, `_` ו־`$` בלבד`price2``price-2` (מקף = חיסור), `my price` (רווח)
לא מתחיל בספרה`item1``1item`
אותיות גדולות וקטנות שונות`total` ו־`Total` הם שני משתנים
מוסכמה: camelCase`totalPrice`, `isLoggedIn``totalprice`, `total_price`
שם שמסביר מה בפנים`userAge`, `ordersCount``x`, `data`, `a1`
בוליאני — כמו שאלת כן/לא`isActive`, `hasStock``active`, `stock`

אפשר טכנית לכתוב שמות בעברית — אל תעשה את זה. בעבודה כל הקוד באנגלית, וכלים רבים לא יתמכו בזה.
