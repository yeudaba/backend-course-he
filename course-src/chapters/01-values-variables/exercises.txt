@@ P01-E25 | 5 | אתגר: סבב של שלושה | 20 | שיעור 2
@task
<p>שלושה משתנים: <code>let a = "אדום"; let b = "ירוק"; let c = "כחול";</code>. כתוב קוד ש"מסובב" אותם: אחרי הסיבוב, <code>a</code> מכיל את מה שהיה ב־<code>b</code>, <code>b</code> את מה שהיה ב־<code>c</code>, ו־<code>c</code> את מה שהיה ב־<code>a</code>.</p>
```out
לפני: אדום ירוק כחול
אחרי: ירוק כחול אדום
```
<p>שאלות לחשיבה:</p>
<ol><li>מה המספר <strong>המינימלי</strong> של משתני עזר שצריך? הוכח בטבלת מעקב.</li><li>אם מסובבים שלוש פעמים ברצף — מה מקבלים? למה?</li></ol>
@hint1
<p>כמו בהחלפה (P01-E15): מה הערך הראשון שנדרס? אותו צריך לשמור.</p>
@hint2
<p>שומרים את <code>a</code> ב־<code>temp</code>, ואז <code>a = b; b = c; c = temp;</code></p>
@solution
```js run file=playground/p01e25.js save=solutions/P01-E25.js
let a = "אדום";
let b = "ירוק";
let c = "כחול";
console.log("לפני:", a, b, c);

const temp = a;
a = b;
b = c;
c = temp;

console.log("אחרי:", a, b, c);
```
```out
לפני: אדום ירוק כחול
אחרי: ירוק כחול אדום
```
<ol><li><strong>משתנה עזר אחד מספיק.</strong> רק הערך הראשון שנדרס (<code>a</code>) צריך גיבוי; אחריו כל ערך שנדרס כבר הועתק למקום החדש שלו.</li><li><strong>שלושה סיבובים מחזירים למצב ההתחלתי</strong> — כל ערך זז מקום אחד בכל סיבוב, ויש שלושה מקומות. (בפרק 4 תוכל לבדוק את זה עם לולאה.)</li></ol>
@mistakes
<ul><li>לסדר את ההשמות בסדר הפוך (<code>c = b</code> קודם) — דורס את מה שעוד לא הועתק.</li></ul>
