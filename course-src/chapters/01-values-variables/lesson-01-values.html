🎯 בשיעור הזה
  • שלושה סוגי ערכים: מחרוזת, מספר ובוליאני.
  • איך שואלים את JavaScript "מה הסוג של זה?" עם `typeof`.
  • הדפסה של כמה ערכים באותה שורה, והערות בקוד.

1. ערך הוא פיסת מידע

כל דבר שתוכנית עובדת איתו הוא ערך (Value): שם של לקוח, מחיר, "האם המשתמש מחובר?". לכל ערך יש סוג (Type) — והסוג קובע מה אפשר לעשות איתו. מחיר אפשר לחבר למחיר אחר; שם אפשר להדפיס, אבל אין טעם לחלק אותו ב־2.

מחרוזת (String) — טקסט

כל טקסט שנמצא בין מירכאות. אפשר מירכאות כפולות `"..."` או בודדות `'...'` — אין הבדל, רק לסגור באותו סוג שפתחת.

```js run console.log("שלום"); console.log('גם זה טקסט'); console.log("42"); ``` ```out שלום גם זה טקסט 42 ```

שים לב לשורה השלישית: `"42"` נראה כמו מספר, אבל המירכאות הופכות אותו לטקסט. נראה תכף איך מוכיחים את זה.

מספר (Number)

שלם, עשרוני, שלילי — הכול אותו סוג. כותבים בלי מירכאות, ואת החלק העשרוני מפרידים בנקודה (לא בפסיק).

```js run console.log(42); console.log(-7); console.log(19.90); console.log(10 / 4); ``` ```out 42 -7 19.9 2.5 ```

`19.90` הודפס כ־`19.9`: למספר אין "אפסים מיותרים בסוף". זה רק עניין של תצוגה — בפרק 2 נלמד איך להציג מחיר עם שתי ספרות אחרי הנקודה.

⚡ חשוב גם במסלול המהיר — מספר אחד לכולם

אם למדת Java או C: ב־JavaScript אין `int`, `double` ו־`float` נפרדים. יש `number` אחד, שתמיד מחושב כעשרוני. לכן `10 / 4` נותן `2.5` ולא `2`. ויש גם תוצאה שמפתיעה כל מתכנת בשבוע הראשון:

```js run console.log(0.1 + 0.2); ``` ```out 0.30000000000000004 ```

זו לא תקלה של JavaScript — כך מחשבים שומרים שברים בבסיס 2, וזה קורה גם בשפות אחרות. במערכות כסף אמיתיות שומרים לכן סכומים באגורות (מספר שלם): `1990` במקום `19.90`. נחזור לזה בפרויקט הדגל.

בוליאני (Boolean) — אמת או שקר

רק שני ערכים: `true` (אמת) ו־`false` (שקר). בלי מירכאות, באותיות קטנות. נראה פשוט, אבל זה הבסיס לכל החלטה בקוד: "האם המשתמש מחובר?", "האם יש מלאי?". בפרק 3 (תנאים) הם יהיו בכל שורה.

```js run console.log(true); console.log(false); ``` ```out true false ```

2. `typeof` — מה הסוג של זה?

כשלא בטוחים, שואלים: `typeof` לפני ערך מחזיר את שם הסוג שלו, כמחרוזת.

```js run console.log(typeof "שלום"); console.log(typeof 42); console.log(typeof "42"); console.log(typeof true); ``` ```out string number string boolean ```

הנה ההוכחה: `"42"` הוא `string`, ו־`42` הוא `number`. בשרת זה חשוב מאוד — כל מה שמגיע מהמשתמש (טופס, כתובת URL) מגיע כטקסט, גם כשהוא נראה כמו מספר. בפרק 2 נלמד להמיר.

3. 🔍 כמה ערכים באותה שורה

ל־`console.log` אפשר לתת כמה ערכים, מופרדים בפסיק. הוא מדפיס את כולם באותה שורה, עם רווח ביניהם:

```js run console.log("מחיר:", 25); console.log("סוג:", typeof 25, "| נכון?", true); console.log("סכום:", 12 + 14 + 8); ``` ```out מחיר: 25 סוג: number | נכון? true סכום: 34 ```

זו התשובה לשאלה מהאתגר של פרק 0: איך מדפיסים "סה״כ" והסכום באותה שורה. הפסיק הוא לא חלק מהפלט — הוא רק מפריד בין הדברים שנותנים ל־`log`.

4. הערות (Comments)

הערה היא טקסט שאתה כותב לבני אדם. Node מדלג עליה לגמרי.

```js run file=playground/comments.js // הערה של שורה אחת: מתחילה ב־// ונמשכת עד סוף השורה console.log("שורה 1"); // אפשר גם בסוף שורת קוד /* הערה של כמה שורות: מתחילה ב־/* ונגמרת בכוכבית־לוכסן */ // console.log("השורה הזו לא תרוץ"); console.log("שורה 2"); ``` ```out שורה 1 שורה 2 ```

שימוש חשוב: "לכבות" שורה זמנית בלי למחוק אותה — שמים `//` בתחילתה. ב־VS Code: עומדים על השורה ומקישים ⌘ + / (ושוב — כדי להחזיר).

💡 מה כותבים בהערה?

לא מה הקוד עושה (את זה הקוד עצמו אומר), אלא למה. גרוע: `// מוסיף 1 ל־count`. טוב: `// סופרים גם את המשתמש הנוכחי`.
