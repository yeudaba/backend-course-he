🎯 בשיעור הזה

  • העתקה רדודה ועמוקה; עדכון בלי לשנות את המקור.

  • `Object.keys/values/entries` ו־JSON.

1. ⚡ הפניות

⚡ חשוב גם במסלול המהיר — אולי הנושא הכי חשוב בפרק ```js run let a = 5; let b = a; b = 10; console.log(a); const user1 = { name: "דנה" }; const user2 = user1; user2.name = "נועה"; console.log(user1.name); console.log(user1 === user2); console.log({ name: "x" } === { name: "x" }); ``` ```out 5 נועה true false ```

מספרים, מחרוזות ובוליאנים מועתקים. אובייקטים ומערכים — לא: המשתנה מחזיק הפניה (כמו כתובת), ו־`user2 = user1` מעתיק רק את הכתובת. שתי מדבקות — קופסה אחת.

הבאג הקלאסי: פונקציה שמשנה את מה שקיבלה

```js run function applyDiscount(product, percent) { product.price = product.price * (1 - percent / 100); return product; } const keyboard = { name: "מקלדת", price: 200 }; const sale = applyDiscount(keyboard, 10); console.log(sale.price, keyboard.price); ``` ```out 180 180 ```

רצינו "מחיר במבצע" — וקיבלנו גם שינוי של המוצר המקורי. הפרמטר `product` הוא עוד חץ לאותו אובייקט, ולכן `product.price = ...` שינה את `keyboard`. בשרת זה יכול להיות מחירון שכל הבקשות משתמשות בו: לקוח אחד קיבל הנחה — וכל הלקוחות אחריו משלמים פחות.

2. העתקה: spread

```js run const original = { name: "מקלדת", price: 200 }; const copy = { ...original }; copy.price = 180; console.log(original.price, copy.price); const updated = { ...original, price: 150, onSale: true }; console.log(updated); ``` ```out 200 180 { name: 'מקלדת', price: 150, onSale: true } ```

`{ ...original }` יוצר אובייקט חדש עם אותם שדות. ו־`{ ...original, price: 150 }` — "הכול כמו במקור, חוץ מ...". זו הדרך המקובלת לעדכן בלי לשנות את המקור. הפונקציה מלמעלה, נכון:

```js run function applyDiscount(product, percent) { return { ...product, price: product.price * (1 - percent / 100) }; } const keyboard = { name: "מקלדת", price: 200 }; const sale = applyDiscount(keyboard, 10); console.log(sale.price, keyboard.price); ``` ```out 180 200 ```

רדוד מול עמוק

```js run const user = { name: "דנה", address: { city: "חיפה" } }; const shallow = { ...user }; shallow.address.city = "אילת"; console.log(user.address.city); const user2 = { name: "דנה", address: { city: "חיפה" } }; const deep = structuredClone(user2); deep.address.city = "אילת"; console.log(user2.address.city); ``` ```out אילת חיפה ```

spread מעתיק רק את הרמה הראשונה. `address` הוא אובייקט — אז ה"עותק" מחזיק הפניה לאותה כתובת. `structuredClone` יוצר עותק עמוק מלא. ברוב הקוד מספיק spread, ומעדכנים גם את הרמה הפנימית במפורש: `{ ...user, address: { ...user.address, city: "אילת" } }`.

3. Destructuring ו־shorthand

```js run const order = { id: 7, total: 320, customer: { name: "עומר" } }; const { id, total } = order; const { customer: { name: customerName } } = order; console.log(id, total, customerName); const [first, second] = ["א", "ב", "ג"]; console.log(first, second); function describe({ name, price = 0 }) { return `${name}: ${price}`; } console.log(describe({ name: "עט" })); const city = "חיפה"; const zip = "3100"; const address = { city, zip }; console.log(address); ``` ```out 7 320 עומר א ב עט: 0 { city: 'חיפה', zip: '3100' } ```
כתיבשווה ל־
`const { id } = order;``const id = order.id;`
`const { customer: { name: customerName } } = order;``const customerName = order.customer.name;`
`const [first, second] = arr;``const first = arr[0]; const second = arr[1];`
`function f({ name, price = 0 })`פונקציה שמקבלת אובייקט ומפרקת אותו בכותרת, עם ברירת מחדל
`{ city, zip }``{ city: city, zip: zip }` (shorthand)

תראה את `({ name, price })` בכותרות של פונקציות בכל מקום — במיוחד ב־Express ו־NestJS. וזוכר מ־P01-E15 את ההחלפה עם `temp`? `[a, b] = [b, a]`.

4. מעבר על שדות: keys / values / entries

```js run const stock = { coffee: 12, tea: 0, cocoa: 5 }; console.log(Object.keys(stock)); console.log(Object.values(stock).reduce((s, n) => s + n, 0)); for (const [item, qty] of Object.entries(stock)) { if (qty === 0) { console.log(`${item} אזל`); } } ``` ```out [ 'coffee', 'tea', 'cocoa' ] 17 tea אזל ```

5. JSON — הפורמט שבו שרתים מדברים

כשהשרת שולח אובייקט לדפדפן, הוא לא יכול לשלוח "אובייקט" — רק טקסט. JSON הוא הדרך לכתוב אובייקט כטקסט:

```js run const order = { id: 7, items: ["עט", "מחברת"], paid: true, coupon: null }; const text = JSON.stringify(order); console.log(text); console.log(typeof text); const back = JSON.parse(text); console.log(back.items[1], back === order); ``` ```out {"id":7,"items":["עט","מחברת"],"paid":true,"coupon":null} string מחברת false ```
JSON מול אובייקט JavaScript
מפתחות חייבים מירכאות כפולות: `{"id": 7}`
מחרוזות — רק מירכאות כפולות
אין פונקציות, אין `undefined` (שדות כאלה נעלמים), תאריכים הופכים למחרוזת
`JSON.parse` על טקסט לא תקין קורס: `SyntaxError: Expected property name or '}' in JSON at position 1`

טריק דיבוג: `JSON.stringify(obj, null, 2)` מדפיס אובייקט "יפה", עם הזחה.
