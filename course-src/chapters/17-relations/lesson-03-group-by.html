🎯 בשיעור הזה
  • `GROUP BY`: צבירה לכל קבוצה.
  • `HAVING` מול `WHERE`.
  • GROUP BY עם JOIN — ומלכודת ה־COUNT.

1. GROUP BY

```sql run db=17-relations/files/store.sql SELECT status, COUNT(*) AS orders FROM orders GROUP BY status ORDER BY orders DESC, status; ``` ```out status | orders -----------+-------- shipped | 6 paid | 3 pending | 2 cancelled | 1 (4 rows) ```

`GROUP BY status` מחלק את השורות לקבוצות לפי הערך, ו־`COUNT(*)` רץ על כל קבוצה בנפרד. בפרק 16 צבירה הפכה את כל הטבלה לשורה אחת; כאן — שורה לכל קבוצה.

⚠️ הכלל

ב־SELECT עם GROUP BY מותר רק: (1) העמודות שב־GROUP BY, (2) פונקציות צבירה. `SELECT status, created_at, COUNT(*) ... GROUP BY status` — שגיאה: לאיזה `created_at` מתוך הקבוצה התכוונת? (חריג אחד: אם מקבצים לפי מפתח ראשי, מותר כל עמודה מאותה טבלה — נראה בהמשך.)

2. GROUP BY עם JOIN

```sql run db=17-relations/files/store.sql SELECT cat.name AS category, SUM(oi.quantity) AS units, SUM(oi.quantity * oi.unit_price) AS revenue FROM order_items oi JOIN orders o ON o.id = oi.order_id JOIN products p ON p.id = oi.product_id JOIN categories cat ON cat.id = p.category_id WHERE o.status <> 'cancelled' GROUP BY cat.name ORDER BY revenue DESC; ``` ```out category | units | revenue -------------+-------+--------- beans | 18 | 1058.20 brewing | 5 | 765.00 grinders | 2 | 378.00 accessories | 11 | 372.60 (4 rows) ```

קודם JOIN (שורה לכל פריט), אחר כך WHERE (בלי הזמנות מבוטלות), ואז GROUP BY (שורה לכל קטגוריה). "ההכנסה לפי X" — כמעט תמיד התבנית הזו.

3. HAVING

```sql run db=17-relations/files/store.sql SELECT c.full_name, COUNT(*) AS orders FROM customers c JOIN orders o ON o.customer_id = c.id WHERE o.status <> 'cancelled' GROUP BY c.id, c.full_name HAVING COUNT(*) >= 2 ORDER BY orders DESC, c.full_name; ``` ```out full_name | orders --------------+-------- Dana Levi | 3 Michal Biton | 2 Ron Avraham | 2 Yossi Cohen | 2 (4 rows) ```

סדר הביצוע המלא: `FROM`/`JOIN` ← `WHERE` ← `GROUP BY` ← `HAVING` ← `SELECT` ← `ORDER BY` ← `LIMIT`.

ולמה `GROUP BY c.id, c.full_name` ולא רק `c.full_name`? כי שני לקוחות יכולים להיקרא "Dana Levi". מקבצים לפי המזהה; השם — כדי להציג.

4. מלכודת ה־COUNT

```sql run db=17-relations/files/store.sql SELECT c.full_name, COUNT(*) AS count_star, COUNT(o.id) AS count_orders FROM customers c LEFT JOIN orders o ON o.customer_id = c.id GROUP BY c.id ORDER BY c.id; ``` ```out full_name | count_star | count_orders --------------+------------+-------------- Dana Levi | 3 | 3 Yossi Cohen | 2 | 2 Noa Mizrahi | 2 | 2 Avi Peretz | 1 | 0 Michal Biton | 2 | 2 Ron Avraham | 2 | 2 Shira David | 1 | 1 Omer Shalom | 1 | 0 (8 rows) ```

ל־Avi ול־Omer אין הזמנות — אבל `COUNT(*)` מחזיר להם 1! כי LEFT JOIN השאיר להם שורה אחת (עם NULL). `COUNT(o.id)` סופר רק ערכים שאינם NULL — וזה מה שרצית. (שים לב גם ל־`GROUP BY c.id` עם `c.full_name` ב־SELECT — זה החריג: id הוא מפתח ראשי, אז כל עמודה של `c` מותרת.)
