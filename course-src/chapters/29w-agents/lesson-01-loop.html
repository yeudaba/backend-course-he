"להוסיף AI" יכול להיות שלושה דברים שונים מאוד:

סוכן מתאים כשהמשימה רב־שלבית וקשה לתאר מראש, כשהתוצאה שווה את העלות, כשהמודל טוב במשימה כזו — וכשטעות אפשר לתפוס ולתקן. אם התשובה לאחת השאלות היא "לא" — workflow, או קריאה אחת (E01).

2. הלולאה

הלולאה הבסיסית כבר מוכרת מפרק 29. מה שהופך אותה לפרודקשן:

```ts const calls = res.content.filter((b): b is Anthropic.ToolUseBlock => b.type === "tool_use"); messages.push({ role: "assistant", content: res.content }); // כמו שהוא — כולל thinking ו־tool_use const results = await Promise.all( // במקביל calls.map(async (c): Promise => { try { return { type: "tool_result", tool_use_id: c.id, content: await tools[c.name].run(c.input) }; } catch (err) { return { type: "tool_result", tool_use_id: c.id, content: `שגיאה: ${(err as Error).message}`, is_error: true }; } }), ); messages.push({ role: "user", content: results }); // כל התוצאות — בהודעה אחת ```
  • במקביל, ובהודעה אחת. המודל יכול לבקש כמה כלים בתור אחד — כי הם בלתי תלויים. מריצים יחד, ומחזירים את כל התוצאות בהודעת user אחת. תוצאות בהודעות נפרדות "מלמדות" אותו להפסיק לבקש במקביל (E06, E20).
  • שגיאה היא תוצאה. כלי שזורק — tool_result עם is_error: true. המודל יכול לנסות אחרת, או להסביר ללקוח. exception שמפיל את השיחה הוא 500 על דבר שהמודל היה מסתדר איתו.
  • ההיסטוריה — append-only. ה־content של המודל חוזר כמו שהוא. במודלים הנוכחיים, עריכה של תורות קודמים (לקצר, לנקות) פוסלת את בלוקי ה־thinking — ובחשבונות חדשים הבקשה נכשלת. מקטינים לפני שמוסיפים (E11).

4. תקרות

סוכן בלי תקרות הוא while (true) שעולה כסף. שלוש תקרות, בקוד: צעדים (maxSteps), זמן (timeout לשיחה ולכל כלי), וכסף (טוקנים מצטברים — פרק 29, ו־task budget של ה־API שנותן למודל לדעת כמה נשאר). כשתקרה נגמרת — סטטוס ברור ("לא הצלחתי להשלים, הועבר לנציג"), לא שתיקה.

💡 tool runner

ה־SDK של Anthropic כולל tool runner (client.beta.messages.toolRunner) שמריץ את הלולאה בשבילך — מגדירים כלים עם zod ופונקציה, והוא קורא, מריץ וחוזר. לרוב הסוכנים זה מספיק, ויש לו hooks לאישורים ולטיפול בשגיאות. כאן כותבים את הלולאה בעצמנו, כי היא בדיוק מה ששואלים עליו בראיון, וכי שיעורים 3–4 צריכים שליטה מלאה: לעצור באמצע לאישור, לשמור מצב, להמשיך אחרי קריסה.
