🎯 בשיעור הזה
  • מבנה `if` / `else if` / `else`.
  • למה הסדר של `else if` קובע את התוצאה.
  • בלוקים `{ }`, הזחה, ומשתנים שחיים רק בתוך בלוק.

1. `if` — "רק אם"

```js run const stock = 3; if (stock < 5) { console.log("⚠️ מלאי נמוך — להזמין עוד"); } console.log("סוף הבדיקה"); ``` ```out ⚠️ מלאי נמוך — להזמין עוד סוף הבדיקה ```

🔍 פירוק

חלקמה זה
`if`"אם"
`(stock < 5)`התנאי — חייב סוגריים עגולים. מחושב ל־`true`/`false`
`{ ... }`בלוק: השורות שירוצו רק אם התנאי `true`
הזחה (2 רווחים)לא חובה ל־JavaScript, אבל חובה לבני אדם: מראה מה בתוך הבלוק. Prettier עושה את זה לבד

אם `stock` היה 10 — השורה הראשונה הייתה מדולגת, ורק "סוף הבדיקה" היה מודפס. אחרי `}` אין `;`.

2. `else` — "ואם לא"

```js run const password = "1234"; if (password.length >= 8) { console.log("סיסמה תקינה"); } else { console.log("סיסמה קצרה מדי — לפחות 8 תווים"); } ``` ```out סיסמה קצרה מדי — לפחות 8 תווים ```

בדיוק אחד מהבלוקים ירוץ — אף פעם לא שניהם ואף פעם לא אף אחד.

3. `else if` — יותר משתי אפשרויות

```js run const temp = 34; if (temp > 30) { console.log("חם"); } else if (temp > 18) { console.log("נעים"); } else { console.log("קר"); } ``` ```out חם ```

34 גדול גם מ־18 — אבל "נעים" לא מודפס, כי הבדיקה נעצרה בתנאי הראשון שהתקיים.

הסדר קובע

אם נחליף את סדר התנאים:

```js run const temp = 34; if (temp > 18) { console.log("נעים"); } else if (temp > 30) { console.log("חם"); } ``` ```out נעים ```

הבלוק של "חם" לעולם לא ירוץ — כל טמפרטורה מעל 30 נתפסת כבר בתנאי הראשון. כלל: בטווחים, מסדרים מהמחמיר ביותר לרופף ביותר (או מהגבוה לנמוך).

4. משתנים בתוך בלוק

משתנה שנוצר עם `let` או `const` בתוך `{ }` קיים רק שם:

```term % node playground/block.js !! ReferenceError: msg is not defined ``` ```js file=playground/block.js const age = 20; if (age >= 18) { const msg = "בגיר"; } console.log(msg); ```

הפתרון: להכריז על המשתנה לפני ה־`if`, עם `let`, ולהציב בתוכו:

```js run const age = 20; let msg; if (age >= 18) { msg = "בגיר"; } else { msg = "קטין"; } console.log(msg); ``` ```out בגיר ```

(בשיעור 4 נראה דרך קצרה יותר — ternary.) נחזור לנושא "איפה משתנה חי" (scope) בפרק 5.

5. תנאי בתוך תנאי

```js run const isLoggedIn = true; const cartItems = 0; if (isLoggedIn) { if (cartItems > 0) { console.log("מעבר לתשלום"); } else { console.log("העגלה ריקה"); } } else { console.log("יש להתחבר קודם"); } ``` ```out העגלה ריקה ```

עובד — אבל כל רמת קינון מקשה לקרוא. בשיעור 3 נלמד לשלב תנאים עם `&&`, ובשיעור 4 — טכניקה בשם guard clause שמשטחת את הקוד.
