  • שישה סימני השוואה, וכל אחד מחזיר `true` או `false`.
  • למה תמיד `===` ולא `==`.
  • השוואת מחרוזות.

1. השוואה היא ביטוי שמחזיר בוליאני

בפרק 1 כתבנו `true` ו־`false` בעצמנו. עכשיו נחשב אותם: כל השוואה היא ביטוי, והתוצאה שלו היא תמיד `true` או `false`.

סימןקוראיםדוגמהתוצאה
`===`שווה (גם בערך וגם בסוג)`5 === 5``true`
`!==`שונה`5 !== 3``true`
`>`גדול מ־`5 > 3``true`
`<`קטן מ־`5 < 3``false`
`>=`גדול או שווה`5 >= 5``true`
`<=`קטן או שווה`4 <= 3``false`
```js run const stock = 4; const ordered = 6; const hasEnough = stock >= ordered; console.log(hasEnough); console.log(typeof hasEnough); console.log(ordered - stock > 0); ``` ```out false boolean true ```

שים לב: אפשר לשמור תוצאת השוואה במשתנה (`hasEnough`) — ושם טוב לבוליאני נשמע כמו שאלת כן/לא.

2. שלושה סימני "שווה" שונים

⚡ חשוב גם במסלול המהיר — למה לא `==`

`==` מנסה להמיר סוגים לפני ההשוואה (כמו שראינו בפרק 2), ומגיע לתוצאות מפתיעות:

```js run console.log(5 == "5"); console.log(0 == false); console.log("" == 0); console.log(5 === "5"); console.log(0 === false); ``` ```out true true true false false ```

ב־Backend, `5 == "5"` הוא בדיוק המקום שבו באגים מתחבאים: מספר מזהה שהגיע מה־URL כטקסט "שווה" למספר במסד — עד שלא. כלל: תמיד `===` ו־`!==`. (כלי ה־ESLint שנתקין בפרק 8 יסמן `==` אוטומטית.) ואם צריך להשוות טקסט למספר — המר קודם במפורש עם `Number()`.

3. השוואת מחרוזות

`===` על מחרוזות בודק שהן זהות לגמרי — כולל אותיות גדולות ורווחים:

```js run const input = " Admin"; console.log(input === "admin"); console.log(input.trim().toLowerCase() === "admin"); ``` ```out false true ```

`<` ו־`>` על מחרוזות משווים לפי סדר מילוני (תו אחר תו, לפי קוד התו). זה עובד כמצופה בין מילים באותיות קטנות, אבל:

```js run console.log("apple" < "banana"); console.log("Zebra" < "apple"); console.log("10" < "9"); ``` ```out true true true ```

אותיות גדולות "קודמות" לקטנות, ו־`"10" < "9"` כי משווים את התו הראשון: `"1"` לפני `"9"`. המסקנה: מספרים שהגיעו כטקסט — להמיר לפני השוואה.
