@hint2
<p><code>phoneInput.trim().replaceAll("-", "").replaceAll(" ", "")</code>. "3 הראשונות" — <code>slice(0, 3)</code>; "4 האחרונות" — <code>slice(-4)</code>.</p>
@solution
```js run file=03-conditions/starter/P03-E27.js save=solutions/P03-E27.js
const phoneInput = " 054-123 4567 ";

const digits = phoneInput.trim().replaceAll("-", "").replaceAll(" ", "");

if (digits.length !== 10 || !digits.startsWith("05")) {
  console.log(`מספר לא תקין: ${phoneInput.trim()}`);
} else {
  const prefix = digits.slice(0, 3);
  console.log(`נקי: ${digits}`);
  console.log(`לתצוגה: ${prefix}-${digits.slice(3)}`);
  console.log(`מוסתר: ${prefix}-***${digits.slice(-4)}`);
}
```

לתצוגה: 054-1234567
מוסתר: 054-***4567

<p><strong>🔁 חזרה על חשבון ו־<code>Math</code> (פרק 2)</strong>, בתוך תנאים. תעריף החניון:</p>
<ul><li>עד 15 דקות (כולל) — חינם.</li><li>מעל 15 דקות — 12 ₪ על השעה הראשונה (גם אם חנית רק 20 דקות).</li><li>אחרי השעה הראשונה — 3.50 ₪ על כל רבע שעה <strong>שהתחיל</strong> (61 דקות = רבע שעה אחד נוסף).</li><li>לא יותר מ־80 ₪ ליום.</li></ul>
<p>כתוב תוכנית שמתחילה ב־<code>const minutesParked = 135;</code> ומדפיסה:</p>
```out
2:15 שעות חניה — לתשלום: 29.50 ₪
```
<p>הדקות תמיד בשתי ספרות (<code>1:05</code>, לא <code>1:5</code>). הבודק מריץ גם עם 10, 15, 16, 60, 61, 75 ו־600 דקות.</p>
<p>📄 כותבים בקובץ <code>03-conditions/starter/P03-E28.js</code> (יש בו רק הערה), מריצים ובודקים:</p>
```term
% node 03-conditions/starter/P03-E28.js
% npm run check P03-E28
```
@hint1
<p>שני חלקים נפרדים: התצוגה (<code>Math.floor</code>, <code>%</code>, <code>padStart</code> — כמו בשעון של P02-E25) והמחיר (<code>if / else if</code>).</p>
<p>"רבע שעה שהתחיל" — איזו פונקציה של <code>Math</code> מעגלת למעלה?</p>
@hint2
<p>מעל שעה: <code>12 + Math.ceil((minutesParked - 60) / 15) * 3.5</code>, ואז <code>Math.min(80, ...)</code>.</p>
@solution
```js run file=03-conditions/starter/P03-E28.js save=solutions/P03-E28.js
const minutesParked = 135;

const firstHour = 12;
const perQuarter = 3.5;
const dailyMax = 80;

let price;
if (minutesParked <= 15) {
  price = 0;
} else if (minutesParked <= 60) {
  price = firstHour;
} else {
  const quarters = Math.ceil((minutesParked - 60) / 15);
  price = Math.min(dailyMax, firstHour + quarters * perQuarter);
}

const hours = Math.floor(minutesParked / 60);
const minutes = String(minutesParked % 60).padStart(2, "0");
console.log(`${hours}:${minutes} שעות חניה — לתשלום: ${price.toFixed(2)} ₪`);
```
```out
2:15 שעות חניה — לתשלום: 29.50 ₪
```
<p>בדיקה ב־135 דקות: אחרי השעה הראשונה נשארו 75 דקות. <code>75 / 15</code> הוא 5 רבעים בדיוק, ולכן <code>12 + 5 × 3.5 = 29.5</code>. ב־61 דקות: <code>Math.ceil(1 / 15)</code> הוא 1, ולכן 15.50.</p>
<p><code>Math.min(80, ...)</code> הוא "תקרה": הערך הקטן מבין השניים. זה אותו טריק כמו <code>Math.max(0, ...)</code> ב־P03-E06, שהוא "רצפה". שניהם חוסכים <code>if</code>.</p>
@mistakes
<ul><li><code>Math.floor</code> או <code>Math.round</code> במקום <code>Math.ceil</code> — ב־61 דקות החניון יפסיד את הרבע שהתחיל.</li><li><code>minutesParked / 15 * 3.5</code> בלי להוריד את השעה הראשונה — השעה נספרת פעמיים.</li><li><code>`${hours}:${minutesParked % 60}`</code> בלי <code>padStart</code> ← <code>1:0</code> במקום <code>1:00</code>.</li></ul>
