1. כלל CSS

```css file=playground/style.css body { font-family: system-ui, sans-serif; background: #f4f5f7; margin: 0; } .card { background: white; border: 1px solid #d8dbe0; border-radius: 12px; padding: 16px; } #title { font-size: 1.5rem; } ```

מחברים מה־`head` של הדף: ``. כל כלל: selector (על מי) + הצהרות `תכונה: ערך;` (מה).

2. Box model

מלכודת קלאסית: `width: 300px` עם `padding: 20px` ו־`border: 1px` — הקופסה תופסת בפועל 342px. הפתרון שכולם שמים בראש כל קובץ CSS:

```css * { box-sizing: border-box; /* width כולל את ה־padding וה־border */ } ```

יחידות: `px` (פיקסלים), `rem` (יחסית לגודל הגופן הבסיסי — `1.5rem` = פי 1.5), `%` (מההורה).

    בלי flex — `li` מסדר את הילדים בשורה רק אם הם "inline", ויישור אנכי הוא סבל. עם flex: שלוש שורות CSS, והכפתור נדחף לקצה. ו־RTL? בזכות `dir="rtl"` על `html`, flex מתחיל מימין — הצ'קבוקס מימין, הכפתור משמאל. בלי לשנות כלום ב־CSS.

    4. עוד תכונות שתצטרך

    ```css file=playground/style.css main { max-width: 720px; margin: 0 auto; } .tasks { list-style: none; padding-inline-start: 0; } .task.done .title { text-decoration: line-through; color: #6b7280; } button { cursor: pointer; } button:disabled { opacity: 0.5; cursor: not-allowed; } [hidden] { display: none !important; } ```
    תכונהמה עושה
    `color` · `font-size` · `line-height`צבע הטקסט · גודל האותיות · גובה שורה (`1.5` — פי 1.5 מגודל האות, קל לקריאה)
    `max-width: 720px` · `min-width`"לא יותר רחב מ־720" (במסך צר — מתכווץ) · "לא צר יותר מ־"
    `margin: 0 auto`0 למעלה ולמטה, ו־`auto` משני הצדדים — האלמנט ממורכז. עובד רק כשיש לו רוחב (`max-width`)
    `list-style: none`רשימה בלי תבליטים. בדרך כלל יחד עם `padding-inline-start: 0` — הריווח בצד שבו הרשימה מתחילה (בעברית — מימין)
    `text-decoration``line-through` (קו חוצה, למשימה שבוצעה) · `none` (קישור בלי קו תחתי)
    `display``block` (תופס שורה שלמה) · `inline` (בתוך השורה) · `flex` · `none` (מוסתר, לא תופס מקום)
    `cursor: pointer`סמן "יד" מעל דבר לחיץ
    `opacity: 0.5`שקיפות: 1 — רגיל, 0 — שקוף לגמרי

    צבע כמו `#6b7280` הוא שלושה מספרים בבסיס 16 (הקסדצימלי): אדום `6b`, ירוק `72`, כחול `80` — כל אחד בין `00` ל־`ff` (0–255). ‏`#fa0` הוא קיצור של `#ffaa00`. ב־JavaScript, `parseInt` עם פרמטר שני קורא מספר בבסיס הזה, ו־`toString(16)` כותב מספר בבסיס 16:

    ⚠️ `hidden` שלא מסתיר

    התכונה `hidden` (`

    `) מסתירה בגלל כלל מובנה של הדפדפן: `display: none`. אבל כלל משלך כמו `.error { display: flex; }` גובר עליו — והאלמנט מופיע למרות ה־`hidden`. הכלל `[hidden] { display: none !important; }` מחזיר את הסדר: `!important` גובר על כל כלל רגיל. (ב־`!important` לא משתמשים בשום מקום אחר — הוא הופך את ה־CSS לקשה לשינוי.)
