1. פרויקט חדש

```term % mkdir ~/dev/npm-playground && cd ~/dev/npm-playground % npm init -y Wrote to /Users/yeuda/dev/npm-playground/package.json: { "name": "npm-playground", "version": "1.0.0", "main": "index.js", "scripts": { "test": "echo \"Error: no test specified\" && exit 1" }, "keywords": [], "author": "", "license": "ISC", "description": "" } ```

`-y` — "כן לכל השאלות" (ברירות מחדל). `package.json` הוא "תעודת הזהות" של הפרויקט. אחרי `init`, נהוג להוסיף `"type": "module"` (ES Modules — פרק 8) ו־`"private": true` (כדי שלא תפרסם אותו בטעות ל־npm).

2. התקנת חבילה

```term % npm install nanoid .. added 1 package, and audited 2 packages in 1s % npm install --save-dev eslint % ls node_modules package-lock.json package.json ``` ```json { "dependencies": { "nanoid": "^6.0.2" }, "devDependencies": { "eslint": "^9.39.0" } } ```
סוגפקודהדוגמאות
`dependencies` — צריך כדי לרוץ`npm install express`Express, Prisma Client, Zod
`devDependencies` — רק לפיתוח`npm install -D typescript`TypeScript, ESLint, כלי בדיקות

ההבדל חשוב בשרת: שם מתקינים רק את ה־dependencies (`npm ci --omit=dev`) — פחות קוד, התקנה מהירה יותר, ופחות "שטח" לפרצות.

3. גרסאות: semver

`4.18.2` = MAJOR.MINOR.PATCH:

חלקעולה כש...שובר קוד קיים?
PATCH (`4.18.2` ← `4.18.3`)תיקון באגלא אמור
MINOR (`4.18` ← `4.19`)יכולת חדשהלא אמור
MAJOR (`4` ← `5`)שינוי שוברכן, ייתכן
ב־package.jsonמתיר
`"^4.18.2"``4.x.x` מ־4.18.2 ומעלה (MINOR ו־PATCH) — ברירת המחדל
`"~4.18.2"`רק `4.18.x` (PATCH)
`"4.18.2"`בדיוק זו

אז למה צריך lockfile? כי `^4.18.2` היום ו־`^4.18.2` בעוד חודש יכולים להתקין גרסאות שונות. ה־lockfile "מקפיא" את הגרסאות המדויקות — כולל של חבילות שהחבילות שלך תלויות בהן — כך שכולם (אתה, הצוות, השרת) מריצים בדיוק את אותו קוד.

4. scripts ו־npx

```json { "scripts": { "start": "node src/server.js", "dev": "node --watch --env-file=.env src/server.js", "test": "node --test", "lint": "eslint ." } } ``` ```term % npm start % npm run dev % npm test % npx eslint src/ ```

`npm run <שם>` מריץ פקודה מ־`scripts` (ל־`start` ול־`test` יש קיצור בלי `run`). בתוך scripts, כלים מ־`node_modules/.bin` זמינים בשמם. `npx <כלי>` — אותו דבר מה־Terminal. (`--watch` — Node מפעיל מחדש בכל שמירה; נוח מאוד לשרת.)

⚠️ חבילות הן קוד של אחרים

כל חבילה שאתה מתקין רצה עם ההרשאות שלך. לפני התקנה: האם יש לה הרבה הורדות שבועיות? מתי עודכנה? האם השם נכון (תוקפים מפרסמים חבילות עם שמות דומים — "expres")? `npm audit` מדווח על פרצות ידועות בתלויות. בפרק 25 נריץ אותו אוטומטית.
