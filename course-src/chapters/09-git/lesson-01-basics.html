  • איך כותבים הודעת commit טובה.

1. Git בשתי שורות

Git שומר תמונות מצב (commits) של הפרויקט שלך, לפי בקשתך. כל תמונה כוללת את כל הקבצים, הודעה שמסבירה מה השתנה, מי עשה ומתי, ומצביע לתמונה הקודמת. כך נוצרת שרשרת — היסטוריה שאפשר לטייל בה.

שים לב: Git לא שומר אוטומטית. אתה מחליט מתי "לצלם". זה לא Google Docs — וזה יתרון: כל commit הוא נקודה שבה הקוד במצב שאתה בחרת.

2. שלושת האזורים

למה צריך אזור הכנה? כי לפעמים שינית חמישה קבצים, אבל שניים מהם שייכים ל"תיקון באג" ושלושה ל"תכונה חדשה". אזור ההכנה מאפשר לעשות מהם שני commits נפרדים ומסודרים.

3. 👣 commit ראשון

```term % cd ~/dev/backend-course/playground % mkdir git-first && cd git-first % git init Initialized empty Git repository in /Users/yeuda/dev/backend-course/playground/git-first/.git/ % git status On branch main No commits yet nothing to commit (create/copy files and use "git add" to track) ```

`git init` יצר תיקייה נסתרת `.git` — שם Git שומר את כל ההיסטוריה. (אל תיגע בה ידנית. ואם תמחק אותה — ההיסטוריה נעלמת, הקבצים נשארים.)

עכשיו צור קובץ `hello.js` עם שורת `console.log` אחת, ו:

```term % git status On branch main No commits yet Untracked files: (use "git add ..." to include in what will be committed) hello.js nothing added to commit but untracked files present (use "git add" to track) % git add hello.js % git status On branch main No commits yet Changes to be committed: (use "git rm --cached ..." to unstage) new file: hello.js % git commit -m "Add hello script" [main (root-commit) 4f2a9c1] Add hello script 1 file changed, 1 insertion(+) create mode 100644 hello.js % git log --oneline 4f2a9c1 (HEAD -> main) Add hello script ```
פקודהמה עושה
`git status`"מה המצב?" — מה השתנה, מה באזור ההכנה. הרץ אותה כל הזמן.
`git add hello.js`מכניס את הקובץ (במצבו עכשיו) לאזור ההכנה. `git add .` — את כל השינויים בתיקייה
`git commit -m "..."`יוצר commit מכל מה שבאזור ההכנה, עם ההודעה
`git log --oneline`ההיסטוריה, שורה לכל commit. בלי `--oneline` — מפורט

`4f2a9c1` הוא מזהה ה־commit (hash) — אצלך יהיה שונה. כל commit מקבל מזהה ייחודי שנגזר מהתוכן שלו. ("טביעת האצבע" שראית ב־`code --version` בפרק 0 — זה בדיוק זה.)

4. הודעות commit

✘ גרוע✔ טוב
`fix``Fix crash when expense file is empty`
`changes``Add monthly summary command`
`asdf``Round amounts to 2 decimals in summary`
`fixed bug and added feature and refactor`שלושה commits נפרדים

המוסכמה: באנגלית, פועל בציווי בהתחלה ("Add", "Fix", "Remove"), עד ~50 תווים, ומשלים את המשפט "If applied, this commit will ___". וcommit אחד = שינוי הגיוני אחד. היסטוריה כזו קריאה כמו יומן — ומראיין שפותח את ה־GitHub שלך רואה אותה.

💡 Git בתוך VS Code

לשונית Source Control בסרגל הפעולות (⌃+⇧+G) מציגה את אותו מידע כמו `git status`, עם `+` ליד כל קובץ (= `add`) ושדה הודעה + ✓ (= `commit`). בקורס נלמד קודם את הפקודות, כדי שתבין מה הכפתורים עושים — ואז תשתמש במה שנוח לך.
