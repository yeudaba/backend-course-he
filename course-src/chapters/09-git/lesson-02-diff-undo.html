1. `git diff`

```term % git diff diff --git a/prices.js b/prices.js index 3b5a1e2..8c4d0f7 100644 --- a/prices.js +++ b/prices.js @@ -1,4 +1,4 @@ -const VAT = 0.17; +const VAT = 0.18; function withVat(p) { return p * (1 + VAT); } ```

שורות עם `-` (אדום) — הוסרו; עם `+` (ירוק) — נוספו; בלי סימן — הקשר. `@@ -1,4 +1,4 @@` — "שורות 1–4 בגרסה הישנה מול 1–4 בחדשה". VS Code מציג את אותו דבר בתצוגה מפוצלת: לחיצה על קובץ בלשונית Source Control.

פקודהמראה
`git diff`שינויים שעוד לא באזור ההכנה
`git diff --staged`מה כן באזור ההכנה — מה שייכנס ל־commit. בדוק לפני כל commit!
`git show 3d36ee3`מה שינה commit מסוים
`git log -p prices.js`כל ההיסטוריה של קובץ, עם השינויים
`git log --oneline --graph --all`ההיסטוריה כגרף, כולל כל הענפים

המצבהפקודהמה קורה

הכנסתי קובץ לאזור ההכנה בטעות`git restore --staged notes.txt`יוצא מאזור ההכנה; הקובץ עצמו לא משתנה

שכחתי קובץ ב־commit האחרון (ועוד לא דחפתי)`git add file` ואז `git commit --amend --no-edit`ה־commit האחרון מוחלף בגרסה מתוקנת
⚠️ פקודות מסוכנות

באינטרנט תמצא `git reset --hard` ו־`git push --force`. הן משכתבות היסטוריה ומוחקות עבודה, ואין להן "בטל". בקורס לא נשתמש בהן. אם נתקעת — `git status` ושאל לפני שמריצים משהו שאתה לא מבין.

3. `.gitignore`

יש קבצים שאסור ש־Git יעקוב אחריהם:

מהלמה
`node_modules/`ספריות שמותקנות מחדש עם `npm install` (פרק 13). מאות מגה, אלפי קבצים
`.env`סודות: סיסמאות למסד, מפתחות API (פרק 13)
`.DS_Store`קובץ זבל שה־Mac יוצר בכל תיקייה
קובצי נתונים מקומיים, logs, `dist/`נוצרים בהרצה; לא חלק מהקוד
```text file=.gitignore node_modules/ .env .DS_Store *.log dist/ ```

שורה = תבנית. `/` בסוף = תיקייה. `*` = "כל דבר". הקובץ `.gitignore` עצמו כן נכנס ל־Git (כדי שכל הצוות ישתמש בו).

⚠️ `.gitignore` לא עוזר בדיעבד

אם קובץ כבר נכנס ל־commit, הוספה ל־`.gitignore` לא מוציאה אותו. צריך `git rm --cached file` (מסיר מהמעקב, משאיר בדיסק) ואז commit. ואם זה סוד — הוא כבר בהיסטוריה; ראה שיעור 4.
