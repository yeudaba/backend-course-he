🎯 בשיעור הזה
  • ליצור מערך ולגשת לאיברים לפי אינדקס.
  • להוסיף ולהסיר: `push`, `pop`, `unshift`, `shift`.
  • לחפש: `includes`, `indexOf`.
  • `const` ומערכים — מה מותר לשנות.

1. מערך = רשימה ממוספרת

```js run const prices = [12, 14, 8]; const names = ["אספרסו", "קרואסון", "מים"]; const empty = []; console.log(prices); console.log(names[0]); console.log(prices.length); console.log(empty.length); ``` ```out [ 12, 14, 8 ] אספרסו 3 0 ```

מערך יכול להכיל כל סוג ערך, גם מעורב (`[1, "שתיים", true]`), אבל בפועל כמעט תמיד כל האיברים מאותו סוג — זה מה שהופך מערך לשימושי.

2. קריאה ושינוי לפי אינדקס

```js run const scores = [70, 85, 90]; scores[1] = 88; console.log(scores); console.log(scores[scores.length - 1]); console.log(scores.at(-1)); console.log(scores[10]); ``` ```out [ 70, 88, 90 ] 90 90 undefined ```

`at(-1)` הוא הקיצור המודרני ל"האחרון". אינדקס שלא קיים מחזיר `undefined`, בלי שגיאה.

3. הוספה והסרה

מתודהאיפהמה מחזירה
`push(x)`מוסיפה לסוףהאורך החדש
`pop()`מסירה מהסוףהאיבר שהוסר
`unshift(x)`מוסיפה להתחלההאורך החדש
`shift()`מסירה מההתחלההאיבר שהוסר
```js run const queue = ["דנה", "עומר"]; queue.push("נועה"); console.log(queue); const first = queue.shift(); console.log(`${first} נכנס/ה. בתור: ${queue}`); queue.unshift("VIP"); const last = queue.pop(); console.log(queue, last); ``` ```out [ 'דנה', 'עומר', 'נועה' ] דנה נכנס/ה. בתור: עומר,נועה [ 'VIP', 'עומר' ] נועה ```

(מערך בתוך template literal מודפס עם פסיקים — בשיעור 2 נראה איך לשלוט בזה עם `join`.) `push` + `shift` = תור (הראשון שנכנס — ראשון לצאת). `push` + `pop` = מחסנית (האחרון שנכנס — ראשון לצאת). שני המבנים האלה יחזרו בפרק 26 (תורים) ובפרק 27 (ראיונות).

4. חיפוש

```js run const roles = ["viewer", "editor", "admin"]; console.log(roles.includes("admin")); console.log(roles.includes("owner")); console.log(roles.indexOf("editor")); console.log(roles.indexOf("owner")); ``` ```out true false 1 -1 ```

תזכורת מפרק 3: `role === "admin" || role === "owner" || ...` — עכשיו אפשר `["admin", "owner"].includes(role)`. נקי יותר, וקל להוסיף תפקיד.

5. ⚡ `const` ומערכים

⚡ חשוב גם במסלול המהיר ```js run const cart = ["עט"]; cart.push("מחברת"); cart[0] = "עיפרון"; console.log(cart); ``` ```out [ 'עיפרון', 'מחברת' ] ```

`const` אומר: המדבקה לא תועבר לקופסה אחרת — `cart = [...]` ייתן `TypeError: Assignment to constant variable.`. אבל התוכן של הקופסה אפשר לשנות. לכן מערכים כמעט תמיד מוגדרים עם `const`. בפרק 7 נבין את זה לעומק ("הפניות").
