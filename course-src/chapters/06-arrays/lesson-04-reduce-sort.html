🎯 בשיעור הזה
  • `reduce` — לכווץ מערך לערך אחד.
  • `sort` — ולמה בלי פונקציה הוא מסוכן.
  • מה משנה את המערך ומה מחזיר מערך חדש: `slice`, `splice`, spread.

1. `reduce` — צובר מובנה

`reduce` הוא בדיוק דפוס הצובר מפרק 4, בשורה אחת:

```js run const prices = [12, 14, 8]; let total = 0; for (const p of prices) { total = total + p; } const total2 = prices.reduce((sum, p) => sum + p, 0); console.log(total, total2); ``` ```out 34 34 ```
בלולאהב־reduce
`let total = 0`הארגומנט השני: `0` (ערך ההתחלה)
`total = total + p`ה־callback: מקבל את הצובר הנוכחי ואת האיבר, מחזיר את הצובר החדש
אחרי הלולאה: `total`מה ש־`reduce` מחזיר

📊 מעקב: `(0, 12) ← 12`, `(12, 14) ← 26`, `(26, 8) ← 34`.

```js run const temps = [-2, 5, 11, -6]; const max = temps.reduce((best, t) => (t > best ? t : best), temps[0]); const csv = ["a", "b", "c"].reduce((acc, x) => acc + x.toUpperCase(), ""); console.log(max, csv); ``` ```out 11 ABC ```
⚠️ תמיד לתת ערך התחלה

בלי הארגומנט השני, `reduce` על מערך ריק קורס: `TypeError: Reduce of empty array with no initial value`. ועגלה ריקה היא מקרה אמיתי. כלל: תמיד `reduce(fn, initial)`.

💡 reduce או לולאה?

לסכום ולמקסימום — `reduce` קצר וברור. כשהלוגיקה בפנים מתארכת (כמה צוברים, תנאים) — לולאת `for...of` קריאה יותר. אין "נכון" אחד; קריאות מנצחת.

2. `sort` — מיון

```js run console.log([10, 1, 5, 100].sort()); console.log([10, 1, 5, 100].sort((a, b) => a - b)); console.log([10, 1, 5, 100].sort((a, b) => b - a)); console.log(["דנה", "אבי", "גיל"].sort((a, b) => a.localeCompare(b))); ``` ```out [ 1, 10, 100, 5 ] [ 1, 5, 10, 100 ] [ 100, 10, 5, 1 ] [ 'אבי', 'גיל', 'דנה' ] ```

בלי פונקציה, `sort` ממיר הכול למחרוזות וממיין "מילונית" — `"100"` לפני `"5"`. תמיד מעבירים פונקציית השוואה (comparator):

הפונקציה מחזירהפירוש
מספר שלילי`a` לפני `b`
מספר חיובי`b` לפני `a`
0לא משנה

`a - b` ← עולה, `b - a` ← יורד, `a.localeCompare(b)` ← מחרוזות לפי סדר אלפביתי (גם בעברית).

3. ⚡ משנה את המקור — או לא?

⚡ חשוב גם במסלול המהיר ```js run const original = [3, 1, 2]; const sorted = original.sort((a, b) => a - b); console.log(original, sorted, original === sorted); const safe = [3, 1, 2]; const sortedCopy = [...safe].sort((a, b) => a - b); console.log(safe, sortedCopy); ``` ```out [ 1, 2, 3 ] [ 1, 2, 3 ] true [ 3, 1, 2 ] [ 1, 2, 3 ] ```

`sort` משנה את המערך המקורי (ומחזיר אותו). אם המערך הגיע מבחוץ — למשל רשימה שפונקציה אחרת עוד משתמשת בה — מיינת לה אותו בלי לשאול. `[...arr]` (spread) יוצר עותק, ואותו ממיינים. (יש גם `toSorted`, מתודה חדשה שמחזירה עותק ממוין.)

משנות את המקור (mutate)מחזירות חדש, המקור לא נגוע
`push`, `pop`, `shift`, `unshift`, `sort`, `reverse`, `splice``map`, `filter`, `slice`, `concat`, `join`, `toSorted`, `[...arr]`

4. `slice` מול `splice`

```js run const letters = ["a", "b", "c", "d", "e"]; console.log(letters.slice(1, 3)); console.log(letters); const removed = letters.splice(1, 2); console.log(removed); console.log(letters); letters.splice(1, 0, "X", "Y"); console.log(letters); ``` ```out [ 'b', 'c' ] [ 'a', 'b', 'c', 'd', 'e' ] [ 'b', 'c' ] [ 'a', 'd', 'e' ] [ 'a', 'X', 'Y', 'd', 'e' ] ```

`slice(start, end)` — "פרוסה": עותק של חלק, כמו במחרוזות. `splice(start, count, ...items)` — "ניתוח": מוחק `count` איברים מ־`start` (ומחזיר אותם), ואופציונלית מכניס חדשים. השמות דומים בצורה מרגיזה — כדאי לזכור ש־splice "inserts".

5. Spread: עותקים וחיבורים

```js run const a = [1, 2]; const b = [3, 4]; const both = [...a, ...b]; const withZero = [0, ...a]; console.log(both, withZero); console.log(Math.max(...both)); ``` ```out [ 1, 2, 3, 4 ] [ 0, 1, 2 ] 4 ```

`...arr` "פורס" את האיברים במקום שבו הוא כתוב. שימושים: עותק, חיבור מערכים, והעברת מערך לפונקציה שמצפה לארגומנטים נפרדים (`Math.max`).
