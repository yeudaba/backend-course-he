🎯 בשיעור הזה

חמש מתודות שמקבלות פונקציה (callback, מפרק 5) ומפעילות אותה על כל איבר. הן מחליפות רוב הלולאות שתכתוב בשרת.

1. `map` — להמיר כל איבר

```js run const prices = [100, 250, 40]; const withVat = prices.map((p) => p * 1.18); console.log(withVat); console.log(prices); const labels = prices.map((p, i) => `${i + 1}) ₪${p}`); console.log(labels.join(" | ")); const numbers = "10,20,30".split(",").map(Number); console.log(numbers); ``` ```out [ 118, 295, 47.199999999999996 ] [ 100, 250, 40 ] 1) ₪100 | 2) ₪250 | 3) ₪40 [ 10, 20, 30 ] ```

`map` מחזיר מערך חדש באותו אורך. ה־callback מקבל את האיבר (ואופציונלית גם את האינדקס). `map(Number)` מעביר את הפונקציה המובנית `Number` — כל מחרוזת הופכת למספר.

2. `filter` — לשמור רק חלק

```js run const orders = [120, 45, 300, 80, 510]; const big = orders.filter((amount) => amount >= 100); console.log(big); const words = " learn node js ".split(" "); console.log(words); console.log(words.filter((w) => w !== "")); ``` ```out [ 120, 300, 510 ] [ '', '', 'learn', '', '', 'node', '', 'js', '' ] [ 'learn', 'node', 'js' ] ```

ה־callback מחזיר בוליאני: `true` — האיבר נשאר. הדוגמה השנייה היא פתרון הרווחים הכפולים של ה־slug: `split(" ")` מייצר מחרוזות ריקות, ו־`filter` מנקה אותן.

3. `find` — הראשון שמתאים

```js run const stock = [0, 0, 7, 3]; console.log(stock.find((s) => s > 0)); console.log(stock.findIndex((s) => s > 0)); console.log(stock.find((s) => s > 100)); ``` ```out 7 2 undefined ```

`find` מחזיר את האיבר (או `undefined`), `findIndex` — את המיקום (או `-1`). שניהם עוצרים ברגע שמצאו — כמו `break`.

4. `some` ו־`every` — שאלות על כל המערך

```js run const ages = [22, 17, 35]; console.log(ages.some((a) => a < 18)); console.log(ages.every((a) => a >= 18)); console.log([].every((a) => a > 100)); ``` ```out true false true ```

"האם יש לפחות אחד?" / "האם כולם?". שים לב למקרה הקצה: `every` על מערך ריק מחזיר `true` ("כל האפס איברים עברו"). במערכת אמיתית — "כל הפריטים בעגלה במלאי?" על עגלה ריקה יחזיר כן, ולכן בודקים קודם שהעגלה לא ריקה.

5. שרשור

```js run const raw = " 45, abc, 120 ,, 300 "; const total = raw .split(",") .map((s) => s.trim()) .filter((s) => s !== "") .map(Number) .filter((n) => !Number.isNaN(n)); console.log(total); ``` ```out [ 45, 120, 300 ] ```

קוראים מלמעלה למטה: פצל ← נקה רווחים ← זרוק ריקים ← המר למספרים ← זרוק לא־מספרים. כל שלב מקבל את המערך של השלב הקודם. ככה נראה קוד עיבוד נתונים בשרת אמיתי.

⚡ חשוב גם במסלול המהיר — map או forEach?

יש גם `forEach((x) => ...)` — מפעיל פונקציה על כל איבר ולא מחזיר כלום. בקורס: אם רוצים מערך חדש — `map`/`filter`. אם רוצים רק "לעשות משהו" (להדפיס) — `for...of` קריא יותר. טעות נפוצה: `const x = arr.forEach(...)` ← `undefined`.
