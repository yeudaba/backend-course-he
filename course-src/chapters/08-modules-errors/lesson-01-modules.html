1. למה לפצל?

קובץ של 800 שורות הוא כמו מחסן בלי מדפים. כשמפצלים לפי נושא — קובץ לחישובי מחירים, קובץ לבדיקות קלט, קובץ ל"תוכנית הראשית" — קל למצוא דברים, קל לבדוק כל חלק לבד, ושני אנשים יכולים לעבוד במקביל בלי להתנגש.

2. CommonJS: `module.exports` ו־`require`

זה הסגנון שבו כתובים קובצי התרגילים מאז פרק 5:

```js file=playground/shop/pricing.js const VAT = 0.18; function withVat(price) { return Math.round(price * (1 + VAT) * 100) / 100; } function discount(price, percent) { return price * (1 - percent / 100); } module.exports = { withVat, discount }; ``` ```js file=playground/shop/main.js const { withVat, discount } = require("./pricing"); console.log(withVat(100)); console.log(withVat(discount(200, 10))); ``` ```term % node playground/shop/main.js 118 212.4 ```
חלקמה זה
`module.exports = { withVat, discount };`"זה מה שהקובץ הזה נותן החוצה" — אובייקט עם שתי פונקציות (shorthand מפרק 7)
`require("./pricing")`מריץ את `pricing.js` (פעם אחת) ומחזיר את ה־`module.exports` שלו
`const { withVat, discount } = ...`destructuring — מוציאים את מה שצריך
`./`חובה לקבצים שלך: "באותה תיקייה". בלי `./`, Node מחפש ספרייה מותקנת (פרק 13)

שים לב: `VAT` לא ייצא, ולכן `main.js` לא רואה אותו — הוא "פרטי" ל־`pricing.js`. ועכשיו מובן מה הבודק עושה: הוא מבצע `require` (ליתר דיוק `import`) לקובץ שלך ומקבל את מה שייצאת.

3. ES Modules: `export` ו־`import`

הסגנון המודרני, שקיים גם בדפדפן. אותו קוד:

```js file=playground/shop-esm/pricing.mjs const VAT = 0.18; export function withVat(price) { return Math.round(price * (1 + VAT) * 100) / 100; } export const discount = (price, percent) => price * (1 - percent / 100); ``` ```js file=playground/shop-esm/main.mjs import { withVat, discount } from "./pricing.mjs"; console.log(withVat(100)); console.log(withVat(discount(200, 10))); ```
CommonJSES Modules
ייצוא`module.exports = { a, b };``export function a() {}` / `export { a, b };`
ייבוא`const { a } = require("./x");``import { a } from "./x.js";`
סיומת בייבואלא חובהחובה (`./x.js`)
איך Node יודעברירת המחדל לקובצי `.js`קובצי `.mjs`, או `"type": "module"` ב־`package.json`

ייצוא ברירת מחדל

```js // logger.mjs export default function log(msg) { console.log(`[${new Date().toISOString()}] ${msg}`); } // main.mjs import log from "./logger.mjs"; ```

ייצוא `default` — "הדבר העיקרי" בקובץ, ומייבאים אותו בלי סוגריים מסולסלים ובאיזה שם שרוצים. בקורס נעדיף ייצוא בשם (named) — שגיאת כתיב בשם נתפסת מיד.

💡 מה בוחרים?

בקוד חדש — ES Modules. מהפרויקט הראשון והלאה, כל פרויקט יקבל `"type": "module"` ב־`package.json`. CommonJS תמשיך לפגוש בקוד קיים, במדריכים ישנים, וב־NestJS (שבו TypeScript מתרגם לזה מאחורי הקלעים). קובצי התרגילים של הקורס נשארים בסגנון CommonJS כדי שלא נשנה הכול באמצע — שניהם עובדים יחד.
