1. stack trace — עד הסוף

בפרק 0 אמרנו "כרגע אפשר להתעלם משורות ה־`at`". הגיע הזמן. נניח שלושה קבצים:

```js file=playground/debug/main.js const { orderTotal } = require("./orders"); const order = { items: [{ price: 10, qty: 2 }, null] }; console.log(orderTotal(order)); ``` ```js file=playground/debug/orders.js const { lineTotal } = require("./lines"); function orderTotal(order) { return order.items.reduce((sum, item) => sum + lineTotal(item), 0); } module.exports = { orderTotal }; ``` ```js file=playground/debug/lines.js function lineTotal(item) { return item.price * item.qty; } module.exports = { lineTotal }; ``` ```term % node playground/debug/main.js .. /Users/yeuda/dev/backend-course/playground/debug/lines.js:2 return item.price * item.qty; ^ !! TypeError: Cannot read properties of null (reading 'price') at lineTotal (/Users/yeuda/dev/backend-course/playground/debug/lines.js:2:15) at /Users/yeuda/dev/backend-course/playground/debug/orders.js:4:50 at Array.reduce () at orderTotal (/Users/yeuda/dev/backend-course/playground/debug/orders.js:4:22) at Object. (/Users/yeuda/dev/backend-course/playground/debug/main.js:4:13) at Module._compile (node:internal/modules/cjs/loader:1554:14) .. ... ```
  1. קרא את הסוג וההודעה: ניסיון לקרוא `price` מתוך `null`.
  2. השורה העליונה שלך: `lines.js:2:15` — שורה 2, תו 15. שם השגיאה קרתה.
  3. אבל הבאג אולי במקום אחר: `lineTotal` לא אשמה שקיבלה `null`. עלה בערימה: מי קרא לה? `orders.js:4`, ומי קרא ל־`orderTotal`? `main.js:4` — ושם, בשורה 3, ההזמנה מכילה `null`. הבאג הוא בנתונים, לא בפונקציה.

(ב־Terminal של VS Code, ⌘ + לחיצה על נתיב כמו `lines.js:2:15` פותחת את הקובץ בדיוק בשורה.)

2. ה־Debugger: לעצור את הזמן

`console.log` הוא כמו לצלם תמונה; הדיבאגר הוא כמו לעצור את הסרט ולהסתובב בתוך הסצנה. במקום לנחש איפה להוסיף הדפסות — עוצרים בשורה ורואים את כל המשתנים.

הפעלה

  1. פתח את `playground/debug/orders.js`. לחץ משמאל למספר השורה 4 — תופיע נקודה אדומה. זה breakpoint.
  2. פתח את לשונית Run and Debug בסרגל הפעולות (אייקון ▷ עם חרק, או ⌘ + ⇧ + D).
  3. לחץ JavaScript Debug Terminal. נפתח Terminal מיוחד בפאנל התחתון.
  4. בו, הרץ כרגיל: `node playground/debug/main.js`. התוכנית תעצור בשורה 4, והשורה תודגש בצהוב.

הכפתורים

כפתורמקשמה עושה
▶ ContinueF5ממשיך עד ה־breakpoint הבא (או הסוף)

(במקלדות Mac אולי צריך fn יחד עם F5/F10. הכפתורים בסרגל עובדים תמיד.)

👣 תרגיל מודרך

  1. עם ה־breakpoint בשורה 4, הקש Step Into — נכנסת ל־callback של `reduce`. ב־VARIABLES רואים `sum: 0` ו־`item: {price: 10, qty: 2}`.
  2. שוב Step Into — נכנסת ל־`lineTotal`. Step Out — חוזרים.
  3. המשך עד שתראה `item: null` — זה הסיבוב השני. מצאת את הבעיה בלי שורת `console.log` אחת.
  4. ב־Debug Console הקלד `order.items` ולחץ Enter — רואים את כל המערך.
💡 breakpoint עם תנאי

לחיצה ימנית על הנקודה האדומה ← Edit Breakpoint ← ביטוי, למשל `item === null`. עכשיו הדיבאגר יעצור רק בסיבוב הבעייתי — גם אם יש 10,000 סיבובים. וכלי נוסף: השורה `debugger;` בתוך הקוד עובדת כמו breakpoint כשמריצים מה־JavaScript Debug Terminal.
