🎯 בשיעור הזה

שלושה כלים "לראות" HTTP, מול שרת ההדגמה של הפרק. הפעל אותו בחלון Terminal אחד (node 14-http/files/demo-server.mjs), ופתח Terminal שני (בפאנל של VS Code: כפתור +) לפקודות.

1. curl

```term % curl http://localhost:4000/products [{"id":1,"name":"מקלדת","price":249},{"id":2,"name":"עכבר","price":89}] % curl -i http://localhost:4000/products/9 HTTP/1.1 404 Not Found Content-Type: application/json; charset=utf-8 Date: Sun, 01 Nov 2026 20:07:57 GMT Connection: keep-alive Keep-Alive: timeout=5 Transfer-Encoding: chunked {"error":"המוצר לא נמצא"} ``` ```term % curl -i -X POST http://localhost:4000/products -H "Content-Type: application/json" -d '{"name":"מסך","price":899}' HTTP/1.1 201 Created Content-Type: application/json; charset=utf-8 Location: /products/3 .. ... {"id":3,"name":"מסך","price":899} ```
דגלמה עושה
`-i`מציג גם את ה־status וה־headers של התשובה
`-X POST`ה־method (ברירת מחדל GET)
`-H "Name: value"`header
`-d '...'`גוף. שים לב למירכאות הבודדות סביב ה־JSON
`-v`"מפורט" — מציג גם את הבקשה שנשלחה (שורות `>`) ואת התשובה (`<`)
`-s`שקט — בלי פס התקדמות

נסה עכשיו: (1) `curl -i -X DELETE localhost:4000/products/3` — מה ה־status ולמה אין גוף? (2) אותה פקודת POST בלי ה־`-H` — מה חוזר? (3) `curl -v localhost:4000/` — מצא בפלט את השורה `> Host:`.

2. REST Client — בקשות בקובץ

צור קובץ `playground/demo.http`:

```text file=playground/demo.http @base = http://localhost:4000 ### כל המוצרים GET {{base}}/products ### מוצרים עד 100 ש״ח GET {{base}}/products?maxPrice=100 ### מוצר חדש POST {{base}}/products Content-Type: application/json { "name": "מסך", "price": 899 } ### אזור מוגן GET {{base}}/secret Authorization: Bearer let-me-in ```

מעל כל בקשה יופיע הקישור Send Request. לחיצה — והתשובה המלאה נפתחת בחלון צד. היתרון על curl: הבקשות שמורות בקובץ, אפשר להכניס אותו ל־Git, וחברי צוות משתמשים באותו קובץ. (`###` מפריד בין בקשות; `@base` — משתנה.) בפרויקטים שלך בהמשך — יהיה קובץ `.http` לכל API.

3. Chrome DevTools

  1. ב־Chrome, פתח `http://localhost:4000/products`.
  2. ⌘ + ⌥ + I (או לחיצה ימנית ← Inspect) ← לשונית Network.
  3. רענן (⌘+R). לחץ על הבקשה `products`: בלשונית Headers — method, status, headers; ב־Response — הגוף; ב־Timing — כמה זמן לקח כל שלב.
  4. נסה גם אתר אמיתי (כל אתר חדשות): כמה בקשות טוען דף אחד? כמה מהן מחזירות JSON?

זה הכלי הראשון שמפתח Backend פותח כשמישהו מה־Frontend אומר "השרת מחזיר שגיאה": רואים בדיוק מה נשלח ומה חזר.
