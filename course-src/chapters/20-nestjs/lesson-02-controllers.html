1. Routes ופרמטרים

```ts @Controller("products") export class ProductsController { constructor(private readonly products: ProductsService) {} @Get() // GET /products?page=2 list(@Query() query: ListProductsQuery) { return this.products.list(query); } @Get(":id") // GET /products/7 findOne(@Param("id", ParseIntPipe) id: number) { return this.products.findOne(id); } @Post() // POST /products — 201 אוטומטית create(@Body() dto: CreateProductDto) { return this.products.create(dto); } @Patch(":id") update(@Param("id", ParseIntPipe) id: number, @Body() dto: UpdateProductDto) { return this.products.update(id, dto); } @Delete(":id") @HttpCode(204) // בלי זה — 200 remove(@Param("id", ParseIntPipe) id: number) { this.products.remove(id); } } ```
Decoratorמקביל ב־Express
`@Param("id")``req.params.id`
`@Query()` · `@Query("page")``req.query` · `req.query.page`
`@Body()``req.body`
`@Headers("x-api-key")``req.get("x-api-key")`
`@HttpCode(204)` · `@Header("Cache-Control", "...")``res.status(204)` · `res.set(...)`

`ParseIntPipe` — pipe שממיר את `"7"` ל־7, ואם זה לא מספר — 400 עוד לפני שה־handler רץ. אפשר גם async: מתודה שמחזירה Promise — Nest מחכה, ושגיאה נתפסת.

2. DTO + ValidationPipe

```ts file=src/products/dto/create-product.dto.ts import { IsBoolean, IsInt, IsNumber, IsOptional, IsString, Length, Max, Min } from "class-validator"; export class CreateProductDto { @IsString() @Length(2, 80) name: string; @IsNumber({ maxDecimalPlaces: 2 }) @Min(0.01) @Max(100_000) price: number; @IsInt() @Min(0) stock: number; @IsOptional() @IsBoolean() isActive?: boolean; } ``` ```ts file=src/main.ts app.useGlobalPipes(new ValidationPipe({ whitelist: true, // שדות בלי decorators — נמחקים forbidNonWhitelisted: true, // ...או, עם זה, 400 transform: true, // הגוף הופך למופע של ה־DTO, ו־query/params מומרים לטיפוסים })); ``` ```term % curl -s -X POST localhost:3000/products -H "Content-Type: application/json" -d '{"name":"X","price":0,"extra":1}' {"message":["property extra should not exist","name must be longer than or equal to 2 characters","price must not be less than 0.01","stock must not be less than 0","stock must be an integer number"],"error":"Bad Request","statusCode":400} ```

(פלט אמיתי. שים לב: על stock שחסר לגמרי יש שתי הודעות — כל decorator בודק בנפרד.) הרעיון זהה ל־Zod בפרק 15: מתארים קלט תקין פעם אחת. ההבדל: ב־Nest הסכמה היא class עם decorators, וה־class משמש גם כטיפוס TypeScript (וגם ל־Swagger, בשיעור 4).

💡 query מגיע כמחרוזת — גם כאן

`?page=2` הוא `"2"`. עם `transform: true` ו־`@Type(() => Number)` (מ־`class-transformer`) על השדה ב־DTO של ה־query — הוא הופך למספר לפני הבדיקה. זה ה־`z.coerce` של Nest.

ול־PATCH: `export class UpdateProductDto extends PartialType(CreateProductDto) {}` (מ־`@nestjs/swagger`) — כל השדות הופכים לאופציונליים, עם אותם חוקים.

הרשימה המלאה — ב־התיעוד של class-validator. DTO מקונן — הזמנה עם פריטים:

```ts file=src/orders/dto/create-order.dto.ts import { Type } from "class-transformer"; import { ArrayMaxSize, ArrayMinSize, IsArray, IsEmail, IsIn, IsInt, IsOptional, IsString, IsUrl, Matches, Min, MinLength, ValidateNested } from "class-validator"; export class OrderItemDto { @IsInt() @Min(1) productId: number; @IsInt() @Min(1) quantity: number; } export class CreateOrderDto { @IsEmail() email: string; @IsIn(["pickup", "courier"]) shipping: string; @IsOptional() @Matches(/^[A-Z0-9]{4,12}$/, { message: "coupon: אותיות גדולות וספרות, 4–12" }) coupon?: string; @IsOptional() @IsUrl() website?: string; @IsArray() @ArrayMinSize(1) @ArrayMaxSize(20) @ValidateNested({ each: true }) @Type(() => OrderItemDto) items: OrderItemDto[]; @IsOptional() @IsString({ each: true }) @MinLength(2, { each: true }) tags?: string[]; } ``` ```term % curl -s -X POST localhost:3000/orders -H "Content-Type: application/json" -d '{"email":"dana@example","shipping":"drone","coupon":"save-10","items":[{"productId":1,"quantity":0}],"tags":["a"]}' {"message":["email must be an email","shipping must be one of the following values: pickup, courier","coupon: אותיות גדולות וספרות, 4–12","items.0.quantity must not be less than 1","each value in tags must be longer than or equal to 2 characters"],"error":"Bad Request","statusCode":400} ```

(פלט אמיתי, עם `ValidationPipe` מסעיף 2.) שים לב ל־`items.0.quantity` — הנתיב לשדה בתוך המערך. בלי `@ValidateNested` ו־`@Type` הפריטים לא נבדקים בכלל: אותה בקשה עם `"quantity": 0` עוברת, ו־`dto.items[0]` הוא `Object` רגיל ולא `OrderItemDto` (בדקנו). `@Type` אומר ל־class-transformer מאיזה class ליצור כל איבר, ו־`@ValidateNested` אומר ל־class-validator להיכנס פנימה.

3. Exceptions

זורקיםstatus
`BadRequestException`400
`UnauthorizedException` · `ForbiddenException`401 · 403
`NotFoundException`404
`ConflictException`409
`UnprocessableEntityException`422
`HttpException(body, status)`כל status
כל שגיאה אחרת (`throw new Error(...)`)500, "Internal server error" — בלי פרטים

התשובה כברירת מחדל: `{"message": "...", "error": "Not Found", "statusCode": 404}`. רוצה את המבנה מפרק 15 (`{"error": {"code", "message"}}`)? exception filter — בשיעור הבא.
