🎯 בשיעור הזה
  • `SELECT ... FROM` — אילו עמודות, מאיזו טבלה.
  • `WHERE`: השוואות, `AND`/`OR`, `IN`, `BETWEEN`, `LIKE`.
  • `ORDER BY`, `LIMIT`, `OFFSET`, `DISTINCT`, ביטויים וכינויים.

1. עמודות וביטויים

```sql run db=16-sql/files/shop.sql SELECT name, price, stock, price * stock AS stock_value FROM products WHERE category = 'brewing'; ``` ```out name | price | stock | stock_value ------------------+--------+-------+------------- French Press 1L | 119.00 | 25 | 2975.00 V60 Ceramic | 99.00 | 0 | 0.00 Moka Pot 6 Cups | 149.00 | 12 | 1788.00 Gooseneck Kettle | 229.00 | 7 | 1603.00 (4 rows) ```
  • `SELECT *` — כל העמודות. נוח לבדיקה מהירה, אבל בקוד אמיתי כותבים עמודות במפורש (פחות נתונים, ולא נשבר כשמוסיפים עמודה).
  • `price * stock AS stock_value` — עמודה מחושבת עם כינוי (alias). הנתונים בטבלה לא משתנים.
  • מחרוזות — בגרש בודד: `'brewing'`. מירכאות כפולות ב־SQL הן לשמות עמודות/טבלאות (`"Order"`), לא לטקסט — טעות נפוצה מאוד.

2. WHERE

אופרטורדוגמה
`=` · `<>` · `<` · `>=``stock = 0` · `category <> 'beans'` (שונה)
`AND` · `OR` · `NOT``is_active AND stock > 0`
`IN (...)``category IN ('beans', 'grinders')`
`BETWEEN a AND b``price BETWEEN 50 AND 150` — כולל את הקצוות
`LIKE` · `ILIKE``name LIKE '%Grinder%'` — `%` = כל רצף, `_` = תו אחד. `ILIKE` — בלי תלות באותיות גדולות/קטנות
```sql run db=16-sql/files/shop.sql SELECT id, name, price FROM products WHERE is_active AND stock > 0 AND price BETWEEN 50 AND 150; ``` ```out id | name | price ----+--------------------+-------- 1 | Ethiopia Beans 1kg | 89.90 7 | French Press 1L | 119.00 9 | Moka Pot 6 Cups | 149.00 (3 rows) ```
⚠️ AND לפני OR

`WHERE category = 'beans' OR category = 'grinders' AND price < 200` — `AND` נקשר חזק יותר, אז זה "כל ה־beans, ועוד grinders מתחת ל־200". כנראה רצית סוגריים: `(category = 'beans' OR category = 'grinders') AND price < 200`. כלל: כשמערבבים AND ו־OR — תמיד סוגריים.

```sql run db=16-sql/files/shop.sql SELECT full_name, email FROM customers WHERE email ILIKE '%@example.com' AND full_name LIKE 'D%'; ``` ```out full_name | email -----------+------------------ Dana Levi | dana@example.com (1 row) ```

3. מיון והגבלה

```sql run db=16-sql/files/shop.sql SELECT name, category, price FROM products WHERE is_active ORDER BY category, price DESC LIMIT 5; ``` ```out name | category | price ------------------------+-------------+------- Ceramic Mug | accessories | 39.00 Paper Filters (100) | accessories | 24.90 Grinder Cleaning Brush | accessories | 19.90 Ethiopia Beans 1kg | beans | 89.90 Colombia Beans 1kg | beans | 84.90 (5 rows) ```
  • `ORDER BY category, price DESC` — קודם לפי קטגוריה (עולה, ברירת מחדל), ובתוך כל קטגוריה לפי מחיר יורד.
  • בלי ORDER BY אין סדר מובטח. גם אם היום השורות חוזרות לפי id — מחר, אחרי עדכונים, אולי לא.
  • `LIMIT 5 OFFSET 10` — דלג על 10, תן 5. זו בדיוק ה־pagination מפרק 15: `OFFSET (page - 1) * limit`.

4. DISTINCT

```sql run db=16-sql/files/shop.sql SELECT DISTINCT category FROM products ORDER BY category; ``` ```out category ------------- accessories beans brewing grinders (4 rows) ```

`DISTINCT` מסיר שורות כפולות בתוצאה. ("כמה מוצרים בכל קטגוריה?" — זו כבר שאלה של `GROUP BY`, בפרק 17.)

5. סדר הכתיבה מול סדר הביצוע

כותבים `SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT`, אבל המסד מבצע: `FROM` (איזו טבלה) ← `WHERE` (אילו שורות) ← `SELECT` (אילו עמודות) ← `ORDER BY` ← `LIMIT`. לכן אפשר להשתמש בכינוי מ־SELECT ב־ORDER BY, אבל לא ב־WHERE:

```sql run db=16-sql/files/shop.sql stderr SELECT name, price * stock AS stock_value FROM products WHERE stock_value > 5000; ``` ```out ERROR: column "stock_value" does not exist LINE 3: WHERE stock_value > 5000; ^ ```
