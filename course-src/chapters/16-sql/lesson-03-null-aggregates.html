🎯 בשיעור הזה
  • NULL: "לא ידוע" — ואיך הוא שובר השוואות.
  • `IS NULL`, `COALESCE`.
  • צבירות: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.
  • `CASE` (גם בתוך ORDER BY), ספירה עם תנאי — `COUNT(*) FILTER (WHERE ...)`, ועוד כמה כלים קטנים.

1. NULL הוא לא ערך

ל־Yossi אין טלפון בטבלה. זה לא `''` (מחרוזת ריקה) ולא `0` — זה `NULL`: "אין מידע". ו־SQL מתייחס ל"לא ידוע" ברצינות:

```sql run db=16-sql/files/shop.sql SELECT full_name, phone FROM customers WHERE phone = NULL; ``` ```out full_name | phone -----------+------- (0 rows) ```

אפס שורות! כי `phone = NULL` הוא לא `true` וגם לא `false` — הוא `NULL` ("אולי? לא יודע"). ו־WHERE מחזיר רק שורות שהתנאי שלהן `true`. הדרך הנכונה:

```sql run db=16-sql/files/shop.sql SELECT full_name, phone FROM customers WHERE phone IS NULL ORDER BY full_name; ``` ```out full_name | phone --------------+------- lior katz | Michal Biton | Omer Shalom | Yossi Cohen | (4 rows) ```
ביטויתוצאה
`NULL = NULL``NULL` (שני לא־ידועים — לא בהכרח שווים)
`NULL + 5``NULL`
`NULL AND false``false` (מספיק שאחד false)
`NULL OR true``true`
`x IS NULL` / `x IS NOT NULL`תמיד `true` או `false`
`x IS DISTINCT FROM y`"שונה", כש־NULL נחשב ערך רגיל
⚠️ המלכודת של `<>`

"כל הלקוחות שלא גרים בחיפה": `WHERE city <> 'Haifa'` — מפספס את מי שהעיר שלו NULL (כי `NULL <> 'Haifa'` הוא NULL). אם הם אמורים להיכלל: `WHERE city IS DISTINCT FROM 'Haifa'`, או `WHERE city <> 'Haifa' OR city IS NULL`.

```sql run db=16-sql/files/shop.sql SELECT full_name, COALESCE(city, 'unknown') AS city FROM customers WHERE city IS NULL OR city = 'Ramat Gan' ORDER BY full_name; ``` ```out full_name | city -------------+----------- Avi Peretz | unknown lior katz | Ramat Gan Omer Shalom | unknown (3 rows) ```

`COALESCE(a, b, c)` — הערך הראשון שאינו NULL. שימושי להצגה, ולברירות מחדל בחישובים.

2. צבירות

```sql run db=16-sql/files/shop.sql SELECT COUNT(*) AS products, SUM(stock) AS units, MIN(price) AS cheapest, MAX(price) AS priciest, ROUND(AVG(price), 2) AS avg_price FROM products WHERE is_active; ``` ```out products | units | cheapest | priciest | avg_price ----------+-------+----------+----------+----------- 12 | 660 | 19.90 | 649.00 | 143.54 (1 row) ```

פונקציית צבירה הופכת הרבה שורות לשורה אחת. ה־WHERE רץ קודם — הצבירה רק על המוצרים הפעילים.

COUNT ו־NULL

```sql run db=16-sql/files/shop.sql SELECT COUNT(*) AS customers, COUNT(phone) AS with_phone, COUNT(DISTINCT city) AS cities FROM customers; ``` ```out customers | with_phone | cities -----------+------------+-------- 12 | 8 | 5 (1 row) ```
  • `COUNT(*)` — כל השורות.
  • `COUNT(phone)` — שורות שבהן phone אינו NULL. כל הצבירות (חוץ מ־`COUNT(*)`) מתעלמות מ־NULL.
  • `COUNT(DISTINCT city)` — ערכים שונים (NULL לא נספר).
💡 numeric לכסף

שים לב ש־`price` הוא `numeric(10, 2)` — מספר עשרוני מדויק. ב־JavaScript, `0.1 + 0.2` הוא `0.30000000000000004` (פרק 2); ב־numeric זה תמיד `0.3`. לכן כסף במסד — numeric, לעולם לא `real`/`float`.

3. CASE, ‏FILTER ועוד כמה כלים

`CASE` הוא ה־`if / else if` (או ה־`switch` מפרק 3) של SQL — ביטוי שמחזיר ערך. יש לו שתי צורות: עם תנאים (`CASE WHEN ... THEN ...`), וקצרה — השוואה של ערך אחד לכמה אפשרויות (`CASE category WHEN 'beans' THEN ...`). הראשון שמתאים מנצח, ובלי `ELSE` מה שלא התאים מקבל NULL:

```sql run db=16-sql/files/shop.sql SELECT name, price, CASE WHEN price < 50 THEN 'cheap' WHEN price < 150 THEN 'regular' ELSE 'premium' END AS tier, CASE category WHEN 'beans' THEN 'coffee' WHEN 'brewing' THEN 'coffee' ELSE 'gear' END AS kind FROM products WHERE is_active AND stock > 0 ORDER BY price LIMIT 5; ``` ```out name | price | tier | kind ------------------------+-------+---------+-------- Grinder Cleaning Brush | 19.90 | cheap | gear Paper Filters (100) | 24.90 | cheap | gear Brazil Beans 250g | 29.90 | cheap | coffee Ceramic Mug | 39.00 | cheap | gear Ethiopia Beans 1kg | 89.90 | regular | coffee (5 rows) ```

CASE בתוך ORDER BY — מיון בסדר שאתה קובע (לא אלפביתי): כל ערך מקבל מספר, וממיינים לפי המספר.

```sql run db=16-sql/files/shop.sql SELECT name, category FROM products WHERE is_active AND stock = 0 ORDER BY CASE category WHEN 'brewing' THEN 1 WHEN 'beans' THEN 2 ELSE 3 END, name; ``` ```out name | category --------------------+---------- V60 Ceramic | brewing Colombia Beans 1kg | beans (2 rows) ```
⚠️ כינוי מ־SELECT — רק לבד ב־ORDER BY

`ORDER BY region` עובד (כינוי מ־SELECT, סעיף 5 בשיעור 2). אבל כינוי בתוך ביטוי ב־ORDER BY — לא:

```sql run db=16-sql/files/shop.sql stderr SELECT full_name, CASE WHEN city IN ('Tel Aviv', 'Ramat Gan') THEN 'center' ELSE 'other' END AS region FROM customers ORDER BY CASE region WHEN 'center' THEN 1 ELSE 2 END; ``` ```out ERROR: column "region" does not exist LINE 3: ORDER BY CASE region WHEN 'center' THEN 1 ELSE 2 END; ^ ```

הפתרון: לכתוב ב־CASE של ה־ORDER BY את העמודה המקורית (`CASE WHEN city IN (...) THEN 1 ELSE 2 END`), או לבחור ב־SELECT מספר ולמיין לפיו.

ספירה עם תנאי — `FILTER`. WHERE מסנן את כל השאילתה. ומה אם רוצים בשורה אחת גם "כמה מוצרים יש" וגם "כמה מהם אזלו"? `FILTER (WHERE ...)` אחרי פונקציית צבירה מסנן רק לה:

```sql run db=16-sql/files/shop.sql SELECT COUNT(*) AS products, COUNT(*) FILTER (WHERE stock = 0) AS out_of_stock, COUNT(*) FILTER (WHERE NOT is_active) AS inactive, SUM(stock) FILTER (WHERE is_active) AS active_units FROM products; ``` ```out products | out_of_stock | inactive | active_units ----------+--------------+----------+-------------- 14 | 3 | 2 | 660 (1 row) ```

ועוד כמה כלים קטנים שתפגוש בתרגול:

כלימה עושה
`ORDER BY city NULLS FIRST`איפה NULL במיון. ברירת המחדל ב־PostgreSQL: NULL "גדול מכולם" — בסוף בסדר עולה, ובהתחלה ב־`DESC`. `NULLS FIRST` / `NULLS LAST` קובעים במפורש
`GREATEST(a, b, ...)` · `LEAST(...)`הגדול / הקטן מבין כמה ערכים באותה שורה (כמו `Math.max`). `GREATEST(20 - stock, 0)` — "כמה חסר עד 20, ולא פחות מ־0". (MAX הוא צבירה על הרבה שורות — משהו אחר)
`ORDER BY 3 DESC, 1`מיון לפי מספר העמודה ב־SELECT (3 = השלישית). קצר, אבל נשבר בשקט כשמוסיפים עמודה — בקוד אמיתי עדיף שם
```sql run db=16-sql/files/shop.sql SELECT name, stock, GREATEST(20 - stock, 0) AS to_order FROM products WHERE category = 'brewing' ORDER BY 3 DESC, 1; ``` ```out name | stock | to_order ------------------+-------+---------- V60 Ceramic | 0 | 20 Gooseneck Kettle | 7 | 13 Moka Pot 6 Cups | 12 | 8 French Press 1L | 25 | 0 (4 rows) ```
