🎯 בשיעור הזה
  • NULL: "לא ידוע" — ואיך הוא שובר השוואות.
  • `IS NULL`, `COALESCE`.
  • צבירות: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.

1. NULL הוא לא ערך

ל־Yossi אין טלפון בטבלה. זה לא `''` (מחרוזת ריקה) ולא `0` — זה `NULL`: "אין מידע". ו־SQL מתייחס ל"לא ידוע" ברצינות:

```sql run db=16-sql/files/shop.sql SELECT full_name, phone FROM customers WHERE phone = NULL; ``` ```out full_name | phone -----------+------- (0 rows) ```

אפס שורות! כי `phone = NULL` הוא לא `true` וגם לא `false` — הוא `NULL` ("אולי? לא יודע"). ו־WHERE מחזיר רק שורות שהתנאי שלהן `true`. הדרך הנכונה:

```sql run db=16-sql/files/shop.sql SELECT full_name, phone FROM customers WHERE phone IS NULL ORDER BY full_name; ``` ```out full_name | phone --------------+------- lior katz | Michal Biton | Omer Shalom | Yossi Cohen | (4 rows) ```
ביטויתוצאה
`NULL = NULL``NULL` (שני לא־ידועים — לא בהכרח שווים)
`NULL + 5``NULL`
`NULL AND false``false` (מספיק שאחד false)
`NULL OR true``true`
`x IS NULL` / `x IS NOT NULL`תמיד `true` או `false`
`x IS DISTINCT FROM y`"שונה", כש־NULL נחשב ערך רגיל
⚠️ המלכודת של `<>`

"כל הלקוחות שלא גרים בחיפה": `WHERE city <> 'Haifa'` — מפספס את מי שהעיר שלו NULL (כי `NULL <> 'Haifa'` הוא NULL). אם הם אמורים להיכלל: `WHERE city IS DISTINCT FROM 'Haifa'`, או `WHERE city <> 'Haifa' OR city IS NULL`.

```sql run db=16-sql/files/shop.sql SELECT full_name, COALESCE(city, 'unknown') AS city FROM customers WHERE city IS NULL OR city = 'Ramat Gan' ORDER BY full_name; ``` ```out full_name | city -------------+----------- Avi Peretz | unknown lior katz | Ramat Gan Omer Shalom | unknown (3 rows) ```

`COALESCE(a, b, c)` — הערך הראשון שאינו NULL. שימושי להצגה, ולברירות מחדל בחישובים.

2. צבירות

```sql run db=16-sql/files/shop.sql SELECT COUNT(*) AS products, SUM(stock) AS units, MIN(price) AS cheapest, MAX(price) AS priciest, ROUND(AVG(price), 2) AS avg_price FROM products WHERE is_active; ``` ```out products | units | cheapest | priciest | avg_price ----------+-------+----------+----------+----------- 12 | 660 | 19.90 | 649.00 | 143.54 (1 row) ```

פונקציית צבירה הופכת הרבה שורות לשורה אחת. ה־WHERE רץ קודם — הצבירה רק על המוצרים הפעילים.

COUNT ו־NULL

```sql run db=16-sql/files/shop.sql SELECT COUNT(*) AS customers, COUNT(phone) AS with_phone, COUNT(DISTINCT city) AS cities FROM customers; ``` ```out customers | with_phone | cities -----------+------------+-------- 12 | 8 | 5 (1 row) ```
  • `COUNT(*)` — כל השורות.
  • `COUNT(phone)` — שורות שבהן phone אינו NULL. כל הצבירות (חוץ מ־`COUNT(*)`) מתעלמות מ־NULL.
  • `COUNT(DISTINCT city)` — ערכים שונים (NULL לא נספר).
💡 numeric לכסף

שים לב ש־`price` הוא `numeric(10, 2)` — מספר עשרוני מדויק. ב־JavaScript, `0.1 + 0.2` הוא `0.30000000000000004` (פרק 2); ב־numeric זה תמיד `0.3`. לכן כסף במסד — numeric, לעולם לא `real`/`float`.
