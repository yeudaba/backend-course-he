1. קריאה

```ts const beans = await prisma.product.findMany({ where: { isActive: true, category: { name: "beans" }, // סינון לפי קשר — Prisma עושה את ה־JOIN name: { contains: "bean", mode: "insensitive" }, // ILIKE '%bean%' price: { gte: 20, lte: 100 }, }, select: { id: true, name: true, price: true }, orderBy: [{ price: "desc" }, { id: "asc" }], skip: 0, take: 10, }); const dana = await prisma.customer.findUnique({ where: { email: "dana@example.com" } }); // או null const total = await prisma.product.count({ where: { isActive: true } }); ```
PrismaSQL
`{ price: 10 }``price = 10`
`{ price: { gt, gte, lt, lte } }``>`, `>=`, `<`, `<=`
`{ status: { in: ["paid", "pending"] } }``IN (...)`
`{ city: null }` · `{ city: { not: null } }``IS NULL` · `IS NOT NULL`
`{ OR: [{...}, {...}] }` · `{ NOT: {...} }``OR` · `NOT`
`{ orders: { some: {...} } }` · `none` · `every``EXISTS (...)` / `NOT EXISTS`

`findUnique` — רק לפי שדה ייחודי (`id`, `email`), ומחזיר `null` אם אין. `findFirst` — לפי כל תנאי, את הראשון.

2. include: קשרים בלי N+1

```ts const orders = await prisma.order.findMany({ where: { customerId: 1 }, orderBy: { createdAt: "desc" }, include: { items: { include: { product: { select: { name: true } } } }, }, }); // orders[0].items[0].product.name ← מוקלד ```

Prisma מריץ שאילתה לכל "רמה" (הזמנות; כל הפריטים שלהן בבת אחת; כל המוצרים בבת אחת) ומחבר בזיכרון — בדיוק "אפשרות 2" משיעור N+1 בפרק 18. אבל לולאה עם `findUnique` לכל פריט — זה עדיין N+1, גם ב־Prisma.

ולראות מה Prisma שולח: `new PrismaClient({ adapter, log: ["query"] })` — כל שאילתה מודפסת. שווה להפעיל מדי פעם בפיתוח.

3. כתיבה

```ts const customer = await prisma.customer.create({ data: { fullName: "Lior Katz", email: "lior@example.com", joinedOn: new Date("2026-11-01") }, }); const order = await prisma.order.create({ // nested create — הזמנה ופריטים, ב־transaction אחד data: { customerId: customer.id, items: { create: [{ productId: 1, quantity: 2, unitPrice: 89.9 }] }, }, include: { items: true }, }); await prisma.product.update({ where: { id: 1 }, data: { stock: { decrement: 2 } } }); // stock = stock - 2 await prisma.customer.delete({ where: { id: customer.id } }); ```

5. עדכון אטומי ו־transactions

```ts // הורדת מלאי בלי מרוץ — updateMany עם תנאי (כמו P18-E10) const { count } = await prisma.product.updateMany({ where: { id: productId, stock: { gte: qty } }, data: { stock: { decrement: qty } }, }); if (count === 0) throw new AppError("OUT_OF_STOCK"); // interactive transaction — כמה פעולות, הכול או כלום const order = await prisma.$transaction(async (tx) => { const p = await tx.product.updateMany({ where: { id: 1, stock: { gte: 1 } }, data: { stock: { decrement: 1 } } }); if (p.count === 0) throw new AppError("OUT_OF_STOCK"); // זריקה ← ROLLBACK return tx.order.create({ data: { customerId: 1, items: { create: [{ productId: 1, quantity: 1, unitPrice: 89.9 }] } } }); }); ```
⚠️ tx, לא prisma

בתוך ה־callback — כל הפעולות דרך `tx`. שאילתה דרך `prisma` רצה מחוץ ל־transaction (חיבור אחר!), ולא תתבטל בכישלון — אותו באג כמו `pool.query("BEGIN")` בפרק 18.

6. SQL ישיר

```ts const rows = await prisma.$queryRaw<{ category: string; revenue: number }[]>` SELECT c.name AS category, SUM(oi.quantity * oi.unit_price)::float AS revenue FROM order_items oi JOIN products p ON p.id = oi.product_id JOIN categories c ON c.id = p.category_id WHERE p.price > ${minPrice} GROUP BY c.name`; ```

דוחות עם GROUP BY על כמה טבלאות, חלונות, CTE — ב־SQL זה פשוט יותר. `$queryRaw` עם template literal (הגרש ההפוך) הופך כל `${...}` לפרמטר — בטוח מ־injection. `$queryRawUnsafe("..." + x)` — לא בטוח, ולא צריך כמעט אף פעם.
