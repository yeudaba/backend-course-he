1. JavaScript + טיפוסים

TypeScript הוא JavaScript שמותר להוסיף לו הערות טיפוסים: "המשתנה הזה הוא מספר", "הפונקציה הזו מקבלת מחרוזת ומחזירה בוליאני". כל קוד JavaScript תקין הוא כמעט תמיד גם TypeScript תקין — מוסיפים טיפוסים בהדרגה.

```ts run function total(prices: number[]): number { return prices.reduce((sum, p) => sum + p, 0); } const vat: number = 0.18; console.log(total([10, 20]) * (1 + vat)); ``` ```out 35.4 ```

כלומר: קוד עם שגיאות טיפוסים ירוץ ב־Node. הטיפוסים הם רשת ביטחון בזמן כתיבה — לא מנגנון שפועל בזמן ריצה. נחזור לנקודה הזו בשיעור 4 ובפרק 12.

2. מה TypeScript תופס

```ts tsc let price = 10; price = "free"; function total(items: { price: number }[]): number { return items.reduce((s, i) => s + i.price, 0); } total([{ price: "5" }]); const user = { name: "dana" }; console.log(user.email); ``` ```out snippet.ts(2,1): error TS2322: Type 'string' is not assignable to type 'number'. snippet.ts(6,10): error TS2322: Type 'string' is not assignable to type 'number'. snippet.ts(8,18): error TS2339: Property 'email' does not exist on type '{ name: string; }'. ```

שלושה באגים מהפרקים הקודמים — נתפסים לפני הרצה, עם קובץ, שורה ועמודה. בכל שורה: (שורה,עמודה), קוד השגיאה (`TS2322`) והסבר. ב־VS Code אותן שגיאות מופיעות בקו אדום מתחת לקוד, ובלשונית PROBLEMS.

3. הסקה — לא צריך לכתוב טיפוס בכל מקום

שים לב לשורה 1: `let price = 10` — לא כתבנו `: number`, ובכל זאת TypeScript ידע. זו הסקה (inference). כלל אצבע:

איפהלכתוב טיפוס?
משתנה עם ערך התחלתי: `const vat = 0.18`לא — מוסק
פרמטרים של פונקציהתמיד — אין ממה להסיק
ערך החזרה של פונקציהמומלץ בפונקציות שמיוצאות — "חוזה" ברור
משתנה בלי ערך התחלתי: `let result;`כן: `let result: number;`

4. הטיפוסים הבסיסיים

טיפוסדוגמה
`string`, `number`, `boolean``const name: string = "דנה";`
`null`, `undefined``let coupon: string | null = null;` (את ה־`|` נלמד בשיעור 3)
`number[]` (או `Array`)`const prices: number[] = [10, 20];`
`void`פונקציה שלא מחזירה כלום: `function log(m: string): void`
`Date`, `Map`, `Set`מחלקות מובנות; בתוך `< >` — מה בפנים
⚠️ אותיות קטנות

`string` ולא `String`; `number` ולא `Number`. הגרסאות עם אות גדולה הן משהו אחר (עטיפות ישנות) — ESLint ו־TypeScript יעירו עליהן.

5. 👣 ההרגל: כתוב ← בדוק ← הרץ
