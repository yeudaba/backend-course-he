1. קופסה חדשה בתרשים

מבחינת השרת שלך, מודל שפה הוא שירות HTTP חיצוני — כמו ספק תשלומים — עם ארבע תכונות שכדאי לזכור מהרגע הראשון:

תכונההמשמעות בקוד
לא דטרמיניסטיאותה שאלה, תשובות שונות. אי אפשר לבדוק "שווה ל־"; מאמתים מבנה (שיעור 2) ומודדים איכות (שיעור 5)
איטישניות, לא מילישניות. streaming ללקוח, תור לעבודות ארוכות (שיעור 4)
עולה לפי שימושכל בקשה — כסף, לפי טוקנים. מגבלות, cache, תקציב (שיעור 4)
הפלט לא אמיןיכול לטעות בביטחון מלא, ויכול להיות מושפע מטקסט זדוני בקלט. ולידציה והרשאות בקוד (שיעורים 2–3)

מה הוא עושה מצוין: להבין טקסט חופשי (לסווג, לחלץ, לסכם, לתרגם), לכתוב טקסט, ולתרגם בקשה בשפה טבעית לפעולה מובנית. מה הוא לא צריך לעשות: חשבון, החלטות על כסף והרשאות, ודברים שיש להם תשובה מדויקת שאפשר לחשב (E01).

2. הקריאה הראשונה

```ts import Anthropic from "@anthropic-ai/sdk"; const client = new Anthropic(); // קורא את ANTHROPIC_API_KEY מהסביבה const response = await client.messages.create({ model: "claude-opus-5-5", max_tokens: 4096, system: "You are the support assistant of an online coffee-equipment shop. Answer briefly, in Hebrew.", messages: [{ role: "user", content: "מה ההבדל בין V60 לפרנץ' פרס?" }], }); ```
  • model — איזה מודל. max_tokens — תקרה לאורך התשובה (לא "כמה לכתוב"): נמוך מדי ← תשובה חתוכה.
  • system — ההוראות הקבועות של האפליקציה. messages — השיחה: user ו־assistant לסירוגין, מתחיל ב־user. ה־API לא זוכר כלום בין בקשות — כל בקשה שולחת את כל השיחה (E07).
  • אין temperature: בגרסת ה־API הנוכחית הוא מחזיר שגיאה, וב־Opus 5.5 החשיבה תמיד פועלת — שולטים בעומק שלה עם output_config: { effort: "low" | "medium" | "high" | … } (ברירת המחדל במודל הזה: medium).

ומה עובר ברשת? הרצתי את ה־SDK עם fetch מדומה — הוא מדפיס את הבקשה ולא שולח אותה לשום מקום (זו הטכניקה של כל הבודקים בפרק, ושל שיעור 5):

```ts run import Anthropic from "@anthropic-ai/sdk"; const client = new Anthropic({ apiKey: "sk-demo", fetch: async (url, init) => { const h = new Headers(init?.headers); console.log(init?.method, String(url)); console.log("authorization:", h.get("authorization")?.replace("sk-demo", ""), "· anthropic-version:", h.get("anthropic-version")); console.log("body:", String(init?.body)); return Response.json({ id: "msg_demo", type: "message", role: "assistant", model: "claude-opus-5-5", content: [{ type: "thinking", thinking: "", signature: "x" }, { type: "text", text: "ב־V60 המים עוברים דרך פילטר נייר…" }], stop_reason: "end_turn", stop_sequence: null, usage: { input_tokens: 41, output_tokens: 87, cache_creation_input_tokens: 0, cache_read_input_tokens: 0 }, }); }, }); const r = await client.messages.create({ model: "claude-opus-5-5", max_tokens: 4096, messages: [{ role: "user", content: "V60 או פרנץ' פרס?" }] }); console.log("blocks:", r.content.map((b) => b.type).join(", "), "· stop_reason:", r.stop_reason, "· usage:", r.usage.input_tokens, "/", r.usage.output_tokens); ``` ```out POST https://api.anthropic.com/v1/messages authorization: Bearer · anthropic-version: 2026-10-21 body: {"model":"claude-opus-5-5","max_tokens":4096,"messages":[{"role":"user","content":"V60 או פרנץ' פרס?"}]} blocks: thinking, text · stop_reason: end_turn · usage: 41 / 87 ```

(התשובה כאן מדומה — אני כתבתי אותה. מה שאמיתי: הבקשה שה־SDK בנה, וה־headers שלו.) שלושה דברים מתוך זה: המפתח עובר בכל בקשה (ולכן היא חייבת לצאת מהשרת שלך, לא מהדפדפן); ה־SDK שולח גרסת API קבועה; וה־body הוא בדיוק מה שכתבת.

3. מה חוזר

content הוא מערך של בלוקים, לא מחרוזת. ב־Opus 5.5 יכול להופיע קודם בלוק thinking (ריק כברירת מחדל — החשיבה קורית ומחויבת, אבל לא מוצגת), אחר כך text, ובשיעור 3 גם tool_use. ולפני שקוראים את התוכן — stop_reason:

stop_reasonמה עושים
end_turnתשובה שלמה
max_tokensנחתכה באמצע — לא מציגים כאילו שלמה; מעלים max_tokens או מקצרים את הבקשה
tool_useהמודל מבקש להריץ כלי (שיעור 3)
refusalהמודל סירב (מסנני בטיחות). מטפלים כמו בשגיאה צפויה — הודעה למשתמש, לא קריסה

ו־usage — כמה טוקנים נקראו ונכתבו: הבסיס לחישוב העלות (E08), ולוג חובה לכל קריאה.

4. טוקנים, מחירים, ובחירת מודל

טוקן הוא חתיכת טקסט — בערך חלק ממילה. מחיר ומגבלות נמדדים בטוקנים, בנפרד לקלט ולפלט. המחירים בטבלה — מהתיעוד של Anthropic כפי שנשמר באוקטובר 2026; לפני שמסתמכים — לבדוק בדף התמחור, הם משתנים:

מודלמזההקלט / מיליוןפלט / מיליון

Claude Sonnet 5.5claude-sonnet-5-5$2$10

קריאה מ־cache (שיעור 4) זולה בהרבה — ב־Opus 5.5 ו־Sonnet 5.5, $0.20 למיליון; כתיבה ל־cache — כ־1.25 ממחיר הקלט. ואיך בוחרים מודל? בפרק הזה כל הדוגמאות משתמשות ב־claude-opus-5-5 — המודל המומלץ כברירת מחדל. מעבר למודל זול יותר בנתיב מסוים (סיווג בכמויות גדולות, למשל) הוא החלטה עסקית שמקבלים אחרי מדידה: eval (שיעור 5) שמראה שהאיכות נשמרת בנתיב הזה. וגם בתוך אותו מודל, effort נמוך יותר זול ומהיר יותר — לפעמים זה מספיק.
