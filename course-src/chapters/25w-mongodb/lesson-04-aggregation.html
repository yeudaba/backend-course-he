🎯 בשיעור הזה
  • aggregation pipeline: שלבים שכל אחד מעבד את הפלט של הקודם.
  • $match, $unwind, $group, $sort, $project, $lookup — ו־$facet.
  • תאריכים ואזורי זמן ב־aggregation.
  • אינדקסים: יחיד, מורכב (ESR), ייחודי ו־TTL.
  • explain: IXSCAN מול COLLSCAN, וכמה מסמכים נבדקו.

1. pipeline

ב־SQL כותבים שאילתה אחת, והמסד מחליט על הסדר. ב־Mongo, aggregate מקבל מערך של שלבים, וכל שלב מקבל את המסמכים שיצאו מהקודם — כמו שרשרת של filter, flatMap ו־reduce על מערך:

```ts run import { MongoClient } from "mongodb"; const client = new MongoClient(process.env.MONGO_URL ?? "mongodb://localhost:27017/?directConnection=true"); const db = client.db("lesson4"); const orders = db.collection("orders"); await orders.insertMany([ { _id: "o1", status: "delivered", items: [{ productId: "p1", price: 62, qty: 2 }, { productId: "p5", price: 89, qty: 1 }] }, { _id: "o2", status: "delivered", items: [{ productId: "p3", price: 48, qty: 3 }] }, { _id: "o4", status: "delivered", items: [{ productId: "p1", price: 62, qty: 1 }] }, { _id: "o5", status: "cancelled", items: [{ productId: "p1", price: 62, qty: 9 }] }, ]); const rows = await orders.aggregate([ { $match: { status: { $ne: "cancelled" } } }, { $unwind: "$items" }, { $group: { _id: "$items.productId", units: { $sum: "$items.qty" }, revenue: { $sum: { $multiply: ["$items.price", "$items.qty"] } } } }, { $sort: { revenue: -1 } }, ]).toArray(); console.log(rows); await db.dropDatabase(); await client.close(); ``` ```out [ { _id: 'p1', units: 3, revenue: 186 }, { _id: 'p3', units: 3, revenue: 144 }, { _id: 'p5', units: 1, revenue: 89 } ] ```
  • $unwind: "$items" — מסמך לכל פריט במערך (o1 הופך לשניים). בלעדיו, "$items.qty" הוא מערך של כמויות, ו־$sum של מערך בתוך $group נותן 0 (E22).
  • $group — _id הוא מפתח הקיבוץ (כמו GROUP BY), והשאר מצטברים: $sum, $avg, $min, $max, $first, $push. { $sum: 1 } סופר מסמכים.
  • שם שדה עם $ בהתחלה ("$items.qty") = "הערך של השדה". בלי $ — המחרוזת עצמה.
  • $project בסוף — לעצב את התוצאה (לשנות את _id ל־productId).

2. $lookup ו־$facet

$lookup מצרף מ־collection אחר: { from: "customers", localField: "_id", foreignField: "_id", as: "customer" } — התוצאה היא מערך (אולי ריק), ולכן אחריו בדרך כלל $unwind. טיפ ביצועים: $limit לפני ה־$lookup, כדי לצרף רק את מה שיוצג (E15).

$facet מריץ כמה pipelines על אותו קלט ומחזיר את כולם במסמך אחד — דשבורד שלם בבקשה אחת: הכנסות לפי יום, ספירה לפי סטטוס, מוצרים מובילים (E24).

3. תאריכים ואזורי זמן

Date ב־Mongo הוא רגע ב־UTC (כמו בפרק 24). "הכנסות לפי יום" — יום לפי איזה שעון? הזמנה ב־22:10 UTC ב־1 בנובמבר היא כבר 2 בנובמבר בישראל. ל־$dateToString ול־$dateTrunc יש פרמטר timezone:

```ts run import { MongoClient } from "mongodb"; const client = new MongoClient(process.env.MONGO_URL ?? "mongodb://localhost:27017/?directConnection=true"); const db = client.db("lesson4b"); await db.collection("orders").insertMany([ { createdAt: new Date("2026-11-01T21:30:00Z"), total: 100 }, { createdAt: new Date("2026-11-01T22:10:00Z"), total: 50 }, ]); const byDay = (timezone: string) => db.collection("orders").aggregate([ { $group: { _id: { $dateToString: { date: "$createdAt", format: "%Y-%m-%d", timezone } }, total: { $sum: "$total" } } }, { $sort: { _id: 1 } }, ]).toArray(); console.log("UTC: ", await byDay("UTC")); console.log("Israel:", await byDay("Asia/Jerusalem")); await db.dropDatabase(); await client.close(); ``` ```out UTC: [ { _id: '2026-11-01', total: 150 } ] Israel: [ { _id: '2026-11-01', total: 100 }, { _id: '2026-11-02', total: 50 } ] ```

4. אינדקסים

בלי אינדקס, כל שאילתה היא COLLSCAN — מעבר על כל המסמכים (כמו Seq Scan, פרק 18). אינדקסים ב־Mongo הם B-tree, בדיוק כמו ב־Postgres, וגם הכללים דומים:

  • מורכב, לפי ESR: שדות של Equality (customerId: "c1") קודם, אחריהם Sort (createdAt: -1), ובסוף Range (price: { $lt: 100 }). כך האינדקס גם מסנן וגם נותן את הסדר, בלי מיון בזיכרון.
  • unique — ה־UNIQUE של Mongo ({ email: 1 }, { unique: true }). הפרה ← שגיאה 11000 (E07).
  • TTL — { expiresAt: 1 }, { expireAfterSeconds: 0 }: תהליך רקע מוחק מסמכים שהזמן שלהם עבר (בערך פעם בדקה). ל־sessions, קודי אימות, נתונים זמניים.
  • אינדקס על שדה במערך (tags) הוא multikey — רשומה לכל ערך במערך.
```ts run import { MongoClient } from "mongodb"; const client = new MongoClient(process.env.MONGO_URL ?? "mongodb://localhost:27017/?directConnection=true"); const db = client.db("lesson4c"); const orders = db.collection("orders"); // 5,000 הזמנות של 100 לקוחות await orders.insertMany(Array.from({ length: 5000 }, (_, i) => ({ customerId: `c${i % 100}`, createdAt: new Date(Date.UTC(2026, 0, 1) + i * 60_000), total: i % 300 }))); const query = () => orders.find({ customerId: "c7" }).sort({ createdAt: -1 }).limit(10); const summary = async () => { const ex: any = await query().explain("executionStats"); const plan = JSON.stringify(ex.queryPlanner.winningPlan); return { scan: plan.includes("IXSCAN") ? "IXSCAN" : "COLLSCAN", inMemorySort: plan.includes('"SORT"'), docsExamined: ex.executionStats.totalDocsExamined, returned: ex.executionStats.nReturned }; }; console.log("before:", await summary()); await orders.createIndex({ customerId: 1, createdAt: -1 }); console.log("after: ", await summary()); await db.dropDatabase(); await client.close(); ``` ```out before: { scan: 'COLLSCAN', inMemorySort: true, docsExamined: 5000, returned: 10 } after: { scan: 'IXSCAN', inMemorySort: false, docsExamined: 10, returned: 10 } ```

לפני: כל 5,000 המסמכים נבדקו, ומוינו בזיכרון. אחרי: נבדקו רק 10 — האינדקס כבר ממוין לפי createdAt בתוך כל customerId, אז Mongo קורא את 10 הראשונים ועוצר. זה ESR בפעולה (E12). ובדיוק כמו ב־Postgres: כל אינדקס מאט כתיבות ותופס מקום — בונים לפי השאילתות שבאמת רצות.
