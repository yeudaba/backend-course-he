<p>בקובץ <code>18-consistency/starter/P18-E07.ts</code> השלם <code>transfer(pool, fromId, toId, amount)</code>: ב־transaction אחד — הורדה, הוספה ורישום ב־<code>transfers</code>; מחזירה את ה־id של ההעברה. כל שגיאה (למשל CHECK על יתרה) ← ROLLBACK, והשגיאה נזרקת הלאה. והחיבור משתחרר — תמיד.</p>
<p>הבדיקה מריצה גם 20 העברות שנכשלות על pool של 3 חיבורים: חיבור שלא שוחרר — והבדיקה תיתקע.</p>
@hint1
<p>הדפוס מהשיעור: <code>pool.connect()</code>, try/catch/finally.</p>
@hint2
<p><code>INSERT ... RETURNING id</code>, ו־<code>rows[0].id</code>.</p>
@solution
```ts save=solutions/P18-E07.ts
// P18-E07
import type { Pool } from "pg";

export async function transfer(pool: Pool, fromId: number, toId: number, amount: number): Promise<number> {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    await client.query("UPDATE accounts SET balance = balance - $1 WHERE id = $2", [amount, fromId]);
    await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2", [amount, toId]);
    const { rows } = await client.query("INSERT INTO transfers (from_id, to_id, amount) VALUES ($1, $2, $3) RETURNING id", [fromId, toId, amount]);
    await client.query("COMMIT");
    return rows[0].id;
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}
```
@mistakes
<ul><li><code>return</code> לפני <code>COMMIT</code> — ה־finally משחרר חיבור עם transaction פתוח, והבקשה הבאה שתקבל אותו תמשיך בתוך ה־transaction הזה.</li></ul>

```ts save=solutions/P18-E08.ts
// P18-E08
import type { Pool } from "pg";

export async function findByOwner(pool: Pool, owner: string) {
  const { rows } = await pool.query("SELECT id, owner, balance FROM accounts WHERE owner = $1 ORDER BY id", [owner]);
  return rows;
}

export async function searchOwners(pool: Pool, text: string) {
  const escaped = text.replace(/[\\%_]/g, "\\$&"); // % ו־_ שהמשתמש הקליד — כתווים רגילים
  const { rows } = await pool.query("SELECT id, owner, balance FROM accounts WHERE owner ILIKE '%' || $1 || '%' ORDER BY id", [escaped]);
  return rows;
}
```

```ts save=solutions/P18-E10.ts
// P18-E10
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function buy(pool: Pool, productId: number, qty: number): Promise<number> {
  const { rows } = await pool.query(
    "UPDATE inventory SET stock = stock - $2 WHERE product_id = $1 AND stock >= $2 RETURNING stock",
    [productId, qty]
  );
  if (rows.length > 0) return rows[0].stock;
  const exists = await pool.query("SELECT 1 FROM inventory WHERE product_id = $1", [productId]);
  throw new AppError(exists.rowCount === 0 ? "PRODUCT_NOT_FOUND" : "OUT_OF_STOCK");
}
```

```ts save=solutions/P18-E13.ts
// P18-E13
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function transferSafe(pool: Pool, fromId: number, toId: number, amount: number) {
  if (fromId === toId) throw new AppError("SAME_ACCOUNT");
  if (!(amount > 0)) throw new AppError("INVALID_AMOUNT");

  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    // נעילה לפי סדר id — שתי העברות הפוכות לא יחכו זו לזו במעגל
    const { rows } = await client.query("SELECT id, balance FROM accounts WHERE id = ANY($1) ORDER BY id FOR UPDATE", [[fromId, toId]]);
    const from = rows.find((r) => r.id === fromId);
    const to = rows.find((r) => r.id === toId);
    if (!from || !to) throw new AppError("ACCOUNT_NOT_FOUND");
    if (Number(from.balance) < amount) throw new AppError("INSUFFICIENT_FUNDS");

    const a = await client.query("UPDATE accounts SET balance = balance - $1 WHERE id = $2 RETURNING balance", [amount, fromId]);
    const b = await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2 RETURNING balance", [amount, toId]);
    const t = await client.query("INSERT INTO transfers (from_id, to_id, amount) VALUES ($1, $2, $3) RETURNING id", [fromId, toId, amount]);
    await client.query("COMMIT");
    return { transferId: t.rows[0].id, fromBalance: Number(a.rows[0].balance), toBalance: Number(b.rows[0].balance) };
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E14.ts
// P18-E14
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function bookSeat(pool: Pool, eventId: number, userId: number): Promise<number> {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const event = await client.query("SELECT capacity FROM events WHERE id = $1 FOR UPDATE", [eventId]);
    if (event.rowCount === 0) throw new AppError("EVENT_NOT_FOUND");
    const { rows } = await client.query("SELECT COUNT(*)::int AS taken FROM bookings WHERE event_id = $1", [eventId]);
    const capacity = event.rows[0].capacity;
    try {
      await client.query("INSERT INTO bookings (event_id, user_id) VALUES ($1, $2)", [eventId, userId]);
    } catch (err) {
      if ((err as { code?: string }).code === "23505") throw new AppError("ALREADY_BOOKED");
      throw err;
    }
    if (rows[0].taken >= capacity) throw new AppError("SOLD_OUT");
    await client.query("COMMIT");
    return capacity - rows[0].taken - 1;
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E18.ts
import type { Pool } from "pg";

export async function listOrders(pool: Pool, { after, limit = 20 }: { after?: number; limit?: number } = {}) {
  if (!Number.isInteger(limit) || limit < 1 || limit > 100) throw new RangeError("limit חייב להיות בין 1 ל־100");
  const { rows } = await pool.query("SELECT id, total FROM big_orders WHERE id > $1 ORDER BY id LIMIT $2", [after ?? 0, limit + 1]);

  const data = rows.slice(0, limit).map((r) => ({ id: r.id, total: Number(r.total) }));

}
```

@task
<p>בקובץ <code>18-consistency/starter/P18-E19.ts</code> השלם <code>withSerializableRetry(pool, work, { retries = 5 } = {})</code>:</p>

<p>הבדיקה: 15 "העלאות מונה" במקביל (קרא ← הוסף 1 ← כתוב) ב־Serializable — בלי ניסיון חוזר רובן נכשלות; עם — המונה מגיע ל־15.</p>
@hint1
<p>לולאת <code>for (let attempt = 0; ; attempt++)</code> סביב try/catch שלם (כמו P14-E19).</p>
@hint2

@solution
```ts save=solutions/P18-E19.ts
// P18-E19
import type { Pool, PoolClient } from "pg";

const RETRYABLE = new Set(["40001", "40P01"]);
const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));

export async function withSerializableRetry<T>(pool: Pool, work: (client: PoolClient) => Promise<T>, { retries = 5 } = {}): Promise<T> {
  const client = await pool.connect();
  try {
    for (let attempt = 0; ; attempt++) {
      try {
        await client.query("BEGIN ISOLATION LEVEL SERIALIZABLE");
        const result = await work(client);
        await client.query("COMMIT");
        return result;
      } catch (err) {
        await client.query("ROLLBACK");
        const code = (err as { code?: string }).code;
        if (!code || !RETRYABLE.has(code) || attempt >= retries) throw err;
        await sleep(5 + Math.random() * 20);
      }
    }
  } finally {
    client.release();
  }
}
```
<p>ההמתנה האקראית ("jitter") חשובה: בלי, כל המתנגשים מנסים שוב באותה מילישנייה — ומתנגשים שוב.</p>
@mistakes
<ul><li>לנסות שוב רק את הפקודה שנכשלה — ב־40001 כל ה־transaction פסול; צריך להתחיל מה־SELECT הראשון.</li></ul>

```ts save=solutions/P18-E23.ts
import type { Pool } from "pg";

export async function customersWithOrderCounts(pool: Pool, ids: number[]) {
  const people = await pool.query("SELECT id, full_name FROM people WHERE id = ANY($1)", [ids]);
  const counts = await pool.query("SELECT customer_id, COUNT(*)::int AS orders FROM big_orders WHERE customer_id = ANY($1) GROUP BY customer_id", [ids]);
  const byId = new Map(people.rows.map((p) => [p.id, p]));
  const countById = new Map(counts.rows.map((c) => [c.customer_id, c.orders]));
  return ids
    .filter((id) => byId.has(id))
    .map((id) => ({ id, fullName: byId.get(id).full_name, orders: countById.get(id) ?? 0 }));
}
```

```ts save=solutions/P18-E24.ts
// P18-E24
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  productId?: number;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

interface Item { productId: number; quantity: number }

async function existingOrder(pool: Pool, key: string) {
  const { rows } = await pool.query("SELECT id, total FROM shop_orders WHERE idempotency_key = $1", [key]);
  return rows[0] && { orderId: rows[0].id, total: Number(rows[0].total), replayed: true };
}

export async function checkout(pool: Pool, { customerId, items, idempotencyKey }: { customerId: number; items: Item[]; idempotencyKey: string }) {
  if (items.length === 0) throw new AppError("EMPTY_CART");
  const before = await existingOrder(pool, idempotencyKey);
  if (before) return before;

  const qty = new Map<number, number>();
  for (const i of items) qty.set(i.productId, (qty.get(i.productId) ?? 0) + i.quantity);
  const ids = [...qty.keys()].sort((a, b) => a - b);

  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const { rows: products } = await client.query("SELECT id, price, stock FROM catalog WHERE id = ANY($1) ORDER BY id FOR UPDATE", [ids]);
    if (products.length !== ids.length) throw new AppError("PRODUCT_NOT_FOUND");
    for (const p of products) {
      if (p.stock < qty.get(p.id)!) {
        const err = new AppError("OUT_OF_STOCK");
        err.productId = p.id;
        throw err;
      }
    }
    const total = products.reduce((sum, p) => sum + Number(p.price) * qty.get(p.id)!, 0);
    let orderId: number;
    try {
      const { rows } = await client.query(
        "INSERT INTO shop_orders (customer_id, idempotency_key, total) VALUES ($1, $2, $3) RETURNING id",
        [customerId, idempotencyKey, total.toFixed(2)]
      );
      orderId = rows[0].id;
    } catch (err) {
      if ((err as { code?: string }).code !== "23505") throw err;
      await client.query("ROLLBACK");
      return (await existingOrder(pool, idempotencyKey))!; // בקשה מקבילה עם אותו מפתח ניצחה
    }
    for (const p of products) {
      await client.query("INSERT INTO shop_order_lines (order_id, product_id, quantity, unit_price) VALUES ($1, $2, $3, $4)", [orderId, p.id, qty.get(p.id), p.price]);
      await client.query("UPDATE catalog SET stock = stock - $1 WHERE id = $2", [qty.get(p.id), p.id]);
    }
    await client.query("COMMIT");
    return { orderId, total: Number(total.toFixed(2)), replayed: false };
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}
```
<p>זה הלב של פרויקט הדגל, בגרסה מוקטנת. (ROLLBACK כפול — אחד ב־catch הפנימי ואחד בחיצוני — לא קורה, כי ה־return יוצא לפני. אבל אם תשנה את הזרימה, שים לב: ROLLBACK בלי transaction פתוח מחזיר רק אזהרה.)</p>

```ts save=solutions/P18-E26.ts
// P18-E26: withTransaction — עוזר שכותבים פעם אחת
import type { Pool, PoolClient } from "pg";

export async function withTransaction<T>(pool: Pool, fn: (client: PoolClient) => Promise<T>): Promise<T> {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const result = await fn(client);
    await client.query("COMMIT");
    return result;
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}

export async function transferAll(pool: Pool, fromId: number, toId: number): Promise<number> {
  return withTransaction(pool, async (client) => {
    const { rows } = await client.query("SELECT balance FROM accounts WHERE id = $1 FOR UPDATE", [fromId]);
    if (rows.length === 0) throw new Error(`חשבון לא קיים: ${fromId}`);
    const amount = Number(rows[0].balance);
    if (amount === 0) throw new Error("אין מה להעביר");
    await client.query("UPDATE accounts SET balance = 0 WHERE id = $1", [fromId]);
    const to = await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2", [amount, toId]);
    if (to.rowCount === 0) throw new Error(`חשבון לא קיים: ${toId}`);
    await client.query("INSERT INTO transfers (from_id, to_id, amount) VALUES ($1, $2, $3)", [fromId, toId, amount]);
    return amount;
  });
}
```
<p>עכשיו <code>transferAll</code> מכילה רק את מה שמיוחד לה. אין בה <code>BEGIN</code>, ‏<code>ROLLBACK</code> או <code>release</code>, ולכן גם אין איפה לשכוח אותם. כל פונקציה עתידית שצריכה transaction תקבל את אותה התנהגות נכונה בחינם. זה בדיוק מה ש־Prisma נותן ב־<code>$transaction(async (tx) =&gt; ...)</code> (פרק 19).</p>

<p>שגיאה ב"יעד לא קיים" מגיעה <em>אחרי</em> שכבר איפסנו את המקור. בלי transaction הכסף היה נעלם. כאן ה־ROLLBACK מחזיר הכול.</p>

@hint2
<p>ב־<code>flush</code>: קודם <code>const batch = waiting; waiting = new Map();</code>, כדי שקריאות חדשות ייכנסו לסיבוב הבא. אחר כך שאילתה עם <code>[...batch.keys()]</code>, ‏<code>Map</code> של התוצאות לפי id, ולולאה שקוראת ל־<code>resolve(byId.get(id) ?? null)</code> לכל ממתין. ב־catch: ‏<code>reject(err)</code> לכולם.</p>
@solution
```ts save=solutions/P18-E27.ts
// P18-E27: מאחד שליפות (batch loader)
import type { Pool } from "pg";

export type Person = { id: number; full_name: string };
type Waiter = { resolve: (p: Person | null) => void; reject: (err: unknown) => void };

export function createPersonLoader(pool: Pick<Pool, "query">) {
  let waiting = new Map<number, Waiter[]>();

  async function flush() {
    const batch = waiting;
    waiting = new Map();
    try {
      const { rows } = await pool.query("SELECT id, full_name FROM people WHERE id = ANY($1)", [[...batch.keys()]]);
      const byId = new Map<number, Person>(rows.map((p: Person) => [p.id, p]));
      for (const [id, waiters] of batch) {
        for (const w of waiters) w.resolve(byId.get(id) ?? null);
      }
    } catch (err) {
      for (const waiters of batch.values()) {
        for (const w of waiters) w.reject(err);
      }
    }
  }

  return function load(id: number): Promise<Person | null> {
    return new Promise((resolve, reject) => {
      if (waiting.size === 0) setTimeout(flush, 0);
      const list = waiting.get(id) ?? [];
      list.push({ resolve, reject });
      waiting.set(id, list);
    });
  };
}
```
<p>שלושה דברים חיים ב־closure, ובכל loader יש עותק משלהם: ה־<code>Map</code> של הממתינים, הפונקציה <code>flush</code>, והחיבור למסד. לכן שני loaders לא מערבבים בקשות.</p>
<p><code>new Promise((resolve, reject) =&gt; ...)</code> מאפשר "להחזיר תשובה אחר כך": ‏<code>load</code> מחזירה Promise מיד, ושומרת את <code>resolve</code> בצד. רק כשהשאילתה חוזרת, <code>flush</code> קוראת לו. זה ה־Promise "הידני" מפרק 10, ופה רואים בשביל מה הוא קיים.</p>
<p>ההחלפה <code>waiting = new Map()</code> <em>לפני</em> ה־<code>await</code> חשובה. בזמן שהשאילתה רצה, קריאות חדשות נכנסות ל־Map החדש ומתזמנות סיבוב משלהן, במקום ללכת לאיבוד.</p>
<p>בפרויקטי GraphQL זה הכלי הסטנדרטי נגד N+1: כל שדה "מבקש" את מה שהוא צריך, וה־loader מאחד הכול.</p>
@mistakes
<ul><li><code>setTimeout(flush, 0)</code> בכל קריאה — כמה <code>flush</code> רצים, והשני שולח שאילתה עם רשימה ריקה (או שולח שוב את אותם ids).</li><li>לנקות את ה־Map רק אחרי ה־<code>await</code> — קריאות שהגיעו בזמן השאילתה נמחקות ולא מקבלות תשובה לעולם.</li><li>לחזור עם <code>rows[i]</code> לפי מקום במערך — המסד לא מבטיח שהשורות יחזרו באותו סדר, ו־id חסר מזיז את כולם.</li><li>לשכוח <code>reject</code> ב־catch — כשהמסד נופל, כל הקוראים תקועים לנצח.</li></ul>

```ts save=solutions/P18-E35.ts
// P18-E35: פתיחת חשבון עם הפקדה ראשונה
import type { Pool } from "pg";

export async function openAccount(pool: Pool, owner: string, fromId: number, deposit: number): Promise<number> {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const { rows } = await client.query("INSERT INTO accounts (owner, balance) VALUES ($1, 0) RETURNING id", [owner]);
    const id: number = rows[0].id;
    await client.query("UPDATE accounts SET balance = balance - $1 WHERE id = $2", [deposit, fromId]);
    await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2", [deposit, id]);
    await client.query("INSERT INTO transfers (from_id, to_id, amount) VALUES ($1, $2, $3)", [fromId, id, deposit]);
    await client.query("COMMIT");
    return id;

    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E36.ts
// P18-E36: תשלום משכורות — הכול או כלום
import type { Pool } from "pg";

export async function payMany(pool: Pool, fromId: number, payments: { toId: number; amount: number }[]): Promise<number[]> {
  if (payments.length === 0) return [];
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const ids: number[] = [];
    for (const { toId, amount } of payments) {
      await client.query("UPDATE accounts SET balance = balance - $1 WHERE id = $2", [amount, fromId]);
      const to = await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2", [amount, toId]);
      if (to.rowCount === 0) throw new Error(`חשבון לא קיים: ${toId}`);

      ids.push(rows[0].id);
    }
    await client.query("COMMIT");
    return ids;
  } catch (err) {

    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E40.ts
// P18-E40: פנקס בזיכרון — הכול או כלום
export type Op = { from: string; to: string; amount: number };

export function applyAll(balances: Map<string, number>, ops: Op[]): Map<string, number> {
  const cents = new Map([...balances].map(([k, v]) => [k, Math.round(v * 100)] as [string, number]));
  for (const { from, to, amount } of ops) {
    for (const name of [from, to]) if (!cents.has(name)) throw new Error(`חשבון לא קיים: ${name}`);
    if (!(amount > 0)) throw new Error("סכום לא חוקי");
    const a = Math.round(amount * 100);
    if (cents.get(from)! < a) throw new Error(`אין מספיק כסף: ${from}`);
    cents.set(from, cents.get(from)! - a);
    cents.set(to, cents.get(to)! + a);
  }
  return new Map([...cents].map(([k, v]) => [k, v / 100] as [string, number]));
}
```

```ts save=solutions/P18-E41.ts
// P18-E41: route של העברה — Zod, transaction ו־status
import type { Pool } from "pg";
import { z } from "zod";

const TransferBody = z.object({
  fromId: z.number().int().positive(),
  toId: z.number().int().positive(),
  amount: z.number().positive().multipleOf(0.01),
});

class HttpFail extends Error {
  status: number;
  code: string;
  constructor(status: number, code: string) {
    super(code);
    this.status = status;
    this.code = code;
  }
}

export async function handleTransfer(pool: Pool, body: unknown): Promise<{ status: number; body: unknown }> {
  const parsed = TransferBody.safeParse(body);
  if (!parsed.success) return { status: 400, body: { error: "VALIDATION" } };
  const { fromId, toId, amount } = parsed.data;
  if (fromId === toId) return { status: 400, body: { error: "SAME_ACCOUNT" } };

  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const from = await client.query("UPDATE accounts SET balance = balance - $1 WHERE id = $2", [amount, fromId]);
    if (from.rowCount === 0) throw new HttpFail(404, "ACCOUNT_NOT_FOUND");
    const to = await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2", [amount, toId]);
    if (to.rowCount === 0) throw new HttpFail(404, "ACCOUNT_NOT_FOUND");
    const { rows } = await client.query("INSERT INTO transfers (from_id, to_id, amount) VALUES ($1, $2, $3) RETURNING id", [fromId, toId, amount]);
    await client.query("COMMIT");
    return { status: 201, body: { id: rows[0].id } };
  } catch (err: any) {
    await client.query("ROLLBACK");
    if (err instanceof HttpFail) return { status: err.status, body: { error: err.code } };
    if (err.code === "23514") return { status: 409, body: { error: "INSUFFICIENT_FUNDS" } };
    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E42.ts
// P18-E42: ייבוא העברות מ־CSV
import type { Pool } from "pg";

type Row = { n: number; from: number; to: number; amount: number };

function parse(csv: string): Row[] {
  const rows: Row[] = [];
  csv.split(/\r?\n/).forEach((line, i) => {
    const n = i + 1;
    if (n === 1 || line.trim() === "") return;
    const parts = line.split(",").map((s) => s.trim());
    const [from, to, amount] = parts.map(Number);
    const ok = parts.length === 3 && parts.every((p) => p !== "") && Number.isInteger(from) && from > 0 && Number.isInteger(to) && to > 0 && amount > 0;
    if (!ok) throw new Error(`שורה ${n}: לא תקינה`);
    rows.push({ n, from, to, amount });
  });
  return rows;
}

export async function importTransfers(pool: Pool, csv: string): Promise<number> {
  const rows = parse(csv);
  const client = await pool.connect();
  let current = 0;
  try {
    await client.query("BEGIN");
    for (const r of rows) {
      current = r.n;
      await client.query("UPDATE accounts SET balance = balance - $1 WHERE id = $2", [r.amount, r.from]);
      await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2", [r.amount, r.to]);
      await client.query("INSERT INTO transfers (from_id, to_id, amount) VALUES ($1, $2, $3)", [r.from, r.to, r.amount]);
    }
    await client.query("COMMIT");
    return rows.length;
  } catch (err: any) {
    await client.query("ROLLBACK");
    throw new Error(`שורה ${current}: ${err.message}`);
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E48.ts
// P18-E48: שמירת מלאי עם כלל "מלאי נמוך"
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function reserve(pool: Pool, productId: number, qty: number): Promise<number> {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const { rows } = await client.query("SELECT stock FROM inventory WHERE product_id = $1 FOR UPDATE", [productId]);
    if (rows.length === 0) throw new AppError("PRODUCT_NOT_FOUND");
    const stock: number = rows[0].stock;
    if (stock < 5 && qty > 2) throw new AppError("LOW_STOCK_LIMIT");
    if (qty > stock) throw new AppError("OUT_OF_STOCK");
    const updated = await client.query("UPDATE inventory SET stock = stock - $2 WHERE product_id = $1 RETURNING stock", [productId, qty]);
    await client.query("COMMIT");
    return updated.rows[0].stock;
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E52.ts
// P18-E52: mutex בזיכרון
export function createMutex() {
  let tail: Promise<unknown> = Promise.resolve();
  let count = 0;
  return {
    run<T>(fn: () => Promise<T>): Promise<T> {
      count++;
      const result = tail.then(() => fn());
      tail = result.catch(() => {}).finally(() => count--);
      return result;
    },
    pending: () => count,
  };
}
```

```ts save=solutions/P18-E53.ts
// P18-E53: מימוש קופון — פעם אחת לכל משתמש
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function redeem(pool: Pool, code: string, userId: number): Promise<number> {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const { rows } = await client.query("UPDATE coupons SET uses_left = uses_left - 1 WHERE code = $1 AND uses_left > 0 RETURNING uses_left", [code]);
    if (rows.length === 0) {
      const exists = await client.query("SELECT 1 FROM coupons WHERE code = $1", [code]);
      throw new AppError(exists.rowCount === 0 ? "COUPON_NOT_FOUND" : "COUPON_EXHAUSTED");
    }
    await client.query("INSERT INTO coupon_redemptions (code, user_id) VALUES ($1, $2)", [code, userId]);
    await client.query("COMMIT");
    return rows[0].uses_left;
  } catch (err: any) {
    await client.query("ROLLBACK");
    if (err.code === "23505") throw new AppError("ALREADY_REDEEMED");
    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E54.ts
// P18-E54: מגבלה יומית להעברות
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export async function transferWithLimit(pool: Pool, fromId: number, toId: number, amount: number, dailyLimit: number): Promise<number> {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const acc = await client.query("SELECT id FROM accounts WHERE id = $1 FOR UPDATE", [fromId]);
    if (acc.rowCount === 0) throw new AppError("ACCOUNT_NOT_FOUND");
    const { rows } = await client.query(
      "SELECT COALESCE(SUM(amount), 0) AS sent FROM transfers WHERE from_id = $1 AND created_at >= date_trunc('day', now())",
      [fromId],
    );
    if (Number(rows[0].sent) + amount > dailyLimit) throw new AppError("DAILY_LIMIT");
    await client.query("UPDATE accounts SET balance = balance - $1 WHERE id = $2", [amount, fromId]);
    await client.query("UPDATE accounts SET balance = balance + $1 WHERE id = $2", [amount, toId]);
    const t = await client.query("INSERT INTO transfers (from_id, to_id, amount) VALUES ($1, $2, $3) RETURNING id", [fromId, toId, amount]);
    await client.query("COMMIT");
    return t.rows[0].id;
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}
```

```ts save=solutions/P18-E66.ts
import type { Pool } from "pg";

export type PlanSummary = { nodes: string[]; seqScans: string[]; indexes: string[] };

export async function planSummary(pool: Pool, sql: string, params: unknown[] = []): Promise<PlanSummary> {
  const { rows } = await pool.query(`EXPLAIN (FORMAT JSON) ${sql}`, params);
  const root = rows[0]["QUERY PLAN"][0].Plan;
  const summary: PlanSummary = { nodes: [], seqScans: [], indexes: [] };
  const walk = (node: any) => {
    summary.nodes.push(node["Node Type"]);
    if (node["Node Type"] === "Seq Scan") summary.seqScans.push(node["Relation Name"]);
    if (node["Index Name"] && !summary.indexes.includes(node["Index Name"])) summary.indexes.push(node["Index Name"]);
    for (const child of node.Plans ?? []) walk(child);
  };
  walk(root);
  return summary;
}
```

@hint2
<p>שמור את המפתחות במערך נפרד (<code>keys</code>) אחרי המיון, כדי לא לקרוא ל־<code>key()</code> בכל השוואה.</p>
@solution
```ts save=solutions/P18-E67.ts
// P18-E67: "index" ממוין בזיכרון
export function createIndex<T>(rows: T[], key: (row: T) => number) {
  const sorted = rows.map((row, i) => ({ row, k: key(row), i })).sort((a, b) => a.k - b.k || a.i - b.i);
  const keys = sorted.map((s) => s.k);
  let count = 0;

  // האינדקס הראשון שבו keys[i] >= v (או > v כש־strict)
  const bound = (v: number, strict: boolean) => {
    let lo = 0;
    let hi = keys.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      count++;
      if (strict ? keys[mid] <= v : keys[mid] < v) lo = mid + 1;
      else hi = mid;
    }
    return lo;
  };
  const slice = (a: number, b: number) => sorted.slice(a, Math.max(a, b)).map((s) => s.row);

  return {
    eq: (v: number) => slice(bound(v, false), bound(v, true)),
    range: (from: number, to: number) => slice(bound(from, false), bound(to, false)),
    comparisons: () => count,
  };
}
```
<p>שני חיפושים בינאריים — "איפה מתחיל" ו"איפה נגמר" — ואז <code>slice</code> של רצף. זה בדיוק "Index Cond" ב־EXPLAIN: קפיצה לתחילת הטווח וקריאה ברצף. ‏<code>log2(100,000)</code> ≈ 17, כך ש־<code>eq</code> עושה כ־34 השוואות. המחיר: מיון אחד בהתחלה, וכל הוספה לנתונים מחייבת לשמור על הסדר — "כל כתיבה מעדכנת את ה־index".</p>

```ts save=solutions/P18-E75.ts
// P18-E75: הזמנות עם השורות שלהן — שתי שאילתות
import type { Pool } from "pg";

export type OrderWithLines = { id: number; total: number; lines: { product: string; quantity: number; unitPrice: number }[] };

export async function ordersWithLines(pool: Pool, orderIds: number[]): Promise<OrderWithLines[]> {
  if (orderIds.length === 0) return [];
  const ids = [...new Set(orderIds)];
  const orders = await pool.query("SELECT id, total FROM shop_orders WHERE id = ANY($1)", [ids]);
  const lines = await pool.query(
    `SELECT l.order_id, c.name AS product, l.quantity, l.unit_price
     FROM shop_order_lines l JOIN catalog c ON c.id = l.product_id
     WHERE l.order_id = ANY($1)
     ORDER BY l.order_id, c.name`,
    [ids],
  );
  const byOrder = new Map<number, OrderWithLines["lines"]>();
  for (const l of lines.rows) {
    if (!byOrder.has(l.order_id)) byOrder.set(l.order_id, []);
    byOrder.get(l.order_id)!.push({ product: l.product, quantity: l.quantity, unitPrice: Number(l.unit_price) });
  }
  const found = new Map<number, number>(orders.rows.map((o) => [o.id, Number(o.total)]));
  return ids.filter((id) => found.has(id)).map((id) => ({ id, total: found.get(id)!, lines: byOrder.get(id) ?? [] }));
}
```

```ts save=solutions/P18-E76.ts
// P18-E76: פיד עם cursor אטום
import type { Pool } from "pg";

export class AppError extends Error {
  code: string;
  constructor(code: string, message = code) {
    super(message);
    this.code = code;
  }
}

export function encodeCursor(createdAt: Date, id: number): string {
  return Buffer.from(`${createdAt.toISOString()}|${id}`).toString("base64url");
}

export function decodeCursor(cursor: string): { createdAt: Date; id: number } {
  const [iso, idText, ...rest] = Buffer.from(cursor, "base64url").toString().split("|");
  const createdAt = new Date(iso);
  const id = Number(idText);
  if (rest.length > 0 || !iso || Number.isNaN(createdAt.getTime()) || !Number.isInteger(id) || id <= 0) throw new AppError("BAD_CURSOR");
  return { createdAt, id };
}

export async function feed(pool: Pool, { customerId, cursor, limit = 20 }: { customerId: number; cursor?: string; limit?: number }) {
  if (!Number.isInteger(limit) || limit < 1 || limit > 100) throw new AppError("BAD_LIMIT");
  const params: unknown[] = [customerId];
  let where = "customer_id = $1";
  if (cursor !== undefined) {
    const c = decodeCursor(cursor);
    params.push(c.createdAt, c.id);
    where += " AND (created_at, id) < ($2, $3)";
  }
  params.push(limit + 1);
  const { rows } = await pool.query(
    `SELECT id, total, created_at FROM big_orders WHERE ${where} ORDER BY created_at DESC, id DESC LIMIT $${params.length}`,
    params,
  );
  const page = rows.slice(0, limit);
  const last = page.at(-1);
  return {
    data: page.map((r) => ({ id: r.id, total: Number(r.total) })),
    nextCursor: rows.length > limit && last ? encodeCursor(last.created_at, last.id) : null,
  };
}
```
<p>‏<code>limit + 1</code> עונה על "יש עוד?" בלי שאילתת COUNT (P18-E65). ה־cursor האטום נותן חופש: מחר אפשר לשנות את המיון או להוסיף שדה, והלקוחות לא נשברים — הם רק מעבירים את המחרוזת חזרה.</p>

```ts save=solutions/P18-E78.ts
// P18-E78: הכנסת אלפי שורות — בכמה פקודות?
import type { Pool } from "pg";

export async function insertTransfers(pool: Pool, rows: { from: number; to: number; amount: number }[]): Promise<number[]> {
  if (rows.length === 0) return [];
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const ids: number[] = [];
    for (let i = 0; i < rows.length; i += 1000) {
      const chunk = rows.slice(i, i + 1000);
      const values = chunk.map((_, j) => `($${j * 3 + 1}, $${j * 3 + 2}, $${j * 3 + 3})`).join(", ");
      const params = chunk.flatMap((r) => [r.from, r.to, r.amount]);
      const { rows: inserted } = await client.query(`INSERT INTO transfers (from_id, to_id, amount) VALUES ${values} RETURNING id`, params);
      ids.push(...inserted.map((r) => r.id));
    }
    await client.query("COMMIT");
    return ids;
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}
```

<p>21 × 2ms. וכמה "חלונות" כאלה נכנסים בשנייה, בכל אחד מ־10 החיבורים?</p>
@hint2
<p>מה קורה לתור כשנכנסים יותר ממה שיוצא?</p>
@solution
<ol><li>42ms לבקשה. חיבור אחד משרת כ־1000 ÷ 42 ≈ 23 בקשות בשנייה; עשרה — כ־238 בשנייה.</li><li>נכנסות 300, יוצאות 238: התור ל־pool גדל בכ־60 בקשות בכל שנייה, וזמני התגובה עולים בלי סוף — עד timeouts ו־503. מבחוץ זה נראה כמו "המסד איטי", אבל המסד כמעט לא עובד; כולם מחכים בתור.</li><li>2 × 2ms = 4ms ← כ־2,500 בקשות בשנייה. פי עשרה יותר קיבולת, מאותו מסד ואותו שרת.</li></ol>

@task
<p>ה־cursor מ־P18-E76 הוא <code>base64url</code> של <code>"2025-06-01T12:00:00.000Z|100000"</code>.</p>
<ol><li>האם הוא "מוצפן"? מה לקוח סקרן יכול לעשות איתו?</li><li>הלקוח שולח cursor שבנה בעצמו, עם <code>id</code> של הזמנה של לקוח <strong>אחר</strong>. האם הוא יקבל הזמנות שאינן שלו? למה?</li><li>מה יקרה אם <code>decodeCursor</code> לא הייתה בודקת כלום, והלקוח שולח <code>"abc"</code>?</li><li>מתי כדאי לחתום את ה־cursor (HMAC — פרק 21)?</li></ol>
<p>🔗 <strong>איך זה מתחבר:</strong> <code>Buffer</code> ו־base64 מפרק 13, ולידציה של קלט מפרק 15 — והשיעור: ה־cursor הוא קלט מהמשתמש כמו כל קלט.</p>
@hint1
<p><code>Buffer.from(cursor, "base64url").toString()</code> — כל אחד יכול להריץ את זה.</p>
@hint2
<p>מה מגביל את השאילתה ללקוח הנוכחי — ה־cursor, או ה־<code>WHERE customer_id = $1</code>?</p>
@solution
<ol><li>לא. base64 הוא קידוד, לא הצפנה — כל אחד מפענח ורואה זמן ו־id. הוא יכול לבנות cursor משלו כדי "לקפוץ" לנקודה כלשהי בזמן.</li><li>לא. ה־cursor רק קובע <strong>מאיפה</strong> להתחיל; ה־<code>customer_id</code> מגיע מהשרת (מהמשתמש המחובר, פרק 21), וה־WHERE מסנן לפיו. הכלל: מה שקובע הרשאה — לעולם לא מתוך ה־cursor.</li><li><code>new Date("abc")</code> ← Invalid Date ← <code>pg</code> נכשל עם שגיאה פנימית ← 500. עם הבדיקה ← 400 <code>BAD_CURSOR</code>.</li><li>כשה־cursor מכיל משהו שאסור לשנות: מזהה של חיפוש שמור, פילטרים שהשרת קבע, או כשלא רוצים שלקוחות יבנו cursors בעצמם (ואז מסתמכים על הפורמט שלהם). חתימה עם סוד של השרת ← אם שינו תו — החתימה לא מתאימה.</li></ol>
@mistakes
<ul><li>לשים ב־cursor את <code>customer_id</code> ולסמוך עליו — "הלקוח שלח, אז זה הוא". זו פרצה מ־OWASP API Top 10 (פרק 21).</li></ul>
